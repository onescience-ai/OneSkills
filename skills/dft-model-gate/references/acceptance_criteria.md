# 门限定义、默认值与依据

所有门限都从 `scripts/elements.py` 的半径数据推导，与体系无关。
下表 `--set key=value` 可用于覆盖（覆盖必须在交付报告中注明）。

## 通用门限（无需契约）

| 编号 | 门限 | 定义 | 默认 | 依据 / 放宽条件 |
|---|---|---|---|---|
| U1 | 结构可解析 | 晶胞体积 > 0，原子数与元素行一致 | — | 解析失败即输入错误 |
| U2 | 片段识别 | 非金属原子不应全部孤立 | — | 全部孤立说明键判据或结构有问题 |
| U2b | 骨架声明 | 契约须给 `framework.elements` | — | 只有单金属体系可省，但会有 WARN |
| U3 | 键长合理性 | 每条键 `d/(r_cov_i+r_cov_j) ∈ [0.70, 1.30]` | `bond_len_range` | 超出说明键判据过松（把非键合当成了键） |
| U4 | 非键合接触 | 见下 | — | **硬门限，不应放宽** |
| U5 | 氢键几何 | H···受体不应落在 (1.0, 1.30) Å | `hbond_h_min` | 更短会引发质子转移，属结构错误 |
| U6 | 维度与真空 | 判定为 2D 时真空 ≥ `vacuum_min` | 12 Å | 含偶极修正建议 15–20 Å |

### U4 的非键合下限（`nonbonded_floor`）

排除 1-2（成键）与 1-3（共用一个成键邻居，如 H–O–H 的两个 H）原子对后：

| 原子对 | 下限 | 说明 |
|---|---|---|
| H···H | `0.80 × (r_vdw_H + r_vdw_H)` = 1.92 Å | 非键合 H···H 不可能低于约 2.0 Å |
| H···电负性原子（N/O/F/S/Cl/Br/I） | `hbond_h_min` = 1.30 Å | **不设 vdW 下限**：正常氢键 1.6–2.2 Å 必须能通过 |
| H···其它（金属、C 等） | `0.80 × (r_vdw_i + r_vdw_j)` | 例如 H 指向金属/碳 |
| 重原子···重原子 | `1.00 × (r_cov_i + r_cov_j)` | 用共价半径，避免离子性接触（K⁺···O 2.8 Å）被误判 |

> 为什么 H···受体不按 vdW 卡：vdW 和约 2.7 Å，而典型氢键就是 1.8–2.0 Å。
> 按 vdW 卡会把**全部正常氢键**判成碰撞；按 1.30 Å 卡则只拦质子转移。

### 1-3 对为什么要排除

水分子内两个 H 相距约 `2 × 0.96 × sin(52.25°) ≈ 1.52 Å`，远低于 1.92 Å。
它是分子内几何（由 H–X–H 角决定），不是"接触"问题。不排除会造成**假 FAIL**。

## 契约门限

| 编号 | 门限 | 定义 | 默认 |
|---|---|---|---|
| C1 | 物种计数 | 每个声明物种的实测个数 == `count` | 严格相等 |
| C2-solvent | 液体膜密度 | `N / (A × (重原子跨度 + 最近邻间距))` 与体相数密度之比 ∈ `density_ratio_range` | [0.75, 1.35] |
| C2-solvent | 氢键网络 | 平均氢键数/分子 ∈ `hbond_per_molecule_range`；每受体接受数 ≤ `hbond_accept_max` | [1.0, 4.5]；2 |
| C2-solvent | 不穿金属 | 溶剂原子不得低于金属顶层 − `sink_tol` | 0.20 Å |
| C2-adsorbate | 最小骨架接触 | `mode=physisorbed` 时 ≥ `0.90 × (r_vdw_金属 + r_vdw_近端原子)`；或显式 `min_contact` | 0.90 |
| C2-ion | 配位壳层 | 配位数 ∈ `coordination_range`（未声明则只报告） | 报告 |
| C3 | slab 声明 | 金属层数 == `layers`（按 `layer_tol` 聚类） | 严格相等 |
| C4 | 固定原子 | 有固定原子，全为金属，`F F F`，且为最底部连续金属层 | 硬门限 |

### 膜厚口径（重要）

`thickness = z 跨度(重原子) + 平均最近邻间距`

- 只用重原子跨度：漏掉分子自身尺寸 → 密度高估。
- 只用含 H 全跨度：把外侧 H 也算进膜厚 → 密度低估。
- 门限同时报告两种口径，便于判断结论是否对口径敏感。

### 氢键判据（与 `hbond_pack` 共用）

一条 D–H···A 记为氢键，当且仅当：
`d(H···A) ≤ hbond_h_max (2.50 Å)` **且** `∠(D–H···A) ≥ hbond_angle_min (120°)`。

排序/打分用的"供体截断"为 `d(D···A) ≤ 3.30 Å`：目标再远，H 也够不到 2.4 Å 以内。

## VASP 输入门限

| 编号 | 门限 | 判定 |
|---|---|---|
| I0 | KPOINTS 行序 | 第 2 行必须是整数 Nk，否则 FAIL（VASP 起不来） |
| I2 | POTCAR 匹配 | 元素顺序与 POSCAR 一致；段数 == 元素种类数 |
| I3 | ENCUT | `ENMAX` 取自 POTCAR 现算；`ENCUT ≥ ENMAX` 为底线，`≥ 1.3 × ENMAX` 才 PASS，1.0–1.3 倍为 WARN |
| I4 | 金属 smearing | 含金属却 `ISMEAR=0` → WARN（建议 1/2） |
| I5 | 色散修正 | 含分子/吸附物却无色散 → FAIL（物理吸附能系统性错误） |
| I6 | 偶极修正 | 无 `LDIPOL/IDIPOL` → WARN |
| I7 | ISIF | slab 非 `ISIF=2` → WARN |
| I8 | ISYM | 含无序溶剂却 `ISYM≠0` → WARN |
| I9 | K 点密度 | 金属体系面内 `|a| × N_k < 25 Å` → FAIL |

## 合理放宽的姿势

1. **先确认是门限不适用，而不是结构不好。** 例如化学吸附构型下
   `mode: "chemisorbed"` + 显式 `min_contact` 就是正确用法，不是放宽。
2. 用 `--set key=value` 覆盖，并在交付报告中写明：改了哪个、改成多少、为什么。
3. **不要改脚本**去让某个结构通过。门限脚本的阈值是可配置的，逻辑不该动。
4. 若某门限在你的体系里系统性误判，应把它作为"门限不适用"记录在案，
   而不是悄悄提高阈值。
