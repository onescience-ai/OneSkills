# 多孔与复杂输运流动场数据驱动预测

## 适用范围

**触发条件**：
- 需要从多孔介质 CFD 模拟数据中训练数据驱动模型
- 需要预测多孔介质内部的速度场、压力场、浓度场等物理量
- 需要在多工况、多几何条件下快速评估流动特性

**适用场景**：
- 多孔介质微流动（microflow）与输运过程的 CFD 数据驱动预测
- 需要 CNN surrogate 或 Neural differential equation 等深度学习代理模型
- 需要产出可复现模型、物理一致性评估和适用域报告的研究或工程场景
- 树脂传递成型（RTM）等工业过程中的流动预测与优化

**不适用场景**：
- 纯宏观多孔介质等效模型（如 Darcy 定律直接求解）
- 不涉及 CFD 数据的物理场预测
- 无网格、无坐标的纯标量数据回归任务

## 输入

- 多孔介质 CFD 模拟数据集（包含网格坐标、物理场变量、工况参数）
- 数据契约：定义输入字段、目标字段、单位、坐标系
- 数据集路径与名称

## 输出

- 可复现的神经网络代理模型（checkpoint）
- 任务结果（apriori 闭合项预测、aposteriori 流场预测）
- 物理一致性评估报告
- 适用域报告与域外工况复核建议

## 流程节点

### Step 1：数据接入与契约核验
- **操作**：接入多孔介质微流动与输运 CFD 数据，核验样本、变量、单位、网格坐标及许可
- **参数**：数据集路径、数据集名称、数据契约
- **工具**：数据读取库、JSON 处理
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏

### Step 2：预处理与数据切分
- **操作**：统一物理量与表示，按几何、工况或时间构造无泄漏切分
- **参数**：切分配置（train/val/test 比例、随机种子、分组方式）、目标变量、是否无量纲化
- **工具**：数据预处理库
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏

### Step 3：模型配置与训练
- **操作**：训练 CNN surrogate 和 Neural differential equation 模型
- **参数**：模型名称、训练配置（框架、epochs、batch_size、学习率、种子、早停耐心）
- **工具**：PyTorch
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现

### Step 4：闭合项预测与后验 CFD 耦合
- **操作**：先验评估闭合项，再嵌入 RANS 或 LES 执行稳定后验推进
- **参数**：模型权重、计算设备、推理批大小
- **工具**：训练好的模型、CFD 求解器（RANS/LES）
- **质量门禁**：闭合张量或通量满足约束；后验求解无非物理解和发散；均值剖面与能谱均经验证

### Step 5：任务验收与适用域判定
- **操作**：评估统计误差、关键物理约束、泛化能力和计算收益
- **参数**：验收指标（closure RMSE、mean profile error、spectrum error、stability horizon）、相对误差门限、是否外推测试
- **工具**：评估脚本
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 模型类型 | CNN surrogate, Neural differential equation | [1][2][3][4] | 数据驱动代理模型的两类核心架构 |
| 切分方式 | 按几何、完整轨迹或物理工况为单位 | [3][4] | 防止同一轨迹帧随机打散导致数据泄漏 |
| 闭合项检查 | 先验误差 + 可实现性检查 | [2][3] | 嵌入求解器前必须验证闭合项物理合理性 |
| 后验验证 | 残差、能谱、统计剖面、稳定性记录 | [2][3][4] | 后验推进必须检查多个物理一致性指标 |
| 适用域外推 | 几何或工况外推测试 | [1][2] | 不得仅凭平均误差宣称工程可用 |

## 边界与分流

- **数据文件不可读或样本缺失**：返回 BLOCKED，列出缺项，不编造数据
- **数据契约不完整**：返回 BLOCKED，要求补全输入目标变量、单位、坐标定义
- **训练验证损失出现 NaN 或 Inf**：记录失败原因，检查数据质量与模型配置，必要时调整学习率或批大小
- **后验求解器发散**：检查闭合项可实现性，回退到先验评估，或调整求解器参数
- **域外工况精度不达标**：明确标注适用域边界，建议用户对域外工况进行 CFD 复核

## 质量检查

- 数据文件可读性检查：文件存在、格式正确、字段完整
- 样本追溯性检查：每个样本可关联到原始 CFD 模拟
- 训练-测试泄漏检查：无同一轨迹的帧同时出现在训练集和测试集
- 模型权重可加载检查：最佳 checkpoint 可重新加载并推理
- 物理一致性检查：闭合张量满足对称性/正定性等约束；后验场无负压、负浓度等非物理值
- 适用域报告完整性：包含最差样本分析、泛化能力评估、域外工况复核建议

## 回退策略

- 若数据不满足切分要求（如工况数不足），可降低切分比例或增加数据采集
- 若模型训练失败，可尝试简化模型架构或调整超参数
- 若后验耦合不稳定，可回退到纯先验评估，仅报告闭合项预测精度
- 若适用域报告无法给出可用性结论，标注为 BLOCKED 并建议领域专家复核
