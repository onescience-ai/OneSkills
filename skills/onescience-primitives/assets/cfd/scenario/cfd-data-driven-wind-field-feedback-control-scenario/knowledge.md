# 数据驱动风场与非定常流反馈控制（CFD_S084）

## 适用范围

本场景面向风场尾迹状态与反馈控制数据，完成数据驱动风场与非定常流反馈控制。典型任务包括：尾迹偏转控制以优化风场布局、减阻控制以降低流体阻力、涡脱落抑制以改善气动性能、主动流动控制以提升系统稳定性。

**适用条件**：
- 拥有足够质量的风场尾迹或非定常流数据（包含控制输入与流场响应）
- 控制目标明确（减阻、偏转、抑制等）
- 流动状态在训练数据覆盖范围内

**不适用条件**：
- 数据量不足以训练降阶模型
- 流动工况严重偏离训练数据分布（域外工况）
- 需要高保真度CFD验证的工程应用（需CFD复核）

## 场景定义

数据驱动风场与非定常流反馈控制是利用机器学习方法从历史流场数据中学习动力学模型，并设计反馈控制策略来主动调节流动状态的技术路线。核心是将高维流场动力学降维到可控制的低维空间，通过实时观测-预测-控制闭环实现对非定常流动的主动干预。

## 模型与方法

| 模型类型 | 说明 | 适用阶段 |
|---|---|---|
| Reduced-order controller | 基于POD/DMD等降维方法的线性/非线性控制器 | 模型配置与训练 |
| Neural MPC | 神经网络模型预测控制，结合数据驱动模型与优化控制 | 闭环策略部署 |

## HPC环境

- **CFD工具**：OpenFOAM（用于高保真度复核和基线对比）
- **计算框架**：PyTorch（用于神经网络训练和推理）

## 关键约束

1. **数据依赖性**：控制策略性能受限于训练数据的覆盖范围和质量
2. **物理一致性**：数据驱动模型需满足流体力学基本守恒律
3. **实时性要求**：控制器响应时间需满足流动控制的实时性需求
4. **安全边界**：控制动作需在物理约束范围内（幅值、频率）

## 适用域边界

| 维度 | 训练域内 | 域外（需CFD复核） |
|---|---|---|
| 雷诺数范围 | 训练数据覆盖的Re范围 | Re偏差>20% |
| 几何构型 | 训练数据中的几何 | 新型几何 |
| 控制频率 | 训练数据中的控制频率 | 更高频率 |
| 流动状态 | 亚临界/超临界一致 | 状态转换 |

## 关联工作流

本场景对应5节点端到端工作流：
1. 数据接入与契约核验 → 2. 预处理与数据切分 → 3. 模型配置与训练 → 4. 闭环策略部署与滚动仿真 → 5. 任务验收与适用域判定
