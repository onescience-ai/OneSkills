# 隐式神经场连续流动降阶建模

## 适用范围

本场景适用于基于连续坐标采样的PDE快照数据，构建隐式神经场连续流动降阶模型（Implicit Neural Representation + Continuous ROM）。主要面向流体动力学中的连续场量重建与降阶建模任务，包括但不限于湍流场、速度场、压力场等物理量的连续表示与预测。

**触发条件**：
- 输入数据为连续坐标采样的PDE快照
- 需要构建连续场量的降阶表示
- 需要评估物理一致性与适用域边界

**不适用场景**：
- 离散网格数据的直接处理（需先进行坐标连续化）
- 强间断流场的高保真模拟（需要CFD复核）
- 域外工况的直接外推（需重新训练或CFD验证）

## 输入

**数据源**：
- 连续坐标采样的PDE快照数据集
- 支持多种文件格式（h5、npy、npz等）
- 包含空间坐标(x,y,z)和时间坐标t

**数据契约**：
```json
{
  "input_fields": ["空间坐标", "时间坐标", "边界条件"],
  "target_fields": ["速度场", "压力场", "温度场", "湍流量"],
  "units": {
    "coordinates": "SI单位或归一化",
    "velocity": "m/s",
    "pressure": "Pa",
    "temperature": "K"
  },
  "coordinates": "连续坐标"
}
```

**预处理要求**：
- 坐标归一化或标准化
- 物理量无量纲化处理
- 边界掩膜生成

## 输出

**模型产物**：
- 隐式神经场表示模型（best_checkpoint.pt）
- 连续降阶模型（CROM权重）
- 训练配置与指标

**评估产物**：
- 物理一致性评估报告
- 适用域判定报告
- 最差样本分析

**验证标准**：
- 相对L2误差 < 0.1
- 守恒残差在可接受范围内
- 边界误差满足物理约束

## 流程节点

### 1. 数据接入与契约核验（s01）
- **操作**：读取数据集，建立数据清单，核验样本、变量、单位、网格坐标
- **参数**：数据集路径、数据集名称、数据契约模板
- **工具**：数据加载器、契约验证器
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏

### 2. 预处理与数据切分（s02）
- **操作**：统一物理量与表示，按几何、工况或时间构造无泄漏切分
- **参数**：切分配置、目标变量、是否无量纲化
- **工具**：数据预处理器、切分器
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏

### 3. 模型配置与训练（s03）
- **操作**：训练Implicit neural representation和Continuous ROM
- **参数**：模型名称、训练配置、初始权重（可选）
- **工具**：PyTorch训练框架、早停机制
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现

### 4. 批量推理与物理恢复（s04）
- **操作**：在独立测试集推理，恢复原始单位、网格和物理派生量
- **参数**：模型权重、计算设备、推理批大小
- **工具**：推理引擎、反归一化器
- **质量门禁**：预测无NaN或Inf且形状单位正确；每个测试样本有唯一结果；推理未使用测试目标校正

### 5. 任务验收与适用域判定（s05）
- **操作**：评估统计误差、关键物理约束、泛化能力和计算收益
- **参数**：验收指标、相对误差门限、是否外推测试
- **工具**：评估指标计算器、适用域分析器
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议

## 边界与分流

**前提条件与改道**：

1. **数据为连续坐标采样**
   - 不成立时 → 改道：先进行坐标连续化处理，或使用基于网格的降阶方法（如POD）

2. **PDE快照数据完整**
   - 不成立时 → 改道：进行数据修复或使用降阶方法中的数据同化技术

3. **物理约束可验证**
   - 不成立时 → 改道：仅进行统计误差评估，物理一致性验证标记为"证据有限"

4. **训练收敛**
   - 不成立时 → 改道：调整超参数、使用学习率调度器、检查数据质量

5. **测试集误差在阈值内**
   - 不成立时 → 改道：进行误差分析、检查模型容量、考虑更复杂的神经表示

## 质量检查

**验证点**：
- 数据完整性检查（缺失值、异常值）
- 模型收敛性验证（损失曲线、梯度稳定性）
- 物理一致性验证（守恒律、边界条件）
- 适用域边界测试（OOD工况）

**阈值**：
- 相对L2误差 < 0.1
- 守恒残差 < 0.01（归一化后）
- 边界误差 < 0.05

**失败处理**：
- 数据质量问题 → 返回s01重新核验
- 训练不收敛 → 调整超参数重试
- 物理不一致 → 标记为BLOCKED，需要CFD复核
- 适用域外 → 明确标注边界，提供复核建议

## 回退策略

**失败时的替代方案**：
1. 模型训练失败 → 尝试简化模型结构或使用迁移学习
2. 物理一致性不足 → 增加物理约束损失项
3. 适用域过窄 → 使用领域自适应或多保真度建模
4. 计算成本过高 → 使用模型压缩或蒸馏技术
