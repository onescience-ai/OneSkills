# CycleGAN无配对LES到DNS超分辨率重建场景

## 适用范围

**触发条件**：
- 拥有非配对的LES（大涡模拟）与DNS（直接数值模拟）湍流数据
- 需要从低分辨LES流场重建高分辨DNS流场
- 数据之间无配对对应关系（不同网格、不同工况、不同时间序列）

**适用场景**：
- 湍流超分辨率重建：LES粗网格结果到DNS精细结果的细节恢复
- CFD后处理增强：提升工程LES模拟的流场分辨率
- 物理一致性评估：验证超分辨重建是否保持湍流统计特性
- 域外工况泛化测试与适用域判定

**不适用场景**：
- LES与DNS数据完全配对的监督学习超分辨率任务
- 纯图像超分辨率（不涉及湍流物理约束）
- 需要实时在线推理的嵌入式部署场景
- 非流体动力学领域的其他超分辨率问题

## 输入

- 非配对LES湍流数据集（低分辨流场快照）
- 非配对DNS湍流数据集（高分辨参考流场）
- 数据集路径（目录或清单文件）
- 数据契约定义（变量、单位、网格坐标）
- 训练超参数配置
- 计算设备配置（CPU/CUDA）

## 输出

- 可复现的CycleGAN模型checkpoint
- 测试集重构流场与误差场
- 能谱统计与物理一致性评估
- 统计误差、物理约束评估与适用域报告
- PASS/REJECT/BLOCKED判定结论

## 流程节点

### s01 数据接入与契约核验
- **操作**：接入非配对LES与DNS湍流数据，核验样本、变量、单位、网格坐标及许可
- **参数**：数据集路径、数据集名称、数据契约
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏

### s02 预处理与数据切分
- **操作**：统一物理量与表示，按几何、工况或时间构造无泄漏切分
- **参数**：切分配置（train 0.7/val 0.15/test 0.15）、目标变量、无量纲化选项
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏

### s03 模型配置与训练
- **操作**：训练CycleGAN完成LES到DNS的无配对映射
- **参数**：模型名称（CycleGAN）、训练配置（PyTorch, epochs=100, batch=8, lr=0.001, seed=42, early_stopping_patience=15）
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现

### s04 低分辨或部分观测流场重构
- **操作**：从低分辨、稀疏或缺损输入恢复完整高分辨率流场
- **参数**：模型权重checkpoint、计算设备、推理批大小
- **质量门禁**：观测掩膜与训练测试协议一致；小尺度频谱与统计量得到验证；边界守恒误差不因超分辨恶化

### s05 任务验收与适用域判定
- **操作**：评估统计误差、关键物理约束、泛化能力和计算收益
- **参数**：验收指标（relative_L2, spectrum_error, gradient_error, conservation_error）、相对误差门限（0.1）、外推测试开关
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 切分比例 | train: 0.7, val: 0.15, test: 0.15 | 场景需求书 s02 | 标准三切分，按几何或轨迹分组 |
| 切分单位 | 按几何、完整轨迹或物理工况 | 场景需求书 s02 | 保证训练/测试独立性 |
| 统计量来源 | 仅用训练集计算 | 场景需求书 s02 | 防止信息泄漏 |
| 验收门限 | 相对L2误差 ≤ 0.1（可调） | 场景需求书 s05 | 量化工程可用性判据 |
| 外推测试 | 几何/工况外推需单独评估 | 场景需求书 s05 | 适用域判定必要条件 |

## 边界与分流

| 前提 | 不成立时的改道 |
|------|---------------|
| LES与DNS数据不可用 | 返回BLOCKED并列出缺项，不编造数据 |
| 数据契约字段不完整 | 补充缺失字段定义或拒绝执行 |
| 同一轨迹帧被打散 | 重新执行切分，修正分组键 |
| CycleGAN训练不收敛 | 调整超参数或回退到监督超分辨模型 |
| 重构频谱严重偏离DNS | 检查模型架构或增加频谱损失项 |
| 域外工况超出分布 | 不宣称工程可用，需CFD复核 |
| 边界守恒误差恶化 | 施加守恒约束后处理或调整网络结构 |

## 质量检查

| 检查点 | 通过标准 | 失败处理 |
|--------|---------|---------|
| 数据可读性 | 文件加载成功，样本数一致 | 返回BLOCKED |
| 切分互斥性 | train/val/test无重叠 | 重新切分 |
| 训练收敛 | val_loss有限且无NaN | 调参重训 |
| 权重可加载 | checkpoint加载一致 | 重新保存 |
| 频谱一致性 | 小尺度能谱偏差在可接受范围 | 增加频谱损失 |
| 边界守恒 | 守恒误差不超限 | 施加约束后处理 |
| 最差样本 | worst_cases.csv可追溯 | 补充分析 |
| 适用域 | 含边界与复核建议 | 补充外推 |

## 回退策略

- 数据不可用：返回BLOCKED
- CycleGAN训练不收敛：回退到监督超分辨模型（若有配对数据）
- 重构物理不一致：回退到传统插值方法作为基线对比
- 验收REJECT：不输出工程可用结论，需CFD复核
