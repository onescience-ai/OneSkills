# 气动弹性与非定常载荷降阶响应预测任务

## 适用范围
本任务面向气动弹性与非定常载荷降阶响应预测，提供从高保真CFD数据中构建降阶模型（ROM）的完整方法路线。适用于跨声速颤振、抖振等非线性气动弹性问题的快速预测，包括翼型/机翼的颤振分析、阵风响应、机动载荷预测等场景。

不适用场景：稳态气动载荷预测（无需时序建模）、完全线性系统（可使用解析方法）、极高马赫数/高温气体效应（需特殊物理模型）。

## 任务目标
1. 从高保真CFD仿真数据中提取非定常气动力与结构响应的低阶动力学模型
2. 建立能够预测气动弹性稳定性、频率锁定和极限环振幅的降阶模型
3. 实现从单次指定运动CFD仿真中学习多模态气动耦合关系
4. 提供训练超参数推荐和评估指标阈值

## 输入契约
**必需输入**：
- 非定常气动力时序数据：包含时间步、工况参数（马赫数、攻角等）、气动力系数、结构响应
- 结构模态坐标：m个结构模态的位移、速度、加速度时序
- 训练数据生成配置：指定运动类型、激励信号参数

**可选输入**：
- 初始流场条件：平均气动力、流体振荡频率
- 物理约束参数：质量比、阻尼比、频率比

**数据格式要求**：
- 时间序列：均匀采样间隔Δt，包含时间步索引
- 物理量：国际单位制，明确标注单位
- 文件格式：CSV、JSON或HDF5

## 输出契约
**必需输出**：
- 训练好的降阶模型检查点
- 模型参数文件：Rayleigh振荡器参数、Volterra核系数、神经网络权重
- 评估报告：稳定性预测、频率锁定区域、极限环振幅

**输出格式**：
- 模型检查点：PyTorch .pt格式
- 参数文件：JSON格式
- 评估报告：Markdown或JSON格式

## 方法路线
### 阶段1：数据准备与预处理
1. **CFD仿真数据生成**：在指定工况下运行非定常CFD仿真
2. **数据提取**：提取气动力系数、结构响应、压力分布
3. **数据清洗**：低通滤波去除高频噪声，有限差分计算导数
4. **数据切分**：训练集、验证集、测试集划分（7:1.5:1.5）

### 阶段2：模型构建
1. **Rayleigh流体振荡器**：建立自激振荡流体动力学模型
   - 参数：ω_F（流体振荡频率）、ε_i（线性增长/非线性饱和）、α_i（非线性参数）
2. **Rayleigh-Volterra流体-结构振荡器**：引入结构运动影响
   - 多输入Volterra级数：对角剪枝减少计算量
   - 核系数：H_{j1...jp}^{i,p,Ξ}[k]描述模态耦合
3. **神经网络修正**：补偿Rayleigh-Volterra模型的不足
   - 架构：2个隐藏层（tanh激活）+线性输出层
   - 输入：当前气动状态+结构运动历史

### 阶段3：模型训练
1. **损失函数**：均方轨迹误差 + L2正则化
2. **优化器**：Adam或LBFGS
3. **训练策略**：反向传播通过离散时间展开
4. **超参数**：
   - 学习率：1e-4 ~ 1e-3
   - 批量大小：全序列或小批量
   - 训练轮数：100-500轮（早停耐心15轮）

### 阶段4：模型评估
1. **稳定性预测**：气动阻尼比、颤振边界
2. **频率响应**：频率锁定区域、相位差
3. **极限环预测**：LCO振幅、波形
4. **泛化能力**：新工况下的预测精度

## 操作序列
1. **数据接入**：加载CFD仿真数据，验证格式完整性
2. **预处理**：滤波、导数计算、无量纲化
3. **模型初始化**：设置Rayleigh参数、Volterra核阶数、神经网络架构
4. **训练执行**：优化模型参数，监控损失收敛
5. **验证评估**：在验证集上评估模型性能
6. **测试评估**：在测试集上最终评估
7. **结果输出**：保存模型、参数、评估报告

## 验证契约
### 物理一致性验证
- 守恒残差：≤ 0.01
- 边界误差：≤ 0.05
- 能量守恒：无非物理能量增长

### 预测精度验证
- 相对L2误差：≤ 0.1（测试集）
- 频率误差：≤ 5%
- 振幅误差：≤ 10%

### 泛化能力验证
- 外推工况：马赫数±0.1，攻角±2°
- 多模态预测：至少2个结构模态

## 边界与分流
- **数据不足**：使用数据增强或迁移学习，参考相似翼型数据
- **模型不收敛**：调整学习率，尝试不同优化器，检查数据质量
- **外推性能差**：扩展训练数据范围，使用物理约束正则化
- **物理约束违反**：引入守恒律约束，调整模型架构
- **计算资源不足**：简化模型，减少Volterra核阶数，使用更高效训练策略

## 质量检查
**验证点**：
1. 数据完整性：时间序列连续，无缺失值
2. 模型收敛性：损失函数稳定下降，无振荡
3. 物理一致性：气动阻尼符号正确，能量守恒
4. 预测精度：相对误差在阈值内
5. 泛化能力：外推工况预测可靠

**阈值**：
- 相对L2误差 ≤ 0.1
- 频率误差 ≤ 5%
- 振幅误差 ≤ 10%
- 守恒残差 ≤ 0.01

**失败处理**：
- 数据问题：返回BLOCKED，列出缺项
- 训练失败：检查超参数，尝试不同配置
- 评估不通过：进行误差分析，确定是否需重新训练

## 回退策略
- **数据不足**：使用数据增强技术或迁移学习
- **模型过于复杂**：简化模型架构，减少Volterra核阶数
- **计算成本过高**：使用更高效的训练策略或近似方法
- **物理约束难以满足**：采用混合方法（数据驱动+物理模型）
