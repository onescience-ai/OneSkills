# 预处理与数据切分任务

## 适用范围

适用于数据驱动流场控制任务的数据准备阶段，负责对原始数据进行质量控制、特征工程、归一化处理，并按物理独立性原则构造训练/验证/测试集切分。

## 输入

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 切分配置 `{SPLIT_CONFIG}` | object | 是 | 按对象工况切分比例 |
| 目标变量 `{TARGET_FIELDS}` | list[str] | 是 | 待预测物理量 |
| 是否无量纲化 `{NONDIMENSIONALIZE}` | bool | 否 | 统一跨工况量纲 |

## 输出

- `train_manifest.json`：训练集清单
- `validation_manifest.json`：验证集清单
- `test_manifest.json`：测试集清单
- `normalization.json`：归一化统计量（仅基于训练集计算）

## 流程节点

1. **质量控制**：基于s01审计结果，过滤不合格样本
2. **特征构建**：根据数据契约构建输入特征（控制输入、边界条件、时间步）
3. **归一化处理**：基于训练集计算统计量（均值、方差），应用到所有数据集
4. **切分执行**：按几何构型、完整轨迹或物理工况为单位切分
5. **一致性验证**：确认切分后数据集无重叠、无泄漏

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|---|---|---|---|
| 训练集比例 | 0.7 | 默认值 | 占总数据70% |
| 验证集比例 | 0.15 | 默认值 | 占总数据15% |
| 测试集比例 | 0.15 | 默认值 | 占总数据15% |
| 随机种子 | 42 | 默认值 | 确保可复现性 |
| 切分单位 | geometry_or_trajectory | 默认值 | 按几何或轨迹切分 |

## 边界与分流

| 条件 | 处理 |
|---|---|
| 数据量不足 | 减少验证/测试比例，但保持独立性 |
| 轨迹数据 | 禁止随机打散，必须按轨迹切分 |
| 多工况数据 | 按工况分层切分，保证分布一致 |
| 无量纲化失败 | 记录原始量纲，标记为未标准化 |

## 质量检查

- [ ] 三份切分的对象轨迹互斥
- [ ] 仅用训练集计算变换统计量
- [ ] 边界与掩膜语义未破坏
- [ ] 归一化参数可逆（用于结果还原）

## 回退策略

- 切分失败：回退到随机切分（仅在非时序数据时允许）
- 归一化失败：使用MinMax归一化作为备选
- 数据泄漏检测：重新执行切分

## 资源召回建议

- 需要时序数据切分知识时，召回时序数据切分卡片
- 需要物理量无量纲化知识时，召回流体力学无量纲化卡片
- 需要数据增强知识时，召回流场数据增强卡片
