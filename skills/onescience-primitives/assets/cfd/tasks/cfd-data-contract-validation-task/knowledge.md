# 数据接入与契约核验任务

## 适用范围

适用于数据驱动流场控制任务的数据预处理阶段，负责核验风场尾迹状态与反馈控制数据的完整性、一致性和可用性。本任务是后续所有数据处理步骤的基础，必须首先完成。

## 输入

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 数据集路径 `{DATASET_PATH}` | doc | 是 | 目录或清单文件 |
| 数据集名称 `{DATASET_NAME}` | str | 是 | 来源与数据版本 |
| 数据契约 `{DATA_CONTRACT}` | object | 否 | 变量单位网格定义 |

## 输出

- `dataset_manifest.json`：数据集元信息清单
- `data_contract.json`：机器可读的数据契约
- `data_audit.md`：数据审计报告

## 流程节点

1. **文件可读性检查**：验证数据文件是否存在、格式是否正确、权限是否可访问
2. **样本统计**：统计样本数量、时间步长、工况分布
3. **变量核验**：检查输入变量（控制输入、边界条件）和目标变量（流场状态）是否存在
4. **单位一致性**：验证所有物理量单位是否统一（SI制或统一约定）
5. **坐标系检查**：确认网格坐标系、参考系是否一致
6. **缺失值检测**：统计缺失值比例、识别缺失模式（随机/系统性）
7. **许可合规**：确认数据使用许可是否满足任务要求

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|---|---|---|---|
| 数据文件可读 | 必须通过 | 场景需求书 | 数据文件必须存在且格式正确 |
| 样本可追溯 | 必须通过 | 场景需求书 | 每个样本需有唯一标识 |
| 变量定义完整 | 必须通过 | 场景需求书 | 输入与目标变量必须明确定义 |
| 坐标系一致 | 必须通过 | 场景需求书 | 网格坐标系必须统一 |
| 无训练测试泄漏 | 必须通过 | 场景需求书 | 训练集与测试集必须独立 |

## 边界与分流

| 条件 | 处理 |
|---|---|
| 数据文件不存在或格式错误 | 返回BLOCKED，列出缺项 |
| 必填变量缺失 | 返回BLOCKED，不得编造 |
| 单位不统一 | 在契约中明确转换规则 |
| 缺失值比例>30% | 标记为高风险，建议数据补全 |
| 使用许可不满足 | 返回BLOCKED，需获取授权 |

## 质量检查

- [ ] 数据文件可读且样本可追溯
- [ ] 输入目标变量单位坐标定义完整
- [ ] 不存在训练测试泄漏
- [ ] 数据契约格式符合schema

## 回退策略

- 数据文件损坏：尝试从备份恢复或请求原始数据
- 单位不明确：参考领域标准单位进行转换
- 许可缺失：联系数据提供方获取授权

## 资源召回建议

- 需要流场数据格式知识时，召回CFD数据格式卡片
- 需要单位转换知识时，召回物理量单位转换卡片
- 需要数据质量检查知识时，召回数据质量评估卡片
