# 任务验收与适用域判定任务

## 适用范围

适用于数据驱动流场控制任务的最终评估阶段，负责综合评估模型性能、物理一致性、泛化能力和计算收益，并明确适用域边界。本任务决定控制策略是否可交付使用。

## 输入

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 验收指标 `{METRICS}` | list[str] | 是 | 统计和物理指标 |
| 相对误差门限 `{MAX_RELATIVE_L2}` | float | 否 | 测试集放行阈值 |
| 是否外推测试 `{RUN_OOD_TEST}` | bool | 否 | 测试域外工况 |

## 输出

- `evaluation.json`：综合评估结果
- `worst_cases.csv`：最差样本分析
- `applicability_report.md`：适用域报告
- `PASS_REJECT_BLOCKED.txt`：最终决策

## 流程节点

1. **统计误差计算**：逐变量L2误差、边界误差、相对误差
2. **物理一致性验证**：守恒律检查、方程残差、稳定性分析
3. **最差样本分析**：识别最差表现样本，分析失败原因
4. **成本效益评估**：推理时间、计算资源、控制能耗
5. **外推测试**：在域外工况上测试泛化能力
6. **适用域划定**：基于测试结果明确适用边界
7. **决策输出**：给出PASS/REJECT/BLOCKED决策

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|---|---|---|---|
| 验收指标 | drag_or_load_reduction, control_energy, stability, constraint_violations | 默认值 | 减阻/能耗/稳定性/约束满足 |
| 相对误差门限 | 0.1 | 默认值 | 测试集L2相对误差上限 |
| 外推测试 | true | 默认值 | 执行域外工况测试 |

## 边界与分流

| 条件 | 处理 |
|---|---|
| 统计指标PASS但物理指标FAIL | REJECT（物理一致性优先） |
| 域内PASS但域外FAIL | 限制适用域，附域外CFD复核要求 |
| 最差样本误差>2倍门限 | REJECT，需分析原因 |
| 推理成本过高 | 标记为成本敏感，建议优化 |
| 缺少必填输入 | 返回BLOCKED |

## 质量检查

- [ ] 统计与物理指标同时报告
- [ ] 最差样本可追溯
- [ ] 结论含适用域限制与复核建议
- [ ] 决策有定量依据

## 回退策略

- 评估指标不足：补充物理一致性检查
- 外推测试失败：限制适用域，添加域外CFD复核要求
- 决策不确定：默认BLOCKED，需人工复核

## 资源召回建议

- 需要误差分析知识时，召回流场误差评估卡片
- 需要物理一致性检查知识时，召回守恒律验证卡片
- 需要泛化能力评估知识时，召回域外测试卡片
