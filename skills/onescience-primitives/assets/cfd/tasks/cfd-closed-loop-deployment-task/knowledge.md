# 闭环策略部署与滚动仿真任务

## 适用范围

适用于数据驱动流场控制任务的验证阶段，负责将训练好的控制策略部署到独立流动工况中，执行闭环滚动仿真，并与无控制基线进行对比评估。

## 输入

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 模型权重 `{CHECKPOINT}` | doc | 是 | 通过训练门限的最佳权重 |
| 计算设备 `{DEVICE}` | str | 是 | CPU或CUDA设备 |
| 推理批大小 `{BATCH_SIZE}` | int | 否 | 按显存调整批量 |

## 输出

- `closed_loop_trajectories/`：闭环轨迹数据目录
- `control_actions.csv`：控制动作记录
- `baseline_comparison.json`：与基线控制器对比结果

## 流程节点

1. **模型加载**：加载s03训练的最佳权重到控制策略
2. **环境初始化**：设置独立初值和工况参数
3. **闭环滚动**：执行观测→预测→优化→控制的完整闭环循环
4. **数据记录**：记录每个控制周期的观测、动作、载荷、能耗
5. **约束检查**：验证控制动作是否满足安全约束
6. **基线对比**：与无控制和基线控制器进行性能对比

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|---|---|---|---|
| 默认设备 | cuda | 默认值 | GPU加速推理 |
| 推理批大小 | 8 | 默认值 | 按显存调整 |
| 控制周期 | 与数据一致 | 数据契约 | 与训练数据时间步长一致 |
| 安全约束 | 幅值+频率 | 任务定义 | 控制动作必须满足 |

## 边界与分流

| 条件 | 处理 |
|---|---|
| 权重加载失败 | 检查checkpoint格式，重新训练 |
| 仿真发散 | 减小控制增益或回退到基线 |
| 约束违例 | 记录违例，标记为不安全状态 |
| 设备不足 | 回退到CPU推理 |
| 测试轨迹继续训练 | 禁止，必须保持测试集独立性 |

## 质量检查

- [ ] 动作满足幅值频率安全约束
- [ ] 闭环过程稳定无数值发散
- [ ] 收益扣除控制能耗后仍成立
- [ ] 与基线对比有定量指标

## 回退策略

- 仿真发散：使用更保守的控制策略或降低控制增益
- 计算超时：减少仿真时间或使用降采样
- 约束频繁违例：重新设计约束边界或调整控制器参数

## 资源召回建议
