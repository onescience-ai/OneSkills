# 模型配置与训练任务

## 适用范围

适用于数据驱动流场控制任务的模型构建阶段，负责训练降阶控制器（Reduced-order controller）与神经网络模型预测控制（Neural MPC）模型。本任务将历史数据中的流场动力学映射为可学习的低维表示，并训练控制策略。

## 输入

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 模型名称 `{MODEL_NAME}` | str | 是 | Reduced-order controller、Neural MPC |
| 训练配置 `{TRAIN_CONFIG}` | object | 是 | 超参数和随机种子 |
| 初始权重 `{INIT_CHECKPOINT}` | doc | 否 | 可选预训练权重 |

## 输出

- `best_checkpoint.pt`：最佳模型权重
- `train_config.json`：训练配置记录
- `training_metrics.csv`：逐轮训练验证指标
- `environment.txt`：代码版本和依赖环境

## 流程节点

1. **模型初始化**：根据MODEL_NAME选择模型架构（POD+线性控制/神经网络MPC）
2. **数据加载**：加载s02切分数据与归一化统计量
3. **训练循环**：执行前向传播、损失计算、反向传播、参数更新
4. **验证监控**：每epoch在验证集上评估，记录指标
5. **早停判断**：验证损失不再改善时停止训练
6. **模型保存**：保存最佳权重和训练状态

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|---|---|---|---|
| 框架 | PyTorch | 默认值 | 深度学习框架 |
| 训练轮数 | 100 | 默认值 | 最大训练epoch |
| 批大小 | 8 | 默认值 | 每批样本数 |
| 学习率 | 0.001 | 默认值 | 优化器学习率 |
| 随机种子 | 42 | 默认值 | 确保可复现性 |
| 早停耐心 | 15 | 默认值 | 验证损失不改善轮数 |

## 边界与分流

| 条件 | 处理 |
|---|---|
| 训练损失为NaN/Inf | 回退到更小学习率重试 |
| 验证损失发散 | 触发早停，回退到最佳epoch |
| 预训练权重不兼容 | 检查结构兼容性，必要时重新初始化 |
| 显存不足 | 减小batch_size或使用混合精度 |
| 缺少必填输入 | 返回BLOCKED，列出缺项 |

## 质量检查

- [ ] 训练验证损失均为有限值
- [ ] 最佳权重可重新加载
- [ ] 配置环境随机种子可复现
- [ ] 训练日志完整（epoch、loss、metrics）

## 回退策略

- 训练失败：检查数据质量，调整超参数重试
- 模型不收敛：尝试不同初始化或架构
- 显存溢出：减小batch_size或使用梯度累积

## 资源召回建议

- 需要神经网络控制知识时，召回Neural MPC卡片
- 需要训练优化知识时，召回深度学习训练技巧卡片
