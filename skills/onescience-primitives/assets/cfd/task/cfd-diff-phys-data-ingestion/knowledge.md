# 数据接入与契约核验

## 适用范围

本任务为可微分物理求解与方程结构学习工作流的入口步骤，负责接入可微数值轨迹与算子数据，完成数据可用性的全面核验。适用于CFD领域的轨迹数据、算子数据、网格信息等多模态数据的接入场景。当数据文件不可读、必填字段缺失或数据格式不兼容时，应返回BLOCKED状态并列出缺项。

## 输入

### 必需输入
| 变量 | 类型 | 说明 |
|------|------|------|
| `{DATASET_PATH}` | doc | 数据集目录或清单文件路径 |
| `{DATASET_NAME}` | str | 数据集名称，标识来源与版本 |

### 可选输入
| 变量 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `{DATA_CONTRACT}` | object | 空结构 | 变量、单位、网格定义的JSON契约 |

### 数据契约模板
```json
{
  "input_fields": [],
  "target_fields": [],
  "units": {},
  "coordinates": "dataset_native"
}
```

## 输出

### 产物清单
| 文件 | 格式 | 说明 |
|------|------|------|
| `dataset_manifest.json` | JSON | 数据集元信息清单 |
| `data_contract.json` | JSON | 机器可读的数据契约 |
| `data_audit.md` | Markdown | 人工可读的审计报告 |

### 质量门禁
- [ ] 数据文件可读且样本可追溯
- [ ] 输入目标变量单位坐标定义完整
- [ ] 不存在训练测试泄漏

## 流程节点

```
1. 解析DATASET_PATH指向的数据结构
   ↓
2. 遍历数据文件，检查格式兼容性
   ↓
3. 提取变量名、单位、维度信息
   ↓
4. 核验网格坐标系与拓扑结构
   ↓
5. 检查时间/工况范围与缺失值
   ↓
6. 验证使用许可合规性
   ↓
7. 生成data_contract.json与data_audit.md
```

## 关键参数

### 核验检查项
| 检查项 | 说明 | 失败处理 |
|--------|------|----------|
| 文件可读性 | 文件存在且格式正确 | BLOCKED，列出不可读文件 |
| 样本数 | 足够训练/验证/测试 | 警告，建议补充数据 |
| 变量完整性 | 输入/目标变量齐全 | BLOCKED，列出缺失变量 |
| 单位一致性 | 所有变量单位明确定义 | 警告，尝试自动推断 |
| 坐标系定义 | 网格坐标系清晰 | BLOCKED，需人工确认 |
| 网格拓扑 | 拓扑关系可构建 | BLOCKED，数据格式不支持 |
| 时间/工况范围 | 范围明确无歧义 | 警告，建议补充元信息 |
| 缺失值 | 缺失比例可接受 | 警告，标记处理策略 |
| 使用许可 | 许可合规 | BLOCKED，许可不允许 |

## 边界与分流

### 正常流
数据完整 → 输出data_contract.json → 传递至s02

### 异常分支
| 条件 | 输出 | 后续 |
|------|------|------|
| 文件不可读 | BLOCKED + 缺项清单 | 修复数据 |
| 变量缺失 | BLOCKED + 缺失列表 | 补充数据或调整契约 |
| 单位不明 | 警告 + 人工确认 | 用户提供单位映射 |
| 许可不合规 | BLOCKED | 获取授权或更换数据 |

### 降级策略
- 若部分字段缺失但核心字段完整，可标记为"部分契约"并继续
- 若单位不明但有参考值，可尝试自动推断并标注

## 质量检查

### 自动检查
- [ ] 文件格式解析成功
- [ ] 变量名与维度匹配
- [ ] 数值范围合理（无异常值）

### 人工确认
- [ ] 单位映射正确
- [ ] 坐标系理解一致
- [ ] 许可条款清晰

## 回退策略

| 失败原因 | 回退方案 |
|----------|----------|
| 数据路径错误 | 检查路径，确认挂载 |
| 格式不支持 | 转换格式或扩展解析器 |
| 契约冲突 | 用户确认优先级 |
