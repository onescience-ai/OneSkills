# 隐式神经场任务验收与适用域判定

## 适用范围

本任务适用于隐式神经场连续流动降阶建模的验收阶段，负责评估统计误差、关键物理约束、泛化能力和计算收益，给出PASS、REJECT或BLOCKED结论，明确适用域边界与复核建议。

**触发条件**：
- 批量推理已完成，预测结果已保存
- 需要评估模型性能与物理一致性
- 需要确定适用域边界

**不适用场景**：
- 推理结果未保存的场景
- 评估指标未定义的场景
- 需要跳过物理验证的场景

## 输入

**数据源**：
- s04输出的预测结果
- s02输出的测试集清单
- 验收指标列表
- 相对误差门限
- 是否外推测试选项

**验收指标列表**：
- relative_L2：相对L2误差
- RMSE：均方根误差
- conservation_residual：守恒残差
- boundary_error：边界误差

**配置参数**：
- 相对误差门限（默认0.1）
- 是否外推测试（默认true）

## 输出

**评估产物**：
- evaluation.json：评估结果（逐变量误差、守恒残差、边界误差等）
- worst_cases.csv：最差样本分析（样本ID、误差、原因分析）
- applicability_report.md：适用域报告（适用范围、限制条件、复核建议）
- PASS_REJECT_BLOCKED.txt：验收结论（PASS/REJECT/BLOCKED）

**验证标准**：
- 统计与物理指标同时报告
- 最差样本可追溯
- 结论含适用域限制与复核建议

## 流程节点

### 1. 数据加载
- **操作**：加载s04输出的预测结果和s02输出的测试集清单
- **参数**：预测结果目录、测试集清单
- **工具**：数据加载器
- **质量门禁**：数据可读、清单完整

### 2. 指标计算
- **操作**：计算统计误差（relative_L2、RMSE）和物理约束（conservation_residual、boundary_error）
- **参数**：预测结果、测试标签、验收指标
- **工具**：指标计算器
- **质量门禁**：指标计算正确、结果完整

### 3. 最差样本分析
- **操作**：识别并分析最差样本（误差最大、物理不满足等）
- **参数**：评估结果、样本信息
- **工具**：最差样本分析器
- **质量门禁**：最差样本可追溯、原因分析合理

### 4. 适用域分析
- **操作**：分析模型在不同工况、几何、参数范围内的表现
- **参数**：评估结果、测试集信息
- **工具**：适用域分析器
- **质量门禁**：适用域边界明确、限制条件清晰

### 5. 复核建议生成
- **操作**：根据评估结果生成复核建议（CFD复核、重新训练等）
- **参数**：评估结果、适用域分析
- **工具**：复核建议生成器
- **质量门禁**：复核建议合理、可操作

### 6. 结论生成
- **操作**：根据评估结果和阈值给出PASS、REJECT或BLOCKED结论
- **参数**：评估结果、相对误差门限、物理约束阈值
- **工具**：结论生成器
- **质量门禁**：结论正确、依据充分

### 7. 报告生成
- **操作**：生成评估结果、最差样本分析、适用域报告、验收结论
- **参数**：评估结果、分析结果
- **工具**：报告生成器
- **质量门禁**：报告格式正确、内容完整

## 边界与分流

**前提条件与改道**：

1. **预测结果已保存**
   - 不成立时 → 改道：返回s04重新执行推理

2. **验收指标已定义**
   - 不成立时 → 改道：使用默认指标列表

3. **物理约束可验证**
   - 不成立时 → 改道：仅进行统计误差评估，物理一致性标记为"证据有限"

4. **评估结果合理**
   - 不成立时 → 改道：检查数据质量、重新评估

5. **适用域边界明确**
   - 不成立时 → 改道：进行更广泛的测试、补充评估

## 质量检查

**验证点**：
- 数据加载正确性
- 指标计算正确性
- 最差样本分析完整性
- 适用域分析合理性
- 复核建议可操作性
- 结论正确性
- 报告完整性

**阈值**：
- 统计与物理指标同时报告：100%
- 最差样本可追溯：100%
- 结论含适用域限制：100%

**失败处理**：
- 数据加载失败 → 检查预测结果、重新加载
- 指标计算错误 → 检查计算逻辑、重新计算
- 最差样本分析不完整 → 补充分析、完善原因
- 适用域分析不明确 → 进行更详细分析、补充测试
- 复核建议不合理 → 调整建议、确保可操作
- 结论错误 → 重新评估、修正结论
- 报告不完整 → 补充内容、完善报告

## 回退策略

**失败时的替代方案**：
1. 指标计算失败 → 使用简单指标、补充计算
2. 最差样本分析失败 → 使用默认分析模板、补充分析
3. 适用域分析失败 → 使用简单划分、标记为"初步分析"
4. 复核建议生成失败 → 使用默认建议模板、补充建议
5. 结论生成失败 → 使用默认结论、标记为"待确认"
6. 报告生成失败 → 使用默认报告模板、补充内容
