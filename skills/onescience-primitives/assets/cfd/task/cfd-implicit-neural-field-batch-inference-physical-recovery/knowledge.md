# 隐式神经场批量推理与物理恢复

## 适用范围

本任务适用于隐式神经场连续流动降阶建模的推理阶段，负责在独立测试集推理，恢复原始单位、网格和物理派生量，保存逐样本结果和耗时，确保推理过程无测试目标校正。

**触发条件**：
- 模型训练完成，权重已保存
- 需要在测试集进行批量推理
- 需要恢复原始物理量与网格

**不适用场景**：
- 模型权重未保存的场景
- 测试集数据未预处理的场景
- 需要使用测试目标校正的场景

## 输入

**数据源**：
- s03输出的模型权重（best_checkpoint.pt）
- s02输出的测试集清单
- 归一化统计量
- 计算设备（CPU或CUDA）
- 推理批大小

**配置参数**：
- 模型权重路径
- 计算设备类型
- 推理批大小

## 输出

**推理产物**：
- predictions/：逐样本预测结果目录
- inference_manifest.json：推理清单（样本ID、预测文件、耗时）
- timing.csv：推理耗时统计

**验证标准**：
- 预测无NaN或Inf且形状单位正确
- 每个测试样本有唯一结果
- 推理未使用测试目标校正

## 流程节点

### 1. 模型加载
- **操作**：加载s03输出的模型权重
- **参数**：模型权重路径、模型结构
- **工具**：模型加载器
- **质量门禁**：权重可加载、模型结构正确

### 2. 数据加载
- **操作**：加载s02输出的测试集清单和归一化统计量
- **参数**：测试集清单、统计量文件
- **工具**：数据加载器
- **质量门禁**：数据可读、统计量完整

### 3. 推理配置
- **操作**：配置计算设备、推理批大小、推理模式
- **参数**：计算设备、批大小、推理模式（eval）
- **工具**：推理配置器
- **质量门禁**：设备可用、配置正确

### 4. 批量推理
- **操作**：在测试集上执行批量推理
- **参数**：测试数据、模型、推理配置
- **工具**：推理引擎
- **质量门禁**：推理过程无错误、输出形状正确

### 5. 物理恢复
- **操作**：反归一化、恢复原始单位、网格和物理派生量
- **参数**：预测结果、归一化统计量、数据契约
- **工具**：物理恢复器
- **质量门禁**：单位恢复正确、网格恢复正确

### 6. 结果保存
- **操作**：保存逐样本预测结果、推理清单、耗时统计
- **参数**：预测结果、推理耗时
- **工具**：结果保存器
- **质量门禁**：结果保存完整、格式正确

### 7. 报告生成
- **操作**：生成推理清单和耗时统计文件
- **参数**：推理结果、耗时数据
- **工具**：报告生成器
- **质量门禁**：报告格式正确、内容完整

## 边界与分流

**前提条件与改道**：

1. **模型权重已保存**
   - 不成立时 → 改道：返回s03重新训练模型

2. **测试集数据已预处理**
   - 不成立时 → 改道：返回s02完成数据预处理

3. **计算设备可用**
   - 不成立时 → 改道：使用CPU推理或调整设备配置

4. **推理过程无错误**
   - 不成立时 → 改道：检查模型兼容性、数据格式

5. **物理恢复正确**
   - 不成立时 → 改道：检查归一化统计量、数据契约

## 质量检查

**验证点**：
- 模型加载正确性
- 数据加载完整性
- 推理过程正确性
- 物理恢复准确性
- 结果保存完整性
- 报告生成正确性

**阈值**：
- 预测完整性：100%（无NaN或Inf）
- 形状正确性：100%（输出形状匹配）
- 单位正确性：100%（单位恢复正确）
- 唯一性：100%（每样本唯一结果）
- 无校正：100%（未使用测试目标）

**失败处理**：
- 模型加载失败 → 检查权重文件、重新加载
- 数据加载失败 → 检查清单文件、重新加载
- 推理过程错误 → 检查模型兼容性、调整设备
- 物理恢复错误 → 检查统计量、重新恢复
- 结果保存失败 → 检查存储空间、重新保存
- 报告生成失败 → 检查数据完整性、重新生成

## 回退策略

**失败时的替代方案**：
1. 模型加载失败 → 使用更简单的模型结构
2. 数据加载失败 → 使用默认数据格式、补充缺失项
3. 推理过程错误 → 使用CPU推理、调整批大小
4. 物理恢复错误 → 使用原始数据、标记未恢复
5. 结果保存失败 → 保存中间结果、补充保存
6. 报告生成失败 → 使用默认报告格式、补充内容
