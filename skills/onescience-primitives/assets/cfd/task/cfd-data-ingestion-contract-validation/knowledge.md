# 数据接入与契约核验

## 适用范围

本任务卡适用于DNS与RANS配对湍流闭合数据的初始接入阶段，负责建立数据清单、核验数据质量、定义数据契约，确保后续预处理和模型训练的数据基础可靠。

## 输入

| 变量 | 类型 | 必填 | 说明 |
|------|------|------|------|
| DATASET_PATH | doc | 是 | 数据集路径（目录或清单文件） |
| DATASET_NAME | str | 是 | 数据集名称与版本 |
| DATA_CONTRACT | object | 否 | 变量、单位、网格定义 |

## 输出

| 文件 | 说明 |
|------|------|
| dataset_manifest.json | 数据清单（样本数、变量列表、网格信息） |
| data_contract.json | 机器可读数据契约 |
| data_audit.md | 数据审计报告 |

## 流程节点

1. **文件可读性检查**
   - 验证DATASET_PATH指向的文件或目录存在且可读
   - 检查文件格式是否符合预期（HDF5、NetCDF、CSV等）

2. **样本数与变量核验**
   - 统计样本总数（DNS快照数或网格点数）
   - 列出所有输入变量和目标变量名称
   - 验证变量维度与网格拓扑匹配

3. **单位与坐标系核验**
   - 确认物理量单位（速度m/s、压力Pa、密度kg/m³等）
   - 确认坐标系定义（笛卡尔、柱坐标、曲线坐标等）
   - 若提供DATA_CONTRACT，逐字段比对一致性

4. **时间或工况范围检查**
   - 确认工况覆盖范围（Reynolds数、Mach数、几何参数等）
   - 检查时间序列连续性（若适用）

5. **缺失值检测**
   - 统计NaN、Inf或异常值比例
   - 标记缺失值位置与模式

6. **使用许可核验**
   - 确认数据集使用许可（开源/授权/受限）
   - 记录许可条款到data_audit.md

7. **训练测试泄漏检测**
   - 检查是否存在同一几何/工况同时出现在训练集和测试集
   - 若发现泄漏，返回BLOCKED并列出泄漏详情

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 必填输入 | DATASET_PATH, DATASET_NAME | 缺失任一返回BLOCKED |
| 可选输入 | DATA_CONTRACT | 提供时做字段级比对 |
| 坐标系默认 | dataset_native | 使用数据集原始坐标 |

## 边界与分流

- **DATASET_PATH不存在**：返回BLOCKED，列出缺项
- **文件格式不支持**：返回BLOCKED，说明支持格式
- **缺失值比例>5%**：标记WARNING但仍可继续
- **发现训练测试泄漏**：返回BLOCKED，必须修复后重试

## 质量检查

| 检查项 | 判据 | 失败处理 |
|--------|------|----------|
| 文件可读 | 文件存在且可打开 | BLOCKED |
| 变量完整 | 所有必需变量存在 | BLOCKED |
| 单位定义 | 无歧义单位定义 | WARNING |
| 坐标定义 | 坐标系明确 | WARNING |
| 无泄漏 | 训练测试集互斥 | BLOCKED |

## 回退策略

- 数据格式不支持时，尝试格式转换工具
- 缺失值过多时，评估是否可插补或需补充数据
- 许可受限时，记录限制条件供下游参考

## 资源召回建议

当需要执行数据驱动湍流闭合且拥有DNS/RANS配对数据时召回本卡。本卡是工作流第一步，完成后进入cfd-preprocessing-data-splitting。
