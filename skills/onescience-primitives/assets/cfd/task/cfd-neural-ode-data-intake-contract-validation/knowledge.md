# 数据接入与契约核验（Neural ODE动力学学习）

## 适用范围

稳定性约束神经微分方程建模流程的第一步：接入显式约束动力系统时序数据，核验样本、变量、单位、网格坐标及许可，输出机器可读数据契约。适用于所有需要从原始动力系统数据启动Neural ODE建模的场景。

## 输入

- {DATASET_PATH}: 数据集路径（必填），目录或清单文件
- {DATASET_NAME}: 数据集名称（必填），默认"显式约束动力系统时序数据"
- {DATA_CONTRACT}: 数据契约模板（可选），变量单位网格定义

## 输出

- dataset_manifest.json: 数据清单（样本数、变量列表、时间范围）
- data_contract.json: 机器可读契约（输入目标变量单位坐标定义）
- data_audit.md: 审计报告（缺失值、许可、完整性评估）

## 流程节点

```
读取数据集 → 检查文件可读性 → 核验样本数/变量/单位/坐标 → 检测缺失值与许可 → 输出数据契约
```

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必填输入 | DATASET_PATH, DATASET_NAME | [场景需求书s01] | 缺少时返回BLOCKED |
| 可选输入 | DATA_CONTRACT | [场景需求书s01] | 有则按模板校验，无则自动推断 |
| 输出格式 | JSON + Markdown | [场景需求书s01] | 机器可读+人工可读 |

## 边界与分流

- 缺少必填输入（数据集路径、数据集名称）→ 返回BLOCKED，列出缺项
- 数据文件不可读或格式不支持 → 拒绝处理，要求修复数据源
- 变量定义不完整 → 标注缺失变量，继续输出部分契约
- 数据集为空 → 返回BLOCKED

## 质量检查

- 数据文件可读且样本可追溯
- 输入目标变量单位坐标定义完整
- 不存在训练测试泄漏（此阶段仅核验，切分在s02）

## 回退策略

- 数据格式不兼容 → 转换为标准格式（HDF5/NumPy/CSV）
- 数据源路径错误 → 明确错误信息，指导用户修复路径
- 部分变量缺失 → 标注缺失量，建议补充或调整预测目标
