# 闭合项预测与后验CFD耦合

## 适用范围

本任务卡适用于数据驱动RANS湍流闭合模型的验证阶段，包含先验评估（在独立DNS快照上预测闭合项并检查误差与可实现性）和后验推进（将预测的闭合项嵌入RANS或LES求解器执行完整CFD计算并验证物理一致性）两个核心阶段。

## 输入

| 变量 | 类型 | 必填 | 说明 |
|------|------|------|------|
| CHECKPOINT | doc | 是 | 通过训练门限的模型权重 |
| DEVICE | str | 是 | 计算设备（CPU或CUDA设备） |
| BATCH_SIZE | int | 否 | 推理批大小（默认8） |

## 输出

| 文件/目录 | 说明 |
|-----------|------|
| apriori_closure/ | 先验闭合项预测结果（逐快照预测值、误差分布） |
| aposteriori_fields/ | 后验CFD计算结果（流场、统计量、残差） |
| solver_stability.csv | 求解器稳定性记录（残差收敛、发散点、迭代次数） |

## 流程节点

### 阶段一：先验评估

1. **加载模型权重**
   - 加载CHECKPOINT中的模型架构与权重
   - 验证模型可正常推理

2. **独立快照预测**
   - 对测试集中的独立DNS快照进行预测
   - 输入：局部流动特征（应变率、旋转率、湍流量等）
   - 输出：预测的雷诺应力张量或涡黏系数

3. **先验误差分析**
   - 计算逐分量预测误差（RMSE、MAE、相对误差）
   - 分析误差空间分布（边界层、分离区、尾迹区）
   - 识别最差样本

4. **可实现性检查**
   - 验证预测的雷诺应力张量满足正定性
   - 验证满足迹约束（2k = τ_ii）
   - 验证满足Cauchy-Schwarz不等式
   - 标记违反可实现性的预测点

### 阶段二：后验推进

5. **求解器接口准备**
   - 准备RANS或LES求解器接口
   - 将模型预测的闭合项转换为求解器可接受的格式
   - 配置边界条件与初始条件

6. **后验CFD计算**
   - 嵌入预测的闭合项执行完整CFD计算
   - 监控残差收敛过程
   - 记录数值稳定性（是否发散、振荡）

7. **后验结果验证**
   - 提取均值速度剖面、雷诺应力剖面
   - 计算能谱分布
   - 与DNS参考解对比
   - 与传统RANS模型结果对比

8. **稳定性记录**
   - 记录每个工况的收敛情况
   - 记录发散点位置与可能原因
   - 输出到solver_stability.csv

## 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| DEVICE | cuda | 推理设备 |
| BATCH_SIZE | 8 | 推理批大小 |
| 求解器类型 | RANS | 可选RANS或LES |
| 收敛标准 | 残差<1e-6 | 可调整 |

## 边界与分流

- **先验误差过大**：检查模型训练是否充分，或调整输入特征
- **可实现性违反严重**：在模型输出层添加约束投影
- **后验发散**：降低Courant数、检查闭合项量级、添加人工耗散
- **后验精度不足**：检查网格分辨率、边界条件、求解器设置

## 质量检查

| 检查项 | 判据 | 失败处理 |
|--------|------|----------|
| 闭合张量约束 | 满足正定性、迹约束 | WARNING |
| 后验无发散 | 残差收敛，无非物理解 | BLOCKED |
| 均值剖面验证 | 与DNS参考解误差可接受 | WARNING |
| 能谱验证 | 能量分布合理 | WARNING |

## 回退策略

- 先验误差大：增加训练数据、调整模型架构、添加物理约束
- 后验发散：使用更保守的时间步长、添加稳定性增强技术
- 物理不一致：在损失函数中添加物理约束项
