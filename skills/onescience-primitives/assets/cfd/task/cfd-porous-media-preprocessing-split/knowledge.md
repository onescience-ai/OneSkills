# 预处理与数据切分

## 适用范围

**触发条件**：
- 需要对多孔介质 CFD 数据进行预处理和标准化切分
- 需要防止训练-测试数据泄漏

**适用场景**：
- CFD 数据的质控、重采样、掩膜、归一化或无量纲化
- 按几何、完整轨迹或物理工况为单位进行无泄漏切分
- 需要保存可逆变换统计量供推理阶段使用

**不适用场景**：
- 已完成预处理的数据集
- 无空间/时间结构的纯标量数据

## 输入

- {SPLIT_CONFIG}：切分配置（train/val/test 比例、随机种子、分组方式）
- {TARGET_FIELDS}：目标变量列表
- {NONDIMENSIONALIZE}：是否无量纲化（默认 true）

## 输出

- train_manifest.json：训练集清单
- validation_manifest.json：验证集清单
- test_manifest.json：测试集清单
- normalization.json：归一化/无量纲化统计量与可逆变换参数

## 流程节点

### Step 2.1：数据质控
- **操作**：检查并处理缺失值、异常值、重复样本
- **参数**：数据集清单、数据契约
- **工具**：数据质控脚本
- **质量门禁**：缺失值处理完成，无异常值

### Step 2.2：重采样或图构建（可选）
- **操作**：对非均匀网格数据进行重采样，或构建图结构数据
- **参数**：目标分辨率或图构建参数
- **工具**：重采样库、图构建库
- **质量门禁**：重采样后数据分布合理，图结构完整

### Step 2.3：掩膜处理（可选）
- **操作**：处理多孔介质固体区域的掩膜
- **参数**：掩膜定义
- **工具**：掩膜处理脚本
- **质量门禁**：固体区域正确标记，流体区域数据完整

### Step 2.4：归一化或无量纲化
- **操作**：对物理量进行归一化或无量纲化处理
- **参数**：目标变量、无量纲化选项
- **工具**：归一化脚本
- **质量门禁**：仅用训练集计算统计量，变换可逆

### Step 2.5：无泄漏切分
- **操作**：按几何、完整轨迹或物理工况为单位进行切分
- **参数**：切分配置（比例、种子、分组方式）
- **工具**：切分脚本
- **质量门禁**：三份切分的对象轨迹互斥，无数据泄漏

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 切分单位 | 几何/轨迹/工况 | [场景需求书 s02] | 防止同一轨迹帧随机打散 |
| 统计量来源 | 仅训练集 | [场景需求书 s02] | 防止测试集信息泄漏 |
| 边界语义 | 掩膜与边界条件保持完整 | [场景需求书 s02] | 物理约束不被破坏 |
| 变换可逆性 | 归一化/无量纲化参数可保存 | [场景需求书 s02] | 推理阶段需要逆变换 |

### 校准数值

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认 train 比例 | 0.7 | [场景需求书] | 可根据数据量调整 |
| 默认 validation 比例 | 0.15 | [场景需求书] | 可根据数据量调整 |
| 默认 test 比例 | 0.15 | [场景需求书] | 可根据数据量调整 |
| 默认随机种子 | 42 | [场景需求书] | 可复现性保证 |
| 默认分组方式 | geometry_or_trajectory | [场景需求书] | 按几何或轨迹分组 |

> 以上数值来自 CFD_S077 场景需求书，供量级校准；其他体系需以自身证据重新锚定。

## 边界与分流

- **切分配置不合理**：调整比例或分组方式，确保各集合有足够样本
- **无量纲化失败**：回退到简单归一化（min-max 或 z-score）
- **掩膜处理异常**：检查掩膜定义，确保与数据格式匹配
- **轨迹数不足**：降低切分比例或增加数据采集

## 质量检查

- 切分互斥性：训练集、验证集、测试集无交叉样本
- 统计量正确性：仅用训练集计算归一化/无量纲化参数
- 边界完整性：掩膜和边界条件在切分后保持一致
- 可逆变换：归一化/无量纲化参数可保存并用于推理阶段

## 回退策略

- 若数据量不足以支持三份切分，可合并验证集和测试集
- 若轨迹数不足，可按工况分组替代轨迹分组
- 若无量纲化参数不合理（如方差接近零），可跳过该变量的无量纲化
