# 预处理与数据切分

## 适用范围

本任务卡适用于DNS与RANS配对湍流闭合数据的预处理阶段，负责统一物理量表示、执行无量纲化或归一化、按几何/工况/轨迹进行无泄漏切分，为模型训练准备高质量数据。

## 输入

| 变量 | 类型 | 必填 | 说明 |
|------|------|------|------|
| SPLIT_CONFIG | object | 是 | 切分配置（比例、种子、分组方式） |
| TARGET_FIELDS | list[str] | 是 | 目标变量列表 |
| NONDIMENSIONALIZE | bool | 否 | 是否无量纲化（默认true） |

## 输出

| 文件 | 说明 |
|------|------|
| train_manifest.json | 训练集清单 |
| validation_manifest.json | 验证集清单 |
| test_manifest.json | 测试集清单 |
| normalization.json | 归一化/无量纲化参数（均值、方差、尺度因子） |

## 流程节点

1. **物理量统一**
   - 统一压力、速度、密度等变量的表示方式
   - 处理坐标系差异（若DNS与RANS使用不同坐标）

2. **无量纲化处理**
   - 当NONDIMENSIONALIZE=true时执行
   - 计算特征尺度（如自由流速度、特征长度、运动粘度）
   - 将物理量转换为无量纲形式
   - 保存转换参数到normalization.json

3. **归一化处理**
   - 计算训练集统计量（均值、标准差、最小值、最大值）
   - 应用归一化变换
   - 保存统计量用于推理时逆变换

4. **无泄漏切分**
   - 按SPLIT_CONFIG.group_by指定的维度切分：
     - geometry_or_trajectory：按几何形状或完整轨迹切分
     - condition：按物理工况切分
     - time：按时间窗口切分
   - 确保同一几何/工况/轨迹的样本完全属于同一子集
   - 默认比例：train:0.7, validation:0.15, test:0.15

5. **统计量计算与保存**
   - 仅从训练集计算统计量
   - 保存到normalization.json
   - 包含可逆变换所需的全部参数

6. **切分验证**
   - 验证三份切分的样本ID互斥
   - 验证切分比例符合配置
   - 验证无训练集信息泄露到验证集/测试集

## 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| train比例 | 0.7 | 训练集占比 |
| validation比例 | 0.15 | 验证集占比 |
| test比例 | 0.15 | 测试集占比 |
| random_seed | 42 | 切分随机种子 |
| group_by | geometry_or_trajectory | 切分维度 |
| NONDIMENSIONALIZE | true | 是否无量纲化 |

## 边界与分流

- **单工况数据**：可跳过几何切分，按时间或采样点切分
- **多工况数据**：必须按工况切分，避免工况信息泄露
- **符号回归模型**：归一化参数需适配符号搜索的输入范围
- **边界层数据**：需保持边界层内样本的完整性

## 质量检查

| 检查项 | 判据 | 失败处理 |
|--------|------|----------|
| 样本互斥 | 三份切分无重叠ID | BLOCKED |
| 统计量来源 | 仅来自训练集 | BLOCKED |
| 边界完整 | 边界与掩膜语义未破坏 | WARNING |
| 比例符合 | 实际比例偏差<1% | WARNING |

## 回退策略

- 切分失败时，降低group_by粒度重试
- 无量纲化失败时，使用简单min-max归一化
- 统计量异常时，检查并剔除离群样本
