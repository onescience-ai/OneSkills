# 任务验收与适用域判定

## 适用范围

本任务卡适用于数据驱动RANS湍流闭合模型的最终验收阶段，负责综合评估统计误差、物理约束满足度、泛化能力和计算收益，明确模型适用域边界，输出验收结论（PASS/REJECT/BLOCKED）与工程复核建议。

## 输入

| 变量 | 类型 | 必填 | 说明 |
|------|------|------|------|
| METRICS | list[str] | 是 | 验收指标列表 |
| MAX_RELATIVE_L2 | float | 否 | 相对误差门限（默认0.1） |
| RUN_OOD_TEST | bool | 否 | 是否执行外推测试（默认true） |

## 输出

| 文件 | 说明 |
|------|------|
| evaluation.json | 综合评估结果（逐指标得分、总分） |
| worst_cases.csv | 最差样本详情（工况、误差、位置） |
| applicability_report.md | 适用域报告（覆盖范围、边界条件、复核建议） |
| PASS_REJECT_BLOCKED.txt | 最终验收结论 |

## 流程节点

1. **统计误差评估**
   - 计算逐变量误差：
     - closure_RMSE：闭合项RMSE
     - mean_profile_error：均值剖面误差
     - spectrum_error：能谱误差
     - stability_horizon：稳定性时间跨度
   - 计算相对L2误差
   - 与MAX_RELATIVE_L2门限比较

2. **物理约束验证**
   - 验证雷诺应力可实现性（正定性、迹约束）
   - 验证能量守恒（湍动能产生-耗散平衡）
   - 验证动量守恒（方程残差）
   - 记录违反约束的样本

3. **最差样本分析**
   - 识别误差最大的样本
   - 分析最差样本的流动特征（高分离、强曲率、高Re等）
   - 追溯误差来源（训练数据不足、模型容量限制、物理机制缺失）

4. **外推测试（OOD Test）**
   - 当RUN_OOD_TEST=true时执行
   - 测试几何外推：未见过的翼型形状、管道构型
   - 测试工况外推：超出训练范围的Reynolds数、Mach数
   - 记录外推性能衰减程度

5. **适用域边界明确**
   - 基于测试结果定义适用域：
     - 几何范围（支持的形状类型）
     - 工况范围（Reynolds数、Mach数范围）
     - 流动类型（附着流、分离流、混合流）
   - 明确域外工况需CFD复核

6. **验收结论**
   - PASS：所有指标满足门限，物理约束满足，适用域明确
   - REJECT：关键指标不满足门限或物理约束违反
   - BLOCKED：数据不足、训练失败或后验发散

7. **复核建议**
   - 针对适用域边界内的工况，提供使用建议
   - 针对适用域边界外的工况，建议CFD复核方案
   - 针对最差样本类型，提供模型改进方向

## 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| MAX_RELATIVE_L2 | 0.1 | 相对误差门限（10%） |
| RUN_OOD_TEST | true | 是否执行外推测试 |
| closure_RMSE | - | 闭合项RMSE指标 |
| mean_profile_error | - | 均值剖面误差指标 |
| spectrum_error | - | 能谱误差指标 |
| stability_horizon | - | 稳定性时间跨度指标 |

## 边界与分流

- **单指标失败**：标记WARNING但仍可继续评估
- **多指标失败**：判定REJECT，建议模型改进
- **物理约束违反**：判定REJECT，需在模型中添加约束
- **外推测试失败**：在适用域报告中明确标注域外边界
- **无外推测试数据**：跳过OOD测试，在报告中说明

## 质量检查

| 检查项 | 判据 | 失败处理 |
|--------|------|----------|
| 统计指标 | 所有指标为有限值 | BLOCKED |
| 物理指标 | 同时报告统计与物理指标 | WARNING |
| 最差样本 | 可追溯至具体工况 | WARNING |
| 适用域结论 | 含限制与复核建议 | BLOCKED |

## 回退策略

- 评估指标不足：增加物理一致性指标（如湍流各向异性比）
- 外推测试无数据：使用留一法交叉验证代替
- 结论不确定：标记为CONDITIONAL PASS，需更多验证

## 资源召回建议

当完成后验CFD耦合（cfd-closure-prediction-coupling）后召回本卡。本卡是工作流最后一步，输出最终验收结论。若判定PASS，模型可交付使用；若判定REJECT或BLOCKED，需返回相应步骤重做。
