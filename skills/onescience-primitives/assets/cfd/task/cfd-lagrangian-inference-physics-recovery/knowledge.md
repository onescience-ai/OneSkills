# 拉格朗日流体模型批量推理与物理恢复

## 适用范围

面向训练好的拉格朗日流体模型的批量推理与物理恢复任务。适用于：
- E3等变粒子网络模型的测试集评估
- 从归一化预测恢复原始物理单位与坐标
- 物理派生量（涡量、应变率等）的计算与验证

任务目标：在独立测试集上执行推理，反归一化恢复物理单位、坐标网格、边界掩膜及任务派生量，保存逐样本结果和耗时，禁止使用测试标签修正预测。

## 输入

**必填输入**：
- {CHECKPOINT}: 模型权重（通过训练门限权重）
- {DEVICE}: 计算设备（CPU或CUDA设备）

**可选输入**：
- {BATCH_SIZE}: 推理批大小（按显存调整）

**前置依赖**：
- s03输出的best_checkpoint.pt（模型权重）
- s02输出的切分清单（test_manifest.json）
- s02输出的归一化统计（normalization.json）

**默认配置**：
- CHECKPOINT: best_checkpoint.pt
- DEVICE: cuda
- BATCH_SIZE: 8

## 输出

**核心产物**：
- predictions/: 预测结果目录（逐样本文件）
- inference_manifest.json: 推理清单（样本列表、预测路径、耗时）
- timing.csv: 耗时记录（总耗时、平均单样本耗时）

**预测内容**：
- 归一化预测值（模型直接输出）
- 反归一化预测值（恢复原始单位）
- 物理派生量（涡量、应变率、散度等）
- 边界掩膜应用后的结果

## 流程节点

```
模型加载 → 数据加载 → 批量推理 → 反归一化 → 物理恢复 → 结果保存 → 耗时统计
```

**模型加载**：
- 操作：加载{CHECKPOINT}及训练时数据契约
- 参数：模型架构、权重路径
- 质量门禁：模型加载成功、权重形状匹配

**数据加载**：
- 操作：加载s02测试集清单与归一化统计
- 参数：测试集路径、归一化参数
- 质量门禁：数据加载正确、归一化参数匹配

**批量推理**：
- 操作：在测试集上以{DEVICE}和{BATCH_SIZE}推理
- 参数：batch_size、设备、推理模式
- 质量门禁：预测无NaN/Inf、形状正确

**反归一化**：
- 操作：应用归一化统计的逆变换
- 参数：均值、标准差、最小值、最大值
- 质量门禁：逆变换正确、单位恢复正确

**物理恢复**：
- 操作：恢复坐标网格、边界掩膜、计算派生量
- 参数：坐标系、边界条件、派生量公式
- 质量门禁：坐标恢复正确、边界应用正确、派生量计算正确

**结果保存**：
- 操作：保存逐样本预测结果
- 参数：保存格式、目录结构
- 质量门禁：每个样本有唯一结果、文件可读

**耗时统计**：
- 操作：记录总耗时和平均单样本耗时
- 参数：计时点
- 质量门禁：耗时记录准确

## 边界与分流

**模型加载失败**：
- 权重文件不存在 → 返回BLOCKED，要求提供有效权重
- 权重形状不匹配 → 返回BLOCKED，要求检查模型架构
- 设备不可用 → 降级到CPU推理

**数据加载失败**：
- 测试集清单不存在 → 返回BLOCKED，要求重新切分
- 归一化统计缺失 → 返回BLOCKED，要求重新计算
- 数据格式不兼容 → 转换格式后重试

**推理异常**：
- 预测出现NaN/Inf → 检查输入数据、模型权重、数值稳定性
- 预测形状错误 → 检查模型输出层、数据维度
- 显存不足 → 减小batch_size、使用梯度检查点（可选）

**物理恢复失败**：
- 坐标恢复错误 → 检查坐标变换公式、归一化参数
- 边界掩膜应用错误 → 检查掩膜定义、索引对应
- 派生量计算错误 → 检查公式实现、数值精度

## 质量检查

**预测有效性**：
- 所有预测值为有限数值（无NaN/Inf）
- 预测形状与输入匹配
- 归一化预测在合理范围内

**物理恢复正确性**：
- 反归一化后单位正确
- 坐标恢复与原始数据一致
- 边界掩膜应用正确
- 派生量计算符合物理定义

**样本唯一性**：
- 每个测试样本有且仅有一个结果
- 结果文件命名唯一
- 无重复或遗漏

**推理纯洁性**：
- 未使用测试标签修正预测
- 未在推理时引入训练信息
- 推理过程无数据泄漏

**耗时记录**：
- 总耗时准确
- 平均单样本耗时合理
- 无异常耗时波动

## 回退策略

**设备降级**：
- GPU不可用 → 降级到CPU推理（耗时增加，结果一致）
- 多GPU不可用 → 使用单GPU或CPU

**批大小调整**：
- 显存不足 → 减小batch_size（如从8减到4或2）
- 内存不足 → 减少数据加载器工作进程

**结果修复**：
- 部分样本预测失败 → 标记失败样本，继续处理其他样本
- 结果文件损坏 → 重新推理失败样本

**物理恢复修复**：
- 坐标恢复错误 → 检查并修复变换公式
- 边界掩膜错误 → 重新定义掩膜或检查索引
- 派生量错误 → 检查并修复计算公式
