# 拉格朗日流体模型任务验收与适用域判定

## 适用范围

面向拉格朗日流体模型的任务验收与适用域判定任务。适用于：
- E3等变粒子网络模型的性能评估与验收
- 物理约束满足性验证（守恒律、边界条件）
- 泛化能力评估与适用域明确
- 域外工况测试与工程可用性判定

任务目标：按验收指标评估统计误差、关键物理约束、泛化能力和计算收益，给出PASS、REJECT或BLOCKED判定，明确适用域限制与复核建议。

## 输入

**必填输入**：
- {METRICS}: 验收指标列表（统计和物理指标）

**可选输入**：
- {MAX_RELATIVE_L2}: 相对误差门限（测试集放行阈值）
- {RUN_OOD_TEST}: 是否外推测试（测试域外工况）

**前置依赖**：
- s04输出的predictions/（预测结果）
- s04输出的inference_manifest.json（推理清单）

**默认配置**：
- METRICS: ["relative_L2", "RMSE", "conservation_residual", "boundary_error"]
- MAX_RELATIVE_L2: 0.1
- RUN_OOD_TEST: true

## 输出

**核心产物**：
- evaluation.json: 评估结果（逐指标、逐变量误差）
- worst_cases.csv: 最差样本（可追溯、可诊断）
- applicability_report.md: 适用域报告（泛化能力、限制条件、复核建议）
- PASS_REJECT_BLOCKED.txt: 验收判定（最终结论）

**评估内容**：
- 逐变量统计误差（L2、RMSE、MAE等）
- 边界误差（壁面、自由面）
- 守恒残差（质量、动量、能量）
- 最差样本分析
- 推理成本统计
- 域外工况测试结果

## 流程节点

```
指标计算 → 误差分析 → 物理验证 → 最差样本 → 域外测试 → 适用域判定 → 结论输出
```

**指标计算**：
- 操作：按{METRICS}计算s04结果
- 参数：指标定义、计算方法
- 质量门禁：指标计算正确、无遗漏

**误差分析**：
- 操作：报告逐变量误差、误差分布、误差统计
- 参数：误差类型、统计方法
- 质量门禁：误差分析完整、可解释

**物理验证**：
- 操作：计算守恒残差、边界误差、物理约束违反
- 参数：物理约束定义、容差
- 质量门禁：物理验证完整、约束明确

**最差样本**：
- 操作：识别并分析最差样本
- 参数：最差样本数量、分析深度
- 质量门禁：最差样本可追溯、可诊断

**域外测试**：
- 操作：若{RUN_OOD_TEST}为true，执行几何或工况外推测试
- 参数：域外工况定义、测试方法
- 质量门禁：域外测试完整、结果明确

**适用域判定**：
- 操作：基于评估结果判定适用域
- 参数：判定规则、阈值
- 质量门禁：适用域明确、限制条件清晰

**结论输出**：
- 操作：输出PASS/REJECT/BLOCKED判定
- 参数：判定标准
- 质量门禁：结论有充分证据支持、含复核建议

## 关键参数

| 参数 | 默认值 | 来源 | 说明 |
|------|--------|------|------|
| 验收指标 | relative_L2, RMSE, conservation_residual, boundary_error | [场景需求书] | 默认指标集 |
| 相对误差门限 | 0.1 | [场景需求书] | 测试集放行阈值 |
| 域外测试 | true | [场景需求书] | 默认执行 |
| 最差样本数 | 5 | [场景需求书] | 可配置 |
| 守恒容差 | 1e-3 | [场景需求书] | 默认配置 |
| 边界误差容差 | 0.05 | [场景需求书] | 默认配置 |
| 判定标准 | PASS: 所有指标达标; REJECT: 任一关键指标超标; BLOCKED: 输入缺失 | [场景需求书] | 默认规则 |

## 边界与分流

**输入缺失**：
- 预测结果缺失 → 返回BLOCKED，要求完成s04
- 评估指标未定义 → 返回BLOCKED，要求明确指标
- 域外工况未定义 → 跳过域外测试，记录为"未测试"

**指标超标**：
- 相对L2误差超门限 → REJECT，需调整模型或数据
- 物理约束违反严重 → REJECT，需增加物理正则化
- 边界误差过大 → REJECT，需改进边界处理

**域外失败**：
- 几何外推失败 → 明确适用域限制（几何范围）
- 工况外推失败 → 明确适用域限制（工况范围）
- 部分域外成功 → 细化适用域边界

**计算问题**：
- 指标计算异常 → 检查预测数据、修复计算公式
- 物理验证失败 → 检查物理模型、调整约束强度

## 质量检查

**统计指标完整性**：
- 逐变量误差报告
- 误差分布统计（均值、方差、分位数）
- 误差与输入的相关性分析

**物理约束验证**：
- 守恒残差计算（质量、动量、能量）
- 边界误差计算（壁面、自由面）
- 物理合理性检查（非负性、单调性等）

**最差样本分析**：
- 最差样本识别（误差最大的样本）
- 最差样本追溯（输入数据、预测结果、误差来源）
- 最差样本诊断（可能原因、改进方向）

**域外测试完整性**：
- 域外工况定义明确
- 测试结果可解释
- 适用域边界清晰

**结论充分性**：
- 判定有充分证据支持
- 适用域限制明确
- 复核建议具体可行

## 回退策略

**指标计算修复**：
- 计算异常 → 检查数据格式、修复计算公式
- 指标不全 → 补充缺失指标、重新计算

**物理验证修复**：
- 守恒违反 → 检查物理模型、增加守恒约束
- 边界误差大 → 改进边界处理、增加边界数据

**域外测试修复**：
- 域外定义不明确 → 明确域外工况、重新测试
- 测试结果不清晰 → 细化测试分析、增加测试用例

**结论修复**：
- 判定证据不足 → 补充评估、增加分析
- 适用域不明确 → 细化适用域边界、增加限制说明
