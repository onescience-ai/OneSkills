# 任务验收与适用域判定

## 适用范围

**触发条件**：
- 需要评估数据驱动模型的统计误差和物理一致性
- 需要判定模型的适用域和域外工况处理策略

**适用场景**：
- 多孔介质 CFD 数据驱动预测模型的最终验收
- 需要多维度指标（统计误差 + 物理约束 + 泛化能力）综合评估
- 需要输出适用域报告和域外工况复核建议

**不适用场景**：
- 仅需初步评估的中间阶段
- 不涉及物理一致性检查的纯数据回归

## 输入

- {METRICS}：验收指标列表（必填，默认含 closure RMSE, mean profile error, spectrum error, stability horizon）
- {MAX_RELATIVE_L2}：相对误差门限（可选，默认 0.1）
- {RUN_OOD_TEST}：是否外推测试（可选，默认 true）

## 输出

- evaluation.json：详细评估结果
- worst_cases.csv：最差样本清单
- applicability_report.md：适用域报告
- PASS_REJECT_BLOCKED.txt：验收结论

## 流程节点

### Step 5.1：统计误差评估
- **操作**：计算逐变量误差、边界误差、最差样本
- **参数**：评估指标、预测结果、参考数据
- **工具**：评估脚本
- **质量门禁**：统计误差在可接受范围内

### Step 5.2：物理约束验证
- **操作**：验证守恒或方程残差
- **参数**：预测场、控制方程
- **工具**：物理验证脚本
- **质量门禁**：守恒误差在可接受范围内

### Step 5.3：泛化能力评估
- **操作**：执行几何或工况外推测试
- **参数**：域外测试数据
- **工具**：评估脚本
- **质量门禁**：域外工况误差不显著高于域内

### Step 5.4：计算收益评估
- **操作**：评估推理成本与加速比
- **参数**：推理时间、CFD 求解时间
- **工具**：计时脚本
- **质量门禁**：推理成本可接受，加速比合理

### Step 5.5：适用域报告生成
- **操作**：综合所有评估结果，生成适用域报告
- **参数**：各维度评估结果
- **工具**：报告生成脚本
- **质量门禁**：报告包含适用域限制与复核建议

### Step 5.6：验收结论
- **操作**：根据评估结果给出 PASS/REJECT/BLOCKED 结论
- **参数**：评估结果、误差门限
- **工具**：决策脚本
- **质量门禁**：结论有充分依据，最差样本可追溯

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 验收维度 | 统计误差 + 物理约束 + 泛化能力 + 计算收益 | [场景需求书 s05] | 多维度综合评估 |
| 最差样本 | 必须可追溯 | [场景需求书 s05] | 不能仅凭平均误差 |
| 适用域报告 | 必须包含限制与复核建议 | [场景需求书 s05] | 域外工况需经 CFD 复核 |
| 验收结论 | PASS/REJECT/BLOCKED | [场景需求书 s05] | 三态结论 |

### 校准数值

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认验收指标 | closure RMSE, mean profile error, spectrum error, stability horizon | [场景需求书] | 统计与物理双维度 |
| 默认相对误差门限 | 0.1 | [场景需求书] | 测试集放行阈值 |
| 默认外推测试 | true | [场景需求书] | 建议执行域外工况测试 |

> 以上数值来自 CFD_S077 场景需求书，供量级校准；其他体系需以自身证据重新锚定。

## 边界与分流

- **统计误差超标**：给出 REJECT 结论，建议数据增强或模型改进
- **物理约束不满足**：给出 REJECT 结论，建议调整闭合项预测策略
- **域外工况精度显著下降**：明确标注适用域边界，建议域外工况经 CFD 复核
- **计算成本过高**：评估加速比，权衡精度与效率
- **数据不足无法评估**：给出 BLOCKED 结论，要求补充测试数据

## 质量检查

- 评估完整性：统计误差、物理约束、泛化能力、计算收益均有评估
- 最差样本可追溯：每个最差样本可关联到具体工况和误差值
- 适用域报告完整：包含适用域限制、域外工况处理建议、复核建议
- 结论有充分依据：PASS/REJECT/BLOCKED 结论基于明确的评估结果

## 回退策略

- 若评估指标不明确，可参考同类任务的基准指标
- 若外推测试不可行，可标注为"未评估"并建议后续补充
- 若适用域报告无法给出明确结论，标注为 BLOCKED 并建议领域专家复核
