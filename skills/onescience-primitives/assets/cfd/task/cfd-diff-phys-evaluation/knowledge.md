# 任务验收与适用域判定

## 适用范围

本任务为可微分物理求解工作流的最终评估阶段，负责综合评估统计误差、关键物理约束、泛化能力和计算收益，输出PASS/REJECT/BLOCKED结论及适用域报告。适用于所有需要工程化部署或学术发表的可微分物理求解任务。不得仅凭平均误差宣称工程可用，必须报告最差样本和适用域边界。

## 输入

### 必需输入
| 变量 | 类型 | 说明 |
|------|------|------|
| `{METRICS}` | list[str] | 验收指标列表 |
| `{MAX_RELATIVE_L2}` | float | 相对L2误差门限（默认0.1） |

### 可选输入
| 变量 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `{RUN_OOD_TEST}` | bool | true | 是否执行域外工况测试 |

### 默认验收指标
```json
[
  "solver_residual",
  "relative_L2",
  "speedup",
  "conservation_error"
]
```

## 输出

### 产物清单
| 文件 | 格式 | 说明 |
|------|------|------|
| `evaluation.json` | JSON | 综合评估结果 |
| `worst_cases.csv` | CSV | 最差样本详情 |
| `applicability_report.md` | Markdown | 适用域报告 |
| `PASS_REJECT_BLOCKED.txt` | Text | 验收结论 |

### 质量门禁
- [ ] 统计与物理指标同时报告
- [ ] 最差样本可追溯
- [ ] 结论含适用域限制与复核建议

## 流程节点

```
1. 加载s04产出的coupled_solution/与residual_history.csv
   ↓
2. 计算统计指标（相对L2误差、最大误差、平均误差）
   ↓
3. 计算物理指标（守恒误差、方程残差、边界误差）
   ↓
4. 定位最差样本并分析原因
   ↓
5. 计算推理成本（加速比、耗时）
   ↓
6. 执行域外工况测试（若RUN_OOD_TEST=true）
   ↓
7. 综合判定PASS/REJECT/BLOCKED
   ↓
8. 生成适用域报告
```

## 关键参数

### 验收指标
| 指标 | 说明 | 通过条件 |
|------|------|----------|
| relative_L2 | 相对L2误差 | ≤ MAX_RELATIVE_L2 (0.1) |
| solver_residual | 求解器残差 | <1e-6 |
| conservation_error | 守恒误差 | <1% |
| speedup | 相对原求解器加速比 | >1（加速）或可接受（无加速） |
| boundary_error | 边界误差 | <可接受阈值 |

### 判定逻辑
| 条件 | 结论 |
|------|------|
| 所有指标通过 | PASS |
| 任一指标不通过 | REJECT |
| 数据/权重不可用 | BLOCKED |

### 适用域测试
| 测试类型 | 说明 |
|----------|------|
| 几何外推 | 测试未见过的几何形状 |
| 工况外推 | 测试超出训练范围的参数 |
| 时间外推 | 测试更长时间尺度 |

## 边界与分流

### 正常流
加载结果 → 计算指标 → 综合判定 → 生成报告

### 异常分支
| 条件 | 处理 |
|------|------|
| 结果文件不完整 | BLOCKED，列出缺失 |
| 指标计算失败 | 降级为部分评估 |
| 域外测试失败 | 标记适用域边界 |

### 降级策略
- 若完整评估不可行，可执行简化评估（仅统计指标）
- 若域外测试不可行，可标注"适用域待确认"

## 质量检查

### 指标完整性
- [ ] 统计误差逐变量报告
- [ ] 物理约束逐项报告
- [ ] 最差样本ID与误差

### 结论可靠性
- [ ] 结论基于指标而非主观判断
- [ ] 适用域边界明确
- [ ] 复核建议具体

## 回退策略

| 失败原因 | 回退方案 |
|----------|----------|
| 结果不可用 | 回退s04检查求解 |
| 指标异常 | 分析数据或模型问题 |
| 适用域不确定 | 扩展测试范围 |
