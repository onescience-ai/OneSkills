# 数据接入与契约核验

## 适用范围

**触发条件**：
- 需要接入多孔介质 CFD 数据集并验证数据质量
- 需要为后续数据驱动建模建立机器可读的数据契约

**适用场景**：
- CFD 数据集的首次导入与质量检查
- 需要核验变量定义、单位、坐标系、网格拓扑
- 需要输出标准化数据契约供后续流程消费

**不适用场景**：
- 已有完整数据契约的已有数据集
- 非 CFD 来源的结构化数据

## 输入

- {DATASET_PATH}：数据集目录或清单文件路径（必填）
- {DATASET_NAME}：数据集名称与版本（必填，默认"多孔介质微流动与输运CFD数据"）
- {DATA_CONTRACT}：数据契约模板（可选，含 input_fields, target_fields, units, coordinates）

## 输出

- dataset_manifest.json：数据集清单（文件列表、样本数、变量清单）
- data_contract.json：机器可读数据契约（变量定义、单位、坐标系）
- data_audit.md：数据审计报告（缺失值、异常、许可信息）

## 流程节点

### Step 1.1：文件可读性检查
- **操作**：检查数据集路径下所有文件是否可读
- **参数**：数据集路径
- **工具**：文件系统操作
- **质量门禁**：所有文件可读，无损坏文件

### Step 1.2：样本与变量核验
- **操作**：统计样本数，识别输入变量和目标变量
- **参数**：数据集清单
- **工具**：数据读取库
- **质量门禁**：样本数 > 0，变量名与类型完整

### Step 1.3：单位与坐标系核验
- **操作**：检查变量单位定义、坐标系、网格拓扑
- **参数**：数据契约模板（如有）
- **工具**：数据验证脚本
- **质量门禁**：单位明确、坐标系一致、网格拓扑合理

### Step 1.4：数据契约生成
- **操作**：将核验结果整理为 machine-readable 契约
- **参数**：核验结果
- **工具**：JSON 序列化
- **质量门禁**：契约包含所有必要字段，格式正确

## 边界与分流

- **文件不可读**：返回 BLOCKED，列出不可读文件清单
- **样本数为零**：返回 BLOCKED，要求补充数据
- **变量定义不完整**：返回 BLOCKED，列出缺失变量
- **单位不一致**：在审计报告中标注，建议统一单位后再继续
- **缺少数据契约模板**：使用默认契约模板，标注"待用户确认"

## 质量检查

- 文件可读性：100% 文件可读
- 样本追溯性：每个样本可关联到原始 CFD 模拟
- 变量完整性：输入变量和目标变量均有明确定义
- 单位一致性：所有变量单位明确且一致

## 回退策略

- 若数据集格式未知，尝试多种读取器（HDF5, NetCDF, CSV, Parquet）
- 若变量名不规范，尝试基于物理含义的模糊匹配
- 若单位缺失，标注为"unknown"并在审计报告中提醒用户
