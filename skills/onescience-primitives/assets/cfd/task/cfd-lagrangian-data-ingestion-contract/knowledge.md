# 拉格朗日粒子轨迹数据接入与契约核验

## 适用范围

面向拉格朗日粒子轨迹数据集的接入、审计与契约生成任务。适用于：
- E3等变粒子网络拉格朗日流体模拟的数据准备阶段
- 粒子动力学数据的质量控制与标准化
- 深度学习流体模型训练前的数据预处理

任务目标：确保数据可读、变量完整、单位坐标系明确、无训练测试泄漏，输出机器可读契约供后续步骤使用。

## 输入

**必填输入**：
- {DATASET_PATH}: 数据集路径（目录或清单文件）
- {DATASET_NAME}: 数据集名称（来源与数据版本标识）

**可选输入**：
- {DATA_CONTRACT}: 数据契约模板（变量、单位、网格定义）

**数据格式要求**：
- 支持格式：HDF5、NumPy、CSV、自定义二进制
- 必须包含：粒子ID、时间戳、位置坐标、速度分量、物理属性
- 坐标系：笛卡尔坐标系（x, y, z）

## 输出

**核心产物**：
- dataset_manifest.json: 数据清单（样本数、变量列表、时间范围）
- data_contract.json: 机器可读契约（变量定义、单位、坐标系、网格拓扑）
- data_audit.md: 审计报告（完整性、一致性、缺失值统计）

**审计内容**：
- 文件可读性检查
- 样本数统计与追溯
- 输入与目标变量识别
- 单位与坐标系验证
- 网格拓扑（粒子邻域关系）
- 时间或工况范围
- 缺失值检测与标记
- 使用许可确认

## 流程节点

```
文件读取 → 变量识别 → 单位验证 → 坐标系确认 → 网格拓扑检查 → 完整性审计 → 契约生成
```

**文件读取**：
- 操作：加载数据集，检查文件格式兼容性
- 参数：文件路径、格式标识
- 质量门禁：文件可读、格式正确

**变量识别**：
- 操作：提取变量名、类型、维度
- 参数：预期变量列表
- 质量门禁：所有必需变量存在

**单位验证**：
- 操作：检查物理量单位定义
- 参数：单位制（SI/自定义）
- 质量门禁：单位明确且一致

**坐标系确认**：
- 操作：验证坐标系定义
- 参数：坐标系类型（笛卡尔/柱坐标/球坐标）
- 质量门禁：坐标系明确且正确

**网格拓扑检查**：
- 操作：分析粒子邻域关系
- 参数：拓扑类型（无结构/图结构）
- 质量门禁：拓扑信息可提取

**完整性审计**：
- 操作：统计缺失值、异常值
- 参数：缺失阈值
- 质量门禁：缺失值可追溯、无训练测试泄漏

**契约生成**：
- 操作：输出机器可读契约
- 参数：契约模板
- 质量门禁：契约完整、格式正确

## 边界与分流

**数据不可用**：
- 文件不存在或不可读 → 返回BLOCKED，列出缺失文件
- 格式不支持 → 返回BLOCKED，要求格式转换
- 必需变量缺失 → 返回BLOCKED，列出缺失变量

**数据质量问题**：
- 缺失值超过阈值 → 警告但不阻塞，记录在审计报告中
- 单位定义不一致 → 警告，尝试自动转换或要求修复
- 坐标系不明确 → 要求用户确认

**许可问题**：
- 数据使用许可不明确 → 记录在审计报告中，要求确认
- 限制性许可 → 警告，说明使用限制

## 质量检查

**数据完整性**：
- 所有必需变量存在且有定义
- 样本数可追溯（每个粒子有唯一ID）
- 时间戳连续或可排序

**数据一致性**：
- 单位定义一致（无混合单位制）
- 坐标系定义明确（无歧义）
- 物理量范围合理（无异常极端值）

**训练测试隔离**：
- 检测潜在的数据泄漏风险
- 确保同一轨迹不会同时出现在训练和测试集
- 记录工况分布，供后续切分参考

**契约合规性**：
- 契约包含所有必需字段
- 变量定义与实际数据匹配
- 单位与坐标系信息完整

## 回退策略

**格式转换**：
- 不兼容格式 → 转换为HDF5或NumPy格式
- 压缩文件 → 解压后重新审计

**变量补全**：
- 缺失变量可计算 → 派生计算（如速度从位置差分）
- 缺失变量不可得 → 明确标注缺失，调整后续步骤

**单位修复**：
- 单位不一致 → 统一转换为SI单位制
- 单位未定义 → 要求用户提供或使用默认假设（需记录）

**坐标系修复**：
- 坐标系不明确 → 要求用户提供或使用默认假设（需记录）
- 坐标系变换 → 应用变换矩阵并记录
