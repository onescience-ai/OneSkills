# 隐式神经场预处理与数据切分

## 适用范围

本任务适用于隐式神经场连续流动降阶建模的预处理阶段，负责统一物理量与表示，按几何、工况或时间构造无泄漏切分，保存统计量与可逆变换，确保数据质量与训练有效性。

**触发条件**：
- 输入数据已通过数据接入与契约核验
- 需要进行数据预处理与切分
- 需要保存统计量与可逆变换

**不适用场景**：
- 数据未通过核验的场景
- 需要保持原始数据完整性的场景
- 切分策略不明确的场景

## 输入

**数据源**：
- s01输出的数据清单和契约
- 切分配置（train/validation/test比例、种子、分组方式）
- 目标变量列表
- 是否无量纲化选项

**切分配置模板**：
```json
{
  "train": 0.7,
  "validation": 0.15,
  "test": 0.15,
  "seed": 42,
  "group_by": "geometry_or_trajectory"
}
```

## 输出

**数据产物**：
- train_manifest.json：训练集清单
- validation_manifest.json：验证集清单
- test_manifest.json：测试集清单
- normalization.json：归一化统计量

**验证标准**：
- 三份切分的对象轨迹互斥
- 仅用训练集计算变换统计量
- 边界与掩膜语义未破坏

## 流程节点

### 1. 数据加载
- **操作**：加载s01输出的数据清单和契约
- **参数**：数据清单路径、契约文件
- **工具**：数据加载器
- **质量门禁**：数据可读、契约完整

### 2. 数据清洗
- **操作**：处理缺失值、异常值、重复样本
- **参数**：清洗规则
- **工具**：数据清洗器
- **质量门禁**：数据质量达标、无异常值

### 3. 物理量统一
- **操作**：统一物理量表示、单位转换、无量纲化
- **参数**：目标变量、是否无量纲化
- **工具**：物理量统一器
- **质量门禁**：单位一致、无量纲化正确

### 4. 数据切分
- **操作**：按几何、工况或时间构造无泄漏切分
- **参数**：切分配置、分组方式
- **工具**：数据切分器
- **质量门禁**：切分互斥、无泄漏

### 5. 统计量计算
- **操作**：计算训练集统计量（均值、方差、最小最大值等）
- **参数**：训练集数据
- **工具**：统计量计算器
- **质量门禁**：统计量正确、仅使用训练集

### 6. 变换保存
- **操作**：保存归一化/无量纲化变换与逆变换
- **参数**：统计量、变换参数
- **工具**：变换保存器
- **质量门禁**：变换可逆、参数完整

### 7. 清单生成
- **操作**：生成三份切分清单和归一化统计文件
- **参数**：切分结果、统计量
- **工具**：清单生成器
- **质量门禁**：清单格式正确、内容完整

## 边界与分流

**前提条件与改道**：

1. **数据已通过核验**
   - 不成立时 → 改道：返回s01重新核验数据

2. **切分配置合理**
   - 不成立时 → 改道：使用默认配置或调整比例

3. **分组方式明确**
   - 不成立时 → 改道：使用默认分组方式或人工指定

4. **统计量计算正确**
   - 不成立时 → 改道：重新计算统计量、验证计算过程

5. **变换可逆**
   - 不成立时 → 改道：检查变换参数、重新保存逆变换

## 质量检查

**验证点**：
- 切分互斥性检查
- 统计量来源验证
- 边界语义检查
- 变换可逆性验证
- 清单完整性检查

**阈值**：
- 切分互斥性 100%
- 统计量来源正确率 100%
- 边界语义完整性 100%
- 变换可逆性 100%

**失败处理**：
- 切分不互斥 → 重新切分、调整分组方式
- 统计量来源错误 → 重新计算、仅使用训练集
- 边界语义破坏 → 检查掩膜、修复边界
- 变换不可逆 → 检查变换参数、重新保存
- 清单不完整 → 重新生成、补充缺失项

## 回退策略

**失败时的替代方案**：
1. 数据清洗失败 → 标记异常值、进行人工处理
2. 物理量统一失败 → 使用原始单位、标记不一致
3. 数据切分失败 → 使用简单随机切分、调整策略
4. 统计量计算失败 → 使用简单统计量、验证计算
5. 变换保存失败 → 保存原始数据、标记无变换
