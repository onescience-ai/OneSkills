# 神经数值耦合求解

## 适用范围

本任务为可微分物理求解工作流的求解执行阶段，负责将训练好的神经网络嵌入传统数值求解器，执行端到端的耦合迭代求解。适用于需要神经网络提供物理校正、网格移动、预条件或代理模块的CFD求解场景。当耦合求解发散时，应停止并输出最后稳定状态，报告发散原因。

## 输入

### 必需输入
| 变量 | 类型 | 说明 |
|------|------|------|
| `{CHECKPOINT}` | doc | s03产出的最佳模型权重 |
| `{DEVICE}` | str | 计算设备：cpu或cuda |

### 可选输入
| 变量 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `{BATCH_SIZE}` | int | 8 | 推理批大小，按显存调整 |

## 输出

### 产物清单
| 文件/目录 | 格式 | 说明 |
|-----------|------|------|
| `coupled_solution/` | 目录 | 求解结果场数据 |
| `residual_history.csv` | CSV | 逐迭代残差历史 |
| `solver_timing.json` | JSON | 求解耗时统计 |

### 质量门禁
- [ ] 耦合接口变量单位一致
- [ ] 残差达到数值收敛门限
- [ ] 相对原求解器误差和加速比均报告

## 流程节点

```
1. 加载s03产出的best_checkpoint.pt
   ↓
2. 初始化数值求解器（如OpenFOAM）
   ↓
3. 将神经网络模块注册为求解器插件
   ↓
4. 设置初始条件与边界条件
   ↓
5. 迭代求解循环：
   ├─ 神经网络前向推理（校正/预条件）
   ├─ 数值求解器一步迭代
   ├─ 计算残差与守恒量
   └─ 检查收敛条件
   ↓
6. 收敛或达到最大迭代 → 保存结果
   ↓
7. 发散 → 保存最后稳定状态 + 发散诊断
```

## 关键参数

### 耦合模式
| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 校正模式 | 神经网络输出残差校正 | 传统求解器加速 |
| 预条件模式 | 神经网络提供预条件矩阵 | 迭代求解器加速 |
| 代理模式 | 神经网络替代部分物理计算 | 计算代价高的物理项 |
| 混合模式 | 多种模式组合 | 复杂耦合问题 |

### 收敛判据
| 判据 | 默认门限 | 说明 |
|------|----------|------|
| 残差范数 | <1e-6 | 相对残差 |
| 守恒误差 | <1% | 质量/能量守恒 |
| 场变化率 | <1e-4 | 相邻迭代场差异 |

## 边界与分流

### 正常流
加载权重 → 嵌入求解器 → 迭代收敛 → 保存结果

### 异常分支
| 条件 | 处理 |
|------|------|
| 求解发散 | 停止，输出最后稳定状态 |
| 残差振荡 | 降低步长或调整预条件 |
| GPU内存不足 | 降低batch_size或使用CPU |
| 接口单位不匹配 | 报错，要求统一单位 |

### 降级策略
- 若神经网络耦合失败，可回退到纯CFD求解
- 若发散频繁，可放宽收敛门限或增加阻尼

## 质量检查

### 收敛监控
- [ ] 残差曲线平滑下降
- [ ] 守恒量误差在可接受范围
- [ ] 无发散或振荡

### 结果验证
- [ ] 物理场分布合理
- [ ] 边界条件满足
- [ ] 与参考解对比误差可接受

## 回退策略

| 失败原因 | 回退方案 |
|----------|----------|
| 权重加载失败 | 检查checkpoint格式 |
| 求解发散 | 降低步长、增加阻尼 |
| 接口错误 | 检查变量映射 |
| 内存不足 | 减小batch_size |
