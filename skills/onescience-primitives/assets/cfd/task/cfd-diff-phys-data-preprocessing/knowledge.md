# 预处理与数据切分

## 适用范围

本任务为可微分物理求解工作流的数据准备阶段，负责将原始数据统一为可训练格式，并按物理约束进行无泄漏切分。适用于CFD轨迹数据的预处理场景，特别强调按几何、轨迹或工况为单位的切分策略，避免同一物理过程的数据泄露到不同集合。当数据不满足无泄漏切分条件时，应返回BLOCKED并说明原因。

## 输入

### 必需输入
| 变量 | 类型 | 说明 |
|------|------|------|
| `{SPLIT_CONFIG}` | object | 切分配置，含比例、种子、分组策略 |
| `{TARGET_FIELDS}` | list[str] | 待预测的目标物理量列表 |

### 可选输入
| 变量 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `{NONDIMENSIONALIZE}` | bool | true | 是否进行无量纲化 |

### 切分配置模板
```json
{
  "train": 0.7,
  "validation": 0.15,
  "test": 0.15,
  "seed": 42,
  "group_by": "geometry_or_trajectory"
}
```

## 输出

### 产物清单
| 文件 | 格式 | 说明 |
|------|------|------|
| `train_manifest.json` | JSON | 训练集清单 |
| `validation_manifest.json` | JSON | 验证集清单 |
| `test_manifest.json` | JSON | 测试集清单 |
| `normalization.json` | JSON | 归一化统计量（可逆） |

### 质量门禁
- [ ] 三份切分的对象轨迹互斥
- [ ] 仅用训练集计算变换统计量
- [ ] 边界与掩膜语义未破坏

## 流程节点

```
1. 加载s01产出的data_contract.json
   ↓
2. 统一物理量单位与表示
   ↓
3. 执行无量纲化（若启用）
   ↓
4. 按group_by策略分组样本
   ↓
5. 计算训练集统计量（均值、方差等）
   ↓
6. 应用变换到所有集合
   ↓
7. 输出三份manifest与normalization.json
```

## 关键参数

### 切分策略
| group_by | 说明 | 适用场景 |
|----------|------|----------|
| `geometry` | 按几何形状分组 | 多几何体数据集 |
| `trajectory` | 按完整轨迹分组 | 时间序列数据 |
| `condition` | 按物理工况分组 | 多工况数据 |
| `none` | 随机切分（不推荐） | 仅用于独立样本 |

### 无量纲化参数
| 参数 | 说明 | 注意事项 |
|------|------|----------|
| 均值 | 训练集均值 | 仅用训练集计算 |
| 方差 | 训练集方差 | 仅用训练集计算 |
| 最小值 | 训练集最小值 | 用于min-max归一化 |
| 最大值 | 训练集最大值 | 用于min-max归一化 |

## 边界与分流

### 正常流
数据统一 → 无量纲化 → 无泄漏切分 → 输出manifests

### 异常分支
| 条件 | 处理 |
|------|------|
| 目标字段不在数据中 | BLOCKED，列出可用字段 |
| 切分比例不匹配 | 调整比例或返回错误 |
| 样本不足 | 警告，建议补充数据 |
| 轨迹交叉 | 强制按轨迹切分，警告重叠 |

### 降级策略
- 若无量纲化失败，可使用原始尺度训练
- 若无泄漏切分不可行，可标记为"近似独立"并记录风险

## 质量检查

### 自动检查
- [ ] 三份manifest的样本ID无交集
- [ ] normalization.json的统计量来自训练集
- [ ] 边界条件标记完整

### 人工确认
- [ ] 切分策略符合物理直觉
- [ ] 无量纲化尺度合理

## 回退策略

| 失败原因 | 回退方案 |
|----------|----------|
| 数据格式不兼容 | 回退s01重新核验 |
| 切分不可行 | 调整策略或人工审查 |
| 统计量异常 | 检查数据质量 |
