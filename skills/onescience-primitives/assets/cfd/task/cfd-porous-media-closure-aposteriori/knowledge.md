# 闭合项预测与后验 CFD 耦合

## 适用范围

**触发条件**：
- 需要将训练好的模型嵌入 CFD 求解器进行后验验证
- 需要预测应力、通量或源项等闭合项

**适用场景**：
- CNN surrogate 或 Neural differential equation 模型的闭合项预测
- 闭合项嵌入 RANS 或 LES 求解器的后验推进
- 先验误差分析与可实现性检查

**不适用场景**：
- 不涉及 CFD 求解器耦合的纯数据回归
- 不需要后验验证的场景

## 输入

- {CHECKPOINT}：模型权重路径（必填，默认"best_checkpoint.pt"）
- {DEVICE}：计算设备（必填，默认"cuda"）
- {BATCH_SIZE}：推理批大小（可选，默认 8）

## 输出

- apriori_closure/：先验闭合项预测结果
- aposteriori_fields/：后验流场预测结果
- solver_stability.csv：求解器稳定性记录

## 流程节点

### Step 4.1：模型加载与推理
- **操作**：加载 checkpoint，在独立快照上执行推理
- **参数**：权重路径、计算设备、批大小
- **工具**：PyTorch, 训练好的模型
- **质量门禁**：模型加载成功，推理输出维度正确

### Step 4.2：先验误差分析
- **操作**：计算闭合项预测的统计误差（RMSE、MAE 等）
- **参数**：预测结果、参考数据
- **工具**：评估脚本
- **质量门禁**：误差在可接受范围内

### Step 4.3：可实现性检查
- **操作**：检查闭合张量或通量是否满足物理约束（对称性、正定性等）
- **参数**：预测的闭合项
- **工具**：约束检查脚本
- **质量门禁**：闭合张量满足对称性、正定性等物理约束

### Step 4.4：后验 CFD 耦合
- **操作**：将预测的闭合项嵌入 RANS 或 LES 求解器，执行后验推进
- **参数**：闭合项、求解器配置
- **工具**：CFD 求解器（RANS/LES）
- **质量门禁**：后验求解无非物理解和发散

### Step 4.5：后验验证
- **操作**：保存残差、能谱、统计剖面与稳定性记录
- **参数**：后验流场结果
- **工具**：验证脚本
- **质量门禁**：均值剖面与能谱经验证，稳定性记录完整

## 边界与分流

- **闭合项不满足约束**：检查模型训练，调整模型架构或训练策略
- **后验求解器发散**：降低时间步长、调整松弛因子、检查闭合项量级
- **均值剖面偏差过大**：检查闭合项预测精度，必要时重新训练模型
- **能谱异常**：检查闭合项的空间分辨率，必要时增加网格分辨率
- **显存不足**：减小推理批大小或使用 CPU 推理

## 质量检查

- 闭合项维度正确：与求解器要求一致
- 物理约束满足：对称性、正定性、量纲一致性
- 后验稳定性：求解器不发散，残差收敛
- 物理一致性：均值剖面、能谱与参考数据吻合

## 回退策略

- 若后验耦合不稳定，可回退到纯先验评估，仅报告闭合项预测精度
- 若求解器发散，可尝试不同的闭合项插值策略
- 若模型预测不准确，可回退到 Step 3 重新训练
