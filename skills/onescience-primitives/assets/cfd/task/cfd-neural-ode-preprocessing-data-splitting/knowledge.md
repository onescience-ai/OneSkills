# 预处理与数据切分（Neural ODE动力学学习）

## 适用范围

稳定性约束神经微分方程建模流程的第二步：统一物理量与表示，按几何、工况或时间构造无泄漏切分。适用于将原始动力系统时序数据转换为模型可消费的标准格式，并确保切分的数据独立性。

## 输入

- {SPLIT_CONFIG}: 切分配置（必填），默认train:0.7/val:0.15/test:0.15, seed:42
- {TARGET_FIELDS}: 目标变量列表（必填），待预测物理量
- {NONDIMENSIONALIZE}: 是否无量纲化（可选，默认true）

## 输出

- train_manifest.json: 训练集清单
- validation_manifest.json: 验证集清单
- test_manifest.json: 测试集清单
- normalization.json: 归一化/无量纲化统计量（均值、方差、尺度因子等）

## 流程节点

```
依据数据契约质控 → 统一物理量表示 → 归一化/无量纲化 → 按几何/轨迹/工况切分 → 保存统计量与可逆变换
```

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 切分比例 | train:0.7, val:0.15, test:0.15 | [场景需求书s02] | 标准三分 |
| 切分单位 | geometry_or_trajectory | [场景需求书s02] | 禁止帧打散 |
| 随机种子 | 42 | [场景需求书s02] | 可复现性 |
| 无量纲化 | true | [场景需求书s02] | 统一跨工况量纲 |

## 边界与分流

- 切分配置无效 → 回退到默认比例（0.7/0.15/0.15）
- 目标变量未定义 → 从data_contract.json自动推断
- 无量纲化失败 → 跳过并保留原始单位，标注警告

## 质量检查

- 三份切分的对象轨迹互斥（同一轨迹的帧不得分散到不同集合）
- 仅用训练集计算变换统计量（防止数据泄漏）
- 边界与掩膜语义未破坏
- 归一化统计量可逆（支持反归一化）

## 回退策略

- 切分比例不合理 → 自动调整为标准三分
- 数据量不足 → 扩充数据或使用迁移学习
- 归一化失败 → 保留原始单位，标注警告
