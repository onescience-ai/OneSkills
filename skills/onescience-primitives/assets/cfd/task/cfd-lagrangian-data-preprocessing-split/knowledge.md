# 拉格朗日粒子数据预处理与切分

## 适用范围

面向拉格朗日粒子轨迹数据的预处理与切分任务。适用于：
- E3等变粒子网络拉格朗日流体模拟的数据准备阶段
- 粒子动力学数据的标准化与图构建
- 需要无泄漏切分的深度学习流体模型训练

任务目标：完成质控、重采样、图构建、掩膜定义、归一化或无量纲化，按配置以几何/轨迹/工况为单位切分，保存可逆变换统计。

## 输入

**必填输入**：
- {SPLIT_CONFIG}: 切分配置（比例、种子、分组策略）
- {TARGET_FIELDS}: 目标变量列表（待预测物理量）

**可选输入**：
- {NONDIMENSIONALIZE}: 是否无量纲化（默认true）

**前置依赖**：
- s01输出的data_contract.json（数据契约）

**切分配置默认值**：
- train: 0.7
- validation: 0.15
- test: 0.15
- seed: 42
- group_by: geometry_or_trajectory

## 输出

**核心产物**：
- train_manifest.json: 训练集清单
- validation_manifest.json: 验证集清单
- test_manifest.json: 测试集清单
- normalization.json: 归一化统计（均值、标准差、最小值、最大值）

**中间产物**：
- 质控后的数据（去噪、去重）
- 图结构（粒子邻域关系）
- 掩膜定义（边界、自由面）
- 无量纲化参数

## 流程节点

```
质控 → 图构建 → 掩膜定义 → 归一化/无量纲化 → 切分 → 统计保存
```

**质控**：
- 操作：去除重复粒子、修复异常值、处理缺失值
- 参数：质控规则、异常阈值
- 质量门禁：数据干净、无重复、异常值处理记录完整

**图构建**：
- 操作：构建粒子邻域图（kNN或半径搜索）
- 参数：邻域大小k或搜索半径r
- 质量门禁：图连通性良好、邻域关系合理

**掩膜定义**：
- 操作：定义边界掩膜（壁面、自由面、入流/出流）
- 参数：掩膜类型、边界条件
- 质量门禁：掩膜语义正确、边界条件明确

**归一化/无量纲化**：
- 操作：统一物理量表示，消除量纲影响
- 参数：归一化方法（min-max/z-score/自定义）、无量纲化参数
- 质量门禁：仅用训练集计算统计量、变换可逆

**切分**：
- 操作：按配置以几何/轨迹/工况为单位切分
- 参数：切分配置（比例、种子、分组策略）
- 质量门禁：三份切分互斥、同一轨迹不跨切分

**统计保存**：
- 操作：保存归一化/无量纲化参数
- 参数：统计量类型
- 质量门禁：参数完整、可用于反变换

## 边界与分流

**数据量不足**：
- 样本数过少 → 调整切分比例（如train:0.8, val:0.1, test:0.1）
- 轨迹数过少 → 使用轨迹内帧切分（需记录风险）

**切分冲突**：
- 同一轨迹出现在多个切分 → 强制互斥切分，记录冲突
- 工况分布不均 → 使用分层切分或记录分布差异

**归一化问题**：
- 极端异常值影响统计 → 使用鲁棒归一化（如中位数/四分位数）
- 物理量范围差异大 → 分别归一化或使用自定义缩放

**图构建问题**：
- 粒子分布稀疏 → 增大搜索半径或使用自适应邻域
- 粒子分布密集 → 减小邻域大小或使用采样

## 质量检查

**切分互斥性**：
- 验证三份切分的粒子ID无交集
- 验证同一轨迹的帧不跨切分
- 记录切分边界（哪些轨迹/工况在哪个切分）

**统计量正确性**：
- 验证归一化参数仅来自训练集
- 验证反变换后恢复原始值
- 检查统计量数值合理性

**边界完整性**：
- 验证掩膜定义正确
- 检查边界条件一致性
- 确认无语义破坏

**数据质量**：
- 检查质控后无重复粒子
- 验证异常值处理记录
- 确认缺失值处理合理

## 回退策略

**切分调整**：
- 互斥性失败 → 强制重新切分，记录调整原因
- 分布不均 → 使用分层切分或调整比例

**归一化修复**：
- 统计量异常 → 使用鲁棒方法重新计算
- 变换不可逆 → 检查变换公式，修复实现

**图构建修复**：
- 连通性差 → 调整邻域参数或使用多尺度图
- 计算开销大 → 使用近似算法或采样

**掩膜修复**：
- 语义错误 → 重新定义边界条件
- 不一致 → 统一掩膜定义
