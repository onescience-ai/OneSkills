# 用于稀疏流的条件潜在生成框架

## 适用范围

用于参数化条件下稀疏流（如近连续流至滑移流、自由分子流）的高维物理场（如分布函数、宏观量）的快速预测与生成。典型场景包括：给定一组离散的物理参数（如克努森数 Kn、马赫数 Ma），需要获得对应连续参数下的流场解；或者需要从有限的参考解数据出发，在参数空间内进行插值或外推预测。该框架适用于流场维度高、传统求解器（如直接模拟蒙特卡洛 DSMC、离散速度法 DVM）计算成本高昂，且对物理一致性有一定要求的参数化研究问题。

## 输入

- **必需输入**：
    - 参数化物理条件集合：作为生成模型的输入条件，例如 Kn 数、Ma 数等。这些条件用于标识训练和查询的流场状态。
    - 空间与速度坐标：用于在最终解码阶段查询任意空间点和速度空间点上的物理场值。
- **可选输入**：
    - 参考解数据集：用于训练神经场表示和条件生成模型的稀疏流场参考解（例如来自 DVM 或 DSMC 的计算结果）。
    - 物理约束项：在物理纠正阶段使用的可微分物理残差（如 BGK 碰撞残差、质量守恒方程、壁面无穿透条件等）。

## 输出

- **主输出**：在给定的（查询）参数条件下，预测的高维物理场（如速度分布函数 δ、宏观密度、速度、温度等）。
- **辅助输出**：
    - 各阶段的误差指标：包括表示误差（神经场重构下限）、条件生成误差（潜在传输误差）和物理纠正效应。
    - 用于诊断和评估的标准化流场数据。

## 流程节点

本框架的核心流程是一个由五个主要步骤构成的有向无环图（DAG）。

### 步骤一：神经场表示学习 (`s1`)
- **步骤名**：神经场表示学习
- **描述**：训练一个条件无关的神经场自解码器。该解码器为每个训练条件分配一个独立的、可优化的查找码（lookup code），并通过共享的坐标解码器将这些编码解码到物理空间。此步骤不向解码器输入物理条件本身。
- **输入参数**：
    - `training_conditions`（训练条件集，枚举类型，必需）：例如 Knudsen 数或马赫数。需根据具体基准问题选择参数化变量。
- **输出**：
    - 条件无关的神经场解码器 D_θD。
    - 每个训练条件的独立查找码 z_i。
- **质量门**：解码误差需达到 Oracle 重构下限（即仅由表示能力决定的误差地板）。
- **上游依赖**：无（起始步骤）。

### 步骤二：潜在图表构建 (`s2`)
- **步骤名**：潜在图表构建
- **描述**：对步骤一获得的所有训练查找码进行主成分分析（PCA），构建一个低维的潜在坐标系（PCA chart）。随后对坐标进行白化/标准化处理，为后续条件生成模型提供紧凑且去相关的输入空间。
- **输入参数**：
    - `lookup_codes`（查找码矩阵，字符串/矩阵类型，必需）：来自步骤 s1 的输出。
    - `chart_dimension`（图表维度，整型，必需）：PCA 保留的主成分数量。其确定需平衡解码精度损失与方差解释率。
- **输出**：
    - 主成分变换矩阵 P 和其逆 P⁻¹。
    - 白化/标准化后的低维潜在坐标 a。
- **质量门**：因 PCA 截断导致的解码误差增量需在可接受范围内。
- **上游依赖**：`s1`。

### 步骤三：条件生成模型训练 (`s3`)
- **步骤名**：条件生成模型训练
- **描述**：在步骤二构建的低维潜在图表上，训练一个条件生成模型（如流匹配 FM 或扩散模型）。该模型学习从某个参考/源状态（例如高斯噪声分布或一个观测到的锚点潜在状态）到目标条件对应的潜在状态的映射。
- **输入参数**：
    - `generator_type`（生成器类型，枚举类型，必需）：可选 “FM”（流匹配）或 “diffusion”（扩散模型）。
    - `reference_state`（参考状态，字符串，必需）：生成的起点分布，例如 “高斯分布” 或 “观测锚点”。具体选择取决于生成器家族和问题特性。
- **输出**：
    - 训练好的条件生成器 G_θG。
    - 生成的终端潜在样本。
- **质量门**：在验证集的条件上，解码后的场误差需达到最低要求。
- **上游依赖**：`s2`。

### 步骤四：场解码与评估 (`s4`)
- **步骤名**：场解码与评估
- **描述**：将步骤三生成的潜在坐标，通过固定的逆 PCA 变换和神经场解码器，映射回高维物理空间，得到预测的流场。随后在指定的查询坐标上评估场值，并计算误差指标。
- **输入参数**：
    - `generated_latents`（生成的潜在坐标，字符串/矩阵类型，必需）：来自步骤 s3 的输出。
    - `query_coordinates`（查询坐标，字符串/矩阵类型，必需）：需要查询物理场的空间和速度空间坐标。
- **输出**：
    - 预测的物理场。
    - 场误差指标（如相对 L1 误差、面积加权 RMSE）。
- **质量门**：插值误差需在预期水平；外推误差需可接受（即不显著高于内插误差）。
- **上游依赖**：`s1`, `s3`。

### 步骤五（可选）：物理纠正 (`s5`)
- **步骤名**：物理纠正（可选）
- **描述**：在冻结的生成器和解码器基础上，训练一个结构化的低秩适配器。该适配器通过引入可微分的物理损失（如 BGK 残差、质量守恒），对预测流场进行后处理修正，以增强物理一致性。训练过程采用多目标检查点选择协议（包括冻结审计和可行性门控），确保在改善物理一致性的同时，场精度的下降在容差范围内。
- **输入参数**：
    - `physics_terms`（物理项，枚举类型，必需）：根据基准测试的可评估物理约束选择，例如 BGK 残差、质量守恒、壁面无穿透条件等。
- **输出**：
    - 物理约束的适配器 A_ψ。
    - 修正后的物理场。
    - 通过冻结审计的检查点。
- **质量门**：物理残差需减少，且场精度需保持在容差内（例如 RMS 相对增加 ≤ 0.05）。
- **上游依赖**：`s4`。

## 边界与分流

- **该框架的适用边界**：本框架主要针对参数化的稀疏流问题，且假设训练条件能够较好地覆盖查询条件所在的参数范围。对于训练条件范围之外的严重外推问题，生成模型的预测精度可能显著下降。
- **与其它方案的分流**：
    - 若问题不具备参数化特性（如单一条件下的流场求解），则应直接使用传统 CFD/DSMC 求解器或非条件化的神经网络代理模型。
    - 若流场的物理规律极其简单且计算成本不高，或对场精度要求极高，可能无需采用生成式模型，直接采用确定性回归模型或传统求解器更合适。
    - 对于强非平衡、多尺度耦合等复杂物理现象，物理纠正阶段可能需要更复杂的约束项或更高保真度的物理模型，这超出了当前适配器的简单实现范围。
- **上下游衔接**：该框架的输入依赖于参数化稀疏流的参考解数据集。其输出（预测的流场）可作为后续工程分析、优化或不确定性量化的输入。

## 质量检查

本框架采用分层、可分离的误差评估体系，以定位不同模块的性能瓶颈：

1.  **表示误差评估**：通过解码每个观测条件的优化查找码，评估神经场自解码器的重构能力。这代表了整个框架的性能下限。
2.  **条件生成误差评估**：固定解码器，评估生成器在潜在图表上进行条件传输后解码回物理空间的总误差。该误差包含了潜在传输误差和生成模型误差。
3.  **物理纠正效应评估**：成对比较冻结的生成预测与经过物理适配器修正后的预测，评估物理一致性（如 BGK 残差降低）和场精度的变化。
4.  **插值与外推评估**：将验证条件分为训练参数范围内的插值条件和范围外的外推条件，分别报告误差，以量化框架的泛化能力。

具体的误差指标（如相对 L1 误差、面积加权 RMSE）需根据物理量的量纲和重要性进行定义和选择。对于物理残差，应使用匹配网格和离散格式进行评估，以便进行公平的配对比较。

## 回退策略

当主流程遇到问题或性能不达标时，可考虑以下回退或调整策略：

- **表示阶段误差过大**：检查训练数据质量、神经场架构容量（如查找码维度、主干网络宽度与深度）以及坐标编码（如傅里叶特征）是否合适。可尝试增加模型容量或改进坐标编码。
- **条件生成模型性能不佳**：
    - 若生成误差高，可尝试切换生成器类型（如在 FM 与扩散间切换），调整生成模型架构（如 MLP 与 Residual MLP）或采样参数（如采样步数、路径类型）。
    - 检查 PCA 图表的维度是否合适，过高的维度可能导致生成困难，过低则损失信息。
- **物理纠正后场精度下降过多**：调整适配器的秩和学习率，或放宽冻结审计中的精度容差阈值。如果物理损失与数据损失冲突严重，可能需要重新审视物理约束项的设置或权重，甚至考虑放弃物理纠正步骤。
- **外推能力差**：这是当前生成模型的固有局限。应明确其适用范围主要为内插。对于必须外推的场景，需收集新条件的参考解以扩充训练集，或考虑其他专门针对外推的方法（如基于物理信息的迁移学习）。

## 资源召回建议

- **配套工具与库**：实现此框架通常需要：
    - **神经网络框架**：如 PyTorch 或 JAX，用于构建和训练自解码器、生成模型及适配器。
    - **生成模型库**：可参考或使用现有的流匹配（如 `torchdiffeq`）和扩散模型（如 `diffusers`）实现。
    - **线性代数库**：用于执行 PCA（如 `numpy.linalg` 或 `sklearn.decomposition`）。
    - **流场后处理工具**：用于计算物理残差（如 BGK 方程）和宏观量统计。
- **模板与参考**：本知识卡片本身提供了完整的流程节点模板（包括步骤、输入参数、输出和质量门），可作为新问题实现的蓝图。具体模型架构参数（如网络宽度、层数、PCA 维度）可参考类似稀疏流基准的典型配置，但最终需根据目标问题的复杂度和数据规模进行调整。
- **数据库**：训练数据需来自可靠、高精度的稀疏流求解器，如直接模拟蒙特卡洛（DSMC）或离散速度法（DVM）的计算结果。
