# 流固耦合逆向设计数据接入与契约核验

## 适用范围
流固耦合逆向设计的第一步，接入流固耦合轨迹与目标响应数据，核验样本、变量、单位、网格坐标及许可，建立数据清单和机器可读契约。适用于任何需要从原始数据开始进行流固耦合逆向设计的任务。

## 输入
- 数据集路径（{DATASET_PATH}）：目录或清单文件
- 数据集名称（{DATASET_NAME}）：来源与数据版本
- 数据契约（{DATA_CONTRACT}，可选）：变量、单位、网格定义

## 输出
- 数据集清单（dataset_manifest.json）
- 数据契约（data_contract.json）
- 数据审计报告（data_audit.md）

## 流程节点
```
s01 数据接入与契约核验
  │  1. 读取数据集路径中的文件
  │  2. 检查文件可读性
  │  3. 核验样本数、输入与目标变量
  │  4. 核验单位、坐标系、网格拓扑
  │  5. 核验时间或工况范围
  │  6. 检查缺失值和使用许可
  │  7. 按数据契约输出机器可读契约
  │  8. 缺少必填输入时返回BLOCKED并列出缺项
  │  不得编造数据、权重、工况或结果
  │  质量门禁：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏
```

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据核验 | 样本、变量、单位、网格、许可 | 场景需求书s01 | 全面检查数据完整性 |
| 缺失值处理 | 检查并记录 | 场景需求书s01 | 不得编造缺失数据 |
| 训练测试泄漏 | 检查并避免 | 场景需求书s01 | 确保数据独立性 |

### 校准数值
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据契约格式 | JSON | 场景需求书s01 | 机器可读格式 |

## 边界与分流
- 缺少必填输入时返回BLOCKED并列出缺项
- 数据文件不可读时返回BLOCKED并说明原因
- 数据契约不完整时返回BLOCKED并列出缺项
- 发现训练测试泄漏时返回REJECT并说明原因

## 质量检查
- 数据文件可读且样本可追溯
- 输入目标变量单位坐标定义完整
- 不存在训练测试泄漏
- 数据审计报告完整记录所有发现

## 回退策略
- 数据文件不可读时检查文件路径和权限
- 数据契约不完整时补充缺失字段
- 发现训练测试泄漏时重新划分数据集
