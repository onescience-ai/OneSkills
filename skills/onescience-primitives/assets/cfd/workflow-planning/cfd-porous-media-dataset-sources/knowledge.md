# 多孔介质微流动与输运CFD数据集获取指南

## 适用范围

面向多孔介质微流动与输运流动场的数据驱动预测任务，需要获取真实多孔介质微流动CFD仿真数据集。适用于孔隙尺度（pore-scale）流动模拟、达西/非达西流动、多孔介质渗透率场预测等场景。不适用于宏观连续介质模型或纯理论分析任务。

## 输入

- 任务目标：训练数据驱动模型预测多孔介质流动场（速度场、压力场、渗透率场）
- 数据需求：三维渗透率场K、速度场u/v、压力场p的网格数据
- 格式要求：VTK/XDMF/HDF5格式，包含网格坐标系和物理量单位

## 输出

- dataset_manifest.json：数据集元数据（样本ID、变量、单位、坐标系）
- data_contract.json：数据契约（输入输出字段定义、物理量映射）
- data_audit.md：数据审计报告（许可证、数据质量、来源验证）

## 流程节点

1. **识别数据源** → 2. **验证数据格式** → 3. **检查许可证** → 4. **生成数据契约** → 5. **执行数据审计**

### 步骤1：识别数据源
- 操作：检索公开多孔介质CFD数据集来源
- 参数：关键词"porous media"、"microflow"、"pore-scale"、"CFD dataset"
- 工具：OpenAlex、WebSearch、GitHub、Zenodo
- 质量门禁：数据集必须来自真实CFD仿真，非合成简化模型

### 步骤2：验证数据格式
- 操作：检查数据文件格式和变量完整性
- 参数：VTK/XDMF/HDF5格式，包含三维坐标和物理量
- 工具：ParaView、Python vtk库、h5py
- 质量门禁：网格坐标系明确，物理量单位完整

### 步骤3：检查许可证
- 操作：验证数据集使用许可证
- 参数：CC-BY、MIT、Apache等开放许可证
- 工具：数据集文档、GitHub README
- 质量门禁：许可证允许商业使用和修改

### 步骤4：生成数据契约
- 操作：创建data_contract.json定义输入输出字段
- 参数：物理量名称、符号、单位、维度、物理含义
- 工具：模板生成脚本
- 质量门禁：字段定义完整，单位映射准确

### 步骤5：执行数据审计
- 操作：验证数据质量和一致性
- 参数：样本完整性、变量相关性、异常值检测
- 工具：Python pandas、numpy
- 质量门禁：无缺失值，变量范围合理

## 边界与分流

### 前提1：存在真实多孔介质CFD数据集
- **不成立时转向**：使用合成数据（如Darcy定律简化模型），但需明确标注为engineering_validation(smoke/demo)，并在metadata中声明"合成数据仅含简化Darcy流动，不含惯性项、湍流、复杂孔隙几何等真实物理效应"

### 前提2：数据格式可被机器读取
- **不成立时转向**：手动解析数据格式，或联系数据提供方获取格式说明文档

### 前次3：许可证允许数据使用
- **不成立时转向**：寻找替代数据集，或联系数据提供方获取使用授权

## 质量检查

1. **数据来源验证**：检查数据集是否来自真实CFD仿真（非合成数据）
2. **格式完整性**：验证VTK/XDMF文件可被ParaView正确读取
3. **许可证检查**：确认许可证允许预期用途
4. **变量一致性**：检查渗透率场、速度场、压力场物理一致性
5. **坐标系验证**：确认网格坐标系明确且一致

## 回退策略

1. **无真实数据集**：使用合成数据，但需在报告中明确标注限制
2. **格式不兼容**：编写格式转换脚本，或寻找替代数据集
3. **许可证限制**：寻找替代数据集，或联系数据提供方获取授权
4. **数据质量差**：执行数据清洗和异常值处理
