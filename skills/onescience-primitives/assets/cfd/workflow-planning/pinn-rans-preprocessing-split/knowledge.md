# PINN湍流RANS均值流求解 - 预处理与数据切分

## 适用范围

本步骤用于PINN湍流RANS均值流求解与闭合的预处理阶段，负责统一物理量与表示，按几何、工况或时间构造无泄漏切分，保存统计量与可逆变换。

**触发条件**：
- 数据接入与契约核验已完成
- 需要为模型训练准备切分数据

**不适用场景**：
- 数据已预处理且切分已建立的情况
- 纯测试评估且无需训练的场景

## 输入

- **{SPLIT_CONFIG}**：切分配置（按对象工况切分）
- **{TARGET_FIELDS}**：目标变量（待预测物理量）
- **{NONDIMENSIONALIZE}**：是否无量纲化（统一跨工况量纲）

## 输出

- **train_manifest.json**：训练集清单
- **validation_manifest.json**：验证集清单
- **test_manifest.json**：测试集清单
- **normalization.json**：归一化统计量与变换参数

## 流程节点

```
质控 → 重采样或图构建 → 掩膜 → 归一化或无量纲化 → 按几何/轨迹/工况切分 → 保存统计量
```

### 关键步骤说明

1. **质控**：检查数据质量，处理异常值
2. **重采样或图构建**：根据数据特性选择重采样或图构建方法
3. **掩膜**：处理缺失值或无效区域
4. **归一化或无量纲化**：统一跨工况量纲
5. **按几何/轨迹/工况切分**：以几何、完整轨迹或物理工况为单位切分
6. **保存统计量**：保存变换参数以支持可逆变换

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 切分比例 | 70/15/15 | 场景需求书 | 训练/验证/测试比例 |
| 切分单位 | 几何/轨迹/工况 | 场景需求书 | 不得打散同一轨迹 |
| 随机种子 | 42 | 场景需求书 | 可复现切分 |

### 校准数值

以下数值来自CFD_S037场景，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认无量纲化 | true | 场景需求书 | 统一跨工况量纲 |
| 默认group_by | geometry_or_trajectory | 场景需求书 | 切分依据 |

## 边界与分流

**关键前提与改道**：

1. **前提：数据接入与契约核验已完成**
   - 不成立时 → 先执行数据接入步骤

2. **前提：切分配置合理**
   - 不成立时 → 调整切分比例或单位

3. **前提：变换可逆**
   - 不成立时 → 调整归一化方法

## 质量检查

- **三份切分的对象轨迹互斥**：训练/验证/测试集无重叠
- **仅用训练集计算变换统计量**：防止数据泄漏
- **边界与掩膜语义未破坏**：物理边界保持完整

## 回退策略

1. **切分不合理**：调整切分比例或单位
2. **变换不可逆**：选择可逆归一化方法
3. **数据泄漏**：重新检查切分逻辑
