# 连续坐标PDE批量推理与物理恢复

## 适用范围
本卡描述如何为潜空间与神经场连续PDE算子学习在独立测试集上进行批量推理并恢复物理量。适用于模型训练完成后、评估前的推理阶段。

## 输入
- CHECKPOINT：模型权重
- DEVICE：计算设备（CPU/CUDA）
- BATCH_SIZE：推理批大小
- 训练时的归一化统计量

## 输出
- predictions/：逐样本预测结果
- inference_manifest.json：推理清单
- timing.csv：推理耗时

## 流程节点
1. 加载模型权重与数据契约
2. 在独立测试集上推理
3. 反归一化并恢复物理单位
4. 恢复坐标网格、边界掩膜及任务派生量
5. 保存逐样本结果和耗时

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认设备 | cuda | 场景需求书 | GPU推理 |
| 默认批大小 | 8 | 场景需求书 | 按显存调整 |
| 检查点 | best_checkpoint.pt | 场景需求书 | 训练最佳权重 |

## 边界与分流
- 预测出现NaN/Inf → 检查模型权重、输入数据、归一化统计量
- 形状或单位不匹配 → 回溯检查checkpoint加载与反归一化
- 禁止用测试标签修正预测 → 推理必须是前向传播，不得使用测试目标

## 质量检查
- 预测无NaN或Inf且形状单位正确
- 每个测试样本有唯一结果
- 推理未使用测试目标校正

## 回退策略
推理失败时，验证checkpoint兼容性、设备配置、批大小与显存匹配。
