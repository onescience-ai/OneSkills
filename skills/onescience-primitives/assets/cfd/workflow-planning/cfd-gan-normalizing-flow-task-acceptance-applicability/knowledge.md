# GAN与正规化流湍流降阶任务验收与适用域判定

## 适用范围

本任务适用于 GAN 与正规化流湍流降阶生成的最终验收阶段，评估统计误差、关键物理约束、泛化能力和计算收益，给出 PASS、REJECT 或 BLOCKED 结论，并明确适用域限制。

**触发条件**：
- 已通过 s04 条件采样与物理一致性筛选
- 需要进行任务验收和适用域判定
- 需要执行域外工况测试

**不适用场景**：
- 采样与筛选未完成（需返回 s04）
- 仅需中间评估而非最终验收

## 输入

**上游产物**：
- s04 产出的 generated_samples/、physics_filter.json、distribution_metrics.json

**参数**：
- 验收指标（{METRICS}）：distribution_distance, diversity, physics_residual, coverage
- 相对误差门限（{MAX_RELATIVE_L2}，默认 0.1）
- 是否外推测试（{RUN_OOD_TEST}，默认 true）

## 输出

**验收产物**：
- evaluation.json：综合评估结果
- worst_cases.csv：最差样本清单（可追溯到工况和随机种子）
- applicability_report.md：适用域报告（含限制条件与复核建议）
- PASS_REJECT_BLOCKED.txt：最终结论

**验证标准**：
- 统计与物理指标同时报告
- 最差样本可追溯
- 结论含适用域限制与复核建议
- 不得仅凭平均误差宣称工程可用

## 流程节点

### 1. 统计误差评估
- **操作**：报告逐变量误差、分布距离、多样性指标
- **参数**：生成样本、真实数据、验收指标
- **工具**：统计评估器
- **质量门禁**：逐变量误差报告完整

### 2. 物理约束评估
- **操作**：报告边界误差、守恒残差、方程残差
- **参数**：生成样本、物理残差
- **工具**：物理评估器
- **质量门禁**：物理指标与统计指标同时报告

### 3. 最差样本分析
- **操作**：识别并追溯最差样本，分析失败原因
- **参数**：评估结果
- **工具**：最差样本分析器
- **质量门禁**：最差样本可追溯到具体工况和随机种子

### 4. 外推测试（可选）
- **操作**：执行几何或工况外推测试，评估泛化能力
- **参数**：外推测试选项
- **工具**：外推测试器
- **质量门禁**：外推测试结果明确标注适用域边界

### 5. 适用域判定
- **操作**：综合评估结果，明确适用域限制与复核建议
- **参数**：评估结果、外推测试结果
- **工具**：适用域判定器
- **质量门禁**：结论含适用域限制与复核建议

### 6. 最终结论
- **操作**：使用 {MAX_RELATIVE_L2} 及任务物理门限给出 PASS、REJECT 或 BLOCKED
- **参数**：验收指标、误差门限
- **工具**：结论生成器
- **质量门禁**：结论明确、可追溯

## 边界与分流

**前提条件与改道**：

1. **s04 采样结果可用**
   - 不成立时 → 改道：返回 s04 重新执行采样

2. **误差门限合理**
   - 不成立时 → 改道：调整门限或说明门限依据

3. **外推测试可执行**
   - 不成立时 → 改道：标记为"未执行外推"并注明局限

4. **物理指标可计算**
   - 不成立时 → 改道：使用可用的物理指标子集并注明

## 质量检查

**验证点**：
- 统计与物理指标同时报告检查
- 最差样本可追溯性验证
- 适用域报告完整性检查
- 最终结论明确性验证
- 平均误差依赖性检查（禁止仅凭平均误差）

**阈值**：
- 相对 L2 误差 ≤ 0.1（默认）
- 物理残差在任务可接受范围内
- 适用域报告完整
- 最终结论明确

**失败处理**：
- 指标不达标 → 给出 REJECT 并说明修复方向
- 物理违反 → 标记 REJECT 并建议物理约束增强
- 适用域不确定 → 标记 BLOCKED 并建议 CFD 复核

## 回退策略

**失败时的替代方案**：
1. 验收不通过 → 根据失败指标定向修复（增加数据、调整模型、添加物理约束）
2. 适用域不确定 → 标记为"需 CFD 复核"并限制使用场景
3. 外推测试失败 → 明确标注适用域边界，域外工况禁止使用
