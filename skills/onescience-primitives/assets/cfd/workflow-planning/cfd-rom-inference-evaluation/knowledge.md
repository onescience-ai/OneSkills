# ROM推理后处理与效率评估

## 适用范围

面向CFD降阶模型（ROM）推理阶段的后处理与效率评估。降阶模型在归一化空间中执行推理后，需要恢复到原始物理空间并生成可与实验/高保真CFD对比的结果，同时需要评估计算效率（加速比、内存节省）。本卡给出单位恢复、网格重建、物理派生量计算的标准流程，以及与全阶CFD求解器的时间对比方法。适用于POD、DMD及其他降阶方法的推理后处理。不适用于降阶模型本身的训练过程，也不适用于CFD求解器的性能优化。

## 输入

- 降阶模型在归一化空间中的预测结果
- normalization.json（归一化统计量）
- 原始网格信息（节点坐标、拓扑关系）
- 全阶CFD求解器的基准计算时间（如有）

## 输出

- 恢复物理单位的预测场（u/v/w分量，单位m/s）
- 重建的空间网格坐标
- 物理派生量（涡量、压力系数、雷诺应力等）
- inference_manifest.json（推理元数据：单位、坐标、时间戳）
- timing.csv（计算时间记录）
- 加速比和内存节省报告

## 流程节点

### 单位恢复
- **操作**：将归一化空间中的预测值反变换到物理空间
- **数学表达**：u_physical = u_normalized * std_u + mean_u；或 u_physical = u_normalized * U_ref
- **参数**：归一化统计量（mean, std, ref_velocity）
- **工具**：NumPy
- **质量门禁**：恢复后的物理量量级与原始数据一致（如速度量级在m/s量级）

### 网格重建
- **操作**：将降阶模型的空间自由度映射回物理空间的网格坐标
- **方法**：
  - 结构网格：直接使用原始节点坐标
  - 非结构网格：从降阶空间的自由度索引反查物理节点坐标
- **参数**：网格类型（结构/非结构）、节点坐标文件
- **工具**：NumPy/PyVista
- **质量门禁**：重建网格与原始网格拓扑一致；节点数和单元数匹配

### 物理派生量计算
- **操作**：从基本物理量（u, v, p等）计算派生量
- **常见派生量**：
  - 涡量：ω = ∇×u（二维：ω = ∂v/∂x - ∂u/∂y）
  - 压力系数：Cp = (p - p∞)/(0.5*ρ*U∞²)
  - 雷诺应力：-ρ<u'v'>
  - 湍动能：TKE = 0.5*(u'² + v'² + w'²)
- **参数**：派生量类型、差分格式（中心差分/迎风）
- **工具**：NumPy/SciPy
- **质量门禁**：派生量量级合理；涡量场与速度场空间一致性

### 推理元数据生成
- **操作**：记录推理结果的完整元数据，生成 inference_manifest.json
- **字段**：预测值单位（m/s, Pa等）、网格坐标系、时间步、物理参数、降阶模型版本
- **工具**：JSON
- **质量门禁**：manifest包含完整单位和坐标信息

### 计算效率评估
- **操作**：对比降阶模型与全阶CFD求解器的计算时间和内存占用
- **加速比计算**：speedup = t_CFD / t_ROM
- **时间复杂度分析**：
  - 全阶CFD：O(N³) 或 O(N²)（迭代求解器）
  - ROM推理：O(r²·N) 或 O(r·N)（r为截断阶数，N为空间自由度）
- **内存分析**：
  - 全阶CFD：O(N) ~ O(N²)
  - ROM：O(r·N)（基函数矩阵）+ O(r²)（时间系数）
- **参数**：t_CFD（基准时间）、t_ROM（推理时间）、N（自由度数）、r（截断阶数）
- **工具**：timeit/memory_profiler
- **质量门禁**：加速比有真实基准支撑（非估算值）；timing.csv记录完整时间信息

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 单位恢复验证 | 与原始数据量级一致 | 领域标准 | 物理单位正确性的基本要求 |
| 加速比基准 | 需真实CFD计算时间 | 领域标准 | 不能使用估算值 |
| 涡量计算精度 | 与原始数据差异 < 5% | 经验值 | 派生量精度的基本要求 |
| 推理时间记录 | 含预热+多次运行取均值 | 最佳实践 | 消除系统噪声影响 |

### 校准数值

以下数值来自典型圆柱绕流体系，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 典型加速比 | 10^2~10^4 | [D1] | ROM相对于全阶CFD |
| 典型内存节省 | 10~1000倍 | 经验值 | 取决于截断阶数r |
| 全阶CFD典型时间 | 10^2~10^4 秒 | [D1] | 标准验证案例 |

## 边界与分流

- **无全阶CFD基准**：当无法运行全阶CFD求解器时，应使用文献报告的同类案例计算时间作为参考基准，并明确标注为估算值
- **GPU加速**：若使用GPU进行ROM推理，应分别报告CPU和GPU时间，加速比应注明硬件配置
- **在线推理 vs 离线推理**：在线推理（实时预测）和离线推理（批量预测）的时间特性不同，应分别评估
- **不确定性量化**：若ROM包含不确定性估计，应额外报告不确定性传播的计算开销

## 质量检查

- [ ] inference_manifest.json 存在且包含完整单位和坐标信息
- [ ] timing.csv 记录了实际计算时间（非估算值）
- [ ] 加速比有真实基准支撑
- [ ] 恢复后的物理量量级正确
- [ ] 派生量（涡量等）与基本量空间一致
- [ ] 网格坐标与原始一致

## 回退策略

- 无全阶CFD基准 → 使用文献值或同类案例的计算时间作为参考，并标注为估算值
- 非结构网格映射失败 → 使用最近邻插值或线性插值重建网格
- 派生量计算精度不足 → 增加网格分辨率或使用高阶差分格式
