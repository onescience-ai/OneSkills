# 神经PDE模型配置与训练

## 适用范围
本卡片适用于神经PDE求解器的模型配置与训练任务，是神经PDE工作流的第三步。核心目标是使用Parareal neural solver或Temporal neural operator进行训练，记录训练指标和最佳权重。适用于时间并行或多时间尺度神经PDE推进场景。

## 输入
- **模型名称**（必填）：Parareal neural solver或Temporal neural operator
- **训练配置**（必填）：框架、超参数、随机种子等
- **切分数据**（来自s02）：train_manifest.json, validation_manifest.json
- **归一化参数**（来自s02）：normalization.json
- **初始权重**（可选）：预训练权重文件

## 输出
- **best_checkpoint.pt**：最佳模型权重
- **train_config.json**：训练配置记录
- **training_metrics.csv**：逐轮训练验证指标
- **environment.txt**：代码版本和依赖信息

## 流程节点
1. **加载切分数据** → 读取s02产出的训练验证集清单
2. **加载归一化参数** → 应用s02计算的统计量
3. **初始化模型** → 根据MODEL_NAME创建模型实例
4. **加载初始权重**（可选） → 检查结构兼容性后加载
5. **训练循环** → 执行epoch训练，记录指标
6. **保存最佳权重** → 基于验证损失选择最佳checkpoint
7. **记录环境信息** → 保存代码版本和依赖

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认框架 | PyTorch | 场景需求书 | 标准深度学习框架 |
| 默认epoch数 | 100 | 场景需求书 | 训练迭代次数 |
| 默认batch_size | 8 | 场景需求书 | 批处理大小 |
| 默认学习率 | 0.001 | 场景需求书 | 优化器学习率 |
| 默认随机种子 | 42 | 场景需求书 | 可复现性保证 |
| 默认early_stopping_patience | 15 | 场景需求书 | 早停耐心值 |

## 边界与分流
- **训练配置缺失**：缺少必填训练配置时，使用默认值或返回BLOCKED
- **权重加载失败**：初始权重结构不兼容时，拒绝加载并继续随机初始化
- **训练收敛失败**：损失出现非有限值时，需检查数据和超参数
- **早停触发**：验证损失不再改善时，提前结束训练

## 质量检查
- 训练验证损失均为有限值
- 最佳权重可重新加载
- 配置环境随机种子可复现
- 训练指标完整记录
- 环境信息准确保存

## 回退策略
- 训练配置不完整：使用默认配置或请求用户补充
- 权重加载失败：跳过预训练，使用随机初始化
- 训练收敛失败：调整学习率或批次大小
- 早停过于激进：增加patience值或调整正则化
