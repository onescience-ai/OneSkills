# 翼型几何流场性能联合数据集获取渠道与格式规范

## 适用范围

**触发条件**：
- 需要获取真实翼型几何-流场-性能联合数据进行模型训练
- 需要了解公开翼型数据库的访问方式和数据格式
- 需要验证数据规模是否满足生成模型训练要求

**适用场景**：
- 翼型气动外形与流场联合逆向设计的数据准备阶段
- CFD代理模型训练数据采集
- 多工况翼型性能数据整合

**不适用场景**：
- 使用模拟数据进行概念验证
- 仅需几何坐标而无需流场数据的场景
- 已有自有CFD仿真数据的场景

## 输入

- 数据获取目标：翼型类型、工况范围、精度要求
- 数据格式要求：结构化程度、单位标准、坐标系约定
- 数据规模目标：翼型数量、工况点数量

## 输出

- 翼型几何坐标数据（格式：.dat 或 .json）
- CFD流场数据（压力系数分布、速度场、涡量场等）
- 气动性能指标（升力系数Cl、阻力系数Cd、升阻比L/D）
- 数据元信息（来源、工况条件、网格分辨率、数值方法）

## 流程节点

### Step 1：公开数据库访问
- **操作**：访问UIUC翼型数据库、NASA湍流模型资源等公开数据源
- **参数**：数据源URL、访问权限、数据更新日期
- **工具**：浏览器或API接口
- **质量门禁**：确认数据源权威性（.edu/.gov域名或知名机构维护）

### Step 2：数据下载与格式解析
- **操作**：下载几何坐标文件和CFD结果数据，解析不同格式
- **参数**：文件格式（SELIG格式、CGNS、VTK等）、编码方式
- **工具**：Python文件读取库
- **质量门禁**：数据文件完整可读，坐标系一致，单位明确

### Step 3：数据标准化与整合
- **操作**：统一物理量单位、坐标系、数据结构
- **参数**：目标单位（SI制）、坐标系约定（翼型坐标原点、弦长归一化）
- **工具**：Python数据处理库
- **质量门禁**：所有数据字段单位统一，几何-流场配对正确

### Step 4：数据规模验证
- **操作**：检查翼型数量、工况点数量是否满足训练要求
- **参数**：最小翼型数量（≥100）、最小工况点数量（≥1000）
- **工具**：Python统计脚本
- **质量门禁**：规模指标达到阈值，数据分布覆盖目标工况范围

## 关键参数

## 边界与分流

- **数据源访问受限**：转向其他公开数据库（如airfoiltools.com）或使用文献补充数据
- **数据格式不兼容**：使用格式转换工具统一数据结构，或编写自定义解析器
- **数据规模不足**：使用数据增强（几何扰动、工况插值）或迁移学习策略
- **流场数据缺失**：仅使用几何-性能数据训练几何生成模型，流场预测由代理模型完成
- **单位不一致**：强制转换为SI制，保留原始单位作为参考

## 质量检查

- 数据源权威性验证（.edu/.gov/.org域名）
- 数据完整性检查（无缺失字段、无异常值）
- 几何-流场配对正确性验证
- 数据规模达到最小阈值
- 工况覆盖范围满足设计需求

## 回退策略

- 公开数据源不可用：使用文献中的数据表格手动整理
- 数据规模严重不足：使用合成数据补充（参数化几何+简化物理模型）
- 数据格式复杂：使用专用CFD后处理工具解析
