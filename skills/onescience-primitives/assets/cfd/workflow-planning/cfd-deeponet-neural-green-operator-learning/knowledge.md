# DeepONet与神经Green函数算子学习

## 适用范围

**触发条件**：
- 需要学习从函数输入到解函数的算子映射
- 已有PDE系统的函数输入-解函数配对数据
- 需要构建CFD代理模型以加速推理

**适用场景**：
- 流体动力学方程的算子学习（如Navier-Stokes方程）
- 参数化PDE的快速求解器构建
- 物理场预测与实时仿真
- 边界条件或初始条件到流场解的映射学习

**不适用场景**：
- 纯数据驱动无物理约束的黑盒预测
- 无函数配对数据的纯文献综述
- 非PDE算子学习的通用机器学习任务

## 输入

**数据格式**：
- 函数输入到解函数的配对数据集
- 支持目录或清单文件指定路径
- 变量包括输入函数（边界条件/初始条件/参数场）和目标解函数（速度场/压力场/温度场等）

**预处理要求**：
- 物理量单位统一
- 网格坐标系明确定义
- 缺失值处理完成
- 数据使用许可确认

## 输出

**产物清单**：
- 可复现的模型checkpoint（best_checkpoint.pt）
- 训练配置与环境信息（train_config.json, environment.txt）
- 逐轮训练验证指标（training_metrics.csv）
- 测试集推理结果（predictions/）
- 统计误差与物理一致性评估（evaluation.json）
- 最差样本分析（worst_cases.csv）
- 适用域报告（applicability_report.md）
- 验收结论（PASS_REJECT_BLOCKED.txt）

**验证标准**：
- 模型权重可重新加载
- 预测无NaN或Inf
- 统计与物理指标同时满足门限

## 流程节点

### Step 1：数据接入与契约核验
- **操作**：接入函数输入到解函数配对数据，核验样本、变量、单位、网格坐标及许可
- **参数**：数据集路径、数据集名称、数据契约定义
- **工具**：数据读取库（h5py/numpy/pandas）
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏

### Step 2：预处理与数据切分
- **操作**：统一物理量与表示，按几何、工况或时间构造无泄漏切分
- **参数**：切分比例（train:validation:test = 0.7:0.15:0.15）、目标变量、是否无量纲化
- **工具**：数据处理库（numpy/scipy）
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏

### Step 3：模型配置与训练
- **操作**：训练DeepONet或Neural Green function完成指定输入到目标物理量的映射
- **参数**：模型名称、训练配置（epochs、batch_size、learning_rate等）、可选预训练权重
- **工具**：PyTorch框架
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现

### Step 4：批量推理与物理恢复
- **操作**：在独立测试集推理，恢复原始单位、网格和物理派生量
- **参数**：模型权重、计算设备（CPU/CUDA）、推理批大小
- **工具**：PyTorch推理引擎
- **质量门禁**：预测无NaN或Inf且形状单位正确；每个测试样本有唯一结果；推理未使用测试目标校正

### Step 5：任务验收与适用域判定
- **操作**：评估统计误差、关键物理约束、泛化能力和计算收益
- **参数**：验收指标（relative_L2、RMSE、conservation_residual、boundary_error）、相对误差门限、是否外推测试
- **工具**：评估脚本
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议

## 边界与分流

**关键前提与改道**：

1. **前提：有函数输入到解函数配对数据**
   - 不成立时 → 转向数据生成或合成数据构建方案族

2. **前提：物理量单位与坐标系明确**
   - 不成立时 → 转向数据清洗与单位标准化方案族

3. **前提：模型收敛且验证损失为有限值**
   - 不成立时 → 转向超参数调优或模型架构调整方案族

4. **前提：物理约束满足（守恒/边界条件）**
   - 不成立时 → 转向物理信息神经网络（PINN）或损失函数加权方案族

5. **前提：域外工况经CFD复核**
   - 不成立时 → 转向保守估计或安全裕度设定方案族

## 质量检查

**验证点**：
- 数据可读性检查：文件存在且格式正确
- 样本完整性：无缺失样本，变量定义完整
- 切分互斥性：训练/验证/测试集无重叠
- 模型收敛性：损失曲线平稳下降
- 权重可加载性：checkpoint结构兼容
- 推理正确性：预测形状与单位匹配
- 物理一致性：守恒残差与边界误差在允许范围内

**阈值**：
- 相对L2误差 < 0.1
- 无NaN/Inf预测
- 守恒残差 < 物理允许值
- 边界误差 < 物理允许值

**失败处理**：
- 数据不可读 → 返回BLOCKED并列出缺项
- 模型不收敛 → 调整超参数或架构后重试
- 物理约束不满足 → 添加物理正则化或损失权重

## 回退策略

**失败时的替代方案**：
1. 数据不足 → 使用合成数据增强或迁移学习
2. 模型不收敛 → 尝试不同架构（MLP→ResNet→Transformer）或优化器
3. 物理约束不满足 → 引入PINN损失项或拉格朗日乘子
4. 域外性能差 → 降低适用域范围或增加训练数据多样性
