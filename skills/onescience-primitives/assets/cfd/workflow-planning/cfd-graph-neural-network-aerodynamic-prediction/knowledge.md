# 图神经网络空气动力学预测

## 适用范围
本卡片描述使用图神经网络（GNN）完成三维网格几何到标量空气动力学量的回归任务。GNN将三角网格或体网格建模为图结构，通过消息传递机制在节点/边间传递局部几何与物理特征，聚合得到全局表示后回归目标值。适用于具有明确网格连接关系的汽车、翼型、飞行器等外流场体系的阻力/升力系数预测。不适用于无网格拓扑的纯点云输入（应使用点云回归器）。

## 输入
- **网格数据**：三角面片网格或体网格，含节点坐标、边连接、面片法向量等
- **节点/边特征**：坐标、法向量、曲率、局部几何量
- **工况参数**（可选）：雷诺数、攻角等
- **目标变量**：阻力系数Cd、升力系数Cl等标量物理量

## 输出
- 标量回归值（Cd或Cl预测）
- 逐样本预测与物理单位恢复
- 统计误差与物理一致性评估

## 流程节点
### 1. 数据准备
- 加载DrivAerNet/DrivAerNet++网格数据
- 构建图结构：节点=网格顶点，边=网格连接
- 计算节点/边特征（坐标、法向量、曲率等）
- 按场景s02配置按几何单位切分

### 2. 模型构建
- 节点特征编码层（MLP）
- 消息传递层（GCN/GAT/MPNN风格，多层堆叠）
- 全局池化（读出层）得到图级表示
- 回归头输出标量预测

### 3. 训练
- 损失函数：MSE或MAE回归损失
- 优化器：Adam（默认lr=0.001）
- 早停：验证损失15轮不降则停止
- 记录逐轮训练验证指标

### 4. 推理
- 加载最佳权重，在独立测试集推理
- 反归一化恢复物理单位
- 保存逐样本预测值

## 边界与分流
- 网格连接断裂或孤立节点 → 图结构无效，需修复网格
- 同一车辆跨集切分 → 切分无效，需重新按对象单位切分
- 消息传递层数过多导致过平滑 → 减少层数或使用残差连接
- 预测值物理量级偏差大 → 检查特征工程与归一化

## 质量检查
1. 网格完整性：节点坐标有效、边连接完整
2. 图构建正确性：邻接矩阵对称、无自环（或按需保留）
3. 训练收敛：loss曲线平滑下降，无NaN/Inf
4. 预测合理性：Cd预测值在0.2-0.5量级（典型汽车），超出需人工审查

## 回退策略
- 网格数据不可用 → 降级为点云回归器（需重新采样为点云）
- GPU显存不足 → 降低batch_size或使用图采样（mini-batch训练）
- 过平滑 → 使用残差连接、减少层数、或切换GAT注意力机制
