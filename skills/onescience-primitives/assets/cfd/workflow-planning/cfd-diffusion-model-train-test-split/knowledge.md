# 预处理与数据切分

## 适用范围

适用于流场扩散模型训练前的数据预处理与切分。核心目标是按几何、工况或时间构造无泄漏切分，确保同一物理轨迹的帧不被随机打散到不同集合中。同时完成归一化/无量纲化并保存可逆变换统计量。

## 输入

- s01 产出的 data_contract.json 与 dataset_manifest.json
- {SPLIT_CONFIG}（必填）：切分比例与策略
- {TARGET_FIELDS}（必填）：目标变量列表
- {NONDIMENSIONALIZE}（可选）：是否无量纲化，默认 true

## 输出

- train_manifest.json：训练集清单
- validation_manifest.json：验证集清单
- test_manifest.json：测试集清单
- normalization.json：归一化参数（均值、标准差、缩放因子等）

## 流程节点

1. 根据 data_contract.json 确认变量与单位
2. 执行质控（去除损坏样本、处理缺失值）
3. 构建图表示（若使用图神经网络架构）
4. 执行掩膜处理（区分有效区域与无效区域）
5. 按 {SPLIT_CONFIG} 以几何/轨迹/工况为单位切分
6. 仅用训练集计算归一化/无量纲化统计量
7. 应用变换并保存可逆参数
8. 输出三份切分清单与归一化参数

## 关键参数

### 通用判据

| 参数 | 说明 | 来源 |
|------|------|------|
| 切分单位 | 以几何/完整轨迹/物理工况为单位 | [场景需求书 s02] |
| 无泄漏 | 同一轨迹帧不跨切分 | [场景需求书 s02] |
| 统计量来源 | 仅用训练集计算 | [场景需求书 s02] |
| 可逆性 | 保存统计量以支持逆变换 | [场景需求书 s02] |
| 边界语义 | 掩膜与边界条件语义不破坏 | [场景需求书 s02] |

### 校准数值

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认 train 比例 | 0.7 | [场景需求书] | 可调整 |
| 默认 val 比例 | 0.15 | [场景需求书] | 可调整 |
| 默认 test 比例 | 0.15 | [场景需求书] | 可调整 |
| 默认 seed | 42 | [场景需求书] | 可调整 |
| 默认 group_by | geometry_or_trajectory | [场景需求书] | 按几何或轨迹切分 |

## 边界与分流

- 切分后出现泄漏 → 回到 s01 重新核验数据组织方式
- 无量纲化失败（如零方差变量） → 跳过该变量的无量纲化并标注
- 图构建失败（非流形网格） → 使用替代表示或回退到网格数据

## 质量检查

- 三份切分的对象轨迹互斥
- 仅用训练集计算变换统计量
- 边界与掩膜语义未破坏

## 回退策略

- 切分比例不合理 → 调整 {SPLIT_CONFIG} 重新切分
- 归一化参数异常 → 检查数据分布，必要时使用鲁棒归一化
