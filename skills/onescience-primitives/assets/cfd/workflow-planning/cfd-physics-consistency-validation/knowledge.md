# 物理一致性验证

## 适用范围
验证神经PDE求解器结果的物理一致性，确保求解结果在物理上合理且工程可用。适用于：
- 神经PDE求解器的验收评估
- 传统数值求解器的结果验证
- 多物理场耦合问题的物理一致性检查
- 模型适用域判定和工程可用性评估

**不适用场景**：
- 纯数学问题（无物理背景）
- 验证标准未定义的问题
- 计算资源严重受限（无法执行完整验证）

## 输入
- **数值解场**：PDE解的时空分布
- **PDE方程**：控制方程（Poisson、Navier-Stokes等）
- **边界条件**：Dirichlet、Neumann、Robin边界条件
- **网格信息**：结构化/非结构化网格拓扑、节点坐标
- **物理参数**：密度、粘度、导热系数等

## 输出
- **守恒误差报告**：质量/能量/动量守恒误差
- **边界条件误差**：边界上的解与边界条件的偏差
- **方程残差**：PDE方程在计算域内的残差分布
- **最差样本分析**：误差最大的样本及其特征
- **适用域报告**：模型适用范围和工程可用性判定
- **PASS/REJECT/BLOCKED判定**：验收结论

## 流程节点
```
守恒量计算 → 边界条件验证 → 方程残差计算 → 最差样本分析 → 适用域判定
```

### 1. 守恒量计算
- **操作**：计算质量/能量/动量等守恒量在计算域内的积分误差
- **参数**：守恒量类型、积分方法、误差阈值
- **工具**：数值积分工具
- **质量门禁**：守恒误差小于阈值（通常<1e-6）；积分方法准确；误差可追溯

### 2. 边界条件验证
- **操作**：验证解在边界上是否满足边界条件
- **参数**：边界条件类型、容差、边界区域定义
- **工具**：边界提取工具、误差计算
- **质量门禁**：边界误差小于容差；边界区域定义准确；误差分布可追溯

### 3. 方程残差计算
- **操作**：计算PDE方程在计算域内的残差分布
- **参数**：PDE方程、差分/有限元格式、残差计算方法
- **工具**：符号计算工具、数值差分
- **质量门禁**：残差范数小于容差；差分格式准确；残差分布可解释

### 4. 最差样本分析
- **操作**：识别误差最大的样本，分析其特征和失败原因
- **参数**：误差指标、样本特征、失败阈值
- **工具**：统计分析工具、可视化工具
- **质量门禁**：最差样本可追溯；失败原因可解释；改进方向明确

### 5. 适用域判定
- **操作**：根据验证结果判定模型适用范围和工程可用性
- **参数**：验收指标、误差门限、物理约束
- **工具**：判定脚本
- **质量门禁**：判定标准明确；结论含适用域限制；建议复核方向

## 边界与分流
- **前提1：PDE方程已知** → 若方程未知，转向数据驱动验证或残差学习方法
- **前提2：边界条件明确定义** → 若边界条件模糊，转向边界敏感性分析
- **前提3：计算资源充足** → 若资源受限，转向抽样验证或降阶模型验证
- **前提4：验收标准已定义** → 若标准未定义，转向工程经验或文献参考标准

## 质量检查
- **守恒验证**：解应满足质量/能量守恒（视PDE类型）
- **边界验证**：边界条件应精确满足（或在容差内）
- **残差验证**：PDE方程残差应小于容差
- **最差样本**：最差样本误差应可接受或已识别改进方向

## 回退策略
- **守恒违反**：检查数值格式、边界条件、网格质量，调整求解参数
- **边界误差大**：细化边界网格、调整边界处理方法、增加边界约束
- **残差过大**：细化网格、提高求解精度、检查PDE建模
- **最差样本失败**：分析失败原因、扩充训练数据、增加物理约束
