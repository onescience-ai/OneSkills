# 流固耦合逆向设计预处理与数据切分

## 适用范围
流固耦合逆向设计的第二步，统一物理量与表示，按几何、工况或时间构造无泄漏切分，为后续模型训练准备数据。适用于任何需要从原始数据进行预处理和切分的流固耦合逆向设计任务。

## 输入
- 切分配置（{SPLIT_CONFIG}）：按对象工况切分
- 目标变量（{TARGET_FIELDS}）：待预测物理量
- 是否无量纲化（{NONDIMENSIONALIZE}）：统一跨工况量纲

## 输出
- 训练集清单（train_manifest.json）
- 验证集清单（validation_manifest.json）
- 测试集清单（test_manifest.json）
- 归一化统计量（normalization.json）

## 流程节点
```
s02 预处理与数据切分
  │  1. 依据s01契约完成质控
  │  2. 重采样或图构建
  │  3. 掩膜处理
  │  4. 归一化或无量纲化
  │  5. 按{SPLIT_CONFIG}以几何、完整轨迹或物理工况为单位切分
  │  6. 不得把同一轨迹的帧随机打散
  │  7. 为{TARGET_FIELDS}保存统计量与可逆变换
  │  质量门禁：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏
```

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 切分方式 | 按几何、完整轨迹或物理工况为单位 | 场景需求书s02 | 不得把同一轨迹的帧随机打散 |
| 变换统计量 | 仅用训练集计算 | 场景需求书s02 | 避免数据泄漏 |
| 边界与掩膜 | 语义未破坏 | 场景需求书s02 | 保持物理意义 |

### 校准数值
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| train/val/test比例 | 0.7/0.15/0.15 | 场景需求书s02 | 以下数值来自场景默认配置，其他体系需以自身证据重新锚定 |
| 随机种子 | 42 | 场景需求书 | |
| 无量纲化 | 默认true | 场景需求书s02 | 统一跨工况量纲 |

## 边界与分流
- 切分配置无效时回退到默认比例（0.7/0.15/0.15）
- 数据量不足时调整切分比例或使用数据增强
- 无量纲化失败时回退到归一化处理

## 质量检查
- 三份切分的对象轨迹互斥
- 仅用训练集计算变换统计量
- 边界与掩膜语义未破坏
- 归一化统计量完整保存

## 回退策略
- 切分配置无效时使用默认配置
- 数据量不足时调整切分比例
- 无量纲化失败时使用归一化替代
