# 数据接入与契约核验

## 适用范围

适用于多尺度湍流粗细状态轨迹数据集的接入验证。当需要从DNS/LES/实验数据构建闭合模型训练集时，首先执行本步骤确保数据完整性与可用性。

## 输入

- DATASET_PATH：数据集路径（目录或清单文件）
- DATASET_NAME：数据集名称（来源与版本）
- DATA_CONTRACT：变量单位网格定义（可选，默认空契约）

## 输出

- dataset_manifest.json：数据清单
- data_contract.json：机器可读数据契约
- data_audit.md：数据审计报告

## 流程节点

1. 读取数据集文件 → 检查文件格式与可读性
2. 统计样本数、时间/工况范围 → 验证数据量充足性
3. 识别输入与目标变量 → 核验变量定义完整性
4. 检查单位与坐标系 → 确保物理一致性
5. 检查网格拓扑 → 验证空间离散化信息
6. 检查缺失值 → 统计缺失比例与分布
7. 检查使用许可 → 确认可复现性
8. 输出数据契约 → 生成JSON格式契约文件

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必填字段 | DATASET_PATH, DATASET_NAME | 场景需求书 | 缺失时返回BLOCKED |
| 可选字段 | DATA_CONTRACT | 场景需求书 | 默认空契约 |
| 输出格式 | JSON + Markdown | 场景需求书 | 机器可读 + 人工可审 |

## 边界与分流

- 文件不可读 → 返回BLOCKED，列出缺项
- 样本数不足 → 警告但不阻塞，建议补充数据
- 单位/坐标不完整 → 在契约中标注缺失项
- 使用许可不明 → 在审计报告中标注风险

## 质量检查

- 数据文件可读且样本可追溯
- 输入目标变量单位坐标定义完整
- 不存在训练测试泄漏

## 回退策略

- 数据不可用 → 更换数据源或请求用户提供
- 契约不完整 → 标注缺失项，由下游步骤处理

## 资源召回建议

- 需要了解数据验证标准时召回本卡
- 需要了解数据切分策略时召回预处理卡
