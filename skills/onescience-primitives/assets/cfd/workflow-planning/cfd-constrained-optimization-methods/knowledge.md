# CFD外形设计约束优化方法

## 适用范围
适用于需要同时优化多个性能指标并满足几何/物理约束的CFD外形设计任务。适用于参数化设计空间，对于网格级拓扑优化需调整方法。

## 输入
- 设计变量（几何参数向量）
- 目标函数（阻力系数、升力系数等）
- 约束函数（几何约束、物理约束）
- 评估成本（CFD仿真时间）

## 输出
- Pareto front（非支配解集）
- 优化历史（搜索轨迹）
- 约束满足情况报告
- 最优设计参数

## 流程节点
1. **问题定义** → 确定设计变量、目标、约束
2. **算法选择** → 根据评估成本选择NSGA-II或贝叶斯优化
3. **约束处理** → 将约束转化为罚函数或可行性规则
4. **优化执行** → 运行优化算法
5. **Pareto front提取** → 识别非支配解
6. **结果可视化** → 绘制Pareto front和搜索轨迹

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 种群大小 | 100-200 | 用户自有 | NSGA-II参数 |
| 交叉概率 | 0.9 | 用户自有 | 模拟二进制交叉 |
| 变异概率 | 1/n_var | 用户自有 | 多项式变异 |
| 代数 | 100-500 | 用户自有 | 终止条件 |
| 采集函数 | EI或UCB | 用户自有 | 贝叶斯优化 |
| 代理模型 | 高斯过程 | 用户自有 | 用于贝叶斯优化 |

## 边界与分流
- 若评估成本极高（>1小时/次），使用贝叶斯优化
- 若设计变量>20维，考虑使用降维或代理模型
- 若约束为硬约束，使用可行性规则而非罚函数

## 质量检查
- 验证Pareto front中每个候选是否满足约束
- 检查优化历史是否记录完整的搜索轨迹
- 验证目标函数改进幅度

## 回退策略
- 若NSGA-II收敛慢，可使用MOEA/D或RNSGA-II
- 若贝叶斯优化陷入局部最优，可增加探索参数
