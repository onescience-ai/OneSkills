# 物理约束神经算子模型配置与训练

## 适用范围
面向带守恒边界和无量纲约束PDE数据的物理约束神经算子训练任务，使用Physics-constrained neural operator完成指定输入到目标物理量的映射，记录代码版本、依赖、随机种子、逐轮训练验证指标与最佳权重。适用于需要从PDE数据中学习输入到解算子映射、并要求预测结果符合物理约束的CFD任务，不适用于纯数据驱动且无物理约束的神经算子学习。

## 输入
- **模型名称**（必填）：Physics-constrained neural operator或类似架构
- **训练配置**（必填）：框架、 epochs、批次大小、学习率、随机种子、早停耐心
- **数据切分**（来自s02）：训练集、验证集清单和统计量
- **初始权重**（可选）：预训练权重，需检查结构兼容性

## 输出
- **best_checkpoint.pt**：通过训练门限的最佳模型权重
- **train_config.json**：训练配置记录，包含超参数和随机种子
- **training_metrics.csv**：逐轮训练验证指标记录
- **environment.txt**：代码版本、依赖和环境信息

## 流程节点
1. **配置解析** → 解析训练配置，验证参数完整性
2. **数据加载** → 加载训练集和验证集，应用归一化或无量纲化
3. **模型初始化** → 初始化Physics-constrained neural operator，加载初始权重（可选）
4. **训练循环** → 执行训练，计算损失函数（含物理约束项），更新模型参数
5. **验证评估** → 每轮验证，计算统计误差和物理约束指标
6. **早停判断** → 根据验证损失和早停耐心判断是否停止训练
7. **最佳权重保存** → 保存最佳模型权重和训练指标
8. **环境记录** → 记录代码版本、依赖和环境信息

## 边界与分流
- **初始权重不兼容** → 返回BLOCKED，要求提供兼容权重或从头训练
- **训练不收敛** → 调整学习率、增加训练轮次、检查数据质量
- **物理约束无法满足** → 降低物理约束权重，转向软约束而非硬约束
- **计算资源不足** → 降低模型复杂度或使用近似推理方法
- **过拟合严重** → 增加正则化、调整早停耐心、增加训练数据

## 质量检查
- **训练验证损失均为有限值**：避免NaN/Inf导致训练失败
- **最佳权重可重新加载**：确保checkpoint完整性
- **配置环境随机种子可复现**：保证实验可重复性
- **物理约束满足**：损失函数包含物理约束项，边界误差和守恒残差在训练中下降

## 回退策略
- **训练失败** → 检查数据质量、调整超参数、简化模型
- **过拟合** → 增加正则化、调整早停耐心、增加训练数据
- **欠拟合** → 增加模型容量、调整学习率、增加训练轮次
- **物理约束不满足** → 调整物理约束权重、修改损失函数设计
