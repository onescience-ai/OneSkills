# 湍流数据集无泄漏切分清单生成规范

## 适用范围
本规范适用于湍流数据集的无泄漏切分，确保训练、验证、测试集之间无信息泄漏，且每个子集的样本ID可追溯。适用于需要生成 `train_manifest.json`、`validation_manifest.json` 和 `test_manifest.json` 的场景。不适用于时间序列数据的前瞻性切分（需使用时间序列交叉验证）。

## 输入
- 已生成数据契约的湍流数据集（包含样本ID）
- 切分参数（比例、随机种子、是否分层）
- 数据分组信息（如模拟工况、时间步长等，可选）

## 输出
- `train_manifest.json`：训练集样本ID列表、切分比例、随机种子
- `validation_manifest.json`：验证集样本ID列表、切分比例、随机种子
- `test_manifest.json`：测试集样本ID列表、切分比例、随机种子

## 流程节点
1. **样本ID提取** → 从数据契约中提取所有样本的唯一标识符
2. **分组检查** → 若存在分组信息（如不同模拟工况），确保同一组样本不跨切分
3. **切分策略选择** → 根据数据特性选择切分方法（随机切分、分层切分、分组切分）
4. **切分执行** → 按指定比例和随机种子生成训练、验证、测试集索引
5. **互斥性验证** → 检查三个子集的样本ID无交集
6. **清单生成** → 将切分结果写入 JSON 文件，包含元数据（比例、种子、方法）

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 切分比例 | 0.7/0.15/0.15（训练/验证/测试） | [D1] | 常用比例，可根据数据量调整 |
| 随机种子 | 固定整数（如42） | [D1] | 确保可复现性 |
| 分层切分 | 若分类任务则启用 | [D1] | 保持类别比例 |
| 分组切分 | 若存在分组则启用 | 领域知识 | 防止组间泄漏 |

## 边界与分流
- **时间序列数据**：若数据具有时间依赖性，应使用时间序列切分（如 `TimeSeriesSplit`），避免未来信息泄漏
- **分组数据**：若样本来自不同模拟工况，应使用分组切分（如 `GroupKFold`），确保同一工况不跨切分
- **小样本数据**：若样本量过少，可使用留一法（Leave-One-Out）交叉验证

## 质量检查
- 验证三个子集的样本ID互斥（无交集）
- 检查切分比例符合预期（允许微小浮点误差）
- 确保随机种子已记录，切分可复现
- 若使用分层切分，验证各子集类别比例与原始数据一致

## 回退策略
- 若切分后出现泄漏，重新调整切分策略（如增加分组约束）
- 若样本量不足，可合并验证集与测试集，使用交叉验证评估
- 若随机种子导致异常切分，尝试其他种子值
