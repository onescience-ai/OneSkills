# 神经PDE批量推理与物理恢复

## 适用范围
本卡片适用于神经PDE求解器的批量推理与物理恢复任务，是神经PDE工作流的第四步。核心目标是在独立测试集上推理，恢复原始单位、网格和物理派生量，生成逐样本结果和耗时统计。适用于评估模型在时间并行或多时间尺度PDE推进场景中的预测能力。

## 输入
- **模型权重**（必填）：通过训练门限的best_checkpoint.pt
- **计算设备**（必填）：CPU或CUDA设备
- **推理批大小**（可选）：按显存调整的批量大小
- **测试集清单**（来自s02）：test_manifest.json
- **归一化参数**（来自s02）：normalization.json
- **数据契约**（来自s01）：data_contract.json

## 输出
- **predictions/**：逐样本预测结果目录
- **inference_manifest.json**：推理结果清单
- **timing.csv**：推理耗时统计

## 流程节点
1. **加载模型权重** → 读取best_checkpoint.pt
2. **加载测试集** → 读取test_manifest.json
3. **加载归一化参数** → 读取normalization.json
4. **批量推理** → 在测试集上执行推理
5. **反归一化** → 恢复原始单位和量纲
6. **恢复物理网格** → 应用坐标系和网格信息
7. **恢复边界掩膜** → 应用边界条件信息
8. **计算派生量** → 生成任务相关的派生物理量
9. **保存结果** → 保存预测结果和耗时统计

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认设备 | cuda | 场景需求书 | GPU推理加速 |
| 默认批大小 | 8 | 场景需求书 | 按显存调整 |
| 禁止事项 | 使用测试标签校正 | 场景需求书 | 保证评估公正性 |

## 边界与分流
- **权重加载失败**：检查权重文件完整性和模型结构兼容性
- **设备不可用**：CUDA设备不可用时，降级到CPU推理
- **显存不足**：减小批大小或使用混合精度推理
- **预测异常**：出现NaN/Inf时，检查模型和输入数据

## 质量检查
- 预测无NaN或Inf且形状单位正确
- 每个测试样本有唯一结果
- 推理未使用测试目标校正
- 物理单位和网格正确恢复
- 耗时统计准确记录

## 回退策略
- 权重加载失败：检查文件路径和模型结构
- 设备不可用：降级到CPU推理
- 显存不足：减小批大小或使用梯度检查点
- 预测异常：检查数据预处理和模型输入
