# 潜空间与神经场连续PDE算子学习工作流

## 适用范围
本卡描述潜空间与神经场连续PDE算子学习的完整工作流，覆盖从数据接入到任务验收的五步闭环。适用于需要从连续坐标PDE数据训练神经算子模型、并进行物理一致性评估的CFD任务。

## 输入
- 连续坐标PDE数据集路径
- 数据契约定义（变量、单位、坐标系）
- 训练配置（超参数、随机种子）
- 验收指标与门限

## 输出
- 训练好的模型权重
- 逐样本推理结果
- 物理一致性评估报告
- 适用域判定结论

## 流程节点
```
s01 数据接入与契约核验
  ↓
s02 预处理与数据切分
  ↓
s03 模型配置与训练
  ↓
s04 批量推理与物理恢复
  ↓
s05 任务验收与适用域判定
```

每步含：操作、参数、工具、质量门禁

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 训练/验证/测试比例 | 0.7/0.15/0.15 | 场景需求书 | 默认切分比例 |
| 切分策略 | 按几何或轨迹 | 场景需求书 | 保持样本独立性 |
| 早停耐心 | 15 | 场景需求书 | 防止过拟合 |
| 相对L2误差门限 | 0.1 | 场景需求书 | 测试集放行阈值 |

## 边界与分流
- s01缺失必填输入 → 返回BLOCKED，不得编造数据
- s02切分泄漏 → 必须重新切分，仅用训练集计算变换统计量
- s03训练发散 → 检查数据预处理、学习率、模型架构
- s04推理异常 → 回溯checkpoint加载与反归一化
- s05验收不通过 → 分析最差样本，必要时返回s02调整

## 质量检查
- 每步质量门禁必须通过才能进入下一步
- 最差样本必须可追溯到具体数据点
- 结论必须含适用域限制与复核建议

## 回退策略
任何步骤失败均可回退到上一步重新执行，但需记录回退原因与调整措施。
