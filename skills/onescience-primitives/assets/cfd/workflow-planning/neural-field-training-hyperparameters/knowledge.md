# 隐式神经场训练超参数选择指南

## 适用范围

本卡片为隐式神经场（INR/CROM）模型训练提供超参数选择依据，适用于连续坐标采样的PDE快照数据降阶建模任务。训练超参数的选择直接影响模型收敛性、泛化能力和计算效率，需要根据数据规模、模型复杂度和任务要求进行调整。

## 输入

### 训练数据特征
- 数据规模：样本数量、空间分辨率、时间步数
- 数据类型：连续坐标采样、规则网格、混合格式
- 物理特性：PDE类型、边界条件、初始条件

### 模型架构特征
- 网络深度：层数、每层神经元数
- 参数数量：总参数量、可训练参数量
- 模型类型：INR、CROM、神经算子（FNO/UNO）

### 任务要求
- 精度要求：相对L2误差阈值
- 效率要求：训练时间、推理时间
- 泛化要求：跨分辨率、跨参数泛化

## 输出

### 超参数配置建议
- epochs：推荐范围和选择逻辑
- batch_size：推荐范围和选择逻辑
- early_stopping_patience：推荐值和使用规范
- 学习率：推荐范围和调度策略

### 收敛性评估
- 训练损失曲线分析
- 验证损失曲线分析
- 过拟合/欠拟合诊断

## 流程节点

1. **数据规模评估** → 2. **模型复杂度分析** → 3. **超参数初始化** → 4. **训练监控** → 5. **参数调优**

### 步骤1：数据规模评估
- 操作：分析训练数据的规模和特征
- 参数：样本数、空间分辨率、时间步数
- 工具：数据统计脚本
- 质量门禁：明确数据规模等级

### 步骤2：模型复杂度分析
- 操作：分析目标模型的复杂度
- 参数：参数量、层数、计算图深度
- 工具：模型摘要工具
- 质量门禁：明确模型复杂度等级

### 步骤3：超参数初始化
- 操作：基于数据和模型特征初始化超参数
- 参数：epochs、batch_size、learning_rate、early_stopping_patience
- 工具：超参数配置生成器
- 质量门禁：超参数在合理范围内

### 步骤4：训练监控
- 操作：监控训练过程，记录损失曲线
- 参数：train_loss、val_loss、epoch数
- 工具：训练日志记录器
- 质量门禁：及时检测过拟合/欠拟合

### 步骤5：参数调优
- 操作：根据训练结果调整超参数
- 参数：调整幅度、调整方向
- 工具：超参数优化器
- 质量门禁：性能持续改进

## 关键参数

### 通用判据
| 参数 | 推荐范围 | 来源 | 说明 |
|------|----------|------|------|
| epochs | 100-1000 | [1][2] | 需根据模型收敛性调整 |
| batch_size | 8-512 | [1][2] | 小数据集用小batch，大数据集用大batch |
| early_stopping_patience | 10-20 | [2] | 防止过拟合的关键机制 |
| 学习率 | 1e-4 to 1e-3 | [1][2] | 初始值，需配合调度策略 |
| 梯度裁剪阈值 | 0.1-1.0 | [2] | 防止梯度爆炸 |

### 校准数值
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| PINO训练epochs | 未明确指定 | [1] | 基于验证性能确定 |
| CNN训练学习率 | 0.0005 (pilot) → 1e-5 (fine-tune) | [2] | 两阶段训练策略 |
| CNN梯度裁剪 | 1.0 (pilot) → 0.1 (fine-tune) | [2] | 配合学习率调整 |
| 数据划分比例 | 80/10/10 或 70/15/15 | [1][2] | 训练/验证/测试集划分 |

## 边界与分流

### epochs不足时
- 模型未充分收敛 → 增加epochs或调整学习率
- 验证损失仍在下降 → 继续训练
- 验证损失开始上升 → 启用early stopping

### batch_size不合适时
- batch_size过小 → 训练不稳定，梯度噪声大
- batch_size过大 → 内存不足，泛化能力下降
- 需要根据GPU内存和数据规模调整

### early_stopping未启用时
- 无法自动判断最优停止点 → 手动监控验证损失
- 可能过拟合或欠拟合 → 需要人工干预
- 建议始终启用early stopping

### 学习率过高时
- 训练不稳定，损失震荡 → 降低学习率
- 梯度爆炸 → 启用梯度裁剪
- 使用学习率调度策略

## 质量检查

### 验证点
1. 超参数配置合理性
2. 训练过程稳定性
3. 收敛性判断准确性
4. 过拟合/欠拟合检测

### 阈值
- 训练损失下降率：>1% per epoch (初期)
- 验证损失稳定性：波动<5%
- 过拟合检测：验证损失连续上升>3 epochs

### 失败处理
- 训练不稳定 → 降低学习率或增加batch_size
- 过拟合 → 增加正则化或减少模型复杂度
- 欠拟合 → 增加模型复杂度或训练epochs

## 回退策略

### 训练失败时
1. 检查数据质量和预处理
2. 验证模型架构正确性
3. 调整超参数重新训练
4. 考虑使用预训练模型或迁移学习

### 性能不达标时
1. 分析误差来源（数据/模型/超参数）
2. 增加训练数据或改进数据质量
3. 调整模型架构或损失函数
4. 使用更先进的训练技术
