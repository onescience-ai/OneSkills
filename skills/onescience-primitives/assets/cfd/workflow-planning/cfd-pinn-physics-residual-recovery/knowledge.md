# PINN方程求解与物理残差恢复

## 适用范围

面向PINN模型的方程求解与物理残差恢复，在查询配点或网格上恢复解场、导数、边界值与方程残差。适用于验证PINN模型是否真正满足PDE方程，而非仅拟合训练数据。

**触发条件**：完成模型训练后，需要验证解的物理一致性。

## 输入

| 输入类型 | 变量 | 必填 | 说明 |
|---------|------|------|------|
| 模型权重 | `{CHECKPOINT}` | 是 | 通过训练门限的权重 |
| 计算设备 | `{DEVICE}` | 是 | CPU或CUDA设备 |
| 推理批大小 | `{BATCH_SIZE}` | 否 | 按显存调整 |
| 查询坐标 | 测试集坐标 | 是 | 空间+时间坐标 |
| 边界坐标 | 边界条件点 | 是 | Dirichlet/Neumann边界 |
| PDE定义 | 方程参数 | 是 | 算子、系数、源项 |

## 输出

| 输出产物 | 格式 | 说明 |
|---------|------|------|
| solution_fields/ | NumPy/HDF5 | 解场（压力、速度、温度等） |
| pde_residuals/ | NumPy/HDF5 | PDE残差场 |
| boundary_residuals.csv | CSV | 边界残差汇总 |

## 流程节点

### 1. 模型加载与推理准备

**操作**：
- 加载{CHECKPOINT}权重
- 设置计算设备{DEVICE}
- 准备查询坐标和边界坐标

**参数**：
- 设备：cuda（默认）或cpu
- 批大小：{BATCH_SIZE}（默认8）
- 梯度计算：需要开启autograd

**质量门禁**：模型加载成功，设备设置正确

---

### 2. 解场恢复

**操作**：
- 在查询坐标上执行前向传播
- 获取模型输出（解场预测值）
- 恢复物理量（反归一化）

**技术要点**：
- 使用自动微分计算空间/时间导数
- 支持批量推理以处理大规模查询
- 保存解场字段（u, v, w, p, T等）

**质量门禁**：解场导数为有限值

---

### 3. 导数恢复

**操作**：
- 使用PyTorch autograd计算一阶导数（∂u/∂x, ∂u/∂t等）
- 计算二阶导数（∂²u/∂x², ∂²u/∂t²等）
- 计算梯度散度、旋度等

**技术要点**：
- autograd: torch.autograd.grad
- 高阶导数: 重复调用grad
- 注意计算图内存

**质量门禁**：所有导数为有限值

---

### 4. PDE残差计算

**操作**：
- 根据PDE定义组装残差表达式
- 计算每个查询点的残差值
- 保存残差场

**残差类型**：
- **Navier-Stokes**: ∂u/∂t + u·∇u = -∇p + ν∇²u
- **Burgers**: ∂u/∂t + u·∂u/∂x = ν∂²u/∂x²
- **扩散方程**: ∂u/∂t = D∇²u
- **波动方程**: ∂²u/∂t² = c²∇²u

**质量门禁**：残差为有限值

---

### 5. 边界残差计算

**操作**：
- 在边界点上计算解与边界条件的偏差
- 分类统计Dirichlet/Neumann/Robin边界误差
- 保存边界残差汇总

**边界类型**：
- Dirichlet: u = u_boundary
- Neumann: ∂u/∂n = q_boundary
- Robin: αu + β∂u/∂n = γ

**质量门禁**：边初值逐项满足门限

---

### 6. 结果保存与验证

**操作**：
- 保存解场字段到solution_fields/
- 保存PDE残差到pde_residuals/
- 保存边界残差到boundary_residuals.csv
- 可选：与独立数值解或解析解对照

**质量门禁**：独立数值解或解析解可对照

## 边界与分流

| 前提条件 | 不成立时转向 |
|---------|-------------|
| 模型权重可加载 | 检查checkpoint格式、路径 |
| autograd可计算导数 | 检查计算图、设备、内存 |
| 残差在合理范围 | 调整模型、增加配点、修改损失权重 |
| 边界条件定义明确 | 检查PDE定义、边界类型 |

## 质量检查

**检查清单**：
1. 模型加载：权重加载成功，设备正确
2. 解场恢复：所有解场值为有限值
3. 导数恢复：所有导数值为有限值
4. PDE残差：残差为有限值，分布合理
5. 边界残差：边界满足门限
6. 结果保存：文件完整，格式正确

## 回退策略

1. **autograd失败**：检查计算图、减少批大小、使用torch.no_grad()的子集
2. **残差过大**：增加配点数量、调整损失权重、检查PDE定义
3. **边界不满足**：增加边界点权重、检查边界条件定义
4. **显存不足**：减小推理批大小、分块计算
