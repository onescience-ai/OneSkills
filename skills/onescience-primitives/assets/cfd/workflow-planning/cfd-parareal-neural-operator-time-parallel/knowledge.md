# Parareal与神经网络结合的时间并行PDE求解

## 适用范围

面向时间依赖偏微分方程（PDE）的长时间积分问题，当传统串行时间推进计算成本过高时，采用Parareal时间并行框架与神经网络算子结合的方法实现加速。适用于扩散方程、Navier-Stokes方程、反应-扩散方程、Allen-Cahn方程等需要高效时间推进的CFD仿真场景。该方法特别适合需要多GPU并行、长时间积分、且对精度有一定要求的应用。不适用于瞬态响应极快（如激波捕获）或时间尺度单一的简单问题。

## 输入

- **PDE定义**：控制方程（如Navier-Stokes、扩散方程）、边界条件、初始条件
- **时间域分解参数**：总时间区间 [0, T]、时间子域数 N、粗时间步长 Δt_coarse、细时间步长 Δt_fine
- **粗传播子选择**：低精度数值方法（如显式Euler、低阶Runge-Kutta）或预训练神经网络
- **细求解器**：高精度数值方法（如隐式BDF、高阶Runge-Kutta）
- **训练数据**：随机初始条件下的轨迹数据，用于训练粗传播子神经网络

## 输出

- **并行时间推进解**：时间域分解后的各子域解 u(t)
- **收敛迭代信息**：Parareal迭代次数、残差收敛曲线
- **计算加速比**：相对于串行细求解器的加速比
- **粗细解一致性验证**：粗传播子与细求解器输出的一致性检查

## 流程节点

```
Step 1: 时间域分解 → 将 [0, T] 分解为 N 个子域
Step 2: 粗传播子初始化 → 训练神经网络或选择低精度数值方法作为粗传播子
Step 3: 粗传播预测 → 串行执行粗传播子预测各子域初始解
Step 4: 细求解器并行 → 并行启动 N 个细求解器，以粗解为初始条件求解
Step 5: 校正更新 → 基于粗细解差异更新粗传播子预测
Step 6: 迭代收敛判断 → 检查残差是否满足精度要求，若未满足返回 Step 4
Step 7: 输出最终解 → 收敛后输出各子域的高精度解
```

每步含：
- **操作**：具体计算任务
- **参数**：Δt_coarse, Δt_fine, 迭代次数上限
- **工具**：GPU并行框架（PyTorch DDP）、数值PDE求解器
- **质量门禁**：粗细解差异阈值（如 L2 范数 < 1e-4）

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 粗传播子类型 | 低精度数值方法或预训练神经网络 | [1][2][3] | 快速但精度有限 |
| 细求解器类型 | 高精度数值方法 | [1][2][3] | 串行或并行均可 |
| Parareal迭代次数 | 2-5次 | [1][2] | 通常收敛较快 |
| 时间子域数 | 可并行GPU数 | [1][3] | 受硬件限制 |
| 粗细解一致性阈值 | L2 < 1e-4 | [2][3] | 可根据精度需求调整 |

### 校准数值（PPINN/RandNet-Parareal 体系）

以下数值来自具体论文实验，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| PPINN加速比 | 与子域数成正比 | [1] | Burgers方程实验 |
| RandNet-Parareal加速比 | 最高125x（串行）、22x（vs传统Parareal） | [2] | 空间网格10^5点 |
| Allen-Cahn方程迭代次数 | 2-5次 | [3] | 多GPU实现 |
| 训练数据量 | 随机初始条件轨迹 | [1][3] | 无需重新训练 |

## 边界与分流

- **粗传播子精度不足**：若粗传播子误差过大，Parareal可能不收敛→ 改用更高精度的粗传播子或增加迭代次数
- **时间子域过大**：若单个子域内时间跨度超过粗传播子稳定域→ 减小Δt_coarse或增加子域数
- **并行效率低**：若GPU通信开销超过计算收益→ 减少子域数或优化通信
- **粗细解不一致**：若神经网络粗传播子与细求解器数值格式不兼容→ 改用数值方法作为粗传播子

## 质量检查

- **收敛性验证**：Parareal迭代残差是否单调下降
- **精度验证**：最终解与串行细求解器解的L2误差是否满足阈值
- **并行效率**：实际加速比与理论加速比的比值
- **粗细解一致性**：粗传播子输出与细求解器输入的一致性

## 回退策略

- **Parareal不收敛**：回退到串行细求解器或增加粗传播子精度
- **并行开销过大**：减少时间子域数，仅在可用GPU上并行
- **神经网络训练不稳定**：改用传统数值方法作为粗传播子
