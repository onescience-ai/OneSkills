# 扩散模型与智能体工程外形协同设计

## 适用范围
适用于使用扩散模型生成工程外形候选并结合多智能体协同优化的设计任务，特别是参数化几何参数空间的CFD外形优化。不适用于网格级CFD求解或非生成式优化。

## 输入
- 几何参数向量（如翼型厚度、弯度、前缘半径等）
- 性能指标（阻力系数Cd、升力系数Cl等）
- 约束条件（几何约束、物理约束）
- 训练数据集（参数-性能映射）

## 输出
- 生成的候选设计参数
- Pareto front（多目标优化）
- 优化轨迹（搜索历史）
- 约束满足情况

## 流程节点
1. **数据准备** → 几何参数标准化，构建训练集
2. **扩散模型训练** → 训练DDPM/DDIM模型学习参数分布
3. **候选生成** → 通过反向去噪过程采样生成新候选
4. **工程代理评估** → 多智能体协同评估候选性能
5. **约束优化** → 基于评估结果进行多目标优化
6. **Pareto front提取** → 提取非支配解集

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 噪声调度β_t | 线性调度，β_1=1e-4，β_T=0.02 | [1] | 控制正向扩散过程 |
| 时间步数T | 1000 | [1] | 扩散过程步数 |
| 去噪网络 | U-Net或Transformer | [1] | 预测噪声ε_θ |
| 训练目标 | 噪声预测ε_θ | [1] | 最小化预测噪声与真实噪声的MSE |
| 条件输入 | 几何参数+性能目标 | [2] | 条件生成 |
| 种群大小 | 100-200 | 用户自有 | NSGA-II参数 |
| 交叉概率 | 0.9 | 用户自有 | 遗传算法参数 |

## 边界与分流
- 若几何参数空间非连续（如拓扑优化），考虑使用离散扩散模型
- 若评估成本极高，可使用基于代理模型的贝叶斯优化替代遗传算法
- 若多目标数量>3，考虑使用降维或分解方法

## 质量检查
- 验证扩散模型是否包含noise_scheduler、timestep_embedding、denoise_step等标准组件
- 检查反向去噪过程输出分布是否收敛
- 验证生成的候选是否满足硬约束

## 回退策略
- 若扩散模型训练失败，可使用变分自编码器（VAE）作为替代生成模型
- 若多智能体协同复杂度过高，可简化为单一代理模型
