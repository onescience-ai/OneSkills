# 数据切分步骤的输出契约

## 适用范围
面向机器学习工作流的数据切分步骤，确保生成标准化的切分清单和归一化配置文件，以便审计、复现和下游步骤自动解析。适用于任何需要数据切分的科学计算任务。

## 输入
- 原始数据集：样本索引和标签
- 切分比例：训练集、验证集、测试集的比例
- 分组键：用于分层切分的变量（如类别、时间）
- 随机种子：确保切分可复现

## 输出
- train_manifest.json：训练集样本索引列表、切分比例、分组键、随机种子
- validation_manifest.json：验证集样本索引列表、切分比例、分组键、随机种子
- test_manifest.json：测试集样本索引列表、切分比例、分组键、随机种子
- normalization.json：各变量的均值、标准差（或最小最大值）、归一化方法名

## 流程节点
1. **数据加载**：读取原始数据集
2. **切分规划**：确定训练集、验证集、测试集的比例和分组键
3. **分层切分**：使用分组键确保类别分布一致
4. **清单生成**：为每个子集生成 JSON 清单文件
5. **归一化计算**：计算训练集的统计量（均值、标准差）
6. **归一化配置**：生成 normalization.json 文件

每步质量门禁：
- 切分比例总和为 1.0
- 分组键在各子集分布一致
- 清单文件可被 JSON 解析

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 训练集比例 | 0.8 | [D1] | 常用比例 |
| 验证集比例 | 0.1 | [D1] | 用于模型选择 |
| 测试集比例 | 0.1 | [D1] | 用于最终评估 |
| 随机种子 | 42 | [D1] | 确保可复现 |
| 归一化方法 | StandardScaler | [D1] | 零均值单位方差 |

## 边界与分流
- 如果数据量过小：使用 k-fold 交叉验证替代固定切分
- 如果类别不平衡：使用分层切分或过采样
- 如果数据有时序性：使用时间序列切分（不随机打乱）

## 质量检查
- 验证点：清单文件存在且可解析
- 阈值：切分比例与指定比例偏差 < 0.01
- 失败处理：重新执行切分并检查随机种子

## 回退策略
- 如果分层切分失败：使用随机切分
- 如果归一化配置缺失：从训练数据重新计算
