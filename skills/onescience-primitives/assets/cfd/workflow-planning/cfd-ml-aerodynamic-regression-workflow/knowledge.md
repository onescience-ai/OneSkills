# 标准空气动力学回归工作流

## 适用范围
本卡片为通用空气动力学回归任务提供标准化五步工作流。适用于从几何数据（点云、网格、参数化表示）预测标量物理量（阻力系数、升力系数、力矩系数等）的深度学习场景。覆盖汽车、飞行器、翼型等外流场体系。不适用于全流场重构、内部流动或多物理场耦合问题。

## 输入
- **几何数据**：三维点云、表面网格或参数化形状表示
- **工况参数**：雷诺数、攻角、来流速度等（可选）
- **目标变量**：阻力系数 Cd、升力系数 Cl 等标量物理量
- **数据集**：包含几何-目标变量配对的结构化数据集

## 输出
- 数据契约（data_contract.json）：字段、单位、坐标系定义
- 三份切分集（train/val/test manifest）
- 训练好的模型权重（best_checkpoint）
- 逐样本预测结果与物理单位恢复
- 综合评估报告（误差、物理一致性、适用域）

## 流程节点

### 步骤1：数据接入与契约核验（s01）
- **操作**：读取数据集路径，核验文件可读性、样本数、变量定义、单位、坐标系、网格拓扑、缺失值与许可
- **质量门禁**：
  - 数据文件可读且样本可追溯
  - 输入目标变量单位坐标定义完整
  - 不存在训练测试泄漏
- **降级路径**：缺少必填输入时返回BLOCKED并列出缺项，不编造数据
- **依据**：场景需求书s01 prompt与outputs

### 步骤2：预处理与数据切分（s02）
- **操作**：统一物理量表示，按几何或工况构造无泄漏切分（默认70/15/15），归一化或无量纲化
- **质量门禁**：
  - 三份切分的对象轨迹互斥
  - 仅用训练集计算变换统计量
  - 边界与掩膜语义未破坏
- **关键约束**：不得把同一轨迹的帧随机打散到不同切分集
- **依据**：场景需求书s02 prompt与outputs

### 步骤3：模型配置与训练（s03）
- **操作**：加载切分数据与统计量，训练模型，记录逐轮训练验证指标与最佳权重
- **质量门禁**：
  - 训练验证损失均为有限值
  - 最佳权重可重新加载
  - 配置环境随机种子可复现
- **可选输入**：初始预训练权重（需检查结构兼容性）
- **依据**：场景需求书s03 prompt与outputs

### 步骤4：批量推理与物理恢复（s04）
- **操作**：在独立测试集推理，反归一化恢复物理单位、坐标网格与边界掩膜
- **质量门禁**：
  - 预测无NaN或Inf且形状单位正确
  - 每个测试样本有唯一结果
  - 推理未使用测试目标校正
- **依据**：场景需求书s04 prompt与outputs

### 步骤5：任务验收与适用域判定（s05）
- **操作**：多指标综合评估（统计误差、物理约束、泛化能力、计算收益），给出PASS/REJECT/BLOCKED
- **质量门禁**：
  - 统计与物理指标同时报告
  - 最差样本可追溯
  - 结论含适用域限制与复核建议
- **OOD测试**：执行几何或工况外推测试并明确适用域，不凭平均误差宣称工程可用
- **依据**：场景需求书s05 prompt与outputs

## 关键参数

### 通用判据
| 参数 | 判据 | 来源 | 说明 |
|------|------|------|------|
| 切分比例 | train≥0.6 / val≥0.1 / test≥0.1 | [场景s02] | 按对象或轨迹单位，三集互斥 |
| 无泄漏原则 | 同一对象/轨迹不跨集 | [场景s02] | 物理一致性基础 |
| 统计量来源 | 仅训练集 | [场景s02] | 防止信息泄漏 |
| 验收门限 | relative_L2 < 0.1（默认） | [场景s05] | 可按任务调整 |
| OOD测试 | 几何/工况外推 | [场景s05] | 适用域边界判定 |

## 边界与分流
- 数据集无目标变量定义 → s01返回BLOCKED，不编造
- 切分时同一轨迹被打散 → s02不通过，按对象单位重新切分
- 模型不收敛（loss为NaN/Inf） → s03不通过，检查数据质量与学习率
- 预测输出含异常值 → s04不通过，回查预处理
- relative_L2 ≥ 0.1 → s05 REJECT，需调整模型或扩大训练域
- OOD测试不通过 → 标REJECT，建议CFD复核后方可用于域外工况

## 质量检查
1. **数据完整性**：s01核验文件、变量、单位、坐标
2. **切分无泄漏**：s02验证三集互斥与统计量来源
3. **训练收敛**：s03检查损失曲线与权重可加载性
4. **预测合理性**：s04检查物理单位量级与无NaN/Inf
5. **多指标判定**：s05统计误差+物理约束+适用域综合

## 回退策略
- 数据加载失败 → 检查路径权限，降级为部分样本验证
- GPU显存不足 → 降低batch_size或切CPU
- 不收敛 → 检查学习率、数据质量、尝试预训练权重
- 评估指标超限 → 调整模型架构或增加训练数据
