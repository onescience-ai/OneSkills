# 数据接入与契约核验

## 适用范围
适用于所有需要将含噪观测数据与PDE先验数据接入CFD工作流的场景，包括贝叶斯PINN概率反演、参数估计、不确定性量化等。该步骤确保数据质量，为后续建模提供可靠基础。

## 输入
- **数据集路径**：目录或清单文件，包含解场 \(u\)、源项 \(f\)、边界条件 \(b\) 的散点观测。
- **数据集名称**：来源与数据版本。
- **数据契约**：变量单位网格定义，包括输入字段、目标字段、单位、坐标系。

## 输出
- **dataset_manifest.json**：数据集清单，包含文件可读性、样本数、输入与目标变量、单位、坐标系、网格拓扑、时间或工况范围、缺失值和使用许可。
- **data_contract.json**：机器可读契约，定义变量、单位、坐标系、网格拓扑。
- **data_audit.md**：数据审计报告，总结数据质量与合规性。

## 流程节点
1. **读取数据**：读取指定路径中的数据集。
2. **检查文件可读性**：确保所有文件可读且格式正确。
3. **核验样本数**：确认样本数量与预期一致。
4. **核验变量**：检查输入与目标变量是否完整。
5. **核验单位**：确保变量单位一致且符合物理意义。
6. **核验坐标系**：确认坐标系定义完整且一致。
7. **核验网格拓扑**：检查网格拓扑是否完整。
8. **核验时间或工况范围**：确认时间或工况范围符合预期。
9. **核验缺失值**：检查缺失值情况。
10. **核验使用许可**：确认数据使用许可。
11. **输出契约**：按数据契约输出机器可读契约。

每步含：操作、参数、工具、质量门禁。

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据文件可读 | true | [1] | 必须确保所有文件可读 |
| 样本可追溯 | true | [1] | 每个样本必须可追溯到源文件 |
| 输入目标变量单位坐标定义完整 | true | [1] | 所有变量必须有完整的单位和坐标定义 |
| 不存在训练测试泄漏 | true | [1] | 训练集和测试集必须严格分离 |

## 边界与分流
- **缺少必填输入**：返回BLOCKED并列出缺项，不得编造数据。
- **数据格式不支持**：尝试转换格式或使用替代数据源。
- **数据质量不合格**：暂停流程并报告问题。

## 质量检查
- **数据文件可读且样本可追溯**：确保数据完整性和可追溯性。
- **输入目标变量单位坐标定义完整**：确保数据定义完整。
- **不存在训练测试泄漏**：确保数据独立性。

## 回退策略
- **数据缺失**：寻找替代数据源或使用合成数据。
- **数据格式错误**：转换格式或使用数据清洗工具。
- **数据质量差**：进行数据清洗或降噪处理。

## 资源召回建议
- **召回时机**：当用户需要接入PDE数据或进行数据审计时。
- **配套资源**：
  - `cfd-data-preprocessing`：数据预处理通用流程。
  - `cfd-data-splitting`：数据切分通用流程。
