# FNO算子学习批量推理与物理恢复任务

## 适用范围

**触发条件**：
- 需要在独立测试集上进行FNO模型推理
- 需要恢复原始单位、网格和物理派生量
- 需要确保预测结果物理一致且可追溯

**适用场景**：
- FNO算子学习流程的推理阶段
- 因子分解与多重网格FNO模型推理
- 流体力学问题的快速求解

**不适用场景**：
- 模型训练阶段
- 非FNO架构的模型推理
- 无测试集数据的推理

## 输入

**必填输入**：
- {CHECKPOINT}：模型权重（通过训练门限权重）
- {DEVICE}：计算设备（CPU或CUDA设备）

**可选输入**：
- {BATCH_SIZE}：推理批大小（按显存调整）

**数据来源**：
- 通过模型配置与训练任务的最佳模型权重
- 通过预处理与数据切分任务的测试集
- 归一化参数和数据契约

## 输出

**产物清单**：
- predictions/：预测结果目录
- inference_manifest.json：推理清单（逐样本结果）
- timing.csv：计时信息（推理耗时）

**格式要求**：
- 预测结果与输入数据格式一致
- 推理清单包含样本索引和预测结果
- 计时信息包含推理时间和批处理信息

## 流程节点

### Step 1：模型加载
- **操作**：加载训练好的FNO模型权重
- **参数**：模型权重路径、模型架构
- **质量门禁**：模型权重正确加载

### Step 2：数据加载
- **操作**：加载测试集数据和归一化参数
- **参数**：测试集路径、归一化参数
- **质量门禁**：测试数据加载成功

### Step 3：推理执行
- **操作**：在测试集上执行推理
- **参数**：计算设备、批大小
- **质量门禁**：预测无NaN或Inf且形状单位正确

### Step 4：物理恢复
- **操作**：反归一化并恢复物理单位、坐标网格、边界掩膜
- **参数**：归一化参数、数据契约
- **质量门禁**：每个测试样本有唯一结果

### Step 5：结果保存
- **操作**：保存预测结果和推理清单
- **参数**：保存路径、保存格式
- **质量门禁**：推理未使用测试目标校正

### Step 6：计时记录
- **操作**：记录推理时间和批处理信息
- **参数**：计时精度、统计方法
- **质量门禁**：计时信息准确

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 计算设备 | cuda | 场景需求书 | 默认使用GPU推理 |
| 推理批大小 | 8 | 场景需求书 | 按显存调整批量 |
| 模型权重 | best_checkpoint.pt | 场景需求书 | 通过训练门限权重 |
| 预测格式 | 与输入数据格式一致 | 通用 | 保持数据一致性 |
| 计时精度 | 毫秒级 | 通用 | 精确记录推理时间 |

## 边界与分流

**异常处理**：
1. **模型权重不存在** → 返回BLOCKED，说明缺失权重
2. **计算设备不可用** → 降级到CPU推理
3. **内存不足** → 减小推理批大小
4. **预测结果异常** → 检查模型权重和输入数据
5. **物理恢复失败** → 检查归一化参数和数据契约

**降级策略**：
- GPU不可用 → 使用CPU推理（推理时间增加）
- 内存不足 → 使用梯度累积或减小批大小

## 质量检查

**验证点**：
- 预测完整性：每个测试样本有唯一结果
- 物理一致性：预测结果物理单位正确
- 数值稳定性：预测无NaN或Inf
- 计时准确性：推理时间记录准确

**失败处理**：
- 预测异常 → 检查模型权重和输入数据
- 物理恢复失败 → 检查归一化参数
- 计时错误 → 重新执行推理
