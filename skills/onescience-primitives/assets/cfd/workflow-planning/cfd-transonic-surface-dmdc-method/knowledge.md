# 表面DMDc方法

## 适用范围
将三维气动问题简化为翼面上的二维压力分布问题，降低计算复杂度。适用于跨声速气动弹性降阶建模，特别是翼型/机翼压力分布预测。

## 输入
- 三维CFD仿真数据（压力分布）
- 翼面网格信息
- 结构模态输入

## 输出
- 基于压力分布的降阶模型
- 翼面压力分布预测
- 气动力计算

## 流程节点
1. **数据准备** → 提取翼面压力分布数据
2. **状态向量构建** → 将压力系数构建为状态向量
3. **输入向量构建** → 将结构模态振幅及其导数构建为输入
4. **快照矩阵构建** → 构建状态和输入快照矩阵
5. **POD分解** → 通过SVD提取POD模态
6. **DMDc训练** → 训练降阶模型
7. **力计算** → 从压力分布计算气动力

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 状态变量 | 压力系数Cp | [1] | 翼面网格顶点处的压力系数 |
| 输入变量 | 模态振幅+导数 | [1] | 包含位移、速度、加速度 |
| POD截断 | 基于奇异值 | [1] | 保留主要模态 |

## 边界与分流
- **强分离流动**：需要更多POD模态
- **三维效应显著**：考虑全流场DMDc方法
- **非线性压力分布**：考虑非线性降阶方法

## 质量检查
- 压力分布预测精度
- 气动力计算精度
- 计算效率提升

## 回退策略
- 使用全流场DMDc方法
- 采用其他降阶方法
- 使用高保真CFD验证
