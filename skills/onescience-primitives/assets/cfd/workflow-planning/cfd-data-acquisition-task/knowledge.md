# 数据接入与契约核验任务

## 适用范围
本任务适用于从翼型壁面压力剪切及速度测量数据中接入数据、核验契约，建立数据清单、数据契约和数据审计报告。适用于任何需要基于壁面测量数据进行气动力反演的场景。

## 输入
- 数据集路径：目录或清单文件。
- 数据集名称：来源与数据版本。
- 数据契约：变量单位网格定义（可选）。

## 输出
- dataset_manifest.json：数据清单。
- data_contract.json：数据契约。
- data_audit.md：数据审计报告。

## 流程节点
1. 读取数据集路径中的数据集。
2. 建立数据清单，检查文件可读性、样本数、输入与目标变量、单位、坐标系、网格拓扑、时间或工况范围、缺失值和使用许可。
3. 按数据契约输出机器可读契约。
4. 缺少必填输入时返回BLOCKED并列出缺项，不得编造数据、权重、工况或结果。

## 关键参数
### 通用判据（方法层）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据文件可读 | true | 质量门禁 | 基本要求 |
| 样本可追溯 | true | 质量门禁 | 每个样本需有唯一标识 |
| 输入目标变量单位坐标定义完整 | true | 质量门禁 | 避免歧义 |
| 不存在训练测试泄漏 | true | 质量门禁 | 数据独立性 |

### 校准数值（体系专属值）
以下数值来自翼型壁面压力剪切与积分气动力联合反演场景，供量级校准；其他体系需以自身证据重新锚定。
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 输入变量 | 壁面压力剪切、速度测量 | 场景需求书 | 翼型壁面数据 |
| 目标变量 | 壁面剪切应力、壁面压力、积分气动力 | 场景需求书 | 反演目标 |

## 边界与分流
- 当数据缺少必填输入（如数据集路径、数据集名称）时返回BLOCKED并列出缺项。
- 当数据不满足质量门禁（如存在训练测试泄漏、单位坐标定义不完整）时，需返回预处理步骤修正。
- 当数据格式不支持时，需转换格式或使用其他工具解析。

## 质量检查
- 数据文件可读且样本可追溯。
- 输入目标变量单位坐标定义完整。
- 不存在训练测试泄漏。

## 回退策略
- 若数据文件不可读，检查文件路径和权限。
- 若数据格式不支持，尝试转换格式或使用其他解析库。
- 若数据存在缺失值，可尝试插补或剔除。

## 资源召回建议
当需要接入翼型壁面压力剪切及速度测量数据并核验契约时召回本卡片。可配合以下卡片使用：
- cfd-data-preprocessing-task：预处理与数据切分。
- cfd-model-training-task：模型配置与训练。
