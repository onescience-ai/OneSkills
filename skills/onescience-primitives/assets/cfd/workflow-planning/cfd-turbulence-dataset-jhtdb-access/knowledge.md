# 公开湍流数据集获取方式与数据格式（以 JHTDB 为例）

## 适用范围
本规范适用于公开湍流数据集的获取，以约翰霍普金斯湍流数据库（JHTDB）为例，说明访问接口、数据结构、下载方法等。适用于需要获取真实湍流数据用于模型训练、验证和评估的场景。不适用于非公开数据集或私有数据。

## 输入
- 数据访问需求（如数据集类型、变量、分辨率）
- 访问权限（JHTDB 需要注册账户）
- 下载工具（Python、Matlab、Fortran、C 接口）

## 输出
- 湍流场数据文件（如 HDF5、Zarr 格式）
- 数据元信息（模拟参数、网格分辨率、时间步长）
- 数据访问日志（用于追溯）

## 流程节点
1. **账户注册** → 在 JHTDB 网站注册账户，获取访问令牌
2. **数据集选择** → 根据需求选择数据集（如 isotropic turbulence、channel flow）
3. **访问方式选择** → 选择访问方式（Web Service、Python API、数据切片服务）
4. **数据查询** → 使用 API 查询特定时空点的速度、压力等物理量
5. **数据下载** → 下载数据子集（如 3D 子立方体）或完整数据集
6. **数据验证** → 验证下载数据的完整性和格式

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据集类型 | DNS isotropic turbulence、channel flow 等 | [D1] | 根据需求选择 |
| 数据格式 | HDF5、Zarr | [D1] | 现代科学数据格式 |
| 访问接口 | Python、Matlab、Fortran、C | [D1] | 多语言支持 |
| 数据分辨率 | 最高 4096^3 | [D1] | 高分辨率湍流数据 |
| 数据大小 | TB 级别 | [D1] | 大规模数据集 |

## 边界与分流
- **访问权限不足**：需注册账户并遵守数据使用协议
- **网络带宽限制**：使用数据切片服务获取子集，而非完整数据集
- **存储空间不足**：选择低分辨率数据或部分时间步长
- **数据格式不兼容**：使用 HDF5 或 Zarr 库进行格式转换

## 质量检查
- 验证数据文件可正常读取（使用 h5py、zarr 库）
- 检查数据元信息是否完整（模拟参数、单位）
- 确保数据下载完整（校验和验证）
- 验证数据物理量范围合理（速度、压力在预期范围内）

## 回退策略
- 若 JHTDB 访问失败，可尝试其他公开湍流数据集（如 DNS 数据库）
- 若数据格式不兼容，使用格式转换工具（如 h5dump）
- 若下载速度过慢，使用数据子集或降低分辨率
