# OneScience CFD工作流产物格式契约

## 适用范围

本卡片为OneScience CFD工作流的产物格式提供规范，适用于所有CFD降阶建模任务的产物生成和验证。工作流产物格式契约确保各步骤输出的一致性、可解析性和可追溯性，是工作流自动化执行和质量门禁的基础。

## 输入

### 工作流步骤信息
- 步骤标识：s01-s05各步骤
- 产物要求：每个步骤的必需产物和可选产物
- 格式规范：文件格式、命名规则、内容结构

### 产物生成信息
- 生成工具：数据处理、模型训练、数据分析工具
- 生成参数：配置参数、随机种子、版本信息
- 生成环境：运行环境、硬件配置

### 验证标准信息
- 格式验证：文件扩展名、编码格式、结构完整性
- 内容验证：数据类型、数值范围、缺失值处理
- 一致性验证：产物间的数据一致性、逻辑一致性

## 输出

### 产物清单
- 必需产物：每个步骤必须生成的文件
- 可选产物：根据任务需求生成的文件
- 产物路径：文件命名和目录结构

### 格式验证报告
- 格式合规性：文件格式是否符合契约
- 内容完整性：必需字段是否存在
- 一致性检查：产物间数据是否一致

## 流程节点

1. **契约解析** → 2. **产物生成** → 3. **格式验证** → 4. **内容验证** → 5. **一致性检查**

### 步骤1：契约解析
- 操作：解析工作流产物格式契约
- 参数：步骤标识、产物要求
- 工具：契约解析器
- 质量门禁：契约解析正确

### 步骤2：产物生成
- 操作：按照契约生成产物文件
- 参数：文件内容、格式、路径
- 工具：产物生成工具
- 质量门禁：产物生成成功

### 步骤3：格式验证
- 操作：验证产物文件格式
- 参数：文件扩展名、编码、结构
- 工具：格式验证器
- 质量门禁：格式符合契约

### 步骤4：内容验证
- 操作：验证产物文件内容
- 参数：数据类型、数值范围、完整性
- 工具：内容验证器
- 质量门禁：内容完整准确

### 步骤5：一致性检查
- 操作：检查产物间数据一致性
- 参数：数据关联、逻辑关系
- 工具：一致性检查器
- 质量门禁：数据一致

## 关键参数

### 通用判据
| 参数 | 格式要求 | 来源 | 说明 |
|------|----------|------|------|
| worst_cases文件 | CSV格式 | 任务要求 | 必须为CSV而非JSON |
| environment.txt | 纯文本格式 | 任务要求 | 包含环境信息 |
| training_metrics | JSON/CSV格式 | 任务要求 | 训练过程记录 |
| evaluation.json | JSON格式 | 任务要求 | 评估结果记录 |
| execution-manifest.json | JSON格式 | 任务要求 | 执行清单记录 |

### 校准数值
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| worst_cases.csv列名 | sample_index, sample_error | 任务要求 | 标准列名 |
| environment.txt编码 | UTF-8 | 通用 | 标准编码格式 |
| JSON缩进 | 2空格 | 通用 | 可读性格式 |
| 文件路径分隔符 | / 或 \ | 平台 | 跨平台兼容 |

## 边界与分流

### 文件格式错误时
- worst_cases为JSON而非CSV → 转换为CSV格式
- 文件扩展名错误 → 重命名为正确扩展名
- 编码格式错误 → 转换为UTF-8编码

### 内容缺失时
- 必需字段缺失 → 补充缺失字段
- 数据类型错误 → 转换为正确数据类型
- 数值超出范围 → 调整数值范围

### 一致性冲突时
- 数据不一致 → 检查数据生成逻辑
- 逻辑矛盾 → 重新执行相关步骤
- 版本不匹配 → 统一版本信息

## 质量检查

### 验证点
1. 文件格式合规性
2. 内容完整性
3. 数据一致性
4. 命名规范性

### 阈值
- 格式合规率：100%
- 内容完整率：100%
- 数据一致率：100%
- 命名规范率：100%

### 失败处理
- 格式错误 → 重新生成正确格式
- 内容缺失 → 补充缺失内容
- 数据不一致 → 检查并修复数据

## 回退策略

### 产物生成失败时
1. 检查生成工具和参数
2. 验证输入数据完整性
3. 使用备选生成方法
4. 手动生成产物文件

### 格式验证失败时
1. 检查格式规范文档
2. 使用格式转换工具
3. 重新生成产物文件
4. 更新格式验证规则
