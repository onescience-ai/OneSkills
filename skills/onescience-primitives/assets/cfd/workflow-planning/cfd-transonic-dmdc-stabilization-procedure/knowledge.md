# DMDc模型稳定化方法

## 适用范围
DMDc模型可能出现的轻微不稳定问题，通过稳定化程序提高预测精度。适用于跨声速气动弹性降阶模型的稳定化处理。

## 输入
- 未稳定的DMDc模型
- 训练信号（需满足对称性和稳态条件）
- 气动响应数据

## 输出
- 稳定化的DMDc模型
- 稳定性验证报告（特征值分析）

## 流程节点
1. **特征值分析** → 检查原始DMDc模型的特征值分布
2. **稳态响应提取** → 选择特征快照，计算准稳态斜率
3. **非稳态分离** → 从总响应中减去准稳态部分
4. **DMDc重新训练** → 对非稳态部分重新训练DMDc模型
5. **模型重构** → 组合准稳态和非稳态模型
6. **稳定性验证** → 验证稳定化后模型的特征值分布

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 对称性要求 | 严格 | [1] | 气动响应需对称于输入 |
| 稳态时间窗口 | 足够长 | [1] | 允许气动达到稳态 |
| 特征快照选择 | 初始+每模态一个 | [1] | 用于计算准稳态斜率 |

## 边界与分流
- **对称性不满足**：调整训练信号振幅或采用其他稳定化方法
- **稳态未达到**：增加训练信号时间窗口
- **强非线性**：考虑非线性稳定化方法或多模型方法

## 质量检查
- 特征值应在单位圆内或圆上
- 压力分布预测精度应提高
- 模型响应应物理合理

## 回退策略
- 使用其他稳定化方法（如ERA方法）
- 采用全耦合CFD仿真验证
- 考虑非线性降阶方法
