# CFD降阶建模数据预处理与数据获取

## 适用范围

面向CFD降阶建模的数据准备阶段，涵盖快照矩阵的无量纲化处理、按工况/几何构造无泄漏切分、归一化统计量管理，以及公开CFD快照数据集的获取与接入流程。适用于不可压缩与可压缩流动、层流与湍流、内流与外流等CFD数据场景。不适用于实验数据的信号处理（那是数据后处理的职责），也不适用于CFD求解器本身的网格生成。

## 输入

- 原始CFD快照矩阵（物理单位：m/s, Pa, K等）
- 物理参数（Re, Ma, 几何尺寸等）
- 时间/空间分辨率信息
- 网格拓扑信息

## 输出

- 无量纲化后的快照矩阵
- normalization.json（归一化统计量：均值、标准差、参考值）
- train/validation/test 划分清单
- 公开数据集接入记录（来源、路径、许可证）

## 流程节点

### 无量纲化处理
- **操作**：基于参考量对物理量进行无量纲化，确保不同量纲的物理量在同一数量级
- **参考量选择**：不可压缩流用参考速度U_ref和参考长度L_ref；可压缩流增加参考温度T_ref和参考压力p_ref
- **参数**：U_ref, L_ref, ρ_ref, T_ref, p_ref（从流动条件中提取）
- **工具**：NumPy
- **质量门禁**：无量纲化后各物理量量级在[0.01, 100]范围内；归一化统计量仅从训练集计算

### 无泄漏切分
- **操作**：按工况/几何配置构造训练/验证/测试集，确保相同工况的数据不跨集泄漏
- **策略**：
  - 多工况数据：按工况编号分配，同一工况的所有时间步归入同一子集
  - 单工况长序列：按时间窗口分配，训练/验证/测试集时间窗口不重叠
  - 多几何数据：按几何配置分配，同一几何的所有数据归入同一子集
- **参数**：split_ratio (如 0.7/0.15/0.15)
- **工具**：NumPy/Pandas
- **质量门禁**：验证训练/验证/测试集无重叠；归一化统计量来源可追溯

### 归一化统计量管理
- **操作**：将归一化参数（均值、标准差、参考值）序列化为normalization.json，确保推理阶段可复用
- **参数**：statistics_fields (mean, std, ref_velocity, ref_length等)
- **工具**：JSON
- **质量门禁**：normalization.json存在且内容完整；统计量仅来自训练集

### 公开数据集获取
- **操作**：从权威来源下载CFD快照数据，验证数据完整性
- **权威来源**：
  - NASA Turbulence Modeling Resource (TMR)：https://tmbwg.github.io/turbmodels/（RANS湍流模型验证案例）
  - Johns Hopkins Turbulence Database (JHTDB)：湍流DNS数据
  - OpenFOAM官方教程案例库
  - AIHub / ModelScope上的CFD数据集
- **参数**：数据格式（VTK/H5/NPY）、物理量分量、时间步信息
- **工具**：wget/curl/Python requests
- **质量门禁**：数据来源可追溯；包含完整的边界条件和物理参数说明

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 无量纲化参考量选择 | 基于流动特征尺度 | 领域标准 | U_ref, L_ref需反映流动主要特征 |
| 归一化统计量隔离 | 仅训练集 | 领域标准 | 防止数据泄漏的关键约束 |
| 切分比例 | 70/15/15 | 领域标准 | 训练/验证/测试集典型比例 |
| 量级校验范围 | [0.01, 100] | 经验值 | 无量纲化后各物理量合理范围 |

### 校准数值

以下数值来自典型圆柱绕流体系，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 典型Re数范围 | 100~10^6 | [D1] | 湍流模型验证案例覆盖范围 |
| 典型马赫数范围 | 0~7 | [D1] | 从亚音速到高超声速 |
| 网格量级 | 10^4~10^7 节点 | [D1] | 验证案例网格量级 |

## 边界与分流

- **多工况混合数据**：若工况间物理参数差异大（如Re数跨越数量级），应按工况分别归一化后再拼接，或采用分段归一化
- **非均匀时间步**：快照时间间隔不均匀时，DMD的时间移位矩阵构建需使用实际时间间隔而非假设均匀步长
- **数据量不足**：快照数 < 50 时，POD/DMD模型稳定性下降，应考虑增加快照或使用迁移学习
- **无公开数据可用**：当标准验证案例不适用时，需自行运行CFD求解器生成数据，此时应记录求解器版本、网格信息和收敛标准

## 质量检查

- [ ] normalization.json 存在且包含完整统计量
- [ ] 归一化统计量仅来自训练集
- [ ] 训练/验证/测试集无重叠
- [ ] 无量纲化后物理量量级合理
- [ ] 数据来源可追溯（公开数据集需记录URL和许可证）
- [ ] 快照矩阵无NaN/Inf

## 回退策略

- 无量纲化参数选择不确定 → 使用特征值分解自动确定参考量（基于快照矩阵的Frobenius范数）
- 公开数据集不可得 → 使用OpenFOAM等开源CFD求解器生成标准验证案例数据
- 数据量不足 → 使用数据增强（时间插值、空间扰动）或迁移学习
