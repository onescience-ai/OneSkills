# Bayesian PINN Training Convergence and Loss Management

## 适用范围

本卡片面向贝叶斯物理信息神经网络（Bayesian PINN）在科学计算与反演问题中的训练过程，提供变分推断损失量级判据、ELBO损失平衡策略、学习率调度与KL权重退火方法、损失曲线异常诊断与修复方案。适用于一维热传导、波动方程等CFD/PDE问题的概率反演与不确定性量化任务。不适用于纯数据驱动的神经网络训练或非贝叶斯确定性PINN。

## 输入

- 训练数据：时空配点上的观测值或合成数据
- PDE控制方程：如一维热传导方程 ∂u/∂t = α∂²u/∂x²
- 边界条件与初始条件
- 训练配置：学习率、网络架构、优化器选择、训练轮数

## 输出

- 收敛的PINN模型权重
- 训练损失曲线（含ELBO损失、数据拟合项、KL散度项）
- 不确定性估计（均值与标准差）
- 收敛判据验证报告

## 流程节点

### 步骤1：损失函数构建

贝叶斯PINN的总损失函数由三项组成：

```
L_total = L_data + λ_PDE * L_PDE + β * L_KL
```

其中：
- **L_data**：数据拟合项（MSE），衡量网络预测与观测数据的偏差
- **L_PDE**：物理约束残差，衡量PDE方程的满足程度
- **L_KL**：KL散度项，量化变分后验与先验的偏离程度
- **β**：KL权重（也称β-VAE中的β参数），控制正则化强度 [论文1]

### 步骤2：ELBO损失量级判据

| 问题尺度 | ELBO损失合理范围 | 数据拟合项范围 | KL散度项范围 | 来源 |
|---------|-----------------|---------------|-------------|------|
| u ∈ [0,1]（一维热传导） | 个位数（1-10） | < 1 | < 5 | [论文1] |
| u ∈ [0,10]（波动方程） | 10-100 | < 10 | < 20 | [论文1] |
| 高维/复杂几何 | 10-1000 | < 50 | < 100 | [论文1] |

**关键判据**：若训练50轮后损失仍为万级（如60000+），表明训练配置严重不当 [报告CFD_S039证据]。

### 步骤3：学习率调度策略

推荐两阶段训练策略（NPINN+框架验证有效）[论文1]：

1. **第一阶段（Adam优化器）**：
   - 初始学习率：0.001
   - 调度器：StepLR（step=1000, γ=0.5）
   - 迭代轮数：10000-20000轮
   - 目标：稳定损失，避免发散

2. **第二阶段（L-BFGS优化器）**：
   - 强Wolfe线搜索
   - 最大迭代：50000轮
   - 目标：高精度收敛

**降级方案**：若Adam+L-BFGS收敛困难，可尝试ReduceLROnPlateau（patience=500, factor=0.5, min_lr=1e-6）[论文1]。

### 步骤4：KL权重β退火策略

KL权重退火（β-annealing）是防止KL项主导训练的关键策略：

| 阶段 | β值 | 退火策略 | 说明 |
|------|-----|---------|------|
| 初始阶段 | 0 → 1e-5 | 线性退火（前1000轮） | 让网络先学习数据特征 |
| 中间阶段 | 1e-5 → 1e-3 | 指数退火（1000-5000轮） | 逐步引入正则化 |
| 后期阶段 | 1e-3 → 1e-2 | 缓慢退火（5000-10000轮） | 稳定后验分布 |

**推荐配置**：对于u ∈ [0,1]量级的问题，β最终值不宜超过0.01，否则KL项会压制数据拟合项 [论文2]。

### 步骤5：SoftAdapt动态损失权重（替代方案）

当固定权重无法平衡多约束时，采用SoftAdapt机制自动调整权重 [论文1]：

```
w_i(e) = exp(s * ΔL_i(e)) / Σ_j exp(s * ΔL_j(e))
```

其中：
- ΔL_i(e) = L_i(e-1) - L_i(e)，表示第i个损失项在epoch e的下降量
- s = 1/τ，τ为温度参数（推荐τ=0.1）
- 下降越慢的损失项获得更大权重，引导模型关注困难目标

## 关键参数

### 通用判据（方法层，同类体系可参考）

| 参数 | 推荐值 | 来源 | 说明 |
|------|--------|------|------|
| Adam初始学习率 | 0.001 | [论文1] | 适用于大多数PINN问题 |
| L-BFGS最大迭代 | 50000 | [论文1] | 确保高精度收敛 |
| SoftAdapt温度τ | 0.1 | [论文1] | 控制权重分布锐度 |
| KL权重β最大值 | 0.01-0.1 | [论文2] | 防止KL项主导训练 |
| 梯度裁剪阈值 | 1.0-10.0 | [论文2] | 防止梯度爆炸 |
| 早停耐心值 | 1000-5000轮 | 通用建议 | 验证损失不再下降时停止 |

### 校准数值（体系专属值）

以一维热传导问题（u ∈ [0,1], α=0.01）为例，以下数值来自NPINN+框架实测 [论文1]，供量级校准；其他体系需以自身证据重新锚定：

| 参数 | 数值 | 说明 |
|------|------|------|
| 网络架构 | 7层 × 100神经元 | 权衡精度与计算成本 |
| 采样点数（PDE） | 12000 | Sobol序列生成 |
| 采样点数（BC/IC） | 3000 | 边界/初始条件 |
| 训练轮数（Adam） | 20000 | 达到1e-3级相对误差 |
| 相对L2误差 | ~1e-3 | 优秀收敛水平 |

## 边界与分流

### 损失不收敛的排查清单（按优先级排序）

1. **学习率过高** → 降低至0.0001或0.00001
2. **KL权重β过大** → 降至1e-5或更小，重新退火
3. **网络深度不足** → 增加隐藏层（5→7层）
4. **数据归一化问题** → 检查输入/输出是否在合理范围
5. **PDE残差权重过低** → 增加λ_PDE（从1.0增至10.0）
6. **配点分布不均** → 使用自适应采样（残差驱动）

### 异常损失模式诊断

| 现象 | 可能原因 | 修复方案 |
|------|---------|---------|
| 损失剧烈波动（1e4-1e6） | 学习率过高或梯度爆炸 | 降低学习率，添加梯度裁剪 |
| 损速下降后平台期 | 陷入局部极小 | 增加配点，使用L-BFGS |
| 验证损失持续上升 | 过拟合 | 增加KL权重，减少网络容量 |
| KL项持续增大 | 退火过快 | 放慢β增长速率 |

## 质量检查

- [ ] 训练损失在合理量级范围内（与问题尺度匹配）
- [ ] 验证损失单调下降且波动收敛
- [ ] ELBO损失中数据拟合项与KL项平衡（不超过一个数量级差异）
- [ ] 损失曲线无剧烈波动（标准差<均值的10%）
- [ ] 最终相对L2误差<0.1（门限要求）

## 回退策略

1. **完全失败**：切换为确定性PINN（去除贝叶斯推断），先验证PDE求解能力
2. **部分收敛**：记录当前最佳权重，作为后续训练的初始化
3. **API限流**：使用本地缓存的预训练模型或降级到简化模型
