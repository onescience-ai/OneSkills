# POD与DMD降阶建模标准工作流

## 适用范围

面向流动降阶建模（Reduced Order Modeling, ROM）任务，适用于从CFD快照矩阵构建基于POD（Proper Orthogonal Decomposition）或DMD（Dynamic Mode Decomposition）的低维模型。本卡给出从原始数据接入到评估验收的完整五步工作流定义，覆盖每步的输入、输出、依赖关系和质量门禁。适用于不可压缩/可压缩流动、湍流/层流、内流/外流等场景。不适用于非线性偏微分方程的纯数值求解（那是CFD求解器自身的职责），也不适用于不基于快照数据的纯理论分析。

## 输入

- CFD快照矩阵 X ∈ R^(m×n)，其中 m 为空间自由度数（网格节点×物理量），n 为时间快照数
- 边界条件、初始条件、物理参数（雷诺数、马赫数等）
- 网格信息（结构/非结构，节点坐标）
- 训练/验证/测试集划分比例（典型 70/15/15）

## 输出

- 降阶模型（POD基函数+时间系数，或DMD模态+特征值）
- 重建/预测流场
- 评估指标（L2误差、能量捕获率、守恒残差、加速比）
- 模型配置文件、训练日志、评估报告

## 流程节点

### s01 数据接入
- **操作**：加载CFD快照矩阵，解析时间戳和空间坐标，验证数据完整性
- **参数**：快照文件格式（.npy/.vtk/.h5）、物理量分量（u/v/w/p/T）
- **工具**：NumPy/PyVista/VTK
- **质量门禁**：快照数 ≥ 10，无NaN/Inf，时间步均匀性检查

### s02 数据预处理与切分
- **操作**：无量纲化处理、按工况/几何构造无泄漏切分、生成归一化统计量
- **参数**：参考速度U_ref、参考长度L_ref、Re数归一化方案
- **工具**：NumPy/PyTorch
- **质量门禁**：归一化统计量仅来自训练集，测试/验证集使用训练集统计量变换

### s03 模型训练
- **操作**：POD：SVD分解获取快照矩阵的奇异向量作为空间基函数；DMD：构建时间移位矩阵并求解特征值问题获取模态和频率
- **参数**：截断阶数r（POD能量阈值或DMD模态数）
- **工具**：NumPy SVD / PyTorch（神经网络参数化POD/DMD）
- **质量门禁**：能量捕获率 ≥ 95%（POD），特征值虚部对应物理频率合理（DMD）

### s04 推理恢复
- **操作**：在独立测试集上执行降阶投影→时间演化→反投影恢复原始物理空间，重建网格并恢复物理单位
- **参数**：截断阶数r、时间积分方案
- **工具**：NumPy/PyTorch
- **质量门禁**：预测值具有正确的物理单位（m/s, Pa等），网格坐标与原始一致

### s05 评估验收
- **操作**：计算L2相对误差、逐点误差分布、能量谱对比、守恒残差、计算加速比
- **参数**：验收阈值（如L2 < 1e-3，conservation_residual < 1e-6）
- **工具**：NumPy/SciPy/Matplotlib
- **质量门禁**：所有指标达标，生成inference_manifest.json和timing.csv

## 关键参数

### 通用判据（方法层，同类体系可参考）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| POD能量捕获阈值 | ≥ 95% | 领域标准 | 决定截断阶数r的基本判据 |
| DMD模态物理合理性 | 特征值虚部/实部比值 | [D1] | 频率与流场主频一致 |
| 守恒残差阈值 | < 1e-6 | 领域标准 | Navier-Stokes方程守恒性验证 |
| 相对L2误差 | < 1e-3 | 领域标准 | 降阶模型预测精度的基本要求 |
| 无泄漏切分 | 训练集统计量隔离 | 领域标准 | 防止数据泄漏的关键约束 |

### 校准数值

以下数值来自典型圆柱绕流/腔体流动体系，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 典型截断阶数r | 10~50 | 文献经验 | 依赖于流动复杂度和快照数 |
| 推荐快照数 | 50~200 | 文献经验 | 时间分辨率需覆盖流动特征时间尺度 |
| 加速比量级 | 10^2~10^4 | [D1] | 相对于全阶CFD求解器 |

## 边界与分流

- **快照矩阵秩亏（rank-deficient）**：若 SVD 奇异值快速衰减至机器精度，说明快照间线性相关性过强或时间步过密，应增加时间步间隔或引入参数化POD
- **DMD特征值不稳定（|λ| > 1）**：表示对应模态增长，对非定常流动需检查时间窗口长度或采用扩展DMD（EDMD）
- **截断阶数选择困难**：能量阈值法与L曲线法可能给出不一致结果，应同时报告两种方案结果
- **非线性主导流动**：POD/DMD为线性方法，对强非线性流动（如激波振荡）精度不足，应考虑神经网络参数化POD或非线性降阶方法

## 质量检查

- [ ] 快照矩阵维度与物理参数一致
- [ ] 训练/验证/测试集无重叠
- [ ] 降阶模型重建误差在验收阈值内
- [ ] 守恒残差满足物理约束
- [ ] 推理输出具有正确物理单位
- [ ] 计算加速比有真实基准支撑

## 回退策略

- SVD分解失败 → 检查数值条件数，考虑使用截断SVD或随机SVD
- DMD模态发散 → 减小时间窗口、增加正则化、采用BOPDMD（Bagging, Optimized DMD）
- 精度不足 → 增加截断阶数或切换到非线性降阶方法
