# GAN与正规化流湍流降阶生成场景

## 适用范围

本场景面向湍流快照与低维潜变量数据，使用生成对抗网络（GAN）或正规化流（Normalizing Flow）完成湍流降阶生成。适用于需要从高维湍流场数据中学习概率分布、生成多样化物理一致流场样本的工程与科研场景。

**触发条件**：
- 输入为湍流快照（时间序列或参数化流场状态）
- 需要生成符合物理规律的多样化湍流场样本
- 需要评估生成模型的物理一致性和适用域
- 潜在空间可编码低维流场特征

**适用场景**：
- 湍流场降阶建模与快速生成
- 湍流统计特性保持的样本扩增
- 湍流工况外推与不确定性量化
- 流场数据压缩与潜在空间探索

**不适用场景**：
- 非湍流层流场的简单插值预测
- 需要严格逐点精确匹配的流场重建
- 强多物理场耦合（如燃烧、化学反应）且无额外耦合处理

## 输入

**数据格式**：
- 湍流快照矩阵：时间或参数序列下的流场状态（速度分量、压力、涡量等）
- 低维潜变量：编码流场特征的低维表示（如 POD 系数、编码器潜空间坐标）
- 网格信息：空间离散化数据（网格坐标、拓扑、边界标识）

**预处理要求**：
- 数据可读性验证（文件完整性、格式一致性）
- 变量单位统一和坐标系对齐
- 物理量归一化或无量纲化（保存可逆变换参数）
- 缺失值处理和异常值检测

## 输出

**产物**：
1. 可复现的 GAN 或 Normalizing Flow 模型权重
2. 训练配置与逐轮指标
3. 条件采样生成的流场样本集
4. 物理一致性筛选报告（边界残差、守恒残差、方程残差）
5. 适用域判定报告（统计误差、泛化能力、计算收益）

**验证标准**：
- 模型可复现性（代码版本、依赖、随机种子）
- 生成样本分布与真实数据分布的统计距离在允许范围内
- 物理约束满足（守恒律、边界条件、控制方程残差）
- 多样性与真实性同时评价（禁止单样本代表性）
- 域外工况需经 CFD 复核

## 流程节点

### Step 1：数据接入与契约核验
- **操作**：接入湍流快照与低维潜变量数据，核验样本、变量、单位、网格坐标及许可
- **参数**：数据集路径、数据集名称、数据契约模板
- **工具**：数据读取库、契约验证脚本
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏

### Step 2：预处理与数据切分
- **操作**：统一物理量与表示，按几何、工况或时间构造无泄漏切分
- **参数**：切分配置（train/val/test 比例、group_by）、目标变量、无量纲化选项
- **工具**：数据预处理库、切分工具
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏

### Step 3：模型配置与训练
- **操作**：训练 GAN 或 Normalizing Flow 完成指定输入到目标物理量的映射
- **参数**：模型名称、训练配置（框架、epochs、batch_size、学习率、早停耐心）
- **工具**：PyTorch 等深度学习框架
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现

### Step 4：条件采样与物理一致性筛选
- **操作**：按工况生成多样流场样本并依据物理残差筛选
- **参数**：模型权重、计算设备、推理批大小
- **工具**：推理引擎、物理残差计算脚本
- **质量门禁**：样本条件与随机种子可追溯；多样性和真实性同时评价；物理筛选前后统计均报告

### Step 5：任务验收与适用域判定
- **操作**：评估统计误差、关键物理约束、泛化能力和计算收益
- **参数**：验收指标、相对误差门限、外推测试选项
- **工具**：评估脚本、可视化工具
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议

## 边界与分流

**关键前提不成立时的改道方案**：

1. **湍流快照数据不足或质量差**
   - 不成立时 → 改道：进行数据清洗、补采或使用数据增强；若数据量过少，可考虑迁移学习或预训练模型微调

2. **GAN 训练不稳定（模式崩塌、振荡）**
   - 不成立时 → 改道：调整损失函数、使用谱归一化、渐进式训练、或切换到 Normalizing Flow 架构

3. **Normalizing Flow 训练不收敛**
   - 不成立时 → 改道：调整流架构复杂度、学习率、正则化参数；或切换到 GAN 架构

4. **物理约束严重违反**
   - 不成立时 → 改道：在损失函数中添加物理惩罚项、使用物理信息判别器、或后处理校正

5. **域外工况**
   - 不成立时 → 改道：标记为"需 CFD 复核"，不得仅凭生成模型输出宣称工程可用

## 质量检查

**验证点**：
- 数据完整性检查（样本数、变量完整性、网格一致性）
- 模型训练收敛性（损失曲线、早停机制、模式多样性）
- 生成样本统计特性（分布距离、多样性、覆盖率）
- 物理一致性验证（边界残差、守恒残差、方程残差）
- 最差样本分析与追溯
- 推理成本评估

**阈值**：
- 相对 L2 误差 ≤ 0.1（默认）
- 守恒残差 < 1e-6（量纲相关）
- 边界误差 < 1%（边界条件满足度）
- 生成分布距离在任务可接受范围内

**失败处理**：
- 误差超标 → 调整模型架构或训练策略
- 物理违反 → 添加物理约束或后处理校正
- 多样性不足 → 增加潜空间采样策略或调整生成器容量
- 模式崩塌 → 使用谱归一化、渐进式训练或切换架构

## 回退策略

**失败时的替代方案**：
1. **GAN 训练失败** → 回退到 Normalizing Flow 或线性降阶方法（POD）
2. **Normalizing Flow 训练失败** → 回退到 GAN 或 POD+插值方法
3. **物理一致性验证失败** → 回退到后处理物理校正或传统 CFD
4. **适用域判定不确定** → 标记为"需 CFD 复核"并限制应用场景
5. **计算资源不足** → 降级到小规模数据集或简化网格
