# 隐式神经场连续流动降阶建模工作流

## 适用范围

本工作流适用于基于连续坐标采样的PDE快照数据，构建隐式神经场连续流动降阶模型。涵盖从数据接入到任务验收的完整流程，确保模型可复现、物理一致性可评估、适用域边界明确。

**触发条件**：
- 输入数据为连续坐标采样的PDE快照
- 需要构建连续场量的降阶表示
- 需要完整的建模与验证流程

**不适用场景**：
- 离散网格数据的直接处理
- 强间断流场的高保真模拟
- 域外工况的直接外推

## 输入

**数据源**：
- 连续坐标采样的PDE快照数据集（目录或清单文件）
- 数据集名称和版本信息
- 数据契约（变量、单位、网格定义）

**配置参数**：
- 切分配置（train/validation/test比例、种子、分组方式）
- 目标变量列表
- 训练配置（框架、超参数、随机种子）
- 验收指标和阈值

## 输出

**工作流产物**：
1. 数据清单和契约（dataset_manifest.json, data_contract.json, data_audit.md）
2. 数据切分和归一化统计（train_manifest.json, validation_manifest.json, test_manifest.json, normalization.json）
3. 训练模型和配置（best_checkpoint.pt, train_config.json, training_metrics.csv, environment.txt）
4. 推理结果和性能（predictions/, inference_manifest.json, timing.csv）
5. 评估报告和适用域（evaluation.json, worst_cases.csv, applicability_report.md, PASS_REJECT_BLOCKED.txt）

**验证标准**：
- 所有产物可机器可读
- 模型权重可重新加载
- 物理一致性验证通过
- 适用域边界明确

## 流程节点

### s01: 数据接入与契约核验
- **输入**：数据集路径、数据集名称、数据契约模板
- **操作**：读取数据集，建立数据清单，核验样本、变量、单位、网格坐标及许可
- **输出**：dataset_manifest.json, data_contract.json, data_audit.md
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏

### s02: 预处理与数据切分
- **输入**：s01输出、切分配置、目标变量、是否无量纲化
- **操作**：统一物理量与表示，按几何、工况或时间构造无泄漏切分
- **输出**：train_manifest.json, validation_manifest.json, test_manifest.json, normalization.json
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏

### s03: 模型配置与训练
- **输入**：s02输出、模型名称、训练配置、初始权重（可选）
- **操作**：训练Implicit neural representation和Continuous ROM，记录代码版本、依赖、随机种子、逐轮训练验证指标与最佳权重
- **输出**：best_checkpoint.pt, train_config.json, training_metrics.csv, environment.txt
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现

### s04: 批量推理与物理恢复
- **输入**：s03输出（模型权重）、计算设备、推理批大小
- **操作**：在独立测试集推理，恢复原始单位、网格和物理派生量，保存逐样本结果和耗时
- **输出**：predictions/, inference_manifest.json, timing.csv
- **质量门禁**：预测无NaN或Inf且形状单位正确；每个测试样本有唯一结果；推理未使用测试目标校正

### s05: 任务验收与适用域判定
- **输入**：s04输出、验收指标、相对误差门限、是否外推测试
- **操作**：评估统计误差、关键物理约束、泛化能力和计算收益，给出PASS、REJECT或BLOCKED结论
- **输出**：evaluation.json, worst_cases.csv, applicability_report.md, PASS_REJECT_BLOCKED.txt
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议

## 边界与分流

**前提条件与改道**：

1. **数据为连续坐标采样**
   - 不成立时 → 改道：先进行坐标连续化处理，或使用基于网格的降阶方法（如POD）

2. **PDE快照数据完整**
   - 不成立时 → 改道：进行数据修复或使用降阶方法中的数据同化技术

3. **物理约束可验证**
   - 不成立时 → 改道：仅进行统计误差评估，物理一致性验证标记为"证据有限"

4. **训练收敛**
   - 不成立时 → 改道：调整超参数、使用学习率调度器、检查数据质量

5. **测试集误差在阈值内**
   - 不成立时 → 改道：进行误差分析、检查模型容量、考虑更复杂的神经表示

## 质量检查

**验证点**：
- 数据完整性检查（缺失值、异常值）
- 切分正确性验证（互斥性、无泄漏）
- 模型收敛性验证（损失曲线、梯度稳定性）
- 物理一致性验证（守恒律、边界条件）
- 适用域边界测试（OOD工况）

**阈值**：
- 相对L2误差 < 0.1
- 守恒残差 < 0.01（归一化后）
- 边界误差 < 0.05
- 数据完整性 100%

**失败处理**：
- 数据质量问题 → 返回s01重新核验
- 切分错误 → 返回s02重新切分
- 训练不收敛 → 调整超参数重试
- 物理不一致 → 标记为BLOCKED，需要CFD复核
- 适用域外 → 明确标注边界，提供复核建议

## 回退策略

**失败时的替代方案**：
1. 数据接入失败 → 检查路径权限、文件格式兼容性
2. 预处理失败 → 简化数据表示、检查单位一致性
3. 模型训练失败 → 尝试简化模型结构、调整超参数
4. 推理失败 → 检查模型兼容性、设备可用性
5. 验收失败 → 进行详细误差分析、提供改进建议
