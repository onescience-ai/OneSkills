# 边界嵌入神经算子批量推理与物理恢复

## 适用范围

本卡片描述边界嵌入神经算子批量推理与物理恢复任务，适用于：
- 在独立测试集上执行批量推理
- 恢复原始单位、网格和物理派生量
- 保存逐样本结果和耗时

**不适用场景**：
- 单样本推理
- 不需要物理恢复的纯预测任务

## 输入

1. **模型权重** `{CHECKPOINT}`：通过训练门限权重
2. **计算设备** `{DEVICE}`：CPU或CUDA设备
3. **推理批大小** `{BATCH_SIZE}`：按显存调整批量

## 输出

1. `predictions/`：预测结果
2. `inference_manifest.json`：推理清单
3. `timing.csv`：耗时统计

## 流程节点

### Step 1：模型加载
- **操作**：加载训练好的模型权重
- **工具**：PyTorch模型加载
- **质量门禁**：模型权重正确加载

### Step 2：数据加载
- **操作**：加载测试集数据和统计量
- **工具**：数据加载工具
- **质量门禁**：测试集数据正确加载

### Step 3：批量推理
- **操作**：在测试集上执行批量推理
- **工具**：PyTorch推理
- **质量门禁**：预测无NaN或Inf

### Step 4：物理恢复
- **操作**：反归一化恢复物理单位、坐标网格、边界掩膜及任务派生量
- **工具**：数据逆变换
- **质量门禁**：恢复后形状和单位正确

### Step 5：结果保存
- **操作**：保存逐样本结果和耗时
- **工具**：文件保存工具
- **质量门禁**：每个测试样本有唯一结果

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 预测无异常值 | 必须 | [场景需求书s04] | 预测无NaN或Inf且形状单位正确 |

| 未使用测试标签 | 必须 | [场景需求书s04] | 推理未使用测试目标校正 |

| 参数 | 值 | 来源 | 说明 |

## 边界与分流

1. **预测有NaN或Inf** → 检查模型权重和数据
2. **结果不唯一** → 检查数据加载和推理逻辑
3. **使用了测试标签** → 检查推理代码，确保未使用测试目标

## 质量检查

1. **预测正确性**：预测无异常值且形状正确
2. **结果唯一性**：每个测试样本有唯一结果
3. **物理恢复正确性**：恢复后物理单位和坐标正确
4. **耗时统计**：推理耗时正确记录

## 回退策略

1. **推理失败** → 检查模型权重和数据格式
2. **物理恢复失败** → 检查逆变换逻辑
3. **内存不足** → 降低批大小
