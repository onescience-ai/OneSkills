# 边界嵌入神经算子预处理与数据切分

## 适用范围

本卡片描述边界嵌入神经算子预处理与数据切分任务，适用于：
- 混合边界与复杂域PDE数据的预处理
- 按几何、工况或时间构造无泄漏切分
- 保存统计量与可逆变换

**不适用场景**：
- 数据已通过其他方式预处理
- 数据格式不符合PDE数据规范

## 输入

1. **切分配置** `{SPLIT_CONFIG}`：按对象工况切分
2. **目标变量** `{TARGET_FIELDS}`：待预测物理量
3. **是否无量纲化** `{NONDIMENSIONALIZE}`：统一跨工况量纲

## 输出

1. `train_manifest.json`：训练集清单
2. `validation_manifest.json`：验证集清单
3. `test_manifest.json`：测试集清单
4. `normalization.json`：归一化参数

## 流程节点

### Step 1：物理量统一
- **操作**：统一物理量表示，确保单位和量纲一致
- **工具**：单位转换库、数据处理工具
- **质量门禁**：所有物理量单位和量纲一致

### Step 2：无量纲化处理
- **操作**：进行无量纲化或归一化，保存统计量
- **工具**：归一化工具
- **质量门禁**：统计量仅来自训练集

### Step 3：无泄漏切分
- **操作**：按几何、工况或时间构造无泄漏切分
- **工具**：数据切分工具
- **质量门禁**：三份切分的对象轨迹互斥

### Step 4：变换保存
- **操作**：保存可逆变换，确保可逆性
- **工具**：序列化工具
- **质量门禁**：变换可逆且保存完整

### Step 5：清单生成
- **操作**：生成训练、验证、测试集清单
- **工具**：JSON生成
- **质量门禁**：清单包含所有必需字段

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 无泄漏切分 | 必须 | [场景需求书s02] | 不得把同一轨迹的帧随机打散 |
| 统计量仅来自训练集 | 必须 | [场景需求书s02] | 验证集和测试集不参与统计量计算 |
| 边界语义完整 | 必须 | [场景需求书s02] | 边界与掩膜语义未破坏 |
| 可逆变换 | 必须 | [场景需求书s02] | 归一化/无量纲化必须可逆 |

### 校准数值

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 训练集比例 | 0.7 | 场景需求书 | 默认训练集比例 |
| 验证集比例 | 0.15 | 场景需求书 | 默认验证集比例 |
| 测试集比例 | 0.15 | 场景需求书 | 默认测试集比例 |
| 随机种子 | 42 | 场景需求书 | 切分随机种子 |
| 无量纲化 | true | 场景需求书 | 默认进行无量纲化 |

以下数值来自CFD_S064场景，供量级校准；其他体系需以自身证据重新锚定。

## 边界与分流

1. **切分导致数据泄漏** → 重新切分，确保对象轨迹互斥
2. **统计量来自非训练集** → 重新计算统计量
3. **边界语义破坏** → 检查预处理步骤，确保边界语义完整
4. **变换不可逆** → 检查变换保存，确保可逆性

## 质量检查

1. **切分互斥性**：训练、验证、测试集互斥
2. **统计量正确性**：统计量仅来自训练集
3. **边界完整性**：边界与掩膜语义完整
4. **变换可逆性**：归一化/无量纲化可逆
5. **清单完整性**：清单包含所有必需字段

## 回退策略

1. **数据泄漏** → 重新设计切分策略
2. **统计量错误** → 重新计算统计量
3. **变换失败** → 使用更简单的归一化方法
4. **清单不完整** → 重新生成清单
