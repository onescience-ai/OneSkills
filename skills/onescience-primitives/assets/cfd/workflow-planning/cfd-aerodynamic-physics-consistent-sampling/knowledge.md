# 生成模型条件采样与物理一致性筛选

## 适用范围

**触发条件**：
- 已完成模型训练（s03），需要基于训练好的生成模型进行条件采样
- 需要对生成样本进行物理一致性筛选（边界残差、守恒残差、方程残差）
- 需要评估生成样本的多样性与分布覆盖

**适用场景**：
- 潜空间扩散模型的气动设计条件采样
- 生成式气动外形-流场的物理一致性验证
- 多样化候选设计的批量生成与筛选

**不适用场景**：
- 仅需少量样本的快速验证（直接用CFD评估更合适）
- 无物理约束要求的纯数据驱动采样
- 需要实时推理的在线部署场景

## 输入

- 模型权重（{CHECKPOINT}：best_checkpoint.pt）
- 计算设备（{DEVICE}：CPU或CUDA）
- 推理批大小（{BATCH_SIZE}：默认8）
- 测试集条件数据

## 输出

- generated_samples/：生成样本目录（含几何、流场、采样轨迹、条件、随机种子）
- physics_filter.json：物理筛选结果（通过/未通过、各残差值）
- distribution_metrics.json：分布覆盖评估（多样性、真实性指标）

## 流程节点

### Step 1：加载模型与条件准备
- **操作**：加载训练好的模型权重，准备测试集条件输入
- **质量门禁**：模型权重加载成功；条件数据格式正确

### Step 2：多样本条件采样
- **操作**：对每个测试条件生成多个随机种子样本，记录采样轨迹
- **参数**：每个条件的采样数量、随机种子列表
- **质量门禁**：样本条件与随机种子可追溯

### Step 3：物理量恢复
- **操作**：将归一化/无量纲化的生成结果恢复为物理量单位
- **参数**：normalization.json（逆变换参数）
- **质量门禁**：逆变换正确；恢复后的物理量量级合理

### Step 4：物理残差计算
- **操作**：计算边界残差（边界条件满足度）、守恒残差（质量/动量/能量守恒）、方程残差（N-S方程残差）
- **工具**：有限差分/有限体积数值计算
- **质量门禁**：各残差值为有限值；残差计算方法可复现

### Step 5：不合格样本剔除
- **操作**：根据物理残差阈值剔除不合格样本
- **参数**：残差阈值（待确认，需根据物理问题设定）
- **质量门禁**：筛选前后统计均报告；禁止用单个漂亮样本代表整体性能

### Step 6：分布覆盖评估
- **操作**：评估生成样本的多样性和真实性（如分布距离、覆盖率）
- **工具**：统计距离度量（如Wasserstein距离、MMD）
- **质量门禁**：多样性和真实性同时评价

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 推理批大小 | 8 | [1] | 按显存调整 |
| 每条件采样数 | 待确认 | - | 需根据需求设定 |
| 物理残差阈值 | 待确认 | - | 需根据物理问题设定 |
| 采样方法 | 随机种子多次采样 | [1] | 保证多样性 |
| 禁止单样本代表 | true | [1] | 原则性要求 |

## 边界与分流

- **物理筛选通过率极低**（<30%）：降低物理约束权重，排查数据质量问题，必要时使用软约束
- **生成样本多样性不足**：增加采样随机性，检查模型是否坍塌
- **物理量恢复后量级异常**：检查逆变换参数是否正确
- **残差计算失败**：使用简化物理模型（如势流理论）做初筛
- **显存不足**：减小推理批大小

## 质量检查

- 样本条件与随机种子可追溯
- 多样性和真实性同时评价
- 物理筛选前后统计均报告
- 禁止用单个漂亮样本代表整体性能
- 最差样本可追溯

## 回退策略

- 物理筛选全部不通过：使用简化物理模型做初筛，再用完整CFD复核
- 多样性严重不足：检查模型训练质量，必要时重新训练
- 残差计算方法不可靠：使用CFD软件直接评估
