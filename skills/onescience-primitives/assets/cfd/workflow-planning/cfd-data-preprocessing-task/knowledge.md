# 预处理与数据切分任务

## 适用范围
本任务适用于对翼型壁面压力剪切及速度测量数据进行预处理与数据切分，统一物理量与表示，按几何、工况或时间构造无泄漏切分。适用于任何需要基于壁面测量数据进行气动力反演的场景。

## 输入
- 切分配置：按对象工况切分。
- 目标变量：待预测物理量。
- 是否无量纲化：统一跨工况量纲。

## 输出
- train_manifest.json：训练集清单。
- validation_manifest.json：验证集清单。
- test_manifest.json：测试集清单。
- normalization.json：归一化统计量。

## 流程节点
1. 依据数据契约完成质控、重采样或图构建、掩膜、归一化或无量纲化。
2. 按切分配置以几何、完整轨迹或物理工况为单位切分，不得把同一轨迹的帧随机打散。
3. 为目标变量保存统计量与可逆变换。

## 关键参数
### 通用判据（方法层）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 切分比例 | train 0.7, validation 0.15, test 0.15 | 场景需求书 | 标准切分比例 |
| 随机种子 | 42 | 场景需求书 | 可复现性保证 |
| 三份切分的对象轨迹互斥 | true | 质量门禁 | 避免数据泄漏 |
| 仅用训练集计算变换统计量 | true | 质量门禁 | 防止信息泄漏 |
| 边界与掩膜语义未破坏 | true | 质量门禁 | 保持数据完整性 |

### 校准数值（体系专属值）
以下数值来自翼型壁面压力剪切与积分气动力联合反演场景，供量级校准；其他体系需以自身证据重新锚定。
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 目标变量 | 壁面剪切应力、壁面压力、积分气动力 | 场景需求书 | 反演目标 |
| 是否无量纲化 | true | 场景需求书 | 默认无量纲化 |

## 边界与分流
- 当数据不满足质量门禁（如存在训练测试泄漏、边界与掩膜语义被破坏）时，需重新切分。
- 当数据量不足时，可尝试数据增强或使用迁移学习。
- 当数据格式不支持时，需转换格式或使用其他工具解析。

## 质量检查
- 三份切分的对象轨迹互斥。
- 仅用训练集计算变换统计量。
- 边界与掩膜语义未破坏。

## 回退策略
- 若切分不满足互斥性，重新设计切分策略。
- 若归一化统计量计算错误，重新计算并验证。
- 若数据格式不支持，尝试转换格式或使用其他解析库。
