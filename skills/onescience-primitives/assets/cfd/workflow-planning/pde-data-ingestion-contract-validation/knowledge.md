# PDE数据接入与契约核验

## 适用范围
本卡片适用于PDE轨迹数据集的接入与契约核验任务，是神经PDE工作流的第一步。核心目标是检查数据文件的可读性、样本完整性、变量定义、单位、坐标系、缺失值等，并生成机器可读的数据清单和契约。适用于长时间多尺度PDE推进场景，以及其他需要结构化数据接入的CFD任务。

## 输入
- **数据集路径**（必填）：目录或清单文件，指向PDE轨迹数据
- **数据集名称**（必填）：描述数据来源与版本，如"长时间多尺度PDE轨迹"
- **数据契约**（可选）：预定义的变量、单位、网格坐标系定义

## 输出
- **dataset_manifest.json**：数据清单，包含文件列表、样本数、变量信息
- **data_contract.json**：机器可读的数据契约，定义输入输出变量、单位、坐标系
- **data_audit.md**：数据审计报告，记录检查过程和发现

## 流程节点
1. **读取数据文件** → 检查文件可读性和格式
2. **统计样本信息** → 记录样本数、时间或工况范围
3. **验证变量定义** → 确认输入与目标变量的单位、坐标系
4. **检查网格拓扑** → 验证网格坐标和拓扑结构
5. **检测缺失值** → 识别和记录数据缺失情况
6. **核验使用许可** → 确认数据使用权限
7. **生成契约** → 输出结构化数据契约

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必填输入 | DATASET_PATH, DATASET_NAME | 场景需求书 | 缺少时返回BLOCKED |
| 可选输入 | DATA_CONTRACT | 场景需求书 | 预定义契约定义 |
| 输出格式 | JSON + Markdown | 场景需求书 | 机器可读+人类可读 |
| 质量门禁 | 3项检查 | 场景需求书 | 可读性、完整性、无泄漏 |

## 边界与分流
- **数据不可读**：文件格式错误或权限不足时，返回BLOCKED并说明原因
- **变量定义缺失**：缺少必要的输入或目标变量定义时，返回BLOCKED并列出缺项
- **坐标系不明确**：无法确定网格坐标系时，需用户补充说明
- **缺失值过多**：缺失比例超过阈值时，需评估数据质量是否满足训练要求

## 质量检查
- 数据文件可读且样本可追溯
- 输入目标变量单位坐标定义完整
- 不存在训练测试泄漏
- 缺失值比例在可接受范围内
- 数据使用许可明确

## 回退策略
- 文件不可读：检查路径和权限，或请求用户重新提供数据
- 变量定义不完整：请求用户补充数据契约定义
- 坐标系不明确：请求用户提供坐标系说明或参考标准
- 数据质量不足：返回BLOCKED，建议用户进行数据清洗

## 资源召回建议
- 需要具体数据格式规范时，可召回数据标准化相关卡片
- 需要坐标系定义标准时，可召回CFD网格规范卡片
- 需要缺失值处理方法时，可召回数据清洗相关卡片
