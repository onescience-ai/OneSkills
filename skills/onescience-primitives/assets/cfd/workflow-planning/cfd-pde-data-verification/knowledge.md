# PDE场数据接入与契约核验

## 适用范围

**触发条件**：
- 需要接入多尺度高频PDE场数据进行算子学习
- 需要建立数据清单并核验完整性
- 需要定义数据契约（输入字段、目标字段、单位、坐标系）

**适用场景**：
- 算子学习工作流的数据准备阶段
- 需要确保数据可追溯性与质量
- 需要避免训练测试泄漏

**不适用场景**：
- 数据已完全验证且契约已定义
- 非PDE场数据的简单回归任务

## 输入

**必填输入**：
- {DATASET_PATH}：数据集路径（目录或清单文件）
- {DATASET_NAME}：数据集名称（来源与数据版本）

**可选输入**：
- {DATA_CONTRACT}：数据契约（变量单位网格定义）

## 输出

**产物清单**：
- dataset_manifest.json：数据清单
- data_contract.json：数据契约
- data_audit.md：数据审计报告

## 流程节点

### 操作步骤
1. 读取{DATASET_PATH}中的{DATASET_NAME}
2. 检查文件可读性、样本数
3. 核验输入与目标变量、单位、坐标系、网格拓扑
4. 检查时间或工况范围、缺失值和使用许可
5. 按{DATA_CONTRACT}输出机器可读契约
6. 缺少必填输入时返回BLOCKED并列出缺项

### 关键参数
- 输入变量：文件路径、数据集名称
- 输出格式：JSON（清单、契约）、Markdown（审计报告）
- 验证内容：文件可读性、样本数、变量定义、单位、坐标、许可

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据契约结构 | input_fields, target_fields, units, coordinates | [场景S055] | 标准数据契约格式 |
| 必填验证项 | 文件可读性、样本数、变量定义 | [场景S055] | 数据完整性检查 |
| 坐标系 | dataset_native | [场景S055] | 默认使用数据集原生坐标系 |

## 边界与分流

**异常处理**：
1. 数据文件不可读 → 返回BLOCKED，列出缺项
2. 变量定义不完整 → 返回BLOCKED，要求补充
3. 单位不一致 → 返回BLOCKED，要求统一
4. 使用许可缺失 → 返回BLOCKED，要求确认

## 质量检查

**验证点**：
- 数据文件可读且样本可追溯
- 输入目标变量单位坐标定义完整
- 不存在训练测试泄漏

**失败处理**：
- 任一验证点不通过 → 返回BLOCKED，列出具体缺项

## 回退策略

**替代方案**：
- 数据质量严重不足 → 建议重新采集或合成数据验证
- 契约定义困难 → 提供模板或示例引导
