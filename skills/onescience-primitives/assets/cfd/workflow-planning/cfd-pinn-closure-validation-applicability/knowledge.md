# PINN闭合反演任务验收与适用域判定

## 适用范围

适用于PINN湍流闭合反演流程的最终验收阶段。必须同时评估统计误差与物理约束，执行几何或工况外推测试，明确适用域边界。不得仅凭平均误差宣称工程可用。

## 输入

- **s04后验结果**：apriori_closure/、aposteriori_fields/、solver_stability.csv
- **验收指标** {METRICS}：closure_RMSE、mean_profile_error、spectrum_error、stability_horizon
- **相对误差门限** {MAX_RELATIVE_L2}：测试集放行阈值，默认0.1
- **外推测试开关** {RUN_OOD_TEST}：是否测试域外工况，默认true

## 输出

- **evaluation.json**：完整评估结果（逐变量误差、边界误差、守恒残差、推理成本）
- **worst_cases.csv**：最差样本清单（含工况、位置、误差值）
- **applicability_report.md**：适用域报告（有效范围、域外表现、复核建议）
- **PASS_REJECT_BLOCKED.txt**：明确判定结论

## 流程节点

1. 读取s04后验结果
2. 计算逐变量统计误差（RMSE、L2范数、最大误差）
3. 计算边界误差（壁面、入口、出口）
4. 计算守恒或方程残差
5. 识别最差样本并追溯至具体工况与位置
6. 评估推理成本（时间、内存）
7. 若{RUN_OOD_TEST}=true，执行几何或工况外推测试
8. 基于{MAX_RELATIVE_L2}及物理门限给出PASS/REJECT/BLOCKED
9. 撰写适用域报告，明确限制与复核建议

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 验收指标 | closure_RMSE, mean_profile_error, spectrum_error, stability_horizon | [场景需求书s05] | 统计+物理指标 |
| 相对误差门限 | 0.1 | [场景需求书s05] | 相对L2范数 |
| 外推测试 | true | [场景需求书s05] | 几何或工况外推 |
| 判定阈值 | PASS/REJECT/BLOCKED | [场景需求书s05] | 明确三态结论 |

## 边界与分流

- 统计误差通过但物理约束不满足 → REJECT（物理一致性优先）
- 平均误差通过但最差样本超限 → REJECT或标注适用域限制
- 域外测试表现显著下降 → 明确标注适用域边界，建议CFD复核
- 数据不足以支撑外推测试 → BLOCKED，补充数据后重试

## 质量检查

- 统计与物理指标同时报告（不可只报误差不报约束）
- 最差样本可追溯（含工况、位置、误差值）
- 结论含适用域限制与复核建议（不可仅凭平均误差宣称可用）

## 回退策略

- 验收不通过：返回s03调整训练策略，或返回s04调整耦合方式
- 适用域不明：扩大外推测试范围，或标记为需进一步验证
- 外推测试失败：明确标注域外工况需CFD复核
