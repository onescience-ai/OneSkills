# 图网络翼型非结构网格RANS场预测工作流

## 适用范围
本卡定义从数据到评估的完整五步流水线，适用于使用图神经网络在非结构网格上预测翼型RANS流场的任务。每步有明确的输入输出契约、质量门禁和异常处理路径。

## 输入
| 输入 | 步骤 | 说明 |
|------|------|------|
| {DATASET_PATH} | s01 | 数据集目录或清单文件 |
| {DATASET_NAME} | s01 | 数据集名称与版本 |
| {DATA_CONTRACT} | s01 | 变量单位网格定义（可选） |
| {SPLIT_CONFIG} | s02 | 切分比例与分组策略 |
| {TARGET_FIELDS} | s02 | 待预测物理量列表 |
| {NONDIMENSIONALIZE} | s02 | 是否无量纲化 |

## 流程节点

### s01 数据接入与契约核验
**操作**：读取数据集，建立数据清单，检查文件可读性、样本数、输入目标变量、单位、坐标系、网格拓扑、工况范围、缺失值和使用许可。

**质量门禁**：
- 数据文件可读且样本可追溯
- 输入目标变量单位坐标定义完整
- 不存在训练测试泄漏

**异常处理**：缺少必填输入时返回BLOCKED并列出缺项，不得编造数据。

### s02 预处理与数据切分
**操作**：依据s01契约完成质控、图构建、掩膜、归一化或无量纲化。以几何、完整轨迹或物理工况为单位切分。

**参数**：
- 默认切分比：train 0.7 / validation 0.15 / test 0.15
- 默认种子：42
- 分组策略：group_by geometry_or_trajectory

**质量门禁**：
- 三份切分的对象轨迹互斥
- 仅用训练集计算变换统计量
- 边界与掩膜语义未破坏

**异常处理**：同一轨迹帧不得随机打散，必须整体归入同一切分。

### s03 模型配置与训练
**操作**：加载s02切分与统计量，使用GNN训练。记录代码版本、依赖、随机种子、逐轮指标与最佳权重。

**参数**：
- 框架：PyTorch
- 默认轮数：100
- 默认批大小：8
- 默认学习率：0.001
- 早停耐心：15轮
- 随机种子：42

**质量门禁**：
- 训练验证损失均为有限值
- 最佳权重可重新加载
- 配置环境随机种子可复现

**异常处理**：若提供{INIT_CHECKPOINT}须检查结构兼容性；缺少必填输入返回BLOCKED。

### s04 批量推理与物理恢复
**操作**：在独立测试集上推理，反归一化并恢复物理单位、坐标网格、边界掩膜及任务派生量。

**质量门禁**：
- 预测无NaN或Inf且形状单位正确
- 每个测试样本有唯一结果
- 推理未使用测试目标校正

**异常处理**：禁止用测试标签修正预测。

### s05 任务验收与适用域判定
**操作**：按指标评价结果，报告逐变量误差、边界误差、守恒残差、最差样本和推理成本。执行几何或工况外推测试。

**判定标准**：
- PASS：统计与物理指标均满足门限
- REJECT：任一指标超标
- BLOCKED：缺少必要输入或数据

**质量门禁**：
- 统计与物理指标同时报告
- 最差样本可追溯
- 结论含适用域限制与复核建议

## 边界与分流
- **数据集格式不匹配**：非标准网格格式需先转换为图结构表示。
- **训练不收敛**：检查数据质量、调整超参、简化模型。
- **推理精度不足**：增加数据、调整图构建、引入物理约束。
- **域外工况**：回退到CFD复核。

## 质量检查
| 检查点 | 判据 | 失败处理 |
|--------|------|----------|
| 每步输出完整性 | 所有规定产物存在 | 定位缺失产物，回退重做 |
| 门禁通过率 | 全部门禁通过 | 不得跳过门禁进入下一步 |
| 可复现性 | 环境与种子记录完整 | 补充environment.txt |

## 回退策略
- 任一步骤失败：检查上游产物，定位根因后重做该步
- 全流程失败：回退到数据接入，检查数据集完整性
