# 李代数正规化 — 任意Lie群等变神经算子

## 适用范围

本卡片服务于任意Lie群下等变神经算子的设计与实现。当PDE的对称群不是常见的SO(2)/SE(2)，而是更一般的Lie群（如SO(3)、SU(2)、SL(2,R)等）时，李代数正规化提供了一种统一的框架，将任意Lie群的等变性约化为李代数层面的规范化操作。适用于：需要处理任意连续对称群的PDE预测；对称群未知或需自动发现的场景；需要统一处理多种对称群的通用框架。不适用于：离散对称群（如晶体群）；无穷维对称群（如微分同胚群）；对称群结构过于复杂无法解析表示的场景。

## 输入

- 目标Lie群G的结构信息（或从数据中推断）
- 等变网络的基架构（如CNN、GNN等）
- 群表示的基底选择

## 输出

- 李代数正规化后的等变层定义
- 群变换的李代数表示矩阵
- 等变性验证报告

## 流程节点

1. **Lie群识别** → 从PDE方程或数据中识别对称群G
2. **李代数提取** → 提取G的李代数g及其结构常数
3. **正规化映射** → 构建从任意群表示到标准李代数表示的映射
4. **等变层设计** → 基于正规化李代数设计等变卷积/线性层
5. **数值验证** → 验证网络输出在群变换下满足等变性
6. **泛化测试** → 测试对不同Lie群的适应性

## 边界与分流

- **对称群未知**：先通过李群分析或数据驱动方法识别群结构
- **群维度过高（>10）**：计算复杂度过高，考虑降维或近似方案
- **离散对称群**：不适用李代数正规化，改用标准等变网络
- **等变性验证失败**：检查李代数提取和正规化映射的正确性

## 质量检查

- 李代数提取正确反映原群结构
- 正规化映射保持群表示的忠实性
- 数值验证等变性误差<1e-6
- 对不同Lie群具有泛化能力

## 回退策略

- 李代数提取困难：使用已知的标准群（如SO(2)）作为近似
- 正规化映射不稳定：使用更保守的群表示基底
