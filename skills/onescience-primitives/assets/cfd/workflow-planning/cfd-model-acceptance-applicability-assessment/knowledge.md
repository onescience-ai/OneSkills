# CFD模型验收与适用域判定

## 适用范围

**触发条件**：
- 已完成流场重构推理（Step 4），重构场与误差场已生成
- 需要按多维指标综合评估模型质量
- 需要明确适用域边界，给出工程可用性结论

**适用场景**：
- CFD流场补全任务的最终验收评估
- 模型在不同工况/几何下的泛化能力评估
- 域外工况（OOD）测试与适用域边界划定
- 工程可用性判定与复核建议生成

**不适用场景**：
- 流场重构未完成（需先执行推理步骤）
- 仅需快速原型验证（不需要正式验收）

## 输入

| 输入项 | 格式 | 必填 | 说明 |
|--------|------|------|------|
| {METRICS} | 列表 | 是 | 验收指标列表 |
| {MAX_RELATIVE_L2} | 浮点数 | 否 | 相对误差门限，默认0.1 |
| {RUN_OOD_TEST} | 布尔 | 否 | 是否执行域外测试，默认true |

## 输出

| 输出项 | 格式 | 说明 |
|--------|------|------|
| evaluation.json | JSON | 综合评估结果（逐变量误差、边界误差、守恒残差） |
| worst_cases.csv | CSV | 最差样本列表与详细误差 |
| applicability_report.md | Markdown | 适用域报告：能力边界、复核建议 |
| PASS_REJECT_BLOCKED.txt | 文本 | 最终验收结论 |

## 流程节点

### Step 5.1：统计误差评估
- **操作**：计算逐变量相对L2误差、最大误差、平均误差
- **参数**：{METRICS}中的统计指标
- **质量门禁**：逐变量误差报告完整

### Step 5.2：物理约束评估
- **操作**：计算梯度误差（场光滑性）、守恒误差（质量/动量/能量守恒）、方程残差
- **参数**：{METRICS}中的物理指标
- **质量门禁**：物理指标与统计指标同时报告

### Step 5.3：频谱分析
- **操作**：比较重构场与真实场的能量谱，评估频段匹配度
- **参数**：频谱统计
- **质量门禁**：频谱误差报告完整

### Step 5.4：最差样本分析
- **操作**：识别并详细分析误差最大的样本
- **参数**：重构结果与真实场
- **质量门禁**：最差样本可追溯

### Step 5.5：域外测试（可选）
- **操作**：在几何或工况外推条件下测试模型泛化能力
- **参数**：{RUN_OOD_TEST}
- **质量门禁**：若执行，结果明确标注适用域边界

### Step 5.6：验收结论生成
- **操作**：综合所有指标，给出PASS/REJECT/BLOCKED结论
- **参数**：{MAX_RELATIVE_L2}及任务物理门限
- **质量门禁**：结论含适用域限制与复核建议

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认验收指标 | relative_L2, spectrum_error, gradient_error, conservation_error | [场景需求书] | 多维度评估 |
| 默认相对L2门限 | 0.1 | [场景需求书] | 测试集放行阈值 |
| 默认OOD测试 | 开启 | [场景需求书] | 评估泛化能力 |
| 结论类型 | PASS/REJECT/BLOCKED | [场景需求书] | 三态结论 |

## 边界与分流

- **统计指标合格但物理指标不合格**：REJECT（物理一致性是硬约束）
- **平均误差合格但最差样本超标**：报告最差样本，不自动PASS
- **域外测试失败**：结论须含适用域限制，建议CFD复核
- **评估数据不足**：BLOCKED并说明需要更多测试数据
- **指标冲突**：统计指标与物理指标矛盾时，物理指标优先

## 质量检查

- 所有{METRICS}中的指标均已报告
- 最差样本可追溯（含样本ID与详细误差）
- 适用域报告含明确的能力边界
- 结论含复核建议
- 不仅凭平均误差宣称工程可用

## 回退策略

- 验收不通过 → 分析失败原因→针对性改进→重新训练/推理
- 适用域过窄 → 收集更多域外数据重新训练
- 物理约束不满足 → 增加物理约束权重或调整模型架构

## 资源召回建议

- 当CFD流场补全任务完成重构推理后，需要最终验收评估时召回

- 本卡为工作流最后一步，评估结果决定任务是否闭环
