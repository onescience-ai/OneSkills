# 稀疏观测数据接入与契约核验

## 适用范围

适用于稀疏实验观测数据（如PIV、LDV、热膜测量）与RANS方程数据的首次接入场景。当数据点空间分布不均匀、无法完整覆盖流场时，需要严格的契约核验以确保后续PINN训练的数据基础可靠。

## 输入

- **数据集路径** {DATASET_PATH}：目录或清单文件，指向原始数据
- **数据集名称** {DATASET_NAME}：来源与数据版本标识
- **数据契约** {DATA_CONTRACT}：可选，定义变量、单位、网格坐标的期望结构

## 输出

- **dataset_manifest.json**：数据清单（文件列表、样本数、变量名）
- **data_contract.json**：机器可读的变量/单位/坐标定义
- **data_audit.md**：数据质量审计报告（缺失值、异常值、许可信息）

## 流程节点

1. 读取数据文件，检查可读性
2. 统计样本数、变量维度、时间/工况范围
3. 核验输入与目标变量的单位、坐标系、网格拓扑
4. 检测缺失值与异常值
5. 记录数据使用许可
6. 按{DATA_CONTRACT}输出契约

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必填输入 | DATASET_PATH, DATASET_NAME | [场景需求书s01] | 缺少任一返回BLOCKED |
| 可选输入 | DATA_CONTRACT | [场景需求书s01] | 变量单位网格定义 |
| 默认数据集名称 | 稀疏实验观测与RANS方程数据 | [场景需求书s01] | 来源标识 |

## 边界与分流

- 数据文件不可读 → 返回BLOCKED，列出不可读文件清单
- 缺少必填输入变量 → 返回BLOCKED，不得编造数据、权重、工况或结果
- 变量单位坐标定义不完整 → 在data_audit.md中标注缺失项
- 存在训练测试泄漏风险 → 标注并阻止进入下一步

## 质量检查

- 数据文件可读且样本可追溯（每个样本有唯一标识）
- 输入目标变量单位坐标定义完整
- 不存在训练测试泄漏（后续步骤数据集无重叠）

## 回退策略

- 数据格式不兼容 → 尝试格式转换工具
- 缺少关键元数据 → 联系数据提供方补充
- 许可限制 → 记录限制条件，在后续步骤中遵守
