# PDE数据预处理与切分

## 适用范围
本卡片适用于PDE轨迹数据的预处理与数据切分任务，是神经PDE工作流的第二步。核心目标是统一物理量表示，按几何、工况或时间构造无泄漏切分，并保存统计量与可逆变换。适用于需要准备训练数据的神经PDE求解器开发场景。

## 输入
- **数据契约**（来自s01）：定义输入输出变量、单位、坐标系
- **切分配置**（必填）：训练/验证/测试集比例、切分策略、随机种子
- **目标变量**（必填）：待预测的物理量列表
- **无量纲化选项**（可选）：是否进行无量纲化处理

## 输出
- **train_manifest.json**：训练集清单
- **validation_manifest.json**：验证集清单
- **test_manifest.json**：测试集清单
- **normalization.json**：归一化统计量和变换参数

## 流程节点
1. **质控处理** → 检查数据质量，处理异常值
2. **重采样或图构建** → 统一数据格式，构建图结构（如需要）
3. **掩膜处理** → 处理边界和掩膜信息
4. **归一化或无量纲化** → 统一跨工况量纲
5. **无泄漏切分** → 按几何、完整轨迹或物理工况为单位切分
6. **保存统计量** → 记录变换参数，确保可逆性

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认训练比例 | 0.7 | 默认配置 | 总数据的70% |
| 默认验证比例 | 0.15 | 默认配置 | 总数据的15% |
| 默认测试比例 | 0.15 | 默认配置 | 总数据的15% |
| 默认随机种子 | 42 | 默认配置 | 切分可复现 |
| 切分单位 | geometry_or_trajectory | 默认配置 | 按几何或完整轨迹 |
| 无量纲化 | true | 默认配置 | 统一跨工况量纲 |

## 边界与分流
- **切分配置缺失**：缺少必填切分配置时，使用默认值或返回BLOCKED
- **数据泄漏风险**：同一轨迹的帧被随机打散时，需重新切分
- **统计量污染**：使用测试集数据计算变换统计量时，需重新计算
- **边界语义破坏**：掩膜或边界条件被错误处理时，需修复后重试

## 质量检查
- 三份切分的对象轨迹互斥
- 仅用训练集计算变换统计量
- 边界与掩膜语义未破坏
- 切分比例符合配置要求
- 变换参数可逆且完整保存

## 回退策略
- 切分配置不完整：使用默认配置或请求用户补充
- 数据泄漏检测：重新按正确单位切分
- 统计量污染：仅使用训练集重新计算
- 边界处理错误：修复掩膜处理逻辑后重试
