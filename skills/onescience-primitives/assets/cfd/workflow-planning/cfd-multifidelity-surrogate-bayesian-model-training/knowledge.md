# 模型配置与训练

## 适用范围

**触发条件**：
- 已完成预处理与数据切分，需要训练多保真代理模型与贝叶斯优化器
- 需要记录训练配置、随机种子、逐轮指标与最佳权重
- 需要确保训练收敛与权重可复现

**适用场景**：
- 多保真代理辅助翼型优化的模型训练阶段
- 需要训练Multi-fidelity surrogate与Bayesian optimizer
- 需要可复现的训练流程与环境记录

**不适用场景**：
- 单保真代理模型训练
- 非贝叶斯优化策略的模型训练
- 无需训练的预训练模型直接推理

## 输入

**必需输入**：
- 模型名称（实现或模型注册名）
- 训练配置（框架、epochs、batch_size、学习率、种子、早停）

**可选输入**：
- 初始权重（可选预训练权重）

**预处理要求**：
- 依赖s02的切分结果与统计量
- 检查初始权重结构兼容性（如提供）

## 输出

**核心产物**：
- best_checkpoint.pt：最佳模型权重
- train_config.json：训练配置文件
- training_metrics.csv：逐轮训练验证指标
- environment.txt：代码版本与依赖环境

**验证标准**：
- 训练验证损失均为有限值
- 最佳权重可重新加载
- 配置环境随机种子可复现

## 流程节点

### Step 1：模型初始化
- **操作**：加载s02切分与统计量，初始化多保真代理模型与贝叶斯优化器
- **参数**：模型名称、训练配置
- **工具**：PyTorch、多保真建模框架、贝叶斯优化库
- **质量门禁**：模型初始化成功，参数可访问

### Step 2：训练循环
- **操作**：执行训练循环，记录逐轮训练验证指标
- **参数**：epochs、batch_size、学习率、早停耐心值
- **工具**：训练循环框架
- **质量门禁**：损失为有限值且下降

### Step 3：最佳权重保存
- **操作**：保存最佳权重与训练配置
- **参数**：最佳权重路径
- **工具**：模型序列化工具
- **质量门禁**：权重可重新加载

### Step 4：环境记录
- **操作**：记录代码版本、依赖、随机种子
- **参数**：环境信息
- **工具**：环境记录脚本
- **质量门禁**：环境信息完整可追溯

## 边界与分流

**训练不收敛时的改道**：
- 损失出现NaN或Inf → 检查数据质量、降低学习率、调整模型结构
- 损失振荡不下降 → 增加早停耐心值、调整批量大小
- 过拟合严重 → 增加正则化、减少模型复杂度

**初始权重不兼容时的改道**：
- 结构不匹配 → 从头训练或调整模型结构
- 权重文件损坏 → 从头训练

**环境不可复现时的改道**：
- 随机种子未固定 → 重新设置种子并重训
- 依赖版本冲突 → 创建隔离环境

## 质量检查

| 检查项 | 阈值/判据 | 失败处理 |
|--------|-----------|----------|
| 损失有限性 | 所有轮次损失为有限值 | 调整超参数重新训练 |
| 权重可加载 | checkpoint可重新加载 | 检查版本兼容性 |
| 环境可复现 | 相同种子产生相同结果 | 固定随机种子 |
| 早停触发 | 验证集损失不再下降时停止 | 调整耐心值 |
| 最佳权重有效性 | 最佳权重对应最低验证损失 | 检查保存逻辑 |

## 回退策略

- 训练完全失败 → 检查数据质量、调整超参数、尝试简化模型
- 权重损坏 → 从最近的检查点恢复或重新训练
- 环境问题 → 创建新的conda环境或容器化部署
