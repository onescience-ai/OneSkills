# CFD数据无量纲化与切分规范

## 适用范围

面向CFD数据预处理任务，定义数据无量纲化标准方法以及train/val/test manifest的字段规范。适用于所有需要将物理量转换为无量纲形式并执行数据切分的CFD数据驱动预测任务。不适用于纯理论分析或不需要数据切分的任务。

## 输入

- 任务目标：对CFD数据进行无量纲化处理并执行数据切分
- 数据需求：物理量数据（速度、压力、渗透率等）和网格坐标
- 格式要求：numpy数组或VTK文件，包含物理量和坐标信息

## 输出

- normalization.json：无量纲化参数（特征值、变换统计量）
- train_manifest.json：训练集样本ID列表和切分信息
- validation_manifest.json：验证集样本ID列表和切分信息
- test_manifest.json：测试集样本ID列表和切分信息

## 流程节点

1. **选择特征尺度** → 2. **执行无量纲化** → 3. **执行数据切分** → 4. **生成manifest** → 5. **验证一致性**

### 步骤1：选择特征尺度
- 操作：确定无量纲化所需的特征尺度
- 参数：特征速度U_ref、特征长度L_ref、流体密度ρ、动力粘度μ
- 工具：任务文档、领域知识
- 质量门禁：特征尺度选择合理，符合物理实际

### 步骤2：执行无量纲化
- 操作：将物理量转换为无量纲形式
- 参数：Reynolds数Re=ρUL/μ、压力系数Cp、速度比u/U_ref
- 工具：Python numpy
- 质量门禁：无量纲化变换正确，物理意义明确

### 步骤3：执行数据切分
- 按配置{"train":0.7,"validation":0.15,"test":0.15,"seed":42,"group_by":"geometry_or_trajectory"}执行无泄漏切分
- 参数：切分比例、随机种子、分组依据
- 工具：Python sklearn
- 质量门禁：切分比例正确，无数据泄漏

### 步骤4：生成manifest
- 操作：创建manifest文件记录切分信息
- 参数：样本ID列表、切分依据、随机种子记录
- 工具：JSON生成器
- 质量门禁：manifest字段完整，可追溯

### 步骤5：验证一致性
- 操作：检查manifest文件和数据的一致性
- 参数：样本ID互斥性、数据完整性
- 工具：验证脚本
- 质量门禁：三份manifest的样本ID互斥且无重叠

## 边界与分流

### 前提1：存在明确的特征尺度
- **不成立时转向**：使用数据驱动的特征尺度选择方法，或使用固定值（如U_ref=1, L_ref=1）

### 前次2：数据切分无泄漏
- **不成立时转向**：使用更严格的分组策略，如按几何结构或工况参数分组

### 前提3：manifest字段完整
- **不成立时转向**：补充缺失字段，或使用简化manifest格式

## 质量检查

1. **无量纲化验证**：检查无量纲化后的数据范围是否合理
2. **切分比例验证**：检查train/validation/test比例是否符合配置
3. **样本ID互斥**：检查三份manifest的样本ID是否互斥
4. **数据完整性**：检查所有样本是否都被分配到某个集合
5. **可重复性验证**：使用相同随机种子重新切分，结果是否一致

## 回退策略

1. **特征尺度选择不当**：重新选择特征尺度，重新执行无量纲化
2. **切分比例错误**：重新执行数据切分，修正比例
3. **manifest字段缺失**：补充缺失字段，重新生成manifest
4. **数据泄漏**：重新设计分组策略，避免泄漏
