# 翼型阵风与跨声速流动主动控制工作流

## 适用范围

**触发条件**：
- 需要在跨声速工况下对翼型阵风载荷进行主动控制
- 目标是通过DRL或神经网络控制器实现载荷削减和气动效率提升
- 涉及激波-边界层干扰物理机制的控制问题

**适用场景**：
- RAE2822、NACA 0012等标准翼型在跨声速流动中的主动控制
- Re=10^4-10^5量级、Ma=0.4-0.85范围内的阵风载荷控制
- 合成射流（synthetic jet）或吹吸射流（blowing/suction）执行器的控制策略设计
- 需要高保真CFD验证的闭环控制系统开发

**不适用场景**：
- 低速不可压缩流动的主动控制（Ma < 0.3）
- 线性控制方法（如PID）适用的简单流动问题
- 无激波干扰的层流翼型控制

## 输入

| 数据类型 | 格式要求 | 来源 | 说明 |
|---------|---------|------|------|
| 翼型几何参数 | 点坐标(x/c, y/c)或参数化表达式 | 用户提供或标准翼型数据库 | RAE2822/NACA 0012等 |
| 流动工况 | Re, Ma, α, 攻角 | 用户定义 | 跨声速范围Ma=0.4-0.85 |
| 阵风模型 | 速度时间序列u_g(t) | 用户定义或(1-cosine)模型 | 阵风强度、持续时间、波长 |
| 传感器配置 | 壁面压力测点位置 | 用户定义 | 用于状态观测 |
| 执行器配置 | 射流位置、几何参数 | 用户定义 | 上表面固定位置 |

## 输出

| 产物 | 格式 | 验证标准 |
|------|------|---------|
| DRL控制策略网络 | PyTorch/TensorFlow模型 | 收敛性验证，奖励曲线稳定 |
| 控制前后气动系数对比 | CSV表（Cd, Cl, L/D） | 载荷削减率>10% |
| 流场可视化 | VTK/CGNS | 激波位置、分离区变化 |
| 训练指标 | CSV（episode, reward, loss） | 训练稳定性评估 |

## 流程节点

### Step 1：翼型几何建模与网格生成
- **操作**：定义翼型几何参数，生成CFD计算网格
- **参数**：翼型类型、网格密度、边界层分辨率（y+<1）
- **工具**：Gmsh、ANSYS Meshing、OpenFOAM snappyHexMesh
- **质量门禁**：网格无关性验证，升阻系数变化<2%

### Step 2：跨声速流动基准计算
- **操作**：求解无控制状态下的跨声速流动
- **参数**：求解器选择（可压缩RANS/LES）、湍流模型（SA/k-ω SST）、时间推进方案
- **工具**：OpenFOAM（rhoSimpleFoam/sonicFoam）、高阶DG求解器
- **质量门禁**：流场收敛，激波位置与文献数据偏差<5%

### Step 3：阵风条件建模
- **操作**：生成阵风速度时间序列
- **参数**：阵风模型（(1-cosine)/离散阵风）、强度、持续时间
- **工具**：Python脚本生成
- **质量门禁**：阵风能量谱与目标一致

### Step 4：DRL控制器训练
- **操作**：定义MDP（状态/动作/奖励），训练DRL智能体
- **参数**：
  - 状态空间：壁面压力传感器观测（维度=测点数）
  - 动作空间：合成射流速度（连续/离散）
  - 奖励函数：R = -(ΔCd + λ·ΔCl) + η·penalty（载荷削减-能耗惩罚）
  - 算法：PPO/SAC/TD3
- **工具**：Stable-Baselines3、Ray RLlib
- **质量门禁**：奖励曲线收敛，策略稳定性验证

### Step 5：闭环部署与滚动仿真
- **操作**：将训练好的控制器部署到CFD仿真中进行闭环测试
- **参数**：控制频率、采样时间、滚动窗口长度
- **工具**：OpenFOAM + 控制器接口
- **质量门禁**：控制效果与开环相比改善>10%

### Step 6：物理一致性评估
- **操作**：验证控制策略的物理合理性
- **参数**：能量守恒、质量守恒、边界条件满足
- **工具**：后处理脚本
- **质量门禁**：无非物理解出现

## 边界与分流

| 条件 | 处理方式 |
|------|---------|
| Ma > 0.85（强激波） | 使用可压缩求解器，增加激波捕捉精度 |
| Re < 10^4（层流主导） | 使用DNS或高精度LES，避免过度湍流建模 |
| 传感器噪声大 | 增加滤波层或使用鲁棒控制策略 |
| 执行器响应延迟 | 在状态空间中增加延迟状态 |
| 训练不收敛 | 调整奖励函数权重、增加课程学习 |

## 质量检查

| 检查点 | 阈值 | 失败处理 |
|--------|------|---------|
| 网格无关性 | 升阻系数变化<2% | 增加网格密度 |
| 基准流动收敛 | 残差下降3个数量级 | 调整松弛因子 |
| DRL训练收敛 | 奖励曲线平稳 | 调整超参数 |
| 控制效果 | 载荷削减>10% | 重新设计控制器 |
| 物理一致性 | 无非物理解 | 检查边界条件 |
