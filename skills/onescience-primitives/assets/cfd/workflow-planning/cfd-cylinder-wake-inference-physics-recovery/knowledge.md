# 圆柱绕流推理与物理恢复

## 适用范围
使用训练好的自回归模型在独立测试集上进行批量推理，将模型输出反归一化并恢复原始物理单位、坐标网格、边界掩膜及任务派生量。适用于圆柱绕流等CFD时序预测任务的推理阶段。

## 输入
- 模型权重（{CHECKPOINT}）：通过训练门限的权重文件
- 计算设备（{DEVICE}）：CPU或CUDA设备
- 推理批大小（{BATCH_SIZE}，默认8）：按显存调整
- 测试集清单（来自s02）
- 归一化统计量（normalization.json）
- 数据契约（data_contract.json）

## 输出
- 推理结果目录（predictions/）
- 推理清单（inference_manifest.json）
- 耗时记录（timing.csv）

## 流程节点
```
s04 批量推理与物理恢复
  操作：
    1. 加载{CHECKPOINT}及训练时数据契约
    2. 在s02独立测试集上以{DEVICE}和{BATCH_SIZE}推理
    3. 反归一化并恢复物理单位、坐标网格、边界掩膜及任务派生量
    4. 保存逐样本结果和耗时
    5. 禁止用测试标签修正预测

  参数：{CHECKPOINT}, {DEVICE}, {BATCH_SIZE}
  质量门禁：
    - 预测无NaN或Inf且形状单位正确
    - 每个测试样本有唯一结果
    - 推理未使用测试目标校正
```

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 推理数据集 | 独立测试集（来自s02） | 场景需求书s04 | 不得使用训练集或验证集 |
| 物理恢复 | 反归一化 + 单位恢复 + 网格映射 | 场景需求书s04 | 需保证形状、单位、坐标正确 |
| 禁止校正 | 不得用测试标签修正预测 | 场景需求书s04 | 保持预测独立性 |

### 校准数值
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认设备 | cuda | 场景需求书s04 | 以下数值来自场景默认配置，其他体系需以自身证据重新锚定 |
| 默认batch_size | 8 | 场景需求书s04 | |

## 边界与分流
- checkpoint不可加载时检查文件完整性和模型结构兼容性
- 推理出现NaN/Inf时REJECT并检查预处理或模型权重
- 显存不足时降低BATCH_SIZE
- 物理恢复后单位不匹配时检查归一化统计量

## 质量检查
- 预测无NaN或Inf且形状单位正确
- 每个测试样本有唯一结果
- 推理未使用测试目标校正
- 耗时记录完整

## 回退策略
- 推理失败时检查checkpoint和数据契约一致性
- 物理恢复异常时回退到归一化空间评估
- 设备不可用时回退到CPU推理
