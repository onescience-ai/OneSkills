# 球面向量场数据格式与接入协议

## 适用范围

面向球面向量场与三维对称PDE数据接入任务，当需要理解数据格式规范、寻找公开数据集或设计数据接入流程时召回本卡片。

## 输入

- 数据来源：公开数据集、用户自有数据
- 数据类型：球面网格上的向量场（速度、位势高度等）
- 格式偏好：NetCDF、HDF5等科学数据格式

## 输出

- 数据契约（data_contract.json）
- 数据清单（dataset_manifest.json）
- 数据质量报告

## 流程节点

1. 识别数据格式 → 2. 验证数据完整性 → 3. 建立数据契约 → 4. 接入数据

### 步骤1：识别数据格式
- 操作：检查数据文件扩展名和内部结构
- 参数：文件路径、格式类型
- 工具：Python netCDF4/h5py库
- 质量门禁：格式识别正确

### 步骤2：验证数据完整性
- 操作：检查变量、维度、单位、缺失值
- 参数：数据文件、验证规则
- 工具：Python数据验证脚本
- 质量门禁：数据完整，无缺失关键变量

### 步骤3：建立数据契约
- 操作：定义输入输出变量、单位、坐标系
- 参数：验证后的数据结构
- 工具：JSON生成
- 质量门禁：契约完整，可机器解析

### 步骤4：接入数据
- 操作：读取数据并准备训练
- 参数：数据契约、切分配置
- 工具：Python数据加载
- 质量门禁：数据加载成功，可训练

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 常用格式 | NetCDF4、HDF5 | 通用知识 | 科学数据标准格式 |
| 球面变量 | 经纬度、时间、向量分量 | 通用知识 | 球面向量场基本变量 |
| 单位规范 | SI单位制 | 通用知识 | 国际单位制 |

### 校准数值
以下数值来自典型球面数据集，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 经纬度范围 | [-180, 180]度, [-90, 90]度 | 通用知识 | 全球球面覆盖 |
| 时间步长 | 小时/天 | 通用知识 | 根据数据集分辨率 |
| 网格类型 | 经纬度网格、正则网格 | 通用知识 | 球面离散化方式 |

## 边界与分流

- 如果数据格式未知，需先进行格式探测
- 如果数据不完整，需联系数据提供方补充
- 如果数据单位不统一，需进行单位转换

## 质量检查

- 验证变量名与契约一致
- 验证单位转换正确
- 验证坐标系定义准确

## 回退策略

- 如果格式不支持，可尝试转换为支持格式
- 如果数据缺失严重，可考虑使用合成数据（需标注）

- 当需要了解科学数据格式时召回本卡片
