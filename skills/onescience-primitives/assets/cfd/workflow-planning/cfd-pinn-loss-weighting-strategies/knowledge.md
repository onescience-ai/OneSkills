# PINN 损失权重平衡策略

## 适用范围

**触发条件**：
- PINN 训练中多个损失项（数据项、PDE 残差、边界条件、初始条件）竞争导致收敛困难
- 需要自动确定各损失项的相对权重
- 静态权重调参耗时且难以迁移到不同工况

**适用场景**：
- 不可压缩 NS 方程 VP/VV 表述的多目标训练
- 多物理场耦合 PDE 的联合优化
- 从简单流（低 Re）到复杂流（高 Re、非稳态）的权重策略迁移

**不适用场景**：
- 单目标纯数据驱动训练（无需物理约束权重）
- 已有成熟解析解可直接监督的简单问题

## 输入

- **损失项列表**：L_data（数据拟合）、L_PDE（方程残差）、L_BC（边界条件）、L_IC（初始条件）
- **训练配置**：epoch 数、优化器类型、学习率调度
- **流场特征**：Reynolds 数、流动复杂度、边界条件类型

## 输出

- **权重方案**：各损失项的权重值或权重更新规则
- **训练曲线**：各损失项的逐 epoch 变化和总损失收敛曲线
- **权重敏感性报告**：不同权重配置下的精度对比

## 流程节点

### 方法 1：静态权重手动调参
- **操作**：为每个损失项分配固定权重 λ_i，通过网格搜索或经验确定
- **参数**：典型初始权重 λ_PDE=1, λ_data=1, λ_BC=10~100（边界权重通常更大）
- **工具**：手动调参、小规模网格搜索
- **质量门禁**：各损失项在同一数量级，无一项主导总损失 [1]
- **局限**：权重需针对每个新问题重新调参，泛化性差

### 方法 2：基于 MLE 的自适应权重（lbPINN）
- **操作**：建立高斯概率模型，将噪声参数 σ_i 的倒数作为权重 w_i = 1/σ_i^2，通过最大似然估计逐 epoch 更新 σ_i
- **更新规则**：σ_i^2(epoch+1) = σ_i^2(epoch) + α · (∂L_i/∂σ_i)（α 为学习率）
- **参数**：初始 σ_i 值（对结果不敏感）、更新学习率 α
- **工具**：自动微分 + 自定义优化器
- **质量门禁**：
  - 各损失项权重在训练过程中自动调整，无手动干预
  - 对初始化选择具有鲁棒性 [2]
  - 验证精度优于静态权重
- **优势**：无需手动调参，适用于多工况迁移

### 方法 3：梯度归一化/GradNorm
- **操作**：基于各损失项梯度的范数动态调整权重，使各梯度量级平衡
- **权重更新**：w_i(t+1) = w_i(t) · (∥∇L_PDE∥/∥∇L_i∥)^α
- **参数**：平衡强度 α（通常 0.5~1.5）
- **质量门禁**：各损失梯度范数在训练中期趋于一致 [3]

### 方法 4：多任务动态权重分配（UniPINN）
- **操作**：在多流/多任务场景下，使用注意力机制选择性增强相关模式，动态权重分配平衡异构流态的损失贡献
- **参数**：任务间注意力权重、损失贡献均衡系数
- **质量门禁**：跨任务负迁移被抑制，各任务精度平衡 [3]

## 关键参数

### 通用判据

| 参数 | 推荐值 | 来源 | 说明 |
|------|--------|------|------|
| 静态边界权重 λ_BC | 10~100 | [1] | 边界约束通常需要更大权重 |
| 静态 PDE 权重 λ_PDE | 1 | [1] | 作为基准 |
| 自适应初始 σ | 1.0 | [2] | 对结果不敏感 |
| 自适应更新学习率 α | 0.01~0.1 | [2] | 过大会振荡，过小收敛慢 |
| 梯度归一化强度 | 0.5~1.5 | [3] | α=1 为完全均衡 |

### 校准数值

以下数值来自特定基准体系，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| Kovasznay 流最佳权重(静态) | λ_PDE=1, λ_BC=10, λ_data=1 | [2] | 2D 稳态基准 |
| 圆柱绕流权重范围 | λ_BC: 10~100 | [1] | 非稳态涡脱落 |
| Beltrami 流自适应收敛 | ~5000 epochs | [2] | 3D 非稳态 |
| lbPINN 相对精度提升 | 10%~30% vs 静态 | [2] | 在 Kovasznay/cylinder/Beltrami 上 |
| UniPINN 多任务学习 | 3 flow regimes | [3] | 共享+专用架构 |

## 边界与分流

| 前提 | 不成立时改道 |
|------|-------------|
| 损失项之间存在竞争 | 若仅有一项主导，静态权重即可 |
| 训练规模允许在线更新 | 使用离线网格搜索预调权重 |
| 多工况/多任务场景 | 升级为 UniPINN 等多任务框架 |

## 质量检查

- 各损失项权重不应相差超过 3 个数量级
- 自适应权重应在训练中期稳定，而非持续漂移
- 最终权重配置应通过交叉验证确认泛化性

## 回退策略

- 自适应权重不收敛：降低更新学习率 → 使用梯度裁剪 → 回退静态权重
- 边界误差仍大：单独提升 λ_BC → 改用硬边界条件
- PDE 残差不降：增加配点数 → 使用更小学习率
