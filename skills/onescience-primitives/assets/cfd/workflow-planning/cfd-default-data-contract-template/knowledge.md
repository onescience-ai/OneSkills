# CFD缺失区补全场景默认数据契约模板

## 适用范围

**触发条件**：
- 用户未提供数据契约
- 需要自动生成占位数据契约
- 需要确保后续步骤有标准契约可用

**适用场景**：
- CFD缺失区补全任务的数据准备阶段
- 使用公开数据集时的契约生成
- 无用户输入时的应急契约生成

**不适用场景**：
- 用户已提供完整数据契约
- 需要自定义变量或单位的场景
- 非CFD领域的数据契约

## 输入

- 场景标准定义（变量、单位、坐标系）
- 公开数据集元信息（如可用）
- 数据契约模板

## 输出

- data_contract.json：默认数据契约文件
- 变量映射表（输入变量、目标变量）
- 单位定义（SI制）
- 坐标系和网格拓扑定义

## 流程节点

### Step 1：场景标准提取
- **操作**：从场景标准工作流中提取默认值
- **参数**：变量列表、单位映射、坐标系定义
- **工具**：配置提取器
- **质量门禁**：场景标准存在且包含默认值

### Step 2：契约模板生成
- **操作**：基于模板生成默认数据契约
- **参数**：模板结构、必填字段、可选字段
- **工具**：模板填充器
- **质量门禁**：模板包含所有必填字段

### Step 3：变量定义
- **操作**：定义标准变量名和物理含义
- **参数**：变量名（x,y,z,t,u,v,w,p,T）、物理含义、数据类型
- **工具**：变量定义器
- **质量门禁**：变量名符合物理规范

### Step 4：单位定义
- **操作**：定义所有变量的SI单位
- **参数**：变量名、单位、单位转换规则
- **工具**：单位转换器
- **质量门禁**：单位为SI制，转换规则正确

### Step 5：坐标系定义
- **操作**：定义坐标系类型和维度
- **参数**：坐标系类型（笛卡尔）、维度（2D/3D）、网格拓扑
- **工具**：坐标系定义器
- **质量门禁**：坐标系定义完整

### Step 6：契约验证
- **操作**：验证生成的数据契约
- **参数**：契约完整性、格式正确性、字段一致性
- **工具**：契约验证器
- **质量门禁**：契约通过验证

## 边界与分流

- **场景标准缺失**：使用最简化的默认契约（仅包含基本变量）
- **变量名冲突**：使用场景标准中的变量名，记录冲突
- **单位转换错误**：强制使用SI制，保留原始单位作为参考
- **坐标系不匹配**：使用笛卡尔坐标，记录坐标系转换规则
- **契约验证失败**：修复错误后重新验证

## 质量检查

- 契约文件JSON格式合法
- 包含所有必填变量
- 单位为SI制
- 坐标系定义完整
- 变量映射正确

## 回退策略

- 契约生成失败：使用最简化模板（仅变量名）
- 验证失败：记录错误，输出部分契约
- 无法修复：标记为占位契约，记录待确认项
- 完全失败：输出默认变量列表
