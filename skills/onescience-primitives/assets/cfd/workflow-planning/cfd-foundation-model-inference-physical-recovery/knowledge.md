# Batch Inference and Physical Recovery

## 适用范围

面向迁移后模型在独立测试集上的批量推理与物理恢复阶段，确保预测结果恢复到原始物理单位、坐标网格和边界掩膜，支持后续验收评估。适用于所有需要对迁移模型进行离线推理评估的场景。

## 输入

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| CHECKPOINT | doc | 是 | 训练完成的模型权重 |
| DEVICE | str | 是 | 计算设备（cpu/cuda） |
| BATCH_SIZE | int | 否 | 推理批大小（默认 8） |

## 输出

| 产物 | 格式 | 说明 |
|------|------|------|
| predictions/ | 目录 | 逐样本预测结果文件 |
| inference_manifest.json | JSON | 推理清单：文件索引、样本对应关系 |
| timing.csv | CSV | 逐样本推理耗时 |

## 流程节点

1. **加载模型权重** → 读取 CHECKPOINT
2. **加载数据契约** → 读取 s01 输出的 data_contract.json
3. **加载归一化参数** → 读取 s02 输出的 normalization.json
4. **构建测试集 DataLoader** → 加载 test_manifest.json
5. **批量推理** → 在 DEVICE 上以 BATCH_SIZE 批量预测
6. **反归一化** → 使用 normalization.json 恢复原始尺度
7. **恢复物理单位** → 按 data_contract.json 恢复单位
8. **恢复坐标网格** → 恢复原始网格拓扑
9. **恢复边界掩膜** → 恢复有效区域标记
10. **计算派生量** → 如 vorticity、pressure coefficient 等
11. **保存逐样本结果** → 避免大文件一次性写入
12. **记录耗时** → 逐样本记录推理时间

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 预测值 | 无 NaN/Inf | 场景需求书 | 推理结果有效性 |
| 形状单位 | 与输入一致 | 场景需求书 | 降维或升维需恢复 |
| 测试标签 | 禁止用于修正 | 场景需求书 | 避免数据泄漏 |
| 每样本唯一 | 一一对应 | 场景需求书 | 确保可追溯 |

### 校准数值
> 以下数值来自场景需求书，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认 BATCH_SIZE | 8 | 场景需求书 | 按显存调整 |
| 默认 DEVICE | cuda | 场景需求书 | GPU 加速 |

## 边界与分流

- **显存不足**：减小 BATCH_SIZE 或使用 CPU
- **权重加载失败**：检查 checkpoint 格式与版本
- **预测结果异常**：检查数据预处理是否可逆

## 质量检查

- [ ] 预测无 NaN 或 Inf 且形状单位正确
- [ ] 每个测试样本有唯一结果
- [ ] 推理未使用测试目标校正
- [ ] 推理耗时已记录

## 回退策略

- 推理 OOM → 降低 batch_size 重试
- 结果异常 → 检查数据契约与归一化参数一致性
