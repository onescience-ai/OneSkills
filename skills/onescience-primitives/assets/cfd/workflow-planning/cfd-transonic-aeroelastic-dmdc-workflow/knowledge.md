# 基于DMDc的跨声速气动弹性降阶建模工作流

## 适用范围
从高保真CFD数据生成到ROM训练、验证和应用的完整工作流。适用于跨声速气动弹性问题的降阶建模，覆盖数据准备、模型训练、推理和验证全流程。

## 输入
- 高保真CFD仿真数据（压力分布、结构模态）
- 工况定义（马赫数、攻角等）
- 结构模型参数

## 输出
- 训练好的DMD-ROM模型
- 验证报告（精度、稳定性、效率）
- 适用域评估

## 流程节点
1. **CFD数据生成** → 使用SU2等高保真CFD代码生成训练数据
2. **快照矩阵构建** → 提取压力分布构建状态矩阵和输入矩阵
3. **POD模态提取** → 通过SVD分解提取POD模态
4. **DMDc模型训练** → 使用DMDc算法训练降阶模型
5. **稳定化处理** → 区分非稳态和准稳态部分，提高模型稳定性
6. **全耦合验证** → 与结构模型耦合验证气动弹性预测能力
7. **适用域评估** → 评估模型在不同工况下的适用性

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| POD模态截断误差 | <1% | [1] | 通过奇异值选择截断点 |
| DMDc模态数 | 30 | [1] | BSCW案例最优值 |
| 训练信号类型 | 混合阶跃 | [1] | 需激励所有输入模态 |
| 时间步长 | 1ms | [1] | 与高保真仿真一致 |

## 边界与分流
- **数据不足**：增加训练工况或采用迁移学习
- **模型不稳定**：调整稳定化参数或增加模态数
- **工况外推**：构建LPV模型或采用多模型插值

## 质量检查
- 特征值稳定性：所有特征值应在单位圆内
- 压力分布精度：与高保真结果误差<5%
- 计算效率：比高保真仿真快100倍以上
- 物理一致性：压力分布应符合气动特性

## 回退策略
- 降级为线性气动弹性分析
- 使用全耦合CFD仿真验证
- 采用其他降阶方法（如ARMA、神经网络）
