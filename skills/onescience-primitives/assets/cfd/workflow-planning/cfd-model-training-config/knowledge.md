# 模型配置与训练

## 适用范围

本步骤适用于CFD流场不确定性反演工作流的第三阶段，负责配置并训练概率网络模型（Bayesian PINN、Physics-informed GAN）。当用户需要执行模型训练、记录训练过程、保存最佳权重时使用。

## 输入

- **{MODEL_NAME}**：模型名称（必填），默认Bayesian PINN、Physics-informed GAN
- **{TRAIN_CONFIG}**：训练配置（必填），含框架、超参数、随机种子
- **{INIT_CHECKPOINT}**：初始权重（可选），预训练权重路径

## 输出

- **best_checkpoint.pt**：最佳模型权重
- **train_config.json**：训练配置文件
- **training_metrics.csv**：训练过程指标（逐轮训练验证损失）
- **environment.txt**：代码版本与依赖环境

## 流程节点

1. 加载s02切分数据与统计量
2. 配置模型架构与超参数
3. 若提供{INIT_CHECKPOINT}，检查结构兼容性
4. 执行训练循环，记录逐轮指标
5. 保存最佳权重（基于验证损失）
6. 输出训练配置与环境信息

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 框架 | PyTorch | 场景需求书 | 默认 |
| 训练轮数 | 100 | 场景需求书 | 默认 |
| 批大小 | 8 | 场景需求书 | 默认 |
| 学习率 | 0.001 | 场景需求书 | 默认 |
| 随机种子 | 42 | 场景需求书 | 默认 |
| 早停耐心 | 15 | 场景需求书 | 默认 |

## 边界与分流

- **不收敛**：训练验证损失非有限值时需调整超参数或检查数据
- **权重不兼容**：{INIT_CHECKPOINT}结构不兼容时需移除或重新初始化
- **内存不足**：批大小过大时需减小或使用梯度累积

## 质量检查

- 训练验证损失均为有限值
- 最佳权重可重新加载
- 配置环境随机种子可复现

## 回退策略

- 不收敛时，调整学习率、增加早停耐心或检查数据质量
- 内存不足时，减小批大小或使用混合精度训练
