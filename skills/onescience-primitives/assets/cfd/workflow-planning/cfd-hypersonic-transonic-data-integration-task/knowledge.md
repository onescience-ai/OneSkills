# 数据接入与契约核验任务

## 适用范围

本任务描述数据驱动湍流代理模型构建的第一步：接入高超声速冷壁与跨声速机翼CFD数据，核验样本、变量、单位、网格坐标及许可，建立数据契约。这是确保后续建模工作可靠性的基础。

**适用场景**：
- 高超声速冷壁边界层CFD数据接入
- 跨声速机翼CFD数据接入
- 需要建立数据契约的CFD数据预处理
- 数据质量核验和可追溯性验证

**不适用场景**：
- 非CFD数据（如实验数据、遥感数据）
- 已建立完整数据契约的数据集
- 数据量过小无法进行统计分析

## 输入

- **{DATASET_PATH}**（必填）：数据集路径，目录或清单文件
- **{DATASET_NAME}**（必填）：数据集名称，来源与数据版本，默认"高超声速冷壁与跨声速机翼CFD数据"
- **{DATA_CONTRACT}**（可选）：数据契约，变量、单位、网格定义，默认空契约

## 输出

- **dataset_manifest.json**：数据清单，包含文件列表、样本数、变量定义
- **data_contract.json**：数据契约，变量、单位、坐标系、网格拓扑
- **data_audit.md**：数据审计报告，质量检查结果

## 流程节点

```
读取数据集 → 检查文件可读性 → 核验样本数 → 验证变量定义 → 检查单位和坐标系 → 评估网格拓扑 → 检查缺失值 → 验证使用许可 → 输出数据契约
```

### 操作步骤

1. **读取数据集**：加载{DATASET_PATH}中的{DATASET_NAME}
2. **检查文件可读性**：确认所有数据文件可正常读取
3. **核验样本数**：统计总样本数，检查是否有足够数据进行建模
4. **验证变量定义**：确认输入和目标变量名称、类型
5. **检查单位和坐标系**：验证物理量单位、坐标系定义
6. **评估网格拓扑**：检查网格类型、节点数、单元数
7. **检查缺失值**：统计缺失值比例，评估影响
8. **验证使用许可**：确认数据使用权限和限制
9. **输出数据契约**：按{DATA_CONTRACT}格式输出机器可读契约

## 边界与分流

**关键前提与分流策略**：

1. **前提：数据文件可读**
   - 不成立时：返回BLOCKED并列出不可读文件
   - 分流目标：检查文件路径、格式、权限

2. **前提：样本数充足**
   - 不成立时：若样本数过少，建议补充数据或降级为经验模型
   - 分流目标：使用公开数据集或文献数据

3. **前提：变量定义完整**
   - 不成立时：若缺少关键变量，返回BLOCKED并列出缺项
   - 分流目标：从文献中补充变量定义

4. **前提：使用许可明确**
   - 不成立时：若许可不明确，暂停使用并报告
   - 分流目标：联系数据提供方确认许可

## 质量检查

**验证点**：
- 数据文件可读且样本可追溯
- 输入目标变量单位坐标定义完整
- 不存在训练测试泄漏
- 使用许可明确

**阈值**：
- 缺失值比例：待确认（根据具体数据集）
- 样本数：待确认（根据具体数据集）

**失败处理**：
- 文件不可读：返回BLOCKED
- 样本不足：建议补充数据
- 变量缺失：返回BLOCKED
- 许可不明：暂停使用

## 回退策略

1. **文件不可读**：检查路径、格式、权限，联系数据提供方
2. **样本不足**：使用公开DNS/LES数据集或文献数据
3. **变量缺失**：从文献中补充变量定义
4. **许可不明**：联系数据提供方确认，或使用开放数据集
