# Data Intake & Contract Validation for Stochastic PDE

## 适用范围
本任务面向随机微分方程（SDE）与高维偏微分方程（PDE）求解的数据准备阶段，执行数据接入与契约核验。检查数据文件可读性、样本数、输入与目标变量、单位、坐标系、网格拓扑、时间或工况范围、缺失值和使用许可，生成机器可读的数据契约。适用于所有需要物理信息PDE求解的数据准备场景。

## 输入
- {DATASET_PATH}：数据集路径（目录或清单文件），必填
- {DATASET_NAME}：数据集名称与版本，必填
- {DATA_CONTRACT}：数据契约模板（变量、单位、网格定义），可选

## 输出
- dataset_manifest.json：数据清单
- data_contract.json：机器可读数据契约
- data_audit.md：数据审计报告

## 流程节点
```
1. 读取数据集 → 2. 检查文件可读性与样本数 → 3. 核验变量与单位定义
→ 4. 验证坐标系与网格拓扑 → 5. 检查时间/工况范围 → 6. 统计缺失值
→ 7. 确认使用许可 → 8. 生成数据契约
```

## 关键参数

### 通用判据（方法层，同类体系可参考）

| 参数 | 判据 | 说明 |
|------|------|------|
| 文件可读性 | 所有数据文件可成功加载 | 不可读则返回BLOCKED |
| 样本可追溯 | 每个样本有唯一标识 | 支持后续切分与追溯 |
| 变量定义完整性 | 输入与目标变量均有明确名称与物理含义 | 缺失则返回BLOCKED |
| 单位一致性 | 所有变量单位定义明确且一致 | 不一致需在预处理阶段统一 |
| 坐标系定义 | 空间坐标系与时间坐标系明确 | 支持后续网格构建与场恢复 |
| 网格拓扑 | 网格类型、节点数、连接关系明确 | 支持物理算子离散化 |
| 训练测试泄漏 | 无数据泄漏 | 交叉验证需在切分阶段完成 |

### 校准数值（场景专属值，供量级校准）
以下数值来自 CFD_S046 场景，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认DATASET_NAME | 随机微分方程与高维PDE样本 | 场景需求书 | 数据集默认名称 |
| 默认坐标系 | dataset_native | 场景需求书 | 使用数据集原生坐标系 |

## 边界与分流
- **数据文件不可读**：返回 BLOCKED，列出缺失文件清单
- **必填变量缺失**：返回 BLOCKED，列出缺失变量
- **单位未定义**：标记为待处理，需在预处理阶段统一
- **坐标系未定义**：标记为待确认，需用户提供
- **使用许可不明**：标记为受限，记录许可状态

## 质量检查
- 数据文件完整性检查（文件存在、格式正确、可读取）
- 样本数统计与验证
- 变量名称与类型检查
- 单位定义完整性检查
- 坐标系与网格拓扑验证
- 缺失值统计
- 使用许可确认

## 回退策略
- 数据不可读：检查文件路径、格式、权限
- 变量缺失：联系数据提供方补充定义
- 单位不一致：在预处理阶段进行单位转换
