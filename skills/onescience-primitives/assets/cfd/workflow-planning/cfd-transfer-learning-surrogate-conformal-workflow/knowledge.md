# 迁移学习代理与共形预测不确定性量化工作流

## 适用范围

**触发条件**：
- 需要跨多个车型家族利用已有CFD数据构建气动性能代理模型
- 需要对代理模型预测结果进行不确定性量化
- 需要评估模型在域外工况下的泛化能力

**适用场景**：
- 跨车型家族汽车CFD数据迁移学习
- 气动力系数与流场物理量快速预测
- 代理模型不确定性约束与可信度评估
- 域外工况识别与CFD复核决策

**不适用场景**：
- 单车型、单工况的独立代理模型构建（无需迁移）
- 无CFD参考数据的纯理论推导
- 实时在线控制等对延迟极度敏感的应用

## 输入

**数据需求**：
- 跨车型家族汽车CFD数据集（含几何、工况、物理量）
- 数据契约定义（变量、单位、坐标系、网格拓扑）
- 许可与版本信息

**数据格式**：
- 目录结构：数据集路径 + 清单文件
- 变量：输入特征（几何参数、工况条件）与目标变量（气动力系数、流场物理量）
- 单位：需统一物理量纲
- 坐标系：dataset_native 或标准化坐标

## 输出

**产物清单**：
- 迁移学习代理模型（best_checkpoint.pt）
- 共形预测不确定性区间
- 物理一致性评估报告
- 适用域判定报告（含域外工况识别）
- 可复现配置（train_config.json, environment.txt）

**验证标准**：
- 统计误差：relative_L2、RMSE
- 物理约束：conservation_residual、boundary_error
- 不确定性校准：预测区间覆盖率
- 适用域：域外工况可追溯

## 流程节点

### Step 1：数据接入与契约核验
- **操作**：接入跨车型家族汽车CFD数据，核验样本、变量、单位、网格坐标及许可
- **参数**：数据集路径、数据集名称、数据契约
- **工具**：数据读取、契约校验
- **质量门禁**：数据文件可读且样本可追溯、输入目标变量单位坐标定义完整、不存在训练测试泄漏

### Step 2：预处理与数据切分
- **操作**：统一物理量与表示，按几何、工况或时间构造无泄漏切分
- **参数**：切分配置（train/val/test比例）、目标变量、是否无量纲化
- **工具**：质控、重采样、归一化
- **质量门禁**：三份切分的对象轨迹互斥、仅用训练集计算变换统计量、边界与掩膜语义未破坏

### Step 3：模型配置与训练
- **操作**：训练Transfer learning surrogate、Conformal predictor完成指定输入到目标物理量的映射
- **参数**：模型名称、训练配置（超参数、随机种子）、初始权重
- **工具**：PyTorch框架
- **质量门禁**：训练验证损失均为有限值、最佳权重可重新加载、配置环境随机种子可复现

### Step 4：批量推理与物理恢复
- **操作**：在独立测试集推理，恢复原始单位、网格和物理派生量
- **参数**：模型权重、计算设备、推理批大小
- **工具**：推理引擎、反归一化
- **质量门禁**：预测无NaN或Inf且形状单位正确、每个测试样本有唯一结果、推理未使用测试目标校正

### Step 5：任务验收与适用域判定
- **操作**：评估统计误差、关键物理约束、泛化能力和计算收益
- **参数**：验收指标、相对误差门限、是否外推测试
- **工具**：误差分析、物理约束检查、OOD测试
- **质量门禁**：统计与物理指标同时报告、最差样本可追溯、结论含适用域限制与复核建议

## 边界与分流

**异常处理**：
- 数据文件不可读或样本不可追溯 → 返回BLOCKED并列出缺项
- 训练验证损失出现NaN或Inf → 回退调整超参数或检查数据
- 最佳权重无法重新加载 → 检查模型结构兼容性
- 预测出现NaN或Inf → 排查数据预处理或模型推理流程

**降级策略**：
- 论文证据不足时如实标注"证据有限"
- 补充通道检索失败时跳过，不阻塞主流程
- 域外工况需经CFD复核，不得仅凭平均误差宣称工程可用

**分支条件**：
- 若{RUN_OOD_TEST}为true，执行几何或工况外推测试并明确适用域
- 若统计与物理指标不同时满足，给出PASS、REJECT或BLOCKED判定

## 质量检查

**验证点**：
- 数据接入：文件可读性、样本追溯性、变量定义完整性
- 预处理：切分互斥性、统计量计算范围、掩膜语义完整性
- 模型训练：损失收敛性、权重可加载性、配置可复现性
- 推理：预测值有限性、结果唯一性、无测试标签泄漏
- 验收：误差报告完整性、最差样本可追溯性、适用域明确性

**阈值**：
- 相对L2误差 ≤ 0.1（默认）
- 守恒残差需在物理可接受范围内
- 边界误差需满足工程精度要求

**失败处理**：
- 任一质量门禁不满足则返回BLOCKED
- 最差样本需单独分析并追溯原因
- 适用域报告需明确域外工况识别标准

## 回退策略

**模型训练失败**：
- 检查数据质量与预处理流程
- 调整超参数（学习率、batch size、早停耐心）
- 尝试不同初始化权重

**推理失败**：
- 检查模型权重与数据契约一致性
- 验证反归一化流程正确性
- 排查计算设备兼容性

**验收不通过**：
- 分析最差样本特征
- 检查物理约束满足情况
- 评估是否需要更多训练数据或调整模型架构
