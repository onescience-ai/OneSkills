# PINN Evaluation Metrics and Acceptance Criteria

## 适用范围

本卡片面向物理信息神经网络（PINN）概率反演任务的验收评估，提供各指标的数学定义、阈值设定依据、多指标综合判定规则，以及标准输出产物格式规范。适用于CFD/PDE问题（热传导、波动方程、流体动力学等）的模型精度验证与不确定性量化评估。

## 输入

- 模型预测解场：u_pred(x,t)（均值与标准差）
- 参考解/真解：u_true(x,t)（解析解或高精度数值解）
- PDE控制方程参数：如热扩散系数α
- 边界条件与初始条件定义
- 配点位置信息

## 输出

- evaluation.json：各指标计算结果
- worst_cases.csv：按误差降序排列的最差样本表
- applicability_report.md：模型适用域分析报告
- PASS_REJECT_BLOCKED.txt：最终判定结论

## 流程节点

### 步骤1：相对L2误差（NRMSE）计算

**数学定义**：
```
relative_L2 = ||u_pred - u_true||₂ / ||u_true||₂
```

其中 ||·||₂ 表示L2范数（欧几里得范数）[论文1]。

**计算公式展开**：
```
relative_L2 = sqrt(Σ(u_pred_i - u_true_i)²) / sqrt(Σ(u_true_i)²)
```

**阈值设定**：
| 指标 | 优秀 | 合格 | 不合格 | 来源 |
|------|------|------|--------|------|
| relative_L2 (NRMSE) | < 0.01 | < 0.1 | ≥ 0.1 | [论文1] |

**CFD_S039案例**：NRMSE=3.055远超0.1门限，超标30倍，模型完全不合格 [报告证据]。

### 步骤2：PDE残差评估

**数学定义**：
对于一维热传导方程 ∂u/∂t = α∂²u/∂x²，PDE残差为：
```
r(x,t) = ∂u_pred/∂t - α * ∂²u_pred/∂x²
```

**均方PDE残差**：
```
MSE_PDE = (1/N) * Σ r(x_i, t_i)²
```

**阈值设定**：
| 指标 | 优秀 | 合格 | 不合格 | 来源 |
|------|------|------|--------|------|
| MSE_PDE（u∈[0,1]） | < 1e-4 | < 0.01 | ≥ 0.1 | [论文1] |
| MSE_PDE（u∈[0,10]） | < 1e-2 | < 1.0 | ≥ 10.0 | [论文1] |

**CFD_S039案例**：PDE残差均值=1.74，远超合格门限，表明物理约束未被有效学习 [报告证据]。

### 步骤3：边界误差评估

**Dirichlet边界误差**：
```
E_bc = (1/N_bc) * Σ |u_pred(x_bc) - u_bc|²
```

**阈值设定**：
| 边界类型 | 优秀 | 合格 | 不合格 |
|---------|------|------|--------|
| Dirichlet（固定值） | < 1e-4 | < 0.01 | ≥ 0.1 |
| Neumann（固定通量） | < 1e-3 | < 0.1 | ≥ 1.0 |
| Robin（混合） | < 1e-3 | < 0.1 | ≥ 1.0 |

**CFD_S039案例**：左边界误差=1.135，右边界误差=1.779，均严重超标 [报告证据]。

### 步骤4：初始条件误差

**数学定义**：
```
E_ic = (1/N_ic) * Σ |u_pred(x, 0) - u_init(x)|²
```

**CFD_S039案例**：初始条件误差=1.367，表明模型无法正确捕捉初始状态 [报告证据]。

### 步骤5：不确定性估计评估

**平均预测标准差**：
```
avg_std = (1/N) * Σ σ_pred(x_i, t_i)
```

**评估标准**：
- 平均标准差应反映数据噪声水平
- 标准差过大（如>1.0）表明不确定性估计不可靠
- 标准差过小（如<1e-6）表明模型过度自信

**CFD_S039案例**：平均预测标准差=4.476，不确定性估计完全不可靠 [报告证据]。

### 步骤6：综合判定逻辑

**PASS判定**（所有条件必须满足）：
```
relative_L2 < 0.1 AND
MSE_PDE < 0.1 AND
E_bc_left < 0.1 AND
E_bc_right < 0.1 AND
E_ic < 0.1
```

**REJECT判定**（任一条件满足）：
```
relative_L2 ≥ 0.1 OR
MSE_PDE ≥ 1.0 OR
E_bc_left ≥ 1.0 OR
E_bc_right ≥ 1.0 OR
E_ic ≥ 1.0
```

**PARTIAL判定**：
- 部分指标合格但未完全满足PASS条件
- 需要人工审查决定是否可接受

**BLOCKED判定**：
- 无法计算指标（如模型未收敛、输出缺失）
- 环境/依赖问题导致评估无法执行

**CFD_S039案例**：所有核心指标均超标，应判定为REJECT而非PARTIAL [报告证据]。

## 关键参数

### 通用判据（方法层，同类体系可参考）

| 参数 | 阈值 | 来源 | 说明 |
|------|------|------|------|
| relative_L2（NRMSE） | 0.1 | [论文1] | 相对L2误差门限 |
| MSE_PDE（u∈[0,1]） | 0.01 | [论文1] | PDE残差均方值 |
| 边界误差（Dirichlet） | 0.01 | [论文1] | 边界条件满足度 |
| 初始条件误差 | 0.01 | 通用建议 | 初始状态匹配度 |
| 平均预测标准差 | < 1.0 | [论文2] | 不确定性估计可靠性 |

### 校准数值（体系专属值）

以一维热传导问题（u ∈ [0,1], α=0.01）为例，以下数值来自NPINN+框架实测 [论文1]，供量级校准；其他体系需以自身证据重新锚定：

| 指标 | 优秀值 | 合格值 | 说明 |
|------|--------|--------|------|
| relative_L2 | 1e-3 | 1e-2 | 优秀水平可达1e-3 |
| MAE | 1e-4 | 1e-3 | 平均绝对误差 |
| MSE | 1e-8 | 1e-6 | 均方误差 |

## 边界与分流

### 指标异常处理

| 异常情况 | 处理方案 |
|---------|---------|
| relative_L2 > 10 | 模型完全失效，需重新训练 |
| PDE残差 > 100 | 物理约束未学，检查损失权重 |
| 边界误差 > 10 | 边界条件施加方式有误 |
| 标准差 > 100 | 贝叶斯推断失败，检查KL权重 |

### 降级策略

1. **无法计算NRMSE**：使用MAE或MSE作为替代指标
2. **无真解可用**：仅报告PDE残差和边界误差，标注"无参考解"
3. **计算资源不足**：使用抽样评估（10%配点）并注明抽样比例

## 质量检查

- [ ] 所有指标均按标准公式计算并记录
- [ ] 指标与门限逐项对比并得出正确结论
- [ ] worst_cases.csv按误差降序排列
- [ ] applicability_report说明模型适用域限制
- [ ] PASS_REJECT_BLOCKED.txt给出明确结论及原因

## 回退策略

1. **评估失败**：检查模型输出是否完整，重新运行推理步骤
2. **指标矛盾**：以relative_L2为主要判据，其他为辅助
3. **门限争议**：记录当前门限设定依据，提交人工审查
