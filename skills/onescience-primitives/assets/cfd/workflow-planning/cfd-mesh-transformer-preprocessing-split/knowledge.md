# 预处理与数据切分

## 适用范围

**触发条件**：
- 已有数据契约（s01输出），需要进行预处理和切分
- 需要按几何、工况或时间构造无泄漏切分
- 需要归一化或无量纲化处理

**适用场景**：
- 大规模网格Transformer流场预测的数据准备阶段
- 任何需要对PDE网格数据进行预处理和切分的场景

**不适用场景**：
- 已有预处理好的数据集
- 无需切分的单一工况数据

## 输入

| 输入 | 类型 | 必填 | 说明 |
|------|------|------|------|
| {SPLIT_CONFIG} | object | 是 | 切分配置（比例、种子、分组策略） |
| {TARGET_FIELDS} | list[str] | 是 | 待预测物理量列表 |
| {NONDIMENSIONALIZE} | bool | 否 | 是否无量纲化（默认true） |

**{SPLIT_CONFIG}默认结构**：
```json
{
  "train": 0.7,
  "validation": 0.15,
  "test": 0.15,
  "seed": 42,
  "group_by": "geometry_or_trajectory"
}
```

## 输出

| 输出 | 格式 | 说明 |
|------|------|------|
| train_manifest.json | JSON | 训练集清单 |
| validation_manifest.json | JSON | 验证集清单 |
| test_manifest.json | JSON | 测试集清单 |
| normalization.json | JSON | 归一化统计量（均值、方差等） |

## 操作流程

### 1. 质控检查
- 依据s01数据契约核验数据
- 标记异常值或缺失值
- 确认变量单位一致

### 2. 重采样或图构建
- 根据数据格式进行重采样
- 构建图结构（如需要）
- 保持网格拓扑关系

### 3. 掩膜处理
- 定义边界掩膜
- 处理内部区域
- 保持掩膜语义

### 4. 归一化或无量纲化
- 计算训练集统计量（均值、方差、最小值、最大值）
- 应用归一化或无量纲化
- 保存统计量用于反归一化

### 5. 数据切分
- 按{SPLIT_CONFIG}的group_by策略切分
- 以几何、完整轨迹或物理工况为单位
- 不得把同一轨迹的帧随机打散

### 6. 统计量保存
- 保存训练集统计量到normalization.json
- 确保可逆变换

## 质量门禁

| 门禁 | 标准 | 失败处理 |
|------|------|----------|
| 切分互斥 | 三份切分的对象轨迹互斥 | 重新切分 |
| 统计量来源 | 仅用训练集计算变换统计量 | 重新计算 |
| 边界完整 | 边界与掩膜语义未破坏 | 检查掩膜逻辑 |
| 可逆性 | 归一化可逆 | 验证反变换 |

## 边界与分流

| 情况 | 处理方式 |
|------|----------|
| 切分比例异常 | 检查配置，调整比例 |
| 统计量计算错误 | 仅用训练集重新计算 |
| 掩膜语义破坏 | 检查掩膜定义和应用逻辑 |
| 轨迹打散 | 重新按group_by策略切分 |

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 切分比例 | train:0.7/val:0.15/test:0.15 | [场景需求书] | 标准三分切分 |
| 分组策略 | geometry_or_trajectory | [场景需求书] | 按几何或轨迹切分 |
| 归一化 | 无量纲化 | [场景需求书] | 统一跨工况量纲 |
| 随机种子 | 42 | [场景需求书] | 可复现性 |

### 校准数值

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 无量纲化方法 | 待确认 | [场景需求书] | 以下数值来自CFD_S006场景，供量级校准；其他体系需以自身证据重新锚定 |
| 重采样方法 | 待确认 | [场景需求书] | 需根据实际数据确定 |

## 回退策略

1. **切分失败**：检查group_by策略，调整分组逻辑
2. **统计量错误**：仅用训练集重新计算
3. **掩膜破坏**：检查掩膜定义，重新处理
4. **轨迹打散**：严格按轨迹切分
