# 批量推理与物理恢复任务

## 适用范围
本任务适用于在独立测试集上进行批量推理，恢复原始单位、网格和物理派生量，生成壁面压力剪切与积分气动力反演结果。适用于任何需要基于壁面测量数据进行气动力反演的场景。

## 输入
- 模型权重：通过训练门限权重。
- 计算设备：CPU或CUDA设备。
- 推理批大小：按显存调整批量。

## 输出
- predictions/：预测结果目录。
- inference_manifest.json：推理清单。
- timing.csv：推理耗时。

## 流程节点
1. 加载模型权重及训练时数据契约。
2. 在独立测试集上以指定设备和批大小推理。
3. 反归一化并恢复物理单位、坐标网格、边界掩膜及任务派生量。
4. 保存逐样本结果和耗时，禁止用测试标签修正预测。

## 关键参数
### 通用判据（方法层）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 预测无NaN或Inf且形状单位正确 | true | 质量门禁 | 结果有效性 |
| 每个测试样本有唯一结果 | true | 质量门禁 | 结果完整性 |
| 推理未使用测试目标校正 | true | 质量门禁 | 公平评估 |

### 校准数值（体系专属值）
以下数值来自翼型壁面压力剪切与积分气动力联合反演场景，供量级校准；其他体系需以自身证据重新锚定。
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 计算设备 | cuda | 场景需求书 | 默认设备 |
| 推理批大小 | 8 | 场景需求书 | 默认批大小 |

## 边界与分流
- 当预测出现NaN或Inf时，需检查模型权重和输入数据。
- 当推理耗时过长时，可尝试减小批大小或使用混合精度推理。
- 当结果形状或单位不正确时，需检查数据契约和反归一化步骤。

## 质量检查
- 预测无NaN或Inf且形状单位正确。
- 每个测试样本有唯一结果。
- 推理未使用测试目标校正。

## 回退策略
- 若推理失败，可尝试重新加载模型权重或检查输入数据。
- 若结果不正确，可尝试调整反归一化参数或检查数据契约。
- 若计算资源不足，可尝试使用CPU推理或减小批大小。
