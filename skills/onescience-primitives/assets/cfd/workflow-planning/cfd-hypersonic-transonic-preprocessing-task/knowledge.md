# 预处理与数据切分任务

## 适用范围

本任务描述数据驱动湍流代理模型构建的第二步：统一物理量与表示，按几何、工况或时间构造无泄漏切分，确保训练集、验证集、测试集互斥。这是避免数据泄漏、保证模型泛化能力的关键步骤。

**适用场景**：
- 高超声速冷壁边界层CFD数据预处理
- 跨声速机翼CFD数据预处理
- 需要按几何或工况切分的数据集
- 需要无量纲化处理的多工况数据

**不适用场景**：
- 单一工况数据（无需切分）
- 已完成预处理的数据集
- 非CFD数据

## 输入

- **{SPLIT_CONFIG}**（必填）：切分配置，默认train:0.7, val:0.15, test:15, seed:42, group_by: geometry_or_trajectory
- **{TARGET_FIELDS}**（必填）：目标变量列表
- **{NONDIMENSIONALIZE}**（可选）：是否无量纲化，默认true

## 输出

- **train_manifest.json**：训练集清单
- **validation_manifest.json**：验证集清单
- **test_manifest.json**：测试集清单
- **normalization.json**：归一化统计量

## 流程节点

```
加载数据契约 → 统一物理量表示 → 按几何/工况分组 → 构造无泄漏切分 → 计算归一化统计量 → 保存变换参数
```

### 操作步骤

1. **加载数据契约**：读取s01输出的data_contract.json
2. **统一物理量表示**：按契约统一变量名称、单位
3. **按几何/工况分组**：根据{SPLIT_CONFIG}的group_by参数分组
4. **构造无泄漏切分**：按比例划分train/val/test，确保同一轨迹不跨集
5. **计算归一化统计量**：仅用训练集计算均值、标准差等
6. **保存变换参数**：保存归一化参数，确保可逆变换

## 边界与分流

**关键前提与分流策略**：

1. **前提：数据契约可用**
   - 不成立时：需返回s01重新建立数据契约
   - 分流目标：完成数据接入与核验

2. **前提：分组字段存在**
   - 不成立时：若无法按几何或工况分组，需降级为随机切分
   - 分流目标：使用随机切分，但需在报告中说明

3. **前提：无量纲化可行**
   - 不成立时：若物理量不适合无量纲化，需保持原单位
   - 分流目标：仅进行标准化（减均值除标准差）

4. **前提：切分无泄漏**
   - 不成立时：若存在数据泄漏，需重新设计切分策略
   - 分流目标：按更严格的分组方式切分

## 质量检查

**验证点**：
- 三份切分的对象轨迹互斥
- 仅用训练集计算变换统计量
- 边界与掩膜语义未破坏
- 归一化参数可逆

**阈值**：
- 切分比例误差：待确认（允许小数点后两位）
- 归一化参数保存完整：100%

**失败处理**：
- 数据泄漏：重新设计切分策略
- 归一化失败：降级为无归一化处理
- 分组字段缺失：使用随机切分

## 回退策略

1. **数据契约不可用**：返回s01重新建立数据契约
2. **分组字段缺失**：使用随机切分，报告中说明
3. **无量纲化失败**：仅进行标准化处理
4. **切分泄漏**：按更严格方式重新切分
