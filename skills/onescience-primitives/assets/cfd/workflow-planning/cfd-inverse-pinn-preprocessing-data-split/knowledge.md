# 预处理与数据切分

## 适用范围

本卡片描述物理信息神经网络稀疏观测参数反演工作流的第二步：预处理与数据切分。适用于：
- 稀疏流场观测数据的质控与重采样
- 物理量的无量纲化与归一化
- 无泄漏的训练/验证/测试集切分

**不适用场景**：
- 完整流场数据的正问题求解
- 无需切分的批量推理

## 输入

1. **切分配置** `{SPLIT_CONFIG}`：按对象工况切分
2. **目标变量** `{TARGET_FIELDS}`：待预测物理量列表
3. **无量纲化标志** `{NONDIMENSIONALIZE}`：是否统一跨工况量纲

## 输出

1. **训练集清单** `train_manifest.json`
2. **验证集清单** `validation_manifest.json`
3. **测试集清单** `test_manifest.json`
4. **归一化统计量** `normalization.json`

## 流程节点

```
质控 → 重采样/图构建 → 掩膜处理 → 归一化/无量纲化 → 按几何/工况/时间切分 → 保存统计量
```

### 详细操作

#### 1. 数据质控

**操作**：
- 检查异常值（超出物理范围）
- 识别并处理缺失值
- 验证数据一致性

**判定标准**：
- 异常值比例<1%或已处理
- 缺失值标记明确
- 数据一致性通过

#### 2. 重采样与图构建

**操作**：
- 对非均匀采样数据进行重采样
- 构建空间邻接关系（图结构）
- 保持物理拓扑结构

**判定标准**：
- 重采样后分辨率满足要求
- 图结构保持空间关系
- 无信息损失

#### 3. 掩膜处理

**操作**：
- 定义有效观测区域
- 处理边界条件区域
- 标记缺失数据区域

**判定标准**：
- 掩膜语义正确
- 边界条件区域明确
- 缺失区域标记完整

#### 4. 归一化与无量纲化

**操作**：
- 计算训练集统计量（均值、标准差、最值）
- 应用归一化变换
- 可选：无量纲化处理（基于特征尺度）

**判定标准**：
- 仅用训练集计算统计量
- 变换可逆
- 量纲统一

#### 5. 无泄漏切分

**操作**：
- 按几何、完整轨迹或物理工况为单位切分
- 不得把同一轨迹的帧随机打散
- 保存切分配置与索引

**判定标准**：
- 三份切分的对象轨迹互斥
- 切分比例符合配置
- 索引可追溯

## 边界与分流

1. **数据量不足**：样本数<最小要求 → 使用数据增强或迁移学习
2. **切分泄漏**：同一轨迹帧被打散 → 重新按轨迹切分
3. **统计量偏差**：训练集分布偏斜 → 使用分层切分
4. **量纲不一致**：不同工况量纲差异大 → 强制无量纲化
5. **边界条件复杂**：多类型边界混合 → 分别处理不同边界类型

## 质量检查

1. **切分互斥**：三份数据无重叠
2. **统计量正确**：仅用训练集计算
3. **变换可逆**：可恢复原始数据
4. **语义保持**：边界条件、掩膜语义未破坏
5. **可追溯**：切分索引与配置可追溯

## 回退策略

1. **切分泄漏** → 按轨迹重新切分
2. **统计量错误** → 重新计算并验证
3. **变换不可逆** → 调整归一化方法
4. **语义破坏** → 检查掩膜与边界处理
