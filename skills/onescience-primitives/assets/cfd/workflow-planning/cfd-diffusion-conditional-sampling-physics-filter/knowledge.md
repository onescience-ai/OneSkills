# 条件采样与物理一致性筛选

## 适用范围

适用于物理信息扩散模型训练完成后的条件采样阶段。按测试工况生成多样流场样本，通过物理残差筛选不合格样本，评估分布覆盖与多样性。该方法确保生成的流场不仅在统计上合理，而且满足物理一致性约束。

## 输入

- {CHECKPOINT}（必填）：通过训练门限的模型权重
- {DEVICE}（必填）：CPU 或 CUDA 设备
- {BATCH_SIZE}（可选）：推理批大小，默认 8

## 输出

- generated_samples/：生成的流场样本目录（含条件、随机种子、采样轨迹）
- physics_filter.json：物理筛选结果（通过/剔除标记、残差值）
- distribution_metrics.json：分布评估指标（多样性、覆盖度、分布距离）

## 流程节点

1. 加载模型权重 {CHECKPOINT}
2. 对每个测试条件，使用多个随机种子生成样本
3. 保存采样轨迹、条件参数与随机种子
4. 恢复物理量（逆归一化/逆无量纲化）
5. 计算边界残差（边界条件满足程度）
6. 计算守恒残差（质量、动量、能量守恒）
7. 计算方程残差（Navier-Stokes 方程满足程度）
8. 按残差阈值剔除不合格样本
9. 评估筛选前后的分布覆盖与多样性
10. 输出样本集、筛选结果与分布指标

## 边界与分流

- 物理筛选过于严格（通过率 <10%） → 放宽残差阈值并标注置信度降级
- 所有样本被剔除 → 检查模型训练质量，必要时重新训练
- 多样性不足（分布距离过小） → 增加随机种子数或调整采样温度
- 推理显存不足 → 减小 {BATCH_SIZE}

## 质量检查

- 样本条件与随机种子可追溯
- 多样性和真实性同时评价
- 物理筛选前后统计均报告

## 回退策略

- 物理筛选失败 → 放宽阈值并标注
- 多样性不足 → 调整采样策略
- 推理成本过高 → 减少采样数或使用加速采样技术（如 Tweedie 公式）
