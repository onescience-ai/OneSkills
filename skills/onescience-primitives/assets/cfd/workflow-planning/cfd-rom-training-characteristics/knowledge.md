# 降阶模型训练特性对比

## 适用范围

面向不同降阶建模方法的训练机制对比，帮助用户理解SVD-based方法（POD、标准DMD）与神经网络参数化降阶模型（POD-DNN、DeepONet、FNO等）在训练特性上的本质差异，并据此选择合适的训练策略和框架。本卡涵盖早停机制的适用性、优化器选择、收敛特性等关键决策点。适用于CFD降阶建模中的方法选择和训练配置决策。不适用于降阶模型的推理阶段，也不适用于CFD求解器本身的训练/优化。

## 输入

- 候选降阶方法（POD、DMD、POD-DNN、DeepONet等）
- 任务需求（精度、速度、可解释性）
- 计算资源（CPU/GPU、内存）
- 数据量（快照数、空间自由度数）

## 输出

- 方法选择建议
- 训练配置（是否需要早停、优化器类型、学习率等）
- 各方法的训练时间、内存占用对比

## 流程节点

### 方法分类与特性识别
- **SVD-based直接分解方法**（非迭代）：
  - POD：对快照矩阵进行SVD分解，一步完成训练
  - 标准DMD：构建时间移位矩阵并求解特征值问题，一步完成训练
  - 特点：无超参数需要调优、无过拟合风险、结果确定性
- **神经网络参数化方法**（迭代优化）：
  - POD-DNN：用神经网络参数化POD的时间系数演化
  - DeepONet：算子学习，用神经网络学习输入-输出映射
  - FNO（Fourier Neural Operator）：在频率域学习算子
  - 特点：需要迭代训练、超参数调优、可能过拟合

### 早停机制适用性判定
- **SVD-based方法**：早停不适用
  - 原因：SVD分解是确定性一步算法，不存在迭代过程，不存在过拟合风险
  - 错误配置：在训练配置中设置early_stopping_patience对SVD-based方法无意义
  - 正确做法：从训练配置中移除早停相关参数
- **神经网络方法**：早停必须
  - 原因：迭代优化过程中可能过拟合训练数据
  - 典型配置：early_stopping_patience=10~20，监控验证集损失
  - 正确做法：在训练流程中实现早停回调

### 框架选择决策
- **NumPy/SciPy**（适用于SVD-based方法）：
  - 优势：轻量、无需GPU、部署简单
  - 适用场景：标准POD、标准DMD、线性降阶模型
  - API：numpy.linalg.svd, scipy.linalg.eig
- **PyTorch**（适用于神经网络方法）：
  - 优势：自动微分、GPU加速、早停回调、动态计算图
  - 适用场景：POD-DNN、DeepONet、FNO、可微分降阶模型
  - API：torch.nn, torch.optim, torch.utils.data.DataLoader
  - 关键特性：torch.no_grad()用于推理、torch.utils.data用于数据加载
- **混合方案**：
  - SVD部分用NumPy，神经网络部分用PyTorch
  - 适用于POD-DNN等混合架构

### 训练配置验证
- **SVD-based方法检查项**：
  - [ ] 无early_stopping参数
  - [ ] 无learning_rate参数
  - [ ] 无optimizer参数
  - [ ] 截断阶数r为唯一主要超参数
- **神经网络方法检查项**：
  - [ ] 包含early_stopping_patience
  - [ ] 包含learning_rate
  - [ ] 包含optimizer类型选择
  - [ ] 包含batch_size
  - [ ] 包含epoch数上限

## 关键参数

### 通用判据（方法层）

| 参数 | SVD-based方法 | 神经网络方法 | 来源 | 说明 |
|------|-------------|------------|------|------|
| 训练方式 | 一步直接分解 | 迭代优化 | 领域标准 | 根本区别 |
| 早停适用性 | 不适用 | 必须 | 领域标准 | 配置错误会导致参数无效 |
| 过拟合风险 | 无（确定性） | 有（需监控） | 领域标准 | 神经网络需要正则化 |
| 超参数数量 | 1（截断阶数r） | 多个（lr, batch, epochs等） | 领域标准 | SVD方法更简单 |
| GPU加速 | 不需要 | 强烈推荐 | 领域标准 | 神经网络训练需要 |
| 结果确定性 | 确定性 | 随机性（初始化） | 领域标准 | SVD每次结果相同 |

| 参数 | SVD-based方法 | 神经网络方法 | 来源 | 说明 |
|------|-------------|------------|------|------|

## 边界与分流

- **数据量极少（< 20快照）**：SVD-based方法更稳定，神经网络方法容易过拟合
- **强非线性流动**：SVD-based线性方法精度不足，应选择神经网络方法
- **需要可解释性**：SVD-based方法的模态有明确物理意义，神经网络方法为黑箱
- **实时推理需求**：SVD-based方法推理速度更快（矩阵乘法），神经网络方法需要前向传播时间
- **可微分需求**：若需要对降阶模型进行梯度优化（如控制、反问题），必须使用PyTorch等可微分框架

## 质量检查

- [ ] 训练配置与实际算法类型匹配
- [ ] SVD-based方法无多余迭代参数
- [ ] 神经网络方法包含早停机制
- [ ] 框架选择与方法类型一致
- [ ] 训练收敛性已验证

## 回退策略

- SVD-based方法精度不足 → 切换到神经网络方法或增加截断阶数
- 神经网络训练不收敛 → 检查学习率、增加数据量、简化网络结构
- GPU内存不足 → 减小batch_size或使用梯度累积
