# 流固耦合逆向设计候选生成与约束优化

## 适用范围
流固耦合逆向设计的第四步，围绕目标性能生成候选，执行约束优化并保留完整搜索轨迹，产出设计候选和Pareto前沿。适用于任何需要从训练好的模型生成候选并进行约束优化的流固耦合逆向设计任务。

## 输入
- 模型权重（{CHECKPOINT}）：通过训练门限权重
- 计算设备（{DEVICE}）：CPU或CUDA设备
- 推理批大小（{BATCH_SIZE}）：按显存调整批量

## 输出
- 设计候选目录（design_candidates/）
- 优化历史（optimization_history.csv）
- Pareto前沿（pareto_front.json）

## 流程节点
```
s04 候选生成与约束优化
  │  1. 加载{CHECKPOINT}和数据契约
  │  2. 将{TARGET_FIELDS}解释为优化目标与约束
  │  3. 执行可复现的候选生成和优化搜索
  │  4. 保存每次评估、可行性、目标值及Pareto前沿
  │  5. 不得把代理预测直接当作高保真认证结果
  │  质量门禁：候选满足几何和物理硬约束；优化轨迹与随机种子完整；最优候选未混用测试标签
```

## 关键参数

## 边界与分流
- 候选不满足几何和物理硬约束时重新生成
- 优化搜索失败时调整约束条件或搜索策略
- 计算资源不足时降低批大小或使用CPU

## 质量检查
- 候选满足几何和物理硬约束
- 优化轨迹与随机种子完整
- 最优候选未混用测试标签
- Pareto前沿完整保存

## 回退策略
- 候选生成失败时调整搜索策略
- 优化搜索失败时放宽约束条件
- 计算资源不足时降低批大小
