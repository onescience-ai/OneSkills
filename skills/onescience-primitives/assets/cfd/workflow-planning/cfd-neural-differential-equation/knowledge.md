# CFD数据驱动预测中的Neural Differential Equation

## 适用范围

面向CFD数据驱动预测任务，定义Neural differential equation的架构选择和实现方法。适用于需要建模连续动力学系统的CFD预测任务，如多孔介质流动、湍流模拟、流体-结构相互作用等。不适用于离散事件系统或纯统计建模任务。

## 输入

- 任务目标：训练NDE模型预测CFD流动场
- 数据需求：时序或空间序列的流动场数据（速度、压力、渗透率等）
- 格式要求：numpy数组或PyTorch张量，包含时空坐标和物理量

## 输出

- NDE模型权重文件（.pth格式）
- 训练配置文件（train_config.json）
- 训练历史记录（training_metrics.csv）
- 环境依赖文件（environment.txt）

## 流程节点

1. **选择NDE架构** → 2. **定义输入输出契约** → 3. **实现ODE右端函数** → 4. **训练NDE模型** → 5. **验证模型性能**

### 步骤1：选择NDE架构
- 操作：根据任务需求选择合适的NDE架构
- 参数：Neural ODE、Neural SDE、FNO-NDE混合架构
- 工具：任务文档、领域知识
- 质量门禁：架构选择符合任务需求，计算复杂度可接受

### 步骤2：定义输入输出契约
- 操作：明确NDE模型的输入输出格式
- 输入：渗透率场K、时空坐标(x,y,z,t)
- 输出：速度场u/v、压力场p
- 质量门禁：输入输出物理意义明确，维度匹配

### 步骤3：实现ODE右端函数
- 操作：实现NDE的微分方程右端函数
- 参数：将Darcy方程或Brinkman方程嵌入ODE右端
- 工具：PyTorch、torchdiffeq库
- 质量门禁：右端函数正确实现物理约束

### 步骤4：训练NDE模型
- 操作：使用时序数据训练NDE模型
- 参数：学习率、批量大小、训练轮数、早停耐心
- 工具：PyTorch优化器、torchdiffeq求解器
- 质量门禁：训练损失收敛，验证损失不发散

### 步骤5：验证模型性能
- 操作：评估NDE模型的预测精度和泛化能力
- 参数：MAE、MSE、物理一致性指标
- 工具：评估脚本
- 质量门禁：预测精度满足要求，物理约束满足

## 边界与分流

### 前提1：存在时序或空间序列数据
- **不成立时转向**：使用CNN surrogate模型，或重新组织数据为时序格式

### 前提2：物理过程可微分
- **不成立时转向**：使用代理模型或简化物理模型，或使用强化学习方法

### 前提3：计算资源充足
- **不成立时转向**：使用更简单的模型架构，或减少训练数据规模

## 质量检查

1. **架构验证**：检查NDE架构是否正确实现
2. **输入输出验证**：检查模型输入输出维度是否匹配
3. **训练收敛性**：检查训练损失是否收敛
4. **泛化能力**：检查模型在验证集上的性能
5. **物理一致性**：检查预测结果是否满足物理约束

## 回退策略

1. **训练不收敛**：调整学习率、批量大小或模型架构
2. **过拟合**：增加正则化、减少模型复杂度或增加数据
3. **计算资源不足**：使用更简单的模型或减少数据规模
4. **物理约束不满足**：将物理约束嵌入损失函数或模型架构
