# 贝叶斯优化气动设计

## 适用范围

贝叶斯优化（Bayesian Optimization, BO）是一种序列模型优化方法，专为计算昂贵的黑箱函数设计。在气动优化中，BO通过构建高斯过程（GP）代理模型，使用采集函数（Acquisition Function）智能选择下一个评估点，以最少的CFD求解器调用次数收敛到全局最优解。本卡片覆盖单目标/多目标BO、约束处理、多保真BO与批量评估策略，适用于翼型优化、气动外形设计、多学科优化等场景。

## 输入

- **目标函数**：计算昂贵的气动性能指标（如升阻比、阻力系数），需要CFD求解器评估
- **设计空间**：连续/离散/混合变量的定义域，典型维度 5-20
- **约束条件**（可选）：等式/不等式约束（如厚度约束、应力约束）
- **初始样本**：通过实验设计（DOE）获得的初始训练集（5-20个点）
- **评估预算**：允许的CFD求解器调用总次数（典型 50-200次）

## 输出

- **最优设计点**：目标函数最大/最小化的设计变量值
- **最优目标值**：对应的气动性能指标
- **收敛历史**：每次迭代的目标函数值、约束满足情况
- **代理模型**：训练好的高斯过程模型（可用于后续分析）
- **Pareto前沿**（多目标）：非支配解集

## 流程节点

### 1. 初始化
- **实验设计**：使用拉丁超立方采样（LHS）生成初始设计点，确保空间填充性
- **初始评估**：对初始设计点进行CFD评估，建立初始训练集
- **代理模型训练**：使用初始数据训练高斯过程模型
- **质量门禁**：初始样本数 > 2×设计变量维度，GP模型交叉验证R² > 0.8

### 2. 采集函数计算
- **期望改进（EI）**：平衡探索与利用的标准选择，计算闭式表达式 [1]
  - EI(x) = E[max(f(x) - f(x⁺), 0)]，f(x⁺)为当前最优值
- **置信上界（UCB）**：通过参数β控制探索程度
  - UCB(x) = μ(x) + β·σ(x)
- **改进概率（PI）**：仅考虑改进概率，适合噪声环境
  - PI(x) = P(f(x) > f(x⁺))
- **质量门禁**：采集函数值 > 收敛阈值（1e-6），计算时间 < 1s

### 3. 候选点选择
- **单点评估**：最大化采集函数，选择最有希望的设计点
- **批量评估**：同时选择多个候选点以利用并行计算资源
  - 方法：q-EI（批量期望改进）、LOCAL penalization、Thompson sampling
- **约束处理**：使用约束EI（CEI）或拉格朗日方法
- **质量门禁**：候选点不在已有评估点附近（距离 > 设计空间长度×1%）

### 4. CFD评估与模型更新
- **目标函数评估**：使用CFD求解器计算候选点的气动性能
- **约束评估**（可选）：评估约束函数值
- **模型更新**：将新数据加入训练集，重新训练GP模型
- **质量门禁**：模型更新后预测误差 < 更新前，无数值异常

### 5. 收敛判断与终止
- **收敛标准**：
  - 目标函数相对变化 < 1e-4（连续5次迭代）
  - 采集函数最大值 < 收敛阈值
  - 达到最大评估次数
- **终止条件**：满足任一收敛标准或评估预算耗尽
- **质量门禁**：最优解的约束满足率 100%，目标函数无异常跳变

## 边界与分流

- **设计空间维度 > 20**：BO效率下降，建议使用降维（PCA、active subspaces）或切换到进化算法
- **噪声目标函数**：使用噪声GP（估计噪声方差）或增加重复评估
- **多目标优化**：使用Pareto BO（如ParEGO、EHVI）或转化为约束问题
- **离散/分类变量**：使用专用BO方法（如TPE、SMAC）或编码为连续变量
- **计算预算极小**：当预算 < 10次时，使用随机采样或响应面方法

## 质量检查

- **GP模型精度**：交叉验证R² > 0.9，预测标准差合理
- **探索充分性**：设计空间覆盖率 > 80%（基于最小距离）
- **收敛验证**：连续5次迭代目标函数变化 < 1e-4
- **约束满足**：最优解的约束违反量 < 容差（如0.1%）

## 回退策略

- **BO不收敛**：增加初始样本、调整GP超参数或切换优化算法
- **GP模型差**：使用更简单核函数、增加训练数据或使用集成GP
- **CFD发散**：检查设计点可行性、调整求解器设置或使用低保真替代
