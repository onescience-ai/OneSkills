# PDO卷积层设计 — 偏微分算子等变卷积

## 适用范围

本卡片服务于对称PDE预测中卷积层的架构设计。当需要设计保持连续群等变性的卷积层时，PDO卷积通过将偏微分算子（Partial Differential Operator）嵌入卷积核实现等变性，适用于SO(2)/SE(2)等连续对称群。两个主要变体：PDO-eConvs（2D等变卷积）和PDO-s3DCNNs（3D可转向卷积）。不适用于：离散对称群（如反射群Z2，应使用标准等变卷积）；无明显群对称性的PDE（应使用标准卷积）；计算资源极其受限场景（PDO卷积参数量较大）。

## 输入

- 目标对称群（如SO(2)、SE(2)、SO(3)）
- 输入场的维度和通道数
- 期望的感受野大小
- 计算资源约束

## 输出

- PDO卷积层定义（权重形状、群表示规格）
- 等变性验证方案
- 计算复杂度分析

## 流程节点

1. **对称群分析** → 确定PDE的连续对称群G及其李代数表示
2. **群表示选择** → 选择G的不可约表示（irreps）或忠实表示
3. **PDO核设计** → 设计偏微分算子嵌入的卷积核，满足等变性约束
4. **2D/3D变体选择** → PDO-eConvs（2D）或PDO-s3DCNNs（3D）
5. **等变性验证** → 数值验证层输出在群变换下满足等变性
6. **集成到网络** → 替换标准卷积层，构建完整等变网络

## 边界与分流

- **对称群为离散群**：不适用PDO卷积，改用标准等变卷积（如E(2)-CNN）
- **3D数据但计算受限**：使用PDO-eConvs的2D切片方案或降维处理
- **等变性验证失败**：检查群表示选择和PDO核设计是否匹配

## 质量检查

- PDO核设计满足偏微分算子等变性约束
- 数值验证输出在群变换下等变（误差<1e-6）
- 计算复杂度在可接受范围内

## 回退策略

- PDO卷积实现困难：使用标准steerable CNN作为替代
- 计算开销过大：使用轻量级PDO变体或近似等变方案
