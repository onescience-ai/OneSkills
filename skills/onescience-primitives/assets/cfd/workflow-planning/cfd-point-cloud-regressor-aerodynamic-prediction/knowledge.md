# 点云回归器空气动力学预测

## 适用范围
本卡片描述使用点云回归器（Point-cloud Regressor）完成三维几何到标量空气动力学量的回归任务。点云回归器直接处理无序三维点集，通过逐点特征提取、局部聚合与全局池化得到几何表示，最终回归目标物理量。适用于汽车、翼型、无人机等外流场体系的阻力系数（Cd）、升力系数（Cl）预测。不适用于需要网格拓扑关系的任务（应使用GNN），也不适用于全流场重构。

## 输入
- **三维点云**：汽车/翼型表面三维坐标点集（N×3），可含法向量、曲率等附加特征
- **工况参数**（可选）：雷诺数、攻角等标量参数
- **目标变量**：阻力系数Cd、升力系数Cl等标量物理量

## 输出
- 标量回归值（Cd或Cl预测）
- 逐样本预测结果与物理单位恢复
- 统计误差（relative_L2、RMSE）

## 流程节点
### 1. 数据准备
- 加载DrivAerNet/DrivAerNet++点云数据
- 检查点云完整性（无缺失坐标、无重复点）
- 按场景s02配置进行无泄漏切分（按几何单位切分）
- 归一化：对点云坐标做中心化与尺度归一化

### 2. 模型构建
- 逐点特征提取层（MLP/卷积）
- 局部聚合层（最大池化/注意力池化）
- 全局池化得到固定长度几何表示
- 回归头（全连接层）输出标量预测

### 3. 训练
- 损失函数：MSE或MAE回归损失
- 优化器：Adam（默认lr=0.001）
- 早停：验证损失15轮不降则停止
- 记录逐轮训练验证指标

### 4. 推理
- 加载最佳权重，在独立测试集推理
- 反归一化恢复物理单位
- 保存逐样本预测值

## 边界与分流
- 点云缺失坐标 → 数据不可用，返回BLOCKED
- 同一车辆跨集切分 → 切分无效，需重新按对象单位切分
- 点云噪声过大（坐标精度低） → 需预处理降噪或增加数据量
- 预测值物理量级偏差大 → 检查归一化是否正确，或回归头容量不足

## 质量检查
1. 点云输入完整性：无缺失坐标、无重复点
2. 切分无泄漏：同一几何对象不跨训练/验证/测试集
3. 训练收敛：loss曲线平滑下降，无NaN/Inf
4. 预测合理性：Cd预测值在0.2-0.5量级（典型汽车），超出则需人工审查

## 回退策略
- 点云数据不可用 → 降级为参数化形状表示（如CAD参数）
- GPU显存不足 → 降低batch_size或减少点云采样点数
- 不收敛 → 检查学习率、增加数据增强、尝试预训练特征
