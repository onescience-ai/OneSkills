# 非均匀PDE预处理与数据切分

## 适用范围
本步骤适用于非均匀采样与变形几何PDE数据的预处理与切分，是域分解神经算子学习工作流的第二步。主要职责是完成数据质控、重采样、归一化，并按几何或工况构造无泄漏切分。

## 输入
- 切分配置（{SPLIT_CONFIG}）：按对象工况切分
- 目标变量列表（{TARGET_FIELDS}）：待预测物理量
- 是否无量纲化（{NONDIMENSIONALIZE}）：统一跨工况量纲
- 数据契约（来自s01）：变量单位网格定义

## 输出
- train_manifest.json：训练集清单
- validation_manifest.json：验证集清单
- test_manifest.json：测试集清单
- normalization.json：归一化统计量与可逆变换

## 流程节点
1. 依据数据契约完成质控
2. 重采样或图构建（针对非均匀数据）
3. 掩膜处理（边界与特殊区域）
4. 归一化或无量纲化
5. 按几何、完整轨迹或物理工况为单位切分
6. 保存统计量与可逆变换

## 边界与分流
- **切分配置无效**：若配置不符合比例要求，需调整配置
- **数据不足**：若样本数过少，需考虑数据增强或调整切分比例
- **非均匀数据处理**：若数据为非结构网格，需采用图构建或点云表示
- **边界掩膜复杂**：若边界复杂，需特殊处理以保持物理一致性
- **归一化失败**：若数据存在异常值，需先清洗再归一化

## 质量检查
- 三份切分的对象轨迹互斥
- 仅用训练集计算变换统计量
- 边界与掩膜语义未破坏
- 归一化统计量保存完整
- 切分后样本数符合预期

## 回退策略
- 若切分比例不合理，需调整配置重新切分
- 若数据泄漏，需重新设计切分策略
- 若归一化失败，需检查数据质量并清洗
- 若边界掩膜破坏，需重新处理边界数据
