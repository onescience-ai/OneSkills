# 数据接入与契约核验

## 适用范围

**触发条件**：
- 需要接入椭圆或演化方程的变分积分数据
- 数据集路径已知，需要核验完整性

**适用场景**：
- Deep Ritz方法的数据准备
- 弱形式神经求解器的数据准备
- 任何变分PDE求解任务的第一步

**不适用场景**：
- 数据已通过其他流程验证
- 非变分形式的PDE数据

## 输入

- **DATASET_PATH**（必需）：数据集目录或清单文件路径
- **DATASET_NAME**（必需）：数据集名称，标识来源与版本
- **DATA_CONTRACT**（可选）：预定义的数据契约，含变量、单位、网格定义

## 输出

- **dataset_manifest.json**：数据清单，含文件列表、样本数、变量列表
- **data_contract.json**：机器可读的数据契约
- **data_audit.md**：数据审计报告

## 流程节点

### 1. 文件可读性检查
- 遍历DATASET_PATH下所有数据文件
- 检查文件格式、编码、大小
- 记录不可读文件并标记

### 2. 样本数统计
- 统计总样本数、各文件样本数
- 检查样本唯一性（无重复）
- 记录样本分布

### 3. 输入与目标变量核验
- 识别输入变量（坐标、参数等）
- 识别目标变量（解场、通量等）
- 检查变量名一致性

### 4. 单位与坐标系检查
- 核验变量单位是否完整定义
- 检查坐标系类型（笛卡尔、极坐标等）
- 验证网格拓扑（结构化/非结构化）

### 5. 缺失值与异常值扫描
- 统计缺失值比例
- 检测异常值（NaN、Inf、超出物理范围）
- 记录缺失模式

### 6. 使用许可确认
- 检查数据许可证或使用条款
- 记录限制条件
- 输出许可状态

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据集名称 | 椭圆与演化方程变分积分数据 | [1] | 默认数据集 |
| 坐标系 | dataset_native | [1] | 保持原始坐标系 |
| 数据契约 | 含input_fields, target_fields, units, coordinates | [1] | 定义数据结构 |

## 边界与分流

- **文件不可读**：标记该文件并继续处理其他文件，在audit中汇总
- **样本数为0**：返回BLOCKED，列出所有缺失项
- **变量定义缺失**：尝试自动推断并标记为"待确认"
- **单位未定义**：标记为"单位未知"，要求用户补充

## 质量检查

- [ ] 数据文件可读且样本可追溯
- [ ] 输入目标变量单位坐标定义完整
- [ ] 不存在训练测试泄漏（本步骤不切分，仅标记）

## 回退策略

- 数据缺失严重 → 返回BLOCKED并列出完整缺项清单
- 格式不兼容 → 尝试格式转换工具
- 许可限制 → 记录限制并标记为"受限数据"
