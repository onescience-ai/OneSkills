# DeepONet模型训练任务

## 适用范围

**触发条件**：
- 数据已通过预处理与切分（s02完成）
- 需要训练DeepONet或Neural Green function模型
- 需要记录训练过程与环境信息

**适用场景**：
- 算子学习流程的模型训练阶段
- CFD代理模型开发
- 参数化PDE快速求解器训练

**不适用场景**：
- 数据未通过预处理
- 纯推理无训练需求
- 非PyTorch框架的模型训练

## 输入

**必填输入**：
- {MODEL_NAME}：模型名称（DeepONet或Neural Green function）
- {TRAIN_CONFIG}：训练配置（超参数、随机种子）

**可选输入**：
- {INIT_CHECKPOINT}：初始权重（可选预训练权重）

**配置详情**：
- 框架：PyTorch
- epochs：100
- batch_size：8
- learning_rate：0.001
- seed：42
- early_stopping_patience：15

## 输出

**产物清单**：
- best_checkpoint.pt：最佳权重文件
- train_config.json：训练配置
- training_metrics.csv：逐轮训练验证指标
- environment.txt：环境依赖信息

**格式要求**：
- checkpoint可重新加载
- 配置可复现
- 指标包含训练/验证损失

## 流程节点

### Step 1：模型初始化
- **操作**：根据{MODEL_NAME}初始化模型架构
- **检查项**：模型结构正确、参数可训练
- **质量门禁**：模型初始化成功

### Step 2：数据加载器构建
- **操作**：根据切分清单构建训练/验证数据加载器
- **参数**：batch_size、shuffle策略
- **质量门禁**：数据加载器正常工作

### Step 3：优化器与损失函数配置
- **操作**：配置优化器（Adam等）和损失函数（MSE等）
- **参数**：learning_rate、损失函数类型
- **质量门禁**：优化器配置正确

### Step 4：训练循环执行
- **操作**：执行训练循环，记录逐轮指标
- **参数**：epochs、early_stopping_patience
- **质量门禁**：训练验证损失均为有限值

### Step 5：最佳权重保存
- **操作**：保存验证损失最低的权重
- **输出**：best_checkpoint.pt
- **质量门禁**：最佳权重可重新加载

### Step 6：环境信息记录
- **操作**：记录代码版本、依赖库版本、随机种子
- **输出**：environment.txt, train_config.json
- **质量门禁**：配置环境随机种子可复现

## 关键参数

**训练配置**：

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 框架 | PyTorch | 场景需求书 | 深度学习框架 |

| batch_size | 8 | 场景需求书 | 批处理大小 |
| learning_rate | 0.001 | 场景需求书 | 学习率 |
| seed | 42 | 场景需求书 | 随机种子 |
| early_stopping_patience | 15 | 场景需求书 | 早停耐心 |

**质量门限**：

| 门限 | 值 | 说明 |
|------|-----|------|
| 损失有限性 | 100% | 训练/验证损失均为有限值 |
| 权重可加载 | 100% | checkpoint结构兼容 |
| 可复现性 | 100% | 相同种子产生相同结果 |

## 边界与分流

**异常处理**：
1. **训练不收敛** → 调整学习率或模型架构
2. **过拟合** → 增加早停耐心或添加正则化
3. **权重不可加载** → 检查模型架构兼容性
4. **内存不足** → 减小batch_size

**降级策略**：
- 无法收敛 → 尝试不同优化器或学习率调度
- 过拟合严重 → 增加数据增强或减少模型复杂度

## 质量检查

**验证点**：
- 收敛性：损失曲线平稳下降
- 可加载性：checkpoint结构正确
- 可复现性：相同种子结果一致
- 指标完整性：训练/验证损失均已记录

**失败处理**：
- 不收敛 → 调整超参数后重试
- 不可加载 → 检查模型定义后重新保存
- 不可复现 → 检查随机种子设置
