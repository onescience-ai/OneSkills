# 边界嵌入神经算子数据接入与契约核验

## 适用范围

本卡片描述边界嵌入神经算子数据接入与契约核验任务，适用于：
- 混合边界与复杂域PDE数据的接入和验证
- 数据契约的建立和机器可读性检查
- 训练测试泄漏检测

**不适用场景**：
- 数据已通过其他方式验证和预处理
- 数据格式不符合PDE数据规范

## 输入

1. **数据集路径** `{DATASET_PATH}`：目录或清单文件
2. **数据集名称** `{DATASET_NAME}`：来源与数据版本
3. **数据契约** `{DATA_CONTRACT}`：变量单位网格定义

## 输出

1. `dataset_manifest.json`：数据清单
2. `data_contract.json`：机器可读契约
3. `data_audit.md`：数据审计报告

## 流程节点

### Step 1：数据文件可读性检查
- **操作**：验证数据文件是否存在、可读、格式正确
- **工具**：Python文件I/O、JSON/YAML解析
- **质量门禁**：所有必需文件可访问且格式正确

### Step 2：样本与变量核验
- **操作**：检查样本数量、输入与目标变量定义、数据类型
- **工具**：Python数据处理
- **质量门禁**：样本可追溯、变量定义完整

### Step 3：单位与坐标系检查
- **操作**：核验物理量单位、坐标系定义、网格拓扑
- **工具**：单位转换库
- **质量门禁**：单位和坐标系定义完整且一致

### Step 4：缺失值与许可检查
- **操作**：检测缺失值、检查数据使用许可
- **工具**：数据清洗工具
- **质量门禁**：缺失值处理得当、许可信息明确

### Step 5：数据契约生成
- **操作**：生成机器可读的数据契约文件
- **工具**：JSON生成
- **质量门禁**：契约包含所有必需字段

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据文件可读 | 必须 | [场景需求书s01] | 所有数据文件必须可访问 |
| 样本可追溯 | 必须 | [场景需求书s01] | 每个样本必须有唯一标识 |
| 变量单位完整 | 必须 | [场景需求书s01] | 所有变量必须有单位定义 |
| 坐标系定义 | 必须 | [场景需求书s01] | 坐标系必须明确定义 |
| 无训练测试泄漏 | 必须 | [场景需求书s01] | 训练集和测试集必须互斥 |

### 校准数值

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 缺失值阈值 | 0 | 场景需求书 | 不允许缺失值 |
| 文件格式 | JSON/YAML | 场景需求书 | 数据契约格式 |

以下数值来自CFD_S064场景，供量级校准；其他体系需以自身证据重新锚定。

## 边界与分流

1. **数据文件不可读** → 返回BLOCKED并列出缺项
2. **变量定义缺失** → 请求用户提供完整变量定义
3. **单位不一致** → 统一单位后重新核验
4. **训练测试泄漏** → 重新切分数据

## 质量检查

1. **文件完整性**：所有必需文件存在且可读
2. **变量完整性**：所有输入输出变量有定义
3. **单位一致性**：所有物理量单位一致
4. **可追溯性**：样本可追溯到原始数据
5. **无泄漏**：训练集和测试集互斥

## 回退策略

1. **数据格式不兼容** → 请求用户提供标准格式数据
2. **缺少关键信息** → 请求用户补充元数据
3. **许可限制** → 检查数据使用许可
