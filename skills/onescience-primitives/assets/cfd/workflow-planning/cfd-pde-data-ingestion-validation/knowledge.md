# PDE数据接入与契约核验

## 适用范围

本任务用于PDE算子学习工作流的第一阶段，验证多方程多网格预训练数据的完整性、一致性与可用性。适用于从CFD数值模拟、实验数据或合成数据构建的PDE数据集，确保数据满足后续预处理和模型训练的要求。

## 输入

- **数据集路径**（{DATASET_PATH}）：目录或清单文件，必填
- **数据集名称**（{DATASET_NAME}）：来源与数据版本，默认"多方程多网格预训练数据"
- **数据契约**（{DATA_CONTRACT}）：变量单位网格定义，可选

## 输出

- **dataset_manifest.json**：数据清单，包含文件列表、样本数、变量名、单位、坐标系
- **data_contract.json**：机器可读数据契约，定义输入/目标字段、单位、坐标
- **data_audit.md**：数据审计报告，记录缺失值、异常值、许可信息

## 流程节点

1. **文件可读性验证** → 检查所有数据文件是否可打开、格式是否一致
2. **样本追溯** → 记录每个样本的来源、索引、时间/工况标识
3. **变量定义检查** → 验证输入与目标变量的名称、维度、物理含义
4. **单位与坐标系核验** → 确认变量单位一致、坐标系定义明确
5. **网格拓扑验证** → 检查网格类型（结构化/非结构化）、节点数、连通性
6. **时间/工况范围** → 记录时间步范围、工况参数范围
7. **缺失值统计** → 统计NaN/Inf比例、缺失模式
8. **使用许可** → 确认数据使用权限、引用要求

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必填输入 | DATASET_PATH, DATASET_NAME | 场景配置 | 缺少时返回BLOCKED |
| 可选输入 | DATA_CONTRACT | 场景配置 | 无则自动生成 |
| 输出格式 | JSON + Markdown | 场景配置 | 机器可读+人工可读 |
| 审计深度 | 完整 | 场景配置 | 每个维度都需验证 |

## 边界与分流

- **文件不可读**：返回BLOCKED，列出不可读文件路径
- **格式不一致**：记录不一致之处，尝试自动推断格式或返回BLOCKED
- **变量定义缺失**：记录缺失变量，标注为待确认
- **单位不一致**：尝试自动转换，无法转换则返回BLOCKED
- **数据泄漏风险**：检测训练测试样本重叠，命中则返回BLOCKED

## 质量检查

- 数据文件可读且样本可追溯
- 输入目标变量单位坐标定义完整
- 不存在训练测试泄漏
- 缺失值比例低于阈值（建议<5%）

## 回退策略

数据格式不兼容→调用onescience-data-standardizer预处理；数据质量严重不足→请求用户提供修正后数据。
