# 伴随神经网络控制

## 适用范围

基于伴随方程与深度学习的流动控制策略训练方法，通过自动微分计算流场对神经网络参数的敏感性，优化升阻比或目标函数。适用于湍流翼型流动控制、敏感性分析与参数优化。不适用于无伴随方程或无法自动微分的求解器。

## 输入

- **流场求解器**：可微分或支持自动微分的CFD求解器
- **控制目标**：升阻比优化、分离抑制、载荷控制
- **执行器模型**：吹吸射流、合成射流等执行器物理模型
- **测量输入**：局部压力测量、流场状态
- **训练配置**：学习率、批量大小、迭代次数

## 输出

- **神经网络控制器**：映射测量输入到控制动作的策略网络
- **敏感性场**：流场对神经网络参数的敏感性分布
- **优化轨迹**：控制策略的优化历史
- **性能指标**：升阻比改善、分离区域减小

## 流程节点

1. **求解器可微分化** → 通过自动微分构建可微分流场求解器
2. **伴随方程求解** → 求解伴随Navier-Stokes方程获取敏感性
3. **策略网络训练** → 基于敏感性梯度更新神经网络参数
4. **闭环验证** → 在独立工况下验证控制策略效果
5. **泛化性测试** → 测试2D训练模型在3D流场中的有效性

## 边界与分流

- **前提：求解器可微分** → 若求解器不可微分，需使用有限差分或代理模型近似敏感性
- **前提：伴随方程可解** → 若伴随方程求解困难，需使用强化学习等替代方法
- **前提：执行器可建模** → 若执行器物理复杂，需简化模型或实验标定
- **前提：测量可用** → 若无局部压力测量，需使用全流场观测或虚拟传感器

## 质量检查

- **敏感性验证**：伴随梯度与有限差分梯度一致性检查
- **控制效果验证**：升阻比改善与分离抑制效果量化评估
- **泛化性验证**：跨维度（2D→3D）或跨工况（不同攻角）迁移测试
- **计算成本评估**：伴随求解与训练时间在可接受范围内

## 回退策略

- **伴随求解不稳定**：调整时间步长或使用隐式格式
- **敏感性计算不准确**：增加网格分辨率或使用高阶格式
- **策略网络不收敛**：调整学习率或网络结构
- **泛化性不足**：增加训练工况多样性或使用域适应技术
