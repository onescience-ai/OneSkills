# Task Acceptance and Applicability Determination

## 适用范围

面向迁移模型的任务验收与适用域判定阶段，综合评估统计误差、物理约束满足度、泛化能力和计算收益，给出 PASS/REJECT/BLOCKED 结论，明确适用域限制，域外工况需经 CFD 复核。适用于所有完成迁移训练后需要验收评估的场景。

## 输入

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| METRICS | list[str] | 是 | 验收指标列表（统计+物理） |
| MAX_RELATIVE_L2 | float | 否 | 相对 L2 误差门限（默认 0.1） |
| RUN_OOD_TEST | bool | 否 | 是否执行外推测试（默认 true） |

## 输出

| 产物 | 格式 | 说明 |
|------|------|------|
| evaluation.json | JSON | 完整评估结果：逐变量误差、物理约束、计算成本 |
| worst_cases.csv | CSV | 最差样本列表与详细信息 |
| applicability_report.md | Markdown | 适用域报告：边界、限制、复核建议 |
| PASS_REJECT_BLOCKED.txt | Text | 最终结论（PASS/REJECT/BLOCKED） |

## 流程节点

1. **加载预测结果** → 读取 s04 输出的 predictions/
2. **加载测试标签** → 读取 test_manifest.json 对应的真实值
3. **逐变量统计误差** → 计算 relative_L2、RMSE、MAE 等
4. **计算边界误差** → 评估边界条件满足度
5. **计算守恒残差** → 验证质量/动量/能量守恒
6. **计算方程残差** → 评估 PDE 残差
7. **定位最差样本** → 找出误差最大样本并记录
8. **计算推理成本** → 统计推理时间、内存占用
9. **综合判定** → 按 METRICS 门限给出 PASS/REJECT/BLOCKED
10. **外推测试**（若 RUN_OOD_TEST=true）→ 测试 OOD 几何或工况
11. **确定适用域** → 明确模型有效工况范围
12. **生成复核建议** → 域外工况需经 CFD 复核
13. **输出报告** → 生成 evaluation.json 和 applicability_report.md

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| relative_L2 | ≤ 0.1 | 场景需求书 | 放行阈值 |
| 误差报告 | 逐变量 | 场景需求书 | 不得仅报告平均 |
| 最差样本 | 必须可追溯 | 场景需求书 | 定位问题 |
| 适用域 | 必须明确 | 场景需求书 | 不得仅凭平均宣称可用 |
| 域外工况 | CFD 复核 | 场景需求书 | 强制要求 |

### 校准数值
> 以下数值来自场景需求书，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认 MAX_RELATIVE_L2 | 0.1 | 场景需求书 | 可调整 |
| 默认 RUN_OOD_TEST | true | 场景需求书 | 建议启用 |

## 边界与分流

- **PASS**：所有指标满足门限，可进入部署或进一步验证
- **REJECT**：指标不满足门限，需调整模型或数据后重训
- **BLOCKED**：缺少必要输入或数据，无法完成评估
- **域外工况**：即使平均误差达标，域外工况仍需 CFD 复核

## 质量检查

- [ ] 统计与物理指标同时报告
- [ ] 最差样本可追溯
- [ ] 结论含适用域限制与复核建议
- [ ] PASS/REJECT/BLOCKED 结论明确

## 回退策略

- 评估结果为 REJECT → 分析失败原因（数据/模型/超参），返回 s03 调整
- 评估结果为 BLOCKED → 补充缺失输入后重新评估
- 域外性能差 → 扩充 OOD 训练数据或使用 domain randomization
