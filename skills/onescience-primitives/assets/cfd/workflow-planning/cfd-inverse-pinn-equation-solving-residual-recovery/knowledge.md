# 方程求解与物理残差恢复

## 适用范围

本卡片描述物理信息神经网络稀疏观测参数反演工作流的第四步：方程求解与物理残差恢复。适用于：
- PINN模型的推理与预测
- PDE方程残差的计算
- 解场、导数与边界值的恢复

**不适用场景**：
- 模型训练阶段
- 数据预处理阶段

## 输入

1. **模型权重** `{CHECKPOINT}`：通过训练门限权重
2. **计算设备** `{DEVICE}`：CPU或CUDA设备
3. **推理批大小** `{BATCH_SIZE}`：按显存调整批量

## 输出

1. **解场文件** `solution_fields/`
2. **PDE残差** `pde_residuals/`
3. **边界残差** `boundary_residuals.csv`

## 流程节点

```
加载模型权重 → 准备查询配点 → 前向推理 → 自动微分求导 → 计算PDE残差 → 计算边界残差 → 保存结果
```

### 详细操作

#### 1. 模型加载与查询配点准备

**操作**：
- 加载`{CHECKPOINT}`权重
- 准备查询配点（测试集坐标或自定义网格）
- 验证模型结构与权重匹配

**判定标准**：
- 权重加载成功
- 查询配点坐标正确
- 模型结构一致

#### 2. 前向推理

**操作**：
- 在查询配点上执行前向传播
- 获取模型预测值
- 处理多输出情况

**判定标准**：
- 输出维度正确
- 预测值在物理范围内
- 无数值异常

#### 3. 自动微分求导

**操作**：
- 使用PyTorch自动微分计算空间导数
- 计算速度梯度、压力梯度等
- 保持计算图完整性

**判定标准**：
- 导数计算正确
- 梯度可传播
- 无梯度消失

#### 4. PDE残差计算

**操作**：
- 将预测值与导数代入PDE方程
- 计算方程残差
- 分析残差分布

**判定标准**：
- 残差为有限值
- 残差分布合理
- 主要区域残差较小

#### 5. 边界残差计算

**操作**：
- 提取边界条件区域
- 计算边界预测值与真实值的差异
- 逐项检查边界条件满足程度

**判定标准**：
- 边界残差为有限值
- 边界条件满足门限
- 可追溯到具体边界

## 边界与分流

1. **权重加载失败**：结构不兼容 → 检查模型定义或重新训练
2. **导数计算异常**：梯度为NaN → 检查计算图或使用数值微分
3. **残差过大**：PDE残差超过门限 → 检查方程定义或配点分布
4. **边界不满足**：边界残差过大 → 检查边界条件处理
5. **显存不足**：推理批大小过大 → 减小批量或使用梯度检查点

## 质量检查

1. **有限值**：解场导数与残差均为有限值
2. **边界满足**：边初值逐项满足门限
3. **可对照**：独立数值解或解析解可对照
4. **可追溯**：残差可追溯到具体配点
5. **一致性**：预测值与物理约束一致

## 回退策略

1. **权重加载失败** → 使用最近成功 checkpoint
2. **导数异常** → 使用数值微分替代自动微分
3. **残差过大** → 增加配点密度或调整损失权重
4. **边界不满足** → 增强边界损失权重
