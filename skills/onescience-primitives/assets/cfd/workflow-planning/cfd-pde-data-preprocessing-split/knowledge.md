# PDE数据预处理与无泄漏切分

## 适用范围

**触发条件**：
- 数据接入与契约核验完成后，需要进行预处理与切分
- 需要将PDE数据按几何/轨迹/工况进行无泄漏切分
- 需要统一物理量表示与量纲

**适用场景**：
- 连续时间PDE轨迹数据的帧级切分
- 随机PDE工况级切分
- 多物理量PDE数据的归一化与无量纲化

**不适用场景**：
- 数据未完成接入核验（先执行s01）
- 无需切分的单次推理任务

## 输入

- 切分配置（SPLIT_CONFIG）：train/val/test比例、随机种子、分组依据，必填
- 目标变量列表（TARGET_FIELDS）：待预测物理量，必填
- 是否无量纲化（NONDIMENSIONALIZE）：统一跨工况量纲，可选（默认true）

## 输出

- train_manifest.json：训练集清单
- validation_manifest.json：验证集清单
- test_manifest.json：测试集清单
- normalization.json：归一化参数（均值、标准差、最小最大值等可逆变换参数）

## 流程节点

### Step 2.1：质控与重采样
- **操作**：按data_contract.json进行数据质量检查，必要时重采样到统一网格
- **质量门禁**：重采样后网格分辨率记录完整

### Step 2.2：掩膜与边界处理
- **操作**：构建边界掩膜，处理不规则区域
- **质量门禁**：掩膜语义正确（边界处物理量连续性不受破坏）

### Step 2.3：归一化/无量纲化
- **操作**：对TARGET_FIELDS执行归一化或无量纲化，**仅用训练集计算统计量**
- **质量门禁**：变换参数仅来自训练集；变换可逆（保存inverse变换）

### Step 2.4：无泄漏切分
- **操作**：按SPLIT_CONFIG以几何、完整轨迹或物理工况为单位切分
- **质量门禁**：三份切分的轨迹/工况互斥；同一轨迹的帧不被打散到不同切分

### Step 2.5：清单输出
- **操作**：输出三份切分清单与归一化参数
- **质量门禁**：清单可被下游步骤解析；归一化参数完整

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认训练比例 | 0.7 | 场景需求书 | 70%训练 |
| 默认验证比例 | 0.15 | 场景需求书 | 15%验证 |
| 默认测试比例 | 0.15 | 场景需求书 | 15%测试 |
| 默认随机种子 | 42 | 场景需求书 | 可复现切分 |
| 默认分组依据 | geometry_or_trajectory | 场景需求书 | 按几何或轨迹 |
| 默认无量纲化 | true | 场景需求书 | 统一跨工况量纲 |

## 边界与分流

- **轨迹泄漏检测失败**：终止切分，报告泄漏位置
- **归一化统计量来自非训练集**：拒绝输出，重新计算
- **掩膜语义破坏**：回退到原始掩膜，重新处理
- **目标变量缺失**：返回BLOCKED，列出缺失变量

## 质量检查

- 切分互斥性验证（无轨迹/工况重叠）
- 归一化参数来源验证（仅训练集）
- 变换可逆性验证（正变换→逆变换≈原始值）
- 掩膜完整性验证

## 回退策略

- 切分比例不满足要求：调整比例重新切分
- 归一化参数不稳定：增加训练集统计量采样
- 掩膜生成失败：使用简化掩膜或跳过非规则区域
