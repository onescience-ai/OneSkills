# POD与模态分解流动降阶建模场景

## 适用范围

**触发条件**：
- 需要从高保真CFD快照数据中提取主导流动模态
- 需要构建参数化流场的降阶模型以加速预测
- 需要评估降阶模型的物理一致性和适用域

**适用场景**：
- 参数化CFD流场降阶建模（如翼型、钝体、湍流等）
- 需要实时或快速流场预测的工程应用
- 流动稳定性分析和模态识别
- 数据驱动的流动建模与控制

**不适用场景**：
- 非参数化流场的单次模拟
- 需要全分辨率CFD计算的高精度分析
- 多物理场强耦合问题（需额外耦合处理）

## 输入

**数据格式**：
- CFD快照矩阵：时间或参数序列下的流场状态（速度、压力等）
- 参数标签：每个快照对应的工况参数（如雷诺数、攻角、几何参数等）
- 网格信息：空间离散化数据（网格坐标、拓扑等）

**预处理要求**：
- 数据可读性验证（文件完整性、格式一致性）
- 变量单位统一和坐标系对齐
- 缺失值处理和异常值检测

## 输出

**产物**：
1. 降阶模型（POD基函数、DMD模态等）
2. 模型训练配置和指标
3. 测试集预测结果
4. 物理一致性评估报告
5. 适用域判定报告

**验证标准**：
- 模型可复现性（代码、依赖、随机种子）
- 预测误差在允许范围内（相对L2误差≤0.1）
- 物理守恒性验证（质量、动量、能量守恒残差）
- 边界条件满足度

## 流程节点

### Step 1：数据接入与契约核验
- **操作**：接入CFD快照矩阵与参数标签，核验样本、变量、单位、网格坐标及许可
- **参数**：数据集路径、数据契约定义
- **工具**：数据读取库、契约验证脚本
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏

### Step 2：预处理与数据切分
- **操作**：统一物理量与表示，按几何、工况或时间构造无泄漏切分
- **参数**：切分配置（train/val/test比例）、目标变量、无量纲化选项
- **工具**：数据预处理库、切分工具
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏

### Step 3：模型配置与训练
- **操作**：训练POD、Dynamic mode decomposition完成指定输入到目标物理量的映射
- **参数**：模型名称、训练配置（框架、epochs、batch_size等）
- **工具**：POD/DMD实现库、训练框架（如PyTorch）
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现

### Step 4：批量推理与物理恢复
- **操作**：在独立测试集推理，恢复原始单位、网格和物理派生量
- **参数**：模型权重、计算设备、推理批大小
- **工具**：推理引擎、后处理脚本
- **质量门禁**：预测无NaN或Inf且形状单位正确；每个测试样本有唯一结果；推理未使用测试目标校正

### Step 5：任务验收与适用域判定
- **操作**：评估统计误差、关键物理约束、泛化能力和计算收益
- **参数**：验收指标、相对误差门限、外推测试选项
- **工具**：评估脚本、可视化工具
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议

## 边界与分流

**关键前提不成立时的改道方案**：
1. **数据质量不足**：若快照矩阵存在严重缺失或不一致，需返回数据清洗或重新采集
2. **模型收敛困难**：若POD/DMD训练不收敛，可调整模态数量、正则化参数或改用其他降阶方法
3. **物理约束违反**：若预测结果不满足守恒律，需检查模型是否包含物理约束或后处理校正
4. **适用域外工况**：若测试工况超出训练数据覆盖范围，需进行CFD复核而非依赖降阶模型

## 质量检查

**验证点**：
- 数据完整性检查（样本数、变量完整性）
- 模型训练收敛性（损失曲线、早停机制）
- 预测结果物理合理性（场分布、统计特性）
- 计算效率（加速比、内存占用）

**阈值**：
- 相对L2误差 ≤ 0.1
- 守恒残差 < 1e-6（量纲相关）
- 边界误差 < 1%（边界条件满足度）

**失败处理**：
- 误差超标：调整模型参数或增加训练数据
- 物理违反：添加物理约束或后处理校正
- 计算超时：优化算法或降级到简化模型

## 回退策略

**失败时的替代方案**：
1. **模型训练失败**：回退到线性POD或简化模态分析
2. **预测精度不足**：回退到传统CFD计算或混合建模
3. **适用域判定不确定**：标记为"需CFD复核"并限制应用场景
4. **计算资源不足**：降级到小规模数据集或简化网格
