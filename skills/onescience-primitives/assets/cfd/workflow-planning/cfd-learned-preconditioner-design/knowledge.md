# 学习预条件器设计

## 适用范围
使用神经网络设计预条件器以加速共轭梯度（CG）及其变体（如FCG、PCG）求解器收敛。适用于：
- 对称正定（SPD）线性系统（如Poisson方程、扩散方程离散化）
- 一般稀疏线性系统（需使用GMRES等方法）
- 传统预条件器（ILU、AMG）设计困难或泛化性差的问题
- 需要跨参数/网格泛化的多查询场景

**不适用场景**：
- 稠密矩阵（预条件器构建开销过大）
- 非线性系统（需先线性化）
- 无法提供训练数据的完全未知问题

## 输入
- **系统矩阵**：稀疏矩阵A（来自PDE离散化）
- **右端向量**：b（源项或边界条件贡献）
- **训练数据**：矩阵-向量对、对应解向量
- **预条件器类型**：稀疏近似逆、不完全分解、神经算子等

## 输出
- **预条件器模型**：可嵌入Krylov求解器的神经网络模块
- **条件数改善**：预条件后系统条件数降低倍数
- **迭代次数减少**：相对无预条件或传统预条件器的迭代次数减少
- **求解时间加速**：端到端求解时间加速比

## 流程节点
```
预条件器类型选择 → 神经网络架构设计 → 条件数感知训练 → Krylov求解器集成 → 性能验证
```

### 1. 预条件器类型选择
- **操作**：根据系统矩阵特征选择预条件器类型
- **参数**：矩阵对称性、稀疏性、条件数估计
- **工具**：矩阵分析工具
- **质量门禁**：明确系统特征（对称/非对称、正定/不定）；选择匹配的预条件器类型

### 2. 神经网络架构设计
- **操作**：设计适合预条件器任务的神经网络架构
- **参数**：GNN层数、消息传递机制、稀疏性约束、矩阵-向量乘法效率
- **工具**：PyTorch/TensorFlow
- **质量门禁**：预条件器应用复杂度O(N)或O(NlogN)；支持GPU并行；内存开销可控

### 3. 条件数感知训练
- **操作**：设计条件数感知的损失函数，训练神经预条件器
- **参数**：损失函数类型（条件数近似、残差范数）、训练策略、正则化
- **工具**：自定义训练循环
- **质量门禁**：条件数改善达到目标；训练收敛；泛化性能稳定

### 4. Krylov求解器集成
- **操作**：将训练好的预条件器集成到Krylov求解器中
- **参数**：求解器类型（CG/GMRES/FCG）、预条件器应用方式（左/右/分裂）
- **工具**：科学计算库（SciPy、PETSc等）
- **质量门禁**：集成后求解器稳定；预条件器应用无额外开销；支持灵活预条件

### 5. 性能验证
- **操作**：在测试问题上验证预条件效果、泛化性和加速效果
- **参数**：测试问题集、收敛容差、最大迭代次数
- **工具**：求解器测试框架
- **质量门禁**：条件数降低；迭代次数减少；求解时间加速；泛化到未见问题

## 边界与分流
- **前提1：系统矩阵稀疏** → 若矩阵稠密，转向快速矩阵乘法或随机近似方法
- **前提2：可提供训练数据** → 若无数据，转向传统预条件器（ILU、AMG）或元学习方法
- **前提3：预条件器应用复杂度可控** → 若应用开销过大，转向轻量级预条件器或混合方法
- **前提4：GPU资源可用** → 若仅CPU可用，转向CPU优化的预条件器架构

## 质量检查
- **条件数验证**：预条件后条件数应显著降低（通常>2x）
- **收敛验证**：Krylov求解器迭代次数应减少
- **稳定性验证**：预条件器在不同问题上性能稳定
- **泛化验证**：在未见过的矩阵上性能保持

## 回退策略
- **训练失败**：降低学习率、增加数据、简化网络、调整损失函数
- **条件数改善不足**：增加网络容量、修改损失函数、尝试不同预条件器类型
- **泛化失败**：扩大训练数据覆盖、使用域适应、增加正则化
- **计算资源不足**：使用混合精度、模型压缩、分布式训练
