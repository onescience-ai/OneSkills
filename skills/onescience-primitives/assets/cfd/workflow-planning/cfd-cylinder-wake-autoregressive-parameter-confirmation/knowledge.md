# 圆柱绕流自回归预测任务中关键参数的确定方法和用户确认流程

## 适用范围
面向圆柱绕流自回归预测任务，提供关键参数的确定方法、默认值依据和用户确认流程。适用于需要确保任务执行参数准确、符合科研要求的场景。

## 输入
- 任务需求：预测目标、精度要求、计算约束
- 物理参数：Reynolds数、几何尺寸、边界条件
- 训练参数：模型架构、超参数、数据配置

## 输出
- 参数确认报告：关键参数的确定依据和确认状态
- 参数配置文件：包含所有参数的配置文件
- 用户确认记录：参数确认的完整记录

## 流程节点
1. **参数识别** → 识别任务中的关键参数
2. **默认值确定** → 基于文献和经验确定默认值
3. **用户确认请求** → 向用户请求参数确认
4. **参数验证** → 验证参数的合理性和一致性
5. **配置生成** → 生成参数配置文件
6. **确认记录** → 记录参数确认过程和结果

## 边界与分流
- **参数缺失时**：使用文献中的标准值作为默认值
- **参数冲突时**：优先采用用户确认的值
- **参数不合理时**：提供建议范围并请求用户重新确认
- **确认超时时**：使用默认值继续执行，但记录未确认状态

## 质量检查
- **完整性检查**：所有关键参数都已确认或使用默认值
- **一致性检查**：参数之间没有逻辑冲突
- **合理性检查**：参数值在合理范围内
- **可追溯性**：每个参数都有确认记录或默认值依据

## 回退策略
1. **使用默认值**：对于非关键参数使用文献默认值
2. **部分确认**：对于部分参数确认，其他使用默认值
3. **延迟确认**：在执行过程中再确认某些参数
4. **降级执行**：使用最小参数集完成基本功能
