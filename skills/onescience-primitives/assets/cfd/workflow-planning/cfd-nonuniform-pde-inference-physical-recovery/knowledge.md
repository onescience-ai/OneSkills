# 非均匀PDE批量推理与物理恢复

## 适用范围
本步骤适用于非均匀采样与变形几何PDE数据的批量推理与物理恢复，是工作流的第四步。主要职责是在独立测试集上推理，恢复原始单位、网格和物理派生量，生成逐样本结果和耗时统计。

## 输入
- 模型权重（{CHECKPOINT}）：通过训练门限权重
- 计算设备（{DEVICE}）：CPU或CUDA设备
- 推理批大小（{BATCH_SIZE}）：按显存调整批量
- 训练时数据契约与统计量（来自s02）

## 输出
- predictions/：预测结果目录
- inference_manifest.json：推理清单
- timing.csv：耗时统计

## 流程节点
1. 加载模型权重及训练时数据契约
2. 在独立测试集上推理
3. 反归一化并恢复物理单位
4. 恢复坐标网格与边界掩膜
5. 计算任务派生量
6. 保存逐样本结果
7. 记录推理耗时

## 边界与分流
- **内存不足**：需减小batch_size或采用流式推理
- **预测异常**：若出现NaN/Inf，需检查模型权重和输入数据
- **物理恢复失败**：若反归一化失败，需检查统计量文件
- **边界掩膜缺失**：若掩膜信息不完整，需标记并记录
- **推理速度慢**：需优化模型或采用混合精度推理

## 质量检查
- 预测无NaN或Inf且形状单位正确
- 每个测试样本有唯一结果
- 推理未使用测试目标校正
- 物理恢复完整
- 耗时统计准确

## 回退策略
- 若内存不足，需调整batch_size或采用梯度检查点
- 若预测异常，需检查数据预处理和模型权重
- 若物理恢复失败，需检查归一化统计量
- 若推理速度慢，需优化模型或采用蒸馏
