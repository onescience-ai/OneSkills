# 基础模型跨PDE零样本时序预测场景

## 适用范围
面向多物理预训练PDE时序数据，完成基础模型跨PDE零样本时序预测的完整场景。适用于需要利用预训练PDE基础模型对未知PDE工况进行零样本时序预测的任务，要求产出可复现模型、任务结果、物理一致性评估和适用域报告。不适用于需要大量下游微调的场景，或物理约束不明确的纯数据驱动预测。

## 输入
- 多物理预训练PDE时序数据集（包含多个PDE工况的时空演化数据）
- 数据契约（定义变量、单位、网格坐标）
- 模型配置（PDE foundation model、In-context learner）
- 训练配置（超参数、随机种子）
- 验收指标（统计误差、物理约束）

## 输出
- 可复现的模型权重（best_checkpoint.pt）
- 任务结果（预测结果、推理耗时）
- 物理一致性评估（守恒残差、边界误差）
- 适用域报告（域外工况分析、复核建议）

## 流程节点
1. **数据接入与契约核验** → 2. **预处理与数据切分** → 3. **模型配置与训练** → 4. **批量推理与物理恢复** → 5. **任务验收与适用域判定**

每步含：操作、参数、工具、质量门禁

### 步骤1：数据接入与契约核验
- **操作**：接入多物理预训练PDE时序数据，核验样本、变量、单位、网格坐标及许可。
- **参数**：数据集路径、数据集名称、数据契约
- **工具**：数据加载脚本、契约验证工具
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏

### 步骤2：预处理与数据切分
- **操作**：统一物理量与表示，按几何、工况或时间构造无泄漏切分。
- **参数**：切分配置、目标变量、是否无量纲化
- **工具**：数据预处理脚本、切分工具
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏

### 步骤3：模型配置与训练
- **操作**：训练PDE foundation model、In-context learner完成指定输入到目标物理量的映射。
- **参数**：模型名称、训练配置、初始权重
- **工具**：PyTorch训练脚本
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现

### 步骤4：批量推理与物理恢复
- **操作**：在独立测试集推理，恢复原始单位、网格和物理派生量。
- **参数**：模型权重、计算设备、推理批大小
- **工具**：推理脚本、反归一化工具
- **质量门禁**：预测无NaN或Inf且形状单位正确；每个测试样本有唯一结果；推理未使用测试目标校正

### 步骤5：任务验收与适用域判定
- **操作**：评估统计误差、关键物理约束、泛化能力和计算收益。
- **参数**：验收指标、相对误差门限、是否外推测试
- **工具**：评估脚本、可视化工具
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议

## 边界与分流
- **数据不可读或缺失关键变量**：返回BLOCKED，列出缺项，不得编造数据。
- **训练验证损失非有限值**：检查数据质量、模型配置，必要时调整超参数。
- **最佳权重无法重新加载**：检查模型架构兼容性，确保保存时包含完整状态。
- **预测出现NaN或Inf**：检查数据预处理、模型数值稳定性，必要时使用混合精度训练。
- **域外工况性能下降**：执行几何或工况外推测试，明确适用域，建议CFD复核。

## 质量检查
- 数据完整性检查：样本数、变量、单位、坐标系
- 切分互斥性检查：训练、验证、测试集无重叠样本
- 模型训练收敛检查：损失曲线、验证指标
- 推理结果合理性检查：物理量范围、守恒性
- 适用域评估：误差分布、最差样本分析

## 回退策略
- 数据质量问题：清洗数据、补充缺失值、重新采集
- 模型训练失败：调整超参数、更换模型架构、使用预训练权重
- 推理性能不足：优化模型结构、增加训练数据、使用集成方法
- 适用域过窄：扩展训练数据覆盖范围、引入领域自适应技术
