# 预处理与数据切分

## 适用范围

**触发条件**：
- 需要统一物理量与表示
- 需要按几何、工况或时间构造无泄漏切分
- 需要确保数据质量和训练有效性

**适用场景**：
- Darcy流渗透率场数据预处理
- Navier-Stokes方程流场数据预处理
- 其他规则网格PDE数据预处理

**不适用场景**：
- 非规则网格数据
- 缺少元数据的数据
- 格式不兼容的数据

## 输入

**数据格式**：
- 规则网格数据（如2D/3D网格）
- 输入参数：渗透率场、初始条件、边界条件等
- 输出目标：压力场、速度场等物理量

**数据来源**：
- 数值模拟生成的训练数据
- 实验测量数据（需预处理）

**预处理要求**：
- 数据归一化或无量纲化
- 网格坐标标准化
- 边界掩膜处理

## 输出

**输出产物**：
- 训练集清单（train_manifest.json）
- 验证集清单（validation_manifest.json）
- 测试集清单（test_manifest.json）
- 归一化统计量（normalization.json）

**验证标准**：
- 三份切分的对象轨迹互斥
- 仅用训练集计算变换统计量
- 边界与掩膜语义未破坏

## 流程节点

### Step 1：数据质控
- **操作**：检查数据质量，处理异常值
- **参数**：异常值阈值、处理策略
- **工具**：数据清洗工具、异常检测脚本
- **质量门禁**：异常值处理得当，数据质量提升

### Step 2：重采样或图构建
- **操作**：根据需要重采样或构建图结构
- **参数**：重采样方法、图构建参数
- **工具**：重采样工具、图构建脚本
- **质量门禁**：重采样后数据分布合理，图结构正确

### Step 3：掩膜处理
- **操作**：处理边界掩膜，确保语义完整
- **参数**：掩膜类型、处理策略
- **工具**：掩膜处理工具、边界检测脚本
- **质量门禁**：掩膜处理后边界语义完整

### Step 4：归一化或无量纲化
- **操作**：统一物理量表示，进行归一化或无量纲化
- **参数**：归一化方法、无量纲化参数
- **工具**：归一化工具、无量纲化脚本
- **质量门禁**：归一化后数据分布合理，量纲统一

### Step 5：数据切分
- **操作**：按几何、完整轨迹或物理工况为单位切分
- **参数**：切分配置（train/validation/test比例）、切分单位
- **工具**：切分工具、数据划分脚本
- **质量门禁**：三份切分的对象轨迹互斥，无数据泄漏

## 边界与分流

**关键前提不成立时的改道方案**：
1. **数据量不足**：使用数据增强或迁移学习
2. **切分后分布偏移**：调整切分策略或使用分层切分
3. **掩膜语义破坏**：重新设计掩膜处理策略
4. **归一化不合理**：尝试不同的归一化方法

## 质量检查

**验证点**：
- 数据质控效果：异常值处理、数据清洗
- 重采样合理性：数据分布、采样率
- 掩膜完整性：边界语义、掩膜覆盖
- 归一化效果：数据分布、量纲统一
- 切分无泄漏：轨迹互斥、分布一致

**阈值**：
- 异常值比例：< 5%
- 重采样后数据分布：KS检验 p > 0.05
- 掩膜覆盖率：100%
- 归一化后数据范围：[0, 1] 或 [-1, 1]

**失败处理**：
- 数据质控失败：返回BLOCKED
- 重采样失败：尝试其他方法
- 掩膜处理失败：重新设计掩膜
- 归一化失败：尝试其他归一化方法

## 回退策略

**失败时的替代方案**：
1. **数据质控失败**：使用更宽松的异常值阈值
2. **重采样失败**：使用简单随机采样
3. **掩膜处理失败**：使用二值掩膜
4. **归一化失败**：使用简单缩放
