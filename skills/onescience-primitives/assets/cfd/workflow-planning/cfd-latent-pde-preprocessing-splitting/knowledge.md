# 连续坐标PDE预处理与数据切分

## 适用范围
本卡描述如何为潜空间与神经场连续PDE算子学习进行数据预处理与无泄漏切分。适用于数据接入验证完成后、模型训练前的数据准备阶段。

## 输入
- data_contract.json：数据契约
- SPLIT_CONFIG：切分配置（比例、随机种子、切分策略）
- TARGET_FIELDS：目标变量列表
- NONDIMENSIONALIZE：是否无量纲化

## 输出
- train_manifest.json：训练集清单
- validation_manifest.json：验证集清单
- test_manifest.json：测试集清单
- normalization.json：归一化统计量

## 流程节点
1. 依据数据契约完成质控
2. 重采样或图构建（如需要）
3. 掩膜处理
4. 归一化或无量纲化
5. 按几何、完整轨迹或物理工况为单位切分

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 训练比例 | 0.7 | 场景需求书 | 默认训练集比例 |
| 验证比例 | 0.15 | 场景需求书 | 默认验证集比例 |
| 测试比例 | 0.15 | 场景需求书 | 默认测试集比例 |
| 随机种子 | 42 | 场景需求书 | 可复现切分 |
| 切分策略 | 按几何或轨迹 | 场景需求书 | 保持样本独立性 |

## 边界与分流
- 同一轨迹帧随机打散 → 禁止，必须按轨迹/工况整体切分
- 变换统计量使用测试集计算 → 禁止，仅用训练集
- 边界与掩膜语义破坏 → 需检查预处理流程

## 质量检查
- 三份切分的对象轨迹互斥
- 仅用训练集计算变换统计量
- 边界与掩膜语义未破坏

## 回退策略
切分不满足要求时，调整切分策略或随机种子重新切分。

## 资源召回建议
