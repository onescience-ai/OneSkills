# 规则网格上 U-Net 类 CNN 的 RANS 流场代理预测方法

## 适用范围

面向规则网格（结构化笛卡尔网格或均匀化后的准结构网格）上 RANS 求解器产出的稳态或非稳态全场流场数据（速度场、压力场、马赫数场等），利用编码器-解码器结构的卷积神经网络构建端到端代理预测模型。适用于气动外形参数化扫描、快速设计迭代、CFD 结果加速等场景。不适用于非结构网格上直接建模（需图神经网络或点云方法）、强瞬态 LES/DNS 涡结构精细预测、或需要严格守恒约束的场景。

## 输入

- **CFD 标注数据**：规则网格上的全场物理量（如 ux, uy, p, Mach number），由 RANS 求解器（k-ω SST 等湍流模型）在给定边界条件下计算得到。
- **几何编码**：通过有符号距离函数（SDF）层或灰度图像编码几何外形。SDF 优于二值掩码表示，可显著提升 CNN 性能 [1]。对于翼型等二维外形，SDF 计算方式为：零等值集 Z = {(X,Y) | SDF(x,y)=0}，内部 SDF<0，外部 SDF>0，值为到最近边界的有符号距离 [1]。
- **边界条件编码**：流场区域通道（FRC）层，为网格单元分配边界条件标签（如：几何=0，流体=1，入口=3，出口=4，壁面=5）[1]。或将叶片几何转换为灰度图像输入 [2]。
- **网格分辨率**：CNN 输入层通常统一为固定尺寸的规则网格（如 256×512 [1] 或512×512 [2]），CFD 非均匀网格需先插值到均匀网格。

## 输出

- **全场预测**：与输入网格同分辨率的物理量预测场（速度分量 ux/uy、压力 p、马赫数等），每个物理量通常由独立解码器输出 [1]。
- **验证指标**：相对 L2 误差、平均绝对误差（MAE）、最大绝对误差、数据分布对比（均值/标准差）、速度剖面误差。

## 流程节点

### 节点 1：CFD 数据生成与预处理

1. 使用 RANS 求解器（如 Star-CCM+、OpenFOAM）对目标几何生成 CFD 数据集
2. 参数化扫描：对几何参数（如翼型弯度、厚度、攻角、雷诺数）进行采样
3. 网格独立性验证：确保 CFD 数据质量（如阻力系数误差 <5%）
4. 将 CFD 结果插值到统一的规则网格
5. 物理量无量纲化：ux* = ux/u∞, p* = p/(ρ·u∞²) [1]
6. Min-max 归一化到 [0,1]：Φ' = (Φ - min(Φ)) / (max(Φ) - min(Φ)) [1]

**质量门禁**：网格独立性验证通过；无量纲化公式与 CFD 求解器一致；归一化范围检查。

### 节点 2：输入表示构建

1. 计算 SDF 层：基于几何轮廓的有符号距离场
2. 构建 FRC 层：边界条件标签场
3. 组合为多通道输入（如 3 通道：FRC + SDF_vehicle + SDF_road [1]）
4. 或将几何转换为灰度图像 [2]

**质量门禁**：SDF 符号正确（内负外正）；FRC 标签无遗漏；通道维度匹配。

### 节点 3：网络架构设计

推荐采用 U-Net 编码器-解码器架构 [1][2]：

**编码器**：
- 4 级编码块，每块含 Conv→ReLU→Conv→ReLU→MaxPooling
- 前两级卷积核大小 5，后两级卷积核大小 3 [1]
- 每级滤波器数量翻倍

**解码器**：
- 对称的 4 级解码块，通过反卷积和上采样恢复空间分辨率
- 编码器-解码器间通过特征拼接（concatenation）连接

**增强模块（可选）**：
- 通道注意力模块（CAM）：全局平均池化 + 全局最大池化 → MLP → sigmoid [2]
- 空间注意力模块（SAM）：通道轴全局池化 → 拼接 → 卷积 → sigmoid [2]
- 注意力机制可加速收敛并降低训练损失（3000 epoch 内收敛）[2]

**激活函数**：编码层用 LeakyReLU（斜率 0.2），解码层用 ReLU [2]；或统一 ReLU [1]

**损失函数**：L1 损失 [2] 或 MSE 损失

## 边界与分流

- **网格类型不匹配**：若输入为非结构网格，需先映射到规则网格（插值法），或改用图神经网络/点云方法 [4]。插值会引入额外误差，尤其在边界层区域。
- **三维扩展**：本卡片聚焦二维截面预测；三维需改用 3D U-Net，显存需求急剧增加，可考虑逐截面预测 + 后处理拼接。
- **物理约束缺失**：纯数据驱动 CNN 不保证质量/动量守恒。若需守恒性，应引入物理信息神经网络（PINN）损失项或后处理校正。
- **训练数据不足**：当几何参数空间采样不足时，模型泛化能力差。应增加采样密度或采用迁移学习/数据增强。
- **边界层精度不足**：CNN 在几何边界层区域误差最大 [1]。可通过自适应网格加密（近壁区更高分辨率）或注意力机制缓解 [2]。
- **雷诺数外推**：训练集雷诺数范围外的预测不可靠，需在训练集中覆盖目标雷诺数范围。

## 质量检查

1. **网格独立性**：CFD 数据生成前必须完成网格独立性验证（如阻力系数随网格加密变化 <5%）
2. **数据分布验证**：对比 CNN 预测与 CFD 结果的统计分布（均值、标准差、直方图），极端值区域需特别关注 [1]
3. **速度剖面验证**：在关键截面（如尾迹区）提取速度剖面，对比 CFD 与 CNN 结果
4. **泛化性测试**：在训练集外的几何/工况上测试，确认误差不显著增大
5. **边界层误差监控**：边界层区域是主要误差源，需单独统计该区域的误差
6. **物理合理性检查**：预测场是否满足基本物理约束（如壁面速度为零、压力分布单调性等）

## 回退策略

- 若 U-Net 精度不足，可尝试：(a) 增加网络深度/宽度；(b) 引入注意力机制；(c) 使用多尺度损失函数；(d) 改用 Fourier Neural Operator (FNO) 等算子学习方法
- 若训练数据不足，可尝试：(a) 数据增强（旋转、缩放）；(b) 迁移学习（从相似几何预训练模型微调）；(c) 半监督学习
- 若边界层精度不足，可采用：(a) 局部网格加密后的 CNN；(b) 混合方法（CNN 预测外场 + 传统方法求解边界层）
