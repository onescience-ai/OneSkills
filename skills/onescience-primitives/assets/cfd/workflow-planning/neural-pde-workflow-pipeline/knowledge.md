# 神经PDE工作流管道

## 适用范围
本卡片定义了神经PDE求解器开发的标准工作流管道，适用于需要从原始PDE轨迹数据训练神经网络模型并进行物理一致性验证的场景。流程涵盖数据接入、预处理、模型训练、批量推理和任务验收五个阶段，每个阶段有明确的输入输出契约和质量门禁。

## 输入
- **PDE轨迹数据集**：长时间序列的流场或其他物理场数据
- **数据契约定义**：变量、单位、网格坐标系的结构化描述
- **切分配置**：训练/验证/测试集的比例和切分策略
- **训练配置**：框架、超参数、随机种子等
- **推理配置**：设备、批大小等

## 输出
- **数据清单与契约**：dataset_manifest.json, data_contract.json, data_audit.md
- **切分结果**：train_manifest.json, validation_manifest.json, test_manifest.json, normalization.json
- **训练产物**：best_checkpoint.pt, train_config.json, training_metrics.csv, environment.txt
- **推理结果**：predictions/, inference_manifest.json, timing.csv
- **评估报告**：evaluation.json, worst_cases.csv, applicability_report.md, PASS_REJECT_BLOCKED.txt

## 流程节点
1. **数据接入与契约核验** → 检查数据完整性、变量定义、坐标系、缺失值，生成机器可读契约
2. **预处理与数据切分** → 统一物理量表示，按几何或时间无泄漏切分，保存统计量
3. **模型配置与训练** → 加载切分数据，训练神经PDE求解器，记录训练指标
4. **批量推理与物理恢复** → 在测试集上推理，反归一化恢复物理单位和网格
5. **任务验收与适用域判定** → 多维度评估，给出PASS/REJECT/BLOCKED结论

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 训练集比例 | 0.7 | 默认配置 | 总数据的70%用于训练 |
| 验证集比例 | 0.15 | 默认配置 | 总数据的15%用于验证 |
| 测试集比例 | 0.15 | 默认配置 | 总数据的15%用于测试 |
| 默认随机种子 | 42 | 默认配置 | 保证切分可复现 |
| 切分单位 | geometry_or_trajectory | 默认配置 | 按几何或完整轨迹切分 |
| 默认设备 | cuda | 默认配置 | GPU推理加速 |
| 推理批大小 | 8 | 默认配置 | 按显存调整 |

## 边界与分流
- **数据缺失**：缺少必填输入时返回BLOCKED，列出缺项清单
- **数据质量不合格**：变量定义不完整或存在训练测试泄漏时，拒绝进入后续流程
- **训练失败**：损失非有限值或权重无法加载时，需检查数据和配置
- **推理异常**：预测出现NaN/Inf时，需检查模型和输入数据
- **适用域不确定**：超出训练分布的工况，需附加CFD复核要求

## 质量检查
- 数据文件可读且样本可追溯
- 输入目标变量单位坐标定义完整
- 三份切分的对象轨迹互斥
- 仅用训练集计算变换统计量
- 训练验证损失均为有限值
- 最佳权重可重新加载
- 配置环境随机种子可复现
- 预测无NaN或Inf且形状单位正确
- 每个测试样本有唯一结果
- 推理未使用测试目标校正
- 统计与物理指标同时报告
- 最差样本可追溯
- 结论含适用域限制与复核建议

## 回退策略
- 数据契约不完整：返回BLOCKED，等待用户补充数据定义
- 切分失败：检查切分配置和数据完整性
- 训练收敛失败：调整超参数或检查数据分布
- 推理异常：检查模型权重和预处理流程
- 评估不确定：默认PASS但附加更严格复核
