# PINN湍流RANS均值流求解 - 任务验收与适用域判定

## 适用范围

本步骤用于PINN湍流RANS均值流求解与闭合的验收阶段，负责评估统计误差、关键物理约束、泛化能力和计算收益，给出PASS/REJECT/BLOCKED判定，明确适用域限制与复核建议。

**触发条件**：
- 方程求解与物理残差恢复已完成
- 需要评估模型性能并给出验收结论

**不适用场景**：
- 仅需训练指标且无需验收的场景
- 方程求解未完成的情况

## 输入

- **{METRICS}**：验收指标（统计和物理指标）
- **{MAX_RELATIVE_L2}**：相对误差门限（测试集放行阈值）
- **{RUN_OOD_TEST}**：是否外推测试（测试域外工况）

## 输出

- **evaluation.json**：评估结果（逐变量误差、边界误差、守恒误差等）
- **worst_cases.csv**：最差样本（最差预测工况）
- **applicability_report.md**：适用域报告（能力边界与复核建议）
- **PASS_REJECT_BLOCKED.txt**：验收结论

## 流程节点

```
计算统计误差 → 计算物理约束 → 识别最差样本 → 执行外推测试 → 评估计算收益 → 生成验收结论
```

### 关键步骤说明

1. **计算统计误差**：计算逐变量相对L2误差、边界误差等
2. **计算物理约束**：计算守恒误差、方程残差等
3. **识别最差样本**：识别并分析最差预测工况
4. **执行外推测试**：如果{RUN_OOD_TEST}为true，测试几何或工况外推
5. **评估计算收益**：评估推理成本与精度权衡
6. **生成验收结论**：按{MAX_RELATIVE_L2}及任务物理门限给出判定

## 边界与分流

**关键前提与改道**：

1. **前提：方程求解与物理残差恢复已完成**
   - 不成立时 → 先执行方程求解步骤

2. **前提：验收指标合理且可计算**
   - 不成立时 → 调整指标或计算方法

3. **前提：外推测试工况合理**
   - 不成立时 → 调整外推范围或方法

## 质量检查

- **统计与物理指标同时报告**：不能仅凭平均误差宣称工程可用
- **最差样本可追溯**：必须识别并分析最差预测工况
- **结论含适用域限制与复核建议**：域外工况需经CFD复核

## 回退策略

1. **验收不通过**：分析原因，调整模型或数据
2. **外推能力不足**：增加训练工况多样性或迁移学习
3. **计算成本过高**：优化推理效率或降低精度要求
