# 预处理与数据切分

## 适用范围

**触发条件**：
- 已通过数据接入与契约核验，需要进行预处理与无泄漏切分
- 需要统一物理量表示，按几何、工况或时间构造互斥切分
- 需要保存统计量与可逆变换

**适用场景**：
- 多保真代理辅助翼型优化的预处理阶段
- 需要无量纲化或归一化跨工况数据
- 需要按对象轨迹分组切分避免数据泄漏

**不适用场景**：
- 单一工况无需分组切分的简单数据
- 无需归一化或无量纲化的场景

## 输入

**必需输入**：
- 切分配置（train/val/test比例、种子、分组依据）
- 目标变量列表

**可选输入**：
- 是否无量纲化（默认true）

**预处理要求**：
- 依赖s01的数据契约与数据清单

## 输出

**核心产物**：
- train_manifest.json：训练集清单
- validation_manifest.json：验证集清单
- test_manifest.json：测试集清单
- normalization.json：归一化统计量与变换参数

**验证标准**：
- 三份切分的对象轨迹互斥
- 仅用训练集计算变换统计量
- 边界与掩膜语义未破坏

## 流程节点

### Step 1：物理量统一
- **操作**：按数据契约统一物理量表示，执行无量纲化或归一化
- **参数**：目标变量、是否无量纲化
- **工具**：归一化库、统计量计算工具
- **质量门禁**：仅用训练集计算变换统计量

### Step 2：分组切分
- **操作**：按几何、完整轨迹或物理工况为单位切分，不得把同一轨迹的帧随机打散
- **参数**：切分配置（train比例、val比例、test比例、seed、group_by）
- **工具**：数据切分库
- **质量门禁**：三份切分的对象轨迹互斥

### Step 3：变换保存
- **操作**：保存统计量与可逆变换，确保可以反向还原
- **参数**：归一化参数
- **工具**：序列化工具
- **质量门禁**：变换可逆，统计量可追溯

### Step 4：清单生成
- **操作**：生成三份切分清单与归一化参数文件
- **参数**：切分结果、变换参数
- **工具**：JSON序列化工具
- **质量门禁**：清单文件可被标准JSON解析

## 边界与分流

**分组依据不可用时的改道**：
- 无几何参数化信息 → 退化为按工况分组
- 无轨迹信息 → 退化为随机切分（需标注风险）

**无量纲化失败时的改道**：
- 物理量尺度差异过大 → 尝试对数变换或分位数变换
- 存在零值或负值 → 调整变换策略

**切分后数据量不足时的改道**：
- 某一切分子集样本过少 → 调整切分比例或使用交叉验证

## 质量检查

| 检查项 | 阈值/判据 | 失败处理 |
|--------|-----------|----------|
| 轨迹互斥 | 0重叠 | 重新切分 |
| 统计量来源 | 仅训练集 | 重新计算 |
| 边界语义 | 未破坏 | 检查约束条件 |
| 清单完整性 | 三份清单均生成 | 检查切分流程 |
| 变换可逆性 | 可反向还原 | 检查变换参数 |

## 回退策略

- 切分后数据量不足 → 调整切分比例或使用交叉验证
- 归一化失败 → 尝试其他变换方法
- 清单生成失败 → 检查切分结果完整性
