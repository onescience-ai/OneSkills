# 跨声速气动弹性降阶模型适用域判定

## 适用范围
评估跨声速气动弹性降阶模型在不同工况下的适用性和限制，确定模型的有效使用范围。

## 输入
- 训练工况定义
- 测试工况集
- 降阶模型性能指标

## 输出
- 适用域报告
- 限制条件说明
- 复核建议

## 流程节点
1. **工况空间定义** → 定义马赫数、攻角等工况参数范围
2. **测试工况选择** → 选择代表性测试工况
3. **性能评估** → 在测试工况上评估模型性能
4. **边界识别** → 识别模型性能显著下降的工况边界
5. **适用域划定** → 划定模型有效使用范围
6. **报告生成** → 生成适用域报告和复核建议

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 马赫数范围 | 0.7-1.2 | [1] | 跨声速范围 |
| 攻角范围 | -5°~15° | [1] | 包含失速工况 |
| 误差门限 | <10% | [1] | 相对L2误差 |

## 边界与分流
- **工况超出适用域**：需经CFD复核
- **强非线性工况**：考虑非线性降阶方法
- **多工况扩展**：构建LPV模型

## 质量检查
- 适用域边界清晰
- 测试工况覆盖充分
- 复核建议明确

## 回退策略
- 采用全耦合CFD仿真验证
- 使用其他降阶方法
- 扩展训练工况范围
