# CFD模型验收标准产物规格

## 适用范围
适用于所有CFD代理模型验收场景，包括性能评估、适用域判定和交付物标准化。具体指标阈值需根据领域调整。

## 输入
- 模型预测结果
- 真实值（CFD仿真或实验数据）
- 约束定义
- 数据分布信息

## 输出
- evaluation.json（四维度评估报告）
- worst_cases.csv（最差样本追溯）
- applicability_report.md（适用域报告）
- PASS_REJECT_BLOCKED.txt（验收结论）

## 流程节点
1. **评估计算** → 计算统计指标（R²、RMSE、MAE）
2. **物理约束检查** → 验证预测是否满足物理约束
3. **最差样本识别** → 按误差排序取top-N最差样本
4. **适用域分析** → 基于数据分布划定适用域
5. **验收判定** → 根据双门槛规则判定PASS/REJECT/BLOCKED
6. **报告生成** → 生成标准化产物

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| R²阈值 | >0.9 | 用户自有 | 统计指标门槛 |
| RMSE阈值 | <0.1 | 用户自有 | 统计指标门槛 |
| 物理约束 | 阻力系数>0 | 用户自有 | 硬约束 |
| 最差样本数 | 10 | 用户自有 | 追溯样本数 |
| 置信水平 | 95% | 用户自有 | 适用域定义 |

## 边界与分流
- 若无真实值，可使用交叉验证或合成数据验证
- 若物理约束复杂，需领域专家定义约束函数
- 若数据分布偏移，需重新评估适用域

## 质量检查
- 验证四个产物文件是否存在
- 检查worst_cases.csv可追溯到具体样本
- 验证applicability_report.md包含适用域限制和复核建议

## 回退策略
- 若统计指标不达标，可降低模型复杂度或增加数据
- 若物理约束冲突，需重新定义约束优先级
