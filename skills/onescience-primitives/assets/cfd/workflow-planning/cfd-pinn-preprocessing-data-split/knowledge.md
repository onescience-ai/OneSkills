# 稀疏观测PINN数据预处理与无泄漏切分

## 适用范围

适用于PINN湍流闭合反演场景中，从原始数据到训练就绪数据集的预处理与切分。核心约束：以几何、完整轨迹或物理工况为单位切分，不得把同一轨迹的帧随机打散，确保训练集与测试集无信息泄漏。

## 输入

- **s01契约**：dataset_manifest.json、data_contract.json
- **切分配置** {SPLIT_CONFIG}：train/val/test比例、随机种子、分组依据
- **目标变量** {TARGET_FIELDS}：待预测物理量列表
- **无量纲化开关** {NONDIMENSIONALIZE}：是否统一跨工况量纲

## 输出

- **train_manifest.json**：训练集清单
- **validation_manifest.json**：验证集清单
- **test_manifest.json**：测试集清单
- **normalization.json**：归一化统计量（均值、标准差、变换参数），仅由训练集计算

## 流程节点

1. 读取s01契约与原始数据
2. 质控（剔除异常值、处理缺失值）
3. 重采样或图构建（如需要）
4. 按{SPLIT_CONFIG}以几何/轨迹/工况为单位互斥切分
5. 仅用训练集计算归一化/无量纲化统计量
6. 对三份切分应用变换，保存可逆参数
7. 输出清单与归一化配置

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 切分比例 | train:0.7, val:0.15, test:0.15 | [场景需求书s02] | 默认配置 |
| 随机种子 | 42 | [场景需求书s02] | 可复现性 |
| 分组依据 | geometry_or_trajectory | [场景需求书s02] | 按对象或轨迹分组 |
| 无量纲化 | true | [场景需求书s02] | 统一跨工况量纲 |
| 目标变量 | 按data_contract.json填写 | [场景需求书s02] | 待预测物理量 |

## 边界与分流

- 切分后三份数据集存在对象重叠 → 报错，要求重新切分
- 归一化统计量来自非训练集数据 → 报错，要求仅用训练集重算
- 边界与掩膜语义被破坏 → 检查切分是否破坏了几何连续性
- 目标变量缺失 → 返回BLOCKED

## 质量检查

- 三份切分的对象轨迹互斥（无样本同时出现在train和test中）
- 仅用训练集计算变换统计量（normalization.json中的统计量仅来自train）
- 边界与掩膜语义未破坏（几何边界条件在各切分中保持一致）

## 回退策略

- 切分比例不合理 → 根据数据量调整比例
- 归一化失败 → 检查数据格式，尝试替代归一化方法
- 轨迹切分困难 → 降级为随机切分并标注风险
