# Differentiable PDE-GNN与Physics-aware Data Assimilation架构规范

## 适用范围
当需要构建结合物理约束和图神经网络的CFD代理模型时使用本知识。适用于流体模拟、天气预报、材料设计等需要物理一致性的机器学习任务。不适用于纯数据驱动的黑箱模型或无物理约束的神经网络。

## 输入
- 网格数据：节点坐标、边连接关系、初始条件
- 物理参数：雷诺数、粘度、边界条件
- 观测数据：有限点位的测量值
- 训练配置：损失权重、学习率、批量大小

## 输出
- 模型架构：GNN层定义、PDE残差计算模块
- 训练记录：损失曲线、物理约束满足度
- 预测结果：流场预测、物理量分布
- 评估报告：统计误差、物理约束验证

## 流程节点
1. 架构设计 → 2. 物理约束定义 → 3. 损失函数配置 → 4. 联合训练 → 5. 评估验证

每步含：
- **操作**：GNN层设计、PDE残差计算、损失权重调整
- **参数**：消息传递轮数、隐藏层维度、损失权重
- **工具**：PyTorch Geometric、DeepXDE、FEniCS
- **质量门禁**：物理约束满足度、收敛性检查、泛化能力测试

## 关键参数

### 通用判据（方法层，同类体系可参考）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 消息传递轮数 | 3-5轮 | 通用实践 | 平衡表达能力和计算效率 |
| 隐藏层维度 | 64-256 | 通用实践 | 根据问题复杂度调整 |
| 物理损失权重 | 0.1-1.0 | 通用实践 | 平衡数据拟合和物理约束 |
| 学习率 | 1e-3 to 1e-4 | 通用实践 | 根据收敛情况调整 |

### 校准数值（体系专属值）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| PDE残差权重 | 0.5 | 任务需求 | 物理约束重要性 |
| 数据拟合权重 | 1.0 | 任务需求 | 观测数据重要性 |
| 边界条件权重 | 0.3 | 任务需求 | 边界约束重要性 |

以下数值来自任务需求，供量级校准；其他体系需以自身证据重新锚定。

## 边界与分流
- **收敛困难**：调整学习率、增加训练轮数或简化模型架构
- **过拟合**：增加正则化、使用早停或增加数据量
- **物理约束不满足**：增加物理损失权重或改进PDE残差计算
- **计算资源不足**：减少模型复杂度或使用混合精度训练

## 质量检查
1. 收敛性：损失函数稳定下降
2. 物理一致性：预测结果满足守恒定律
3. 泛化能力：在未见数据上表现良好
4. 计算效率：推理时间在可接受范围内

## 回退策略
- 如果模型无法收敛，尝试简化架构或调整超参数
- 如果物理约束无法满足，增加约束权重或改进物理模块
- 如果计算资源不足，使用模型压缩或知识蒸馏
