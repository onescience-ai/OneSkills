# 对称PDE预处理与数据切分

## 适用范围

本卡片服务于对称PDE数据的预处理阶段。在数据接入与契约核验完成后，需要对PDE快照数据进行物理量统一、归一化或无量纲化，并按轨迹/几何/工况构造无泄漏的训练-验证-测试切分。适用于时间序列PDE数据（快照序列）、空间场数据、参数化PDE族数据。不适用于：静态单帧数据（无需轨迹切分逻辑）；纯散点数据（需额外图构建预处理）。

## 输入

- s01输出的data_contract.json（变量、单位、坐标定义）
- 切分配置（{SPLIT_CONFIG}）：train/val/test比例、切分维度
- 目标变量列表（{TARGET_FIELDS}）
- 是否无量纲化（{NONDIMENSIONALIZE}）

## 输出

- train_manifest.json：训练集清单
- validation_manifest.json：验证集清单
- test_manifest.json：测试集清单
- normalization.json：归一化统计量（均值、方差或min/max）

## 流程节点

1. **物理量统一** → 按data_contract.json统一变量名称和单位
2. **重采样或图构建** → 根据网格类型进行空间重采样或图构建
3. **掩膜处理** → 处理边界掩膜和无效区域
4. **归一化或无量纲化** → 仅用训练集计算统计量，保存可逆变换参数
5. **无泄漏切分** → 以几何/完整轨迹/物理工况为单位切分
6. **统计量保存** → 保存到normalization.json用于推理反变换

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 切分维度 | geometry_or_trajectory | 场景JSON s02 | 禁止打散同一轨迹帧 |
| 泄漏防护 | 三份切分对象轨迹互斥 | 场景JSON s02 quality_gate | 强制门禁 |
| 统计量来源 | 仅用训练集 | 场景JSON s02 quality_gate | 防止数据泄漏 |

## 边界与分流

- **轨迹数据无法按帧切分**：必须以完整轨迹为单位，即使单条轨迹很长
- **无量纲化参数异常（如方差为零）**：跳过该变量的无量纲化，记录到normalization.json
- **边界掩膜语义被破坏**：quality_gate不通过，BLOCKED
- **多物理场耦合数据**：需为每个物理场独立保存变换参数

## 质量检查

- 三份切分的对象轨迹互斥（质量门禁）
- 仅用训练集计算变换统计量（质量门禁）
- 边界与掩膜语义未破坏（质量门禁）
- normalization.json包含所有目标变量的变换参数

## 回退策略

- 切分比例不满足需求：调整配置重新切分
- 无量纲化失败：使用原始量纲，但在模型训练中可能出现梯度问题
