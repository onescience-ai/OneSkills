# 任务验收与适用域判定任务

## 适用范围

本任务描述数据驱动湍流代理模型构建的第五步：评估统计误差、关键物理约束、泛化能力和计算收益，判定模型是否通过验收并明确适用域。这是确保模型工程可用性的最终步骤。

**适用场景**：
- 高超声速冷壁边界层湍流代理模型验收
- 跨声速机翼CFD数据驱动模型验收
- 需要评估泛化能力和适用域的模型
- 需要明确工程可用边界的模型

**不适用场景**：
- 仅需先验评估的模型
- 无法进行外推测试的模型
- 非工程应用场景

## 输入

- **{METRICS}**（必填）：验收指标列表，默认["closure_RMSE", "mean_profile_error", "spectrum_error", "stability_horizon"]
- **{MAX_RELATIVE_L2}**（可选）：相对误差门限，默认0.1
- **{RUN_OOD_TEST}**（可选）：是否外推测试，默认true

## 输出

- **evaluation.json**：评估结果
- **worst_cases.csv**：最差样本记录
- **applicability_report.md**：适用域报告
- **PASS_REJECT_BLOCKED.txt**：验收结论

## 流程节点

```
加载后验结果 → 计算统计误差 → 评估物理约束 → 执行外推测试 → 分析最差样本 → 判定适用域 → 输出验收结论
```

### 操作步骤

1. **加载后验结果**：读取s04输出的后验流场和稳定性记录
2. **计算统计误差**：计算各指标的统计误差
3. **评估物理约束**：验证湍流可实现性、能量守恒等
4. **执行外推测试**：若{RUN_OOD_TEST}为true，测试域外工况
5. **分析最差样本**：找出误差最大的样本，分析原因
6. **判定适用域**：根据测试结果明确模型适用范围
7. **输出验收结论**：给出PASS、REJECT或BLOCKED结论

## 边界与分流

**关键前提与分流策略**：

1. **前提：后验结果可用**
   - 不成立时：需返回s04重新进行后验验证
   - 分流目标：完成闭合项预测与后验CFD耦合

2. **前提：统计误差满足门限**
   - 不成立时：若误差超标，需返回s03调整模型
   - 分流目标：重新训练或调整模型结构

3. **前提：物理约束满足**
   - 不成立时：若物理约束不满足，需添加约束到损失函数
   - 分流目标：使用物理信息神经网络方法

4. **前提：外推测试通过**
   - 不成立时：若外推失败，需明确适用域限制
   - 分流目标：在适用域报告中标注复核建议

## 质量检查

**验证点**：
- 统计与物理指标同时报告
- 最差样本可追溯
- 结论含适用域限制与复核建议
- 验收结论明确

**阈值**：
- 相对误差门限：0.1（测试集放行）
- 物理约束：湍流可实现性、能量守恒

**失败处理**：
- 误差超标：返回s03调整模型
- 物理约束不满足：添加约束到损失函数
- 外推失败：明确适用域限制

## 回退策略

1. **后验结果不可用**：返回s04重新进行后验验证
2. **误差超标**：返回s03调整模型
3. **物理约束不满足**：添加约束到损失函数
4. **外推失败**：明确适用域限制，标注复核建议
