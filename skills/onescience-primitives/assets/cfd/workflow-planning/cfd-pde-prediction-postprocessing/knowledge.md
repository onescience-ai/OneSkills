# PDE预测后处理与物理量恢复

## 适用范围

**触发条件**：
- 需要将归一化空间的模型预测恢复为原始物理量
- 需要将预测张量与网格坐标和时间步关联
- 需要从预测场计算物理派生量（涡度、压力、动能等）
- 推理步骤要求恢复原始单位、网格和物理派生量

**适用场景**：
- PDE神经算子（FNO、DeepONet、Mamba-NO）的推理后处理
- 与传统CFD结果的对比分析
- 物理可解释性分析（从预测场提取物理量）
- 推理结果的标准化输出（含网格坐标和单位信息）

**不适用场景**：
- 纯统计误差评估（无需物理量恢复）
- 归一化空间内的模型对比（无需逆变换）
- 无网格信息的黑盒预测

## 输入

- 归一化空间的预测张量 u_pred_normalized
- 训练集统计量（mean, std）用于逆归一化
- 网格坐标信息（x, y, z坐标和时间步t）
- PDE类型和物理量单位信息

## 输出

- 逆归一化后的预测场 u_pred_original（原始物理量单位）
- 关联网格坐标的预测结果（含空间坐标和时间步）
- 物理派生量（如涡度、压力、动能等）
- 推理耗时记录（timing.csv，含per-sample推理时间）

## 流程节点

### Step 1：逆归一化
- **操作**：使用训练集统计量将预测值从归一化空间恢复到原始物理量空间
- **公式**：u_original = u_normalized * std + mean
- **参数**：mean（训练集均值）、std（训练集标准差）
- **工具**：NumPy/PyTorch
- **质量门禁**：逆归一化后数值范围与训练数据一致

### Step 2：网格坐标关联
- **操作**：将预测张量的索引与实际空间坐标和时间步对应
- **方法**：从数据文件中读取坐标信息，建立索引→坐标的映射
- **参数**：x_coords, y_coords, z_coords, t_coords
- **工具**：NumPy/h5py
- **质量门禁**：每个预测点有对应的空间坐标和时间步

### Step 3：物理派生量计算
- **操作**：从原始变量（如速度场u）计算衍生物理量
- **涡度**：ω = ∂v/∂x - ∂u/∂y（二维）或 ∇×u（三维）
- **动能**：KE = 0.5 * (u² + v² + w²)
- **应变率**：ε_ij = 0.5*(∂u_i/∂x_j + ∂u_j/∂x_i)
- **参数**：原始预测场、网格间距
- **工具**：NumPy梯度计算
- **质量门禁**：派生量量级合理，无数值爆炸

### Step 4：结果保存
- **操作**：将逆归一化后的预测和派生量保存为标准格式
- **格式选择**：
  - HDF5（推荐，支持大数组和元数据）
  - VTK（适用于可视化）
  - NetCDF（适用于气象/气候数据）
- **必含信息**：预测场、网格坐标、时间步、单位信息、模型配置
- **工具**：h5py/vtk/netCDF4
- **质量门禁**：输出文件可被标准工具读取

### Step 5：推理耗时记录
- **操作**：记录per-sample和总推理耗时
- **格式**：timing.csv（含sample_id, inference_time列）
- **参数**：推理时间戳
- **工具**：time.time()或timeit
- **质量门禁**：耗时记录准确，格式为CSV

### Step 6：可追溯性元数据
- **操作**：记录每个预测样本的完整溯源信息
- **内容**：输入条件、模型配置、推理参数、预处理步骤
- **格式**：inference_manifest.json
- **工具**：json.dump
- **质量门禁**：元数据完整，可追溯到具体输入和配置

## 边界与分流

- **训练集统计量不可用**：使用预测数据自身的统计量（不推荐，可能导致偏差）
- **网格信息缺失**：使用均匀网格假设，在报告中标注
- **物理派生量计算不稳定**：降低派生量阶数（如从二阶导数降为一阶导数）
- **输出格式不兼容**：同时输出HDF5和VTK格式，确保兼容性

## 质量检查

- [ ] 逆归一化后的数值范围与训练数据一致
- [ ] 每个预测点有关联的空间坐标和时间步
- [ ] 物理派生量量级合理（无数值爆炸）
- [ ] 输出文件包含单位信息
- [ ] timing记录为CSV格式且含per-sample数据
- [ ] inference_manifest.json包含完整溯源信息

## 回退策略

- 若网格坐标不可用，输出仅含索引的预测结果，在报告中标注
- 若物理派生量计算失败，跳过派生量，仅保存原始预测场
- 若HDF5不可用，降级为NPZ格式
