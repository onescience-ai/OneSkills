# CFD模型泛化能力评估标准方法

## 适用范围
当需要评估CFD代理模型（如神经网络、高斯过程、多项式混沌展开）的泛化能力和计算收益时使用本知识。适用于模型选择、性能对比、工程应用验证等场景。不适用于模型训练或数据预处理。

## 输入
- 训练好的模型
- 训练数据集和验证数据集
- 测试数据集（不同几何、工况、边界条件）
- 传统求解器基准（用于计算收益评估）

## 输出
- 泛化能力评估报告：外推测试结果、交叉验证分数
- 计算收益报告：加速比、精度-效率权衡
- 模型适用性声明：适用场景和限制条件

## 流程节点
1. 测试数据集设计 → 2. 泛化能力评估 → 3. 计算收益评估 → 4. 结果分析 → 5. 适用性声明

每步含：
- **操作**：外推测试、交叉验证、基准测试
- **参数**：测试用例数量、验证折数、基准求解器配置
- **工具**：scikit-learn、时间测量工具、统计分析工具
- **质量门禁**：测试覆盖度、结果可重复性、统计显著性

## 关键参数

### 通用判据（方法层，同类体系可参考）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 外推测试用例数 | ≥5 | 通用实践 | 确保统计显著性 |
| 交叉验证折数 | 5-10 | 通用实践 | 平衡偏差和方差 |
| 基准求解器精度 | 工程可接受精度 | 通用实践 | 确保基准可靠 |
| 计算时间测量 | 多次运行取平均 | 通用实践 | 减少测量误差 |

### 校准数值（体系专属值）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 外推测试维度 | 几何、雷诺数、边界条件 | 任务需求 | 测试模型外推能力 |
| 计算收益基准 | 传统CFD求解器 | 任务需求 | 比较计算效率 |

以下数值来自任务需求，供量级校准；其他体系需以自身证据重新锚定。

## 边界与分流
- **测试数据不足**：使用合成数据或公开基准数据集
- **计算资源有限**：使用代理模型评估或采样方法
- **结果不显著**：增加测试用例或调整评估指标
- **模型过拟合**：增加正则化或使用交叉验证

## 质量检查
1. 测试覆盖度：覆盖不同几何、工况、边界条件
2. 结果可重复性：多次运行结果一致
3. 统计显著性：结果具有统计意义
4. 计算收益准确：基于实际测试而非估计

## 回退策略
- 如果外推测试数据不足，使用公开基准数据集
- 如果计算资源有限，使用采样估计或代理基准
- 如果结果不显著，调整评估指标或增加测试用例
