# 科研任务工作流管理：时间预算与脚本兼容性

## 适用范围

面向科研任务工作流管理，当需要分配时间预算、处理跨平台脚本编码或使用PowerShell命令时召回本卡片。适用于所有在Windows环境执行的Python脚本。

## 输入

- 工作流步骤列表
- 计算资源信息
- 脚本执行环境（Windows/Linux）

## 输出

- 时间预算分配方案
- 兼容性脚本
- 执行日志

## 流程节点

1. 评估步骤复杂度 → 2. 分配时间预算 → 3. 处理脚本编码 → 4. 适配命令语法

### 步骤1：评估步骤复杂度
- 操作：分析各步骤的计算需求和风险
- 参数：步骤类型、数据规模、计算资源
- 工具：经验评估
- 质量门禁：复杂度评估合理

### 步骤2：分配时间预算
- 操作：为各步骤分配独立时间预算
- 参数：总预算、步骤复杂度、风险系数
- 工具：预算分配算法
- 质量门禁：预算分配合理，关键步骤有足够时间

### 步骤3：处理脚本编码
- 操作：确保Python脚本在Windows环境下正确处理Unicode字符
- 参数：脚本内容、目标编码
- 工具：Python编码设置
- 质量门禁：脚本无编码错误

### 步骤4：适配命令语法
- 操作：将Bash命令语法适配为PowerShell语法
- 参数：原始命令、目标Shell
- 工具：语法转换
- 质量门禁：命令在PowerShell中可执行

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 时间预算分配原则 | 高风险步骤预留更多时间 | 通用知识 | 模型训练等高风险步骤需更多时间 |
| Python默认编码 | UTF-8 | [D1] | Python 3默认使用UTF-8编码 |
| PowerShell命令分隔符 | 分号(;) | 通用知识 | PowerShell不支持Bash的&&语法 |

### 校准数值
以下数值来自典型科研任务，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据接入步骤预算 | 5-10分钟 | 经验值 | 根据数据规模调整 |
| 模型训练步骤预算 | 30-60分钟 | 经验值 | 根据模型复杂度调整 |
| 在线检索步骤预算 | 5-15分钟 | 经验值 | 根据检索复杂度调整 |

## 边界与分流

- 如果时间预算不足，应优先保证关键步骤（模型训练）
- 如果编码问题无法解决，可尝试使用ASCII兼容的输出
- 如果PowerShell语法不兼容，可使用cmd或WSL

## 质量检查

- 验证时间预算分配是否合理
- 验证脚本在Windows环境下无编码错误
- 验证命令在PowerShell中可执行

## 回退策略

- 如果时间预算超支，可调整后续步骤预算
- 如果编码问题持续，可使用二进制输出避免文本编码
- 如果PowerShell不兼容，可使用批处理文件(.bat)

## 资源召回建议

- 当在Windows环境执行Python脚本时召回本卡片
- 当需要分配科研任务时间预算时召回本卡片
- 配套资源：execution-manifest.json知识卡片、等变神经算子实现卡片
