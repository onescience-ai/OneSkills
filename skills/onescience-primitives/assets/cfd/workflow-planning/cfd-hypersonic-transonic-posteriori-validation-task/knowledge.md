# 闭合项预测与后验CFD耦合任务

## 适用范围

本任务描述数据驱动湍流代理模型构建的第四步：先验评估闭合项，再嵌入RANS或LES执行稳定后验推进，验证模型在真实CFD求解器中的表现。这是确保代理模型物理一致性的关键步骤。

**适用场景**：
- 高超声速冷壁边界层湍流闭合项预测
- 跨声速机翼CFD代理模型后验验证
- 需要嵌入RANS/LES求解器的代理模型
- 需要评估物理一致性的湍流模型

**不适用场景**：
- 仅需先验误差评估的场景
- 无法嵌入CFD求解器的代理模型
- 非湍流闭合项预测任务

## 输入

- **{CHECKPOINT}**（必填）：模型权重路径，默认best_checkpoint.pt
- **{DEVICE}**（必填）：计算设备，默认cuda
- **{BATCH_SIZE}**（可选）：推理批大小，默认8

## 输出

- **apriori_closure/**：先验闭合项预测结果
- **aposteriori_fields/**：后验流场结果
- **solver_stability.csv**：求解器稳定性记录

## 流程节点

```
加载模型权重 → 预测闭合项 → 先验误差评估 → 嵌入CFD求解器 → 后验推进 → 稳定性监控 → 结果验证
```

### 操作步骤

1. **加载模型权重**：加载{CHECKPOINT}中的最佳权重
2. **预测闭合项**：在独立快照上预测应力、通量或源项
3. **先验误差评估**：计算预测值与真实值的误差
4. **嵌入CFD求解器**：将预测的闭合项嵌入RANS或LES求解器
5. **后验推进**：执行稳定的后验推进
6. **稳定性监控**：记录求解器稳定性、残差、能谱
7. **结果验证**：验证均值剖面与能谱

## 边界与分流

**关键前提与分流策略**：

1. **前提：模型权重可用**
   - 不成立时：需返回s03重新训练模型
   - 分流目标：完成模型配置与训练

2. **前提：闭合项满足约束**
   - 不成立时：若闭合项不满足物理约束，需调整模型
   - 分流目标：添加物理约束到损失函数

3. **前提：后验求解稳定**
   - 不成立时：若求解器发散，需回退为先验评估
   - 分流目标：仅报告先验误差和可实现性检查结果

4. **前提：均值剖面与能谱验证通过**
   - 不成立时：若验证失败，需检查模型或求解器设置
   - 分流目标：调整求解器参数或模型结构

## 质量检查

**验证点**：
- 闭合张量或通量满足约束
- 后验求解无非物理解和发散
- 均值剖面与能谱均经验证
- 求解器稳定性记录完整

**阈值**：
- 先验误差：待确认（根据具体任务）
- 后验稳定性：无发散、无非物理解

**失败处理**：
- 闭合项不满足约束：调整模型
- 后验发散：回退为先验评估
- 验证失败：检查模型或求解器

## 回退策略

1. **模型权重不可用**：返回s03重新训练
2. **闭合项不满足约束**：添加物理约束到损失函数
3. **后验发散**：仅报告先验误差
4. **验证失败**：调整求解器参数或模型结构
