# 任务验收与适用域判定

## 适用范围

本步骤适用于CFD流场不确定性反演工作流的最终阶段，负责评估模型性能并判定适用域。当用户需要评估统计误差、物理约束满足度、泛化能力和计算收益时使用。

## 输入

- **{METRICS}**：验收指标（必填），如relative_L2、NLL、coverage、calibration_error
- **{MAX_RELATIVE_L2}**：相对误差门限（可选），默认0.1
- **{RUN_OOD_TEST}**：是否外推测试（可选），默认true

## 输出

- **evaluation.json**：评估结果，含逐变量误差、边界误差、守恒或方程残差
- **worst_cases.csv**：最差样本列表
- **applicability_report.md**：适用域报告，含几何/工况外推能力评估
- **PASS_REJECT_BLOCKED.txt**：验收结论

## 流程节点

1. 按{METRICS}评价s04结果
2. 报告逐变量误差、边界误差、守恒或方程残差
3. 识别最差样本并追溯
4. 评估推理成本
5. 使用{MAX_RELATIVE_L2}及物理门限给出PASS/REJECT/BLOCKED
6. 若{RUN_OOD_TEST}为true，执行几何或工况外推测试并明确适用域

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 验收指标 | relative_L2, NLL, coverage, calibration_error | 场景需求书 | 默认 |
| 相对误差门限 | 0.1 | 场景需求书 | 测试集放行阈值 |
| 外推测试 | true | 场景需求书 | 默认执行 |

## 边界与分流

- **REJECT**：相对误差超过门限或物理约束不满足时拒绝
- **BLOCKED**：数据或模型不可用时返回BLOCKED
- **域外工况**：几何或工况超出训练分布时需CFD复核

## 质量检查

- 统计与物理指标同时报告
- 最差样本可追溯
- 结论含适用域限制与复核建议

## 回退策略

- REJECT时，返回s03调整模型或s02增加数据
- 物理约束不满足时，增加物理损失权重或修正边界条件

## 资源召回建议

当用户需要执行模型验收与适用域判定时召回本卡片。作为工作流最后一步，输出最终验收结论。
