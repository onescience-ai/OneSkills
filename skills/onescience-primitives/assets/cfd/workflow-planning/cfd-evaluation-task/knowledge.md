# 任务验收与适用域判定任务

## 适用范围
本任务适用于评估壁面压力剪切与积分气动力联合反演的统计误差、关键物理约束、泛化能力和计算收益，判定适用域。适用于任何需要基于壁面测量数据进行气动力反演的场景。

## 输入
- 验收指标：统计和物理指标。
- 相对误差门限：测试集放行阈值。
- 是否外推测试：测试域外工况。

## 输出
- evaluation.json：评估结果。
- worst_cases.csv：最差案例。
- applicability_report.md：适用域报告。
- PASS_REJECT_BLOCKED.txt：验收结论。

## 流程节点
1. 按验收指标评价推理结果，至少报告逐变量误差、边界误差、守恒或方程残差、最差样本和推理成本。
2. 使用相对误差门限及任务物理门限给出PASS、REJECT或BLOCKED。
3. 若运行外推测试为true，执行几何或工况外推测试并明确适用域，不得仅凭平均误差宣称工程可用。

## 关键参数
### 通用判据（方法层）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 相对L2误差门限 | 0.1 | 场景需求书 | 测试集放行阈值 |
| 验收指标 | relative_L2, RMSE, conservation_residual, boundary_error | 场景需求书 | 统计和物理指标 |
| 统计与物理指标同时报告 | true | 质量门禁 | 全面评估 |
| 最差样本可追溯 | true | 质量门禁 | 结果可追溯 |
| 结论含适用域限制与复核建议 | true | 质量门禁 | 明确边界 |

### 校准数值（体系专属值）
以下数值来自翼型壁面压力剪切与积分气动力联合反演场景，供量级校准；其他体系需以自身证据重新锚定。
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 是否外推测试 | true | 场景需求书 | 默认执行外推测试 |

## 边界与分流
- 当统计与物理指标未同时报告时，需补充缺失指标。
- 当最差样本不可追溯时，需重新关联样本信息。
- 当结论未含适用域限制与复核建议时，需补充说明。

## 质量检查
- 统计与物理指标同时报告。
- 最差样本可追溯。
- 结论含适用域限制与复核建议。

## 回退策略
- 若评估失败，可尝试重新加载推理结果或检查评估脚本。
- 若适用域不明确，可尝试增加外推测试用例或调整评估指标。
- 若验收结论为REJECT，可尝试调整模型架构、增加数据量或使用迁移学习。
