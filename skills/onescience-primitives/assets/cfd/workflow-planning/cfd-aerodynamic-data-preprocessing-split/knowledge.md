# 翼型几何流场联合数据预处理与无泄漏切分

## 适用范围

**触发条件**：
- 已完成数据契约核验（s01），需要对翼型几何-流场联合数据进行预处理和切分
- 需要确保训练/验证/测试集切分不破坏几何对象或轨迹的完整性
- 需要对跨工况数据进行无量纲化处理

**适用场景**：
- 气动逆向设计工作流的数据预处理阶段
- 多工况翼型数据的标准化处理
- 需要防止数据泄漏的切分场景

**不适用场景**：
- 数据已预处理完毕的场景
- 非翼型类数据的通用预处理（需适配）

## 输入

- 数据契约（s01输出的 data_contract.json）
- 切分配置（{SPLIT_CONFIG}：train/val/test比例、种子、分组策略）
- 目标变量列表（{TARGET_FIELDS}）
- 是否无量纲化（{NONDIMENSIONALIZE}）

## 输出

- train_manifest.json：训练集清单
- validation_manifest.json：验证集清单
- test_manifest.json：测试集清单
- normalization.json：归一化/无量纲化参数（均值、方差、缩放因子等）

## 流程节点

### Step 1：质控与重采样
- **操作**：根据数据契约进行数据清洗，必要时重采样统一分辨率
- **参数**：目标分辨率、插值方法
- **质量门禁**：数据质量满足下游要求

### Step 2：无量纲化
- **操作**：对物理量进行无量纲化处理（如用参考长度、速度、密度归一化）
- **参数**：参考值、无量纲化公式
- **质量门禁**：仅用训练集计算无量纲化参数

### Step 3：归一化
- **操作**：对输入和目标变量进行归一化（如min-max或z-score）
- **参数**：归一化方法
- **质量门禁**：仅用训练集计算统计量；归一化参数可逆

### Step 4：无泄漏切分
- **操作**：按几何对象或完整轨迹为单位切分，不得把同一轨迹的帧随机打散
- **参数**：切分比例（默认0.7/0.15/0.15）、随机种子、分组策略
- **质量门禁**：三份切分的对象轨迹互斥；同一几何/轨迹不跨集出现

### Step 5：保存统计量
- **操作**：保存归一化/无量纲化参数，确保可逆变换
- **工具**：JSON序列化
- **质量门禁**：normalization.json 完整且可逆

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 切分比例 | train:0.7 / val:0.15 / test:0.15 | [1] | 默认配置 |
| 随机种子 | 42 | [1] | 可复现 |
| 分组策略 | geometry_or_trajectory | [1] | 按对象切分 |
| 无量纲化 | 默认开启 | [1] | 统一跨工况量纲 |
| 仅训练集统计 | true | [1] | 防止数据泄漏 |

## 边界与分流

- **轨迹包含时序帧**：按完整轨迹切分，不拆散单条轨迹的不同帧
- **几何对象数量不足**：增加验证/测试集比例或使用交叉验证
- **无量纲化参数异常**（如参考值为零）：记录异常并使用替代参考值
- **切分后样本分布不均**：记录分布并评估是否需要重采样

## 质量检查

- 三份切分的对象轨迹互斥（同一几何/轨迹不跨集）
- 仅用训练集计算归一化统计量
- 边界与掩膜语义未破坏
- normalization.json 可逆且完整

## 回退策略

- 切分失败：调整分组策略或使用更保守的切分比例
- 无量纲化参数异常：使用简单min-max归一化替代
