# CFD任务中三种扩散模型族的架构差异与训练配置对比

## 适用范围

**触发条件**：
- 需要选择或比较Score-based data assimilation、Diffusion PDE model、Neural fluid field三种模型族
- 需要设计多模型对比实验验证不同模型族在流场重构任务上的性能差异
- 需要理解三种模型族的架构设计差异和适用场景

**适用场景**：
- 部分观测扩散同化与连续流场反演任务（需要训练多个模型族进行对比）
- 流场超分辨率重建（需要选择最适合的模型架构）
- 物理约束深度学习模型选型（需要理解不同模型族的物理约束方式）

**不适用场景**：
- 纯数据驱动、无物理约束需求的流场预测
- 仅需单一模型族的简单任务
- 高维混沌流场（如充分发展湍流）的长期预测

## 输入

**模型配置需求**：
- 任务目标：流场重构、数据同化、参数反演等
- 数据特征：网格类型（结构化/非结构化）、变量数量、时间分辨率
- 物理约束：PDE类型（Navier-Stokes、Burgers等）、守恒律要求
- 计算资源：GPU/CPU、训练时间预算

**输入数据格式**：
- 完整流场或部分观测数据
- 观测掩膜（用于部分观测任务）
- 物理参数（雷诺数、粘度等）

## 输出

**模型产物**：
- 三个独立的训练好的模型权重（best_checkpoint.pt）
- 三个独立的训练配置和训练曲线（training_metrics.json）
- 多模型对比评估报告

**评估指标**：
- 相对L2误差（阈值通常为0.1）
- 频谱误差
- 相关系数
- 物理一致性（散度、能量守恒等）

## 流程节点

### Step 1：模型族选择
- **操作**：根据任务目标和数据特征选择合适的模型族组合
- **质量门禁**：至少选择两个模型族进行对比；选择依据明确

### Step 2：架构设计
- **操作**：为每个模型族设计独立的网络架构
- **质量门禁**：架构设计符合各模型族的标准范式；参数量合理

### Step 3：训练配置
- **操作**：为每个模型族配置独立的训练参数
- **质量门禁**：训练配置包含epochs、batch_size、learning_rate等关键参数；配置可复现

### Step 4：独立训练
- **操作**：分别训练三个模型族，保存独立的权重和训练曲线
- **质量门禁**：每个模型训练完成且收敛；权重文件可重新加载

### Step 5：多模型对比
- **操作**：在相同测试集上评估三个模型族的性能
- **质量门禁**：评估指标完整；对比结论有统计意义

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 模型族数量 | ≥2（推荐3） | 任务需求 | 多模型对比需要足够数量 |
| 训练独立性 | 每个模型独立训练 | 实验设计 | 避免参数共享干扰对比 |
| 评估一致性 | 相同测试集和评估指标 | 实验设计 | 确保对比公平性 |
| 权重保存 | 每个模型保存独立checkpoint | 训练配置 | 便于后续分析和部署 |

### 校准数值（CFD_S097任务示例）

以下数值来自CFD_S097任务，供量级校准；其他任务需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| Score-based模型 | 简化得分网络 + UNet | CFD_S097 | 侧重得分函数估计 |
| Diffusion PDE模型 | PDE约束扩散过程 | CFD_S097 | 结合物理约束的扩散 |
| Neural fluid field | 神经网络参数化连续流场 | CFD_S097 | 侧重连续场表示 |
| 训练epochs | 100-1000 | CFD_S097 | CPU训练需调整预期 |
| batch_size | 8-32 | CFD_S097 | GPU训练推荐值 |

## 边界与分流

- **计算资源不足**：可先训练简化版本进行初步对比，再训练完整版本
- **数据量不足**：选择数据效率更高的模型族（如Physics-informed方法）
- **任务目标单一**：可选择最适合的单一模型族，无需强制多模型对比
- **物理约束复杂**：优先选择PDE约束强的模型族（如Diffusion PDE model）

## 质量检查

- 模型数量：至少训练两个模型族
- 训练收敛：每个模型训练曲线收敛
- 评估完整：三个模型族在相同测试集上评估
- 对比结论：有统计意义的性能差异分析

## 回退策略

- 训练失败：检查模型架构设计和训练配置
- 性能不达标：调整超参数或选择更合适的模型族
- 对比不显著：增加测试样本或调整评估指标
