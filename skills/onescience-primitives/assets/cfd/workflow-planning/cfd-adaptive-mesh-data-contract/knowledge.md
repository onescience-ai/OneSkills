# 自适应有限元网格误差数据标准格式契约

## 适用范围

面向自适应有限元网格优化任务，定义网格误差数据的标准格式契约。适用于学习型网格移动、网格自适应细化、误差驱动的网格优化等场景。本卡规定了数据读取阶段必须遵循的JSON/CSV结构规范，确保下游模型训练和评估步骤可正确加载数据。

## 输入

- 数据源格式：JSON或CSV文件
- 数据内容：网格拓扑信息、物理量、误差指标
- 预处理要求：数据需包含完整的网格几何和拓扑信息

## 输出

- 标准化的数据契约文件（data_contract.json）
- 数据质量审计报告（data_audit.md）
- 格式验证结果

## 流程节点

1. **数据源识别** → 确认数据文件路径和格式
2. **字段解析** → 提取节点坐标、单元连接、误差指示器、目标位移
3. **契约生成** → 生成data_contract.json定义变量映射和单位
4. **质量审计** → 生成data_audit.md记录数据质量检查结果
5. **格式验证** → 检查数据完整性、类型一致性、数值范围

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 节点坐标格式 | JSON: {"nodes": [[x,y,z],...]} | 领域规范 | 三维坐标数组 |
| 单元连接格式 | JSON: {"elements": [[n1,n2,...],...]} | 领域规范 | 节点索引数组 |
| 误差指示器格式 | JSON: {"error_indicators": [e1,e2,...]} | 领域规范 | 每单元误差值 |
| 目标位移格式 | JSON: {"target_displacements": [[dx,dy,dz],...]} | 领域规范 | 节点位移向量 |
| 物理单位 | SI单位制 | 领域规范 | 米(m)、帕斯卡(Pa) |

### 校准数值（体系专属）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 最大节点数 | 无上限，视内存 | 体系约束 | 需考虑计算资源 |
| 最小单元尺寸 | 1e-6 m | 体系约束 | 避免数值奇异 |
| 误差指示器范围 | [0, 1] | 体系约束 | 归一化误差值 |

## 边界与分流

- 数据格式不符合契约：拒绝加载，报告格式错误
- 缺少必要字段（节点坐标、单元连接）：标记为BLOCKED，要求补充数据
- 单位不一致：执行单位转换或标记警告
- 数据量过小（<100节点）：警告可能不足以训练有效模型

## 质量检查

- 验证JSON/CSV格式可正确解析
- 检查节点坐标数值范围合理性（无NaN/Inf）
- 检查单元连接索引有效性（索引在节点范围内）
- 检查误差指示器非负性
- 检查目标位移维度与节点数匹配

## 回退策略

- 数据格式错误：尝试自动转换格式（如CSV转JSON）
- 缺少字段：从其他数据源补充或使用默认值
- 数据量不足：使用数据增强或迁移学习
