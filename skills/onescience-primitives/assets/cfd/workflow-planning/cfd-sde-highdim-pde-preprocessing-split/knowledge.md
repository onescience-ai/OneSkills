# Preprocessing & Data Split for Stochastic PDE

## 适用范围
本任务面向随机微分方程（SDE）与高维偏微分方程（PDE）求解的预处理阶段，执行物理量统一与数据切分。基于数据契约完成质控、重采样、归一化或无量纲化；按几何、工况或轨迹为单位构造无泄漏切分。适用于所有需要物理信息PDE求解的预处理场景，特别强调同一轨迹帧不可被打散。

## 输入
- {SPLIT_CONFIG}：切分配置（train/val/test比例、随机种子、分组策略），必填
- {TARGET_FIELDS}：目标变量列表（待预测物理量），必填
- {NONDIMENSIONALIZE}：是否无量纲化（统一跨工况量纲），可选，默认true

## 输出
- train_manifest.json：训练集清单
- validation_manifest.json：验证集清单
- test_manifest.json：测试集清单
- normalization.json：归一化统计量与可逆变换参数

## 流程节点
```
1. 读取数据契约 → 2. 质控（缺失值/异常值处理） → 3. 重采样（如需）
→ 4. 归一化或无量纲化 → 5. 按工况/轨迹切分 → 6. 保存统计量
→ 7. 验证切分互斥性
```

## 关键参数

### 通用判据（方法层，同类体系可参考）

| 参数 | 判据 | 说明 |
|------|------|------|
| 切分互斥性 | train/val/test样本互斥 | 同一样本不得出现在多个切分中 |
| 轨迹完整性 | 同一轨迹帧不得被打散到不同切分 | 按几何/工况/轨迹为单位切分 |
| 统计量来源 | 仅用训练集计算变换统计量 | 防止数据泄漏 |
| 边界语义 | 边界与掩膜语义未破坏 | 保持物理边界条件的正确性 |
| 变换可逆性 | 归一化/无量纲化变换可逆 | 支持结果恢复到原始物理量纲 |

### 校准数值（场景专属值，供量级校准）
以下数值来自 CFD_S046 场景，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认train比例 | 0.7 | 场景需求书 | 70%训练集 |
| 默认validation比例 | 0.15 | 场景需求书 | 15%验证集 |
| 默认test比例 | 0.15 | 场景需求书 | 15%测试集 |
| 默认随机种子 | 42 | 场景需求书 | 切分随机种子 |
| 默认分组策略 | geometry_or_trajectory | 场景需求书 | 按几何或轨迹分组 |

## 边界与分流
- **同一轨迹被打散**：重新执行切分，确保轨迹完整性
- **统计量泄漏**：重新计算，仅使用训练集
- **边界语义破坏**：检查掩膜定义，恢复边界条件
- **无量纲化失败**：检查物理量纲定义，手动指定参考值

## 质量检查
- 三份切分的样本互斥性验证
- 轨迹/工况完整性检查
- 统计量仅来自训练集的验证
- 归一化变换可逆性测试
- 边界条件语义检查

## 回退策略
- 切分失败：调整分组策略或切分比例
- 归一化失败：改用其他归一化方法或手动指定参数
- 边界破坏：恢复原始边界定义，重新构建掩膜
