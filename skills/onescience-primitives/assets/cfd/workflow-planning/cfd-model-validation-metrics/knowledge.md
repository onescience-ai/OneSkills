# CFD数据驱动模型验收指标体系

## 适用范围

面向CFD数据驱动模型评估任务，定义验收指标体系。适用于所有需要评估数据驱动CFD模型精度、物理一致性和泛化能力的验收评估任务。不适用于模型训练或数据预处理任务。

## 输入

- 任务目标：评估CFD数据驱动模型的性能
- 数据需求：模型预测结果、CFD基准解、物理约束条件
- 格式要求：numpy数组或VTK文件，包含预测场和基准场

## 输出

- evaluation.json：评估结果文件，包含所有指标数值
- worst_cases.csv：最差样本列表，包含误差指标和工况参数
- applicability_report.md：适用域报告，定义模型可用边界
- PASS_REJECT_BLOCKED.txt：验收结论，给出通过/拒绝/阻塞判定

## 流程节点

1. **计算统计误差** → 2. **验证物理约束** → 3. **评估泛化能力** → 4. **分析计算收益** → 5. **生成验收报告**

### 步骤1：计算统计误差
- 操作：计算模型预测与基准解之间的统计误差
- 参数：MAE、MSE、RMSE、R²
- 工具：Python numpy
- 质量门禁：误差计算正确，数值范围合理

### 步骤2：验证物理约束
- 操作：检查模型预测是否满足物理约束
- 参数：质量守恒、动量守恒、能量守恒
- 工具：物理约束验证脚本
- 质量门禁：物理约束满足，误差在允许范围内

### 步骤3：评估泛化能力
- 操作：评估模型在不同工况下的泛化能力
- 参数：不同Reynolds数、不同几何结构、不同边界条件
- 工具：泛化能力评估脚本
- 质量门禁：泛化能力良好，性能下降可接受

### 步骤4：分析计算收益
- 操作：比较数据驱动模型与传统CFD的计算效率
- 参数：计算时间、内存占用、并行效率
- 工具：性能分析工具
- 质量门禁：计算收益明显，效率提升显著

### 步骤5：生成验收报告
- 操作：生成验收评估报告和结论
- 参数：所有评估指标、最差样本分析、适用域定义
- 工具：报告生成器
- 质量门禁：报告完整，结论明确

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 统计误差指标 | MAE/MSE/RMSE/R² | [领域标准] | 基本统计误差指标 |
| 物理约束验证 | 质量守恒/动量守恒 | [领域标准] | 物理一致性检查 |
| 泛化能力评估 | 不同工况测试 | [领域标准] | 泛化能力验证 |
| 计算收益分析 | 时间/内存/并行 | [领域标准] | 效率评估 |
| 验收结论 | PASS/REJECT/BLOCKED | [标准规范] | 验收判定 |

### 校准数值（体系专属值）

以下数值来自典型CFD模型验收任务，供量级校准；其他体系需以自身证据重新锚定：

| 参数 | 典型值 | 来源 | 说明 |
|------|--------|------|------|
| closure_RMSE阈值 | <0.1 | [典型值] | 相对误差门限 |
| mean_profile_error | <5% | [典型值] | 均值剖面误差 |
| spectrum_error | <10% | [典型值] | 能谱误差 |
| stability_horizon | >100步 | [典型值] | 稳定性时域 |
| 质量守恒误差 | <1% | [典型值] | 质量守恒精度 |

## 边界与分流

### 前提1：存在CFD基准解
- **不成立时转向**：使用解析解或实验数据作为基准，或降低评估标准

### 前提2：物理约束可计算
- **不成立时转向**：使用简化物理约束，或仅评估统计误差

### 前提3：计算资源充足
- **不成立时转向**：减少评估工况数量，或使用采样评估

## 质量检查

1. **指标计算验证**：检查指标计算是否正确
2. **物理约束验证**：检查物理约束是否满足
3. **最差样本分析**：检查最差样本是否可追溯
4. **适用域定义**：检查适用域是否明确
5. **验收结论验证**：检查验收结论是否有据可依

## 回退策略

1. **指标计算错误**：修正计算方法，重新计算指标
2. **物理约束不满足**：调整模型或物理约束，重新验证
3. **泛化能力不足**：增加训练数据或调整模型架构
4. **计算收益不明显**：优化模型或使用更高效的实现
