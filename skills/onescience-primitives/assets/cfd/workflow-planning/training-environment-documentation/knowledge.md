# 深度学习训练环境记录规范

## 适用范围

本卡片为深度学习训练环境记录提供规范，适用于所有需要可复现性的训练任务，特别是CFD降阶建模、物理信息神经网络等科研任务。environment.txt是训练产物的重要组成部分，确保其他研究者能够复现训练环境。

## 输入

### 训练环境信息
- Python版本：主要解释器版本
- 深度学习框架版本：PyTorch/TensorFlow版本
- CUDA版本：GPU计算平台版本
- 操作系统信息：OS类型和版本
- 硬件信息：GPU型号、CPU型号、内存大小

### 依赖包信息
- 核心科学计算包：numpy、scipy、pandas
- 深度学习框架：torch、tensorflow、jax
- 可视化工具：matplotlib、plotly
- CFD专用工具：openfoam、pyFOAM等

### 训练配置信息
- 随机种子：确保可复现性
- 硬件配置：GPU数量、内存分配
- 软件环境：conda环境、虚拟环境

## 输出

### environment.txt文件
- 格式：纯文本文件，每行一个键值对
- 内容：完整的训练环境信息
- 位置：与训练产物在同一目录

### 环境验证报告
- 环境完整性检查
- 依赖冲突检测
- 复现性评估

## 流程节点

1. **环境信息收集** → 2. **依赖包扫描** → 3. **硬件信息检测** → 4. **文件生成** → 5. **验证检查**

### 步骤1：环境信息收集
- 操作：收集Python、框架、OS基本信息
- 参数：版本号、构建信息
- 工具：系统信息收集脚本
- 质量门禁：信息完整准确

### 步骤2：依赖包扫描
- 操作：扫描所有已安装的依赖包
- 参数：包名、版本、安装来源
- 工具：pip/conda列表工具
- 质量门禁：包含所有关键依赖

### 步骤3：硬件信息检测
- 操作：检测GPU、CPU、内存信息
- 参数：型号、核心数、内存大小
- 工具：硬件检测库（nvidia-smi、psutil）
- 质量门禁：硬件信息准确

### 步骤4：文件生成
- 操作：生成environment.txt文件
- 参数：格式、编码、路径
- 工具：文件写入工具
- 质量门禁：文件格式正确

### 步骤5：验证检查
- 操作：验证environment.txt内容完整性
- 参数：必需字段、格式规范
- 工具：验证脚本
- 质量门禁：所有必需字段存在

## 边界与分流

### 环境信息缺失时
- 关键版本信息缺失 → 标记为"未知"并说明原因
- 硬件信息无法检测 → 使用通用描述
- 依赖包版本冲突 → 记录冲突并建议解决方案

### 文件格式错误时
- 缺少必需字段 → 补充缺失信息
- 格式不规范 → 重新生成标准格式
- 编码问题 → 使用UTF-8编码

### 复现性问题时
- 环境差异过大 → 提供环境配置脚本
- 依赖冲突 → 提供requirements.txt
- 硬件不兼容 → 说明硬件要求

## 质量检查

### 验证点
1. 必需字段完整性
2. 版本号准确性
3. 格式规范性
4. 编码正确性

### 阈值
- 必需字段：100%存在
- 版本号格式：符合语义化版本规范
- 文件编码：UTF-8无错误

### 失败处理
- 字段缺失 → 补充缺失信息
- 格式错误 → 重新生成文件
- 编码问题 → 转换编码格式

## 回退策略

### 环境信息收集失败时
1. 使用系统命令手动收集信息
2. 参考已知环境配置
3. 提供环境配置脚本供用户运行

### 文件生成失败时
1. 检查文件写入权限
2. 验证目录结构
3. 使用备选文件路径
