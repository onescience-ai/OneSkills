# 任务验收与适用域判定

## 适用范围

本卡片描述物理信息神经网络稀疏观测参数反演工作流的第五步：任务验收与适用域判定。适用于：
- PINN模型的性能评估
- 物理一致性验证
- 适用域界定与外推测试

**不适用场景**：
- 模型训练阶段
- 数据预处理阶段

## 输入

1. **验收指标** `{METRICS}`：统计和物理指标
2. **相对误差门限** `{MAX_RELATIVE_L2}`：测试集放行阈值
3. **外推测试标志** `{RUN_OOD_TEST}`：测试域外工况

## 输出

1. **评估结果** `evaluation.json`
2. **最差样本** `worst_cases.csv`
3. **适用域报告** `applicability_report.md`
4. **验收结论** `PASS_REJECT_BLOCKED.txt`

## 流程节点

```
计算统计误差 → 计算物理约束误差 → 识别最差样本 → 执行外推测试 → 判定适用域 → 输出结论
```

### 详细操作

#### 1. 统计误差计算

**操作**：
- 计算相对L2误差
- 逐变量误差分析
- 整体误差统计

**判定标准**：
- 误差为有限值
- 误差分布可分析
- 最差样本可识别

#### 2. 物理约束误差计算

**操作**：
- 计算PDE残差
- 计算边界误差
- 计算守恒误差

**判定标准**：
- 残差为有限值
- 边界误差可接受
- 守恒律满足

#### 3. 最差样本识别

**操作**：
- 按误差排序识别最差样本
- 分析最差样本特征
- 追溯最差样本来源

**判定标准**：
- 最差样本可追溯
- 特征分析合理
- 来源可识别

#### 4. 外推测试（可选）

**操作**：
- 执行几何外推测试
- 执行工况外推测试
- 评估泛化能力

**判定标准**：
- 外推测试完成
- 泛化能力量化
- 适用域边界明确

#### 5. 适用域判定

**操作**：
- 综合统计与物理指标
- 判定PASS/REJECT/BLOCKED
- 给出适用域限制与复核建议

**判定标准**：
- 结论明确
- 适用域限制清晰
- 复核建议具体

## 边界与分流

1. **误差超标**：相对L2误差>0.1 → REJECT，需改进模型或数据
2. **物理约束不满足**：PDE残差过大 → REJECT，需检查方程定义
3. **边界不满足**：边界误差过大 → REJECT，需检查边界条件
4. **域外工况失败**：外推测试失败 → BLOCKED，需CFD复核
5. **指标不一致**：统计与物理指标冲突 → 综合判定，标注冲突

## 质量检查

1. **多指标报告**：统计与物理指标同时报告
2. **最差可追溯**：最差样本可追溯
3. **适用域明确**：结论含适用域限制与复核建议
4. **结论明确**：PASS/REJECT/BLOCKED结论清晰
5. **可复现**：评估过程可复现

## 回退策略

1. **误差超标** → 改进模型架构或增加数据
2. **物理约束不满足** → 调整损失权重或方程定义
3. **域外工况失败** → 执行CFD复核验证
4. **指标冲突** → 综合多指标判定
