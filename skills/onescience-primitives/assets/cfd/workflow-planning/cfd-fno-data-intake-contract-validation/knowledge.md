# FNO算子学习数据接入与契约核验任务

## 适用范围

**触发条件**：
- 需要接入高分辨率规则网格PDE数据用于FNO算子学习
- 需要验证数据质量是否满足训练要求
- 需要生成机器可读的数据契约

**适用场景**：
- FNO算子学习流程的数据准备阶段
- 因子分解与多重网格FNO模型训练前的数据验证
- 多源PDE数据整合前的标准化验证

**不适用场景**：
- 非规则网格或非结构化网格数据
- 数据已通过验证的推理阶段
- 无PDE配对数据的纯文献分析

## 输入

**必填输入**：
- {DATASET_PATH}：数据集路径（目录或清单文件）
- {DATASET_NAME}：数据集名称（来源与版本）

**可选输入**：
- {DATA_CONTRACT}：数据契约定义（变量、单位、坐标系）

**数据格式**：
- 支持常见科学数据格式（HDF5、NetCDF、NumPy等）
- 需包含输入函数和目标解函数的配对样本
- 数据应为高分辨率规则网格格式

## 输出

**产物清单**：
- dataset_manifest.json：数据清单（样本数、变量列表、维度信息）
- data_contract.json：机器可读数据契约（变量定义、单位、坐标系）
- data_audit.md：数据审计报告（完整性、一致性、使用许可）

**格式要求**：
- JSON格式可被标准解析器读取
- 审计报告包含明确的通过/失败结论

## 流程节点

### Step 1：数据文件检查
- **操作**：验证数据文件可读性、格式正确性
- **检查项**：文件存在、格式可解析、无损坏
- **质量门禁**：数据文件可读

### Step 2：样本完整性核验
- **操作**：统计样本数、检查缺失值、验证配对完整性
- **检查项**：样本数>0、无缺失样本、输入-目标配对完整
- **质量门禁**：样本可追溯

### Step 3：变量与单位核验
- **操作**：确认输入与目标变量定义、单位一致性
- **检查项**：变量名明确、单位定义完整、无量纲冲突
- **质量门禁**：输入目标变量单位定义完整

### Step 4：网格坐标核验
- **操作**：验证网格坐标系、拓扑结构、边界定义
- **检查项**：坐标系明确、网格连续、边界完整
- **质量门禁**：坐标定义完整

### Step 5：使用许可确认
- **操作**：检查数据使用许可、版权信息
- **检查项**：许可明确、允许研究使用
- **质量门禁**：使用许可确认

### Step 6：契约生成
- **操作**：生成机器可读的数据契约
- **输出**：data_contract.json
- **质量门禁**：契约包含完整变量定义

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必填输入 | DATASET_PATH, DATASET_NAME | 场景需求书 | 缺少时返回BLOCKED |
| 可选输入 | DATA_CONTRACT | 场景需求书 | 可预定义契约模板 |
| 输出格式 | JSON, Markdown | 场景需求书 | 机器可读+人工可读 |
| 数据格式 | HDF5, NetCDF, NumPy | 通用 | 支持常见科学数据格式 |
| 网格类型 | 高分辨率规则网格 | 场景需求书 | FNO算子学习要求 |

## 边界与分流

**异常处理**：
1. **数据文件不存在** → 返回BLOCKED，列出缺项
2. **数据格式不可解析** → 返回BLOCKED，说明格式要求
3. **样本数为0** → 返回BLOCKED，说明数据为空
4. **变量定义缺失** → 返回BLOCKED，列出缺失变量
5. **单位不一致** → 返回BLOCKED，说明单位冲突
6. **使用许可不明确** → 返回BLOCKED，说明许可问题

**降级策略**：
- 部分变量缺失 → 标注缺失变量，继续可用变量的核验
- 单位不明确 → 尝试从数据元数据推断，标注不确定性

## 质量检查

**验证点**：
- 文件可读性：100%文件可解析
- 样本完整性：无缺失样本
- 变量完整性：所有必需变量已定义
- 单位一致性：无量纲冲突
- 坐标完整性：网格坐标定义完整
- 许可明确性：使用许可已确认

**失败处理**：
- 任一检查失败 → 返回BLOCKED
- BLOCKED时列出所有缺项
- 不得编造数据或结果
