# 三维湍流DNS/LES数据集获取

## 适用范围
面向三维湍流时空预测任务，提供DNS（直接数值模拟）与LES（大涡模拟）湍流数据集的获取途径、公开数据源、生成工具部署与配置知识，以及数据格式契约规范。适用于需要高保真湍流数据进行机器学习模型训练、验证和评估的CFD任务。

## 输入
- 任务需求：湍流数据类型（DNS/LES）、流动条件（雷诺数、几何形状）、数据变量（速度分量u,v,w，压力p，涡量等）
- 计算资源：HPC集群或本地高性能计算资源
- 软件环境：CFD求解器（OpenFOAM、Nek5000等）、数据处理工具（ParaView、Python等）

## 输出
- 湍流数据集文件（HDF5、NetCDF、VTK格式）
- 数据集元数据（网格信息、时间步长、物理参数）
- 数据质量报告（完整性、一致性检查）

## 流程节点
1. **需求分析** → 确定湍流数据类型、流动条件、数据变量
2. **数据源检索** → 搜索公开湍流数据集（Johns Hopkins Turbulence Database、NASA Turbulence Data等）
3. **数据获取** → 下载或生成符合需求的湍流数据
4. **数据格式转换** → 将数据转换为任务所需格式（HDF5、NetCDF、VTK）
5. **数据验证** → 检查数据完整性、一致性、物理合理性
6. **数据契约生成** → 生成机器可读的数据契约文档

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据类型 | DNS/LES | 任务需求 | 直接数值模拟或大涡模拟 |
| 雷诺数 | 依任务而定 | 流动条件 | 决定湍流强度和尺度 |
| 网格分辨率 | 依雷诺数而定 | DNS/LES要求 | DNS需解析所有尺度，LES需足够分辨率解析大尺度 |
| 时间步长 | 依CFL条件而定 | 数值稳定性要求 | 保证时间精度和稳定性 |
| 数据格式 | HDF5/NetCDF/VTK | 任务需求 | 选择适合大规模数据存储和访问的格式 |

## 边界与分流
- **公开数据不可用**：转向CFD求解器生成自定义数据
- **计算资源不足**：使用降阶模型或合成湍流生成
- **数据格式不兼容**：使用格式转换工具（如ParaView、Python库）
- **数据质量不达标**：返回数据验证步骤或重新生成

## 质量检查
- 数据完整性：检查缺失值、异常值
- 物理一致性：验证速度、压力等变量的物理合理性
- 网格质量：检查网格正交性、光滑性
- 时间序列连续性：验证时间步长的一致性

## 回退策略
- 公开数据不可用时，使用CFD求解器生成简化几何的湍流数据
- 计算资源不足时，使用降阶模型生成近似湍流数据
- 数据格式转换失败时，使用中间格式（如VTK）进行转换

## 资源召回建议

- 当需要部署CFD求解器生成湍流数据时召回本卡片
- 当需要处理湍流数据格式转换时召回本卡片
