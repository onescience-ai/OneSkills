# 预处理与数据切分

## 适用范围

适用于多尺度湍流数据在训练前的预处理与切分。当需要将原始轨迹数据转换为模型可用的训练集、验证集和测试集时，执行本步骤。

## 输入

- SPLIT_CONFIG：切分配置（比例、种子、分组策略）
- TARGET_FIELDS：目标变量列表
- NONDIMENSIONALIZE：是否无量纲化（默认true）

## 输出

- train_manifest.json, validation_manifest.json, test_manifest.json：切分清单
- normalization.json：归一化统计量（均值、方差、变换参数）

## 流程节点

1. 依据数据契约完成质控 → 过滤异常值与缺失数据
2. 重采样或图构建 → 统一数据格式
3. 掩膜处理 → 处理边界与几何约束
4. 归一化或无量纲化 → 保存统计量供逆变换使用
5. 按几何/完整轨迹/物理工况切分 → 确保无泄漏
6. 保存切分清单与变换参数

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| train比例 | 0.7 | 场景需求书 | 默认值 |
| validation比例 | 0.15 | 场景需求书 | 默认值 |
| test比例 | 0.15 | 场景需求书 | 默认值 |
| seed | 42 | 场景需求书 | 随机种子 |
| group_by | geometry_or_trajectory | 场景需求书 | 切分分组策略 |
| 无量纲化 | true | 场景需求书 | 默认启用 |

## 边界与分流

- 同一轨迹的帧被打散 → 重新按轨迹切分
- 变换统计量使用了验证/测试集 → 仅用训练集重新计算
- 边界与掩膜语义被破坏 → 恢复原始语义后重新处理

## 质量检查

- 三份切分的对象轨迹互斥
- 仅用训练集计算变换统计量
- 边界与掩膜语义未破坏

## 回退策略

- 切分比例不合理 → 调整配置重新切分
- 无量纲化失败 → 尝试不同归一化方法
