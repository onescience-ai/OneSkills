# CFD 数据输入契约验证规则

## 适用范围

本卡面向所有依赖外部数据输入的计算流体力学（CFD）科学计算工作流，定义数据输入契约的强制性验证规则、验证时机与错误处置标准。适用于数据驱动的 CFD 任务，包括但不限于流场分布生成、代理模型训练、物理信息模型训练等场景。不适用于纯数值求解（无需外部数据输入）的 CFD 仿真任务。

## 输入

- 数据集路径（必填）：指向 CFD 数据集的文件系统路径
- 数据集名称/标识符（必填）：用于任务调度和日志追踪的唯一标识
- 数据格式描述（可选）：预期的文件格式（如 NetCDF、HDF5、VTK、CSV）
- 变量列表（可选）：数据集中应包含的物理变量名（如速度场、压力场、网格坐标）
- 网格信息（可选）：预期的网格维度、坐标系、分辨率

## 输出

- 验证结果报告：包含每项检查的通过/失败状态、失败原因、建议修复措施
- 结构化错误信息：当验证失败时，返回包含错误码、错误描述、失败参数名的 JSON 对象
- 任务状态：`PRECHECK_PASSED`（验证通过）、`PRECHECK_FAILED`（验证失败，任务终止）、`PRECHECK_NEEDS_CONFIRMATION`（需人工确认）

## 流程节点

1. **路径存在性检查** → 验证数据集路径在文件系统中是否存在
2. **文件可读性检查** → 验证目标路径下的文件是否可被当前进程读取
3. **基本格式校验** → 检查文件扩展名、文件头、编码是否符合预期格式
4. **变量完整性检查** → 验证数据集中是否包含任务所需的全部必填变量
5. **网格坐标检查** → 验证网格维度、坐标系、分辨率是否满足任务要求
6. **单位一致性检查** → 验证物理量单位是否与任务配置一致
7. **生成验证报告** → 汇总所有检查结果，输出结构化报告

每步含：操作（具体检查逻辑）、参数（检查阈值）、工具（文件系统 API、数据格式解析库）、质量门禁（所有必填项通过才允许继续）

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 路径存在性检查 | 必须通过 | [论文4] | 路径不存在时任务必须立即终止，不得尝试自动创建 |
| 文件可读性检查 | 必须通过 | [论文4] | 文件存在但不可读（权限不足）同样阻断任务 |
| 必填变量完整性 | 100% 覆盖 | [论文1][论文2] | 缺少任一必填变量即判定验证失败 |
| 网格维度匹配 | 允许误差 ≤ 1% | [论文2] | 网格分辨率偏差超过阈值时需人工确认 |

### 校准数值（来自具体 CFD 体系，供量级校准；其他体系需以自身证据重新锚定）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| ChannelFlow-Tools 数据集变量 | 速度场 (u,v,w)、压力场 (p)、SDF 表示 | [论文1] | 3D 阻塞通道流的标准变量集 |
| LBM 验证管道网格分辨率 | 1024×512×512 | [论文2] | 高分辨率湍流模拟的基准网格 |
| ERA5 气象数据变量 | 6 地表变量 + 6 大气变量 × 13 气压层 | [论文3] | 全球天气预报的数据输入契约示例 |

## 边界与分流

- **路径不存在**：直接返回 `PRECHECK_FAILED`，错误信息包含实际尝试的路径和预期路径格式建议。不执行任何文件创建操作。
- **路径存在但格式不匹配**：返回 `PRECHECK_FAILED`，错误信息列出预期格式与实际格式的差异。
- **文件可读但变量缺失**：返回 `PRECHECK_FAILED`，错误信息列出缺失的变量名和已有变量名。
- **网格维度偏差在容忍范围内**：返回 `PRECHECK_NEEDS_CONFIRMATION`，需人工确认是否继续。
- **网格维度偏差超出容忍范围**：返回 `PRECHECK_FAILED`，建议重新配置网格参数。
- **数据格式版本不兼容**：返回 `PRECHECK_FAILED`，列出支持的格式版本和当前格式版本。
- **预检步骤本身执行异常**（如文件系统不可用）：返回 `PRECHECK_FAILED`，错误信息指向预检步骤本身的异常原因。

## 质量检查

- 所有必填参数（路径、名称）的验证必须在任务启动前完成，不得在业务逻辑执行中才检测
- 验证结果必须以结构化格式输出，便于下游系统解析和日志记录
- 错误信息必须包含：错误码（如 `DATA_PATH_NOT_FOUND`）、失败参数名、实际值（如有）、期望值描述
- 验证报告必须持久化保存，供后续审计和问题排查使用

## 回退策略

- 预检失败时，任务以 `PRECHECK_FAILED` 状态终止，不执行任何后续步骤
- 若系统支持，可提供场景索引中可能配置的默认数据路径作为备选方案
- 若默认路径也不存在，终止并提示用户手动配置正确路径
- 不允许"跳过预检直接执行"的降级模式

## 资源召回建议

- 当任务编排器（onescience-orchestrator）准备调度 CFD 数据处理技能前，应先召回本卡
- 配套资源：`scientific-workflow-preflight-check` 卡（提供通用预检框架）、`onescience-runsite` 技能（运行站点配置）、`cfd-dataset-path-validation-workflow` 卡（提供数据集路径验证的底层实现方法）
- 本卡适用于 s01 数据接入步骤的前置验证，也可作为独立预检技能被调用
