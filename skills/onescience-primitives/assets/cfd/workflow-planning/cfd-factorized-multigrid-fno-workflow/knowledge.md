# 因子分解与多重网格FNO高效算子学习工作流

## 适用范围

**触发条件**：
- 需要从高分辨率规则网格PDE数据中学习输入到解算子的映射
- 涉及Navier-Stokes方程、Helmholtz方程等流体力学问题的快速求解
- 需要处理多尺度、多分辨率的PDE数据

**适用场景**：
- 计算流体动力学（CFD）中的快速流场预测
- 空气动力学设计中的参数化模拟
- 气象预报中的数值天气预测加速
- 材料科学中的多物理场耦合问题

**不适用场景**：
- 非规则网格或非结构化网格数据
- 强非线性或强间断的PDE问题（需要特殊处理）
- 无监督或无标签的纯数据驱动问题

## 输入

**输入数据格式**：
- 高分辨率规则网格PDE数据（如NetCDF、HDF5格式）
- 输入场：初始条件、边界条件、参数场等
- 输出场：PDE的解（如速度场、压力场、温度场等）

**数据预处理要求**：
- 数据归一化或无量纲化处理
- 网格坐标标准化
- 物理量单位统一
- 数据切分：按几何、工况或时间构造无泄漏切分

**数据契约**：
- 输入字段：初始条件、边界条件、源项等
- 目标字段：PDE的解（速度、压力、温度等）
- 单位：国际单位制（SI）
- 坐标系：笛卡尔坐标系或柱坐标系
- 网格拓扑：结构化规则网格

## 输出

**输出产物**：
- 训练好的算子模型（best_checkpoint.pt）
- 训练配置文件（train_config.json）
- 训练指标（training_metrics.csv）
- 环境信息（environment.txt）
- 推理结果（predictions/）
- 评估报告（evaluation.json）
- 适用域报告（applicability_report.md）

**输出格式**：
- 模型权重：PyTorch checkpoint格式
- 指标：CSV或JSON格式
- 报告：Markdown格式

**验证标准**：
- 统计误差：相对L2误差 < 0.1，RMSE < 阈值
- 物理约束：守恒残差 < 阈值，边界误差 < 阈值
- 计算效率：推理速度提升比 > 10x

## 流程节点

### Step 1：数据接入与契约核验
- **操作**：接入高分辨率规则网格PDE数据，核验样本、变量、单位、网格坐标及许可
- **参数**：数据集路径、数据集名称、数据契约
- **工具**：数据加载器、格式转换器
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏

### Step 2：预处理与数据切分
- **操作**：统一物理量与表示，按几何、工况或时间构造无泄漏切分
- **参数**：切分配置（train: 0.7, validation: 0.15, test: 0.15）、目标变量、是否无量纲化
- **工具**：数据预处理库（如NumPy、Pandas）
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏

### Step 3：模型配置与训练
- **操作**：训练Factorized FNO、Multigrid neural operator完成指定输入到目标物理量的映射
- **参数**：模型名称、训练配置（epochs=100, batch_size=8, learning_rate=0.001, seed=42, early_stopping_patience=15）
- **工具**：PyTorch框架、NeuralOperator库
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现

### Step 4：批量推理与物理恢复
- **操作**：在独立测试集推理，恢复原始单位、网格和物理派生量
- **参数**：模型权重、计算设备（cuda）、推理批大小（8）
- **工具**：PyTorch推理引擎
- **质量门禁**：预测无NaN或Inf且形状单位正确；每个测试样本有唯一结果；推理未使用测试目标校正

### Step 5：任务验收与适用域判定
- **操作**：评估统计误差、关键物理约束、泛化能力和计算收益
- **参数**：验收指标（relative_L2, RMSE, conservation_residual, boundary_error）、相对误差门限（0.1）、是否外推测试（true）
- **工具**：评估脚本
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议

## 边界与分流

**关键前提不成立时的改道方案**：

1. **非规则网格数据**：转向基于图神经网络（GNN）的算子学习方法
2. **强非线性问题**：考虑使用DeepONet或注意力机制增强的神经算子
3. **强间断问题**：采用间断捕获神经算子（如φ-DeepONet）或激波捕捉方法
4. **小样本数据**：使用迁移学习或数据增强技术
5. **高维问题**：考虑降维技术或张量分解方法

**异常处理**：
- 训练发散：降低学习率或使用梯度裁剪
- 过拟合：增加正则化或使用早停
- 推理不稳定：检查模型权重和输入数据预处理

## 质量检查

**验证点**：
- 训练收敛性：验证损失下降且稳定
- 测试集性能：相对L2误差 < 0.1
- 物理一致性：守恒残差在可接受范围内
- 边界条件：边界误差 < 阈值
- 最差样本：可追溯且误差分析完整
- 计算效率：推理时间符合预期

**阈值**：
- 相对L2误差：< 0.1（默认）
- RMSE：< 物理量量级的1%
- 守恒残差：< 1e-3
- 边界误差：< 1e-2

**失败处理**：
- 检查数据预处理是否正确
- 调整模型超参数
- 增加训练数据量
- 考虑模型架构改进

## 回退策略

**失败时的替代方案**：
1. **模型训练失败**：使用预训练权重进行微调
2. **推理性能不佳**：尝试不同的模型架构（如U-NO、DeepONet）
3. **物理约束不满足**：在损失函数中添加物理约束项
4. **计算资源不足**：使用模型压缩或知识蒸馏技术
5. **数据不足**：使用迁移学习或数据增强
