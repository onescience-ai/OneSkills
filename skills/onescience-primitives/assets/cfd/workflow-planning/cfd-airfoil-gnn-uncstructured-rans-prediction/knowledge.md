# 图网络翼型非结构网格RANS场预测

## 适用范围
本卡服务的问题类：给定翼型几何与来流工况，在非结构网格上用图神经网络（GNN）快速预测RANS流场（压力、速度、湍流量等），替代或加速传统CFD求解器。

**适用场景**：
- 翼型气动设计空间探索与快速评估
- 多工况批量流场预测
- 代理模型辅助优化

**不适用场景**：
- 域外几何或极端工况（需CFD复核）
- 高精度转捩或分离流预测（RANS模型本身限制）
- 需要时间分辨的非定常流场

## 输入
| 输入 | 类型 | 说明 |
|------|------|------|
| 翼型几何 | 非结构网格 | 节点坐标、单元连接、边界标记 |
| 工况参数 | 标量 | 攻角、来流速度、雷诺数等 |
| 物理场标签 | 场量 | 压力系数、速度分量、湍动能等（训练用） |

## 输出
| 输出 | 类型 | 说明 |
|------|------|------|
| 预测物理场 | 场量 | 逐节点/单元的压力、速度、湍流量预测值 |
| 物理一致性指标 | 标量 | 守恒残差、边界误差、方程残差 |
| 适用域报告 | 文档 | 几何/工况覆盖范围、域外判定、复核建议 |

## 流程节点
数据接入与契约核验 → 预处理与数据切分 → 模型配置与训练 → 批量推理与物理恢复 → 任务验收与适用域判定

每步含：操作、参数、工具、质量门禁（详见 workflow 级卡片）

## 边界与分流
- **非结构网格拓扑差异**：若目标网格类型与训练集差异大（如三角形→四面体），图构建策略需调整，否则精度下降。
- **工况超出训练域**：攻角或雷诺数超出训练范围时，模型外推不可靠，需CFD复核。
- **数据集不含目标变量**：若数据契约缺少某物理量，该变量无法训练，应标记为BLOCKED。
- **计算资源不足**：GPU显存不足时，降低批大小或采用模型并行。

## 质量检查
| 检查点 | 判据 | 失败处理 |
|--------|------|----------|
| 数据文件可读性 | 所有样本可加载 | 返回BLOCKED，列出缺项 |
| 训练/测试泄漏 | 同一几何不跨切分 | 重新切分 |
| 预测无NaN/Inf | 逐样本检查 | 排除异常样本，报告数量 |
| 守恒残差 | 在可接受范围 | 标记为需CFD复核 |
| 最差样本可追溯 | 逐样本误差排序 | 输出worst_cases.csv |

## 回退策略
- 模型训练不收敛：检查数据质量、调整超参、简化模型结构
- 推理精度不足：增加训练数据、调整图构建策略、引入物理约束损失
- 适用域外工况：回退到传统CFD求解器

## 资源召回建议
- 需要图神经网络模型组件时，召回 GNN 相关模型卡
