# CFD神经算子架构与评估方法

## 适用范围
本卡适用于区分和选择CFD中常用的神经算子架构（如UNO、FNO、DeepONet等），理解其设计原理、适用场景，并实施独立的模型评估流程，确保不同架构的性能可区分、可复现。

## 输入
- 问题类型：PDE求解、参数化求解、时间推进等
- 数据格式：网格数据、点云数据、函数空间数据
- 计算约束：内存限制、训练时间、推理速度要求

## 输出
- 架构选择建议：基于问题特性的最优架构推荐
- 评估协议：独立的模型评估流程和指标
- 性能对比报告：不同架构在精度、速度、内存等方面的对比

## 流程节点

### 1. 架构类型识别
**U-shaped Neural Operator (UNO)**：
- 特点：内存效率高，适合大规模模拟 [论文2]
- 结构：编码器-解码器结构，跳跃连接
- 适用：大网格、高分辨率问题

**Fourier Neural Operator (FNO)**：
- 特点：频域学习，全局感受野 [论文2]
- 结构：傅里叶层、卷积层
- 适用：周期性边界、均匀网格问题

**Deep Operator Network (DeepONet)**：
- 特点：分支-主干结构，函数空间映射 [论文3]
- 分支网络：编码输入函数
- 主干网络：编码查询点位置
- 适用：参数化PDE、多输入问题

**二阶神经网络**：
- 特点：基于二阶微分方程构建，表达能力更强 [论文1]
- 结构：残差连接、二阶差分格式
- 适用：抛物型PDE、需要高阶精度的问题

### 2. 架构选择准则
**根据问题特性选择**：
- 大规模问题 → UNO（内存效率）
- 周期性问题 → FNO（频域优势）
- 多参数问题 → DeepONet（函数空间映射）
- 高精度要求 → 二阶神经网络（强表达能力）

**根据数据特性选择**：
- 网格数据 → UNO/FNO
- 非结构化数据 → DeepONet
- 函数空间数据 → DeepONet

### 3. 独立评估流程
**权重初始化**：
- 每个模型使用独立的随机种子初始化权重
- 避免使用相同初始化导致结果相同

**训练配置**：
- 相同的数据集划分（训练/验证/测试）
- 相同的优化器和学习率调度
- 相同的训练轮数或早停策略

**评估指标**：
- **精度指标**：相对L2误差、均方误差（MSE）
- **物理一致性**：质量守恒误差、能量守恒误差
- **计算效率**：训练时间、推理速度、内存占用
- **泛化能力**：未见数据上的性能、不同分辨率下的性能

### 4. 物理一致性约束
**局部矩匹配**：
- 零阶矩（质量）：$\sum_i f_i = \rho$ [论文2]
- 一阶矩（动量）：$\sum_i f_i c_i = \rho \vec{u}$ [论文2]
- 确保微观分布函数与宏观物理量一致

**全局等变性**：
- 离散对称群下的不变性（如D4、D3Q19）[论文2]
- 空间变换与速度通道置换的联合等变性
- 确保学习的算子尊重物理对称性

**数据保真度损失**：
- 预测分布函数与参考分布函数的MSE [论文2]
- 宏观量（密度、速度、相场）的MSE

### 5. 加速比计算
**推理加速**：
- 与传统数值方法对比（如Lattice Boltzmann）
- 报告加速比（如167倍、530倍）[论文2]
- 考虑预处理和后处理时间

**训练成本**：
- 训练时间、收敛速度
- 内存占用、GPU利用率
- 数据需求量

## 边界与分流

### 内存限制
当GPU内存不足时：
- 选择UNO而非FNO（内存效率更高）[论文2]
- 减少批量大小或网络深度
- 使用混合精度训练

### 数据不足
当训练数据有限时：
- 使用物理信息约束（MSE+Phys）[论文2]
- 采用迁移学习或预训练模型
- 增强数据（如对称性增强）

### 多尺度问题
当问题包含多个尺度时：
- 使用多分辨率训练策略
- 考虑域分解方法
- 结合传统数值方法（如隐式时间积分）

## 质量检查
1. **独立性验证**：确保不同模型使用独立权重，评估结果可区分
2. **物理一致性检查**：验证质量、动量守恒误差是否在可接受范围内
3. **分辨率泛化**：测试模型在不同网格分辨率下的性能
4. **收敛性验证**：确保训练损失持续下降，无过拟合
5. **可复现性**：记录随机种子、超参数，确保结果可复现

## 回退策略
1. **架构选择不确定**：从UNO开始（内存友好），根据性能调整
2. **评估结果相同**：检查权重初始化、数据划分、训练配置是否独立
3. **物理约束失效**：调整物理约束权重或改用软约束
4. **计算资源不足**：选择更轻量的架构或使用迁移学习
