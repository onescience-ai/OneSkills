# PINN湍流RANS均值流求解 - 模型配置与训练

## 适用范围

本步骤用于PINN湍流RANS均值流求解与闭合的模型训练阶段，负责训练Turbulence-augmented PINN完成指定输入到目标物理量的映射，记录代码版本、依赖、随机种子、逐轮训练验证指标与最佳权重。

**触发条件**：
- 数据预处理与切分已完成
- 需要训练PINN模型进行湍流场重建

**不适用场景**：
- 模型已训练且权重可用的情况
- 纯推理评估且无需训练的场景

## 输入

- **{MODEL_NAME}**：模型名称（实现或模型注册名）
- **{TRAIN_CONFIG}**：训练配置（超参数和随机种子）
- **{INIT_CHECKPOINT}**：初始权重（可选预训练权重）

## 输出

- **best_checkpoint.pt**：最佳模型权重
- **train_config.json**：训练配置
- **training_metrics.csv**：逐轮训练验证指标
- **environment.txt**：代码版本与依赖环境

## 流程节点

```
加载切分数据 → 初始化模型 → 设置优化器 → 训练循环 → 验证评估 → 保存最佳权重 → 记录环境
```

### 关键步骤说明

1. **加载切分数据**：加载s02切分与统计量
2. **初始化模型**：使用{MODEL_NAME}初始化Turbulence-augmented PINN
3. **设置优化器**：配置学习率、批大小等超参数
4. **训练循环**：执行训练，记录逐轮损失
5. **验证评估**：在验证集上评估模型性能
6. **保存最佳权重**：保存验证损失最低的权重
7. **记录环境**：记录代码版本、依赖、随机种子

## 边界与分流

**关键前提与改道**：

1. **前提：数据预处理与切分已完成**
   - 不成立时 → 先执行预处理与数据切分步骤

2. **前提：训练配置合理**
   - 不成立时 → 调整超参数或网络架构

3. **前提：初始权重结构兼容**（如果提供）
   - 不成立时 → 从头训练或调整网络结构

## 质量检查

- **训练验证损失均为有限值**：不能出现NaN或Inf
- **最佳权重可重新加载**：权重文件完整且可加载
- **配置环境随机种子可复现**：相同种子产生相同结果

## 回退策略

1. **训练不收敛**：调整学习率、批大小或网络架构
2. **过拟合**：增加早停耐心、添加正则化或数据增强
3. **权重损坏**：重新训练或使用备份权重
