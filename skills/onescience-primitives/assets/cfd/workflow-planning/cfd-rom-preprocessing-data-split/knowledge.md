# 预处理与数据切分

## 适用范围

本卡描述可迁移ROM工作流第二步：基于s01数据契约，完成质控、归一化或无量纲化，并按几何、完整轨迹或物理工况为单位进行无泄漏切分。适用于跨几何参数CFD数据的预处理与切分。

## 输入

| 输入 | 类型 | 必填 | 说明 |
|------|------|------|------|
| s01契约 | object | 是 | data_contract.json（变量、单位、坐标系） |
| {SPLIT_CONFIG} | object | 是 | 切分比例、分组依据、随机种子 |
| {TARGET_FIELDS} | list[str] | 是 | 待预测物理量列表 |
| {NONDIMENSIONALIZE} | bool | 否 | 是否执行无量纲化（默认true） |

## 输出

| 输出 | 说明 |
|------|------|
| train_manifest.json | 训练集清单（样本ID、文件路径、统计量引用） |
| validation_manifest.json | 验证集清单 |
| test_manifest.json | 测试集清单 |
| normalization.json | 归一化/无量纲化参数（均值、标准差、缩放因子等） |

## 流程节点

1. **质控**：根据s01审计报告处理缺失值与异常值
2. **重采样或图构建**：按需要进行数据重采样或图结构构建
3. **掩膜处理**：应用边界掩膜或区域掩膜
4. **归一化或无量纲化**：按{NONDIMENSIONALIZE}执行，仅使用训练集统计量
5. **切分执行**：按{SPLIT_CONFIG}以几何/轨迹/工况为单位切分
6. **统计量保存**：将变换参数保存到normalization.json
7. **可逆变换记录**：记录逆变换公式供s04物理恢复使用

## 关键参数

### 通用判据

| 参数 | 判据 | 来源 | 说明 |
|------|------|------|------|
| 切分单位 | 按几何/轨迹/工况为单位，不打散同一轨迹帧 | s02质量门禁 | 防止时间/空间泄漏 |
| 切分互斥 | 三份切分的对象轨迹互斥 | s02质量门禁 | 防止数据泄漏 |
| 统计量来源 | 仅用训练集计算变换统计量 | s02质量门禁 | 防止信息泄漏 |
| 边界语义 | 边界与掩膜语义未破坏 | s02质量门禁 | 物理一致性保障 |
| 可逆性 | 变换可逆，逆变换参数完整保存 | s02流程要求 | s04物理恢复依赖 |

### 校准数值

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认切分比例 | train:0.7, validation:0.15, test:0.15 | 场景需求书s02 | 其他体系需重新锚定 |
| 默认随机种子 | 42 | 场景需求书s02 | 复现性保障 |
| 默认分组依据 | geometry_or_trajectory | 场景需求书s02 | 按几何或轨迹分组 |
| 默认无量纲化 | true | 场景需求书s02 | 统一跨工况量纲 |

## 边界与分流

- s01契约缺失 → 回退到s01重新生成
- 缺失值比例过高 → 在train_manifest中标注，评估是否影响训练
- 无量纲化参数计算异常 → 检查训练集数据质量
- 切分后样本数过少 → 警告并评估是否满足最低训练需求
- 掩膜语义被破坏 → 检查掩膜定义与数据格式

## 质量检查

- 三份切分的对象轨迹互斥（无样本ID交集）
- 仅用训练集计算变换统计量（验证集/测试集未参与统计量计算）
- 边界与掩膜语义未破坏（掩膜值在合理范围内）
- normalization.json可被标准JSON解析
- 逆变换参数完整（均值、标准差、缩放因子等）

## 回退策略

- 切分泄漏：重新定义分组依据，确保同组样本不跨切分集
- 统计量泄漏：重新计算，仅使用训练集样本
- 掩膜异常：检查掩膜定义文件，修正格式或范围
- 数据量不足：合并切分比例或增加数据采集
