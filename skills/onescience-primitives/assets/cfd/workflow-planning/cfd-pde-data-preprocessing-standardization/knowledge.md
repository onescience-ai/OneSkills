# PDE数据预处理标准流程

## 适用范围
适用于PDE逆问题任务中原始数据的预处理，包括数据验证、单位统一、无泄漏切分和归一化。适用于真实观测数据和合成数据。不适用于数据生成过程本身。

## 输入
- 原始数据集（HDF5、NetCDF、NumPy数组等）
- 任务需求（PDE类型、边界条件、初始条件）
- 数据划分比例（训练集、验证集、测试集）

## 输出
- 预处理后的数据集（训练集、验证集、测试集）
- 归一化参数（均值、标准差、最小值、最大值）
- 数据切分清单（包含样本索引和划分标签）
- 预处理报告（包含统计信息和验证结果）

## 流程节点
1. 数据加载 → 读取原始数据文件
2. 数据验证 → 检查数据完整性、维度、值范围
3. 单位统一 → 统一物理单位（如SI单位制）
4. 无泄漏切分 → 按几何或轨迹分组切分，避免数据泄露
5. 归一化 → 应用标准化或归一化变换
6. 统计保存 → 保存归一化参数和切分信息
7. 报告生成 → 生成预处理报告

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 推荐切分比例 | 70%/15%/15% | 通用 | 训练/验证/测试集比例 |
| 归一化方法 | Z-score标准化 | 通用 | 均值为0，标准差为1 |
| 切分策略 | 按轨迹分组 | [D1] | 避免同一轨迹数据分布在不同集合 |
| 数据验证阈值 | 缺失值<1%, 异常值<5% | 通用 | 数据质量基本要求 |

## 边界与分流
- 数据量过少：使用数据增强或迁移学习
- 数据质量差：进行数据清洗或使用合成数据补充
- 切分后分布不均：调整切分策略或使用分层抽样
- 归一化参数不一致：确保使用训练集参数归一化验证/测试集

## 质量检查
- 验证切分后各集合数据分布一致性
- 检查归一化参数是否合理
- 确认无数据泄露（同一轨迹数据未跨集合）
- 验证数据维度匹配模型输入要求

## 回退策略
- 数据验证失败：进行数据清洗或使用合成数据
- 切分失败：使用随机切分（但需标注可能的数据泄露风险）
- 归一化失败：使用简单缩放或保留原始数据
