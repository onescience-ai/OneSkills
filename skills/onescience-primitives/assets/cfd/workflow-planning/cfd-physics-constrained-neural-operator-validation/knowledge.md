# 物理约束神经算子任务验收与适用域判定

## 适用范围
面向带守恒边界和无量纲约束PDE数据的任务验收与适用域判定任务，评估统计误差、关键物理约束、泛化能力和计算收益，使用验收指标及任务物理门限给出PASS、REJECT或BLOCKED，执行几何或工况外推测试并明确适用域，不得仅凭平均误差宣称工程可用。适用于Physics-constrained neural operator训练完成后的验收评估阶段，确保模型满足物理一致性要求并明确适用范围。

## 输入
- **验收指标**（必填）：统计误差（relative_L2, RMSE）和物理约束（conservation_residual, boundary_error）
- **相对误差门限**（可选）：测试集放行阈值，默认0.1
- **是否外推测试**（可选）：测试域外工况，默认true
- **推理结果**（来自s04）：预测结果、物理恢复数据和推理耗时
- **数据切分**（来自s02）：测试集清单和统计量

## 输出
- **evaluation.json**：评估结果，包含统计误差、物理约束指标和综合评价
- **worst_cases.csv**：最差样本记录，可追溯的极端情况
- **applicability_report.md**：适用域报告，明确模型适用范围和限制
- **PASS_REJECT_BLOCKED.txt**：验收结论，基于门限的通过/拒绝/阻塞判定

## 流程节点
1. **统计误差计算** → 计算relative_L2、RMSE等统计误差指标
2. **物理约束评估** → 计算conservation_residual、boundary_error等物理约束指标
3. **最差样本分析** → 识别和记录最差性能样本，确保可追溯
4. **泛化能力测试** → 执行几何或工况外推测试，评估模型泛化能力
5. **计算收益评估** → 评估推理成本与精度权衡
6. **适用域判定** → 基于评估结果确定模型适用范围
7. **验收结论** → 基于门限给出PASS、REJECT或BLOCKED判定

## 边界与分流
- **统计误差超门限** → REJECT，建议调整模型或增加训练数据
- **物理约束不满足** → REJECT，建议增加物理约束权重或修改损失函数
- **泛化能力不足** → BLOCKED，建议增加训练数据多样性或使用迁移学习
- **最差样本异常** → 分析异常原因，建议数据清洗或模型改进
- **适用域过窄** → 警告并建议扩展训练数据范围
- **域外工况** → 超出适用域时，必须经CFD复核，不得直接使用模型预测

## 质量检查
- **统计与物理指标同时报告**：确保评估全面性
- **最差样本可追溯**：确保极端情况可分析
- **结论含适用域限制与复核建议**：确保工程可用性
- **不得仅凭平均误差宣称工程可用**：避免误导性结论

## 回退策略
- **评估失败** → 检查推理结果完整性，重新执行推理
- **指标计算错误** → 检查指标计算代码，修正计算逻辑
- **适用域判定困难** → 增加外推测试样本，细化适用域划分
