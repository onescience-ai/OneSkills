# PDE场数据预处理与无泄漏切分

## 适用范围

**触发条件**：
- 已完成数据核验，需要进行预处理与切分
- 需要按几何、工况或时间构造无泄漏切分
- 需要统一物理量表示与归一化

**适用场景**：
- 算子学习工作流的数据预处理阶段
- 需要确保训练/验证/测试集独立性
- 需要保存可逆变换用于物理恢复

**不适用场景**：
- 数据已完全预处理且切分完成
- 非PDE场数据的简单回归任务

## 输入

**必填输入**：
- {SPLIT_CONFIG}：切分配置（比例、种子、分组策略）
- {TARGET_FIELDS}：目标变量列表

**可选输入**：
- {NONDIMENSIONALIZE}：是否无量纲化（默认true）

## 输出

**产物清单**：
- train_manifest.json：训练集清单
- validation_manifest.json：验证集清单
- test_manifest.json：测试集清单
- normalization.json：归一化统计量

## 流程节点

### 操作步骤
1. 依据s01契约完成质控
2. 重采样或图构建、掩膜
3. 归一化或无量纲化
4. 按{SPLIT_CONFIG}以几何、完整轨迹或物理工况为单位切分
5. 为{TARGET_FIELDS}保存统计量与可逆变换

### 关键参数
- 切分比例：默认0.7:0.15:0.15（train:val:test）
- 分组策略：按geometry_or_trajectory分组
- 随机种子：默认42
- 无量纲化：默认开启

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认切分比例 | 0.7:0.15:0.15 | [场景S055] | train:val:test |
| 分组策略 | geometry_or_trajectory | [场景S055] | 避免同一轨迹帧随机打散 |
| 随机种子 | 42 | [场景S055] | 可复现性 |
| 无量纲化 | true | [场景S055] | 统一跨工况量纲 |

## 边界与分流

**异常处理**：
1. 切分后训练集过小 → 调整切分比例或使用数据增强
2. 变量分布差异大 → 使用分层切分或独立归一化
3. 时间序列数据 → 按时间顺序切分，避免未来信息泄漏

## 质量检查

**验证点**：
- 三份切分的对象轨迹互斥
- 仅用训练集计算变换统计量
- 边界与掩膜语义未破坏

**失败处理**：
- 任一验证点不通过 → 重新检查切分逻辑并修复

## 回退策略

**替代方案**：
- 切分策略复杂 → 简化为随机切分并标注风险
- 归一化不稳定 → 使用鲁棒归一化方法（如分位数归一化）
