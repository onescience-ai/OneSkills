# 算子推理与物理恢复

## 适用范围

**触发条件**：
- 已完成模型训练，需要在测试集上推理
- 需要恢复原始单位、网格和物理派生量
- 需要保存逐样本结果与耗时

**适用场景**：
- 算子学习工作流的推理阶段
- 需要确保预测完整性与物理正确性
- 需要避免使用测试标签修正预测

**不适用场景**：
- 模型未训练完成或权重不可用
- 非PDE场数据的推理任务

## 输入

**必填输入**：
- {CHECKPOINT}：模型权重（通过训练门限权重）
- {DEVICE}：计算设备（CPU或CUDA设备）

**可选输入**：
- {BATCH_SIZE}：推理批大小（默认8）

## 输出

**产物清单**：
- predictions/：逐样本预测结果
- inference_manifest.json：推理清单
- timing.csv：推理耗时记录

## 流程节点

### 操作步骤
1. 加载{CHECKPOINT}及训练时数据契约
2. 在s02独立测试集上以{DEVICE}和{BATCH_SIZE}推理
3. 反归一化并恢复物理单位、坐标网格、边界掩膜及任务派生量
4. 保存逐样本结果和耗时
5. 禁止用测试标签修正预测

### 关键参数
- 推理设备：CPU或CUDA
- 批大小：默认8
- 反归一化：使用训练时统计量

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认批大小 | 8 | [场景S055] | 按显存调整 |
| 推理设备 | cuda | [场景S055] | 默认使用GPU |
| 反归一化 | 使用训练时统计量 | [场景S055] | 确保物理单位正确 |

## 边界与分流

**异常处理**：
1. 预测出现NaN或Inf → 检查输入数据与模型权重
2. 形状或单位不正确 → 检查数据契约与反归一化逻辑
3. 推理设备不可用 → 降级为CPU推理
4. 内存不足 → 减小批大小或使用混合精度

## 质量检查

**验证点**：
- 预测无NaN或Inf且形状单位正确
- 每个测试样本有唯一结果
- 推理未使用测试目标校正

**失败处理**：
- 任一验证点不通过 → 检查推理代码，定位问题并修复

## 回退策略

**替代方案**：
- 推理失败 → 检查数据契约与权重兼容性
- 物理恢复失败 → 降级为无量纲结果或标注不确定性
