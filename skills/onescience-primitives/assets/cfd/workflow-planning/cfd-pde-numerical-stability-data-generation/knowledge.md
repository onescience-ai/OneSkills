# PDE数值求解稳定性保障与合成数据生成

## 适用范围

**触发条件**：
- 需要从PDE方程生成合成训练数据
- 遇到数值不稳定（NaN/Inf）问题需要解决
- 需要为PDE求解模型提供高质量训练数据集

**适用场景**：
- Burgers方程、Navier-Stokes方程、线性对流方程、扩散方程的合成数据生成
- PDE神经网络算子的训练数据准备
- 数值方法稳定性验证与参数调优
- 需要生成具有特定动力学特征（如激波、湍流）的PDE轨迹数据

**不适用场景**：
- 实验数据或观测数据的处理（非合成数据）
- 纯解析解已知的简单PDE（无需数值求解）
- 需要高保真CFD求解器（如OpenFOAM）的工程应用

## 输入

- PDE方程类型与参数（方程形式、系数、初始/边界条件）
- 空间域和时间域范围
- 网格分辨率要求（nx, nt）
- 数值方法选择（显式/隐式/谱方法）

## 输出

- 数值稳定的PDE合成数据集（HDF5/NPZ格式）
- 数值方法配置信息（CFL数、离散格式、求解器参数）
- 数据质量校验报告（NaN/Inf检查、数值范围、时空连续性）
- 可视化验证图（时空剖面图、激波特征）

## 流程节点

### Step 1：CFL条件检查
- **操作**：根据PDE类型和网格参数计算CFL数，确保稳定性
- **对流方程**：CFL = c·Δt/Δx ≤ 1（c为对流速度）
- **扩散方程**：D·Δt/Δx² ≤ 0.5（D为扩散系数）
- **非线性方程**：CFL = max|u|·Δt/Δx ≤ 1（u为解场）
- **参数**：Δx, Δt, PDE系数
- **工具**：NumPy计算
- **质量门禁**：CFL < 1（显式格式必须满足）

### Step 2：数值方法选择
- **操作**：根据PDE类型选择合适的数值方法
- **线性对流方程**：显式欧拉 + 一阶/二阶迎风格式（简单稳定）
- **Burgers方程**：伪谱法 + 去混叠（处理非线性项），或Crank-Nicolson格式
- **扩散方程**：隐式Euler或Crank-Nicolson（无条件稳定）
- **Navier-Stokes**：IMEX格式（隐式处理扩散项，显式处理对流项）
- **参数**：PDE类型、非线性程度、刚性程度
- **工具**：SciPy/NumPy
- **质量门禁**：所选方法在给定CFL数下稳定

### Step 3：伪谱法实现（推荐用于非线性PDE）
- **操作**：用FFT在频域计算空间导数，用FFT处理非线性项
- **去混叠**：2/3规则（截断最高1/3频率模式）或3/2零填充
- **参数**：nx（空间网格数）、dealiasing_ratio（去混叠比例）
- **工具**：NumPy FFT (np.fft.fftn, np.fft.ifftn)
- **质量门禁**：非线性项计算无能量堆积（频域能量谱无异常峰值）

### Step 4：时间积分
- **操作**：选择合适的时间积分格式推进求解
- **显式Euler**：u(t+Δt) = u(t) + Δt·f(u(t))（最简单，CFL限制严格）
- **RK4**：四阶Runge-Kutta（精度高，CFL限制较宽）
- **ETDRK4**：指数时间差分RK4（适合刚性PDE，频域实现高效）
- **参数**：Δt、总时间T、时间步数nt
- **工具**：自定义时间积分循环
- **质量门禁**：解场在所有时间步无NaN/Inf

### Step 5：数据质量校验
- **操作**：生成后自动执行多项质量检查
- **NaN/Inf检查**：np.any(np.isnan(data)) 或 np.any(np.isinf(data))
- **数值范围**：检查|u|是否在物理合理范围内
- **时空连续性**：检查相邻时间步和空间点的差异是否平滑
- **参数**：数据数组、物理量范围
- **工具**：NumPy
- **质量门禁**：无NaN/Inf，数值范围合理，时空连续

### Step 6：可视化验证
- **操作**：生成时空剖面图验证数据质量
- **对流方程**：应显示波的传播特征
- **Burgers方程**：应显示激波形成特征
- **参数**：x坐标、t坐标、u场
- **工具**：Matplotlib
- **质量门禁**：图像显示预期的PDE动力学特征

## 关键参数

### 通用判据（方法层）

| 参数 | 推荐值 | 来源 | 说明 |
|------|--------|------|------|
| CFL数 | < 1（显式格式） | [D1][D2] | 显式格式稳定性的必要条件 |
| 去混叠比例 | 2/3 | [D1] | 伪谱法标准去混叠规则 |
| 空间分辨率 | ≥ 64点 | [D1] | 足够分辨PDE特征（激波/边界层） |
| 时间分辨率 | 满足CFL | [D1][D2] | 由CFL条件和空间分辨率推导 |
| NaN检查 | 必须通过 | [D3] | 数据质量底线 |

### 校准数值（来自Burgers方程体系，供量级校准；其他体系需以自身证据重新锚定）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| ν（粘性系数） | 0.01-0.1 | [D1] | Burgers方程的粘性参数 |
| nx（空间网格） | 256-1024 | [D1] | 谐波法常用分辨率 |
| Δt | 1e-4 ~ 1e-2 | [D2] | 取决于CFL条件 |
| 总时间T | 1-10 | [D1] | 通常覆盖2-5个特征时间尺度 |
| 初始条件 | 随机光滑函数 | [D3] | 避免不连续初始条件导致数值不稳定 |

## 边界与分流

- **CFL条件不满足**：减小Δt或增大Δx，直到CFL<1
- **伪谱法出现能量堆积**：增加去混叠比例（2/3→3/4），或检查时间步长
- **非线性项处理失败**：改用IMEX格式（隐式处理非线性项）或降低时间步长
- **数据生成后出现NaN**：回溯到最后一个非NaN时间步，调整参数重新生成
- **线性对流方程作为替代**：若Burgers方程不稳定，先用线性对流方程验证模型架构，但需在报告中标注

## 质量检查

- [ ] CFL数 < 1（显式格式）
- [ ] 生成数据无NaN/Inf
- [ ] 数值范围在物理合理量级内
- [ ] 时空剖面图显示预期的PDE动力学特征
- [ ] 边界条件在所有时间步满足
- [ ] 总质量变化率 < 1e-3（对守恒方程）

## 回退策略

- 若伪谱法不稳定，改用有限差分法（更鲁棒但精度较低）
- 若非线性PDE不稳定，先用线性化版本验证，再逐步引入非线性
- 若时间积分失败，改用隐式方法（如ETDRK4）
