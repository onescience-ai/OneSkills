# 批量推理与物理恢复

## 适用范围

本卡描述可迁移ROM工作流第四步：加载训练好的模型权重与数据契约，在独立测试集上执行批量推理，反归一化并恢复原始物理单位、坐标网格、边界掩膜及任务派生量。适用于ROM推理结果的物理意义恢复。

## 输入

| 输入 | 类型 | 必填 | 说明 |
|------|------|------|------|
| {CHECKPOINT} | doc | 是 | 训练好的模型权重（best_checkpoint.pt） |
| s02切分数据 | object | 是 | test_manifest.json（独立测试集） |
| s02统计量 | object | 是 | normalization.json（逆变换参数） |
| {DEVICE} | str | 是 | 计算设备（cpu或cuda） |
| {BATCH_SIZE} | int | 否 | 推理批大小（默认8） |

## 输出

| 输出 | 说明 |
|------|------|
| predictions/ | 逐样本预测结果目录 |
| inference_manifest.json | 推理清单（样本ID、预测文件路径、耗时） |
| timing.csv | 推理耗时统计（逐样本与汇总） |

## 流程节点

1. **模型加载**：加载{CHECKPOINT}权重，设置{DEVICE}
2. **测试集加载**：读取s02 test_manifest.json
3. **批量推理**：以{BATCH_SIZE}批量执行推理
4. **反归一化**：使用s02 normalization.json执行逆变换
5. **物理单位恢复**：将无量纲预测值恢复为原始物理单位
6. **网格坐标恢复**：恢复空间坐标与网格拓扑
7. **边界掩膜恢复**：恢复边界条件掩膜
8. **派生量计算**：计算任务特定的派生物理量
9. **结果保存**：保存逐样本预测结果与耗时

## 关键参数

### 通用判据

| 参数 | 判据 | 来源 | 说明 |
|------|------|------|------|
| 无异常值 | 预测无NaN或Inf | s04质量门禁 | 推理产物可用性 |
| 形状单位正确 | 预测形状与原始数据一致、单位正确 | s04质量门禁 | 物理恢复有效性 |
| 唯一性 | 每个测试样本有唯一结果 | s04质量门禁 | 结果可追溯性 |
| 无标签泄漏 | 推理未使用测试目标校正 | s04质量门禁 | 评估公正性 |
| 可逆性 | 逆变换参数完整且正确 | s04流程要求 | 物理恢复前提 |

### 校准数值

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认设备 | cuda | 场景需求书s04 | 其他体系需以自身证据重新锚定 |
| 默认推理Batch Size | 8 | 场景需求书s04 | 按显存调整 |

## 边界与分流

- {CHECKPOINT}无法加载 → 判定模型产物无效，需回到s03重新训练
- 推理结果包含NaN/Inf → 检查模型权重与输入数据
- 预测形状不匹配 → 检查输入数据格式与模型输入维度
- 逆变换参数缺失 → 无法执行物理恢复，需回到s02重新生成normalization.json
- 推理设备不可用 → 降级到CPU推理，记录设备变更

## 质量检查

- 预测无NaN或Inf且形状单位正确
- 每个测试样本有唯一结果文件
- 推理未使用测试目标校正（无信息泄漏）
- timing.csv包含逐样本与汇总耗时
- predictions/目录结构完整

## 回退策略

- 模型加载失败：检查权重文件完整性与模型架构
- 推理异常：降级推理精度（如float32→float64）或减小batch size
- 物理恢复失败：检查normalization.json参数完整性
- 设备不可用：切换到CPU推理，记录性能降级

## 资源召回建议

当任务需要对训练好的可迁移ROM执行推理并恢复物理意义时召回本卡片。本卡片依赖s03训练产物，完成后进入s05验收。
