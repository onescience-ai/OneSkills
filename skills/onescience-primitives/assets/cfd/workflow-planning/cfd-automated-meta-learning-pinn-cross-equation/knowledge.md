# 自动化与元学习PINN跨方程求解

## 适用范围

面向偏微分方程（PDE）族，使用自动化与元学习方法训练物理信息神经网络（PINN），实现跨多个物理方程的统一求解。适用于需要在一个模型框架内处理多种PDE类型（如Navier-Stokes方程、Burgers方程、扩散方程、波动方程等）的场景，特别适合PDEBench、PINNacle等多方程基准测试任务。

**不适用场景**：
- 单一方程高精度求解（传统PINN或数值方法更优）
- 纯数据驱动无物理约束的学习任务
- 域外工况需经CFD专业复核的工程应用

## 输入

| 输入类型 | 变量 | 说明 |
|---------|------|------|
| 数据集路径 | `{DATASET_PATH}` | PDEBench/PINNacle多方程基准目录 |
| 数据集名称 | `{DATASET_NAME}` | 来源与版本标识 |
| 数据契约 | `{DATA_CONTRACT}` | 变量、单位、网格定义（可选） |
| 训练配置 | `{TRAIN_CONFIG}` | 超参数、框架、随机种子 |

## 输出

| 输出产物 | 说明 |
|---------|------|
| 可复现模型 | 训练好的Meta-PINN/PINN agent/PINN Transformer权重 |
| 任务结果 | 解场、导数、通量、残差场 |
| 物理一致性评估 | 统计误差+物理约束+守恒验证 |
| 适用域报告 | PASS/REJECT/BLOCKED判定及边界条件 |

## 流程节点

数据接入与契约核验 → 预处理与数据切分 → 模型配置与训练 → 方程求解与物理残差恢复 → 任务验收与适用域判定

**各节点说明**：

1. **数据接入与契约核验**：读取基准数据集，检查文件可读性、样本数、变量定义、单位、坐标系、网格拓扑、时间范围、缺失值和使用许可，输出机器可读契约。
2. **预处理与数据切分**：统一物理量表示，按几何、工况或时间构造无泄漏切分，保存统计量与可逆变换。
3. **模型配置与训练**：使用Meta-PINN、PINN agent或PINN Transformer训练模型，记录代码版本、依赖、随机种子、逐轮指标与最佳权重。
4. **方程求解与物理残差恢复**：在查询配点或网格上恢复解场、导数、边界值与方程残差，禁止仅依据训练损失判定求解。
5. **任务验收与适用域判定**：评估统计误差、物理约束、泛化能力和计算收益，给出PASS/REJECT/BLOCKED结论。

## 关键参数

### 通用判据（方法层）

| 参数 | 判据 | 来源 | 说明 |
|------|------|------|------|
| 数据泄漏检测 | 训练集/验证集/测试集对象轨迹互斥 | [场景需求书s01] | 按几何或完整轨迹切分，不得打散同一轨迹帧 |
| 变换统计量 | 仅用训练集计算归一化/无量纲化参数 | [场景需求书s02] | 防止信息泄漏 |
| 损失有限性 | 训练验证损失均为有限值 | [场景需求书s03] | 发散即终止 |
| 权重可加载 | 最佳权重可重新加载 | [场景需求书s03] | checkpoint完整性校验 |
| 残差有限性 | 解场导数与残差均为有限值 | [场景需求书s04] | 非数值即异常 |
| 边界满足 | 边初值逐项满足门限 | [场景需求书s04] | 物理约束硬性要求 |
| 双指标报告 | 统计与物理指标同时报告 | [场景需求书s05] | 不得仅凭平均误差判定 |

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认训练轮数 | 100 epochs | [场景需求书s03] | 可根据收敛调整 |

## 边界与分流

| 前提条件 | 不成立时转向 |
|---------|-------------|
| 数据集格式符合PDEBench/PINNacle规范 | 进行格式适配或手动定义数据契约 |
| 模型能在训练集上收敛 | 检查损失函数设计、网络结构、学习率调度 |
| 物理残差在合理范围 | 回退到单方程PINN训练，或调整损失权重 |
| 域外工况需要复核 | 转入CFD专业复核流程，不自动放行 |

## 质量检查

- **数据层**：文件可读、样本可追溯、变量单位坐标完整、无训练测试泄漏
- **训练层**：损失有限、权重可加载、环境可复现（随机种子固定）
- **求解层**：导数与残差有限、边界满足、可与独立数值解或解析解对照
- **验收层**：统计与物理指标双报告、最差样本可追溯、结论含适用域限制

## 回退策略

1. **训练不收敛**：降低学习率、增加训练轮数、调整网络结构（增加宽度/深度）
2. **残差过大**：增加配点数量、调整损失权重（PDE残差vs边界残差vs数据拟合）
3. **跨方程泛化差**：使用元学习策略（如DATS困难感知采样）、增加任务多样性
4. **域外工况失效**：明确标记适用域边界，提交CFD专业复核
