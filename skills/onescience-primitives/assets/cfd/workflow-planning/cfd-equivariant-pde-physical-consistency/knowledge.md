# 等变PDE物理一致性评估

## 适用范围

本卡片服务于等变PDE预测模型的物理一致性评估。在批量推理完成后，需要从守恒律、边界条件、对称性保持、方程残差等维度评估预测结果的物理合理性。适用于任何PDE预测模型的物理验证。不适用于：纯数据驱动且不关心物理一致性的场景（如图像超分辨率）；PDE本身无守恒律（如纯扩散方程的部分简化形式）。

## 输入

- s04输出的预测结果（predictions/）
- 原始PDE方程信息（用于方程残差计算）
- 边界条件定义
- 守恒量定义（如质量、动量、能量）

## 输出

- 守恒残差（conservation_residual）：预测场的守恒量偏差
- 边界误差（boundary_error）：边界条件满足度
- 对称性保持度：预测场在群变换下的不变性/等变性
- 方程残差：预测场代入PDE方程后的残差
- 物理一致性综合报告

## 流程节点

1. **守恒量计算** → 计算预测场的总质量、总动量、总能量等
2. **守恒残差评估** → 与初始条件/真实值的守恒量偏差
3. **边界条件检验** → 预测场在边界上是否满足给定条件
4. **对称性验证** → 对预测场施加群变换，验证输出等变性
5. **方程残差计算** → 将预测场代入PDE方程计算残差
6. **综合评估** → 加权或阈值判定物理一致性是否达标

## 边界与分流

- **守恒残差超标但统计指标达标**：REJECT，模型物理不一致
- **边界误差超标**：检查边界条件定义和模型边界处理
- **对称性保持度低**：检查等变层设计是否正确实现
- **OOD工况物理一致性差**：限定适用域，输出复核建议

## 质量检查

- 守恒残差、边界误差、方程残差同时报告（质量门禁）
- 对称性保持度数值验证通过
- 最差样本可追溯到具体物理工况
- 适用域报告含物理一致性限制

## 回退策略

- 物理约束违反严重：引入物理信息惩罚项（PINN风格）重新训练
- 守恒律无法计算：使用代理指标（如局部梯度平滑度）
