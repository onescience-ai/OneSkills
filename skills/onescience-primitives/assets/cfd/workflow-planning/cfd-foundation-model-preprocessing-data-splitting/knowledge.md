# Preprocessing and Data Splitting

## 适用范围

面向多物理算子迁移的预处理与数据切分阶段，统一物理量表示、无量纲化处理、按几何/轨迹/工况构造无泄漏训练验证测试集。适用于所有需要从多物理预训练数据切分出目标任务数据的场景。

## 输入

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| SPLIT_CONFIG | object | 是 | 切分配置：比例、随机种子、分组依据 |
| TARGET_FIELDS | list[str] | 是 | 目标变量列表（待预测物理量） |
| NONDIMENSIONALIZE | bool | 否 | 是否无量纲化（默认 true） |

## 输出

| 产物 | 格式 | 说明 |
|------|------|------|
| train_manifest.json | JSON | 训练集清单 |
| validation_manifest.json | JSON | 验证集清单 |
| test_manifest.json | JSON | 测试集清单 |
| normalization.json | JSON | 归一化/无量纲化统计量（均值、标准差、范围） |

## 流程节点

1. **接收 s01 契约** → 加载 data_contract.json
2. **质控与清洗** → 处理缺失值、异常值
3. **重采样或图构建** → 统一网格表示或构建图结构
4. **掩膜处理** → 生成边界掩膜、有效区域掩膜
5. **归一化或无量纲化** → 按 NONDIMENSIONALIZE 配置处理
6. **无泄漏切分** → 按 group_by（geometry/trajectory/condition）切分
7. **保存统计量** → 记录变换参数，支持可逆恢复

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 切分比例 | train:val:test = 0.7:0.15:0.15 | 场景需求书 | 默认比例 |
| 切分单位 | 几何/完整轨迹/物理工况 | 场景需求书 | 不得打散同一轨迹帧 |
| 随机种子 | 42 | 场景需求书 | 可复现性 |

### 校准数值
> 以下数值来自场景需求书，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认 train 比例 | 0.7 | 场景需求书 | 可调整 |
| 默认 seed | 42 | 场景需求书 | 固定种子 |

## 边界与分流

- **切分比例不满足**：调整 SPLIT_CONFIG 后重新切分
- **数据量过小**：考虑使用 K-fold 交叉验证替代
- **工况跨度过大**：按工况分层切分确保分布一致

## 质量检查

- [ ] 三份切分的对象轨迹互斥
- [ ] 仅用训练集计算变换统计量
- [ ] 边界与掩膜语义未破坏
- [ ] 可逆变换参数已保存

## 回退策略

- 切分后验证集分布偏移 → 重新调整切分策略
- 归一化参数泄露 → 重新从训练集计算统计量
