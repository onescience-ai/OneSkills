# PINN基准数据接入与契约核验

## 适用范围

面向PDEBench、PINNacle等多方程基准数据集的接入与契约核验，用于自动化PINN跨方程求解工作流的第一步。确保数据格式合规、变量定义完整、无训练测试泄漏，为后续预处理和模型训练提供可靠输入。

**触发条件**：开始PINN跨方程求解任务时，首先执行本步骤。

## 输入

| 输入类型 | 变量 | 必填 | 说明 |
|---------|------|------|------|
| 数据集路径 | `{DATASET_PATH}` | 是 | 目录或清单文件 |
| 数据集名称 | `{DATASET_NAME}` | 是 | 来源与数据版本 |
| 数据契约 | `{DATA_CONTRACT}` | 否 | 变量单位网格定义 |

## 输出

| 输出产物 | 格式 | 说明 |
|---------|------|------|
| dataset_manifest.json | JSON | 数据清单（文件列表、样本数、变量、单位、坐标、网格、时间范围） |
| data_contract.json | JSON | 机器可读契约（输入字段、目标字段、单位、坐标系） |
| data_audit.md | Markdown | 人工可读审计报告（缺失值、异常、许可、建议） |

## 流程节点

### 1. 文件可读性检查

**操作**：
- 遍历{DATASET_PATH}下所有数据文件
- 检查文件是否存在、可读、格式合规（HDF5/NetCDF/CSV等）
- 记录文件大小、修改时间

**参数**：
- 支持格式：HDF5, NetCDF, CSV, NumPy
- 编码检查：UTF-8, ASCII

**质量门禁**：所有必填文件可读

---

### 2. 样本数与可追溯性

**操作**：
- 统计每个文件的样本数
- 检查样本索引是否连续、唯一
- 验证样本可追溯到具体工况/几何/时间

**参数**：
- 样本ID格式：{geometry}_{condition}_{time_step} 或等效
- 最小样本数：依任务而定

**质量门禁**：样本可追溯到具体工况

---

### 3. 变量定义检查

**操作**：
- 识别输入变量和目标变量
- 验证变量名、维度、数据类型
- 检查变量间依赖关系

**参数**：
- 输入字段：空间坐标(x,y,z)、时间t、初始条件、边界条件等
- 目标字段：压力p、速度(u,v,w)、温度T等

**质量门禁**：输入与目标变量定义完整

---

### 4. 单位与坐标系

**操作**：
- 提取各变量的单位信息
- 验证坐标系定义（笛卡尔/柱坐标/球坐标）
- 检查单位一致性（如SI单位制）

**参数**：
- 单位来源：文件元数据或{DATA_CONTRACT}
- 坐标系：dataset_native 或显式定义

**质量门禁**：单位与坐标系定义完整且一致

---

### 5. 网格拓扑与时间范围

**操作**：
- 检查空间网格类型（结构化/非结构化/点云）
- 验证网格分辨率、边界
- 提取时间步范围、时间分辨率

**参数**：
- 网格类型：structured/unstructured/point_cloud
- 时间范围：[t_min, t_max]
- 时间步数：N_t

**质量门禁**：网格与时间信息完整

---

### 6. 缺失值与异常检测

**操作**：
- 统计各变量缺失值比例
- 检测异常值（NaN, Inf, 超出物理范围）
- 记录缺失模式（随机/系统性）

**参数**：
- 缺失阈值：>5%需标记
- 异常范围：依物理量而定

**质量门禁**：缺失值已记录，异常值已标记

---

### 7. 使用许可与数据审计

**操作**：
- 检查数据集许可条款
- 确认引用要求
- 生成人工可读审计报告

**参数**：
- 许可类型：MIT/Apache/CC-BY/专有
- 引用要求：BibTeX条目

**质量门禁**：许可条款明确，引用要求已记录

## 边界与分流

| 前提条件 | 不成立时转向 |
|---------|-------------|
| 数据格式为HDF5/NetCDF/CSV | 尝试格式转换或手动定义契约 |
| 单位信息存在于元数据 | 从{DATA_CONTRACT}读取或人工指定 |
| 坐标系信息明确 | 使用dataset_native或手动定义 |
| 许可条款明确 | 标记为待确认，不阻塞主流程 |

## 质量检查

**检查清单**：
1. 文件可读性：所有文件存在、可读、格式合规
2. 样本数：统计完整，索引唯一连续
3. 变量定义：输入与目标变量完整，维度正确
4. 单位：所有变量单位明确
5. 坐标系：定义明确且一致
6. 网格：类型、分辨率、边界信息完整
7. 时间：范围、步数、分辨率明确
8. 缺失值：已统计并记录
9. 异常值：已检测并标记
10. 许可：条款明确，引用要求已记录

## 回退策略

1. **文件格式不支持**：尝试格式转换（如CSV→HDF5），或手动定义数据契约
2. **单位信息缺失**：从数据集文档或{DATA_CONTRACT}读取，或人工指定
3. **坐标系不明确**：使用dataset_native，或从网格结构推断
4. **许可条款模糊**：标记为待确认，继续流程但不公开分发
