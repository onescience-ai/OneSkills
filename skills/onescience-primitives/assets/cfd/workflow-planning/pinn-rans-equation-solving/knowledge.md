# PINN湍流RANS均值流求解 - 方程求解与物理残差恢复

## 适用范围

本步骤用于PINN湍流RANS均值流求解与闭合的方程求解阶段，负责在查询配点或网格上恢复解场、导数、边界值与方程残差，验证物理一致性。

**触发条件**：
- 模型训练已完成且权重可用
- 需要在查询点上恢复完整湍流场

**不适用场景**：
- 仅需训练指标且无需场重建的场景
- 模型权重不可用或损坏的情况

## 输入

- **{CHECKPOINT}**：模型权重（通过训练门限权重）
- **{DEVICE}**：计算设备（CPU或CUDA设备）
- **{BATCH_SIZE}**：推理批大小（按显存调整批量）

## 输出

- **solution_fields/**：解场文件（速度、压力、湍流量等）
- **pde_residuals/**：PDE残差文件（方程残差）
- **boundary_residuals.csv**：边界残差文件（边界条件满足情况）

## 流程节点

```
加载权重 → 加载测试数据 → 前向推理 → 计算导数 → 计算通量 → 计算方程残差 → 保存解场与残差
```

### 关键步骤说明

1. **加载权重**：加载{CHECKPOINT}中的模型权重
2. **加载测试数据**：加载测试参数、边界和查询坐标
3. **前向推理**：使用自动微分恢复导数
4. **计算导数**：计算速度梯度、应力张量等
5. **计算通量**：计算质量通量、动量通量等
6. **计算方程残差**：计算RANS方程残差
7. **保存解场与残差**：保存solution_fields/和pde_residuals/

## 边界与分流

**关键前提与改道**：

1. **前提：模型权重可用且结构正确**
   - 不成立时 → 重新训练或使用备份权重

2. **前提：查询坐标在训练域内或合理外推**
   - 不成立时 → 调整查询范围或使用外推方法

3. **前提：自动微分可用**
   - 不成立时 → 使用离散算子替代

## 质量检查

- **解场导数与残差均为有限值**：不能出现NaN或Inf
- **边初值逐项满足门限**：边界条件满足预设阈值
- **独立数值解或解析解可对照**：与参考解对比验证

## 回退策略

1. **导数或残差出现NaN**：检查模型权重、调整推理批大小
2. **边界条件不满足**：调整边界处理方法或配点策略
3. **无法对照验证**：使用网格收敛性研究替代
