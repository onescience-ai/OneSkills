# A Priori / A Posteriori Coupling Validation for LES Closure Models

## 适用范围

**触发条件**：
- 已训练数据驱动湍流闭合模型（应力张量、通量或源项预测器），需要验证其物理一致性和求解器集成效果
- 需要区分先验统计评估与后验推进评估两个阶段的方法和判据
- 需要判定闭合模型是否满足工程LES使用的物理约束

**适用场景**：
- 数据驱动LES源项嵌入RANS或LES求解器后的验证
- 机器学习湍流闭合模型的物理可实现性检查
- 先验误差与后验一致性的对比分析

**不适用场景**：
- 纯统计预测（不嵌入求解器）
- 传统RANS模型的参数调优
- 无高保真参考数据的先验评估

## 输入

| 输入 | 类型 | 说明 |
|------|------|------|
| 已训练模型权重 | checkpoint | 通过训练门限的最佳权重 |
| 先验快照 | data | 独立DNS/LES快照，用于先验误差评估 |
| 求解器配置 | config | RANS或LES求解器的网格、边界条件、数值格式 |
| 物理约束定义 | spec | 闭合张量需满足的对称性、正定性、量纲要求 |
| 验收指标 | list | 统计指标与物理指标列表 |

## 输出

| 输出 | 格式 | 说明 |
|------|------|------|
| apriori_closure/ | Directory | 先验闭合项预测场与误差场 |
| aposteriori_fields/ | Directory | 后验求解器输出的流场变量 |
| solver_stability.csv | CSV | 残差历史、时间步、稳定性标记 |
| evaluation.json | JSON | 综合评估指标 |
| worst_cases.csv | CSV | 最差样本及其工况信息 |
| applicability_report.md | Markdown | 适用域判定报告 |
| PASS_REJECT_BLOCKED.txt | Text | 最终验收结论 |

## 流程节点

### Phase A：A Priori 先验评估

#### A1：闭合项预测
- **操作**：加载模型权重，在独立DNS/LES快照上预测应力张量、通量或源项
- **质量门禁**：预测值为有限值，无NaN/Inf

#### A2：物理可实现性检查
- **操作**：检查闭合张量是否满足基本物理约束
- **检查项**：
  - 对称性：应力张量 τ_ij = τ_ji
  - 正定性/负定性（取决于模型约定）
  - 量纲一致性：应力量纲为Pa（压力量纲）
  - 守恒约束：源项积分满足守恒律
- **工具**：自定义检查脚本

#### A3：先验统计误差
- **操作**：计算逐点误差、RMSE、相对L2误差
- **指标**：closure_RMSE、逐分量误差、空间分布热图

### Phase B：A Posteriori 后验验证

#### B1：求解器嵌入
- **操作**：将模型封装为求解器可调用的闭合项模块，嵌入RANS或LES框架
- **关键**：模型推理必须在求解器的每个时间步或迭代步可调用
- **工具**：CFD求解器（OpenFOAM/自研）+ PyTorch inference

#### B2：后验推进
- **操作**：执行完整的流场求解推进，记录残差、场变量和稳定性信息
- **输出**：aposteriori_fields/（流场快照）、solver_stability.csv（稳定性记录）
- **质量门禁**：残差单调下降或收敛到稳定值；无非物理振荡或发散

#### B3：统计一致性
- **操作**：对比后验流场与参考数据的均值剖面、能谱、雷诺应力分布
- **指标**：mean_profile_error、spectrum_error、stability_horizon

### Phase C：验收与适用域

#### C1：综合验收
- **操作**：汇总先验与后验指标，按门限给出PASS/REJECT/BLOCKED
- **判据**：统计误差 + 物理约束 + 稳定性同时满足

#### C2：适用域判定
- **操作**：分析最差样本，评估几何/工况外推能力
- **产出**：applicability_report.md（适用域边界）+ worst_cases.csv（最差样本追溯）
- **关键约束**：不得仅凭平均误差宣称工程可用

## 关键参数

### 通用判据

| 参数 | 判据 | 来源 | 说明 |
|------|------|------|------|
| 张量对称性 | τ_ij = τ_ji 偏差 < 容差 | 场景需求书 s04 quality_gate | 闭合张量基本要求 |
| 后验无发散 | 残差收敛，无非物理解 | 场景需求书 s04 quality_gate | 求解器集成基本要求 |
| 能谱一致性 | 高波数段能谱衰减趋势匹配 | 场景需求书 s04 quality_gate | LES闭合模型的物理一致性 |
| 均值剖面 | 速度/压力量纲误差在可接受范围 | 场景需求书 s04 quality_gate | 工程精度判据 |
| 统计+物理联合 | 两类指标同时报告 | 场景需求书 s05 quality_gate | 不得仅报告统计指标 |
| 最差样本追溯 | worst_cases.csv含工况和误差 | 场景需求书 s05 quality_gate | 可追溯性要求 |

### 校准数值

以下数值来自场景需求书默认配置，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 默认值 | 来源 | 说明 |
|------|--------|------|------|
| 推理批大小 | 8 | 场景需求书 s04 | 视显存调整 |
| 相对L2门限 | 0.1 | 场景需求书 s05 | 验收放行阈值 |
| 默认验收指标 | closure_RMSE, mean_profile_error, spectrum_error, stability_horizon | 场景需求书 s05 | 覆盖统计与物理维度 |

## 边界与分流

| 前提 | 不成立时的改道 |
|------|---------------|
| 先验闭合项违反物理约束 | 在后验推进前施加约束投影，或回退到传统模型 |
| 后验求解发散 | 回退到先验评估，仅报告统计误差，不宣称工程可用 |
| 能谱在高波数段不匹配 | 检查模型是否过度平滑，调整模型架构或正则化 |
| 最差样本误差显著高于均值 | 分析最差样本特征，判定是否在适用域内 |
| 域外工况误差超标 | 不宣称工程可用，需扩展训练数据或回退到原体系 |

## 质量检查

| 检查点 | 通过标准 | 失败处理 |
|--------|---------|---------|
| 闭合张量可实现性 | 对称性/量纲/正定性检查通过 | 约束投影或回退 |
| 后验求解稳定 | 残差收敛，无非物理振荡 | 缩小时间步或回退 |
| 能谱一致性 | 高波数衰减趋势匹配 | 调整模型正则化 |
| 均值剖面精度 | 误差 ≤ 门限 | 回退到传统模型 |
| 最差样本可追溯 | worst_cases.csv记录完整 | 补充分析 |
| 适用域明确 | 报告含工况/几何边界 | 补充外推测试 |

## 回退策略

- 先验约束不满足：施加后处理约束投影
- 后验发散：仅报告先验评估
- 验收REJECT：不输出工程可用结论
- 适用域外推失败：回退到原体系校准
