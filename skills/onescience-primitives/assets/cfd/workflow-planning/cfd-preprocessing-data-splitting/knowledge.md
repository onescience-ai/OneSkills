# CFD预处理与数据切分

## 适用范围

**触发条件**：
- CFD数据已完成接入与契约核验
- 需要将数据切分为训练/验证/测试集
- 需要进行归一化、无量纲化或图构建

**适用场景**：
- 流场数据按轨迹、几何或工况进行无泄漏切分
- 多工况流场数据的标准化处理
- 为GNN准备图结构数据（节点特征、邻接矩阵）
- 自编码器潜空间流动降阶时序预测的数据预处理

**不适用场景**：
- 数据已切分且无需重新处理
- 纯时间序列数据（无空间维度）

## 输入

- 切分配置（{SPLIT_CONFIG}）：train/val/test比例、随机种子、分组依据
- 目标变量（{TARGET_FIELDS}）：待预测物理量列表
- 是否无量纲化（{NONDIMENSIONALIZE}）：统一跨工况量纲

## 输出

- train_manifest.json / validation_manifest.json / test_manifest.json：各切分清单
- normalization.json：归一化统计量（均值、标准差、极值等）

## 流程节点

### Step 1：质控与重采样
- **操作**：基于data_contract.json进行质控，必要时重采样
- **参数**：重采样目标分辨率需保持物理一致性
- **质量门禁**：质控后数据完整性>95%

### Step 2：图构建（GNN专用）
- **操作**：将流场网格转换为图结构（节点=网格点/单元，边=邻接关系）
- **参数**：k-最近邻或Delaunay三角化；边特征可包含距离、角度
- **质量门禁**：图连通性良好，每个节点至少有1条边

### Step 3：掩膜与归一化
- **操作**：应用边界掩膜，计算并保存归一化统计量
- **参数**：仅用训练集计算统计量；保存逆变换参数
- **质量门禁**：仅用训练集计算变换统计量

### Step 4：无量纲化（可选）
- **操作**：将物理量转换为无量纲形式（如Re、Ma等无量纲参数）
- **参数**：参考量（特征长度、特征速度、特征密度等）需明确定义
- **质量门禁**：无量纲化可逆，逆变换参数已保存

### Step 5：无泄漏切分
- **操作**：按几何、完整轨迹或物理工况为单位切分
- **参数**：默认train=0.7, val=0.15, test=0.15, seed=42, group_by=geometry_or_trajectory
- **质量门禁**：三份切分的对象轨迹互斥

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认切分比例 | 0.7/0.15/0.15 | 场景需求书 | train/val/test |
| 随机种子 | 42 | 场景需求书 | 可复现性 |
| 分组依据 | geometry_or_trajectory | 场景需求书 | 按几何或轨迹切分，防止泄漏 |
| 归一化方式 | z-score / min-max | 通用标准 | 保存逆变换参数 |
| 图构建方法 | k-NN / Delaunay | 通用标准 | 取决于网格类型 |

## 边界与分流

- 不得把同一轨迹的帧随机打散（会引入时间泄漏）
- 归一化统计量必须仅从训练集计算（验证/测试集不得参与）
- 边界与掩膜语义不得因预处理而破坏

## 质量检查

- 三份切分的对象/轨迹互斥验证
- 归一化后物理量范围合理（如速度<10倍声速等）
- 图构建后连通性检查

## 回退策略

- 切分泄漏：重新按轨迹/几何分组切分
- 归一化异常：检查极端值，考虑clip或robust归一化
- 图构建失败：检查网格拓扑，必要时降级为点云处理
