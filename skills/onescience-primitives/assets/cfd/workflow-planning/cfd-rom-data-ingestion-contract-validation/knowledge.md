# 数据接入与契约核验

## 适用范围

本卡描述可迁移ROM工作流第一步：接入跨几何参数CFD与稀疏监测数据，核验数据完整性并建立机器可读契约。适用于任何需要从原始CFD数据启动ROM构建的任务。

## 输入

| 输入 | 类型 | 必填 | 说明 |
|------|------|------|------|
| {DATASET_PATH} | doc | 是 | 数据集目录或清单文件路径 |
| {DATASET_NAME} | str | 是 | 数据集来源与版本标识 |
| {DATA_CONTRACT} | object | 否 | 预定义的变量、单位、坐标系定义（可选） |

## 输出

| 输出 | 说明 |
|------|------|
| dataset_manifest.json | 数据集完整清单（文件列表、样本数、变量清单） |
| data_contract.json | 机器可读数据契约（变量、单位、坐标系、网格拓扑） |
| data_audit.md | 数据审计报告（缺失值、异常、许可信息） |

## 流程节点

1. **文件可读性检查**：验证{DATASET_PATH}下所有数据文件可读
2. **样本追溯性确认**：建立样本ID与文件的映射关系
3. **变量清单提取**：识别输入变量与目标变量
4. **单位与坐标系核验**：确认物理量单位、坐标系定义完整
5. **网格拓扑检查**：确认网格类型、维度、拓扑信息
6. **时间/工况范围确认**：提取仿真时间范围或工况参数范围
7. **缺失值扫描**：统计缺失值分布
8. **使用许可记录**：记录数据使用许可或限制条件
9. **契约输出**：按{DATA_CONTRACT}格式输出data_contract.json

## 关键参数

### 通用判据

| 参数 | 判据 | 来源 | 说明 |
|------|------|------|------|
| 文件可读性 | 所有数据文件可正常读取 | s01质量门禁 | 首要检查项 |
| 样本可追溯 | 每个样本有唯一ID且可追溯到源文件 | s01质量门禁 | 数据完整性基础 |
| 变量定义完整 | 输入与目标变量均明确定义 | s01质量门禁 | 后续步骤依赖 |
| 单位定义完整 | 所有变量有明确物理单位 | s01质量门禁 | 无量纲化与物理恢复依赖 |
| 坐标系定义 | 坐标系类型与方向明确 | s01质量门禁 | 空间数据一致性 |
| 无训练测试泄漏 | 训练集与测试集无重叠样本 | s01质量门禁 | 模型评估有效性前提 |

### 校准数值

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认数据集名称 | 跨几何参数CFD与稀疏监测数据 | 场景需求书s01 | 其他体系需以自身证据重新锚定 |
| 默认坐标系 | dataset_native | 场景需求书s01 | 使用数据集原始坐标系 |

## 边界与分流

- 数据文件不可读 → BLOCKED，列出不可读文件清单
- 缺少必填输入（{DATASET_PATH}或{DATASET_NAME}） → BLOCKED，列出缺项
- 变量或单位定义不完整 → 在data_audit.md中标注缺失项，尝试从文件元数据推断
- 存在训练测试泄漏 → 在data_audit.md中标注，阻止后续步骤
- 使用许可受限 → 在data_audit.md中记录限制条件

## 质量检查

- 数据文件可读且样本可追溯（每样本有唯一ID）
- 输入目标变量单位坐标定义完整
- 不存在训练测试泄漏（样本ID无交集）
- data_contract.json可被标准JSON解析

## 回退策略

- 文件格式不兼容：尝试格式转换或联系数据提供方
- 单位缺失：从论文或数据说明文档推断，标注为"推断值"
- 坐标系不明：使用数据集原始坐标系，标注为"未验证"

## 资源召回建议

当任务需要从原始CFD数据启动ROM构建时召回本卡片。本卡片是工作流第一步，完成后进入s02预处理与数据切分。
