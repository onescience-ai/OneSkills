# PINN模型物理约束评估标准

## 适用范围

本卡片为PINN模型物理约束评估提供标准指标体系和门限值知识，涵盖连续性方程残差、动量方程残差、边界误差、守恒误差的计算方法和判定标准，以及硬约束PINN确保物理约束满足的技术方法。适用于评估物理约束神经网络模型的物理一致性。

**不适用场景**：
- 纯数据驱动模型的评估
- 无物理约束的回归模型评估
- 非流体力学领域的物理约束评估

## 输入

- **模型预测结果**：速度场、压力场、温度场等
- **物理方程**：Navier-Stokes方程、Euler方程等
- **边界条件**：Dirichlet、Neumann、Robin等边界条件

## 输出

- **物理约束评估报告**：各约束满足情况
- **残差分析结果**：PDE残差、边界残差分布
- **验收结论**：PASS/REJECT/BLOCKED

## 流程节点

```
残差计算 → 约束评估 → 门限判定 → 报告生成 → 验收结论
```

### 详细操作

#### 1. 残差计算

**操作**：
- 计算PDE残差（连续性方程、动量方程、能量方程）
- 计算边界残差（Dirichlet、Neumann、Robin边界条件）
- 计算守恒误差（质量守恒、动量守恒、能量守恒）

**判定标准**：
- 残差计算方法正确
- 残差值在合理范围内
- 残差分布合理

#### 2. 约束评估

**操作**：
- 评估连续性方程满足情况
- 评估动量方程满足情况
- 评估能量方程满足情况
- 评估边界条件满足情况

**判定标准**：
- 各约束满足情况明确
- 约束评估方法正确
- 评估结果可追溯

#### 3. 门限判定

**操作**：
- 根据预设门限判定各约束是否满足
- 计算约束满足率
- 识别未满足约束的原因

**判定标准**：
- 门限设置合理
- 判定结果准确
- 原因分析正确

#### 4. 报告生成

**操作**：
- 生成物理约束评估报告
- 包含各约束满足情况、残差分布、门限判定结果
- 提供改进建议

**判定标准**：
- 报告内容完整
- 报告格式规范
- 改进建议可行

#### 5. 验收结论

**操作**：
- 根据评估结果给出验收结论
- PASS：所有约束满足门限
- REJECT：关键约束未满足
- BLOCKED：评估无法完成

**判定标准**：
- 验收结论明确
- 判定依据充分
- 结论可追溯

## 边界与分流

### 约束不满足时
- **连续性方程残差过大** → 检查质量守恒约束，调整损失权重
- **动量方程残差过大** → 检查动量守恒约束，调整网络架构
- **边界误差过大** → 检查边界条件实现，增加边界配点
- **守恒误差过大** → 检查全局守恒约束，调整约束权重

### 评估无法完成时
- **模型预测结果缺失** → 检查模型加载和推理过程
- **物理方程定义错误** → 验证PDE定义和自动微分实现
- **边界条件不明确** → 确认边界条件类型和参数

## 质量检查

### 验证点
1. **残差计算正确性**：残差计算方法正确，结果合理
2. **约束评估完整性**：所有相关约束均被评估
3. **门限设置合理性**：门限值基于领域知识和工程经验
4. **报告格式规范性**：报告内容完整，格式规范

### 阈值
- 残差计算正确率：100%
- 约束评估覆盖率：100%
- 门限设置合理率：>90%
- 报告格式规范率：100%

### 失败处理
- 残差计算错误 → 检查PDE定义和自动微分实现
- 约束评估不完整 → 补充遗漏的约束评估
- 门限设置不合理 → 调整门限值，重新评估

## 回退策略

### 物理约束评估失败时
1. 检查模型预测结果质量
2. 验证物理方程定义正确性
3. 确认边界条件实现
4. 调整评估参数和门限

### 验收结论不确定时
1. 重新分析约束满足情况
2. 检查评估指标计算
3. 咨询领域专家意见
4. 采用更保守的判定标准
