# 神经多重网格与预条件线性PDE求解

## 适用范围
面向大规模稀疏线性系统（如Poisson方程、扩散方程、弹性力学方程离散化所得），使用神经网络增强传统多重网格或预条件共轭梯度（PCG）方法，加速PDE数值求解。适用于以下场景：
- 偏微分方程离散化后产生的大规模稀疏线性系统
- 需要反复求解相关线性系统的参数化PDE问题
- 对求解速度有高要求的实时仿真、优化设计、不确定性量化
- 传统多重网格方法收敛慢或预条件器设计困难的非椭圆/不定系统

**不适用场景**：
- 非线性PDE直接求解（需先线性化或嵌入非线性求解器）
- 稠密线性系统
- 无法提供训练数据或系数分布信息的完全未知问题

## 输入
- **PDE系数矩阵**：稀疏矩阵A（来自PDE离散化，如有限差分、有限元）
- **右端向量**：b（源项或边界条件贡献）
- **网格信息**：结构化/非结构化网格拓扑、节点坐标
- **边界条件类型**：Dirichlet、Neumann或混合边界条件
- **训练数据**：系数分布样本、对应解向量（用于离线训练）

## 输出
- **PDE数值解**：x（满足精度要求的近似解）
- **收敛历史**：残差范数序列、迭代次数
- **加速比**：相对于经典方法（如AMG、ILU）的加速比
- **条件数改善**：预条件后系统条件数
- **物理守恒量**：质量/能量/动量守恒误差

## 流程节点
```
数据接入与契约核验 → 预处理与数据切分 → 模型配置与训练 → 神经数值耦合求解 → 任务验收与适用域判定
```

### 1. 数据接入与契约核验
- **操作**：读取PDE系数矩阵、右端向量、网格信息，核验数据完整性
- **参数**：数据集路径、变量定义、单位、坐标系
- **工具**：文件I/O、JSON解析
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏

### 2. 预处理与数据切分
- **操作**：统一物理量表示，按几何、工况或时间构造无泄漏切分
- **参数**：切分比例（train/val/test）、随机种子、分组策略
- **工具**：数据切分脚本、归一化工具
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏

### 3. 模型配置与训练
- **操作**：选择神经多重网格或学习预条件器架构，配置训练参数，执行离线训练
- **参数**：模型类型、学习率、批大小、早停耐心、随机种子
- **工具**：PyTorch/TensorFlow、自定义训练循环
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现

### 4. 神经数值耦合求解
- **操作**：将训练好的神经模块嵌入数值求解器（如PCG），执行端到端迭代求解
- **参数**：模型权重、计算设备、推理批大小、收敛容差
- **工具**：数值求解器（OpenFOAM等）、神经网络推理
- **质量门禁**：耦合接口变量单位一致；残差达到数值收敛门限；相对原求解器误差和加速比均报告

### 5. 任务验收与适用域判定
- **操作**：评估统计误差、关键物理约束、泛化能力和计算收益
- **参数**：验收指标、相对误差门限、是否外推测试
- **工具**：评估脚本、可视化工具
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议

## 边界与分流
- **前提1：线性系统对称正定** → 若不满足（如不定系统、非对称系统），转向广义最小残差（GMRES）或其他Krylov方法
- **前提2：稀疏矩阵结构已知** → 若矩阵结构未知或动态变化，转向矩阵无关（matrix-free）方法或在线学习预条件器
- **前提3：可提供训练数据** → 若无训练数据，转向传统预条件器（AMG、ILU）或元学习/少样本学习方法
- **前提4：求解精度要求明确** → 若精度要求极高且计算资源充足，可考虑直接求解器或混合方法

## 质量检查
- **收敛验证**：残差范数应单调递减（或在容差内波动），最终残差应小于指定容差
- **物理一致性**：解应满足质量/能量守恒（视PDE类型），边界条件应精确满足
- **泛化测试**：在未见过的几何、系数分布、边界条件下测试，报告最差样本性能
- **数值稳定性**：避免除零、溢出，检查条件数是否在合理范围

## 回退策略
- **训练失败**：降低学习率、增加训练数据、简化网络结构
- **收敛失败**：增加迭代次数、调整预条件器参数、切换到更鲁棒的Krylov方法
- **泛化失败**：扩大训练数据覆盖范围、使用域适应技术、增加正则化
- **计算资源不足**：使用混合精度、模型压缩、分布式计算
