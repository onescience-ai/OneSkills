# 边界嵌入神经算子任务验收与适用域判定

## 适用范围

本卡片描述边界嵌入神经算子任务验收与适用域判定任务，适用于：
- 评估统计误差、关键物理约束、泛化能力和计算收益
- 给出PASS、REJECT或BLOCKED结论
- 执行几何或工况外推测试并明确适用域

**不适用场景**：
- 不需要验收的快速原型验证
- 不需要适用域判定的内部测试

## 输入

1. **验收指标** `{METRICS}`：统计和物理指标
2. **相对误差门限** `{MAX_RELATIVE_L2}`：测试集放行阈值
3. **是否外推测试** `{RUN_OOD_TEST}`：测试域外工况

## 输出

1. `evaluation.json`：评估结果
2. `worst_cases.csv`：最差案例
3. `applicability_report.md`：适用域报告
4. `PASS_REJECT_BLOCKED.txt`：验收结论

## 流程节点

### Step 1：统计误差评估
- **操作**：计算逐变量误差、RMSE、相对L2误差
- **工具**：误差计算工具
- **质量门禁**：统计误差计算正确

### Step 2：物理约束评估
- **操作**：计算边界误差、守恒或方程残差
- **工具**：物理残差计算工具
- **质量门禁**：物理约束评估正确

### Step 3：最差案例分析
- **操作**：识别和分析最差样本
- **工具**：数据分析工具
- **质量门禁**：最差样本可追溯

### Step 4：外推测试
- **操作**：执行几何或工况外推测试
- **工具**：外推测试工具
- **质量门禁**：外推测试执行正确

### Step 5：适用域判定
- **操作**：根据评估结果判定适用域
- **工具**：判定逻辑
- **质量门禁**：结论含适用域限制与复核建议

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 统计与物理指标同时报告 | 必须 | [场景需求书s05] | 不能只报告统计误差 |
| 最差样本可追溯 | 必须 | [场景需求书s05] | 最差案例必须可追溯 |
| 结论含适用域限制 | 必须 | [场景需求书s05] | 必须明确适用域限制 |
| 复核建议 | 必须 | [场景需求书s05] | 必须提供复核建议 |

### 校准数值

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| MAX_RELATIVE_L2 | 0.1 | 场景需求书 | 默认相对误差门限 |
| METRICS | ["relative_L2", "RMSE", "conservation_residual", "boundary_error"] | 场景需求书 | 默认验收指标 |
| RUN_OOD_TEST | true | 场景需求书 | 默认执行外推测试 |

以下数值来自CFD_S064场景，供量级校准；其他体系需以自身证据重新锚定。

## 边界与分流

1. **统计误差超标** → 分析原因，调整模型或数据
2. **物理约束不满足** → 检查边界嵌入机制
3. **外推测试失败** → 明确标注适用域限制
4. **结论不确定** → 建议CFD复核

## 质量检查

1. **评估全面性**：统计与物理指标同时报告
2. **可追溯性**：最差样本可追溯
3. **结论完整性**：结论含适用域限制与复核建议
4. **外推测试**：外推测试执行正确

## 回退策略

1. **评估不通过** → 重新审查数据质量、模型架构或超参数配置
2. **适用域不确定** → 建议CFD复核
3. **外推测试失败** → 明确标注适用域限制
