# CFD领域公开数据集与案例库权威来源指南

## 适用范围

**触发条件**：
- 需要获取CFD仿真案例数据用于开发或验证
- 需要公开的CFD数据集进行模型训练或基准测试
- 需要权威的CFD案例库作为参考

**适用场景**：
- CFD工作流开发与测试
- 机器学习模型训练数据获取
- 仿真结果验证与对比
- 教学与培训材料准备

**不适用场景**：
- 需要私有或专有CFD数据的场景
- 需要实时CFD数据流的场景
- 非公开的商业CFD案例库

## 输入

**输入数据格式**：
- 数据需求描述（几何类型、流动类型、物理模型等）
- 数据格式要求（OpenFOAM、FEM、通用格式等）
- 数据量需求（案例数量、网格规模等）

**来源**：
- 用户需求
- 项目规格说明
- 领域标准

**预处理要求**：
- 明确数据类型和格式需求
- 确定数据质量标准

## 输出

**输出产物**：
- 权威数据源URL列表
- 数据获取指南
- 数据格式说明
- 使用示例

**格式**：
- 结构化列表（JSON、Markdown）
- 数据访问链接
- 使用说明文档

**验证标准**：
- URL可访问性
- 数据格式兼容性
- 数据质量符合要求

## 流程节点

### Step 1：需求分析
- **操作**：分析用户对CFD数据的具体需求
- **参数**：数据类型=案例/数据集/基准测试、几何类型=2D/3D、物理模型=流体/传热/多相流
- **工具**：需求分析器、分类器
- **质量门禁**：需求理解准确率 ≥ 90%

### Step 2：来源识别
- **操作**：识别符合需求的权威数据源
- **参数**：来源类型=官方仓库/学术平台/标准库、权威性等级=官方/学术/社区
- **工具**：来源数据库、权威性评估器
- **质量门禁**：来源权威性评分 ≥ 8/10

### Step 3：数据获取
- **操作**：从权威来源获取数据或访问链接
- **参数**：获取方式=直接下载/API访问/克隆仓库
- **工具**：下载工具、API客户端、Git客户端
- **质量门禁**：数据获取成功率 ≥ 95%

### Step 4：数据验证
- **操作**：验证获取的数据质量和完整性
- **参数**：验证项目=格式正确性、完整性、一致性
- **工具**：格式检查器、完整性验证器
- **质量门禁**：数据验证通过率 ≥ 90%

### Step 5：文档生成
- **操作**：生成数据使用文档和示例
- **参数**：文档格式=Markdown、示例类型=代码示例、配置示例
- **工具**：文档生成器、示例创建器
- **质量门禁**：文档完整性 ≥ 85%

## 边界与分流

**前提1：数据源可公开访问**
- 不成立时：寻找替代数据源或使用合成数据

**前提2：数据格式兼容**
- 不成立时：进行格式转换或寻找兼容格式的数据

**前提3：数据质量符合要求**
- 不成立时：进行数据清洗或寻找更高质量的数据源

## 质量检查

**验证点**：
1. 数据源权威性验证
2. 数据格式兼容性检查
3. 数据完整性验证
4. 数据质量评估

**阈值**：
- 权威性评分：≥ 8/10
- 格式兼容性：100%
- 完整性：≥ 95%
- 质量评分：≥ 7/10

**失败处理**：
- 权威性不足：寻找替代来源
- 格式不兼容：进行格式转换
- 完整性不足：补充缺失数据
- 质量不足：进行数据清洗

## 回退策略

**策略1：使用社区数据源**
- 当官方数据源不可用时，使用高质量的社区数据源

**策略2：生成合成数据**
- 当真实数据不可获取时，使用物理模型生成合成数据

**策略3：请求用户提供数据**
- 当自动获取失败时，请求用户直接提供数据
