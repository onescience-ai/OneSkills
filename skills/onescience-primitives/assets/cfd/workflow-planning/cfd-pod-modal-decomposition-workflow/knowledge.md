# POD与模态分解流动降阶建模工作流

## 适用范围

**触发条件**：
- 需要从CFD快照数据系统化构建降阶模型
- 需要完整的数据处理、模型训练和验证流程
- 需要评估降阶模型的工程适用性

**适用场景**：
- 参数化CFD流场降阶建模项目
- 需要可复现、可追踪的建模流程
- 工程应用中的快速流场预测系统开发

**不适用场景**：
- 快速原型验证（可简化流程）
- 非参数化流场的单次分析
- 纯理论模态分析（无需完整建模流程）

## 输入

**前置条件**：
- CFD快照数据文件（时间/参数序列）
- 参数标签文件
- 数据契约定义（可选）

**输入格式**：
- 快照矩阵：numpy数组或类似结构
- 参数标签：CSV或JSON格式
- 数据契约：JSON格式定义变量、单位、坐标

## 输出

**工作流产物**：
1. 数据清单（dataset_manifest.json）
2. 数据契约（data_contract.json）
3. 数据审计报告（data_audit.md）
4. 训练/验证/测试集清单
5. 归一化统计量（normalization.json）
6. 训练后的模型权重
7. 训练配置和指标
8. 测试集预测结果
9. 评估报告和适用域判定

**质量标准**：
- 所有中间产物可追溯
- 模型可复现（代码、依赖、随机种子）
- 物理一致性验证通过

## 流程节点

### Step 1：数据接入与契约核验
- **操作**：读取数据集，建立数据清单，验证数据质量
- **输入**：数据集路径、数据集名称、数据契约
- **输出**：dataset_manifest.json, data_contract.json, data_audit.md
- **质量门禁**：
  - 数据文件可读且样本可追溯
  - 输入目标变量单位坐标定义完整
  - 不存在训练测试泄漏
- **工具**：数据读取库、契约验证脚本

### Step 2：预处理与数据切分
- **操作**：统一物理量表示，按几何/工况/时间进行无泄漏切分
- **输入**：切分配置、目标变量、无量纲化选项
- **输出**：train/validation/test清单、归一化统计量
- **质量门禁**：
  - 三份切分的对象轨迹互斥
  - 仅用训练集计算变换统计量
  - 边界与掩膜语义未破坏
- **依赖**：Step 1

### Step 3：模型配置与训练
- **操作**：配置POD/DMD模型，执行训练，记录过程
- **输入**：模型名称、训练配置、初始权重（可选）
- **输出**：best_checkpoint.pt, train_config.json, training_metrics.csv, environment.txt
- **质量门禁**：
  - 训练验证损失均为有限值
  - 最佳权重可重新加载
  - 配置环境随机种子可复现
- **依赖**：Step 2

### Step 4：批量推理与物理恢复
- **操作**：在测试集上推理，恢复物理单位和网格
- **输入**：模型权重、计算设备、推理批大小
- **输出**：predictions/, inference_manifest.json, timing.csv
- **质量门禁**：
  - 预测无NaN或Inf且形状单位正确
  - 每个测试样本有唯一结果
  - 推理未使用测试目标校正
- **依赖**：Step 3

### Step 5：任务验收与适用域判定
- **操作**：评估统计误差、物理约束、泛化能力
- **输入**：验收指标、相对误差门限、外推测试选项
- **输出**：evaluation.json, worst_cases.csv, applicability_report.md, PASS_REJECT_BLOCKED.txt
- **质量门禁**：
  - 统计与物理指标同时报告
  - 最差样本可追溯
  - 结论含适用域限制与复核建议
- **依赖**：Step 4

## 边界与分流

**关键前提不成立时的改道方案**：

1. **数据质量不足**：若快照矩阵存在严重缺失或不一致，返回数据清洗或重新采集流程
2. **切分无法保证互斥**：若几何/轨迹/工况无法清晰划分，需重新设计切分策略或简化问题
3. **模型训练不收敛**：调整模态数量、正则化参数或改用其他降阶方法
4. **物理约束严重违反**：添加物理约束到模型或使用后处理校正
5. **适用域外工况**：标记为"需CFD复核"，限制应用场景

## 质量检查

**验证点**：
- 数据完整性（样本数、变量完整性）
- 切分合理性（互斥性、分布一致性）
- 训练收敛性（损失曲线、早停机制）
- 预测合理性（场分布、统计特性）
- 物理一致性（守恒律、边界条件）
- 计算效率（加速比、内存占用）

**阈值**：
- 相对L2误差 ≤ 0.1
- 守恒残差 < 1e-6（量纲相关）
- 边界误差 < 1%

**失败处理**：
- 误差超标：调整模型参数或增加训练数据
- 物理违反：添加物理约束或后处理校正
- 计算超时：优化算法或降级到简化模型

## 回退策略

**失败时的替代方案**：
1. **完整流程失败**：回退到简化版本（如仅POD，无DMD）
2. **模型训练失败**：回退到线性POD或模态分析
3. **预测精度不足**：回退到传统CFD计算
4. **适用域判定不确定**：标记为"需CFD复核"
