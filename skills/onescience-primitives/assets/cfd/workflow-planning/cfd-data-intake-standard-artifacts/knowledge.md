# CFD数据接入步骤标准产物规格

## 适用范围
适用于CFD工作流的数据接入步骤（s01），当执行数据核验和契约定义时，需要生成三个标准产物：dataset_manifest.json、data_contract.json和data_audit.md。该知识帮助确保数据接入步骤产出完整、格式正确的标准产物。

## 输入
- 原始数据集（如CFD仿真数据）
- 数据接入配置
- 数据质量要求

## 输出
- dataset_manifest.json（数据集清单）
- data_contract.json（数据契约）
- data_audit.md（数据审计报告）

## 流程节点
1. 数据发现 → 2. 生成dataset_manifest.json → 3. 生成data_contract.json → 4. 生成data_audit.md → 5. 验证产物完整性

### 步骤1：数据发现
- 操作：扫描原始数据集，识别数据文件、格式和结构
- 参数：数据集路径、文件模式
- 工具：数据发现脚本
- 质量门禁：成功识别所有数据文件

### 步骤2：生成dataset_manifest.json
- 操作：创建数据集清单文件，记录数据集元信息
- 参数：数据集路径、样本数量、变量列表、数据格式
- 工具：清单生成脚本
- 质量门禁：文件生成成功，包含必要字段

### 步骤3：生成data_contract.json
- 操作：创建数据契约文件，定义输入输出字段、单位和坐标系
- 参数：变量定义、单位系统、坐标系、数据类型
- 工具：契约生成脚本
- 质量门禁：文件生成成功，字段定义完整

#### data_contract.json标准格式（CFD_S087补充）
- **input_fields**：输入字段定义（字段名、物理含义、单位、维度）
- **target_fields**：目标字段定义（同上）
- **units**：物理量单位映射
- **coordinates**：网格坐标系定义（如cartesian/cylindrical、dx/dy值）
- **验证要求**：data_contract.json需包含所有输入/输出变量定义，确保下游标准化和归一化正确执行

### 步骤4：生成data_audit.md
- 操作：创建数据审计报告，记录数据质量检查结果
- 参数：数据完整性检查、缺失值统计、异常值检测
- 工具：审计生成脚本
- 质量门禁：报告生成成功，包含质量检查结果

### 步骤5：验证产物完整性
- 操作：检查三个标准产物是否存在且格式正确
- 参数：文件路径、格式要求
- 工具：验证脚本
- 质量门禁：所有产物存在且可解析

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 产物1 | dataset_manifest.json | 归因报告 | 数据集清单文件 |
| 产物2 | data_contract.json | 归因报告 | 数据契约文件 |
| 产物3 | data_audit.md | 归因报告 | 数据审计报告 |
| 生成步骤 | s01数据接入 | 归因报告 | 工作流步骤编号 |

### 校准数值
以下数值来自CFD_S049任务，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 缺失后果 | 后续步骤无法基于正确的数据契约进行 | 归因报告 | 产物缺失的影响 |

## 边界与分流
- 如果dataset_manifest.json缺失，数据切分步骤（s02）无法确定数据源
- 如果data_contract.json缺失，训练步骤（s03）无法确定输入输出格式
- 如果data_audit.md缺失，无法评估数据质量是否满足要求
- 任何产物缺失都应导致数据接入步骤失败，不继续后续步骤

## 质量检查
- 验证dataset_manifest.json包含数据集路径、样本数量、变量列表
- 验证data_contract.json包含输入输出字段、单位和坐标系
- 验证data_audit.md包含数据质量检查结果
- 验证所有JSON文件可被标准JSON解析器解析

## 回退策略
- 如果无法生成完整产物，应记录缺失的产物并终止数据接入步骤
- 如果产物格式不正确，应尝试重新生成或使用备用格式
