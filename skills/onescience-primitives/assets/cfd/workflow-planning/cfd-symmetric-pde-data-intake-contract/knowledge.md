# 对称PDE数据接入与契约核验

## 适用范围

本卡片服务于具有群对称性的PDE数据集接入阶段。当用户提供了PDE模拟或实验数据，需要建立数据清单、验证数据完整性、确认变量定义与单位一致性时使用。适用于旋转/平移/洛伦兹等连续对称群的PDE数据。不适用于：纯文本或非结构化数据；无网格坐标的散点数据（需额外点云处理）；数据量极小（<10样本）无法支撑后续训练的场景。

## 输入

- 数据集路径（{DATASET_PATH}）：目录或清单文件
- 数据集名称（{DATASET_NAME}）：来源与数据版本标识
- 数据契约（{DATA_CONTRACT}）：可选，变量单位网格定义

## 输出

- dataset_manifest.json：数据清单（文件列表、样本数、变量清单）
- data_contract.json：机器可读数据契约（变量、单位、坐标系、网格拓扑）
- data_audit.md：审计报告（缺失值、异常值、使用许可）

## 流程节点

1. **文件可读性检查** → 确认所有数据文件可被程序读取
2. **样本可追溯性确认** → 每个样本可追溯到来源文件和索引
3. **变量与单位核查** → 输入/目标变量名称、物理量纲、单位一致性
4. **坐标系与网格拓扑确认** → 网格类型（结构化/非结构化）、坐标系（笛卡尔/极坐标/曲线坐标）
5. **时间或工况范围检查** → 时间步长、工况参数范围完整性
6. **缺失值与异常值审计** → 统计缺失比例、识别明显异常
7. **使用许可记录** → 数据许可和使用限制
8. **输出契约生成** → 生成data_contract.json和data_audit.md

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必须检查项 | 文件可读性、样本可追溯、变量单位完整、坐标定义完整 | 场景JSON s01 quality_gate | 缺任一项则BLOCKED |
| 泄漏检测 | 训练测试无泄漏 | 场景JSON s01 quality_gate | 强制门禁 |
| 缺失值处理 | 统计并记录，不自动填充 | 场景JSON s01 prompt | 需人工决策 |

### 校准数值（来自CFD_S063场景，供量级校准）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认坐标系 | dataset_native | 场景JSON s01 default | 保留原始坐标 |
| 默认输入/目标字段 | 空列表 | 场景JSON s01 default | 需用户指定 |

## 边界与分流

- **缺少必填输入（路径/名称）**：返回BLOCKED并列出缺项，不得编造数据
- **数据文件不可读**：报告具体文件路径和错误，BLOCKED
- **变量单位不一致**：在data_audit.md中标注冲突，建议统一方案，但不自动修改数据
- **网格拓扑不明**：标记为"待确认"，在后续预处理步骤中解决

## 质量检查

- 数据文件可读且样本可追溯（质量门禁）
- 输入目标变量单位坐标定义完整（质量门禁）
- 不存在训练测试泄漏（质量门禁）
- data_contract.json为合法JSON且包含所有必要字段

## 回退策略

- 数据格式不支持：报告格式要求，建议转换工具
- 数据量不足：报告样本数，建议数据增强或迁移学习方案
