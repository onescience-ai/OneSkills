# Data Intake and Contract Validation

## 适用范围

面向多物理多分辨率预训练数据接入阶段，核验数据完整性与一致性，建立机器可读数据契约。适用于所有需要进行多物理算子迁移的科学基础模型场景。

## 输入

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| DATASET_PATH | doc | 是 | 数据集目录或清单文件路径 |
| DATASET_NAME | str | 是 | 数据集名称与版本 |
| DATA_CONTRACT | object | 否 | 预定义数据契约模板（变量、单位、坐标定义） |

## 输出

| 产物 | 格式 | 说明 |
|------|------|------|
| dataset_manifest.json | JSON | 数据清单：文件列表、样本数、变量信息 |
| data_contract.json | JSON | 机器可读数据契约 |
| data_audit.md | Markdown | 数据审计报告 |

## 流程节点

1. **读取数据集** → 加载 DATASET_PATH 中的 DATASET_NAME
2. **检查文件可读性** → 验证文件存在、格式正确、可解析
3. **统计样本数** → 确认样本总量、输入目标变量数量
4. **核验变量定义** → 检查输入/目标变量名称、类型、维度
5. **核验单位坐标** → 确认物理量单位、坐标系定义、网格拓扑
6. **检查工况范围** → 时间步、Reynolds数、Ma数等工况参数范围
7. **检查缺失值** → 统计 NaN/Inf 比例、缺失位置
8. **核验使用许可** → 确认数据许可、使用限制
9. **输出契约** → 按 DATA_CONTRACT 模板输出 JSON 契约

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必须检查项 | 文件可读性、样本数、变量定义、单位坐标 | 场景需求书 | 缺一不可 |
| 缺失值阈值 | 待确认 | — | 超阈值需标记或排除 |
| 许可要求 | 必须明确 | 场景需求书 | 无许可禁止使用 |

## 边界与分流

- **文件不可读**：返回 BLOCKED，列出缺项
- **变量定义不完整**：返回 BLOCKED，列出缺失变量
- **缺少必填输入**：返回 BLOCKED 并列出缺项，不得编造数据

## 质量检查

- [ ] 数据文件可读且样本可追溯
- [ ] 输入目标变量单位坐标定义完整
- [ ] 不存在训练测试泄漏

## 回退策略

- 数据集路径错误 → 重新指定路径
- 格式不支持 → 转换格式或联系数据提供方
