# 物理网络可压缩高速绕流求解与激波识别工作流

## 适用范围

**触发条件**：
- 需要对亚声速至超声速可压缩绕流进行物理一致的流场求解
- 需要在超声速流场中自动识别激波位置和强度
- 已有CFD模拟数据或可压缩绕流样本，需要构建机器学习代理模型

**适用场景**：
- 翼型/圆柱等几何体的可压缩绕流场预测（亚声速、跨声速、超声速）
- 超声速流场中激波位置的自动检测与分类
- 高保真CFD数据的快速代理模型构建
- 物理一致性要求高的工程气动设计

**不适用场景**：
- 不可压缩流（Ma < 0.3）问题
- 无激波结构的低速粘性流动
- 缺乏物理控制方程的纯数据驱动场景
- 超出训练工况域外的外推预测（需CFD复核）

## 输入

| 输入 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 数据集路径 | doc | 是 | 包含可压缩绕流模拟数据的目录或清单文件 |
| 数据集名称 | str | 是 | 数据来源与版本标识 |
| 数据契约 | object | 否 | 变量、单位、网格坐标定义；缺失时由步骤s01自动生成 |

数据要求：包含流场物理量（密度、速度分量、压力、温度等）、网格坐标、边界条件标识、工况参数（Ma、Re等）。

## 输出

| 输出 | 格式 | 说明 |
|------|------|------|
| 训练好的模型权重 | .pt / .pth | 最佳checkpoint |
| 推理结果 | predictions/ | 逐样本预测场、恢复物理单位后的结果 |
| 评估报告 | evaluation.json | 统计误差、物理约束、适用域判定 |
| 适用域报告 | applicability_report.md | 外推测试结果与复核建议 |

## 流程节点

### Step 1：数据接入与契约核验
- **操作**：接入亚声速至超声速可压缩绕流数据，核验样本、变量、单位、网格坐标及许可
- **参数**：数据契约（变量单位网格定义）
- **工具**：Python 数据校验脚本
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏
- **产出**：dataset_manifest.json, data_contract.json, data_audit.md

### Step 2：预处理与数据切分
- **操作**：统一物理量表示，按几何/工况/时间构造无泄漏切分
- **参数**：切分比例（默认70/15/15）、无量纲化开关
- **工具**：Python 数据处理
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏
- **产出**：train/validation/test manifest, normalization.json

### Step 3：模型配置与训练
- **操作**：训练Physics-informed neural network与Shock classifier
- **参数**：PyTorch框架、epoch数、batch size、学习率、早停耐心
- **工具**：PyTorch
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现
- **产出**：best_checkpoint.pt, train_config.json, training_metrics.csv

### Step 4：批量推理与物理恢复
- **操作**：在独立测试集推理，恢复原始单位、网格和物理派生量
- **参数**：计算设备、推理批大小
- **工具**：PyTorch
- **质量门禁**：预测无NaN/Inf且形状单位正确；每个测试样本有唯一结果；推理未使用测试目标校正
- **产出**：predictions/, inference_manifest.json, timing.csv

### Step 5：任务验收与适用域判定
- **操作**：评估统计误差、关键物理约束、泛化能力和计算收益
- **参数**：验收指标（相对L2、RMSE、守恒残差、边界误差）、相对误差门限、外推测试开关
- **工具**：评估脚本
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议
- **产出**：evaluation.json, worst_cases.csv, applicability_report.md, PASS/REJECT/BLOCKED判定

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 模型框架 | PyTorch | [1][2][3] | 主流深度学习框架 |
| 多阶段训练 | MS-PINN（多阶段迭代最小化残差） | [1] | 可逼近机器精度精度 |
| 坐标变换 | 将无穷域映射到有限域 | [1] | 解决无界域PINN收敛问题 |
| 物理渐近约束 | 嵌入网络架构 | [1] | 保证远场行为物理合理 |
| 激波传感器类型 | 无监督GMM（高斯混合模型） | [2] | 无需标注数据 |

| 验收误差门限 | 相对L2 ≤ 0.1 | [场景S005] | 默认放行阈值 |

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| MS-PINN精度 | 接近机器精度 | [1] | 圆/椭圆翼型亚声速绕流 |

## 边界与分流

| 前提 | 不成立时的改道方案 |
|------|---------------------|
| 数据包含完整物理量（密度、速度、压力） | 转向部分场预测（如仅预测压力/速度），需修改损失函数 |
| 流动存在激波结构 | 禁用Shock classifier模块，仅保留PINN流场求解 |
| 计算资源充足（GPU显存） | 降低网络规模或批大小，使用混合精度训练 |
| 物理控制方程已知 | 转向纯数据驱动方法（如ANN回归），丧失物理一致性保证 |
| 工况在训练域内 | 标记为域外样本，需CFD复核后方可使用 |

## 质量检查

1. **训练阶段**：训练/验证损失收敛且为有限值；最佳权重可重新加载
2. **推理阶段**：预测场无NaN/Inf；形状与输入网格一致；物理单位正确恢复
3. **物理一致性**：守恒残差在可接受范围内；边界条件误差满足阈值
4. **泛化验证**：外推测试（新几何/新工况）结果明确标注适用域边界
5. **最差样本分析**：worst_cases.csv包含最差样本追溯信息

## 回退策略

- PINN训练不收敛 → 尝试多阶段训练策略（MS-PINN），增加残差采样点
- 激波识别精度不足 → 切换到有监督训练或集成多种传感器方法
- 物理约束违反严重 → 增大损失函数中物理残差项权重
- 推理精度不达标 → 降低网络复杂度，增加训练数据
