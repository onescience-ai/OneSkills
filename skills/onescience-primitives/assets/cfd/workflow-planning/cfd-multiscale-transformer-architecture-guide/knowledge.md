# 多尺度Transformer架构实现指南

## 适用范围
面向汽车气动预测CFD任务，提供多尺度Transformer架构（DragSolver、PMRT、Triplane network）的网络结构设计、输入输出格式、训练策略和超参数选择指南。适用于需要训练高精度CFD代理模型的场景，不适用于使用简化MLP模型或CNN/GNN等其他架构的场景。

## 输入
- 三维汽车表面网格数据（顶点坐标、面片连接）
- 体流场数据（速度、压力等物理量）
- 数据格式（HDF5、NPZ、VTK等）

## 输出
- 训练好的多尺度Transformer模型（权重文件）
- 训练日志（损失曲线、评估指标）
- 推理结果（预测流场、气动力系数）

## 流程节点
1. **架构选择** → 根据任务需求选择DragSolver、PMRT或Triplane network
2. **网络结构定义** → 实现多尺度注意力机制、金字塔结构或三平面表示
3. **数据预处理** → 将原始CFD数据转换为模型输入格式（如体素化、投影到三个正交平面）
4. **训练策略配置** → 设置优化器、学习率、批次大小、训练轮数等超参数
5. **模型训练** → 执行训练流程，监控损失收敛情况
6. **模型评估** → 使用测试集评估模型性能（R²、相对误差等）

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| DragSolver | 多尺度注意力机制 | [用户自有] | 处理不同分辨率特征，捕捉多尺度流动结构 |
| PMRT | 金字塔多分辨率Transformer | [用户自有] | 逐步细化预测，从粗到细捕捉流场细节 |
| Triplane network | 三平面表示 | [用户自有] | 将3D数据投影到三个正交平面进行处理，降低计算复杂度 |
| 输入格式 | 三维体数据或表面网格 | [用户自有] | 需要统一为模型可接受的格式 |
| 输出格式 | 预测流场或气动力系数 | [用户自有] | 根据任务需求选择回归或分类目标 |

## 边界与分流
- 若任务时间不足，可考虑使用简化模型验证训练流程，但需记录架构差异对性能的影响。
- 若数据格式不匹配，需进行预处理转换（如体素化、网格对齐）。
- 若硬件资源有限，可调整模型大小或使用混合精度训练。

## 质量检查
- 验证模型架构是否与任务要求一致（多尺度Transformer vs 简化MLP）。
- 检查训练损失是否收敛，评估指标是否达到预期（R² > 0.8）。
- 确认模型在测试集上的泛化能力。

## 回退策略
- 若多尺度Transformer实现复杂度过高，可考虑使用简化模型作为基准，但需记录性能差距。
- 若训练时间过长，可调整超参数（如学习率、批次大小）或使用预训练模型。
