# 物理信息损失函数设计指南

## 适用范围

本卡片为CFD降阶模型中的物理信息损失函数设计提供实现方法，适用于INR/CROM等隐式神经场模型，以及物理信息神经网络（PINN）等需要集成物理约束的场景。物理信息损失项能够强制模型遵守基本物理定律，提高模型的物理一致性和泛化能力。

## 输入

### 物理方程信息
- 控制方程：Navier-Stokes方程、连续性方程
- 边界条件：Dirichlet、Neumann、周期性边界
- 初始条件：初始流场、初始压力场
- 物理参数：粘度、密度、雷诺数

### 训练数据信息
- 数据类型：连续坐标采样、规则网格
- 数据质量：噪声水平、采样密度
- 数据规模：样本数量、空间分辨率

### 模型输出信息
- 预测场：速度场、压力场、温度场
- 导数信息：空间导数、时间导数
- 中间特征：网络激活值、特征图

## 输出

### 损失函数组件
- 数据保真损失：MSE、MAE等
- PDE残差损失：控制方程残差
- 边界条件损失：边界约束满足度
- 守恒律损失：质量、动量、能量守恒

### 损失权重配置
- 权重选择策略：固定权重、自适应权重
- 权重调优方法：网格搜索、贝叶斯优化
- 权重平衡技巧：梯度归一化、损失缩放

## 流程节点

1. **物理方程解析** → 2. **自动微分计算** → 3. **损失项设计** → 4. **权重配置** → 5. **集成训练**

### 步骤1：物理方程解析
- 操作：解析控制方程和边界条件
- 参数：方程形式、边界类型
- 工具：符号计算库（SymPy）
- 质量门禁：方程解析正确

### 步骤2：自动微分计算
- 操作：计算模型输出的导数
- 参数：一阶导数、二阶导数
- 工具：PyTorch自动微分
- 质量门禁：导数计算准确

### 步骤3：损失项设计
- 操作：设计各个物理约束损失项
- 参数：损失形式、计算方法
- 工具：损失函数库
- 质量门禁：损失项物理意义明确

### 步骤4：权重配置
- 操作：配置各个损失项的权重
- 参数：权重值、调度策略
- 工具：超参数优化器
- 质量门禁：权重平衡合理

### 步骤5：集成训练
- 操作：将物理信息损失集成到训练流程
- 参数：损失计算、反向传播
- 工具：训练框架
- 质量门禁：训练过程稳定

## 关键参数

### 通用判据
| 参数 | 推荐范围 | 来源 | 说明 |
|------|----------|------|------|
| 数据损失权重 | 1.0 | [1][2] | 基准权重 |
| PDE残差权重 | 0.1-1.0 | [1] | 根据PDE复杂度调整 |
| 边界条件权重 | 1.0-10.0 | [1][2] | 边界约束通常需要较强惩罚 |
| 守恒律权重 | 0.01-1.0 | [1] | 根据守恒要求调整 |
| 损失权重调度 | 自适应/固定 | [1][2] | 根据训练阶段调整 |

### 校准数值
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 质量守恒损失 | ∇·u = 0 | [1][2] | 不可压缩流动 |
| 动量方程损失 | ρ(u·∇)u = -∇p + μ∇²u | [1][2] | Navier-Stokes方程 |
| 障碍物损失 | u|_B = 0 | [2] | 固体区域无流动 |
| 周期性损失 | u(x) = u(x+T) | [2] | 周期性边界条件 |
| 曲折度损失 | τ_u = τ_v | [2] | 宏观输运性质 |

## 边界与分流

### PDE残差计算失败时
- 自动微分精度不足 → 使用有限差分近似
- 计算图过于复杂 → 简化PDE形式
- 内存不足 → 使用随机采样点计算残差

### 边界条件处理困难时
- 边界类型复杂 → 分解为简单边界分别处理
- 边界数据不足 → 使用软约束而非硬约束
- 边界条件冲突 → 优先保证主要边界条件

### 守恒律违反严重时
- 质量不守恒 → 增加连续性方程权重
- 动量不守恒 → 增加Navier-Stokes方程权重
- 能量不守恒 → 增加能量方程权重

### 损失权重不平衡时
- 某个损失项主导训练 → 降低其权重或使用梯度归一化
- 某个损失项被忽略 → 增加其权重或使用课程学习
- 训练不稳定 → 使用更小的学习率或梯度裁剪

## 质量检查

### 验证点
1. PDE残差计算准确性
2. 边界条件满足度
3. 守恒律遵守程度
4. 损失权重平衡性

### 阈值
- 质量守恒残差：<0.01（参考值）
- 边界误差：<0.05（参考值）
- 动量方程残差：<0.1（参考值）
- 损失权重比：<10（避免极端不平衡）

### 失败处理
- PDE残差过大 → 检查自动微分和方程实现
- 边界误差过大 → 检查边界条件实现
- 守恒律违反 → 检查物理参数和约束实现

## 回退策略

### 物理信息损失实施困难时
1. 使用纯数据驱动训练作为基准
2. 逐步增加物理约束强度
3. 使用迁移学习从简单任务开始
4. 考虑使用预训练模型

### 训练过程不稳定时
1. 降低学习率
2. 增加梯度裁剪
3. 使用更简单的网络架构
4. 减少物理约束强度
