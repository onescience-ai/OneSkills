# OOD泛化与适用域判定

## 适用范围
本卡片提供空气动力学机器学习模型的域外（Out-of-Distribution, OOD）泛化评估与适用域边界划定方法。适用于任何基于数据驱动的CFD预测模型在部署前的泛化能力验证，确保模型在训练域外工况（新几何形状、新雷诺数范围、新攻角等）的预测可靠性。核心原则：不凭平均误差宣称工程可用，必须通过OOD测试明确适用域边界，域外工况需经CFD复核。

## 输入
- **训练域定义**：训练集覆盖的几何形状范围、工况参数范围
- **测试集**：含域内测试集与域外测试集（OOD）
- **模型预测**：逐样本预测值与真实值
- **评估指标**：relative_L2、RMSE、守恒残差、边界误差等

## 输出
- OOD测试结果（误差指标、逐样本对比）
- 适用域报告（applicability_report.md）：明确几何/工况边界
- PASS/REJECT/BLOCKED验收结论
- worst_cases.csv：最差样本追溯

## 流程节点
### 1. 域定义与OOD测试集构建
- 明确训练域的几何形状范围（如DrivAerNet标准车型）
- 明确训练域的工况参数范围（如标准雷诺数、零攻角）
- 构建OOD测试集：新几何形状（如非常规车身）或新工况（如高雷诺数、大攻角）

### 2. 多维度误差评估
- **统计误差**：relative_L2、RMSE（域内+域外分别计算）
- **物理一致性**：守恒残差（质量/动量守恒偏差）、边界误差（壁面附近预测偏差）
- **最差样本分析**：worst_cases.csv追溯最大误差样本

### 3. 适用域边界划定
- 几何边界：模型在哪些形状范围内可靠
- 工况边界：模型在哪些参数范围内可靠
- 失效模式：典型失效场景描述

### 4. 验收判定
- PASS：域内+域外误差均在阈值内，物理一致性满足
- REJECT：域内误差超限或域外显著失效
- BLOCKED：数据或模型问题导致无法评估

## 边界与分流
- 域内误差超限 → REJECT，需调整模型或扩大训练域
- 域外误差显著大于域内 → REJECT，标明适用域边界，建议CFD复核
- 物理一致性不满足（守恒残差大） → REJECT，模型物理可信度不足
- 无法构建OOD测试集 → BLOCKED，无法评估泛化能力
- 域内外误差均满足且物理一致 → PASS，可在适用域内部署

## 质量检查
1. 域内+域外误差分别报告，不混为一谈
2. 物理指标（守恒、边界）与统计指标同时报告
3. worst_cases.csv可追溯最大误差样本的几何/工况信息
4. 适用域报告明确列出几何/工况边界与失效模式
5. 验收结论含复核建议

## 回退策略
- OOD测试集不足 → 增加人工构造的OOD样本（如扰动几何）
- 物理指标难以计算 → 降级为纯统计误差评估，但需注明
- 模型全面失效 → 建议更换模型架构或增加训练数据多样性
