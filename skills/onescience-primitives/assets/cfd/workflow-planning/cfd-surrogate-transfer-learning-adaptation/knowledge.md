# 气动代理迁移学习适应策略

## 适用范围

**触发条件**：
- 源几何族上已训练的代理模型需要迁移到拓扑结构不同的新几何族
- 目标域高保真数据稀缺（通常 < 50 个工况）
- 需要选择最优适应策略并评估迁移效果

**适用场景**：
- 汽车跨车型系列气动代理迁移（如从轿车迁移到 SUV）
- 航空跨翼型族/机身构型迁移
- 工况域外迁移（新雷诺数、攻角范围）
- 多保真数据融合中的潜空间对齐

**不适用场景**：
- 单一几何族内的工况内插（无拓扑变化）
- 目标域数据充足（> 200 工况）时直接重新训练更高效
- 模型结构完全不兼容（需从头设计新架构）

## 输入

- **源域预训练 checkpoint**：在源几何族上训练好的代理权重
- **目标域数据**：少量高保真工况（20–50 个）
- **可选低保真数据**：大量廉价 RANS 或低精度仿真数据
- **模型结构描述**：编码器-解码器架构、参数量、层定义

## 输出

- **最优适应策略**：LoRA / FFT / LFT / 自编码器微调 的推荐选择
- **逐策略误差对比**：R²、RMSE、相对 L₂ 误差
- **收敛性分析**：训练曲线、过拟合检测
- **迁移质量报告**：源域保留度 vs 目标域精度的权衡

## 流程节点

### Step 1：源域模型分析
- **操作**：分析预训练模型的编码器架构、参数量、几何表示能力，评估其对新几何族的潜在迁移性
- **参数**：预训练 checkpoint、模型结构描述
- **工具**：模型分析脚本
- **质量门禁**：编码器冻结后仍能处理目标域输入格式；参数量与目标域数据量匹配评估

### Step 2：适应策略选择与配置
- **操作**：根据目标域数据量和几何差异度选择策略：
  - **LoRA**：在所有层注入低秩适配器，正则化损失景观同时保留预训练特征（适用于中等数据量，推荐首选）
  - **FFT（Full Fine-Tuning）**：全参数更新，数据极少时易过拟合
  - **LFT（Lightweight Fine-Tuning）**：冻结编码器仅调解码器，编码器无法表示未见形状时失败
  - **自编码器潜空间对齐**：冻结编码器学习潜空间，微调解码器适配目标域（适用于多保真场景）
- **参数**：LoRA rank、冻结层选择、学习率
- **工具**：适应策略配置脚本
- **质量门禁**：策略配置与数据量匹配；冻结/可训练参数比例合理

### Step 3：目标域适应训练
- **操作**：在目标域少量数据上执行适应训练，记录逐轮训练验证指标
- **参数**：ADAPT_CONFIG（学习率、轮次、批大小、早停）
- **工具**：PyTorch 训练框架
- **质量门禁**：训练损失收敛；验证损失不低于训练损失太多（防过拟合）；权重可重新加载

### Step 4：迁移效果评估
- **操作**：在目标域测试集上评估各策略的 R²、RMSE、相对 L₂ 误差；对比从头训练基线
- **参数**：测试集、评估指标
- **工具**：评估脚本
- **质量门禁**：至少一个策略达到 R² > 0.8；最差样本误差可追溯

## 边界与分流

- **目标域数据 > 200 工况**：直接重新训练可能更高效，迁移学习收益递减
- **几何拓扑差异极大**（如从翼型到旋转机械）：LoRA 可能仍不足，需回退到自编码器潜空间对齐或全新架构设计
- **编码器冻结后 R² < 0**：说明编码器无法表示目标域形状，必须采用 LoRA 或 FFT 等允许编码器更新的策略
- **LoRA rank 过高**：退化为 FFT，失去正则化优势；rank 过低则表达力不足
- **多保真场景**：优先选择自编码器路径（冻结 LF 编码器 + 微调 HF 解码器），而非纯 LoRA

## 质量检查

- **收敛性**：训练曲线平滑、验证损失稳定
- **泛化性**：目标域测试集 R² > 0.8
- **稳定性**：多次运行方差小（±0.02）
- **效率**：适应训练时间在可接受范围内（小时级）
- **可复现性**：随机种子、超参数全部记录

## 回退策略

- LoRA 失败 → 尝试更高 rank 或 FFT（需更多数据）
- FFT 过拟合 → 回退到 LoRA 或 LFT
- LFT 编码器冻结失败 → 必须使用 LoRA 或 FFT
- 所有策略失败 → 从头训练 + 增加数据采集
- 数据完全不足 → BLOCKED + 数据缺口清单
