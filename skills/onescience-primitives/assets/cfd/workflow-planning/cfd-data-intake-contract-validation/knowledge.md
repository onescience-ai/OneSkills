# CFD数据接入与契约核验

## 适用范围

适用于任意几何非结构网格CFD数据的接入和核验任务，确保数据完整性、定义数据契约、为后续图神经算子训练做好准备。

## 输入

- 非结构网格CFD数据集路径
- 数据集名称和版本信息
- 数据契约模板（可选）

## 输出

- 数据清单（dataset_manifest.json）
- 数据契约（data_contract.json）
- 数据审计报告（data_audit.md）

## 流程节点

1. **读取数据集** → 加载数据文件，检查文件格式和可读性
2. **样本检查** → 验证样本数量、输入与目标变量
3. **单位检查** → 确认物理量单位定义完整
4. **坐标系检查** → 验证网格坐标和拓扑结构
5. **工况检查** → 检查时间或工况范围
6. **缺失值检查** → 识别和处理缺失值
7. **许可检查** → 确认数据使用许可
8. **生成契约** → 输出机器可读的数据契约

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必填输入 | 数据集路径 | 场景需求书 | 数据文件或目录 |
| 必填输入 | 数据集名称 | 场景需求书 | 来源与数据版本 |
| 可选输入 | 数据契约 | 场景需求书 | 变量单位网格定义 |
| 输出格式 | JSON | 场景需求书 | 机器可读契约 |

## 边界与分流

- **数据不可读**：返回BLOCKED并列出缺项，不得编造数据
- **数据不完整**：记录缺失字段，提供补全建议
- **许可限制**：记录许可条款，确保合规使用

## 质量检查

- **数据文件可读且样本可追溯**：所有数据文件可访问，样本有唯一标识
- **输入目标变量单位坐标定义完整**：所有物理量有明确单位，坐标系定义清晰
- **不存在训练测试泄漏**：数据切分前无信息泄露

## 回退策略

- **数据不完整**：请求用户提供完整数据或补充信息
- **格式不支持**：建议用户转换数据格式或提供转换工具
- **许可问题**：建议用户获取必要许可或使用替代数据

## 资源召回建议

- 当需要接入非结构网格CFD数据时
- 当需要定义数据契约确保数据质量时
- 配套资源：数据验证工具、契约模板生成器
