# 小波与局部谱核多尺度算子学习工作流

## 适用范围

**触发条件**：
- 需要从多尺度高频PDE场数据构建神经算子代理模型
- 需要完整的从数据到模型到评估的工作流
- 需要物理一致性保证的CFD代理建模

**适用场景**：
- 流体动力学中的湍流、多相流模拟
- 多尺度PDE系统的快速求解
- 需要可复现、可追溯的模型开发流程
- 工程应用中的代理模型构建与验证

**不适用场景**：
- 仅需快速原型验证的简单PDE问题
- 缺乏足够训练数据的小样本场景
- 对物理约束要求不严格的纯数据驱动任务

## 输入

**数据要求**：
- 多尺度高频PDE场数据（空间坐标、时间、物理量场）
- 数据契约定义（输入字段、目标字段、单位、坐标系）
- 数据集路径与名称

**配置要求**：
- 切分配置（train/val/test比例、分组策略）
- 训练配置（框架、 epochs、batch_size、学习率等）
- 验收指标与门限

## 输出

**产物清单**：
- 数据清单与契约（dataset_manifest.json, data_contract.json）
- 切分后的数据集（train/val/test_manifest.json）
- 归一化统计量（normalization.json）
- 训练好的模型权重（best_checkpoint.pt）
- 训练配置与环境记录（train_config.json, environment.txt）
- 推理结果与物理恢复（predictions/, inference_manifest.json）
- 评估报告与适用域判定（evaluation.json, applicability_report.md）

## 流程节点

### Step 1：数据接入与契约核验
- **操作**：读取数据、建立清单、核验完整性
- **关键检查**：文件可读性、样本数、变量定义、单位坐标、使用许可
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏

### Step 2：预处理与数据切分
- **操作**：单位统一、无量纲化、无泄漏切分
- **关键检查**：物理量单位一致性、切分策略有效性、变换可逆性
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏

### Step 3：模型配置与训练
- **操作**：加载数据、配置模型、训练、保存最佳权重
- **关键检查**：模型结构正确性、训练收敛性、权重可复现性
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现

### Step 4：批量推理与物理恢复
- **操作**：加载权重、测试集推理、反归一化、物理单位恢复
- **关键检查**：推理结果完整性、单位正确性、无数据泄漏
- **质量门禁**：预测无NaN或Inf且形状单位正确；每个测试样本有唯一结果；推理未使用测试目标校正

### Step 5：任务验收与适用域判定
- **操作**：统计误差评估、物理约束验证、泛化能力测试、适用域判定
- **关键检查**：误差指标满足门限、物理约束满足、最差样本可追溯
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议

## 边界与分流

**异常处理**：
1. 数据文件不可读 → 返回BLOCKED，列出缺项
2. 数据契约定义不完整 → 返回BLOCKED，要求补充
3. 训练不收敛 → 调整超参数或检查数据质量
4. 物理约束不满足 → 增加物理正则化或调整损失函数
5. 适用域过窄 → 明确标注限制，建议CFD复核

## 质量检查

**验证点**：
- 数据完整性与可追溯性
- 切分有效性（无泄漏）
- 模型收敛性与可复现性
- 物理一致性（守恒、边界）
- 适用域明确性

## 回退策略

**失败替代**：
- 数据质量不足 → 降级为小规模实验
- 模型不收敛 → 更换架构或超参数
- 物理约束不满足 → 增加物理正则化
- 适用域过窄 → 标注限制，建议CFD复核
