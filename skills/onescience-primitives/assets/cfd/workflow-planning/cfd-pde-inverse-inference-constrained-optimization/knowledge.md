# PDE逆问题推理约束优化方法

## 适用范围
适用于PDE逆问题任务中的推理阶段，特别是当反演结果需要满足物理约束（如守恒律、边界条件）时。涵盖设计候选生成、约束满足验证和Pareto前沿搜索。不适用于训练阶段。

## 输入
- 训练好的神经网络模型
- 观测数据（或合成数据）
- 物理约束定义（PDE方程、边界条件、初始条件）
- 优化目标（最小化误差、满足约束）

## 输出
- 设计候选集合（反演参数或边界条件）
- 约束满足报告（每个候选的约束违反程度）
- Pareto前沿（多目标优化下的最优解集）
- 优化历史记录（搜索轨迹、目标值变化）

## 流程节点
1. 候选生成 → 使用模型生成初始设计候选
2. 约束验证 → 检查每个候选是否满足物理约束
3. 目标评估 → 计算每个候选的目标函数值
4. Pareto搜索 → 使用多目标优化算法搜索Pareto前沿
5. 结果筛选 → 根据约束满足度和目标值筛选最终候选
6. 报告生成 → 记录优化过程和结果

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 候选数量 | 100 ~ 1000 | 通用 | 平衡搜索范围和计算成本 |
| 约束容忍度 | 1e-3 ~ 1e-6 | 通用 | 根据精度要求调整 |
| Pareto前沿大小 | 10 ~ 50 | 通用 | 提供足够选择空间 |
| 优化算法 | NSGA-II, MOEA/D | 通用 | 多目标优化常用算法 |

## 边界与分流
- 约束满足困难：放松约束或使用惩罚函数
- Pareto前沿过大：使用聚类或决策者偏好筛选
- 优化收敛慢：使用代理模型加速
- 计算资源不足：减少候选数量或并行计算

## 质量检查
- 验证候选是否满足物理约束
- 检查Pareto前沿的多样性和收敛性
- 确认优化历史记录完整
- 验证最终候选的合理性

## 回退策略
- 优化失败：使用随机搜索或网格搜索
- 约束无法满足：使用软约束或后处理修正
- Pareto前沿退化：调整优化参数或算法
