# CFD数据预处理与无泄漏切分任务

## 适用范围

**触发条件**：
- 需要对CFD快照数据进行预处理
- 需要构造无泄漏的训练/验证/测试集切分
- 需要保存归一化统计量以确保可逆性

**适用场景**：
- POD/DMD降阶建模的数据准备阶段
- 机器学习建模的标准化数据预处理
- 需要保证数据切分无泄漏的场景

**不适用场景**：
- 已预处理数据的直接使用
- 实时数据流处理
- 非参数化数据的处理

## 输入

**输入数据**：
- 经过数据接入与契约核验的CFD快照数据
- 数据契约定义
- 切分配置

**输入格式**：
- 快照矩阵：numpy数组或类似结构
- 参数标签：CSV或JSON格式
- 切分配置：JSON格式（train比例、validation比例、test比例、随机种子、分组依据）

**预处理要求**：
- 数据已通过数据接入与契约核验
- 数据契约已建立

## 输出

**输出产物**：
1. train_manifest.json：训练集清单
2. validation_manifest.json：验证集清单
3. test_manifest.json：测试集清单
4. normalization.json：归一化统计量（均值、标准差等）

**验证标准**：
- 三份切分的对象轨迹互斥
- 仅用训练集计算变换统计量
- 边界与掩膜语义未破坏

## 流程节点

### Step 1：物理量统一
- **操作**：统一物理量表示（如单位转换、坐标系对齐）
- **参数**：目标变量列表、单位转换规则
- **工具**：数据转换脚本
- **质量门禁**：所有变量单位一致，坐标系对齐

### Step 2：无量纲化处理
- **操作**：根据需要对物理量进行无量纲化
- **参数**：无量纲化选项、参考值
- **工具**：无量纲化脚本
- **质量门禁**：无量纲化可逆，保存参考值

### Step 3：数据切分
- **操作**：按几何、工况或时间进行无泄漏切分
- **参数**：切分配置（比例、随机种子、分组依据）
- **工具**：数据切分脚本
- **质量门禁**：三份切分互斥，分组依据合理

### Step 4：统计量计算
- **操作**：仅基于训练集计算归一化统计量
- **参数**：统计量类型（均值、标准差等）
- **工具**：统计计算脚本
- **质量门禁**：统计量仅来自训练集，保存为可逆格式

### Step 5：清单生成
- **操作**：生成各切分的数据清单
- **参数**：清单格式
- **工具**：清单生成脚本
- **质量门禁**：清单完整，包含所有必要信息

## 边界与分流

**关键前提不成立时的改道方案**：

1. **切分无法保证互斥**：若几何/轨迹/工况无法清晰划分，需重新设计切分策略或简化问题
2. **无量纲化不可逆**：检查参考值保存是否完整，重新计算
3. **统计量计算错误**：重新计算，确保仅使用训练集
4. **边界掩膜破坏**：检查掩膜定义，恢复原始语义

## 质量检查

**验证点**：
- 切分互斥性验证
- 统计量来源验证
- 无量纲化可逆性验证
- 边界掩膜语义验证
- 清单完整性检查

**阈值**：
- 三份切分无重叠
- 统计量仅来自训练集
- 无量纲化误差 < 1e-10

**失败处理**：
- 切分问题：重新设计切分策略
- 统计量问题：重新计算并验证
- 无量纲化问题：检查参考值并重新处理

## 回退策略

**失败时的替代方案**：
1. **切分策略失败**：回退到简单随机切分（不推荐，可能泄漏）
2. **无量纲化失败**：跳过无量纲化，直接使用原始数据
3. **清单生成失败**：手动记录切分信息
