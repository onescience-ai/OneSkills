# 自回归网络圆柱尾迹长时滚动预测

## 适用范围
面向圆柱绕流非定常时序数据，采用自回归卷积神经网络（Autoregressive CNN）和 PDE-Refiner 等神经网络PDE求解器，完成尾迹流场的长时滚动预测。适用于低马赫数不可压缩圆柱绕流的非定常流场预测任务，覆盖单工况或多工况的时序推演。

**不适用场景**：高马赫数可压缩流、涉及化学反应的燃烧流场、三维复杂几何的湍流直接模拟。域外工况（不同Reynolds数、不同直径比、不同来流条件）必须经CFD复核后方可使用。

## 输入
- 圆柱绕流非定常时序数据集（时间步 × 空间场的快照序列）
- 数据契约：输入变量、目标变量、单位、网格坐标、时间范围、工况范围
- 数据集来源与许可信息

## 输出
- 可复现的模型 checkpoint（best_checkpoint.pt）
- 训练配置与指标（train_config.json, training_metrics.csv）
- 测试集推理结果（逐样本预测、物理恢复后的场数据）
- 评估报告（evaluation.json, worst_cases.csv, applicability_report.md）
- 验收结论（PASS/REJECT/BLOCKED）

## 流程节点
数据接入与契约核验 → 预处理与数据切分 → 模型配置与训练 → 批量推理与物理恢复 → 任务验收与适用域判定

## 边界与分流
- 数据契约缺失必填字段时 → 返回BLOCKED，列出缺项，不得编造
- 训练验证损失为NaN/Inf时 → REJECT，需检查数据质量或模型配置
- 推理出现NaN/Inf或形状不匹配时 → REJECT，需排查预处理或反归一化
- 相对误差超过门限但物理约束通过时 → 需综合判定，不可仅凭统计指标放行
- 域外工况未测试时 → 不得仅凭平均误差宣称工程可用，需明确适用域限制

## 质量检查
- 数据文件可读且样本可追溯
- 输入目标变量单位坐标定义完整
- 不存在训练测试泄漏
- 三份切分的对象轨迹互斥
- 仅用训练集计算变换统计量
- 边界与掩膜语义未破坏
- 训练验证损失均为有限值
- 最佳权重可重新加载
- 配置环境随机种子可复现
- 预测无NaN或Inf且形状单位正确
- 每个测试样本有唯一结果
- 推理未使用测试目标校正
- 统计与物理指标同时报告
- 最差样本可追溯
- 结论含适用域限制与复核建议

## 回退策略
- 模型训练失败时可尝试降低学习率或减小batch size
- 推理阶段显存不足时降低推理batch size
- 域外工况外推失败时需CFD复核后方可使用
