# PINN Navier-Stokes 方程表述选择

## 适用范围

**触发条件**：
- 使用 PINN 求解不可压缩 NS 方程时需要选择网络输出变量和对应的方程残差形式
- 需要决定是否直接预测压力或通过后处理恢复

**适用场景**：
- VP 表述：需要同时获得速度场和压力场的通用场景
- VV 表述：涡量是关键物理量、或需要避免压力直接求解的场景
- 混合策略：压力 Poisson 方程增强（pressure augmentation）提升压力精度

**不适用场景**：
- 可压缩流（需能量方程和状态方程）
- 非牛顿流体（本构关系不同）

## 输入

- **流动参数**：Reynolds 数、流动维数（2D/3D）、稳态/非稳态
- **精度需求**：速度精度 vs 压力精度的相对要求
- **计算预算**：网络规模和训练时间约束

## 输出

- **选定的表述形式**：VP 或 VV
- **网络输入/输出定义**：明确网络映射 f: (x, y, [t]) → (u, v, [p/ω])
- **损失函数残差项**：对应的 PDE 残差公式

## 流程节点

### VP（速度-压力）表述
- **网络映射**：f: (x, y, t) → (u, v, p)
- **输入**：空间坐标 (x, y) 和时间 t
- **输出**：速度分量 u, v 和压力 p
- **PDE 残差**：
  - 动量方程：ρ(∂u/∂t + u·∇u) = -∇p + μ∇²u
  - 连续性方程：∇·u = 0
- **压力恢复**：压力 p 作为网络输出，通过连续性约束隐式学习；无需额外压力数据 [1]
- **优势**：直接输出压力，适用于需要压力场的工程问题
- **劣势**：压力精度通常低于速度，需要额外约束增强
- **质量门禁**：速度场相对 L2 误差 < 0.1，压力 Poisson 增强后可提升一个数量级 [3]

### VV（速度-涡量）表述
- **网络映射**：f: (x, y, t) → (u, v, ω)
- **输入**：空间坐标 (x, y) 和时间 t
- **输出**：速度分量 u, v 和涡量 ω
- **PDE 残差**：
  - 涡量方程：∂ω/∂t + u·∇ω = ω·∇u + ν∇²ω
  - 连续性方程：∇·u = 0（通过 ω = ∂v/∂x - ∂u/∂y 隐式满足）
- **压力恢复**：压力通过求解 Poisson 方程后处理获得
- **优势**：避免压力直接求解的困难，涡量场更易收敛
- **劣势**：压力需要后处理，边界条件中涡量不易施加
- **质量门禁**：涡量场精度与速度场一致，压力通过 Poisson 方程恢复后误差可控 [1]

### 压力增强（Pressure Augmentation）
- **操作**：在 VP 表述的损失函数中添加压力 Poisson 方程项
- **公式**：L_aug = λ_aug · ∥∇²p + ρ·(∂u/∂t + u·∇u)·∇u∥²
- **效果**：压力精度可提升一个数量级 [3]
- **适用**：压力精度要求高的场景

## 关键参数

### 通用判据

| 参数 | 推荐值 | 来源 | 说明 |
|------|--------|------|------|
| VP 表述适用 Re | < 3900 | [1] | 层流到弱转捩 |
| VV 表述适用维数 | 2D/3D | [1] | 涡量在 3D 中需矢量涡量 |
| 压力增强权重 λ_aug | 0.1~1.0 | [3] | 过大会干扰速度学习 |
| VP 压力精度（无增强） | ~O(10^-2) | [1][3] | 典型相对误差 |
| VP 压力精度（有增强） | ~O(10^-3) | [3] | Poisson 增强后 |

### 校准数值

以下数值来自特定基准体系，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| VP-NSFnet 腔体流 Re=1000 | u,v 相对误差 ~O(10^-3) | [1] | 2D 稳态 |
| VV-NSFnet 圆柱绕流 Re=100 | 涡脱落 Strouhal 数误差 <5% | [1] | 2D 非稳态 |
| 压力 Poisson 增强提升 | 10x 精度改善 | [3] | Beltrami 流验证 |
| 3D Beltrami 流 VV 表述 | 稳态解收敛 | [1][2] | 有解析解 |

## 边界与分流

| 前提 | 不成立时改道 |
|------|-------------|
| 流动为不可压缩 | 转向可压缩 NS 方程（含能量方程） |
| 需要高精度压力场 | 使用 VP + Poisson 增强或 FV-PINN |
| 涡量边界条件难以施加 | 改用 VP 表述 |
| 3D 问题 | VV 表述需矢量涡量，复杂度增加，考虑 VP |

## 质量检查

- VP 表述：检查 ∇·u ≈ 0 的连续性满足度
- VV 表述：检查 ω = ∂v/∂x - ∂u/∂y 的涡量一致性
- 压力恢复：检查压力 Poisson 方程残差
