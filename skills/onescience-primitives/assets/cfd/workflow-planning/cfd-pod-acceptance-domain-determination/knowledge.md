# POD与模态分解任务验收与适用域判定任务

## 适用范围

**触发条件**：
- 需要评估降阶模型的统计误差
- 需要验证物理约束满足度
- 需要判定模型的适用域和泛化能力

**适用场景**：
- 降阶模型的工程验收
- 模型适用性评估和边界确定
- 需要外推测试的场景

**不适用场景**：
- 模型训练过程监控
- 快速原型验证
- 理论分析研究

## 输入

**输入数据**：
- 测试集预测结果
- 原始测试数据（标签）
- 数据契约
- 验收指标配置

**输入格式**：
- 预测结果：numpy数组或类似结构
- 原始数据：numpy数组或类似结构
- 数据契约：JSON格式
- 验收配置：JSON格式

**预处理要求**：
- 推理已完成，预测结果已保存
- 物理单位已恢复

## 输出

**输出产物**：
1. evaluation.json：评估结果（统计误差、物理约束等）
2. worst_cases.csv：最差样本信息
3. applicability_report.md：适用域报告
4. PASS_REJECT_BLOCKED.txt：验收结论

**验证标准**：
- 统计与物理指标同时报告
- 最差样本可追溯
- 结论含适用域限制与复核建议

## 流程节点

### Step 1：统计误差评估
- **操作**：计算逐变量误差、边界误差、守恒残差等
- **参数**：验收指标列表、误差门限
- **工具**：误差计算脚本
- **质量门禁**：所有指标计算完整，误差门限应用正确

### Step 2：物理约束验证
- **操作**：验证质量、动量、能量守恒等物理约束
- **参数**：物理约束定义
- **工具**：物理验证脚本
- **质量门禁**：物理约束满足度在允许范围内

### Step 3：最差样本分析
- **操作**：识别并分析最差样本
- **参数**：最差样本定义
- **工具**：样本分析脚本
- **质量门禁**：最差样本可追溯，原因分析完整

### Step 4：外推测试
- **操作**：测试模型在几何或工况外推下的性能
- **参数**：外推测试配置
- **工具**：外推测试脚本
- **质量门禁**：外推测试完成，结果明确

### Step 5：适用域判定
- **操作**：根据评估结果判定适用域和验收结论
- **参数**：判定规则
- **工具**：判定脚本
- **质量门禁**：判定结论明确，限制条件清晰

## 边界与分流

**关键前提不成立时的改道方案**：

1. **指标计算失败**：检查预测结果和原始数据格式
2. **物理约束严重违反**：标记为REJECT，建议模型改进
3. **外推测试不通过**：明确适用域限制，建议CFD复核
4. **判定不确定**：标记为BLOCKED，建议进一步验证

## 质量检查

**验证点**：
- 指标计算完整性
- 物理约束满足度
- 最差样本可追溯性
- 外推测试明确性
- 适用域限制清晰性

**阈值**：
- 相对L2误差 ≤ 0.1
- 守恒残差 < 1e-6（量纲相关）
- 边界误差 < 1%

**失败处理**：
- 指标计算失败：检查数据格式
- 物理违反：标记为REJECT
- 外推不通过：明确限制条件
- 判定不确定：标记为BLOCKED

## 回退策略

**失败时的替代方案**：
1. **评估失败**：回退到简化评估指标
2. **物理验证失败**：回退到统计误差评估
3. **判定不确定**：标记为BLOCKED，建议人工审核
