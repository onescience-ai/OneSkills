# 跨声速翼型流动主动控制

## 适用范围

面向跨声速翼型流动中的激波-边界层干扰、阵风载荷与非定常振荡问题，提供基于深度学习（Deep RL、伴随神经网络）的主动控制策略规划与执行框架。适用于翼型/机翼在跨声速或可压缩流动条件下的减阻、增升、阵风载荷缓解与流动稳定性控制任务。不适用于亚声速不可压缩流动或高超声速极端工况。

## 输入

- **几何模型**：翼型/机翼几何定义（如 RAE2822、NACA0012）
- **流场参数**：雷诺数、马赫数、攻角范围
- **控制目标**：减阻、增升、升阻比优化、阵风载荷缓解
- **控制约束**：执行器幅值/频率限制、能耗预算、安全边界
- **数据契约**：输入/目标变量、单位、网格坐标、工况范围定义

## 输出

- **控制策略**：训练好的神经网络控制器（Deep RL agent 或 adjoint-based network）
- **仿真结果**：闭环轨迹、控制动作、载荷/阻力变化
- **评估报告**：统计误差、物理约束满足情况、适用域报告
- **可复现产物**：最佳权重、训练配置、环境记录

## 流程节点

1. **数据接入与契约核验** → 核验样本、变量、单位、网格坐标及许可
2. **预处理与数据切分** → 统一物理量与表示，按几何/工况构造无泄漏切分
3. **模型配置与训练** → 训练 Deep RL controller 或 Adjoint neural controller
4. **闭环策略部署与滚动仿真** → 部署策略，滚动记录观测、动作、载荷和安全约束
5. **任务验收与适用域判定** → 评估统计误差、物理约束、泛化能力和计算收益

## 边界与分流

- **前提：跨声速流动** → 若流动为亚声速或不可压缩，控制策略需重新设计
- **前提：激波存在** → 若无激波（如低马赫数），控制目标可能不同（如分离控制）
- **前提：执行器可用** → 若无合成射流或其他执行器，需考虑被动控制或替代方案
- **前提：CFD求解器可用** → 若无高保真CFD，需降低仿真精度或使用降阶模型

## 质量检查

- **数据完整性**：数据文件可读且样本可追溯
- **切分有效性**：三份切分的对象轨迹互斥，仅用训练集计算变换统计量
- **训练验证**：训练验证损失均为有限值，最佳权重可重新加载
- **闭环验证**：动作满足幅值频率安全约束，闭环过程稳定无数值发散
- **适用域判定**：统计与物理指标同时报告，最差样本可追溯，结论含适用域限制与复核建议

## 回退策略

- **训练不收敛**：调整学习率、批量大小或网络结构；检查数据质量
- **闭环发散**：减小控制增益或时间步长；检查执行器约束
- **泛化不足**：增加训练数据多样性；使用域外测试验证适用域
- **计算成本过高**：使用降阶模型或自适应网格；考虑并行计算
