# 物理约束神经算子批量推理与物理恢复

## 适用范围
面向带守恒边界和无量纲约束PDE数据的批量推理与物理恢复任务，在独立测试集推理，恢复原始单位、网格和物理派生量，保存逐样本结果和耗时，禁止用测试标签修正预测。适用于Physics-constrained neural operator的推理阶段，确保预测结果可恢复为物理单位并保持物理一致性。

## 输入
- **模型权重**（必填）：通过训练门限的最佳模型权重
- **计算设备**（必填）：CPU或CUDA设备
- **推理批大小**（可选）：按显存调整批量，默认8
- **数据切分**（来自s02）：测试集清单和统计量
- **数据契约**（来自s01）：变量单位、网格坐标、边界条件类型

## 输出
- **predictions/**：预测结果目录，包含逐样本预测文件
- **inference_manifest.json**：推理清单，记录每个样本的预测结果和元数据
- **timing.csv**：推理耗时记录，包含每个样本的推理时间

## 流程节点
1. **模型加载** → 加载最佳模型权重和数据契约
2. **测试集加载** → 加载测试集清单，应用归一化或无量纲化
3. **批量推理** → 在测试集上执行推理，保存预测结果
4. **物理恢复** → 反归一化并恢复物理单位、坐标网格、边界掩膜及任务派生量
5. **结果验证** → 检查预测结果完整性和物理一致性
6. **耗时记录** → 记录每个样本的推理时间

## 边界与分流
- **模型权重不可加载** → 返回BLOCKED，检查权重文件完整性和模型架构
- **计算设备不可用** → 返回BLOCKED，检查设备驱动和可用性
- **推理异常值** → 检查数据预处理、模型权重、计算设备
- **物理恢复失败** → 检查归一化统计量和数据契约
- **内存不足** → 降低推理批大小或使用CPU推理

## 质量检查
- **预测无NaN或Inf且形状单位正确**：确保推理结果有效
- **每个测试样本有唯一结果**：避免结果混淆
- **推理未使用测试目标校正**：保证评估公平性
- **物理恢复正确**：预测结果可恢复为物理单位并保持物理约束

## 回退策略
- **推理失败** → 检查模型权重、数据质量、计算设备
- **物理恢复失败** → 检查归一化统计量和数据契约
- **内存不足** → 降低推理批大小或使用CPU推理
- **结果不完整** → 检查数据加载和保存逻辑
