# CFD多保真代理模型任务准备与降级策略

## 适用范围

本卡片为CFD多保真代理模型任务提供执行前的准备知识与阻塞时的降级策略，覆盖数据获取渠道检查、计算环境配置、可行性评估方法以及任务状态管理。适用于需要构建多保真代理模型但面临数据缺失、环境不成熟或任务阻塞的场景，支持从规划到执行的完整路径规划，确保任务在约束条件下仍能产出有价值的中间结果。

## 输入

- **任务描述**：CFD多保真代理模型构建任务的目标、约束和预期产出
- **可用资源**：本地计算环境、网络访问权限、已有数据或工具
- **任务状态**：当前执行进度、阻塞原因、已生成的产物

## 输出

- **数据获取方案**：公开数据集访问方式、数据格式规范、数据契约定义
- **环境配置方案**：Python科学计算栈安装指南、轻量级CFD工具配置
- **可行性评估报告**：数据可得性检查结果、环境可得性检查结果、风险评估
- **降级执行方案**：模拟数据生成规范、产物清单调整规则、任务状态标注
- **后续建议**：详细的数据获取步骤、环境配置指南、替代执行路径

## 流程节点

### 1. 数据可得性检查
- **操作**：搜索公开数据集（UIUC翼型数据库、风洞测试数据）、检查本地数据、评估数据生成可行性
- **参数**：数据源URL、数据格式（.dat文件）、变量定义（厚度、弯度、攻角、升力系数、阻力系数）
- **工具**：webfetch（下载数据样本）、bash（检查本地文件）
- **质量门禁**：至少找到1个可用数据源，数据格式符合契约要求

### 2. 环境可得性检查
- **操作**：检测Python环境、检查必要库（scikit-learn、GPyTorch、PyTorch）、评估安装可行性
- **参数**：Python版本（3.8+）、库版本兼容性、安装权限
- **工具**：bash（运行python -c 'import sklearn; import torch'）
- **质量门禁**：核心库可导入，版本满足最低要求

### 3. 风险评估与降级方案制定
- **操作**：评估数据缺失概率、环境缺失概率，制定降级执行方案
- **参数**：数据缺失概率、环境缺失概率、降级执行条件
- **工具**：LLM推理（风险评估）
- **质量门禁**：降级方案明确，产物清单调整规则清晰

### 4. 任务状态管理
- **操作**：根据检查结果标注任务状态（BLOCKED vs PARTIAL），提供后续建议
- **参数**：任务状态、阻塞原因、后续建议
- **工具**：LLM推理（状态标注）
- **质量门禁**：状态标注准确，后续建议具体可执行

### 5. 降级执行（如适用）
- **操作**：使用模拟数据执行任务，标注为engineering_validation(smoke)
- **参数**：模拟数据生成方法（NACA翼型参数化公式）、产物清单调整
- **工具**：Python脚本（生成模拟数据）
- **质量门禁**：模拟数据符合物理规律，产物标注为降级执行

## 边界与分流

- **数据完全不可用**：当公开数据集无法访问且无模拟数据生成能力时，保持BLOCKED状态，在execution-manifest.json中提供详细的数据获取步骤
- **环境配置失败**：当Python环境无法配置时，标注BLOCKED并提供详细的环境配置指南，建议使用在线Jupyter环境
- **降级执行不适用**：当任务需要真实物理验证时（如安全性关键设计），降级执行不适用，必须保持BLOCKED状态
- **计算资源不足**：当本地CPU无法满足训练需求时，可考虑使用云服务或简化模型

## 质量检查

- **数据质量**：公开数据集格式符合契约，模拟数据符合物理规律
- **环境质量**：Python环境可运行核心代码，库版本兼容
- **降级执行质量**：产物标注清晰，后续建议具体可执行
- **状态管理质量**：BLOCKED/PARTIAL标注准确，阻塞原因明确

## 回退策略

- **数据获取失败**：使用模拟数据（如NACA翼型参数化）生成工程验证数据集
- **环境配置失败**：提供详细的环境配置指南，建议使用容器化环境
- **降级执行失败**：保持BLOCKED状态，提供详细的后续执行路径
- **任务状态标注错误**：重新评估任务状态，修正标注并更新后续建议
