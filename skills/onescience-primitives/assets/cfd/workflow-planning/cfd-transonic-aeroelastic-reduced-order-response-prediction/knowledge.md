# 跨声速气动弹性降阶响应预测

## 适用范围
面向跨声速颤振与buffet耦合数据，构建降阶响应预测模型，实现从高保真CFD数据到快速气动弹性分析的转换。适用于跨声速气动弹性问题，包括颤振边界预测、压力分布预测和系统稳定性分析。不适用于强非线性激波动力学占主导的工况，需经CFD复核。

## 输入
- 跨声速颤振与buffet耦合CFD数据（压力分布、结构模态、工况参数）
- 结构模型（质量、阻尼、 stiffness矩阵）
- 工况定义（马赫数、攻角、雷诺数等）

## 输出
- 降阶气动弹性模型（状态空间形式）
- 压力分布预测
- 系统稳定性评估（特征值分析）
- 适用域报告

## 流程节点
1. **数据接入与契约核验** → 接入跨声速颤振与buffet耦合数据，核验样本、变量、单位、网格坐标及许可
2. **预处理与数据切分** → 统一物理量与表示，按几何、工况或时间构造无泄漏切分
3. **模型配置与训练** → 训练Neural reduced-order model、Neural ODE完成指定输入到目标物理量的映射
4. **批量推理与物理恢复** → 在独立测试集推理，恢复原始单位、网格和物理派生量
5. **任务验收与适用域判定** → 评估统计误差、关键物理约束、泛化能力和计算收益

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| DMDc模态数 | 30 | [1] | BSCW案例最优模态数，平衡精度与过拟合 |
| 训练信号振幅 | 适中 | [1] | 需足够激励动力学但避免强非线性 |
| 稳定化假设 | 对称响应 | [1] | 气动响应需对称于输入 |
| 稳态时间窗口 | 足够长 | [1] | 训练信号需允许气动达到稳态 |

## 边界与分流
- **强激波动力学**：当训练工况外出现强激波时，单一线性模型失效，需构建多个线性模型并插值（LPV方法）
- **非线性结构**：本方法假设线性结构动力学，大变形非线性需其他方法
- **多工况扩展**：单工况模型需扩展为LPV模型以覆盖多个操作条件

## 质量检查
- 特征值分析：所有特征值应在单位圆内或圆上
- 压力分布预测：与高保真CFD结果比较
- 稳定性预测：与全耦合仿真结果比较
- 计算效率：ROM计算时间应显著低于高保真仿真

## 回退策略
- 降级为线性气动弹性分析（亚声速工况）
- 使用全耦合CFD仿真验证关键工况
- 采用其他降阶方法（如ARMA、神经网络）
