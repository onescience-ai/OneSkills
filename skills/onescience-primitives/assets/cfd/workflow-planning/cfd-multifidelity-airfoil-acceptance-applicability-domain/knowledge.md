# 任务验收与适用域判定

## 适用范围

**触发条件**：
- 已完成候选生成与约束优化，需要评估统计误差、物理约束、泛化能力和计算收益
- 需要输出适用域报告与域外工况CFD复核建议
- 需要给出PASS/REJECT/BLOCKED判定

**适用场景**：
- 多保真代理辅助翼型优化的验收阶段
- 需要物理一致性评估与适用域报告
- 需要识别域外工况并建议CFD复核

**不适用场景**：
- 仅需简单统计误差评估的场景
- 无需物理约束验证的场景
- 无需适用域判定的场景

## 输入

**必需输入**：
- 验收指标列表（如objective_improvement、constraint_violation、CFD_validation_error）

**可选输入**：
- 相对误差门限（测试集放行阈值，默认0.1）
- 是否外推测试（测试域外工况，默认true）

**预处理要求**：
- 依赖s04的优化结果与设计候选

## 输出

**核心产物**：
- evaluation.json：评估结果，含逐变量误差、边界误差、守恒或方程残差
- worst_cases.csv：最差样本记录
- applicability_report.md：适用域报告，含域外工况识别与CFD复核建议
- PASS_REJECT_BLOCKED.txt：最终判定结果

**验证标准**：
- 统计与物理指标同时报告
- 最差样本可追溯
- 结论含适用域限制与复核建议

## 流程节点

### Step 1：统计误差评估
- **操作**：计算逐变量误差、边界误差、最差样本
- **参数**：验收指标、相对误差门限
- **工具**：评估脚本
- **质量门禁**：所有误差指标为有限值，最差样本可追溯

### Step 2：物理约束验证
- **操作**：验证守恒律、方程残差等物理约束
- **参数**：物理约束定义
- **工具**：物理验证脚本
- **质量门禁**：物理约束满足或违反在可接受范围内

### Step 3：泛化能力评估
- **操作**：执行几何或工况外推测试，明确适用域
- **参数**：是否外推测试、外推范围
- **工具**：泛化评估脚本
- **质量门禁**：域外工况识别明确，适用域边界清晰

### Step 4：适用域报告生成
- **操作**：生成适用域报告，含域外工况CFD复核建议
- **参数**：评估结果
- **工具**：报告生成工具
- **质量门禁**：报告含适用域限制与复核建议

### Step 5：最终判定
- **操作**：根据评估结果给出PASS/REJECT/BLOCKED判定
- **参数**：验收指标、误差门限
- **工具**：判定逻辑脚本
- **质量门禁**：判定逻辑正确，结论明确

## 边界与分流

**统计误差超标时的改道**：
- 误差超过阈值但物理约束满足 → 标记为需谨慎使用，不完全拒绝
- 误差超过阈值且物理约束违反 → 标记为REJECT，需重新训练

**物理约束违反时的改道**：
- 轻微违反（可接受范围） → 标记为需CFD复核的工况
- 严重违反（不可接受） → 标记为REJECT，不进入优化流程

**域外工况识别时的改道**：
- 识别出域外工况 → 标记为需CFD复核，不宣称工程可用
- 无法确定适用域 → 标记为BLOCKED，需进一步分析

## 质量检查

| 检查项 | 阈值/判据 | 失败处理 |
|--------|-----------|----------|
| 误差指标完整性 | 所有验收指标均有值 | 补充缺失指标 |
| 最差样本可追溯 | 逐样本误差可查 | 生成worst_cases.csv |
| 物理约束验证 | 约束满足或违反可接受 | 标记需CFD复核 |
| 适用域报告 | 含域外工况识别 | 补充OOD测试 |
| 判定逻辑 | PASS/REJECT/BLOCKED正确 | 检查判定规则 |

## 回退策略

- 评估指标缺失 → 补充评估或调整指标定义
- 物理约束验证失败 → 降低约束阈值或标记需CFD复核
- 适用域报告不完整 → 补充域外工况分析
