# GAN与正规化流湍流降阶数据接入与契约核验

## 适用范围

本任务适用于 GAN 与正规化流湍流降阶生成的数据接入阶段，负责接入湍流快照与低维潜变量数据，核验数据完整性、变量定义、单位一致性、网格坐标和使用许可，建立机器可读的数据契约。

**触发条件**：
- 输入数据为湍流快照与低维潜变量数据
- 需要建立数据清单和契约
- 需要验证数据质量与完整性

**不适用场景**：
- 数据格式不兼容且无法转换
- 缺少必要元数据且无法补全
- 数据来源不明或无使用许可

## 输入

**数据源**：
- 数据集路径（{DATASET_PATH}，目录或清单文件）
- 数据集名称（{DATASET_NAME}，来源与数据版本）
- 数据契约模板（{DATA_CONTRACT}，可选，默认空契约）

**数据契约模板**：
```json
{
  "input_fields": [],
  "target_fields": [],
  "units": {},
  "coordinates": "dataset_native"
}
```

## 输出

**数据产物**：
- dataset_manifest.json：数据清单，包含文件列表、样本数、变量信息
- data_contract.json：数据契约，定义输入输出变量、单位、坐标系
- data_audit.md：数据审计报告，记录检查结果与异常

**验证标准**：
- 数据文件可读且样本可追溯
- 输入目标变量单位坐标定义完整
- 不存在训练测试泄漏

## 流程节点

### 1. 数据加载
- **操作**：读取 {DATASET_PATH} 中的 {DATASET_NAME}
- **参数**：数据集路径、文件格式
- **工具**：数据加载器（h5py, numpy, xarray 等）
- **质量门禁**：文件可读、格式正确

### 2. 样本核验
- **操作**：检查样本数量、完整性、缺失值
- **参数**：数据清单模板
- **工具**：样本检查器
- **质量门禁**：样本可追溯、无缺失值

### 3. 变量定义
- **操作**：核验输入与目标变量、单位、坐标系
- **参数**：数据契约模板
- **工具**：变量核验器
- **质量门禁**：变量定义完整、单位一致

### 4. 网格检查
- **操作**：检查网格拓扑、时间或工况范围
- **参数**：网格信息
- **工具**：网格检查器
- **质量门禁**：网格定义正确、范围合理

### 5. 许可核验
- **操作**：检查数据使用许可、版权信息
- **参数**：许可信息
- **工具**：许可检查器
- **质量门禁**：使用许可明确、无侵权风险

### 6. 契约生成
- **操作**：生成数据清单、契约和审计报告
- **参数**：核验结果
- **工具**：契约生成器
- **质量门禁**：输出格式正确、内容完整

## 边界与分流

**前提条件与改道**：

1. **数据文件可读**
   - 不成立时 → 改道：检查文件路径、权限、格式兼容性

2. **样本完整可追溯**
   - 不成立时 → 改道：进行数据修复或标记缺失样本

3. **变量定义完整**
   - 不成立时 → 改道：补充变量定义或使用默认契约

4. **单位一致**
   - 不成立时 → 改道：进行单位转换或标记不一致项

5. **使用许可明确**
   - 不成立时 → 改道：获取许可或标记为受限数据

## 质量检查

**验证点**：
- 文件可读性检查
- 样本完整性验证
- 变量定义核验
- 单位一致性检查
- 网格拓扑验证
- 使用许可确认

**阈值**：
- 数据完整性 100%
- 变量定义完整率 100%
- 单位一致性 100%

**失败处理**：
- 文件不可读 → 返回路径检查、权限获取
- 样本不完整 → 标记缺失样本、进行数据修复
- 变量定义缺失 → 补充定义或使用默认契约
- 单位不一致 → 进行单位转换或标记
- 许可不明确 → 获取许可或标记为受限

## 回退策略

**失败时的替代方案**：
1. 数据加载失败 → 检查文件格式、尝试其他加载器
2. 样本核验失败 → 进行数据清洗、标记异常样本
3. 变量定义失败 → 使用默认契约、补充定义
4. 单位转换失败 → 标记不一致、进行人工核验
5. 许可核验失败 → 标记为受限数据、限制使用范围
