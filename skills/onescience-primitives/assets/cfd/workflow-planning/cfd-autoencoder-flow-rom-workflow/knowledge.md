# 自编码器潜空间流动降阶时序预测工作流

## 适用范围

本卡片描述自编码器潜空间流动降阶时序预测的完整工作流，适用于从高维流场数据到可复现预测模型的端到端流程。工作流覆盖数据质量控制、模型训练配置、物理一致性评估和适用域判定。

## 输入

- **数据集**：高维流场快照时序数据（如 2D/3D 网格上的速度、压力场）
- **配置文件**：数据契约、切分配置、训练配置
- **可选输入**：预训练权重、初始检查点

## 输出

- **模型产物**：训练好的自编码器模型、潜空间动力学模型、最佳权重检查点
- **评估产物**：预测结果、评估指标报告、适用域报告、最差案例分析
- **文档产物**：数据清单、数据契约、数据审计报告、训练配置、环境信息

## 流程节点

### 步骤1：数据接入与契约核验
- **操作**：接入高维流场快照时序数据，核验样本、变量、单位、网格坐标及许可
- **参数**：数据集路径、数据集名称、数据契约
- **工具**：数据读取工具、格式验证工具
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏
- **输出**：dataset_manifest.json, data_contract.json, data_audit.md

### 步骤2：预处理与数据切分
- **操作**：统一物理量与表示，按几何、工况或时间构造无泄漏切分
- **参数**：切分配置（训练/验证/测试比例）、目标变量、是否无量纲化
- **工具**：数据预处理工具、统计量计算工具
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏
- **输出**：train_manifest.json, validation_manifest.json, test_manifest.json, normalization.json

### 步骤3：模型配置与训练
- **操作**：训练卷积自编码器（CAE）和潜空间动力学模型
- **参数**：模型名称、训练配置（框架、 epochs、批量大小、学习率、种子、早停耐心）、初始权重
- **工具**：深度学习训练框架（如 PyTorch）、模型定义工具
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现
- **输出**：best_checkpoint.pt, train_config.json, training_metrics.csv, environment.txt

### 步骤4：批量推理与物理恢复
- **操作**：在独立测试集推理，恢复原始单位、网格和物理派生量
- **参数**：模型权重、计算设备、推理批大小
- **工具**：推理引擎、后处理工具
- **质量门禁**：预测无 NaN 或 Inf 且形状单位正确；每个测试样本有唯一结果；推理未使用测试目标校正
- **输出**：predictions/, inference_manifest.json, timing.csv

### 步骤5：任务验收与适用域判定
- **操作**：评估统计误差、关键物理约束、泛化能力和计算收益
- **参数**：验收指标（相对 L2、RMSE、守恒残差、边界误差）、相对误差门限、是否外推测试
- **工具**：评估指标计算工具、可视化工具
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议
- **输出**：evaluation.json, worst_cases.csv, applicability_report.md, PASS_REJECT_BLOCKED.txt

## 边界与分流

- **数据质量问题**：若数据文件不可读或样本不可追溯，返回 BLOCKED 状态
- **训练失败**：若训练损失为 NaN 或 Inf，检查数据预处理和模型配置
- **推理异常**：若预测包含 NaN 或 Inf，检查模型权重和推理配置
- **物理不一致**：若守恒残差或边界误差超标，可能需要添加物理约束正则化
- **域外工况**：若外推测试失败，明确适用域限制，建议经 CFD 复核

## 质量检查

- 每个步骤都有明确的质量门禁
- 最差案例可追溯到具体样本
- 评估报告包含统计指标和物理指标
- 结论明确适用域限制和复核建议

## 回退策略

- **数据不足**：若数据量不足，考虑数据增强或迁移学习
- **模型过拟合**：调整正则化参数、增加数据量或使用更简单的模型架构
- **计算资源不足**：减小批量大小、使用混合精度训练或分布式训练
- **物理一致性不满足**：添加物理约束损失项或使用物理信息神经网络（PINN）架构
