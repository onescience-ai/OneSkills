# PDE逆问题模型评估指标体系

## 适用范围
适用于PDE逆问题任务中模型性能的全面评估，包括统计误差、物理约束满足度、泛化能力和计算收益。适用于训练后模型验证和比较。不适用于训练过程监控。

## 输入
- 训练好的模型
- 测试数据集
- 物理约束定义
- 计算资源信息

## 输出
- 评估报告（evaluation.json）
- 最差案例分析（worst_cases.csv）
- 适用域判定报告（applicability_report.md）
- 通过/拒绝/阻塞判定（PASS_REJECT_BLOCKED.txt）

## 流程节点
1. 评估准备 → 加载模型和测试数据
2. 统计误差计算 → 计算MAE、MSE、RMSE、R²等
3. 物理约束验证 → 检查预测是否满足PDE方程和边界条件
4. 泛化能力测试 → 在未见数据上测试模型性能
5. 计算收益分析 → 评估计算时间和资源消耗
6. 最差案例识别 → 找出性能最差的样本并分析原因
7. 适用域判定 → 确定模型适用的数据范围和条件
8. 报告生成 → 汇总评估结果

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| MAE阈值 | <0.01 | 通用 | 平均绝对误差要求 |
| 物理约束违反度 | <1e-4 | 通用 | PDE残差要求 |
| 泛化性能下降 | <10% | 通用 | 从训练到测试的性能下降 |
| 计算时间比 | <10x | 通用 | 相对于传统方法的加速比 |

## 边界与分流
- 评估指标不达标：重新训练或调整模型
- 物理约束违反严重：增加物理约束损失权重
- 泛化能力差：增加数据多样性或使用正则化
- 计算成本过高：优化模型结构或使用近似方法

## 质量检查
- 验证评估指标计算正确性
- 检查最差案例分析合理性
- 确认适用域判定依据充分
- 验证报告完整性

## 回退策略
- 评估失败：使用简化评估指标
- 模型性能差：使用基线模型对比
- 计算资源不足：使用采样评估
