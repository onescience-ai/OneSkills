# CFD后验耦合执行约束

## 适用范围

面向CFD后验耦合验证的流程规范，涵盖RANS/LES求解器接口要求、闭合项张量约束条件、后验推进稳定性判据。适用于湍流闭合模型的后验验证、CFD求解器集成、数值模拟稳定性分析等场景。不适用于纯理论分析或无求解器的离线验证。

## 输入

- 闭合模型：训练好的湍流闭合模型（如神经网络、随机微分方程模型）
- 求解器配置：CFD求解器（如OpenFOAM、Fluent、自研求解器）的配置文件
- 初始条件：流场初始条件、边界条件
- 验证目标：闭合项预测精度、流场物理一致性、数值稳定性

## 输出

- 后验验证结果：闭合项预测、流场演化、误差分析
- 稳定性报告：数值稳定性判据、发散原因分析
- 适用性评估：模型适用范围、局限性、改进建议

## 流程节点

### 求解器接口准备

1. **RANS求解器接口**
   - 输入：平均流场、湍流量（k, ε, ω）、闭合项张量
   - 输出：修正后的平均流场、湍流量演化
   - 接口格式：OpenFOAM字典、Fluent UDF、自定义格式

2. **LES求解器接口**
   - 输入：滤波速度场、亚格子应力、闭合项张量
   - 输出：修正后的滤波速度场、亚格子应力演化
   - 接口格式：OpenFOAM字典、Fluent UDF、自定义格式

3. **求解器可用性检查**
   - 求解器安装状态：是否已安装、版本兼容性
   - 求解器配置：网格格式、边界条件、数值格式
   - 求解器测试：运行简单案例验证求解器可用

### 闭合项张量约束

1. **对称性约束**
   - 应力张量对称性：τ_ij = τ_ji
   - 实现方法：投影到对称张量空间
   - 违反后果：能量不守恒、数值不稳定

2. **正定性约束**
   - 应力张量正定性：主对角线元素 > 0
   - 实现方法：特征值截断、正则化
   - 违反后果：负湍流粘度、数值不稳定

3. **量纲一致性**
   - 单位一致性：闭合项与求解器方程单位匹配
   - 归一化一致性：归一化/反归一化一致性
   - 实现方法：单位转换、归一化检查

4. **物理约束**
   - 能量守恒：闭合项不破坏能量守恒
   - 动量守恒：闭合项满足牛顿第三定律
   - 实现方法：物理约束投影、惩罚项

### 后验推进稳定性

1. **时间步长限制**
   - CFL条件：Courant数 < 1
   - 扩散限制：扩散数 < 0.5
   - 实现方法：自适应时间步长、CFL控制

2. **空间离散稳定性**
   - 网格质量：正交性、纵横比、偏斜度
   - 数值格式：中心差分、迎风差分、混合格式
   - 实现方法：网格优化、格式选择

3. **耦合稳定性**
   - 耦合强度：闭合项与求解器方程的耦合强度
   - 迭代收敛：耦合迭代的收敛性
   - 实现方法：欠松弛、迭代控制

4. **发散检测**
   - 残差监控：连续性、动量、能量方程残差
   - 物理量监控：速度、压力、湍流量的合理性
   - 实现方法：残差阈值、物理量边界检查

### 验证与评估

1. **闭合项预测精度**
   - 误差指标：MSE、MAE、相对误差
   - 物理一致性：闭合项与真实值的物理一致性
   - 实现方法：误差计算、可视化对比

2. **流场物理一致性**
   - 统计特性：均值、方差、能谱
   - 物理约束：质量守恒、动量守恒、能量守恒
   - 实现方法：统计分析、物理约束检查

3. **数值稳定性**
   - 发散次数：模拟过程中发散的次数
   - 稳定性判据：CFL数、扩散数、残差
   - 实现方法：稳定性分析、发散检测

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| CFL条件 | < 1 | 数值分析 | 时间步长限制 |
| 扩散数 | < 0.5 | 数值分析 | 空间离散稳定性 |
| 残差阈值 | < 1e-6 | 收敛标准 | 迭代收敛判据 |

| 正定性约束 | 主对角线 > 0 | 物理约束 | 正定性约束满足程度 |

## 边界与分流

### 求解器不可用时
- 求解器未安装 → 转向标记BLOCKED状态，提供替代验证方案
- 求解器版本不兼容 → 转向版本降级或升级
- 求解器配置错误 → 转向配置修复

### 闭合项约束违反时
- 对称性约束违反 → 转向投影到对称张量空间
- 正定性约束违反 → 转向特征值截断或正则化
- 量纲不一致 → 转向单位转换

### 数值不稳定时
- CFL条件违反 → 转向减小时间步长
- 扩散数违反 → 转向减小空间步长或改变数值格式
- 残差发散 → 转向减小耦合强度或改变迭代策略

## 质量检查

1. **求解器接口检查**：验证求解器安装、配置、可用性
2. **闭合项约束检查**：验证对称性、正定性、量纲一致性
3. **数值稳定性检查**：验证CFL条件、扩散条件、残差收敛
4. **物理一致性检查**：验证质量守恒、动量守恒、能量守恒
5. **验证结果检查**：验证闭合项预测精度、流场物理一致性

## 回退策略

- 如果求解器不可用，标记BLOCKED状态并提供替代验证方案
- 如果闭合项约束违反，进行约束投影或正则化
- 如果数值不稳定，调整时间步长或空间步长
- 如果验证失败，记录失败原因并提供改进建议
