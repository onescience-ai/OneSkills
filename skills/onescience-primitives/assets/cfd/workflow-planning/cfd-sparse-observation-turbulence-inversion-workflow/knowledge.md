# 稀疏观测PINN湍流均值流与闭合联合反演工作流

## 适用范围

**触发条件**：
- 需要从稀疏实验观测数据（如有限传感器测量）重建湍流统计量（均值流、雷诺应力）
- 需要同时反演湍流闭合项并验证其物理一致性
- 研究涉及物理信息神经网络（PINN）在湍流反演中的应用

**适用场景**：
- 圆柱绕流等复杂流场的稀疏数据反演
- 工业流体机械内部流动的重建与验证
- 基于数据驱动的湍流模型开发与验证
- 实验测量数据有限时的流动状态估计

**不适用场景**：
- 完全 resolved 的直接数值模拟（DNS）数据处理
- 稳态层流或低雷诺数流动
- 纯理论湍流建模（无实验数据验证）

## 输入

**数据格式**：
- CSV、NumPy（.npy/.npz）或 HDF5 格式
- 空间坐标：(x, y, z) 三维笛卡尔坐标
- 物理量：速度分量 (u, v, w)、压力 (p)、雷诺应力分量 (u'u', v'v', w'w', u'v', u'w', v'w')
- 时间信息（对于瞬态数据）：时间戳 t

**数据来源**：
- 稀疏实验测量（如 PIV、热线风速仪、压力传感器阵列）
- 高保真模拟数据的稀疏采样
- 论文附件数据集（如 arXiv:2510.06049）

**预处理要求**：
- 坐标系对齐与单位统一
- 缺失值处理与异常值检测
- 数据归一化（可选）

## 输出

**产物**：
1. 反演结果：重建的均值流场、雷诺应力场、湍动能分布
2. 闭合项：反演的湍流闭合张量（需满足物理约束）
3. 验证报告：统计误差、物理约束满足情况、收敛性分析
4. 可视化：流线图、等值线图、误差分布图

**格式**：
- 结果文件：NumPy 格式或 HDF5 格式
- 报告文件：Markdown 或 PDF
- 可视化：PNG 或 SVG 格式

**验证标准**：
- 统计误差：closure_RMSE、mean_profile_error、spectrum_error
- 物理约束：Reynolds 应力半正定性、数值范围合理性
- 收敛性：stability_horizon（后验求解稳定性）

## 流程节点

### Step 1：数据接入与质量门禁
- **操作**：加载稀疏实验观测数据，执行质量检查
- **参数**：数据格式=CSV/NumPy/HDF5，变量完整性检查=开启
- **工具**：Python（pandas/numpy/h5py）
- **质量门禁**：
  - 文件可读性检查：成功读取无报错
  - 样本数验证：样本数 ≥ 最小要求（如 100）
  - 变量完整性检查：所有必需变量存在且无全 NaN 列
  - 训练测试泄漏检查：确保无重叠样本

### Step 2：数据切分与契约生成
- **操作**：将数据切分为训练集、验证集、测试集，生成数据契约
- **参数**：切分比例（如 70%/15%/15%），随机种子=42
- **工具**：scikit-learn（train_test_split）
- **质量门禁**：
  - 切分后各集样本数合理
  - 无数据泄漏（训练集与测试集无重叠）
  - 数据契约包含所有变量描述

### Step 3：PINN 反演训练
- **操作**：构建 PINN 模型，训练反演均值流与闭合项
- **参数**：网络架构（全连接层）、损失函数（物理约束+数据拟合）、学习率、迭代次数
- **工具**：PyTorch/TensorFlow、自定义 PINN 框架
- **质量门禁**：
  - 损失函数收敛（如下降 > 90%）
  - 验证集误差稳定
  - 无梯度爆炸/消失

### Step 4：后验 CFD 耦合与物理约束验证
- **操作**：将反演结果代入 RANS 方程，验证闭合项可实现性
- **参数**：RANS 求解器、收敛标准、物理约束检查
- **工具**：OpenFOAM 或自定义求解器
- **质量门禁**：
  - 闭合张量半正定性检查（特征值 ≥ 0）
  - 数值范围在物理合理范围内（如湍动能 ≥ 0）
  - 后验求解无发散（stability_horizon 达标）

### Step 5：验收评估与报告生成
- **操作**：计算验收指标，生成评估报告
- **参数**：closure_RMSE、mean_profile_error、spectrum_error、stability_horizon
- **工具**：NumPy/SciPy、Matplotlib
- **质量门禁**：
  - 所有验收指标计算正确
  - 相对误差门限满足（如 < 20%）
  - 外推测试执行（可选）
  - 结论含适用域限制与复核建议

## 边界与分流

**关键前提不成立时的改道方案**：

1. **稀疏数据质量过差**（如噪声 > 30%）：
   - 转向：数据预处理加强（滤波、降噪）或改用鲁棒性更强的反演方法
   - 方案族：小波降噪、卡尔曼滤波、贝叶斯推断

2. **PINN 训练不收敛**：
   - 转向：调整网络架构或损失函数权重
   - 方案族：增加隐藏层、调整学习率、引入课程学习

3. **闭合项不满足物理约束**：
   - 转向：增加约束项或修改损失函数
   - 方案族：拉格朗日乘子法、投影层、后处理修正

4. **后验求解发散**：
   - 转向：调整求解器参数或使用隐式时间积分
   - 方案族：降低时间步长、增加松弛因子、使用更稳健的离散格式

## 质量检查

**验证点**：
1. 数据完整性：所有必需变量存在且无全 NaN
2. 训练收敛：损失函数下降稳定，验证集误差不回升
3. 物理一致性：闭合张量半正定，湍动能非负
4. 数值稳定性：后验求解无发散，残差收敛
5. 指标达标：所有验收指标在可接受范围内

**阈值**：
- 数据缺失率 < 5%
- 训练损失下降 > 90%
- 闭合张量最小特征值 ≥ -1e-6（允许数值误差）
- 后验求解残差 < 1e-6
- 相对误差 < 20%

**失败处理**：
- 数据质量问题：返回 Step 1 重新预处理
- 训练失败：调整参数后重试
- 物理约束违反：增加约束项重新训练
- 求解发散：调整求解器设置

## 回退策略

**失败时的替代方案**：
1. **PINN 反演失败**：改用传统优化方法（如伴随方法、遗传算法）
2. **数据不足**：使用迁移学习或数据增强
3. **计算资源不足**：使用降阶模型或代理模型
4. **物理约束难以满足**：采用弱约束形式或正则化方法
