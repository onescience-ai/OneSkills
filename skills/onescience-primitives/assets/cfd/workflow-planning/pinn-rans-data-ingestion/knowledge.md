# PINN湍流RANS均值流求解 - 数据接入与契约核验

## 适用范围

本步骤用于PINN湍流RANS均值流求解与闭合的数据接入阶段，负责接入RANS方程与稀疏均值流湍流数据，核验样本、变量、单位、网格坐标及许可，建立数据清单与机器可读契约。

**触发条件**：
- 具备RANS方程描述和稀疏均值流湍流数据
- 需要建立数据契约以支持后续建模

**不适用场景**：
- 数据已预处理且契约已建立的情况
- 纯数值模拟数据且无需契约核验的场景

## 输入

- **{DATASET_PATH}**：数据集路径（目录或清单文件）
- **{DATASET_NAME}**：数据集名称（来源与数据版本）
- **{DATA_CONTRACT}**：数据契约（变量单位网格定义）

## 输出

- **dataset_manifest.json**：数据清单（样本数、变量、坐标系等）
- **data_contract.json**：机器可读契约（变量定义、单位、坐标）
- **data_audit.md**：数据审计报告（缺失值、使用许可等）

## 流程节点

```
读取数据集 → 检查文件可读性 → 核验样本数 → 验证输入目标变量 → 检查单位坐标系 → 生成数据契约 → 输出审计报告
```

### 关键步骤说明

1. **读取数据集**：从{DATASET_PATH}读取{DATASET_NAME}
2. **检查文件可读性**：验证文件是否存在、格式是否正确
3. **核验样本数**：统计样本数量，确保数据完整
4. **验证输入目标变量**：检查变量名称、类型、范围
5. **检查单位坐标系**：验证物理量单位、坐标系定义
6. **生成数据契约**：按{DATA_CONTRACT}输出机器可读契约
7. **输出审计报告**：记录缺失值、使用许可等信息

## 边界与分流

**关键前提与改道**：

1. **前提：数据文件存在且可读**
   - 不成立时 → 返回BLOCKED并列出缺项，不得编造数据

2. **前提：必填输入变量完整**
   - 不成立时 → 返回BLOCKED并列出缺项

3. **前提：单位坐标定义完整**
   - 不成立时 → 返回BLOCKED并列出缺项

## 质量检查

- **数据文件可读且样本可追溯**：每个样本有唯一标识
- **输入目标变量单位坐标定义完整**：所有变量有明确单位和坐标
- **不存在训练测试泄漏**：数据切分前验证

## 回退策略

1. **数据文件不可读**：检查文件路径、权限、格式
2. **变量定义不完整**：参考领域标准补充定义
3. **单位不一致**：统一单位转换或标注
