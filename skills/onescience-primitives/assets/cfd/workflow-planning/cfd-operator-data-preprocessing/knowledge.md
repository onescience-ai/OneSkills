# 预处理与数据切分任务

## 适用范围

**触发条件**：
- 数据已通过契约核验（s01完成）
- 需要统一物理量表示
- 需要构造训练/验证/测试集切分

**适用场景**：
- 算子学习流程的数据准备阶段
- 多工况数据整合与标准化
- 物理场数据的训练集构建

**不适用场景**：
- 数据未通过核验
- 无函数配对数据
- 纯数据探索或可视化

## 输入

**必填输入**：
- {SPLIT_CONFIG}：切分配置（比例、分组策略、随机种子）
- {TARGET_FIELDS}：目标变量列表

**可选输入**：
- {NONDIMENSIONALIZE}：是否无量纲化（默认true）

**配置详情**：
- train比例：0.7
- validation比例：0.15
- test比例：0.15
- 分组策略：geometry_or_trajectory
- 随机种子：42

## 输出

**产物清单**：
- train_manifest.json：训练集清单
- validation_manifest.json：验证集清单
- test_manifest.json：测试集清单
- normalization.json：归一化统计量（均值、标准差、最小值、最大值）

**格式要求**：
- 清单包含样本索引、路径、元数据
- 统计量可逆变换支持

## 流程节点

### Step 1：物理量统一
- **操作**：统一物理量单位、表示格式
- **检查项**：单位一致、格式统一
- **质量门禁**：物理量表示统一

### Step 2：无量纲化处理
- **操作**：根据{NONDIMENSIONALIZE}决定是否无量纲化
- **参数**：参考尺度选择
- **质量门禁**：仅用训练集计算统计量

### Step 3：分组策略设计
- **操作**：按几何、工况或时间设计分组策略
- **检查项**：分组语义明确、无泄漏风险
- **质量门禁**：分组策略合理

### Step 4：无泄漏切分
- **操作**：按分组策略切分数据
- **检查项**：训练/验证/测试集无重叠
- **质量门禁**：三份切分的对象轨迹互斥

### Step 5：掩膜与边界处理
- **操作**：保存边界掩膜、处理特殊区域
- **检查项**：掩膜语义完整
- **质量门禁**：边界与掩膜语义未破坏

### Step 6：统计量保存
- **操作**：保存归一化统计量，支持可逆变换
- **输出**：normalization.json
- **质量门禁**：统计量可逆

## 关键参数

**切分配置**：

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| train比例 | 0.7 | 场景需求书 | 训练集比例 |
| validation比例 | 0.15 | 场景需求书 | 验证集比例 |
| test比例 | 0.15 | 场景需求书 | 测试集比例 |
| 分组策略 | geometry_or_trajectory | 场景需求书 | 按几何或轨迹分组 |
| 随机种子 | 42 | 场景需求书 | 可复现切分 |
| 无量纲化 | true | 场景需求书 | 默认开启 |

**质量门限**：

| 门限 | 值 | 说明 |
|------|-----|------|
| 切分互斥性 | 100% | 训练/验证/测试集无重叠 |
| 统计量来源 | 仅训练集 | 防止数据泄漏 |
| 掩膜完整性 | 100% | 边界语义未破坏 |

## 边界与分流

**异常处理**：
1. **切分比例不合法** → 调整比例至总和为1
2. **分组策略不可行** → 尝试其他分组维度
3. **存在轨迹泄漏** → 重新设计分组策略
4. **掩膜语义破坏** → 恢复掩膜并重新处理

**降级策略**：
- 无法按轨迹分组 → 按工况或时间分组
- 无量纲化失败 → 保留原始单位，标注未标准化

## 质量检查

**验证点**：
- 切分互斥性：训练/验证/测试集无重叠样本
- 统计量唯一性：仅用训练集计算归一化统计量
- 掩膜完整性：边界与掩膜语义未破坏
- 可逆性：归一化变换可逆

**失败处理**：
- 切分泄漏 → 重新设计分组策略
- 统计量污染 → 重新计算，仅用训练集
- 掩膜破坏 → 恢复原始掩膜
