# CFD数据集获取备用通道与降级策略

## 适用范围
当需要获取CFD数据集用于训练、验证或基准测试，但主要数据源（如AirfRANS、CFDBench）因网络问题、认证失败、下载错误等原因无法访问时使用本知识。适用于CFD机器学习、数据同化、代理模型训练等场景。不适用于实时CFD模拟或在线数据流处理。

## 输入
- 目标数据集名称和版本
- 网络环境信息（代理设置、防火墙限制）
- 认证信息（API密钥、登录凭证）
- 本地缓存状态

## 输出
- 备用数据获取方案列表
- 降级策略执行计划
- 合成数据生成规范（如需要）
- 数据获取状态报告

## 流程节点
1. 主要数据源尝试 → 2. 失败检测与诊断 → 3. 备用通道激活 → 4. 降级策略执行 → 5. 数据验证

每步含：
- **操作**：数据源尝试顺序、失败检测机制、备用通道选择
- **参数**：超时设置、重试次数、认证配置
- **工具**：wget/curl、Hugging Face Hub、本地文件系统
- **质量门禁**：数据完整性检查、许可证验证、训练测试泄漏检查

## 关键参数

### 通用判据（方法层，同类体系可参考）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 重试次数 | 3次 | 通用实践 | 网络请求失败时重试 |
| 超时时间 | 30秒 | 通用实践 | 单次请求超时 |
| 备用源优先级 | 镜像源→离线包→合成数据 | 通用实践 | 按可用性和数据质量排序 |

### 校准数值（体系专属值）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| AirfRANS主要源 | Hugging Face Hub | 任务需求 | 主要下载渠道 |
| CFDBench主要源 | 需要认证 | 任务需求 | 可能需要特殊权限 |

以下数值来自任务需求，供量级校准；其他体系需以自身证据重新锚定。

## 边界与分流
- **网络限制**：使用代理、镜像源或离线数据包
- **认证失败**：检查凭证、使用替代认证方式或联系数据提供者
- **数据损坏**：验证校验和、重新下载或使用备份
- **合成数据降级**：遵循物理一致性规范，确保数据可用于方法验证

## 质量检查
1. 数据完整性：文件大小、校验和验证
2. 许可证检查：确认数据使用许可
3. 泄漏检查：确保训练集和测试集无重叠
4. 物理合理性：合成数据需符合物理规律

## 回退策略
- 如果所有在线源失败，使用本地缓存或离线数据包
- 如果离线数据不可用，生成合成数据作为方法演示
- 如果合成数据无法满足需求，记录限制并降级任务状态

1. CFD数据集下载失败（网络错误、认证失败）
2. 需要设计数据获取的备用通道
3. 合成数据生成需要物理一致性指导
4. 数据获取流程需要鲁棒性设计
