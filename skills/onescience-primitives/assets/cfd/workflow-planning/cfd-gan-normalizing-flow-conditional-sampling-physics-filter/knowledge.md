# GAN与正规化流湍流降阶条件采样与物理一致性筛选

## 适用范围

本任务适用于 GAN 与正规化流湍流降阶生成的条件采样与物理筛选阶段，按工况生成多样流场样本并依据物理残差筛选，确保生成样本的物理一致性。

**触发条件**：
- 已通过 s03 模型训练
- 需要按工况生成多样化湍流场样本
- 需要评估生成样本的物理一致性

**不适用场景**：
- 模型权重不可用（需返回 s03）
- 仅需单次推理无筛选需求（直接使用推理引擎）

## 输入

**上游产物**：
- s03 产出的 best_checkpoint.pt

**参数**：
- 模型权重（{CHECKPOINT}，默认 best_checkpoint.pt）
- 计算设备（{DEVICE}，默认 cuda）
- 推理批大小（{BATCH_SIZE}，默认 8）

## 输出

**采样与筛选产物**：
- generated_samples/：生成的流场样本集
- physics_filter.json：物理筛选报告（通过率、剔除原因统计）
- distribution_metrics.json：分布覆盖评估指标

**验证标准**：
- 样本条件与随机种子可追溯
- 多样性和真实性同时评价
- 物理筛选前后统计均报告
- 禁止单个漂亮样本代表整体性能

## 流程节点

### 1. 条件采样
- **操作**：对每个测试条件生成多随机种子样本
- **参数**：模型权重、计算设备、推理批大小
- **工具**：推理引擎
- **质量门禁**：样本条件与随机种子可追溯

### 2. 物理量恢复
- **操作**：将生成结果恢复为物理量（逆归一化、单位转换）
- **参数**：归一化参数（normalization.json）
- **工具**：逆变换器
- **质量门禁**：物理量恢复正确

### 3. 物理残差计算
- **操作**：计算边界残差、守恒残差、控制方程残差
- **参数**：生成样本、物理量
- **工具**：物理残差计算器
- **质量门禁**：残差计算正确

### 4. 物理筛选
- **操作**：依据物理残差阈值剔除不合格样本
- **参数**：残差阈值
- **工具**：筛选器
- **质量门禁**：筛选前后统计均报告

### 5. 分布覆盖评估
- **操作**：评估生成样本对目标流场空间的覆盖程度
- **参数**：生成样本、真实数据
- **工具**：分布评估器
- **质量门禁**：多样性和真实性同时评价

## 边界与分流

**前提条件与改道**：

1. **模型权重可用**
   - 不成立时 → 改道：返回 s03 重新训练或加载其他检查点

2. **物理残差阈值合理**
   - 不成立时 → 改道：调整阈值或增强物理约束训练

3. **生成多样性充足**
   - 不成立时 → 改道：增加潜空间采样策略、调整生成器容量

4. **计算资源充足**
   - 不成立时 → 改道：减小推理批大小、分批采样

## 质量检查

**验证点**：
- 样本可追溯性检查（条件+随机种子唯一）
- 多样性评价（统计分布、方差分析）
- 物理筛选通过率统计
- 筛选前后分布对比
- 最差样本追溯

**阈值**：
- 物理筛选通过率 > 0（至少部分样本可用）
- 多样性指标在合理范围内
- 分布覆盖满足任务需求

**失败处理**：
- 通过率过低 → 放宽物理门限或增强物理约束
- 多样性不足 → 增加采样策略或调整潜空间
- 追溯失败 → 检查元数据记录逻辑

## 回退策略

**失败时的替代方案**：
1. 物理筛选全部不通过 → 放宽门限或回退到无筛选推理
2. 多样性严重不足 → 回退到数据增强或传统方法
3. 计算资源不足 → 降级采样数量或使用 CPU 推理
