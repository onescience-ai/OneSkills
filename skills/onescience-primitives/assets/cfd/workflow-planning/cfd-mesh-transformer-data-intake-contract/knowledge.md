# 数据接入与契约核验

## 适用范围

**触发条件**：
- 需要接入百万节点通用三维PDE网格数据
- 需要核验数据完整性、变量定义、单位和网格拓扑
- 需要输出机器可读的数据契约

**适用场景**：
- 大规模网格Transformer流场预测的数据准备阶段
- 任何需要对PDE网格数据进行质量检查和契约定义的场景

**不适用场景**：
- 已有成熟数据管道直接输出契约
- 小规模规则网格数据（简单检查即可）

## 输入

| 输入 | 类型 | 必填 | 说明 |
|------|------|------|------|
| {DATASET_PATH} | doc | 是 | 数据集路径（目录或清单文件） |
| {DATASET_NAME} | str | 是 | 数据集名称与版本 |
| {DATA_CONTRACT} | object | 否 | 预定义数据契约（含input_fields、target_fields、units、coordinates） |

**{DATA_CONTRACT}默认结构**：
```json
{
  "input_fields": [],
  "target_fields": [],
  "units": {},
  "coordinates": "dataset_native"
}
```

## 输出

| 输出 | 格式 | 说明 |
|------|------|------|
| dataset_manifest.json | JSON | 数据清单（文件列表、样本数、变量信息） |
| data_contract.json | JSON | 机器可读数据契约 |
| data_audit.md | Markdown | 人工可读审计报告 |

## 操作流程

### 1. 文件可读性检查
- 验证{DATASET_PATH}存在且可访问
- 识别数据格式（HDF5、NetCDF、NumPy等）
- 检查文件完整性（无损坏）

### 2. 样本统计
- 统计总样本数
- 识别输入变量和目标变量
- 记录变量维度和形状

### 3. 单位与坐标核验
- 检查变量单位定义
- 验证坐标系（笛卡尔/柱坐标/球坐标）
- 确认网格拓扑（非结构化/结构化）

### 4. 工况与时间范围
- 识别时间步或工况参数
- 检查缺失值分布
- 记录值域范围

### 5. 许可检查
- 检查数据使用许可
- 记录限制条件

### 6. 契约输出
- 按{DATA_CONTRACT}格式生成data_contract.json
- 输出dataset_manifest.json和data_audit.md

## 质量门禁

| 门禁 | 标准 | 失败处理 |
|------|------|----------|
| 文件可读 | 数据文件存在且可打开 | 返回BLOCKED，列出不可读文件 |
| 样本可追溯 | 每个样本有唯一标识 | 补充标识或标记 |
| 变量完整 | 输入和目标变量均有定义 | 列出缺失变量 |
| 单位定义 | 所有变量有单位 | 标注单位缺失 |
| 坐标完整 | 网格坐标有定义 | 标注坐标缺失 |
| 无泄漏 | 训练测试无重叠 | 标记潜在泄漏 |

## 边界与分流

| 情况 | 处理方式 |
|------|----------|
| 缺少必填输入 | 返回BLOCKED并列出缺项 |
| 数据格式未知 | 尝试常见格式解析，失败则标注 |
| 单位缺失 | 标注"单位待确认"，不编造 |
| 网格拓扑不清 | 标注"拓扑待确认"，不推断 |
| 许可不明 | 标注"许可待确认"，不假设可用 |

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必填输入 | DATASET_PATH, DATASET_NAME | [场景需求书] | 缺少即BLOCKED |
| 坐标默认 | dataset_native | [场景需求书] | 使用数据集原生坐标 |
| 许可检查 | 必须 | [场景需求书] | 不得忽略许可 |

### 校准数值

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据规模 | 百万节点级 | [场景需求书] | 以下数值来自CFD_S006场景，供量级校准；其他体系需以自身证据重新锚定 |
| 数据格式 | 待确认 | [场景需求书] | 需根据实际数据集确定 |

## 回退策略

1. **文件不可读**：检查路径权限，尝试替代读取方式
2. **格式未知**：使用通用解析器尝试，失败则标注
3. **变量缺失**：列出已有变量，标注缺失项
4. **许可限制**：记录限制条件，不编造许可
