# 代理模型评估与适用域判定

## 适用范围

**触发条件**：
- 需要评估CFD代理模型的性能
- 需要判定模型的适用域
- 需要识别域外工况并建议CFD复核

**适用场景**：
- 汽车气动代理模型工程验收
- 模型泛化能力评估
- 域外工况识别与风险控制

**不适用场景**：
- 模型训练过程中的内部验证
- 无需工程验收的研究探索

## 输入

**数据需求**：
- 测试集预测结果
- 测试集真实值
- 数据契约与归一化统计量
- 验收指标配置

**数据格式**：
- 预测结果：NumPy数组或类似格式
- 真实值：与预测结果格式一致
- 配置：JSON格式

## 输出

**产物清单**：
- evaluation.json：评估结果
- worst_cases.csv：最差样本
- applicability_report.md：适用域报告
- PASS_REJECT_BLOCKED.txt：验收判定

**验证标准**：
- 统计与物理指标同时报告
- 最差样本可追溯
- 结论含适用域限制与复核建议

## 流程节点

### Step 1：统计误差评估
- **操作**：计算逐变量误差指标（relative_L2, RMSE等）
- **参数**：预测结果、真实值、验收指标
- **工具**：误差计算
- **质量门禁**：误差指标计算正确

### Step 2：物理约束检查
- **操作**：检查守恒残差、边界误差等物理约束
- **参数**：预测结果、物理约束定义
- **工具**：物理检查
- **质量门禁**：物理约束满足工程精度要求

### Step 3：泛化能力评估
- **操作**：评估模型在域外工况下的泛化能力
- **参数**：测试集、OOD测试配置
- **工具**：泛化评估
- **质量门禁**：域外工况识别准确

### Step 4：最差样本分析
- **操作**：识别并分析最差样本
- **参数**：误差指标、样本信息
- **工具**：样本分析
- **质量门禁**：最差样本可追溯

### Step 5：适用域判定
- **操作**：综合评估结果判定适用域
- **参数**：评估结果、物理门限
- **工具**：判定逻辑
- **质量门禁**：结论含适用域限制与复核建议

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 验收指标 | "relative_L2, RMSE, conservation_residual, boundary_error" | [场景需求书] | 统计与物理约束指标 |
| 相对误差门限 | 0.1 | [场景需求书] | 默认测试集放行阈值 |
| 外推测试 | true | [场景需求书] | 默认执行外推测试 |

## 边界与分流

**异常处理**：
- 误差指标超出门限 → 给出REJECT判定
- 物理约束不满足 → 给出REJECT或BLOCKED判定
- 域外工况无法识别 → 标记为适用域不确定

**降级策略**：
- 统计指标不足时补充物理指标
- 物理约束不明确时标记为待确认
- 域外工况识别困难时建议全面CFD复核

**分支条件**：
- 若{RUN_OOD_TEST}为true，执行几何或工况外推测试
- 若统计与物理指标不同时满足，给出PASS、REJECT或BLOCKED判定

## 质量检查

**验证点**：
- 统计误差：计算正确、门限满足
- 物理约束：检查完整、精度满足
- 泛化能力：评估全面、识别准确
- 最差样本：可追溯、分析完整
- 适用域：判定合理、建议明确

**阈值**：
- 相对L2误差：≤ 0.1（默认）
- 守恒残差：物理可接受范围
- 边界误差：工程精度要求

**失败处理**：
- 任一检查不满足则给出REJECT或BLOCKED
- 最差样本需单独分析并追溯原因
- 适用域报告需明确域外工况识别标准

## 回退策略

**验收不通过**：
- 分析最差样本特征
- 检查物理约束满足情况
- 评估是否需要更多训练数据或调整模型架构

**适用域不确定**：
- 建议全面CFD复核
- 标记为适用域不确定
- 提供详细风险评估

**外推测试失败**：
- 检查OOD测试配置
- 调整外推范围
- 回退到内插测试
