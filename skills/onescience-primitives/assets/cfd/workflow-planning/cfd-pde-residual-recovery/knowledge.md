# PDE Residual Recovery

## 适用范围
面向符号与稀疏PDE发现任务的方程求解与物理残差恢复步骤。加载训练好的模型权重，在查询配点或网格上恢复解场、导数、边界值与方程残差，用于后续物理一致性评估。

## 输入
- **模型权重**（必填）：通过训练门限的best_checkpoint.pt。
- **计算设备**（必填）：CPU或CUDA设备标识。
- **推理批大小**（可选）：按显存调整的批量大小。
- **测试参数与边界**（来自s01）：测试集的坐标、边界条件。

## 输出
- **solution_fields/**：解场文件目录，含各物理量的空间-时间分布。
- **pde_residuals/**：PDE残差场文件目录，含方程各阶导数残差。
- **boundary_residuals.csv**：边界条件逐项残差记录。

## 流程节点
```
1. 加载{CHECKPOINT}权重
2. 在测试参数、边界和查询坐标上求解目标PDE
3. 使用自动微分或离散算子恢复导数
4. 计算通量和方程残差
5. 保存解场与残差场
6. 汇总边界残差
```

## 边界与分流
- **权重加载失败**：检查checkpoint文件完整性和模型架构匹配。
- **导数非有限值**：检查自动微分设置，切换至有限差分验证。
- **残差异常大**：检查模型是否过拟合或数据预处理是否正确。
- **无独立解对照**：使用已发表数值解或解析解进行基准对比，若均无则标注"无独立对照"。

## 质量检查
1. 解场导数与残差均为有限值。
2. 边初值逐项满足门限。
3. solution_fields/目录结构完整。
4. boundary_residuals.csv可读且逐项列出。
5. 可选：与独立数值解或解析解对照通过。

## 回退策略
- 自动微分失败：切换至有限差分或离散算子。
- 内存不足：减小推理批大小。
- 残差异常：回退至s03检查训练质量。
