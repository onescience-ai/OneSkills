# 物理约束神经算子学习工作流

## 适用范围
面向带守恒边界和无量纲约束PDE数据的物理约束神经算子学习标准工作流，覆盖从数据接入到适用域判定的完整闭环。适用于Physics-constrained neural operator训练任务，核心流程包括数据契约核验、预处理切分、物理约束模型训练、推理物理恢复和验收评估。工作流强调物理一致性验证，要求同时报告统计误差和物理约束指标。

## 输入
- **PDE数据集**：包含带守恒边界和无量纲约束的PDE数据
- **数据契约**：定义变量单位、网格坐标、边界条件类型和守恒律约束
- **训练配置**：神经算子架构参数、学习率、批次大小等超参数
- **验收指标**：统计误差（relative_L2, RMSE）和物理约束（conservation_residual, boundary_error）

## 输出
- **训练好的物理约束神经算子**：可复现的模型checkpoint
- **物理一致性评估报告**：包含边界误差、守恒残差、无量纲不变量偏差等指标
- **适用域报告**：明确模型在几何、工况、参数空间上的适用范围和限制
- **域外工况复核建议**：超出适用域时需经CFD复核的明确指示

## 流程节点
### s01: 数据接入与契约核验
- **操作**：接入带守恒边界和无量纲约束PDE数据，核验样本、变量、单位、网格坐标及许可
- **输入**：{DATASET_PATH}, {DATASET_NAME}, {DATA_CONTRACT}
- **输出**：dataset_manifest.json, data_contract.json, data_audit.md
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏

### s02: 预处理与数据切分
- **操作**：统一物理量与表示，按几何、工况或时间构造无泄漏切分
- **输入**：{SPLIT_CONFIG}, {TARGET_FIELDS}, {NONDIMENSIONALIZE}
- **输出**：train_manifest.json, validation_manifest.json, test_manifest.json, normalization.json
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏

### s03: 模型配置与训练
- **操作**：训练Physics-constrained neural operator完成指定输入到目标物理量的映射
- **输入**：{MODEL_NAME}, {TRAIN_CONFIG}, {INIT_CHECKPOINT}
- **输出**：best_checkpoint.pt, train_config.json, training_metrics.csv, environment.txt
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现

### s04: 批量推理与物理恢复
- **操作**：在独立测试集推理，恢复原始单位、网格和物理派生量
- **输入**：{CHECKPOINT}, {DEVICE}, {BATCH_SIZE}
- **输出**：predictions/, inference_manifest.json, timing.csv
- **质量门禁**：预测无NaN或Inf且形状单位正确；每个测试样本有唯一结果；推理未使用测试目标校正

### s05: 任务验收与适用域判定
- **操作**：评估统计误差、关键物理约束、泛化能力和计算收益
- **输入**：{METRICS}, {MAX_RELATIVE_L2}, {RUN_OOD_TEST}
- **输出**：evaluation.json, worst_cases.csv, applicability_report.md, PASS_REJECT_BLOCKED.txt
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议

## 边界与分流
- **数据契约不完整** → 返回BLOCKED，列出缺项，不得编造数据
- **边界条件类型未知** → 转向通用PDE数据预处理流程，需人工确认边界条件类型
- **守恒律约束不明确** → 转向无物理约束的纯数据驱动神经算子学习，但需在适用域报告中声明物理一致性未保证
- **训练不收敛** → 调整学习率、增加训练轮次、检查数据质量
- **推理异常值** → 检查数据预处理、模型权重、计算设备
- **物理约束不满足** → 降低物理约束权重，转向软约束而非硬约束
- **域外工况** → 超出适用域时，必须经CFD复核，不得直接使用模型预测

## 质量检查
- **数据完整性检查**：文件可读、样本可追溯、变量单位坐标定义完整
- **切分有效性检查**：训练/验证/测试集对象轨迹互斥，无泄漏
- **训练稳定性检查**：训练验证损失均为有限值，最佳权重可重新加载，随机种子可复现
- **推理正确性检查**：预测无NaN/Inf且形状单位正确，每个测试样本有唯一结果
- **物理一致性检查**：边界误差、守恒残差、无量纲不变量偏差满足物理门限
- **适用域明确性检查**：结论含适用域限制与复核建议，不得仅凭平均误差宣称工程可用

## 回退策略
- **物理约束无法满足** → 降低物理约束权重，转向软约束（损失惩罚）而非硬约束（架构约束）
- **训练不收敛** → 调整学习率、增加训练轮次、检查数据质量
- **泛化能力不足** → 增加训练数据多样性，引入数据增强或迁移学习
- **计算资源不足** → 降低模型复杂度或使用近似推理方法
