# OpenFOAM多孔介质CFD求解器配置指南

## 适用范围

面向多孔介质CFD求解任务，定义OpenFOAM求解器的安装配置流程。适用于需要在OpenFOAM中设置多孔介质区域并配置Darcy/Forchheimer阻力模型的CFD仿真任务。不适用于非OpenFOAM求解器或多孔介质以外的CFD任务。

## 输入

- 任务目标：配置OpenFOAM进行多孔介质CFD仿真
- 数据需求：几何模型、边界条件、材料属性、求解器参数
- 格式要求：OpenFOAM字典文件格式

## 输出

- OpenFOAM案例目录结构
- 网格文件（blockMeshDict/snappyHexMeshDict）
- 求解器配置文件（simpleFoam/pimpleFoam）
- 后处理结果（ParaView文件）

## 流程节点

1. **安装OpenFOAM** → 2. **创建案例目录** → 3. **生成网格** → 4. **配置求解器** → 5. **运行仿真** → 6. **后处理分析**

### 步骤1：安装OpenFOAM
- 操作：安装OpenFOAM求解器和ParaView后处理工具
- 参数：OpenFOAM版本、操作系统兼容性
- 工具：包管理器、源码编译
- 质量门禁：安装成功，命令可执行

### 步骤2：创建案例目录
- 操作：创建标准OpenFOAM案例目录结构
- 参数：案例名称、目录路径
- 工具：mkdir命令
- 质量门禁：目录结构完整，符合OpenFOAM规范

### 步骤3：生成网格
- 操作：使用blockMesh或snappyHexMesh生成网格
- 参数：几何尺寸、网格分辨率、边界类型
- 工具：blockMesh/snappyHexMesh
- 质量门禁：网格质量良好，无负体积

### 步骤4：配置求解器
- 操作：配置simpleFoam/pimpleFoam求解器参数
- 参数：湍流模型、离散格式、收敛判据
- 工具：OpenFOAM字典文件
- 质量门禁：配置合理，符合物理实际

### 步骤5：运行仿真
- 操作：执行CFD仿真
- 参数：时间步长、最大迭代次数、输出频率
- 工具：simpleFoam/pimpleFoam
- 质量门禁：仿真收敛，残差下降

### 步骤6：后处理分析
- 操作：使用ParaView进行可视化分析
- 参数：可视化变量、视图设置、动画输出
- 工具：ParaView
- 质量门禁：结果可视化清晰，物理意义明确

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 求解器选择 | simpleFoam/pimpleFoam | [OpenFOAM] | 稳态/瞬态选择 |
| 湍流模型 | k-ε/k-ω SST | [领域标准] | 根据流动特性选择 |
| 离散格式 | 二阶迎风 | [领域标准] | 精度与稳定性平衡 |
| 收敛判据 | 残差<1e-4 | [领域标准] | 一般收敛标准 |
| 多孔介质模型 | Darcy/Forchheimer | [领域标准] | 根据Reynolds数选择 |

### 校准数值（体系专属值）

以下数值来自典型多孔介质CFD仿真，供量级校准；其他体系需以自身证据重新锚定：

| 参数 | 典型值 | 来源 | 说明 |
|------|--------|------|------|
| 网格分辨率 | 1e-4 ~ 1e-3 m | [典型值] | 孔隙尺度网格 |
| 时间步长 | 1e-3 ~ 1e-1 s | [典型值] | 根据CFL条件调整 |
| 最大迭代次数 | 1000 ~ 5000 | [典型值] | 根据收敛情况调整 |
| 残差收敛标准 | 1e-4 ~ 1e-6 | [典型值] | 根据精度要求调整 |
| Darcy阻力系数 | 1e-8 ~ 1e-4 m² | [典型值] | 根据渗透率调整 |

## 边界与分流

### 前提1：OpenFOAM已正确安装
- **不成立时转向**：使用其他CFD求解器（如ANSYS Fluent、COMSOL），或联系管理员安装OpenFOAM

### 前提2：几何模型可导入
- **不成立时转向**：使用blockMesh创建简单几何，或使用snappyHexMesh从STL文件生成网格

### 前提3：计算资源充足
- **不成立时转向**：减少网格分辨率，或使用并行计算

## 质量检查

1. **安装验证**：检查OpenFOAM命令是否可执行
2. **网格质量**：检查网格质量指标（正交性、偏斜度等）
3. **收敛性验证**：检查残差曲线是否单调下降
4. **质量守恒**：检查进出口流量是否守恒
5. **物理合理性**：检查速度、压力分布是否合理

## 回退策略

1. **安装失败**：使用Docker容器或联系管理员
2. **网格质量差**：调整网格参数，重新生成网格
3. **不收敛**：调整求解器参数，或使用更稳定的离散格式
4. **质量不守恒**：检查边界条件，修正入口流量
