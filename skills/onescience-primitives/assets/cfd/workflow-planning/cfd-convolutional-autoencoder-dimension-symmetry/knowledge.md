# 卷积自编码器编解码维度对称性约束

## 适用范围
适用于所有基于Conv2d/ConvTranspose2d的编解码架构，核心约束为总stride乘积×特征图尺寸+累计padding/output_padding偏移必须等于输入尺寸。当输入尺寸(H,W)经stride=2的Conv2d逐层下采样后，编码器末层特征图尺寸为(H//2^n, W//2^n)，解码器必须通过对应的ConvTranspose2d恢复到原始尺寸。

## 输入
- 输入张量尺寸：(batch_size, channels, H, W)
- 编码器结构：多层Conv2d(stride=2)逐层下采样
- 解码器结构：多层ConvTranspose2d(stride=2)逐层上采样
- 目标输出尺寸：与输入尺寸完全一致

## 输出
- 编解码器维度匹配的自编码器架构
- 验证通过的forward pass
- 维度计算验证脚本

## 流程节点
1. **编码器尺寸计算** → 逐步计算每层Conv2d输出尺寸
2. **解码器尺寸逆推** → 从编码器末层尺寸逆推每层ConvTranspose2d输出尺寸
3. **维度对称性验证** → 确保解码器最终输出等于编码器输入
4. **奇数维度处理** → 对奇数维度输入添加自适应池化或调整kernel_size/stride
5. **Forward Pass测试** → 用实际输入tensor验证输出shape与输入shape一致

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 总stride乘积 | 2^n | 编码器层数决定 | 每层stride=2，n层总stride=2^n |
| 编码器末层尺寸 | (H//2^n, W//2^n) | 数学推导 | 向下取整 |
| 解码器目标尺寸 | (H, W) | 输入尺寸 | 必须完全匹配 |
| 奇数维度处理 | 自适应池化或调整kernel_size | 实践经验 | 当H或W为奇数时需要特殊处理 |

### 校准数值
以下数值来自CFD_S087任务，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 输入尺寸 | (3, 172, 79) | CFD_S087任务 | 奇数宽度需要特殊处理 |
| 编码器层数 | 4层 | CFD_S087任务 | 每层stride=2 |
| 末层特征图尺寸 | (11, 5) | 计算：172//16=10.75→11, 79//16=4.9375→5 | 向下取整 |
| 解码器输出尺寸 | (3, 176, 80) | CFD_S087任务实际输出 | 与输入不匹配导致错误 |

## 边界与分流
- **偶数维度输入**：标准stride=2下采样/上采样，无需特殊处理
- **奇数维度输入**：需要添加自适应池化层或调整kernel_size/stride，确保最终输出尺寸匹配
- **多层下采样**：需逐层验证尺寸计算，确保每层输出尺寸正确
- **非2的幂次下采样**：需要更复杂的尺寸计算和对称性验证

## 质量检查
- 用实际输入tensor执行forward pass，断言输出shape与输入shape一致
- 验证编码器各层输出尺寸计算正确
- 验证解码器各层输出尺寸逆推匹配
- 检查奇数维度输入的处理是否正确

## 回退策略
- 若维度不匹配，检查编码器和解码器的层数是否对称
- 若奇数维度导致问题，尝试添加自适应池化层
- 若kernel_size/stride不匹配，调整解码器的output_padding参数
