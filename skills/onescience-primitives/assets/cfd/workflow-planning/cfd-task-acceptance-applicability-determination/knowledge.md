# 任务验收与适用域判定

## 适用范围
适用于所有需要评估贝叶斯PINN模型性能并确定适用边界的场景，包括流体力学、热传导、反应扩散等问题。该步骤确保模型满足工程要求，明确适用范围。

## 输入
- **验收指标**：统计和物理指标，包括相对L2误差、PDE残差、边界误差、守恒误差。
- **相对误差门限**：测试集放行阈值。
- **是否外推测试**：测试域外工况。

## 输出
- **evaluation.json**：评估结果。
- **worst_cases.csv**：最差样本。
- **applicability_report.md**：适用域报告。
- **PASS_REJECT_BLOCKED.txt**：验收结论。

## 流程节点
1. **计算统计误差**：计算逐变量误差。
2. **计算物理约束误差**：计算边界误差、守恒或方程残差。
3. **识别最差样本**：找出表现最差的样本。
4. **计算推理成本**：计算推理时间和资源消耗。
5. **外推测试**：测试几何或工况外推性能。
6. **确定适用域**：明确模型适用范围。
7. **给出验收结论**：给出PASS、REJECT或BLOCKED结论。

每步含：操作、参数、工具、质量门禁。

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 验收指标 | 相对L2误差、PDE残差、边界误差、守恒误差 | [1] | 多指标综合评估 |
| 相对误差门限 | 0.1 | [1] | 测试集放行阈值 |
| 外推测试 | true | [1] | 测试域外工况 |
| 统计与物理指标同时报告 | true | [1] | 避免仅凭平均误差宣称工程可用 |
| 最差样本可追溯 | true | [1] | 便于分析模型弱点 |
| 结论含适用域限制与复核建议 | true | [1] | 明确模型适用范围 |

## 边界与分流
- **误差超标**：拒绝模型并返回改进建议。
- **外推性能差**：限制适用域并建议CFD复核。
- **计算成本过高**：考虑简化模型或使用近似方法。

## 质量检查
- **统计与物理指标同时报告**：避免仅凭平均误差宣称工程可用。
- **最差样本可追溯**：便于分析模型弱点。
- **结论含适用域限制与复核建议**：明确模型适用范围。

## 回退策略
- **验收失败**：返回改进方向并重新训练。
- **适用域不明**：进行更广泛的测试。
- **计算成本过高**：使用模型压缩或近似方法。

## 资源召回建议
- **召回时机**：当用户需要评估模型性能或确定适用边界时。
- **配套资源**：
  - `cfd-equation-solving`：方程求解。
  - `cfd-model-training`：模型训练。
