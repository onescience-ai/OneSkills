# 多保真代理建模

## 适用范围

多保真代理建模用于融合不同精度级别的仿真数据（如低保真XFOIL与高保真RANS），构建能够预测高保真响应的代理模型，显著降低气动优化中的计算成本。本卡片覆盖多保真高斯过程、神经网络多保真方法、保真度间相关性建模与不确定性量化技术，适用于翼型优化、气动外形设计、不确定性传播分析等需要平衡精度与效率的场景。

## 输入

- **低保真数据**：快速但精度较低的仿真结果（如XFOIL、Panel Method、低分辨率网格RANS）
- **高保真数据**：高精度但计算昂贵的仿真结果（如细网格RANS、LES、实验数据）
- **输入空间定义**：设计变量及其范围，不同保真度可能使用不同参数化 [2]
- **保真度标签**：每个数据点对应的保真度级别（如 0=低保真，1=高保真）
- **目标变量**：气动力系数（CL、CD）或流场量（压力、速度）

## 输出

- **代理模型**：可预测任意设计点高保真响应的数学模型
- **预测均值与方差**：点预测及其不确定性估计
- **保真度间相关性函数**：描述低保真与高保真响应关系的数学表达
- **主动学习采样建议**：下一步应评估的设计点（不确定性触发）
- **模型精度评估**：RMSE、R²、交叉验证误差等指标

## 流程节点

### 1. 多保真数据收集
- **低保真采样**：使用拉丁超立方采样（LHS）生成初始设计点，XFOIL评估 ~0.01s/点
- **高保真采样**：对低保真采样点的子集进行RANS评估 ~10-1000s/点
- **数据对齐**：确保不同保真度在相同设计点或可映射设计点上有观测
- **质量门禁**：最小高保真样本数 > 5×设计变量维度，数据无异常值

### 2. 保真度相关性建模
- **线性自回归模型**：高保真 = ρ × 低保真 + 噪声，ρ 为相关系数
- **非线性自回归模型**：高保真 = f(低保真) + 噪声，f 为非线性映射
- **Co-Kriging**：同时建模两个保真度的空间相关性，使用交叉协方差函数 [2]
- **深度高斯过程**：使用多层GP捕获非线性保真度关系 [3]
- **质量门禁**：相关系数 |ρ| > 0.5（线性模型），或非线性映射R² > 0.7

### 3. 代理模型训练
- **核函数选择**：Matérn 5/2（气动响应）、RBF（光滑响应）、周期核（周期性工况）
- **超参数优化**：最大似然估计（MLE）或最大后验估计（MAP）
- **不确定性量化**：预测方差 = 模型不确定性 + 噪声方差
- **质量门禁**：超参数收敛，负对数似然 < 阈值

### 4. 主动学习采样
- **不确定性触发**：当预测方差 > 阈值时，将该设计点加入高保真评估队列
- **精英保留**：当前最优候选必须进行高保真验证 [1]
- **同步采样**：批量评估多个设计点以利用并行计算资源
- **质量门禁**：高保真评估占比 < 30%（相比纯高保真优化）

### 5. 模型验证与部署
- **交叉验证**：K折交叉验证评估模型泛化能力
- **独立测试集**：保留10-20%数据作为测试集
- **预测精度**：RMSE < 5% 目标变量范围，R² > 0.9
- **质量门禁**：模型在设计空间边界处的预测不确定性 < 内部区域的2倍

## 边界与分流

- **保真度相关性弱**：当 |ρ| < 0.3 时，多保真建模收益有限，建议使用单保真高保真代理
- **设计空间差异大**：不同保真度使用不同参数化时，需使用MF-DGP等支持不同输入域的方法 [3]
- **计算预算极小**：当高保真预算 < 10次时，建议使用纯低保真优化或实验设计
- **模型过拟合**：增加正则化、减少模型复杂度或使用集成方法

## 质量检查

- **数据质量**：无异常值、无缺失值、保真度标签正确
- **模型精度**：交叉验证R² > 0.9，测试集RMSE < 5%
- **不确定性校准**：预测区间覆盖率与置信水平一致（如95%区间应覆盖~95%测试点）
- **计算效率**：高保真评估占比 < 30%，总计算时间 < 纯高保真优化的50%

## 回退策略

- **模型训练失败**：降低模型复杂度、增加高保真样本或使用更简单核函数
- **主动学习不收敛**：放宽停止条件、增加最大迭代次数或使用随机采样替代
- **预测精度不足**：增加训练数据、调整超参数或使用集成代理模型
