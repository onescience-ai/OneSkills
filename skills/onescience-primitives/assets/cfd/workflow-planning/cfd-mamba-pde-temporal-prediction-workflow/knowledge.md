# Mamba状态空间神经算子时序预测工作流

## 适用范围

**触发条件**：
- 用户需要端到端执行Mamba/SSM神经算子的PDE时序预测任务
- 从原始PDE轨迹数据到最终验收报告的完整流水线

**适用场景**：
- 流体力学时间依赖PDE的替代模型构建
- 需要可复现、可追踪的完整训练-推理-评估流水线
- 需要物理约束验收的工程应用场景

**不适用场景**：
- 仅需单项任务（如仅训练、仅评估）的场景——应直接召回对应task卡
- 数据尚未就绪的场景——需先完成数据准备

## 输入

- 时间依赖PDE轨迹数据集路径 `{DATASET_PATH}`
- 数据集名称 `{DATASET_NAME}`
- 可选数据契约 `{DATA_CONTRACT}`
- 模型名称（默认Mamba Neural Operator / State-space operator）
- 训练配置 `{TRAIN_CONFIG}`
- 验收指标 `{METRICS}`

## 输出

- 训练好的模型权重 `best_checkpoint.pt`
- 完整评估报告 `evaluation.json`, `applicability_report.md`
- 判定结论 `PASS_REJECT_BLOCKED.txt`
- 全流程产物清单

## 流程节点

```
s01 数据接入与契约核验
  ↓
s02 预处理与数据切分
  ↓
s03 模型配置与训练
  ↓
s04 批量推理与物理恢复
  ↓
s05 任务验收与适用域判定
```

### s01 → s02：数据就绪后进入预处理
- s01产出 data_contract.json 作为 s02 的输入契约
- 质量门禁：数据可读、变量完整、无泄漏

### s02 → s03：切分完成后进入训练
- s02产出 normalization.json 和切分manifest 作为 s03 的数据源
- 质量门禁：三份切分互斥、统计量仅来自训练集

### s03 → s04：训练完成后进入推理
- s03产出 best_checkpoint.pt 作为 s04 的权重输入
- 质量门禁：权重可加载、配置可复现

### s04 → s05：推理完成后进入验收
- s04产出预测结果 作为 s05 的评估输入
- 质量门禁：预测无NaN/Inf、形状正确

## 关键参数

### 工作流级参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 框架 | PyTorch | [1][2] | 所有基准测试均使用PyTorch |
| 默认epochs | 100 | 场景需求书 | 可根据收敛情况调整至500 |
| 默认batch_size | 8 | 场景需求书 | 受限于GPU显存 |
| 默认学习率 | 0.001 | [2] | AdamW, weight_decay=1e-4 |
| 随机种子 | 42 | 场景需求书 | 确保可复现 |
| early_stopping_patience | 15 | 场景需求书 | 防止过拟合 |
| 相对L2门限 | 0.1 | 场景需求书 | 测试集放行阈值 |

### 模型架构参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| SSM类型 | S4D（对角化） | [2] | 计算效率最优 |
| 扫描方向 | 双向 | [1][2] | 必须双向，单向性能下降10x |
| d_state | 16–64 | [1][2] | 16为性价比最优，64为精度最优 |
| ssm_ratio | 2 | [1] | SSM分支通道比例 |
| 阻尼 | 自适应学习 | [2] | ρ_k>0，核定位自适应 |
| 频率 | 自适应学习 | [2] | ω_k可学习，数据驱动频谱选择 |
| 记忆窗口K | 4 | [2] | 时序S4层窗口大小 |
| 时序层位置 | stack中部 | [2] | 放在空间层中间 |

## 边界与分流

- 数据不完整（缺字段/缺时间步）→ 返回BLOCKED并列出缺项
- 训练不收敛 → 降低lr、增加轮数、检查数据质量
- 推理NaN/Inf → 检查反归一化、权重加载、输入数据
- 外推误差过大 → 明确标注适用域，建议CFD复核

## 质量检查

- 每步输出文件存在且格式正确
- 训练曲线收敛（验证损失下降）
- 最佳权重可重新加载
- 评估指标同时包含统计和物理指标
- 最差样本可追溯
- 结论含适用域限制
