# 自然梯度优化器在PINN训练中的实现

## 适用范围

**触发条件**：
- PINN训练中梯度下降收敛缓慢，需要加速收敛
- 参数空间曲率不一致导致训练不稳定
- 多目标损失函数中不同损失分量梯度尺度差异大

**适用场景**：
- PINN求解偏微分方程的训练优化
- 多目标损失函数的平衡优化
- 参数量适中的神经网络训练

**不适用场景**：
- 参数量极大的网络（>1M参数），需使用近似方法
- 非概率模型需要经验Fisher近似

## 输入

- **模型参数** θ：神经网络权重
- **损失函数** L(θ)：包含PDE残差、边界残差、初始条件残差等多个分量
- **梯度** g = ∇L(θ)：损失函数对参数的梯度

## 输出

- **参数更新方向** Δθ = F^{-1} * g：自然梯度预处理后的更新方向
- **更新后的参数** θ_new = θ - lr * Δθ

## 流程节点

### 步骤1：计算梯度
- **操作**：通过反向传播计算损失函数对每个参数的梯度
- **参数**：损失函数各分量
- **工具**：自动微分（torch.autograd）
- **质量门禁**：梯度非NaN/Inf

### 步骤2：估计Fisher信息矩阵
- **操作**：构建Fisher信息矩阵F的近似
- **参数**：近似方法选择（对角/块对角/KFAC）
- **工具**：梯度外积累积
- **质量门禁**：Fisher矩阵正定

### 步骤3：求解线性系统
- **操作**：求解(F + λI)Δθ = g
- **参数**：阻尼项λ（防止Fisher矩阵奇异）
- **工具**：线性代数求解器
- **质量门禁**：解存在且唯一

### 步骤4：参数更新
- **操作**：更新参数 θ_new = θ - lr * Δθ
- **参数**：学习率lr
- **工具**：优化器step方法
- **质量门禁**：损失函数下降

## 关键参数

### 通用判据（方法层，同类体系可参考）

## 边界与分流

**前提1：参数量适中（<100K参数）**
- 不成立时转向：使用KFAC或EKFAC等高效近似方法

**前提2：Fisher矩阵正定**
- 不成立时转向：加入阻尼项λI，或使用伪逆

**前提3：计算资源充足**
- 不成立时转向：使用一阶优化器（如Adam）作为替代

## 质量检查

**验证点**：
- Fisher矩阵近似值的正定性和条件数
- 训练损失下降速度和最终精度
- 与一阶优化器的对比结果

**阈值**：
- Fisher矩阵条件数 < 1e6
- 相对L2误差 < 10%（对于简单PDE）
- 收敛速度提升 > 2倍

**失败处理**：
- Fisher矩阵奇异：增加阻尼项λ
- 收敛缓慢：调整学习率或Fisher近似方法
- 内存不足：使用更粗糙的近似（如对角近似）

## 回退策略

**失败时的替代方案**：
- 自然梯度实现复杂：使用Adam优化器作为基准
- Fisher矩阵计算开销大：使用对角近似或经验Fisher
- 收敛效果不佳：尝试不同的阻尼项λ或学习率
