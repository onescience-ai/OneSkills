# GAN与正规化流湍流降阶预处理与数据切分

## 适用范围

本任务适用于 GAN 与正规化流湍流降阶生成的预处理阶段，依据 s01 数据契约完成质控、重采样、掩膜、归一化或无量纲化，并按几何、完整轨迹或物理工况为单位构造无泄漏切分。

**触发条件**：
- 已通过 s01 数据接入与契约核验
- 需要统一物理量与表示
- 需要构造无泄漏的训练/验证/测试切分

**不适用场景**：
- 数据契约未建立（需返回 s01）
- 数据质量严重不达标且无法修复

## 输入

**上游产物**：
- s01 产出的 data_contract.json（变量定义、单位、坐标系）

**参数**：
- 切分配置（{SPLIT_CONFIG}）：train:0.7, validation:0.15, test:0.15, seed:42, group_by: geometry_or_trajectory
- 目标变量（{TARGET_FIELDS}）
- 是否无量纲化（{NONDIMENSIONALIZE}，默认 true）

## 输出

**切分产物**：
- train_manifest.json：训练集清单
- validation_manifest.json：验证集清单
- test_manifest.json：测试集清单
- normalization.json：归一化/无量纲化参数（保存可逆变换）

## 流程节点

### 1. 质控
- **操作**：检查数据质量、处理缺失值和异常值
- **参数**：数据契约
- **工具**：质控脚本
- **质量门禁**：数据质量满足训练要求

### 2. 归一化/无量纲化
- **操作**：对目标变量进行统一物理量表示，保存变换参数
- **参数**：目标变量、无量纲化选项
- **工具**：归一化工具
- **质量门禁**：变换可逆、统计量仅用训练集计算

### 3. 无泄漏切分
- **操作**：按几何、完整轨迹或物理工况为单位切分，禁止把同一轨迹的帧随机打散
- **参数**：切分配置、group_by 策略
- **工具**：切分工具
- **质量门禁**：三份切分的对象轨迹互斥

### 4. 统计量保存
- **操作**：保存归一化/无量纲化参数用于逆变换
- **参数**：训练集统计量
- **工具**：参数保存器
- **质量门禁**：参数可加载、变换可逆

## 边界与分流

**前提条件与改道**：

1. **s01 契约可用**
   - 不成立时 → 改道：返回 s01 重新建立数据契约

2. **切分比例合理**
   - 不成立时 → 改道：调整切分比例或使用交叉验证

3. **group_by 策略可执行**
   - 不成立时 → 改道：检查轨迹/工况标识，补充标识或调整分组策略

4. **无量纲化参数可保存**
   - 不成立时 → 改道：检查变换参数格式，修正保存逻辑

## 质量检查

**验证点**：
- 训练/验证/测试集轨迹互斥检查
- 归一化统计量仅来自训练集验证
- 边界与掩膜语义完整性检查
- 变换可逆性验证（逆变换后与原始数据比对）

**阈值**：
- 轨迹互斥率 100%
- 统计量来源正确率 100%
- 边界语义完整率 100%

**失败处理**：
- 轨迹泄漏 → 重新执行切分并检查 group_by 配置
- 统计量泄漏 → 仅用训练集重新计算
- 边界语义破坏 → 恢复原始掩膜或边界定义

## 回退策略

**失败时的替代方案**：
1. 切分失败 → 调整比例或改用随机切分（降低质量标准并记录）
2. 归一化失败 → 使用简单 Min-Max 归一化或跳过无量纲化
3. 轨迹分组失败 → 降级为随机切分（需在审计报告中注明）
