# 方程求解与物理残差恢复

## 适用范围
适用于所有需要在查询点或网格上求解PDE并评估物理一致性的场景，包括贝叶斯PINN概率反演、参数估计、不确定性量化等。该步骤确保解场满足物理约束，为后续评估提供依据。

## 输入
- **模型权重**：通过训练门限权重。
- **计算设备**：CPU或CUDA设备。
- **推理批大小**：按显存调整批量。

## 输出
- **solution_fields/**：解场目录，包含 \(u(x)\) 及其导数。
- **pde_residuals/**：PDE残差目录。
- **boundary_residuals.csv**：边界残差。

## 流程节点
1. **加载模型**：加载最佳模型权重。
2. **定义查询点**：定义测试参数、边界和查询坐标。
3. **前向传播**：计算解场 \(u(x)\)。
4. **计算导数**：使用自动微分计算导数、通量。
5. **计算PDE残差**：计算方程残差。
6. **计算边界残差**：计算边界条件残差。
7. **保存结果**：保存解场与残差场。

每步含：操作、参数、工具、质量门禁。

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 计算设备 | cuda | [1] | 默认使用GPU加速 |
| 推理批大小 | 8 | [1] | 按显存调整 |
| 自动微分 | true | [1] | 使用自动微分计算导数 |
| 禁止仅依据训练损失判定方程已求解 | true | [1] | 必须独立评估 |

## 边界与分流
- **计算资源不足**：使用CPU或减少批大小。
- **导数计算失败**：检查自动微分实现或使用有限差分。
- **残差异常大**：检查模型权重或PDE定义。

## 质量检查
- **解场导数与残差均为有限值**：确保计算稳定性。
- **边初值逐项满足门限**：边界条件满足预设误差阈值。
- **独立数值解或解析解可对照**：验证解的正确性。

## 回退策略
- **自动微分失败**：使用有限差分近似导数。
- **计算超时**：减少查询点数量或使用近似方法。
- **残差异常**：检查PDE定义或模型权重。

## 资源召回建议
- **召回时机**：当用户需要求解PDE或评估物理一致性时。
- **配套资源**：
  - `cfd-model-training`：模型训练。
  - `cfd-task-acceptance`：任务验收。
