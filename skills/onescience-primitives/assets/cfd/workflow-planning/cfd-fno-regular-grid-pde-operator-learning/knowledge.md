# Fourier Neural Operator规则网格参数化PDE算子学习

## 适用范围

**触发条件**：
- 需要从规则网格数据（如Darcy流或Navier-Stokes方程）训练算子学习模型
- 需要学习输入参数到输出物理场的映射关系
- 需要处理参数化偏微分方程（PDE）的求解问题

**适用场景**：
- Darcy流渗透率场到压力场的映射
- Navier-Stokes方程中流场参数到速度/压力场的映射
- 其他规则网格上的PDE参数化问题

**不适用场景**：
- 非规则网格或复杂几何域上的PDE求解
- 需要高精度数值解的工程仿真（需CFD复核）
- 实时控制或优化问题

## 输入

**数据格式**：
- 规则网格数据（如2D/3D网格）
- 输入参数：渗透率场、初始条件、边界条件等
- 输出目标：压力场、速度场等物理量

**数据来源**：
- 数值模拟生成的训练数据
- 实验测量数据（需预处理）

**预处理要求**：
- 数据归一化或无量纲化
- 网格坐标标准化
- 边界掩膜处理

## 输出

**输出产物**：
- 训练好的FNO模型权重
- 推理结果（预测场）
- 评估指标（相对误差、守恒残差等）
- 适用域报告

**验证标准**：
- 测试集相对L2误差 < 0.1（默认门限）
- 物理守恒残差在可接受范围内
- 边界误差满足精度要求

## 流程节点

### Step 1：数据接入与契约核验
- **操作**：接入Darcy与Navier-Stokes规则网格数据，核验样本、变量、单位、网格坐标及许可
- **参数**：数据集路径、数据集名称、数据契约
- **工具**：数据读取工具、契约验证脚本
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏

### Step 2：预处理与数据切分
- **操作**：统一物理量与表示，按几何、工况或时间构造无泄漏切分
- **参数**：切分配置（train/validation/test比例）、目标变量、是否无量纲化
- **工具**：数据预处理脚本、切分工具
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏

### Step 3：模型配置与训练
- **操作**：训练Fourier Neural Operator完成指定输入到目标物理量的映射
- **参数**：模型名称（FNO）、训练配置（框架、epochs、batch_size、学习率等）、初始权重
- **工具**：PyTorch框架、FNO实现代码
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现

### Step 4：批量推理与物理恢复
- **操作**：在独立测试集推理，恢复原始单位、网格和物理派生量
- **参数**：模型权重、计算设备、推理批大小
- **工具**：推理脚本、反归一化工具
- **质量门禁**：预测无NaN或Inf且形状单位正确；每个测试样本有唯一结果；推理未使用测试目标校正

### Step 5：任务验收与适用域判定
- **操作**：评估统计误差、关键物理约束、泛化能力和计算收益
- **参数**：验收指标（相对L2、RMSE、守恒残差、边界误差）、相对误差门限、是否外推测试
- **工具**：评估脚本、可视化工具
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议

| 参数 | 值 | 来源 | 说明 |

## 边界与分流

**关键前提不成立时的改道方案**：
1. **数据非规则网格**：转向非规则网格神经算子方法（如Graph Neural Operator）
2. **高精度要求**：结合传统CFD求解器进行后处理或混合建模
3. **实时性要求**：考虑模型压缩或轻量化架构
4. **多物理场耦合**：使用耦合FNO或物理信息神经网络（PINN）

## 质量检查

**验证点**：
- 数据完整性检查：样本数、变量数、网格尺寸
- 模型训练收敛性：损失曲线、验证指标
- 推理结果合理性：物理场可视化、边界条件满足
- 适用域评估：几何/工况外推测试

**阈值**：
- 相对L2误差 < 0.1（默认）
- 守恒残差 < 预设阈值
- 边界误差 < 预设阈值

**失败处理**：
- 数据问题：返回BLOCKED并列出缺项
- 训练失败：检查超参数、数据质量
- 推理异常：检查模型权重、数据预处理

## 回退策略

**失败时的替代方案**：
1. **数据不足**：使用数据增强或迁移学习
2. **模型不收敛**：调整学习率、优化器或模型架构
3. **泛化能力差**：增加训练数据多样性或使用正则化
4. **计算资源不足**：使用模型并行或梯度累积
