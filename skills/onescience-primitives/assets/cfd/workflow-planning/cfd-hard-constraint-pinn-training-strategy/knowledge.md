# 硬约束PINN复杂几何边界求解训练策略

## 适用范围

本卡片为硬约束PINN在复杂几何边界问题上的训练提供策略指导，涵盖学习率调度、损失权重平衡、早停策略、自适应配点采样、网络架构选择等训练技巧，以及收敛性诊断方法。适用于训练Hard-constraint PINN、Boundary PINN等物理约束神经网络模型。

**不适用场景**：
- 纯数据驱动的神经网络训练
- 无物理约束的回归问题
- 简单几何边界的PINN问题

## 输入

- **问题特征**：PDE类型、边界条件类型、几何复杂度
- **训练数据**：配点分布、边界点、初始条件
- **模型架构**：网络层数、隐藏维度、激活函数

## 输出

- **训练策略推荐**：学习率、损失权重、早停参数
- **收敛性诊断**：训练曲线分析、损失平衡评估
- **超参数配置**：最优超参数组合

## 流程节点

```
问题分析 → 策略选择 → 参数配置 → 训练监控 → 收敛诊断 → 策略调整
```

### 详细操作

#### 1. 问题分析

**操作**：
- 分析PDE类型（椭圆型、抛物型、双曲型）
- 识别边界条件类型（Dirichlet、Neumann、Robin、周期性）
- 评估几何复杂度（简单/复杂、规则/不规则）

**判定标准**：
- 问题特征明确
- 边界条件类型识别正确
- 几何复杂度评估合理

#### 2. 策略选择

**操作**：
- 根据问题特征选择训练策略
- 确定损失权重平衡方法
- 选择学习率调度策略

**判定标准**：
- 策略选择与问题特征匹配
- 损失权重平衡方法合理
- 学习率调度策略适当

#### 3. 参数配置

**操作**：
- 配置学习率、批次大小、训练轮数
- 配置损失权重（PDE损失、边界损失、数据损失）
- 配置早停参数（耐心值、最小改进阈值）

**判定标准**：
- 参数配置完整
- 参数值在合理范围内
- 参数组合经过验证

#### 4. 训练监控

**操作**：
- 监控训练损失和验证损失
- 监控各损失分量的平衡情况
- 监控梯度范数和学习率

**判定标准**：
- 训练过程稳定
- 损失函数收敛
- 梯度范数在合理范围内

#### 5. 收敛诊断

**操作**：
- 分析训练曲线形态
- 评估损失平衡情况
- 诊断收敛问题（过拟合、欠拟合、振荡）

**判定标准**：
- 收敛诊断准确
- 问题识别正确
- 改进建议有效

## 边界与分流

### 训练不收敛时
- **损失振荡** → 降低学习率，增加批次大小
- **损失停滞** → 检查网络架构，增加网络容量
- **梯度爆炸** → 使用梯度裁剪，降低学习率
- **梯度消失** → 更换激活函数，使用残差连接

### 损失不平衡时
- **PDE损失过大** → 增加PDE损失权重，增加配点数量
- **边界损失过大** → 增加边界损失权重，增加边界配点
- **数据损失过大** → 检查数据质量，调整数据损失权重

### 过拟合时
- **训练损失下降，验证损失上升** → 增加正则化，减少网络复杂度
- **训练损失和验证损失都下降但验证损失较高** → 增加训练数据，使用数据增强

## 质量检查

### 验证点
1. **收敛性**：训练损失和验证损失均收敛
2. **损失平衡**：各损失分量在合理范围内
3. **梯度稳定性**：梯度范数在合理范围内
4. **物理一致性**：解场满足物理约束

### 阈值
- 最终损失值：<0.1（根据问题复杂度调整）
- 损失平衡比：各损失分量比值在1-10范围内
- 梯度范数：<100（根据网络架构调整）

### 失败处理
- 收敛失败 → 调整超参数，重新训练
- 损失不平衡 → 调整损失权重
- 梯度异常 → 使用梯度裁剪或调整网络架构

## 回退策略

### 训练策略失败时
1. 检查问题定义和边界条件
2. 验证数据格式和质量
3. 调整网络架构和超参数
4. 使用更保守的训练策略

### 收敛性诊断失败时
1. 重新分析问题特征
2. 检查损失函数设计
3. 验证配点分布合理性
4. 调整训练策略参数
