# CFD任务中PDE状态观测数据的接入、来源验证与真实性核验

## 适用范围

**触发条件**：
- 需要接入PDE状态视频、双帧观测或连续流场数据完成CFD任务
- 需要验证数据来源的真实性（实验/仿真/公开数据集）
- 需要区分合成数据与真实数据的使用场景边界

**适用场景**：
- 部分观测扩散同化与连续流场反演任务（CFD_S097类场景）
- 流场超分辨率重建（从稀疏观测恢复完整流场）
- 实验数据与仿真数据融合的数据同化任务
- 需要数据来源可追溯的科研验收场景

**不适用场景**：
- 纯合成数据的开发调试（仅作为脚手架，不作为最终产物）
- 无物理约束需求的纯数据驱动任务
- 用户明确声明使用合成数据进行方法验证的场景

## 输入

**数据来源分类**：
1. **实验测量数据**：PIV（粒子图像测速）、LDV（激光多普勒测速）、热线风速仪等实验测量结果
2. **数值仿真数据**：高保真CFD求解器（如DNS/LES）生成的仿真数据
3. **公开基准数据集**：如CFDBench、AI-Airfoil等公开发布的基准数据集

**数据规格要求**：
- 数据集路径：用户显式提供或公开可下载的真实CFD数据集
- 数据集名称：唯一标识符，用于数据溯源
- 变量完整性：至少包含速度场（u, v）、压力场（p）等关键物理量
- 时间分辨率：连续帧之间的时间间隔满足Nyquist采样定理
- 空间分辨率：网格分辨率与任务需求匹配

## 输出

**产出文件**：
- `dataset_manifest.json`：数据集清单，包含数据来源、变量列表、时间/空间分辨率等元数据
- `data_contract.json`：数据契约，定义输入输出变量格式、单位、坐标系
- 原始数据文件：速度场（u.npy, v.npy）、涡量场（vorticity.npy）、观测掩膜（mask_sparse.npy, mask_block.npy）等

**验证标准**：
- `dataset_manifest.json`中`source`字段为`real`/`experimental`/`simulation`，不得为`synthetic_generation`
- 数据文件可读且样本可追溯
- 输入目标变量单位、坐标定义完整
- 不存在训练测试泄漏

## 流程节点

### Step 1：数据来源识别
- **操作**：确认用户是否提供实际数据集路径或公开可下载的数据源
- **质量门禁**：数据集路径非空且可访问；数据来源可追溯（实验/仿真/公开数据集）

### Step 2：数据来源验证
- **操作**：验证数据来源的真实性，区分实验数据、仿真数据和合成数据
- **质量门禁**：实验数据需有实验条件记录；仿真数据需有求解器配置；公开数据集需有引用信息

### Step 3：数据许可检查
- **操作**：检查数据使用许可，确保符合科研伦理和版权要求
- **质量门禁**：数据许可明确且允许当前用途；无版权争议

### Step 4：变量完整性核验
- **操作**：核验数据集包含任务所需的全部变量（速度、压力、涡量等）
- **质量门禁**：变量列表与数据契约一致；单位和坐标系正确

### Step 5：合成数据判定
- **操作**：判定数据是否为合成生成，若是则标注限制条件
- **质量门禁**：合成数据仅可作为开发调试脚手架，不得替代真实数据完成科研验收

### Step 6：BLOCKED判定
- **操作**：当用户未提供数据且无公开数据源时，明确标注BLOCKED并列出所需数据规格
- **质量门禁**：BLOCKED判定有明确依据；所需数据规格清单完整

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据来源分类 | experimental/simulation/real | 任务需求 | 三种合法数据来源 |
| 合成数据标识 | synthetic_generation | 任务需求 | 合成数据仅作为调试脚手架 |
| BLOCKED条件 | 用户未提供数据且无公开数据源 | 任务需求 | 需明确标注BLOCKED |
| 变量完整性 | 速度(u,v)、压力(p)、涡量(vorticity) | 任务需求 | 至少包含速度场 |
| 时间分辨率 | 满足Nyquist采样定理 | 物理约束 | 连续帧间隔合理 |
| 空间分辨率 | 与任务需求匹配 | 任务需求 | 网格分辨率足够 |

## 边界与分流

- **用户未提供数据**：明确BLOCKED，列出所需数据规格清单，不得自行生成合成数据作为替代
- **数据来源不明**：需进一步验证，无法验证时视为合成数据处理
- **数据许可不明确**：需用户确认许可，否则不得使用
- **变量不完整**：需补充缺失变量或调整任务目标

## 质量检查

- 数据来源可追溯：`dataset_manifest.json`中`source`字段非`synthetic_generation`
- 数据文件可读：所有.npy文件可正常加载
- 变量完整性：数据契约中定义的变量全部存在
- 无训练测试泄漏：训练集和测试集样本互斥

## 回退策略

- 数据不可用：切换到公开基准数据集（如CFDBench）
- 数据来源不明：标注为合成数据，限制使用场景
- 变量不完整：调整任务目标或补充数据采集
