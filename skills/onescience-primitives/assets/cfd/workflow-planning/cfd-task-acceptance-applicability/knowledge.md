# CFD任务验收与适用域判定

## 适用范围

适用于评估图神经算子流场预测模型的性能，包括统计误差、物理约束、泛化能力和计算收益，确定模型适用范围。

## 输入

- 验收指标（相对L2、RMSE、守恒残差、边界误差）
- 相对误差门限
- 是否外推测试标志
- 预测结果
- 测试集真实值

## 输出

- 评估结果（evaluation.json）
- 最差样本记录（worst_cases.csv）
- 适用域报告（applicability_report.md）
- 验收结论（PASS_REJECT_BLOCKED.txt）

## 流程节点

1. **计算统计误差** → 逐变量误差、整体误差
2. **检查物理约束** → 守恒残差、边界误差
3. **识别最差样本** → 追溯最差预测样本
4. **评估泛化能力** → 几何或工况外推测试
5. **计算推理成本** → 时间、内存占用
6. **确定适用域** → 几何范围、工况范围
7. **生成报告** → 适用域限制与复核建议
8. **给出结论** → PASS、REJECT或BLOCKED

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 验收指标 | relative_L2, RMSE, conservation_residual, boundary_error | 场景需求书 | 统计和物理指标 |
| 相对误差门限 | 0.1 | 场景需求书 | 测试集放行阈值 |
| 外推测试 | true | 场景需求书 | 测试域外工况 |

## 边界与分流

- **误差超标**：REJECT模型，建议重新训练或调整
- **物理约束违反**：检查模型是否满足物理定律
- **泛化能力不足**：明确适用域限制，建议CFD复核
- **数据不足**：BLOCKED，建议收集更多数据

## 质量检查

- **统计与物理指标同时报告**：全面评估模型性能
- **最差样本可追溯**：可定位问题样本
- **结论含适用域限制与复核建议**：明确使用边界

## 回退策略

- **评估失败**：使用简化指标或人工评估
- **适用域不明确**：保守估计适用范围
- **结论不确定**：建议进一步验证

## 资源召回建议

- 当需要评估图神经算子流场预测模型性能时
- 当需要确定模型适用范围和边界时
- 配套资源：评估指标库、物理约束检查工具、适用域分析工具
