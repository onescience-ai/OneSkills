# 神经PDE任务验收与适用域判定

## 适用范围
本卡片适用于神经PDE求解器的任务验收与适用域判定任务，是神经PDE工作流的第五步（最后一步）。核心目标是评估统计误差、关键物理约束、泛化能力和计算收益，给出PASS/REJECT/BLOCKED结论。适用于时间并行或多时间尺度神经PDE推进场景的最终验证阶段。

## 输入
- **验收指标**（必填）：统计和物理指标列表，如relative_L2、RMSE、conservation_residual、boundary_error
- **相对误差门限**（可选）：测试集放行阈值，默认0.1（10%）
- **外推测试选项**（可选）：是否测试域外工况，默认true
- **预测结果**（来自s04）：predictions/, inference_manifest.json
- **测试集清单**（来自s02）：test_manifest.json
- **数据契约**（来自s01）：data_contract.json

## 输出
- **evaluation.json**：多维度评估结果
- **worst_cases.csv**：最差样本详情
- **applicability_report.md**：适用域报告
- **PASS_REJECT_BLOCKED.txt**：最终验收结论

## 流程节点
1. **加载预测结果** → 读取s04产出的预测数据
2. **计算统计误差** → 逐变量计算relative_L2、RMSE等
3. **计算物理约束** → 评估守恒残差、边界误差等
4. **识别最差样本** → 找出误差最大的样本并分析原因
5. **计算推理成本** → 统计推理时间和资源消耗
6. **执行外推测试**（可选） → 测试几何或工况外推能力
7. **生成适用域报告** → 明确模型泛化边界
8. **给出验收结论** → PASS/REJECT/BLOCKED

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认验收指标 | relative_L2, RMSE, conservation_residual, boundary_error | 场景需求书 | 多维度评估 |
| 默认误差门限 | 0.1 (10%) | 场景需求书 | PASS/REJECT阈值 |
| 默认外推测试 | true | 场景需求书 | 测试泛化能力 |
| 禁止事项 | 仅凭平均误差宣称可用 | 场景需求书 | 需多维度评估 |

## 边界与分流
- **指标计算失败**：检查预测结果完整性
- **误差超限**：相对L2超过门限时，给出REJECT结论
- **物理约束违反**：守恒残差或边界误差超限时，分析物理一致性缺陷
- **外推能力不足**：域外工况误差显著增大时，明确适用域限制
- **判定不确定**：默认PASS但附加更严格复核要求

## 质量检查
- 统计与物理指标同时报告
- 最差样本可追溯
- 结论含适用域限制与复核建议
- 评估结果完整且可复现
- 适用域报告清晰明确

## 回退策略
- 指标计算失败：检查数据格式和完整性
- 误差超限：分析原因并考虑重新训练或调整模型
- 物理约束违反：改进模型物理一致性
- 外推能力不足：扩大训练数据分布或调整模型

## 资源召回建议
- 需要具体评估指标计算时，可召回CFD评估指标卡片
- 需要物理约束验证方法时，可召回守恒残差计算卡片
- 需要适用域分析方法时，可召回泛化能力评估卡片
- 域外工况复核时，建议召回CFD标准验证流程卡片
