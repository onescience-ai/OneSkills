# 跨声速气动弹性CFD数据集接入与验证

## 适用范围

**触发条件**：
- 需要为跨声速气动弹性任务获取CFD仿真数据
- 数据路径缺失或未提供，导致任务阻塞
- 需要确认数据集格式、变量定义和许可信息

**适用场景**：
- 跨声速颤振与buffet耦合分析的数据准备
- 气动弹性降阶响应预测任务的数据接入
- CFD仿真数据路径确认与访问验证
- 数据可用性评估与契约生成

**不适用场景**：
- 数据路径已明确且可访问（直接执行数据读取）
- 非跨声速气动弹性任务（需使用对应领域卡）

## 输入

| 输入项 | 格式 | 必填 | 说明 |
|--------|------|------|------|
| {TASK_ID} | 字符串 | 是 | 任务标识符，用于追溯数据来源 |
| {DATA_DESCRIPTION} | 字符串 | 是 | 数据需求描述（如"跨声速颤振与buffet耦合CFD数据"） |
| {DATA_SOURCE_HINT} | 路径或URL | 否 | 已知的数据来源提示（如有） |

## 输出

| 输出项 | 格式 | 说明 |
|--------|------|------|
| dataset_path | 路径 | 确认的数据文件路径 |
| dataset_manifest.json | JSON | 数据集清单：文件列表、样本数、变量名、单位、坐标系 |
| data_contract.json | JSON | 机器可读数据契约：输入字段、目标字段、单位映射、坐标定义 |
| data_audit.md | Markdown | 数据审计报告：可读性、完整性、缺失值、许可信息 |

## 流程节点

### Step 1：数据路径确认
- **操作**：检查execution-manifest.json中data_availability状态，确认数据路径是否提供
- **参数**：{TASK_ID}对应的execution-manifest.json
- **质量门禁**：数据路径非空且可访问

### Step 2：数据格式验证
- **操作**：确认数据文件格式（NetCDF/HDF5/CSV等），验证文件可读性
- **参数**：数据文件路径列表
- **质量门禁**：100%文件可解析

### Step 3：变量与单位核验
- **操作**：提取所有变量名、检查单位完整性、验证输入与目标变量定义
- **参数**：跨声速气动弹性任务的变量需求（如马赫数、攻角、气动力系数、结构响应等）
- **质量门禁**：输入目标变量单位坐标定义完整

### Step 4：许可信息确认
- **操作**：检查数据集使用许可、访问权限、引用要求
- **参数**：数据集元数据或README文件
- **质量门禁**：许可信息明确，可合法用于目标任务

### Step 5：数据契约生成
- **操作**：汇总所有核验结果，生成机器可读的data_contract.json和data_audit.md
- **参数**：核验结果汇总
- **质量门禁**：契约字段覆盖率100%

## 边界与分流

- **数据路径缺失**：记录BLOCKED状态，列出缺失项，等待用户提供数据路径
- **数据格式不支持**：记录格式问题，建议格式转换预处理
- **变量缺失**：若必需输入变量缺失 → BLOCKED并列出缺项
- **许可受限**：记录限制条件，不阻塞后续步骤但需在报告中说明

## 质量检查

- 数据路径确认且可访问
- 数据文件格式可解析
- 输入/目标变量清单完整
- 单位映射无歧义
- 坐标系定义明确
- 许可信息明确

## 回退策略

- **数据路径未提供**：等待用户提供，记录BLOCKED状态
- **格式不支持**：转换工具预处理后重新接入
- **变量/单位缺失**：联系数据提供方补充
- **许可受限**：寻找替代数据源或调整任务范围
