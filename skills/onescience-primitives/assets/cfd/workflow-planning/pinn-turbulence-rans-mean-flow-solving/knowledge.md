# PINN湍流RANS均值流求解与闭合

## 适用范围

本场景面向RANS方程与稀疏均值流湍流数据，使用物理信息神经网络(PINN)进行湍流均值流求解与闭合建模。适用于需要从稀疏测量数据重建完整湍流场、验证物理一致性并评估模型适用域的计算流体力学任务。

**触发条件**：
- 具备RANS方程描述和稀疏均值流湍流数据
- 需要物理一致的湍流场重建
- 需要评估模型在域外工况的适用性

**不适用场景**：
- 直接数值模拟(DNS)或大涡模拟(LES)数据充足的情况
- 纯数据驱动且无物理约束需求的任务
- 域外工况未经CFD复核的直接应用

## 输入

- **RANS方程**：Reynolds平均Navier-Stokes方程描述
- **稀疏均值流湍流数据**：来自实验或数值模拟的稀疏测量数据
- **数据契约**：变量定义、单位、坐标系、网格拓扑、时间/工况范围

## 输出

- **可复现模型**：训练好的PINN模型权重与配置
- **任务结果**：完整湍流场解、导数、通量、方程残差
- **物理一致性评估**：统计误差与物理约束满足情况
- **适用域报告**：模型能力边界与复核建议

## 流程节点

```
数据接入与契约核验 → 预处理与数据切分 → 模型配置与训练 → 方程求解与物理残差恢复 → 任务验收与适用域判定
```

### 关键步骤说明

1. **数据接入与契约核验**：接入RANS方程与稀疏均值流湍流数据，核验样本、变量、单位、网格坐标及许可
2. **预处理与数据切分**：统一物理量与表示，按几何、工况或时间构造无泄漏切分
3. **模型配置与训练**：训练Turbulence-augmented PINN完成指定输入到目标物理量的映射
4. **方程求解与物理残差恢复**：在查询配点或网格上恢复解场、导数、边界值与方程残差
5. **任务验收与适用域判定**：评估统计误差、关键物理约束、泛化能力和计算收益

## 边界与分流

**关键前提与改道**：

1. **前提：稀疏数据充分表征湍流特征**
   - 不成立时 → 转向数据增强或半监督学习方法

2. **前提：RANS方程适用（湍流充分发展）**
   - 不成立时 → 转向DNS/LES数据或转捩模型

3. **前提：物理约束可微分**
   - 不成立时 → 转向混合PINN-CFD方法或代理模型

## 质量检查

- **统计与物理指标同时报告**：不能仅凭平均误差宣称工程可用
- **最差样本可追溯**：必须识别并分析最差预测工况
- **结论含适用域限制与复核建议**：域外工况需经CFD复核

## 回退策略

1. **训练不收敛**：调整学习率、批大小或网络架构
2. **物理残差过大**：增加物理损失权重或调整配点策略
3. **泛化能力不足**：增加训练工况多样性或引入迁移学习
