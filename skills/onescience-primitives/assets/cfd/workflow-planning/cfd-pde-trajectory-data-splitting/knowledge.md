# PDE轨迹数据结构化切分与无泄漏验证

## 适用范围

**触发条件**：
- 需要将PDE轨迹数据按group_by策略分为训练/验证/测试集
- 需要防止同一几何/工况/轨迹的样本跨集合泄漏
- 切分比例需要满足特定默认值要求

**适用场景**：
- 多几何/多工况PDE数据集的切分（按geometry或trajectory分组）
- 合成数据集的训练/验证/测试集构建
- 需要无泄漏验证的PDE模型评估
- 数据切分比例需要满足场景默认配置（如7:1.5:1.5）

**不适用场景**：
- 无结构化信息的纯随机数据（直接随机切分即可）
- 时间序列预测中的时序切分（需保持时间顺序）
- 单一样本的数据集（无需切分）

## 输入

- PDE轨迹数据集（包含样本和分组信息）
- 切分比例配置（train:val:test）
- 分组策略（group_by参数：geometry/trajectory/condition）
- 样本的分组标识（如几何ID、初始条件类型、工况参数）

## 输出

- 切分索引文件（split_indices.json）
- 切分统计信息（各集合的样本数和比例）
- 数据泄漏检测报告
- 分组依据记录

## 流程节点

### Step 1：分组策略确定
- **操作**：根据数据组织方式确定group_by策略
- **geometry分组**：按几何形状（如翼型、管道截面）分组
- **trajectory分组**：按完整PDE轨迹（同一起始条件的完整时间序列）分组
- **condition分组**：按工况参数（如雷诺数、马赫数）分组
- **参数**：数据集元信息
- **工具**：元数据分析
- **质量门禁**：分组策略与数据组织方式匹配

### Step 2：切分比例配置
- **操作**：设置train/val/test切分比例
- **默认值**：train=0.7, val=0.15, test=0.15
- **约束**：比例之和为1，各集合至少有1个样本
- **参数**：train_ratio, val_ratio, test_ratio
- **工具**：配置文件
- **质量门禁**：比例配置正确，满足场景默认值

### Step 3：分组切分执行
- **操作**：按group_by策略将样本分组，再按比例切分各组
- **方法**：GroupKFold或GroupShuffleSplit（scikit-learn）
- **参数**：分组标识、切分比例、随机种子
- **工具**：sklearn.model_selection.GroupKFold
- **质量门禁**：同一组的样本不跨集合

### Step 4：切分比例验证
- **操作**：验证实际切分比例与配置比例的偏差
- **公式**：deviation = |actual_ratio - target_ratio| / target_ratio
- **阈值**：偏差 < 5%为可接受
- **参数**：实际切分结果、目标比例
- **工具**：NumPy计算
- **质量门禁**：各集合比例偏差 < 5%

### Step 5：数据泄漏检测
- **操作**：检查训练集和测试集之间是否存在数据泄漏
- **检查项**：
  - 时间序列重叠：同一轨迹的样本是否跨集合
  - 空间域重叠：不同几何的样本是否共享空间坐标
  - 初始条件相似度：训练集和测试集的初始条件是否过于相似
- **参数**：各集合的样本特征
- **工具**：相似度计算（如余弦相似度）
- **质量门禁**：无泄漏检出，或泄漏量在可接受范围内

### Step 6：切分记录保存
- **操作**：保存切分结果和元信息
- **输出格式**：split_indices.json（包含各集合的索引列表）
- **元信息**：切分比例、分组策略、随机种子、偏差统计
- **工具**：json.dump
- **质量门禁**：切分文件完整，可复现

## 边界与分流

- **分组信息缺失**：退化为随机切分，在报告中标注分组信息缺失
- **样本数过少（<10）**：使用留一法（Leave-One-Out）或增加数据生成
- **切分比例偏差过大**：调整比例或增加数据量后重新切分
- **检测到数据泄漏**：重新设计分组策略，确保同一组不跨集合

## 质量检查

- [ ] 实际切分比例与目标比例偏差 < 5%
- [ ] 同一组的样本不跨训练/验证/测试集
- [ ] 切分文件包含完整的索引列表和元信息
- [ ] 数据泄漏检测已执行并记录结果
- [ ] 切分比例满足场景默认值要求

## 回退策略

- 若分组切分不可行（分组信息缺失），使用分层随机切分（StratifiedShuffleSplit）
- 若数据量不足以支持15%验证集，可适当降低验证集比例（但需标注）
- 若切分比例严重偏离，重新生成数据并调整切分参数
