# 圆柱与钝体OpenFOAM传感动作轨迹数据集获取

## 适用范围
面向深度强化学习钝体尾迹闭环减阻控制任务，提供圆柱与钝体OpenFOAM传感动作轨迹数据集的获取途径、公开数据源、数据格式规范和许可要求。适用于需要获取圆柱绕流或钝体尾迹OpenFOAM模拟数据进行DRL策略训练的研究任务。不适用于非OpenFOAM生成的数据或非圆柱/钝体几何的数据。

## 输入
- 任务需求：几何形状（圆柱/钝体）、流动条件（雷诺数范围）、数据变量（速度分量、压力、涡量、控制动作）
- 网络环境：可访问公开数据源或学术数据库
- 存储空间：足够的磁盘空间存储数据集
- 许可协议：遵守数据集使用许可

## 输出
- 数据集文件路径和访问方式
- 数据格式说明和变量定义
- 数据集元数据（网格信息、时间步长、物理参数）
- 数据使用许可信息
- 数据质量报告（完整性、一致性检查）

## 流程节点
1. **需求分析** → 确定几何形状、流动条件、数据变量需求
2. **数据源检索** → 搜索公开圆柱/钝体OpenFOAM数据集
3. **数据获取** → 下载或生成符合需求的数据集
4. **数据格式验证** → 检查数据格式、变量定义、单位一致性
5. **数据许可确认** → 确认数据使用许可和引用要求
6. **数据接入准备** → 生成数据清单和契约文档

## 关键参数

### 通用判据（方法层，同类体系可参考）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据类型 | OpenFOAM模拟结果 | 任务需求 | 必须是OpenFOAM生成的数据 |
| 几何形状 | 圆柱/钝体 | 任务需求 | 包括2D和3D几何 |
| 流动条件 | 亚临界到超临界雷诺数 | 任务需求 | 根据具体任务确定 |
| 数据变量 | 速度、压力、涡量、控制动作 | 任务需求 | 包含传感和动作轨迹 |
| 数据格式 | OpenFOAM格式（VTK/CSV） | 通用实践 | 便于后续处理 |

### 校准数值（体系专属值）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 雷诺数范围 | 100-10000 | 圆柱绕流典型范围 | 以下数值来自圆柱绕流体系，供量级校准；其他体系需以自身证据重新锚定 |
| 网格分辨率 | 依雷诺数而定 | DNS/LES要求 | 需足够分辨率解析边界层和尾迹 |
| 时间步长 | 依CFL条件而定 | 数值稳定性要求 | 保证时间精度和稳定性 |

## 边界与分流
- **公开数据不可用**：转向CFD求解器生成自定义数据
- **计算资源不足**：使用降阶模型或合成数据生成
- **数据格式不兼容**：使用格式转换工具（如ParaView、Python库）
- **数据质量不达标**：返回数据验证步骤或重新生成
- **许可限制**：遵守数据集使用许可，必要时联系数据提供者

## 质量检查
1. 数据完整性：检查缺失值、异常值
2. 物理一致性：验证速度、压力等变量的物理合理性
3. 网格质量：检查网格正交性、光滑性
4. 时间序列连续性：验证时间步长的一致性
5. 许可合规：确认数据使用许可

## 回退策略
- 公开数据不可用时，使用OpenFOAM生成简化几何的数据
- 计算资源不足时，使用降阶模型生成近似数据
- 数据格式转换失败时，使用中间格式（如VTK）进行转换
- 许可限制时，寻找替代数据源或生成合成数据
