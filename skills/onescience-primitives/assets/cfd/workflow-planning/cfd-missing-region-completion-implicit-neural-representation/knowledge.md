# CFD缺失区补全：隐式表示与扩散桥方法

## 适用范围

**触发条件**：
- CFD流场存在稀疏采样、局部缺损或低分辨率观测，需要恢复完整高保真场
- 需要从坐标查询（x, y, z, t）直接预测物理量值的连续场重构
- 需要在补全缺失区域的同时保持物理一致性（守恒律、方程残差）

**适用场景**：
- 实验测量稀疏的流场重构（如PIV有限采样点）
- 数值模拟中因网格损坏或数据丢失导致的场补全
- 超分辨率重建：从低分辨率CFD输出恢复高分辨率细节
- 湍流场的压缩存储与高质量重建
- 多物理场耦合中缺失变量的补全

**不适用场景**：
- 纯数据驱动、无物理约束的图像补全（不保证流体力学一致性）
- 域外工况（几何/雷诺数/边界条件严重偏离训练分布）需经CFD复核
- 需要实时在线推断且计算资源极度受限的场景

## 输入

| 输入项 | 格式 | 说明 |
|--------|------|------|
| 稀疏/缺损CFD场 | NetCDF/HDF5/CSV，含坐标(x,y,z,t)和物理量(u,v,w,p,T等) | 支持2D/3D非结构化或结构化网格 |
| 坐标查询 | (x,y,z,t)坐标对列表 | 隐式表示的核心输入，定义补全位置 |
| 数据契约 | JSON | 变量名、单位、坐标系、网格拓扑定义 |
| 掩膜定义 | 布尔掩膜或坐标列表 | 标记缺失区域与已知区域 |

## 输出

| 输出项 | 格式 | 说明 |
|--------|------|------|
| 完整重构流场 | 与输入同格式 | 缺失区域已补全的完整场 |
| 误差场 | 逐点误差分布 | 已知区域的重建误差分布 |
| 频谱统计 | JSON | 能量谱、统计剖面对比 |
| 适用域报告 | Markdown | 模型能力边界与复核建议 |

## 流程节点

### Step 1：数据接入与契约核验
- **操作**：接入稀疏或缺损CFD场，核验文件可读性、样本数、变量、单位、网格坐标
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏

### Step 2：预处理与数据切分
- **操作**：统一物理量表示，按几何/工况/时间构造无泄漏切分，执行归一化或无量纲化
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏

### Step 3：模型配置与训练
- **操作**：配置并训练隐式神经表示和扩散桥模型，完成输入到目标物理量的映射
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现

### Step 4：低分辨或部分观测流场重构
- **操作**：加载训练好的模型，构造与真实采集一致的低分辨/稀疏/缺损输入，执行重构
- **质量门禁**：观测掩膜与训练测试协议一致；小尺度频谱与统计量得到验证；边界守恒误差不因超分辨恶化

### Step 5：任务验收与适用域判定
- **操作**：按统计误差、物理约束、泛化能力和计算收益进行综合评估
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议

## 边界与分流

- **数据契约缺失**：返回BLOCKED并列出缺项，不得编造数据
- **训练发散**：损失为NaN或Inf时回退调整学习率或网络结构
- **观测掩膜不一致**：推断时掩膜必须与训练协议一致，否则REJECT
- **域外工况**：几何/工况外推测试失败时，结论须含适用域限制，建议CFD复核
- **边界守恒恶化**：超分辨率导致守恒误差增大时，需评估是否接受

## 质量检查

- 逐变量相对L2误差 ≤ 门限
- 能量谱匹配度（高频段误差可接受但须报告）
- 梯度误差反映场光滑性
- 守恒误差/方程残差在工程容差内
- 最差样本可追溯、误差分布合理

## 回退策略

- 模型训练失败 → 检查数据质量，简化网络结构或增大训练数据
- 重构质量不足 → 增加物理约束权重，调整模型架构
- 域外泛化差 → 收集更多域外数据重新训练，或切换至传统CFD方法
