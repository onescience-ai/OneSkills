# 预处理与数据切分

## 适用范围

本步骤适用于CFD流场不确定性反演工作流的第二阶段，负责数据质控、归一化和无泄漏切分。当用户需要对原始数据进行预处理、按物理工况切分、避免数据泄漏时使用。

## 输入

- **{SPLIT_CONFIG}**：切分配置（必填），含train/validation/test比例、随机种子、切分策略
- **{TARGET_FIELDS}**：目标变量（必填），待预测物理量列表
- **{NONDIMENSIONALIZE}**：是否无量纲化（可选），默认true

## 输出

- **train_manifest.json**：训练集清单
- **validation_manifest.json**：验证集清单
- **test_manifest.json**：测试集清单
- **normalization.json**：归一化统计量（均值、标准差、变换参数）

## 流程节点

1. 依据s01契约完成质控
2. 重采样或图构建
3. 掩膜处理
4. 归一化或无量纲化
5. 按{SPLIT_CONFIG}切分（以几何、完整轨迹或物理工况为单位）
6. 保存统计量与可逆变换

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 训练集比例 | 0.7 | 场景需求书 | 默认 |
| 验证集比例 | 0.15 | 场景需求书 | 默认 |
| 测试集比例 | 0.15 | 场景需求书 | 默认 |
| 随机种子 | 42 | 场景需求书 | 默认 |
| 切分策略 | geometry_or_trajectory | 场景需求书 | 按几何或轨迹切分 |
| 无量纲化 | true | 场景需求书 | 默认执行 |

## 边界与分流

- **数据泄漏**：同一轨迹的帧被打散时需重新切分
- **统计量污染**：验证/测试集参与归一化计算时需重做
- **掩膜破坏**：边界或掩膜语义被破坏时需修复

## 质量检查

- 三份切分的对象轨迹互斥
- 仅用训练集计算变换统计量
- 边界与掩膜语义未破坏

## 回退策略

- 切分不当导致泄漏时，返回s02调整切分策略
- 归一化参数异常时，检查数据质量或调整归一化方法

## 资源召回建议

当用户需要执行数据预处理与切分时召回本卡片。作为工作流第二步，完成后进入模型训练步骤。
