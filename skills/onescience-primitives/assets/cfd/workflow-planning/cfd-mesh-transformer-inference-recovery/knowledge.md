# 批量推理与物理恢复

## 适用范围

**触发条件**：
- 已有训练好的模型权重（s03输出）
- 需要在独立测试集上执行推理
- 需要反归一化恢复物理单位和坐标

**适用场景**：
- 大规模网格Transformer流场预测的推理阶段
- 任何需要对PDE网格数据进行神经推理的场景

**不适用场景**：
- 在线实时推理（本步骤为批量推理）
- 训练阶段的验证推理

## 输入

| 输入 | 类型 | 必填 | 说明 |
|------|------|------|------|
| {CHECKPOINT} | doc | 是 | 模型权重路径（默认best_checkpoint.pt） |
| {DEVICE} | str | 是 | 计算设备（CPU/CUDA，默认cuda） |
| {BATCH_SIZE} | int | 否 | 推理批大小（默认8，按显存调整） |

## 输出

| 输出 | 格式 | 说明 |
|------|------|------|
| predictions/ | 目录 | 逐样本预测结果 |
| inference_manifest.json | JSON | 推理清单（样本ID、预测路径） |
| timing.csv | CSV | 推理耗时（总时间、每样本时间） |

## 操作流程

### 1. 模型加载
- 加载{CHECKPOINT}权重
- 加载训练时数据契约（data_contract.json）
- 加载归一化统计量（normalization.json）

### 2. 测试集加载
- 加载s02独立测试集
- 应用相同的预处理（归一化等）

### 3. 批量推理
- 以{DEVICE}和{BATCH_SIZE}执行推理
- 记录推理时间
- 禁止用测试标签修正预测

### 4. 物理恢复
- 反归一化恢复原始单位
- 恢复坐标网格
- 恢复边界掩膜
- 计算任务派生量

### 5. 结果保存
- 保存逐样本预测结果
- 保存inference_manifest.json
- 保存timing.csv

## 质量门禁

| 门禁 | 标准 | 失败处理 |
|------|------|----------|
| 无NaN/Inf | 预测值无异常 | 检查模型和数据 |
| 形状正确 | 预测形状与输入匹配 | 检查模型输出 |
| 单位正确 | 恢复后单位与数据契约一致 | 检查反归一化 |
| 唯一结果 | 每个测试样本有唯一结果 | 检查索引逻辑 |
| 无标签修正 | 推理未使用测试目标 | 检查推理代码 |

## 边界与分流

| 情况 | 处理方式 |
|------|----------|
| 权重加载失败 | 检查文件路径和格式 |
| 设备不可用 | 降级到CPU推理 |
| 显存不足 | 减小BATCH_SIZE |
| 预测异常 | 检查模型和数据，标记异常样本 |
| 反归一化错误 | 检查统计量文件 |

## 回退策略

1. **权重加载失败**：检查文件路径、格式、模型结构
2. **设备不可用**：降级到CPU，减小批大小
3. **显存不足**：减小BATCH_SIZE，使用混合精度
4. **预测异常**：标记异常样本，检查模型和数据
5. **反归一化错误**：检查统计量文件，验证变换可逆性
