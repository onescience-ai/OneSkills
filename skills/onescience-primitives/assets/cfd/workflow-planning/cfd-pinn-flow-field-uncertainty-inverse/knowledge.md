# 物理信息概率网络流场不确定性反演场景

## 适用范围

本场景针对CFD领域中流场不确定性反演问题。当用户拥有稀疏观测数据与CFD先验信息，需要通过物理信息概率网络（如Bayesian PINN、Physics-informed GAN）完成流场重构并量化不确定性时，可使用本场景。

**适用条件**：
- 具备稀疏观测数据（如传感器测量值、PIV数据片段）
- 具备CFD先验信息（如Navier-Stokes方程、边界条件）
- 需要量化预测的不确定性（认知不确定性与随机不确定性）

**不适用条件**：
- 海量稠密观测数据（可直接使用纯数据驱动方法）
- 稳态均匀流场（无需概率方法）
- 域外工况未经CFD复核（需额外验证）

## 输入

- **稀疏观测数据**：传感器位置的流场测量值，含坐标与物理量
- **CFD先验信息**：控制方程（Navier-Stokes）、边界条件、初始条件
- **数据契约**：变量定义、单位、坐标系、网格拓扑

## 输出

- **可复现模型**：训练后的概率网络权重
- **任务结果**：流场预测分布（均值、方差、样本集合）
- **物理一致性评估**：方程残差、边界误差、守恒误差
- **适用域报告**：几何/工况外推能力评估

## 流程节点

1. 数据接入与契约核验 → 2. 预处理与数据切分 → 3. 模型配置与训练 → 4. 概率推理与不确定性校准 → 5. 任务验收与适用域判定

## 边界与分流

- **数据缺失**：缺少稀疏观测或CFD先验时，返回BLOCKED状态
- **域外工况**：几何或工况超出训练分布时，需CFD复核
- **模型不收敛**：训练验证损失非有限值时，需调整超参数或检查数据

## 质量检查

- 概率输出有限且定义清楚
- 测试集未参与校准训练
- 区间覆盖率与宽度同时报告
- 统计与物理指标同时报告
- 最差样本可追溯
- 结论含适用域限制与复核建议

## 回退策略

- 模型不收敛时，检查数据质量、调整学习率或增加早停耐心
- 物理一致性不足时，增加物理损失权重或修正边界条件
- 域外泛化差时，增加训练数据多样性或使用迁移学习
