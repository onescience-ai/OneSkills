# CFD-DRL壁湍流摩阻削减验收评估流程

## 适用范围

本卡片为深度强化学习（DRL）控制壁湍流减阻任务提供完整的验收评估流程。适用于使用主动流动控制（AFC）或壁面吹吸控制策略降低通道流、边界层流或绕流体拖曳的CFD-DRL任务。不适用于无物理约束的纯数值优化问题或被动控制（PFC）评估。

## 输入

- 训练完成的DRL策略（policy）
- 未控制基准流场数据
- 受控流场统计数据
- 控制参数配置（执行器数量、响应时间、奖励函数参数）
- 能量预算数据（泵送功率、壁面功、总耗散）

## 输出

- `evaluation.json`：多维指标统计报告
- `worst_cases.csv`：最差样本追溯信息
- `applicability_report.md`：适用域判定报告
- `PASS_REJECT_BLOCKED.txt`：最终验收结论

## 流程节点

### 1. 核心性能指标计算
- 拖曳削减率：ΔCD = (CD_b - CD) / CD_b × 100% [论文1]
- 升力系数波动：CL_RMS（评估轴对称性保持）
- Strouhal数变化：St的变化反映涡脱落频率控制效果 [论文1]
- 回流泡长度：Lr/D变化评估尾迹结构改变 [论文1]

### 2. 能量预算与物理一致性验证
- 泵送功率：P_p = |⟨∂xp⟩| × Ub [论文2]
- 壁面功：W_w = -1/(LxLy) ∫⟨w_w p⟩ dxdy [论文2]
- 总耗散：ε = P_p + W_w/H [论文2]
- 净能量平衡：Δε = (ε₀ - ε) / ε₀ × 100% [论文2]
- **关键判据**：名义拖曳削减必须伴随总耗散降低（Δε > 0），否则为奖励欺骗 [论文2]

### 3. 控制能耗效率评估
- 质量流量效率：Ec*/ΔCD（质量成本/拖曳削减） [论文1]
- 幅值代理：W_in = 1/2 × 1/(LxLy) ∫⟨|w_w|³⟩ dxdy [论文2]
- 壁面峰值幅度：|w_w|max [论文2]

### 4. 稳定性与收敛性评估
- 闭环轨迹发散检测：监控时间序列是否趋于无穷或周期性振荡
- 训练收敛性：奖励曲线是否平稳
- 策略饱和检测：动作是否退化为bang-bang开关（幅值饱和） [论文2]
- 低频振荡检测：是否存在与episode时长相关的振荡 [论文1]

### 5. 约束满足验证
- 零净质量流条件：∫w_w dxdy = 0（数值精度<10⁻⁸） [论文2]
- 执行器幅值约束：|a_i| ≤ 1（归一化范围）
- 时间平滑性：避免质量流突变

### 6. 最差样本追溯（worst_cases.csv）
- 记录拖曳系数最高的时刻（CD_max）
- 记录总耗散最高的时刻（ε_max）
- 记录壁面功最大的时刻（W_w_max）
- 记录约束违反最大的时刻
- 对应时刻的流场快照路径

### 7. 适用域判定（applicability_report.md）
- 雷诺数范围：基于训练和评估的Re_τ或Re_D
- 计算域尺寸：最小流元 vs 大域评估
- 执行器配置：数量、布局、响应时间
- 奖励函数类型：拖曳削减 vs 能量感知
- 策略类型：无记忆 vs 循环网络
- 评估域大小影响：小域可能导致人工虚高DR [论文2]

## 关键参数

### 通用判据

| 参数 | 判据 | 来源 | 说明 |
|------|------|------|------|
| 拖曳削减率 ΔCD | >0 且物理一致 | [论文1] | 必须伴随ε降低 |
| 净能量平衡 Δε | >0 | [论文2] | 真实物理有效性判据 |
| 壁面功 W_w | < 10⁻³ 量级 | [论文2] | 过大表明奖励欺骗 |
| 约束残差 | < 10⁻⁸ | [论文2] | 零净质量流精度 |
| 策略饱和度 | < 90% 幅值占比 | [论文2] | 避免bang-bang退化 |
| 低频振荡周期 | < episode时长 | [论文1] | 稳定性要求 |

### 校准数值（壁湍流通道流 Re_τ≈180）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 参考DR（opposition） | 21.4% | [论文2] | 对立控制基准 |
| 参考DR（GRU-MARL） | 17.3% | [论文2] | 循环多智能体 |
| 基准P_p | 4.10×10⁻³ | [论文2] | 未控制泵送功率 |
| 基准ε | 4.10×10⁻³ | [论文2] | 未控制总耗散 |

## 边界与分流

### 奖励欺骗检测失败时
当检测到名义DR>0但Δε<0时，判定为**BLOCKED**，要求重新设计奖励函数（添加能量感知项）或修复约束处理方式。

### 约束违反超限时
当零净质量流残差>10⁻⁶时，判定为**BLOCKED**，需检查执行器实现或数值格式。

### 评估域过小时
当评估域接近最小流元时，DR可能因层流化而虚高，需在`applicability_report.md`中注明评估域限制。

### 策略严重饱和时
当>90%时刻处于幅值饱和时，判定为**REJECT**，表明策略退化为非学习型开关控制。

### 稳定性不满足时
当闭环轨迹发散或存在持续低频振荡（周期>episode时长）时，判定为**REJECT**或**BLOCKED**。

## 质量检查

- 检查点1：evaluation.json中所有指标数值在合理物理范围内
- 检查点2：ΔCD与Δε符号一致（同正或同负）
- 检查点3：worst_cases.csv中记录的时刻确实对应最差样本
- 检查点4：约束残差数值记录正确（<10⁻⁸）
- 检查点5：策略饱和度统计准确

## 回退策略

当物理一致性验证失败时：
1. 检查奖励函数是否包含能量惩罚项
2. 检查约束处理方式（投影是否在策略内）
3. 检查观测是否包含足够时间信息（循环网络/堆叠帧）
4. 增加评估域尺寸避免人工虚高
