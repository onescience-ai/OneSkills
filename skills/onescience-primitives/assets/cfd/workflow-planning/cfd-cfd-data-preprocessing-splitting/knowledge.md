# CFD数据预处理与无泄漏切分

## 适用范围

**触发条件**：
- 已通过数据接入与契约核验（Step 1），数据清单与契约已建立
- 需要对CFD流场数据进行统一表示、归一化和无泄漏切分
- 目标是为后续模型训练提供干净、无泄漏、可逆变换的数据集

**适用场景**：
- 多工况/多几何CFD数据集的标准化预处理
- 以几何或轨迹为单位的训练/验证/测试切分
- 物理量无量纲化处理（如速度/参考速度、压力/动压）
- 归一化统计量的保存与可逆变换

**不适用场景**：
- 数据尚未通过契约核验（需先执行数据接入）
- 需要实时在线预处理的流式数据

## 输入

| 输入项 | 格式 | 必填 | 说明 |
|--------|------|------|------|
| {SPLIT_CONFIG} | JSON | 是 | 切分比例与策略配置 |
| {TARGET_FIELDS} | 列表 | 是 | 待预测的目标物理量 |
| {NONDIMENSIONALIZE} | 布尔 | 否 | 是否执行无量纲化，默认true |

## 输出

| 输出项 | 格式 | 说明 |
|--------|------|------|
| train_manifest.json | JSON | 训练集清单 |
| validation_manifest.json | JSON | 验证集清单 |
| test_manifest.json | JSON | 测试集清单 |
| normalization.json | JSON | 归一化/无量纲化统计量（均值、标准差、参考值等） |

## 流程节点

### Step 2.1：物理量统一与质控
- **操作**：按data_contract.json统一变量名和单位，检查异常值
- **参数**：data_contract.json中的变量映射
- **质量门禁**：变量名统一、单位一致

### Step 2.2：掩膜构建
- **操作**：为缺失区域构建布尔掩膜，标记已知/未知区域
- **参数**：缺失区域定义
- **质量门禁**：掩膜语义正确，已知/未知区域不混淆

### Step 2.3：无量纲化/归一化
- **操作**：执行无量纲化（如适用）或Z-score/Min-Max归一化，仅用训练数据计算统计量
- **参数**：{NONDIMENSIONALIZE}, 归一化方法
- **质量门禁**：仅用训练集计算统计量；变换可逆

### Step 2.4：无泄漏切分
- **操作**：按{SPLIT_CONFIG}以几何、完整轨迹或物理工况为单位切分
- **参数**：{SPLIT_CONFIG}中的比例与group_by策略
- **质量门禁**：三份切分的对象轨迹互斥；同一轨迹帧不跨集

### Step 2.5：统计量保存
- **操作**：保存归一化/无量纲化统计量到normalization.json
- **参数**：均值、标准差、参考值、变换类型
- **质量门禁**：统计量完整、可逆变换信息齐全

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认训练比例 | 0.7 | [场景需求书] | 可按实际调整 |
| 默认验证比例 | 0.15 | [场景需求书] | 可按实际调整 |
| 默认测试比例 | 0.15 | [场景需求书] | 可按实际调整 |
| 切分种子 | 42 | [场景需求书] | 可复现性 |
| 切分策略 | geometry_or_trajectory | [场景需求书] | 以几何或轨迹为单位 |
| 无量纲化 | 默认开启 | [场景需求书] | 统一跨工况量纲 |
| 目标变量 | 按data_contract.json | [场景需求书] | 待预测物理量 |

## 边界与分流

- **轨迹泄漏**：检测到同一轨迹帧跨集 → REJECT并重新切分
- **统计量来源错误**：非训练集数据参与统计量计算 → REJECT
- **掩膜破坏**：切分导致掩膜语义变化 → REJECT并检查切分逻辑
- **无量纲化失败**：参考值为零或物理不合理 → 回退至Z-score归一化
- **切分比例异常**：总和≠1或某集合为空 → 自动修正或BLOCKED

## 质量检查

- 三份切分无对象重叠
- 归一化统计量仅来自训练集
- 变换可逆性验证（逆变换后误差<eps）
- 掩膜在切分后语义一致
- 目标变量统计量合理

## 回退策略

- 切分泄漏 → 调整group_by策略或手动隔离
- 归一化异常 → 切换归一化方法或检查数据分布
- 掩膜破坏 → 重新定义掩膜或调整切分边界
