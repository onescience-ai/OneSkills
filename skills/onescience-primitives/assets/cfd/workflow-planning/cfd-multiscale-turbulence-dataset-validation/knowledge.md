# 多尺度湍流数据集获取与验证

## 适用范围

面向需要获取和验证多尺度湍流数据集的CFD研究与工程应用，提供公开DNS/LES数据库使用方法、数据契约验证流程、真实湍流数据特征识别技术。适用于湍流闭合模型训练、湍流统计分析、多尺度湍流模拟等场景。不适用于单尺度均匀湍流或各向同性湍流的简单应用。

## 输入

- 数据需求：湍流类型（各向同性/壁湍流/自由剪切）、雷诺数范围、尺度范围
- 数据来源：公开数据库、实验数据、数值模拟数据
- 验证标准：数据契约、物理约束、统计特性要求

## 输出

- 验证后的湍流数据集：符合物理特性和数据契约要求
- 数据质量报告：验证结果、问题识别、改进建议
- 数据特征报告：能谱、统计矩、空间相关性等

## 流程节点

### 数据来源识别

1. **公开DNS/LES数据库**
   - Johns Hopkins Turbulence Database (JHTDB)：高雷诺数各向同性湍流DNS数据
   - NASA Turbulence Modeling Resource：标准湍流测试案例
   - ERCOFTAC Database：实验和数值湍流数据
   - Kaggle湍流数据集：社区贡献的湍流数据

2. **数据获取方法**
   - API访问：通过REST API获取数据子集
   - 批量下载：下载完整数据集进行本地分析
   - 流式访问：实时获取大尺度数据的局部信息

3. **数据格式识别**
   - 网格数据：均匀网格上的速度场、压力场
   - 粒子数据：拉格朗日粒子轨迹数据
   - 统计量数据：能谱、雷诺应力、概率密度函数

### 数据契约验证

1. **单位一致性验证**
   - 速度单位：m/s 或归一化单位
   - 长度单位：m 或网格单位
   - 时间单位：s 或对流时间单位
   - 密度单位：kg/m³ 或归一化密度

2. **网格兼容性验证**
   - 网格类型：均匀网格、非均匀网格、自适应网格
   - 网格分辨率：满足奈奎斯特采样定理
   - 网格边界：周期性边界、壁面边界、自由流边界

3. **物理约束验证**
   - 质量守恒：连续性方程满足程度
   - 动量守恒：动量方程满足程度
   - 能量守恒：能量方程满足程度

### 真实湍流数据特征识别

1. **能谱特征**
   - 能谱斜率：-5/3（惯性子区）、-3（二维湍流）
   - 能谱峰值：对应最大能量尺度
   - 能谱截断：耗散区高波数衰减

2. **统计矩特征**
   - 均值：速度均值、压力均值
   - 方差：速度方湍流强度
   - 偏度：速度分布的非对称性
   - 峰度：速度分布的尖锐程度

3. **空间相关性特征**
   - 积分尺度：大尺度涡的特征长度
   - Taylor微尺度：中等尺度涡的特征长度
   - Kolmogorov尺度：最小尺度涡的特征长度

### 合成数据检测

1. **合成数据特征**
   - 统计特性过于完美：无随机波动
   - 物理约束过于严格：完全满足守恒律
   - 缺少实验误差：无测量噪声和系统误差

2. **检测方法**
   - 能谱分析：检查能谱斜率和峰值
   - 统计检验：检查统计矩和概率分布
   - 物理一致性：检查守恒律满足程度

3. **处理策略**
   - 标记为合成数据：明确标注数据来源
   - 添加噪声：模拟实验误差
   - 调整统计特性：使其更接近真实数据

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |

## 边界与分流

### 数据来源不可用时
- 公开数据库访问受限 → 转向本地生成合成数据（需明确标注）
- 数据格式不兼容 → 转向数据格式转换工具

### 数据质量不达标时
- 能谱特征异常 → 转向数据滤波或重采样
- 统计特性不收敛 → 转向增加样本数量或调整采样策略
- 物理约束违反 → 转向数据修正或降级使用

### 真实数据与合成数据冲突时
- 统计特性差异大 → 优先使用真实数据
- 物理约束差异大 → 检查数据来源和处理方法
- 无法确定数据来源 → 标记为"待验证"

## 质量检查

1. **能谱验证**：检查能谱斜率和峰值是否符合湍流理论
2. **统计矩验证**：检查均值、方差、偏度、峰度是否合理
3. **空间相关性验证**：检查积分尺度、Taylor微尺度、Kolmogorov尺度
4. **物理约束验证**：检查质量守恒、动量守恒、能量守恒
5. **数据来源验证**：确认数据来自真实实验或数值模拟

## 回退策略

- 如果公开数据库不可用，使用本地生成的合成数据（需明确标注）
- 如果数据质量不达标，进行数据清洗和滤波
- 如果物理约束违反，进行数据修正或降级使用
- 如果无法验证数据来源，标记为"待验证"
