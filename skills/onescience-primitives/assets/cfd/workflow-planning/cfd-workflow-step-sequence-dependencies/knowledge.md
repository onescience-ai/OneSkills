# CFD标准工作流步骤序列与依赖关系

## 适用范围
适用于CFD工作流编排，当执行标准工作流时，需要按顺序执行s01到s05五个步骤，每个步骤都有明确的输入要求、输出产物和前置依赖。该知识帮助确保工作流步骤按顺序完成并生成对应产物。

## 输入
- 任务目标（如因子分解与多重网格FNO高效算子学习）
- 原始数据集（如CFD仿真数据）
- 工作流配置

## 输出
- s01：dataset_manifest.json、data_contract.json、data_audit.md
- s02：数据切分结果（训练集、验证集、测试集）
- s03：训练好的模型
- s04：推理结果
- s05：评估结果和适用域报告

## 流程节点
s01数据接入 → s02数据切分 → s03模型训练 → s04推理 → s05评估

### 步骤s01：数据接入
- 操作：数据发现、清单生成、契约定义、质量审计
- 输入：原始数据集、数据接入配置
- 输出：dataset_manifest.json、data_contract.json、data_audit.md
- 前置依赖：无
- 质量门禁：所有产物生成成功且格式正确

### 步骤s02：数据切分
- 操作：根据数据契约将数据切分为训练集、验证集、测试集
- 输入：dataset_manifest.json、data_contract.json、切分比例
- 输出：切分后的数据集文件、切分报告
- 前置依赖：s01完成
- 质量门禁：数据切分比例正确，数据文件完整

### 步骤s03：模型训练
- 操作：使用训练数据训练模型，保存检查点
- 输入：训练数据集、模型配置、训练参数
- 输出：训练好的模型、训练日志、检查点文件
- 前置依赖：s02完成
- 质量门禁：模型训练收敛，检查点保存成功

### 步骤s04：推理
- 操作：使用训练好的模型对测试数据进行推理
- 输入：训练好的模型、测试数据集
- 输出：推理结果文件、预测值与真实值对比
- 前置依赖：s03完成
- 质量门禁：推理完成，结果文件生成成功

### 步骤s05：评估
- 操作：评估模型性能，生成适用域报告
- 输入：推理结果、测试数据集、评估指标
- 输出：评估报告、适用域报告、性能指标
- 前置依赖：s04完成
- 质量门禁：评估报告生成成功，性能指标计算正确

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 步骤数量 | 5个（s01-s05） | 归因报告 | 标准工作流步骤数 |
| 步骤顺序 | 必须按顺序执行 | 归因报告 | 前置依赖关系 |
| 产物完整性 | 每个步骤必须生成对应产物 | 归因报告 | 产物缺失导致后续步骤失败 |

### 校准数值
以下数值来自CFD_S049任务，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 缺失步骤 | s02-s05完全缺失 | 归因报告 | 实际缺失的步骤 |
| 实际产物 | 只有task_understanding.md和克隆的仓库 | 归因报告 | 实际生成的产物 |
| 缺失后果 | 任务目标完全未达成 | 归因报告 | 步骤缺失的后果 |

## 边界与分流
- 如果s01未完成，不能执行s02
- 如果s02未完成，不能执行s03
- 如果s03未完成，不能执行s04
- 如果s04未完成，不能执行s05
- 任何步骤失败都应导致工作流停止，不继续后续步骤

## 质量检查
- 验证每个步骤的输入产物存在
- 验证每个步骤的输出产物生成成功
- 验证步骤间依赖关系正确
- 验证所有产物格式符合标准

## 回退策略
- 如果某个步骤失败，应记录错误并终止工作流
- 如果步骤产物缺失，应尝试重新执行该步骤
- 如果工作流中断，应从失败步骤重新开始
