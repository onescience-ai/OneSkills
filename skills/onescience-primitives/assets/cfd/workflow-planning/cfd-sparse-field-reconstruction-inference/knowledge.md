# 稀疏CFD流场重构推理

## 适用范围

**触发条件**：
- 已完成模型训练（Step 3），最佳权重已保存且可加载
- 需要对测试集执行低分辨/稀疏/缺损输入的流场重构
- 需要恢复物理单位和边界，评估重构质量

**适用场景**：
- 从低分辨率CFD输出恢复高分辨率流场细节
- 从稀疏采样点重构完整连续场
- 从局部缺损区域补全完整流场
- 超分辨率湍流场重建

**不适用场景**：
- 模型训练未完成或权重不可加载（需先执行训练步骤）
- 需要在线实时推理（本卡为离线批量推理）
- 域外工况的推理（需额外评估适用域）

## 输入

| 输入项 | 格式 | 必填 | 说明 |
|--------|------|------|------|
| {CHECKPOINT} | 路径 | 是 | 通过训练门限的模型权重 |
| {DEVICE} | 字符串 | 是 | 计算设备（cpu/cuda） |
| {BATCH_SIZE} | 整数 | 否 | 推理批大小，默认8 |

## 输出

| 输出项 | 格式 | 说明 |
|--------|------|------|
| reconstructed_fields/ | 目录 | 逐样本重构流场文件 |
| error_fields/ | 目录 | 逐样本误差场（重构-真实） |
| spectral_statistics.json | JSON | 能量谱、统计剖面对比 |

## 流程节点

### Step 4.1：模型加载与验证
- **操作**：加载{CHECKPOINT}，验证模型结构与权重匹配
- **参数**：{CHECKPOINT}, {DEVICE}
- **质量门禁**：权重可加载、模型结构正确

### Step 4.2：测试输入构造
- **操作**：对测试集构造与真实采集一致的低分辨、稀疏或缺损输入
- **参数**：测试集清单、掩膜定义
- **质量门禁**：观测掩膜与训练测试协议一致

### Step 4.3：批量推理
- **操作**：执行批量推理，按{BATCH_SIZE}分批处理
- **参数**：{BATCH_SIZE}, {DEVICE}
- **质量门禁**：推理完成、无异常中断

### Step 4.4：物理单位恢复
- **操作**：将归一化/无量纲化的输出逆变换回物理单位
- **参数**：normalization.json中的统计量
- **质量门禁**：逆变换正确、单位恢复

### Step 4.5：误差场与频谱计算
- **操作**：计算逐点误差场、能量谱、统计剖面
- **参数**：重构场与真实场
- **质量门禁**：误差场物理合理、频谱匹配度可评估

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认批大小 | 8 | [场景需求书] | 可按显存调整 |
| 默认设备 | cuda | [场景需求书] | 支持CPU回退 |
| 误差类型 | 逐点误差、频谱误差 | [场景需求书] | 多维度评估 |
| 输出格式 | 与输入同格式 | [场景需求书] | 保持一致性 |

## 边界与分流

- **掩膜不一致**：推断掩膜与训练不一致 → REJECT，不执行推理
- **显存不足**：减小{BATCH_SIZE}或使用CPU
- **逆变换异常**：统计量缺失或异常 → 检查normalization.json
- **边界守恒恶化**：超分辨率导致守恒误差增大 → 记录并报告
- **频谱失真**：高频段能量异常 → 分析原因并在报告中标注

## 质量检查

- 所有测试样本重构完成
- 误差场物理合理（无系统性偏差）
- 能量谱在关键频段匹配
- 边界守恒误差在可接受范围
- 逐样本结果可追溯

## 回退策略

- 推理失败 → 检查权重完整性、降低批大小
- 逆变换异常 → 检查统计量文件、手动验证变换逻辑
- 频谱严重失真 → 分析模型局限性、考虑后处理修正
