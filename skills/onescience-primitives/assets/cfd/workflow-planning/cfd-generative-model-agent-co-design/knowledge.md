# 生成模型与智能体工程外形协同设计

## 适用范围

本知识卡片适用于使用生成模型（如扩散模型）和工程智能体进行车辆或软体结构的外形协同设计。覆盖从概念草图到气动性能评估的全流程，整合多智能体协作、几何深度学习和物理增强生成模型，实现美学与性能的协同优化。适用于汽车设计、软体机器人设计、电磁结构设计等需要平衡美学与工程性能的领域。

## 输入

- **概念草图**：2D手绘草图或设计概念图
- **设计目标**：美学要求、气动性能指标、制造约束
- **数据集**：现有设计数据库（如DrivAerNet++、超材料数据集）
- **模拟器**：CFD模拟器、有限元分析工具
- **配置参数**：训练配置、优化预算、评估指标

## 输出

- **设计候选**：生成的3D设计、中间形状、优化后的设计
- **性能评估**：气动性能、力学性能、制造可行性
- **优化历史**：搜索轨迹、Pareto前沿、约束满足情况
- **适用域报告**：统计误差、物理约束、泛化能力、计算收益
- **模型产物**：训练好的模型权重、配置文件、环境依赖

## 流程节点

### 场景级工作流

1. **数据接入与契约核验** → 2. **预处理与数据切分** → 3. **模型配置与训练** → 4. **候选生成与约束优化** → 5. **任务验收与适用域判定**

### 每步详情

#### 步骤1：数据接入与契约核验
- **操作**：接入车辆或软体结构生成设计数据，核验样本、变量、单位、网格坐标及许可
- **参数**：数据集路径、数据集名称、数据契约
- **工具**：数据加载脚本、验证工具
- **质量门禁**：数据文件可读且样本可追溯；输入目标变量单位坐标定义完整；不存在训练测试泄漏

#### 步骤2：预处理与数据切分
- **操作**：统一物理量与表示，按几何、工况或时间构造无泄漏切分
- **参数**：切分配置、目标变量、是否无量纲化
- **工具**：数据预处理脚本、归一化工具
- **质量门禁**：三份切分的对象轨迹互斥；仅用训练集计算变换统计量；边界与掩膜语义未破坏

#### 步骤3：模型配置与训练
- **操作**：训练Diffusion design model、Engineering agent完成指定输入到目标物理量的映射
- **参数**：模型名称、训练配置、初始权重
- **工具**：PyTorch框架、训练脚本
- **质量门禁**：训练验证损失均为有限值；最佳权重可重新加载；配置环境随机种子可复现

#### 步骤4：候选生成与约束优化
- **操作**：围绕目标性能生成候选，执行约束优化并保留完整搜索轨迹
- **参数**：模型权重、计算设备、推理批大小
- **工具**：推理脚本、优化器
- **质量门禁**：候选满足几何和物理硬约束；优化轨迹与随机种子完整；最优候选未混用测试标签

#### 步骤5：任务验收与适用域判定
- **操作**：评估统计误差、关键物理约束、泛化能力和计算收益
- **参数**：验收指标、相对误差门限、是否外推测试
- **工具**：评估脚本、可视化工具
- **质量门禁**：统计与物理指标同时报告；最差样本可追溯；结论含适用域限制与复核建议

## 边界与分流

- **域外工况**：当设计超出训练数据分布时，需要CFD复核
- **评估预算有限**：当模拟预算受限时，使用渐进搜索和一致性样本选择
- **多模态数据**：当涉及多种数据格式（3D拓扑、密度条件、力学属性）时，使用统一模型
- **实时性要求**：当需要快速设计迭代时，使用代理模型和多智能体并行

## 质量检查

- **数据质量**：验证数据完整性、一致性、无泄漏
- **模型质量**：验证训练收敛性、泛化能力、物理一致性
- **设计质量**：验证几何约束、物理性能、制造可行性
- **流程质量**：验证可复现性、可追溯性、文档完整性

## 回退策略

- **数据不足**：使用数据增强、迁移学习
- **模型不收敛**：调整超参数、使用预训练权重
- **评估预算不足**：使用代理模型、渐进优化
- **域外工况**：增加CFD验证、调整适用域
