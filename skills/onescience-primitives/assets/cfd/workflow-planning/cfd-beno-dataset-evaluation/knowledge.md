# BENO数据集评估与来源管理

## 适用范围
BENO（边界嵌入神经算子）数据集的具体数据内容评估、场景需求匹配度分析、学术来源追溯与使用许可管理。适用于需要评估BENO数据集是否满足特定CFD场景需求，以及追溯其学术来源和使用许可的场景。

## 输入
- 数据集需求描述（如"混合边界与复杂域PDE数据"）
- BENO数据集的metadata信息
- 场景的具体数据要求

## 输出
- 数据集匹配度评估报告
- 学术来源追溯信息
- 使用许可与引用要求

## 流程节点
1. **需求分析** → 解析场景对数据集的具体要求（边界条件类型、几何域复杂度、数据规模等）
2. **数据集审查** → 分析BENO数据集的metadata和描述信息
3. **匹配度评估** → 对比数据集能力与场景需求，计算匹配度
4. **来源追溯** → 查找BENO数据集的学术来源论文和生成方法
5. **许可管理** → 确认使用许可和引用要求

每步含：操作、参数、工具、质量门禁

## 关键参数

| 参数 | 值 | 来源 | 说明 |

## 边界与分流
- **匹配度不足**：触发数据获取/生成流程，补充缺失的数据维度
- **来源不明确**：标记为"待确认"，建议用户提供来源信息
- **许可不明确**：避免使用该数据集，或寻求明确许可
- **数据集不存在**：回退到替代数据集或数据生成方案

## 质量检查
- 验证BENO数据集的边界条件类型覆盖场景需求
- 验证几何域复杂度满足场景要求
- 验证数据规模（样本数、维度）满足场景需求
- 验证学术来源可追溯且使用许可明确

## 回退策略
- 匹配度不足时，寻找替代数据集或生成补充数据
- 来源不明确时，在data_audit中标注"来源待确认"
- 许可不明确时，避免使用或寻求法律咨询
- 数据集不存在时，回退到数据生成流程
