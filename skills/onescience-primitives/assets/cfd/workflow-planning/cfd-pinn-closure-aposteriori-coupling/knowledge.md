# 闭合项预测与后验CFD耦合

## 适用范围

适用于PINN训练完成后，将预测的湍流闭合项（Reynolds应力张量或等效涡粘性系数）嵌入RANS或LES求解器进行后验验证的场景。先验评估闭合项精度，后验验证流场物理一致性。

## 输入

- **模型权重** {CHECKPOINT}：通过s03训练门限的best_checkpoint.pt
- **计算设备** {DEVICE}：CPU或CUDA设备
- **推理批大小** {BATCH_SIZE}：按显存调整，默认8

## 输出

- **apriori_closure/**：先验闭合项预测（应力张量、通量、源项的独立快照评估）
- **aposteriori_fields/**：后验流场（均值速度场、压力场、能谱）
- **solver_stability.csv**：求解器稳定性记录（残差、发散标志、迭代数）

## 流程节点

1. 加载s03最佳权重
2. 在独立快照上预测闭合项（应力、通量或源项）
3. 先验误差评估（与参考数据对比）
4. 可实现性检查（正定性、量纲一致性、物理约束）
5. 嵌入RANS或LES求解器
6. 执行后验推进，记录残差与稳定性
7. 保存均值剖面、能谱与统计场

## 边界与分流

- 闭合张量不满足物理约束（如负涡粘性） → 对闭合项施加物理约束裁剪，或返回s03调整训练
- 后验求解非物理发散 → 检查闭合项量纲、边界条件、网格质量
- 能谱异常（能量堆积或耗散过度） → 检查闭合项高频行为，必要时增加滤波
- 先验误差过大 → 返回s03调整模型架构或训练策略

## 质量检查

- 闭合张量或通量满足物理约束（正定性、量纲一致性、对称性）
- 后验求解无非物理解和发散（残差收敛、速度场合理）
- 均值剖面与能谱均经验证（与实验或高保真数据对比）

## 回退策略

- 后验求解发散：降级为纯先验评估，仅报告闭合项预测精度
- 闭合项物理不可实现：尝试投影到可行空间或施加约束重训练
- 求解器不稳定：调整时间步长、增加数值耗散、检查边界条件
