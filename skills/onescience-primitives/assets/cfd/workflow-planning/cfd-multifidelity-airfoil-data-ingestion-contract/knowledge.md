# 数据接入与契约核验

## 适用范围

**触发条件**：
- 已有多工况翼型几何与气动力数据，需要接入并建立数据清单
- 需要核验样本完整性、变量定义、单位一致性及使用许可
- 缺少必填输入时需返回BLOCKED并列出缺项

**适用场景**：
- 多保真代理辅助翼型优化的数据准备阶段
- 需要建立机器可读的数据契约
- 需要检查训练测试泄漏风险

**不适用场景**：
- 单一工况、单一保真度的简单数据接入
- 无结构化数据契约要求的场景

## 输入

**必需输入**：
- 数据集路径（目录或清单文件）
- 数据集名称（来源与数据版本）

**可选输入**：
- 数据契约定义（变量单位网格定义，默认为空契约）

**预处理要求**：
- 无特殊预处理要求，本步骤为数据接入的初始阶段

## 输出

**核心产物**：
- dataset_manifest.json：数据清单，含文件可读性、样本数、变量列表等
- data_contract.json：机器可读的数据契约，含输入目标变量、单位、坐标系定义
- data_audit.md：数据审计报告，含缺失值、异常值、使用许可等

**验证标准**：
- 数据文件可读且样本可追溯
- 输入目标变量单位坐标定义完整
- 不存在训练测试泄漏

## 流程节点

### Step 1：数据文件读取与验证
- **操作**：读取数据集路径中的文件，检查文件可读性
- **参数**：数据集路径
- **工具**：文件系统操作库
- **质量门禁**：100%文件可读

### Step 2：样本与变量核验
- **操作**：核验样本数、输入与目标变量、单位、坐标系
- **参数**：数据契约定义
- **工具**：数据解析库
- **质量门禁**：所有必需字段非空，单位坐标定义完整

### Step 3：数据审计
- **操作**：检查网格拓扑、时间或工况范围、缺失值和使用许可
- **参数**：数据集内容
- **工具**：数据审计脚本
- **质量门禁**：缺失值比例在可接受范围内，使用许可明确

### Step 4：契约生成
- **操作**：按数据契约输出机器可读契约
- **参数**：核验结果
- **工具**：JSON序列化工具
- **质量门禁**：契约文件可被标准JSON解析

## 边界与分流

**数据文件不可读时的改道**：
- 部分文件损坏 → 返回BLOCKED，列出不可读文件路径
- 数据集路径不存在 → 返回BLOCKED，提示检查路径

**变量定义不完整时的改道**：
- 缺少目标变量定义 → 返回BLOCKED，列出缺失字段
- 单位未定义 → 返回BLOCKED，提示补充单位信息

**训练测试泄漏风险时的改道**：
- 检测到同一轨迹样本出现在多个切分中 → 返回BLOCKED，提示重新设计切分策略

## 质量检查

| 检查项 | 阈值/判据 | 失败处理 |
|--------|-----------|----------|
| 文件可读性 | 100%通过 | 返回BLOCKED |
| 变量完整性 | 所有必需字段非空 | 返回BLOCKED |
| 单位定义 | 所有变量有单位 | 返回BLOCKED |
| 坐标系定义 | 明确坐标系 | 返回BLOCKED |
| 训练测试泄漏 | 0泄漏 | 返回BLOCKED |
| 使用许可 | 许可明确 | 警告但不阻塞 |

## 回退策略

- 数据文件损坏 → 检查数据源完整性，必要时重新获取
- 变量定义不完整 → 联系数据提供方补充定义
- 训练测试泄漏 → 重新设计切分策略，确保样本隔离
