# 圆柱绕流DNS/LES模拟数据标准和获取方法

## 适用范围
面向圆柱绕流DNS/LES模拟任务，提供真实CFD数据的标准格式规范、来源渠道和获取方法，以及工程验证数据与真实科研数据的区别和使用限制。适用于需要接入真实圆柱绕流非定常时序数据的科研任务，包括自回归网络训练、流场重构、降阶建模等应用场景。

## 输入
- 数据来源：公开数据集、CFD求解器生成、文献补充数据
- 数据格式：支持多种格式（HDF5、NetCDF、NPY等）
- 预处理要求：物理单位标准化、时间序列对齐、空间分辨率匹配

## 输出
- 标准化数据集：包含速度场、压力场、涡量场等完整物理量
- 元数据文件：记录Reynolds数、几何参数、边界条件等关键信息
- 质量验证报告：确认数据符合DNS/LES标准

## 流程节点
1. **数据源识别** → 确定数据获取渠道（公开数据集/自生成/文献提取）
2. **格式验证** → 检查数据格式是否符合标准规范
3. **物理量完整性检查** → 验证是否包含必要的物理量（u, v, p, ω等）
4. **参数提取** → 提取Reynolds数、几何尺寸、边界条件等关键参数
5. **质量评估** → 验证数据精度、分辨率和统计特性
6. **标准化转换** → 转换为统一格式并生成元数据

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| Reynolds数范围 | 100-1000 | [1] | 圆柱绕流研究的典型Reynolds数范围 |
| 空间分辨率 | ≥128×128 | [1] | DNS数据的最低分辨率要求 |
| 时间步长 | CFL≤0.5 | [1] | 稳定性要求 |
| 计算域尺寸 | 30D×20D | [1] | D为圆柱直径 |
| 边界条件 | 入口均匀流，出口开放边界 | [1] | 标准圆柱绕流配置 |

## 边界与分流
- **数据不可用时**：优先使用公开数据集（如JHU Turbulence Database），或使用CFD求解器生成验证数据
- **格式不兼容时**：使用格式转换工具（如CFD后处理软件）进行转换
- **参数缺失时**：从文献中提取标准参数值，或使用工程估算方法

## 质量检查
- **数据完整性**：检查所有必需的物理量是否齐全
- **精度验证**：与文献基准解对比，误差≤5%
- **统计稳定性**：验证时间平均和空间平均的收敛性
- **物理合理性**：检查速度、压力等物理量的范围是否合理

## 回退策略
1. **公开数据集优先**：JHU Turbulence Database、Kaggle CFD数据集
2. **CFD求解器生成**：使用OpenFOAM、Fluent等工具生成验证数据
3. **文献数据提取**：从已发表论文中提取标准数据
4. **工程验证数据**：仅用于功能测试，不用于科研结论

## 资源召回建议
当任务涉及圆柱绕流DNS/LES模拟、流场重构、降阶建模、自回归预测等需要真实CFD数据时，召回本卡片获取数据标准和获取方法指导。
