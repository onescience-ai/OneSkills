# 物理约束神经算子数据接入与契约核验

## 适用范围
面向带守恒边界和无量纲约束PDE数据的接入与契约核验任务，检查数据文件可读性、样本数、输入与目标变量、单位、坐标系、网格拓扑、时间或工况范围、缺失值和使用许可，按数据契约输出机器可读契约。适用于Physics-constrained neural operator训练的数据准备阶段，确保数据完整性和契约一致性。

## 输入
- **数据集路径**（必填）：目录或清单文件，包含PDE数据文件
- **数据集名称**（必填）：来源与数据版本描述
- **数据契约**（可选）：变量单位网格定义，默认包含input_fields、target_fields、units、coordinates

## 输出
- **dataset_manifest.json**：数据清单，包含文件列表、样本数、变量定义
- **data_contract.json**：机器可读数据契约，定义变量单位、网格坐标、边界条件类型
- **data_audit.md**：数据审计报告，记录检查结果和异常

## 流程节点
1. **文件可读性检查** → 验证数据文件存在且可读取
2. **样本数统计** → 统计总样本数、训练/验证/测试集划分潜力
3. **变量定义检查** → 核验输入与目标变量名称、类型、维度
4. **单位与坐标检查** → 确认物理量单位、坐标系定义、网格拓扑
5. **边界条件检查** → 识别边界条件类型（Dirichlet/Neumann/周期性）和守恒约束
6. **缺失值分析** → 检查数据完整性、缺失值比例和分布
7. **使用许可确认** → 确认数据使用许可和限制条件
8. **契约生成** → 输出机器可读数据契约

## 边界与分流
- **数据文件不可读** → 返回BLOCKED，列出不可读文件路径
- **变量定义缺失** → 返回BLOCKED，列出缺失变量名称
- **单位定义缺失** → 返回BLOCKED，要求用户提供单位定义
- **边界条件不明确** → 警告并建议人工确认边界条件类型
- **守恒约束不明确** → 警告并建议人工确认守恒律约束
- **缺失值过多** → 警告并建议数据清洗或插值处理
- **使用许可限制** → 警告并建议确认使用许可合规性

## 质量检查
- **数据文件可读且样本可追溯**：所有数据文件存在且可读取，每个样本有唯一标识
- **输入目标变量单位坐标定义完整**：变量名称、类型、维度、单位、坐标系均明确定义
- **不存在训练测试泄漏**：数据切分前无法识别泄漏风险，但需记录潜在风险

## 回退策略
- **数据文件损坏** → 尝试数据恢复或请求用户重新提供数据
- **变量定义不一致** → 建议用户统一变量定义并重新提供数据
- **边界条件复杂** → 建议简化边界条件或使用通用边界条件处理流程

## 资源召回建议
- **边界条件处理**：需要特定边界条件施加策略时，可召回边界条件处理卡片
- **数据预处理**：需要数据清洗或插值时，可召回相关预处理卡片
- **数据契约生成**：需要标准化数据契约格式时，可参考数据契约模板
