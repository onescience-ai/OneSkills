# 圆柱绕流预测验收与适用域判定

## 适用范围
圆柱绕流自回归预测模型的全面验收评估，包括统计误差、关键物理约束、泛化能力和计算收益分析，以及适用域判定。适用于需要工程可用性判断的CFD数据驱动预测任务。

## 输入
- 验收指标列表（{METRICS}）：统计和物理指标
- 相对误差门限（{MAX_RELATIVE_L2}，默认0.1）
- 是否外推测试（{RUN_OOD_TEST}，默认true）
- 推理结果（来自s04）
- 数据契约（data_contract.json）

## 输出
- 评估报告（evaluation.json）
- 最差样本记录（worst_cases.csv）
- 适用域报告（applicability_report.md）
- 验收结论（PASS/REJECT/BLOCKED）

## 流程节点
```
s05 任务验收与适用域判定
  操作：
    1. 按{METRICS}逐变量评估s04结果
    2. 报告边界误差、守恒或方程残差、最差样本和推理成本
    3. 使用{MAX_RELATIVE_L2}及任务物理门限给出PASS、REJECT或BLOCKED
    4. 若{RUN_OOD_TEST}为true，执行几何或工况外推测试并明确适用域
    5. 不得仅凭平均误差宣称工程可用

  参数：{METRICS}, {MAX_RELATIVE_L2}, {RUN_OOD_TEST}
  质量门禁：
    - 统计与物理指标同时报告
    - 最差样本可追溯
    - 结论含适用域限制与复核建议
```

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 验收指标 | relative_L2, RMSE, conservation_residual, boundary_error | 场景需求书s05 | 统计与物理指标必须同时报告 |
| 外推测试 | 需要（默认true） | 场景需求书s05 | 几何或工况外推测试决定适用域边界 |
| 适用域声明 | 必须含限制与复核建议 | 场景需求书s05 | 域外工况需经CFD复核 |

### 校准数值
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 相对误差门限 | 0.1 | 场景需求书s05 | 以下数值来自场景默认配置，其他体系需以自身证据重新锚定 |

## 边界与分流
- 统计指标通过但物理约束未通过时 → REJECT，不可仅凭统计指标放行
- 物理约束通过但统计指标超门限时 → 需综合判定，标注证据有限
- 外推测试未执行时 → 不得宣称工程可用，需补充测试
- 域外工况外推失败时 → 明确适用域边界，标注需CFD复核
- 最差样本误差显著高于平均时 → 需分析原因并纳入适用域限制

## 质量检查
- 统计与物理指标同时报告
- 最差样本可追溯
- 结论含适用域限制与复核建议
- 评估报告含逐变量误差和推理成本

## 回退策略
- 评估指标不完整时补充缺失指标
- 外推测试失败时降低适用域范围
- 验收结论不明确时增加评估维度
