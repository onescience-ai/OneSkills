# CFD公开数据集获取与使用规范

## 适用范围
本卡适用于CFD神经PDE求解器的训练和验证，提供公开CFD数据集的获取渠道、数据格式、变量定义和使用规范，确保模型基于真实物理数据进行训练和评估。

## 输入
- 研究问题：湍流、多相流、空气动力学、传热传质等
- 数据需求：训练集大小、验证集大小、测试集大小
- 计算资源：存储空间、内存、GPU

## 输出
- 数据集列表：公开CFD数据集的名称、来源、访问方式
- 数据格式规范：统一的数据存储格式和变量定义
- 使用指南：数据预处理、切分、增强的最佳实践

## 流程节点

### 1. 数据集发现与评估
**在线资源库**：
- **Zenodo**：开放数据存储库，支持DOI引用 [论文1]
- **Figshare**：科学数据共享平台
- **GitHub**：开源项目通常附带数据集
- **特定领域库**：如CFD基准数据集库

**评估标准**：
- 数据质量：分辨率、采样频率、噪声水平
- 物理覆盖：是否包含目标物理现象
- 文档完整性：变量定义、单位、边界条件说明
- 许可证：是否允许商业/学术使用

### 2. 数据格式标准化
**通用格式**：
- **HDF5**：层次化数据格式，支持大文件
- **NetCDF**：科学数据格式，支持多维数组
- **VTK**：可视化工具包格式，适合3D场数据
- **CSV**：简单表格数据，适合1D/2D数据

**变量定义**：
- **速度场**：u, v, w (m/s) 或无量纲形式
- **压力场**：p (Pa) 或无量纲形式
- **密度场**：ρ (kg/m³) 或无量纲形式
- **温度场**：T (K) 或无量纲形式
- **相场**：ϕ (无量纲，0-1)

### 3. 数据切分策略
**标准切分**：
- 训练集：80% [论文1]
- 验证集：10% [论文1]
- 测试集：10% [论文1]

**物理一致性切分**：
- 按参数范围切分（如不同雷诺数）
- 按几何形状切分（如不同翼型）
- 按时间窗口切分（如不同演化阶段）

### 4. 数据增强技术
**对称性增强**：
- 旋转对称（90°、180°、270°）[论文1]
- 反射对称（x、y、z轴）
- 平移对称（周期性边界）

**物理一致性增强**：
- 无量纲化（保持物理相似性）
- 参数插值（在已知参数间插值）
- 噪声注入（模拟测量误差）

### 5. 数据质量检查
**物理合理性**：
- 检查守恒量（质量、动量、能量）
- 验证边界条件满足度
- 检查数值稳定性（无发散）

**统计特性**：
- 检查数据分布（均值、方差）
- 验证采样均匀性
- 检查异常值或缺失值

## 边界与分流

### 数据不可用
当目标数据集不可用时：
- 使用合成数据（如解析解生成）
- 采用迁移学习（从相关任务预训练）
- 使用物理信息约束减少数据需求

### 数据质量不足
当数据质量不足时：
- 数据清洗（去除异常值）
- 数据增强（对称性、插值）
- 多保真度学习（结合高低精度数据）

### 计算资源限制
当存储/内存不足时：
- 数据降采样（减少分辨率）
- 数据压缩（如PCA降维）
- 在线学习（不加载全部数据）

## 质量检查
1. **数据完整性**：检查是否有缺失值或损坏文件
2. **物理一致性**：验证守恒量和边界条件
3. **格式一致性**：确保所有数据使用相同格式和单位
4. **文档完整性**：确认变量定义和使用说明完整
5. **许可证合规**：确保数据使用符合许可协议

## 回退策略
1. **数据集找不到**：使用合成数据或物理信息约束
2. **数据格式不兼容**：编写格式转换脚本
3. **数据量不足**：使用数据增强或迁移学习
4. **物理不一致**：重新检查数据生成过程或使用物理约束
