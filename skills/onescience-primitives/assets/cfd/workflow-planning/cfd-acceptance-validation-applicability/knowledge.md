# 任务验收与适用域判定

## 适用范围

本步骤适用于生成模型与智能体工程外形协同设计流程的第五步，负责评估统计误差、关键物理约束、泛化能力和计算收益，给出PASS、REJECT或BLOCKED结论，并明确适用域限制与复核建议。

## 输入

- **验收指标**：{METRICS} - 统计和物理指标
- **相对误差门限**：{MAX_RELATIVE_L2} - 测试集放行阈值
- **外推测试标志**：{RUN_OOD_TEST} - 是否测试域外工况
- **设计候选**：来自步骤4的design_candidates/、optimization_history.csv

## 输出

- **评估报告**：evaluation.json - 详细评估结果
- **最差样本**：worst_cases.csv - 性能最差的样本信息
- **适用域报告**：applicability_report.md - 适用域限制与复核建议
- **验收结论**：PASS_REJECT_BLOCKED.txt - 最终验收结论

## 流程节点

### 1. 指标评估
- 按{METRICS}评估s04结果
- 报告逐变量误差、边界误差、守恒或方程残差
- 计算最差样本和推理成本

### 2. 误差分析
- 分析统计误差分布
- 识别系统性偏差和异常模式
- 评估误差来源和影响

### 3. 物理约束验证
- 验证关键物理约束（如守恒律、边界条件）
- 检查物理一致性（如能量守恒、动量守恒）
- 评估物理合理性

### 4. 泛化能力测试
- 若{RUN_OOD_TEST}为true，执行几何或工况外推测试
- 评估模型在域外工况的表现
- 识别泛化能力的限制

### 5. 适用域判定
- 基于评估结果划定适用域
- 识别适用域边界和限制条件
- 提出复核建议和改进方向

### 6. 验收结论
- 使用{MAX_RELATIVE_L2}及任务物理门限给出PASS、REJECT或BLOCKED
- 记录验收理由和条件
- 输出最终结论

## 边界与分流

- **验收不通过**：根据错误类型选择重新训练、调整设计或CFD复核
- **泛化能力不足**：扩大训练数据范围或使用域适应技术
- **物理约束违反**：调整模型架构或训练策略
- **计算成本过高**：优化模型推理效率或使用代理模型
- **适用域过窄**：增加训练数据多样性或使用迁移学习

## 质量检查

- **全面性检查**：统计与物理指标同时报告
- **可追溯性检查**：最差样本可追溯
- **完整性检查**：结论含适用域限制与复核建议
- **客观性检查**：评估基于客观指标，避免主观判断
- **可操作性检查**：结论明确，便于后续决策

## 回退策略

- **评估失败**：使用不同的评估指标或方法
- **验收标准不明确**：与利益相关者确认验收标准
- **适用域判定困难**：使用更保守的适用域边界
- **复核建议不清晰**：提供更详细的改进方向
