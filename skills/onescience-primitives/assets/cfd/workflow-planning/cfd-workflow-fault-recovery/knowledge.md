# CFD工作流异常恢复与降级执行

## 适用范围

面向CFD工作流执行过程中的异常恢复与降级执行，提供超时检测、中间状态保存、断点续训、降级策略的触发条件和执行流程。适用于编排器设计、任务调度器实现和容错机制构建。

## 输入

- 异常类型：超时、API限流、环境不可用、资源不足
- 当前状态：已完成步骤、中间产物路径
- 降级选项：数据缩减、模型简化、时间预算调整

## 输出

- 异常检测信号（超时预警、资源监控）
- 中间状态保存点（checkpoint）
- 降级执行方案（自动/手动触发）
- 恢复后状态验证

## 流程节点

1. **异常检测** → 监控执行时间、资源使用、API响应状态
2. **状态保存** → 序列化当前进度到task_state.json
3. **降级决策** → 根据异常类型选择降级策略
4. **降级执行** → 缩减数据规模/简化模型/调整超参数
5. **恢复验证** → 验证降级后状态的正确性和完整性

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 超时预警阈值 | 预算的80% | [3] | 提前预警，预留降级决策时间 |
| Checkpoint频率 | 每完成一个step | [2] | 最小化重做工作量 |
| 降级触发条件 | 超时/资源不足/API限流 | [3] | 自动检测并触发 |
| 最大重试次数 | 3次 | [2] | 超过则降级或终止 |

### 校准数值（CFD工作流场景）

| 异常类型 | 检测方式 | 降级策略 | 来源 |
|----------|----------|----------|------|
| 单步超时 | wallclock_budget监控 | 减小batch_size、降低epochs | [3] |
| 总任务超时 | 全局时间累加 | 跳过非关键步骤、简化评估 | [3] |
| API限流(429) | HTTP响应码检测 | 指数退避重试、切换备用API | [3] |
| 环境不可用 | 连接/执行失败检测 | 切换备用环境、本地降级执行 | [2] |
| 内存不足 | OOM错误捕获 | 减小数据规模、使用梯度累积 | 经验值 |

## 边界与分流

- **可恢复异常**：超时、API限流 → 自动重试+降级
- **不可恢复异常**：硬件故障、数据损坏 → 终止并报告
- **降级失败**：降级后仍超时 → 保存当前状态，人工介入
- **状态不一致**：checkpoint损坏 → 回退到最近有效checkpoint

## 质量检查

- Checkpoint完整性验证（文件存在、可解析）
- 降级后状态一致性检查（参数匹配、数据完整）
- 恢复后性能验证（模型精度不低于降级前80%）

## 回退策略

- 降级执行失败：保存中间状态，等待人工介入
- Checkpoint损坏：回退到上一个有效checkpoint
- 资源完全耗尽：终止任务，保留所有中间产物
