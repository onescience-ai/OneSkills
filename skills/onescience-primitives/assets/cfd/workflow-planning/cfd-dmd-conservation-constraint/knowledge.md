# DMD降阶模型守恒约束

## 适用范围

面向DMD（Dynamic Mode Decomposition）降阶模型的物理守恒约束机制。DMD方法本身不保证降阶模型满足Navier-Stokes方程的守恒性质（质量、动量、能量守恒），导致守恒残差可能远超验收阈值。本卡给出在DMD框架内施加守恒约束的数学表达、惩罚项构造方法和实现策略，适用于不可压缩与可压缩流动的降阶建模。不适用于纯POD降阶模型（POD通过Galerkin投影可部分保持守恒性），也不适用于不涉及物理守恒律的降阶任务。

## 输入

- DMD模态矩阵 Φ ∈ C^(m×r) 和特征值 Λ
- 原始快照矩阵 X 和时间移位矩阵 X'
- 控制方程（Navier-Stokes方程的离散形式）
- 守恒量定义（质量ρ、动量ρu、能量ρE）

## 输出

- 施加守恒约束后的DMD模型
- 守恒残差指标（conservation_residual）
- 守恒约束的惩罚项值

## 流程节点

### 守恒方程离散化
- **操作**：将Navier-Stokes方程在降阶空间中离散化，构造守恒残差算子
- **数学表达**：
  - 质量守恒：∇·u = 0（不可压缩）或 ∂ρ/∂t + ∇·(ρu) = 0（可压缩）
  - 动量守恒：∂(ρu)/∂t + ∇·(ρu⊗u) = -∇p + ∇·τ + ρg
  - 能量守恒：∂(ρE)/∂t + ∇·(ρEu) = -∇·(pu) + ∇·(τ·u) + ρq
- **参数**：离散格式（有限差分/有限体积/谱方法）
- **工具**：NumPy/SciPy
- **质量门禁**：守恒残差算子维度与降阶空间一致

### 守恒残差惩罚项构造
- **操作**：在DMD的目标函数中添加守恒残差的L2范数惩罚项
- **数学表达**：
  - 目标函数：min ||X' - ΦΛΦ†X||² + λ·||R(Φ,Λ)||²
  - 其中 R(Φ,Λ) 为守恒残差向量，λ 为惩罚系数
  - 守恒残差 R 定义为：将DMD重构流场代入离散守恒方程后的残差
- **参数**：惩罚系数λ（通过交叉验证选择，典型范围 1e-2 ~ 1e2）
- **工具**：SciPy.optimize
- **质量门禁**：惩罚项在优化过程中单调下降；最终守恒残差 < 1e-6

### 约束投影方法
- **操作**：将DMD模态投影到满足守恒约束的子空间中
- **方法一（后处理投影）**：对标准DMD结果进行守恒校正，将不满足守恒性的模态分量投影到守恒流形上
- **方法二（约束优化）**：在DMD求解过程中直接加入等式约束，确保解在守恒流形上
- **参数**：投影方法选择（后处理/在线约束）、守恒流形维度
- **工具**：NumPy/SciPy
- **质量门禁**：投影后DMD模态仍满足正交性（POD基）或近似正交性

### 守恒验证
- **操作**：计算施加约束后的DMD模型在独立测试集上的守恒残差
- **验证指标**：
  - 质量守恒残差：max|∇·u_pred|
  - 动量守恒残差：||NS(u_pred, p_pred)||
  - 能量守恒残差：||Energy_eq(u_pred, T_pred)||
- **参数**：验收阈值（conservation_residual < 1e-6）
- **工具**：NumPy
- **质量门禁**：所有守恒残差 < 1e-6；与全阶CFD解的守恒残差量级一致

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 守恒残差验收阈值 | < 1e-6 | 领域标准 | Navier-Stokes方程守恒性的基本要求 |
| 惩罚系数λ范围 | 1e-2 ~ 1e2 | 经验值 | 通过交叉验证选择最优值 |
| 守恒验证指标 | 质量+动量+能量 | 领域标准 | 三重守恒缺一不可 |
| 网格收敛性 | 残差随网格加密减小 | [D1] | 确保数值误差而非方法缺陷 |

### 校准数值

以下数值来自典型圆柱绕流体系，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 无约束DMD守恒残差 | ~300（量级） | 归因报告 | 未施加约束时的典型值 |
| 施加约束后目标值 | < 1e-6 | 领域标准 | 满足生产环境要求 |
| 惩罚系数最优值 | ~1.0 | 经验值 | 需针对具体问题调优 |

## 边界与分流

- **不可压缩流**：仅需质量守恒（∇·u=0）和动量守恒，能量守恒可退化为温度输运方程
- **可压缩流**：需完整守恒三组方程（质量/动量/能量），约束更强，优化难度更大
- **湍流模型耦合**：若使用RANS湍流模型，还需确保湍流量（k, ε, ω）的守恒/输运约束
- **约束过强导致精度下降**：λ 过大会过度约束DMD模态，降低预测精度；需在守恒性和精度之间权衡
- **高维问题**：三维流动的守恒约束维度大，可考虑分量独立约束或降维后再约束

## 质量检查

- [ ] 守恒残差 < 1e-6
- [ ] 惩罚项在优化中单调下降
- [ ] DMD模态物理合理性（特征值对应物理频率）
- [ ] 约束施加后精度损失 < 5%
- [ ] 与全阶CFD解的守恒残差量级一致

## 回退策略

- 约束优化不收敛 → 降低惩罚系数λ，或改用后处理投影方法
- 精度损失过大 → 减小λ，或仅对关键守恒量（如质量）施加强约束
- 高维问题计算量过大 → 采用分块约束或仅在关键区域施加约束
