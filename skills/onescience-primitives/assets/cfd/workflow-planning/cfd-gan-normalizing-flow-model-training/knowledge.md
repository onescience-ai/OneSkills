# GAN与正规化流湍流降阶模型配置与训练

## 适用范围

本任务适用于 GAN 与正规化流湍流降阶生成的模型训练阶段，使用 GAN 或 Normalizing Flow 训练湍流降阶生成模型，完成指定输入到目标物理量的映射。

**触发条件**：
- 已通过 s02 预处理与数据切分
- 需要训练 GAN 或 Normalizing Flow 生成模型
- 训练配置已确定

**不适用场景**：
- 数据切分未完成（需返回 s02）
- 需要训练非生成式模型（如 POD、DMD）

## 输入

**上游产物**：
- s02 产出的 train_manifest.json、validation_manifest.json、normalization.json

**参数**：
- 模型名称（{MODEL_NAME}，默认 GAN/Normalizing flow）
- 训练配置（{TRAIN_CONFIG}）：framework: PyTorch, epochs: 100, batch_size: 8, learning_rate: 0.001, seed: 42, early_stopping_patience: 15
- 初始权重（{INIT_CHECKPOINT}，可选预训练权重）

## 输出

**训练产物**：
- best_checkpoint.pt：最佳模型权重
- train_config.json：训练配置（含代码版本、依赖）
- training_metrics.csv：逐轮训练验证指标
- environment.txt：环境依赖记录

**验证标准**：
- 训练验证损失均为有限值
- 最佳权重可重新加载
- 配置环境随机种子可复现

## 边界与分流

**前提条件与改道**：

1. **s02 切分数据可用**
   - 不成立时 → 改道：返回 s02 重新执行切分

2. **训练收敛**
   - 不成立时 → 改道：调整超参、切换 GAN↔Normalizing Flow 架构、或使用预训练权重微调

3. **初始权重兼容**
   - 不成立时 → 改道：检查模型架构兼容性、跳过初始权重从头训练

4. **计算资源充足**
   - 不成立时 → 改道：减小 batch_size、使用混合精度训练、或降级到更小模型

## 质量检查

**验证点**：
- 损失曲线收敛性检查
- 最佳权重加载验证
- 随机种子复现性测试
- 环境依赖完整性检查

**阈值**：
- 损失有限性 100%
- 权重可加载 100%
- 随机种子复现 100%

**失败处理**：
- 损失爆炸 → 降低学习率、添加梯度裁剪、检查数据
- 权重不可加载 → 检查架构兼容性、保存格式
- 不可复现 → 检查随机种子设置、依赖版本

## 回退策略

**失败时的替代方案**：
1. GAN 训练失败 → 切换到 Normalizing Flow 或 POD 方法
2. Normalizing Flow 训练失败 → 切换到 GAN 或 POD 方法
3. 两者均失败 → 回退到传统 CFD 计算
4. 资源不足 → 降级到小规模模型或简化数据
