# 物理约束神经算子预处理与数据切分

## 适用范围
面向带守恒边界和无量纲约束PDE数据的预处理与数据切分任务，依据数据契约完成质控、重采样或图构建、掩膜、归一化或无量纲化，按几何、完整轨迹或物理工况为单位切分，不得把同一轨迹的帧随机打散，为目标变量保存统计量与可逆变换。适用于Physics-constrained neural operator训练的数据准备阶段，确保数据质量和切分有效性。

## 输入
- **数据契约**（来自s01）：定义变量单位、网格坐标、边界条件类型和守恒律约束
- **切分配置**（必填）：按对象工况切分比例、随机种子、分组方式
- **目标变量**（必填）：待预测物理量列表
- **是否无量纲化**（可选）：统一跨工况量纲，默认true

## 输出
- **train_manifest.json**：训练集清单，包含样本列表和统计量
- **validation_manifest.json**：验证集清单，包含样本列表和统计量
- **test_manifest.json**：测试集清单，包含样本列表和统计量
- **normalization.json**：归一化统计量，支持可逆变换

## 流程节点
1. **数据质控** → 检查数据完整性、异常值和一致性
2. **重采样或图构建** → 根据数据类型进行重采样或构建图结构
3. **掩膜处理** → 处理边界掩膜和缺失值掩膜
4. **归一化或无量纲化** → 统一物理量表示，保存变换统计量
5. **数据切分** → 按几何、完整轨迹或物理工况为单位切分
6. **统计量保存** → 保存训练集统计量用于可逆变换

## 边界与分流
- **数据契约缺失** → 返回BLOCKED，要求先完成数据接入与契约核验
- **边界条件类型未知** → 警告并建议使用通用边界条件处理流程
- **守恒律约束不明确** → 警告并建议人工确认守恒约束
- **无量纲化困难** → 转向基于物理量纲的归一化方法
- **数据质量差** → 建议数据清洗或插值处理
- **切分比例不合理** → 警告并建议调整切分配置

## 质量检查
- **三份切分的对象轨迹互斥**：训练/验证/测试集无重叠样本
- **仅用训练集计算变换统计量**：防止数据泄漏
- **边界与掩膜语义未破坏**：物理约束在预处理后仍有效

## 回退策略
- **数据质量不足** → 建议数据清洗或插值处理
- **切分无效** → 调整切分配置或分组方式
- **无量纲化失败** → 转向基于物理量纲的归一化方法
