# 公开汽车CFD数据集获取指南

## 适用范围
面向汽车空气动力学CFD任务，提供公开数据集的获取方法、下载命令、数据格式说明和预处理要求。适用于需要真实汽车CFD数据进行模型训练、验证和评估的场景，不适用于使用模拟数据或内部专有数据集的场景。

## 输入
- 数据集名称或关键词（如 DrivAerNet, Ahmed body, WindsorML）
- 下载目标路径
- 网络连接权限（用于访问 GitHub、Kaggle、Zenodo 等平台）

## 输出
- 下载的数据集文件（格式可能为 HDF5、NPZ、VTK 等）
- 数据集清单文件（如 dataset_manifest.json）
- 数据审计报告（如 data_audit.md）

## 流程节点
1. **数据集识别** → 根据任务需求选择合适的数据集（DrivAerNet、Ahmed body、WindsorML 等）
2. **数据源定位** → 确定数据集的存储位置（GitHub、Kaggle、Zenodo 等）
3. **下载方法选择** → 根据数据源选择下载命令（git clone、wget、API 调用等）
4. **数据格式验证** → 检查下载文件的格式是否符合预期（HDF5、NPZ、VTK 等）
5. **预处理要求分析** → 根据数据集文档确定预处理步骤（网格转换、归一化、切分等）

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| DrivAerNet | 开源汽车CFD数据集 | [用户自有] | 包含多种车型的表面网格和流场数据 |
| Ahmed body | 经典汽车气动基准模型 | [用户自有] | 用于气动性能基准测试 |
| WindsorML | 高保真汽车CFD数据集 | [用户自有] | 提供高分辨率流场数据 |

## 边界与分流
- 若数据集无法从公开来源获取（如 GitHub 仓库不存在、Kaggle 404 错误），应记录失败原因并考虑使用模拟数据作为临时替代（但需标注限制）。
- 若数据格式与任务要求不匹配，需进行格式转换或选择其他数据集。
- 若网络连接受限，应考虑离线下载或使用镜像源。

## 质量检查
- 验证下载文件的完整性（如校验和、文件大小）。
- 检查数据格式是否符合任务要求（如字段名称、维度）。
- 确认数据集许可证允许用于研究目的。

## 回退策略
- 若公开数据集获取失败，可考虑使用模拟数据（但需记录模拟数据的局限性）。
- 若多个数据源均不可用，可尝试联系数据集作者或寻找替代数据集。

## 资源召回建议
