# 湍流场物理约束筛选阈值范围

## 适用范围
本规范适用于湍流场生成样本的物理约束筛选，定义合理的阈值范围，包括连续性方程残差、能量谱残差、涡量散度等，确保生成的样本满足基本物理规律。适用于需要筛选生成样本以保留物理合理样本的场景。不适用于其他类型流体（如层流、可压缩流）的约束筛选。

## 输入
- 生成的湍流场样本（速度场、压力场等）
- 物理约束定义（如连续性方程、能量谱、涡量散度）
- 阈值参数（残差容差、相对误差等）

## 输出
- 筛选后的样本集合
- 筛选统计信息（通过率、拒绝率、残差分布）
- 物理约束验证报告

## 流程节点
1. **约束定义** → 定义物理约束（如连续性方程 ∇·u = 0）
2. **残差计算** → 计算每个样本的约束残差（如速度散度的最大值、L2范数）
3. **阈值设定** → 根据真实湍流数据的统计特性设定阈值
4. **样本筛选** → 根据阈值筛选样本，保留满足约束的样本
5. **统计报告** → 生成筛选统计信息和验证报告

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 连续性方程残差阈值 | ≤ 1e-3（相对误差） | 领域知识 | 基于DNS数据统计 |
| 能量谱残差阈值 | ≤ 10%（相对误差） | 领域知识 | 低波数段更重要 |
| 涡量散度阈值 | ≤ 1e-2（绝对值） | 领域知识 | 不可压缩流假设 |
| 通过率期望 | ≥ 30% | 领域知识 | 避免过度筛选 |

## 边界与分流
- **阈值过严**：若阈值设置过严导致无样本通过，应放宽阈值或使用相对阈值
- **阈值过松**：若阈值过松导致物理不合理样本通过，应收紧阈值或增加约束
- **多约束冲突**：若多个约束相互冲突，优先保证关键约束（如连续性方程）

## 质量检查
- 验证筛选后样本的物理约束残差在阈值内
- 检查通过率是否合理（避免过拟合或欠筛选）
- 确保筛选统计信息完整（残差分布、通过率）
- 验证生成样本的统计特性与真实数据一致

## 回退策略
- 若所有样本均被拒绝，可放宽阈值或使用更宽松的约束
- 若筛选后样本质量差，可尝试使用更复杂的物理约束（如Navier-Stokes残差）
- 若计算资源不足，可使用简化约束（如仅检查连续性方程）
