# 非笛卡尔晶格与曲面网络流动数据格式标准

## 适用范围
本卡片服务于CFD模拟中涉及非笛卡尔网格（包括曲线网格、非结构化网格）和曲面网络的数据格式选择与数据集获取任务。当模拟任务需要处理复杂几何形状、弯曲边界或自由曲面时，需要采用非笛卡尔网格表示，此时数据格式的选择和数据源的获取成为任务执行的关键前提。本卡片提供数据格式标准、典型数据源和获取方式，确保数据接入阶段可顺利执行。

## 输入
- 任务描述中指定的几何类型（如曲面、弯曲管道、复杂边界）
- 模拟需求（如稳态/瞬态、可压缩/不可压缩流动）
- 数据格式兼容性要求（如与特定求解器或后处理工具的兼容性）
- 数据源类型偏好（如公开数据集、模拟生成数据、实验数据）

## 输出
- 符合标准的数据文件（如CGNS、OpenFOAM格式）
- 数据集元数据（包含网格拓扑、变量定义、单位约定）
- 数据质量验证报告（可选）

## 流程节点
1. **几何分析** → 分析任务几何特征，确定网格类型需求（结构化/非结构化/混合网格）
2. **格式选择** → 根据几何类型和求解器要求选择数据格式（CGNS、OpenFOAM、Gmsh等）
3. **数据源定位** → 搜索公开数据集或生成模拟数据
4. **数据获取** → 下载或生成数据文件
5. **格式验证** → 检查数据文件完整性和格式符合性

每步操作：
- 几何分析：使用几何处理工具（如Gmsh、Salome）分析曲面特征
- 格式选择：参考CGNS标准或求解器文档选择兼容格式
- 数据源定位：搜索CFD数据仓库（如CFD Open Access Repository、NASA Turbulence Modeling Resource）
- 数据获取：使用wget/curl下载或运行生成脚本
- 格式验证：使用格式验证工具（如cgns-check、checkMesh）

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| CGNS标准版本 | 4.x | [D1] | CFD通用符号系统，支持结构化/非结构化网格 |
| OpenFOAM网格格式 | foam-extend 5.x | [D2] | 支持多面体网格、曲面网格 |
| 典型数据格式 | CGNS, OpenFOAM, Gmsh, VTK | [D1][D2] | 不同求解器支持不同格式 |
| 网格拓扑类型 | 结构化、非结构化、混合 | [D1] | 根据几何复杂度选择 |
| 变量定义标准 | 物理量名称、单位、坐标系 | [D1] | 遵循CGNS或求解器约定 |

## 边界与分流
- **几何过于复杂**：考虑使用自适应网格细化（AMR）或笛卡尔网格浸入边界法
- **数据格式不兼容**：使用格式转换工具（如cgns-convert、fluent2foam）
- **数据源不可用**：使用网格生成工具（如Gmsh、snappyHexMesh）从CAD模型生成
- **数据量过大**：使用数据压缩或并行I/O格式

## 质量检查
- 网格质量检查：检查网格正交性、偏斜度、纵横比
- 数据完整性检查：验证所有必要变量存在且无NaN值
- 单位一致性检查：确保所有变量使用一致的单位系统
- 格式符合性检查：使用标准验证工具检查文件格式

## 回退策略
- 如果标准格式不兼容，尝试使用中间格式转换
- 如果公开数据集不可用，使用简化几何生成测试数据
- 如果网格质量不达标，进行网格优化或重新生成
