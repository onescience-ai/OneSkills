# 任务验收与适用域判定

## 适用范围

本卡描述可迁移ROM工作流第五步：评估推理结果的统计误差、物理约束满足度、泛化能力和计算收益，给出PASS/REJECT/BLOCKED判定，并明确适用域限制与复核建议。适用于可迁移ROM部署前的最终验收。

## 输入

| 输入 | 类型 | 必填 | 说明 |
|------|------|------|------|
| s04推理结果 | doc | 是 | predictions/目录 |
| {METRICS} | list[str] | 是 | 验收指标列表（统计+物理） |
| {MAX_RELATIVE_L2} | float | 否 | 相对L2误差门限（默认0.1） |
| {RUN_OOD_TEST} | bool | 否 | 是否执行域外工况测试（默认true） |

## 输出

| 输出 | 说明 |
|------|------|
| evaluation.json | 完整评估结果（逐变量误差、物理指标、汇总统计） |
| worst_cases.csv | 最差样本清单（含样本ID、误差值、原因分析） |
| applicability_report.md | 适用域报告（泛化能力、限制条件、复核建议） |
| PASS_REJECT_BLOCKED.txt | 最终判定文件 |

## 流程节点

1. **统计误差计算**：计算relative_L2、RMSE等统计指标
2. **物理约束验证**：计算守恒残差、边界误差等物理指标
3. **逐变量评估**：对每个目标变量分别报告误差
4. **最差样本分析**：识别并分析误差最大的样本
5. **推理成本统计**：报告推理时间与计算资源消耗
6. **OOD测试**：若{RUN_OOD_TEST}为true，执行几何或工况外推测试
7. **适用域判定**：基于所有评估结果划定模型适用范围
8. **判定输出**：根据{MAX_RELATIVE_L2}及物理门限给出PASS/REJECT/BLOCKED

## 关键参数

### 通用判据

| 参数 | 判据 | 来源 | 说明 |
|------|------|------|------|
| 指标完备性 | 统计与物理指标同时报告 | s05质量门禁 | 评估全面性 |
| 最差样本可追溯 | 每个最差样本有唯一ID与原因分析 | s05质量门禁 | 问题定位基础 |
| 适用域明确 | 结论含适用域限制与复核建议 | s05质量门禁 | 部署安全性 |
| OOD评估 | 域外工况需执行外推测试 | s05质量门禁 | 泛化能力验证 |
| 不凭平均误差宣称 | 不得仅凭平均误差宣称工程可用 | s05流程要求 | 避免评估偏差 |

### 校准数值

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认验收指标 | relative_L2, RMSE, conservation_residual, boundary_error | 场景需求书s05 | 其他体系需重新锚定 |
| 默认相对L2门限 | 0.1 | 场景需求书s05 | 其他体系需重新锚定 |
| 默认OOD测试 | true | 场景需求书s05 | 建议始终执行 |

## 边界与分流

- 相对L2 ≤ 门限且物理指标满足 → PASS
- 相对L2 > 门限或物理指标不满足 → REJECT，需调整模型或数据
- 推理结果不可用（含NaN/Inf） → BLOCKED，需回到s04检查
- 域外工况泛化不足 → 在applicability_report中标注限制，域外需CFD复核
- 最差样本误差过大 → 分析原因，决定是否需要针对性改进

## 质量检查

- 统计与物理指标同时报告（缺一不可）
- 最差样本可追溯到具体测试样本ID
- 结论必须包含适用域限制与复核建议
- 不得仅凭平均误差宣称工程可用
- OOD测试结果单独报告

## 回退策略

- 评估指标不达标：根据误差分析回到s02（数据）或s03（模型）修复
- 适用域过窄：增加训练数据覆盖范围或采用更灵活的参数化方案
- 物理约束不满足：在损失函数中增加物理正则项或后处理修正
- 最差样本分析：针对特定工况增加训练数据或调整模型

## 资源召回建议

当任务需要对可迁移ROM进行最终验收与适用域判定时召回本卡片。本卡片是工作流最后一步，完成后可输出部署决策。
