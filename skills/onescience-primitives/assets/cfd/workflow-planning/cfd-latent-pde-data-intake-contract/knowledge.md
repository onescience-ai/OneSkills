# 连续坐标PDE数据接入与契约核验

## 适用范围
本卡描述如何为潜空间与神经场连续PDE算子学习建立数据清单与机器可读契约。适用于接收连续坐标PDE数据后、进行预处理前的数据验证阶段。

## 输入
- 数据集路径（目录或清单文件）
- 数据集名称与来源
- 可选的数据契约定义

## 输出
- dataset_manifest.json：数据清单
- data_contract.json：机器可读契约
- data_audit.md：数据审计报告

## 流程节点
1. 读取数据文件 → 验证可读性
2. 检查样本数、输入与目标变量、单位、坐标系、网格拓扑
3. 检查时间或工况范围、缺失值和使用许可
4. 按数据契约输出机器可读契约

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必填输入 | 数据集路径 | 场景需求书 | 缺失则返回BLOCKED |
| 变量检查 | 输入/目标变量 | 场景需求书 | 需明确定义 |
| 单位检查 | 物理单位 | 场景需求书 | 需统一量纲 |
| 坐标系 | 空间坐标定义 | 场景需求书 | 需明确坐标系类型 |

## 边界与分流
- 数据文件不可读 → 返回BLOCKED，列出缺项
- 变量定义不完整 → 返回BLOCKED，不得编造变量
- 单位不统一 → 在预处理阶段统一，此处仅记录

## 质量检查
- 数据文件可读且样本可追溯
- 输入目标变量单位坐标定义完整
- 不存在训练测试泄漏

## 回退策略
数据不可用时，需联系数据提供方补充或修正。

## 资源召回建议
当任务涉及PDE数据接入、需要验证数据完整性时召回本卡。
