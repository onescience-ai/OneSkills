# 工作流预检清单管理

## 适用范围
工作流编排系统中前置校验文件（execution-manifest.json）的生成、格式定义与校验机制管理。适用于任何需要在执行前验证任务清单、步骤定义和产物预期的编排场景，确保编排器规划完成后能正确启动执行流程。

## 输入
- 编排器生成的任务计划（Global Plan）
- 步骤清单与依赖关系
- 产物预期与状态元数据

## 输出
- 符合格式要求的execution-manifest.json文件
- 校验通过状态（退出码0）

## 流程节点
1. **计划解析** → 从编排器输出中提取步骤清单和依赖关系
2. **清单生成** → 创建execution-manifest.json，包含任务ID、步骤清单、产物清单和状态元数据
3. **格式校验** → 验证清单格式符合预检要求（JSON结构、必填字段、类型检查）
4. **内容校验** → 验证清单内容与任务计划一致（步骤数量、依赖关系、产物路径）
5. **预检执行** → 运行workflow_preflight.py，确保退出码为0

每步含：操作、参数、工具、质量门禁

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 清单格式 | JSON | 技术推理 | 必须为有效的JSON格式 |
| 必填字段 | task_id, steps, artifacts, status | 技术推理 | 缺少任一字段将导致校验失败 |
| 校验时机 | 编排器规划完成后、执行步骤前 | 技术推理 | 过早或过晚生成都会导致流程问题 |
| 退出码 | 0表示成功 | 技术推理 | 非0退出码表示校验失败 |

### 校准数值
以下数值来自边界嵌入与任意阶硬约束神经场求解任务场景，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 任务ID格式 | "CFD_S064" | 归因报告 | 任务唯一标识符 |
| 步骤数量 | 5步（s01-s05） | 归因报告 | 典型CFD工作流步骤数 |
| 产物类型 | dataset_manifest, data_contract等 | 技术推理 | 工作流中间产物 |

## 边界与分流
- **清单缺失**：workflow_preflight.py将以退出码1终止，阻止任何步骤执行
- **清单格式错误**：预检失败，需修复格式后重新生成
- **清单内容不匹配**：预检失败，需调整清单与任务计划一致
- **编排器超时**：清单未生成，需在超时前完成清单生成步骤

## 质量检查
- 验证execution-manifest.json为有效JSON
- 验证所有必填字段存在且类型正确
- 验证步骤清单与任务计划一致
- 运行workflow_preflight.py确认退出码为0

## 回退策略
- 清单生成失败时，回退到编排器重新生成任务计划
- 格式校验失败时，根据错误信息修复清单格式
- 内容校验失败时，调整清单内容与任务计划对齐

## 资源召回建议
- 当编排器规划完成后，召回本卡片生成execution-manifest.json
- 当预检校验失败时，召回本卡片检查清单格式和内容
- 当需要定义新的工作流步骤时，参考本卡片的清单格式规范
