# 神经-数值耦合求解

## 适用范围
将训练好的神经模块（平滑器、预条件器、代理模型、校正器）嵌入传统数值求解器，执行端到端迭代求解。适用于：
- 需要神经加速的大规模PDE求解任务
- 瞬态PDE问题（需要时间步进求解）
- 传统求解器收敛慢、需要神经增强的场景
- 多物理场耦合问题（神经模块作为子求解器）

**不适用场景**：
- 神经模块未经训练或训练不充分
- 数值求解器接口不支持自定义预条件器/平滑器
- 计算资源严重受限（神经推理开销过大）

## 输入
- **模型权重**：训练好的神经模块权重（.pt/.pth/.onnx）
- **数值求解器**：传统求解器配置（OpenFOAM、FEniCS等）
- **初始场**：PDE求解初值
- **边界条件**：Dirichlet、Neumann、Robin边界条件
- **求解参数**：收敛容差、最大迭代次数、时间步长

## 输出
- **数值解场**：PDE解的时空分布
- **残差历史**：每步残差范数序列
- **求解时间**：各阶段耗时（神经推理、数值迭代、总时间）
- **守恒量**：质量/能量/动量守恒误差
- **收敛状态**：收敛/发散/达到最大迭代

## 流程节点
```
神经模块加载 → 耦合接口配置 → 端到端迭代求解 → 残差与守恒监控 → 收敛判定与输出
```

### 1. 神经模块加载
- **操作**：加载训练好的神经模块权重，验证模型结构
- **参数**：权重路径、模型架构、设备（CPU/GPU）
- **工具**：PyTorch/TensorFlow加载函数
- **质量门禁**：权重文件可加载；模型结构与训练时一致；设备兼容

### 2. 耦合接口配置
- **操作**：配置神经模块与数值求解器的接口
- **参数**：接口变量（残差、解向量、网格信息）、数据格式、单位转换
- **工具**：求解器API、自定义接口代码
- **质量门禁**：接口变量单位一致；数据格式匹配；无内存泄漏

### 3. 端到端迭代求解
- **操作**：执行迭代求解，神经模块与数值求解器交替工作
- **参数**：收敛容差、最大迭代次数、时间步长（瞬态问题）
- **工具**：数值求解器、神经推理引擎
- **质量门禁**：迭代稳定推进；无数值溢出；神经推理开销可控

### 4. 残差与守恒监控
- **操作**：监控每步残差、守恒量、数值稳定性
- **参数**：残差容差、守恒误差阈值、发散检测阈值
- **工具**：监控脚本、日志记录
- **质量门禁**：残差单调递减（或在容差内波动）；守恒误差小于阈值；无发散迹象

### 5. 收敛判定与输出
- **操作**：判定收敛状态，输出求解结果和诊断信息
- **参数**：收敛判据、输出格式
- **工具**：结果处理脚本
- **质量门禁**：收敛判定准确；输出完整；诊断信息可追溯

## 边界与分流
- **前提1：神经模块可加载** → 若权重损坏或架构不匹配，重新训练或使用替代模块
- **前提2：耦合接口正确** → 若接口变量不匹配，检查数据契约、修复接口代码
- **前提3：迭代稳定** → 若发散，降低时间步长、调整预条件器、切换求解器
- **前提4：计算资源充足** → 若资源不足，使用混合精度、减少批大小、分布式计算

## 质量检查
- **收敛验证**：残差范数应单调递减（或在容差内波动）
- **守恒验证**：解应满足质量/能量守恒（视PDE类型）
- **稳定性验证**：无数值溢出、除零等异常
- **性能验证**：求解时间符合预期，神经推理开销可控

## 回退策略
- **神经模块失败**：使用传统预条件器/平滑器，或重新训练
- **发散检测**：保存最后稳定状态，降低时间步长或迭代参数后重试
- **守恒违反**：检查边界条件、数值格式，调整求解参数
- **性能不足**：优化神经推理、使用混合精度、并行化
