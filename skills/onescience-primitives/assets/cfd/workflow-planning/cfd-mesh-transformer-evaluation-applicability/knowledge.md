# 任务验收与适用域判定

## 适用范围

**触发条件**：
- 已有推理结果（s04输出）
- 需要评估统计误差和物理一致性
- 需要给出验收结论和适用域判定

**适用场景**：
- 大规模网格Transformer流场预测的评估阶段
- 任何需要对神经PDE求解器进行验收评估的场景

**不适用场景**：
- 仅需简单误差计算
- 无需物理一致性评估的场景

## 输入

| 输入 | 类型 | 必填 | 说明 |
|------|------|------|------|
| {METRICS} | list[str] | 是 | 验收指标列表 |
| {MAX_RELATIVE_L2} | float | 否 | 相对误差门限（默认0.1） |
| {RUN_OOD_TEST} | bool | 否 | 是否外推测试（默认true） |

**{METRICS}默认值**：
- relative_L2：相对L2误差
- RMSE：均方根误差
- conservation_residual：守恒残差
- boundary_error：边界误差

## 输出

| 输出 | 格式 | 说明 |
|------|------|------|
| evaluation.json | JSON | 评估结果（逐变量误差、守恒残差等） |
| worst_cases.csv | CSV | 最差样本详情（样本ID、误差值） |
| applicability_report.md | Markdown | 适用域报告（适用范围、限制、复核建议） |
| PASS_REJECT_BLOCKED.txt | Text | 验收结论（PASS/REJECT/BLOCKED） |

## 操作流程

### 1. 统计误差评估
- 计算逐变量relative_L2
- 计算RMSE
- 识别最差样本

### 2. 物理约束评估
- 计算守恒残差（conservation_residual）
- 计算边界误差（boundary_error）
- 检查物理合理性

### 3. 泛化能力评估
- 若{RUN_OOD_TEST}为true，执行几何或工况外推测试
- 评估域外性能
- 明确适用域边界

### 4. 计算收益评估
- 记录推理成本
- 与传统CFD方法对比（如可能）

### 5. 验收结论
- 使用{MAX_RELATIVE_L2}及任务物理门限
- 给出PASS、REJECT或BLOCKED结论
- 不得仅凭平均误差宣称工程可用

### 6. 适用域报告
- 明确适用域限制
- 给出复核建议
- 域外工况需经CFD复核

## 质量门禁

| 门禁 | 标准 | 失败处理 |
|------|------|----------|
| 统计+物理 | 两类指标同时报告 | 补充缺失指标 |
| 最差可追溯 | 最差样本有唯一标识 | 补充标识 |
| 结论完整 | 含适用域限制与复核建议 | 补充报告 |
| 无平均误判 | 不得仅凭平均误差宣称可用 | 重新评估 |

## 边界与分流

| 情况 | 处理方式 |
|------|----------|
| 指标缺失 | 补充计算或标注"待评估" |
| 物理约束违反 | 标注物理不可信区域 |
| 域外性能差 | 限制适用域，增加复核建议 |
| 结论不确定 | 给出有条件结论，标注不确定因素 |

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 验收指标 | relative_L2, RMSE, conservation_residual, boundary_error | [场景需求书] | 统计+物理双维度 |
| 相对误差门限 | 0.1 | [场景需求书] | 默认放行阈值 |
| 域外测试 | 默认开启 | [场景需求书] | 几何或工况外推 |
| 结论类型 | PASS/REJECT/BLOCKED | [场景需求书] | 三态结论 |

### 校准数值

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 误差阈值 | 0.1 | [场景需求书] | 以下数值来自CFD_S006场景，供量级校准；其他体系需以自身证据重新锚定 |
| 守恒残差阈值 | 待确认 | [场景需求书] | 需根据具体物理问题确定 |

## 回退策略

1. **指标不足**：补充计算或标注"待评估"
2. **物理违反严重**：引入物理信息损失函数重新训练
3. **域外性能差**：限制适用域，增加域内测试覆盖
4. **结论不确定**：给出有条件结论，标注不确定因素
