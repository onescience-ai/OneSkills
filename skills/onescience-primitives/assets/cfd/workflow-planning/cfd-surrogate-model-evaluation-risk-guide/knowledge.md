# CFD代理模型性能评估与风险管控指南

## 适用范围
面向CFD代理模型任务，提供性能评估指标、风险管控策略、测试集规模影响分析和物理约束验证方法。适用于需要评估模型性能、识别潜在风险并采取管控措施的场景，不适用于模型训练或数据预处理阶段。

## 输入
- 模型训练日志（损失曲线、训练指标）
- 测试集预测结果（预测值 vs 真实值）
- 模型架构信息（多尺度Transformer、MLP、CNN等）
- 数据来源信息（模拟数据、真实CFD数据）

## 输出
- 性能评估报告（R²、相对误差、最差案例分析）
- 风险识别清单（数据质量、模型复杂度、评估稳定性）
- 物理约束验证结果（连续性方程、动量方程满足情况）

## 流程节点
1. **性能指标计算** → 计算R²、平均相对误差、最差案例误差等指标
2. **数据质量评估** → 分析训练数据与测试数据的分布差异、模拟数据与真实数据的影响
3. **模型复杂度分析** → 评估模型架构是否匹配任务需求（如多尺度Transformer vs 简化MLP）
4. **测试集规模评估** → 分析测试集大小对评估稳定性的影响
5. **物理约束验证** → 检查模型预测是否满足基本物理定律（如质量守恒、动量守恒）
6. **风险管控建议** → 根据评估结果提出改进策略（如增加数据、调整模型、扩大测试集）

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| R² 阈值 | > 0.8 | [用户自有] | 模型性能验收标准 |
| 相对误差阈值 | < 0.1 | [用户自有] | 模型预测精度要求 |
| 测试集规模 | ≥ 100 样本 | [用户自有] | 确保评估稳定性 |
| 物理约束 | 连续性方程、动量方程 | [用户自有] | CFD代理模型必须满足的基本物理定律 |
| 数据来源影响 | 模拟数据 vs 真实数据 | [用户自有] | 模拟数据会导致泛化能力差 |

## 边界与分流
- 若性能指标远低于验收标准，应考虑重新设计模型架构或获取更高质量数据。
- 若测试集规模过小，应扩大测试集或使用交叉验证。
- 若物理约束验证失败，应检查模型设计或数据预处理流程。

## 质量检查
- 验证性能指标计算正确（如R²、相对误差）。
- 检查风险识别清单是否覆盖关键风险（数据质量、模型复杂度、评估稳定性）。
- 确认物理约束验证方法合理（如数值验证、守恒误差计算）。

## 回退策略
- 若性能评估发现重大问题，可回退到模型训练阶段调整架构或数据。
- 若风险管控措施无效，可考虑暂停任务并重新规划。
