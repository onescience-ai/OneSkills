# OneScience任务验收指标阈值定义

## 适用范围
适用于OneScience任务验收和质量门禁判定的场景，定义completion_criteria中的macro_f1_score>0.7为硬性门槛，低于该阈值时training_completion应标记为REJECT。

## 输入
- 任务性能指标（macro F1、micro F1、accuracy等）
- 验收标准文档
- 质量门禁配置

## 输出
- 验收结果（PASS/PARTIAL/REJECT/BLOCKED）
- 质量门禁状态报告
- 性能对比分析

## 流程节点
1. 指标收集 → 2. 阈值对比 → 3. 门禁判定 → 4. 结果生成 → 5. 报告输出

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| macro_f1_threshold | 0.7 | [1] | 硬性验收门槛 |
| PASS标准 | 完全满足 | 规范要求 | 所有指标达标 |
| PARTIAL标准 | 部分满足 | 规范要求 | 部分指标达标 |
| REJECT标准 | 不满足 | 规范要求 | 核心指标未达标 |

## 边界与分流
- 指标计算失败时：标记为BLOCKED
- 阈值争议时：以标准workflow为准
- 多个指标冲突时：以macro F1为准

## 质量检查
- 指标计算正确性检查：确保指标计算无误
- 阈值对比准确性检查：确保对比逻辑正确
- 门禁判定一致性检查：确保判定结果一致
- 报告完整性检查：确保报告包含所有必需信息

## 回退策略
- 指标计算失败时：使用简化指标或报告错误
- 阈值对比失败时：使用默认阈值或报告争议
- 门禁判定失败时：等待人工裁决
