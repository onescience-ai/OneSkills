# OneScience任务参数契约

## 适用范围
适用于OneScience任务中参数配置和管理的场景，确保参数值从标准workflow的输入规格中提取而非自行设定，包括batch_size、random_seed、threshold等参数的默认值和可选范围定义。

## 输入
- 标准workflow参数规格文档
- 任务特定参数需求
- 参数约束条件

## 输出
- 参数配置文件（YAML/JSON）
- 参数验证报告
- 参数传递链文档

## 流程节点
1. 参数规格解析 → 2. 参数值提取 → 3. 参数验证 → 4. 参数配置 → 5. 参数传递

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| batch_size | 32 | 标准workflow | 默认批次大小 |
| random_seed | 11 | 标准workflow | 随机种子 |
| threshold | 0.5 | 标准workflow | 分类阈值 |
| seq_len_upper_bound | 1024 | 标准workflow | 序列长度上限 |

## 边界与分流
- 参数值缺失时：使用默认值（需明确标注）
- 参数值超出范围时：使用边界值或报告错误
- 参数冲突时：以标准workflow为准

## 质量检查
- 参数完整性检查：确保所有必需参数存在
- 参数类型检查：确保参数值类型正确
- 参数范围检查：确保参数值在允许范围内
- 参数一致性检查：确保参数在不同组件间一致

## 回退策略
- 参数配置失败时：使用默认配置
- 参数验证失败时：报告错误并停止执行
- 参数传递失败时：使用本地配置
