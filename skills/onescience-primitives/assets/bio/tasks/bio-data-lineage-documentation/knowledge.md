# Data Lineage Documentation for DNA Language Model Benchmarking

## 适用范围
用于确保DNA语言模型评测过程的数据血缘可追溯性，支持结果验证和可复现性。

## 输入
- 输入数据来源信息
- 处理过程记录
- 模型选择理由

## 输出
- 完整的数据血缘记录
- 验证报告

## 流程节点
1. 输入数据记录：记录输入数据的来源、版本、处理过程
2. 模型选择记录：记录模型选择理由、版本信息
3. 处理过程记录：记录每个步骤的处理过程和参数
4. 输出数据记录：记录输出数据的格式、版本
5. 验证检查：验证数据血缘记录的完整性

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必需字段 | 输入来源、版本、处理过程、模型选择理由 | [1] | 数据血缘核心信息 |
| 验证方法 | 完整性检查、一致性检查 | [1] | 确保记录完整 |
| 记录格式 | 结构化JSON或YAML | [1] | 便于解析和验证 |

## 边界与分流
- 如果某些信息无法获取，需记录阻塞原因
- 记录格式需根据项目需求调整

## 质量检查
- 检查数据血缘记录是否包含所有必需字段
- 验证记录的一致性和完整性
- 检查记录是否可追溯

## 回退策略
- 信息无法获取时，记录阻塞原因
- 记录格式不兼容时，进行格式转换

## 资源召回建议
- 当需要确保DNA语言模型评测过程的数据可追溯性时召回本卡片
- 配套资源：BEND_tasks数据集、分层性能评估方法
