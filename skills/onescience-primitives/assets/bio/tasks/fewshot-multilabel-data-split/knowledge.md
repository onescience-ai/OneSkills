# few-shot多标签分类数据切分策略

## 适用范围
适用于few-shot多标签分类任务中数据切分的场景，确保使用迭代分层抽样保证每个GO类别在各子集中至少有1个样本，避免类别不平衡。

## 输入
- 多标签数据集（样本-标签矩阵）
- 切分比例（训练/验证/测试）
- 分层抽样配置

## 输出
- 切分后的数据集（训练/验证/测试）
- 类别分布报告
- 切分质量验证

## 流程节点
1. 数据分析 → 2. 分层策略选择 → 3. 迭代切分 → 4. 分布验证 → 5. 结果生成

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 切分比例 | 60/20/20 | [1] | 训练/验证/测试比例 |
| 分层方法 | 基于标签组合 | [1] | 多标签分层策略 |
| 最小样本数 | 1 per class | [1] | 每个类别最少样本数 |
| 迭代次数 | 10 | 经验总结 | 确保稳定性 |

## 边界与分流
- 类别样本数不足时：使用降采样或过采样
- 分层失败时：使用简单随机切分
- 切分比例冲突时：以任务要求为准

## 质量检查
- 类别分布检查：确保各子集类别分布一致
- 样本唯一性检查：确保无样本泄漏
- 切分比例检查：确保符合指定比例
- 标签完整性检查：确保所有标签都被覆盖

## 回退策略
- 分层抽样失败时：使用简单随机切分
- 类别不平衡严重时：使用过采样或降采样
- 切分验证失败时：重新执行切分
