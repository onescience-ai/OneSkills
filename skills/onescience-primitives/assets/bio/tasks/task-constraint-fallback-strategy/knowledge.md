# 任务约束中的回退策略要求

## 适用范围
本卡片描述在资源不足或不可用时，如何使用替代方案完成任务的决策逻辑和执行策略。适用于所有需要资源获取的计算任务。

## 输入
- 原始资源需求描述
- 资源获取失败状态
- 任务约束条件（时间、质量、成本等）

## 输出
- 替代资源推荐
- 回退执行计划
- 质量保证措施

## 流程节点
1. **资源状态评估** → 确认原始资源是否可用
2. **约束分析** → 分析任务约束中的回退要求
3. **替代方案生成** → 基于约束生成可行替代方案
4. **替代方案评估** → 评估替代方案的可行性和质量
5. **回退执行** → 执行替代方案
6. **质量验证** → 验证替代方案满足任务要求

每步含：操作、参数、工具、质量门禁

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 资源可用性检查 | URL可访问性、文件完整性 | 通用 | 确认资源是否真正可用 |
| 替代方案优先级 | 学术替代 > 开源替代 > 商业替代 | 通用 | 替代方案选择优先级 |
| 质量保证阈值 | 与原始资源相当或可接受 | 任务特定 | 替代方案质量要求 |
| 回退触发条件 | 资源不可用、访问受限、格式不兼容 | 任务约束 | 何时启动回退流程 |

## 边界与分流
- 当替代方案质量不足时：报告限制并建议人工干预
- 当回退策略违反任务约束时：寻求额外资源或调整任务目标
- 当多个替代方案可用时：选择最符合约束的方案
- 当回退失败时：记录失败原因并建议改进措施

## 质量检查
- 验证替代方案满足任务基本要求
- 检查替代方案与原始方案的兼容性
- 确认替代方案不会引入新风险
- 记录回退决策过程和结果

## 回退策略
- 若所有替代方案都不可用，记录详细失败报告
- 建议联系资源提供者或寻找人工解决方案
- 考虑调整任务目标或范围

## 资源召回建议
- 当资源获取失败时召回本卡片
- 配套资源：bioinformatics-resource-acquisition（资源获取渠道）

## 证据来源
基于任务约束分析和通用回退策略原则，无特定论文证据。
