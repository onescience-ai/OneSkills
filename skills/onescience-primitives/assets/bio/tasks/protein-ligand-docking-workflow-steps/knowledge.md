# 蛋白质-配体对接工作流的标准步骤序列

## 适用范围
本卡片描述蛋白质-配体对接工作的标准步骤序列，适用于基于结构的药物设计、虚拟筛选和结合模式预测任务。当需要预测小分子配体与蛋白质靶标的结合构象和亲和力时，可遵循此工作流。

## 输入
- 靶标蛋白质受体结构（PDB格式）
- 配体结构（SMILES、SDF或PDB格式）
- 结合位点定义（可选，若未定义则使用已知配体位置）

## 输出
- 蛋白质-配体复合物结构
- 结合稳定性评估（配体RMSD）
- 结合亲和力评分（MMGBSA或类似方法）
- 结合模式排名

## 流程节点
1. **受体结构准备** → 加载靶标受体结构，定义搜索空间
2. **结合位点识别** → 使用G-LoSA等工具识别配体结合位点（LBS）
3. **模板选择** → 从PDB库中选择非同源模板结构（序列同一性<30%）
4. **受体构象生成** → 使用MD模拟和距离约束生成多个受体构象
5. **刚性受体对接** → 使用AutoDock Vina等工具进行刚性受体对接
6. **姿态采样** → 每个受体构象收集前10个结合姿态
7. **结合稳定性筛选** → 使用MD模拟评估结合稳定性（配体RMSD<3 Å）
8. **结合能计算** → 使用MMGBSA计算结合自由能
9. **最终排名** → 根据结合稳定性或结合能对结合模式进行排名

每步含：操作、参数、工具、质量门禁

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 模板数量 | 3-10 | [1] | 用于生成受体构象的模板数量 |
| 序列同一性阈值 | <30% | [1] | 选择非同源模板的标准 |
| 搜索空间大小 | 22.5 Å立方体 | [1] | 对接搜索空间大小 |
| MD模拟时长 | 50 ns | [1] | 受体构象细化和结合稳定性评估 |
| 配体RMSD阈值 | <3 Å | [1] | 稳定结合姿态的筛选标准 |
| 力场 | CHARMM36m, CGenFF | [1] | 蛋白质和配体力场 |
| 溶剂模型 | TIP3P水 + 0.15 M KCl | [1] | 显式溶剂模型 |

## 边界与分流
- 当受体为apo结构时：使用模板-based方法生成holo受体构象
- 当配体柔性高时：增加模板数量以生成更多构象变体
- 当对接失败时：检查结合位点定义、配体质子化状态和力场参数
- 当计算资源有限时：可减少模板数量或MD模拟时长

## 质量检查
- 受体结构完整性检查（缺失残基、原子）
- 配体质子化状态和电荷分配
- 对接盒子大小和位置验证
- 结合姿态的物理化学合理性检查

## 回退策略
- 若标准工作流失败，可尝试：
  - 使用不同的对接工具（如Glide、MOE Dock）
  - 调整搜索空间参数
  - 使用柔性残基侧链接入
  - 增加MD模拟时长

## 资源召回建议
- 当需要进行蛋白质-配体对接时召回本卡片
- 配套资源：对接工具（AutoDock Vina、Glide）、MD模拟软件（GROMACS、AMBER）、结构准备工具（CHARMM-GUI、PDB2PQR）
