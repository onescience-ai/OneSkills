# OneScience任务权重文件命名契约

## 适用范围
适用于OneScience任务中模型权重文件的命名、保存和加载场景，确保权重文件名与标准workflow中指定的标识一致，且权重来源是预训练模型而非随机初始化训练。

## 输入
- 标准workflow中指定的权重标识（如multimodal_protein.pt）
- 预训练模型权重或训练后的模型权重
- 模型保存路径配置

## 输出
- 命名规范的权重文件
- 权重文件元数据（来源、版本、大小）
- 权重验证报告

## 流程节点
1. 标识解析 → 2. 权重来源验证 → 3. 文件命名 → 4. 权重保存 → 5. 权重验证

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 权重文件名 | multimodal_protein.pt | 标准workflow | 必须与workflow指定一致 |
| 权重来源 | 预训练模型 | 任务要求 | 非随机初始化训练 |
| 文件大小 | >100MB | 经验值 | 预训练模型通常较大 |
| 保存路径 | checkpoints/ | 标准路径 | 权重文件存放目录 |

## 边界与分流
- 权重文件名不匹配时：重命名文件以符合契约
- 权重来源非预训练时：重新加载预训练权重
- 权重文件损坏时：重新下载或训练模型

## 质量检查
- 文件名一致性检查：确保文件名与workflow指定一致
- 权重来源验证：确保权重来自预训练模型
- 文件完整性检查：确保权重文件可正常加载
- 参数一致性检查：确保加载后模型参数正确

## 回退策略
- 权重文件不可用时：使用随机初始化权重（需明确标注）
- 权重加载失败时：重新下载或训练模型
- 文件名冲突时：使用版本号或时间戳进行区分
