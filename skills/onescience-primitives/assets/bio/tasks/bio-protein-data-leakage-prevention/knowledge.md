# 蛋白功能预测数据泄漏检测与预防

## 适用范围
蛋白功能预测任务中，训练/测试数据分割时的数据泄漏检测与预防；适用于确保模型评估结果真实反映泛化能力的场景。

## 输入
- 蛋白质accession列表（含训练集和测试集）
- 序列数据（可选）
- 数据分割配置

## 输出
- 数据泄漏检测报告（是否存在accession重叠）
- 泄漏严重程度评估（重叠比例）
- 修正后的数据分割方案

## 流程节点
1. accession-level检查 → 检查训练和测试accession集合的交集
2. sequence-level检查 → 检查序列相似性（如>90%序列一致性）
3. 泄漏严重程度评估 → 计算重叠比例并评估影响
4. 修正方案生成 → 生成无泄漏的数据分割方案

每步含：操作、参数、工具、质量门禁

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| accession-level分割 | 训练/测试accession集合交集为空 | [1] | 最严格的分割方式 |
| sequence-level分割 | 序列相似性<90%（或<25%用于更严格场景） | [1] | 基于序列相似性的分割 |
| 泄漏检测方法 | random label experiment | [1] | 使用随机标签训练检测泄漏 |
| 重叠比例阈值 | 0%（不允许重叠） | [1] | 理想情况下不应有重叠 |
| 泄漏影响 | 评估结果高估泛化性能 | [1] | 泄漏导致记忆化而非泛化 |

## 边界与分流
- 若检测到accession重叠 → 必须停止训练并修正分割
- 若仅检测到序列相似性高（无accession重叠） → 记录WARNING但可继续
- 若无法进行accession-level分割 → 使用sequence-level分割并标注限制

## 质量检查
- 验证训练和测试accession集合的交集为空
- 检查随机标签实验的p值（p > 0.05表示无显著泄漏）
- 对比不同分割策略下的模型性能差异

## 回退策略
- 若检测到泄漏 → 重新进行数据分割，确保无accession重叠
- 若原始数据源限制导致无法完全避免泄漏 → 记录限制并标注评估结果的可信度
- 记录数据泄漏检测的方法和结果
