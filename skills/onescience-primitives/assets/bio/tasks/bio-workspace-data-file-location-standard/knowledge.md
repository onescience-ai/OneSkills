# OneScience工作空间数据文件存放位置规范

## 适用范围
适用于在OneScience工作空间中定位数据文件的任务，包括任务产物目录、工作空间根目录、.onescience/data/子目录、模型注册表等可能的数据存放路径。用于在数据验证步骤前执行数据发现，提高文件定位成功率。

## 输入
- 数据文件名称或模式（如antigen_antibody_set.json、asafm.ckpt）
- 工作空间根目录路径
- 任务ID或任务产物目录路径

## 输出
- 数据文件实际路径
- 数据发现日志，记录搜索了哪些路径及结果

## 流程节点
1. 搜索任务产物目录（task-artifact/<task_id>/）
2. 搜索工作空间根目录（.）
3. 搜索.onescience/data/子目录
4. 搜索模型注册表或数据注册表
5. 搜索远程数据源（如ModelScope）
6. 记录搜索结果

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 搜索优先级 | 任务产物目录 > 工作空间根目录 > .onescience/data/ > 模型注册表 > 远程数据源 | 通用实践 | 各路径的搜索顺序 |
| 文件匹配模式 | 精确匹配 > 模糊匹配 | 通用实践 | 先尝试精确文件名，再尝试模式匹配 |

## 边界与分流
- 如果所有本地路径均未找到文件，则尝试远程数据源查询
- 如果远程数据源也未找到，则报告文件缺失，任务阻塞

## 质量检查
- 确认搜索了所有标准路径
- 确认搜索日志完整记录

## 回退策略
- 如果文件不存在，则提供数据生成或获取的建议

## 资源召回建议
当需要定位OneScience工作空间中的数据文件时召回本卡片。
