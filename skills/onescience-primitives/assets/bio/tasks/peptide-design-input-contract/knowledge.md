# 靶标特异性全原子肽类设计任务输入契约

## 适用范围
本输入契约定义了靶标特异性全原子肽类设计任务的所有输入参数，包括必填和可选参数及其默认值。当默认值可用时，任务无需等待用户输入即可继续执行。

## 输入
### 必填输入
- **设计输入**：蛋白质受体结构文件（默认target_interface.pdb），包含靶标蛋白的三维结构。
- **设计模型**：PepFlow模型（默认权重文件pepflow.ckpt）。
- **目标长度**：设计肽的长度（默认256个残基）。

### 可选输入
- **固定残基位点**：指定肽中固定残基的位置（默认[10,25]）。
- **对称群**：指定对称性约束（默认C1，即无对称性）。
- **设计数量**：生成的设计候选数量（默认64）。
- **采样温度**：控制生成多样性的温度参数（默认0.2）。
- **随机种子**：确保可重复性的随机种子（默认17）。
- **筛选阈值**：界面置信度筛选阈值（默认0.6）。
- **保留多样候选**：是否保留多样化的候选设计（默认true）。

## 输出
- **标准化设计输入**：解析后的输入参数集合。
- **约束清单**：所有设计约束的列表。
- **参数验证报告**：输入参数的验证结果。

## 流程节点
1. **参数解析**：读取用户提供的参数，识别默认值。
2. **默认值填充**：对于未提供的参数，使用默认值填充。
3. **参数验证**：检查参数的有效性和一致性。
4. **约束生成**：根据参数生成设计约束清单。
5. **输出整理**：格式化输出标准化输入和约束清单。

## 质量检查
- 验证所有必填参数是否提供或使用默认值。
- 检查参数值是否在合理范围内。
- 确认参数组合不会导致矛盾约束。
