# 单细胞RNA-seq统计检验方法

## 适用范围
适用于单细胞RNA-seq分析中的统计验证场景，包括模型比较、差异表达分析、实验设计中的样本量规划，以及结果解释中的不确定性评估。

## 输入
- 待检验的比较对象（模型A vs 模型B、处理组 vs 对照组等）
- 样本量（细胞数、患者数）
- 效应量估计（Cohen's d、fold change等）
- 显著性水平（α，默认0.05）

## 输出
- 统计检验结果（p值、置信区间、效应量）
- 样本量建议（达到统计功效所需的最小样本量）
- 结果解释报告（统计显著性 vs 实际意义）

## 流程节点
1. 样本量规划 → 2. 统计检验选择 → 3. 效应量计算 → 4. 结果解释 → 5. 不确定性报告

### 1. 样本量规划
基于文献报道的单细胞分析样本量要求 [1][2]：

**统计功效分析（Power Analysis）**：
- 目标功效（Power）：通常设定为0.8（80%）
- 显著性水平：α=0.05（双侧检验）
- 预期效应量：基于先验研究或 pilot 数据估计
- 工具：scDesign（单细胞RNA-seq专用）[1]、pwr包（R）

**单细胞分析的样本量特点**：
- 单细胞数据通常包含数千至数万个细胞，但患者/样本数量可能有限
- 细胞内变异（intra-cellular）和细胞间变异（inter-cellular）需分别考虑
- 批次效应可能掩盖真实生物学差异

**样本量对分析结果的影响** [2]：
- 细胞数量不足导致聚类不稳定、细胞类型注释不准确
- 患者数量不足导致统计检验功效不足、假阴性风险增加
- 最小建议：每组至少3个生物学重复（患者），每重复至少100个细胞

### 2. 统计检验选择

| 检验类型 | 适用场景 | 假设条件 | 注意事项 |
|----------|---------|----------|---------|
| t检验 | 两组均值比较（正态分布） | 正态性、方差齐性 | 单细胞数据通常不满足正态假设 |
| Wilcoxon秩和检验 | 两组非参数比较 | 无需正态假设 | 单细胞分析常用 [3] |
| Mann-Whitney U检验 | 同Wilcoxon秩和检验 | 独立样本 | 扰动预测中常用 [1] |
| ANOVA/Kruskal-Wallis | 多组比较 | 独立样本 | 需事后检验 |
| Bootstrap重采样 | 小样本推断 | 无分布假设 | 适用于样本量<10 |
| Permutation检验 | 模型比较 | 无分布假设 | 计算密集但可靠 |

**单细胞数据的特殊考虑**：
- 数据稀疏性（sparsity）：大量零值，非正态分布
- 高维性：同时检验数千个基因，需多重检验校正
- 批次效应：使用limma、ComBat等方法校正后再检验

### 3. 效应量计算

**常用效应量指标**：

| 效应量 | 计算方法 | 解释标准 | 适用场景 |
|--------|---------|----------|---------|
| Cohen's d | (M1-M2)/SD_pooled | 小:0.2, 中:0.5, 大:0.8 | 均值比较 |
| Fold Change | M1/M2 | >2为显著变化 | 差异表达 |
| Odds Ratio | (a/b)/(c/d) | >2或<0.5为显著 | 分类结果 |
| η² (Eta-squared) | SS_between/SS_total | 小:0.01, 中:0.06, 大:0.14 | 方差分析 |

**效应量 vs p值的关系**：
- p值受样本量影响：大样本量下微小差异也可显著
- 效应量反映实际意义：不随样本量变化
- **必须同时报告p值和效应量** [报告规范]

### 4. 结果解释

**p值的正确解读**：
- p<0.05表示"在α=0.05水平下拒绝原假设"，**不表示**"差异有实际意义"
- p>0.05表示"无统计学意义"，**不表示**"无差异"
- p值不提供效应大小或临床/生物学意义的信息

**统计显著性 vs 实际意义**：
- 统计显著（p<0.05）但效应量小：可能无实际意义
- 统计不显著（p>0.05）但效应量大：可能是样本量不足
- **建议**：使用置信区间而非仅报告p值

**模型比较中的解释**：
- 模型A（0.0434）vs 模型B（0.0360），p=0.2241
- 正确解读：差异无统计学意义（p>0.05），效应量小（Cohen's d=-0.25）
- 错误解读：模型A优于模型B（过度解读）

### 5. 不确定性报告

**必须报告的信息**：
- 样本量（细胞数、患者数、重复数）
- 效应量及其置信区间
- p值（精确值而非仅"<0.05"）
- 统计功效（observed power）
- 多重检验校正方法（如适用）

**模拟数据 vs 真实数据的风险**：
- 模拟数据结论可能不适用于真实生物学场景
- 小样本模拟的统计检验功效不足
- 建议：在真实数据上验证模拟结果

**报告模板**：
```
比较对象：模型A vs 模型B
样本量：n=50 per group
效应量：Cohen's d = -0.25 (95% CI: [-0.65, 0.15])
p值：0.2241 (Wilcoxon rank-sum test)
统计功效：0.23
结论：差异无统计学意义，效应量小，需更大样本量验证
```

## 关键参数
| 参数 | 推荐值 | 来源 | 说明 |
|------|--------|------|------|
| 显著性水平 | α=0.05 | [通用] | 双侧检验 |
| 统计功效 | Power≥0.8 | [通用] | 80%检测真实差异 |
| 最小效应量 | Cohen's d≥0.5 | [通用] | 中等效应量 |
| 最小样本量 | ≥3 patients/group | [2] | 生物学重复 |
| 多重检验校正 | Benjamini-Hochberg | [通用] | FDR控制 |
| 置信区间 | 95% CI | [通用] | 结果可靠性 |

## 边界与分流
- **样本量<10**：使用Bootstrap或Permutation检验，报告置信区间
- **数据非正态**：使用非参数检验（Wilcoxon、Kruskal-Wallis）
- **存在批次效应**：先校正批次效应再进行统计检验
- **多重比较**：使用FDR校正（Benjamini-Hochberg）控制假阳性

## 质量检查
- 验证统计检验的假设条件（正态性、独立性、方差齐性）
- 确认样本量满足统计功效要求
- 检查效应量计算的正确性
- 确认多重检验校正的适当性

## 回退策略
- 若样本量不足，增加数据量或使用bootstrap重采样
- 若检验假设不满足，使用非参数替代方法
- 若效应量无法估计，报告原始数据分布和可视化
