# 技能选择原则

## 适用范围
本卡片描述根据任务领域和具体任务类型选择对应的执行技能的原则。适用于需要选择合适技能执行特定任务的场景。

## 输入
- 任务领域（bio、matchem、climate、cfd、general）
- 任务类型（对接、训练、推理、分析等）
- 任务约束条件

## 输出
- 推荐技能列表
- 技能匹配理由
- 执行建议

## 流程节点
1. **任务领域识别** → 确定任务所属领域
2. **任务类型分析** → 分析任务具体类型和需求
3. **技能库检索** → 检索可用技能及其适用范围
4. **技能匹配** → 匹配任务需求与技能能力
5. **技能选择** → 选择最合适的技能
6. **验证确认** → 验证选择的技能能完成任务

每步含：操作、参数、工具、质量门禁

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 领域关键词 | protein, ligand, docking → bio | 领域检测规则 | 领域识别依据 |
| 任务类型 | 对接 → onescience-coder/infer | 技能描述 | 任务类型与技能匹配 |
| 技能层级 | 编排技能 vs 执行技能 | 技能架构 | 选择正确层级的技能 |
| 匹配度评估 | 领域匹配 + 任务类型匹配 | 通用 | 技能选择标准 |

## 边界与分流
- 当多个技能匹配时：选择最具体、最专业的技能
- 当技能能力不足时：组合多个技能或寻求专家指导
- 当任务跨领域时：使用通用编排技能协调
- 当技能选择不确定时：使用默认技能或寻求澄清

## 质量检查
- 验证选择的技能适用于任务领域
- 检查技能能力覆盖任务需求
- 确认技能输入输出与任务兼容
- 评估技能执行成本和效率

## 回退策略
- 若首选技能不可用，寻找替代技能
- 若技能选择错误，及时调整并重新执行
- 若任务超出技能能力，报告限制并建议改进
