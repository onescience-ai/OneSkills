# 蛋白质序列长度分布知识

## 适用范围
适用于蛋白质序列处理和模型设计的场景，了解典型蛋白序列长度分布和预训练模型的输入长度限制，避免序列信息丢失。

## 输入
- 蛋白质序列数据
- 序列长度统计信息
- 模型输入长度限制

## 输出
- 序列长度分布报告
- 截断策略建议
- 模型兼容性评估

## 流程节点
1. 序列长度统计 → 2. 分布分析 → 3. 模型限制查询 → 4. 截断策略选择 → 5. 兼容性验证

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 典型序列长度 | 100-3000氨基酸 | [1] | 蛋白质序列长度范围 |
| max_seq_len推荐值 | 1024 | [1] | 可覆盖大部分蛋白 |
| ESM-2输入限制 | 512-2048 | [1] | 预训练模型输入长度 |
| 截断策略 | 前端截断/后端截断/滑动窗口 | 经验总结 | 不同截断方法 |

## 边界与分流
- 序列过长时：使用滑动窗口或分块处理
- 序列过短时：使用padding填充
- 模型限制冲突时：选择兼容的截断策略

## 质量检查
- 序列长度统计检查：确保统计准确
- 截断策略验证：确保截断后保留关键信息
- 模型兼容性检查：确保序列长度符合模型要求
- 信息完整性检查：确保截断未丢失关键功能位点

## 回退策略
- 序列长度超限时：使用滑动窗口处理
- 截断策略失败时：使用简单截断
- 模型不兼容时：选择其他模型或调整参数
