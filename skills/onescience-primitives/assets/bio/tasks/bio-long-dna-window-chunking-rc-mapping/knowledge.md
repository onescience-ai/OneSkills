# 基因组DNA长窗口分块处理与正反链映射

## 适用范围

**触发条件**：
- 需要处理超过模型最大输入长度（如>131kb）的DNA序列窗口
- 需要构建正反链双向输入并确保中心坐标对齐
- 需要实现RC（反向互补）等变性的可逆映射

**适用场景**：
- Caduceus模型的长程输入预处理
- 增强子-启动子远距离相互作用建模
- 3D基因组接触图的序列窗口构造
- 任何需要双向DNA输入的基因组建模任务

**不适用场景**：
- 短序列（<1kb）无需分块处理
- 不需要RC等变性的单向序列建模
- 非基因组序列（如蛋白质、RNA）

## 输入

**输入要求**：
- DNA序列：FASTA格式，长度>131,072 bp
- 基因组坐标：染色体:起始-终止（hg38参考）
- 模型最大输入长度：如8192或131,072 bp

**预处理要求**：
- 序列必须为正链方向（5'→3'）
- 坐标需验证在参考基因组有效范围内
- 序列长度需记录用于后续分块计算

## 输出

**输出产物**：
- 分块序列列表：每个块长度≤模型最大输入
- 坐标映射表：分块坐标与原始坐标的对应关系
- 正反链索引映射：可逆的RC映射表

**验证标准**：
- 所有分块覆盖原始序列无遗漏
- 分块边界坐标连续无重叠
- RC映射可逆：x经RC变换后再经映射恢复等于原始x

## 流程节点

### Step 1：序列预处理
- **操作**：验证序列格式和坐标有效性
- **参数**：参考基因组=hg38, 坐标范围检查
- **工具**：Python + biopython
- **质量门禁**：序列长度>模型最大输入

### Step 2：分块策略选择
- **操作**：确定分块大小和重叠策略
- **参数**：块大小=模型最大输入, 重叠=0或固定值
- **工具**：Python逻辑
- **质量门禁**：分块数计算正确

### Step 3：滑动窗口分块
- **操作**：将长序列切分为多个块
- **参数**：块大小, 步长, padding策略
- **工具**：Python切片操作
- **质量门禁**：所有块长度≤模型最大输入

### Step 4：坐标对齐
- **操作**：建立分块坐标与原始坐标的映射
- **参数**：中心坐标固定, 两端padding
- **工具**：Python字典/列表
- **质量门禁**：中心坐标在分块后不偏移

### Step 5：正反链映射
- **操作**：构建RC可逆映射表
- **参数**：互补规则(A↔T, C↔G), 方向反转
- **工具**：Python映射表
- **质量门禁**：映射可逆性验证通过

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 模型最大输入 | 131,072 bp | [1] | Caduceus标准窗口 |
| 分块大小 | 8,192 bp | [1] | 单个Mamba处理单元 |
| 重叠策略 | 0或512 bp | [1] | 视任务需求选择 |
| padding方式 | 零填充或循环填充 | [1] | 保持序列连续性 |
| 中心坐标固定 | 是 | [1] | 避免信息偏移 |
| RC互补规则 | A↔T, C↔G | [1] | DNA反向互补 |
| 映射可逆性 | x→RC(x)→map(RC(x))=x | [1] | 必须满足 |

## 边界与分流

**异常处理**：
- 序列长度不足→直接使用无需分块
- 坐标超出参考范围→裁剪到有效范围
- RC映射不可逆→检查互补规则实现

**降级策略**：
- 长窗口处理内存不足→使用流式处理或减少batch_size
- 分块坐标对齐困难→使用固定步长分块
- RC映射复杂→先实现正向链，RC等变性后续补充

**分支条件**：
- 任务为双向输入→同时生成正向和反向分块
- 任务为单向输入→仅生成正向分块
- 需要中心坐标固定→使用padding保持中心位置

## 质量检查

**验证点**：
1. 分块完整性：所有分块覆盖原始序列
2. 坐标连续性：分块边界坐标无间隙
3. 长度合规性：所有块长度≤模型最大输入
4. RC可逆性：x→RC→map后恢复原始x

**阈值**：
- 覆盖率：100%
- 连续性：100%
- 长度合规率：100%
- 可逆性验证通过率：100%

## 回退策略

**失败替代方案**：
- 长窗口处理完全不可用→使用短窗口（如4096bp）作为近似
- RC映射实现困难→仅使用正向链，牺牲双向信息
- 内存不足→使用内存映射文件或流式处理
