# 蛋白语言模型预测不确定度量化

## 适用范围
当需要量化蛋白语言模型预测结果的不确定度时，本卡提供bootstrap采样、模型集成和置信区间估计的方法。适用于评估蛋白变异效应预测结果的可靠性，支持结果解释和决策制定。

## 输入
- 预测结果：蛋白变异的功能评分（如ESM-1v零样本评分）
- 模型信息：蛋白语言模型的类型和参数
- 样本信息：预测的突变位点和序列

## 输出
- 不确定度指标：评分标准差、置信区间
- 可靠性评估：预测结果的置信水平
- 不确定度来源：模型不确定性、数据不确定性

## 流程节点
1. **Bootstrap采样** → 2. **模型集成** → 3. **方差分析** → 4. **置信区间估计** → 5. **不确定度报告**

### 步骤1：Bootstrap采样
- 操作：对预测结果进行重采样估计不确定度
- 参数：重采样次数（通常1000次）、采样方法（有放回采样）
- 工具：numpy随机采样
- 质量门禁：重采样分布合理，无偏差

### 步骤2：模型集成
- 操作：使用多个模型或多个随机种子进行预测
- 参数：模型数量、随机种子数量
- 工具：模型并行推理
- 质量门禁：模型间预测差异在合理范围

### 步骤3：方差分析
- 操作：计算预测结果的方差和标准差
- 参数：预测分布、统计量
- 工具：numpy统计函数
- 质量门禁：方差计算正确，标准差合理

### 步骤4：置信区间估计
- 操作：估计预测结果的置信区间
- 参数：置信水平（通常95%）、估计方法
- 工具：百分位数法或正态近似
- 质量门禁：置信区间宽度合理，覆盖真实值

### 步骤5：不确定度报告
- 操作：生成包含不确定度的预测报告
- 参数：报告格式、不确定度指标
- 工具：数据可视化
- 质量门禁：报告清晰，不确定度信息完整

## 边界与分流
- **计算资源不足**：减少重采样次数或模型数量，使用近似方法
- **样本量过小**（<50突变）：转向使用贝叶斯方法或先验信息
- **模型差异过大**：检查模型选择，可能需重新训练或微调
- **不确定度过高**：增加样本量或改进模型，避免过度解释

## 质量检查
- 验证点：重采样方法正确性、置信区间覆盖性、不确定度报告完整性
- 阈值：置信区间覆盖真实值概率>90%
- 失败处理：记录具体失败原因，提供改进建议

## 回退策略
- 标准方法不适用时，考虑使用其他不确定度估计方法（如MC Dropout）
- 计算资源受限时，使用解析近似或简化模型
- 不确定度估计不准确时，明确标注局限性，谨慎解释结果
