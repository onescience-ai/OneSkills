# 基因组语言模型中转录因子特征的因果解析（B66）

## 适用范围

**适用场景**：
- 输入的参考组装、坐标、链方向和等位基因明确，目标是基因组功能预测、变异效应或序列设计。
- 有与输入上下文对应的实验轨迹或标签，并能在独立区间/物种/细胞条件上评估。
- 模型上下文长度、物种和调控任务处于验证范围内，外推部分会单独标记。
- 结果用于研究假设、变异优先级或调控元件候选设计，不替代遗传诊断或实验验证。

**不适用场景**：
- 参考基因组版本、坐标或等位基因不一致，无法复现窗口和效应计算。
- 训练和测试包含相邻窗口、同一变异或同源序列泄漏，却需要宣称泛化。
- 模型没有覆盖目标物种、细胞类型、修饰或长程范围，且没有补充验证。
- 需要直接给出临床致病性或育种决策而没有独立实验和群体证据。

## 研究对象与输入

**研究对象**：基因组DNA区间、变异、调控轨迹和细胞/组织上下文

| 输入项 | 说明 |
|---|---|
| 输入文件 | TF_binding_sequences.fasta |
| 输入模态 | FASTA、BED/VCF、轨迹表或序列-标签数据 |
| 样本单元 | 一个基因组区间、变异或序列设计候选 |
| 标签/条件 | 表达、染色质可及性、结合/剪接轨迹、变异效应或细胞类型条件 |
| 模型引用 | causal_dictionary.pt |

**初始结构**：默认输入名称为“TF_binding_sequences.fasta”；执行者必须核验格式、版本、实体/样本完整性、缺失值和可解析性，并记录实际使用的相对名称或数据标识。

**表面/硬约束**：固定参考基因组版本、坐标体系、链方向、等位基因和细胞/组织条件；不得把预测轨迹或序列生成结果当作已验证调控机制。

**划分策略**：按染色体/基因、物种、细胞类型和变异家族拆分，防止相邻窗口、同一位点或参考序列泄漏。

**采样要求**：默认覆盖完整独立区间/变异测试集，并对每个碱基、区间或候选序列给出效应、置信度和质量标记。

## 核心科学问题

1. 在基因组DNA区间、变异、调控轨迹和细胞/组织上下文和输入“TF_binding_sequences.fasta”上，从基因组语言模型表征中识别可干预的转录因子结合特征，支持机制解释能否得到可复核的干预效应结果，并满足任务的硬约束？
2. 输入中的坐标和等位基因一致性、长程上下文、调控效应和跨物种泛化如何影响基因组语言模型中转录因子特征的因果解析的输出，哪些样本、区域或候选最容易失败？
3. 模型在独立样本、未见家族/条件或困难子集上的表现是否稳定，误差和不确定度如何量化？
4. 结果是否具有足够的生物学、化学或临床证据支持后续决策，哪些部分只能作为探索性线索？
5. 在当前数据、模型和资源边界下，哪些结论可以签收，哪些结论必须标记为无法回答或需要额外验证？

## 比较与评估

- 主任务：从基因组语言模型表征中识别可干预的转录因子结合特征，支持机制解释；核心指标：干预效应。
- 目录模型候选为Causal Dictionary Model，需与可解释基线、参考标签或独立质量检查比较。
- 按物种、染色体/基因、细胞类型和变异类别分层报告性能与校准。
- 比较参考/突变、正负对照和至少一个简单序列基线，记录窗口边界效应。

## 工作流

### 步骤 1：基因组输入与坐标规范化

**目的**：读取基因组语言模型中转录因子特征的因果解析的DNA、区间、变异或表观信号。

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 基因组输入 | `{GENOMICS_INPUT}` | doc | 是 | `TF_binding_sequences.fasta` | 输入序列区间或变异 |
| 基因组模型 | `{MODEL_NAME}` | enum | 是 | `Causal Dictionary Model` | 可选值：`Causal Dictionary Model` |
| 参考基因组 | `{REFERENCE_GENOME}` | enum | 否 | `hg38` | 可选值：`hg38`、`mm10`、`IRGSP-1.0`、`multi_species` |

**输出**：标准化基因组输入、坐标检查报告、任务配置

**质量门禁**：
- 坐标位于参考范围
- 等位基因方向一致
- 样本标识唯一

**操作指令**：`读取{GENOMICS_INPUT}，相对{REFERENCE_GENOME}校验序列和坐标，使用{MODEL_NAME}建立基因组语言模型中转录因子特征的因果解析任务。`

### 步骤 2：序列窗口与模型准备

**目的**：加载权重并构造满足上下文长度的正反链输入。

**依赖步骤**：s01

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 模型权重 | `{CHECKPOINT}` | doc | 是 | `causal_dictionary.pt` | — | 模型权重名称 |
| 上下文长度 | `{CONTEXT_LENGTH}` | int | 否 | `131072` | 128–1048576 | 设置DNA窗口碱基数 |
| 反向互补增强 | `{REVERSE_COMPLEMENT}` | bool | 否 | true | — | 是否加入反向互补序列 |

**输出**：序列窗口、方向映射、模型加载记录

**质量门禁**：
- 窗口长度符合模型要求
- 中心坐标未偏移
- 反向映射可恢复

**操作指令**：`加载{CHECKPOINT}，按{CONTEXT_LENGTH}构造序列窗口，并按{REVERSE_COMPLEMENT}生成方向增强特征。`

### 步骤 3：基因组预测或序列生成

**目的**：批量执行轨迹、分类、变异评分或条件生成。

**依赖步骤**：s02

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 批次大小 | `{BATCH_SIZE}` | int | 是 | `8` | 1–512 | 设置序列批次大小 |
| 细胞上下文 | `{CELL_CONTEXTS}` | list[str] | 否 | ["K562", "HepG2"] | — | 选择组织或细胞类型 |
| 随机种子 | `{SEED}` | int | 否 | `2025` | 0–2147483647 | 固定生成或评测结果 |

**输出**：基因组预测、变异或生成分数、运行日志

**质量门禁**：
- 每个区间均有结果
- 正反链结果已对齐
- 数值无NaN或Inf

**操作指令**：`以批次{BATCH_SIZE}和种子{SEED}运行基因组语言模型中转录因子特征的因果解析，分别输出{CELL_CONTEXTS}上下文的结果。`

### 步骤 4：轨迹与效应质量评估

**目的**：计算干预效应并导出区间、碱基或变异层结果。

**依赖步骤**：s03

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 结果阈值 | `{SCORE_THRESHOLD}` | float | 否 | `0.5` | 0–1 | 设置显著结果阈值 |
| 输出粒度 | `{OUTPUT_LEVEL}` | enum | 否 | `variant` | — | 可选值：`base`、`interval`、`variant`、`track` |

**输出**：结果表、干预效应汇总、基因组质控报告

**质量门禁**：
- 参考与替代等位可区分
- 输出坐标未越界
- 指标与数据切分匹配

**操作指令**：`计算干预效应，用{SCORE_THRESHOLD}标记显著结果，并按{OUTPUT_LEVEL}导出可追溯记录。`

## 验收标准与质量门禁

### 硬约束（不可违反）

- 固定参考基因组版本、坐标体系、链方向、等位基因和细胞/组织条件；不得把预测轨迹或序列生成结果当作已验证调控机制。
- 输入、标签、模型版本、数据划分和实际输出之间的血缘必须可追溯；任何偏离都要记录并经场景确认。
- 不得把平均分数、单个高分样本或模型自评当作生物学、化学或临床事实；正式结论必须有独立证据。
- 历史论文、参考模型和示例文件只能用于方案设计或交叉检查，不能冒充本次任务的新结果。

### 最低证据要求

- 实际研究对象、输入、模型/权重、工具和场景约束与任务书一致，所有偏离均有变更记录。
- 输入、标签/参考数据、版本、筛选规则和训练/评估划分可追溯，泄漏和缺失处理有证据。
- 模型或推理结果有独立于选择过程的干预效应评估、分层统计、最差案例和适用域说明。
- 全量结果、失败样本、异常、拒答或低质量标记均被保存；正式分析只使用质量合格的范围。
- 每个目标结果都有定义、单位/量纲（如适用）、样本量、分析窗口、置信区间或不确定度。
- 比较基线、参考标签或人工复核的口径一致，不能只报告对模型有利的子集。
- 结论明确区分观察、模型误差、标签/采样不确定度、偏差和未验证假设。
- 输出文件、环境、日志、版本和校验信息足以让第三方复核关键数值。

**验收判定**：执行者必须对每个交付项给出 PASS、PARTIAL、REJECT 或 BLOCKED，并附文件、日志、图表或数值证据；没有证据的‘运行正常’或‘效果良好’不能作为签收依据。

## 必要结果项

- **结构结果**：参考组装、坐标、链方向、序列窗口和轨迹/变异输入的规范化报告；同时说明输入清洗、版本和任何变更。
- **参考标签结果**：实验轨迹、变异标签、物种/细胞上下文和数据版本的血缘与覆盖说明；标注缺失、噪声、类别不平衡和不可用于正式验收的部分。
- **模型结果**：模型/权重、窗口或上下文范围、独立区间测试、校准和外推风险；明确模型适用的实体、序列/结构/模态范围和不能外推的边界。
- **动力学结果**：碱基/区间预测、等位基因差异、设计序列或干预结果及日志；保留全量候选或逐样本输出、失败原因、随机种子/条件和版本记录。
- **性质结果**：轨迹相关、效应量、活性达成率、分类/回归指标和不确定度；每个指标给出定义、单位或量纲、样本范围、分析窗口和置信区间。
- **结论结果**：一份将观察结果、独立证据、模型误差、采样/标签不确定度、偏差和无法回答的问题分开的科学结论报告。
