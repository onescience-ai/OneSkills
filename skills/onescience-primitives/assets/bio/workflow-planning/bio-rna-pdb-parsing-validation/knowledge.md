# RNA PDB文件解析与验证工作流

## 适用范围
**触发条件**：
- 需要解析RNA PDB文件进行反向设计
- 需要验证RNA输入文件的合法性
- 需要检查碱基字符和配对索引

**适用场景**：
- RNA三维反向设计任务的输入验证
- RNA结构预测前的文件预处理
- RNA设计工具的数据准备阶段

**不适用场景**：
- 蛋白质PDB文件解析
- 非标准RNA修饰的解析

## 输入
- RNA PDB文件（.pdb格式）
- 目标结构信息（可选）
- 验证参数配置

## 输出
- 验证后的标准化RNA输入
- 验证报告（包含错误和警告）
- 清洗后的PDB文件

## 流程节点

### Step 1：文件格式检查
- **操作**：检查PDB文件格式和完整性
- **参数**：文件扩展名、文件大小、行数
- **工具**：文件系统检查
- **质量门禁**：文件存在且非空

### Step 2：碱基字符验证
- **操作**：检查RNA碱基字符合法性
- **参数**：合法字符集={A, U, G, C, a, u, g, c}
- **工具**：正则表达式匹配
- **质量门禁**：所有碱基字符合法

### Step 3：链标识检查
- **操作**：验证RNA链标识符
- **参数**：链ID格式、链数量
- **工具**：PDB解析库（如BioPython）
- **质量门禁**：链标识符唯一且有效

### Step 4：配对索引验证
- **操作**：检查碱基配对索引冲突
- **参数**：配对索引格式、冲突检测
- **工具**：自定义验证脚本
- **质量门禁**：无配对索引冲突

### Step 5：dot-bracket格式转换
- **操作**：将PDB结构转换为dot-bracket表示
- **参数**：二级结构提取、dot-bracket生成
- **工具**：ModeRNA、DSSR
- **质量门禁**：dot-bracket格式正确

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 合法碱基字符 | A, U, G, C | [1] | RNA标准碱基 |
| 链标识符格式 | 单字符（A-Z, a-z, 0-9） | [1] | PDB标准格式 |
| 配对索引范围 | 1到序列长度 | [1] | 1-based索引 |
| dot-bracket字符 | '.', '(', ')' | [1] | 二级结构表示 |
| 文件格式 | PDB格式 | [1] | 标准结构文件 |
| 分辨率阈值 | <4.0 Å | [1] | 高质量结构 |

## 边界与分流
- **非法碱基字符**：替换为'N'或删除
- **配对索引冲突**：重新计算配对或标记为无效
- **链标识重复**：重命名链标识符

## 质量检查
- 验证所有碱基字符在{A, U, G, C}中
- 验证配对索引无冲突
- 验证链标识符唯一
- 验证dot-bracket格式语法正确

## 回退策略
- 使用标准RNA结构数据库（如RNASolo）
- 联系数据提供者获取标准化文件
- 使用自动化清洗工具处理
