# 标准CAME-AB工作流的4步定义和各步骤的具体输入输出契约

## 适用范围
本知识适用于CAME-AB抗体-抗原结合位点预测任务的标准工作流定义，特别是需要严格按照4步工作流执行时。

## 输入
- 任务目标：抗体-抗原结合位点预测
- 输入文件：antibody_antigen.fasta（序列）、came_ab.pt（权重）
- 工作流定义：s01-s04四步工作流

## 输出
- 预测结果：结合位点位置
- 评估报告：AUPRC、F1等指标
- 筛选结果：高置信度预测
- 可开发性报告

## 流程节点
1. **s01-输入验证** → 验证输入文件和参数
2. **s02-特征准备** → 准备CDR、表位、界面特征
3. **s03-推理执行** → 执行模型推理
4. **s04-评估筛选** → 评估性能并筛选结果

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 工作流步骤 | 4步 | 任务报告 | 标准工作流定义 |
| s01输入 | antibody_antigen.fasta | 任务报告 | 序列文件 |
| s02特征 | CDR、表位、界面 | 任务报告 | 结构特征 |
| s03权重 | came_ab.pt | 任务报告 | 预训练权重 |
| s04指标 | 界面AUPRC | 任务报告 | 评估指标 |

## 边界与分流
- **步骤缺失**：必须严格按照4步执行，不能增删步骤
- **输入缺失**：检查输入文件是否存在
- **权重缺失**：获取预训练权重或使用随机初始化（不推荐）
- **评估异常**：检查数据质量和模型性能

## 质量检查
- 验证工作流步骤完整性
- 检查每步输入输出契约
- 验证中间结果合理性
- 检查最终评估指标

## 回退策略
1. 使用随机初始化权重（性能会下降）
2. 使用合成数据（不推荐）
3. 简化工作流步骤（不推荐）
4. 报告工作流执行异常
