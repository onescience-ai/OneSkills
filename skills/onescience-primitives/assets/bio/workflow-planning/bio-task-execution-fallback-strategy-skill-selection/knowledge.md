# 任务执行回退策略和技能选择原则

## 适用范围
本卡片适用于OneScience任务执行中的决策逻辑，包括资源不足时的回退策略、任务拆解原则和技能选择方法。适用于生物信息学、材料科学、气候模拟等多个领域的复杂任务执行。

## 输入
- **任务描述**：任务目标、约束条件和期望输出
- **资源状态**：可用数据、模型权重、计算资源
- **执行环境**：本地环境、远程集群、云平台
- **技能库**：可用技能列表和能力边界

## 输出
- **执行计划**：任务步骤序列和依赖关系
- **回退方案**：资源不足时的替代路径
- **技能选择**：匹配任务领域的执行技能
- **验证标准**：任务完成的质量检查点

## 流程节点
1. **任务理解** → 2. **资源评估** → 3. **技能选择** → 4. **任务拆解** → 5. **执行监控** → 6. **回退处理**

### 详细步骤：
1. **任务理解**：解析任务目标和约束条件
   - 操作：分析任务描述、识别关键要求
   - 参数：目标明确度、约束严格度
   - 工具：自然语言处理、需求分析
   - 质量门禁：任务理解准确性检查

2. **资源评估**：评估可用资源和缺口
   - 操作：检查数据可用性、模型权重、计算资源
   - 参数：资源完整性、访问权限
   - 工具：资源清单、访问测试
   - 质量门禁：资源缺口识别完整性

3. **技能选择**：根据任务领域选择合适技能
   - 操作：匹配任务类型与技能能力
   - 参数：领域匹配度、技能可用性
   - 工具：技能目录、能力矩阵
   - 质量门禁：技能选择合理性检查

4. **任务拆解**：将任务分解为可执行步骤
   - 操作：识别子任务、确定依赖关系
   - 参数：步骤粒度、并行可能性
   - 工具：工作流规划、依赖分析
   - 质量门禁：步骤完整性检查

5. **执行监控**：监控任务执行状态
   - 操作：跟踪进度、检测异常
   - 参数：执行日志、性能指标
   - 工具：日志分析、性能监控
   - 质量门禁：执行稳定性检查

6. **回退处理**：处理执行中的失败和异常
   - 操作：触发回退策略、执行替代方案
   - 参数：回退条件、替代方案优先级
   - 工具：异常处理、回退逻辑
   - 质量门禁：回退有效性检查

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 回退触发条件 | 资源不足、执行失败、约束违反 | [1] | 何时启动回退策略 |
| 替代方案优先级 | 替代数据集 > 替代模型 > 简化任务 | [1] | 回退时的选择顺序 |
| 任务拆解原则 | 严格遵循workflow定义 | 报告 | 必须按场景索引中的workflow拆解 |
| 技能选择原则 | 领域匹配 > 任务类型匹配 | 报告 | 根据bio/material/climate等选择 |
| 验证标准 | RMSD ≤ 2 Å、PoseBusters验证 | [1] | 任务完成的质量判据 |

## 边界与分流
- **资源充足**：按标准流程执行，无需回退
- **资源部分不足**：尝试替代方案，保持核心目标
- **资源严重不足**：简化任务或标记BLOCKED
- **技能不匹配**：寻找领域专家技能或通用执行技能

## 质量检查
1. **回退触发检查**：确认回退条件是否满足
2. **替代方案验证**：确保替代方案可行
3. **任务完整性检查**：确认核心目标仍可达成
4. **执行一致性检查**：确保回退后结果可接受

## 回退策略
- **数据不足**：使用公开数据集（如PDBbind）或合成数据
- **模型权重缺失**：寻找预训练模型或简化模型架构
- **计算资源不足**：使用云计算平台或优化算法
- **技能不匹配**：使用通用执行技能（如onescience-coder）
