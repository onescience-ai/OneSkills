# 蛋白变异效应预测结果质量评估

## 适用范围
当需要评估蛋白变异效应预测结果的科学有效性时，本卡提供统计显著性判断标准、预期表现范围和质量门禁规则。适用于基于深度突变扫描数据验证蛋白语言模型预测准确性的场景，支持模型性能评估和结果可靠性判断。

## 输入
- 预测结果：蛋白变异的功能评分（如ESM-1v零样本评分）
- 实验数据：深度突变扫描（DMS）的功能评分（如TEM-1 DMS数据）
- 评估指标：Spearman相关系数及其统计显著性

## 输出
- 质量评估报告：包含相关系数、p值、置信区间
- 显著性判断：是否达到统计显著性阈值
- 结果解释：预测结果的科学有效性评估

## 流程节点
1. **数据对齐** → 2. **相关性计算** → 3. **统计检验** → 4. **置信区间估计** → 5. **质量门禁判断**

### 步骤1：数据对齐
- 操作：将预测评分与实验DMS评分按突变位点对齐
- 参数：匹配键（突变标识）、数据类型转换
- 工具：pandas数据合并
- 质量门禁：所有突变位点正确匹配，无缺失值

### 步骤2：相关性计算
- 计算Spearman秩相关系数（rho）
- 参数：对齐后的评分向量
- 工具：scipy.stats.spearmanr
- 质量门禁：相关系数在合理范围（-1到1）

### 步骤3：统计检验
- 计算p值评估统计显著性
- 参数：样本量、相关系数
- 工具：统计检验函数
- 质量门禁：p值计算正确，样本量足够

### 步骤4：置信区间估计
- 使用Bootstrap方法估计相关系数的置信区间
- 参数：重采样次数（通常1000次）、置信水平（通常95%）
- 工具：Bootstrap重采样
- 质量门禁：置信区间宽度合理，不包含零值

### 步骤5：质量门禁判断
- 根据预设阈值判断结果质量
- 参数：显著性阈值（p<0.05）、相关性阈值（rho>0.3）
- 工具：逻辑判断
- 质量门禁：明确输出PASS/FAIL判断

## 边界与分流
- **样本量不足**（<100突变）：转向使用Bootstrap置信区间或贝叶斯方法，避免p值误导
- **相关性过低**（rho < 0.3）：检查数据质量、模型选择或评估方法，可能需重新分析
- **p值不显著**（p > 0.05）：结果可能无统计学意义，需谨慎解释或增加样本量
- **置信区间过宽**：增加Bootstrap重采样次数或检查数据异质性

## 质量检查
- 验证点：数据对齐正确性、统计计算准确性、阈值应用一致性
- 阈值：p < 0.05且rho > 0.3为通过标准
- 失败处理：记录具体失败原因，提供改进建议

## 回退策略
- 标准方法不适用时，考虑使用其他相关性指标（如Pearson、Kendall）
- 统计检验受限时，使用描述性统计和可视化辅助判断
- 样本量严重不足时，明确标注结果局限性，避免过度解释
