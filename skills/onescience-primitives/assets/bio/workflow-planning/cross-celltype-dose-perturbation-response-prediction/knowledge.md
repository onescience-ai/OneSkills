# 跨细胞类型与剂量的扰动响应预测（B73）

## 适用范围

**适用场景**：
- 单细胞/空间/多组学矩阵和关键元数据完整，目标是表征、注释、扰动响应或空间组织分析。
- 供体、批次和条件可独立划分，且有足够的细胞数和生物学重复评估泛化。
- 预处理、缺失机制和标签本体明确，结果会报告不确定性和细胞群体覆盖。
- 结果用于探索细胞状态和实验设计，不把模型反事实直接当作真实干预或临床结论。

**不适用场景**：
- 没有细胞/供体/扰动元数据，或计数、峰和蛋白测量含义无法确认。
- 同一供体、细胞或空间邻域泄漏到测试集，无法支持跨条件泛化。
- 需要声称因果机制、药物疗效或临床决策，而没有实验干预和外部验证。
- 目标模态、物种或组织明显超出模型训练范围，且不允许进行独立适用性评估。

## 研究对象与输入

**研究对象**：单细胞表达、染色质、空间或多组学矩阵及细胞元数据

| 输入项 | 说明 |
|---|---|
| 输入文件 | Parse_filtered.h5ad |
| 输入模态 | h5ad/矩阵、空间坐标、扰动设计和细胞注释表 |
| 样本单元 | 一个细胞、一个空间位置、一个供体或一个扰动条件 |
| 标签/条件 | 细胞类型、批次/供体、空间区域、扰动、剂量和多组学模态标签 |
| 模型引用 | state.ckpt |

**初始结构**：默认输入名称为“Parse_filtered.h5ad”；执行者必须核验格式、版本、实体/样本完整性、缺失值和可解析性，并记录实际使用的相对名称或数据标识。

**表面/硬约束**：保留基因/峰/蛋白标识、计数含义、空间坐标、供体和扰动元数据；规范化、批次校正和缺失值处理必须可追溯。

**划分策略**：按供体、批次、组织、细胞类型和扰动条件拆分，严禁同一细胞或近重复样本跨训练测试泄漏。

**采样要求**：默认输出全量细胞/位置的嵌入、标签或响应分布，并报告每个细胞类型、供体和条件的样本量与不确定度。

## 核心科学问题

1. 在单细胞表达、染色质、空间或多组学矩阵及细胞元数据和输入“Parse_filtered.h5ad”上，预测未见细胞类型、供体和剂量下的转录响应，适用于细胞因子及遗传扰动研究能否得到可复核的差异表达相关结果，并满足任务的硬约束？
2. 输入中的细胞状态表征、扰动/反事实响应、空间结构和跨模态一致性如何影响跨细胞类型与剂量的扰动响应预测的输出，哪些样本、区域或候选最容易失败？
3. 模型在独立样本、未见家族/条件或困难子集上的表现是否稳定，误差和不确定度如何量化？
4. 结果是否具有足够的生物学、化学或临床证据支持后续决策，哪些部分只能作为探索性线索？
5. 在当前数据、模型和资源边界下，哪些结论可以签收，哪些结论必须标记为无法回答或需要额外验证？

## 比较与评估

- 主任务：预测未见细胞类型、供体和剂量下的转录响应，适用于细胞因子及遗传扰动研究；核心指标：差异表达相关。
- 目录模型候选为STATE，需与可解释基线、参考标签或独立质量检查比较。
- 按供体、批次、细胞类型、扰动剂量和空间区域分层报告性能。
- 比较未扰动基线、简单批次/聚类基线和真实标签，审查稀有细胞群的失败。

## 工作流

### 步骤 1：单细胞数据与任务定义

**目的**：读取跨细胞类型与剂量的扰动响应预测的表达、染色质或空间多组学数据。

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 单细胞数据 | `{CELL_DATA}` | doc | 是 | `Parse_filtered.h5ad` | 输入H5AD或表达矩阵 |
| 单细胞模型 | `{MODEL_NAME}` | enum | 是 | `STATE` | 可选值：`STATE` |
| 表达数据层 | `{DATA_LAYER}` | str | 否 | `counts` | 填写用于分析的数据层 |

**输出**：标准化AnnData、特征与样本清单、任务配置

**质量门禁**：
- 细胞和基因标识唯一
- 计数矩阵维度一致
- 必要的元数据列存在

**操作指令**：`读取{CELL_DATA}的{DATA_LAYER}层，检查细胞、基因和空间坐标，使用{MODEL_NAME}建立跨细胞类型与剂量的扰动响应预测任务。`

### 步骤 2：预处理与模型表征

**目的**：加载权重并执行归一化、基因对齐和批次编码。

**依赖步骤**：s01

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 模型权重 | `{CHECKPOINT}` | doc | 是 | `state.ckpt` | 模型权重名称 |
| 批次字段 | `{BATCH_KEY}` | str | 否 | `batch` | 填写批次元数据列名 |
| 归一化计数 | `{NORMALIZE_COUNTS}` | bool | 否 | true | 是否执行总量归一化 |

**输出**：模型输入矩阵、细胞表征、预处理日志

**质量门禁**：
- 基因词表已对齐
- 批次标签无缺失
- 输入数值均为有限值

**操作指令**：`加载{CHECKPOINT}，按{BATCH_KEY}编码批次，并依据{NORMALIZE_COUNTS}处理计数后生成模型表征。`

### 步骤 3：细胞状态推理与生成

**目的**：执行表征、注释、扰动预测或空间恢复任务。

**依赖步骤**：s02

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 目标基因 | `{TARGET_GENES}` | list[str] | 否 | ["TP53", "MYC", "CD3D"] | — | 列出重点分析基因 |
| 采样数量 | `{NUM_SAMPLES}` | int | 是 | `128` | 1–100000 | 设置每条件采样细胞数 |
| 随机种子 | `{SEED}` | int | 否 | `19` | 0–2147483647 | 固定采样与评测结果 |

**输出**：细胞级结果、基因级结果、推理日志

**质量门禁**：
- 所有细胞有唯一结果
- 输出基因顺序一致
- 采样数量符合配置

**操作指令**：`运行跨细胞类型与剂量的扰动响应预测，以种子{SEED}为{TARGET_GENES}相关条件产生{NUM_SAMPLES}个预测或表征样本。`

### 步骤 4：生物一致性与泛化评估

**目的**：计算差异表达相关并检查细胞类型、通路和空间结构保持。

**依赖步骤**：s03

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 相关性下限 | `{MIN_CORRELATION}` | float | 否 | `0.5` | -1–1 | 设置表达相关性下限 |
| 评测标签字段 | `{LABEL_KEY}` | str | 否 | `cell_type` | — | 填写真实标签列名 |

**输出**：评测结果、差异表达相关明细、生物一致性报告

**质量门禁**：
- 训练测试样本隔离
- 低质量细胞已标记
- 结果保留原始细胞索引

**操作指令**：`基于{LABEL_KEY}和{MIN_CORRELATION}评估差异表达相关、差异表达及结构保持并汇总失败条件。`

- 保留基因/峰/蛋白标识、计数含义、空间坐标、供体和扰动元数据；规范化、批次校正和缺失值处理必须可追溯。

- 历史论文、参考模型和示例文件只能用于方案设计或交叉检查，不能冒充本次任务的新结果。

### 最低证据要求

- 实际研究对象、输入、模型/权重、工具和场景约束与任务书一致，所有偏离均有变更记录。
- 输入、标签/参考数据、版本、筛选规则和训练/评估划分可追溯，泄漏和缺失处理有证据。
- 模型或推理结果有独立于选择过程的差异表达相关评估、分层统计、最差案例和适用域说明。
- 全量结果、失败样本、异常、拒答或低质量标记均被保存；正式分析只使用质量合格的范围。
- 每个目标结果都有定义、单位/量纲（如适用）、样本量、分析窗口、置信区间或不确定度。
- 比较基线、参考标签或人工复核的口径一致，不能只报告对模型有利的子集。
- 结论明确区分观察、模型误差、标签/采样不确定度、偏差和未验证假设。
- 输出文件、环境、日志、版本和校验信息足以让第三方复核关键数值。

## 必要结果项

- **结构结果**：矩阵稀疏性、基因/峰标识、元数据、空间坐标和预处理血缘报告；同时说明输入清洗、版本和任何变更。
- **参考标签结果**：细胞类型、扰动、空间区域、实验批次和多组学配对标签的来源与缺失说明；标注缺失、噪声、类别不平衡和不可用于正式验收的部分。
- **模型结果**：模型/权重、预处理和批次策略、独立供体/条件测试、校准与失败群体分析；明确模型适用的实体、序列/结构/模态范围和不能外推的边界。
- **动力学结果**：细胞嵌入、注释、扰动/反事实分布、空间区域或跨模态检索结果；保留全量候选或逐样本输出、失败原因、随机种子/条件和版本记录。
- **性质结果**：聚类/注释、差异表达、扰动方向、空间保持或检索指标及置信区间；每个指标给出定义、单位或量纲、样本范围、分析窗口和置信区间。
- **结论结果**：一份将观察结果、独立证据、模型误差、采样/标签不确定度、偏差和无法回答的问题分开的科学结论报告。
