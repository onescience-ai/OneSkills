# ESM-1v蛋白语言模型获取与使用

## 适用范围
适用于需要获取和使用ESM-1v蛋白语言模型进行蛋白变异效应预测的场景。该卡片提供模型权重下载、加载API使用和零样本评分策略的知识，支持蛋白变异效应预测任务的模型准备阶段。

## 输入
- 目标模型：ESM-1v (esm1v_t33_650M_UR90S_1)
- 模型类型：蛋白语言模型，用于零样本变异效应预测
- 输入格式：蛋白质序列（氨基酸字符串）

## 输出
- 模型权重文件：esm1v_t33_650M_UR90S_1.pt
- 模型加载代码：Python API调用示例
- 评分结果：突变的功能评分（esm_score）

## 流程节点
1. **模型权重下载** → 2. **模型加载** → 3. **序列预处理** → 4. **零样本评分** → 5. **结果后处理**

### 步骤1：模型权重下载
- 操作：从官方源下载ESM-1v模型权重文件
- 参数：权重文件URL、文件大小、SHA256校验值
- 工具：wget/curl下载工具
- 质量门禁：下载完成，文件大小约1.3GB，校验值匹配

### 步骤2：模型加载
- 使用esm.pretrained.esm1v_t33_650M_UR90S_1()加载预训练模型
- 参数：设备选择（CPU/GPU）、精度设置（FP32/FP16）
- 工具：PyTorch、esm库
- 质量门禁：模型成功加载，参数量约650M

### 步骤3：序列预处理
- 操作：将蛋白质序列转换为模型输入格式
- 参数：序列长度限制、特殊token添加
- 工具：esm.Alphabet.from_pretrained()
- 质量门禁：输入张量形状正确，batch dimension处理

### 步骤4：零样本评分
- 使用wt-marginals策略计算突变评分
- 参数：wild-type序列、突变位点、氨基酸替换
- 工具：模型forward pass + 评分计算
- 质量门禁：输出分数在合理范围（通常0-1）

### 步骤5：结果后处理
- 操作：标准化评分，生成突变效应排序
- 参数：评分归一化方法、排序方向
- 工具：pandas/numpy数据处理
- 质量门禁：评分分布合理，无异常值

## 边界与分流
- **模型下载失败**：尝试镜像站点或联系Facebook Research
- **内存不足**：使用CPU推理或模型量化
- **序列过长**：截断或分段处理
- **评分异常**：检查输入序列格式，验证突变位点

## 质量检查
- 验证点：模型权重完整性、参数量验证、评分合理性
- 阈值：权重文件SHA256校验通过，参数量650M±5%
- 失败处理：重新下载权重，检查esm库版本兼容性

## 回退策略
- 官方源不可用时，尝试学术镜像或合作者提供的备用链接
- 使用ESM-2或其他蛋白语言模型作为临时替代
- 联系Facebook Research获取数据访问权限
