# 靶标特异性全原子肽类设计工作流

## 适用范围
本卡片服务于靶标特异性全原子肽类设计任务，即基于给定蛋白质受体结构，设计能够特异性结合该靶标的肽序列和全原子构象。该任务常见于药物发现、蛋白质工程和生物材料设计等领域。本卡片提供基于PepFlow模型的标准工作流，适用于需要生成全原子肽结构并评估结合亲和力的场景。

## 输入
必填输入包括：
- 设计输入：蛋白质受体的PDB结构文件（默认 `target_interface.pdb`），包含受体结构及结合口袋信息。
- 设计模型：PepFlow模型（默认使用预训练权重 `pepflow.ckpt`）。
- 目标长度：肽序列长度（默认256）。

可选输入包括：
- 固定残基位点：指定肽链中固定残基的位置（默认 `[10,25]`）。
- 对称群：肽结构的对称性约束（默认 `C1`，即无对称性）。
- 设计数量：生成的候选肽数量（默认64）。
- 采样温度：控制生成多样性的温度参数（默认0.2）。
- 随机种子：确保结果可重复（默认17）。
- 筛选阈值：筛选候选肽的置信度阈值（默认0.6）。
- 保留多样候选：是否保留多样化的候选肽（默认true）。

当默认值可用时，无需用户提供即可继续执行。

## 输出
输出产物包括：
- 设计的肽序列（FASTA格式）。
- 全原子构象（PDB格式）。
- 界面置信度评分。
- 结构自洽性评估报告。
- 约束满足度报告。

验证标准：
- 生成的肽序列长度符合目标长度。
- 全原子构象的立体化学合理性（键长、键角、二面角）。
- 界面置信度高于筛选阈值。
- 结构自洽性通过能量最小化或分子动力学模拟验证。

## 流程节点
标准工作流包含四个步骤：

### s01: 解析设计输入
- **操作**：读取蛋白质受体PDB文件，识别结合口袋区域，解析设计参数。
- **参数**：设计输入文件路径、目标长度、固定残基位点、对称群。
- **工具**：PDB解析库（如MDAnalysis、Biopython）。
- **质量门禁**：PDB文件格式正确，结合口袋区域完整。

### s02: 加载权重并编码条件
- **操作**：加载PepFlow模型权重，编码固定残基位点、对称性及功能条件。
- **参数**：模型权重文件路径、固定残基位点列表、对称群类型。
- **工具**：PepFlow模型加载器。
- **质量门禁**：模型成功加载，条件编码无错误。

### s03: 生成结构或序列候选
- **操作**：基于条件生成肽序列和全原子构象候选。
- **参数**：设计数量、采样温度、随机种子。
- **工具**：PepFlow生成器。
- **质量门禁**：生成的候选数量符合要求，无生成失败。

### s04: 筛选候选
- **操作**：按界面置信度、结构自洽性和约束满足度筛选候选。
- **参数**：筛选阈值、保留多样候选标志。
- **工具**：筛选评估工具。
- **质量门禁**：入选候选数量大于零，评估报告完整。

## 边界与分流
- 当默认输入文件不存在时：检查任务产物目录或提示用户提供，而非阻塞等待。
- 当PepFlow模型权重不可用时：尝试从官方来源下载，或使用其他生成模型作为降级方案。
- 当网络访问受限时：优先从场景索引的标准workflow和prompt字段提取设计要求，作为reproduction_spec的输入。
- 当论文获取失败时：直接从标准工作流信息启动任务，论文解析可作为补充而非阻塞条件。

## 质量检查
验证点：
1. PDB文件格式正确，结合口袋区域完整。
2. 模型成功加载，条件编码无错误。
3. 生成的候选数量符合要求。
4. 入选候选的界面置信度高于阈值。
5. 结构自洽性评估通过。

阈值：
- 界面置信度阈值：0.6
- 结构自洽性：能量最小化后无显著冲突。

失败处理：
- PDB文件格式错误：重新解析或提示用户提供正确文件。
- 模型加载失败：检查权重文件路径，尝试重新下载。
- 生成失败：调整采样参数或检查输入条件。

## 回退策略
当PepFlow模型不可用时，可考虑以下替代方案：
- 使用其他肽设计工具（如RFdiffusion + ProteinMPNN + AlphaFold3组合），但需注意这可能不满足标准要求。
- 使用基于物理的分子对接方法。
- 使用已知肽库进行筛选。
