# 靶标特异性全原子肽类设计标准工作流

## 适用范围
- **触发条件**：需要进行靶标特异性全原子肽类设计时使用
- **适用场景**：
  - 基于PepFlow模型的肽设计
  - 需要标准4步工作流的场景
  - 需要明确输入输出契约的场景
- **不适用场景**：
  - 非靶向肽设计
  - 其他肽设计模型的工作流

## 输入
- **设计输入**：蛋白质受体的PDB结构文件（必填，默认：target_interface.pdb）
- **设计模型**：PepFlow模型（必填，默认：PepFlow）
- **目标长度**：肽序列长度（必填，默认：256）

## 输出
- **设计产物**：全原子肽结构和序列
- **验证报告**：界面置信度、结构自洽性和约束满足度报告
- **日志文件**：设计过程日志

## 流程节点
### s01：解析设计输入
- **操作**：读取蛋白质受体结构，提取设计约束
- **输入**：target_interface.pdb
- **输出**：标准化设计输入、约束清单和设计区域
- **工具**：PDB解析器、结构分析工具
- **质量门禁**：结构完整性检查

### s02：加载权重并编码条件
- **操作**：加载PepFlow模型权重，编码固定残基位点和对称群
- **输入**：pepflow.ckpt、固定残基位点（可选）、对称群（可选）
- **输出**：条件特征、固定残基掩码和模型加载记录
- **工具**：PepFlow模型加载器
- **质量门禁**：权重加载成功验证

### s03：生成设计候选
- **操作**：使用条件流匹配生成肽序列和结构
- **输入**：设计数量（必填，默认64）、采样温度（可选，默认0.2）、随机种子（可选，默认17）
- **输出**：设计候选、采样分数和生成日志
- **工具**：PepFlow采样器
- **质量门禁**：生成数量验证、采样多样性检查

### s04：筛选和验证
- **操作**：按界面置信度、结构自洽性和约束满足度筛选候选
- **输入**：筛选阈值（可选，默认0.6）、保留多样候选（可选，默认true）
- **输出**：入选设计、界面置信度汇总表和约束质控报告
- **工具**：筛选器、验证器
- **质量门禁**：筛选比例验证、多样性检查

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 设计输入 | target_interface.pdb | [1] | 默认蛋白质受体结构文件 |
| 设计模型 | PepFlow | [1] | 基于多模态条件流匹配的模型 |
| 目标长度 | 256 | [1] | 默认肽序列长度 |
| 固定残基位点 | [10,25] | [1] | 可选，默认固定位点 |
| 对称群 | C1 | [1] | 可选，默认对称性 |
| 设计数量 | 64 | [1] | 必填，默认生成数量 |
| 采样温度 | 0.2 | [1] | 可选，控制采样随机性 |
| 随机种子 | 17 | [1] | 可选，确保可重复性 |
| 筛选阈值 | 0.6 | [1] | 可选，界面置信度阈值 |
| 保留多样候选 | true | [1] | 可选，是否保留多样设计 |

## 边界与分流
- **异常处理**：
  - 当蛋白质受体结构不可用时，提示用户提供或使用默认输入
  - 当模型权重加载失败时，提示用户检查路径或使用替代模型
- **降级策略**：
  - 当PepFlow不可用时，可使用RFdiffusion+ProteinMPNN组合
  - 当计算资源不足时，可减少设计数量
- **分支条件**：
  - 根据任务类型选择不同的采样模式
  - 根据约束条件调整筛选参数

## 质量检查
- **验证点**：
  - s01：结构完整性检查
  - s02：权重加载成功验证
  - s03：生成数量验证、采样多样性检查
  - s04：筛选比例验证、多样性检查
- **阈值**：
  - 界面置信度 > 0.6
  - 生成数量 = 设计数量
  - 多样性 > 0.3
- **失败处理**：
  - 重新采样或调整参数
  - 降低设计质量要求

## 回退策略
- **失败时的替代方案**：
  - 使用其他肽设计模型
  - 手动设计肽序列
- **降级路径**：
  - 从全原子设计降级到仅骨架设计
  - 从多模态设计降级到单模态设计

## 使用示例
```python
# 标准工作流使用示例
from pepflow_workflow import PeptideDesignWorkflow

# 初始化工作流
workflow = PeptideDesignWorkflow()

# s01：解析设计输入
design_input = workflow.parse_input(
    protein_structure="target_interface.pdb",
    target_length=256
)

# s02：加载权重并编码条件
model = workflow.load_model(
    model_path="pepflow.ckpt",
    fixed_residues=[10, 25],
    symmetry="C1"
)

# s03：生成设计候选
candidates = workflow.generate(
    model=model,
    design_input=design_input,
    num_designs=64,
    temperature=0.2,
    seed=17
)

# s04：筛选和验证
validated_designs = workflow.validate(
    candidates=candidates,
    confidence_threshold=0.6,
    diversity=True
)
```
