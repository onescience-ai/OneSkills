# 抗体候选筛选评估方法与可开发性指标体系

## 适用范围
本知识适用于抗体候选筛选任务，包括基于模型得分的候选排序、统计显著性评估、CDR截断检测、低特异性标记和可开发性评估。适用于需要从大量候选中筛选出最优抗体的场景。

## 输入
- 模型预测得分：亲和力预测模型输出的连续数值
- 真实值（可选）：实验测量的亲和力值（如KD值）
- 抗体序列：候选抗体的氨基酸序列

## 输出
- 排序候选列表：按模型得分排序的候选列表
- Spearman相关结果：预测得分与真实值的相关性
- 可开发性报告：每个候选的可开发性评估

## 流程节点
1. **得分排序** → 按模型预测得分降序排列候选
2. **Spearman相关计算** → 计算预测得分与真实值的Spearman相关系数
3. **统计显著性检验** → 计算p值，判断相关性是否显著（p<0.05）
4. **CDR截断检测** → 检测候选序列是否存在CDR区域异常截断
5. **低特异性标记** → 标记与已知非中和抗体序列相似度过高的候选
6. **可开发性评估** → 评估表达量预测、聚集倾向、免疫原性风险
7. **Top-N筛选** → 保留Top-N候选（默认20）
8. **报告生成** → 生成包含排序候选、统计结果和可开发性指标的报告

## 关键参数

### 通用判据（方法层）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 相关性指标 | Spearman相关系数 | [论文1] | 非参数相关性指标 |
| 显著性阈值 | p<0.05 | [论文1] | 统计显著性标准 |
| 排序方向 | 降序（高分优先） | [论文1] | 高亲和力得分优先 |
| Top-N默认值 | 20 | [论文1] | 保留候选数量 |

### 校准数值（以SARS-CoV-2抗体为例）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| CDR-H3长度范围 | 8-20个残基 | [论文2] | 以下数值来自特定体系，供量级校准 |
| 低特异性阈值 | 序列相似度>80% | [论文1] | 与非中和抗体相似度 |
| 可开发性指标 | 表达量/聚集/免疫原性 | [论文1] | 综合评估指标 |

## 边界与分流
- **缺少真实值**：仅使用模型得分排序，不计算Spearman相关
- **数据泄露风险**：确保分层评估使用测试集而非全集
- **候选数量不足**：调整Top-N参数
- **非标准抗体格式**：调整CDR截断检测规则

## 质量检查
- 验证Spearman相关p值<0.05
- 检查排序候选列表完整性
- 验证CDR截断检测正确性
- 检查可开发性指标完整性

## 回退策略
1. 仅使用模型得分排序，不进行统计评估
2. 使用简单的阈值筛选（如得分>0.7）
3. 仅保留Top-10候选
