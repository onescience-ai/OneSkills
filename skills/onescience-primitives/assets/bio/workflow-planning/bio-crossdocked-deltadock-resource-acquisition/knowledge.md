# CrossDocked数据集和DeltaDock模型权重获取指南

## 适用范围
本卡片适用于蛋白质-配体对接任务中CrossDocked数据集和DeltaDock模型权重的获取，提供权威获取渠道、访问方式和许可证信息。适用于对接基准测试、交叉对接评估和高精度对接任务。

## 输入
- **资源类型**：数据集（CrossDocked2020）或模型权重（DeltaDock）
- **资源版本**：具体版本号或发布日期
- **用途说明**：基准测试、模型训练、推理评估

## 输出
- **获取链接**：官方下载地址
- **访问方式**：直接下载、API访问、申请使用
- **许可证信息**：使用条款和限制
- **验证方法**：文件完整性检查

## 流程节点
1. **资源识别** → 2. **渠道选择** → 3. **访问验证** → 4. **下载获取** → 5. **完整性检查**

### 详细步骤：
1. **资源识别**：确定所需资源的官方名称和版本
   - 操作：检索论文、官方文档、GitHub仓库
   - 参数：资源名称、版本号、发布日期
   - 工具：Google Scholar、arXiv、PubMed
   - 质量门禁：资源真实性验证

2. **渠道选择**：选择权威获取渠道
   - 操作：根据资源类型选择平台
   - 参数：平台可信度、访问便利性
   - 工具：GitHub、Zenodo、HuggingFace
   - 质量门禁：渠道权威性验证

3. **访问验证**：确认资源可访问性
   - 操作：测试链接有效性、检查访问权限
   - 参数：HTTP状态码、认证要求
   - 工具：浏览器、wget、curl
   - 质量门禁：访问成功率检查

4. **下载获取**：下载资源文件
   - 操作：执行下载、处理认证
   - 参数：下载工具、代理设置
   - 工具：wget、curl、浏览器
   - 质量门禁：下载完整性检查

5. **完整性检查**：验证文件完整性
   - 操作：计算哈希值、检查文件大小
   - 参数：哈希算法、预期值
   - 工具：sha256sum、md5sum
   - 质量门禁：哈希值匹配检查

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 资源验证 | 确认官方发布渠道 | [1][2] | 避免获取非官方或修改版本 |
| 许可证检查 | 确认使用条款 | [1][2] | 遵守数据集和模型的使用限制 |
| 版本匹配 | 获取与任务兼容的版本 | [1][2] | 确保与现有代码和工作流兼容 |

### CrossDocked数据集
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据集名称 | CrossDocked2020 | [1] | 包含224.6万蛋白质-配体复合物 |
| 数据格式 | PDB/SDF | [1] | 蛋白质结构和配体构象 |
| 获取渠道 | GitHub仓库 | [1] | https://github.com/Cresset-group/crossdocked |
| 备选渠道 | PDBbind数据库 | [1] | https://www.pdbbind.org/ |
| 许可证 | 学术使用 | [1] | 用于研究和基准测试 |
| 文件大小 | ~20GB（完整版） | [1] | 包含预处理和未处理版本 |

### DeltaDock模型权重
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 模型名称 | DeltaDock | [2] | 基于几何深度学习的对接工具 |
| 获取渠道 | GitHub仓库 | [2] | https://github.com/luigibonati/deltadock |
| 备选渠道 | 论文附属材料 | [2] | 通过论文链接获取 |
| 许可证 | MIT License | [2] | 开源许可，可自由使用 |
| 依赖要求 | PyTorch、PyG | [2] | 需要安装相关依赖 |

## 边界与分流
- **公开资源**：直接下载，无需申请（CrossDocked2020、DeltaDock）
- **受限资源**：需要注册账户或学术邮箱验证（PDBbind高级版本）
- **商业资源**：需要购买许可证或机构订阅（商业对接软件）
- **稀缺资源**：联系作者或机构获取（未公开数据集）

## 质量检查
1. **来源验证**：确认资源来自GitHub官方仓库或论文附属材料
2. **版本检查**：确保获取正确版本（CrossDocked2020、DeltaDock最新版）
3. **许可证确认**：了解使用限制和要求
4. **完整性验证**：哈希值匹配检查

## 回退策略
- **主要渠道失败**：尝试备用渠道（如PDBbind替代GitHub）
- **访问受限**：联系发布者申请访问权限
- **资源不存在**：查找替代数据集或模型（如PDBBind替代CrossDocked）
- **许可证限制**：寻找开源替代方案
