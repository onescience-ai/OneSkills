# 对比学习驱动的宏基因组分箱（B92）

## 适用范围

**适用场景**：
- 宏基因组序列、样本元数据和目标标签可以追溯，目标是分类、分箱、宿主关联或风险筛查。
- 训练/测试按样本和近重复独立划分，有外部或人工核验标签评估跨物种泛化。
- 序列质量、污染、测序/组装版本和类别不平衡能够被报告和控制。
- 结果用于生态研究、监测或实验候选优先级，不直接替代临床诊断或药敏确认。

**不适用场景**：
- 样本来源、污染和分类标签不明，或序列质量不足以支持目标任务。
- 同一菌株/contig跨训练测试泄漏，却需要宣称跨物种或新样本泛化。
- 把风险分数直接解释为感染性、致病性或耐药临床决定。
- 目标环境、物种或测序长度远超模型覆盖，且没有外部验证和人工复核。

## 研究对象与输入

**研究对象**：宏基因组 reads、contigs、基因、噬菌体和宿主关联数据

| 输入项 | 说明 |
|---|---|
| 输入文件 | metagenome_contigs.fasta |
| 输入模态 | FASTA/FASTQ、contig/基因表、样本丰度或宿主图数据 |
| 样本单元 | 一个样本、contig、基因组、噬菌体或宿主-病毒候选边 |
| 标签/条件 | 分类、分箱、功能、宿主关联、致病性、生活方式或耐药表型 |
| 模型引用 | clmb.pt |

**初始结构**：默认输入名称为“metagenome_contigs.fasta”；执行者必须核验格式、版本、实体/样本完整性、缺失值和可解析性，并记录实际使用的相对名称或数据标识。

**表面/硬约束**：记录测序平台、质控、组装、样本和物种标签；病原性、耐药性或宿主预测只能作为风险筛查，不能替代培养、药敏或公共卫生确认。

**划分策略**：按样本、物种、地理/时间批次和基因组近重复拆分，防止同一 contig、菌株或污染序列泄漏。

**采样要求**：默认对全量样本/contig 输出标签、分数、置信度和未分类项，并保留低质量、污染和冲突样本的审计记录。

## 核心科学问题

1. 在宏基因组 reads、contigs、基因、噬菌体和宿主关联数据和输入“metagenome_contigs.fasta”上，融合序列组成和丰度的对比表征完成宏基因组分箱，适用于微生物基因组重建能否得到可复核的分箱F1结果，并满足任务的硬约束？
2. 输入中的序列质量、样本组成、分类/分箱、宿主关联和风险评分如何影响对比学习驱动的宏基因组分箱的输出，哪些样本、区域或候选最容易失败？
3. 模型在独立样本、未见家族/条件或困难子集上的表现是否稳定，误差和不确定度如何量化？
4. 结果是否具有足够的生物学、化学或临床证据支持后续决策，哪些部分只能作为探索性线索？
5. 在当前数据、模型和资源边界下，哪些结论可以签收，哪些结论必须标记为无法回答或需要额外验证？

## 比较与评估

- 主任务：融合序列组成和丰度的对比表征完成宏基因组分箱，适用于微生物基因组重建；核心指标：分箱F1。
- 目录模型候选为CLMB，需与可解释基线、参考标签或独立质量检查比较。
- 按物种、样本来源、丰度和序列长度分层报告性能及假阳性。
- 比较未分类比例、简单k-mer/丰度基线和外部样本，审查污染和低覆盖样本。

## 工作流

### 步骤 1：宏基因组输入与任务定义

**目的**：读取对比学习驱动的宏基因组分箱所需的序列、丰度或宿主标签。

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 宏基因组输入 | `{METAGENOME_INPUT}` | doc | 是 | `metagenome_contigs.fasta` | 输入序列或特征表 |
| 宏基因组模型 | `{MODEL_NAME}` | enum | 是 | `CLMB` | 可选值：`CLMB` |
| 序列类型 | `{SEQUENCE_TYPE}` | enum | 否 | `contig` | 可选值：`read`、`contig`、`gene`、`genome` |

**输出**：标准化序列、样本与标签表、任务配置

**质量门禁**：
- 序列字符合法
- 样本来源可追溯
- 标签定义无冲突

**操作指令**：`读取{METAGENOME_INPUT}中的{SEQUENCE_TYPE}序列并检查字符、长度和标签，使用{MODEL_NAME}建立对比学习驱动的宏基因组分箱任务。`

### 步骤 2：序列过滤与模型准备

**目的**：加载权重并进行长度过滤、分词和参考信息编码。

**依赖步骤**：s01

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 模型权重 | `{CHECKPOINT}` | doc | 是 | `clmb.pt` | — | 模型权重名称 |
| 最短序列长度 | `{MIN_CONTIG_LENGTH}` | int | 否 | `1000` | 50–100000 | 设置最短序列碱基数 |
| 参考数据库 | `{REFERENCE_DB}` | doc | 否 | `GTDB_R220` | — | 参考数据库名称 |

**输出**：过滤后序列、序列表征、过滤统计

**质量门禁**：
- 过滤阈值已记录
- 参考版本可追溯
- 序列与样本映射保持

**操作指令**：`加载{CHECKPOINT}和{REFERENCE_DB}，过滤短于{MIN_CONTIG_LENGTH}的序列并生成模型特征。`

### 步骤 3：微生物预测与聚合

**目的**：批量完成分类、分箱、宿主关联或耐药性预测。

**依赖步骤**：s02

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 批次大小 | `{BATCH_SIZE}` | int | 是 | `64` | 1–4096 | 设置序列批次大小 |
| 判定阈值 | `{DECISION_THRESHOLD}` | float | 否 | `0.5` | 0–1 | 设置阳性判定阈值 |
| 随机种子 | `{SEED}` | int | 否 | `29` | 0–2147483647 | 固定聚类或评测结果 |

**输出**：序列级预测、样本级汇总、运行日志

**质量门禁**：
- 每条序列有结果
- 聚合规则可复现
- 低置信结果未强制归类

**操作指令**：`以批次{BATCH_SIZE}和种子{SEED}运行对比学习驱动的宏基因组分箱，用{DECISION_THRESHOLD}输出序列及样本级结果。`

### 步骤 4：生态与分类质量评估

**目的**：计算分箱F1并检查跨物种、样本和数据集泛化。

**依赖步骤**：s03

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 置信度下限 | `{MIN_CONFIDENCE}` | float | 否 | `0.7` | 0–1 | 设置报告置信度下限 |
| 报告未知类别 | `{REPORT_UNKNOWN}` | bool | 否 | true | — | 是否保留未知类别结果 |

**输出**：评测汇总、分箱F1明细、未知与异常清单

**质量门禁**：
- 评测按样本隔离
- 未知类别未被静默丢弃
- 结果可回溯原序列

**操作指令**：`计算分箱F1，按{MIN_CONFIDENCE}标记可信结果，并依据{REPORT_UNKNOWN}保留未知类别。`

## 验收标准与质量门禁

### 硬约束（不可违反）

- 记录测序平台、质控、组装、样本和物种标签；病原性、耐药性或宿主预测只能作为风险筛查，不能替代培养、药敏或公共卫生确认。
- 输入、标签、模型版本、数据划分和实际输出之间的血缘必须可追溯；任何偏离都要记录并经场景确认。
- 不得把平均分数、单个高分样本或模型自评当作生物学、化学或临床事实；正式结论必须有独立证据。
- 历史论文、参考模型和示例文件只能用于方案设计或交叉检查，不能冒充本次任务的新结果。

### 最低证据要求

- 实际研究对象、输入、模型/权重、工具和场景约束与任务书一致，所有偏离均有变更记录。
- 输入、标签/参考数据、版本、筛选规则和训练/评估划分可追溯，泄漏和缺失处理有证据。
- 模型或推理结果有独立于选择过程的分箱F1评估、分层统计、最差案例和适用域说明。
- 全量结果、失败样本、异常、拒答或低质量标记均被保存；正式分析只使用质量合格的范围。
- 每个目标结果都有定义、单位/量纲（如适用）、样本量、分析窗口、置信区间或不确定度。
- 比较基线、参考标签或人工复核的口径一致，不能只报告对模型有利的子集。
- 结论明确区分观察、模型误差、标签/采样不确定度、偏差和未验证假设。
- 输出文件、环境、日志、版本和校验信息足以让第三方复核关键数值。

**验收判定**：执行者必须对每个交付项给出 PASS、PARTIAL、REJECT 或 BLOCKED，并附文件、日志、图表或数值证据；没有证据的‘运行正常’或‘效果良好’不能作为签收依据。

1. 任务理解、执行方案、变更记录和输入/许可核验。

## 必要结果项

- **结构结果**：reads/contig/基因输入的质量、长度、污染、丰度和样本元数据报告；同时说明输入清洗、版本和任何变更。
- **参考标签结果**：分类、宿主、功能、致病性、生活方式或耐药标签的来源、版本和不确定性；标注缺失、噪声、类别不平衡和不可用于正式验收的部分。
- **模型结果**：模型/权重、独立样本/物种测试、类别校准、未分类比例和最差样本分析；明确模型适用的实体、序列/结构/模态范围和不能外推的边界。
- **动力学结果**：分箱、分类、宿主关联或风险预测及逐样本置信度和日志；保留全量候选或逐样本输出、失败原因、随机种子/条件和版本记录。
- **性质结果**：F1/AUROC/Hit@k/灵敏度、假阳性、跨物种泛化和不确定度统计；每个指标给出定义、单位或量纲、样本范围、分析窗口和置信区间。
- **结论结果**：一份将观察结果、独立证据、模型误差、采样/标签不确定度、偏差和无法回答的问题分开的科学结论报告。
