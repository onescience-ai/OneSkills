# CAME-AB模型预训练权重的获取途径和加载方法

## 适用范围
本知识适用于CAME-AB模型预训练权重的获取和加载，特别是需要使用预训练模型进行抗体-抗原结合位点预测时。

## 输入
- 模型名称：CAME-AB
- 权重文件：came_ab.pt
- 论文来源：arXiv:2509.06465（待确认）
- 框架：PyTorch

## 输出
- 预训练权重文件（came_ab.pt）
- 模型加载接口
- 权重验证信息

## 流程节点
1. **权重来源查找** → 查找论文作者提供的权重下载链接
2. **权重下载** → 从官方仓库或公开资源下载权重文件
3. **权重验证** → 验证权重文件完整性和格式
4. **权重加载** → 使用PyTorch加载权重到模型
5. **参数验证** → 验证加载后参数非随机初始化

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 权重格式 | .pt | PyTorch标准 | PyTorch模型保存格式 |
| 参数量 | 19.4M | 任务报告 | CAME-AB模型参数量 |
| 初始化方法 | xavier_uniform_ | 任务报告 | 随机初始化方法（不推荐） |
| 论文编号 | arXiv:2509.06465 | 待确认 | 论文预印本编号 |

## 边界与分流
- **权重不可用**：尝试联系论文作者或查找官方仓库
- **格式不兼容**：使用PyTorch兼容版本加载
- **版本不匹配**：检查模型架构是否与权重匹配
- **下载失败**：尝试备用下载源或联系管理员

## 质量检查
- 验证权重文件SHA256校验和
- 检查加载后参数是否非随机初始化
- 验证模型输出是否合理
- 检查权重文件大小是否合理

## 回退策略
1. 使用随机初始化权重（需注明，性能会下降）
2. 尝试其他预训练模型（如IgFold）
3. 联系论文作者获取权重
4. 使用合成数据训练临时模型
