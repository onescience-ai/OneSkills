# TEM-1 β-内酰胺酶深度突变扫描数据来源指南

## 适用范围
适用于需要获取TEM-1 β-内酰胺酶深度突变扫描数据的场景，包括但不限于：
- 蛋白变异效应预测模型的验证
- 蛋白质工程和定向进化研究
- 机器学习模型训练数据获取
- 生物信息学分析流程开发

不适用场景：
- 非TEM-1蛋白的深度突变扫描数据
- 结构性突变数据（非深度突变扫描）
- 模拟或合成数据

## 输入
- 目标蛋白：TEM-1 β-内酰胺酶（BLAT_ECOLX）
- 数据类型：深度突变扫描数据集
- 数据格式：CSV文件，包含突变体、功能评分等列

## 输出
- 真实的DMS数据文件（BLAT_ECOLX_Ranganathan2015.csv）
- 数据格式验证报告
- 数据血缘说明文档

## 流程节点
1. **数据源识别** → 确定Ranganathan Lab原始数据存储位置
2. **格式规范确认** → 验证CSV文件列格式
3. **数据下载** → 从GitHub/Zenodo获取真实数据
4. **格式验证** → 检查数据完整性和格式正确性
5. **数据血缘记录** → 记录数据来源、版本和获取时间

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据文件名 | BLAT_ECOLX_Ranganathan2015.csv | [归因报告] | 标准命名格式 |
| 主要列 | mutant, func_score | [归因报告] | 必需列，用于后续分析 |

## 边界与分流
- **数据不可用**：若GitHub/Zenodo均无法访问，记录阻塞原因并建议替代数据源
- **格式不匹配**：若下载的CSV列格式与标准不符，提供格式转换脚本
- **数据不完整**：若缺少关键列（如func_score），标记数据质量不足
- **许可证限制**：需确认数据使用许可证（通常为CC-BY或类似）

## 质量检查
1. **行数验证**：CSV文件应包含数千条突变记录
2. **列名匹配**：必须包含mutant、func_score等标准列
3. **野生型验证**：应包含野生型序列作为基准
4. **数据完整性**：func_score应在合理范围内（如0-1）
5. **重复检查**：不应有重复的突变记录

## 回退策略
1. **GitHub不可用**：尝试从Zenodo获取相同数据集
2. **官方数据源不可用**：搜索其他已发表论文的补充材料
3. **格式不匹配**：编写格式转换脚本适配标准格式
4. **数据质量不足**：标记数据限制并建议用户谨慎使用
