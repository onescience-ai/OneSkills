# 跨膜蛋白序列离散扩散设计（B19）

## 适用范围

**适用场景**：
- 设计目标、结构或功能约束能够被明确表示，并且允许生成多个候选进行筛选。
- 有回折叠、结构质量、化学几何或其他独立代理证据评估候选，而不是只看生成分数。
- 目标序列长度、拓扑、配体和约束组合在模型验证范围内，或执行者能补充适用域检查。
- 结果用于候选发现、蛋白工程或实验优先级排序，最终功能仍需实验确认。

**不适用场景**：
- 没有明确的设计目标或硬约束，只要求无条件地产生看似合理的序列并宣称功能成立。
- 无法对候选进行结构、化学或功能代理质控，或者只保留成功样本而丢弃失败记录。
- 目标含非标准残基、复杂反应或环境效应而模型没有相应训练和验证证据。
- 任务要求直接给出已验证的疗效、催化速率或安全性结论而没有实验数据。

## 研究对象与输入

**研究对象**：受约束的蛋白骨架、序列、肽或酶设计任务

| 输入项 | 说明 |
|---|---|
| 输入文件 | membrane_backbone.pdb |
| 输入模态 | PDB/mmCIF、口袋/配体描述、反应条件或设计约束文件 |
| 样本单元 | 一个设计目标及其候选序列/结构集合 |
| 标签/条件 | 固定残基、基序、口袋、拓扑、反应或功能约束 |
| 模型引用 | tgdd_model.pt |

**初始结构**：默认输入名称为“membrane_backbone.pdb”；执行者必须核验格式、版本、实体/样本完整性、缺失值和可解析性，并记录实际使用的相对名称或数据标识。

**表面/硬约束**：设计前锁定目标长度、固定残基、基序、链拓扑、口袋/反应条件和允许氨基酸集合；任何约束变更必须记录并经确认。

**划分策略**：按目标家族、骨架相似性和约束组合划分设计评估；不得用生成候选本身或其近重复样本估计泛化能力。

**采样要求**：默认生成不少于 64 个带随机种子和条件记录的候选，保留全部硬约束失败项以便审计，并输出去冗余后的候选集。

## 核心科学问题

1. 在受约束的蛋白骨架、序列、肽或酶设计任务和输入“membrane_backbone.pdb”上，在膜拓扑和骨架约束下生成跨膜蛋白序列，适用于受体与通道蛋白设计能否得到可复核的膜区恢复率结果，并满足任务的硬约束？
2. 输入中的硬约束满足、结构自洽、序列多样性和功能代理指标如何影响跨膜蛋白序列离散扩散设计的输出，哪些样本、区域或候选最容易失败？
3. 模型在独立样本、未见家族/条件或困难子集上的表现是否稳定，误差和不确定度如何量化？
4. 结果是否具有足够的生物学、化学或临床证据支持后续决策，哪些部分只能作为探索性线索？
5. 在当前数据、模型和资源边界下，哪些结论可以签收，哪些结论必须标记为无法回答或需要额外验证？

## 比较与评估

- 主任务：在膜拓扑和骨架约束下生成跨膜蛋白序列，适用于受体与通道蛋白设计；核心指标：膜区恢复率。
- 目录模型候选为Token-Guided Diffusion，需与可解释基线、参考标签或独立质量检查比较。
- 将候选与输入骨架/参考序列及至少一个简单基线进行结构、序列和多样性比较。
- 分别报告硬约束通过率、独立回折叠结果和去冗余前后的候选数量。

## 工作流

### 步骤 1：设计目标与约束定义

**目的**：解析跨膜蛋白序列离散扩散设计的目标结构、功能条件和设计范围。

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 设计输入 | `{DESIGN_INPUT}` | doc | 是 | `membrane_backbone.pdb` | — | 输入结构或约束文件 |
| 设计模型 | `{MODEL_NAME}` | enum | 是 | `Token-Guided Diffusion` | — | 可选值：`Token-Guided Diffusion` |
| 目标长度 | `{TARGET_LENGTH}` | int | 是 | `256` | 20–1200 | 设置目标残基数量 |

**输出**：标准化设计输入、约束清单、设计区域

**质量门禁**：
- 约束引用有效
- 目标长度受模型支持
- 设计区域无冲突

**操作指令**：`读取{DESIGN_INPUT}，使用{MODEL_NAME}定义长度为{TARGET_LENGTH}的跨膜蛋白序列离散扩散设计任务及可设计区域。`

### 步骤 2：模型与条件特征准备

**目的**：加载权重并编码固定残基、对称性及功能条件。

**依赖步骤**：s01

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 模型权重 | `{CHECKPOINT}` | doc | 是 | `tgdd_model.pt` | 模型权重名称 |
| 固定残基位点 | `{FIXED_POSITIONS}` | list[int] | 否 | [10, 25] | 列出保持不变的位点 |
| 对称群 | `{SYMMETRY}` | str | 否 | `C1` | 填写蛋白对称群 |

**输出**：条件特征、固定残基掩码、模型加载记录

**质量门禁**：
- 固定位点在长度范围内
- 对称群可解析
- 条件特征无缺失

**操作指令**：`加载{CHECKPOINT}，编码{FIXED_POSITIONS}固定残基与{SYMMETRY}对称条件，生成模型输入特征。`

### 步骤 3：候选生成与序列采样

**目的**：生成结构或序列候选并记录随机性参数。

**依赖步骤**：s02

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 设计数量 | `{NUM_DESIGNS}` | int | 是 | `64` | 1–5000 | 设置生成候选数量 |
| 采样温度 | `{TEMPERATURE}` | float | 否 | `0.2` | 0.01–2 | 控制采样多样性 |
| 随机种子 | `{SEED}` | int | 否 | `17` | 0–2147483647 | 固定随机采样结果 |

**输出**：设计候选、采样分数、生成日志

**质量门禁**：
- 候选数量达标
- 固定残基未改变
- 序列与结构长度一致

**操作指令**：`以温度{TEMPERATURE}和种子{SEED}运行跨膜蛋白序列离散扩散设计，生成{NUM_DESIGNS}个候选。`

### 步骤 4：回折叠与设计筛选

**目的**：按膜区恢复率、结构自洽性和约束满足度筛选候选。

**依赖步骤**：s03

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 筛选阈值 | `{METRIC_THRESHOLD}` | float | 否 | `0.6` | 0–1 | 设置核心指标下限 |
| 保留多样候选 | `{KEEP_DIVERSE}` | bool | 否 | true | — | 是否执行序列去冗余 |

**输出**：入选设计、膜区恢复率汇总表、约束质控报告

**质量门禁**：
- 入选设计满足硬约束
- 结构几何无严重冲突
- 序列多样性已报告

**操作指令**：`计算膜区恢复率并以{METRIC_THRESHOLD}筛选；按{KEEP_DIVERSE}控制去冗余后导出候选。`

## 验收标准与质量门禁

### 硬约束（不可违反）

- 设计前锁定目标长度、固定残基、基序、链拓扑、口袋/反应条件和允许氨基酸集合；任何约束变更必须记录并经确认。
- 输入、标签、模型版本、数据划分和实际输出之间的血缘必须可追溯；任何偏离都要记录并经场景确认。
- 不得把平均分数、单个高分样本或模型自评当作生物学、化学或临床事实；正式结论必须有独立证据。
- 历史论文、参考模型和示例文件只能用于方案设计或交叉检查，不能冒充本次任务的新结果。

### 最低证据要求

- 实际研究对象、输入、模型/权重、工具和场景约束与任务书一致，所有偏离均有变更记录。
- 输入、标签/参考数据、版本、筛选规则和训练/评估划分可追溯，泄漏和缺失处理有证据。
- 模型或推理结果有独立于选择过程的膜区恢复率评估、分层统计、最差案例和适用域说明。
- 全量结果、失败样本、异常、拒答或低质量标记均被保存；正式分析只使用质量合格的范围。
- 每个目标结果都有定义、单位/量纲（如适用）、样本量、分析窗口、置信区间或不确定度。
- 比较基线、参考标签或人工复核的口径一致，不能只报告对模型有利的子集。
- 结论明确区分观察、模型误差、标签/采样不确定度、偏差和未验证假设。
- 输出文件、环境、日志、版本和校验信息足以让第三方复核关键数值。

**验收判定**：执行者必须对每个交付项给出 PASS、PARTIAL、REJECT 或 BLOCKED，并附文件、日志、图表或数值证据；没有证据的‘运行正常’或‘效果良好’不能作为签收依据。

## 交付物清单

### 最小交付物

1. 任务理解、执行方案、变更记录和输入/许可核验。
2. 经格式和约束检查的设计目标、固定区域掩码、候选结构/序列及结构自洽报告及数据血缘、质量和缺失说明。
3. 模型与权重版本、条件编码记录、独立回折叠/结构评估和失败模式及独立测试、适用域和失败案例报告。
4. 全量候选、采样分数、硬约束通过/失败清单及随机性记录、全量异常/失败记录和运行日志。
5. 基序/口袋/界面保持度、序列恢复或催化几何等指标的逐候选统计、可视化/表格、统计不确定度和分层结果。
6. 完整复现包：输入标识、脚本、环境、版本、任务记录、结果清单和文件校验信息。

### 报告规范

- 报告先给结论，再给证据、方法选择理由、限制、偏差和未完成项。
- 所有结果标注膜区恢复率定义、单位或量纲、样本/候选范围、模型版本和数据来源。
- 任何历史资料、参考模型、外部数据库或人工复核都要显式标注身份、用途和可能影响。

### 失败交付要求

如果任务未完成，仍须交付最后一个可复用的健康产物、失败位置、根因证据、影响范围、已排除原因和下一步建议；失败结果不得包装成正式科学结论。

- 本任务关注在膜拓扑和骨架约束下生成跨膜蛋白序列，适用于受体与通道蛋白设计、硬约束满足、结构自洽、序列多样性和功能代理指标以及膜区恢复率的可复核评估。

**不属于默认交付**：

## 执行前确认事项

- 输入格式、版本、样本/实体完整性和固定残基、基序、口袋、拓扑、反应或功能约束是否足以支撑任务。

## 必要结果项

- **结构结果**：经格式和约束检查的设计目标、固定区域掩码、候选结构/序列及结构自洽报告；同时说明输入清洗、版本和任何变更。
- **参考标签结果**：设计约束、训练/参考结构、功能标签和筛选规则的来源与适用范围；标注缺失、噪声、类别不平衡和不可用于正式验收的部分。
- **模型结果**：模型与权重版本、条件编码记录、独立回折叠/结构评估和失败模式；明确模型适用的实体、序列/结构/模态范围和不能外推的边界。
- **动力学结果**：全量候选、采样分数、硬约束通过/失败清单及随机性记录；保留全量候选或逐样本输出、失败原因、随机种子/条件和版本记录。
- **性质结果**：基序/口袋/界面保持度、序列恢复或催化几何等指标的逐候选统计；每个指标给出定义、单位或量纲、样本范围、分析窗口和置信区间。
- **结论结果**：一份将观察结果、独立证据、模型误差、采样/标签不确定度、偏差和无法回答的问题分开的科学结论报告。
