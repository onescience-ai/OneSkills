# TEM-1 β-内酰胺酶深度突变扫描数据获取

## 适用范围
适用于需要获取TEM-1 β-内酰胺酶（BLAT_ECOLX）深度突变扫描（DMS）数据的场景，特别是Ranganathan Lab 2015年发表的数据集。该卡片提供数据源定位、格式验证和下载方式的知识，支持蛋白变异效应预测任务的数据准备阶段。

## 输入
- 目标蛋白：TEM-1 β-内酰胺酶（BLAT_ECOLX）
- 数据类型：深度突变扫描（DMS）数据
- 期望格式：CSV文件，包含突变信息和功能评分

## 输出
- 数据文件：BLAT_ECOLX_Ranganathan2015.csv
- 数据格式验证：检查列名匹配（mutant、func_score等）和数据完整性
- 数据血缘说明：数据来源、版本和使用条款

## 流程节点
1. **数据源定位** → 2. **格式验证** → 3. **下载测试** → 4. **数据完整性检查**

### 步骤1：数据源定位
- 操作：确定TEM-1 DMS数据的公开存储位置
- 参数：数据文件名BLAT_ECOLX_Ranganathan2015.csv
- 工具：Web搜索、科学数据库查询
- 质量门禁：确认至少一个可访问的数据源

### 步骤2：格式验证
- 操作：验证数据文件格式是否符合预期
- 参数：列名（mutant、func_score等）、数据类型、编码格式
- 工具：CSV解析器、数据验证脚本
- 质量门禁：所有必需列存在，数据类型正确

### 步骤3：下载测试
- 操作：测试数据文件下载可行性
- 参数：下载URL、认证要求、文件大小
- 工具：HTTP客户端、下载管理器
- 质量门禁：成功下载文件，无404或传输错误

### 步骤4：数据完整性检查
- 操作：验证下载数据的完整性和准确性
- 参数：行数（应为数千条突变）、野生型氨基酸验证
- 工具：数据清洗脚本、统计验证
- 质量门禁：数据行数合理，野生型序列正确

## 关键参数
| 参数 | 值 | 来源 | 说明 |

| 数据文件名 | BLAT_ECOLX_Ranganathan2015.csv | [归因报告] | 标准命名格式 |

## 边界与分流
- **数据源不可用**：尝试多个备用源（GitHub、Zenodo、protmutdb.org）
- **格式不匹配**：检查数据版本，可能存在格式更新
- **下载失败**：检查网络连接，尝试镜像站点或联系数据发布者
- **数据质量问题**：进行数据清洗，过滤无效突变记录

## 质量检查
- 验证点：数据文件可读性、列名匹配、数据类型正确性
- 阈值：所有必需列存在，无缺失值，数据行数>1000
- 失败处理：记录错误详情，尝试备用数据源

## 回退策略
- 主数据源失败时，尝试学术机构或合作者提供的备用链接
- 联系Ranganathan Lab获取数据访问权限
- 使用类似蛋白的DMS数据作为临时替代（需明确标注）

## 资源召回建议
- 何时应召回本卡片：当任务需要TEM-1 β-内酰胺酶的深度突变扫描数据时
- 配套资源：ESM-1v模型权重（bio-esm1v-model-acquisition）、蛋白变异效应预测工作流
