# PDB结构文件的下载和解析方法

## 适用范围
本知识适用于PDB结构文件的下载和解析，特别是需要提取抗体-抗原复合物结构信息时。

## 输入
- PDB ID：蛋白质结构数据库标识符
- 下载源：rcsb.org、AbDb等
- 解析需求：残基坐标、链信息、界面残基

## 输出
- PDB结构文件（.pdb格式）
- 残基坐标数据
- 链组成信息
- 界面残基列表

## 流程节点
1. **PDB ID查询** → 确定需要下载的结构
2. **文件下载** → 从rcsb.org或AbDb下载PDB文件
3. **格式解析** → 解析PDB文件格式，提取ATOM记录
4. **坐标提取** → 提取残基坐标（CA原子或其他原子）
5. **链识别** → 识别重链、轻链、抗原链
6. **界面分析** → 识别抗体-抗原界面残基

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 下载API | rcsb.org REST API | [论文1] | 官方API接口 |
| 文件格式 | PDB | [论文1] | 蛋白质结构数据库格式 |
| 原子类型 | CA | [论文1] | α碳原子（主链） |
| 分辨率 | <2.5Å | [论文1] | 高质量结构标准 |
| 界面距离 | <8Å | [论文1] | 界面残基定义距离 |

## 边界与分流
- **PDB ID不存在**：检查ID是否正确，尝试备用数据库
- **文件下载失败**：尝试镜像站点或联系管理员
- **格式解析错误**：检查文件是否损坏，使用解析库
- **界面识别错误**：调整距离阈值或使用其他方法

## 质量检查
- 验证PDB文件格式正确性
- 检查残基坐标完整性
- 验证链识别准确性
- 检查界面残基数量合理性

## 回退策略
1. 使用其他PDB下载源（如AbDb）
2. 使用简化格式（如FASTA）
3. 手动提取关键信息
4. 使用模拟数据（不推荐）
