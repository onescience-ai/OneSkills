# 大卷积核RNA二级结构预测（B86）

## 适用范围

**适用场景**：
- RNA序列或目标结构、配对标签和固定约束明确，目标是折叠预测、反向设计或相互作用评估。
- 有独立结构/配对/功能参考，能够分别评估家族内、家族外和长序列表现。
- 目标长度、拓扑、碱基修饰和伪结处理在模型覆盖内，外推会被显式标记。
- 结果用于结构假设、候选设计和实验优先级排序，不替代体外/体内验证。

**不适用场景**：
- 序列方向、配对定义或非标准碱基未说明，导致结构结果无法复核。
- 只报告最优结构/序列而没有失败候选、约束检查和家族外测试。
- 目标依赖模型未表达的化学修饰、强环境或复杂共转录动力学。
- 需要直接宣称RNA疗效、毒性或机制而没有实验和独立结构证据。

## 研究对象与输入

**研究对象**：RNA序列、二级/三级结构、配对关系和设计约束

| 输入项 | 说明 |
|---|---|
| 输入文件 | ArchiveII.fasta |
| 输入模态 | FASTA、PDB/mmCIF、dot-bracket、约束 JSON 或配对表 |
| 样本单元 | 一条RNA、一个结构目标或一个RNA-蛋白配对 |
| 标签/条件 | 碱基配对、三维坐标、靶标关系、亲和力或编码/功能约束 |
| 模型引用 | kirigami.pt |

**初始结构**：默认输入名称为“ArchiveII.fasta”；执行者必须核验格式、版本、实体/样本完整性、缺失值和可解析性，并记录实际使用的相对名称或数据标识。

**表面/硬约束**：保持RNA字母表、长度、固定碱基、配对/伪结约定、链方向和修饰说明；不能把预测结构或设计序列直接当作实验功能。

**划分策略**：按RNA家族、长度、结构拓扑和同源序列拆分，记录伪结、非标准碱基和结构模板泄漏。

**采样要求**：默认生成或评估不少于 20 个候选/完整测试样本，并保存全量序列、结构、约束通过状态和失败原因。

## 核心科学问题

1. 在RNA序列、二级/三级结构、配对关系和设计约束和输入“ArchiveII.fasta”上，利用大卷积核捕获远距离碱基配对，预测RNA二级结构并评估家族外泛化能否得到可复核的F1结果，并满足任务的硬约束？
2. 输入中的长程配对、三维几何、序列-结构一致性和约束满足如何影响大卷积核RNA二级结构预测的输出，哪些样本、区域或候选最容易失败？
3. 模型在独立样本、未见家族/条件或困难子集上的表现是否稳定，误差和不确定度如何量化？
4. 结果是否具有足够的生物学、化学或临床证据支持后续决策，哪些部分只能作为探索性线索？
5. 在当前数据、模型和资源边界下，哪些结论可以签收，哪些结论必须标记为无法回答或需要额外验证？

## 比较与评估

- 主任务：利用大卷积核捕获远距离碱基配对，预测RNA二级结构并评估家族外泛化；核心指标：F1。
- 目录模型候选为Kirigami，需与可解释基线、参考标签或独立质量检查比较。
- 按长度、RNA家族、结构拓扑和伪结状态分层报告性能。
- 比较序列/结构基线与独立折叠或几何检查，审查高分但不满足硬约束的候选。

## 工作流

### 步骤 1：RNA输入与任务定义

**目的**：读取大卷积核RNA二级结构预测所需的RNA序列、结构或配对样本。

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| RNA输入 | `{RNA_INPUT}` | doc | 是 | `ArchiveII.fasta` | 输入RNA序列或结构 |
| RNA模型 | `{MODEL_NAME}` | enum | 是 | `Kirigami` | 可选值：`Kirigami` |
| RNA任务模式 | `{TASK_MODE}` | enum | 否 | `prediction` | 可选值：`prediction`、`inverse_design`、`affinity` |

**输出**：标准化RNA输入、碱基与链映射、任务配置

**质量门禁**：
- 碱基字符合法
- 配对索引无冲突
- 模型与任务模式兼容

**操作指令**：`读取{RNA_INPUT}并检查碱基、链和配对标记，使用{MODEL_NAME}建立{TASK_MODE}模式的大卷积核RNA二级结构预测任务。`

### 步骤 2：结构约束与模型准备

**目的**：加载权重并编码二级、三级和固定序列约束。

**依赖步骤**：s01

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 模型权重 | `{CHECKPOINT}` | doc | 是 | `kirigami.pt` | — | 模型权重名称 |
| RNA长度上限 | `{MAX_LENGTH}` | int | 否 | `512` | 10–10000 | 限制RNA输入长度 |
| 允许假结 | `{ALLOW_PSEUDOKNOT}` | bool | 否 | false | — | 是否保留假结配对 |

**输出**：RNA模型特征、结构约束、模型加载记录

**质量门禁**：
- 序列长度符合要求
- 结构约束可满足
- 固定碱基未丢失

**操作指令**：`加载{CHECKPOINT}，将序列限制在{MAX_LENGTH}以内，并按{ALLOW_PSEUDOKNOT}编码结构约束。`

### 步骤 3：结构预测或序列采样

**目的**：执行折叠、反向设计或复合物亲和力推理。

**依赖步骤**：s02

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 候选数量 | `{NUM_CANDIDATES}` | int | 是 | `100` | 1–10000 | 设置候选结构或序列数 |
| 采样温度 | `{TEMPERATURE}` | float | 否 | `0.8` | 0.01–3 | 控制RNA候选多样性 |
| 随机种子 | `{SEED}` | int | 否 | `31` | 0–2147483647 | 固定随机采样结果 |

**输出**：RNA候选、模型得分、推理日志

**质量门禁**：
- 候选数量达标
- 配对关系可解析
- 输出与输入链一致

**操作指令**：`运行大卷积核RNA二级结构预测，以温度{TEMPERATURE}和种子{SEED}生成或排序{NUM_CANDIDATES}个候选。`

### 步骤 4：RNA结构与功能质控

**目的**：计算F1并检查结构一致性、序列约束和候选多样性。

**依赖步骤**：s03

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 结果阈值 | `{SCORE_THRESHOLD}` | float | 否 | `0.6` | 0–1 | 设置合格结果阈值 |
| 输出格式 | `{OUTPUT_FORMAT}` | enum | 否 | `dot_bracket` | — | 可选值：`dot_bracket`、`PDB`、`CSV` |

**输出**：排序候选、F1汇总、RNA质控报告

**质量门禁**：
- 结构格式可解析
- 硬约束全部满足
- 低质量候选已标记

**操作指令**：`计算F1，用{SCORE_THRESHOLD}筛选候选，并按{OUTPUT_FORMAT}导出结构、序列和质控结果。`

## 验收标准与质量门禁

### 硬约束（不可违反）

- 保持RNA字母表、长度、固定碱基、配对/伪结约定、链方向和修饰说明；不能把预测结构或设计序列直接当作实验功能。
- 输入、标签、模型版本、数据划分和实际输出之间的血缘必须可追溯；任何偏离都要记录并经场景确认。
- 不得把平均分数、单个高分样本或模型自评当作生物学、化学或临床事实；正式结论必须有独立证据。
- 历史论文、参考模型和示例文件只能用于方案设计或交叉检查，不能冒充本次任务的新结果。

### 最低证据要求

- 实际研究对象、输入、模型/权重、工具和场景约束与任务书一致，所有偏离均有变更记录。
- 输入、标签/参考数据、版本、筛选规则和训练/评估划分可追溯，泄漏和缺失处理有证据。
- 模型或推理结果有独立于选择过程的F1评估、分层统计、最差案例和适用域说明。
- 全量结果、失败样本、异常、拒答或低质量标记均被保存；正式分析只使用质量合格的范围。
- 每个目标结果都有定义、单位/量纲（如适用）、样本量、分析窗口、置信区间或不确定度。
- 比较基线、参考标签或人工复核的口径一致，不能只报告对模型有利的子集。
- 结论明确区分观察、模型误差、标签/采样不确定度、偏差和未验证假设。
- 输出文件、环境、日志、版本和校验信息足以让第三方复核关键数值。

**验收判定**：执行者必须对每个交付项给出 PASS、PARTIAL、REJECT 或 BLOCKED，并附文件、日志、图表或数值证据；没有证据的‘运行正常’或‘效果良好’不能作为签收依据。

## 必要结果项

- **结构结果**：规范化RNA序列、结构约束、链方向、伪结/修饰处理和输入质量报告；同时说明输入清洗、版本和任何变更。
- **参考标签结果**：实验结构、配对标签、功能/亲和力标签和RNA家族划分的来源与覆盖；标注缺失、噪声、类别不平衡和不可用于正式验收的部分。
- **模型结果**：模型/权重、结构编码和独立家族外测试、误差分层与适用域说明；明确模型适用的实体、序列/结构/模态范围和不能外推的边界。
- **动力学结果**：预测结构、反向设计序列、配对/亲和力结果、候选分数和日志；保留全量候选或逐样本输出、失败原因、随机种子/条件和版本记录。
- **性质结果**：RMSD/F1/恢复率/约束满足率、几何合法性、多样性和不确定度；每个指标给出定义、单位或量纲、样本范围、分析窗口和置信区间。
- **结论结果**：一份将观察结果、独立证据、模型误差、采样/标签不确定度、偏差和无法回答的问题分开的科学结论报告。
