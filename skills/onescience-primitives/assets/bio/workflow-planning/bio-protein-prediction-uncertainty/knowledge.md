# 蛋白语言模型预测不确定度量化方法

## 适用范围
适用于蛋白语言模型（如ESM-1v）预测结果的不确定度量化，包括：
- 蛋白变异效应预测的不确定性估计
- 计算生物学研究结果的可靠性评估
- 生物信息学流程的质量控制
- 科学决策支持系统

不适用场景：
- 蛋白结构预测的不确定度（使用其他方法如AlphaFold的pLDDT）
- 实验数据误差估计
- 蛋白-蛋白相互作用预测的不确定度

## 输入
- 蛋白序列：输入的蛋白序列
- 预测模型：ESM-1v或其他蛋白语言模型
- 预测分数：模型输出的变异效应分数

## 输出
- 预测分数的标准差（score_std）
- 置信区间（ci_lower, ci_upper）
- 不确定度报告
- 可视化图表（可选）

## 流程节点
1. **Bootstrap采样** → 多次重采样计算预测分布
2. **随机种子推理** → 不同随机种子下的预测方差
3. **模型集成** → 多个模型的预测一致性
4. **置信区间计算** → 基于预测分布计算置信区间
5. **不确定度报告** → 生成结构化不确定度信息

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| Bootstrap迭代次数 | 1000次 | [最佳实践] | 足够的统计功效 |
| 置信水平 | 95% | [统计学标准] | 常用置信水平 |
| 随机种子数量 | 5-10个 | [计算开销平衡] | 方差估计精度 |
| 集成模型数量 | 3-5个 | [资源限制] | 模型多样性 |
| 样本大小 | 原始序列的80% | [Bootstrap标准] | 重采样比例 |

## 边界与分流
- **计算资源不足**：减少Bootstrap迭代次数或随机种子数量
- **时间限制**：使用简化置信区间估计方法
- **模型不可用**：使用单模型的不确定度估计
- **序列过长**：分段处理并合并不确定度估计
- **结果不稳定**：增加迭代次数或检查数据质量

## 质量检查
1. **迭代收敛性**：检查Bootstrap迭代是否收敛
2. **置信区间合理性**：确保置信区间在合理范围内
3. **不确定度一致性**：检查不同方法得到的不确定度是否一致
4. **计算时间**：监控计算时间是否在可接受范围内
5. **结果可重复性**：验证不同随机种子下的结果稳定性

## 回退策略
1. **Bootstrap不收敛**：增加迭代次数或使用更简单的采样方法
2. **计算时间过长**：使用并行计算或减少迭代次数
3. **模型集成不可用**：使用单模型的方差估计
4. **置信区间过宽**：检查数据质量或使用更精确的估计方法
5. **结果不稳定**：增加样本量或使用更稳健的统计方法
