# 分层性能评估方法与报告

## 适用范围
适用于DNA语言模型生物任务基准评测中需要进行分层性能评估的场景。按多个维度分别报告性能指标，识别模型优势和劣势领域。

## 输入
- 评测结果数据：模型预测值、真实标签
- 分层维度：染色体/基因、物种、细胞类型、变异类别
- 评估指标：AUC-ROC、Accuracy、Pearson Correlation等

## 输出
- 分层性能报告：各维度下的性能指标
- 模型适用域分析：优势领域和劣势领域
- 校准分析：预测概率校准情况

## 流程节点
1. 数据分层 → 2. 指标计算 → 3. 报告生成 → 4. 适用域分析 → 5. 校准评估

### 步骤1：数据分层
- **操作**：按指定维度对评测数据进行分层
- **参数**：分层维度、分层粒度、样本量要求
- **工具**：Python分层脚本
- **质量门禁**：分层正确，样本量充足

### 步骤2：指标计算
- **操作**：计算各分层下的性能指标
- **参数**：AUC-ROC、Accuracy、Pearson Correlation、F1-score
- **工具**：sklearn、scipy统计库
- **质量门禁**：指标计算正确，置信区间合理

### 步骤3：报告生成
- **操作**：生成标准化的分层性能报告
- **参数**：报告格式、可视化要求、统计显著性
- **工具**：报告生成脚本、可视化库
- **质量门禁**：报告完整，格式规范

### 步骤4：适用域分析
- **操作**：分析模型在不同子集上的表现差异
- **参数**：性能差异、优势领域、劣势领域
- **工具**：分析脚本
- **质量门禁**：分析合理，结论可解释

### 步骤5：校准评估
- **操作**：评估预测概率的校准情况
- **参数**：校准曲线、Brier分数、可靠性图
- **工具**：校准评估脚本
- **质量门禁**：校准评估准确，结论可靠

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 分层维度 | 染色体/基因、物种、细胞类型、变异类别 | 归因报告 | 多维度分层 |
| 评估指标 | AUC-ROC、Accuracy、Pearson Correlation | 归因报告 | 标准评估指标 |
| 报告格式 | 表格+可视化 | 标准要求 | 直观展示结果 |
| 校准方法 | 可靠性图、Brier分数 | 标准方法 | 概率校准评估 |

## 边界与分流
- **异常处理**：样本量不足时使用交叉验证，指标异常时检查数据质量
- **降级策略**：分层失败时使用整体指标，校准失败时跳过校准分析
- **分支条件**：不同任务类型可能需要不同的评估指标

## 质量检查
- **验证点**：分层正确性、指标准确性、报告完整性、分析合理性
- **阈值**：置信区间宽度<0.1，校准误差<0.05
- **失败处理**：重新计算指标或调整分层策略

## 回退策略
- 分层样本量不足时合并相似维度
- 指标计算异常时检查数据预处理
- 报告生成失败时使用简化格式
