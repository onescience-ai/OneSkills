# 蛋白结构自洽性评估

## 适用范围
适用于蛋白结构生成后的质量评估，特别是需要验证结构有效性、几何合理性和约束满足度的场景。包括：
- 生成的蛋白结构需要验证物理化学合理性
- 需要评估结构自洽性（回折叠验证）
- 需要检查几何约束（键长、键角、二面角）
- 不适用于仅验证序列格式或文件完整性的场景

## 输入
- **PDB/CIF文件**：包含全原子坐标的结构文件
- **序列信息**：生成的氨基酸序列
- **约束条件**：固定残基位点、对称性要求等

## 输出
- **几何检查报告**：键长RMSD、键角分布、范德华冲突检测
- **Ramachandran图统计**：phi/psi角分布、允许区域占比
- **结构有效性评分**：综合几何、能量和约束满足度的分数
- **回折叠证据**（如可用）：预测序列与生成序列的一致性

## 流程节点
1. **坐标解析** → 读取PDB/CIF文件提取原子坐标
2. **几何计算** → 计算键长、键角、二面角
3. **Ramachandran分析** → 计算phi/psi角并评估分布
4. **能量评估** → 计算范德华能量、静电能量
5. **约束验证** → 检查固定残基、对称性等约束满足度
6. **报告生成** → 汇总检查结果并生成质量报告

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| CA-CA距离 | ~3.8Å | [蛋白质结构化学] | 标准α-螺旋中相邻残基CA距离 |
| Ramachandran允许区域 | >90% | [结构生物学标准] | 蛋白结构质量的基本要求 |
| 键长RMSD | <0.1Å | [分子动力学标准] | 结构几何合理性的阈值 |
| 范德华冲突 | 最小距离>1.2Å | [分子力学标准] | 避免原子间过度重叠 |

## 边界与分流
- **MDTraj不可用时**：实现简化几何检查（CA-CA距离分布、原子间最小距离）
- **AlphaFold/RoseTTAFold不可用时**：跳过回折叠验证，记录为"证据有限"
- **结构严重不合理时**：标记为无效候选，不进入后续筛选
- **约束冲突时**：记录冲突详情，报告约束满足度

## 质量检查
- 每个候选结构应输出几何检查结果
- Ramachandran图中允许区域占比应>90%
- 键长RMSD应<0.1Å
- 无严重范德华冲突（最小距离>1.2Å）

## 回退策略
- 专业工具不可用时，使用简化几何检查作为代理指标
- 回折叠验证不可用时，在报告中明确标注"证据有限"
- 几何检查失败时，标记候选为无效，但记录失败原因
