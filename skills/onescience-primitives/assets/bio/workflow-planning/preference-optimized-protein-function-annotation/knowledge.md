# 偏好优化驱动的蛋白功能注释（B32）

## 适用范围

**适用场景**：
- 任务有明确的蛋白序列或结构输入及可追溯的功能、稳定性、适应度或动力学标签。
- 训练与测试可按家族、突变或实验批次独立划分，能够检验真实迁移而非记忆。
- 目标是注释、优先级排序、效应预测或假设生成，且输出会标注模型不确定性。
- 标签单位、方向和缺失机制可解释，允许进行分层指标和误差审查。

**不适用场景**：
- 标签定义、单位或正负方向不一致，或者只有无出处的文本描述而无法建立监督目标。
- 测试集与训练集存在未审计的同源/同突变泄漏，无法支持泛化结论。
- 需要从预测相关性直接推断因果机制、临床风险或实际催化参数。
- 目标蛋白/底物化学空间远超训练数据而没有外推验证或人工审查。

## 研究对象与输入

**研究对象**：蛋白序列、突变、结构域、酶底物或功能标签数据

| 输入项 | 说明 |
|---|---|
| 输入文件 | SwissProt_GO.csv |
| 输入模态 | FASTA、突变/功能表、结构文件或序列-底物配对表 |
| 样本单元 | 一个蛋白、一个突变或一个酶-底物样本 |
| 标签/条件 | 功能类别、适应度、稳定性、动力学常数或实验效应标签 |
| 模型引用 | annodpo.ckpt |

**初始结构**：默认输入名称为“SwissProt_GO.csv”；执行者必须核验格式、版本、实体/样本完整性、缺失值和可解析性，并记录实际使用的相对名称或数据标识。

**表面/硬约束**：固定标签本体、单位、突变表示、野生型参照和序列版本；不能把相关性预测解释成因果机制或未经测量的实验事实。

**划分策略**：按蛋白家族、序列同源性、实验批次和突变位点拆分，去除近重复并记录训练-测试血缘。

**采样要求**：默认覆盖完整独立测试集，并对每个样本输出预测、置信度、校准状态和可解释特征；不因缺失标签而伪造结果。

## 核心科学问题

1. 在蛋白序列、突变、结构域、酶底物或功能标签数据和输入“SwissProt_GO.csv”上，利用优选与拒绝注释对训练蛋白功能模型，减少无依据标签并提升多标签注释质量能否得到可复核的宏平均F1结果，并满足任务的硬约束？
2. 输入中的标签定义、变异效应/功能预测、跨家族泛化和可解释性如何影响偏好优化驱动的蛋白功能注释的输出，哪些样本、区域或候选最容易失败？
3. 模型在独立样本、未见家族/条件或困难子集上的表现是否稳定，误差和不确定度如何量化？
4. 结果是否具有足够的生物学、化学或临床证据支持后续决策，哪些部分只能作为探索性线索？
5. 在当前数据、模型和资源边界下，哪些结论可以签收，哪些结论必须标记为无法回答或需要额外验证？

## 比较与评估

- 主任务：利用优选与拒绝注释对训练蛋白功能模型，减少无依据标签并提升多标签注释质量；核心指标：宏平均F1。
- 目录模型候选为AnnoDPO，需与可解释基线、参考标签或独立质量检查比较。
- 报告总体和按蛋白家族、效应方向、标签来源分层的性能。
- 与简单序列/频率基线或已有实验排序比较，并审查最差和反常样本。

## 工作流

### 步骤 1：蛋白样本与目标定义

**目的**：读取偏好优化驱动的蛋白功能注释的序列、结构或变异样本及目标标签。

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 蛋白任务数据 | `{PROTEIN_DATA}` | doc | 是 | `SwissProt_GO.csv` | 输入序列结构或标签表 |
| 功能模型 | `{MODEL_NAME}` | enum | 是 | `AnnoDPO` | 可选值：`AnnoDPO` |
| 预测目标 | `{TARGET_TYPE}` | enum | 否 | `continuous` | 可选值：`continuous`、`binary`、`multilabel`、`retrieval` |

**输出**：标准化样本、标签字典、数据检查报告

**质量门禁**：
- 序列字符合法
- 变异位点有效
- 标签类型与目标一致

**操作指令**：`解析{PROTEIN_DATA}并检查序列、变异和标签，使用{MODEL_NAME}建立{TARGET_TYPE}目标的偏好优化驱动的蛋白功能注释任务。`

### 步骤 2：表征与参考数据准备

**目的**：加载权重并构建序列、结构或底物联合表征。

**依赖步骤**：s01

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 模型权重 | `{CHECKPOINT}` | doc | 是 | `annodpo.ckpt` | — | 模型权重名称 |
| 参考数据 | `{REFERENCE_DATA}` | doc | 否 | `UniProtKB_2025_01` | — | 参考数据集名称 |
| 序列长度上限 | `{MAX_SEQUENCE_LENGTH}` | int | 否 | `1024` | 32–10000 | 限制模型输入长度 |

**输出**：蛋白表征、参考标签映射、预处理日志

**质量门禁**：
- 权重加载成功
- 序列分块可回溯
- 参考标签无重复冲突

**操作指令**：`加载{CHECKPOINT}和{REFERENCE_DATA}，将序列裁剪或分块至{MAX_SEQUENCE_LENGTH}并生成联合表征。`

### 步骤 3：功能或效应推理

**目的**：批量输出功能类别、连续效应或检索分数。

**依赖步骤**：s02

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 批次大小 | `{BATCH_SIZE}` | int | 是 | `32` | 1–1024 | 设置单批处理样本数 |
| 判定阈值 | `{DECISION_THRESHOLD}` | float | 否 | `0.5` | 0–1 | 设置阳性判定阈值 |
| 随机种子 | `{SEED}` | int | 否 | `11` | 0–2147483647 | 固定评测随机过程 |

**输出**：样本级预测、模型分数、推理日志

**质量门禁**：
- 每个样本都有结果
- 分数为有限值
- 失败样本已记录

**操作指令**：`以批次{BATCH_SIZE}和种子{SEED}运行偏好优化驱动的蛋白功能注释，用{DECISION_THRESHOLD}产生标签或效应结果。`

### 步骤 4：评测与解释汇总

**目的**：计算宏平均F1并输出残基、结构域或样本层解释。

**依赖步骤**：s03

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 指标下限 | `{MIN_METRIC}` | float | 否 | `0.6` | 0–1 | 设置合格指标下限 |
| 导出解释 | `{EXPORT_EXPLANATION}` | bool | 否 | true | — | 是否输出模型解释 |

**输出**：评测汇总、宏平均F1明细、解释与误差报告

**质量门禁**：
- 数据切分无泄漏
- 指标定义明确
- 解释可定位到原始样本

**操作指令**：`计算宏平均F1并与{MIN_METRIC}比较，按{EXPORT_EXPLANATION}导出特征贡献和错误分析。`

## 验收标准与质量门禁

### 硬约束（不可违反）

- 固定标签本体、单位、突变表示、野生型参照和序列版本；不能把相关性预测解释成因果机制或未经测量的实验事实。
- 输入、标签、模型版本、数据划分和实际输出之间的血缘必须可追溯；任何偏离都要记录并经场景确认。
- 不得把平均分数、单个高分样本或模型自评当作生物学、化学或临床事实；正式结论必须有独立证据。
- 历史论文、参考模型和示例文件只能用于方案设计或交叉检查，不能冒充本次任务的新结果。

### 最低证据要求

- 实际研究对象、输入、模型/权重、工具和场景约束与任务书一致，所有偏离均有变更记录。
- 输入、标签/参考数据、版本、筛选规则和训练/评估划分可追溯，泄漏和缺失处理有证据。
- 模型或推理结果有独立于选择过程的宏平均F1评估、分层统计、最差案例和适用域说明。
- 全量结果、失败样本、异常、拒答或低质量标记均被保存；正式分析只使用质量合格的范围。
- 每个目标结果都有定义、单位/量纲（如适用）、样本量、分析窗口、置信区间或不确定度。
- 比较基线、参考标签或人工复核的口径一致，不能只报告对模型有利的子集。
- 结论明确区分观察、模型误差、标签/采样不确定度、偏差和未验证假设。
- 输出文件、环境、日志、版本和校验信息足以让第三方复核关键数值。

**验收判定**：执行者必须对每个交付项给出 PASS、PARTIAL、REJECT 或 BLOCKED，并附文件、日志、图表或数值证据；没有证据的‘运行正常’或‘效果良好’不能作为签收依据。

## 必要结果项

- **结构结果**：规范化序列、突变/底物表示、标签本体、去重和数据质量报告；同时说明输入清洗、版本和任何变更。
- **参考标签结果**：实验标签、测量单位、批次、结构或进化信息的出处及可用范围；标注缺失、噪声、类别不平衡和不可用于正式验收的部分。
- **模型结果**：模型/权重和微调记录、独立测试指标、校准/不确定度和跨家族误差分析；明确模型适用的实体、序列/结构/模态范围和不能外推的边界。
- **动力学结果**：逐样本功能/效应预测、排序、置信度和残基/结构域级解释；保留全量候选或逐样本输出、失败原因、随机种子/条件和版本记录。
- **性质结果**：核心指标、分层性能、类别平衡、误差分布和可复核的解释结果；每个指标给出定义、单位或量纲、样本范围、分析窗口和置信区间。
- **结论结果**：一份将观察结果、独立证据、模型误差、采样/标签不确定度、偏差和无法回答的问题分开的科学结论报告。
