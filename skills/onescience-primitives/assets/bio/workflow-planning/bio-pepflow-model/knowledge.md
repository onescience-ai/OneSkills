# PepFlow模型：基于多模态条件流匹配的全原子肽类设计

## 适用范围
- **触发条件**：需要进行靶标特异性全原子肽类设计时使用
- **适用场景**：
  - 蛋白质-肽结合物设计
  - 靶向特定蛋白质受体的肽设计
  - 固定骨架序列设计
  - 侧链包装任务
- **不适用场景**：
  - 蛋白质骨架设计（应使用RFdiffusion）
  - 大规模蛋白质设计（应使用其他工具）
  - 非靶向肽设计

## 输入
- **设计输入**：蛋白质受体的PDB结构文件（默认：target_interface.pdb）
- **设计模型**：PepFlow模型（默认：pepflow.ckpt）
- **目标长度**：肽序列长度（默认：256）
- **可选参数**：
  - 固定残基位点（默认：[10,25]）
  - 对称群（默认：C1）
  - 设计数量（默认：64）
  - 采样温度（默认：0.2）
  - 随机种子（默认：17）

## 输出
- **设计产物**：全原子肽结构和序列
- **格式**：PDB格式
- **验证标准**：
  - 界面置信度 > 0.6
  - 结构自洽性检查
  - 约束满足度验证

## 流程节点
1. **s01：解析设计输入** → 读取蛋白质受体结构，提取设计约束
2. **s02：加载权重并编码条件** → 加载PepFlow模型权重，编码固定残基和对称性
3. **s03：生成设计候选** → 使用条件流匹配生成肽序列和结构
4. **s04：筛选和验证** → 按界面置信度、结构自洽性和约束满足度筛选候选

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 模型架构 | 多模态条件流匹配 | [1] | 基于SE(3)流形、环面和单纯形的联合建模 |
| 输入模态 | 蛋白质受体结构 | [1] | 需要PDB格式的受体结构 |
| 输出模态 | 全原子肽结构和序列 | [1] | 包含骨架坐标、侧链角度和残基类型 |
| 采样步数 | N步欧拉方法 | [1] | 默认100步，控制生成质量 |
| 损失函数 | 多模态CFM损失 | [1] | 包含位置、方向、角度和类型损失 |

## 边界与分流
- **异常处理**：当蛋白质受体结构不可用时，提示用户提供或使用默认输入
- **降级策略**：当PepFlow模型权重不可用时，可使用其他肽设计模型（如RFdiffusion+ProteinMPNN）
- **分支条件**：根据任务类型选择不同的采样模式（全原子设计、固定骨架设计、侧链包装）

## 质量检查
- **验证点**：界面置信度、结构自洽性、约束满足度
- **阈值**：界面置信度 > 0.6
- **失败处理**：重新采样或调整参数

## 回退策略
- **失败时的替代方案**：使用其他肽设计模型或手动设计
- **降级路径**：从全原子设计降级到仅骨架设计

## 技术细节
### 模型架构
PepFlow采用编码器-解码器架构：
- **编码器**：几何等变编码器，捕获目标蛋白质的上下文信息
- **解码器**：基于不变点注意力（IPA）的时变解码器，预测向量场

### 多模态流匹配
- **欧几里得CFM**：用于位置向量（ℝ³）
- **球面CFM**：用于方向（SO(3)流形）
- **环面CFM**：用于扭转角（5维环面）
- **单纯形CFM**：用于残基类型（概率单纯形）

### 采样过程
1. 编码目标蛋白质一次
2. 从先验分布采样肽状态
3. 迭代N步，每步：
   - 解码预测肽状态
   - 计算向量场
   - 使用欧拉方法更新状态
4. 重构全原子肽结构

## 使用示例
```python
# PepFlow使用示例
from pepflow import PepFlowModel

# 加载模型
model = PepFlowModel.load("pepflow.ckpt")

# 读取蛋白质受体结构
receptor = load_pdb("target_interface.pdb")

# 生成肽设计
peptides = model.generate(
    receptor=receptor,
    num_designs=64,
    target_length=256,
    temperature=0.2,
    seed=17
)

# 筛选高置信度设计
filtered_peptides = [p for p in peptides if p.confidence > 0.6]
```
