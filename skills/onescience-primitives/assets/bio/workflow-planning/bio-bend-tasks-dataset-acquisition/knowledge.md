# BEND_tasks数据集获取与验证

## 适用范围
适用于DNA语言模型生物任务基准评测中需要获取BEND_tasks数据集的场景。包括调控、剪接和染色质三个任务的测试集获取、格式验证和版本管理。

## 输入
- 数据集获取需求：调控、剪接、染色质三个任务的测试集
- 参考基因组版本：hg38
- 数据格式要求：FASTA、BED/VCF、轨迹表或序列-标签数据

## 输出
- 验证后的BEND_tasks数据集文件
- 数据集元信息：版本、格式、样本数量、缺失值报告
- 数据血缘记录：获取路径、版本、处理过程

## 流程节点
1. 数据集获取 → 2. 格式验证 → 3. 版本确认 → 4. 完整性检查 → 5. 数据血缘记录

### 步骤1：数据集获取
- **操作**：从官方源下载BEND_tasks数据集
- **参数**：参考基因组版本hg38，包含三个任务的测试集
- **工具**：wget/curl下载，GitHub克隆
- **质量门禁**：文件下载完整，无损坏

### 步骤2：格式验证
- **操作**：检查文件格式是否符合规范
- **参数**：FASTA、BED/VCF、轨迹表格式
- **工具**：awk、grep、自定义验证脚本
- **质量门禁**：格式解析成功，无格式错误

### 步骤3：版本确认
- **操作**：确认数据集版本信息
- **参数**：版本号、发布日期、更新日志
- **工具**：文件头检查、README核对
- **质量门禁**：版本信息明确，与预期一致

### 步骤4：完整性检查
- **操作**：检查样本数量、缺失值、实体完整性
- **参数**：至少包含调控、剪接、染色质三个任务的测试集
- **工具**：wc、awk、Python脚本
- **质量门禁**：样本数量充足（数千个区间），缺失值<5%

### 步骤5：数据血缘记录
- **操作**：记录数据获取全过程
- **参数**：获取路径、版本、处理过程、时间戳
- **工具**：execution-manifest.json
- **质量门禁**：血缘链完整，可追溯

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 参考基因组 | hg38 | 归因报告 | 标准人类参考基因组版本 |
| 任务类型 | 调控、剪接、染色质 | 归因报告 | BEND_tasks包含的三个主要任务 |
| 数据格式 | FASTA、BED/VCF、轨迹表 | 归因报告 | 官方数据格式规范 |
| 样本规模 | 数千个基因组区间 | 归因报告 | 完整测试集规模 |

## 边界与分流
- **异常处理**：下载失败时尝试备用源（Zenodo、其他镜像）
- **降级策略**：格式验证失败时尝试格式转换
- **分支条件**：不同任务类型可能需要不同的验证规则

## 质量检查
- **验证点**：文件完整性、格式正确性、版本一致性、样本完整性
- **阈值**：缺失值<5%，格式解析成功率100%
- **失败处理**：重新下载或尝试备用源

## 回退策略
- 官方源不可用时使用镜像源
- 格式验证失败时参考官方文档调整验证规则
- 版本信息不明确时联系数据维护者
