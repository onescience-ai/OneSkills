## 执行流程

规划活动按 [usage.md](usage.md) 请求资源结果，将 `content` 中的 [spec.md](spec.md) 方法交给 coder；coder 实现固定配置，runtime 真实执行并保留终态/日志，data-analyzer 独立分析。本卡不调度作业、不提供已安装资源或新执行器。

### 步骤 1：核验对象、真实受测全集和任务协议

- 输入：原任务、真实 FASTA/结构、实验肽表、供体/队列/测定记录、允许的资源范围与预算。
- 动作：区分 APL 抗原分支与有独立依据的抗体/TCR 分支；建立 protein/chain/peptide_id/坐标/序列实体键，记录原表行及正/负/未知定义与重复响应合并规则。按 spec 的实验实例限制核验 S1/S3 适用性，不从阳性表推阴性。冻结方法版本、参数、归一化总体、MHC 等位基因、聚合/对照、Top-K/并列、重采样和验收协议；仅在允许范围核对本地资源身份/hash/许可/可读性。
- 输出：实体和真值表、完整受测全集、来源/排除记录、固定配置及资源状态。
- 验证：原行与 FASTA 坐标/序列逐条相符；未知仍为未知；同序列异实体不丢失；未读范围与无命中分开记录。缺失资源不等同方法错误，参数不依赖评价标签。

### 步骤 2：计算并复核四特征与残基 APL

- 输入：已核验实体、熵/柔性量/COREX/SASA 完整数组、结构字段来源和固定 API 配置。
- 动作：由 coder 按 spec 固定版本实现方向转换、两轮 15 点平滑、ddof=0 标准化、L2 权重组合、10 点 Hanning 滤波、稳定/不稳定域与侧翼加权/插值，交 runtime 实际执行。pLDDT 仅在语义确认后转为 `100-pLDDT` 一次；晶体 B-factor 直接使用。明确上层/下层 API 默认，保存原值和每步中间量。
- 输出：逐残基 APL、聚合分数、域分段、中间数组、版本/参数与转换标记。
- 验证：链/插入码/长度/顺序对齐，恰有一次置信度转换且符号正确；与固定版本独立数值对照。检查常量/缺失/非有限、短数组、空稳定或不稳定域及零范数；不能以源码整列 NaN 置零掩盖无效输入。未实际执行不得称为计算结果。

### 步骤 3：投影真实肽并核验精确 MHC 输入

- 输入：真实肽坐标表、残基 APL、声明的肽总体和指定 MHC 缓存或实际可用离线工具/参数。
- 动作：逐肽取恰好覆盖真实序列的残基均值，在同一声明总体 minmax；若用 mers 接口，核对首肽原点、step 累加和顺序，不用示例滑窗替换实验库。以实体键消费精确 MHC 方法/版本/等位基因结果，保留原 rank 和尺度，按任务选择如 `-rank` 统一高值更强；记录缺失、映射及原始行来源。
- 输出：逐实体肽 APL、归一化范围、逐等位基因原始与方向统一的 MHC 分数、逐行状态。
- 验证：均值覆盖数等于真实肽长，缺段/歧义显式排除；同序列不同实体保留；方法/版本/等位基因逐项相符，缺失与 rank=0 区分。拒绝模糊等位基因、fillna(0) 或在线 requests 包装器冒充离线计算；常量总体不能造有效 minmax。

### 步骤 4：逐等位基因组合并按协议聚合

- 输入：对齐的肽 APL 与各等位基因高值更强的 MHC 分数、固定权重/阈值/聚合/对照及总体。
- 动作：按 spec 先分别 ddof=0 zscore，再 L2 权重组合、第一次 minmax、按各自 minmax 后的 APL/MHC 阈值过滤、第二次 minmax；保存每阶段值与范围。显式传入上层或下层权重，逐等位基因计算后按预声明方案聚合，并构建同口径 APL-only 和 MHC-only 对照。
- 输出：逐等位基因与聚合分数、对照表、参数/过滤和退化记录。
- 验证：实体顺序和所有指定等位基因覆盖正确，列 dtype 不代替等位基因身份；权重及顺序与版本一致；空/常量/过滤后全同留原因。跨等位基因聚合来自任务而非臆定官方默认，不用标签选最佳组合。

### 步骤 5：分析共同集并交付证据

- 输入：真实真值、全量预测/对照与异常表、固定正式评价和重采样协议、runtime 日志。
- 动作：data-analyzer 在真实标签及所有比较所需分数有效的共同集计算非插值 `AP=ΣΔRecall·Precision`，同分阈值成组，报告受测全集/有效数/阳性数/阳性率、覆盖和排除；Top-K 单列。依重叠肽依赖结构作配对块重采样，保留重复抽块及有效/无效计数，按有真值的分层和预声明敏感性分析报告不确定度。封存输入、配置、环境、文件校验、全量结果和失败证据。
- 输出：AP/PR、配对比较与不确定度、最差案例/适用边界、复现包及逐项证据状态。
- 验证：正式协议要求双类时，空集/全阳性/全阴性返回正式 AP=null 且 PR 不作正式结果；混合/同分与独立实现对照，不用梯形面积替代 AP。报告实际分母，单类抽样不隐瞒，未有供体/HLA 真值不造分层；区分静态/工程与真实科学完成，不预设必须优于对照或继承邻域性能门槛。

## 决策分支

- 若对象为抗原加工/呈递排序，走上述 APL 分支；若为独立抗体结合/设计，按已核验 CAME-AB 或其他实际模型及任务协议处理 CDR/界面/可开发性，保留原卡相关质量门禁。
- 若关键输入或精确离线资源未就绪，列出缺口、影响、最小补充信息和最后健康产物；若就绪，进入真实计算，不让预检脚本对所有状态无条件失败。部分可用结果保留逐项状态，不冒充完整科学结果。
- 若数值退化、实体映射或测定真值不成立，停止受影响分数/正式评价并留原因；若需改变方法，先形成明确变更及独立验证，不能静默换版本、换总体或调参。

## 不可跳过的约束

- 使用通过正式资源结果传入的方法知识；不改宿主调度器，不凭文档中的来源地址假定资源已安装，不绕过允许的访问范围。
- 保持输入→残基→真实肽→逐等位基因→共同集/排除的血缘；保存全部异常、失败和最后健康产物，恢复时不无条件覆盖非空健康结果。
- 保持版本、任务配置、随机条件和评价标签隔离；块宽/次数/种子、Top-K 及阈值不固定为某次评测答案。
- 依据原任务和独立证据逐项给 PASS/PARTIAL/REJECT/BLOCKED；预测不作临床或保护证明，minmax 不作概率，单抗原再分析不作家族外泛化。
