# 合成路线约束的GFlowNet分子生成（B58）

## 适用范围

**适用场景**：
- 有明确的靶点/参考配体或性质目标，且约束、单位和优先级可以被审计。
- 候选会经过独立化学合法性、结构/性质验证和可合成性或人工审查。
- 训练/测试按化学系列或时间独立，能够区分记忆参考配体和真正的新颖性。
- 结果用于先导发现和实验优先级排序，而不是直接宣称药效、毒性或临床可用性。

**不适用场景**：
- 约束只写成模糊的‘高活性’或‘低毒’，没有可测指标、单位和验收口径。
- 没有化学合法性和重复审计，或者把生成分数当作实验活性。
- 目标化学空间包含模型不支持的元素、反应或强环境效应，且不允许外推验证。
- 任务要求直接作出临床安全性、药代或疗效决定而没有实验/临床证据。

## 研究对象与输入

**研究对象**：靶点口袋、参考配体、分子约束和候选小分子库

| 输入项 | 说明 |
|---|---|
| 输入文件 | reaction_templates.json（需求示例；固定实现实际读取化学 XLSX / 砌块 CSV） |
| 输入模态 | SDF/SMILES、口袋结构、活性/性质表或多任务约束文件 |
| 样本单元 | 一个设计任务及其生成分子集合 |
| 标签/条件 | 活性、选择性、ADMET、药物相似性、合成或多任务目标 |
| 模型引用 | rgfn.pt（待核验标识；从头训练时检查点为产物，恢复/推理时核验真实兼容权重） |

**初始结构**：默认输入名称为“reaction_templates.json”；执行者必须核验格式、版本、实体/样本完整性、缺失值和可解析性，并记录实际使用的相对名称或数据标识。

本实例按 RGFN `6ce59169f855ed18f34ba4e8279de93bee306e4f` 对齐：ReactionDataFactory 使用 XLSX 的反应/砌块页，独立砌块文件使用 CSV 的 `SMILES` 列；JSON 转换须核对字段与化学实体。完整专业契约维护在 [TC 场景正文](../../scenario/bio-synthesis-route-constrained-gflownet-molecule-generation-scenario/knowledge.md)，包括真实表/列、化学库统计层级与索引、隐式试剂、硼代理身份和回映射。检索本 legacy 实例时，仍按已有 `edge:scenario` / `edge:workflow` 完成 TC 链展开并标 `legacy_instance: true`，不能以本卡替代 Scenario→Workflow→全部 Task。

**表面/硬约束**：保持元素/键级/立体化学合法，明确活性、脱靶、ADMET、相似性和合成约束；生成分子不能被表述为已验证药物。

**划分策略**：按靶点、骨架、时间和化学系列去重划分评估，避免参考配体或近邻分子泄漏到测试结论。

**采样要求**：不少于 100 个唯一候选是待任务确认的预算示例；实际运行先明确采样数、停止条件、随机种子和去重口径，保留无效、重复和约束失败分子及其原因。

## 核心科学问题

1. 在靶点口袋、参考配体、分子约束和候选小分子库和输入“reaction_templates.json”上，在反应模板和可购砌块约束下生成高奖励分子，适用于可执行的先导发现能否得到可复核的可合成率结果，并满足任务的硬约束？
2. 输入中的化学有效性、目标性质、结构新颖性、可合成性和多目标权衡如何影响合成路线约束的GFlowNet分子生成的输出，哪些样本、区域或候选最容易失败？
3. 模型在独立样本、未见家族/条件或困难子集上的表现是否稳定，误差和不确定度如何量化？
4. 结果是否具有足够的生物学、化学或临床证据支持后续决策，哪些部分只能作为探索性线索？
5. 在当前数据、模型和资源边界下，哪些结论可以签收，哪些结论必须标记为无法回答或需要额外验证？

## 比较与评估

- 主任务：在反应模板和可购砌块约束下生成高奖励分子，适用于可执行的先导发现；核心指标：可合成率。
- 目录模型候选为RGFN，需与可解释基线、参考标签或独立质量检查比较。
- 报告有效/唯一/可合成候选率，并按目标性质和化学系列分层。
- 将生成候选与参考配体、简单基线和独立验证打分分别比较。
- 按 TC 场景的评价契约，冻结生成模型后独立随机新采样并冻结全队列，再以独立规划策略/模板、可比库存和相同预算评价；保留获解、未解、超时和程序错误及全队列分母，报告 MW/QED 分层和库存偏差。构建轨迹或对接高分不能替代实验可合成性/活性证据。

## 工作流

### 步骤 1：分子设计目标定义

**目的**：解析合成路线约束的GFlowNet分子生成的靶点、种子分子和生成任务。

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 分子设计输入 | `{MOLECULE_INPUT}` | doc | 是 | `reaction_templates.json`（示例） | 绑定实际化学库；对接分支另需准备好的受体与口袋 |
| 分子模型 | `{MODEL_NAME}` | enum | 是 | `RGFN` | 可选值：`RGFN` |
| 生成模式 | `{GENERATION_MODE}` | enum | 否 | `de_novo` | 需求模式示例：`de_novo`、`lead_optimization`、`fragment_growth`，须核验所选实现支持，不直接视为官方枚举 |

**输出**：标准化分子输入、靶点条件、生成任务配置

**质量门禁**：
- 分子化学价合法
- 靶点条件可解析
- 生成模式与输入兼容
- 保存化学实体/同位素/立体化学与原串→实际索引；隐式原子来源和反应条件缺项分开记录，详见 TC 场景 s01

**操作指令**：`读取{MOLECULE_INPUT}并检查化学结构，使用{MODEL_NAME}建立{GENERATION_MODE}模式的合成路线约束的GFlowNet分子生成任务。`

### 步骤 2：模型与性质条件准备

**目的**：定义反应/砌块状态空间和优化目标，选择从头训练或兼容恢复；对接分支另绑定受体与奖励。

**依赖步骤**：s01

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 模型权重 | `{CHECKPOINT}` | doc | 条件必填 | `rgfn.pt`（示例） | 从头训练不需要预存；恢复/已有模型推理时核验真实兼容检查点 |
| 优化目标 | `{OBJECTIVES}` | list[str] | 否 | ["QED", "SA", "affinity"]（示例） | 定义可用奖励、方向和限制；代理指标不等于实验性质 |
| 保留核心骨架 | `{KEEP_SCAFFOLD}` | bool | 否 | false | 需求约束，须核验实现支持及固定骨架原子映射 |

**输出**：训练或恢复记录、反应/砌块与模型配置、奖励定义和骨架约束；对接分支另存受体/口袋准备记录

**质量门禁**：
- 从头训练配置可追溯；恢复分支的权重、化学库索引与模型配置兼容
- 性质定义完整
- 固定骨架原子映射有效

**操作指令**：`按TC场景s02定义{OBJECTIVES}及合法反应动作/终止条件；从头训练或在索引兼容后从{CHECKPOINT}恢复，按实现支持核验{KEEP_SCAFFOLD}。保存奖励变换、配置及实际恢复状态。`

### 步骤 3：离散反应生成与外部构象准备

**目的**：先生成离散分子与反应构建轨迹，再按任务需要外部生成构象/准备对接，记录两阶段血缘与随机性。

**依赖步骤**：s02

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 生成分子数 | `{NUM_MOLECULES}` | int | 是 | `1000`（预算示例） | 1–100000（待确认） | 设置实际采样数量及停止口径 |
| 采样温度 | `{TEMPERATURE}` | float | 否 | `1`（共享槽示例） | 0.01–5（待核验） | 仅实现支持时绑定；不得与奖励 beta 默认等同 |
| 随机种子 | `{SEED}` | int | 否 | `42`（示例） | 0–2147483647 | 保存实际种子/RNG与配置，不单凭种子承诺完整复现 |

**输出**：候选分子图/SMILES、反应构建轨迹与奖励/失败状态；外部构象分支另输出 SDF/PDBQT、能量及身份映射

**质量门禁**：
- 生成数量达标
- 外部构象产物的原子坐标为有限值；离散生成本身不以坐标为输出前提
- 每个分子可被化学解析
- 构建轨迹可重放，原分子、代理分子及对接产物可回溯；有限失败分数不能计为成功

**操作指令**：`按实际采样配置和{SEED}生成{NUM_MOLECULES}个离散分子与反应轨迹，保留全部状态；仅在实现支持时应用{TEMPERATURE}。需要对接时再按TC场景s03完成外部构象/质子化/PDBQT准备，并关联成功与失败产物。`

### 步骤 4：性质过滤与候选排序

**目的**：按可合成率、药物相似性和合成可行性汇总候选。

**依赖步骤**：s03

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 性质阈值 | `{PROPERTY_LIMITS}` | object | 否 | {"qed_min": 0.6, "sa_max": 6}（示例） | — | 预先确认硬约束/软目标，不冒充客户验收阈值 |
| 保留分子数 | `{TOP_K}` | int | 否 | `100`（示例） | 1–10000（待确认） | 设置最终保留数量；不改变独立评价全队列分母 |

**输出**：排序分子集、可合成率明细、性质与多样性报告

**质量门禁**：
- 入选分子通过化学检查
- 重复结构已合并
- 筛选规则可复现

**操作指令**：`按TC场景s04独立评价冻结全队列，保存实际路线叶子stock核验、全部搜索状态和分母；另用{PROPERTY_LIMITS}过滤、去重聚类并保留前{TOP_K}个候选，不以排序子集替代全队列统计。`

## 验收标准与质量门禁

### 硬约束（不可违反）

- 保持元素/键级/立体化学合法，明确活性、脱靶、ADMET、相似性和合成约束；生成分子不能被表述为已验证药物。
- 输入、标签、模型版本、数据划分和实际输出之间的血缘必须可追溯；任何偏离都要记录并经场景确认。
- 不得把平均分数、单个高分样本或模型自评当作生物学、化学或临床事实；正式结论必须有独立证据。
- 历史论文、参考模型和示例文件只能用于方案设计或交叉检查，不能冒充本次任务的新结果。

### 最低证据要求

- 实际研究对象、输入、模型/权重、工具和场景约束与任务书一致，所有偏离均有变更记录。
- 输入、标签/参考数据、版本、筛选规则和训练/评估划分可追溯，泄漏和缺失处理有证据。
- 模型或推理结果有独立于选择过程的可合成率评估、分层统计、最差案例和适用域说明。
- 全量结果、失败样本、异常、拒答或低质量标记均被保存；正式分析只使用质量合格的范围。
- 每个目标结果都有定义、单位/量纲（如适用）、样本量、分析窗口、置信区间或不确定度。
- 比较基线、参考标签或人工复核的口径一致，不能只报告对模型有利的子集。
- 结论明确区分观察、模型误差、标签/采样不确定度、偏差和未验证假设。
- 输出文件、环境、日志、版本和校验信息足以让第三方复核关键数值。

**验收判定**：执行者必须对每个交付项给出 PASS、PARTIAL、REJECT 或 BLOCKED，并附文件、日志、图表或数值证据；没有证据的‘运行正常’或‘效果良好’不能作为签收依据。

## 交付物清单

### 最小交付物

1. 任务理解、执行方案、变更记录和输入/许可核验。
2. 标准化口袋/参考配体和候选分子的化学合法性、立体化学与去重报告及数据血缘、质量和缺失说明。
3. 模型/权重版本、条件设置、独立性质/对接验证、校准和外推风险及独立测试、适用域和失败案例报告。
4. 全量生成分子、生成分数、约束通过状态、随机性和失败原因、全量异常/失败记录和运行日志。
5. 有效率、唯一率、目标性质、选择性、相似性和合成代理指标及不确定度、可视化/表格、统计不确定度和分层结果。
6. 完整复现包：输入标识、脚本、环境、版本、任务记录、结果清单和文件校验信息。

### 报告规范

- 报告先给结论，再给证据、方法选择理由、限制、偏差和未完成项。
- 所有结果标注可合成率定义、单位或量纲、样本/候选范围、模型版本和数据来源。
- 任何历史资料、参考模型、外部数据库或人工复核都要显式标注身份、用途和可能影响。

### 失败交付要求

如果任务未完成，仍须交付最后一个可复用的健康产物、失败位置、根因证据、影响范围、已排除原因和下一步建议；失败结果不得包装成正式科学结论。

## 边界与限制

**本工作流关注**：
- 本任务关注在反应模板和可购砌块约束下生成高奖励分子，适用于可执行的先导发现、化学有效性、目标性质、结构新颖性、可合成性和多目标权衡以及可合成率的可复核评估。
- 因果机制、实验功能、临床疗效/安全性或其他超出输入和验证证据的结论不属于默认交付，除非补充方案获得确认。

**不属于默认交付**：
- 场景不要求照抄论文或历史案例的具体命令、软件参数、脚本、目录结构或资源配置。
- 场景不要求在缺少可靠标签、结构、元数据或独立验证时补造训练目标、样本或性能。
- 场景不接受只给模型文件、平均指标或少量成功样本而没有失败记录、数据血缘和适用性说明的交付。

## 执行前确认事项

- 输入格式、版本、样本/实体完整性和活性、选择性、ADMET、药物相似性、合成或多任务目标是否足以支撑任务。
- 模型与权重的许可证、版本、训练覆盖和适用域，及是否需要可解释基线或外部工具。
- 核对从头训练/恢复分支及化学索引兼容性；外部对接与独立逆合成资源按实际节点另证就绪，缓存可读不等于资源可用。
- 训练/验证/测试划分是否存在同源、患者、样本、位点、化学系列或其他信息泄漏。
- 指标可合成率的定义、方向、单位、分层统计和最低可接受证据。
- 资源、时间和人工/实验复核是否足以完成目标；若冲突，先提交取舍方案。

**信息缺失策略**：如果关键输入、标签、科学口径、许可或资源信息缺失，执行者必须列出缺口、影响和最小补充信息；在确认前不得用默认值静默替代，也不得提交会被误解为正式结论的高成本运行。

## 必要结果项

- **结构结果**：标准化口袋/参考配体和候选分子的化学合法性、立体化学与去重报告；同时说明输入清洗、版本和任何变更。
- **参考标签结果**：活性、性质、合成模板和筛选约束的来源、单位、测量条件与覆盖范围；标注缺失、噪声、类别不平衡和不可用于正式验收的部分。
- **模型结果**：模型/权重版本、条件设置、独立性质/对接验证、校准和外推风险；明确模型适用的实体、序列/结构/模态范围和不能外推的边界。
- **动力学结果**：全量生成分子、生成分数、约束通过状态、随机性和失败原因；保留全量候选或逐样本输出、失败原因、随机种子/条件和版本记录。
- **性质结果**：有效率、唯一率、目标性质、选择性、相似性和合成代理指标及不确定度；每个指标给出定义、单位或量纲、样本范围、分析窗口和置信区间。
- **结论结果**：一份将观察结果、独立证据、模型误差、采样/标签不确定度、偏差和无法回答的问题分开的科学结论报告。
