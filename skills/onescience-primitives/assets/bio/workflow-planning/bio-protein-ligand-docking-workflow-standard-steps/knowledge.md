# 蛋白质-配体对接工作流标准步骤

## 适用范围
本卡片适用于结构基药物发现中的蛋白质-配体对接任务，描述标准工作流步骤序列及依赖关系。适用于已知结合口袋位置的对接场景，包括自对接（self-docking）和交叉对接（cross-docking）。

## 输入
- **蛋白质结构**：PDB格式文件，包含受体蛋白的三维结构
- **配体结构**：SMILES字符串、SDF文件或PDB格式文件
- **结合口袋定义**：口袋中心坐标和尺寸，或参考配体位置
- **对接参数**：搜索算法、采样数量、评分函数选择等

## 输出
- **对接姿态**：配体在蛋白质结合口袋中的三维构象
- **评分结果**：结合亲和力预测分数（如Vina score、对接分数）
- **相互作用分析**：蛋白质-配体相互作用指纹
- **验证报告**：几何合理性检查（如PoseBusters验证）

## 流程节点
1. **受体准备** → 2. **配体准备** → 3. **口袋定义** → 4. **对接执行** → 5. **姿态排序** → 6. **后处理与验证**

### 详细步骤：
1. **受体准备**：蛋白质结构清洁、质子化、能量最小化
   - 操作：去除水分子、添加氢原子、修复缺失残基
   - 参数：pH值、力场选择
   - 工具：PDBFixer、Open Babel
   - 质量门禁：结构完整性检查

2. **配体准备**：配体结构优化和构象生成
   - 操作：生成三维构象、能量优化、质子化状态确定
   - 参数：力场、电荷计算方法
   - 工具：RDKit、Open Babel
   - 质量门禁：化学合理性检查

3. **口袋定义**：确定结合位点和搜索空间
   - 操作：定义对接盒子中心、尺寸和网格间距
   - 参数：盒子大小、网格间距
   - 工具：AutoDock Vina、Glide
   - 质量门禁：口袋覆盖度检查

4. **对接执行**：运行对接算法生成初始姿态
   - 操作：执行构象搜索和评分
   - 参数：搜索算法、采样数量、 exhaustiveness
   - 工具：AutoDock Vina、Gnina、DiffDock
   - 质量门禁：收敛性检查

5. **姿态排序**：根据评分函数对生成姿态排序
   - 操作：应用评分函数、聚类分析
   - 参数：评分函数类型、聚类阈值
   - 工具：内置评分函数、重新评分工具
   - 质量门禁：排名稳定性检查

6. **后处理与验证**：姿态几何修正和物理化学验证
   - 操作：能量最小化、立体冲突消除、相互作用分析
   - 参数：最小化步骤、力场
   - 工具：PoseBusters、OpenMM
   - 质量门禁：RMSD ≤ 2 Å、PoseBusters验证

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| RMSD阈值 | ≤ 2 Å | [1] | 几何有效性判据，低于此值视为成功对接 |
| PoseBusters验证 | 18项检查全通过 | [1] | 物理化学合理性验证 |
| 搜索算法 | 基因算法/蒙特卡洛 | [1] | 构象空间搜索策略 |
| 采样数量 | 10-1000个姿态 | [1] | 采样充分性与计算成本的权衡 |
| 评分函数 | 经验/知识/机器学习 | [1] | 结合亲和力预测方法 |

## 边界与分流
- **已知口袋位置**：标准对接流程，直接执行s01-s04
- **未知口袋位置**：需先执行口袋预测步骤（如FPocket、DeepSite）
- **交叉对接场景**：受体结构与配体共晶结构不同，需额外考虑受体柔性
- **大规模虚拟筛选**：需优化计算流程，可能使用代理模型加速

## 质量检查
1. **几何检查**：RMSD ≤ 2 Å（与参考结构比较）
2. **物理化学检查**：通过PoseBusters所有18项验证
3. **相互作用检查**：关键相互作用残基匹配
4. **收敛性检查**：多次运行结果一致性

## 回退策略
- **对接失败**：尝试不同对接算法或参数设置
- **评分异常**：使用多种评分函数重新评估
- **几何冲突**：应用后处理最小化修正
- **计算超时**：减少采样数量或使用更快的算法
