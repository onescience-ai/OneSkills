# La-Proteina模型架构与条件编码

## 适用范围
适用于全原子蛋白结构与序列联合生成任务，特别是需要基于Flow Matching进行蛋白质设计的场景。包括：
- 需要生成全原子蛋白结构（包含所有重原子N, CA, C, O, CB等）
- 需要同时生成序列和结构
- 需要处理固定残基、对称性等约束条件
- 不适用于仅生成Cα坐标或仅生成序列的任务

## 输入
- **条件特征**：包括目标长度、固定残基位点、对称群类型、基序/口袋条件
- **固定残基位点**：列表形式，如[10,25]，必须在目标长度范围内
- **对称群**：C1（无对称）、C2（二重对称）、Cn（n重对称）等点群
- **允许氨基酸集合**：可选参数，指定允许出现的氨基酸类型

## 输出
- **全原子坐标**：shape为[N, num_atoms, 3]，包含所有重原子的3D坐标
- **序列**：长度为N的氨基酸序列字符串
- **设计结果**：包含坐标、序列、置信度分数的JSON结构

## 流程节点
1. **条件解析** → 解析固定残基、对称性、基序等约束
2. **特征编码** → 将约束编码为模型条件向量
3. **潜空间生成** → 使用Flow Matching在部分潜空间生成
4. **解码** → 将潜变量解码为全原子坐标和序列
5. **验证** → 检查结构有效性和约束满足度

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 模型架构 | 部分潜空间流匹配 | [La-Proteina论文] | 粗骨架显式建模，序列和原子细节通过潜变量捕获 |
| 潜变量维度 | 固定维度 | [La-Proteina论文] | 避免显式侧链表示的挑战 |
| 最大长度 | 800残基 | [La-Proteina论文] | 模型可生成的有效蛋白质长度范围 |
| 输出格式 | 全原子PDB | [La-Proteina论文] | 包含所有重原子坐标 |

## 边界与分流
- **固定残基验证**：生成后必须验证固定位点残基类型未改变
- **对称性约束**：C2对称要求坐标满足特定对称性（如旋转180度后重合）
- **长度限制**：超过800残基可能导致生成质量下降
- **权重验证**：必须验证checkpoint文件完整性和key匹配

## 质量检查
- 模型权重文件大小应在数百MB到GB级别（0.23MB明显异常）
- state_dict key必须匹配，无Missing/Unexpected key警告
- 生成的结构应满足基本键长约束（CA-CA距离约3.8Å）

## 回退策略
- 权重验证失败时，停止执行并报告，不得使用随机初始化
- 长度超过限制时，建议分段生成或使用其他模型
- 对称性约束无法满足时，记录约束冲突并报告
