# ANARCI抗体编号工具使用工作流

## 适用范围

**触发条件**：
- 需要对抗体序列进行标准编号以识别CDR区域
- 需要获取CDR H1/H2/H3掩码用于抗体亲和力预测
- 需要提取抗原界面特征作为模型输入

**适用场景**：
- 抗体-抗原结合亲和力预测任务的预处理步骤
- CDR区域序列编码与特征工程
- 抗体结构注释与分析

**不适用场景**：
- 非抗体序列的编号
- 无需CDR区域识别的简单序列分析

## 输入

**输入数据格式**：
- 重链和轻链的氨基酸序列（FASTA格式或字符串）
- 序列标识符（可选）

**来源**：
- 用户提供的抗体序列文件
- 数据库下载的抗体序列

**预处理要求**：
- 序列应为标准单字母氨基酸代码
- 去除信号肽和恒定区（可选）

## 输出

**输出产物**：
1. 标准编号序列：按选定方案编号的抗体序列
2. CDR掩码：H1/H2/H3区域的起止位置（掩码向量）
3. 链类型信息：重链/轻链标识
4. 编号方案标识：IMGT/Kabat/Chothia/Schofield

**格式**：
- 编号序列：带编号的字符串或DataFrame
- CDR掩码：二进制向量或区间列表
- 链类型：字符串或整数编码

**验证标准**：
- 编号连续且长度不超限
- CDR区域位置合理（如H3长度通常为8-20个残基）
- 链类型正确标识

## 流程节点

### Step 1：环境准备
- **操作**：安装ANARCI工具
- **参数**：`pip install anarci` 或从GitHub安装
- **工具**：pip, git
- **质量门禁**：ANARCI版本兼容，可正常导入

### Step 2：序列输入
- **操作**：读取抗体序列文件
- **参数**：文件路径或序列字符串
- **工具**：Python文件读取
- **质量门禁**：序列格式正确，无非法字符

### Step 3：ANARCI编号
- **操作**：调用ANARCI进行编号
- **参数**：编号方案（默认IMGT）、输入格式（FASTA/序列）、输出格式（numbered sequences）
- **工具**：ANARCI Python API
- **质量门禁**：编号成功，无错误输出

### Step 4：CDR区域提取
- **操作**：从编号结果中提取CDR H1/H2/H3区域
- **参数**：CDR定义（根据编号方案）、掩码类型（二进制/区间）
- **工具**：Python解析ANARCI输出
- **质量门禁**：CDR区域连续且长度合理

### Step 5：抗原界面特征提取
- **操作**：根据编号和结构信息提取界面残基
- **参数**：界面定义（距离阈值）、残基类型
- **工具**：Python脚本
- **质量门禁**：界面残基数量合理

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 编号方案 | IMGT, Kabat, Chothia, Schofield | [1] | ANARCI支持的方案 |
| 输入格式 | FASTA, 序列字符串 | [1] | ANARCI接受的输入 |
| 输出格式 | numbered sequences, CDR masks | [1] | ANARCI输出 |
| CDR区域定义 | H1: 26-32, H2: 56-58, H3: 95-102 (IMGT) | [1] | 根据方案不同而变化 |
| 链类型 | 重链 (H), 轻链 (L/K) | [1] | 抗体链分类 |

## 边界与分流

**异常处理**：
- 如果ANARCI安装失败，尝试从GitHub源码安装
- 如果编号方案不支持，降级到默认IMGT方案
- 如果序列格式错误，返回错误信息并提示修正

**降级策略**：
- 当ANARCI不可用时，使用简单规则估算CDR区域（如基于位置的启发式方法）
- 当编号失败时，使用原始序列长度和氨基酸频率作为替代特征

## 质量检查

**验证点**：
- ANARCI输出包含CDR区域定义
- CDR编号连续且长度不超限
- 链类型正确识别
- 界面残基数量在合理范围内（通常20-50个残基）

**阈值**：
- CDR H3长度：8-20个残基
- 界面残基距离阈值：8-10 Å

**失败处理**：
- 如果CDR区域提取失败，记录警告并继续
- 如果界面特征提取失败，使用零向量替代

## 回退策略

**失败时的替代方案**：
1. 使用在线ANARCI服务（如Observed Antibody Space）
2. 使用预定义的CDR位置规则（基于文献）
3. 使用简单的序列长度和氨基酸频率特征
