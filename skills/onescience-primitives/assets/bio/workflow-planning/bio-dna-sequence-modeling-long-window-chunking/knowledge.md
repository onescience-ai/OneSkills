# DNA序列建模任务长窗口分块处理策略

## 适用范围

面向DNA序列建模任务，处理长窗口（>100kb）的分块策略与内存管理；覆盖滑动窗口分块、坐标对齐、正反链映射和方向恢复逻辑；适用于需要百万碱基对级别长程建模的DNA语言模型。

## 输入

- 原始基因组序列文件（FASTA格式）
- 目标窗口长度（如131072bp）
- 分块大小（如8192bp）
- 模型最大输入长度

## 输出

- 分块后的序列数据
- 坐标映射信息
- 正反链映射表
- 数据验证报告

## 流程节点

1. **长窗口分块** → 2. **坐标对齐** → 3. **正反链映射** → 4. **方向恢复** → 5. **数据验证**

### 步骤1：长窗口分块
- 操作：将长序列按模型最大输入长度分块
- 参数：目标窗口长度、分块大小、重叠大小
- 工具：自定义分块脚本
- 质量门禁：分块后序列长度符合要求，无数据丢失

### 步骤2：坐标对齐
- 操作：确保分块后中心坐标不偏移
- 参数：中心坐标、分块边界、填充策略
- 工具：坐标计算脚本
- 质量门禁：中心坐标在分块后保持不变

### 步骤3：正反链映射
- 操作：构建正向链索引→反向互补链索引的可逆映射表
- 参数：序列长度、碱基互补规则（A↔T, C↔G）
- 工具：映射表生成脚本
- 质量门禁：映射表可逆，满足RC(x)[i]=complement(x[N-1-i])

### 步骤4：方向恢复
- 操作：确保分块后可逆恢复原始序列方向
- 参数：分块索引、方向标记、恢复规则
- 工具：方向恢复脚本
- 质量门禁：恢复后序列与原始序列一致

### 步骤5：数据验证
- 操作：验证分块和映射的正确性
- 参数：验证规则、测试用例
- 工具：验证脚本
- 质量门禁：所有验证用例通过

## 边界与分流

- **内存不足时**：减小分块大小或使用流式处理
- **坐标偏移时**：重新计算中心坐标并调整分块边界
- **映射错误时**：重新生成映射表并验证可逆性
- **方向恢复失败时**：检查分块逻辑和恢复规则

## 质量检查

- 验证分块后序列长度符合要求
- 检查中心坐标在分块后保持不变
- 验证正反链映射可逆
- 测试方向恢复功能正常

## 回退策略

- 内存不足时：使用流式处理或减小分块大小
- 坐标偏移时：重新计算中心坐标
- 映射错误时：重新生成映射表
