# BEND基准数据集：DNA语言模型生物任务评测数据

## 适用范围

**触发条件**：
- 需要评测DNA语言模型在生物任务上的表现
- 需要获取标准化的基因组调控、剪接和染色质任务测试集
- 需要对DNA语言模型进行公平比较

**适用场景**：
- DNA语言模型（如DNABERT-2、Caduceus、Nucleotide Transformer等）的基准评测
- 基因表达预测、剪接位点识别、染色质可及性预测等任务的性能评估
- 多模型对比分析和排名
- 模型在调控元件识别、变异效应预测等任务上的泛化能力评估

**不适用场景**：
- 非人类物种的基因组评测（BEND基于人类基因组hg38）
- 蛋白质语言模型评测
- 需要自定义任务定义的研究场景

## 输入

- **数据来源**：BEND官方GitHub仓库（https://github.com/frederikkemarin/BEND）
- **参考基因组版本**：hg38（GRCh38）
- **数据格式**：基因组区间（BED格式）、序列（FASTA格式）、标签文件
- **预处理要求**：
  - 下载完整的BEND_tasks数据集
  - 验证文件完整性和格式正确性
  - 检查参考基因组版本一致性

## 输出

- **标准化基因组区间**：经过坐标规范化的基因组区间数据
- **质量检查报告**：包含数据完整性、格式正确性、样本数量等验证结果
- **数据血缘记录**：输入数据来源、版本、处理过程的完整记录

## 流程节点

### Step 1：获取BEND数据集
- **操作**：从官方GitHub仓库克隆或下载BEND基准数据集
- **参数**：仓库地址=https://github.com/frederikkemarin/BEND，参考基因组=hg38
- **工具**：git clone或wget
- **质量门禁**：仓库克隆成功，文件完整

### Step 2：数据格式验证
- **操作**：检查数据文件格式是否符合BEND规范
- **参数**：文件格式=BED/FASTA/CSV，编码=UTF-8
- **工具**：awk, python scripts
- **质量门禁**：格式错误率=0%

### Step 3：样本数量检查
- **操作**：统计每个任务类别的样本数量
- **参数**：任务类别=调控、剪接、染色质，最小样本数=1000（每个任务）
- **工具**：wc, python pandas
- **质量门禁**：每个任务类别样本数≥1000

### Step 4：数据划分验证
- **操作**：检查训练集、验证集、测试集的划分是否正确
- **参数**：划分策略=BEND标准划分，测试集占比=约20%
- **工具**：python scripts
- **质量门禁**：划分比例符合BEND规范，无数据泄露

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 参考基因组 | hg38 (GRCh38) | [1] | BEND基准基于人类参考基因组hg38 |
| 任务类型 | 调控、剪接、染色质 | [1] | BEND覆盖三类主要生物任务 |
| 数据格式 | BED, FASTA, CSV | [1] | 基因组区间用BED，序列用FASTA |
| 最小样本量 | 数千个基因组区间 | [1] | 完整BEND数据集包含数千个区间 |
| 数据划分 | 训练/验证/测试集 | [1] | BEND提供标准划分策略 |
| 预洗牌要求 | 必须预洗牌 | [2] | 硬件相关的数据加载伪影需通过预洗牌消除 |

### 校准数值（来自BEND体系，供量级校准）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 任务数量 | 约30+任务 | [1] | BEND包含多个下游评测任务 |
| 基因组区间长度 | 可变（1kb-100kb） | [1] | 不同任务的区间长度不同 |
| 数据加载worker数 | 0（预洗牌后） | [2] | 预洗牌后不需要多worker加载 |

## 边界与分流

- **数据获取失败**：若官方仓库不可访问，检查网络连接或使用镜像仓库
- **格式验证失败**：检查下载文件是否完整，重新下载损坏的文件
- **样本量不足**：确认下载了完整数据集而非子集
- **版本不匹配**：确保使用最新版本的BEND数据集（与hg38对齐）

## 质量检查

- **检查点1**：数据集文件存在且大小合理（完整数据集约数百MB）
- **检查点2**：每个任务类别包含足够的样本（≥1000个区间）
- **检查点3**：基因组坐标在hg38范围内（chr1-chr22, chrX, chrY）
- **检查点4**：无重复区间（去重后样本数=原始样本数）
- **失败处理**：任何检查失败则停止并报告具体错误

## 回退策略

- **方案A**：使用BEND提供的数据预处理脚本自动修复格式问题
- **方案B**：手动检查并修复异常区间坐标
- **方案C**：联系BEND维护团队获取支持
