# 蛋白变异效应预测质量评估标准

## 适用范围
适用于评估蛋白语言模型（如ESM-1v）对变异效应预测结果的质量，包括：
- 深度突变扫描（DMS）数据分析
- 蛋白变异效应预测模型验证
- 计算生物学研究结果评估
- 生物信息学流程质量控制

不适用场景：
- 蛋白结构预测评估（使用其他指标如TM-score）
- 蛋白-蛋白相互作用预测评估
- 蛋白功能注释评估

## 输入
- 预测分数：蛋白语言模型输出的变异效应分数
- 实验分数：深度突变扫描实验的功能分数
- 样本量：突变位点数量（通常>100）

## 输出
- Spearman相关性系数（rho）
- 统计显著性（p值）
- 质量等级评估
- 置信区间（可选）

## 流程节点
1. **数据准备** → 对齐预测分数和实验分数
2. **相关性计算** → 计算Spearman秩相关
3. **显著性检验** → 计算p值并评估统计显著性
4. **质量分级** → 根据rho和p值确定质量等级
5. **结果解释** → 提供生物学意义解释

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 显著性阈值 | p < 0.05 | [统计学标准] | 统计显著性要求 |
| 中等相关性 | rho > 0.3 | [效应量标准] | 中等以上相关强度 |
| ESM-1v预期范围 | rho 0.4-0.6 | [文献报道] | TEM-1 DMS上的典型表现 |
| 最小样本量 | >100突变 | [统计学要求] | 确保统计功效 |
| Bootstrap迭代 | 1000次 | [最佳实践] | 置信区间估计 |

## 边界与分流
- **样本量不足**：若突变数<100，标记统计功效不足
- **相关性过低**：若rho<0.3，建议检查数据质量或模型选择
- **p值不显著**：若p>0.05，标记结果无统计学意义
- **异常值影响**：建议检查并处理异常突变位点
- **多重比较**：若进行多次预测，需校正p值

## 质量检查
1. **数据对齐验证**：确认预测分数和实验分数正确对齐
2. **样本量检查**：确保突变数足够（>100）
3. **分布检查**：评估分数分布是否合理
4. **异常值检测**：识别可能影响相关性的异常值
5. **结果可重复性**：建议进行bootstrap验证

## 回退策略
1. **样本量不足**：使用较小样本的统计方法（如Kendall tau）
2. **相关性过低**：考虑使用其他预测模型或方法
3. **p值不显著**：增加样本量或使用更敏感的统计方法
4. **数据质量问题**：重新检查数据预处理步骤
5. **计算资源不足**：使用简化置信区间估计方法
