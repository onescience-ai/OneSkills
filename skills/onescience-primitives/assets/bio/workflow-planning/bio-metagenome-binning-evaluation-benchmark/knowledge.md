# 宏基因组分箱评估与基准数据集

## 适用范围
- **触发条件**：需要评估宏基因组分箱工具的性能，或验证分箱结果的质量。
- **适用场景**：开发新的分箱算法；比较不同分箱工具；评估分箱结果在真实数据集上的表现。
- **不适用场景**：当缺乏参考基因组或真实标签时；当仅需快速评估而非严格基准测试时。

## 输入
- **分箱结果**：bins文件（contig ID到bin ID的映射）。
- **参考数据**：
  - **模拟数据集**：带有真实物种标签的contigs（如CAMI挑战数据集）。
  - **真实数据集**：无真实标签，但可使用CheckM等工具评估质量。
- **预处理要求**：
  - 确保分箱结果格式正确（每行一个contig ID和bin ID）。
  - 对于模拟数据，确保参考标签与contig ID匹配。

## 输出
- **评估指标**：
  - **分箱F1分数**：基于真实标签计算的精确率和召回率的调和平均。
  - **完整性（Completeness）**：bins捕获的原始基因组比例。
  - **污染度（Contamination）**：bins中非目标基因组的比例。
  - **调整兰德指数（ARI）**：聚类结果与真实标签的一致性。
- **报告**：包含指标汇总、每个bin的详细评估、跨物种泛化分析。
- **可视化**：t-SNE嵌入图、混淆矩阵、指标分布图。

## 流程节点
1. **数据准备** → 2. **指标计算** → 3. **跨物种泛化评估** → 4. **报告生成** → 5. **质量门禁**

### 步骤1：数据准备
- **操作**：加载分箱结果和参考标签。
- **参数**：参考标签格式（TSV或CSV）。
- **工具**：pandas、自定义脚本。
- **质量门禁**：确保所有contig在分箱结果和参考标签中都有对应条目。

### 步骤2：指标计算
- **操作**：计算分箱F1、完整性、污染度、ARI。
- **分箱F1计算原理**：
  - **精确率（Precision）**：bin中正确分配的contigs比例。
  - **召回率（Recall）**：真实基因组中被正确捕获的contigs比例。
  - **F1分数**：精确率和召回率的调和平均。
- **参数**：完整性阈值（>90%），污染度阈值（<5%）。
- **工具**：AMBER（模拟数据）、CheckM/CheckM2（真实数据）。
- **质量门禁**：指标计算无错误，结果合理。

### 步骤3：跨物种泛化评估
- **操作**：按物种划分测试集，评估分箱工具在不同物种上的性能。
- **参数**：物种划分方法（基于GTDB分类或ANI聚类）。
- **工具**：GTDB-Tk、FastANI。
- **质量门禁**：确保每个物种有足够的contigs用于评估。

### 步骤4：报告生成
- **操作**：汇总指标，生成可视化图表。
- **参数**：报告格式（HTML、PDF、文本）。
- **工具**：matplotlib、seaborn、自定义脚本。
- **质量门禁**：报告清晰、完整，包含所有关键指标。

### 步骤5：质量门禁
- **操作**：验证评估结果的可靠性。
- **参数**：一致性检查（多次运行结果稳定）。
- **工具**：自定义脚本。
- **质量门禁**：评估结果可重复，无异常值。

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 高质量bins阈值 | 完整性>90%，污染度<5% | [CAMI II] | 行业标准 |
| 分箱F1计算基础 | 真实物种标签或组装基因组 | [Evaluation] | 需要参考标准 |
| 跨物种泛化方法 | 按物种划分测试集 | [Evaluation] | 评估泛化能力 |
| 未知类别处理 | 单独报告或标记为“未知” | [CAMI II] | 避免强制归类 |
| 评估工具 | AMBER（模拟），CheckM2（真实） | [Evaluation] | 不同数据类型使用不同工具 |

## 边界与分流
- **异常处理**：
  - 如果参考标签缺失，使用无监督评估指标（如contig聚类纯度）。
  - 如果分箱结果包含过小的bins（<200 kbp），过滤后再评估。
- **降级策略**：
  - 当无法获取真实标签时，使用CheckM等工具进行质量估计。
  - 当数据量小时，使用交叉验证或bootstrap方法。
- **分支条件**：
  - 模拟数据集使用AMBER计算分箱F1。
  - 真实数据集使用CheckM2评估完整性/污染度。

## 质量检查
- **验证点**：
  1. 分箱F1计算是否基于真实标签（而非模拟标签）。
  2. 跨物种泛化评估是否覆盖足够多的物种。
  3. 未知类别是否单独处理。
- **阈值**：
  - 分箱F1 > 0.7 表示良好性能。
  - 跨物种泛化性能下降 < 20%。
- **失败处理**：
  - 如果评估指标异常，检查参考标签格式和contig ID匹配。

## 回退策略
- **替代方案**：
  - 使用无监督评估指标（如contig聚类纯度）。
  - 使用半监督评估（如部分标签）。
  - 使用基准数据集（如CAMI II）进行标准化评估。
- **降级路径**：
  - 当缺乏真实标签时，使用CheckM等工具进行质量估计。
  - 当数据量小时，使用简化评估流程。
