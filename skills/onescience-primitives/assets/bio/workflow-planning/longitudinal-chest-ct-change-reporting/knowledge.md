# 纵向胸部CT变化检测与报告生成（B100）

## 适用范围

**适用场景**：
- 影像和文本输入已去标识化且患者、检查和时间点可准确配对，目标是辅助问答、报告草拟或变化提取。
- 有独立患者级参考报告/标签和专业人员复核，能够评估遗漏、幻觉、偏差和拒答。
- 影像模态、设备、体位和病种在验证范围内，外推病例会单独标记。
- 结果只作为临床工作流辅助，最终解释和决策由合格临床人员负责。

**不适用场景**：
- 患者身份、时间点或影像方向无法确认，或数据未完成去标识化。
- 没有患者级独立测试和专业复核，却需要宣称临床准确或安全。
- 任务要求自动诊断、急救分诊、处方或治疗决定，超出辅助报告范围。
- 图像质量、设备或病种远超模型覆盖，且不能安排人工复核和拒答机制。

## 研究对象与输入

**研究对象**：医学影像、文本报告、患者/时间点元数据和临床问题

| 输入项 | 说明 |
|---|---|
| 输入文件 | paired_chest_ct.json |
| 输入模态 | DICOM、PNG/JPEG、结构化病例 JSON 和文本提示 |
| 样本单元 | 一个检查、一个患者时间点或一对纵向影像 |
| 标签/条件 | 影像发现、变化标签、报告实体、临床问题或事实性标注 |
| 模型引用 | alter_ct.pt |

**初始结构**：默认输入名称为“paired_chest_ct.json”；执行者必须核验格式、版本、实体/样本完整性、缺失值和可解析性，并记录实际使用的相对名称或数据标识。

**表面/硬约束**：先完成去标识化、患者和时间点对齐、方向/单位核验；输出必须明确是辅助草稿并由合格医生复核，禁止自动诊断或治疗建议。

**划分策略**：按患者、机构、设备、时间和疾病谱独立拆分，严禁同一患者或同一检查泄漏到测试集。

**采样要求**：默认覆盖独立病例并逐例保存输入质量、证据定位、生成文本、置信度和人工复核状态；低质量或冲突病例不得静默通过。

## 核心科学问题

1. 在医学影像、文本报告、患者/时间点元数据和临床问题和输入“paired_chest_ct.json”上，比较同一患者不同时点胸部CT并生成变化报告，适用于病灶进展和疗效随访能否得到可复核的变化F1结果，并满足任务的硬约束？
2. 输入中的影像质量、跨模态事实一致性、纵向变化和临床安全如何影响纵向胸部CT变化检测与报告生成的输出，哪些样本、区域或候选最容易失败？
3. 模型在独立样本、未见家族/条件或困难子集上的表现是否稳定，误差和不确定度如何量化？
4. 结果是否具有足够的生物学、化学或临床证据支持后续决策，哪些部分只能作为探索性线索？
5. 在当前数据、模型和资源边界下，哪些结论可以签收，哪些结论必须标记为无法回答或需要额外验证？

## 比较与评估

- 主任务：比较同一患者不同时点胸部CT并生成变化报告，适用于病灶进展和疗效随访；核心指标：变化F1。
- 目录模型候选为ALTER，需与可解释基线、参考标签或独立质量检查比较。
- 按机构、设备、病种、时间点和阳性/阴性病例分层报告事实性与安全指标。
- 与人工参考、简单检索/模板基线比较，并单独审查高置信错误和拒答病例。

## 工作流

### 步骤 1：医学数据与任务定义

**目的**：读取纵向胸部CT变化检测与报告生成所需的去标识影像和临床文本。

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 医学输入 | `{MEDICAL_INPUT}` | doc | 是 | `paired_chest_ct.json` | 输入去标识医学数据 |
| 医学模型 | `{MODEL_NAME}` | enum | 是 | `ALTER` | 可选值：`ALTER` |
| 影像模态 | `{MODALITY}` | enum | 否 | `CT` | 可选值：`DICOM`、`X-ray`、`CT` |

**输出**：去标识输入、影像元数据、任务配置

**质量门禁**：
- 患者标识已移除
- 影像序列可解析
- 模态与模型兼容

**操作指令**：`读取{MEDICAL_INPUT}并核对去标识状态，使用{MODEL_NAME}建立{MODALITY}模态的纵向胸部CT变化检测与报告生成任务。`

### 步骤 2：影像预处理与提示构建

**目的**：加载权重、规范化影像并建立临床问题或报告提示。

**依赖步骤**：s01

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 模型权重 | `{CHECKPOINT}` | doc | 是 | `alter_ct.pt` | — | 模型权重名称 |
| 临床提示 | `{CLINICAL_PROMPT}` | str | 是 | `描述主要影像发现并给出依据` | — | 填写具体临床任务问题 |
| 最大输出词元 | `{MAX_TOKENS}` | int | 否 | `512` | 32–4096 | 限制生成内容长度 |

**输出**：模型输入影像、临床提示、预处理日志

**质量门禁**：
- 像素与方向信息正确
- 提示不含患者身份
- 权重版本可追溯

**操作指令**：`加载{CHECKPOINT}并规范化影像，用{CLINICAL_PROMPT}构建任务，限制输出为{MAX_TOKENS}个词元。`

### 步骤 3：医学推理与一致性校订

**目的**：生成问答或报告并执行可选的事实一致性校订。

**依赖步骤**：s02

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 生成温度 | `{TEMPERATURE}` | float | 否 | `0.2` | 0–2 | 控制医学文本随机性 |
| 随机种子 | `{SEED}` | int | 否 | `7` | 0–2147483647 | 固定医学生成结果 |
| 启用二次校订 | `{REVISION_PASS}` | bool | 否 | true | — | 是否执行事实二次核对 |

**输出**：医学回答或报告、证据定位、校订记录

**质量门禁**：
- 输出无患者身份信息
- 结论可定位到影像证据
- 不确定性已明确表达

**操作指令**：`以温度{TEMPERATURE}和种子{SEED}运行纵向胸部CT变化检测与报告生成，按{REVISION_PASS}决定是否执行二次事实校订。`

### 步骤 4：临床质量与安全复核

**目的**：计算变化F1并检查事实、遗漏、矛盾和安全风险。

**依赖步骤**：s03

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 临床得分下限 | `{MIN_CLINICAL_SCORE}` | float | 否 | `0.7` | 0–1 | 设置临床质量下限 |
| 要求医生复核 | `{REQUIRE_REVIEW}` | bool | 否 | true | — | 是否标记必须人工复核 |

**输出**：临床质控报告、变化F1明细、人工复核清单

**质量门禁**：
- 无依据结论已标记
- 关键异常遗漏已检查
- 输出明确不是最终诊断

**操作指令**：`计算变化F1并与{MIN_CLINICAL_SCORE}比较；按{REQUIRE_REVIEW}标记医生复核后方可使用。`

## 验收标准与质量门禁

### 硬约束（不可违反）

- 先完成去标识化、患者和时间点对齐、方向/单位核验；输出必须明确是辅助草稿并由合格医生复核，禁止自动诊断或治疗建议。
- 输入、标签、模型版本、数据划分和实际输出之间的血缘必须可追溯；任何偏离都要记录并经场景确认。
- 不得把平均分数、单个高分样本或模型自评当作生物学、化学或临床事实；正式结论必须有独立证据。
- 历史论文、参考模型和示例文件只能用于方案设计或交叉检查，不能冒充本次任务的新结果。

### 最低证据要求

- 实际研究对象、输入、模型/权重、工具和场景约束与任务书一致，所有偏离均有变更记录。
- 输入、标签/参考数据、版本、筛选规则和训练/评估划分可追溯，泄漏和缺失处理有证据。
- 模型或推理结果有独立于选择过程的变化F1评估、分层统计、最差案例和适用域说明。
- 全量结果、失败样本、异常、拒答或低质量标记均被保存；正式分析只使用质量合格的范围。
- 每个目标结果都有定义、单位/量纲（如适用）、样本量、分析窗口、置信区间或不确定度。
- 比较基线、参考标签或人工复核的口径一致，不能只报告对模型有利的子集。
- 结论明确区分观察、模型误差、标签/采样不确定度、偏差和未验证假设。
- 输出文件、环境、日志、版本和校验信息足以让第三方复核关键数值。

**验收判定**：执行者必须对每个交付项给出 PASS、PARTIAL、REJECT 或 BLOCKED，并附文件、日志、图表或数值证据；没有证据的‘运行正常’或‘效果良好’不能作为签收依据。

## 交付物清单

### 最小交付物

1. 任务理解、执行方案、变更记录和输入/许可核验。
2. 影像/文本格式、去标识化、患者-时间点配对、视野和质量检查报告及数据血缘、质量和缺失说明。
3. 模型/权重、提示和预处理版本、患者级独立测试、事实性/偏差/安全分析及独立测试、适用域和失败案例报告。
4. 逐例回答或报告草稿、证据区域/实体、置信度、拒答和复核标记、全量异常/失败记录和运行日志。
5. 临床事实正确率、遗漏/矛盾、实体关系、变化检测和亚组不确定度、可视化/表格、统计不确定度和分层结果。
6. 完整复现包：输入标识、脚本、环境、版本、任务记录、结果清单和文件校验信息。

### 报告规范

- 报告先给结论，再给证据、方法选择理由、限制、偏差和未完成项。
- 所有结果标注变化F1定义、单位或量纲、样本/候选范围、模型版本和数据来源。
- 任何历史资料、参考模型、外部数据库或人工复核都要显式标注身份、用途和可能影响。

### 失败交付要求

如果任务未完成，仍须交付最后一个可复用的健康产物、失败位置、根因证据、影响范围、已排除原因和下一步建议；失败结果不得包装成正式科学结论。

## 边界与限制

**本工作流关注**：
- 本任务关注比较同一患者不同时点胸部CT并生成变化报告，适用于病灶进展和疗效随访、影像质量、跨模态事实一致性、纵向变化和临床安全以及变化F1的可复核评估。
- 因果机制、实验功能、临床疗效/安全性或其他超出输入和验证证据的结论不属于默认交付，除非补充方案获得确认。

**不属于默认交付**：
- 场景不要求照抄论文或历史案例的具体命令、软件参数、脚本、目录结构或资源配置。
- 场景不要求在缺少可靠标签、结构、元数据或独立验证时补造训练目标、样本或性能。
- 场景不接受只给模型文件、平均指标或少量成功样本而没有失败记录、数据血缘和适用性说明的交付。

## 执行前确认事项

- 输入格式、版本、样本/实体完整性和影像发现、变化标签、报告实体、临床问题或事实性标注是否足以支撑任务。
- 模型与权重的许可证、版本、训练覆盖和适用域，及是否需要可解释基线或外部工具。
- 训练/验证/测试划分是否存在同源、患者、样本、位点、化学系列或其他信息泄漏。
- 指标变化F1的定义、方向、单位、分层统计和最低可接受证据。
- 资源、时间和人工/实验复核是否足以完成目标；若冲突，先提交取舍方案。

**信息缺失策略**：如果关键输入、标签、科学口径、许可或资源信息缺失，执行者必须列出缺口、影响和最小补充信息；在确认前不得用默认值静默替代，也不得提交会被误解为正式结论的高成本运行。

## 必要结果项

- **结构结果**：影像/文本格式、去标识化、患者-时间点配对、视野和质量检查报告；同时说明输入清洗、版本和任何变更。
- **参考标签结果**：放射科报告、变化标签、实体关系或临床问答标注的来源和审阅状态；标注缺失、噪声、类别不平衡和不可用于正式验收的部分。
- **模型结果**：模型/权重、提示和预处理版本、患者级独立测试、事实性/偏差/安全分析；明确模型适用的实体、序列/结构/模态范围和不能外推的边界。
- **动力学结果**：逐例回答或报告草稿、证据区域/实体、置信度、拒答和复核标记；保留全量候选或逐样本输出、失败原因、随机种子/条件和版本记录。
- **性质结果**：临床事实正确率、遗漏/矛盾、实体关系、变化检测和亚组不确定度；每个指标给出定义、单位或量纲、样本范围、分析窗口和置信区间。
- **结论结果**：一份将观察结果、独立证据、模型误差、采样/标签不确定度、偏差和无法回答的问题分开的科学结论报告。
