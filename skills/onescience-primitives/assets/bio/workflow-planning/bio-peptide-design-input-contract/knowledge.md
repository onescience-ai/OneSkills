# 靶标特异性全原子肽类设计输入契约

## 适用范围
- **触发条件**：需要理解肽设计任务的输入参数时使用
- **适用场景**：
  - 任务规划阶段需要明确输入参数
  - 需要使用默认值简化用户输入
  - 需要验证输入参数完整性
- **不适用场景**：
  - 非靶向肽设计
  - 其他肽设计模型的输入契约

## 输入
- **蛋白质受体结构**：PDB格式文件（必填）
- **设计模型**：模型名称（必填）
- **目标长度**：整数（必填）

## 输出
- **标准化输入**：验证和标准化后的输入参数
- **约束清单**：从输入中提取的设计约束
- **设计区域**：蛋白质受体上的设计区域

## 流程节点
1. **输入验证** → 检查必填参数是否提供
2. **默认值应用** → 为未提供的可选参数应用默认值
3. **输入标准化** → 格式化和验证所有输入参数
4. **约束提取** → 从输入中提取设计约束

## 关键参数
### 必填参数
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 设计输入 | target_interface.pdb | 蛋白质受体的PDB结构文件 |
| 设计模型 | PepFlow | 使用的肽设计模型 |
| 目标长度 | 256 | 肽序列的目标长度 |

### 可选参数
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 固定残基位点 | [10, 25] | 需要固定的残基位置 |
| 对称群 | C1 | 肽结构的对称性约束 |
| 设计数量 | 64 | 生成的设计候选数量 |
| 采样温度 | 0.2 | 控制采样随机性的温度参数 |
| 随机种子 | 17 | 确保结果可重复性的种子 |
| 筛选阈值 | 0.6 | 界面置信度筛选阈值 |
| 保留多样候选 | true | 是否保留多样化的候选设计 |

## 边界与分流
- **异常处理**：
  - 当必填参数缺失时，提示用户提供或使用默认值
  - 当参数类型错误时，自动转换或报错
- **降级策略**：
  - 当默认文件不存在时，检查任务产物目录
  - 当模型不可用时，使用替代模型
- **分支条件**：
  - 根据参数值选择不同的设计策略
  - 根据约束条件调整工作流

## 质量检查
- **验证点**：
  - 必填参数完整性检查
  - 参数类型和范围验证
  - 默认值应用验证
- **阈值**：
  - 所有必填参数必须提供或使用默认值
  - 参数值必须在合理范围内
- **失败处理**：
  - 缺失必填参数时提示用户
  - 参数错误时自动修正或报错

## 回退策略
- **失败时的替代方案**：
  - 使用其他肽设计模型的输入契约
  - 手动指定输入参数
- **降级路径**：
  - 从全参数输入降级到最小参数输入
  - 从复杂约束降级到简单约束

# 输入契约使用示例
from peptide_input_contract import PeptideDesignInput

# 创建输入契约
input_contract = PeptideDesignInput()

# 验证输入
validated_input = input_contract.validate(
    protein_structure="target_interface.pdb",  # 必填，使用默认值
    model="PepFlow",  # 必填，使用默认值
    target_length=256,  # 必填，使用默认值
    fixed_residues=[10, 25],  # 可选，使用默认值

    num_designs=64,  # 可选，使用默认值
    temperature=0.2,  # 可选，使用默认值
    seed=17,  # 可选，使用默认值
    confidence_threshold=0.6,  # 可选，使用默认值
    diversity=True  # 可选，使用默认值
)

# 提取约束
constraints = input_contract.extract_constraints(validated_input)

# 识别设计区域
design_region = input_contract.identify_design_region(validated_input)
