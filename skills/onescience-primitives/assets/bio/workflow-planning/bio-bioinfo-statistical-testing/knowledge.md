# 生物信息学统计检验流程

## 适用范围
面向生物信息学分析中的统计检验需求，提供从样本量规划到结果解释的标准化流程。适用于单细胞分析、差异表达分析、模型比较等需要统计推断的场景。

## 输入
- 待比较的两组或多组数据
- 显著性水平（α，默认0.05）
- 预期效应量（Cohen's d或相关系数）
- 数据类型（连续/离散、正态/非正态）

## 输出
- 统计检验结果（p值、置信区间、效应量）
- 样本量建议
- 结果解释报告

## 流程节点

### 1. 样本量规划

#### 1.1 功效分析（Power Analysis）
- **定义**：在给定效应量和显著性水平下，检测到真实差异所需的最小样本量
- **计算公式**：
  ```python
  from statsmodels.stats.power import TTestIndPower
  power_analysis = TTestIndPower()
  # 计算所需样本量
  sample_size = power_analysis.solve_power(
      effect_size=0.5,  # Cohen's d
      alpha=0.05,
      power=0.8  # 80%功效
  )
  ```
- **推荐参数**：
  - 功效（power）：≥0.8（80%）
  - 效应量（effect size）：根据领域知识设定
  - 显著性水平（α）：0.05（双侧检验）

#### 1.2 单细胞分析样本量要求
| 分析类型 | 最小样本量 | 推荐样本量 | 说明 |
|----------|------------|------------|------|
| 细胞类型注释 | 100 cells/type | 500+ cells/type | 确保统计功效 |
| 差异表达分析 | 3 samples/group | 5+ samples/group | 控制假阳性 |
| 模型比较 | 50 cells | 100+ cells | 稳定估计效应量 |
| 扰动预测 | 100 perturbed cells | 500+ perturbed cells | 覆盖异质性 |

#### 1.3 样本量不足的处理
- **降低效应量阈值**：接受较小的效应量
- **增加显著性水平**：使用α=0.1（需明确说明）
- **报告置信区间**：强调估计的不确定性
- **建议后续研究**：明确指出需要更大样本量验证

### 2. 统计检验选择

#### 2.1 参数检验
| 检验方法 | 适用条件 | 应用场景 |
|----------|----------|----------|
| 独立样本t检验 | 正态分布、方差齐性 | 两组均值比较 |
| 配对t检验 | 正态分布、配对数据 | 同一对象前后比较 |
| 方差分析（ANOVA） | 正态分布、多组比较 | 多组均值比较 |
| 线性回归 | 连续变量、线性关系 | 多因素影响分析 |

#### 2.2 非参数检验
| 检验方法 | 适用条件 | 应用场景 |
|----------|----------|----------|
| Mann-Whitney U检验 | 非正态分布 | 两组中位数比较 |
| Wilcoxon符号秩检验 | 配对非正态数据 | 配对中位数比较 |
| Kruskal-Wallis检验 | 非正态多组 | 多组中位数比较 |
| Spearman秩相关 | 非线性关系 | 相关性分析 |

#### 2.3 单细胞分析常用检验
| 分析类型 | 推荐检验 | 说明 |
|----------|----------|------|
| 差异表达 | Wilcoxon秩和检验 | scanpy默认方法 |
| 模型比较 | 配对t检验 | 同一样本两模型比较 |
| 聚类评估 | 调整兰德指数 | 聚类质量评估 |
| 扰动效应 | t检验+效应量 | 扰动前后比较 |

### 3. p值解释

#### 3.1 p值含义
- **定义**：在原假设成立时，观察到当前或更极端结果的概率
- **常见误解**：
  - ❌ p值不是"原假设为真的概率"
  - ❌ p值不是"效应大小的度量"
  - ❌ p值不是"结果重要性的度量"

#### 3.2 p值解释标准
| p值范围 | 解释 | 建议行动 |
|---------|------|----------|
| p < 0.001 | 极显著 | 强烈拒绝原假设 |
| 0.001 ≤ p < 0.01 | 高度显著 | 拒绝原假设 |
| 0.01 ≤ p < 0.05 | 显著 | 拒绝原假设（需报告效应量） |
| 0.05 ≤ p < 0.1 | 边缘显著 | 谨慎解释，建议增加样本量 |
| p ≥ 0.1 | 不显著 | 无法拒绝原假设 |

#### 3.3 p值报告规范
```python
# 报告内容应包括：
report = {
    "test_statistic": t_stat,  # 检验统计量
    "p_value": p_value,  # p值
    "effect_size": cohens_d,  # 效应量
    "confidence_interval": (ci_lower, ci_upper),  # 置信区间
    "sample_size": (n1, n2),  # 样本量
    "significance": p_value < 0.05  # 是否显著
}
```

### 4. 效应量解释

#### 4.1 Cohen's d
- **定义**：两组均值差异与合并标准差的比值
- **计算公式**：
  ```python
  import numpy as np
  def cohens_d(group1, group2):
      n1, n2 = len(group1), len(group2)
      var1, var2 = np.var(group1, ddof=1), np.var(group2, ddof=1)
      pooled_std = np.sqrt(((n1-1)*var1 + (n2-1)*var2) / (n1+n2-2))
      return (np.mean(group1) - np.mean(group2)) / pooled_std
  ```
- **解释标准**：
  | Cohen's d | 效应大小 | 解释 |
  |-----------|----------|------|
  | 0.2 | 小效应 | 差异存在但实际意义有限 |
  | 0.5 | 中等效应 | 差异具有实际意义 |
  | 0.8 | 大效应 | 差异具有重要实际意义 |

#### 4.2 相关系数（r）
- **解释标准**：
  | r值范围 | 效应大小 | 解释 |
  |---------|----------|------|
  | 0.1-0.3 | 弱相关 | 关系较弱 |
  | 0.3-0.5 | 中等相关 | 关系中等 |
  | 0.5-0.7 | 强相关 | 关系较强 |
  | 0.7-1.0 | 非常强相关 | 关系很强 |

#### 4.3 效应量与p值的关系
- **小样本+大效应**：p值可能不显著，但效应量有意义
- **大样本+小效应**：p值可能显著，但效应量无实际意义
- **建议**：始终报告效应量，不要仅依赖p值

### 5. 置信区间

#### 5.1 置信区间含义
- **定义**：在重复抽样中，包含真实参数值的区间比例
- **常见水平**：95% CI（最常用）、99% CI
- **解释**：我们有95%的信心认为真实值落在该区间内

#### 5.2 置信区间计算
```python
from scipy import stats
def confidence_interval(data, confidence=0.95):
    n = len(data)
    mean = np.mean(data)
    se = stats.sem(data)
    ci = stats.t.interval(confidence, n-1, loc=mean, scale=se)
    return ci
```

#### 5.3 置信区间解释
- **区间宽度**：反映估计精度（越窄越精确）
- **区间位置**：反映效应方向（是否包含0）
- **区间重叠**：两组CI重叠不一定意味着无显著差异

### 6. 多重检验校正

#### 6.1 问题
- 多次检验增加假阳性风险
- 例如：检验1000个基因，α=0.05，预期50个假阳性

#### 6.2 校正方法
| 方法 | 适用场景 | 严格程度 |
|------|----------|----------|
| Bonferroni校正 | 最严格 | 控制FWER |
| Benjamini-Hochberg | 常用 | 控制FDR |
| Benjamini-Yekutieli | 相关检验 | 控制FDR |
| q-value | 高通量数据 | 控制FDR |

#### 6.3 单细胞分析中的应用
```python
# scanpy差异表达分析中的多重检验校正
sc.tl.rank_genes_groups(adata, groupby='cell_type', method='wilcoxon')
# 结果包含pvals_adj（校正后p值）
```

## 关键参数

### 统计检验选择判据
| 数据特征 | 推荐检验 | 说明 |
|----------|----------|------|
| 正态分布+方差齐性 | t检验/ANOVA | 参数检验最优 |
| 非正态分布 | Wilcoxon/Mann-Whitney | 非参数检验 |
| 配对数据 | 配对t检验/Wilcoxon符号秩 | 控制个体差异 |
| 多组比较 | ANOVA/Kruskal-Wallis | 避免多次t检验 |

### 样本量规划参数
| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 功效（power） | 0.8 | 检测到真实差异的概率 |
| 显著性水平（α） | 0.05 | 假阳性风险 |
| 效应量（Cohen's d） | 0.5 | 中等效应（可根据领域调整） |
| 置信水平 | 95% | 估计精度 |

### 结果解释参数
| 参数 | 推荐值 | 说明 |
|------|--------|------|
| p值阈值 | 0.05 | 显著性判断 |
| 效应量阈值 | 0.2 | 实际意义判断 |
| 置信区间 | 95% | 估计精度 |
| 多重校正方法 | BH-FDR | 高通量数据 |

## 边界与分流

### 异常处理
- **样本量不足**：报告置信区间，建议增加样本量
- **p值不显著**：检查效应量，避免"无差异"结论
- **多重检验问题**：使用FDR校正，报告校正后p值

### 降级策略
- 如样本量不足，仅报告描述性统计
- 如数据不满足参数检验条件，使用非参数检验
- 如多重检验校正后无显著结果，探索性分析需谨慎解释

## 质量检查

### 检验前检查
1. 数据分布检验（正态性检验）
2. 方差齐性检验
3. 样本量充足性评估
4. 缺失值处理

### 结果检查
1. p值在合理范围内（非极端值）
2. 效应量与p值一致
3. 置信区间合理
4. 样本量报告完整

### 报告完整性检查
1. 检验方法已说明
2. 样本量已报告
3. 效应量已报告
4. 置信区间已报告
5. 多重检验已校正（如适用）

## 回退策略
- 如参数检验不满足条件，使用非参数检验
- 如样本量不足，仅报告描述性统计
- 如多重检验校正后无显著结果，建议增加样本量或探索性分析
