# 单细胞基础模型评测流程

## 适用范围
面向单细胞基础模型（如Geneformer、scGPT）的比较评测任务，提供多维度生物学一致性验证框架。适用于需要评估模型在细胞状态表征、扰动响应、空间结构保持和跨模态整合方面能力的场景。

## 输入
- 预训练模型（Geneformer/scGPT）
- 标准化单细胞数据集（H5AD格式）
- 评测任务配置（选择性执行扰动/空间/跨模态评测）

## 输出
- 多维度评测报告（含各指标数值、统计检验结果）
- 可视化图表（模型比较热图、指标分布图）
- 模型推荐建议

## 流程节点

### 1. 细胞状态表征评测

#### 1.1 概念纯度（Concept Purity）
- **定义**：模型表征空间中同一细胞类型细胞的聚集程度
- **计算方法**：
  ```python
  from sklearn.metrics import silhouette_score
  # 基于模型提取的嵌入计算轮廓系数
  purity = silhouette_score(embeddings, cell_type_labels)
  ```
- **阈值**：>0.3为良好，>0.5为优秀
- **局限性**：仅反映线性可分性，不反映生物学功能

#### 1.2 细胞类型分离度
- **定义**：不同细胞类型在表征空间中的分离程度
- **计算方法**：基于UMAP可视化+定量指标（如adjusted Rand index）
- **互补关系**：概念纯度关注类内聚集，分离度关注类间分离

### 2. 扰动/反事实响应评测

#### 2.1 扰动预测任务
- **任务描述**：模拟基因敲除后的细胞状态变化
- **标准流程**：
  1. 选择目标基因（如TP53、MYC、CD3D）
  2. 在输入中掩码目标基因表达
  3. 模型预测扰动后的表达谱
  4. 与真实扰动数据（如Perturb-seq）比较

#### 2.2 评测指标
| 指标 | 计算方法 | 阈值 | 说明 |
|------|----------|------|------|
| Pearson相关系数 | 预测vs真实表达谱 | >0.5 | 整体表达趋势一致性 |
| 差异表达基因召回率 | 预测DEGs/真实DEGs | >0.6 | 关键基因捕捉能力 |
| 通路富集一致性 | GSEA富集分数比较 | >0.4 | 功能层面一致性 |
| 细胞状态转换 | 细胞类型比例变化 | 定性 | 生物学合理性 |

#### 2.3 数据需求
- **必需**：包含扰动实验的单细胞数据（如Perturb-seq、CRISPR筛选）
- **推荐**：至少3个目标基因的扰动数据
- **替代**：如无真实扰动数据，使用in silico扰动模拟

### 3. 空间结构保持性评测

#### 3.1 任务描述
- 验证模型表征是否保持细胞在组织空间中的邻近关系
- 适用于空间转录组数据（如MERFISH、Visium）

#### 3.2 评测方法
- **空间自相关检验**：Moran's I指数
  ```python
  from pysal.explore import esda
  from pysal.lib import weights
  # 计算空间自相关
  w = weights.KNN.from_array(spatial_coords)
  moran = esda.Moran(embeddings, w)
  ```
- **邻近保持性**：空间邻近细胞在嵌入空间中的距离
- **组织结构可视化**：嵌入坐标与空间坐标的对应关系

#### 3.3 评测指标
| 指标 | 计算方法 | 阈值 | 说明 |
|------|----------|------|------|
| Moran's I | 空间自相关系数 | >0.3 | 空间聚集程度 |
| 邻近保持率 | 空间邻近vs嵌入邻近 | >0.6 | 局部结构保持 |
| 轮廓系数（空间注释） | 基于空间区域的聚类 | >0.4 | 区域分离度 |

#### 3.4 数据需求
- **必需**：包含空间坐标信息的单细胞数据
- **推荐**：高分辨率空间转录组数据
- **替代**：如无空间数据，跳过此评测

### 4. 跨模态一致性评测

#### 4.1 任务描述
- 验证不同组学数据（如RNA+ATAC、RNA+蛋白质）的一致性
- 评估模型的多组学整合能力

#### 4.2 评测方法
- **跨模态对齐**：同一细胞的不同组学表示的距离
- **模态预测**：从一种组学预测另一种组学
- **一致性评分**：不同组学的细胞类型注释一致性

#### 4.3 评测指标
| 指标 | 计算方法 | 阈值 | 说明 |
|------|----------|------|------|
| 跨模态轮廓系数 | 不同模态嵌入的距离 | >0.3 | 模态对齐程度 |
| 模态预测准确率 | 从RNA预测ATAC | >0.7 | 跨模态预测能力 |
| 注释一致性 | 不同模态的细胞类型匹配 | >0.8 | 功能一致性 |

#### 4.4 数据需求
- **必需**：配对的多组学数据（如同一细胞的RNA+ATAC）
- **推荐**：10x Multiome或SHARE-seq数据
- **替代**：如无配对数据，跳过此评测

### 5. 综合评测报告

#### 5.1 指标汇总
```python
evaluation_report = {
    "concept_purity": {"geneformer": 0.36, "scgpt": 0.43},
    "perturbation_correlation": {"geneformer": 0.52, "scgpt": 0.61},
    "spatial_morans_i": {"geneformer": 0.38, "scgpt": 0.42},
    "cross_modal_alignment": {"geneformer": 0.45, "scgpt": 0.51}
}
```

#### 5.2 统计检验
- **配对t检验**：比较两个模型在各指标上的差异
- **效应量**：Cohen's d，评估差异的实际意义
- **置信区间**：95% CI，评估估计精度

#### 5.3 模型推荐
- 根据任务需求选择最优模型
- 提供模型选择的权衡分析

## 关键参数

### 评测指标选择判据
| 评测维度 | 必需指标 | 可选指标 | 适用场景 |
|----------|----------|----------|----------|
| 细胞状态表征 | 概念纯度 | 分离度、UMAP可视化 | 所有单细胞分析 |
| 扰动响应 | Pearson相关系数 | DEG召回率、通路一致性 | 药物研发、基因功能研究 |
| 空间结构 | Moran's I | 邻近保持率 | 空间转录组分析 |
| 跨模态一致性 | 跨模态轮廓系数 | 模态预测准确率 | 多组学整合分析 |

### 统计检验要求
| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 最小样本量 | 50 cells | 统计检验功效要求 |
| 显著性水平 | 0.05 | p值阈值 |
| 效应量阈值 | 0.2 | 实际意义判断 |
| 置信水平 | 95% | 估计精度 |

## 边界与分流

### 异常处理
- **评测数据缺失**：跳过对应评测维度，在报告中说明
- **统计检验不显著**：标注"无统计学意义"，建议增加样本量
- **模型加载失败**：检查权重文件完整性和版本兼容性

### 降级策略
- 如无扰动数据，使用文献报告的扰动结果作为参考
- 如无空间数据，跳过空间结构评测
- 如无配对多组学数据，跳过跨模态评测

## 质量检查

### 评测完整性检查
1. 所有必需指标已计算
2. 统计检验已执行
3. 结果可复现（随机种子固定）
4. 可视化已生成

### 结果合理性检查
1. 指标值在合理范围内（0-1）
2. 统计检验p值合理（非极端值）
3. 模型比较结论与指标一致

## 回退策略
- 如某评测维度数据不足，降低该维度权重
- 如统计检验不显著，仅报告描述性统计
- 如模型比较无明显差异，建议增加数据量
