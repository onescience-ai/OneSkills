# BEND_tasks数据集规模与划分策略

## 适用范围
适用于需要理解BEND_tasks数据集完整规模、采样要求和划分策略的场景。确保评测结果具有统计显著性和代表性。

## 输入
- 数据集规模需求：完整测试集规模
- 采样要求：分层采样方法
- 划分策略：按染色体/基因、物种、细胞类型和变异类别划分

## 输出
- 完整数据集规模信息
- 分层采样策略文档
- 统计显著性评估方法

## 流程节点
1. 规模评估 → 2. 采样设计 → 3. 划分实施 → 4. 显著性评估 → 5. 代表性验证

### 步骤1：规模评估
- **操作**：评估BEND_tasks数据集完整规模
- **参数**：基因组区间数量、任务类型分布、样本平衡性
- **工具**：数据统计脚本
- **质量门禁**：规模信息准确，覆盖三个任务

### 步骤2：采样设计
- **操作**：设计分层采样策略
- **参数**：采样比例、分层维度、随机种子
- **工具**：Python采样脚本
- **质量门禁**：采样代表性好，无偏差

### 步骤3：划分实施
- **操作**：按标准划分数据集
- **参数**：训练集/验证集/测试集比例、划分依据
- **工具**：数据划分脚本
- **质量门禁**：划分合理，无数据泄露

### 步骤4：显著性评估
- **操作**：评估评测结果的统计显著性
- **参数**：置信区间、p值、效应量
- **工具**：统计分析脚本
- **质量门禁**：显著性水平达标，结果可靠

### 步骤5：代表性验证
- **操作**：验证采样结果的代表性
- **参数**：分布相似性、覆盖率、偏差评估
- **工具**：验证脚本
- **质量门禁**：代表性好，无系统偏差

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 完整规模 | 数千个基因组区间 | 归因报告 | 标准工作流要求 |
| 分层维度 | 染色体/基因、物种、细胞类型、变异类别 | 归因报告 | 多维度分层 |
| 采样比例 | 按任务类型平衡 | 归因报告 | 确保任务代表性 |
| 显著性水平 | p<0.05 | 标准统计要求 | 结果可靠性 |

## 边界与分流
- **异常处理**：采样偏差时调整采样权重，显著性不足时增加样本量
- **降级策略**：数据不足时使用交叉验证，分层失败时使用随机采样
- **分支条件**：不同任务类型可能需要不同的采样策略

## 质量检查
- **验证点**：规模准确性、采样代表性、划分合理性、显著性水平
- **阈值**：覆盖率>90%，偏差<5%，p<0.05
- **失败处理**：重新采样或调整划分策略

## 回退策略
- 数据规模不足时使用数据增强或迁移学习
- 采样偏差过大时调整采样权重或方法
- 显著性不足时增加样本量或使用更敏感的统计方法
