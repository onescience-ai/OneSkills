# 生物信息学统计检验知识

## 适用范围

**触发条件**：
- 任务需要对单细胞分析结果进行统计检验
- 需要评估样本量是否足够、效应量是否有意义
- 统计检验无显著性时需要风险评估

**适用场景**：
- 差异表达分析
- 模型性能比较
- 扰动效应评估
- 跨数据集整合验证

**不适用场景**：
- 临床诊断决策（需要临床验证）
- 因果推断（需要实验干预）
- 预测性模型验证（需要独立测试集）

## 输入

| 输入项 | 说明 |
|--------|------|
| 样本数据 | 细胞级或基因级观测值 |
| 分组信息 | 细胞类型、处理条件、批次 |
| 效应指标 | 差异表达、聚类质量、预测准确率 |
| 样本量 | 每组细胞数/重复数 |

## 输出

| 输出项 | 说明 |
|--------|------|
| p值 | 统计显著性 |
| 效应量 | 实际意义大小（Cohen's d、rho等） |
| 置信区间 | 估计不确定性 |
| 样本量建议 | 达到统计功效所需样本量 |
| 风险评估 | 模拟数据vs真实数据结论差异 |

## 流程节点

### 步骤1：样本量评估

**操作**：评估当前样本量是否足够检测目标效应

**单细胞分析样本量要求**：

| 分析类型 | 最小样本量 | 推荐样本量 | 说明 |
|----------|------------|------------|------|
| 差异表达 | 50细胞/组 | >200细胞/组 | 检测2倍变化 |
| 聚类质量 | >100细胞 | >500细胞 | 稳定ARI |
| 扰动预测 | >100细胞/条件 | >500细胞/条件 | 跨条件泛化 |
| 模型比较 | >30样本 | >100样本 | 稳定性能差异 |

**功效分析（Power Analysis）**：

```
功效 = 1 - β = P(拒绝H0 | H1为真)
```

**功效参数**：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 显著性水平 α | 0.05 | Type I错误率 |
| 统计功效 1-β | 0.8 | Type II错误率 |
| 效应量 d | 0.5 | 中等效应 |
| 样本量计算 | G*Power / pwr包 | 在线工具 |

**功效不足风险**：
- 样本量<50 → 高假阴性率
- 样本量<30 → 结果不稳定
- 样本量<10 → 不应进行统计检验

### 步骤2：效应量解释

**操作**：计算并解释效应量，区分统计显著与实际意义

**常用效应量指标**：

| 指标 | 定义 | 小效应 | 中效应 | 大效应 | 适用场景 |
|------|------|--------|--------|--------|----------|
| Cohen's d | 均值差/合并标准差 | 0.2 | 0.5 | 0.8 | 两组比较 |
| eta-squared | 组间方差/总方差 | 0.01 | 0.06 | 0.14 | 多组比较 |
| Spearman rho | 秩相关 | 0.1 | 0.3 | 0.5 | 相关性 |
| ARI | 调整兰德指数 | 0.3 | 0.5 | 0.7 | 聚类质量 |
| NMI | 标准化互信息 | 0.3 | 0.5 | 0.7 | 聚类质量 |

**效应量解释原则**：
- p值反映统计显著性，效应量反映实际意义
- 大样本量下，微小效应也可显著
- 应同时报告p值和效应量

### 步骤3：置信区间计算

**操作**：计算效应量的置信区间，量化估计不确定性

**置信区间方法**：

| 方法 | 适用场景 | 公式 |
|------|----------|------|
| Bootstrap | 非正态分布 | 重采样95%分位数 |
| t分布 | 正态分布、小样本 | mean ± t * SE |
| Wilson区间 | 比例估计 | 改进的 Wald 区间 |
| Bonferroni校正 | 多重检验 | CI宽度增加 |

**置信区间解释**：
- 95% CI：重复实验95%会包含真实值
- CI不包含0 → 效应显著
- CI宽度反映估计精度

### 步骤4：多重检验校正

**操作**：校正同时进行的多次检验

**校正方法**：

| 方法 | 控制目标 | 适用场景 | 保守程度 |
|------|----------|----------|----------|
| Bonferroni | FWER | 少量检验 | 最保守 |
| Holm | FWER | 少量检验 | 较保守 |
| Benjamini-Hochberg | FDR | 大量检验 | 适中 |
| Storey q-value | FDR | 大量检验 | 较宽松 |

**校正后阈值**：

```
校正后p值 = p值 * 检验次数 (Bonferroni)
```

**单细胞分析常用**：
- 差异表达：BH校正，FDR<0.05
- 基因集富集：FDR<0.1
- 聚类差异：Holm校正

### 步骤5：模拟数据与真实数据风险评估

**操作**：评估基于模拟数据的结论与真实数据的差异风险

**模拟数据风险**：

| 风险类型 | 描述 | 量化方法 |
|----------|------|----------|
| 分布假设错误 | 模拟分布与真实分布不匹配 | KS检验、QQ图 |
| 参数估计偏差 | 模拟参数基于小样本估计 | 参数CI检查 |
| 结构简化 | 模拟忽略真实复杂性 | 批次效应、 dropout |
| 过拟合风险 | 模型在模拟数据上过拟合 | 交叉验证 |

**风险缓解策略**：

| 策略 | 操作 | 适用场景 |
|------|------|----------|
| 真实数据验证 | 使用独立真实数据集 | 有条件时 |
| 敏感性分析 | 改变模拟参数重复分析 | 始终推荐 |
| 不确定性量化 | 报告置信区间和敏感性范围 | 始终推荐 |
| 保守结论 | 标注模拟数据局限性 | 始终推荐 |

### 步骤6：结论规范

**操作**：规范统计检验结论的报告

**结论报告模板**：

```
统计检验结果：
- 效应量：[指标] = [值] (95% CI: [下限], [上限])
- 显著性：p = [值] [校正方法]
- 实际意义：[效应量解释]
- 样本量：[n] (功效 = [值])
- 局限性：[数据类型、假设、风险]
```

**结论规范**：

| 检验结果 | 结论表述 | 禁止表述 |
|----------|----------|----------|
| p<0.05, 大效应 | "显著差异，效应量大" | "证明有效" |
| p>0.05, 小效应 | "无显著差异，但样本量不足" | "无差异" |
| p<0.05, 小效应 | "统计显著但实际意义有限" | "高度显著" |
| 模拟数据 | "模拟数据显示...需真实数据验证" | "真实数据显示" |

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 显著性水平α | 0.05 | [1] | 标准阈值 |
| 统计功效1-β | 0.8 | [1] | 最低可接受 |
| 最小样本量 | >30 | [1] | 稳定估计 |
| FDR阈值 | <0.05 | [1] | 多重检验校正 |
| CI置信水平 | 95% | [1] | 标准置信区间 |

## 边界与分流

**异常处理**：
- 样本量不足 → 标注功效不足，建议增加样本量
- 效应量小 → 标注实际意义有限
- 多重检验 → 执行校正并报告校正后p值

**分支条件**：
- 模拟数据 → 风险评估+保守结论
- 真实数据 → 标准统计检验
- 混合数据 → 分别报告+综合评估

## 质量检查

| 检查点 | 阈值 | 失败处理 |
|--------|------|----------|
| 样本量报告 | 100% | 标注缺失 |
| 效应量报告 | 100% | 仅报告p值不完整 |
| 置信区间 | 100% | 标注不确定性未量化 |
| 局限性说明 | 100% | 结论过度解读 |

## 回退策略

1. **首选**：完整统计检验（p值+效应量+CI+功效）
2. **备选**：报告效应量和CI，标注p值不可靠
3. **兜底**：描述性统计+定性结论
