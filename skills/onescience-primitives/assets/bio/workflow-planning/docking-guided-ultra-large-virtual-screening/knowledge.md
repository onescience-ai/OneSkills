# 对接引导的超大规模虚拟筛选（B47）

## 适用范围

**适用场景**：
- 受体和配体结构可解析，配体键级、立体化学、质子化和目标口袋有明确记录。
- 有实验姿态、亲和力或独立几何检查来评估生成与排序，不只依赖模型分数。
- 受体/配体家族和口袋范围在验证数据覆盖内，或执行者会明确标记外推。
- 结果用于虚拟筛选、姿态假设和候选优先级排序，实验结合仍是必要确认。

**不适用场景**：
- 配体键级、质子化、立体异构或受体口袋定义不确定，导致姿态无法复核。
- 把对接分数直接当作实验亲和力、疗效或选择性证明而没有校准和实验数据。
- 体系包含强共价反应、金属配位、膜环境或大规模构象变化而模型未覆盖。
- 只保留看起来合理的姿态、没有记录失败和碰撞构象，无法审计筛选偏差。

## 研究对象与输入

**研究对象**：受体结构、配体化学结构、候选口袋和对接姿态

| 输入项 | 说明 |
|---|---|
| 输入文件 | screening_library.smi |
| 输入模态 | PDB/mmCIF、SDF/SMILES、口袋描述或姿态集合 |
| 样本单元 | 一个受体-配体对及其候选姿态 |
| 标签/条件 | 实验结合姿态、口袋中心、亲和力或姿态成功标签 |
| 模型引用 | boltzina.ckpt |

**初始结构**：默认输入名称为“screening_library.smi”；执行者必须核验格式、版本、实体/样本完整性、缺失值和可解析性，并记录实际使用的相对名称或数据标识。

**表面/硬约束**：保持受体链、质子化/电荷、配体键级、立体化学和口袋定义；碰撞、断键或不合法价态的姿态不得进入正式排序。

**划分策略**：按蛋白家族、配体骨架、共价状态和时间切分拆分评估，并报告口袋已知/未知及近邻泄漏。

**采样要求**：默认为每个受体-配体对保留多个候选姿态（至少 10 个或数据允许的完整集合），并给出几何质控和排序证据。

## 核心科学问题

1. 在受体结构、配体化学结构、候选口袋和对接姿态和输入“screening_library.smi”上，结合快速对接与学习式结合预测，对超大化合物库进行分层虚拟筛选能否得到可复核的富集因子结果，并满足任务的硬约束？
2. 输入中的口袋定位、姿态几何、排序可靠性和化学有效性如何影响对接引导的超大规模虚拟筛选的输出，哪些样本、区域或候选最容易失败？
3. 模型在独立样本、未见家族/条件或困难子集上的表现是否稳定，误差和不确定度如何量化？
4. 结果是否具有足够的生物学、化学或临床证据支持后续决策，哪些部分只能作为探索性线索？
5. 在当前数据、模型和资源边界下，哪些结论可以签收，哪些结论必须标记为无法回答或需要额外验证？

## 比较与评估

- 主任务：结合快速对接与学习式结合预测，对超大化合物库进行分层虚拟筛选；核心指标：富集因子。
- 目录模型候选为Boltz、Boltzina，需与可解释基线、参考标签或独立质量检查比较。
- 分别报告已知口袋、盲口袋、近邻/远离训练化学空间的姿态和排序表现。
- 将学习分数与几何合法性、接触证据及至少一个基线排序进行对照。

## 工作流

### 步骤 1：受体配体输入预检

**目的**：标准化对接引导的超大规模虚拟筛选的受体、配体或候选姿态输入。

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 对接输入 | `{DOCKING_INPUT}` | doc | 是 | `screening_library.smi` | 输入复合物或配体数据 |
| 对接模型 | `{MODEL_NAME}` | enum | 是 | `Boltz` | 可选值：`Boltz`、`Boltzina` |
| 补充氢原子 | `{ADD_HYDROGENS}` | bool | 否 | true | 是否标准化质子化状态 |

**输出**：标准化受体、标准化配体、输入异常清单

**质量门禁**：
- 受体结构可解析
- 配体化学价合法
- 实体标识不重复

**操作指令**：`读取{DOCKING_INPUT}，按{ADD_HYDROGENS}处理质子化状态，并用{MODEL_NAME}建立对接引导的超大规模虚拟筛选任务。`

### 步骤 2：口袋与模型特征准备

**目的**：加载权重并定义口袋中心、范围和图特征。

**依赖步骤**：s01

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 模型权重 | `{CHECKPOINT}` | doc | 是 | `boltzina.ckpt` | — | 模型权重名称 |
| 口袋中心 | `{POCKET_CENTER}` | list[float] | 否 | [0, 0, 0] | — | 填写三维中心坐标 |
| 口袋半径 | `{POCKET_RADIUS}` | float | 否 | `12` | 3–40 | 设置口袋搜索半径 |

**输出**：口袋定义、蛋白配体特征、模型加载记录

**质量门禁**：
- 中心包含有效坐标
- 口袋残基非空
- 配体拓扑保持

**操作指令**：`加载{CHECKPOINT}，围绕{POCKET_CENTER}和{POCKET_RADIUS}构建口袋及蛋白配体图特征。`

### 步骤 3：构象采样与打分

**目的**：采样平移、旋转和扭转自由度并输出候选得分。

**依赖步骤**：s02

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 每配体姿态数 | `{POSES_PER_LIGAND}` | int | 是 | `40` | 1–1000 | 设置每个配体姿态数 |
| 推理步数 | `{INFERENCE_STEPS}` | int | 否 | `20` | 1–1000 | 设置构象采样步数 |
| 随机种子 | `{SEED}` | int | 否 | `101` | 0–2147483647 | 固定随机采样结果 |

**输出**：候选姿态、对接得分、采样日志

**质量门禁**：
- 每个成功配体有候选
- 坐标为有限值
- 配体键连接未改变

**操作指令**：`运行对接引导的超大规模虚拟筛选，以种子{SEED}执行{INFERENCE_STEPS}步采样，为每个配体产生{POSES_PER_LIGAND}个姿态。`

### 步骤 4：物理几何质控与排序

**目的**：按富集因子、碰撞和内部几何筛选对接结果。

**依赖步骤**：s03

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| RMSD阈值 | `{MAX_RMSD}` | float | 否 | `2` | 0.1–10 | 设置成功构象阈值 |
| 保留姿态数 | `{TOP_K}` | int | 否 | `5` | 1–100 | 设置每配体保留数量 |

**输出**：排序姿态、富集因子汇总表、几何质控报告

**质量门禁**：
- 入选姿态无严重碰撞
- 排序分数定义明确
- 失败配体原因已记录

**操作指令**：`检查碰撞与键几何，计算富集因子并按{MAX_RMSD}标记成功构象，每个配体保留前{TOP_K}个。`

## 验收标准与质量门禁

### 硬约束（不可违反）

- 保持受体链、质子化/电荷、配体键级、立体化学和口袋定义；碰撞、断键或不合法价态的姿态不得进入正式排序。
- 输入、标签、模型版本、数据划分和实际输出之间的血缘必须可追溯；任何偏离都要记录并经场景确认。
- 不得把平均分数、单个高分样本或模型自评当作生物学、化学或临床事实；正式结论必须有独立证据。
- 历史论文、参考模型和示例文件只能用于方案设计或交叉检查，不能冒充本次任务的新结果。

### 最低证据要求

- 实际研究对象、输入、模型/权重、工具和场景约束与任务书一致，所有偏离均有变更记录。
- 输入、标签/参考数据、版本、筛选规则和训练/评估划分可追溯，泄漏和缺失处理有证据。
- 模型或推理结果有独立于选择过程的富集因子评估、分层统计、最差案例和适用域说明。
- 全量结果、失败样本、异常、拒答或低质量标记均被保存；正式分析只使用质量合格的范围。
- 每个目标结果都有定义、单位/量纲（如适用）、样本量、分析窗口、置信区间或不确定度。
- 比较基线、参考标签或人工复核的口径一致，不能只报告对模型有利的子集。
- 结论明确区分观察、模型误差、标签/采样不确定度、偏差和未验证假设。
- 输出文件、环境、日志、版本和校验信息足以让第三方复核关键数值。

**验收判定**：执行者必须对每个交付项给出 PASS、PARTIAL、REJECT 或 BLOCKED，并附文件、日志、图表或数值证据；没有证据的‘运行正常’或‘效果良好’不能作为签收依据。

## 交付物清单

### 最小交付物

1. 任务理解、执行方案、变更记录和输入/许可核验。
2. 受体/配体标准化记录、口袋坐标、质子化和立体化学检查报告及数据血缘、质量和缺失说明。

5. RMSD/Top-k/富集或物理几何指标、碰撞/价态统计和不确定度、可视化/表格、统计不确定度和分层结果。

- 本任务关注结合快速对接与学习式结合预测，对超大化合物库进行分层虚拟筛选、口袋定位、姿态几何、排序可靠性和化学有效性以及富集因子的可复核评估。
- 因果机制、实验功能、临床疗效/安全性或其他超出输入和验证证据的结论不属于默认交付，除非补充方案获得确认。

## 执行前确认事项

- 输入格式、版本、样本/实体完整性和实验结合姿态、口袋中心、亲和力或姿态成功标签是否足以支撑任务。

## 必要结果项

- **结构结果**：受体/配体标准化记录、口袋坐标、质子化和立体化学检查报告；同时说明输入清洗、版本和任何变更。
- **参考标签结果**：实验姿态、亲和力、口袋注释和数据集切分规则的来源与覆盖范围；标注缺失、噪声、类别不平衡和不可用于正式验收的部分。
- **模型结果**：模型/权重版本、独立姿态成功率/排序指标、校准和失败构象审查；明确模型适用的实体、序列/结构/模态范围和不能外推的边界。
- **动力学结果**：候选姿态、打分、口袋置信度、接触图和推理日志；保留全量候选或逐样本输出、失败原因、随机种子/条件和版本记录。
- **性质结果**：RMSD/Top-k/富集或物理几何指标、碰撞/价态统计和不确定度；每个指标给出定义、单位或量纲、样本范围、分析窗口和置信区间。
- **结论结果**：一份将观察结果、独立证据、模型误差、采样/标签不确定度、偏差和无法回答的问题分开的科学结论报告。
