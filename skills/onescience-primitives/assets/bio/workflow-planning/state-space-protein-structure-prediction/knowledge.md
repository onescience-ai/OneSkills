# 蛋白质构象状态空间预测

## 适用范围

当蛋白质的生物学功能依赖于构象异质性——包括但不限于变构信号传递、配体诱导的构象选择与诱导契合、折叠-去折叠切换、低占位功能激发态、环境响应性重排——时，单一结构坐标模型无法充分描述其功能状态。本流程将蛋白质结构预测重新表述为状态空间推断问题，核心目标是恢复可访问的构象状态集合、它们之间的能量与动力学关系、对生物学背景条件的依赖性以及对序列或环境扰动的响应。

该流程适用于以下典型任务场景：
- 需要推断蛋白质在不同条件（配体结合、pH变化、翻译后修饰、膜环境）下可访问的构象集合及其相对群体
- 需要构建完整的构象能量景观，包括状态间的自由能差异和转换路径
- 需要预测突变或环境变化如何重塑构象群体分布
- 实验已揭示显著的构象异质性（如NMR、cryo-EM分类、SAXS、DEER），需要计算层面的系统性表征

若蛋白质功能由单一刚性结构主导且构象波动可忽略，传统单结构预测方法更为高效，无需启用本流程。

## 输入

**必需输入：**
- **蛋白质序列**（氨基酸字符串）：作为构象生成的起始输入，决定了序列编码的构象空间基本拓扑
- **任务需求声明**：明确需要推断的是完整的状态空间描述（而非单一结构），并说明目标生物学背景

**条件输入：**
- **生物学背景条件**：如配体种类与浓度、pH值、离子强度、翻译后修饰位点、结合伙伴、膜环境、氧化还原状态等。这些条件对构象景观具有显著重塑作用，是状态空间推断的关键条件化信号
- **实验约束数据**（可选但强烈建议）：如DEER距离分布、交联质谱约束、NMR化学位移/J-耦合、SAXS散射曲线等，可用于引导采样或验证预测

## 输出

- **构象状态空间模型**：包含可访问构象状态的坐标集合、各状态的相对群体（占有率）、状态间的连接途径（转换路径与能垒估计）、背景条件依赖性以及对序列突变或环境变化的响应预测
- **构象能量景观**：以自由能面或自由能景观图的形式呈现，包括各能量盆地的深度（稳定性）、盆地间的鞍点（转换态）和群体分布
- **状态群体分布**：各构象状态在给定条件下的热力学或动力学群体估计，可直接用于与实验群体测量值的比较
- **扰动响应预测**：突变或环境变化对构象群体重新分配的预测结果

## 流程节点

整体流程由三个阶段构成迭代框架：深度学习提出候选构象，物理方法估计其能量组织，实验数据确立其生物学相关性。

### s1：识别与生成候选构象

**步骤描述**：首先评估任务是否确实需要状态空间描述（而非单一结构预测）。当确认需要后，使用深度学习方法生成蛋白质在给定序列和生物学背景下可能访问的替代构象集合。

**构象生成的典型技术路线**（综合推断，非单一素材直证）：
- **MSA扰动**：通过对多序列比对的系统性扰动，探索序列信息中的构象多样性信号
- **随机采样**：在深度学习模型的潜在空间或输出空间中进行随机采样，生成构象多样性集合
- **生成式模型**（如BioEmu）：直接近似平衡分布的生成式深度学习方法，能够从序列出发高效采样构象集合
- **集成方法**：运行多次预测以捕捉模型不确定性所映射的构象变异性

**输入**：
| 参数 | 类型 | 是否必需 | 说明 |
|------|------|----------|------|
| sequence | str | 是 | 蛋白质氨基酸序列 |
| context | str | 否 | 生物学背景条件（配体、pH、离子环境、修饰等） |

**输出**：一组几何合理的候选构象坐标模型，应覆盖潜在的构象空间

**质量门**：生成的构象在几何上合理（无原子碰撞、键长键角在物理允许范围内），且覆盖了序列可能编码的构象空间的主要区域。若仅生成高度相似的构象集合，需检查生成方法的多样性是否充分

**上游依赖**：无（流程起点）

### s2：能量建模与景观重构

**步骤描述**：对候选构象集合进行物理能量评估，估计各构象状态的相对稳定性、自由能差和群体分布，并刻画状态间的转换路径。

**典型技术路线**：
- **经典分子动力学模拟**：对候选构象进行短时或长时MD模拟，评估其局部稳定性和动态行为
- **增强采样方法**：如副本交换（REMD）、元动力学（metadynamics）、自适应偏置力（ABF）等，加速构象间转换的采样
- **自由能计算**：估计不同构象状态之间的自由能差和自由能景观，提供热力学群体预测
- **深度学习能量近似**：如BioEmu等方法尝试直接近似平衡分布，可视为对物理能量模型的快速替代或补充

**输入**：
| 参数 | 类型 | 是否必需 | 说明 |
|------|------|----------|------|
| candidate_conformations | list | 是 | 步骤s1生成的候选构象集合 |

**输出**：构象景观的能量信息，包括各状态的相对群体、自由能差、转换能垒和连接路径

**质量门**：能量估计与可获得的实验数据（如热稳定性、DSC测量）或已知物理原理一致。若能量排名与实验群体显著矛盾，需回溯检查候选构象的覆盖度或能量计算的收敛性

**上游依赖**：s1

### s3：实验约束整合与验证

**步骤描述**：整合实验数据对计算预测进行约束和验证。实验在此框架中承担双重角色：一是作为约束条件指导构象采样和模型选择，二是作为验证标准评估预测的构象景观的生物学相关性。

**典型实验约束类型**：
- **DEER（双电子-电子共振）光谱**：提供残基间距离分布，可直接约束构象集合的几何分布。专用工具（如DEERFold）将距离分布直接集成到神经网络中，引导采样走向与实验一致的构象
- **交联质谱（XL-MS）**：提供残基间最大距离约束，特别适用于多聚体组装界面的识别和构象约束。专用工具（如AlphaLink2）利用交联约束改善预测，尤其在MSA进化信号弱或缺失时效果显著
- **NMR数据**：化学位移、J-耦合、残余偶极耦合等提供原子分辨率的构象约束
- **HDX-MS（氢氘交换质谱）**：反映残基水平的溶剂可及性和动态性
- **SAXS（小角X射线散射）**：提供整体形状和尺寸信息
- **cryo-EM分类**：从单颗粒分析中提取的构象分类可直接验证预测的状态集合

**输入**：
| 参数 | 类型 | 是否必需 | 说明 |
|------|------|----------|------|
| predicted_landscape | object | 是 | 步骤s2生成的预测构象景观 |
| experimental_restraints | list | 否 | DEER距离分布、交联质谱等实验约束 |

**输出**：经实验验证或约束的构象状态空间模型

**质量门**：预测的群体分布或状态组成与实验测量结果定量一致。若存在显著偏差，需迭代改进生成和能量模型

**上游依赖**：s2

## 边界与分流

**本流程适用的典型情形：**
- 蛋白质功能明确依赖于构象异质性（变构、动态切换、多态折叠）
- 实验数据已暗示显著的构象多样性（如cryo-EM显示多个类、NMR显示宽泛的化学位移分布）
- 需要理解突变或配体如何重塑构象群体

**应改用其他方案的情形：**
- **单一刚性结构预测**：若目标蛋白是小型、刚性、构象波动可忽略的蛋白域，AlphaFold2/ESMFold等单结构预测方法的效率和准确度更高
- **蛋白质复合物组装预测**：若核心问题在于复合物的化学计量和组装路径而非单体构象多样性，应优先使用AlphaFold3等对接/组装专用方法
- **快速动力学过程表征**：当目标蛋白的功能依赖于皮秒-纳秒时间尺度的快速动力学过程时，状态空间推断（通常基于离散状态模型）可能不足以捕捉连续动力学特征，此时增强采样MD和Markov状态模型可能是更合适的选择
- **纯从头设计任务**：当目标是设计全新序列以实现特定构象而非表征已有序列的构象空间时，应使用蛋白质设计专用流程

**与上下游资产的衔接：**
- 上游：可对接AlphaFold2/ESMFold生成的初始结构作为候选构象的起点或参考
- 下游：构象景观输出可直接用于变构机制分析、药物靶点评估、突变效应预测等下游任务
- 可替换方案：当深度学习生成方法不可用时，可退化为纯物理模拟路线（以同源结构或NMR约束起始的MD模拟），但计算成本显著增加

## 质量检查

构象状态空间预测的质量需从多个维度系统评估：

**构象覆盖度评估：**
- 候选构象集合是否覆盖了已知的或预期的构象空间区域
- 可通过构象聚类分析（如RMSD矩阵聚类）和降维可视化（如t-SNE、PCA）评估采样的多样性
- 与实验结构（如PDB中同一蛋白的不同构象）的比较可提供参考覆盖度

**能量景观一致性：**
- 热力学群体分布是否与实验测量值（如NMR群体、HDX保护因子）定性一致
- 状态间自由能差是否在物理合理范围内（通常亚稳态与基态间差异在1-5 kcal/mol量级，具体需根据体系判断）
- 能量景观的拓扑结构（盆地数量、深度、连接性）是否合理

**实验约束满足度：**
- DEER距离分布预测是否与实验观测重叠良好
- 交联质谱约束是否被满足
- SAXS曲线拟合质量
- cryo-EM分类结果是否与预测的状态集合对应

**几何与物理合理性：**
- 各构象状态的键长、键角、二面角是否在物理允许范围内
- 无严重原子碰撞或不合理接触
- 溶剂可及性和二级结构内容是否合理

**收敛性评估（针对MD模拟）：**
- 增强采样模拟的收敛性检查（如自由能估计的统计误差、不同运行间的一致性）
- 群体估计的自相关分析

## 回退策略

基于该方法的已知失效模式，提供以下分层回退路径：

**当深度学习生成的构象多样性不足时：**
- 检查MSA质量（序列深度、一致性分布），若MSA过浅或过深可能限制构象探索
- 尝试不同的随机种子或采样温度以增加多样性
- 回退到物理模拟路线：使用多个起始构象进行独立MD模拟

**当预测模型对突变或环境变化响应不足时：**
- 这是当前深度学习方法的已知局限：训练数据（主要来自PDB）偏向稳定构象，可能导致模型对替代状态的预测偏差，以及对扰动产生非物理的鲁棒性
- 应增加物理模拟步骤的权重，通过显式的自由能计算来评估突变效应
- 引入实验约束数据（DEER、交联质谱等）以纠正模型偏差

**当基于MSA的预测收敛到同源蛋白的相似构象时：**
- 这在同源预测中是已知问题：即使目标蛋白存在独特的构象状态，基于MSA的先验可能将其拉向同源蛋白的已知构象
- 应降低MSA依赖，增加随机采样或生成式模型的权重
- 整合目标蛋白特有的实验约束以引导采样

**当组件集成的计算成本过高时：**
- 深度学习与物理模拟的耦合校准困难，可采用分层策略：先用快速的深度学习方法生成候选构象集合，再选择最有代表性的子集进行精细的能量计算
- 降低MD模拟的时间尺度要求，聚焦于候选构象间的相对稳定性比较而非完整动力学

**当实验约束数据覆盖率低或质量不足时：**
