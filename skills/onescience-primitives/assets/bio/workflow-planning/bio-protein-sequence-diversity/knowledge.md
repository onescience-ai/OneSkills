# 蛋白序列多样性评估

## 适用范围
适用于蛋白设计任务中生成候选序列的多样性评估，特别是需要评估序列多样性、去冗余和聚类分析的场景。包括：
- 需要评估生成候选序列的多样性
- 需要去除冗余序列以获得多样化候选集
- 需要进行序列聚类分析
- 不适用于仅评估单个序列质量或结构有效性的场景

## 输入
- **序列集合**：生成的多个蛋白序列（FASTA格式或列表）
- **去冗余阈值**：序列同一性百分比阈值（如30%、50%、70%）
- **评估指标**：需要计算的多样性指标类型

## 输出
- **序列同一性矩阵**：两两序列同一性百分比矩阵
- **聚类结果**：按相似度聚类的序列分组
- **去冗余统计**：原始数量、去冗余后数量、冗余率
- **多样性评分**：综合多样性指标（如平均同一性、聚类数等）

## 流程节点
1. **序列对齐** → 计算两两序列比对（Needleman-Wunsch或Smith-Waterman）
2. **同一性计算** → 计算序列同一性百分比
3. **矩阵构建** → 构建序列同一性矩阵
4. **聚类分析** → 使用层次聚类或DBSCAN进行聚类
5. **去冗余** → 按阈值去除冗余序列
6. **报告生成** → 汇总多样性指标和聚类结果

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 序列同一性阈值 | 30%/50%/70% | [UniProt标准] | 常用的去冗余阈值 |
| 打分矩阵 | BLOSUM62 | [序列分析标准] | 蛋白序列比对的标准打分矩阵 |
| 聚类方法 | 层次聚类 | [生物信息学标准] | 常用的序列聚类方法 |
| 最小聚类大小 | 2 | [多样性评估] | 避免单序列聚类 |

## 边界与分流
- **序列长度差异大时**：使用局部比对而非全局比对
- **序列数量过多时**：采样后计算或使用近似算法
- **需要结构多样性时**：补充TM-score计算（如结构可用）
- **去冗余过度时**：调整阈值或保留代表性序列

## 质量检查
- 序列同一性矩阵应为对称矩阵，对角线为100%
- 去冗余后应保留足够的多样性（如至少30%的原始序列）
- 聚类结果应有明确的聚类边界
- 多样性评分应有明确的解释（如"高多样性"、"中等多样性"、"低多样性"）

## 回退策略
- 序列比对不可用时，使用k-mer频率作为相似性度量
- 聚类算法不可用时，使用简单的阈值过滤
- 需要结构多样性但结构不可用时，记录为"仅序列多样性评估"
