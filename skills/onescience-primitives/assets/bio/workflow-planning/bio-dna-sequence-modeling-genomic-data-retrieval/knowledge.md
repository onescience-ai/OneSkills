# DNA序列建模任务基因组数据获取与预处理

## 适用范围

面向DNA序列建模任务，获取公开基因组DNA序列数据的路径与格式规范；覆盖ENCODE、UCSC、GenBank等数据库，以及DNALONGBENCH等基准数据集；适用于基因组功能预测、变异效应预测、基因表达预测等任务。

## 输入

- 目标基因组参考版本（hg38、hg19等）
- 任务类型（基因组功能预测、变异效应预测、基因表达预测等）
- 数据规模需求（训练集、测试集大小）
- 输入格式要求（FASTA、BED、VCF等）

## 输出

- 基因组序列数据文件
- 功能标签数据文件
- 数据划分信息（训练/验证/测试）
- 数据统计信息

## 流程节点

1. **数据源识别** → 2. **数据下载** → 3. **格式转换** → 4. **数据验证** → 5. **数据划分**

### 步骤1：数据源识别
- 操作：根据任务需求识别合适的数据源
- 参数：任务类型、基因组版本、数据规模
- 工具：文献调研、数据库搜索
- 质量门禁：找到至少一个权威数据源

### 步骤2：数据下载
- 操作：从权威数据库下载基因组序列和功能标签
- 参数：下载地址、文件格式、文件大小
- 工具：wget、curl、huggingface-cli
- 质量门禁：文件完整，大小与预期相符

### 步骤3：格式转换
- 操作：将下载的数据转换为任务所需的格式
- 参数：输入格式、输出格式、转换规则
- 工具：bedtools、samtools、自定义脚本
- 质量门禁：格式转换成功，数据完整性保持

### 步骤4：数据验证
- 操作：验证数据完整性和正确性
- 参数：数据文件路径、验证规则
- 工具：自定义验证脚本、数据质量检查
- 质量门禁：数据验证通过，无缺失或异常

### 步骤5：数据划分
- 操作：按任务要求划分训练/验证/测试集
- 参数：划分比例、随机种子、划分策略
- 工具：自定义划分脚本
- 质量门禁：划分后数据集大小符合预期，无数据泄露

## 边界与分流

- **数据不可用时**：寻找替代数据源或使用合成数据
- **格式不兼容时**：进行格式转换或调整任务需求
- **下载失败时**：尝试镜像站点或联系维护者
- **数据量不足时**：使用数据增强或迁移学习

## 质量检查

- 验证数据文件可正常加载
- 检查数据格式与任务需求匹配
- 验证数据标签与序列一一对应
- 检查数据划分无重叠

## 回退策略

- 数据不可用时：使用合成数据或迁移学习
- 下载失败时：使用本地已有的数据或寻找替代来源
- 格式不兼容时：进行格式转换或调整任务需求
