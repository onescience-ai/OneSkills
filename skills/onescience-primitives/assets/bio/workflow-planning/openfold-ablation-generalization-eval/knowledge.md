# OpenFold组件消融与结构泛化评测（B02）

## 适用范围

**适用场景**：
- 输入是可解析的蛋白序列、结构或明确的复合物实体，且目标是结构预测、精修、状态建模或质量评估。
- 有独立参考结构、可信基准或可说明的无标签质量检查，能够区分模型置信度和真实准确度。
- 目标长度、实体类型和构象范围处于所选模型的已验证适用域内，或允许补充验证。
- 结果将用于结构注释、机制假设、实验前筛选或候选排序，而不是直接替代实验确认。

**不适用场景**：
- 任务核心是电子结构、反应动力学、非蛋白大分子或模型没有训练覆盖的化学实体。
- 输入缺少序列/实体身份，或参考标签和质量证据不足以判断预测是否可信。
- 需要把单次预测当作临床诊断、药效或确定性机制证明，而没有独立实验验证。
- 目标构象、长度或复合物组成明显超出模型和验证数据，且不允许重新设计评估。

## 研究对象与输入

**研究对象**：蛋白质序列、复合物实体或构象集合

| 输入项 | 说明 |
|---|---|
| 输入文件 | CAMEO_targets.fasta |
| 输入模态 | FASTA、PDB/mmCIF或复合物描述文件 |
| 样本单元 | 一条序列、一个复合物或一个构象集合 |
| 标签/条件 | 实验结构、链界面、构象状态或置信度参考（如有） |
| 模型引用 | finetuning_ptm_2.pt |

**初始结构**：默认输入名称为“CAMEO_targets.fasta”；执行者必须核验格式、版本、实体/样本完整性、缺失值和可解析性，并记录实际使用的相对名称或数据标识。

**表面/硬约束**：保持输入序列、链组成、配体身份、残基编号和任务模式；不得静默删链、改残基或把低置信区域当作已证实结构。

**划分策略**：按序列同源性、长度、复合物实体和未见折叠划分评估边界，并记录模板或数据库版本；同源泄漏不得冒充泛化证据。

**采样要求**：默认至少保留 5 个可追溯候选或一个完整构象集合，并报告候选间差异、置信度和失败样本。

## 核心科学问题

1. 在蛋白质序列、复合物实体或构象集合和输入“CAMEO_targets.fasta”上，复现并消融OpenFold特征、回收和损失组件，比较其在未见折叠上的结构泛化能力能否得到可复核的TM-score结果，并满足任务的硬约束？
2. 输入中的链组成、折叠拓扑、界面几何和置信度如何影响OpenFold组件消融与结构泛化评测的输出，哪些样本、区域或候选最容易失败？
3. 模型在独立样本、未见家族/条件或困难子集上的表现是否稳定，误差和不确定度如何量化？
4. 结果是否具有足够的生物学、化学或临床证据支持后续决策，哪些部分只能作为探索性线索？
5. 在当前数据、模型和资源边界下，哪些结论可以签收，哪些结论必须标记为无法回答或需要额外验证？

## 比较与评估

- 主任务：复现并消融OpenFold特征、回收和损失组件，比较其在未见折叠上的结构泛化能力；核心指标：TM-score。
- 目录模型候选为OpenFold，需与可解释基线、参考标签或独立质量检查比较。
- 至少与一个可解释基线、实验结构或独立质量指标比较。
- 分别报告已见同源、未见同源和低置信/困难样本的表现。

## 工作流

### 步骤 1：输入与任务定义

**目的**：校验OpenFold组件消融与结构泛化评测所需的序列、链组成和任务设置。

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 序列或结构输入 | `{INPUT_DATA}` | doc | 是 | `CAMEO_targets.fasta` | 输入FASTA或结构文件 |
| 结构模型 | `{MODEL_NAME}` | enum | 是 | `OpenFold` | 可选值：`OpenFold` |
| 链处理模式 | `{CHAIN_MODE}` | enum | 否 | `auto` | 可选值：`auto`、`monomer`、`complex` |

**输出**：标准化输入、实体清单、任务配置

**质量门禁**：
- 输入可被解析
- 链标识唯一
- 模型支持输入实体

**操作指令**：`读取{INPUT_DATA}，检查实体、序列和链标识，使用{MODEL_NAME}并按{CHAIN_MODE}建立OpenFold组件消融与结构泛化评测任务。`

### 步骤 2：特征与模型准备

**目的**：准备模型权重、序列比对和结构模板特征。

**依赖步骤**：s01

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 模型权重 | `{CHECKPOINT}` | doc | 是 | `finetuning_ptm_2.pt` | — | 模型权重名称 |
| MSA模式 | `{MSA_MODE}` | enum | 否 | `precomputed` | — | 可选值：`precomputed`、`database_search`、`single_sequence` |
| 模板上限 | `{MAX_TEMPLATES}` | int | 否 | `4` | 0–20 | 限制结构模板数量 |

**输出**：模型加载记录、序列特征、模板特征

**质量门禁**：
- 权重版本可追溯
- 特征长度一致
- 模板数量不超限

**操作指令**：`加载{CHECKPOINT}，按{MSA_MODE}准备序列特征并最多保留{MAX_TEMPLATES}个模板。`

### 步骤 3：结构推理与采样

**目的**：运行结构推理并生成可复现的候选集合。

**依赖步骤**：s02

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 候选数量 | `{NUM_SAMPLES}` | int | 是 | `5` | 1–100 | 设置候选结构数量 |
| 回收次数 | `{NUM_RECYCLES}` | int | 否 | `10` | 1–50 | 设置模型回收次数 |
| 随机种子 | `{SEED}` | int | 否 | `2026` | 0–2147483647 | 固定随机采样结果 |

**输出**：结构候选、原始置信度、推理日志

**质量门禁**：
- 候选数量达标
- 坐标无NaN或Inf
- 实体数量与输入一致

**操作指令**：`执行OpenFold组件消融与结构泛化评测，回收{NUM_RECYCLES}次并以种子{SEED}生成{NUM_SAMPLES}个结构候选。`

### 步骤 4：结构质控与汇总

**目的**：按TM-score及几何完整性筛选并汇总结果。

**依赖步骤**：s03

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|---|---|
| 质量阈值 | `{QUALITY_THRESHOLD}` | float | 否 | `0.7` | 0–1 | 设置候选质量下限 |
| 结构格式 | `{OUTPUT_FORMAT}` | enum | 否 | `mmCIF` | — | 可选值：`mmCIF`、`PDB` |

**输出**：排序结构、TM-score汇总表、结构质控报告

**质量门禁**：
- 结构文件可解析
- 低质量候选已标记
- 结果可追溯到参数

**操作指令**：`计算TM-score，用{QUALITY_THRESHOLD}标记低质量候选，并按{OUTPUT_FORMAT}导出排序结构。`

## 验收标准与质量门禁

### 硬约束（不可违反）

- 保持输入序列、链组成、配体身份、残基编号和任务模式；不得静默删链、改残基或把低置信区域当作已证实结构。
- 输入、标签、模型版本、数据划分和实际输出之间的血缘必须可追溯；任何偏离都要记录并经场景确认。
- 不得把平均分数、单个高分样本或模型自评当作生物学、化学或临床事实；正式结论必须有独立证据。
- 历史论文、参考模型和示例文件只能用于方案设计或交叉检查，不能冒充本次任务的新结果。

### 最低证据要求

- 实际研究对象、输入、模型/权重、工具和场景约束与任务书一致，所有偏离均有变更记录。
- 输入、标签/参考数据、版本、筛选规则和训练/评估划分可追溯，泄漏和缺失处理有证据。
- 模型或推理结果有独立于选择过程的TM-score评估、分层统计、最差案例和适用域说明。
- 全量结果、失败样本、异常、拒答或低质量标记均被保存；正式分析只使用质量合格的范围。
- 每个目标结果都有定义、单位/量纲（如适用）、样本量、分析窗口、置信区间或不确定度。
- 比较基线、参考标签或人工复核的口径一致，不能只报告对模型有利的子集。
- 结论明确区分观察、模型误差、标签/采样不确定度、偏差和未验证假设。
- 输出文件、环境、日志、版本和校验信息足以让第三方复核关键数值。

**验收判定**：执行者必须对每个交付项给出 PASS、PARTIAL、REJECT 或 BLOCKED，并附文件、日志、图表或数值证据；没有证据的‘运行正常’或‘效果良好’不能作为签收依据。

## 边界与限制

**本工作流关注**：
- 本任务关注复现并消融OpenFold特征、回收和损失组件，比较其在未见折叠上的结构泛化能力、链组成、折叠拓扑、界面几何和置信度以及TM-score的可复核评估。
- 因果机制、实验功能、临床疗效/安全性或其他超出输入和验证证据的结论不属于默认交付，除非补充方案获得确认。

- 输入格式、版本、样本/实体完整性和实验结构、链界面、构象状态或置信度参考（如有）是否足以支撑任务。

## 必要结果项

- **结构结果**：标准化的序列/实体清单、预测结构或构象集合，以及链和几何完整性报告；同时说明输入清洗、版本和任何变更。
- **参考标签结果**：可用实验结构、基准标签或独立参考集合的来源、覆盖范围和缺失说明；标注缺失、噪声、类别不平衡和不可用于正式验收的部分。
- **模型结果**：模型与权重版本、推理设置、置信度校准、独立结构指标和最差案例分析；明确模型适用的实体、序列/结构/模态范围和不能外推的边界。
- **动力学结果**：候选结构、界面/状态分数、置信度分布和可复核的推理日志；保留全量候选或逐样本输出、失败原因、随机种子/条件和版本记录。
- **性质结果**：围绕结构质量、界面质量、构象覆盖或场景指标的逐样本数据和统计不确定度；每个指标给出定义、单位或量纲、样本范围、分析窗口和置信区间。
- **结论结果**：一份将观察结果、独立证据、模型误差、采样/标签不确定度、偏差和无法回答的问题分开的科学结论报告。
