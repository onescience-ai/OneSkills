# DNA序列建模任务评估指标与结果导出

## 适用范围

面向DNA序列建模任务，定义评估指标与结果导出格式；覆盖平均精度(AUPRC)标准定义、区间/碱基/变异层结果导出、参考与替代等位基因区分；适用于基因组功能预测、变异效应预测、基因表达预测等任务。

## 输入

- 模型预测结果（概率分数）
- 真实标签（二分类或多分类）
- 基因组坐标信息（染色体、位置）
- 等位基因信息（参考、替代）

## 输出

- 评估指标报告（AUPRC、AUC、准确率等）
- 区间级结果文件（BED格式）
- 碱基层结果文件（tabular格式）
- 变异级结果文件（VCF格式）

## 流程节点

1. **指标定义** → 2. **预测结果处理** → 3. **指标计算** → 4. **结果导出** → 5. **报告生成**

### 步骤1：指标定义
- 操作：定义任务所需的评估指标
- 参数：任务类型、指标选择、阈值设定
- 工具：sklearn文档、文献调研
- 质量门禁：指标定义符合任务需求

### 步骤2：预测结果处理
- 操作：处理模型预测结果，准备评估输入
- 参数：预测概率、真实标签、样本权重
- 工具：自定义处理脚本
- 质量门禁：预测结果格式正确，无缺失值

### 步骤3：指标计算
- 操作：计算评估指标
- 参数：预测结果、真实标签、指标函数
- 工具：sklearn.metrics.average_precision_score
- 质量门禁：指标计算正确，结果可复现

### 步骤4：结果导出
- 操作：将评估结果导出为标准格式
- 参数：结果数据、输出格式、文件路径
- 工具：自定义导出脚本
- 质量门禁：导出文件格式正确，数据完整

### 步骤5：报告生成
- 操作：生成评估报告
- 参数：评估指标、结果文件、统计信息
- 工具：报告生成脚本
- 质量门禁：报告内容完整，格式规范

| 参数 | 判据 | 来源 | 说明 |

## 边界与分流

- **指标不适用时**：选择替代指标或调整任务定义
- **结果格式不兼容时**：进行格式转换或调整导出逻辑
- **数据不平衡时**：使用加权指标或采样策略
- **计算资源不足时**：使用采样评估或分布式计算

## 质量检查

- 验证指标计算正确
- 检查结果文件格式正确
- 验证数据完整性
- 检查报告内容完整

## 回退策略

- 指标不适用时：选择替代指标
- 结果格式不兼容时：进行格式转换
- 计算资源不足时：使用采样评估
