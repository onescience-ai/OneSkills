# AlphaFold蛋白质结构预测系统

## 适用范围
用于解决蛋白质结构预测的核心问题：仅从氨基酸序列信息预测其天然折叠的三维原子结构。AlphaFold是一个端到端的深度学习系统，专门设计用于此任务，其核心优势在于能够整合序列的进化信息（通过多序列比对）来推断三维空间约束。该方法适用于大多数具有可检测同源序列的单链蛋白质预测。对于已知高相似度实验结构模板的蛋白质，传统同源建模可能更高效；而对于进化信息极其匮乏的孤儿蛋白，预测准确性可能受限。

## 输入
- 必需：蛋白质的氨基酸序列（FASTA格式字符串）。
- 可选：多序列比对文件（MSA，如A3M格式）。若未提供，系统通常会自动运行序列搜索程序从数据库中生成。
- 可选：模板结构信息（来自PDB数据库的同源结构）。系统会搜索已知结构作为参考，但现代版本在缺乏模板时仍能表现良好。

## 输出
- 三维原子坐标：预测的蛋白质结构，通常以PDB或mmCIF格式保存。
- 置信度分数：
  - pLDDT：每个残基的预测局部距离差异测试分数，范围0-100，分数越高表示该残基区域的预测置信度越高。通常pLDDT > 70被认为是可信区域。
  - pTM：预测的全局模板建模分数，范围0-1，用于评估整体拓扑预测的质量。
- 可视化图像：生成的结构图像（如卡通表示、置信度着色图）。

## 流程节点
AlphaFold的工作流程可以分解为以下四个核心步骤，它们构成一个有向无环图（DAG）。

1.  **MSA构建**
    *   **步骤名**：MSA构建
    *   **上游依赖**：无（起始步骤）
    *   **输入**：`query_sequence`（必需，蛋白质氨基酸序列）。
    *   **输出**：MSA文件。
    *   **质量门**：MSA深度足够。实践中，通常要求MSA的序列数中位数大于30，以确保有足够的进化信号。
    *   **描述**：使用序列搜索工具（如jackhmmer, nhmmer）在大型蛋白质序列数据库（如BFD、UniRef）中搜索与查询序列同源的序列，并对齐生成多序列比对。这一步提取了蛋白质在进化过程中保守和变异的信息，是后续预测的关键输入。

2.  **Evoformer处理**
    *   **步骤名**：Evoformer处理
    *   **上游依赖**：`s1` (MSA构建)
    *   **输入**：来自步骤1的MSA表示。
    *   **输出**：更新后的MSA表示、成对表示（pair representation）。
    *   **质量门**：表示更新收敛。网络内部通过多轮迭代（模块堆叠）来精炼表示。
    *   **描述**：将MSA输入到Evoformer网络模块中。Evoformer同时处理两种信息表示：MSA表示（关注序列间关系）和成对表示（关注残基间的空间约束关系）。通过多头注意力机制和特定设计的更新规则，Evoformer能够在这两种表示之间交换信息，并捕获远程和局部的共进化模式，从而推断出潜在的三维接触图和距离分布。

3.  **结构预测**
    *   **步骤名**：结构预测
    *   **上游依赖**：`s2` (Evoformer处理)
    *   **输入**：处理后的MSA表示和成对表示。
    *   **输出**：三维原子坐标。
    *   **质量门**：坐标预测满足基本的物理化学约束（如键长、键角合理性）。
    *   **描述**：使用结构模块（Structure Module）将抽象的表示转化为具体的原子坐标。结构模块通常包含一个Invariant Point Attention (IPA)层，它能够在保持SE(3)等变性的同时，根据当前的结构估计和来自Evoformer的特征，迭代地更新每个残基的刚性框架（旋转和平移）和侧链构象。

4.  **迭代优化**
    *   **步骤名**：迭代优化
    *   **上游依赖**：`s3` (结构预测)
    *   **输入**：初始的三维原子坐标。
    *   **输出**：优化后的最终三维结构。
    *   **质量门**：置信度分数（如pLDDT, pTM）稳定。
    *   **描述**：通过多轮迭代（recycling）将结构模块的输出重新馈入网络前端，使Evoformer能够根据最新的结构预测进一步优化其表示。整个系统通常会并行运行多个（如5个）独立的模型（不同随机种子），然后根据预测的置信度分数选择最佳结构作为最终输出。

## 边界与分流
- **高精度同源建模**：如果目标序列与某个已知高分辨率实验结构的序列一致性很高（通常>50%），则基于模板的传统同源建模方法（如SWISS-MODEL, Modeller）可能速度更快、结构细节更可靠，此时AlphaFold可作为验证或提供无偏预测的补充。
- **蛋白质复合物预测**：AlphaFold最初针对单链蛋白质设计。对于蛋白质-蛋白质相互作用复合物，需使用其专门的复合物预测模式（如AlphaFold-Multimer）或结合其他对接工具。
- **动态构象预测**：AlphaFold预测的是静态的、接近天然态的单一结构。如果需要研究蛋白质的构象变化、折叠路径或构象系综，则需要分子动力学模拟或专门的增强采样方法。
- **实验数据整合**：当有部分实验数据（如小角X射线散射数据、交联质谱数据、NMR约束）时，可使用这些数据对AlphaFold预测结构进行筛选、排序或作为约束进行分子动力学精修，而非完全依赖纯序列预测。

## 质量检查
预测结果的可靠性评估至关重要，主要依据系统输出的置信度指标：
1.  **检查pLDDT分布**：在可视化工具（如PyMOL, ChimeraX）中加载PDB文件并按pLDDT值着色。理想情况下，核心折叠区域应显示为蓝色（pLDDT > 90）或浅蓝色（pLDDT 70-90）。无序区域或预测不确定的环区通常呈黄色或橙色（pLDDT < 70）。
2.  **评估pTM分数**：全局pTM分数 > 0.8 通常表示整体拓扑预测良好。
3.  **目视检查**：观察预测结构是否满足基本的蛋白质结构原则，如无严重的原子冲突、氢键网络合理、二级结构元素（α螺旋、β折叠）形成完整。
4.  **多模型一致性**：运行多个模型后，比较它们生成的结构。如果多个模型在大部分区域给出非常相似的构象（RMSD小），则结果更可信。若模型间差异大，则表明预测不确定性高。

## 回退策略
- **MSA深度严重不足**：如果构建的MSA深度很浅（中位数序列数远小于30，甚至为1），表明进化信息匮乏。此时应：
  - 检查输入序列是否正确，尝试使用更敏感的搜索策略或不同的数据库。
  - 如果确实为孤儿蛋白，可考虑使用专门针对无同源序列设计的蛋白质结构预测方法（如RoseTTAFold的某些模式），但需知晓这类方法的准确性通常也会下降。
  - 将预测结果视为初步的、低保真的结构假设，需通过后续实验验证。
- **蛋白质尺寸过大**：当序列长度超过数千个残基时，计算资源和内存需求激增。可尝试：
  - 使用支持更长序列但可能牺牲部分精度的计算模式或软件版本。
  - 将大蛋白质拆分成多个结构域或片段，分别预测后尝试组装（需专业知识和后续验证）。
  - 优先使用云计算资源或高性能计算集群。
- **预测结构置信度低**：如果pLDDT普遍较低且pTM<0.5，表明网络对该序列缺乏信心。此时不应将预测结构视为可靠模型，而应将其作为生成假设的起点，结合其他生物信息学分析（如保守性分析、结构域预测），或转向实验结构测定。

## 资源召回建议
- **官方代码与模型**：AlphaFold的开源实现和预训练模型权重由DeepMind公开发布，是运行预测的核心资源。
- **数据库**：
  - 序列数据库：BFD（Big Fantastic Database）、UniRef、MGnify等，用于生成MSA。
  - 结构数据库：PDB（Protein Data Bank），用于搜索模板和评估预测准确性（如lDDT）。
- **辅助工具**：用于MSA生成的序列搜索程序（如HH-suite, jackhmmer）、用于结构可视化的软件（PyMOL, ChimeraX, UCSF Chimera）、用于结构比较和验证的工具（如Superpose, ERRAT, PROCHECK）。
- **相关方法**：可了解与之相关的神经网络模块（如Evoformer）的通用原理，以及其他蛋白质结构预测工具（如RoseTTAFold, ESMFold）作为补充或对比方案。
