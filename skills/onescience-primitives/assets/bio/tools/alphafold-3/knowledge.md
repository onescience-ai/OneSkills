# AlphaFold 3 结构预测模型

## 适用范围

面向生物分子复合物三维结构预测，AlphaFold 3 适用于以下任务类型：

- **蛋白质-配体复合物**：预测小分子抑制剂或药物先导化合物与目标蛋白的结合构象，用于虚拟筛选、结合模式分析和先导优化。典型场景包括激酶抑制剂设计、蛋白酶底物识别研究等。
- **蛋白质-核酸复合物**：预测转录因子-DNA、核糖体-RNA、CRISPR 复合物等蛋白-核酸相互作用的三维结构。
- **多蛋白质复合物**：预测蛋白质寡聚体、蛋白酶体复合物等多亚基组装体的结构。
- **含修饰残基的复合物**：支持磷酸化（SEP、TPO、PTR 等）、糖基化等翻译后修饰残基的结构建模。
- **含离子和辅因子的复合物**：金属离子结合位点、辅酶/辅因子结合构象的预测。

该工具适合在缺乏实验结构（如 X 射线晶体学、冷冻电镜）的情况下，为复合物提供高精度的结构假设。当需要从序列和化学信息出发快速获得原子级三维模型时，它是当前首选方案之一。

以下情形**不建议**直接使用：
- 仅需单链蛋白质折叠（AlphaFold-Multimer v2.3 或 AlphaFold 单链模型即可胜任）。
- 需要表征溶液中的构象动力学和构象系综（AlphaFold 3 输出静态结构）。
- 需要预测共价修饰后的过渡态或反应路径。
- 商业用途场景（当前服务器仅限非商业使用）。

## 输入

AlphaFold 3 的输入由三类信息组成：

### 必需输入

| 输入类别 | 格式要求 | 说明 |
|---------|---------|------|
| 蛋白质序列 | 单字母氨基酸序列（FASTA 或纯文本） | 每条蛋白链提供一条序列 |
| 核酸序列 | DNA/RNA 碱基序列 | 可选，仅在复合物含核酸时提供 |
| 配体结构 | SMILES 字符串 | 小分子配体的标准化学线性表示 |

### 可选输入

| 输入类别 | 格式要求 | 说明 |
|---------|---------|------|
| 残基修饰信息 | 指定修饰位点和修饰类型 | 如磷酸化位点（残基编号 + 修饰代码） |
| 链间相互作用提示 | 非必需，但可提升精度 | 当已知哪些链之间存在相互作用时可指定 |
| 离子信息 | 指定离子类型和结合位点 | 金属离子（如 Zn²⁺、Mg²⁺）的结合位置 |

### 输入准备注意事项

- SMILES 字符串应确保化学正确性（键级、电荷、立体化学），可通过 RDKit 或 Open Babel 等工具进行预处理和验证。
- 蛋白质序列中的非标准氨基酸应转换为对应的修饰残基代码。
- 链的命名和编号需保持内部一致，避免重复编号导致歧义。

## 输出

AlphaFold 3 输出包含预测的原子坐标结构和多种置信度指标：

### 结构输出

- **PDB 格式文件**：包含所有原子的三维坐标，可直接在 PyMOL、ChimeraX、VMD 等分子可视化软件中打开。
- **mmCIF 格式文件**：适用于大规模数据库存储和下游分析流程。

### 置信度指标

| 指标 | 含义 | 参考范围 |
|------|------|----------|
| **pLDDT** (predicted Local Distance Difference Test) | 每个残基级别的局部结构置信度 | 0–100；>90 表示高置信度，<50 通常为无序区域 |
| **PAE** (Predicted Aligned Error) | 残基对之间的预期对齐误差，反映链间和链内相对位置的可靠性 | 值越低越可靠；<5 Å 通常表示高度可信 |
| **PDE** (Predicted Distance Error) | 原子间距离预测的预期误差 | 值越低表示距离预测越准确 |

### 解读建议

- pLDDT < 50 的区域通常对应固有无序区（IDR），不宜将其预测的结构作为功能性构象依据。
- PAE 矩阵是评估复合物整体拓扑正确性的关键指标，尤其是蛋白-配体和蛋白-核酸界面处。
- 多次预测结果的 pLDDT/PAE 一致性可作为鲁棒性的间接指标。

## 流程节点

AlphaFold 3 的典型使用流程如下：

1. **输入准备**：整理所有参与复合物的分子信息——蛋白质序列、核酸序列、配体 SMILES、修饰位点信息。确保格式正确，化学信息完整。

2. **提交预测任务**：通过 AlphaFold 3 服务器（https://www.alphafoldserver.com）提交预测。根据提示输入各分子的序列和结构信息，指定链的组成和相互作用关系。

3. **模型推理**：服务器端自动执行以下内部流程——
   - 多序列比对（MSA）的生成与处理（AF3 简化了 MSA 处理，使用 pairformer 模块替代 AF2 的 evoformer）。
   - 特征提取与 pairformer 模块计算。
   - 扩散模块直接预测原始原子坐标。

4. **结果下载与初步筛选**：下载预测结构（通常提供多个采样结果），根据 pLDDT、PAE 等指标初步筛选最可靠的预测。

5. **质量评估**：使用结构验证工具检查预测结果的物理合理性（详见质量检查节）。

6. **后续应用**：将高质量预测结构用于分子对接验证、MD 模拟初始构象、药物设计流程或实验设计参考。

## 边界与分流

### 与同类工具的比较边界

| 场景 | 推荐工具 | 说明 |
|------|---------|------|
| 蛋白质-核酸复合物 | **AlphaFold 3**（首选）或 RoseTTAFold2NA | AF3 在 CASP15 RNA 靶标上表现出色 |
| 蛋白质-小分子对接 | **AlphaFold 3** 或 Vina/Gold | AF3 无需口袋预定义信息；传统对接工具需要已知结合口袋 |
| 多蛋白质复合物 | **AlphaFold 3** 或 AlphaFold-Multimer v2.3 | AF3 架构更新，但 Multimer 对纯蛋白复合物仍有成熟经验 |
| 含修饰残基复合物 | **AlphaFold 3** | 支持磷酸化等修饰；其他工具可能不原生支持 |
| 蛋白质单链折叠 | AlphaFold-Multimer v2.3 或 RoseTTAFold All-Atom | AF3 也可用，但单链场景更轻量的模型足够 |

### 上下游衔接

- **上游**：蛋白质结构预测（无复合物需求时可直接用 AlphaFold 单链模型）；小分子构象生成（RDKit、OMEGA 等）。
- **下游**：分子动力学模拟（GROMACS、OpenMM）；结合自由能计算（FEP、MM-PBSA）；虚拟筛选流程（需要高通量时需评估计算成本）。

### 关键限制

- 当前服务器仅限**非商业使用**，商业用途需寻找替代方案或等待授权。
- 模型预测静态结构，无法捕获构象动力学信息——如需构象系综，应将 AF3 预测作为 MD 模拟的初始构象。
- 对于抗体-抗原等高构象多样性靶标，单次预测可能不可靠，需要生成大量预测并通过聚类和打分进行排名。

## 质量检查

预测完成后，建议进行以下质量检查：

### 物理合理性检查

- **立体化学违反检测**：检查手性中心是否正确、原子间是否存在不合理的重叠（clash）。可使用 MolProbity、PoseBusters 等工具进行验证。
- **键长键角合理性**：标准化学键参数应在合理范围内，严重偏离可能提示结构不可靠。

### 置信度审查

- 检查 pLDDT 分布：高置信度残基（>90）占比越高，整体预测越可靠。
- 检查 PAE 矩阵：界面区域（如蛋白-配体接触面）的 PAE 值应明显低于随机水平。
- 对于 pLDDT < 50 的区域，将其视为无序区，不做结构层面的解读。

### 与已知信息对照

- 如有实验数据（如突变数据、交联质谱、NMR 化学位移），可与预测结构进行定性对照。
- 对于蛋白-配体复合物，可与已知的活性口袋几何特征进行比较。

### 多预测一致性

- 生成多次预测（建议 ≥5 次），比较结果的一致性。高度一致的预测通常更可靠。
- 对于不一致的区域，标记为低置信度区域。

## 回退策略

当 AlphaFold 3 预测质量不理想或不适用时，可考虑以下替代路径：

### 预测质量不佳

- **pLDDT 普遍偏低**：检查输入序列和 SMILES 的正确性，确认无格式错误。如仍不理想，考虑使用实验结构（同源建模）作为替代。
- **立体化学违反严重**：使用结构优化工具（如 OpenMM 能量最小化、Phenix refinement）进行后处理修正。
- **蛋白-配体界面不可信**：转向传统分子对接工具（如 Vina、Gold、Glide），利用已知结合口袋信息。

### 模型不适用

- **需要构象动力学**：将 AF3 预测结构作为初始构象，输入 MD 模拟流程（GROMACS、OpenMM）获取构象系综。
- **需要商业化部署**：考虑使用 RoseTTAFold All-Atom 或其他开源替代方案。
- **蛋白质-核酸复合物精度不足**：尝试 RoseTTAFold2NA 作为补充或替代。
- **抗体-抗原复合物预测不可靠**：结合 AlphaDesign 或专门的抗体建模工具（如 RosettaAntibody）。

### 输入限制

- **无法提供 SMILES**：使用 PubChem、ChEMBL 等数据库检索，或通过 RDKit 从分子名称/InChI 转换。
- **修饰残基不在支持列表内**：将修饰残基替换为标准残基进行近似预测，或在后处理中手动添加修饰基团。

## 资源召回建议

### 配套工具

- **RDKit**：SMILES 处理、化学信息验证、分子可视化。
- **PyMOL / ChimeraX / VMD**：预测结构的可视化和分析。
- **PoseBusters**：蛋白-配体复合物的立体化学合理性验证。
- **MolProbity**：蛋白质结构质量评估（Ramachandran 图、clashscore 等）。

### 参考数据库

- **PDB**（Protein Data Bank）：获取已知实验结构作为比较基准。
- **PubChem / ChEMBL**：获取配体的 SMILES 和化学属性。
- **UniProt**：获取蛋白质序列和功能注释。

### 可替代资产

- **AlphaFold-Multimer v2.3**：纯蛋白复合物预测的成熟选择。
- **RoseTTAFold All-Atom**：开源替代方案，支持多种分子类型。
- **RoseTTAFold2NA**：专注于蛋白质-核酸复合物预测。
- **Vina / Gold / Glide**：传统分子对接工具，适用于已知结合口袋的配体对接。
