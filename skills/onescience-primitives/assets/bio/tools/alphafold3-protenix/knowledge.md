# AlphaFold3蛋白质结构预测模型（Protenix实现）

## 适用范围

用于基于蛋白质氨基酸序列，预测其三维原子级结构的计算任务。典型触发场景包括：从头进行蛋白质结构预测、研究蛋白质折叠或构象变化、为分子对接、动力学模拟或功能分析提供高精度的初始结构模型。该方法的核心在于直接对原子坐标进行生成式建模，因此特别适用于需要捕捉精细构象细节或原子层面相互作用的场景。

## 输入

- **必需**：蛋白质氨基酸序列（通常为 FASTA 格式的单链或多链序列）。
- **可选**：多序列比对（MSA）。
    - 提供 MSA 有助于提升预测精度，尤其对于序列同源性信息较为丰富的情况。
    - 若不提供，模型可能依赖内部模块进行隐式推断，但对于同源结构信息匮乏的蛋白质，预测可靠性可能下降。

## 输出

- **预测的全原子蛋白质三维结构**：以原子坐标的形式给出，通常为 PDB 或 mmCIF 格式文件。输出结构包含了蛋白质主链和侧链所有重原子的空间位置，可直接用于下游的结构分析、可视化或分子动力学模拟的输入。

## 流程节点

一个典型的使用该模型进行蛋白质结构预测的流程节点如下：

1.  **序列准备与 MSA 生成**：
    - 输入蛋白质氨基酸序列。
    - **可选步骤**：使用如 MMseqs2、JackHMMER 等工具生成多序列比对（MSA），以增强模型对进化约束的感知。是否生成及生成质量会影响最终预测。
    - **依赖**：无上游步骤。
    - **参数**：MSA 生成工具的选择、数据库范围（如 Uniref、ColabFoldDB）、序列覆盖度阈值。

2.  **模型预测**：
    - 将蛋白质序列（及可选的 MSA）输入 AlphaFold3/Protenix 模型。
    - 模型内部执行：通过 MSA Module 和 PairFormer 将序列信息编码为条件嵌入；随后，全原子扩散模块从噪声分布开始，迭代地精炼原子坐标，直至输出收敛的蛋白质结构构象。
    - **依赖**：步骤 1（序列及可选的 MSA）。
    - **质量门**：预测结果会附带每个原子的 pLDDT（predicted Local Distance Difference Test）置信度分数，分数越高代表该区域的预测越可靠。
    - **提示词模板**：`python run_protenix.py --input_sequence {input_sequence} [--msa_path {msa_path}] --output_dir {output_dir}`

3.  **后处理与评估**：
    - 对输出的原子坐标结构进行格式转换、能量最小化（可选，如使用 OpenMM）等处理。
    - 使用 pLDDT 分数、PAE（Predicted Aligned Error）图等指标评估整体和局部结构的预测质量。
    - **依赖**：步骤 2（原始预测结构）。
    - **质量门**：检查关键功能位点或预期结构域的 pLDDT 是否达标（通常 > 70 表示较可靠）。

## 边界与分流

- **与 AlphaFold2 的关系**：AlphaFold3（及 Protenix 实现）是 AlphaFold2 的重要演进。AlphaFold2 主要依赖 Evoformer 和结构模块，对骨架使用粗粒化的框架表示。而 AlphaFold3 采用全原子扩散模型，在理论上对侧链构象和原子级细节的建模能力更强。对于一般性的高精度单体结构预测，AlphaFold3 是更先进的选择；但对于需要快速获取大量结构草图或特定已成熟协议的场景，AlphaFold2 仍是可靠的备选。
- **需要物理能量对齐时**：该模型作为生成式模型，其直接输出是基于数据拟合的坐标，可能不完全符合真实的分子力学能量景观。若后续研究需要严格遵循物理能量规律的结构集合（例如用于分子动力学模拟的初始构象），则建议将模型预测的结构作为起点，接入如 **EBA（Energy-Based Alignment）** 等微调或对齐流程，将结构优化至势能面的低能区域。
- **同源结构信息匮乏时**：当目标蛋白质在数据库中缺乏同源序列（导致 MSA 质量差）且不使用模板输入时，模型的预测精度会显著下降。在这种情况下，预测结果应被视为探索性的，需结合其他方法（如基于物理的折叠模拟、冷冻电镜数据等）进行交叉验证。

## 质量检查

1.  **置信度分数评估**：检查输出结构的全局 pLDDT 平均值以及局部区域（如活性位点、结合口袋）的 pLDDT 值。一般认为 pLDDT > 70 为可靠结构，pLDDT 在 50-70 之间为可能存在较大误差，pLDDT < 50 为低置信度区域。
2.  **结构合理性检查**：使用分子可视化软件（如 PyMOL, ChimeraX）目视检查结构是否合理，有无明显的原子碰撞、不合理二面角或断裂的化学键。
3.  **与实验数据对比**：如果存在相关的实验结构（如 X 射线晶体学、冷冻电镜数据），计算预测结构与实验结构的 RMSD（均方根偏差）以进行定量比较。RMSD < 2 Å 通常被认为是较好的预测。

## 回退策略

- **预测置信度整体偏低**：
    - 尝试生成更高质量的 MSA。
    - 检查输入序列是否有误。
    - 考虑使用模型的不同随机种子多次预测，选取置信度最高的构象。
- **关键区域预测不可靠**：
    - 如果研究重点是该区域，而预测 pLDDT 低于 50，则不应直接依赖该预测结果。
    - 可尝试使用 **结构模板**（若存在同源结构）作为输入来引导预测。
    - 或转向其他更适用于低同源性蛋白的预测方法（如 RoseTTAFold2、ESMFold），但需注意其精度局限。
- **生成模型输出不符合物理能量**：
    - 此为该类模型的固有特性。回退策略是接入后处理流程，使用分子力学力场（如 AMBER, CHARMM）对预测结构进行能量最小化或短时分子动力学弛豫，使其落入更合理的能量盆地。

## 资源召回建议

- **模型实现**：**Protenix** 是 AlphaFold3 的官方开源实现，提供了从数据处理到模型推理的完整流程。
- **序列比对工具**：**MMseqs2**、**JackHMMER**、**ColabFold**（集成 MSA 生成与 AlphaFold 预测）。
- **结构分析与可视化**：**PyMOL**、**UCSF ChimeraX**、**MDAnalysis**（用于坐标轨迹分析）。
- **能量最小化与动力学**：**OpenMM**、**GROMACS**、**AmberTools**。
