# SimpleFold蛋白质结构预测模型与流程

## 适用范围
用于从蛋白质氨基酸序列直接预测其全原子三维结构的计算任务。适用于蛋白质从头设计、结构功能预测、同源建模精度不足时的替代方案等场景。该方法属于生成式结构预测范式，通过流匹配模型学习噪声到结构的映射关系，其推理过程是一个从随机噪声初始化的积分过程。

## 输入
- **必需输入**：蛋白质氨基酸序列（单链），以标准单字母或三字母代码表示。
- **可选输入**：序列截断窗口大小（当序列过长时使用）。

## 输出
- **主要输出**：预测的蛋白质全原子三维坐标（通常为 PDB 格式）。
- **辅助输出**：每个残基的 pLDDT 置信度分数（0-100），用于评估预测结构各区域的可靠性。

## 流程节点
1.  **序列嵌入与初始化**：
    *   使用预训练的蛋白语言模型（如 ESM2-3B）将输入氨基酸序列编码为每个残基的条件嵌入向量。
    *   初始化一个与目标结构原子数匹配的坐标张量，其值从标准高斯分布 N(0, I) 中采样得到（即噪声起点 x₀）。

2.  **流积分采样**：
    *   在时间 t∈[ε, 1]（通常从 ε=0.0001 开始）上积分由模型预测的速度场。这一步通常采用 Euler-Maruyama 数值积分器。
    *   关键参数包括积分步数（默认 500 步）和可能的随机性控制系数。此过程将初始噪声逐步转化为具有合理化学物理特性的原子坐标。

3.  **结构后处理**：
    *   对积分完成后的原子坐标进行必要的后处理，可能包括最小化原子间范德华力重叠、重建键长键角等，以生成化学上更合理的结构。

4.  **置信度评估**：
    *   将预测的结构坐标输入一个独立的 pLDDT 预测模块（由多层 Transformer 构成）。该模块在模型冻结状态下训练，输出每个残基的局部距离差测试（LDDT）预测值，作为结构区域的可信度评分。

## 边界与分流
- **序列长度限制**：当蛋白质序列显著长于训练数据分布（例如 >512 个残基）时，可能需要进行序列分段或使用滑动窗口策略进行预测，然后拼接，但这可能导致结构域间相对位置信息丢失。
- **同源建模优先**：如果目标蛋白存在高序列相似性（>30%）的实验解析结构模板，同源建模方法通常更快速、更可靠。
- **多链复合体**：该基础模型主要针对单链蛋白质设计。对于多链复合体，需要采用专门的对接或复合体预测流程。
- **对训练分布外目标的预测**：对于与训练集（主要是 PDB 和 AlphaFold 数据库）分布差异极大的序列（如设计的全新序列），预测结构的可靠性会下降，需谨慎解读。

## 质量检查
- **pLDDT 分数检查**：重点关注预测结构中整体或特定结构域的 pLDDT 分数。通常 pLDDT > 70 的区域可信度较高，pLDDT < 50 的区域需谨慎对待。
- **物理合理性检查**：使用分子可视化软件（如 PyMOL、ChimeraX）检查预测结构是否存在明显的原子碰撞、不合理的键长键角或不合理的二级结构排列。
- **与序列保守性/结构预测共识对比**：可将预测结果与基于多序列比对（MSA）的传统预测方法（如 AlphaFold2）的结果进行交叉验证，尤其对于关键功能位点。
- **生成样本多样性**：由于生成模型的随机性，可以进行多次独立推理（改变随机种子），观察生成结构的收敛性。多次采样得到的结构越一致，通常表明预测越可靠。

## 回退策略
- **训练不稳定或模式崩塌**：如果模型在微调或推理中表现出不稳定（如生成质量差），需检查训练数据质量、学习率调度、损失权重等，并确保使用了预训练的稳定基础权重。
- **生成结构违背物理约束**：在后处理阶段未能解决严重原子碰撞时，可考虑使用能量最小化工具（如 OpenMM）对结构进行简短弛豫。
- **对于长序列效率低下**：可采用上述的序列分段策略，或考虑使用针对长序列优化的替代模型（如 ESMFold 在某些长序列任务上可能更快）。
- **pLDDT 评估不可靠**：若对 pLDDT 评估结果存疑，可放弃使用该置信度，转而依赖其他基于物理或共识的评估指标（如 Ramachandran 图分析）。

## 资源召回建议
- **核心软件栈**：实现该流程通常需要深度学习框架（如 PyTorch）、分子可视化与操作库（如 MDAnalysis, pytraj）、以及 PDB 文件处理工具。
- **预训练模型权重**：需要获取 SimpleFold 本身及其依赖的 ESM2-3B 蛋白语言模型的预训练权重。
- **计算硬件**：模型参数量较大（SimpleFold 约为 3B），且 ESM2-3B 同样为 3B 参数，因此进行一次完整推理需要具备一定显存（建议至少 16GB GPU 显存）的计算设备。
- **相关模型**：在评估或对比时，可参考 ESMFold（同样端到端但基于结构预测头）、AlphaFold2（基于模板和 MSA 的混合模型）、以及其他基于扩散或流匹配的生成式模型（如 ESMFlow, AlphaFlow）。
