# AbAffinity模型推理接口

## 适用范围
AbAffinity是基于深度学习的抗体-抗原亲和力预测模型，适用于从抗体和抗原序列预测结合亲和力。适用于治疗性抗体筛选、抗体工程化和虚拟筛选。

## 输入
- **抗体编号序列**：经ANARCI编号后的重链和轻链序列
- **CDR掩码**：H1/H2/H3区域的二进制掩码（1表示CDR区域，0表示框架区域）
- **抗原界面特征**：抗体-抗原界面残基的理化性质特征
- **输入格式**：PyTorch张量或NumPy数组
- **输入维度**：根据模型架构而定，通常为批处理大小×序列长度×特征维度

## 输出
- **亲和力预测得分**：预测的结合自由能（ΔG）或解离常数（KD）
- **输出格式**：连续数值（kcal/mol或nM）
- **置信度**：模型预测的置信区间或不确定性估计（可选）

## 流程节点
1. **数据预处理** → 使用ANARCI对序列进行标准编号，生成CDR掩码
2. **特征构建** → 提取界面残基特征，构建输入张量
3. **模型加载** → 加载预训练的AbAffinity模型权重
4. **推理执行** → 将输入张量输入模型，获取亲和力预测
5. **后处理** → 将预测结果转换为可解释的亲和力值
6. **结果验证** → 检查预测结果的合理性和统计显著性

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 模型架构 | 深度神经网络 | [1] | 具体架构取决于模型版本 |
| 输入张量格式 | (batch_size, seq_len, feature_dim) | [1] | 批处理大小×序列长度×特征维度 |
| 采样温度 | 0.1-1.0 | [1] | 控制预测的随机性，较低温度产生更确定性的预测 |
| 随机种子 | 可选 | [1] | 确保结果可重复 |
| 推理批处理大小 | 32-128 | [1] | 根据GPU内存调整 |
| 模型权重格式 | .pt或.pkl | [1] | PyTorch或pickle格式 |

## 边界与分流
- **序列长度过长**：可能需要截断或分段处理
- **非标准氨基酸**：模型可能无法处理，需预处理
- **缺乏ANARCI编号**：需先进行抗体编号再输入模型
- **计算资源不足**：可使用CPU推理或模型量化

## 质量检查
- **输入验证**：检查输入张量维度和值范围
- **输出合理性**：验证预测亲和力值在合理范围内（通常-20到0 kcal/mol）
- **推理时间**：监控推理时间，确保在可接受范围内
- **日志记录**：记录模型输入输出维度、得分分布和推理时间

## 回退策略
- **模型不可用**：可使用其他抗体亲和力预测模型（如MVSF-AB、Phys-AbGAT）
- **性能不足**：可尝试模型微调或集成多个模型
- **计算限制**：可使用轻量级模型或特征选择
