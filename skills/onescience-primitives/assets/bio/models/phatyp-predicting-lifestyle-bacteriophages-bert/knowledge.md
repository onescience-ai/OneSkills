# 噬菌体生活方式预测工具与评估基准

## 适用范围

适用于对噬菌体基因组或contig进行生活方式（裂解性或溶源性）分类，尤其适用于从宏基因组数据组装获得的不完整序列（contig）。典型触发条件包括：需要从大量宏基因组组装片段中批量识别噬菌体并分类其生活方式；研究中关注短序列（几百至几千碱基对）的预测准确性与稳定性；需要评估预测模型在面对训练数据中未见的、低序列相似度噬菌体时的泛化能力。

## 输入

- **必需输入**：待预测的噬菌体基因组序列或contig（FASTA格式）。
- **可选输入（用于训练与重训）**：
    - 大量无标注的噬菌体基因组（用于自监督学习预训练）。
    - 带有已知生活方式标签的噬菌体基因组（用于微调分类和评估）。
    - 用户自定义的训练数据集，用于重新训练模型以适应特定领域。

## 输出

- **预测结果**：输入序列的生活方式分类（virulent 或 temperate）。
- **模型产物**：训练好的预测模型文件。
- **评估指标**：在各测试集上计算的灵敏度、特异性、准确率和AUC-ROC。
- **比较报告**：与多种现有工具（如DeePhage, PHACTS, PhagePred, BACPHLIP）在速度与准确性上的定量比较结果。

## 流程节点

该工具的开发与评估遵循一个可复用的流程，核心是构建稳健的预测模型并进行系统评估。

1.  **数据准备 (s1)**
    *   **描述**：整合已知生活方式的标注噬菌体数据集，并收集用于自监督学习的大规模无标注噬菌体基因组。
    *   **输入**：有标注的噬菌体数据集 (`annotated_dataset`)。
    *   **输出**：准备就绪的训练/验证数据集。
    *   **质量门**：数据集需涵盖完整基因组和不同长度的短contig，以确保模型训练的全面性。

2.  **构建测试集 (s2)**
    *   **描述**：基于序列相似度和片段长度，构建用于挑战模型的困难测试集。
    *   **输入参数**：
        | 参数名 | 类型 | 默认值 | 取值范围/说明 |
        | :--- | :--- | :--- | :--- |
        | 相似度阈值 (`similarity_threshold`) | float | 0.05 | 用于筛选与训练集低相似度的测试噬菌体，阈值越低，测试集越“困难”。 |
        | 片段长度范围 (`fragment_lengths`) | str | “100-1800bp” | 通常划分为4个范围（如100-400bp, 400-800bp等）以模拟宏基因组组装contig。 |
    *   **输出**：低相似度测试集、短contig测试集。
    *   **质量门**：低相似度测试集中序列与训练集的最大相似度需低于设定阈值；片段需通过相似度过滤以去除冗余。

3.  **模型训练与评估 (s3)**
    *   **描述**：执行两阶段训练策略，并在不同测试集上进行评估。
    *   **依赖**：s1, s2。
    *   **输入参数**：
        | 参数名 | 类型 | 默认值 | 说明 |
        | :--- | :--- | :--- | :--- |
        | 是否使用数据增强 (`augmentation`) | bool | true | 在微调阶段，对训练序列生成不同长度的片段，以增强模型对短contig的鲁棒性。 |
    *   **核心方法**：
        *   **自监督预训练**：使用BERT架构，在无标注的蛋白质序列上执行Masked Language Model任务，学习蛋白质关联特征。
        *   **微调分类**：在标注数据上进行分类微调，并应用数据增强。
    *   **输出**：训练好的模型、在各测试集上的性能指标。
    *   **质量门**：模型性能（尤其是AUC-ROC）应优于或可比于基线工具。

4.  **结果比较与分析 (s4)**
    *   **描述**：系统比较不同方法，并在真实数据上进行验证。
    *   **依赖**：s3。
    *   **输入参数**：真实宏基因组数据 (`real_metagenomic_data`，如新生儿肠道数据)。
    *   **输出**：性能比较报告（包括速度与准确性）、真实数据中噬菌体生活方式的组成分析。
    *   **质量门**：报告需提供定量比较数据，并对生物学意义进行解释。

## 边界与分流

- **序列长度限制**：当前模型主要针对100bp至1800bp长度范围的片段进行了优化和验证。对于极短的contig（例如<100bp），预测性能可能显著下降，此时应考虑先进行序列延伸或过滤。
- **计算速度与精度的权衡**：PhaTYP因其内部调用序列比对工具（如DIAMOND BLASTP）而需要一定的运行时间。如果对速度要求极高且输入为完整的噬菌体基因组，可考虑使用BACPHLIP等更快速的工具（但BACPHLIP不适用于不完整基因组）。
- **领域特异性**：若目标噬菌体与训练数据的已知噬菌体在蛋白质组成上差异极大（极低相似度），模型的特异性可能受到影响。对于高度特异的生态位（如特定极端环境），建议使用该工具提供的重新训练功能，利用该领域的噬菌体数据进行模型适配。
- **上下游衔接**：输入序列通常来自宏基因组组装和后续的噬菌体识别步骤（例如使用VIBRANT、PHAMB等工具）。该工具的输出（生活方式标签）可直接用于下游的生态学分析，如构建噬菌体-宿主互作网络或分析溶原噬菌体在群落中的潜在作用。

## 质量检查

- **泛化能力评估**：使用与训练集序列相似度低于设定阈值（如0.05）的测试集进行评估，以验证模型对新类型噬菌体的预测能力，避免因训练/测试数据重叠而高估性能。
- **短序列稳定性验证**：在不同长度的片段（如100-400bp, 400-800bp等）上分别评估模型性能，观察性能随序列长度变化的趋势，确保在目标长度范围内无剧烈性能波动。
- **方法基准比较**：与多种现有工具（包括可重训练的DeePhage、PhagePred和使用固定模型的PHACTS、BACPHLIP）在相同数据集和评估标准下进行比较，确认预测准确性和稳定性的优势。

## 回退策略

- **当输入contig极短（<100bp）时**：预测结果的可信度较低。建议回退到更上游的步骤，对组装结果进行质量控制或尝试使用更长片段的组装策略。若必须预测，需明确声明结果具有高度不确定性。
- **当输入序列与训练集相似度极低，且预测结果特异性不高时**：不宜直接采信单一工具的预测。应结合基于序列相似性的注释（如BLAST搜索已知生活方式噬菌体）或其他基于基因组特征的方法（如检查已知整合酶基因）进行交叉验证。
- **当跳过自监督预训练阶段，仅用标注数据微调时**：模型在短contig上的准确性和稳定性可能会下降。必须在更多、更多样化的标注数据上重新评估模型性能，并考虑是否补充无标注数据进行预训练。
- **当忽略数据增强时**：模型对短序列的泛化能力会受损。如果因计算资源限制无法进行数据增强，应降低对短contig预测结果的置信度，或在解释结果时更加保守。
- **当训练数据与测试数据存在重叠时**：评估结果可能虚高。必须使用独立的、经过相似度过滤的测试集来获得无偏的性能估计。

## 资源召回建议

- **序列预处理工具**：Prodigal（用于基因组ORF预测）、DIAMOND BLASTP（用于蛋白质序列比对，是嵌入计算的主要部分）、BLASTN（用于在数据准备阶段去除高相似度的训练序列）。
- **相似度估计工具**：Dashing（用于快速估计序列集之间的相似度，辅助构建低相似度测试集）。
- **宏基因组分析工具**：Bowtie2（用于将测序reads比对回组装contig）、BBmap（用于计算每百万映射片段数RPM，评估丰度）。
- **相关模型与方法**：Masked Language Model (BERT)（自监督预训练的核心架构）、数据增强（Data Augmentation，提升短序列鲁棒性的关键技术）。
