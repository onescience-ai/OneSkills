# 抗体结合位点预测的CAME-AB深度学习框架

## 适用范围

用于基于深度学习的抗体结合位点（antibody binding site）预测任务，具体为对给定抗体序列中每个残基进行结合/不结合的二分类。该方法特别适用于需要同时利用序列进化信息、语言模型语义表征、结构感知特征和物化图邻域信息等多模态生物特征的场景。典型触发条件包括：抗体序列及其抗原结合注释数据可获取；预测目标为重链可变区（VH）中 CDR-H1、CDR-H2、CDR-H3 区域的残基级结合位点。

## 输入

- 必需：
  - 抗体序列数据集：包含 VH 区域氨基酸序列及对应的抗原结合注释（残基级二分类标签）。
  - 超参数配置：包括学习率、批次大小、训练轮数、嵌入维度、Transformer 层数、注意力头数等。
  - 聚类相似度阈值：用于 CD-HIT 序列去冗余，默认 90% 用于初步聚类，80% 用于进一步细化划分。
- 可选：
  - 物化描述符配置：用于构建残基间物化相似图，如疏水性、极性、表面可及性等 PyBioMed 描述符类型选择。
  - 对比学习超参数：温度系数、负样本采样策略等。

## 输出

- 训练完成的模型权重文件。
- 在独立测试集上的综合性能评估报告，包含以下指标：
  - Precision（精确率）
  - Recall（召回率）
  - F1-score
  - AUC-ROC
  - MCC（Matthews 相关系数）
- 每个残基的结合位点概率预测图。

## 流程节点

以下流程为一个有向无环图（DAG），步骤按依赖关系从上游到下游执行。

### s1 · 数据准备与划分

**步骤名**：数据准备与划分  
**上游依赖**：无（起始步骤）

| 参数 | 类型 | 默认值 | 是否必需 | 说明 |
|------|------|--------|----------|------|
| `sequences` | str | — | 是 | 包含 VH 区域注释和结合信息的抗体序列集合 |
| `identity_threshold` | float | 0.9 | 是 | CD-HIT 序列聚类相似度阈值，用于减少数据冗余和泄漏 |

**质量门**：
- 去除所有条目不完整或含缺失值的序列。
- 使用 CD-HIT 以 90% 相似度阈值进行初步聚类，再以 80% 阈值进一步细化，确保高度相似序列不跨数据集划分。
- 最终数据集按 80%（训练）/ 10%（验证）/ 10%（测试）比例划分。

**输出**：划分好的训练集、验证集和测试集。

### s2 · 多模态特征提取

**步骤名**：多模态特征提取  
**上游依赖**：s1

| 参数 | 类型 | 默认值 | 是否必需 | 说明 |
|------|------|--------|----------|------|
| `sequences` | str | — | 是 | 来自 s1 的训练/验证/测试集序列 |

**质量门**：每种特征模态成功提取并具有预期维度：
- 独热编码（F_onehot ∈ ℝ^(L×20)）
- BLOSUM 特征（F_blosum ∈ ℝ^(L×20)）
- ESMC 上下文嵌入（F_esm ∈ ℝ^(L×d₁)）
- ESMC 结构感知嵌入（F_struct ∈ ℝ^(L×d₂)）
- GCN 物化嵌入（F_gcn ∈ ℝ^(L×d₃)）

**输出**：五种模态的特征矩阵。

**特征提取说明**（综合推断，非单一素材直证）：
- **独热编码**：将每个残基编码为 20 维二值向量，捕捉残基身份信息。
- **BLOSUM 特征**：基于 BLOSUM 替换矩阵，将残基替换倾向性映射为 20 维特征向量，反映进化保守性。
- **ESMC 上下文嵌入**：通过预训练蛋白质语言模型（如 ESMC）获取上下文化 token 嵌入，编码语义与进化上下文。具体嵌入维度取决于所选模型配置。
- **ESMC 结构感知嵌入**：从模型的结构输出层提取，反映残基的空间特征推断。
- **GCN 物化嵌入**：首先使用 PyBioMed 计算残基级物化描述符（疏水性、极性、表面可及性等），基于残基间物化相似度构建残基图；然后通过图卷积网络（GCN）进行两层传播，聚合邻域的化学与空间上下文信息，输出精炼后的节点嵌入。

### s3 · 特征投影与融合

**步骤名**：特征投影与融合  
**上游依赖**：s2

| 参数 | 类型 | 默认值 | 是否必需 | 说明 |
|------|------|--------|----------|------|
| `F_onehot` | tensor | — | 是 | 独热编码特征，来自 s2 |
| `F_blosum` | tensor | — | 是 | BLOSUM 特征，来自 s2 |
| `F_esm` | tensor | — | 是 | ESMC 上下文嵌入，来自 s2 |
| `F_struct` | tensor | — | 是 | ESMC 结构感知嵌入，来自 s2 |
| `F_gcn` | tensor | — | 是 | GCN 物化嵌入，来自 s2 |

**质量门**：
- 所有模态特征均通过模态特定变换投影至统一的 256 维潜在空间。
- 融合权重通过反向传播联合优化。

**输出**：融合后的多模态表征 F_fused ∈ ℝ^(L×256)。

**融合机制说明**：自适应模态融合（AMF）模块不同于简单的拼接或固定权重平均。它通过三重权重机制动态分配各模态权重：（1）全局重要性权重——捕捉各模态在整体数据中的通用信息量；（2）样本特异性权重——适应每个抗体输入的独特特征分布；（3）类别感知权重——将融合过程与任务类别语义关联。这三重权重通过反向传播端到端联合学习。

### s4 · Transformer 编码与 MoE 处理

**步骤名**：Transformer 编码与 MoE 处理  
**上游依赖**：s3

| 参数 | 类型 | 默认值 | 是否必需 | 说明 |
|------|------|--------|----------|------|
| `F_fused` | tensor | — | 是 | 融合后的表征，来自 s3 |

**质量门**：
- Transformer 采用 Pre-LN 架构。
- MoE 模块由 K 个专家网络组成，每个专家为两层 MLP；门控网络对专家分配软分布。
- 通过多样性正则化损失防止专家坍缩。

**输出**：经过 Transformer 和 MoE 精炼的表征 h_moe。

**架构说明**：
- **Transformer 编码器**：默认 2 层，捕捉残基间的序列依赖关系和 CDR 区域内的交互。超参数网格搜索范围：层数 {2, 4, 6}，注意力头数 {4, 8, 12}。
- **混合专家模块（MoE）**：在 Transformer 输出后引入，通过多个并行的专家子网络实现特征专业化。每个样本由门控网络软路由到不同专家，允许模型学习多样化的特征变换。多样性正则化损失确保各专家发展出不同的特化能力，防止所有专家坍缩到相同输出。

### s5 · 分类与对比学习

**步骤名**：分类与对比学习  
**上游依赖**：s4

| 参数 | 类型 | 默认值 | 是否必需 | 说明 |
|------|------|--------|----------|------|
| `h_moe` | tensor | — | 是 | MoE 精炼表征，来自 s4 |
| `labels` | int | — | 是 | 残基级结合/不结合标签 |

**质量门**：总损失由以下四部分加权组成：
- **焦点损失（Focal Loss）**：用于最终二分类，缓解类别不平衡。
- **辅助模态损失**：鼓励各模态保持独立的判别能力。
- **监督对比损失**：在投影空间中拉近同类样本、推远异类样本，并结合硬负样本挖掘策略。
- **多样性损失**：约束 MoE 专家的多样性。

**输出**：分类预测结果和对比学习嵌入。

**对比学习说明**：通过投影头将 h_moe 映射到对比嵌入空间，得到嵌入向量 z。对比损失鼓励同一类别的残基嵌入彼此靠近，不同类别的嵌入彼此远离。硬负样本挖掘策略选取决策边界附近的高置信度错误样本作为负例，增强学习信号。

### s6 · 模型训练与评估

**步骤名**：模型训练与评估  
**上游依赖**：s5

| 参数 | 类型 | 默认值 | 是否必需 | 说明 |
|------|------|--------|----------|------|
| `dataset` | str | — | 是 | 来自 s1 划分的数据 |
| `training_config` | dict | 见下表 | 是 | 优化器、学习率、轮数等超参数 |

**训练配置默认值**：

| 参数 | 默认值 |
|------|--------|
| epochs | 50 |
| batch_size | 64 |
| learning_rate | 1×10⁻⁴ |
| optimizer | Adam |
| lr_scheduler | cyclical with exponential decay |
| weight_decay | 1×10⁻⁵ |
| lr_decay_factor | 0.95（每 10 个 epoch） |
| embedding_dim（网格搜索） | {64, 128, 256} |
| transformer_depth（网格搜索） | {2, 4, 6} |
| attention_heads（网格搜索） | {4, 8, 12} |

**质量门**：
- 训练采用 Adam 优化器和周期性学习率调度。
- 基于验证损失应用早停法。
- 训练后期应用随机权重平均（SWA）以提升泛化性能。
- 评估在非重叠测试集上使用五项标准指标（Precision, Recall, F1, AUC-ROC, MCC）。

**输出**：训练好的模型权重和在测试集上的性能指标报告。

## 边界与分流

- **仅有序列、无结构信息**：该方法利用 ESMC 结构感知嵌入从序列推断结构信息，因此不需要实验确定的三维结构。但如果已有高质量的实验结构或同源模型结构，可考虑引入基于结构的特征（如距离矩阵、二面角）以进一步提升性能。
- **目标为抗体-抗原界面残基而非 CDR 区域**：该框架聚焦 VH 区域的 CDR 残基。若预测目标为抗原侧结合位点或完整的界面残基，需调整输入区域定义和数据组织方式。
- **多链抗体（如轻重链配对）**：当前流程聚焦于重链可变区。对于需要联合建模轻链和重链的任务，需要扩展输入和特征提取流程。
- **数据量极小（<100 条序列）**：多模态深度融合模型对数据量有一定需求。数据极少时，建议退化为基于语言模型嵌入的轻量模型或使用迁移学习策略。
- **下游可替换模块**：该流程中各模态特征提取器、融合模块、编码器架构均可根据具体需求替换。例如，可将 Transformer 替换为等长卷积网络，或将 MoE 替换为更简单的 MLP 分类头。

## 质量检查

- **数据完整性验证**：在 s1 步骤中确认所有序列条目完整，无缺失残基或缺失结合注释。
- **数据泄漏检查**：确认 CD-HIT 聚类后，训练集、验证集和测试集之间无高度相似（>80% 相似度）的序列。
- **特征维度核验**：在 s2 步骤后验证各模态特征维度符合预期（如独热编码为 L×20）。
- **类别分布监控**：在训练前检查各数据划分中正负样本比例，确认上/下采样策略生效。
- **训练收敛监控**：观察训练/验证损失曲线，确认无严重过拟合（训练损失远低于验证损失）或欠拟合（两者均未收敛）。
- **评估指标全面性**：在类别不平衡场景下，不应仅依赖 Accuracy，需综合审查 Precision、Recall、F1、AUC-ROC 和 MCC 五项指标。MCC 在类别不平衡时尤为关键。

## 回退策略

- **输入序列信息不完整**：回退至数据清洗步骤，去除缺失条目后重新划分。若可用序列过少，考虑从公共数据库（如 IMGT、abYsis）补充数据。
- **类别严重不平衡导致模型偏向多数类**：加强上/下采样力度；增大焦点损失中聚焦参数 γ；或在对比损失中增加对少数类的采样权重。
- **训练不收敛或震荡**：降低学习率（如从 1×10⁻⁴ 降至 5×10⁻⁵）；检查学习率调度是否合理；验证梯度流是否正常（如检查梯度裁剪）。
- **过拟合严重**：减小模型容量（减少 Transformer 层数或 MoE 专家数）；增大 weight_decay；增加数据增强（如序列随机截取、残基替换等）。
- **MoE 专家坍缩**（多个专家输出趋同）：增大多样性正则化损失权重；减少专家数量；调整门控网络的负载均衡系数。
- **计算资源不足**：减小嵌入维度（如选择 64 而非 256）；减小批次大小并相应调整学习率；考虑仅使用部分模态以降低计算开销。

## 资源召回建议

- **蛋白质语言模型嵌入**：ESMC、ESM-2、ProtTrans 等预训练模型可提供高质量的上下文嵌入与结构感知嵌入。
- **物化特征工具**：PyBioMed 可计算残基级疏水性、极性、表面可及性等物化描述符。
- **序列去冗余工具**：CD-HIT 用于基于序列相似度的聚类与去冗余。
- **深度学习框架**：PyTorch（推荐），配合 PyTorch Geometric 处理 GCN 相关计算。
- **训练优化组件**：torch.optim.lr_scheduler（学习率调度）、torch.optim.swa_utils（随机权重平均）。
- **评估工具**：scikit-learn 提供 Precision、Recall、F1、AUC-ROC 的标准实现；MCC 可通过 matthews_corrcoef 计算。
- **数据来源**：IMGT、abYsis、SAbDab 等抗体序列与结构数据库可作为训练数据来源。
