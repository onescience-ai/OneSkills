# 基于三级结构的RNA设计（RDesign方法）

## 适用范围

用于从已知或预测的RNA三级结构坐标出发，计算设计与之对应的核苷酸序列的场景。典型触发条件包括：基于冷冻电镜或X射线晶体学获得的高分辨率RNA结构进行序列设计；对已知RNA结构进行重设计以探索序列空间或优化功能；在结构引导下进行从头RNA设计。该方法适用于结构相对完整、坐标信息可靠的目标结构。

## 输入

- **必需输入**：
  - **RNA三级结构坐标**：PDB格式或其他结构坐标格式文件，包含每个核苷酸的原子坐标信息。
  - **预训练模型权重**：在涵盖多样RNA拓扑的数据集上训练好的RDesign模型参数。
- **可选输入**：
  - **二级结构约束**：以括号表示法（如`((...))`）提供的碱基配对信息。当已知或预期目标结构具有特定的二级结构模式时，此输入可用于约束设计过程，提高序列的折叠可靠性。
- **环境依赖**：需要安装Python及深度学习框架（如PyTorch）的计算环境。

## 输出

- **设计的RNA序列**：预测出的、最可能折叠成输入三级结构的核苷酸序列。
- **置信度评估（可选）**：模型对所设计序列的预测置信度分数，可用于初步筛选设计方案。

## 流程节点

### 步骤一：三级结构图建模

- **步骤标识**：`s1`
- **描述**：将输入的RNA三级结构坐标转换为图结构表示。以每个核苷酸（通常以其磷酸骨架上的一个原子，如C4‘，作为代表）为节点，根据其在三维空间中的距离，通过K近邻算法构建图的边，从而捕获局部空间邻近关系。
- **输入参数**：
  | 参数名 | 类型 | 默认值 | 说明 |
  | :--- | :--- | :--- | :--- |
  | `structure` | `str` | 无 | RNA三级结构文件路径或坐标数据 |
  | `K` | `int` | 30 | 构建边时每个节点考虑的近邻数量。默认值30经验证能平衡图密度与信息量。范围通常设为1-50。 |
- **输出**：属性图 `G`，其节点属性编码核苷酸的内禀几何特征，边属性编码核苷酸对之间的相对空间关系（如距离、方向）。
- **质量门**：生成的图 `G` 应当能够充分表示结构的局部几何环境和核苷酸间的相对空间排布，为后续的图神经网络处理提供有效输入。

### 步骤二：层次化表示学习

- **步骤标识**：`s2`
- **描述**：对步骤一得到的结构图 `G` 进行多层次的表示学习，旨在学习数据高效、且能同时捕获结构整体拓扑和微观内在性质的图表示。该过程通常包含两个子模块：
  1.  **簇级对比学习**：利用RNA结构间的拓扑相似性（如通过结构比对得到的相似性分数），将相似的结构在表示空间中拉近，不相似的推远，从而学习捕获全局拓扑特征的图级表示。
  2.  **扰动置信度学习**：通过对输入结构进行随机扰动（如原子坐标的微小扰动），并定义原始结构与扰动结构为正样本对。通过对比学习，迫使模型学习对微观结构变化敏感的表示，以捕获核苷酸级别的内在特性。
- **输入参数**：
  | 参数名 | 类型 | 默认值 | 说明 |
  | :--- | :--- | :--- | :--- |
  | `G` | `str` | 无 | 来自步骤`s1`的结构图 |
- **输出**：图级别的表示向量 `hG`，以及其在超球面空间的投影 `g(hG)`。
- **质量门**：学到的表示应使得拓扑相似的RNA结构在表示空间中聚集，而差异大的结构则分离。用于对比学习的扰动数据，其质量需满足TM-score > 0.8且RMSD < 1.0 Å的过滤条件，以确保扰动后的结构仍与原始结构高度相似，属于有意义的对比样本。

### 步骤三：序列预测与二级结构约束优化

- **步骤标识**：`s3`
- **描述**：从步骤二获得的图表示 `hG` 中解码出初始的RNA序列预测。随后，若提供了二级结构约束，则利用该约束对初始预测进行后处理优化。
- **输入参数**：
  | 参数名 | 类型 | 默认值 | 说明 |
  | :--- | :--- | :--- | :--- |
  | `hG` | `str` | 无 | 来自步骤`s2`的图表示 |
  | `secondary_structure` | `str` | `None` | 可选的二级结构约束，括号表示法 |
  | `tau_prime` | `float` | 0.5 | 温度参数，用于锐化配对位点的预测置信度。较低值使预测更确定。 |
- **输出**：经过约束优化后的最终RNA序列。
- **质量门**：优化后的序列应当满足输入的二级结构约束（例如，配对位置的碱基应符合沃森-克里克配对规则：A-U， G-C等）。这是验证序列设计是否满足已知折叠规则的关键步骤。

## 边界与分流

- **适用边界**：该方法强依赖于输入三级结构坐标的质量与可靠性。对于仅为预测的、低精度的三级结构（如RMSD > 5 Å或TM-score较低的模型），设计的序列可能无法可靠地折叠成目标结构。模型的泛化能力受限于其训练数据的拓扑多样性；当目标结构与训练集中的结构在拓扑上差异极大时，性能可能下降。
- **分流建议**：
  - 若仅拥有二级结构信息而无三级结构坐标，应转向基于二级结构的RNA设计方法。
  - 若对设计的序列能否真实折叠成目标结构有严格验证要求，必须将设计出的序列输入独立的三级结构预测工具（如RhoFold、AlphaFold 2 for RNA等）进行验证，形成“设计-验证”的闭环。这本身不是该方法的内置步骤，而是必要的下游应用。
  - 该方法与用于序列生成或从头设计的其他计算方法（如基于语言模型的方法）可能互补，可结合使用。

## 质量检查

- **结构一致性验证**：将设计的序列提交给独立的RNA三级结构预测工具，预测其最可能折叠的结构，并将该预测结构与设计输入的原始结构进行比较（计算RMSD、TM-score等）。这是验证设计是否成功的黄金标准。
- **二级结构符合性检查**：如果使用了二级结构约束，检查设计序列的预测二级结构是否与输入约束匹配。
- **物理化学合理性评估**：使用核酸折叠预测工具（如RNAfold）检查设计序列的最小自由能结构，并观察其与目标结构的对应关系。
- **实验验证**：最终的有效性需通过体外转录、凝胶电泳、功能测定或结构测定（如X射线晶体学、冷冻电镜）等实验手段来确认。

## 回退策略

- **缺乏可靠三级结构**：如果输入的三级结构来源不可靠（如仅为低精度预测模型），应首先使用更高精度的结构预测或实验方法获取结构，或考虑改用基于二级结构或序列模板的设计方法。
- **模型性能不足**：如果在验证流程中发现设计序列的折叠预测与目标结构偏差过大，可能表明模型对该类结构的泛化不足。可尝试：1）在训练数据中寻找与目标拓扑更相似的结构作为参考；2）调整图建模参数（如K值）以适应目标结构的特征；3）考虑使用其他针对特定RNA家族进行微调的模型。
- **下游验证失败**：如果序列经结构预测后无法折叠成目标结构，应将此结果反馈，用于重新审视设计假设、结构输入或选择其他设计方案。

## 资源召回建议

- **相关模型与工具**：
  - 结构预测验证：RhoFold， AlphaFold 2 (针对RNA)， RoseTTAFold。
  - 序列折叠预测：RNAfold (ViennaRNA包)， NUPACK。
  - 结构比对与分析：US-align, PyMOL。
- **数据集**：训练此类模型通常需要包含三级结构坐标的RNA结构数据库（如PDB中解析的RNA结构）。
- **概念参考**：可参考其他将生物大分子结构图化并应用于生成或预测任务的工作，例如蛋白质设计中的GraphTrans、PiFold等方法的思路，了解图表示学习在结构生物学中的普遍范式。
