# BEND_tasks Dataset for DNA Language Model Benchmarking

## 适用范围
用于评测DNA语言模型在生物任务上的迁移与泛化能力，特别是调控、剪接和染色质相关任务。

## 输入
- 基因组区间、变异、调控轨迹和细胞/组织上下文
- 参考基因组版本：hg38

## 输出
- 模型在各类生物任务上的性能指标
- 分层性能评估报告

## 流程节点
1. 数据获取：从BEND官方源（https://github.com/ufqir/BEND）获取数据集
2. 数据格式验证：检查FASTA、BED/VCF、轨迹表或序列-标签数据格式
3. 数据完整性检查：核验样本数量、缺失值和可解析性
4. 数据划分：按标准策略进行采样，确保覆盖调控、剪接和染色质三个任务的测试集

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 参考基因组版本 | hg38 | [1] | 人类参考基因组版本 |
| 数据集规模 | 数千个基因组区间 | [1] | 包含多个生物任务的测试集 |
| 任务类型 | 调控、剪接、染色质 | [1] | 三个主要评测维度 |

## 边界与分流
- 如果无法获取完整数据集，可使用模拟数据作为临时替代，但需标注数据来源
- 数据格式不兼容时，需进行格式转换

## 质量检查
- 检查数据集文件是否存在、格式是否正确
- 验证样本数量是否充足（至少包含调控、剪接、染色质三个任务的测试集）
- 检查数据血缘记录是否完整

## 回退策略
- 官方源不可用时，可尝试从Zenodo等替代源获取
- 数据格式不兼容时，参考官方文档进行格式转换

## 资源召回建议
- 当需要评测DNA语言模型在生物任务上的性能时召回本卡片
- 配套资源：DNABERT-2模型、Caduceus模型、分层性能评估方法
