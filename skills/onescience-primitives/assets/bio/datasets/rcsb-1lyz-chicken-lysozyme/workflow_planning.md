# RCSB 1LYZ 使用规划

## description

为需要既有结构输入的任务提供 RCSB 1LYZ 的来源定位与质控交接；具体实体位置以 usage/access 的同一资源版本为准。

## when_to_use

需要该条目实体 1、链 A 的来源与坐标核对时使用。需要独立标签、完整特征或其他科研输入时，须先满足对应资源要求。

## inputs

usage/access 指定的本地资源根及三个必要文件，spec 的版本、实体与链选择，以及消费者要求的输出位置。共享消费需额外核验共享副本。

## outputs

原始结构及标准化结构输入、可逆编号映射、实体/链/残基对应表、缺失/插入码/altloc/解析异常记录和可重新读取的质控产物。

## procedure

1. 从 usage/access 绑定 data_dir；核对三个必要文件、大小和哈希，输出文件核验结果。
2. 对照官方 JSON 核对资源身份、修订和实体来源；输出身份对应记录。
3. 读取结构并记录坐标覆盖与解析异常，按 spec 保留原始及标准化编号对应。
4. 保存交付物并重新读取，向消费者交接实际使用路径、版本与质量检查结果。

## constraints

保持 spec/constraints 和 usage/operation_limits 的科学及资源边界。共享不存在时保留真实本地位置；不得据此宣布完整下游任务依赖就绪。

## next_phase_recommendation

消费者通过 usage/integration_paths 接收 data_dir 和结构路径，并使用对应表与异常记录判断自身输入条件。进入其他科研分支前独立核验所需数据、软件和标签。

## fallback

文件缺失、哈希不符或来源对应不明时，停止将此副本标记为可用并从 usage/access 的官方来源重新核验。仅共享缺失时，可在允许本地消费的场景使用已核实本地副本；必须共享的消费者等待物化和一致性验证。
