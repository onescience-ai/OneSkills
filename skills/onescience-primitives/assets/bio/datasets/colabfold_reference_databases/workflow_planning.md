## description

为ColabFold environmental/UniRef30 本地归档包选择数据入口、字段映射和下游接入路线，固化来源、样本单位与划分约束。

## when_to_use

OpenDDE 本地 ColabFold 参考数据库归档原语，登记 environmental 202108 与 UniRef30 2103 版本、首个 tar 成员及重复下载候选，标明小归档截断和 MMseqs 搜索索引尚未验证。 当需要使用上述本地数据及其具体 schema 时召回本卡。

## inputs

数据根目录 `/public/share/sugonhpcapp01/onestore/onedatasets/OpenDDE/colabfold_db`，所选子集、消费目标和输出目录；同时指定模型/解析器版本、标签或目标字段、划分协议。

## outputs

交付可追溯的数据接入信息：所选文件、样本单位、字段映射、标签/目标定义、划分和检查结果；保留未验证事项。

消费边界：archive_path、release、候选/截断状态与待验证事项；只有完成恢复与索引验证后才交付可搜索前缀，当前不提供虚构的索引路径。

## procedure

1. 解析数据根目录和子集，确认文件可读、非空，记录实际选择与版本线索。
2. 检查实际 schema 和样本单位，保留原始标识与来源；配套资源必须与数据版本匹配。
3. 排除已报 EOFError 的小归档，保留 .1 为待完整性验证候选。
4. 在独立目录恢复并核查实际成员/格式，再由匹配工具构建或验证 MMseqs 搜索库。
5. 记录字段映射、划分、依赖和验证结果，交接至对应的数据 adapter 或只读索引步骤。

## constraints

这是参考数据库资源，不是训练样本集。归档版本和候选文件必须单独固定，.tar.gz 与 .tar.gz.1 不视为多分片，不拼接恢复。

小 UniRef30 文件明确不可作为完整输入；.1 仅为候选，需来源 checksum/全流校验。未发现并核实可直接搜索的索引，不宣称本地可运行 MSA 搜索。不能自动执行来源 shell 脚本。

## next_phase_recommendation

归档候选选择 → 完整性/来源校验 → 独立位置恢复 → 核对 TSV/数据库产物 → MMseqs/ColabFold 建库与最小查询。

先完成当前消费接口的样本级验证，再根据用户目标进入数据准备、推理、训练或评测；本卡自身不执行这些工作。

## fallback

归档不完整时报告具体文件和错误，可保留资源发现结果；不要拼接重复下载候选或声称已获得完整数据库。
