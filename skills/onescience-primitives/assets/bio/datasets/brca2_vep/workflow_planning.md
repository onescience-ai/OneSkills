## description

为BRCA2 功能变异与成对窗口评测数据选择数据入口、字段映射和下游接入路线，固化来源、样本单位与划分约束。

## when_to_use

Carbon 本地 BRCA2 VEP 表与来源缓存原语，绑定 6836 个变异的功能 score/class、8192 bp 成对窗口及 hg19 chr13/实验表缓存，区分实验功能类别和临床致病性。 当需要使用上述本地数据及其具体 schema 时召回本卡。

## inputs

数据根目录 `/public/share/sugonhpcapp01/onestore/onedatasets/Carbon/eval/brca2`，所选子集、消费目标和输出目录；同时指定模型/解析器版本、标签或目标字段、划分协议。

## outputs

交付可追溯的数据接入信息：所选文件、样本单位、字段映射、标签/目标定义、划分和检查结果；保留未验证事项。

消费边界：ref_seq/var_seq、变异身份、来源 score/class 和模型独立预测；保留参考版本和窗口策略。

## procedure

1. 解析数据根目录和子集，确认文件可读、非空，记录实际选择与版本线索。
2. 检查实际 schema 和样本单位，保留原始标识与来源；配套资源必须与数据版本匹配。
3. 明确目标是功能类别或连续功能 score，取得阈值和方向定义。
4. 核对 ref/alt 窗口和 chr13 hg19 关联，保留来源分数与模型预测的独立性。
5. 记录字段映射、划分、依赖和验证结果，交接至对应的数据 adapter 或只读索引步骤。

## constraints

完整表为本地评测入口，没有显式 train/validation/test 列。smoke 仅支持接口检查。若用于学习，按位点/氨基酸或实验分组另定协议，不能把同位点变异泄漏到评测。

重建窗口时先核实坐标与 hg19 参考缓存，不可与 TraitGym hg38 窗口混用。实验功能与临床致病性不同；阈值来源不清时只报告原始分数/类别。

## next_phase_recommendation

配对窗口校验 → 模型 ref/alt 打分 → 经核实的功能 class/score 评测；参考/XLSX 仅作为来源回查。

先完成当前消费接口的样本级验证，再根据用户目标进入数据准备、推理、训练或评测；本卡自身不执行这些工作。

## fallback

缺少类别生成协议时只做序列对接入与原始标签保留，不臆造致病性标签；参考不匹配则输出异常位点。
