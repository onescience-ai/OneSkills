## description

为RoseTTAFold 本地 HH-suite 参考数据库包选择数据入口、字段映射和下游接入路线，固化来源、样本单位与划分约束。

## when_to_use

RoseTTAFold 本地 BFD、PDB100_2021Mar03、UniRef30_2020_06 及 uniref30 别名参考数据库原语，登记 HH-suite 文件前缀、版本与软链接，明确别名实际指向 UniRef30_2021_03。 当需要使用上述本地数据及其具体 schema 时召回本卡。

## inputs

数据根目录 `/public/share/sugonhpcapp01/onestore/onedatasets/RoseTTAFold`，所选子集、消费目标和输出目录；同时指定模型/解析器版本、标签或目标字段、划分协议。

## outputs

交付可追溯的数据接入信息：所选文件、样本单位、字段映射、标签/目标定义、划分和检查结果；保留未验证事项。

消费边界：数据库角色、release、解析后的前缀、相关文件对、只读路径和可用性状态；消费方为搜索/模板工具而非序列分类 loader。

## procedure

1. 解析数据根目录和子集，确认文件可读、非空，记录实际选择与版本线索。
2. 检查实际 schema 和样本单位，保留原始标识与来源；配套资源必须与数据版本匹配。
3. 选择真实版本，特别区分独立 2020_06 与指向 2021_03 的 uniref30 别名。
4. 核对文件对和前缀后交给匹配搜索器做查询，不因目录存在就声明索引可执行。
5. 记录字段映射、划分、依赖和验证结果，交接至对应的数据 adapter 或只读索引步骤。

## constraints

参考数据库不是 train/test 数据。需要时间截止评测时按实际 release/条目日期约束检索范围，不能把 2021_03 别名宣称为 2020_06。

检查软链接解析后的真实路径、成对文件、文件非空和搜索器版本兼容。归档/安装脚本、BLAST 程序和模型权重与参考库分开登记；存在 md5sums 不代表已执行校验。

## next_phase_recommendation

确定搜索器与 release → 前缀/软链接/文件对核查 → 独立工作目录中的小样本检索验证 → MSA/模板 adapter。

先完成当前消费接口的样本级验证，再根据用户目标进入数据准备、推理、训练或评测；本卡自身不执行这些工作。

## fallback

链接失效或索引对缺失时列明受影响库/版本；未经确认不自动切换其他 release，归档可以登记为待恢复资源。
