## description

为DNA 序列扰动配对偏好基准选择数据入口、字段映射和下游接入路线，固化来源、样本单位与划分约束。

## when_to_use

Carbon 本地 DNA Perturbation Bench，覆盖人/鼠同义密码子替换、CAG 插入、启动子反向互补及历史 tata/codon 分支，保留原序列与扰动序列配对、坐标和操作元数据。 当需要使用上述本地数据及其具体 schema 时召回本卡。

## inputs

数据根目录 `/public/share/sugonhpcapp01/onestore/onedatasets/Carbon/eval/perturbation-bench`，所选子集、消费目标和输出目录；同时指定模型/解析器版本、标签或目标字段、划分协议。

## outputs

交付可追溯的数据接入信息：所选文件、样本单位、字段映射、标签/目标定义、划分和检查结果；保留未验证事项。

消费边界：original_sequence 与 sequence 成对输入，附分支和可用的 benchmark_id/位点/物种/操作元数据；输出配对分数及固定方向的偏好结果。

## procedure

1. 解析数据根目录和子集，确认文件可读、非空，记录实际选择与版本线索。
2. 检查实际 schema 和样本单位，保留原始标识与来源；配套资源必须与数据版本匹配。
3. 先选择具有明确定义的操作分支，按实际字段确定身份键。
4. 核对序列变化范围与打分方向，保持配对与位点分组，单独报告历史分支。
5. 记录字段映射、划分、依赖和验证结果，交接至对应的数据 adapter 或只读索引步骤。

## constraints

现代分支作为 test 入口；data.parquet 历史分支没有显式 split 列。每对始终同组，同位点/转录本关联样本不能随意跨训练和测试；smoke 与完整集分开。

保留原/扰动方向、链方向、参考组装和 CDS/patch 的坐标约定。不能把六分支 schema 强行补成一套已存在的字段，也不能仅按列名判断所有分支功能含义相同。

## next_phase_recommendation

选定分支和操作定义 → 序列对一致性检查 → 配对模型打分 → 按操作/物种/位点分层；保留完整操作元数据。

先完成当前消费接口的样本级验证，再根据用户目标进入数据准备、推理、训练或评测；本卡自身不执行这些工作。

## fallback

操作或正负定义未核实时只做配对结构检查，不给出致病性结论；缺少定位字段时保留源文件与行号，不合成 benchmark_id 充当上游 ID。
