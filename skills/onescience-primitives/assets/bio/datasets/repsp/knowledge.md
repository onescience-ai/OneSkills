# REPSP 蛋白质结构预测评估基准

## 适用范围

用于评估蛋白质表示（从单体链提取的嵌入向量）在结构预测相关任务上的有效性。典型触发场景包括：新提出蛋白质表示学习方法需要在结构预测维度上与已有方法（如 ESM2 等仅序列模型、或已有结构感知模型）进行受控比较；研究者希望量化不同规模预训练模型的表示在几何互补性和结合属性推断方面的能力差异；以及需要验证表示学习是否能实际加速单体结构预测流程。

本基准的核心设计思想是：蛋白质表示的价值不仅体现在功能注释（如 EC 分类、GO 预测）上，更应体现在能否为结构预测提供有用信号。因此，评估任务均围绕结构生成能力展开，而非传统的序列级下游任务。

## 输入

- **必需**：从待评估蛋白质表示学习模型提取的单体链级蛋白质表示（嵌入向量）。表示的提取方式取决于具体模型架构——对序列语言模型通常取残基级 token embedding，对结构感知模型可取三维坐标编码或几何特征。
- **可选**：表示的归一化参数（如 LayerNorm / PCA 降维设置），用于控制不同模型输出空间的对齐程度。

输入表示的来源模型不限，已验证可涵盖：纯序列蛋白质语言模型（如 ESM2 系列）、结构感知预训练模型（如基于多视图对齐的方法），以及任意中间或最终层表示。

## 输出

三项评估任务各自产出独立的评估指标：

| 评估任务 | 主要指标 | 指标说明 |
|---|---|---|
| 同源二聚体共折叠（Task 1） | DockQ, iRMSD | 衡量预测复合物结构与真实复合物结构的全局和局部一致性 |
| 残基级结合属性预测（Task 2） | 逐残基分类/回归指标（如 AUROC、MCC 等） | 衡量单体表示中编码的结合界面几何信息 |
| 表示对齐单体结构预测（Task 3） | TM-score, lDDT | 衡量经蒸馏后单体结构预测的质量提升幅度 |

最终产出为各方法在三项任务上的完整指标对比表，可用于判断表示在结构预测维度上的综合优劣。

## 流程节点

### Task 1：同源二聚体共折叠评估

**目的**：检验蛋白质表示是否编码了足够的三维几何信息，使得模型能仅凭单体表示推断同源二聚体的结合构象。

**数据**：从 AlphaFold 蛋白质结构数据库（AFDB）同源二聚体发布版本中获取的约 180 万同源二聚体复合物，经统一预处理后用于评估。

**方法**：采用基于 Transformer 的单体折叠模型（如 SimpleFold）的修改版本，将其改造为同源二聚体柔性对接模型。评估时输入两条相同序列的单体表示，模型预测结合后的复合物结构，再与 AFDB 提供的预测复合物结构进行比对。

**关键考量**：同源二聚体天然具有对称性，预测难度相对异源复合物较低，但能有效区分表示中几何信息的有无与强弱。

### Task 2：残基级结合属性预测

**目的**：检验单体链表示中是否编码了残基级别的结合界面信息。

**方法**：在冻结的蛋白质表示之上训练一个轻量级 MLP 探针（probing head），对每个残基预测其是否位于同源二聚体的结合界面及其结合属性（如接触频率、界面面积贡献等）。分类/回归的真值标签从同源二聚体复合物结构中提取。

**设计意图**：MLP probing 是评估表示中局部几何信息的标准手段——如果表示本身不编码界面信息，即使使用更强的分类器也无法获得好的结果。
