# 基于TM-score的结构预测评估

## 适用范围

用于蛋白质三维结构预测模型的准确性标准化评估。典型触发场景包括：新预测模型或模型组件变更后的性能对比、预测流水线中各模块贡献的消融分析、以及跨方法的基准评测。TM-score 评估的核心思想是将预测结构与实验测定的天然结构进行全局拓扑比对，输出一个归一化的相似性得分，从而以单一数值刻画预测质量。

该评估方法适用于所有基于原子坐标输出的蛋白质结构预测任务，包括但不限于 AlphaFold 系列、OpenFold、RosettaFold 等主流方法。评估对象可以是单链蛋白质，也可扩展至多链复合物（需逐链评估或使用专门的复合物比对指标）。

## 输入

- **必需输入**
  - 预测的蛋白质三维结构文件：标准格式为 PDB 或 mmCIF，包含完整的原子坐标。
  - 实验测定的蛋白质三维结构文件（基准真相，ground truth）：同样为 PDB 或 mmCIF 格式，需与预测结构为同一蛋白质序列。
  - 结构比对工具：推荐 US-align 或 TM-align，二者均为免费开源工具，输出标准化的 TM-score 值。

- **可选输入**
  - 基线 TM-score 阈值：用于过滤基线性能过低的蛋白质样本。典型阈值为 0.7——即仅保留基线模型（如标准 OpenFold 运行）对该蛋白的 TM-score > 0.7 的样本进入后续分析。
  - 多组预测结构：用于消融实验或组件贡献分析时，需同时输入多组预测结果以计算 ΔTM。

## 输出

- **TM-score 值**：取值范围 [0, 1]，值越接近 1 表示预测结构与天然结构的拓扑越相似。一般认为 TM-score > 0.5 表示具有相同的折叠拓扑，> 0.7 表示高精度预测。
- **性能变化差值（ΔTM）**：在消融分析中，以某基线配置的 TM-score 为参照，计算变更特定组件后的 TM-score 变化量。ΔTM > 0 表示该组件贡献正向改善，ΔTM ≈ 0 表示该组件对该类蛋白质影响可忽略，ΔTM < 0 表示该组件引入退化。
- 比对工具通常同时输出 RMSD（Root Mean Square Deviation）和 lDDT 等辅助指标，可作为补充参考。

## 流程节点

1. **数据准备**：收集预测结构与天然结构文件，确保二者对应同一蛋白质序列，文件格式正确且原子信息完整。

2. **样本过滤**：对所有待评估蛋白质执行基线比对，筛选出基线 TM-score 超过设定阈值（如 0.7）的子集。过滤的目的是排除基线模型本身表现极差的蛋白质（如内在无序区域），这些蛋白质上的小幅度变化难以产生有统计意义的差异。阈值 0.7 适用于 OpenFold 标准运行的基线；其他基线模型或评测体系应根据自身分布特征重新设定。

3. **结构比对与评分**：对过滤后的每一对（预测结构, 天然结构）调用比对工具计算 TM-score。命令行示例：
   ```
   US-align prediction.pdb native.pdb -TMscore -chain 1
   ```
   或使用 TM-align：
   ```
   TM-align prediction.pdb native.pdb
   ```
   工具输出中定位 "TM-score = X.XXXX" 行获取数值。

4. **差异计算**：对于消融实验，对同一批蛋白质分别计算基线配置和变更配置的 TM-score，逐蛋白求差值得到 ΔTM，再汇总统计均值、标准差和显著性。

5. **结果汇总**：输出逐蛋白的 TM-score 表格、组间 ΔTM 分布统计、以及可视化图表（如直方图、散点图）。

## 边界与分流

- **评估对象为蛋白质复合物时**：标准 TM-score 针对单链设计。多链复合物应使用链间比对模式（US-align 支持 `-het` 参数处理异源多链），或采用 DockQ、CAPRI 等复合物专用指标。
- **评估对象为短肽（< 30 残基）时**：TM-score 对短序列的统计区分度较低，建议结合 lDDT 或 GDT-TS 等补充指标。
- **仅关注局部结构精度时**：TM-score 侧重全局拓扑相似性，局部细节精度（如侧链构象）应辅以 lDDT、contacts Precision 等局部指标。
- **与 CAMEO 等在线评测平台的衔接**：CAMEO 等平台提供周期性的盲测评估，其评测逻辑与本流程一致，但数据获取和提交方式有特定规范。

## 质量检查

- **比对工具输出校验**：确认 TM-score 值落在 [0, 1] 区间内；若输出为负值或异常大值，通常是结构文件解析错误。
- **序列一致性检查**：确保预测结构与天然结构为同一蛋白质序列。若序列不同，比对结果无意义。可通过序列比对工具（如 BLAST 或 mmseqs2）预验证。
- **链 ID 匹配**：PDB 文件中的链 ID 需在比对时正确指定，否则工具可能仅比对部分链或匹配错误链。
- **过滤阈值合理性**：0.7 阈值为经验值，应检查过滤后的样本量是否充足（通常需数百个蛋白质以上以保证统计功效）。样本量过少时应降低阈值或补充数据。

## 回退策略

- **结构文件格式错误**：使用 Open Babel 或 pdb-tools 等工具进行格式转换与修复；对缺失原子的结构使用 Modeller 或 other 补全工具进行修复后重新评分。
- **比对失败（链 ID 不匹配等）**：检查 PDB 文件头部的链 ID 信息，使用 US-align 的 `-chain` 参数显式指定比对链；或使用 pdb-tools 重命名链 ID。
- **评估蛋白质与训练集重叠**：若被评估的预测模型曾使用目标蛋白质的同源序列进行训练，评估结果将产生乐观偏差。应通过序列相似性搜索（如 HHblits）排查训练集与评估集的同源重叠，并剔除或单独报告。
- **基线 TM-score 过低**：若某蛋白质在所有配置下基线 TM-score 均低于阈值，说明该蛋白质对当前预测方法极具挑战性，可将其归入"困难子集"单独分析，而非直接纳入主报告。

## 资源召回建议

- **比对工具**：US-align（推荐，速度快且支持多种比对模式）、TM-align（经典工具，结果与 US-align 兼容）。
- **结构文件处理**：pdb-tools（Python 库，用于 PDB 文件解析与编辑）、Open Babel（多格式分子结构转换）。
- **统计分析**：SciPy（用于配对 t 检验或 Wilcoxon 检验评估 ΔTM 显著性）、Matplotlib / seaborn（可视化）。
- **评测数据集**：CAMEO（在线盲测平台）、CASP（蛋白质结构预测竞赛官方评测集）、PDB 中的最新实验结构。
