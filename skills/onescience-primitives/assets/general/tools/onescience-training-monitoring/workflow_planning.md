# 训练监控接入与交接

用户明确要求或持久化任务已要求监控时消费本资源。普通训练不主动添加监控；查看和诊断不授权运行训练。

1. 由任务卡确认实际训练入口、统计口径、框架/rank、更新与恢复边界。
2. coder 获取本卡 spec/usage 的真实正文，按对应兼容范围生成代码；知识不足请求补召回或版本化重蒸馏，不要求用户提供 OneScience 源码。
3. OneCode 中同时召回 contracts/onecode-training-monitoring，交付项目配置和平台接入；其他宿主只消费通用 API，不引入平台身份依赖。
4. 获准运行时 installer 查询目标环境能力并区分业务必需依赖与可选监控依赖；runtime 复用原执行通道，监控失败不阻断训练。
5. 逐项记录 accepted、close、verify 与用户要求的补充指标；OneCode 采集和展示另行取证，不以组件验证代替页面成功。

未完成仅报告相应缺口，不自动安装、不替换 writer、不重训。源码核对仅属于知识维护/蒸馏，不属于普通编码步骤。来源与适用范围见 source.json；引用只用于维护追踪。
