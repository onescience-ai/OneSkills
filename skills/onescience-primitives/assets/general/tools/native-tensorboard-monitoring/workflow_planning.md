# 原生后端交接

OneScience 监控接口兼容且初始化成功时优先使用；缺包、接口/依赖不兼容或初始化失败时使用原生 TensorBoard。两者均不可用时告警并继续已获准的训练。后端在初始化时确定，训练中不反复切换；显式关闭监控时不初始化任一后端。监控异常不改变训练退出码、不触发重训，真实训练异常正常传播。

复用当前 attempt 的身份和事件目录，训练写标准 TensorBoard 事件后由既有采集链路处理；结束时 flush/close。原生基础 DDP 只记录 rank 0，不启动 OneScience 汇总器。

正常训练不额外执行 verify。明确要求诊断时再读取监控诊断契约；不为检查事件而重训。
