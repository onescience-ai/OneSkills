# CLI 非交互执行与故障分类

## 适用范围

本卡片适用于需要在自动化、批处理、CI/CD 或远程 SSH 环境中可靠执行命令行工具的场景。包括：脚本调用外部 CLI 工具、自动化测试中的命令执行、科学计算工作流中的工具链调度。不适用于交互式终端使用（如需要用户输入的命令）或图形界面工具。

## 输入

- CLI 命令及其参数
- 执行环境配置（shell 类型、工作目录、环境变量）
- 超时设置（可选）
- 沙箱/隔离要求（可选）

## 输出

- 退出码（exit code）
- 标准输出（stdout）
- 标准错误（stderr）
- 执行状态分类（成功/失败/超时/被杀）

## 流程节点

### 1. 命令构建与转义
- 操作：将命令和参数组装为可执行字符串
- 参数：命令名、参数列表、shell 类型
- 工具：subprocess（Python）、os.system、shell 脚本
- 质量门禁：参数正确转义，避免注入风险

### 2. 执行环境配置
- 操作：设置工作目录、环境变量、shell 类型
- 参数：cwd、env、shell（bash/sh/powershell）
- 质量门禁：环境变量不包含敏感信息

### 3. 超时控制
- 操作：设置最大执行时间，超时后强制终止
- 参数：timeout（秒）
- 质量门禁：超时值合理，避免过短导致误杀或过长导致阻塞

### 4. 进程执行与监控
- 操作：启动子进程，等待完成或超时
- 工具：subprocess.Popen、subprocess.run
- 质量门禁：进程正确启动，无立即崩溃

### 5. 退出码解析
- 操作：根据退出码判断执行结果
- 退出码语义：
  - 0：成功
  - 1-125：应用程序错误（具体含义由程序定义）
  - 126：命令无法执行（权限问题）
  - 127：命令未找到
  - 128+N：被信号 N 终止（如 130=SIGINT, 137=SIGKILL, 143=SIGTERM）
  - 255：退出码超出范围
- 质量门禁：退出码被正确捕获和解释

### 6. 标准错误判读
- 操作：分析 stderr 输出，识别错误类型
- 常见错误模式：
  - 权限拒绝（Permission denied）
  - 文件不存在（No such file or directory）
  - 参数错误（invalid option, missing argument）
  - 资源不足（out of memory, disk full）
  - 网络错误（connection refused, timeout）
- 质量门禁：错误信息被正确提取和分类

### 7. 故障分类与恢复
- 操作：根据退出码和错误信息确定故障类别，选择恢复策略
- 故障类别：
  - 可重试错误（如网络超时、资源临时不足）
  - 不可重试错误（如语法错误、文件不存在）
  - 环境错误（如依赖缺失、权限不足）
- 质量门禁：恢复策略与故障类别匹配

## 关键参数

| 参数 | 典型值 | 说明 |
|------|--------|------|
| timeout | 30-300 秒 | 根据命令复杂度调整 |
| shell | bash/sh/powershell | 根据平台选择 |
| retries | 0-3 | 可重试错误的最大重试次数 |
| encoding | utf-8 | stdout/stderr 编码 |
| errors | replace | 编码错误处理策略 |

## 边界与分流

- **权限不足**：检查命令是否需要 sudo 或特定用户权限
- **命令不存在**：检查 PATH 环境变量或使用绝对路径
- **超时频繁**：增加 timeout 值或优化命令性能
- **输出编码错误**：设置正确的 encoding 参数或使用 errors='replace'

## 质量检查

- 退出码捕获：subprocess.run 返回的.returncode
- stderr 捕获：subprocess.run 的 stderr=subprocess.PIPE
- 输出解码：使用正确的 encoding 参数
- 进程清理：确保子进程正确终止，无僵尸进程

## 回退策略

- 若 CLI 工具不可用，检查安装状态或提供安装指引
- 若超时，记录日志并尝试降级执行（如跳过非关键步骤）
- 若权限不足，记录所需权限并请求用户授权
