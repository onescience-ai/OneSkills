# when_to_use

Use this primitive when a task needs scientific figure design, plotting, export planning, accessibility review, or image metadata validation.

# when_not_to_use

- Use a domain-specific visualization primitive when specialized structure rendering or field visualization dominates.
- Use a report/output-format primitive when the main task is assembling a document rather than designing figures.
- Use a data-analysis primitive when the statistics have not yet been computed.

# planning_steps

1. Confirm evidence source, target medium, and expected output formats.
2. Select the visual encoding from variable semantics.
3. Plan uncertainty, missing data, transformations, and accessibility cues.
4. Implement with scoped plotting styles and explicit export settings.
5. Inspect rendered outputs and record provenance.

# fallback

- If journal requirements are unknown, make a provisional general figure and mark publisher choices pending.
- If accessibility cannot be fully verified, provide a conservative alternative and source data.
- If the data transformation is unclear, pause at a figure specification.

# handoff_notes

Include source data, figure purpose, target medium, size, formats, uncertainty definition, palette policy, and inspection criteria.
