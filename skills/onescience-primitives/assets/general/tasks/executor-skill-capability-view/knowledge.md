# 所有executor技能的完整能力视图

## 适用范围
本任务提供所有OneScience executor技能的完整能力视图，包括输入要求、输出产物、负责事项、不负责事项、下游交接对象等。适用于任务编排系统的技能调度、任务拆分和能力查询。

不适用场景：技能内部实现细节、技能开发、技能部署。

## 任务目标
1. 建立完整的executor技能能力台账
2. 明确每个技能的输入输出契约
3. 定义技能间的交接关系
4. 支持orchestrator准确的任务拆分和调度

## 输入契约
**必需输入**：
- 所有executor技能的SKILL.md文件路径
- 技能目录结构
- 技能依赖关系

**可选输入**：
- 技能使用历史数据
- 技能性能指标
- 技能错误日志

**数据格式要求**：
- SKILL.md文件：标准Markdown格式
- 技能目录：按技能类型组织
- 依赖关系：JSON或YAML格式

## 输出契约
**必需输出**：
- executor_inventory.json：完整的executor能力台账
- 技能能力矩阵：输入输出契约对照表
- 技能交接关系图：下游交接对象映射

**输出格式**：
- 能力台账：JSON格式
- 能力矩阵：JSON或CSV格式
- 交接关系：JSON格式或图形化表示

## 方法路线
### 阶段1：技能发现与枚举
1. **目录扫描**：扫描skills目录，识别所有executor技能
2. **技能分类**：按类型分类（expert/executor）
3. **技能验证**：验证SKILL.md文件存在性和格式正确性
4. **技能清单**：生成all_executor_skills列表

### 阶段2：能力信息提取
1. **SKILL.md解析**：从每个技能的SKILL.md中提取关键信息
2. **输入要求提取**：识别必需输入、可选输入、数据格式
3. **输出产物提取**：识别必需输出、可选输出、验证标准
4. **负责事项提取**：明确技能职责范围
5. **不负责事项提取**：明确技能边界
6. **下游交接对象提取**：识别技能间交接关系

### 阶段3：能力台账构建
1. **数据结构化**：将提取的信息结构化为JSON格式
2. **完整性验证**：确保所有技能都被查询
3. **一致性检查**：检查技能间交接关系的一致性
4. **版本管理**：记录能力台账版本和更新时间

### 阶段4：能力应用支持
1. **查询接口**：提供能力查询接口
2. **调度建议**：基于能力台账提供调度建议
3. **冲突检测**：检测技能能力冲突
4. **优化建议**：提供技能使用优化建议

## 操作序列
1. **技能发现**：扫描skills目录，识别所有executor技能

## 边界与分流
- **技能发现失败**：记录失败技能，使用默认能力台账
- **能力信息提取失败**：使用部分提取信息，标记缺失字段
- **交接关系识别失败**：使用默认交接关系，标记不确定关系
- **台账更新失败**：使用历史台账，标记过期信息
- **查询接口故障**：提供降级查询接口

## 质量检查
**验证点**：
1. 技能发现完整性：是否找到所有executor技能
2. 能力信息完整性：是否提取了所有必要字段
3. 交接关系准确性：技能间交接关系是否正确
4. 台账格式正确性：JSON格式是否正确
5. 查询接口可用性：查询接口是否正常工作

**阈值**：
- 技能发现完整率 = 100%
- 能力信息提取完整率 = 100%
- 交接关系完整率 = 100%
- 查询响应时间 ≤ 1秒

**失败处理**：
- 技能发现失败：记录日志，使用默认技能列表
- 能力信息提取失败：标记缺失字段，使用部分信息
- 交接关系识别失败：标记不确定关系，使用默认关系
- 台账更新失败：使用历史台账，标记过期
- 查询接口故障：提供降级接口，记录故障
