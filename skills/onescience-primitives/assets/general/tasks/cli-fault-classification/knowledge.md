# CLI 非交互执行与故障分类

## 适用范围
在自动化工作流中通过命令行接口（CLI）调用外部工具时，需要处理非交互执行环境下的各类故障。适用于科研计算中需要批量调用 CLI 工具、自动化测试、CI/CD 管道等场景。不适用于交互式终端操作或图形界面程序。

## 输入
- CLI 命令字符串及参数
- 执行环境配置（工作目录、环境变量、超时阈值）
- 预期退出码语义（0=成功，非0=失败的含义定义）

## 输出
- 执行状态：success（退出码 0）、failed（非 0 退出码）、timeout（超时终止）、error（启动失败）
- 错误分类：可恢复（临时故障、资源不足）vs 不可恢复（参数错误、依赖缺失）
- 诊断信息：stdout 内容、stderr 内容、退出码、执行耗时

## 流程节点
1. **命令构建与参数校验** → 检查命令字符串、参数合法性、路径是否存在
2. **执行环境准备** → 设置工作目录、环境变量、子进程组（便于超时终止）
3. **超时监控启动** → 设置 watchdog 计时器，超时后发送终止信号
4. **进程执行与输出捕获** → 同步/异步执行，捕获 stdout 和 stderr
5. **退出码解析** → 读取进程退出码，对照预定义语义表分类
6. **故障分类与重试决策** → 根据退出码和错误信息判断是否可恢复

## 关键参数

### 通用判据
| 参数 | 推荐值 | 来源 | 说明 |
|------|--------|------|------|
| 超时阈值 | 根据任务复杂度设定（简单命令 30s，复杂计算 3600s） | [1] | 超时后应终止进程并记录超时错误 |
| 退出码 0 | 成功 | POSIX 标准 | 所有 POSIX 兼容系统通用 |
| 退出码 1-125 | 一般错误 | POSIX 标准 | 应检查 stderr 获取详细信息 |
| 退出码 126 | 命令不可执行 | POSIX 标准 | 权限问题或不是可执行文件 |
| 退出码 127 | 命令未找到 | POSIX 标准 | PATH 问题或命令不存在 |
| 退出码 128+N | 被信号 N 终止 | POSIX 标例 | N=9 表示 SIGKILL（可能 OOM） |
| 退出码 130 | 被 Ctrl+C 终止 | POSIX 标准 | SIGINT 信号 |
| 退出码 255 | 退出码溢出 | POSIX 标准 | 超出 0-255 范围时取模 |

### 校准数值
以下数值来自软件工程实践文献，供量级校准；其他体系需以自身证据重新锚定：
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 错误处理代码覆盖率 | <20% | [2] | 大多数软件项目错误处理代码占比低 |
| API 错误处理缺陷率 | ~30% | [3] | 通过模糊测试发现的 API 错误处理问题比例 |
| 超时终止信号序列 | SIGTERM → 等待 → SIGKILL | [1] | 优雅终止的标准流程 |

## 边界与分流
- **退出码 126/127**：不可恢复，应检查命令路径和环境配置，不重试
- **退出码 128+9 (SIGKILL)**：可能 OOM，可尝试减少资源使用后重试
- **超时**：可恢复，可增加超时阈值或优化命令性能后重试
- **退出码 1-125**：需检查 stderr 内容判断是否为临时故障
- **stderr 含 "permission denied"**：不可恢复，需修改文件权限
- **stderr 含 "no such file"**：不可恢复，需检查路径配置

## 质量检查
- 所有 CLI 调用必须记录退出码、stdout、stderr、执行耗时
- 超时阈值应根据历史执行时间动态调整
- 重试策略应有最大重试次数限制（建议 ≤3 次）
- 连续失败应触发告警并暂停后续执行

## 回退策略
- CLI 工具不可用时：检查环境配置、依赖安装状态
- 超时持续发生：增加超时阈值或联系工具维护者
- 退出码语义不明：查阅工具文档或源码中的 exit() 调用

## 资源召回建议
当任务涉及以下场景时应召回本卡片：
- 调用外部 CLI 工具（如 GROMACS、LAMMPS、OpenBabel）
- 自动化工作流中需要处理执行失败
- CI/CD 管道中的命令执行监控
- 批量任务中的故障隔离与恢复
