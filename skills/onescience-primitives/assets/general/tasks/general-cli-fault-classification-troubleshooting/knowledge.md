# CLI 非交互执行与故障分类

## 适用范围
面向命令行工具在自动化、批处理或非交互环境中的执行场景，涵盖命令启动、退出码捕获、故障类型识别、错误恢复策略制定及诊断证据保留。适用于任何需要在无用户交互条件下稳定运行CLI命令的系统，包括科学计算流水线、CI/CD作业、数据处理脚本等。

## 输入
- CLI命令及参数
- 执行环境信息（操作系统、Shell类型、权限级别）
- 超时配置（可选）
- 重试策略配置（可选）

## 输出
- 命令执行结果（stdout/stderr）
- 退出码（exit code）
- 故障分类标签（成功/非零退出/超时/信号中断）
- 诊断日志（时间戳、命令、参数、退出码、错误信息）

## 流程节点
1. 命令构建与参数验证 → 2. 执行环境检查 → 3. 命令启动与监控 → 4. 退出码捕获与分类 → 5. 故障诊断与日志记录 → 6. 恢复策略执行

### 步骤详解

**步骤1：命令构建与参数验证**
- 操作：拼接命令字符串，验证参数格式，处理特殊字符转义
- 参数：命令模板、参数列表
- 工具：Shell解析器
- 质量门禁：参数通过shell语法校验，无注入风险

**步骤2：执行环境检查**
- 操作：检查工作目录、环境变量、依赖工具可用性
- 参数：工作目录路径、环境变量配置
- 工具：系统检测命令
- 质量门禁：所有必要环境条件满足

**步骤3：命令启动与监控**
- 操作：启动子进程，设置超时监控，收集stdout/stderr
- 参数：超时时间、缓冲区大小
- 工具：子进程管理器
- 质量门禁：进程正常启动，资源消耗在预期范围内

**步骤4：退出码捕获与分类**
- 操作：等待进程结束，捕获退出码，执行故障分类
- 参数：退出码、信号信息
- 工具：进程状态检测
- 质量门禁：退出码被正确捕获并分类

**步骤5：故障诊断与日志记录**
- 操作：根据退出码分类故障类型，记录诊断信息
- 参数：退出码、stderr内容、执行时长
- 工具：日志系统
- 质量门禁：诊断信息完整，可追溯

**步骤6：恢复策略执行**
- 操作：根据故障类型选择恢复策略（重试/跳过/终止/降级）
- 参数：故障类型、重试次数、降级选项
- 工具：恢复策略引擎
- 质量门禁：恢复策略正确执行，系统状态恢复稳定

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码 0 | 成功 | [1] | 命令正常完成 |
| 退出码 1-125 | 应用错误 | [1] | 命令执行失败，具体含义由应用定义 |
| 退出码 126 | 权限错误 | [1] | 命令不可执行或无权限 |
| 退出码 127 | 命令未找到 | [1] | 命令不存在或PATH配置错误 |
| 退出码 128+n | 信号中断 | [1] | 命令被信号n终止（如n=9为SIGKILL） |
| 退出码 130 | Ctrl+C中断 | [1] | 命令被用户中断（SIGINT） |
| 退出码 143 | 正常终止 | [1] | 命令被SIGTERM终止 |

### 校准数值
以下数值来自特定CLI执行场景，供量级校准；其他场景需以自身证据重新锚定：
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认超时时间 | 30秒 | [3] | 防止命令无限挂起 |
| 重试次数上限 | 3次 | [3] | 避免无限重试 |
| stderr缓冲区大小 | 4KB | [2] | 捕获足够错误信息 |

## 边界与分流
- **前提1：命令可执行** → 若命令不存在或无权限，转向环境配置检查流程
- **前提2：环境资源充足** → 若资源不足（内存、磁盘），转向资源清理或降级流程
- **前提3：网络可达** → 若命令需要网络访问且不可达，转向离线模式或等待重试
- **前提4：超时配置合理** → 若超时过短导致误判，转向超时参数调整

## 质量检查
- 验证点1：所有退出码被正确捕获和分类
- 验证点2：诊断日志包含足够的故障定位信息
- 验证点3：恢复策略在预期时间内完成
- 验证点4：系统状态在恢复后保持稳定
- 失败处理：若检查失败，记录失败原因并触发人工干预

## 回退策略
- 重试策略：对于瞬态故障（如网络抖动），最多重试3次，间隔递增
- 跳过策略：对于非关键命令，记录警告后继续执行
- 降级策略：对于可替代命令，切换到备选实现
- 终止策略：对于不可恢复错误，安全终止并清理资源
