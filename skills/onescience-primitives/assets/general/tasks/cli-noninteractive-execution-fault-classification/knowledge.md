# CLI 非交互执行与故障分类

## 适用范围
适用于自动化脚本、CI/CD流水线、批处理任务等非交互式CLI执行场景，需要诊断和分类执行故障以修正启动配置或恢复策略。

## 输入
- 命令行命令及参数
- 执行环境信息（操作系统、shell、权限）
- 可选的沙箱/容器配置
- 可选的超时设置

## 输出
- 退出码（exit code）
- 标准错误（stderr）输出
- 可选的日志文件
- 故障分类结果（参数错误、认证失败、沙箱限制、超时、运行时错误等）

## 流程节点
1. **命令解析** → 检查命令语法、参数格式、环境变量
2. **执行环境验证** → 确认权限、依赖、沙箱配置
3. **执行与监控** → 运行命令并监控退出码、信号、超时
4. **退出码分析** → 根据退出码分类故障类型（0=成功，1=通用错误，2=误用shell命令，126=权限问题，127=命令未找到，128+N=信号终止）
5. **标准错误解析** → 提取错误信息、堆栈跟踪、警告
6. **故障分类** → 将故障归类为参数错误、认证失败、沙箱限制、超时、资源不足、运行时错误等
7. **恢复策略** → 根据分类选择修正方案（修正参数、重试、降级、报警）

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| exit_code_0 | 0 | [D2] | 成功退出 |
| exit_code_1 | 1-255 | [D2] | 通用错误码，具体含义由程序定义 |
| exit_code_126 | 126 | [D2] | 命令不可执行（权限问题） |
| exit_code_127 | 127 | [D2] | 命令未找到 |
| exit_code_128+N | 128+signal | [D2] | 被信号N终止（如SIGTERM=143） |
| SIGTERM | 15 | [D2] | 终止信号，用于优雅停止 |
| SIGKILL | 9 | [D2] | 强制终止，不可捕获 |
| timeout_seconds | 可配置 | 通用 | 非交互执行的超时限制 |
| sandbox_mode | docker, firejail, 等 | 通用 | 沙箱环境限制 |

## 边界与分流
- **退出码非标准**：某些程序使用非标准退出码，需查阅程序文档
- **信号终止**：区分正常终止（SIGTERM）和强制终止（SIGKILL）
- **沙箱限制**：沙箱可能限制网络、文件系统、进程等，导致特定错误
- **超时处理**：超时后需决定是否重试、终止或记录日志
- **认证失败**：可能涉及密码、令牌、证书等，需安全处理

## 质量检查
- 验证退出码是否在预期范围内
- 检查标准错误是否包含关键错误信息
- 确认故障分类是否准确
- 验证恢复策略是否匹配故障类型

## 回退策略
- 若无法分类，记录详细日志并人工介入
- 若恢复策略失败，尝试降级方案或报警
- 若沙箱限制导致，调整沙箱配置或使用替代环境
