# CLI 非交互执行与故障分类知识

## 适用范围
适用于需要在非交互环境下（如自动化流水线、后台服务、CI/CD 系统）执行命令行工具并处理执行失败的场景。覆盖命令参数配置、认证机制、沙箱隔离、超时控制、退出码语义和标准错误判读等核心知识。不扩展到具体任务领域的结论生成。

## 输入
- 命令行工具的调用参数与选项
- 执行环境配置（认证、沙箱、超时设置）
- 标准输出与标准错误流

## 输出
- 执行状态（成功/失败/超时）
- 退出码与对应故障类别
- 标准错误内容的结构化解析

## 流程节点
1. **参数准备** → 构造命令行参数，验证必填选项
2. **环境配置** → 设置认证令牌、沙箱权限、超时阈值
3. **命令执行** → 启动子进程，捕获标准输出和标准错误
4. **状态检测** → 读取退出码，判断执行结果
5. **故障分类** → 根据退出码和标准错误内容分类故障类型
6. **诊断记录** → 保留完整日志用于后续分析

每步含：操作、参数、工具、质量门禁

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码 0 | 成功 | [论文1] | 命令正常完成 |
| 退出码 1 | 通用错误 | [论文1] | 未指定的执行错误 |
| 退出码 2 | 用法错误 | [论文1] | 命令参数无效 |
| 退出码 126 | 权限错误 | [论文1] | 命令不可执行 |
| 退出码 127 | 命令未找到 | [论文1] | 命令不存在 |
| 退出码 128+n | 信号终止 | [论文1] | 被信号 n 终止 |
| 退出码 130 | 中断 (Ctrl+C) | [论文1] | 用户中断 |
| 退出码 137 | OOM 终止 | [论文1] | 内存不足被杀 |

### 校准数值
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认超时 | 30s | [论文2] | 外部服务调用超时阈值 |
| 最大重试次数 | 3 | [论文2] | 超时后重试上限 |
| 退出码阈值 | <128 | [论文3] | 区分错误与信号终止 |

## 边界与分流
- **认证失败**（退出码 1 + 权限错误信息）→ 检查认证令牌有效性，刷新令牌后重试
- **超时**（退出码 124 或无退出码）→ 增加超时阈值或优化命令性能
- **沙箱拒绝**（退出码 126）→ 调整沙箱权限配置
- **命令不存在**（退出码 127）→ 验证命令路径和环境变量

## 质量检查
- 验证退出码是否在预期范围内
- 检查标准错误是否包含关键故障信息
- 确认超时设置与命令执行时间匹配
- 验证诊断日志完整性

## 回退策略
- 退出码异常时，记录完整环境快照
- 超时失败时，降级到简化版命令或跳过该步骤
- 权限错误时，切换到备用认证方式
