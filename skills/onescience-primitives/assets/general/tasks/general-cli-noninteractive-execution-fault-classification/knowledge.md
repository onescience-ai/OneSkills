# 命令行界面非交互执行与故障分类

## 适用范围
适用于需要以非交互方式（脚本、CI/CD、自动化流水线）执行命令行工具，并对其进行故障诊断和分类的场景。涵盖命令参数设计、认证、沙箱、超时、退出码处理、标准错误判读等关键环节，不扩展到具体领域结论。

## 输入
- 目标CLI工具或脚本
- 执行环境（本地、远程SSH、容器、SLURM作业）
- 预期输入数据与参数
- 故障现象描述（退出码、错误信息、超时等）

## 输出
- CLI执行结果（成功/失败）
- 结构化故障分类报告（错误类型、原因、建议修复动作）
- 诊断日志（包含退出码、标准错误、超时信息）

## 流程节点
1. **命令构建** → 参数解析、引号转义、环境变量设置
2. **执行通道选择** → 本地进程、SSH、容器、SLURM作业提交
3. **超时控制** → 设置合理超时时间，捕获超时异常
4. **退出码捕获** → 读取进程退出码，映射到故障类别
5. **标准错误分析** → 解析stderr输出，提取错误关键词
6. **故障分类** → 根据退出码和错误信息分类：认证失败、权限不足、资源不足、依赖缺失、超时、配置错误等
7. **恢复策略** → 根据故障类别选择重试、降级、告警或终止

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 超时时间 | 根据任务复杂度设置（秒） | [1] | 避免无限等待，防止资源泄漏 |
| 退出码映射 | 0=成功，1=一般错误，2=用法错误，126=权限问题，127=命令未找到，128+信号=被信号终止 | [1] | 标准Unix退出码约定 |
| 重试次数 | 3次（指数退避） | [1] | 应对临时性网络或资源故障 |
| 标准错误缓冲 | 实时捕获或重定向到文件 | [1] | 便于事后分析 |

## 边界与分流
- **认证失败**（退出码1/错误信息含"unauthorized"、"permission denied"）→ 检查凭证、重新认证
- **资源不足**（退出码137/错误信息含"out of memory"、"disk full"）→ 申请更多资源或清理空间
- **超时**（进程被信号15终止）→ 增加超时时间或优化任务拆分
- **依赖缺失**（退出码127/错误信息含"command not found"）→ 安装缺失依赖或检查PATH
- **配置错误**（退出码2/错误信息含"invalid argument"）→ 检查命令参数和配置文件

## 质量检查
- 验证退出码是否在预期范围内
- 检查标准错误是否包含关键错误信息
- 确认超时设置是否合理（任务执行时间 < 超时时间）
- 测试故障恢复策略是否有效

## 回退策略
- 退出码无法识别时，记录原始退出码和错误信息，归类为"未知错误"
- 标准错误为空时，检查是否重定向到了其他文件
- 超时设置不合理时，采用动态超时（基于历史执行时间）
