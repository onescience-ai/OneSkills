# CLI非交互执行与故障分类

## 适用范围
适用于CLI工具在非交互环境（如自动化脚本、CI/CD流水线、远程执行）中的故障诊断与恢复。涵盖命令参数解析、认证、沙箱、超时、退出码和标准错误判读。

## 输入
- CLI命令字符串及其参数
- 执行环境信息（操作系统、shell类型、权限）
- 错误输出（stderr）和退出码

## 输出
- 故障分类（如参数错误、认证失败、超时、资源限制、权限问题）
- 诊断报告（包含错误原因、可能解决方案）
- 恢复建议（如重试策略、配置调整）

## 流程节点
1. 命令执行与捕获 → 2. 退出码分析 → 3. 标准错误解析 → 4. 故障分类 → 5. 恢复建议生成
每步含：操作、参数、工具、质量门禁

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码 | 0-255 | 操作系统规范 | 0表示成功，非0表示失败 |
| 超时 | 可配置 | 用户设置 | 命令执行最大时间 |
| 重试次数 | 可配置 | 用户设置 | 失败后重试次数 |

## 边界与分流
- 退出码为0：视为成功，无需诊断
- 退出码126-127：权限问题或命令未找到
- 退出码128+N：信号终止（N为信号编号）
- 超时：强制终止并记录超时错误
- 沙箱限制：权限不足时提示调整沙箱配置

## 质量检查
- 验证退出码是否在预期范围内
- 检查标准错误是否包含关键错误信息
- 确认故障分类是否准确（通过对比已知错误模式）

## 回退策略
- 重试：对于暂时性错误（如网络超时），可重试
- 降级：对于永久性错误，尝试简化命令或使用替代方案
- 报告：生成详细错误报告供人工干预
