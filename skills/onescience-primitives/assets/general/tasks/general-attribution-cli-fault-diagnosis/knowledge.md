# 归因分析CLI非交互执行与故障分类

## 适用范围
适用于归因分析CLI工具在非交互环境中执行时的故障诊断与恢复。覆盖命令参数错误、认证失败、沙箱限制、超时、退出码判读和标准错误解析，用于修正启动配置或恢复策略，确保归因分析进程稳定完成并保留诊断证据。

## 输入
- 归因分析CLI命令行
- 命令行参数（含标志、选项、位置参数）
- 环境配置（环境变量、conda/venv路径、认证凭证）
- 超时阈值（最大允许执行时间）
- 工作目录

## 输出
- 退出码（exit code）
- 标准输出（stdout）
- 标准错误（stderr）
- 执行元数据（耗时、内存、信号记录）

## 流程节点
### 1. 命令构建与校验
- 组装归因分析CLI命令行
- 校验可执行文件存在且有执行权限
- 检查conda/虚拟环境是否已激活
- 参数特殊字符转义

### 2. 进程启动（非交互模式）
- 使用`subprocess.Popen`启动子进程
- 设置`stdin=subprocess.DEVNULL`阻止等待用户输入
- 重定向stdout/stderr到管道或文件
- 设置`start_new_session=True`使子进程独立于父进程会话

### 3. 超时监控与强制终止
- 设置`timeout`参数
- 超时触发时发送`SIGTERM`，等待宽限期后发送`SIGKILL`
- 记录超时事件：进程ID、已运行时间、超时阈值

### 4. 退出码分类与判读
| 退出码范围 | 含义 | 典型故障 | 响应策略 |
|---|---|---|---|
| 0 | 成功 | - | 继续流水线 |
| 1 | 一般错误 | 业务逻辑异常、数据校验失败 | 检查stderr中的具体错误信息 |
| 2 | 用法错误 | 参数缺失或格式错误 | 校验命令行参数构建逻辑 |
| 126 | 权限拒绝 | 文件不可执行、沙箱限制 | 检查文件权限和沙箱配置 |
| 127 | 命令未找到 | PATH未设置、依赖缺失 | 检查环境变量和conda激活 |
| 128+N | 信号终止 | OOM(9)、段错误(11)、超时(15) | 根据信号类型调整资源限制或超时阈值 |
| 130 | Ctrl+C (SIGINT) | 用户中断 | 重试或标记为中断 |
| 143 | SIGTERM | 优雅终止请求 | 检查是否有外部进程终止信号 |

### 5. 标准错误流解析
- 捕获stderr全文输出
- 按错误模式分类：Python traceback、segmentation fault、OOM killer、conda环境错误
- 提取关键错误信息用于自动化诊断
- 对stderr进行正则匹配，识别已知错误模式

### 6. 故障恢复策略
- **可重试错误**（退出码1、超时、临时网络错误）：指数退避重试，最大3次
- **环境错误**（退出码126、127）：触发环境修复流程
- **不可恢复错误**（退出码134、139）：记录诊断快照，标记任务失败
- **部分失败**：检查输出文件完整性，决定是否使用部分结果

## 关键参数
### 通用判据
| 参数 | 推荐值 | 来源 | 说明 |
|------|--------|------|------|
| 超时宽限期 | 5-10s | POSIX惯例 | SIGTERM后等待进程清理的时间 |

## 边界与分流
- **认证失败**（exit 1 + "unauthorized"/"token expired"）：触发认证刷新流程，不重试原始命令
- **沙箱限制**（exit 126 + "permission denied"）：检查沙箱配置，升级权限或切换执行通道
- **资源不足**（exit 137 + SIGKILL）：检查OOM日志，增加内存限制或优化任务
- **依赖缺失**（exit 127 + "command not found"）：触发`onescience-installer`环境修复
- **信号终止**（exit 128+9）：检查是否有外部进程（如SLURM）主动终止

## 质量检查
- 退出码必须与stderr内容一致（exit 0时stderr应为空或仅含警告）
- 超时终止后必须确认进程已完全终止（检查进程表）
- 重试前必须检查部分输出文件，避免覆盖有效结果
- 认证相关错误不应触发盲目重试（需先刷新凭证）

## 回退策略
- 自动重试失败后：降级为手动诊断模式，生成诊断报告
- 环境修复失败后：切换到备用执行通道（如从本地切换到SLURM）
- 超时持续发生：自动调整超时阈值或拆分任务粒度
