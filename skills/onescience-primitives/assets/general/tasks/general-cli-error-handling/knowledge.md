# CLI非交互执行与故障分类

## 适用范围
适用于诊断CLI进程异常退出、未产生有效响应或超时等问题，覆盖命令参数、认证、沙箱、超时、退出码和标准错误判读。不适用于领域特定的科学计算任务结论。

## 输入
- CLI命令及其参数
- 执行环境信息（操作系统、shell类型、依赖版本）
- 错误日志或退出码

## 输出
- 故障分类（参数错误、认证失败、沙箱限制、超时、依赖缺失等）
- 诊断证据（退出码、标准错误输出、日志片段）
- 修复建议（修正启动配置或恢复策略）

## 流程节点
1. **命令参数检查** → 验证命令格式、参数有效性、路径正确性
2. **认证与权限检查** → 验证API密钥、访问令牌、文件权限
3. **沙箱环境检查** → 验证容器限制、网络隔离、资源配额
4. **超时与资源检查** → 监控执行时间、内存使用、CPU负载
5. **退出码分析** → 解读进程退出码（0=成功，非0=错误，特殊码=信号）
6. **标准错误解析** → 提取错误信息、堆栈跟踪、警告消息

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 成功退出码 | 0 | 通用约定 | 进程正常退出 |
| 一般错误退出码 | 1-125 | 通用约定 | 程序检测到的错误 |
| 信号终止退出码 | 126-135 | 通用约定 | 进程被信号终止（128+信号编号） |
| 超时阈值 | 可配置 | 具体任务 | 超过此时间判定为超时 |
| 内存限制 | 可配置 | 具体任务 | 超过此内存判定为资源不足 |

## 边界与分流
- **参数错误**：修正命令格式、参数值或路径
- **认证失败**：检查API密钥、令牌有效性或权限设置
- **沙箱限制**：调整容器配置或使用特权模式
- **超时问题**：增加超时时间或优化执行逻辑
- **依赖缺失**：安装缺失的软件包或库
- **信号终止**：检查系统资源限制或进程信号处理

## 质量检查
- 验证退出码是否符合预期范围
- 检查标准错误输出是否包含关键错误信息
- 确认修复后进程能正常退出（退出码=0）

## 回退策略
- 如果无法诊断具体故障，收集完整日志并联系系统管理员
- 如果问题持续，尝试在隔离环境中复现以排除环境因素
