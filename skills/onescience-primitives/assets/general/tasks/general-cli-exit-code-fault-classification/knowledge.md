# CLI非交互执行与故障分类知识

## 适用范围
适用于需要在自动化、脚本化或远程环境中执行命令行程序（CLI）并诊断其执行故障的场景，包括但不限于：CI/CD流水线、自动化测试框架、远程SSH执行、批处理作业调度等。不适用于交互式会话调试或GUI应用程序。

## 输入
- 命令行程序及其参数
- 执行环境信息（操作系统、shell类型、用户权限）
- 预期的输出格式和退出码

## 输出
- 执行结果（成功/失败状态）
- 退出码（exit code）
- 标准输出（stdout）和标准错误（stderr）
- 故障分类与诊断信息

## 流程节点

### 1. 命令构建与参数解析
- 操作：组装命令行字符串或参数列表
- 参数：程序路径、参数列表、工作目录、环境变量
- 工具：shell（bash/powershell/cmd）、参数解析库
- 质量门禁：参数不包含shell注入字符；路径正确引用

### 2. 执行环境准备
- 操作：验证环境依赖、设置超时、配置沙箱
- 参数：超时时间（秒）、内存限制、CPU限制
- 工具：timeout命令、ulimit、cgroups
- 质量门禁：环境变量完整；依赖项已安装

### 3. 进程执行与监控
- 操作：启动子进程并等待完成
- 参数：执行模式（同步/异步）、输出捕获方式
- 工具：subprocess（Python）、Process（Node.js）、popen（C）
- 质量门禁：进程在超时时间内完成；输出编码正确

### 4. 退出码收集与分类
- 操作：获取进程退出码并分类
- 参数：退出码、信号信息
- 工具：waitpid、WEXITSTATUS宏
- 质量门禁：退出码在有效范围内（0-255）

### 5. 标准输出/错误解析
- 操作：捕获并解析stdout和stderr
- 参数：输出编码、缓冲区大小
- 工具：管道、临时文件
- 质量门禁：输出未被截断；编码正确

## 关键参数

### 退出码语义（POSIX标准）
| 退出码 | 含义 | 来源 | 说明 |
|--------|------|------|------|
| 0 | 成功执行 | POSIX标准 | 程序正常完成 |
| 1 | 通用错误 | POSIX标准 | 未分类的错误 |
| 2 | 用法错误 | POSIX标准 | 命令行参数错误 |
| 126 | 权限问题 | POSIX标准 | 命令不可执行或无执行权限 |
| 127 | 命令未找到 | POSIX标准 | 命令不存在或PATH配置错误 |
| 128+N | 被信号终止 | POSIX标准 | N为信号编号（如130=SIGINT=2） |
| 130 | Ctrl+C终止 | 常见约定 | SIGINT信号（128+2） |
| 137 | OOM终止 | Linux约定 | SIGKILL信号（128+9），通常因内存不足 |
| 143 | 正常终止 | 常见约定 | SIGTERM信号（128+15） |

### 超时处理参数
| 参数 | 推荐值 | 来源 | 说明 |
|------|--------|------|------|
| 默认超时 | 30秒 | 通用约定 | 简单CLI命令 |
| 复杂任务超时 | 300秒 | 通用约定 | 涉及数据处理或网络IO |
| 超时信号 | SIGTERM | POSIX标准 | 先尝试优雅终止 |
| 强制终止延迟 | 5秒 | 最佳实践 | SIGTERM后等待时间 |

## 边界与分流

### 超时处理策略
- **前提**：程序在合理时间内完成
- **不成立时**：使用timeout命令强制终止，收集退出码124
- **降级方案**：记录已产生的输出，分析是否存在死循环或阻塞IO

### 权限问题处理
- **前提**：执行用户具有足够权限
- **不成立时**：检查文件权限、sudo配置、SELinux/AppArmor策略
- **降级方案**：切换用户或调整权限后重试

### 编码问题处理
- **前提**：输出编码与系统locale匹配
- **不成立时**：强制指定UTF-8编码或使用二进制模式读取
- **降级方案**：忽略无法解码的字节

## 质量检查

### 执行前检查
1. 验证程序路径存在且可执行
2. 检查参数格式正确
3. 确认工作目录可访问
4. 验证环境变量完整

### 执行后检查
1. 退出码在预期范围内（成功：0，失败：非0）
2. 输出格式符合预期（JSON/文本/二进制）
3. 无安全警告（如权限拒绝、路径遍历）
4. 无资源泄漏（文件句柄、网络连接）

## 回退策略

### 退出码非0
- 检查stderr输出获取错误信息
- 验证输入参数格式
- 检查依赖项和环境配置
- 查看系统日志（dmesg、/var/log/syslog）

### 输出为空
- 检查程序是否有输出功能
- 验证输出重定向配置
- 检查缓冲区是否已刷新
- 尝试增加超时时间

### 无法捕获输出
- 改用临时文件存储输出
- 检查管道缓冲区大小
- 验证子进程继承配置
- 使用tee命令分流输出
