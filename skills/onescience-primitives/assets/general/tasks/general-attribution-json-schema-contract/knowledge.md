# 归因分析报告JSON Schema交付契约

## 适用范围
适用于验证归因分析报告是否符合预定义的JSON Schema契约，确保报告可解析且包含所有必填字段。用于诊断报告校验错误、字段缺失或类型不匹配等问题，确保report.json与任务身份一致。

## 输入
- 归因分析报告文件（如report.json）
- JSON Schema定义文件（如report-schema.json）
- 任务身份信息（task_id、task名称）

## 输出
- 验证结果（通过/失败）
- 详细错误信息（缺失字段、类型错误、约束违反）
- 修复建议（如何调整报告以满足Schema要求）

## 流程节点
### 1. Schema加载
- 解析JSON Schema定义，识别必填字段和约束
- 识别任务身份字段（task_id、task名称）

### 2. 报告解析
- 读取并解析JSON报告文件
- 检查JSON格式是否正确

### 3. 字段完整性检查
- 验证所有必填字段是否存在
- 检查字段名称是否与Schema定义一致

### 4. 类型与格式检查
- 验证字段值是否符合Schema定义的类型和格式
- 检查字符串字段是否为空字符串
- 检查数组字段是否为空数组

### 5. 任务身份校验
- 验证task_id是否与任务索引一致
- 验证task名称是否与任务name一致
- 检查任务身份字段是否为字符串类型

### 6. 数组约束检查
- 验证数组字段是否符合最小/最大长度约束
- 检查数组元素类型是否正确

### 7. 额外字段检测
- 检查是否包含Schema未定义的额外字段
- 决定是否允许额外字段

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必填字段 | 根据Schema定义 | Schema文件 | 报告必须包含的所有字段 |
| 类型约束 | string/number/array/object等 | Schema文件 | 字段值的类型要求 |
| 数组最小长度 | 根据Schema定义 | Schema文件 | 数组字段的最小元素数 |
| 任务身份字段 | task_id, task | 任务规范 | 必须与任务索引一致 |
| 额外字段策略 | 允许/禁止 | Schema定义 | 是否允许未定义字段 |

## 边界与分流
- **字段缺失**：添加缺失字段到报告中
- **类型错误**：修正字段值类型以符合Schema定义
- **任务身份不匹配**：更新task_id和task名称以匹配任务索引
- **数组约束违反**：调整数组长度以满足最小/最大约束
- **额外字段**：移除Schema未定义的额外字段或更新Schema以包含它们
- **JSON格式错误**：修正JSON语法错误（如缺少逗号、引号）

## 质量检查
- 使用标准JSON Schema验证器进行验证
- 确保所有必填字段都存在且类型正确
- 验证任务身份信息与任务索引一致
- 检查数组约束是否满足
- 确保报告可被标准JSON解析器解析

## 回退策略
- 如果Schema文件缺失或损坏，从备份恢复或重新生成
- 如果验证器不可用，手动检查关键字段和约束
- 如果问题持续，记录详细错误信息并联系Schema维护者
