# typical_workflow

1. Choose create, extract, or edit mode.
2. Use built-in heading and table structures.
3. Preserve images, lists, comments, and tracked changes explicitly.
4. Render the document to PDF or images.
5. Validate package structure and inspect the rendered output.

# usage_notes

- Use real heading styles for table-of-contents support.
- Set table widths on both the table and cells.
- Keep page dimensions explicit.
- Do not assume a generated document is correct without rendering it.
