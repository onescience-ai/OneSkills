# typical_workflow

1. Choose the document template.
2. Write the Markdown structure first.
3. Select the Mermaid diagram type that matches the relationship.
4. Add accessibility title and description where supported.
5. Render a preview and keep any image derivative linked to the Markdown source.

# usage_notes

- Keep one H1 per document.
- Prefer tables for structured comparisons.
- Use Mermaid for workflows, sequences, schemas, timelines, and architectures.
- Commit the Markdown source even when a PNG or SVG derivative is delivered.
