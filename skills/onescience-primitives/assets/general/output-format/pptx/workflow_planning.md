# when_to_use

Use this primitive when creating, editing, or delivering a research presentation, slide deck, poster, or PowerPoint template.

# when_not_to_use

- Use Markdown/Mermaid for source-controlled documentation.
- Use scientific_visualization for a standalone data figure.
- Use DOCX or PDF for report-oriented deliverables.

# planning_steps

1. Confirm audience, aspect ratio, template, and presentation purpose.
2. Map content to varied slide layouts and visual elements.
3. Add charts, figures, notes, and citations with provenance.
4. Render and inspect every slide.
5. Validate OOXML structure, charts, relationships, and placeholder cleanup.

# fallback

- If a template is corrupt, baseline against it and isolate newly introduced faults.
- If a chart type is not native, use a carefully reviewed image with source data retained.
- If text does not fit, split content or change the layout rather than shrinking it into illegibility.

# handoff_notes

Include deck purpose, audience, slide count, template, aspect ratio, source figures/data, notes requirements, and visual inspection criteria.
