# typical_workflow

1. Decide whether to create, edit, or derive from a template.
2. Inspect template layouts before placing content.
3. Build slides with explicit dimensions, text margins, charts, visuals, and notes.
4. Render the deck to images or PDF.
5. Validate package structure and inspect every slide for overflow and overlap.

# usage_notes

- Use native charts when PowerPoint supports the chart type.
- Set the slide layout before adding slides.
- Keep source data and provenance for every chart or figure.
- Never leave placeholder text or clipped content in the final deck.
