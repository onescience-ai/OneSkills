# when_to_use

Use this primitive when finding papers, resolving identifiers, building a bibliography, cleaning BibTeX, or validating references for a manuscript or review.

# when_not_to_use

- Use literature_review for search strategy, screening, and synthesis.
- Use public_database_lookup for non-scholarly database retrieval.
- Use scientific_writing for evidence-bound prose and authorship controls.

# planning_steps

1. Define the paper scope, identifiers, and required metadata.
2. Search authoritative scholarly sources.
3. Resolve and enrich records.
4. Deduplicate and format for the target venue.
5. Validate identifiers and record unresolved fields.

# fallback

- If an identifier fails, search by exact title and author.
- If metadata sources disagree, preserve both records and flag the conflict.
- If a field cannot be verified, mark it unresolved rather than guessing.

# handoff_notes

Include query or identifier, source databases, citation style, target venue, output format, and verification status.
