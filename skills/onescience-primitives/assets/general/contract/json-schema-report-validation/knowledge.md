# JSON Schema 报告交付契约规范

## 适用范围
适用于需要确保结构化报告（如归因报告、分析报告、验证报告）符合特定格式要求的场景，确保报告可被解析、字段完整且与任务身份一致。该契约规范定义了报告必须包含的必填字段、任务身份标识、数组约束及输出格式标准。

## 输入
- 报告内容（JSON格式）
- 任务身份信息（task_id, task_name）
- 报告校验规则（必填字段、数组约束等）

## 输出
- 验证通过的结构化报告
- 校验错误详情（如有）
- 合规性状态

## 流程节点
1. **身份验证** → 检查报告中的 task_id 和 task_name 是否与任务索引一致
2. **必填字段校验** → 验证报告包含所有必需的顶层字段
3. **数组约束检查** → 确保数组字段符合定义的约束条件
4. **格式标准化** → 将报告转换为标准格式
5. **输出生成** → 生成符合契约的最终报告

每步含：操作、参数、工具、质量门禁

## 关键参数

### 通用判据（方法层，同类体系可参考）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必填顶层字段 | ['issues', 'summary', 'task', 'task_id'] | [1] | 报告必须包含这些字段 |
| task_id 一致性 | 必须与任务索引匹配 | [1] | 确保报告与任务身份对应 |
| task 一致性 | 必须与任务 name 一致 | [1] | 确保报告内容与任务描述匹配 |
| summary 类型 | 非空字符串 | [1] | 摘要必须为非空字符串 |
| issues 类型 | 数组 | [1] | issues 必须为数组类型 |

### 校准数值（体系专属值，供量级校准）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| JSON Schema 版本 | Draft 2019-09 或更新 | [1] | 使用现代 JSON Schema 标准 |
| 类型验证精度 | 0-1 范围的分数 | [1] | 数据类型准确性度量 |
| 依赖匹配规则 | 精确集合相等 | [1] | 逻辑依赖必须完全匹配 |

## 边界与分流
- **身份不匹配** → 报告无效，返回错误并要求修正 task_id/task_name
- **必填字段缺失** → 报告无效，返回缺失字段列表
- **数组约束违反** → 报告无效，返回违反约束的具体字段
- **格式不标准** → 尝试标准化转换，失败则返回格式错误
- **非JSON格式** → 拒绝处理，返回格式不支持错误

## 质量检查
1. 报告可被标准 JSON 解析器解析
2. 所有必填字段存在且类型正确
3. 数组字段符合约束条件
4. 任务身份信息与任务索引一致
5. 摘要字段为非空字符串

## 回退策略
- 解析失败 → 尝试修复常见JSON语法错误（如缺少引号、尾随逗号）
- 字段缺失 → 生成最小化报告模板供用户填充
- 身份不匹配 → 保留报告内容但标记身份验证失败
- 格式问题 → 尝试自动格式化，失败则提供格式修正建议
