# JSON Schema 报告交付契约

## 适用范围
适用于需要确保报告结构完整性和任务身份一致性的场景，特别是CLI工具、自动化流水线和LLM代理的输出验证。规定必填字段、任务身份、数组约束及输出格式，确保报告可解析、可校验。

## 输入
- 报告内容（JSON格式）
- 目标JSON Schema定义
- 任务身份信息（task_id, task名称）
- 校验规则（必填字段、类型约束、数组约束）

## 输出
- 校验通过的报告（符合Schema）
- 校验失败错误报告（缺失字段、类型错误、任务身份不匹配）
- 诊断信息（具体错误位置、错误描述）

## 流程节点
1. **Schema加载** → 读取JSON Schema定义，验证Schema格式
2. **报告解析** → 将报告内容解析为JSON对象
3. **字段校验** → 检查必填字段是否存在，类型是否匹配
4. **任务身份验证** → 比对task_id和task名称是否与预期一致
5. **数组约束检查** → 验证数组字段是否符合minItems、maxItems、uniqueItems等约束
6. **错误收集** → 收集所有校验错误，生成结构化错误报告
7. **结果输出** → 输出校验通过或失败状态及详细错误信息

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必填字段 | ["task_id", "task", "issues", "summary"] | [1] | 报告顶层必须包含这些字段 |
| 任务身份匹配 | task_id与任务索引一致，task与任务name一致 | [1] | 确保报告与任务对应 |
| 数组约束 | issues必须是数组类型 | [1] | 便于遍历处理 |
| 字符串约束 | summary必须是非空字符串 | [1] | 提供报告摘要 |

## 边界与分流
- **缺失必填字段** → 报告无效，返回缺失字段列表
- **任务身份不匹配** → 报告可能对应错误任务，返回身份验证错误
- **类型错误** → 例如issues不是数组，summary不是字符串，返回类型错误
- **额外字段** → 允许但警告，不影响校验通过
- **Schema加载失败** → 返回Schema错误，无法进行校验

## 质量检查
- 验证Schema本身是否有效（JSON格式、draft版本）
- 检查报告是否可解析为JSON
- 确认所有必填字段存在且类型正确
- 验证任务身份是否匹配
- 测试边界情况：空数组、空字符串、缺失字段

## 回退策略
- Schema加载失败时，使用基本字段检查作为降级校验
- 报告解析失败时，尝试修复常见JSON格式错误（未闭合引号、多余逗号）
- 任务身份不匹配时，记录警告但允许通过（可能用于调试）
