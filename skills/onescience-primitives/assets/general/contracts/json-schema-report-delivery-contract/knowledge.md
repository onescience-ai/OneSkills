# JSON Schema报告交付契约

## 适用范围
适用于需要结构化报告交付的自动化场景，包括归因分析报告、测试报告、审计报告等。当报告需要被下游系统自动解析、校验和消费时，本卡片提供JSON Schema契约设计、字段约束定义、任务身份绑定与校验失败诊断的完整知识框架。特别适用于需要多维度验证（类型准确性、必填字段、多类型支持、集合结构、实体关系、时间演化）的复杂报告场景。

## 输入
- 报告内容数据（任务信息、分析结果、证据列表）
- 任务身份信息（task_id、task名称）
- Schema版本与兼容性要求
- 校验失败的错误信息
- 验证维度配置（可选，用于多维度评估）

## 输出
- 符合Schema的JSON报告
- 校验结果（通过/失败）
- 错误详情（缺失字段、多余字段、类型错误）
- 修复建议
- 多维度验证报告（可选，包含六个验证维度的详细结果）

## 流程节点
1. **Schema定义** → 定义报告的JSON Schema结构
2. **字段约束** → 设置必填字段、类型约束、格式约束
3. **任务绑定** → 将报告与任务身份（task_id、task名称）绑定
4. **报告生成** → 按Schema生成结构化报告
5. **Schema校验** → 使用Schema验证报告结构
6. **错误诊断** → 分析校验失败原因并提供修复建议
7. **报告交付** → 输出校验通过的报告
8. **多维度验证** → 执行六个验证维度的详细评估（可选）

每步含：操作、参数、工具、质量门禁

## 边界与分流
- **缺失字段**：报告缺少必填字段时，返回缺失字段列表与添加建议
- **多余字段**：报告包含未定义字段时，警告并建议移除（严格模式）或忽略（宽松模式）
- **类型错误**：字段类型不匹配时，返回类型转换建议
- **任务身份错配**：task_id与任务索引不一致时，返回身份验证失败并建议核对
- **Schema版本冲突**：使用旧版Schema时，建议升级到最新版本
- **多类型支持不足**：报告未能正确表示联合类型时，建议使用oneOf/anyOf/oneOf组合Schema
- **时间演化检测失败**：报告未能检测结构演化时，建议添加版本控制和时间戳字段

## 质量检查
- Schema校验通过率100%
- 任务身份一致性验证
- 字段类型正确性检查
- 错误信息可读性验证
- 六个验证维度得分（可选）
- Schema质量分数（SQS）计算（可选）

## 回退策略
- 降级到宽松校验模式（忽略多余字段）
- 使用部分Schema校验（仅校验核心字段）
- 人工审核并手动修复
- 降级到单一维度验证（当多维度验证失败时）

## 资源召回建议
