# 平台监控流程选择

生成代码：维护项目任务配置，消费通用 OneScience 知识，交付身份读取和上报片段；不登记运行。执行已有代码：读取任务配置，继承监控要求，复用当前执行通道；平台分配新运行，明确 retry/resume 才保留逻辑 run 并换 attempt。

提交响应不明：先核对真实作业，不能把监控 warning 当提交失败重提。明确训练成功而监控缺失：保持训练结果，定位写入/清单/runtime/metrics/查看阶段，不自动重训。已有历史未关联：仅按用户指定手工关联，不自动发现全部旧日志。

监控验证：当前 writer 事件 → 平台确切身份与绑定 → 增量字节与有效点 → TensorBoard 数据 → 页面证据，分别记录结果。暂停不自动恢复；已完成不重开；收尾超期报告不完整。后台采集由平台负责，不增加 Agent 轮询服务。
