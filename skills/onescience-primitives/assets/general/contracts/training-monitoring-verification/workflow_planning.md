# 验收与异常规划

| 现象 | 检查与决策 |
|---|---|
| 仅代码修改完成 | 按代码范围验收，采集/展示 not_run；不自行启动训练 |
| capabilities 支持但无事件 | 不能判成功；检查真实入口、配置启用、输出目录、flush/采样及同步 |
| verify waiting | 先查运行状态、采样点数、封存与汇总；不是训练失败证明，不自动重跑 |
| verify ok 但所需验证/诊断缺失 | 补充事件证据，缺失指标仍 partial，不伪造 |
| 缺 rank/源未同步 | 展示已知本地/部分数据，不能宣称完整全局 |
| check 出现依赖/版本错误 | 环境问题按 installer；源码 API 不匹配回编码规划 |
| 配置/写入/汇总异常 | 保留原始报告并按证据定位，不用空目录或占位事件充数 |
| 原训练/严重设备错误 | 以真实作业状态判定；不承诺监控绝对隔离 |
| OneCode 未绑定/展示未实现 | 单列展示缺口，不把采集通过提升为端到端展示通过 |

只保留用户本次要求的必需验收项；没有验证阶段不为监控新增验证训练逻辑。监控故障与训练故障独立报告，修复若涉及新代码/新运行应由 orchestrator 按原授权重新选择步骤。

## 宿主与独立知识边界

OneScience 公共 API 与接入示例通过 tools/onescience-training-monitoring 的 spec/usage 召回，无需源仓库。OneCode 项目另召回 contracts/onecode-training-monitoring，核对持久化配置、平台身份、清单、独立来源、缓存权限和分阶段诊断；不把这些平台规则当成 OneScience 公共 API。训练业务源码仍由相应 executor 按任务范围处理。
