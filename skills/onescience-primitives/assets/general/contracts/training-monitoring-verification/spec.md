# 按需训练监控诊断

本契约仅用于用户明确要求验证监控、检查指标或排查无曲线的任务，不属于正常生成、提交、训练或采集流程。正常训练不以 verify、事件点数或页面验收作为成功门槛。

## 诊断范围

从指定运行的真实日志、任务身份、事件目录和既有采集状态定位问题。区分训练作业、事件写入、目录绑定、采集连接及页面展示；监控没有数据不等于训练失败。

OneScience 公共 verify、TensorBoard 事件读取器均为按需手段。只检查用户要求的指标及其真实口径，不强制所有任务满足统一点数或高级诊断项；原生 DDP rank 0 数据不宣称全局完整。

## 权限与结果

只读诊断不修改代码/配置、不安装依赖、不启动或延长训练、不制造事件。需要修复时沿原授权交给相应 owner；监控故障不自动重新提交训练。

返回已观察事实、缺口和建议，代码、训练、数据、展示分别报告；没有相应证据时保留未知或 not_run。诊断报告不是新的训练成功条件。
