# JSON Schema报告交付契约验证

## 适用范围
本卡片服务于结构化数据交付场景，验证JSON格式输出是否符合预定义的Schema契约。适用于自动化报告生成、API响应验证、数据管道质量门禁、测试输出验证等需要确保数据格式一致性的场景。不适用于非JSON格式数据验证或复杂的业务逻辑验证。

## 输入
- JSON格式数据（待验证的输出）
- JSON Schema定义文件（契约规范）
- 验证配置（严格模式、格式检查等）
- 上下文信息（任务ID、任务名称、时间戳等）

## 输出
- 验证结果（通过/失败）
- 错误详情（缺失字段、类型错误、格式违规等）
- 校验报告（包含错误位置、预期值、实际值）
- 修复建议（针对每个错误的具体修复方法）

## 流程节点
1. **加载Schema** → 解析JSON Schema定义文件，构建验证规则
2. **解析数据** → 解析待验证的JSON数据
3. **执行验证** → 按Schema规则逐一验证数据字段
4. **错误收集** → 收集所有验证错误并分类
5. **报告生成** → 生成结构化验证报告
6. **修复指导** → 基于错误类型提供具体修复建议
7. **契约确认** → 验证输出是否满足交付要求

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必填字段检查 | required | [D1] | 验证所有必需字段是否存在 |
| 类型验证 | type | [D1] | 验证字段数据类型是否匹配 |
| 格式验证 | format | [D1] | 验证字符串格式（日期、邮箱、URI等） |
| 数值范围 | minimum/maximum | [D1] | 验证数值是否在指定范围内 |
| 数组约束 | minItems/maxItems | [D1] | 验证数组长度是否在指定范围内 |
| 对象约束 | minProperties/maxProperties | [D1] | 验证对象属性数量是否在指定范围内 |
| 字符串约束 | minLength/maxLength | [D1] | 验证字符串长度是否在指定范围内 |
| 模式匹配 | pattern | [D1] | 验证字符串是否匹配正则表达式 |

## 边界与分流
- **缺失必填字段**：添加缺失字段或使用默认值
- **类型不匹配**：转换数据类型或修正Schema定义
- **格式违规**：修正数据格式或放宽Schema格式要求
- **额外字段**：移除额外字段或更新Schema允许额外属性
- **范围越界**：调整数值或修改Schema范围约束
- **模式不匹配**：修正数据内容或调整正则表达式模式

## 质量检查
- 所有必填字段是否存在且非空
- 数据类型是否与Schema定义一致
- 字符串格式是否符合规范（如ISO日期、邮箱格式）
- 数值是否在指定范围内
- 数组长度是否满足约束条件
- 对象属性数量是否在限制内
- 正则表达式模式是否匹配成功

## 回退策略
- 当Schema定义不完整时，记录缺失验证规则并告警
- 当数据格式严重违规时，提供部分验证结果并标记不可信字段
- 当验证工具不可用时，实施基础字段存在性检查
- 当Schema版本不兼容时，提供版本迁移建议
