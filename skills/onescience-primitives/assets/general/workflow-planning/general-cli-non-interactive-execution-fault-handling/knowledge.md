# CLI 非交互执行故障处理

## 适用范围
适用于需要在自动化脚本、CI/CD 管道或批处理任务中运行命令行工具的场景，重点处理非交互模式下的故障识别、分类与恢复。适用于各种操作系统和 shell 环境。

## 输入
- 命令行工具及其参数
- 执行环境（操作系统、shell 版本、用户权限）
- 预期输出或退出码
- 超时限制（可选）

## 输出
- 故障分类（超时、退出码异常、沙箱限制、权限错误等）
- 诊断报告（包含错误信息、退出码、标准输出/错误）
- 恢复建议（重试、调整参数、环境修复等）

## 流程节点
1. **执行前检查** → 验证命令路径、参数格式、环境依赖
2. **执行监控** → 设置超时、捕获输出流、记录时间戳
3. **故障检测** → 检查退出码、输出内容、进程状态
4. **故障分类** → 根据错误模式分类（超时、退出码、权限、资源等）
5. **诊断生成** → 收集上下文信息、生成结构化报告
6. **恢复策略** → 根据故障类型选择重试、降级或终止

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码 0 | 成功 | [D1] | 命令正常执行完成 |
| 退出码 1-255 | 失败 | [D1] | 命令执行错误，具体含义取决于命令 |
| 超时退出码 | 124 | [D2] | 命令超时被终止 |
| 信号退出码 | 128+信号编号 | [D1] | 命令被信号终止（如 SIGKILL=137） |

### 校准数值
以下数值来自常见实践，供量级校准；其他体系需以自身证据重新锚定。
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认超时 | 300 秒 | [D2] | Python subprocess 默认超时 |
| 最大重试次数 | 3 | [D1] | 常见重试策略上限 |
| 输出缓冲区大小 | 4096 字节 | [D2] | 捕获输出时的缓冲区大小 |

## 边界与分流
- **沙箱环境限制**：若工具在容器或受限沙箱中运行，需检查资源限制（内存、CPU、网络）
- **权限不足**：若退出码为 126 或 127，检查文件权限和 PATH 环境变量
- **依赖缺失**：若工具依赖其他库或服务，需预先检查并安装
- **超时处理**：超时后需清理子进程，避免僵尸进程

## 质量检查
- 验证退出码是否在预期范围内
- 检查标准输出和错误流是否包含关键信息
- 确认超时设置是否合理（过短导致误报，过长浪费资源）
- 确保故障报告包含足够的上下文信息

## 回退策略
- 若命令反复失败，尝试使用替代工具或方法
- 若环境问题无法解决，记录环境状态并通知维护人员
- 若故障分类不明确，保留完整日志供人工分析
