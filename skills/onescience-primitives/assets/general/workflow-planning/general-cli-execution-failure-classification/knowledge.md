# CLI 执行失败分类与诊断

## 适用范围
面向命令行接口（CLI）工具的非交互执行场景，提供故障分类、诊断与恢复的通用方法论。适用于各类CLI工具的自动化执行、脚本集成、持续集成（CI）流水线和批处理作业中的故障排查。不适用于交互式CLI会话或图形用户界面（GUI）应用。

## 输入
- CLI工具路径与命令参数
- 执行环境配置（操作系统、shell类型、环境变量）
- 输入数据文件或管道数据
- 预期输出格式与验证标准

## 输出
- 故障分类结果（参数错误、认证失败、资源不足、超时、依赖缺失等）
- 退出码与标准错误（stderr）内容解析
- 故障原因诊断报告
- 恢复建议或自动重试策略

## 流程节点
1. **命令构建** → 2. **执行监控** → 3. **退出码捕获** → 4. **标准错误解析** → 5. **故障分类** → 6. **诊断报告生成** → 7. **恢复策略执行**

每步含：
- 操作：具体执行步骤
- 参数：关键配置项
- 工具：推荐工具或库
- 质量门禁：验证点与阈值

## 关键参数
### 通用判据（方法层，同类体系可参考）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码范围 | 0-255 | [1] | 标准Unix退出码范围 |
| 退出码0 | 成功 | [1] | 命令正常执行完成 |
| 退出码1-125 | 通用错误 | [1] | 参数错误、资源不可用等 |
| 退出码126 | 权限拒绝 | [1] | 无法执行命令文件 |
| 退出码127 | 命令未找到 | [1] | PATH中找不到命令 |
| 退出码128+N | 信号终止 | [1] | 被信号N终止（如SIGTERM=143） |
| 退出码130 | Ctrl+C终止 | [1] | SIGINT终止 |
| 退出码255 | 退出码溢出 | [1] | 退出码超出范围 |

### 校准数值（体系专属值）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 超时默认值 | 300秒 | [用户实践] | 长时间运行命令的默认超时 |
| 重试间隔 | 5秒 | [用户实践] | 失败后重试的等待时间 |
| 最大重试次数 | 3次 | [用户实践] | 自动重试的上限 |

## 边界与分流
- **参数解析错误**：检查命令语法、参数顺序、必填参数缺失
- **认证失败**：验证凭据、令牌有效期、权限级别
- **资源不足**：检查磁盘空间、内存、CPU使用率
- **超时**：调整超时设置、优化命令性能、拆分大任务
- **依赖缺失**：安装缺失的包、库、工具
- **信号终止**：捕获信号、清理资源、优雅退出

## 质量检查
- 退出码是否在预期范围内
- 标准错误输出是否包含有意义的错误信息
- 执行时间是否在合理范围内
- 输出结果是否符合预期格式

## 回退策略
- 自动重试（指数退避）
- 降级执行（简化参数、跳过非关键步骤）
- 人工干预（记录诊断信息、发送告警）
