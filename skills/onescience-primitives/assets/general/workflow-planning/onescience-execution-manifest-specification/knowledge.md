# OneScience Execution Manifest 规范

## 适用范围

本卡适用于OneScience orchestrator工作流中execution-manifest.json文件的生成、内容规范和校验规则。当orchestrator需要为任务生成执行清单时，本卡提供execution-manifest.json的必需字段、生成时机和校验标准，确保preflight检查通过。

## 输入

- 任务规划结果：global_plan生成后的工作流步骤定义
- 步骤依赖关系：步骤间的执行顺序和依赖约束
- 产物清单：每个步骤预期的输出文件和目录

## 输出

- execution-manifest.json：任务执行清单文件
- 校验结果：preflight检查通过/失败状态

## 流程节点

1. **规划阶段完成** → 2. **清单生成** → 3. **清单校验** → 4. **写入文件系统** → 5. **preflight检查**

### 步骤1：规划阶段完成
- 操作：确认global_plan已生成，步骤定义完整
- 参数：步骤列表、依赖图、产物定义
- 质量门禁：所有步骤有明确的目标和验证标准

### 步骤2：清单生成
- 操作：根据规划结果生成execution-manifest.json
- 参数：任务ID、步骤定义、依赖关系、产物清单、超时设置
- 工具：清单生成器
- 质量门禁：包含所有必需字段，格式符合JSON规范

### 步骤3：清单校验
- 操作：校验清单内容的完整性和一致性
- 参数：清单内容、校验规则
- 工具：清单校验器
- 质量门禁：所有必需字段非空，依赖关系无循环，产物路径有效

### 步骤4：写入文件系统
- 操作：将execution-manifest.json写入任务产物根目录
- 参数：清单内容、目标路径
- 工具：文件写入器
- 质量门禁：文件成功写入，可读取和解析

### 步骤5：preflight检查
- 操作：执行preflight检查，验证清单存在性和有效性
- 参数：清单路径、检查规则
- 工具：workflow_preflight.py
- 质量门禁：退出码为0，所有检查通过

## 边界与分流

### 生成问题分流
- **规划阶段未完成**：等待global_plan生成完成
- **步骤定义不完整**：补充缺失的步骤信息
- **依赖关系循环**：重新规划步骤依赖

### 校验问题分流
- **必需字段缺失**：补充缺失字段内容
- **依赖关系错误**：修正依赖图中的循环或矛盾
- **产物路径无效**：修正路径格式或创建目录

### 写入问题分流
- **目录不存在**：创建目标目录
- **权限不足**：检查写入权限
- **磁盘空间不足**：清理空间或调整路径

### preflight问题分流
- **清单文件不存在**：重新生成并写入清单
- **清单格式错误**：修正JSON格式问题
- **清单内容无效**：补充或修正清单内容

## 质量检查

1. **格式检查**：验证JSON格式正确，可被标准JSON解析器解析
2. **完整性检查**：所有必需字段非空，步骤定义完整
3. **一致性检查**：依赖关系无循环，产物路径唯一
4. **可读性检查**：文件可被workflow_preflight.py读取和解析
5. **性能检查**：清单大小在合理范围内，不影响后续处理

## 回退策略

1. **清单生成失败**：使用简化清单模板，只包含核心字段
2. **校验失败**：记录具体错误，提供修复建议
3. **写入失败**：尝试备用路径，或输出到标准输出供手动保存
4. **preflight失败**：执行降级检查，仅验证关键字段
