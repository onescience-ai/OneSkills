# 模型训练产物标准命名规范

## 适用范围

面向模型训练管理任务，定义模型训练产物的标准文件命名规范。适用于所有需要输出模型权重、训练配置和环境依赖的机器学习任务。不适用于推理任务或数据分析任务。

## 输入

- 任务目标：训练模型并输出标准产物
- 数据需求：训练好的模型权重、训练配置信息、环境依赖
- 格式要求：PyTorch权重文件、JSON配置文件、文本环境文件

## 输出

- best_checkpoint.pt：最优模型权重文件
- train_config.json：训练配置文件
- training_metrics.csv：训练指标文件
- environment.txt：环境依赖文件

## 流程节点

1. **定义命名规范** → 2. **生成配置文件** → 3. **保存模型权重** → 4. **记录训练指标** → 5. **记录环境依赖**

### 步骤1：定义命名规范
- 操作：确定文件命名规则和格式
- 参数：文件名、扩展名、版本号
- 工具：任务文档、领域知识
- 质量门禁：命名规范清晰，易于识别

### 步骤2：生成配置文件
- 操作：创建train_config.json记录训练参数
- 参数：framework、epochs、batch_size、learning_rate、seed、early_stopping_patience
- 工具：JSON生成器
- 质量门禁：配置参数完整，格式正确

### 步骤3：保存模型权重
- 操作：保存训练好的模型权重
- 参数：模型架构、权重参数、优化器状态
- 工具：PyTorch torch.save
- 质量门禁：权重文件可正确加载

### 步骤4：记录训练指标
- 操作：保存训练过程中的指标
- 参数：训练损失、验证损失、准确率等
- 工具：CSV生成器
- 质量门禁：指标记录完整，格式规范

### 步骤5：记录环境依赖
- 操作：保存运行环境信息
- 参数：Python版本、PyTorch版本、CUDA版本、pip freeze摘要
- 工具：环境信息收集脚本
- 质量门禁：环境信息完整，可重现

## 边界与分流

### 前提1：存在训练好的模型
- **不成立时转向**：先执行模型训练，再生成产物

### 前提2：训练配置可记录
- **不成立时转向**：使用默认配置，或手动记录关键参数

### 前提3：环境信息可获取
- **不成立时转向**：使用简化环境信息，或手动记录关键依赖

## 质量检查

1. **文件命名验证**：检查文件命名是否符合规范
2. **配置完整性**：检查train_config.json字段是否完整
3. **权重可加载性**：检查模型权重是否可正确加载
4. **指标完整性**：检查训练指标是否记录完整
5. **环境可重现性**：检查环境信息是否完整

## 回退策略

1. **命名不规范**：重命名文件，符合标准规范
2. **配置缺失**：补充缺失字段，重新生成配置文件
3. **权重损坏**：重新保存模型权重，验证可加载性
4. **环境信息不全**：补充缺失的环境信息
