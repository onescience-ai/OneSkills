# CLI非交互执行故障诊断与恢复

## 适用范围
本卡片服务于命令行界面（CLI）工具在非交互执行环境（如自动化脚本、CI/CD流水线、批处理作业、定时任务）中的故障诊断与恢复。适用于需要理解退出码含义、处理执行超时、管理进程生命周期以及实施错误恢复策略的场景。不适用于交互式Shell调试或图形界面应用故障排查。

## 输入
- CLI命令或脚本执行日志
- 退出码（exit code）或返回状态（return status）
- 标准错误（stderr）输出
- 进程执行上下文（命令路径、参数、环境变量）
- 执行时间限制（超时设置）

## 输出
- 故障分类（命令未找到、权限错误、信号终止、超时等）
- 退出码解释（0成功，1-125应用错误，126不可执行，127未找到，128+N信号终止）
- 恢复策略建议（重试、降级、告警、终止）
- 诊断报告（包含错误详情、上下文信息、建议操作）

## 流程节点
1. **捕获执行状态** → 记录退出码、标准输出、标准错误、执行时间
2. **退出码分类** → 根据退出码范围判断故障类型
3. **信号分析** → 检查是否因信号终止（退出码>128）
4. **上下文诊断** → 分析命令路径、权限、依赖环境
5. **恢复决策** → 根据故障类型选择恢复策略
6. **执行恢复** → 实施重试、降级或终止操作
7. **记录诊断** → 生成结构化诊断报告供后续分析

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 成功退出码 | 0 | [D1] | 命令执行成功 |
| 应用错误范围 | 1-125 | [D1] | 应用程序特定错误 |
| 不可执行退出码 | 126 | [D1] | 命令文件不可执行 |
| 未找到退出码 | 127 | [D1] | 命令未找到 |
| 信号终止公式 | 128+N | [D1] | N为信号编号 |
| 内建命令错误 | 2 | [D1] | 内建命令用法错误 |
| 特殊参数 | $? | [D1] | 上一个命令退出状态 |

## 边界与分流
- **命令未找到（127）**：检查PATH环境变量、命令拼写、安装状态
- **不可执行（126）**：检查文件权限、文件类型、执行位设置
- **信号终止（>128）**：检查系统资源限制、进程组管理、信号处理
- **超时故障**：实施超时控制、进程监控、优雅终止策略
- **依赖缺失**：检查共享库、环境变量、配置文件
- **权限不足**：检查用户权限、sudo配置、文件系统权限

## 质量检查
- 退出码是否在0-255有效范围内
- 标准错误输出是否包含有意义的错误信息
- 执行时间是否在预期范围内
- 恢复策略是否与故障类型匹配
- 诊断报告是否包含足够上下文信息

## 回退策略
- 当无法确定故障类型时，记录完整执行上下文并告警
- 当恢复策略失败时，实施优雅终止并保存现场
- 当多次重试失败时，升级处理或人工干预
- 当环境问题无法解决时，提供环境修复建议
