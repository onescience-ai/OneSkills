# 通用命令行接口故障分类与错误处理

## 适用范围
适用于需要非交互执行命令行接口（CLI）工具的场景，包括自动化脚本、批处理任务、CI/CD 流水线等。提供 CLI 工具故障分类、错误处理、退出码诊断和标准错误判读的通用方法，确保工具在无人值守环境下的稳定性和可诊断性。

## 输入
- CLI 工具的命令行参数、认证信息、沙箱配置、超时设置等。
- 执行环境的系统信息（操作系统、依赖版本、资源限制）。
- 错误日志和退出码。

## 输出
- 结构化的故障分类报告，包括错误类型、可能原因、建议修复措施。
- 退出码与标准错误信息的解析结果。
- 诊断证据链，支持后续自动化处理。

## 流程节点
1. **命令参数校验** → 检查命令行参数格式、必填项、类型匹配，避免因参数错误导致的执行失败 [1]。
2. **认证与权限检查** → 验证认证令牌、证书、环境变量是否有效，确保工具能访问所需资源 [1]。
3. **沙箱环境配置** → 配置隔离环境（如容器、虚拟环境），避免外部依赖冲突 [1]。
4. **超时与资源监控** → 设置执行超时阈值，监控 CPU、内存、磁盘 I/O，防止资源耗尽 [1]。
5. **错误捕获与分类** → 捕获标准错误流（stderr）和退出码，根据预定义规则分类错误类型（如参数错误、认证失败、超时、资源不足）[1][2]。
6. **故障诊断与报告** → 生成结构化报告，包含错误摘要、堆栈跟踪、可能原因和修复建议 [1]。

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码 0 | 成功 | 通用约定 | 表示命令执行成功 |
| 退出码 1-125 | 失败 | 通用约定 | 表示命令执行失败，具体含义由工具定义 |
| 退出码 126 | 无法执行 | 通用约定 | 表示命令不可执行（权限问题） |
| 退出码 127 | 命令未找到 | 通用约定 | 表示命令不存在 |
| 退出码 128+n | 信号终止 | 通用约定 | 表示命令被信号 n 终止 |
| 超时阈值 | 可配置 | 工具定义 | 防止无限期执行 |
| 重试次数 | 0-5 | 可配置 | 根据错误类型决定是否重试 |

## 边界与分流
- **参数错误** → 校验失败后输出用法说明并退出，退出码 1。
- **认证失败** → 尝试刷新令牌或提示用户更新凭证，退出码 2。
- **超时** → 强制终止进程并记录超时信息，退出码 124。
- **资源不足** → 监控资源使用，超阈值时优雅降级或终止，退出码 137。
- **未知错误** → 捕获未预期异常，记录堆栈跟踪，退出码 1。

## 质量检查
- 退出码必须符合 POSIX 标准或工具自定义约定。
- 错误日志必须包含时间戳、错误类型、上下文信息。
- 诊断报告必须可解析（如 JSON 格式），支持自动化处理。

## 回退策略
- 当主错误处理流程失败时，回退到基础错误捕获并输出原始日志。
- 当诊断无法确定原因时，提供通用排查步骤（如检查依赖、权限、环境变量）。
