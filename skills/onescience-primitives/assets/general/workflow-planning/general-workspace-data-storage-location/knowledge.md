# OneScience工作空间数据文件标准存放位置规范

## 适用范围

**触发条件**：
- 任务执行前需要查找输入数据文件
- 数据文件不在默认的任务产物目录中
- 需要确定数据文件的查找优先级

**适用场景**：
- 科学工作流执行前的数据发现
- 多数据源环境下的文件定位
- 自动化工作流中的数据验证步骤

**不适用场景**：
- 数据文件内容的处理或转换
- 数据质量检查或验证
- 远程数据源的下载或获取

## 输入

**输入数据格式**：
- 任务ID或任务名称
- 工作空间根目录路径
- 可能的文件名或文件模式

**来源**：
- 用户提供的任务信息
- 工作空间配置文件
- 任务状态文件

**预处理要求**：
- 确定工作空间根目录
- 验证目录访问权限
- 准备文件搜索模式

## 输出

**输出产物**：
- 数据文件完整路径列表
- 文件查找优先级顺序
- 查找结果状态报告

**格式**：
- JSON格式的查找结果
- 文本格式的查找日志

**验证标准**：
- 所有必需文件都被找到
- 文件路径可访问
- 文件完整性验证通过

## 流程节点

### Step 1：任务产物目录搜索
- **操作**：在任务产物目录（task-artifact/{task_id}）中搜索目标文件
- **参数**：task_id, 文件名模式
- **工具**：文件系统API, Glob模式匹配
- **质量门禁**：文件存在且可读

### Step 2：工作空间根目录搜索
- **操作**：在工作空间根目录中递归搜索文件
- **参数**：根目录路径, 文件名模式
- **工具**：递归目录遍历, 文件匹配
- **质量门禁**：找到文件且路径有效

### Step 3：.onescience/data/目录搜索
- **操作**：在.onescience/data/子目录中搜索文件
- **参数**：data目录路径, 文件名模式
- **工具**：目录遍历, 文件匹配
- **质量门禁**：文件存在且格式正确

### Step 4：模型注册表搜索
- **操作**：查询模型注册表获取文件位置
- **参数**：模型名称, 版本信息
- **工具**：注册表API, 查询接口
- **质量门禁**：注册表中有记录且文件可访问

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 任务产物目录 | task-artifact/{task_id} | [系统规范] | 默认数据存放位置 |
| 工作空间根目录 | /workspace | [系统规范] | 工作空间根路径 |
| 数据目录 | .onescience/data/ | [系统规范] | OneScience数据存储 |
| 模型注册表 | modelscope | [外部服务] | 模型数据来源 |
| 搜索优先级 | 1.任务目录 2.根目录 3.data目录 4.注册表 | [最佳实践] | 查找顺序 |

## 边界与分流

**异常处理**：
- 文件不存在：记录缺失状态，尝试下一个搜索路径
- 权限不足：跳过受限目录，记录警告
- 网络超时：重试注册表查询，失败则标记为待确认

**降级策略**：
- 本地搜索失败时，提示用户手动指定路径
- 注册表不可用时，使用缓存的元数据信息
- 多路径搜索失败时，提供数据生成建议

**分支条件**：
- 文件名明确：直接搜索特定文件
- 文件名模糊：使用模式匹配搜索
- 无文件信息：跳过搜索，提示用户提供

## 质量检查

**验证点**：
- 文件存在性检查
- 文件可读性验证
- 文件格式兼容性检查
- 文件完整性校验

**阈值**：
- 文件大小 > 0
- 文件修改时间在合理范围内
- 文件格式符合预期

**失败处理**：
- 文件不存在：记录缺失，继续搜索其他路径
- 文件损坏：记录错误，建议重新获取
- 格式不匹配：记录警告，尝试兼容处理

## 回退策略

**替代方案**：
1. 提示用户手动指定文件路径
2. 使用数据生成工具创建示例数据
3. 从论文补充材料中提取数据
4. 从公共数据仓库下载示例数据

**失败时的处理**：
- 记录所有尝试的路径和结果
- 提供详细的数据缺失报告
- 建议可能的数据获取途径
