# CLI非交互执行故障分类与诊断

## 适用范围
面向命令行接口（CLI）工具的非交互执行场景，提供故障分类与诊断方法。适用于自动化脚本、流水线作业、云环境运维等需要处理CLI错误、退出码和异常模式的任务。不适用于交互式会话或图形界面操作。

## 输入
- CLI命令执行结果（退出码、标准输出、标准错误）
- 执行环境信息（操作系统、Shell类型、权限）
- 历史执行日志（可选）

## 输出
- 故障类别标签（如：参数错误、权限不足、资源超限、依赖缺失）
- 退出码解读与建议
- 恢复策略推荐（重试、降级、终止）

## 流程节点
1. **退出码解析** → 根据非零退出码映射到故障大类（如：1=通用错误，2=误用Shell命令，126=权限问题，127=命令未找到，128=无效退出参数，130=脚本被Ctrl+C终止，139=段错误）。
2. **标准错误分析** → 提取关键错误信息，识别常见模式（如："Permission denied"、"No such file or directory"、"Connection timed out"）。
3. **上下文关联** → 结合执行环境（如：Linux/Windows、Python版本、依赖库）判断故障根因。
4. **分类与诊断** → 将故障归类到预定义类别，并生成诊断报告。
5. **恢复策略生成** → 根据故障类别推荐恢复动作（如：自动重试、参数调整、环境修复）。

## 关键参数
### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码映射 | POSIX标准 | [1] | 0=成功，1-2=Shell错误，126-128=执行环境错误，130+信号错误 |
| 错误模式库 | 动态维护 | [2] | 包含常见CLI错误的正则表达式匹配规则 |
| 恢复策略阈值 | 可配置 | 实践 | 重试次数、超时时间、降级条件 |

### 校准数值
以下数值来自CLI风险分类研究，供量级校准；其他体系需以自身证据重新锚定。
- 风险分类模型F1-score：0.85-0.92 [1]
- 命令拦截系统误报率：<5% [1]
- 敏感数据检测准确率：0.90 [2]

## 边界与分流
- **前提1：CLI命令可执行** → 若命令不存在或无法执行，转向"环境配置检查"分支。
- **前提2：退出码可读** → 若进程被强制终止（如kill -9），退出码可能缺失，转向"信号分析"分支。
- **前提3：错误信息可解析** → 若输出为二进制或加密，转向"黑盒诊断"分支（仅依赖退出码和进程状态）。

## 质量检查
- 退出码映射覆盖率：≥90% POSIX标准退出码
- 错误模式识别准确率：≥85%
- 诊断报告完整性：包含故障类别、根因、恢复建议

## 回退策略
- 退出码无法解析时，记录原始退出码并标记为"未知故障"
- 错误信息为空时，仅基于退出码进行粗粒度分类
- 恢复策略失败时，记录失败原因并终止执行
