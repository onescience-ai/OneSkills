# CLI非交互执行与故障分类知识

## 适用范围
适用于所有需要在自动化工作流中启动、监控和诊断CLI子进程的场景，特别是归因分析、数据处理、模型训练等OneScience任务的CLI执行环节。

**不适用场景**：交互式shell会话、需要用户输入的命令、GUI应用程序。

## 输入
- 命令行参数序列（args）
- 执行环境配置（cwd, env, shell参数）
- 超时限制（timeout秒数）
- 标准输入数据（可选）

## 输出
- CompletedProcess对象，包含：
  - `returncode`: 退出状态码（0=成功，负值=信号终止，正值=错误）
  - `stdout`: 标准输出（bytes或str）
  - `stderr`: 标准错误（bytes或str）
  - `args`: 启动命令

## 流程节点

### 1. 进程创建
- 使用`subprocess.run()`推荐方式启动
- 或使用`subprocess.Popen()`进行高级控制
- 关键参数：`shell=True/False`、`cwd`、`env`

### 2. 输出捕获
- `stdout=subprocess.PIPE` 捕获标准输出
- `stderr=subprocess.PIPE` 捕获标准错误
- `stderr=subprocess.STDOUT` 合并输出到stdout

### 3. 超时控制
- `timeout=N` 参数指定最大等待秒数
- 超时触发`TimeoutExpired`异常
- 子进程未终止时需手动`proc.kill()`清理

### 4. 退出码检查
- `returncode == 0`: 成功
- `returncode > 0`: 进程错误码（具体含义取决于程序）
- `returncode < 0`: 被信号终止（POSIX）

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| returncode | 0 | [Python docs] | 成功退出 |
| returncode | 1-255 | [Python docs] | 程序定义的错误码 |
| returncode | -N | [Python docs] | 被信号N终止（仅POSIX） |
| timeout | 秒数 | 用户指定 | 超时触发TimeoutExpired |
| shell | True/False | 用户指定 | 是否通过shell执行 |

## 边界与分流

### 故障分类

| 故障类型 | 异常/状态 | 诊断方法 |
|----------|----------|----------|
| 命令不存在 | OSError/FileNotFoundError | 检查路径、环境变量 |
| 超时 | TimeoutExpired | 检查timeout设置、进程负载 |
| 非零退出 | CalledProcessError | 检查returncode、stderr |
| 权限错误 | PermissionError | 检查文件权限、执行权限 |
| 输入阻塞 | 死锁 | 使用communicate()避免 |

### 降级策略
1. 超时失败 → 增加timeout或优化命令
2. 非零退出 → 解析stderr获取详细错误
3. 资源不足 → 简化命令、减少并发

## 质量检查
- 验证returncode是否符合预期
- 检查stderr内容是否有错误信息
- 对于归因任务，确保报告格式符合契约

## 回退策略
1. 使用`check=False`捕获错误而非抛出异常
2. 手动解析stdout/stderr获取诊断信息
3. 记录完整的执行上下文用于后续分析

## 批次补充（2026-09-17：退出码诊断知识）

### 退出码分类与诊断

| 退出码范围 | 含义 | 诊断方法 | 修复策略 |
|------------|------|----------|----------|
| 0 | 成功 | 检查输出是否符合预期 | 无需修复 |
| 1-2 | 通用错误 | 解析stderr获取详细错误信息 | 根据错误信息修正命令参数 |
| 3-125 | 程序特定错误 | 查阅程序文档了解具体含义 | 根据程序文档修正输入 |
| 126 | 命令不可执行 | 检查文件权限和执行位 | chmod +x 或检查路径 |
| 127 | 命令未找到 | 检查命令是否存在、PATH环境变量 | 安装命令或修正路径 |
| 128+N | 被信号N终止 | 检查系统日志和资源限制 | 增加资源限制或优化命令 |
| 130 | Ctrl+C终止 (SIGINT) | 检查是否被外部中断 | 增加超时设置或使用信号处理 |
| 255 | 退出码溢出 | 检查程序是否异常终止 | 使用更小的退出码范围 |

### 常见退出码案例

**案例1：归因分析任务292（渤黄海海浪智能预报模型）**
- 退出码：1（通用错误）
- 诊断：CLI进程未正常完成生命周期
- 根因：输出格式不符合Schema校验要求
- 修复：确保输出前按契约校验报告

**案例2：归因分析任务291（渤黄海海浪智能订正模型）**
- 退出码：1（通用错误）
- 诊断：缺少必填字段、包含额外字段
- 根因：输出结构不符合预定Schema定义
- 修复：移除未定义字段，确保必填字段完整

**案例3：归因分析任务81（细胞类型特异调控DNA条件生成）**
- 退出码：1（通用错误）
- 诊断：任务身份字段缺失或不匹配
- 根因：无法关联到正确的任务索引
- 修复：验证task_id与任务索引一致、task与任务name一致

### 退出码诊断流程

1. **获取退出码**：从CompletedProcess.returncode或CalledProcessError.returncode获取
2. **分类判断**：根据退出码范围确定错误类型
3. **错误解析**：解析stderr获取详细错误信息
4. **根因定位**：结合退出码和错误信息定位问题
5. **修复验证**：根据根因修正后重新执行并验证
