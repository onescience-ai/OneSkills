# CLI非交互执行故障分类与诊断

## 适用范围

面向命令行界面（CLI）非交互执行场景，提供故障分类体系、诊断方法与恢复策略。适用于自动化脚本、批处理任务、CI/CD流水线、科学计算工作流等需要CLI执行的场景，覆盖启动、执行、输出和退出全阶段故障的识别与处理。

## 输入

- CLI命令及参数
- 执行环境信息（操作系统、shell类型、环境变量）
- 预期输出格式和退出码
- 历史执行日志（可选）

## 输出

- 故障分类结果（类型、严重性、阶段）
- 诊断报告（原因分析、影响评估）
- 恢复建议（重试策略、降级方案、替代方案）
- 退出码语义映射

## 流程节点

1. **故障检测** → 监控CLI执行状态，捕获异常信号
2. **故障分类** → 根据错误特征将故障归入预定义类别
3. **原因分析** → 基于分类结果和环境信息推断根本原因
4. **影响评估** → 评估故障对整体工作流的影响程度
5. **恢复决策** → 根据故障类型和影响选择恢复策略
6. **执行恢复** → 应用重试、降级或替代方案
7. **结果验证** → 确认恢复操作成功并记录经验

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 错误类型 | 编译时/运行时/逻辑 | [1] | 错误发生阶段分类 |

## 边界与分流

### 启动故障处理
- **命令不存在**：检查PATH环境变量、命令拼写、安装状态
- **权限不足**：检查用户权限、文件权限、sudo配置
- **环境变量缺失**：检查必需变量、默认值设置、配置文件

### 执行故障处理
- **参数错误**：验证参数格式、数量、类型
- **资源不可用**：检查磁盘空间、网络连接、依赖服务
- **超时**：调整超时时间、优化执行流程、增加重试

### 输出故障处理
- **格式错误**：验证输出格式、编码设置、管道兼容性
- **编码问题**：统一UTF-8编码、处理特殊字符、支持多语言
- **管道断裂**：检查管道连接、处理SIGPIPE信号、实现优雅退出

### 退出码故障处理
- **非标准退出码**：映射到标准语义、记录异常退出码
- **退出码缺失**：检查进程状态、分析信号处理、补充退出码
- **语义不明确**：建立退出码映射表、标准化退出码使用

## 回退策略

### 重试机制
- **指数退避**：等待时间随重试次数指数增长
- **最大重试**：设置重试次数上限避免无限循环
- **条件重试**：仅对可恢复错误进行重试

### 降级策略
- **功能降级**：跳过非关键功能，保证核心功能执行
- **精度降级**：降低输出精度要求，换取执行成功率
- **并行降级**：将并行任务转为串行执行

### 替代方案
- **工具替代**：使用功能相似的替代工具
- **手动执行**：在自动化失败时转为手动操作
- **离线处理**：在网络不可用时使用本地缓存或默认值
