# typical_workflow

1. Define the review question and eligibility criteria.
2. Select databases and record query syntax for each.
3. Run pilot searches, refine terms, and preserve counts.
4. Screen titles, abstracts, and full texts with exclusion reasons.
5. Extract data, assess quality, synthesize evidence, verify citations, and assemble outputs.

# usage_notes

- Record every search date and search string.
- Use more than one database for systematic work.
- Keep search, screening, and extraction artifacts separate from narrative text.
- Hand off diagrams, citations, and output formats to the relevant primitives.
