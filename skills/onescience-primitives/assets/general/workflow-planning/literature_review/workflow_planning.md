# when_to_use

Use this primitive for systematic reviews, scoping reviews, meta-analysis preparation, state-of-the-art summaries, and research-gap mapping.

# when_not_to_use

- Use public_database_lookup when the task is a factual API retrieval rather than evidence synthesis.
- Use scientific-writing when the search and screening are already complete.
- Use a domain-specific literature primitive if one exists for specialized sources.

# planning_steps

1. Frame the question and eligibility criteria.
2. Choose databases and build reproducible queries.
3. Record search dates, result counts, and deduplication rules.
4. Plan screening, extraction, quality appraisal, and synthesis.
5. Verify citations before assembling the final review.

# fallback

- If scope is too broad, produce a scoping search plan first.
- If databases are unavailable, list coverage gaps and alternatives.
- If citations cannot be verified, mark them unresolved rather than presenting them as validated.

# handoff_notes

Include question, criteria, databases, query strings, search dates, screening counts, extraction schema, citation style, and output format.
