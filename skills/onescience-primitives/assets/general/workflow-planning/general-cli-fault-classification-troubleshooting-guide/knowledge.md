# CLI 非交互执行与故障分类通用指南

## 适用范围
本卡片服务于命令行接口（CLI）工具的非交互执行场景，提供故障分类、诊断和恢复的通用方法。适用于各类科学计算、生物信息学、数据分析等领域的 CLI 工具，当工具在批处理、自动化流水线或远程执行环境中出现异常退出、错误信息或性能问题时，可依据本指南进行系统化排查。

## 输入
- 故障现象描述（错误信息、退出码、异常行为）
- 执行环境信息（操作系统、Python 版本、依赖库版本）
- 工具配置参数（命令行参数、环境变量、输入文件路径）
- 执行日志（标准输出、标准错误、调试日志）

## 输出
- 故障分类结果（环境问题、输入问题、代码问题、资源问题）
- 诊断报告（根本原因分析、影响范围评估）
- 恢复策略（具体修复步骤、预防措施）

## 流程节点
1. **故障现象收集** → 收集错误信息、退出码、执行日志
2. **环境验证** → 检查依赖库、路径配置、权限设置
3. **输入验证** → 验证输入文件格式、路径、完整性
4. **故障分类** → 根据症状匹配故障类别
5. **根本原因分析** → 深入分析故障机制
6. **恢复策略制定** → 制定修复和预防方案

每步含：操作、参数、工具、质量门禁

## 边界与分流
- **环境问题**：依赖库缺失、版本不兼容、路径配置错误 → 转向环境配置修复方案
- **输入问题**：文件不存在、格式错误、权限不足 → 转向输入数据验证方案
- **代码问题**：程序 bug、逻辑错误、未处理异常 → 转向代码调试和修复方案
- **资源问题**：内存不足、磁盘空间满、进程限制 → 转向资源优化和扩容方案

## 质量检查
- 错误信息完整性检查：确保捕获完整的标准错误输出
- 退出码一致性检查：验证退出码与错误类型匹配
- 环境一致性检查：对比成功执行和失败执行的环境差异
- 可重复性检查：验证故障是否可稳定重现

## 回退策略
- 简化执行环境：使用最小依赖集重新执行
- 分步执行：将复杂命令拆分为多个简单步骤
- 交互式调试：使用调试工具逐步排查
- 社区支持：查阅官方文档、GitHub issues、Stack Overflow
