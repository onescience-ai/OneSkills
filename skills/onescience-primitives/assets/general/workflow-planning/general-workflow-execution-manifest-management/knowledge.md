# 任务执行机制中的execution-manifest.json管理

## 适用范围
面向科学计算工作流执行任务，提供execution-manifest.json的生成时机、格式规范和持久化机制，以及任务超时阈值的设定依据和调整策略。适用于需要确保任务执行状态可追踪、可恢复的科研任务。

## 输入
- 任务配置：任务ID、步骤定义、资源需求
- 执行环境：计算资源、存储路径、网络配置
- 用户参数：关键参数、确认状态、约束条件

## 输出
- execution-manifest.json：任务执行状态核心凭证
- 超时配置文件：超时阈值和调整策略
- 执行日志：任务执行过程记录

## 流程节点
1. **任务初始化** → 生成初始execution-manifest.json
2. **步骤执行** → 每个步骤完成后更新manifest
3. **状态持久化** → 定期保存执行状态
4. **超时监控** → 检测执行时间并触发超时处理
5. **异常恢复** → 从manifest恢复执行状态
6. **任务完成** → 生成最终执行报告

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 生成时机 | 任务启动时 | [通用] | 必须在s01步骤完成后立即生成 |
| 更新频率 | 每个步骤完成后 | [通用] | 确保状态可恢复 |
| 超时阈值 | 预估时长×1.5-2.0 | [通用] | 考虑不确定性 |
| 重试次数 | 3次 | [通用] | 超时后自动重试 |
| 持久化间隔 | 5分钟 | [通用] | 防止状态丢失 |

## 边界与分流
- **manifest缺失时**：任务被判定为无效，需要重新执行
- **manifest格式错误时**：尝试修复格式，失败则重新生成
- **超时阈值不合理时**：根据历史数据调整阈值
- **持久化失败时**：使用备用存储路径或增加重试机制

## 质量检查
- **格式验证**：JSON格式正确，包含所有必需字段
- **状态一致性**：manifest状态与实际执行状态一致
- **持久化可靠性**：定期验证manifest文件可读性
- **超时准确性**：超时阈值与实际执行时间匹配

## 回退策略
1. **手动恢复**：从manifest手动恢复执行状态
2. **重新执行**：从失败步骤重新执行
3. **跳过步骤**：对于非关键步骤尝试跳过
4. **降级执行**：使用简化配置完成任务
