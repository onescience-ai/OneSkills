# CLI非交互执行与故障分类

## 适用范围

**触发条件**：
- 需要在无人值守环境下自动执行CLI工具
- CLI工具执行失败需要诊断故障原因
- 需要处理进程超时、资源耗尽等异常情况

**适用场景**：
- 科研工作流中的批量任务执行
- 自动化测试与持续集成
- 远程计算节点的任务调度
- 归因分析等诊断工具的非交互运行

**不适用场景**：
- 交互式命令行操作
- 图形界面应用程序
- 实时流式数据处理

## 输入

- CLI命令字符串或参数列表
- 执行环境配置（工作目录、环境变量、超时限制）
- 可选：输入数据流（stdin）

## 输出

- 退出码（returncode）
- 标准输出（stdout）
- 标准错误（stderr）
- 结构化故障分类报告

## 流程节点

### Step 1：命令构建与参数化
- **操作**：将CLI命令转换为可执行参数列表
- **参数**：使用shlex.split()解析命令字符串，避免shell注入
- **工具**：subprocess.Popen或subprocess.run
- **质量门禁**：参数列表正确性验证，路径空格安全处理

### Step 2：进程启动与监控
- **操作**：启动子进程并设置超时监控
- **参数**：timeout（秒），stdout/stderr管道配置
- **工具**：subprocess.run(timeout=N)
- **质量门禁**：进程成功启动，超时设置合理（建议30-300秒）

### Step 3：输出捕获与超时处理
- **操作**：等待进程完成或捕获超时异常
- **参数**：capture_output=True，timeout到期后kill进程
- **工具**：subprocess.TimeoutExpired异常处理
- **质量门禁**：超时后正确清理进程资源

### Step 4：退出码分类与诊断
- **操作**：根据退出码判断故障类型
- **参数**：returncode值分析
- **工具**：退出码分类规则（见关键参数表）
- **质量门禁**：故障分类准确，诊断信息完整

### Step 5：错误恢复与重试
- **操作**：根据故障类型执行恢复策略
- **参数**：重试次数、回退方案
- **工具**：异常处理逻辑
- **质量门禁**：恢复策略匹配故障类型

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码 0 | 成功 | [D1] | 命令正常执行完成 |
| 退出码 1-125 | 应用错误 | [D1] | 命令本身执行失败 |
| 退出码 126 | 命令不可执行 | [D1] | 文件无执行权限 |
| 退出码 127 | 命令未找到 | [D1] | PATH中不存在该命令 |
| 退出码 128+N | 信号终止 | [D1] | 被信号N终止（如SIGKILL=137） |
| 退出码 >128 | 信号相关 | [D1] | 负返回码-N表示被信号N终止 |
| 超时异常 | TimeoutExpired | [D1] | 进程执行超时，需kill并清理 |
| 非零退出 | CalledProcessError | [D1] | check=True时非零退出码抛出异常 |

## 边界与分流

- **超时场景**：若进程超时未完成，应kill进程并捕获已产生的输出，避免资源泄漏
- **权限不足**：退出码126表示无执行权限，需检查文件权限设置
- **命令不存在**：退出码127表示命令未找到，需检查PATH环境变量
- **信号终止**：退出码128+N表示被信号终止，需分析系统日志确定原因
- **资源耗尽**：进程因内存或文件描述符耗尽失败，需调整资源限制或优化程序

## 质量检查

- 验证退出码分类是否符合标准语义
- 检查超时后进程是否被正确清理
- 确认stderr输出被完整捕获用于诊断
- 验证重试逻辑不会导致无限循环

## 回退策略

- 超时后重试仍失败：记录诊断信息并标记任务为永久失败
- 权限问题：尝试使用sudo或修改文件权限
- 命令不存在：检查并修正PATH或使用绝对路径
- 资源耗尽：降低并发数或增加系统资源

## 资源召回建议

- 当需要在自动化工作流中执行CLI工具时召回
- 当CLI工具频繁出现非零退出码时召回
- 当需要诊断进程超时或异常终止原因时召回
- 配套卡片：general-json-schema-report-validation（用于输出格式验证）
