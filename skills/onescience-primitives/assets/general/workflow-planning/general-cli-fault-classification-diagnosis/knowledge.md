# CLI非交互执行与故障分类诊断

## 适用范围
适用于所有命令行接口（CLI）工具在非交互环境（如自动化脚本、CI/CD流水线、远程执行环境、批处理作业）中的执行故障诊断。涵盖故障分类、退出码解读、错误日志分析和恢复策略制定。不适用于交互式终端操作或图形用户界面故障诊断。

## 输入
- CLI工具的执行命令和参数
- 执行环境信息（操作系统、shell类型、环境变量）
- 错误输出（stderr）和退出码
- 执行日志（如有）

## 输出
- 故障分类结果（参数错误、认证失败、超时、资源限制、沙箱限制等）
- 退出码解读和错误原因分析
- 恢复策略建议（配置修正、重试策略、降级方案）
- 诊断报告（包含证据和修复建议）

## 流程节点
1. **执行监控** → 捕获退出码、stdout/stderr、执行时间
2. **故障分类** → 根据退出码和错误信息分类故障类型
3. **错误诊断** → 分析错误日志，识别根本原因
4. **恢复策略** → 根据故障类型选择修复方案
5. **验证执行** → 重新执行验证修复效果

每步含：操作、参数、工具、质量门禁

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码0 | 成功 | 通用约定 | 标准Unix/Windows退出码约定 |
| 退出码1 | 通用错误 | 通用约定 | 未分类的错误 |
| 退出码2 | 参数错误 | 通用约定 | 命令行参数使用错误 |
| 退出码126 | 权限错误 | 通用约定 | 无法执行命令 |
| 退出码127 | 命令未找到 | 通用约定 | 命令或路径不存在 |
| 退出码130 | 中断 | 通用约定 | Ctrl+C中断 |
| 超时退出码 | 124/137 | 工具相关 | 命令超时被终止 |

### 校准数值
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认超时 | 30秒 | [论文2] | 超时敏感任务的主要瓶颈 |
| 重试间隔 | 指数退避 | [论文1] | 避免重复触发相同错误 |
| 日志缓冲区 | 4KB | 实践经验 | 保留足够诊断信息 |

## 边界与分流
- **认证失败**：转向认证配置检查（API Key、Token、证书）
- **沙箱限制**：转向沙箱环境配置检查（权限、网络、文件系统访问）
- **超时错误**：转向资源评估和超时参数调整
- **资源不可用**：转向资源申请或降级策略
- **参数错误**：转向命令行参数验证和帮助文档查询

## 质量检查
- 退出码解读与错误信息一致性验证
- 恢复策略执行后的功能回归测试
- 诊断报告的可追溯性（每条结论绑定证据）
