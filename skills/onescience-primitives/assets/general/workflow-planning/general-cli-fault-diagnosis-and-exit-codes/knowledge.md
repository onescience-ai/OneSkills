# CLI 非交互执行与故障分类知识

## 适用范围
面向需要理解命令行界面（CLI）非交互执行场景下的进程终止状态、退出码含义和错误处理的场景。本卡片提供退出码分类、信号处理和故障恢复策略，帮助开发者快速诊断 CLI 执行失败原因并采取相应措施。

## 输入
- **CLI 命令执行结果**：包括标准输出、标准错误和退出码。
- **退出码值**：进程终止时返回给父进程的状态码（0-255）。
- **信号信息**：导致进程终止的信号（如 SIGTERM、SIGKILL）。
- **上下文信息**：命令执行环境、输入参数、依赖资源等。

## 输出
- **故障分类**：根据退出码和信号信息，将故障归类为成功、常规错误、严重错误或信号终止。
- **诊断建议**：提供可能的故障原因和排查步骤。
- **恢复策略**：推荐的重试、回退或人工介入措施。

## 流程节点
1. **执行命令** → 在非交互环境中执行 CLI 命令，捕获输出和退出码。
2. **获取退出码** → 从进程终止状态中提取退出码（status & 0xFF）。
3. **解读退出码** → 根据退出码值判断故障类型（0=成功，非0=错误）。
4. **分类故障** → 结合信号信息和上下文，将故障归类为可恢复或不可恢复。
5. **采取恢复措施** → 根据故障分类执行重试、回退或报警。

每步含：操作、参数、工具、质量门禁。

## 关键参数
### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 成功退出码 | 0 | [D1] | 表示命令执行成功 |
| 常规错误退出码 | 1-125 | [D1] | 表示命令执行过程中出现错误 |
| 信号终止退出码 | 126-127 | [D1] | 表示命令无法执行或被信号终止 |
| 信号退出码 | 128+信号编号 | [D1] | 表示进程被特定信号终止（如 130=128+2=SIGINT） |
| 标准退出常量 | EXIT_SUCCESS (0), EXIT_FAILURE (1) | [D1] | C 标准定义的退出常量 |

### 校准数值
以下数值来自 Linux 系统，供量级校准；其他系统需以自身证据重新锚定。
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码最大值 | 255 | [D1] | 退出码只返回最低有效字节（status & 0xFF） |
| 信号编号范围 | 1-31 | [D1] | 常见信号如 SIGTERM(15), SIGKILL(9), SIGINT(2) |
| 僵尸进程保留时间 | 父进程调用 waitpid 后释放 | [D1] | 退出状态传递给父进程前，进程变为僵尸进程 |

## 边界与分流
- **退出码不在标准范围**：当退出码超出 0-255 时，可能被截断或导致未定义行为，此时应检查命令实现或系统限制。
- **信号处理冲突**：如果父进程设置了 SA_NOCLDWAIT 或 SIGCHLD 为 SIG_IGN，退出状态可能被丢弃，无法获取准确退出码。
- **非标准退出码**：某些应用程序使用非标准退出码表示特定错误，需参考其文档进行解读。

## 质量检查
- 验证退出码提取逻辑（status & 0xFF）是否正确。
- 测试不同故障场景下的退出码值（正常退出、错误退出、信号终止）。
- 确保信号处理符合系统规范（如 SIGCHLD 处理）。
- 监控退出码分布，识别异常模式。

## 回退策略
- 使用默认退出码（如 1）表示未分类错误。
- 记录详细日志（包括退出码、信号、输出）供后续分析。
- 实现重试机制，对于可恢复错误（如临时网络故障）自动重试。
- 对于不可恢复错误，触发报警或人工介入。
