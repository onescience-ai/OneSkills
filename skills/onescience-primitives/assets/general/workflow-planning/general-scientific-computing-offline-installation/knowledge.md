# 科学计算环境离线安装与异常恢复

## 适用范围
**触发条件**：
- 网络连接问题导致无法从PyPI或conda仓库安装依赖包
- 需要在隔离环境或HPC集群上部署科学计算软件
- 依赖安装失败，需要离线解决方案

**适用场景**：
- HPC集群无外网访问权限
- 安全隔离环境中的软件部署
- 网络不稳定导致的安装失败
- 批量部署相同环境

**不适用场景**：
- 有稳定网络连接的环境
- 非Python科学计算栈的安装
- 容器化环境（如Docker）的构建

## 输入
**输入数据**：
- 目标软件包列表（requirements.txt或environment.yml）
- 目标平台信息（操作系统、Python版本、CUDA版本）
- 已下载的离线包目录（可选）

**预处理要求**：
- 在有网络的环境中预先下载依赖包
- 收集目标平台的系统信息
- 确定包依赖关系和版本兼容性

## 输出
**输出产物**：
- 离线安装脚本（install_offline.sh或install_offline.py）
- 依赖包目录结构
- 安装日志和错误报告
- 环境验证结果

**验证标准**：
- 所有依赖包成功安装
- Python导入测试通过
- 关键功能验证通过

## 流程节点
### Step 1：依赖分析
- **操作**：分析目标软件包的依赖关系
- **参数**：输入文件=requirements.txt, 解析工具=pipdeptree或conda tree
- **工具**：pipdeptree, conda list, pip show
- **质量门禁**：依赖树完整，无循环依赖

### Step 2：离线包下载
- **操作**：在有网络环境中下载所有依赖包
- **参数**：下载目录=./offline_packages, 平台=manylinux2014_x86_64
- **工具**：pip download, conda pack
- **质量门禁**：所有依赖包下载成功，版本匹配

### Step 3：镜像源配置
- **操作**：配置本地镜像源或文件系统路径
- **参数**：镜像源路径=/path/to/mirror, 索引文件=local_index.html
- **工具**：pip.conf, .condarc
- **质量门禁**：本地源可访问，包列表完整

### Step 4：离线安装执行
- **操作**：使用离线包安装依赖
- **参数**：安装命令=pip install --no-index --find-links=./offline_packages
- **工具**：pip, conda
- **质量门禁**：安装成功，无网络错误

### Step 5：环境验证
- **操作**：验证安装结果
- **参数**：验证脚本=validate_env.py
- **工具**：python -c "import torch; print(torch.cuda.is_available())"
- **质量门禁**：所有导入成功，功能正常

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| Python版本 | 3.8+ | [1] | 科学计算常用版本 |
| PyPI镜像 | 清华大学镜像 | [2] | 国内加速源 |
| conda离线包格式 | tarball | [3] | conda pack格式 |
| pip离线安装标志 | --no-index | [4] | 禁用网络索引 |

## 边界与分流
**异常处理**：
- 依赖冲突：使用虚拟环境隔离或版本约束
- 平台不兼容：寻找替代包或从源码编译
- 磁盘空间不足：清理缓存或选择性安装

**降级策略**：
- 核心功能优先：只安装必需依赖
- 使用容器：在有网络的环境中构建容器镜像

## 质量检查
**验证点**：
- 依赖包完整性检查
- 版本兼容性验证
- 导入测试
- 功能 smoke test

**阈值**：
- 依赖安装成功率：100%
- 导入测试通过率：100%

**失败处理**：
- 记录详细错误日志
- 回滚到上一个已知良好状态
- 通知管理员

## 回退策略
**失败时的替代方案**：
- 使用容器化部署（Docker/Singularity）
- 从源码编译安装
- 使用其他科学计算栈（如R、Julia）
- 联系管理员配置网络代理
