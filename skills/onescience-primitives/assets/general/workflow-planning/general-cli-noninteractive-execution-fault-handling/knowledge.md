# CLI非交互执行与故障分类

## 适用范围
适用于需要通过命令行接口（CLI）进行非交互式执行的场景，例如自动化脚本、批处理任务、CI/CD流水线。涵盖错误检测、分类、诊断和恢复的通用方法。

## 输入
- 命令行参数字符串或列表
- 环境变量（可选）
- 输入文件或数据流（可选）

## 输出
- 执行结果（成功/失败）
- 退出码（0表示成功，非0表示错误）
- 错误信息（发送到stderr）
- 结构化错误报告（可选）

## 流程节点
1. **参数解析** → 使用CLI解析库（如argparse）定义和解析命令行参数。
2. **输入验证** → 检查参数类型、范围、必填项等。
3. **执行逻辑** → 运行核心业务逻辑。
4. **错误捕获** → 捕获异常并分类（参数错误、运行时错误、资源错误等）。
5. **故障诊断** → 根据错误类型生成诊断信息。
6. **退出处理** → 设置适当的退出码并输出错误信息。

每步含：操作、参数、工具、质量门禁

## 关键参数

### 通用判据（方法层）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码0 | 成功 | [D1] | 约定俗成的成功状态码 |
| 退出码1 | 通用错误 | [D1] | 未指定类别的错误 |
| 退出码2 | 参数错误 | [D1] | 命令行参数解析失败 |
| stderr | 错误流 | [D1] | 错误信息应输出到标准错误流 |
| exit_on_error | True/False | [D1] | argparse参数，控制是否自动退出 |

### 校准数值（实例级）
以下数值来自Python argparse库，供量级校准；其他体系需以自身证据重新锚定。
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认退出码 | 2 | [D1] | argparse解析错误时返回2 |
| 错误信息格式 | "usage: ..." | [D1] | argparse自动生成的错误信息格式 |
| 帮助选项 | -h/--help | [D1] | 默认添加的帮助选项 |

## 边界与分流
- 当CLI解析库不支持非交互执行时，转向手动参数解析。
- 当错误类型无法分类时，使用通用错误退出码1。
- 当需要详细错误报告时，启用结构化输出（如JSON格式）。

## 质量检查
- 验证所有参数在调用前已定义。
- 检查必填参数是否提供。
- 测试无效输入时的错误处理。
- 确认退出码符合POSIX标准。

## 回退策略
- 如果主解析库失败，使用备用解析逻辑。
- 如果错误分类不确定，使用通用错误码。
- 如果自动恢复失败，记录详细日志并退出。
