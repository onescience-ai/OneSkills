# 用户输入超时处理与默认数据集降级策略

## 适用范围

**触发条件**：
- 任务编排系统请求用户确认但未收到响应
- 用户确认阶段超过预设超时阈值
- 需要自动降级到默认数据集继续执行

**适用场景**：
- 科研工作流中用户确认数据来源、执行模式、验收阈值的场景
- 自动化任务执行中用户无法及时响应的情况
- 需要在用户无响应时仍能推进任务执行的场景

**不适用场景**：
- 实时交互式任务（用户必须在线）
- 无默认数据集可用的任务
- 用户明确拒绝使用默认数据集的任务

## 输入

- 用户确认请求：包含需要确认的数据来源、执行模式、验收阈值等
- 超时配置：超时阈值、检查间隔
- 默认数据集配置：可用的demo案例列表、选择条件

## 输出

- 超时检测结果：是否超时、超时时间
- 默认数据集选择：选定的demo案例路径和配置
- 降级执行状态：任务是否成功进入执行阶段
- 状态恢复记录：降级执行的完整日志

## 流程节点

### Step 1：用户确认请求发起
- **操作**：向用户发送确认请求，包含需要确认的内容
- **参数**：
  - 确认内容：数据来源、执行模式、验收阈值
  - 超时阈值：默认300秒（5分钟）
  - 检查间隔：默认30秒
- **质量门禁**：确认请求已成功发送

### Step 2：超时监控
- **操作**：定期检查用户是否已响应
- **参数**：
  - 检查间隔：30秒
  - 预警阈值：80%超时时间
  - 中断阈值：100%超时时间
- **质量门禁**：监控机制正常运行

### Step 3：超时触发降级
- **操作**：当超时触发时，执行降级策略
- **参数**：
  - 降级条件：用户确认超时
  - 降级动作：自动选择默认数据集
  - 日志记录：记录降级原因和时间
- **质量门禁**：降级策略正确触发

### Step 4：默认数据集选择
- **操作**：根据任务类型选择合适的默认数据集
- **参数**：
  - 选择条件：任务类型、领域、复杂度
  - 数据集来源：内置demo案例库
  - 配置适配：自动适配默认数据集的配置
- **质量门禁**：选择的数据集与任务类型匹配

### Step 5：降级执行
- **操作**：使用默认数据集继续执行任务
- **参数**：
  - 执行模式：降级模式（可能跳过某些步骤）
  - 状态标记：标记为降级执行
  - 恢复点：保存执行状态供后续恢复
- **质量门禁**：任务成功进入执行阶段

### Step 6：状态恢复与通知
- **操作**：记录降级执行结果，通知用户
- **参数**：
  - 恢复记录：保存降级执行的完整日志
  - 用户通知：告知用户任务已使用默认数据集执行
  - 恢复选项：提供后续使用真实数据重新执行的选项
- **质量门禁**：恢复记录完整，用户可追溯

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认超时阈值 | 300秒 | 工程实践 | 用户确认的默认超时时间 |
| 检查间隔 | 30秒 | 工程实践 | 平衡监控精度和开销 |
| 预警阈值 | 80% | 工程实践 | 提前提醒即将超时 |
| 降级触发 | 100% | 工程实践 | 超时后自动降级 |
| 重试上限 | 1次 | 工程实践 | 降级后不重试用户确认 |

### 校准数值

以下数值来自具体任务体系，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 用户确认超时 | 300秒 | OneScience系统 | 默认5分钟 |
| 预警通知时间 | 240秒 | OneScience系统 | 超时前1分钟预警 |
| 降级执行标记 | "fallback_by_timeout" | OneScience系统 | 状态标记 |
| 默认数据集路径 | "{TASK_TYPE}_demo" | OneScience系统 | 按任务类型选择 |

## 边界与分流

- **无默认数据集**：若任务类型无可用的默认数据集，记录错误并终止任务
- **用户明确拒绝**：若用户明确拒绝使用默认数据集，等待用户手动干预
- **降级执行失败**：若降级执行也失败，记录错误并提供手动干预指南
- **恢复执行**：用户后续可提供真实数据，重新执行任务覆盖降级结果

## 质量检查

- **超时检测准确**：超时阈值设置合理，不会误判
- **降级策略正确**：降级动作正确执行，任务进入执行阶段
- **默认数据集匹配**：选择的数据集与任务类型匹配
- **恢复记录完整**：降级执行的完整日志可追溯

## 回退策略

- **超时阈值不合理**：根据任务复杂度调整超时阈值
- **默认数据集不匹配**：扩展默认数据集库，覆盖更多任务类型
- **降级执行失败**：提供手动干预指南，记录失败原因
- **恢复执行失败**：终止任务并生成错误报告
