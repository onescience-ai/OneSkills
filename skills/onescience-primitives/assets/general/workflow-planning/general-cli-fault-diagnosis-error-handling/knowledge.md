# CLI 非交互执行与故障诊断

## 适用范围
适用于命令行界面（CLI）工具在非交互环境（如自动化脚本、CI/CD管道、批处理作业）中的执行与故障诊断场景。当需要确保CLI工具在无人值守环境中的稳定执行、快速故障定位和自动恢复时，可使用本框架。不适用于交互式命令行会话或图形用户界面应用。

## 输入
- CLI工具或脚本
- 执行环境配置（超时设置、资源限制、沙箱参数）
- 预期输出格式和验证标准

## 输出
- 执行状态码和退出码
- 标准错误（stderr）和标准输出（stdout）日志
- 故障分类和诊断报告
- 恢复建议和操作指南

## 流程节点
1. 执行准备 → 配置执行环境、设置超时和资源限制
2. 进程启动 → 以非交互模式启动CLI工具
3. 状态监控 → 监控进程状态、资源使用和输出流
4. 故障检测 → 识别异常退出、超时或资源耗尽
5. 故障分类 → 根据退出码和错误信息分类故障类型
6. 恢复执行 → 根据故障类型采取相应恢复策略

每步含：操作、参数、工具、质量门禁

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码分类 | 0-255 | [1] | 标准退出码范围，0表示成功 |
| 超时阈值 | 可配置 | [1] | 根据任务复杂度设置合理超时 |
| 重试次数 | 3次 | [1] | 典型重试策略的最大尝试次数 |
| 资源限制 | 可配置 | [1] | 内存、CPU时间等资源限制 |
| 错误日志级别 | ERROR/WARN/INFO | [1] | 错误信息的详细程度分级 |

### 校准数值
以下数值来自典型CLI工具执行场景，供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 成功退出码 | 0 | [1] | 标准成功状态码 |
| 通用错误退出码 | 1 | [1] | 未指定类型的错误 |
| 参数错误退出码 | 2 | [1] | 命令行参数错误 |
| 资源不可用退出码 | 3 | [1] | 文件或资源不存在 |
| 权限错误退出码 | 4 | [1] | 权限不足或访问被拒绝 |
| 超时退出码 | 124 | [1] | 常见超时状态码（如timeout命令） |

## 边界与分流
- 当退出码不在标准范围内时，检查工具是否使用了自定义退出码约定
- 当超时频繁发生时，应评估任务复杂度并调整超时阈值
- 当资源限制导致失败时，应检查资源使用模式并优化配置
- 当沙箱环境限制过严时，应调整安全策略或寻找替代方案

## 质量检查
- 验证退出码是否符合预期约定
- 检查标准错误输出是否包含有用的诊断信息
- 评估超时设置是否合理（不过长也不过短）
- 验证重试策略是否有效（避免无限重试）
- 检查资源限制是否适当（避免资源耗尽）

## 回退策略
- 当CLI工具无法执行时，检查环境依赖和路径设置
- 当退出码诊断不明确时，使用更详细的日志记录和调试模式
- 当自动恢复失败时，记录完整上下文并通知人工干预
- 当故障分类不确定时，保守处理并记录详细诊断信息
