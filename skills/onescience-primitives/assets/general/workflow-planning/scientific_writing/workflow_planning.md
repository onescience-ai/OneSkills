# when_to_use

Use this primitive for scientific manuscripts, methods/results sections, research reports, declarations, submission preparation, and evidence-bound revision.

# when_not_to_use

- Use literature_review for literature search and synthesis before drafting.
- Use citation_management for bibliographic metadata operations.
- Use output-format primitives for the final DOCX, PDF, PPTX, or Markdown packaging.

# planning_steps

1. Define document type, study design, venue, and accountable authors.
2. Establish evidence, claim, numeric, and consistency records.
3. Draft with explicit evidence bindings and unresolved states.
4. Audit methods, results, citations, figures, tables, and declarations.
5. Hand off final packaging only after human scientific approval.

# fallback

- If evidence is incomplete, produce an outline and unresolved-issues list.
- If venue rules are unknown, mark them pending verification.
- If confidentiality authorization is unclear, keep the workflow local.

# handoff_notes

Include document scope, evidence manifest, claim registry, venue, reporting guideline, figures/tables, declarations, confidentiality status, and approval owner.
