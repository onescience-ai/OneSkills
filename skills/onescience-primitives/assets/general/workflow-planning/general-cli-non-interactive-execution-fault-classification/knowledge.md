# 面向非交互环境的 CLI 执行故障分类与处理

## 适用范围
本卡片为在非交互环境（如自动化脚本、CI/CD 流水线、后台任务）中执行命令行工具的应用提供故障分类与处理方法论。适用于任何需要解析 CLI 退出码、处理执行异常、管理超时和沙箱限制的场景。目标是提供系统化的故障识别、分类和处理策略，提高非交互执行的可靠性。

## 输入
- **CLI 命令**：待执行的命令行指令。
- **执行上下文**：包括环境变量、工作目录、用户权限、资源限制。
- **预期行为**：命令的预期退出码、输出格式、执行时间。
- **故障处理策略**：超时时间、重试次数、降级方案。

## 输出
- **执行结果**：退出码、标准输出、标准错误。
- **故障分类**：根据退出码和错误信息确定的故障类型。
- **处理建议**：针对不同故障类型的处理策略。

## 流程节点
1. **命令执行**：在非交互环境中执行 CLI 命令。
   - 操作：使用系统调用或进程管理库执行命令。
   - 参数：命令字符串、环境变量、超时设置。
   - 工具：系统进程管理库（如 subprocess、exec）。
   - 质量门禁：命令启动成功，进程 ID 有效。
2. **退出码捕获**：捕获命令的退出码。
   - 操作：等待进程结束，获取退出状态。
   - 参数：等待策略（阻塞/非阻塞）、超时处理。
   - 工具：系统进程管理库。
   - 质量门禁：退出码在 0-255 范围内。
3. **故障分类**：根据退出码和错误信息进行故障分类。
   - 操作：映射退出码到故障类型，解析标准错误。
   - 参数：故障分类规则、错误模式匹配。
   - 工具：自定义分类逻辑。
   - 质量门禁：分类结果准确、一致。
4. **故障处理**：根据故障类型执行相应处理策略。
   - 操作：重试、降级、告警、终止。
   - 参数：处理策略配置、重试间隔。
   - 工具：错误处理框架。
   - 质量门禁：处理策略执行成功。

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码范围 | 0-255 | [D1] | 标准退出码范围，超过 255 的值会被截断。 |
| 成功退出码 | 0 | [D1] | 零退出码表示命令成功执行。 |
| 命令未找到 | 127 | [D1] | 命令不存在时返回的退出码。 |
| 命令不可执行 | 126 | [D1] | 命令存在但无执行权限时返回的退出码。 |
| 致命信号终止 | 128+N | [D1] | 命令因信号 N 终止时，退出码为 128+N。 |
| 内建命令错误 | 2 | [D1] | Bash 内建命令使用错误时返回的退出码。 |

### 校准数值
以下数值来自特定应用系统，供量级校准；其他系统需以自身证据重新锚定。
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 典型超时时间（简单命令） | 30秒 | 用户实践 | 根据命令复杂度调整。 |
| 典型重试次数 | 3次 | 用户实践 | 网络或临时故障时的重试次数。 |
| 沙箱内存限制 | 1GB | 用户实践 | 根据命令资源需求调整。 |

## 边界与分流
- **退出码非标准**：某些命令可能返回非标准退出码，需要查阅命令文档。
- **信号处理复杂**：信号终止可能涉及多个信号，需要根据信号类型细分处理。
- **环境差异**：不同操作系统和 shell 的退出码语义可能不同。
- **资源限制**：沙箱环境可能限制系统调用，导致意外退出码。

## 质量检查
- **退出码有效性**：退出码必须在 0-255 范围内。
- **故障分类准确性**：退出码到故障类型的映射必须准确。
- **错误信息完整性**：标准错误必须被捕获和记录。
- **处理策略有效性**：故障处理策略必须执行成功。

## 回退策略
- **退出码未知**：将未知退出码归类为“未分类错误”，执行默认处理策略。
- **命令超时**：强制终止进程，返回超时错误码。
- **资源不足**：降低命令资源需求或使用替代命令。
