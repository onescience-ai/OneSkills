# CLI 非交互执行故障分类与恢复方法论

## 适用范围
本卡片服务于命令行接口（CLI）工具在非交互式环境（如批处理作业、自动化流水线、远程 SSH 会话）中执行时出现的故障诊断与恢复问题。适用于各类科研计算任务、数据处理脚本、模拟工具等依赖 CLI 执行的场景。

## 输入
- CLI 工具的退出码（exit code）
- 标准错误（stderr）输出
- 标准输出（stdout）输出
- 执行环境信息（操作系统、Shell 类型、资源限制）
- 任务上下文（输入参数、依赖文件、网络状态）

## 输出
- 故障类别判定（如：参数错误、资源不足、依赖缺失、超时、认证失败等）
- 恢复策略建议（如：重试、降级、跳过、终止并告警）
- 诊断证据摘要（关键日志片段、退出码解释）

## 流程节点
1. **退出码捕获** → 捕获 CLI 进程的退出码，非零退出码表示故障。
2. **标准错误解析** → 解析 stderr 输出，提取错误关键词、堆栈跟踪、错误消息。
3. **故障分类** → 根据退出码和错误消息，将故障映射到预定义类别。
4. **恢复策略选择** → 根据故障类别和任务关键性，选择恢复策略。
5. **执行恢复** → 执行选定的恢复策略（如重试、降级、终止）。
6. **记录与告警** → 记录故障详情和恢复结果，必要时触发告警。

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码 0 | 成功 | POSIX 标准 | CLI 工具正常退出 |
| 退出码 1 | 一般错误 | POSIX 标准 | CLI 工具遇到通用错误 |
| 退出码 2 | 用法错误 | POSIX 标准 | 命令行参数错误 |
| 退出码 126 | 权限问题 | POSIX 标准 | 无法执行命令 |
| 退出码 127 | 命令未找到 | POSIX 标准 | 命令不存在或路径错误 |
| 退出码 128+N | 信号终止 | POSIX 标准 | 进程被信号 N 终止 |
| 退出码 130 | Ctrl+C | POSIX 标准 | 进程被 SIGINT 终止 |
| 退出码 255 | 超出范围 | 常见约定 | 退出码超出 0-255 范围 |

## 边界与分流
- **退出码不标准**：某些 CLI 工具使用非标准退出码，需查阅工具文档。
- **错误消息模糊**：当 stderr 输出不明确时，需结合 stdout 和上下文信息。
- **环境依赖故障**：如依赖库缺失、权限不足，需转向环境修复流程。
- **网络故障**：如超时、连接拒绝，需检查网络配置和代理设置。
- **资源不足**：如内存不足、磁盘空间不足，需调整资源配额或清理空间。

## 质量检查
- 验证退出码是否符合 POSIX 标准或工具文档定义。
- 检查错误消息是否包含关键信息（如文件路径、参数名）。
- 确保恢复策略与故障类别匹配。
- 记录故障详情以供后续分析。

## 回退策略
- 当故障分类不确定时，默认采取“记录并终止”策略。
- 当恢复策略失败时，升级为人工干预。
- 当工具文档缺失时，使用通用故障分类作为降级方案。
