# 命令行工具故障分类与处理

## 适用范围
面向命令行工具，识别执行故障类型并实施恢复策略，确保工具可靠执行。适用于需要非交互执行、自动化流水线、CI/CD环境的命令行工具。

## 输入
- 命令行工具执行命令
- 执行环境（操作系统、shell类型）
- 预期输出格式

## 输出
- 故障类型分类（退出码、信号、超时、资源耗尽等）
- 故障诊断信息
- 恢复策略建议

## 流程节点
1. **执行命令** → 捕获退出码和标准错误输出
2. **分类故障** → 根据退出码和错误信息判断故障类型
3. **诊断分析** → 分析故障原因（参数错误、依赖缺失、资源不足等）
4. **恢复策略** → 根据故障类型选择恢复策略（重试、回退、终止等）
5. **日志记录** → 记录故障详情和恢复措施

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| EXIT_SUCCESS | 0 | [D1] | 表示成功执行 |
| EXIT_FAILURE | 1 | [D1] | 表示执行失败 |
| 退出码范围 | 0-255 | [D1] | 最低有效字节返回给父进程 |
| 信号终止 | 128+信号编号 | [D1] | 被信号终止时的退出码 |

## 边界与分流
- 退出码为0：视为成功，无需恢复
- 退出码非0：根据具体退出码判断故障类型
- 超时故障：需要设置超时机制和终止策略
- 资源耗尽：需要监控资源使用并实施限流

## 质量检查
- 验证退出码是否符合预期范围
- 检查标准错误输出是否包含关键错误信息
- 确认恢复策略是否有效执行

## 回退策略
- 重试策略：对于临时性故障（如网络问题）
- 回退策略：对于配置错误或依赖缺失
- 终止策略：对于不可恢复的故障
