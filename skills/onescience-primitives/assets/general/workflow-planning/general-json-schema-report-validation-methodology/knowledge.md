# JSON Schema报告交付契约验证方法论

## 适用范围
本卡片为JSON Schema报告提供验证、评估和质量保证的方法论框架，适用于任何需要验证JSON结构化输出的场景，包括API响应验证、数据集成质量检查、报告生成系统等。覆盖模式验证、结构化输出校验、一致性检查和错误处理全流程。

## 输入
- JSON Schema定义文件（标准JSON Schema格式）
- 待验证的JSON数据（单个文档或文档集合）
- 参考模式（如有ground-truth模式）
- 验证规则和阈值配置

## 输出
- 验证结果报告（通过/失败状态）
- 结构化错误详情（路径、错误类型、严重程度）
- 模式质量评估指标（类型准确性、依赖关系、时间演化）
- 修复建议和优化方案

## 流程节点
1. **模式解析** → 加载并解析JSON Schema定义
2. **数据预处理** → 规范化JSON数据格式
3. **验证执行** → 应用验证规则进行检查
4. **质量评估** → 多维度评估模式质量（SVEF框架）
5. **错误分析** → 分类和优先级排序验证错误
6. **报告生成** → 生成结构化验证报告

## 关键参数
### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 类型准确性度量 | Type Conformance = |交集|/|并集| | [1] | SVEF框架的数据类型准确性指标 |
| 必需字段阈值 | 0.90 | [1] | 属性在数据集中出现的最小频率 |
| 依赖关系置信度 | 0.80 | [1] | 关联规则的最小置信度 |
| 时间演化检测 | VDA + CDR组合 | [1] | 版本检测准确率和变化检测率 |

### 校准数值
以下数值来自SVEF框架实验，供量级校准；其他系统需以自身证据重新锚定：
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 维度权重 | DTA:0.20, ROF:0.15, MTS:0.15, CSC:0.15, ERR:0.20, TED:0.15 | [1] | SVEF六维评估权重配置 |
| 惩罚系数λ | 0.5 | [1] | 多类型支持中的过度泛化惩罚 |
| 同质性权重α | 0.7 | [1] | 集合结构一致性中的熵-深度平衡 |
| 关系平衡系数β | 0.7 | [1] | 实体关系恢复中的F1-图编辑距离平衡 |

## 边界与分流
- **模式语法错误**：转向模式修复和语法验证工具
- **数据格式不匹配**：转向数据转换和适配层
- **验证性能瓶颈**：转向增量验证和流式处理
- **跨版本兼容性问题**：转向模式演进和版本管理
- **复杂依赖关系**：转向图对齐和关系图验证

## 质量检查
- 验证覆盖率：所有必需字段和类型约束
- 错误检测率：漏报率<5%，误报率<10%
- 性能指标：验证延迟<100ms（千文档级）
- 可扩展性：支持模式版本演进和增量更新

## 回退策略
- 当模式过于复杂时，回退到核心字段验证
- 当验证超时时，回退到采样验证策略
- 当参考模式不可用时，回退到基于规则的启发式验证
- 当遇到未知数据类型时，回退到通用类型检测
