# CFD任务标准产物清单

## 适用范围

面向CFD工作流管理任务，定义标准产物清单。适用于所有需要执行完整CFD数据驱动预测工作流的任务，包括数据准备、模型训练、后验评估和验收评估等阶段。不适用于单一阶段任务或非CFD领域任务。

## 输入

- 任务目标：执行完整CFD数据驱动预测工作流
- 数据需求：任务配置、阶段定义、产物规范
- 格式要求：JSON配置文件、目录结构

## 输出

- 每阶段的标准产物文件
- 产物完整性检查报告
- 缺失产物列表和修复建议

## 流程节点

1. **定义产物清单** → 2. **检查产物完整性** → 3. **识别缺失产物** → 4. **生成修复建议** → 5. **验证产物质量**

### 步骤1：定义产物清单
- 操作：明确每个阶段的必选和可选产物
- 参数：阶段名称、产物名称、产物格式、是否必选
- 工具：任务文档、领域知识
- 质量门禁：产物清单完整，覆盖所有阶段

### 步骤2：检查产物完整性
- 操作：检查每个阶段的产物是否齐全
- 参数：产物文件路径、文件存在性、格式正确性
- 工具：文件检查脚本
- 质量门禁：检查准确，无遗漏

### 步骤3：识别缺失产物
- 操作：识别缺失的产物文件
- 参数：缺失产物名称、缺失原因、影响范围
- 工具：分析脚本
- 质量门禁：识别准确，原因明确

### 步骤4：生成修复建议
- 操作：为缺失产物生成修复建议
- 参数：修复方法、所需资源、预计时间
- 工具：建议生成器
- 质量门禁：建议可行，资源明确

### 步骤5：验证产物质量
- 操作：验证已存在产物的质量
- 参数：产物完整性、格式正确性、内容合理性
- 工具：质量检查脚本
- 质量门禁：产物质量良好，符合规范

## 边界与分流

### 前提1：任务阶段定义明确
- **不成立时转向**：使用标准5阶段工作流，或根据任务需求调整阶段

### 前提2：产物规范已定义
- **不成立时转向**：使用标准产物规范，或根据任务需求自定义产物

### 前提3：检查工具可用
- **不成立时转向**：手动检查产物完整性，或编写简单检查脚本

## 质量检查

1. **清单完整性**：检查产物清单是否覆盖所有阶段
2. **产物存在性**：检查所有必选产物是否存在
3. **格式正确性**：检查产物格式是否符合规范
4. **内容合理性**：检查产物内容是否合理
5. **可追溯性**：检查产物是否可追溯到任务配置

## 回退策略

1. **产物缺失**：补充缺失产物，重新生成
2. **格式错误**：修正格式错误，重新生成
3. **内容不合理**：修正内容，重新生成
4. **检查工具不可用**：手动检查，或编写简单检查脚本
