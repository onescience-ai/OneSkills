# 数据标准化技能三段式源解析机制

## 适用范围

面向科学计算任务的数据标准化需求，提供将原始数据转换为AI-Ready格式的标准化机制。适用于需要将外部数据源（用户显式路径、本地文件系统、ModelScope平台）转换为统一数据格式的场景。

**触发条件**：
- 任务需要处理外部数据集
- 数据源格式不符合AI-Ready标准
- 需要将数据注册到数据管理系统

**适用场景**：
- 科研工作流中的数据准备阶段
- 多源数据集成与标准化
- 数据集构建与发布
- 模型训练前的数据预处理

**不适用场景**：
- 已经是AI-Ready格式的数据
- 实时流式数据处理
- 数据清洗与特征工程（在标准化之后进行）

## 输入

### 任务上下文
| 输入类型 | 说明 | 来源 |
|---------|------|------|
| dataset_name | 数据集名称 | 任务上下文 |
| domain | 数据领域（cfd/bio/climate/matchem） | 任务上下文 |
| source_dir | 数据源目录（可选） | 用户指定或自动探测 |
| target_dir | 目标目录（可选） | 用户指定或默认 |
| autonomous_mode | 自主执行模式 | 配置参数 |

### 数据源类型
| 数据源 | 说明 | 解析优先级 |
|-------|------|-----------|
| 显式路径 | 用户明确指定的数据路径 | 最高 |
| 本地探测 | 在本地文件系统中自动搜索 | 中等 |
| ModelScope | 从ModelScope平台下载 | 最低 |


## 流程节点

### Step 1：触发条件评估
- **操作**：检查任务是否需要数据标准化
- **参数**：
  - 任务类型：训练/推理/分析
  - 数据状态：原始/已标准化
  - 数据可用性：可用/不可用
- **质量门禁**：确认需要数据标准化

### Step 2：三段式源解析
- **操作**：按优先级解析数据源
- **参数**：
  - 优先级1：显式路径（用户指定）
  - 优先级2：本地探测（自动搜索）
  - 优先级3：ModelScope下载（在线获取）
- **质量门禁**：成功解析到至少一个数据源

### Step 3：数据转换与标准化
- **操作**：将原始数据转换为AI-Ready格式
- **参数**：
  - Tier1：确定性适配器（已知格式转换）
  - Tier2：LLM合成转换器（未知格式生成）
- **质量门禁**：数据格式符合AI-Ready标准

### Step 4：数据注册与验证
- **操作**：将标准化数据注册到数据管理系统
- **参数**：
  - 注册位置：~/.onescience/data_management.json
  - 验证标准：数据完整性、格式正确性
- **质量门禁**：注册成功且验证通过

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 源解析优先级 | 显式路径 > 本地探测 > ModelScope | [规范] | 三段式解析顺序 |
| 转换器选择 | Tier1优先，Tier2兜底 | [规范] | 确定性转换优先 |
| 注册验证 | 100%通过 | [规范] | 所有产物必须验证 |
| 数据审计 | 必须生成 | [规范] | 提供数据质量报告 |
| 目录结构 | 标准化结构 | [规范] | 符合AI-Ready标准 |

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| ModelScope下载超时 | 300秒 | OneScience系统 | 单次下载超时 |
| 本地探测深度 | 3层 | OneScience系统 | 目录搜索深度 |
| 数据验证阈值 | 95% | OneScience系统 | 数据完整性阈值 |
| 注册重试次数 | 3次 | OneScience系统 | 注册失败重试 |

## 边界与分流

### 异常处理
| 异常情况 | 处理策略 | 降级方案 |
|---------|---------|---------|
| 显式路径不存在 | 尝试本地探测 | 标记为数据不可用 |
| 本地探测无结果 | 尝试ModelScope下载 | 标记为离线模式 |
| ModelScope下载失败 | 使用合成数据 | 标记为合成数据 |
| 数据格式不兼容 | 使用Tier2转换器 | 标记为格式转换 |
| 注册失败 | 重试3次 | 标记为注册失败 |

### 分支条件
- 若数据源可用：执行标准化流程
- 若数据源不可用：使用降级策略或终止任务
- 若格式不兼容：尝试格式转换或使用合成数据

## 质量检查

### 验证点
1. 数据源解析成功
2. 数据格式转换正确
3. 目录结构符合标准
4. 注册信息完整
5. 数据审计通过

### 阈值
| 指标 | 阈值 | 失败处理 |
|------|------|---------|
| 数据完整性 | 95% | 补充缺失数据 |
| 格式正确性 | 100% | 重新转换 |
| 注册成功率 | 100% | 重试或降级 |
| 审计通过率 | 90% | 数据清洗 |

## 回退策略

1. **数据源不可用**：使用合成数据或终止任务
2. **格式转换失败**：使用简化格式或人工干预
3. **注册失败**：本地存储并记录注册失败
4. **审计失败**：数据清洗后重新审计
