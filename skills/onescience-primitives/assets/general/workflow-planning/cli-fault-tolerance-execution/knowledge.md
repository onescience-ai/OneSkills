# CLI非交互执行与故障分类通用方法论

## 适用范围
面向命令行接口（CLI）非交互执行场景，提供故障分类、错误码解析、超时处理、沙箱隔离与恢复策略的通用方法论框架。适用于任意CLI工具或脚本的健壮性增强与自动化运维，包括但不限于科学计算工具、数据处理流水线、系统管理脚本等。不适用于交互式CLI会话或图形用户界面应用。

## 输入
- CLI工具或脚本的命令行参数、认证凭据、执行环境配置
- 超时阈值、重试策略、沙箱隔离级别等运维参数
- 任务执行历史日志与错误码记录

## 输出
- 结构化故障分类报告（故障类型、错误码、影响范围、恢复建议）
- 可执行的恢复策略（重试、降级、回滚、告警）
- 健壮性增强后的CLI配置或包装脚本

## 流程节点

### 故障分类阶段
1. **故障类型识别** → 2. **错误码解析** → 3. **影响范围评估** → 4. **恢复策略选择**

### 每步操作
- **故障类型识别**：根据退出码、错误输出、超时信号等特征，将故障归类为：
  - 退出码类故障（非零退出码、异常终止）
  - 超时类故障（执行超时、响应超时）
  - 认证类故障（凭据失效、权限不足）
  - 资源类故障（内存不足、磁盘满、网络不可达）
  - 依赖类故障（外部服务不可用、库缺失）
  - 沙箱类故障（隔离策略冲突、权限限制）
- **错误码解析**：参照POSIX标准、工具特定约定或自定义规范，将退出码映射为语义化错误类型
- **影响范围评估**：判断故障是局部（单次执行失败）还是系统性（配置错误、环境问题）
- **恢复策略选择**：根据故障类型和影响范围，选择重试、降级、回滚或告警策略

### 质量门禁
- 每次故障必须绑定具体证据（日志片段、错误输出、退出码）
- 恢复策略必须可执行、可验证
- 系统性故障必须触发配置审查而非简单重试

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码语义 | 0=成功，1-125=工具错误，126=不可执行，127=未找到，128+=信号终止 | [论文1] | POSIX标准约定 |
| 超时阈值 | 根据任务复杂度设置，建议60-300秒 | [论文3] | 避免无限等待 |
| 重试次数 | 临时故障3次，系统性故障1次 | [论文1] | 平衡效率与稳定性 |
| 沙箱级别 | 最小权限原则，仅授予必要资源访问 | [论文4] | 安全隔离 |

### 校准数值
以下数值来自具体CLI工具实践，供量级校准；其他体系需以自身证据重新锚定：
- 医疗集成引擎超时框架：外部API调用超时30秒，重试2次，降级到缓存响应 [论文3]
- WLCG CLI认证：JWT token有效期1小时，自动刷新机制 [论文4]

## 边界与分流
- **临时故障**（网络抖动、资源暂时不可用）→ 重试策略（指数退避）
- **永久故障**（配置错误、凭据失效）→ 立即告警，不重试
- **系统性故障**（环境问题、依赖缺失）→ 触发配置审查或环境修复
- **安全故障**（权限不足、沙箱冲突）→ 终止执行，记录审计日志

## 质量检查
- 验证点：每次故障分类必须有明确的退出码或错误输出证据
- 阈值：系统性故障比例超过10%需触发环境审查
- 失败处理：无法分类的故障记录为"未知故障"，保留完整日志供后续分析

## 回退策略
- 降级执行：使用简化参数或模拟模式完成部分任务
- 手动干预：复杂故障转交运维人员处理
- 任务跳过：非关键任务失败时继续执行后续任务
