# CLI 非交互执行与故障分类

## 适用范围

面向命令行界面（CLI）工具的非交互执行场景，提供故障分类、诊断与恢复的通用方法论。适用于任何需要自动化执行CLI工具的科研工作流，包括但不限于数据处理、模型训练、仿真模拟等场景。当CLI工具在无人值守环境中执行时，本方法论帮助识别、分类和处理各类故障，确保工作流的稳定性和可恢复性。

## 输入

- CLI工具的命令行参数和配置
- 执行环境信息（操作系统、依赖版本、资源限制）
- 输入数据路径和格式
- 预期输出格式和验证标准

## 输出

- 故障分类结果（故障类型、严重程度、影响范围）
- 诊断报告（错误日志、堆栈跟踪、环境快照）
- 恢复策略（重试、降级、人工干预）
- 执行状态（成功、失败、部分完成）

## 流程节点

1. **故障检测** → 2. **故障分类** → 3. **根因分析** → 4. **恢复策略选择** → 5. **执行与验证**

### 步骤1：故障检测
- **操作**：监控CLI进程的退出码、标准输出、标准错误、执行时间
- **参数**：超时阈值、资源限制、输出缓冲区大小
- **工具**：进程监控工具、日志收集器
- **质量门禁**：及时检测故障，避免僵尸进程

### 步骤2：故障分类
- **操作**：根据退出码和错误信息将故障分类为：参数错误、环境问题、资源不足、数据问题、依赖缺失、超时、认证失败、沙箱限制等
- **参数**：退出码映射表、错误模式库
- **工具**：模式匹配、规则引擎
- **质量门禁**：准确分类，避免误判

### 步骤3：根因分析
- **操作**：分析故障的深层原因，包括依赖关系、环境配置、数据完整性
- **参数**：依赖图、配置模板、数据校验规则
- **工具**：日志分析器、依赖检查器
- **质量门禁**：定位根本原因，而非表面症状

### 步骤4：恢复策略选择
- **操作**：根据故障类型选择恢复策略：自动重试、参数调整、环境修复、人工干预
- **参数**：重试策略（指数退避、固定间隔）、降级方案、通知机制
- **工具**：策略引擎、工作流调度器
- **质量门禁**：选择合适的恢复策略，避免无限重试

### 步骤5：执行与验证
- **操作**：执行恢复策略，验证输出结果，记录执行日志
- **参数**：验证规则、日志格式、通知渠道
- **工具**：验证器、日志记录器、通知服务
- **质量门禁**：确保恢复成功，输出符合预期

## 关键参数

## 边界与分流

- **前提1：CLI工具可执行** → 若命令不存在或无权限，转向环境配置修复或人工干预
- **前提2：输入数据有效** → 若数据格式错误或路径不存在，转向数据预处理或验证
- **前提3：资源充足** → 若内存或磁盘不足，转向资源扩容或任务降级
- **前提4：网络可达** → 若需要网络访问但连接失败，转向网络诊断或离线模式
- **前提5：依赖满足** → 若缺少依赖库，转向依赖安装或环境重建

## 质量检查

- 退出码分类准确率 ≥ 95%
- 故障检测延迟 ≤ 5秒
- 恢复策略成功率 ≥ 80%
- 日志完整性 ≥ 99%

## 回退策略

- 自动恢复失败时，发送人工干预通知
- 记录详细故障信息，便于后续分析
- 提供降级方案，确保核心功能可用
