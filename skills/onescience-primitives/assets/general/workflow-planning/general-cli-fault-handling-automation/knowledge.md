# CLI非交互执行与故障分类通用方法论

## 适用范围

面向通过命令行接口（CLI）执行非交互式自动化任务的场景，提供故障分类、错误处理和诊断的通用方法论。适用于任何需要通过CLI执行批处理、自动化脚本、作业提交等任务并处理执行失败的领域，包括但不限于科学计算、数据处理、系统运维、持续集成等。

不适用于交互式CLI会话、图形用户界面应用、Web服务请求处理或需要人工实时干预的场景。

## 输入

- **CLI命令**：要执行的命令行指令，包括可执行文件路径和参数
- **环境配置**：环境变量、工作目录、用户权限、资源限制
- **超时设置**：命令执行的最大允许时间
- **重试策略**：失败后的重试次数和退避策略

## 输出

- **退出码（Exit Code）**：表示命令执行结果的整数值
- **标准输出（stdout）**：命令的正常输出流
- **标准错误（stderr）**：命令的错误输出流
- **诊断日志**：详细的执行过程和错误信息记录
- **健康状态**：命令是否成功完成、是否需要干预

## 流程节点

### 1. 命令预处理
- **操作**：解析命令行参数，验证输入合法性
- **参数**：命令字符串、参数列表、环境变量
- **工具**：Shell解析器、参数验证库
- **质量门禁**：命令语法正确、参数类型匹配、路径有效

### 2. 环境准备
- **操作**：设置执行环境，包括工作目录、权限、资源限制
- **参数**：用户身份、资源配额、临时文件路径
- **工具**：环境管理器、权限检查器
- **质量门禁**：环境配置完整、权限充足、资源可用

### 3. 命令执行
- **操作**：启动子进程执行命令，监控执行状态
- **参数**：超时时间、输出捕获策略
- **工具**：进程管理器、输出流重定向
- **质量门禁**：进程正常启动、输出正常捕获、超时监控生效

### 4. 退出码分类
- **操作**：根据退出码判断执行结果类型
- **参数**：退出码值、预期退出码
- **工具**：退出码解析器
- **质量门禁**：退出码正确分类、错误类型识别准确

### 5. 错误处理
- **操作**：根据错误类型执行相应的处理策略
- **参数**：错误类型、重试策略、降级方案
- **工具**：错误处理器、重试管理器
- **质量门禁**：错误处理策略匹配、重试次数合理、降级方案有效

### 6. 诊断记录
- **操作**：记录详细的执行信息和错误诊断
- **参数**：日志级别、日志格式、存储位置
- **工具**：日志系统、诊断工具
- **质量门禁**：日志完整、格式规范、便于后续分析

## 边界与分流

### 前提1：命令可执行
- **条件**：命令存在且有执行权限
- **不成立时转向**：返回退出码127（命令不存在）或126（无权限），记录诊断信息

### 前提2：资源可用
- **条件**：系统资源（内存、CPU、磁盘）充足
- **不成立时转向**：返回退出码1（一般错误），记录资源不足信息

### 前提3：环境兼容
- **条件**：执行环境满足命令要求
- **不成立时转向**：返回退出码1，记录环境不兼容信息

### 前提4：超时合理
- **条件**：设置的超时时间足够命令完成
- **不成立时转向**：返回退出码124（超时），建议增加超时时间

## 质量检查

| 检查点 | 阈值 | 失败处理 |
|--------|------|----------|
| 退出码有效性 | 0-255 | 非法退出码视为一般错误 |
| 输出捕获完整性 | 100% | 输出丢失视为执行异常 |
| 诊断信息完整性 | 包含时间戳、命令、参数、退出码 | 缺失关键信息视为诊断失败 |
| 重试成功率 | >50% | 重试成功率过低需调整策略 |
| 超时检测准确性 | 误报率<1% | 误报率过高需调整超时检测算法 |

## 回退策略

1. **降级执行**：尝试使用简化参数或替代命令执行
2. **部分成功处理**：记录已完成部分，跳过失败部分继续执行
3. **人工干预**：在自动处理失败时，记录详细诊断信息等待人工处理
4. **资源清理**：无论成功失败，都清理临时文件和资源
