# CLI非交互执行与故障分类知识

## 适用范围
本卡片为非交互环境中命令行工具执行提供故障分类与退出码处理方法，确保工具在批处理、自动化和脚本化场景下能够稳定运行并提供可诊断的错误信息。适用于任何需要通过脚本或程序调用外部命令行工具并处理其执行结果的场景，不适用于交互式shell会话或图形界面工具。

## 输入
- 命令行工具执行环境（shell、脚本、程序）
- 工具退出码（整数，0-255）
- 标准错误输出（stderr）
- 信号（如SIGTERM、SIGINT）
- 父进程等待状态

## 输出
- 故障分类（成功、一般错误、特定错误、信号终止）
- 错误传播机制（退出码传递、信号转发）
- 恢复策略（重试、跳过、终止、记录日志）

## 流程节点
1. 执行工具并捕获退出码 → 操作：运行命令，参数：命令字符串，工具：shell执行器，质量门禁：退出码在0-255范围内
2. 分类退出码 → 操作：根据退出码语义分类，参数：退出码值，工具：分类逻辑，质量门禁：覆盖所有已知退出码类别
3. 处理标准错误输出 → 操作：捕获并解析stderr，参数：错误输出流，工具：流处理器，质量门禁：错误信息完整记录
4. 根据错误类型采取恢复策略 → 操作：选择恢复策略，参数：故障分类结果，工具：策略选择器，质量门禁：策略匹配错误类型

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码语义 | 0=成功，非0=失败 | [D1][D2] | POSIX标准定义的退出码含义 |
| EXIT_SUCCESS | 0 | [D1][D2] | 成功终止的常量 |
| EXIT_FAILURE | 1 | [D1][D2] | 失败终止的常量 |
| 退出码范围 | 0-255 | [D1] | 只有最低有效字节传递给父进程 |
| 僵尸进程 | 子进程终止后保留状态 | [D1][D2] | 父进程需通过wait获取状态 |
| 线程安全 | exit()非线程安全 | [D1] | 使用全局变量，多线程环境需注意 |

### 校准数值
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| BSD退出码标准 | 参见sysexits.h | [D1] | BSD尝试标准化的退出码 |
| 信号SIGHUP | 前台进程组收到 | [D1] | 会话领导进程终止时发送 |
| atexit函数调用顺序 | 逆序调用 | [D1][D2] | 注册函数的调用顺序 |

## 边界与分流
- 退出码不在0-255范围 → 转为未知错误处理，记录原始值并报告异常
- 信号导致终止 → 转为信号处理流程，根据信号类型决定是否核心转储
- 父进程未等待子进程 → 僵尸进程状态保留，直到父进程调用wait
- atexit函数未返回 → 剩余函数不调用，exit处理不完成
- 多次调用exit() → 行为未定义，应避免

## 质量检查
- 验证退出码是否在0-255范围内
- 验证标准错误输出是否被捕获并记录
- 验证退出码分类是否覆盖所有已知类别
- 验证恢复策略是否匹配错误类型

## 回退策略
- 使用默认错误处理：记录退出码和错误信息，继续执行后续任务
- 对于未知退出码，标记为"未知错误"并记录详细日志
- 对于信号终止，根据信号类型决定是否重试

- 自动化流程中需要根据错误类型采取不同恢复策略
- 需要构建可诊断的CLI工具执行环境

## 补充：JSON Schema报告交付契约

### 适用范围
本补充节规定CLI工具输出JSON报告时的Schema校验契约，确保结构化报告符合预定义格式，便于自动化处理和验证。

### 输入
- CLI工具的stdout输出（JSON字符串）
- 预定义的JSON Schema文件（draft-07或更新版本）
- 校验选项（如严格模式、容错模式）

### 输出
- 校验结果（成功/失败）
- 校验错误列表（字段缺失、类型错误、约束违反等）
- 校验后的结构化报告（如通过校验）

### 流程节点
1. **JSON解析** → 将stdout字符串解析为JSON对象，处理编码和格式问题。
2. **Schema加载** → 加载并编译JSON Schema，支持引用和递归定义。
3. **Schema校验** → 根据Schema校验JSON对象，检查必填字段、类型、格式、约束。
4. **错误分类** → 将校验错误分类为字段缺失、类型错误、格式错误、约束违反等。
5. **报告生成** → 生成校验报告，包含错误详情和建议修复措施。

### 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| JSON Schema版本 | draft-07 | [D3] | 当前广泛支持的版本 |
| 校验模式 | 严格模式 | 经验值 | 不容忍额外字段或类型 coerce |
| 错误信息格式 | JSON数组 | 通用约定 | 每个错误包含路径、消息、严重性 |

### 边界与分流
- **JSON解析失败** → 视为Schema校验失败，错误分类为"JSON格式错误"。
- **Schema文件缺失或无效** → 跳过校验，报告为"Schema校验不可用"。
- **校验超时** → 根据输出大小调整超时时间，或分块校验。
- **Schema版本不兼容** → 降级到最接近的兼容版本，或报告兼容性问题。

### 质量检查
- 验证JSON解析是否成功。
- 验证Schema是否有效且可编译。
- 验证校验错误是否完整捕获。
- 验证校验报告是否包含足够信息用于修复。

### 回退策略
- 如果严格模式校验失败，尝试宽松模式（允许额外字段）。
- 如果Schema校验超时，分块校验或增加超时时间。
- 如果Schema文件不可用，跳过校验并记录警告。
