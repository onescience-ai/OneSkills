# CLI非交互执行与故障分类知识

## 适用范围
本卡片服务的问题类：在命令行接口非交互执行场景下，如何对进程终止状态进行分类、解读退出码含义、处理错误码体系，并建立故障诊断流程。适用于自动化脚本、批处理作业、远程执行等需要程序化处理CLI执行结果的场景。

## 输入
- CLI命令执行结果（退出码、标准输出、标准错误）
- 进程终止状态信息
- 错误码（errno）值
- 父进程等待状态

## 输出
- 故障分类结果（成功/失败/异常类型）
- 退出码解读报告
- 错误处理建议
- 故障诊断流程图

## 流程节点
1. **进程终止状态捕获** → 捕获子进程退出码（status & 0xFF）[D1]
2. **退出码分类** → 区分EXIT_SUCCESS（0）、EXIT_FAILURE（非0）及自定义退出码 [D1]
3. **错误码解析** → 读取errno变量，映射到具体错误类型（如ENOENT、EACCES）[D2]
4. **故障类型判定** → 根据退出码和错误码组合判定故障类别
5. **错误处理执行** → 根据故障类型执行相应处理策略
6. **诊断报告生成** → 生成结构化故障诊断报告

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| EXIT_SUCCESS | 0 | [D1] | 成功终止标准码 |
| EXIT_FAILURE | 非0 | [D1] | 失败终止标准码 |
| 退出码提取 | status & 0xFF | [D1] | 获取进程终止状态最低有效字节 |
| errno线程安全 | 线程本地 | [D2] | errno是线程局部变量 |

### 校准数值
以下数值来自Linux系统，供量级校准；其他系统需以自身证据重新锚定：
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| EPERM | 1 | [D2] | 操作不允许 |
| ENOENT | 2 | [D2] | 无此文件或目录 |
| EACCES | 13 | [D2] | 权限拒绝 |
| EIO | 5 | [D2] | 输入/输出错误 |

## 边界与分流
- **前提1：进程正常终止** → 若进程被信号终止，退出码为信号编号+128，需转信号处理流程
- **前提2：父进程正确等待** → 若父进程未设置SA_NOCLDWAIT，子进程可能成为僵尸进程
- **前提3：errno有效读取** → errno仅在系统调用失败后有效，成功调用后可能被修改

## 质量检查
- 验证退出码是否在0-255范围内（status & 0xFF）
- 检查errno是否在调用前被重置（对某些函数）
- 确认错误码映射表与目标系统一致
- 验证故障分类逻辑覆盖所有常见错误类型

## 回退策略
- 当errno信息不足时，检查标准错误输出（stderr）
- 当退出码为非标准值时，查阅具体程序的文档
- 当信号终止时，分析信号来源（如SIGKILL、SIGSEGV）
