# JSON Schema 报告交付契约验证

## 适用范围
本卡片为结构化报告生成场景提供基于 JSON Schema 的报告交付契约验证方法。适用于自动化报告生成、数据导出、API 响应验证等场景，确保报告格式符合预定义规范。覆盖必填字段、数据类型、数组约束、任务身份匹配等验证点。不适用于非 JSON 格式报告或动态 schema 场景。

## 输入
- 报告 JSON 数据
- JSON Schema 定义文件
- 任务身份信息（任务 ID、任务名称）
- 验证配置（严格模式、错误处理策略）

## 输出
- 验证结果（通过/失败）
- 错误详情（字段路径、错误类型、错误描述）
- 修复建议（字段格式、缺失字段、类型转换）
- 验证报告（验证统计、性能指标）

## 流程节点
1. **Schema 加载** → 解析 JSON Schema，验证语法正确性
2. **数据预处理** → 清理数据，处理特殊字符，确保 JSON 格式
3. **验证执行** → 逐字段验证，检查类型、约束、必填字段
4. **错误收集** → 收集所有验证错误，分类整理
5. **报告生成** → 生成验证报告，提供修复建议

## 关键参数

### 通用判据（方法层）
| 参数 | 判据 | 来源 | 说明 |
|------|------|------|------|
| 验证模式选择 | 严格/宽松 | [论文1] | 根据数据重要性和容错需求选择 |
| 错误处理策略 | 阻断/继续 | 通用实践 | 根据验证目的和后续流程选择 |
| 验证范围 | 必填字段+可选字段 | 通用实践 | 根据契约要求确定验证范围 |
| 错误报告格式 | 结构化JSON | 通用实践 | 便于自动化处理和集成 |

### 校准数值（体系专属值）
以下数值来自特定系统，供量级校准；其他系统需以自身证据重新锚定。
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 验证性能目标 | ≤100ms | [论文2] | 对于中等规模报告，验证时间应控制在毫秒级 |
| 验证加速比 | 10倍 | [论文2] | 编译优化后的验证性能提升 |
| 字段覆盖率 | 100% | 通用实践 | 所有必填字段必须验证，可选字段按需验证 |

## 边界与分流
- **Schema 语法错误**：检查 JSON Schema 格式，修复语法问题
- **数据类型不匹配**：检查字段类型，提供类型转换建议
- **必填字段缺失**：确定是否为关键字段，决定是否继续验证
- **数组约束违反**：检查数组长度、元素类型、唯一性约束
- **任务身份不匹配**：验证任务 ID 和名称，确保报告与任务一致

## 质量检查
- 验证准确率 ≥ 99%
- 误报率 ≤ 1%
- 验证性能 ≤ 100ms（中等规模报告）
- 错误描述清晰度 ≥ 90%

## 回退策略
1. **Schema 加载失败**：使用备用 schema 或跳过验证
2. **验证性能过慢**：优化 schema 复杂度，使用编译优化
3. **错误描述不清晰**：提供通用错误模板，人工补充细节
4. **任务身份验证失败**：记录不匹配信息，人工审核
