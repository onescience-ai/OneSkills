# 论文获取替代方案和降级策略

## 适用范围
- **触发条件**：当主论文源（如arXiv）不可访问时使用
- **适用场景**：
  - 网络连接受限环境
  - 学术网络访问限制
  - 论文下载失败时的降级处理
- **不适用场景**：
  - 正常网络环境下的论文获取
  - 需要完整论文全文的场景

## 输入
- **论文标识符**：DOI、arXiv ID或论文标题
- **网络环境**：当前网络连接状态
- **降级策略**：选择的降级方案

## 输出
- **论文元数据**：标题、作者、摘要等基本信息
- **论文内容**：摘要或部分内容
- **获取状态**：成功/失败及原因

## 流程节点
1. **主源尝试** → 尝试从arXiv等主源获取
2. **镜像站点** → 尝试从镜像站点获取
3. **DOI检索** → 使用DOI检索服务获取元数据
4. **本地缓存** → 检查本地是否已有相关论文
5. **标准信息提取** → 从场景索引的标准字段提取任务信息

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 主源 | arXiv | [1] | 首选论文来源 |
| 镜像站点 | arXiv备份 | [1] | 主源不可用时的备选 |
| DOI服务 | CrossRef、DOI.org | [1] | 通过DOI获取元数据 |
| 本地缓存 | 本地文件系统 | [1] | 检查已下载的论文 |
| 标准字段 | 场景索引 | [1] | 从标准workflow和prompt字段提取 |

## 边界与分流
- **异常处理**：
  - 当所有源都不可用时，记录失败原因
  - 当网络超时时，自动切换到其他源
- **降级策略**：
  - 从全文获取降级到摘要获取
  - 从实时获取降级到缓存获取
- **分支条件**：
  - 根据网络状态选择获取策略
  - 根据论文类型选择最佳源

## 质量检查
- **验证点**：
  - 论文元数据完整性检查
  - 内容质量评估
  - 获取状态验证
- **阈值**：
  - 元数据完整度 > 80%
  - 内容长度 > 500字符
- **失败处理**：
  - 记录失败原因
  - 使用替代方案

## 回退策略
- **失败时的替代方案**：
  - 使用其他可访问的论文源
  - 直接从场景索引提取信息
- **降级路径**：
  - 从全文降级到摘要
  - 从实时降级到缓存
