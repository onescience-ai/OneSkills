# OneScience知识资源应用规则

## 适用范围

面向OneScience知识资源的应用规则，定义workflow-planning类型知识的参数契约如何传递给executor、质量门禁如何在执行过程中强制检查、知识定义与实际执行不一致时的处理流程。适用于需要确保知识资源正确应用到执行流程的编排场景，保证执行流程与知识定义的一致性和可追溯性。当知识定义与实际执行存在偏离时，提供偏离记录和处理流程。

## 输入

**必要输入**：
- 知识资源定义（knowledge.md中的参数契约和质量门禁）
- 执行器工作流定义（executor实际执行的步骤）
- 执行结果数据

**可选输入**：
- 偏离申请
- 审批流程配置
- 历史执行记录

**数据要求**：
- 知识资源定义完整，包含参数契约和质量门禁
- 执行器工作流定义明确，步骤清晰
- 执行结果数据可验证

## 输出

**主要输出**：
- 知识资源应用规则文档
- 参数契约传递验证结果
- 质量门禁检查结果
- 偏离记录和处理结果

**验证标准**：
- 参数契约传递完整，无遗漏
- 质量门禁检查正确，无冲突
- 偏离记录完整，处理合理

## 流程节点

### Step 1：参数契约传递验证
- **操作**：验证知识资源中的参数契约是否正确传递给executor
- **参数**：知识定义中的参数契约，执行器输入参数
- **工具**：参数契约验证器
- **质量门禁**：参数契约传递完整，无遗漏

### Step 2：质量门禁强制检查
- **操作**：在执行过程中强制检查知识资源中的质量门禁
- **参数**：质量门禁定义，执行结果数据
- **工具**：质量门禁检查器
- **质量门禁**：质量门禁检查正确，无冲突

### Step 3：偏离检测与记录
- **操作**：检测知识定义与实际执行的偏离并记录
- **参数**：知识定义，实际执行结果
- **工具**：偏离检测器
- **质量门禁**：偏离检测完整，记录准确

### Step 4：偏离处理与审批
- **操作**：处理检测到的偏离，必要时启动审批流程
- **参数**：偏离记录，审批规则
- **工具**：偏离处理器
- **质量门禁**：偏离处理合理，审批完整

### Step 5：应用规则文档生成
- **操作**：生成完整的知识资源应用规则文档
- **参数**：验证结果，检查结果，偏离记录
- **工具**：文档生成器
- **质量门禁**：文档完整，规则清晰

## 边界与分流

**异常处理**：
- 参数契约传递遗漏 → 重新传递参数，标记PARTIAL
- 质量门禁检查失败 → 标记BLOCKED，等待人工干预
- 偏离检测不完整 → 重新检测，补充遗漏偏离
- 偏离处理超时 → 升级至更高级别处理

**降级策略**：
- 无法完成完整检查时 → 执行简化检查，仅验证关键参数
- 审批流程不可用时 → 使用默认处理规则，但需记录偏离
- 质量门禁无法检查时 → 标记BLOCKED，等待环境恢复

**分支条件**：
- 参数契约传递完整 → 继续质量门禁检查
- 参数契约传递遗漏 → 重新传递参数
- 质量门禁检查通过 → 继续偏离检测
- 质量门禁检查失败 → 标记BLOCKED

## 质量检查

**验证点**：
1. 参数契约传递：所有参数正确传递，无遗漏
2. 质量门禁检查：所有门禁正确检查，无冲突
3. 偏离检测：所有偏离检测完整，记录准确
4. 偏离处理：偏离处理合理，审批完整
5. 文档完整性：所有规则文档化，清晰可读

**阈值**：
- 参数契约传递完整性：100%
- 质量门禁检查率：100%
- 偏离检测完整性：100%
- 偏离处理及时性：≤24小时
- 文档完整性：100%

**失败处理**：
- 参数契约传递失败 → 标记PARTIAL，重新传递
- 质量门禁检查失败 → 标记BLOCKED，等待人工干预
- 偏离检测不完整 → 重新检测，补充遗漏
- 偏离处理超时 → 升级处理

## 回退策略

**替代方案**：
1. 使用默认参数契约（如可用）
2. 采用简化检查（仅验证关键参数）
3. 降级为人工检查（复杂场景）
4. 使用历史成功案例作为参考

**回退触发条件**：
- 知识资源定义不完整
- 执行器工作流定义不明确
- 检查工具不可用
- 审批流程不可用
