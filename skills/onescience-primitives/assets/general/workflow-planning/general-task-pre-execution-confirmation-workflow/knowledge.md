# 任务执行前预确认流程

## 适用范围

**触发条件**：
- 任务需要用户输入必需数据（如传感器观测、目标区域时段）才能执行
- 任务涉及目标范围、数据口径、成本或验收标准的关键取舍需先确认
- 复杂任务执行前需验证数据可用性、方法选择合理性及资源估算

**适用场景**：
- 遥感数据处理任务需要指定传感器类型、时间范围和区域
- 科学计算任务需要确认输入数据格式和参数设置
- 多步骤工作流需要用户确认关键决策点
- 任何涉及不可逆操作或高成本执行的任务

**不适用场景**：
- 简单、无需用户输入的自动化任务
- 已明确所有输入参数和执行路径的标准化流程
- 实时响应型任务（如流处理）

## 输入

**必需输入**：
- 任务描述和目标
- 用户提供的初始约束和需求
- 可用数据资源清单

**预处理要求**：
- 解析任务描述，识别关键参数和缺失信息
- 评估数据可用性，标记缺失或不确定的数据源
- 初步方法选择，提供备选方案

## 输出

**输出产物**：
- 预确认报告（task_report.md），包含：
  - 任务理解总结
  - 数据可用性检查结果
  - 方法选择理由
  - 输入输出契约定义
  - 验证设计
  - 时间与资源估算
  - 质量门禁标准
  - 主要风险识别
  - 失败分支和替代方案
  - 缺失信息列表
  - 需要用户确认的事项

**验证标准**：
- 报告包含所有必需章节
- 缺失信息明确标注
- 关键取舍选项清晰列出
- 用户确认机制可追溯

## 流程节点

### Step 1：任务理解解析
- **操作**：分析任务描述，提取目标、约束和关键参数
- **参数**：任务描述文本、用户约束列表
- **工具**：自然语言处理、需求分析
- **质量门禁**：任务理解准确性 ≥ 90%，关键参数识别完整

### Step 2：数据可用性检查
- **操作**：评估所需数据的可用性、格式和质量
- **参数**：数据源清单、数据格式要求
- **工具**：数据探查、格式验证
- **质量门禁**：数据可用性评估完成，缺失数据标记清晰

### Step 3：方法选择与备选方案
- **操作**：基于数据可用性和任务目标选择执行方法
- **参数**：候选方法列表、选择标准
- **工具**：方法评估、成本效益分析
- **质量门禁**：至少提供2种备选方法，选择理由明确

### Step 4：输入输出契约定义
- **操作**：定义每个步骤的输入输出格式和验证标准
- **参数**：数据格式规范、验证规则
- **工具**：契约设计、 schema 定义
- **质量门禁**：契约覆盖所有关键接口，验证规则可执行

### Step 5：验证设计与质量门禁
- **操作**：设计验证点和质量检查标准
- **参数**：验证指标、阈值设定
- **工具**：质量规划、验证框架
- **质量门禁**：验证点覆盖关键风险，阈值合理可测量

### Step 6：资源估算与风险评估
- **操作**：估算时间、计算资源和人力需求，识别主要风险
- **参数**：资源历史数据、风险清单
- **工具**：估算模型、风险矩阵
- **质量门禁**：估算误差 ≤ 20%，风险识别覆盖率 ≥ 80%

### Step 7：预确认报告生成与用户确认
- **操作**：生成结构化报告，提交用户确认
- **参数**：报告模板、确认机制
- **工具**：报告生成、用户界面
- **质量门禁**：报告格式规范，用户确认记录可追溯

## 边界与分流

**关键前提不成立时的改道方案**：

1. **任务理解不完整** → 转向需求澄清子流程，与用户交互确认任务目标
2. **数据完全不可用** → 转向数据获取或替代数据源探索流程
3. **方法选择无可行方案** → 转向任务重新定义或范围调整流程
4. **资源估算严重超限** → 转向任务分解或优先级重排流程
5. **风险评估显示高风险** → 转向风险缓解计划制定流程

## 质量检查

**验证点**：
1. 预确认报告完整性检查（所有必需章节存在）
2. 缺失信息标注准确性（用户可快速识别需要提供的信息）
3. 关键取舍选项清晰度（用户能明确做出选择）
4. 用户确认记录可追溯性（确认时间、内容、决策可查询）

**阈值**：
- 报告完整性：100%
- 缺失信息标注率：100%
- 用户确认响应时间：≤ 24小时

**失败处理**：
- 报告不完整 → 重新生成缺失章节
- 用户未确认 → 任务保持阻塞状态，定期提醒
- 确认内容模糊 → 请求用户澄清具体决策

## 回退策略

**失败时的替代方案**：
1. **预确认流程本身失败** → 降级为简化确认（仅确认关键参数）
2. **用户长时间未响应** → 发送提醒，设置超时机制
3. **确认内容相互矛盾** → 请求用户统一决策，提供冲突分析
