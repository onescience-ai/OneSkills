# CLI 非交互执行与故障分类

## 适用范围
本卡适用于命令行接口（CLI）非交互执行场景下的故障分类、错误诊断和退出码分析。当 CLI 工具在自动化脚本、CI/CD 管道或远程执行环境中运行时，需要系统性地识别和分类执行错误，以支持故障恢复和配置修正。

## 输入
- CLI 命令执行日志（stdout/stderr）
- 退出码（exit code）
- 执行环境信息（操作系统、shell 版本、依赖版本）
- 命令参数和配置

## 输出
- 错误分类标签（如：成功、逻辑错误、命名异常、其他错误）
- 诊断报告（包含错误原因、影响范围、修复建议）
- 故障恢复策略

## 流程节点
1. **执行监控** → 捕获 CLI 命令的退出码和输出流
2. **错误识别** → 根据退出码和输出内容识别错误类型
3. **分类标注** → 将错误映射到预定义的分类标签
4. **根因分析** → 分析错误产生的根本原因
5. **恢复策略** → 制定故障恢复和配置修正方案

## 边界与分流
- **单错误 vs 多错误**：单错误提示可能隐藏逻辑错误，多错误输出可能包含额外标签
- **首次错误 vs 专家路径**：首次执行错误标签与专家修复路径标签可能不一致
- **退出码语义**：不同操作系统和 shell 的退出码语义可能不同
- **环境依赖**：错误可能由环境配置问题而非代码逻辑问题引起

## 质量检查点
- 退出码解析准确性验证
- 错误分类标签一致性检查
- 诊断报告完整性验证
- 恢复策略可行性评估

## 回退策略
- 当错误分类不明确时，使用通用错误标签
- 当退出码无法解析时，记录原始退出码并标记为未知错误
- 当环境信息缺失时，仅基于命令输出进行诊断
