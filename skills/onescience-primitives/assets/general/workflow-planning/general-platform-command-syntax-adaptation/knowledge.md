# 跨平台命令语法适配规范

## 适用范围

**触发条件**：
- orchestrator需要在不同操作系统环境下执行shell命令
- 任务可能在Windows、Linux或macOS上运行
- 需要确保命令语法的跨平台兼容性

**适用场景**：
- 科学计算任务在混合环境中执行
- 工作流步骤需要调用系统命令
- 脚本执行需要适配不同shell环境

**不适用场景**：
- 单一平台固定环境（无需适配）
- 容器化环境（已隔离平台差异）
- 高级语言调用（不依赖shell语法）

## 输入

| 输入项 | 格式 | 必填 | 说明 |
|--------|------|------|------|
| {COMMAND} | 字符串 | 是 | 需要执行的命令 |
| {PLATFORM} | 字符串 | 否 | 目标平台（auto/windows/linux） |
| {SHELL_TYPE} | 字符串 | 否 | shell类型（powershell/bash/zsh） |

## 输出

| 输出项 | 格式 | 说明 |
|--------|------|------|
| adapted_command | 字符串 | 适配后的命令 |
| platform_info | JSON | 检测到的平台信息 |
| execution_result | JSON | 命令执行结果 |

## 平台检测策略

### 检测方法
1. **环境变量检测**：检查 `$PSVersionTable`（PowerShell）或 `$BASH_VERSION`（bash）
2. **系统命令检测**：尝试执行 `uname -s`（Linux/macOS）或 `ver`（Windows）
3. **Python检测**：使用 `python -c "import platform; print(platform.system())"`

### 检测时机
- orchestrator启动时执行一次平台检测
- 结果缓存在 `task_state.platform_info` 中
- 后续命令执行直接使用缓存信息

## 命令差异对照表

### 文件操作命令

| 操作 | Linux bash | Windows PowerShell | 适配规则 |
|------|------------|-------------------|----------|
| 列出文件 | `ls -la` | `Get-ChildItem -Force` | 根据平台选择 |
| 创建目录 | `mkdir -p dir` | `New-Item -ItemType Directory -Path dir` | 根据平台选择 |
| 删除文件 | `rm file` | `Remove-Item -Path file` | 根据平台选择 |
| 复制文件 | `cp src dst` | `Copy-Item -Path src -Destination dst` | 根据平台选择 |
| 查找文件 | `find . -name "*.py"` | `Get-ChildItem -Recurse -Filter "*.py"` | 根据平台选择 |

### 流程控制命令

| 操作 | Linux bash | Windows PowerShell | 适配规则 |
|------|------------|-------------------|----------|
| 条件执行 | `cmd1 && cmd2` | `cmd1; if ($?) { cmd2 }` | 语法转换 |
| 或者执行 | `cmd1 \|\| cmd2` | `cmd1; if (-not $?) { cmd2 }` | 语法转换 |
| 重定向错误 | `cmd 2>&1` | `cmd 2>&1` | 语法相同 |
| 管道 | `cmd1 \| cmd2` | `cmd1 \| cmd2` | 语法相同 |

### 路径处理

| 操作 | Linux bash | Windows PowerShell | 适配规则 |
|------|------------|-------------------|----------|
| 路径分隔符 | `/` | `\` 或 `/` | 自动转换 |
| 当前目录 | `./` | `.\` 或 `./` | 自动转换 |
| 家目录 | `~/` | `$env:USERPROFILE\` | 变量替换 |

## Orchestrator命令生成规则

### 生成流程
1. **接收命令需求**：从步骤定义中提取命令需求
2. **平台检测**：获取当前平台信息
3. **语法适配**：根据平台选择对应的命令语法
4. **安全检查**：验证命令不会破坏系统
5. **执行命令**：使用适配后的命令执行

### 适配策略
- **首选跨平台命令**：优先使用两种平台都支持的命令（如Python、git）
- **平台特定命令**：当必须使用平台特定命令时，根据平台选择
- **回退机制**：当适配失败时，尝试替代方案

### 错误处理
- **命令不存在**：记录错误，尝试替代命令
- **语法错误**：检查平台差异，重新适配
- **权限不足**：提示用户权限问题

## 边界与分流

### 异常处理
- **平台检测失败**：默认使用Linux bash语法
- **命令适配失败**：尝试替代命令或跳过该步骤
- **执行超时**：终止命令并记录错误
- **权限不足**：提示用户提升权限

### 降级策略
- **无法适配时**：使用最简单的跨平台命令
- **命令不存在**：跳过该步骤并记录
- **执行失败**：记录错误并继续后续步骤

## 质量检查

1. **平台检测准确性**：验证检测结果与实际平台一致
2. **命令适配正确性**：验证适配后的命令语法正确
3. **执行成功率**：统计命令执行成功率
4. **错误处理完整性**：验证错误处理机制完善

## 回退策略

1. **平台检测失败**：使用默认平台（Linux）
2. **命令适配失败**：使用Python脚本替代
3. **执行失败**：记录错误并继续
4. **权限不足**：提示用户手动执行
