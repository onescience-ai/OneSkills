# CLI执行故障分类与诊断

## 适用范围
适用于命令行界面（CLI）工具的非交互执行场景，涵盖从简单脚本到复杂科学计算流水线的错误诊断。问题类是：当CLI工具返回非零退出码或产生异常输出时，如何系统性地分类故障、定位原因并实施恢复策略。具体实例包括但不限于：Python脚本执行失败、Shell脚本错误、科学计算工具（如GROMACS、LAMMPS）作业异常。

## 输入
- CLI命令及其参数
- 执行环境信息（操作系统、Shell类型、依赖版本）
- 标准输出（stdout）和标准错误（stderr）日志
- 退出码（exit code）
- 可选的配置文件、输入数据路径

## 输出
- 故障分类结果（如：参数错误、依赖缺失、资源超限、权限问题、沙箱限制）
- 根因分析报告
- 恢复建议（如：修正参数、安装依赖、调整资源配额、修改权限）
- 诊断证据链（包括日志片段、退出码映射）

## 流程节点
1. **退出码捕获** → 捕获CLI进程的退出码（$?）
2. **标准错误解析** → 解析stderr输出，提取错误关键词和堆栈跟踪
3. **故障分类** → 根据退出码和错误信息映射到故障类别
4. **根因定位** → 结合环境信息和配置参数定位具体原因
5. **恢复策略生成** → 为每类故障提供标准化的修复步骤
6. **验证执行** → 执行修复后重新运行CLI，验证故障是否解决

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码 0 | 成功 | [D1] | 命令执行成功 |
| 退出码 1-255 | 错误 | [D1] | 非零退出码表示错误或异常条件 |
| 特殊退出码 | 126-130 | [D1] | 126：权限问题；127：命令未找到；128+N：信号终止 |
| stderr输出 | 非空 | 通用实践 | 通常包含错误详情和堆栈跟踪 |
| 超时退出 | 124（timeout命令） | 通用实践 | 命令执行超时 |

### 校准数值
无具体体系校准数值。以上数值来自Unix/Linux通用规范，供量级校准；其他体系需以自身证据重新锚定。

## 边界与分流
- **退出码无法捕获**：检查Shell配置、进程信号处理，转向日志分析
- **标准错误被重定向**：确保stderr未被重定向到/dev/null，检查文件描述符
- **沙箱环境限制**：确认沙箱内可用资源（CPU、内存、磁盘）、网络访问权限
- **依赖缺失**：检查Python环境、系统库版本，使用包管理器安装
- **权限问题**：检查文件/目录权限、用户组权限、sudo配置

## 质量检查
- 验证退出码映射表的完整性（覆盖常见退出码）
- 检查错误关键词库的更新（新工具可能产生新的错误模式）
- 确认恢复策略的可执行性（依赖安装命令、权限修改步骤）
- 通过成功、非零退出和超时用例验证诊断流程

## 回退策略
- **完全无法诊断**：收集完整日志（stdout、stderr、环境信息）并人工分析
- **退出码映射失败**：使用通用错误类别（参数错误、资源错误、权限错误）
- **恢复策略无效**：提供通用调试步骤（检查日志、验证输入、简化命令）
