# 离线科学计算资源获取策略

## 适用范围
本卡服务的问题类是如何在网络受限或完全离线的科学计算环境中获取必要的外部资源，包括Python包、模型权重、数据集、代码仓库等。适用于需要访问GitHub、PyPI、Conda Forge、Hugging Face等外部服务的各类科学计算任务，尤其针对企业内网、安全隔离环境、高延迟网络等场景。

## 输入
- 目标计算环境的网络限制描述（代理、防火墙、完全离线）
- 所需资源清单（Python包、模型文件、数据集、代码仓库）
- 资源来源信息（官方URL、版本要求、文件格式）
- 传输约束（文件大小、传输介质、安全要求）

## 输出
- 离线资源包（wheel文件、conda包、模型文件、数据集压缩包）
- 配置脚本（代理设置、镜像源配置、环境变量）
- 安装指南（离线安装步骤、依赖关系说明）
- 验证方法（网络测试、资源完整性检查）

## 流程节点
1. **需求分析** → 确定所需资源和网络限制级别
2. **资源预下载** → 在有网络的环境中下载所需资源
3. **离线打包** → 组织资源文件，创建离线安装包
4. **传输部署** → 通过USB、内部网络等方式传输到目标环境
5. **环境配置** → 配置代理、镜像源、离线安装路径
6. **安装验证** → 执行离线安装，验证资源可用性

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 代理配置方式 | 环境变量/命令行参数/配置文件 | [D1] | http_proxy, https_proxy, --proxy参数 |
| 镜像源类型 | PyPI镜像/Conda镜像/GitHub镜像 | [D1] | 清华源、阿里云源、官方镜像 |
| 离线包格式 | wheel/conda-pack/压缩包 | [D1] | wheel用于pip，conda-pack用于conda |
| 资源完整性校验 | MD5/SHA256 | [D1] | 确保传输过程无损坏 |
| 传输介质 | USB/内部网络/光盘 | [D1] | 根据安全要求选择 |

### 校准数值（以下数值来自常见科学计算环境，供量级校准；其他环境需以自身证据重新锚定）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 典型Python包大小 | 1-100MB | [D1] | 单个包的大小范围 |
| 模型权重文件 | 100MB-10GB | [D1] | 深度学习模型常见规模 |
| 数据集大小 | 1GB-1TB | [D1] | 科学数据集常见范围 |
| 离线安装时间 | 5-60分钟 | [D1] | 取决于资源数量和磁盘速度 |

## 边界与分流
- **完全离线环境**：使用预下载的离线包，通过物理介质传输
- **代理认证失败**：检查代理配置，尝试不同认证方式（Basic/Digest/NTLM）
- **镜像源不可用**：切换其他镜像源，或使用官方源（需网络）
- **资源版本冲突**：使用约束文件锁定版本，或创建独立环境
- **传输安全限制**：使用加密传输，或经过安全审查的介质

## 质量检查
- 网络连接测试（ping/traceroute/curl）
- 代理配置验证（环境变量设置、配置文件语法）
- 离线包完整性检查（文件校验、包列表对比）
- 安装后功能验证（导入测试、基本功能测试）

## 回退策略
- 代理不可用时，尝试直接连接或更换代理
- 镜像源不可用时，使用其他镜像或官方源
- 离线包损坏时，重新下载或从备份恢复
- 传输失败时，检查介质完整性，更换传输方式

## 资源召回建议
当遇到以下情况时召回本卡片：
- 在网络受限环境中部署科学计算环境
- 配置Python包镜像源或代理服务器
- 创建离线安装包用于空气隔离环境
- 管理科学计算资源的版本和依赖
- 解决网络连接失败导致的安装错误
