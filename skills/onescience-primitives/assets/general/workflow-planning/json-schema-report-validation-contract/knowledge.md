# JSON Schema报告交付契约

## 适用范围

**触发条件**：
- 需要定义JSON格式报告的结构规范
- 需要验证JSON报告是否符合契约要求
- 需要处理动态引用和注释依赖的复杂Schema
- 需要确保报告交付的格式一致性

**适用场景**：
- 科学计算报告的结构化交付
- API响应格式的验证和标准化
- 数据交换格式的契约定义
- 配置文件格式的验证
- 文档生成系统的格式约束

**不适用场景**：
- 非JSON格式的报告（如XML、CSV）
- 简单键值对验证（无需复杂Schema）
- 实时流数据验证（需要流式处理）

## 输入

- JSON Schema定义文件
- 待验证的JSON报告实例
- 验证规则和约束条件
- 历史报告样本（用于模式学习）
- 领域特定的验证规则

## 输出

- 验证结果（通过/失败）
- 详细错误信息（字段路径、错误类型、期望值）
- Schema优化建议
- 验证性能统计

## 流程节点

### Step 1：Schema解析与规范化
- **操作**：解析JSON Schema，处理URI引用和资源扁平化
- **参数**：Schema版本（Draft 2020-12）、引用解析策略
- **工具**：Schema解析器、URI解析器
- **质量门禁**：完整解析所有引用、处理嵌套资源

### Step 2：验证规则提取
- **操作**：从Schema中提取验证规则
- **参数**：关键字类型、依赖关系、验证顺序
- **工具**：关键字提取器、依赖分析器
- **质量门禁**：完整提取所有验证规则、正确处理关键字顺序

### Step 3：实例验证执行
- **操作**：对JSON实例应用验证规则
- **参数**：验证模式（严格/宽松）、错误处理策略
- **工具**：验证引擎、规则执行器
- **质量门禁**：正确执行所有验证规则、处理边界条件

### Step 4：错误诊断与报告
- **操作**：分析验证失败原因，生成诊断报告
- **参数**：错误分类、修复建议、性能统计
- **工具**：错误分析器、报告生成器
- **质量门禁**：准确诊断错误原因、提供可操作的修复建议

### Step 5：Schema优化建议
- **操作**：分析Schema复杂度，提供优化建议
- **参数**：性能指标、可维护性指标
- **工具**：复杂度分析器、优化建议器
- **质量门禁**：识别性能瓶颈、提供切实可行的优化方案

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| Schema版本 | Draft 2020-12 | [1] | Modern JSON Schema最新版本 |
| 验证复杂性 | PSPACE-complete（动态引用） | [1] | 包含动态引用时的最坏情况复杂性 |
| 注释依赖关键字 | unevaluatedProperties, unevaluatedItems | [2] | 依赖验证注释的关键字 |
| 动态引用消除 | 指数级Schema膨胀 | [2] | 消除动态引用的代价 |
| 验证性能 | 10x加速（编译后） | [3] | Blaze编译器性能提升 |
| 静态引用复杂性 | P（多项式时间） | [1] | 仅静态引用时的复杂性 |
| 数据复杂性 | P（固定Schema） | [1] | 固定Schema时的复杂性 |

## 边界与分流

### Schema版本边界
- **Draft 2020-12**：支持动态引用和注释依赖
- **Draft 2019-09**：支持$recursiveRef和$recursiveRef
- **Draft-06及之前**：仅支持静态引用

### 验证复杂性边界
- **静态引用**：多项式时间可解
- **动态引用**：PSPACE完全，最坏情况指数级
- **注释依赖**：单独处理时保持多项式复杂性

### 错误处理边界
- **严格模式**：任何验证失败都停止验证
- **宽松模式**：收集所有错误后报告
- **自定义模式**：根据错误类型决定是否继续

## 质量检查

- **Schema解析成功率**：100%的合法Schema能被正确解析
- **验证准确率**：≥99%的验证结果与标准一致
- **错误诊断准确率**：≥95%的错误能被正确分类
- **性能基准**：验证时间与Schema大小和实例大小的关系
- **兼容性**：支持所有标准JSON Schema关键字

## 回退策略

- **Schema过于复杂**：简化Schema或分阶段验证
- **验证性能不足**：使用编译优化或缓存机制
- **动态引用问题**：转换为静态引用或简化Schema结构
- **注释依赖问题**：重写Schema避免注释依赖
