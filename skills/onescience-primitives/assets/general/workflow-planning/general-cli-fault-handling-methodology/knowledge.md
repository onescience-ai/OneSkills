# CLI 非交互执行与故障分类方法论

## 适用范围
面向命令行工具在自动化环境中的非交互执行场景，提供故障分类、诊断和恢复的通用方法。适用于CI/CD流水线、批量任务调度、科学计算工作流等需要无人值守运行的场景。不适用于交互式调试或图形界面应用。

## 输入
- CLI 工具及其参数配置
- 执行环境信息（操作系统、Shell 类型、资源限制）
- 预期输出格式和验证标准

## 输出
- 执行结果（成功/失败状态）
- 退出码分类和诊断信息
- 标准错误日志解析结果
- 故障恢复建议

## 流程节点
1. **参数预检** → 2. **环境验证** → 3. **执行监控** → 4. **退出码分类** → 5. **错误流解析** → 6. **故障诊断** → 7. **恢复策略**

### 详细步骤

**步骤1：参数预检**
- 操作：验证所有必要参数是否提供，参数格式是否正确
- 参数：命令行参数列表、参数模式定义
- 工具：参数解析库（argparse、click等）
- 质量门禁：参数验证失败时立即退出并返回退出码2

**步骤2：环境验证**
- 操作：检查执行环境是否满足工具要求
- 参数：依赖检查清单、权限要求
- 工具：环境检测脚本
- 质量门禁：环境不满足时返回退出码3

**步骤3：执行监控**
- 操作：启动进程并监控执行状态
- 参数：超时时间、资源限制
- 工具：进程管理库（subprocess、psutil）
- 质量门禁：超时返回退出码124，资源超限返回退出码137

**步骤4：退出码分类**
- 操作：根据退出码判断故障类别
- 参数：退出码映射表
- 质量门禁：使用标准退出码范围

**步骤5：错误流解析**
- 操作：解析标准错误输出，提取关键错误信息
- 参数：错误模式库
- 工具：正则表达式、日志解析器
- 质量门禁：错误信息完整性检查

**步骤6：故障诊断**
- 操作：基于退出码和错误信息进行故障定位
- 参数：故障诊断规则库
- 质量门禁：诊断结果置信度评估

**步骤7：恢复策略**
- 操作：根据故障类别选择恢复策略
- 参数：恢复策略配置
- 质量门禁：恢复操作幂等性验证

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码范围 | 0-255 | POSIX标准 | 0表示成功，非0表示失败 |
| 标准退出码 | 0,1,2,126,127,128+n,130,137 | Linux约定 | 通用故障分类基准 |
| 超时退出码 | 124 | timeout命令约定 | 表示执行超时 |
| 信号中断退出码 | 128+信号编号 | POSIX标准 | 表示被信号终止 |
| 标准错误流 | stderr (fd2) | POSIX标准 | 用于错误信息输出 |

### 校准数值
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 默认超时时间 | 300秒 | 工程实践 | 可根据任务复杂度调整 |
| 重试次数上限 | 3次 | 工程实践 | 指数退避策略 |
| 退避基数 | 2秒 | 工程实践 | 用于计算重试间隔 |
| 日志缓冲区大小 | 1MB | 工程实践 | 用于捕获错误输出 |

## 边界与分流
- **参数缺失**：返回退出码2，提示用户检查参数
- **环境不满足**：返回退出码3，提示安装缺失依赖
- **权限不足**：返回退出码126，提示权限配置
- **命令未找到**：返回退出码127，提示检查PATH
- **执行超时**：返回退出码124，建议增加超时时间或优化任务
- **资源耗尽**：返回退出码137，建议增加资源配额或优化内存使用
- **信号中断**：返回退出码130（SIGINT）或143（SIGTERM），建议实现优雅退出

## 质量检查
- 退出码必须符合POSIX标准约定
- 错误信息必须包含足够诊断上下文
- 重试策略必须实现指数退避
- 日志必须包含时间戳和执行上下文
- 超时处理必须支持优雅终止

## 回退策略
- 主执行通道失败时，尝试降级执行模式
- 标准错误流不可用时，使用标准输出作为备选
- 本地执行失败时，考虑远程执行通道
- 所有恢复策略失败时，记录完整诊断信息并告警
