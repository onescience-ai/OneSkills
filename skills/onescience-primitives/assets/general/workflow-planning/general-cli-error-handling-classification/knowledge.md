# CLI非交互执行与故障分类知识

## 适用范围
适用于CLI工具在非交互环境（如自动化流水线、批处理作业、远程执行）中的执行故障诊断与恢复。覆盖命令参数解析、认证失败、沙箱限制、超时处理、退出码判读和标准错误流分析。

## 输入
- CLI命令及参数
- 执行环境信息（操作系统、shell类型、用户权限）
- 预期输出格式和错误处理策略

## 输出
- 故障分类结果（参数错误、认证失败、沙箱限制、超时、运行时错误等）
- 退出码和标准错误流分析
- 恢复策略建议

## 流程节点
1. **命令参数验证** → 检查参数格式、数量、顺序是否正确
2. **认证状态检查** → 验证凭据、令牌、权限是否有效
3. **沙箱环境检测** → 确认执行环境是否受限制
4. **超时监控** → 设置合理的超时阈值并监控执行时间
5. **退出码分析** → 根据退出码分类故障类型
6. **标准错误解析** → 提取错误信息并映射到具体问题

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码0 | 成功 | 通用约定 | 命令执行成功 |
| 退出码1 | 通用错误 | 通用约定 | 命令执行失败 |
| 退出码2 | 参数错误 | 通用约定 | 命令参数使用错误 |
| 退出码126 | 权限问题 | POSIX标准 | 命令不可执行 |
| 退出码127 | 命令未找到 | POSIX标准 | 命令不存在 |
| 退出码128+n | 信号终止 | POSIX标准 | 命令被信号n终止 |
| 超时阈值 | 可配置 | 任务需求 | 根据任务复杂度设置 |

## 边界与分流
- **参数错误**：检查命令格式、参数顺序、必需参数是否缺失
- **认证失败**：验证凭据有效性、令牌是否过期、权限是否足够
- **沙箱限制**：确认文件系统访问权限、网络访问权限、资源限制
- **超时**：调整超时阈值、优化命令执行效率、考虑异步执行
- **运行时错误**：检查依赖项、环境变量、资源可用性

## 质量检查
- 验证退出码与实际错误是否匹配
- 检查标准错误流是否包含有用的诊断信息
- 确认恢复策略是否有效解决问题

## 回退策略
- 对于认证失败：尝试重新认证或使用备用凭据
- 对于沙箱限制：调整环境配置或使用替代执行方式
- 对于超时：优化命令或增加超时阈值
