# 远程HPC环境连接与预检执行

## 适用范围
面向需要在远程高性能计算（HPC）环境执行科学计算任务的场景，包括气候模拟、生物信息学分析、材料科学计算等。本卡提供建立可靠的SSH/SLURM连接并执行预检的方法，确保环境就绪性、连接稳定性和作业调度系统可用性。适用于任何需要通过SSH连接到远程集群并使用SLURM作业调度系统的任务。

## 输入
- 远程HPC集群的连接信息：主机名/IP地址、端口、用户名、认证方式（密码或SSH密钥）
- SLURM作业调度系统配置：分区（partition）、队列（queue）、资源限制（ GPUs、内存、时间）
- 本地执行环境：操作系统、SSH客户端版本、网络连通性
- 任务执行脚本或命令
- 环境变量和模块加载需求

## 输出
- 连接验证结果：成功/失败状态、连接延迟、超时设置
- 预检报告：环境就绪性检查结果（SSH连接、SLURM可用性、模块加载、文件系统访问）
- 配置建议：优化后的连接参数、超时重试策略、模块加载顺序
- 错误日志：连接失败原因、超时详情、SLURM错误代码

## 流程节点
1. **连接配置验证** → 2. **SSH连接测试** → 3. **SLURM系统检查** → 4. **模块加载验证** → 5. **环境一致性校验** → 6. **预检报告生成**

每步含：操作、参数、工具、质量门禁
- 连接配置验证：检查主机名、端口、用户名、认证方式；使用ssh命令或配置文件；确保配置完整且正确
- SSH连接测试：建立SSH连接，测试超时设置；使用ssh -v调试输出；确保连接成功且延迟可接受
- SLURM系统检查：验证SLURM守护进程运行、分区可用、资源限制；使用sinfo、squeue命令；确保SLURM系统响应正常
- 模块加载验证：测试所需模块的加载和卸载；使用module avail、module load；确保模块依赖满足
- 环境一致性校验：比较本地和远程环境的关键变量（Python版本、库版本、路径）；使用环境快照对比；确保环境差异在可接受范围内
- 预检报告生成：汇总所有检查结果，生成结构化报告；使用JSON或YAML格式；确保报告包含所有关键指标和建议

## 边界与分流
- **SSH连接超时**：若连接超时，首先检查网络连通性（ping测试），然后验证SSH配置（端口、防火墙），最后考虑使用代理或VPN
- **SLURM系统不可用**：若SLURM守护进程未运行，联系集群管理员；若分区不可用，尝试其他分区或调整资源请求
- **模块加载失败**：若模块不存在，检查模块路径（module avail）；若依赖冲突，使用环境容器（conda、singularity）隔离
- **环境差异过大**：若版本差异超过阈值，在本地使用容器模拟远程环境，或在远程重新安装依赖
- **认证失败**：检查SSH密钥权限（chmod 600）、主机密钥验证（~/.ssh/known_hosts）、用户名密码正确性

## 质量检查
- 连接成功率：应达到100%（排除网络故障）
- 预检完成时间：应在60秒内完成所有检查
- 模块加载成功率：应达到100%（排除模块不存在）
- 环境一致性得分：关键版本匹配率应≥95%
- 错误日志完整性：所有失败步骤必须记录详细错误信息

## 回退策略
- **SSH连接失败**：尝试使用其他SSH客户端（如Paramiko）、检查防火墙设置、联系网络管理员
- **SLURM系统故障**：使用本地模拟环境（如Singularity容器）进行测试，或联系集群支持团队
- **模块依赖冲突**：使用conda创建独立环境，或联系软件供应商获取兼容版本
- **网络延迟过高**：使用SSH压缩（-C选项）、优化数据传输批量大小、考虑使用边缘计算节点
