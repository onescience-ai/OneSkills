# 命令行非交互执行故障分类与诊断

## 适用范围

面向需要非交互执行命令行工具的场景，诊断进程退出状态、错误分类和故障恢复，确保CLI工具在自动化、批处理或远程执行环境中稳定运行并提供清晰的诊断信息。适用于各类命令行工具、脚本和自动化流水线，不限于特定领域或工具类型。

## 输入

- 命令行工具或脚本的执行环境
- 执行参数（命令、参数、环境变量）
- 执行上下文（交互式/非交互式、本地/远程、单次/批处理）
- 可选的超时设置和重试策略

## 输出

- 结构化的退出状态码（0-255）
- 错误分类信息（命令未找到、权限不足、执行失败等）
- 诊断证据（标准错误流、日志文件、资源使用情况）
- 故障恢复建议（重试、降级、终止）

## 流程节点

1. **命令执行** → 2. **退出状态收集** → 3. **错误分类** → 4. **诊断证据收集** → 5. **故障恢复决策**

### 步骤详解

**步骤1：命令执行**
- 操作：在指定环境中执行命令行工具
- 参数：命令路径、参数列表、环境变量、工作目录
- 工具：shell解释器、进程管理器
- 质量门禁：命令启动成功，无语法错误

**步骤2：退出状态收集**
- 操作：收集进程退出状态码和信号信息
- 参数：退出状态码（0-255）、信号编号
- 工具：wait()系统调用、$?特殊参数
- 质量门禁：退出状态码在有效范围内，信号信息完整

**步骤3：错误分类**
- 操作：根据退出状态码和错误信息进行分类
- 参数：退出状态码、错误消息、资源使用情况
- 工具：错误分类规则、模式匹配
- 质量门禁：错误分类准确，覆盖主要故障类型

**步骤4：诊断证据收集**
- 操作：收集标准错误流、日志文件和资源使用信息
- 参数：stderr输出、日志路径、资源监控数据
- 工具：重定向、日志记录、性能监控
- 质量门禁：诊断证据完整，可追溯

**步骤5：故障恢复决策**
- 操作：根据错误分类和诊断证据决定恢复策略
- 参数：错误类型、重试次数、超时设置、降级方案
- 工具：重试逻辑、超时控制、降级执行
- 质量门禁：恢复策略合理，避免无限循环

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出状态码范围 | 0-255 | [D1] | 进程退出状态码的有效范围 |
| 成功状态码 | 0 | [D1] | 命令执行成功返回0 |
| 命令未找到 | 127 | [D1] | shell无法找到指定命令 |
| 权限不足 | 126 | [D1] | 命令找到但不可执行 |
| 执行失败范围 | 1-125 | [D1] | 命令执行过程中的各种失败 |
| 信号终止 | >128 | [D1] | 命令因接收信号而终止 |

### 校准数值（体系专属值）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 通用超时建议 | 300秒 | [D1] | 非交互式命令的默认超时建议 |
| 重试次数建议 | 3次 | [D1] | 临时性故障的重试次数建议 |
| 错误日志保留 | 7天 | [D1] | 诊断日志的保留期限建议 |

## 边界与分流

### 前提不成立时的分流

1. **退出状态码超出范围（>255）**：
   - 分流目标：进程管理异常处理方案族
   - 处理：记录异常状态码，检查进程管理机制

2. **非标准退出状态码（1-125但含义不明）**：
   - 分流目标：工具特定错误处理方案族
   - 处理：查阅工具文档，分析标准错误输出

3. **信号终止但无明确信号信息**：
   - 分流目标：系统资源监控方案族
   - 处理：检查系统日志，监控资源使用情况

### 异常处理

- **超时故障**：执行超时控制，记录超时前状态
- **资源耗尽**：监控内存、CPU使用，实施资源限制
- **权限问题**：检查文件权限、用户权限、环境变量

## 质量检查

### 验证点

1. **退出状态码验证**：确保状态码在0-255范围内
2. **错误分类验证**：确认错误分类与实际故障匹配
3. **诊断证据完整性**：检查stderr输出和日志记录
4. **恢复策略有效性**：验证重试和降级策略的执行效果

### 阈值

- 退出状态码有效性：100%
- 错误分类准确率：>90%
- 诊断证据完整率：>95%
- 恢复策略成功率：>80%

### 失败处理

- 退出状态码无效：记录异常，终止执行
- 错误分类失败：降级为通用错误处理
- 诊断证据缺失：启动最小化诊断收集
- 恢复策略失败：执行最终终止策略

## 回退策略

1. **降级执行**：使用简化参数或默认配置重试
2. **替代工具**：调用功能相似的替代命令行工具
3. **手动干预**：记录详细诊断信息，等待人工处理
4. **终止执行**：在关键故障时安全终止，保留现场状态
