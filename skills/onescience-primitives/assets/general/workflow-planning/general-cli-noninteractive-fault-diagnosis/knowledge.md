# CLI 非交互执行故障诊断

## 适用范围
面向命令行工具的非交互执行场景，诊断和处理 CLI 进程的启动失败、超时、退出码异常和标准错误输出。适用于自动化脚本、CI/CD流水线、远程SSH 执行、SLURM 作业提交等无法人工干预的环境。

## 输入
- CLI 命令及其参数
- 执行环境信息（操作系统、shell类型、工作目录）
- 预期退出码和输出格式

## 输出
- 故障分类（参数错误/认证错误/沙箱错误/超时/运行时错误）
- 诊断日志（stdout/stderr 内容）
- 修复建议或恢复策略

## 流程节点
1. **命令构建** → 构造非交互执行命令，确保参数正确转义
2. **进程启动** → 使用 subprocess/ssh/sbatch 启动 CLI 进程
3. **超时监控** → 设置合理超时时间，防止无限等待
4. **退出码检查** → 读取进程退出码，分类故障类型
5. **输出捕获** → 捕获 stdout 和 stderr 用于诊断
6. **故障分类** → 根据退出码和错误信息确定故障类别
7. **恢复策略** → 根据故障类别选择修复或重试策略

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| exit_on_error | True/False | [D1] | 控制解析错误时是否自动退出 |
| stderr 重定向 | 必须捕获 | [D1] | 错误信息写入 stderr |
| 超时设置 | 场景相关 | 通用 | 防止进程无限挂起 |

### 校准数值
以下数值来自 Python argparse 实现，供量级校准：
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 解析错误退出码 | 2 | [D1] | argparse 无效参数时的默认退出码 |
| stderr 输出 | error message | [D1] | 错误信息标准输出位置 |

## 边界与分流
- **参数解析错误**：退出码 2，检查命令行参数格式
- **类型转换错误**：参数类型不匹配，修正 type 参数
- **选择验证错误**：choices 不满足，检查允许值列表
- **认证失败**：检查凭据、token、环境变量
- **沙箱限制**：检查权限、资源配额、网络访问
- **超时**：增加超时时间或优化命令性能

## 质量检查
- 验证退出码与故障类型匹配
- 确认 stderr 输出包含有效错误信息
- 检查日志完整性

## 回退策略
- 参数错误：使用 argparse 的 exit_on_error=False 手动处理异常
- 超时：实现重试机制或增加超时阈值
- 认证失败：刷新 token 或重新认证
