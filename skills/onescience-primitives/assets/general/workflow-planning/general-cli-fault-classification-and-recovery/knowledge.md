# CLI 故障分类与恢复策略

## 适用范围
本卡片为命令行界面（CLI）工具提供非交互执行环境下的故障分类、诊断与恢复策略。适用于自动化流水线、批处理作业、CI/CD 集成等场景，其中 CLI 工具需要在没有人工干预的情况下稳定运行。覆盖超时、退出码异常、沙箱隔离、认证失败等常见故障类型。不适用于交互式 CLI 会话或图形界面应用。

## 输入
- CLI 工具执行日志（stdout/stderr）
- 进程退出码
- 执行环境配置（沙箱参数、认证凭证、超时设置）
- 系统资源使用情况（CPU、内存、磁盘空间）

## 输出
- 故障分类结果（故障类型、严重等级、影响范围）
- 诊断报告（根因分析、相关日志片段、环境状态）
- 恢复建议（自动重试策略、配置调整、替代方案）
- 预防措施（监控指标、告警阈值、最佳实践）

## 流程节点
1. **故障检测** → 监控进程退出码、执行时间、资源使用
2. **故障分类** → 根据退出码、错误信息、环境状态进行分类
3. **根因分析** → 分析日志、配置、依赖关系确定根本原因
4. **恢复策略** → 选择自动重试、配置调整或人工干预
5. **预防优化** → 更新监控规则、调整配置、改进工具设计

## 关键参数

### 通用判据（方法层）
| 参数 | 判据 | 来源 | 说明 |
|------|------|------|------|
| 故障分类维度 | 退出码、错误信息、环境状态 | [论文1] | 多维度综合分类，提高准确性 |
| 恢复策略选择 | 自动重试、配置调整、人工干预 | 通用实践 | 根据故障严重程度和可恢复性选择 |
| 监控指标 | 退出码、执行时间、资源使用 | 通用实践 | 实时监控，及时发现故障 |
| 沙箱隔离级别 | 容器/虚拟环境 | [论文1] | 根据安全需求选择隔离级别 |

### 校准数值（体系专属值）
以下数值来自特定系统（SAP HANA），供量级校准；其他系统需以自身证据重新锚定。
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 超时阈值 | 30-300秒 | [论文2] | 根据任务复杂度动态调整，避免过早超时 |
| 测试失败率 | 49%-70% | [论文2] | 重复测试执行下的超时相关失败率 |
| 超时优化效果 | 减少80%超时相关失败 | [论文2] | 自动调整超时值的效果 |

## 边界与分流
- **超时故障**：检查网络连接、资源竞争、任务复杂度，调整超时设置或优化任务
- **退出码异常**：区分可恢复错误（重试）和致命错误（人工干预）
- **沙箱失败**：检查权限、资源限制、配置错误，调整沙箱参数
- **认证失败**：验证凭证、检查权限、刷新令牌
- **资源不足**：监控资源使用，调整资源分配或优化任务

## 质量检查
- 故误分类准确率 ≥ 90%
- 恢复成功率 ≥ 80%
- 平均恢复时间 ≤ 5分钟
- 误报率 ≤ 5%

## 回退策略
1. **自动重试失败**：记录详细日志，发送告警，等待人工干预
2. **配置调整无效**：回滚到已知稳定配置，逐步调试
3. **沙箱环境异常**：切换备用环境，验证核心功能
4. **认证持续失败**：临时禁用认证，使用降级模式（仅限测试环境）
