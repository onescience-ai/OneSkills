# JSON Schema 报告交付契约验证框架

## 适用范围

适用于无模式数据环境中 JSON 或类 JSON 输出的结构化验证场景，包括但不限于：自动化流水线中的报告交付物校验、API 响应契约验证、数据集成管道中的 Schema 一致性检查、以及任何需要确保 JSON 输出符合预定义结构要求的应用。本卡提供系统化的多维度评估方法论，不绑定特定验证库或实现。

## 输入

- **待验证 JSON 数据**：需要验证的 JSON 文档或数据流
- **参考 Schema**：预定义的 JSON Schema 或结构规范（可选，用于对照验证）
- **评估上下文**：验证目的、质量要求、容忍度阈值

## 输出

- **验证结果报告**：包含六个维度的评分及总体质量得分
- **维度级诊断**：各维度的具体问题定位
- **改进建议**：基于评估结果的 Schema 优化方向

## 流程节点

1. **数据准备** → 收集待验证 JSON 数据和参考 Schema
2. **类型准确性评估** → 检查原始类型推断的正确性
3. **必选/可选字段评估** → 验证属性存在性和依赖关系
4. **异构类型支持评估** → 评估联合类型和类型变体覆盖
5. **集合结构一致性评估** → 分析数组结构和元素同质性
6. **实体关系恢复评估** → 检测跨文档关系和引用完整性
7. **时间演变检测评估** → 识别 Schema 版本边界和演变模式
8. **综合评分** → 计算加权总体质量得分 (SQS)

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 存在阈值 (τ) | 0.90 | [论文1] | 属性被认为是"必需"的最小经验频率 |
| 依赖匹配规则 | 精确集合相等 | [论文1] | 逻辑依赖仅在推断前件集与 ground truth 完全匹配时正确 |
| 异构类型惩罚系数 (λ) | 0.5 | [论文1] | 控制过度泛化类型联合的惩罚权重 |
| 同质性-深度权衡 (α) | 0.7 | [论文1] | 平衡类型同质性（基于熵）和嵌套深度一致性 |
| ERR 平衡系数 (β) | 0.7 | [论文1] | 权衡 F1 分数和图编辑距离归一化 |

## 边界与分流

- **无参考 Schema 时**：可基于数据实例进行推断式验证，但无法评估时间演变维度
- **流式数据场景**：当前框架假设静态数据集，增量验证需扩展时间窗口机制
- **性能敏感场景**：框架未覆盖运行时效率评估，大规模部署需补充性能基准

## 质量检查

- 六个维度评分均在 [0,1] 区间内
- 总体 SQS 为各维度加权平均
- 各维度可独立诊断，无单一维度主导总体评估

## 回退策略

- 当无法获取参考 Schema 时，退化为基于数据实例的统计验证
- 当时间信息不可用时，跳过时间演变检测维度，重新归一化权重
