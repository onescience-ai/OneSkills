# 原子探针断层扫描

## 适用范围

用于材料科学研究中，需要在三维空间内以原子级分辨率同时获取化学成分和微观结构信息的场景。典型应用包括分析材料中的元素偏析、界面成分梯度、纳米析出物或团簇、核壳结构以及缺陷处的化学组成。该技术是揭示复杂微纳米结构三维化学分布的核心工具之一。

## 输入

- **必需**：
  - 经过聚焦离子束（FIB）制备的针尖状样品，尖端曲率半径通常小于 100 纳米。
  - 超高真空环境（工作腔体压力低于 10⁻⁸ Pa）。
- **可选/辅助**：
  - 用于样品制备的 FIB-SEM 双束系统。
  - 样品传输与冷却至低温（如 50 K）的装置。

## 输出

- **原子级三维成分分布图（3D Tomography）**：展示样品内不同元素原子在三维空间中的精确位置。
- **元素等值面（Iso-surface）**：可视化特定元素浓度达到某一阈值的空间区域，常用于突出界面、析出物等特征。
- **成分分布曲线（Proxigram）**：基于选定界面计算的，成分随距离界面的分布情况，用于定量分析界面偏析或成分梯度。
- **频率分布分析数据**：用于统计特定区域内元素分布的均匀性或团聚趋势。

## 流程节点

1.  **样品制备**：利用聚焦离子束（FIB）设备，通过改良的 lift-out 技术，从目标材料中制备出符合要求的针尖状样品。该过程对样品的最终质量和分析成功率至关重要。
2.  **仪器安装与环境建立**：将制备好的针尖样品安装到原子探针断层扫描仪（例如 CAMECA LEAP 4000X Si 系统）的样品台上，并抽至超高真空。将样品冷却至预设的低温（如 50 K）。
3.  **数据采集**：施加高压电场并开启脉冲光源（如波长 355 nm 的紫外激光系统）。按照设定参数（如激光能量 20 pJ，检测率 0.5%，脉冲频率 200 kHz）开始场蒸发过程。飞行的离子被位置灵敏探测器接收，记录其飞行时间、撞击位置和荷质比。
4.  **数据重建与分析**：使用专用分析软件（如 Integrated Visualization and Analysis (IVAS) 3.8.4）对采集的数据进行三维重建。分析过程包括元素鉴定、等值面绘制、proxigram 计算和统计分析。

## 边界与分流

- **适用边界**：APT 对样品导电性有一定要求（否则易因电荷积累而失效）；样品制备复杂且成功率受限；分析区域通常较小（微米级）。
- **技术分流**：
  - 当仅需二维高分辨成分成像时，可优先考虑 **HAADF-STEM 结合 EDX mapping** 或 **EELS**。
  - 当分析区域较大或需快速筛选时，可使用 **SEM-EDX** 或 **电子探针微区分析 (EPMA)**。
  - 当需要分析材料晶体结构信息时，**TEM** 或 **EBSD** 是更直接的选择。

## 回退策略

- **样品制备失败**：若 FIB 制备的针尖频繁断裂或形态不佳，需重新优化制备参数（如束流、电压、切割路径），或更换制备方案（如电化学抛光）。
- **数据采集质量差**（如检测率过低、信噪比差）：检查并优化仪器参数（如脉冲能量、延迟、检测率）；确保样品冷却温度稳定；考虑样品本身是否过于不均匀或存在制备损伤。
- **分析结果与预期不符**：重新检查数据重建参数和元素识别标定；结合其他表征技术（如 TEM）进行交叉验证，以确认结构真实性。

## 资源召回建议

- **配套软件**：IVAS（Integrated Visualization and Analysis）是商业且广泛使用的 APT 数据分析软件。
- **互补表征技术**：与 **HAADF-STEM (高角环形暗场扫描透射电镜)**、**EDX mapping (能量色散X射线光谱成像)**、**EELS (电子能量损失谱)** 联合使用，可以提供从三维原子成分到二维高分辨结构与电子结构的完整图像。
- **样品制备**：熟练的 **FIB** 操作技能是获得高质量样品的关键。
