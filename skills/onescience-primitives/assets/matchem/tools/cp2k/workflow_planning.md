# description
CP2K 原语用于科学研究中需要大体系第一性原理计算的任务规划。当任务核心是通过 DFT 级别方法对数百至数千原子的周期性体系进行结构优化、分子动力学、过渡态搜索、振动分析或增强采样时，应优先考虑 CP2K 作为计算工具。规划重点不是选择输入参数的具体数值，而是确定方法与体系的适配性、资源可行性，并构建合理的计算工作流。

# when_to_use
- 需要对 100–5000 原子规模体系进行 DFT 级别的结构优化或单点能计算。
- 需要进行第一性原理分子动力学（AIMD/BOMD）模拟，尤其是液体、溶液、界面或固态电解质体系。
- 需要进行 QM/MM 混合计算，将高精度量子方法应用于催化活性中心、酶反应位点等局部区域。
- 需要进行增强采样自由能计算（metadynamics、umbrella sampling），重构多维自由能面。
- 需要进行振动分析、红外/Raman 光谱预测或声子态密度计算。
- 需要使用 NEB/DIMER 方法定位化学反应过渡态。
- 体系为周期性固体、表面、二维材料或显式溶剂模型。
- GPU 加速环境可用，希望利用 DBCSR GPU 加速进行大基组 DFT 计算。

# when_not_to_use
- 目标是小分子（< 20 原子）的高精度量子化学计算（如精确能量差、激发态）：应使用 Gaussian / ORCA / Molpro / MRCC 等专用量子化学软件。
- 体系超过 10000 原子且不需要电子结构信息：应使用经典力场 MD 软件（LAMMPS / GROMACS / NAMD）。
- 需要使用全电子全相对论方法（如 Dirac-Coulomb 哈密顿量）：CP2K 主要基于赝势/有效芯势，推荐使用 DIRAC 或 ReSpect。
- 需要高精度多参考方法（CASSCF/CASPT2/MRCI）：CP2K 不支持多参考计算，推荐 Molcas / Molpro。
- 体系为纯金属且需要精确费米面/导电性质预测：VASP/QE 可能在能带和态密度方面有更完善的工具链。
- 输入结构不适合周期性边界条件（孤立气相分子除外）。

# inputs
- 任务目标：能量评估、结构优化、AIMD、过渡态搜索、振动分析或增强采样。
- 体系信息：
  - 原子种类、数量及自旋极化需求（开壳层/闭壳层）。
  - 是否周期性体系（3D/2D/1D/0D）。
  - 是否包含过渡金属（涉及磁矩设置和 UKS）。
  - 体系总电荷和自旋多重度。
- 精度要求：
  - 能量收敛判据、力收敛判据。
  - 基组大小需求（DZVP/TZVP/QZVP）。
  - 泛函选择（GGA/hybrid/meta-GGA/双杂化）及 vdW 修正。
- 计算资源：
  - 可用节点数、每节点核心数、每核心内存。
  - 是否有 GPU 节点。
  - 队列时间限制（对 AIMD 尤为重要）。
  - 可用并行文件系统和存储空间。
- 工作流需求：
  - 是否需要波函数重启/续算。
  - 是否需要轨迹后处理和自由能重建。

# outputs
- 工具选型结论：CP2K 是否适合当前任务，或推荐替代工具。
- 输入文件模板：基于目标体系和方法的结构化 `.inp` 文件框架。
- 基组/赝势方案：推荐的基组-赝势组合及对应数据文件路径。
- 方法路线图：
  - DFT 方法：GGA/Hybrid 选择、vdW 修正策略。
  - SCF 求解策略：OT vs 对角化、预条件子、MIXING 参数。
  - MD 方案：系综、恒温器/恒压器、时间步长、波函数外推。
- 资源预估：预计每步 SCF 时间、总计算时间、内存需求和存储需求。
- 启动命令：MPI/Slurm 启动脚本框架及环境变量设置。
- 验证计划：截断能收敛性测试、时间步长能量漂移测试、SCF 收敛性监控方法。
- 风险清单：
  - 方法与体系不匹配（如金属体系使用 OT）。
  - 资源不足（内存/时间/存储）。
  - 收敛性问题（SCF/NEB/metadynamics）。
  - 精度不足（基组/截断能）。

# procedure
1. **确认任务类型**：明确任务是单点能评估、几何优化、AIMD、过渡态搜索、振动分析还是增强采样。每个类型的 `RUN_TYPE` 和控制参数不同。
2. **评估体系规模与方法适配性**：
   - 原子数 < 100：OT 和对角化均可选。
   - 原子数 100–1000：推荐 OT + ELPA。
   - 原子数 > 1000：必须 OT + ELPA。
   - 金属/零带隙体系：禁用 OT，使用对角化 + smearing。
3. **选择泛函与基组**：
   - 优先 PBE + D3(BJ) 作为起点。
   - 根据精度需求升级至 meta-GGA（如 SCAN/r²SCAN）或 hybrid（如 HSE06/PBE0）。
   - 基组从 DZVP-MOLOPT-SR-GTH 开始，按需升级至 TZVP/TZV2P。
   - 过渡金属使用包含 d 极化函数的基组。
4. **确定截断能**：对代表性构型进行 `CUTOFF` 和 `REL_CUTOFF` 收敛性测试（通常从 300/40 开始，以 100/10 递增至 600/60），以总能量变化 < 1e-4 a.u./atom 为目标。
5. **构建输入文件**：
   - 从 `&GLOBAL` 段开始设置 PROJECT 和 RUN_TYPE。
   - 在 `&FORCE_EVAL` 中填入 DFT 参数和体系信息。
   - 对于 AIMD，在 `&MOTION` 中设置 MD 参数，确保波函数外推（`QS/EXTRAPOLATION ASPC`）已启用。
   - 使用 `@SET` 变量集中管理关键参数（CUTOFF、TEMPERATURE 等），提高可维护性。
6. **准备基组与赝势文件**：确认 `BASIS_SET`、`POTENTIAL`（或 `GTH_POTENTIALS`）文件存在于运行目录或 `CP2K_DATA_DIR` 指向的路径。
7. **执行快速测试**：
   - 提交单点能计算（或 `RUN_TYPE ENERGY`）验证输入文件语法和 SCF 收敛性。
   - 对于 AIMD，先运行 10–20 步测试能量守恒和时间步长合理性。
8. **提交正式生产作业**：根据资源预估调整 MPI 进程数、OpenMP 线程数和节点数，生成 Slurm/PBS 作业脚本并提交。
9. **监控与后处理**：
   - SCF 收敛：检查输出中 `SCF run converged` 的频率和平均迭代数。
   - AIMD：检查温度振荡、总能量漂移和原子位移。
   - 几何优化：检查 `OPTIMIZATION COMPLETED` 和最终力/位移。
   - 自由能计算：使用 `graph.popt` 或其他后处理工具重建自由能面。

# constraints
- 输入文件的层次结构严格受 CP2K 解析器约束，段顺序和嵌套必须符合手册规范，不能随意改变。
- 基组名和赝势名必须在提供的 `BASIS_SET` / `POTENTIAL` 文件中存在，否则 CP2K 启动时立即报错。
- OT 方法仅适用于非零带隙体系（绝缘体/半导体）；在金属体系中必须使用对角化。
- `CUTOFF` 和 `REL_CUTOFF` 不能盲目使用默认值，必须针对目标体系做收敛性测试——这在不同元素组合下变化显著。
- AIMD 中 H 含原子的时间步长严格限制在 ≤ 1.0 fs，推荐 0.5 fs。
- 混合泛函（HSE06/PBE0 等）在大体系（> 200 原子）的计算开销可能达到纯 GGA 的 10–100 倍，规划资源时必须考虑。
- NEB 计算的初始态和终态构型必须保证原子数量、种类和顺序一致。
- metadynamics 的收敛性依赖于 CV 的适当选择和山参数（高度、宽度、沉积频率）的合理配置——不适当的参数会导致计算无效。
- QM/MM 计算需手动定义分区和链接原子，不存在自动分区机制；分区的合理性直接影响结果质量。
- 周期性边界条件体系的单位胞必须在所有方向上足够大，以避免 DFT 中由镜像相互作用引入的伪影。

# next_phase_recommendation
- 为当前材料体系建立参数收敛性基准：记录 CUTOFF / REL_CUTOFF 收敛曲线、基组收敛趋势、泛函对比。
- 对于催化/QM/MM 任务，先通过纯 DFT 小模型验证反应路径的合理性，再扩展至 QM/MM 生产计算。
- 对于 AIMD 任务，建立自动化的能量漂移监测和异常检测脚本。
- 如体系包含过渡金属，优先验证磁矩初值和 UKS 设置的合理性。
- 对于自由能计算，通过短时间测试验证 CV 的选择和 metadynamics 山参数的有效性。

# fallback
- SCF 不收敛：
  - 尝试切换到 OT（如果体系有带隙）。
  - 调整 `MIXING ALPHA`（0.3–0.6）。
  - 使用 `&SCF/&OUTER_SCF` 结合对角化作为外部循环。
  - 检查初始结构是否有异常近邻接触。
  - 使用 smear（`&SCF/ADDED_MOS` + `&SCF/SMEAR`）。
- 内存不足/时间超限：
  - 降低基组大小至 DZVP 级别。
  - 减少 MPI 进程数（降低 DBCSR 通信开销）。
  - 增加 `EPS_DEFAULT`（如 1e-10 → 1e-8），牺牲少量精度换取更稀疏的矩阵和更快计算。
  - 使用 LRIGPW（局部 RI 近似）替代完整 GPW。
- 几何优化震荡/不收敛：
  - 改用 LBFGS 优化器（对大体系更稳定）。
  - 降低优化步长上限（`MAX_STEP_SIZE`）。
  - 在优化初期使用较低截断能，最后几步切换至高精度。
- AIMD 能量漂移过大：
  - 降低时间步长至 0.25–0.5 fs。
  - 确认波函数外推已正确启用（`QS/EXTRAPOLATION ASPC`）。
  - 提高 EPS_SCF（1e-7 → 1e-8）。
- metadynamics 未有效探索构型空间：
  - 检查 CV 是否能区分目标状态。
  - 增大初始山高或提高沉积频率。
  - 使用 Multiple-Walker metadynamics 加速构型空间采样。
