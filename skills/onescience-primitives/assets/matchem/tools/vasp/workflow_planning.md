# VASP 工作流规划指南

---

## #description

VASP 是用于周期性体系第一性原理电子结构计算的工业级软件包。本指南帮助判断在科研工作流中何时应将 VASP 作为计算引擎，以及如何将其与上下游工具衔接，以构成完整的计算材料科学/化学工作流。

VASP 的核心定位是**高精度 DFT 计算引擎**——当你需要以下信息时，VASP 是最合适的选择：
- 基态电子结构和总能量
- 平衡晶体结构和晶格常数
- 电子能带结构和态密度
- 声子谱和热力学性质
- 光学和介电性质
- 表面/界面能量学与吸附能
- 反应路径和活化能垒

---

## #when_to_use

### 适用场景

#### 1. 周期性体系 DFT 计算
- **晶体材料**：体相晶体、合金、化合物的电子结构、形成能、相稳定性
- **表面科学**：表面能、表面重构、功函数、表面态
- **界面建模**：异质结、晶界、固-液界面
- **缺陷物理**：点缺陷（空位、间隙、反位）形成能、迁移能垒

#### 2. 结构预测与优化
- 对实验结构进行弛豫获得理论平衡结构
- 基于全局优化算法（如 USPEX、CALYPSO 结合 VASP）进行晶体结构预测
- 高压物态方程（EOS）计算

#### 3. 电子性质分析
- 态密度（DOS）和投影态密度（PDOS）
- 电子能带结构（含自旋轨道耦合）
- 电荷密度差分析、Bader 电荷分析、ELF 分析
- 功函数和离子化势

#### 4. DFT 级别的分子动力学
- Born-Oppenheimer 分子动力学（BOMD）
- 有限温度性质采样（径向分布函数、扩散系数等）
- 固态相变和化学反应动态过程模拟

#### 5. 声子与热力学
- 通过有限位移法或 DFPT 计算声子色散
- 声子态密度、零点能、自由能
- 晶格热导率（需配合 Phono3py 等工具）
- 电子-声子耦合

#### 6. 光谱学模拟
- 红外光谱（Born 有效电荷）
- 拉曼光谱
- 紫外-可见吸收光谱（介电函数虚部）
- X 射线吸收谱（XANES）

#### 7. 反应动力学
- 过渡态搜索（NEB / CI-NEB / Dimer）
- 最低能量路径（MEP）确定
- 催化反应能垒计算

## #when_not_to_use

### 不适用场景及替代方案

| 场景 | 不适用的原因 | 推荐替代方案 |
|------|-------------|-------------|
| **大规模经典分子动力学**（> 10000 原子，ns–μs 时间尺度） | DFT 级别计算成本过高，无法达到统计采样的时空尺度 | LAMMPS、GROMACS、NAMD 配合经典力场 |
| **非周期性的孤立分子量子化学** | 周期性边界条件需大量真空层降低镜像相互作用，计算效率低 | Gaussian、ORCA、Q-Chem（局域基组更高效） |
| **高通量万级材料筛选** | 每个 VASP 计算成本高，适合精细计算但非高通量粗筛 | 紧束缚（DFTB+、xTB）、机器学习势（MACE-MP-0）预筛，再精选用 VASP 验证 |
| **强关联体系**（莫特绝缘体、重费米子） | 标准 DFT 无法正确描述强关联效应 | DFT+DMFT 方法、量子蒙特卡洛（QMC）、或与 DMFT 结合的多体方法 |
| **激发态动力学**（光化学反应、非绝热过程） | VASP 的实时 TDDFT 能力不如专用软件完善，激发态梯度计算有限 | SHARC、Newton-X（非绝热动力学），Molpro/Molcas（多参考方法） |
| **大分子生物体系** | 计算成本不可接受，且周期性处理蛋白质等生物大分子不自然 | GROMACS、AMBER、NAMD 配合经典力场，QM/MM 方法用 VASP 作为 QM 区亦可 |
| **快速力场级别预筛** | 即使粗参数设置，VASP 的计算成本也远高于力场方法 | 经典力场（ReaxFF、COMPASS）、通用 MLIP（MACE-MP-0、SevenNet） |
| **液体/无定形体系的能带计算** | k 点采样需超胞已足够大才可近似 Gamma 点 | 需超大超胞（> 200 原子）或改用 CP2K（混合基组） |

## #procedure

### 典型 DFT 工作流

VASP 在科研工作流中通常处于计算执行阶段。以下为标准工作流：

#### 阶段 0：输入准备
1. **结构获取**：从实验数据（CIF/Crystallography Open Database）、数据库（Materials Project、ICSD、COD）或结构预测算法获取初始结构
2. **输入文件生成**：使用 Pymatgen、ASE 或 VASPKIT 将结构转化为 POSCAR；生成 INCAR（根据计算类型选择参数模板）；生成 POTCAR（自动拼接 PE 赝势）；生成 KPOINTS（通过 KSPACING 自动）
3. **伪势收敛测试**：对目标体系做 ENCUT 收敛测试和 k 点收敛测试（能量差 < 1 meV/atom）

#### 阶段 1：结构弛豫
4. 粗精度弛豫：`ISIF=3, IBRION=2, EDIFF=1E-5, EDIFFG=-0.02`
5. 检查弛豫结果：力的最大分量是否低于 EDIFFG；晶胞参数是否已收敛
6. 高精度弛豫：使用更严格的收敛标准 `EDIFF=1E-7, EDIFFG=-0.005` 精修
7. 对于相变/晶胞敏感体系，做多步弛豫：先 ISIF=2 → ISIF=3 → ISIF=2 分步优化

#### 阶段 2：静态 SCF
8. 在弛豫后的 CONTCAR 上执行静态自洽计算：`NSW=0, IBRION=-1, ISMEAR=-5, LCHARG=T, LWAVE=T`
9. 获取精确的总能量和电荷密度（CHGCAR），用于后续性质计算

#### 阶段 3：性质计算
10. **DOS 计算**：从 CHGCAR 起步（`ICHARG=11`），使用更密集的 k 点网格
11. **能带计算**：确定高对称路径，用线模式 KPOINTS 进行非自洽计算
12. **光学性质**：`LOPTICS=TRUE` 计算介电函数
13. **功函数**：从 LOCPOT 文件中提取静电势
14. **Bader 电荷**：用 Bader 分析程序处理 CHGCAR

#### 阶段 4：后处理与分析
15. 使用 VASPKIT 进行后处理（能带、DOS 提取与绘图，功函数，有效质量等）
16. 使用 Pymatgen/ASE 解析 vasprun.xml，提取能量、力、结构信息
17. 绘制能带图（sumo-bandstats）、态密度图、电荷密度等可视化
18. 整理数据并撰写报告

#### 阶段 5（可选）：高级计算
19. **声子谱**：生成超胞 → 有限位移 → 系列 VASP 计算 → Phonopy 后处理
20. **过渡态**：NEB 插值 → NEB 计算 → CI-NEB 精确定位 → 虚频验证
21. **弹性常数**：`IBRION=6, ISIF≥3` 应力-应变法计算弹性张量
22. **AIMD**：`IBRION=0, SMASS` 设定恒温器参数，运行 BOMD

## #constraints

### 使用约束

1. **商业许可证**
   - VASP 是闭源商业软件，使用前需购买许可证
   - 许可证价格根据研究组规模和地区有所不同
   - 不得在未授权的情况下分发 VASP 可执行文件或 POTCAR 赝势库
   - 学术论文中需引用 VASP 的原始文献

2. **平台限制**
   - 仅支持 Linux 操作系统（x86_64/ARM64 架构）
   - 不支持 Windows/macOS 原生运行（需 WSL 或虚拟机）
   - GPU 版本需 NVIDIA CUDA 工具链

3. **方法约束**
   - 仅支持周期性边界条件（PBC）
   - 仅使用平面波 + PAW 赝势方法（无全电子选项）
   - 波函数基组为非局域轨道基组（无原子轨道选项）

4. **计算复杂度**
   - 计算成本随体系电子数 $N_e$ 以 $O(N_e^3)$ 量级增长
   - 对 500+ 原子的大体系，需大量 HPC 资源和较长机时
   - GW/RPA/BSE 等高阶方法的计算量比 DFT 高 1–3 个数量级

## #next_phase_recommendation

### 上下游工具链推荐

#### 输入准备工具

| 工具 | 用途 | 与 VASP 的衔接方式 |
|------|------|-------------------|
| **Pymatgen** | Python 材料学库，结构构建、输入文件生成、结果解析 | `pymatgen.io.vasp` 模块直接读写 VASP 输入输出 |
| **ASE** | 原子模拟环境，统一接口操作多种 DFT 代码 | `ase.calculators.vasp.Vasp` 作为 VASP 计算器 |
| **VASPKIT** | VASP 专用预处理和后处理命令行工具 | 通过读取 VASP 输出文件直接操作 |
| **SeeK-path** | 自动确定晶体结构高对称 k 点路径 | 输出 KPOINTS 格式的线模式 k 路径 |

#### 性质计算/后处理工具

| 工具 | 用途 | 与 VASP 的衔接方式 |
|------|------|-------------------|
| **Phonopy** | 声子谱、热力学性质计算 | 读取 VASP 的力常数矩阵，使用有限位移法或 DFPT 接口 |
| **Phono3py** | 三阶力常数、晶格热导率 | 基于 VASP 力的高阶展开 |
| **VASPKIT** | 一站式后处理（能带、DOS、功函数、有效质量等） | 直接解析 VASP 输出 |
| **Sumo** | 能带结构、态密度高质量绘图 | 解析 vasprun.xml |
| **Bader** | Bader 电荷分析 | 处理 CHGCAR 文件 |
| **Lobster** | COHP/COOP 化学键分析 | 读取 VASP 的 PAW 投影波函数 |

#### 高级计算/工作流框架

| 工具 | 用途 | 与 VASP 的衔接方式 |
|------|------|-------------------|
| **Atomate** | 高通量 DFT 工作流自动化 | 以 VASP 为计算引擎，FireWorks 为任务调度器 |
| **AiiDA** | 可追溯的高通量计算框架 | 通过 `aiida-vasp` 插件管理 VASP 计算 |
| **ASE** | 过渡态搜索（NEB）、全局优化（Basin-Hopping）、MD | 以 VASP 作为底层能量和力的提供者 |
| **VTST** | NEB/CI-NEB/Dimer 高级过渡态搜索 | VASP 的社区插件，直接编译进 VASP |
| **DeepMD / MACE / DPA3** | 机器学习势函数训练 | 以 VASP 生成的能量和力作为 DFT 级别训练数据 |

### 数据持久化与可重复性

- **AS SEEN**：将 CONTCAR 转存为下一计算的 POSCAR 时，务必保留原始结构文件
- **收敛性记录**：记录每个阶段使用的 ENCUT、KSPACING、EDIFF、EDIFFG 等关键参数，确保结果可复现
- **INPUT/OUTPUT 归档**：建议使用 AiiDA 或自定义脚本完整保存每次计算的输入和输出文件
- **vasprun.xml**：这是 VASP 输出中最结构化和易于程序解析的文件，优先用其进行自动分析
