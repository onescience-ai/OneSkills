# ReaxNet 极化长程神经网络势框架

## 适用范围

适用于需要高精度、高效率地进行包含电荷转移、极化效应和长程静电相互作用的分子动力学模拟的研究场景。典型应用对象包括离子导体、固态电解质、催化表面、铁电/压电材料以及涉及非平衡电荷分布的分子体系。该框架的设计目标是提供一个通用、可迁移的势能面描述方案，其核心价值在于将物理驱动的静电模型与数据驱动的短程模型相结合，从而在保持计算效率的同时，获得接近量子力学计算的精度，尤其擅长处理依赖于电子极化的材料性质。

## 输入

- **原子坐标 (ri)**：体系中所有原子的三维坐标，为浮点数数组。
- **原子类型 (Zi)**：原子序数或元素标识，为整数数组。框架支持周期表前102号元素的预设参数。
- **体系边界条件**：用于确定周期性边界和模拟盒子形状。
- **PQEq 参数**：包括电负性 (χ0)、化学硬度 (η0) 和弹簧常数 (Ki^s)。这些是预置的102个元素的经验参数，通常从实验数据或高级量子化学计算导出，对于特定体系无需重新训练。

## 输出

- **总势能 (Epot)**：体系的总势能，为标量。
- **原子力**：作用于每个原子的力向量。
- **维里应力**：模拟盒子的应力张量。
- **原子部分电荷 (qi)**：经PQEq自洽计算后收敛的原子部分电荷，为辅助输出。
- **壳层位置 (ris)**：极化模型中用于描述电子云位移的壳层位置。

## 流程节点

该势能计算的流程是一个有向无环图（DAG），总势能由三个独立的能量分量求和得到：短程机器学习势能 (E0)、长程极化静电能 (EPQEq) 和色散修正能 (ED3)。

1.  **构建原子图与特征嵌入 (s1)**：将原子坐标和类型转换为图神经网络的输入表示。这是所有后续计算的共同起点。步骤输入包括原子坐标和原子类型。输出为原子特征向量和原子间连接关系。质量要求是特征能正确编码原子间距离和方向信息。

2.  **计算短程机器学习势能 (E0) (s2)**：基于步骤s1的输出，通过等变消息传递神经网络块预测非静电贡献的能量。该神经网络组件被专门设计为仅捕获与静电相互作用不同的能量贡献，以避免能量分配重叠。输出为标量能量 E0。依赖步骤：s1。

3.  **极化电荷平衡 (PQEq) 自洽计算 (s3)**：基于原子坐标和类型，迭代求解一个线性方程组以确定收敛的部分电荷和壳层位置，进而计算长程静电能。该方案的核心是直接优化静电相互作用能，而非部分电荷。步骤输入包括原子核位置、原子类型和PQEq参数。输出为收敛的部分电荷、壳层位置和静电能 EPQEq。质量要求是电荷和壳层位置收敛。依赖步骤：s1。

4.  **计算色散能 (ED3) (s4)**：基于原子坐标和类型，使用DFT-D3方法计算色散修正能 ED3。依赖步骤：s1。

5.  **汇总总能量与力 (s5)**：将 E0、EPQEq 和 ED3 相加得到总势能 Epot。随后，通过对总能量关于原子坐标的自动微分，计算原子力和维里应力。部分电荷也可作为辅助输出被提取。依赖步骤：s2， s3， s4。质量要求是能量分量叠加逻辑正确，微分计算无误。

## 边界与分流

- **适用场景**：该框架特别适合模拟过程涉及显著电荷重排、外场响应或需要准确描述库仑长程作用的体系。其等变图网络部分确保了对短程键合的灵活描述。
- **不适用或需替换的场景**：
    - 若模拟体系完全由中性分子组成且极化效应极弱，或对计算速度要求极高且可接受更简化的静电模型，可考虑使用不包含极化模块的普通机器学习势。
    - 对于元素种类超出预设PQEq参数表（当前为102个元素）的体系，需要自行获取或拟合对应元素的PQEq参数。
    - 当原子间距离超过图神经网络的截断半径（典型值为5.0 Å）时，消息传递机制将无法连接这些原子，可能导致计算失败。此时需要调整截断半径或使用能描述更长程相互作用的模型架构。
- **与上下游的衔接**：该框架的输出（能量、力、应力、电荷）可直接用于分子动力学引擎（如ASE）进行时间演化。计算得到的部分电荷可作为重要的电子结构近似结果，用于后续分析（如静电势计算、电荷输运分析）。

## 质量检查

- **收敛性检查**：确保PQEq自洽计算中的部分电荷和壳层位置已收敛。未收敛的电荷会导致静电能不准确。
- **能量分量合理性**：检查短程能 E0、静电能 EPQEq 和色散能 ED3 的量级是否在物理合理范围内，避免因模型问题导致某一能量分量异常。
- **力与应力验证**：通过有限差分法或对称性检查，验证自动微分计算得到的力与维里应力是否正确。
- **元素覆盖性**：确保模拟体系中的所有元素都在预置的PQEq参数表内，或已为其提供了可靠的参数。

## 回退策略

- **PQEq计算不收敛**：检查初始猜测、调整迭代参数或检查体系构型是否过于异常。如果持续失败，可尝试使用更简单的QEq方法作为临时替代，但需注意其不区分核心与壳层电荷，无法正确响应垂直于分子偶极的外场。
- **特定元素精度不足**：已知某些元素（如镱 Yb）由于训练数据的传递性问题，预测可能不准确。此时应从训练数据中排除该元素，或在应用该势能进行模拟时，对该元素相关的结果持谨慎态度，并考虑使用经过专门优化的势能模型。
- **非物理电荷转移**：如果观察到长程分子间出现非物理的电荷转移，这可能是基础QEq方法的缺陷（该方法假设体系为完美导体，不对远距离电荷转移进行惩罚）。此时应确保使用的是本文描述的极化版本（PQEq），它通过核心-壳层分离缓解了此问题。若问题依旧，需检查PQEq参数或考虑结合更高级的量子力学/机器学习混合方案。

## 资源召回建议

- **模拟接口**：可与原子模拟环境（ASE）等主流计算化学软件集成，用于设置模拟、运行动力学和后处理分析。
- **基座模型**：等变图神经网络部分可参考 NequIP 等框架的设计思路。对于类似的多组分势，也可参考 4G-HDNNP 等工作。
- **训练数据**：模型的训练通常需要大规模、高质量的原子构型及其能量、力数据。MPtrj 是一个适用于该类通用势训练的大型数据集。
- **代码实现**：该框架的开源JAX实现可在 GitHub 或 Zenodo 上获取。
- **替代方案**：如果极化效应不是核心关注点，可替换神经网络块为其他主流机器学习势架构（如 SchNet， PaiNN）；长程相互作用部分也可替换为其他模型（如经典的Ewald求和与固定电荷模型）。
