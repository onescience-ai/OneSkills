# description
`lammps` 工具原语的规划重点是为经典分子动力学模拟任务选择合适的 LAMMPS 工作流：根据体系特征（元素、原子数、晶相/非晶、含化学反应与否）确定力场类型、系综序列、模拟参数和计算资源需求，并输出可执行的 in 脚本骨架、资源建议和风险清单。

# when_to_use
- 需要执行经典分子动力学模拟（晶体、非晶、液体、界面、表面、聚合物、生物大分子等体系）
- 需要进行结构弛豫（能量最小化）、NVT/NPT 平衡或生产运行
- 需要计算热力学性质（温度、压力、能量、状态方程）或结构性质（RDF、MSD、VACF）
- 需要模拟力学行为（拉伸、压缩、剪切形变）或热输运（热导率）
- 需要将 ML 势函数（MACE、DeepMD 等）集成到 MD 模拟流程中
- 需要为 DFT 计算生成初始构型（退火、弛豫后的结构）

# when_not_to_use
- 需要第一性原理电子结构计算（应使用 VASP、CP2K、Quantum ESPRESSO 等 DFT 软件）
- 需要处理电子激发态、光吸收/发射等非绝热过程（时间尺度超出经典 MD 范围）
- 需要量子化学级别的单分子计算（应使用 Gaussian、ORCA 等）
- 仅需要可视化或轨迹分析（使用 OVITO、VMD 等后处理工具）
- 需要构建初始分子/聚合物构型（使用 Packmol、Avogadro 等建模工具）
- 需要粗粒化（CG）模拟（LAMMPS 支持 CG 势但不包含 CG 力场参数化功能）

# inputs
- 体系信息：化学元素、原子数（大致规模）、相态（晶态/非晶/液体）、周期性边界条件需求
- 模拟目标：弛豫（energy minimization）、平衡（NVT/NPT）、生产运行（NVE/NVT）、特殊计算（形变/热导/扩散等）
- 精度要求：力场精度级别（经典势/反应力场/ML 势函数）、截断半径、长程静电处理
- 资源约束：可用计算节点数、每节点核心数、GPU 可用性、模拟时间预算
- 力场来源：文献推荐的势参数、已训练好的 ML 模型文件、内置势库
- 输出需求：轨迹格式（lammpstrj/xyz/dcd）、热力学输出频率、数据分析指标

# outputs
- 完整的 LAMMPS in 输入脚本（包含所有 4 个部分）
- 势函数文件引用（pair_coeff 文件路径、ML 模型路径）
- 作业提交脚本（SLURM/PBS 模板）
- 模拟参数建议：timestep、系综类型、Tdamp/Pdamp、平衡步数、生产步数
- 后处理指导：推荐的分析方法和工具（OVITO、VMD、Python MDAnalysis/pymatgen）
- 风险清单：时间步长稳定性、平衡充分性、力场适用范围、资源估算

# procedure
1. **体系分析**：确认元素组成、相态（晶体/非晶/液体/界面）、是否含化学反应、是否需长程静电
2. **力场选型**：
   - 金属体系 → EAM/MEAM
   - 半导体 → Tersoff/Stillinger-Weber
   - 离子晶体 → Buckingham + Coulomb（需 kspace_style pppm）
   - 有机/生物分子 → OPLS/CHARMM/AMBER（data 文件需含分子拓扑）
   - 化学反应用体系 → ReaxFF/COMB/AIREBO
   - 需要 DFT 精度 → MLIAP（MACE/DeepMD/NequIP）
   - 简单测试/教学 → LJ
3. **单位系统确定**：材料模拟默认 `units metal`，生物分子默认 `units real`
4. **系综序列设计**：
   - 结构弛豫 → minimize（cg/fire）
   - 温度平衡 → NVT（25000-100000 步）
   - 压力/密度平衡 → NPT（25000-100000 步）
   - 生产运行 → NVE 或 NVT（100000-10000000 步）
5. **时间步长设定**：根据最轻原子和最高频率振动确定，配合约束方法（SHAKE/RATTLE）
6. **输出配置**：thermo 间隔、dump 轨迹间隔、compute 数据分析设置
7. **资源估算**：根据原子数、力场复杂度和模拟步数估算计算时间，推荐进程数和节点数
8. **脚本生成**：输出完整 in 脚本，包含注释说明每部分的作用

# constraints
- 不在 LAMMPS 输入脚本中进行力场参数拟合（应使用外部工具如 potfit、MEAMfit 等）
- 不在 in 脚本中硬编码绝对文件路径，优先使用相对路径或环境变量
- 势函数文件必须在所有计算节点上可访问（可通过共享文件系统或预分发解决）
- 模拟盒子尺寸必须大于 2 × pair_style 截断半径
- 使用 MLIAP 时，LAMMPS 版本必须支持对应的 ML 框架接口
- 初始速度分布的随机种子需要在脚本中明确写出（便于复现）
- 周期体系不能与 `boundary f`（固定边界）混合用于体相性质计算
- 分子体系需注意柔性约束（SHAKE）与 timestep 的配合

# next_phase_recommendation
- 建立力场参数库：记录常用势函数的文件路径、参数来源和验证结果
- 建立模拟模板库：按体系类型（金属/半导体/离子晶体/分子/反应）归档已验证的 in 脚本
- 集成后处理工作流：将 LAMMPS 输出与 OVITO/VMD/Python 分析脚本连接
- 建立势函数验证协议：对陌生力场参数先做晶格常数、弹性常数、缺陷形成能的基准测试
- ML 势函数集成：建立 MLIAP 接口的标准调用模板，覆盖 MACE、DeepMD 等常见 ML 势

# fallback
- **力场不可用**：切换到更通用的力场（如 LJ 用于简单测试、Tersoff 用于半导体、EAM 用于金属），或尝试 OpenKIM 在线势函数库
- **模拟不稳定**：减小 timestep（如从 1.0 fs 降至 0.25 fs）；降低初始温度增量；增加能量最小化的收敛精度
- **平衡不收敛**：增加 NVT/NPT 平衡步数；调整 Tdamp（缩短温度阻尼时间）；检查是否需要用 Langevin 恒温器代替 Nose-Hoover
- **计算时间过长**：降低生产运行步数；增大 dump 间隔；减小近邻列表更新频率；使用更简单的力场；启用 GPU 加速
- **内存不足**：减少原子数（缩小模拟区域）；使用更简单的力场；减少 dump 输出
- **MLIAP 接口错误**：检查 LAMMPS 是否编译了 MLIAP 包；验证 ML 模型文件格式和路径；确认模型截断半径与 neighbor 设置匹配
- **跨平台可移植性**：文件路径使用相对路径；通过 `-var` 命令行参数传入关键变量；避免使用平台特定命令
