# description
这是一个以能量凸包距离为判据的计算筛选工作流，把“判断MXene组成能否稳定存在”转化为“对候选组成进行DFT并比较其相对于分解产物的热力学优势”。该流程面向新材料合成中的理性设计环节：在MXene合成往往是试错的前提下，先用计算扫描29个过渡金属和11种表面终止的组合，给出998个被预测为（亚）稳定的组成；它既可以用于完整的高通量扫描，也可以在Materials Project能量不全时只对感兴趣的少量MXene做精细判断。该方法可从MXene迁移到其他二维层状材料系统，只要具备相应的参考相能量。

# when_to_use
适合在以下场景中启用：还没有进入实验、需要判断某个新组成的MXene（例如特定M与-O/-OH/-F终止）是否值得合成；想从众多元素组合中选取热力学最稳定的前十名进行优先实验；或者要系统研究不同表面终止对材料稳定性的影响并产出可以指导合成的化学规律。当已有的晶体结构来自MAX相剥层而表面终止未知时，也可以用该流程来预测哪种终止最易存在。该工作流适用于数百个候选物级别的通量扫描；如果只需要一两个结构，也可以直接把判断公式用于单点计算。

# inputs
上游输入包括：候选MXene的化学式空间，即29种过渡金属、11种表面官能团、可选的M_{n+1}X_n层厚组合；母体结构模板（如Ti_{n+1}C_n等骨架）；DFT计算所需的初始晶胞与赝势；所有竞争相（单质、二元/三元碳化物/氮化物等）的能量——它们通常来自Materials Project。如果希望复现论文，还需要准备论文给出的998个组成中的结构ID作为重点对象。输入还包括磁性状态和初始晶格常数设定，这些影响DFT能量是否进入正确的局域极小。

# outputs
最重要的输出是每个MXene候选的能量高于凸包距离（energy above hull）值，以及热力学稳定/亚稳定的分类标签；论文最终给出998个被预测为（亚）稳定组成的名单和表面终止化学规律。在可复用软件输出方面，建议提供一个结构化文件：每条目包含化学式、凸包距离、弛豫结构、对应参考相和状态，方便后面作为训练标签或放进材料数据库。输出还需要把结果按过渡金属和终止类型做聚合视图，突出哪些组合对稳定性起关键作用。

# procedure
1. 枚举候选组成：固定论文指定的29种过渡金属和11种表面终止，生成候选MXene化学式清单。
2. 生成初始结构：对每个化学式，从其无终止MXene母体出发，按表面官能团的高对称放置方案添加T原子，设置真空层厚度和晶胞尺寸。
3. 执行DFT结构优化与总能量计算：将结构输入DFT代码，运行原子与晶胞弛豫，检查收敛，提取最终能量和晶格参数。
4. 建立凸包：收集该体系中全部候选和参考相的能量，用pymatgen PhaseDiagram构造化学计量空间中的能量凸包。
5. 计算凸包距离：调用对应接口，计算每个MXene候选到凸包表面的垂直距离（meV/atom），得到排序。
6. 分类与解读：将距离较小的候选归入(亚)稳定集合，统计表面终止在稳定名单中的分布，归纳有利于热力学稳定的元素/终止组合，最终给出类似论文所报道的998组成级别的分类名单。

# constraints
该方法要求参考相能量完备且可靠，否则凸包会被错误相点扭曲；当只有形成焓而缺少完整化学势凸包时，不能直接模拟分解路径。该流程评估的是0K热力学稳定性，不包含振动自由能和高压/高温相变，也不评估MAX相到MXene的刻蚀转化动力学。论文的终止集是预先固定的单一基团，若遇到混合终止或表面覆盖率不足的实验条件，必须扩展枚举或采用随机/全局优化处理，否则系统不封闭。资源约束也很关键，全空间19金属×11终止的DFT成本巨大；复现者可以先取论文的998个稳定候选重新验证，而不要一开始就跑全空间。

注：本卡基于论文摘要撰写（未获取全文），细节深度受限，实际使用前请核对源论文原文。

# next_phase_recommendation
筛选完成后，下一步建议以三个方向延伸：一是对凸包距离很小的MXene做动态稳定性验证（声子谱、AIMD），排除软模造成的虚稳；二是把稳定MXene与目标应用（能量存储、催化、电磁屏蔽）结合进行电子结构和表面性质预测，为应用实验提供优先级；三是把论文得到的998个组成以及hull distance写入开放材料数据库，作为机器学习模型训练集，从而加速更大化学空间或混合终止体系的筛选。若把表面官能团扩展到论文以外的Cl、Br、S等基团，本工作提供的凸包距离计算框架可以直接作为基底流程，形成迭代式的“计算预测—实验合成—数据回填”闭环。

# fallback
当批量DFT不可用或算力不足时，可先查询Materials Project数据库中是否已存在目标MXene或接近MAX相的能量，用这些现成数据估计组成稳定性；若数据库没有该化合物，则暂时使用相对金属和石墨/氮气的简单形成能近似来粗筛，并在报告里明确其局限。当没有完整凸包参考相时，可以退回到“分解焓近似的经验判据”——只比较MXene与最可能竞争相的生成焓差，人工取前几个竞争相做简化计算。对于应用场景较急的团队，可优先采用实验合成成功率高、文献报道多的Ti、V、Nb、Mo等过渡金属与-O/-OH终止组合，把DFT资源聚焦在这些热点组合上验证，而不是全空间扫描。所有降级方案得到的预测都应称之为假设，而非可作为结论的绝对稳定性判断。
