# architecture_overview
该方案不是单一神经网络或软件，而是一套面向MXene二维材料的高通量DFT稳定性筛选流程。整体架构由候选空间生成器、结构优化与DFT能量计算器、凸包分析器以及结果解释器四部分组成：空间生成器枚举29种过渡金属和11种表面终止得到候选化学式；DFT计算器对每个化学式弛豫并提取总能量；凸包分析器将能量置于元素/竞争相的热力学坐标系，计算候选到能量凸包的垂直距离；结果解释器对距离排序并归纳表面终止化学规律。源论文（DOI: 10.1021/acs.chemmater.4c02274）在Abstract中说明以DFT和能量凸包距离为核心描述符，并强调表面终止化学的关键作用。

# parameter_scale
筛选范围明确为29种过渡金属与11种表面终止，覆盖从第IVB族至较晚过渡金属的元素区间（具体元素列表见论文正文）。MXene的化学计量可包含M_{n+1}X_n的不同层厚，因此实际结构数量多于29×11的简单乘积。论文最终筛选出998个被预测为（亚）稳定的MXene组成，也就是经过全空间搜索压缩后的热力学候选名单。每个候选至少需要一次全弛豫DFT计算，总任务量通常在千个左右；DFT单任务对应单元原子数约10~100（取决于层厚），属于中高维度材料筛选中常见的计算规模。

# architecture_structure
作为计算筛选方法，其架构本质是一条任务流水线：输入定义候选化学空间（M、X、T三组变量的笛卡尔积），每个具体结构进入独立的DFT弛豫/能量计算分支，最后所有分支的输出汇集到凸包归约节点。由于DFT任务彼此独立，易于在集群上用job array并行；最终将能量表导入pymatgen PhaseDiagram对象完成凸包几何计算。论文的宏观流程在Abstract中体现为“枚举→DFT→凸包→分析结果”，没有神经网络中的层间张量变换，核心数据对象是结构文件与能量表。

# input_schema
单个任务输入是一个完整MXene晶胞：确定过渡金属M层与X（C/N）层骨架，在上下表面按一定覆盖率放置表面官能团T；输入至少包含晶格矢量、原子坐标、原子种类、赝势标识和初始磁矩设置。在DFT代码层面，常提供四个文件（VASP风格）：POSCAR含原子坐标，POTCAR含对应元素的赝势，INCAR含收敛参数，KPOINTS含k点网格。二维材料建模需要在z方向加入足够大的真空层（领域常用约15 Å以上）以避免周期镜像作用。论文未公布统一输入模板，但MXene表面官能团不能随机放置，而应按能量低的高对称覆盖构型初始建模。

# output_schema
每个候选的直接输出是DFT总能量以及弛豫后的结构（晶格常数、原子坐标和受力）。后处理将总能量换算为形成能，再投影到凸包上得到每个候选的能量高于凸包的距离（energy above hull，常用meV/atom单位）。论文的最终输出提供998个被预测为（亚）稳定组成的集合，并按表面官能团类型、过渡金属类别给出化学趋势分析。工程化输出可组织为CSV或JSON，每条记录至少包含化学式、空间群、晶格参数、总能量、凸包距离和稳定状态，方便下游机器学习或实验排程直接消费。

# shape_transformations
该方法关心的核心数据变换是从高维原子坐标到能量标量再到凸包距离。原子结构经DFT求解映成一个浮点能量，维度从3N维坐标坍缩为标量；随后多个参考相能量在化学计量空间中构成凸包，每个候选投影到凸包表面得到一个几何距离。DFT内部的键长、键角都通过原子坐标变化体现，与深度学习里的张量shape链不同；凸包计算则是标准计算几何问题，输入能量和组成坐标，输出每个点到凸包的垂直距离。

# key_dependencies
该流程依赖高质量DFT求解器（如VASP、Quantum ESPRESSO）和完整的热力学参考相数据集。要构造凸包，需要所用M、X、T元素的所有稳定单质、二元/三元化合物等竞争相的能量，通常从Materials Project数据库抽取或另行计算。工具链方面，pymatgen.analysis.phase_diagram的PhaseDiagram类承担凸包构建与距离计算；原子结构生成和作业流管理可借助ASE、atomate等Python库。论文在Abstract说明使用DFT求凸包距离，但没有列出具体泛函和软件；领域常用PBE泛函与PAW赝势作为默认配置，实际参数应查阅论文Methods。

# common_modification_points
使用者可按需在下述位置修改流程：1）扩展或替换过渡金属池和X元素，迁移到其他二维层状碳化物/氮化物的稳定性筛查；2）增删表面官能团，论文只覆盖了单一种类终止，可增加混合终止或部分覆盖率来贴近真实实验条件；3）更换更高阶的电子结构方法，如DFT+U、杂化泛函或RPA，修正强关联体系的能量偏差；4）扩充竞争相数据库，纳入更多MAX相或析出物参考能量，使凸包相图更完整；5）把稳定性指标从凸包距离换为分解自由能或考虑电化学条件。论文结论提示T池的变化通常比M池对稳定性影响更复杂且有决定性，因此修改终止组合是一个高度杠杆化的变量。

# implementation_risks
主要风险来自DFT系统误差和结构模型的不完整。凸包距离的量级常常只有几十meV/atom，若k点密度、截断能、力的收敛不够，边缘候选会被错误排序；建议先在代表性结构上做收敛测试。含d/f电子的过渡金属磁性构型可能显著改变总能量，需要测试不同磁序或使用DFT+U。表面终止覆盖构型枚举不足时，漏掉低能排列会人为抬高凸包距离，使本应稳定的MXene被判为不稳定。此外，MXene中的空位、层间堆垛等缺陷未在简单模型中考虑，会引入约几十meV/atom的不确定性；最终把结果交给实验前应评估这些误差范围。

# code_references
源论文发表在Chemistry of Materials，DOI为10.1021/acs.chemmater.4c02274；Abstract和正文给出方法学与结果列表，但没有公开官方代码仓库。论文的Methods或Supporting Information应包含具体的DFT代码版本、泛函选择、k点与截断能等细节，复现时需以原文为准。如果希望采用类似的自动化流程，可在开源框架pymatgen和atomate基础上搭建结构生成、DFT投递与凸包分析，再结合Materials Project提供的相图数据实现该筛选管线的可重复版本。
