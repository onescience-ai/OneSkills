# 锂金属电池operando µCT图像分析

## 适用范围
用于对电化学能量存储器件（尤其是涉及锂金属沉积/剥离过程的可充电电池）进行 operando X 射线微计算机断层扫描（µCT）数据的处理与分析。典型触发场景包括：需要在电池运行过程中无损、动态地观察电极内部三维结构演化；需要定量追踪锂枝晶生长、锂金属沉积/再沉积、孔洞形成等微观过程；需要分析这些过程与电池膨胀、容量衰减之间的关联。该方法适用于从数十 GB 的原始体数据中，自动、高精度地提取特定组分的空间分布与定量指标。

## 输入
- **必需输入**：
  - 原始 µCT 投影数据（raw projection data）：一次完整 operando 扫描产生的海量数据集（可达数十 GB）。
  - 初始少量手写标注数据（initial labels）：用于启动迭代训练过程的二维切片标注。这些标注是模型学习的种子，无需覆盖所有成分或达到完美精度。
- **可选输入**：
  - 先验结构信息（如已知的电极、隔膜、集流体大致位置）：可辅助 ROI 选取和模型训练。
  - 预训练权重：如果对相同材料体系有先前分割模型，可用于加速训练。

## 输出
- **重建后的三维灰度图像堆栈**：从原始投影数据重建得到的体素化三维图像。
- **语义分割结果**：对每个时间点三维图像进行体素级分类的结果图，通常包含五类：枝晶、凹坑（孔洞）、沉积锂、再沉积锂和背景。
- **定量分析数据集**：基于分割结果计算得到的各种物理量，包括但不限于：各成分的体积分数随时间的变化曲线、有效电极厚度变化、各成分的空间相关性分析等。

## 流程节点
1.  **图像预处理与重建 (s1)**
    -   **描述**：将采集到的原始二维投影数据通过断层重建算法转换为三维灰度图像堆栈。
    -   **依赖**：无（起始步骤）。
    -   **核心输入**：`projection_data`（原始投影数据，`str` 类型，必需）。
    -   **核心输出**：重建后的多 GB 体素图像堆栈。
    -   **质量门**：重建图像需清晰展现电池的宏观与微观结构，无明显伪影。
    -   **提示词模板**：使用 TomoPy 库，采用 Gridrec 算法进行重建。典型采集参数为 27.5 keV 能量，100 ms 曝光时间，在 180° 旋转下采集 1500 个投影。

2.  **图像对齐与配准 (s2)**
    -   **描述**：对不同时间点（operando 扫描的不同阶段）获得的三维图像堆栈进行空间对齐，确保相同体素位置对应电池的同一物理空间。
    -   **依赖**：s1（需要所有时间点的重建图像）。
    -   **核心输出**：对齐后的多时间点图像堆栈。
    -   **质量门**：对齐后，不同时间点图像中的刚性结构（如集流体、隔膜）在空间上应重合。

3.  **选择感兴趣区域 (s3)**
    -   **描述**：从巨大的对齐后数据集中，选取一个具有代表性且包含所有目标锂相关成分的三维子集（ROI）进行后续分析，以降低计算负担。
    -   **依赖**：s2（需要对齐后的图像）。
    -   **核心输出**：选定的 ROI 三维子集。
    -   **质量门**：ROI 必须包含分析所关注的所有类别的结构（如枝晶、孔洞、锂沉积物）。

4.  **模型迭代训练与分割 (s4)**
    -   **描述**：采用迭代残差 U-Net 架构，通过一个自举式的迭代训练过程，实现多类别语义分割。训练过程从少量不完美的初始标签开始，逐步扩展和优化。
    -   **依赖**：s3（需要 ROI 图像）、初始手写标注数据。
    -   **核心输入**：`initial_labels`（初始少量手写标签，`str` 类型，必需）。
    -   **核心输出**：对每个时间点 ROI 图像的五类语义分割结果。
    -   **质量门**：最终模型在独立测试集上需达到高精度（如测试精度 98.8%，总体 IoU 95.5%）。
    -   **提示词模板**：采用迭代训练策略：
        1.  使用少量 2D 面内切片标注，训练初始模型分割“凹坑”、“锂（沉积/再沉积合并）”和“背景”。
        2.  利用初始模型的预测结果作为起点，进行更多、更精细的标注。
        3.  将“沉积锂”和“再沉积锂”等需要精细区分的类别，分别作为二分类问题训练专门的子模型。
        4.  最终，使用少量高质量的跨截面标签（如 42 张）训练并优化得到最终的多类别分类模型。
    -   **训练参数**：典型划分：72% 训练集，13% 验证集，15% 测试集。训练停止条件：训练时间达 1 小时或验证精度在 10 次迭代内未提升。训练在高性能计算节点（如配备 4 块 GPU 的节点）上使用 PyTorch 框架的分布式数据并行功能进行。

5.  **后处理与定量分析 (s5)**
    -   **描述**：对分割结果进行必要的平滑、去噪或形态学操作，然后基于分类体素计算各种定量指标。
    -   **依赖**：s4（需要分割结果）。
    -   **核心输出**：各锂相关成分的体积变化曲线、有效电极厚度变化曲线、空间分布热图及相关性分析图等。
    -   **质量门**：定量结果应能合理、连贯地反映电池循环过程中锂沉积/剥离的动态过程和电池的体积膨胀/收缩现象。

## 边界与分流
- **适用边界**：本方法专门针对基于 X 射线 µCT 的 operando 三维成像数据。对于二维表征技术（如 SEM、光学显微镜）或非断层扫描的三维技术（如 MRI），流程不适用。
- **模型替代**：虽然流程以迭代残差 U-Net 为核心，但其他先进的 3D 语义分割模型（如 V-Net、SegNet 的 3D 变体）也可替换，但可能需要调整训练策略和参数。
- **材料体系迁移**：当应用于新的电池材料体系时，初始标注数据和模型需要重新建立或迁移学习。校准参数（如 X 射线能量）需根据材料元素的衰减特性重新设定。
- **上游依赖**：上游必须提供可重建的 µCT 原始投影数据。如果仅有已重建的图像，则从步骤 s2 开始执行。
- **下游衔接**：分割与定量分析的结果可直接用于电化学性能关联分析、有限元模拟的几何建模输入，或作为数据集用于训练更通用的电池图像分割模型。

## 回退策略
- **初始标签质量不佳**：如果初始模型性能很差，应退回步骤 s4，增加初始标注的数量或质量，或简化初始分类任务（例如先只分“锂”与“背景”）。
- **分割精度低（尤其针对低频类别如枝晶）**：这可能是由于类别不平衡导致。回退策略包括：1) 在损失函数中加入类别权重；2) 使用数据增强（如旋转、缩放）增加稀有类别的样本多样性；3) 采用更复杂的采样策略。
- **图像对比度差导致分割困难**：这通常是锂金属 X 射线衰减弱的物理限制。回退策略包括：1) 在重建阶段尝试不同的算法参数以优化对比度；2) 在 ROI 选取时专注于对比度相对较好的区域；3) 在模型训练时加入更多针对低对比度边界的标注。
- **计算资源不足**：对于超大规模数据，若单节点训练不可行，可回退并采用：1) 更激进的 ROI 选取策略，减小数据体积；2) 使用混合精度训练；3) 寻求分布式计算资源。

## 资源召回建议
- **核心工具**：
    - **TomoPy**：用于断层图像重建。
    - **batteryNET**：开源的迭代训练与分割代码库（https://github.com/lbl-camera/batteryNET）。
    - **PyTorch**：深度学习框架。
- **辅助工具**：
    - **Fiji / ImageJ**：常用于图像预览、简单的后处理和可视化。
    - **ORS Dragonfly 或 Avizo**：商业软件，用于高级三维可视化、分析和分割结果的交互式验证。
- **计算环境**：需要配备 GPU 的高性能计算节点，用于加速模型训练和推理。
- **数据管理**：由于数据量巨大，需要有效的存储和 I/O 策略，例如使用并行文件系统或分块存储格式。
