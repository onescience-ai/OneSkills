# CO2光催化阴极材料计算筛选与发现工作流

## 适用范围

用于从大型、非特异性的固态材料数据库（如包含数万种无机化合物的集合）中，通过高通量第一性原理计算，系统性筛选出潜在的二氧化碳（CO₂）光催化还原阴极材料。该流程旨在快速识别兼具热力学（亚）稳定性、可见光吸收能力以及在水相电解质中电化学稳定性的材料候选。其核心是一系列基于材料固有物理化学性质的、可顺序执行的计算筛选判据，具有较强的通用性，可为其他需要多条件约束的材料发现任务（如光阳极、电催化剂筛选）提供方法论参考。

## 输入

- **必需输入**：
    - 初始材料候选库。该库应包含材料的化学式、晶体结构（CIF 或 POSCAR 格式）以及初步的形成能等数据。来源通常为综合性材料数据库，例如Materials Project或无机晶体结构数据库（ICSD）。
    - 进行第一性原理计算（如密度泛函理论，DFT）的能力及相关软件环境。
- **可选输入**：
    - 预计算的PBE泛函下的电子结构数据（用于带隙初筛）。
    - 高精度计算资源（用于执行杂化泛函如HSE06计算）。
    - 相关的Pourbaix图热力学数据，或用于生成该数据的离子溶解能等参数。

## 输出

- **主要输出**：
    - 经过多层筛选后保留的材料列表，包含其化学式、晶体信息及各项筛选判据的数值。
    - 最终通过高精度计算验证的、带边对齐适合CO₂还原的候选材料列表。
- **辅助输出**：
    - 每一层筛选后剩余的材料数量，用于监控筛选进程。
    - 与已知光催化阴极材料的对比分析报告，用于验证筛选策略的有效性。

## 流程节点

该工作流是一个由多个计算步骤构成的有向无环图（DAG），每个步骤依赖于前序步骤的输出。具体步骤如下：

1.  **材料候选库构建 (s1)**
    - **描述**：从Materials Project、ICSD等数据库获取初始材料列表。该列表是筛选的起点，其广度与质量直接影响最终发现。
    - **上游依赖**：无。
    - **质量门**：材料来源可靠，数据完整（包含结构与能量信息）。

2.  **热力学稳定性筛选 (s2)**
    - **描述**：通过计算材料能量高于其组分相凸包的能量差（ΔEₕᵤₗₗ）来评估热力学稳定性。ΔEₕᵤₗₗ越低，材料越稳定或越接近稳定，实验合成的可能性越高。
    - **上游依赖**：s1。
    - **输入参数**：
        | 参数名 | 类型 | 默认值/范围 | 说明 |
        | :--- | :--- | :--- | :--- |
        | `delta_Ehull` | float | ≤ 80 meV/atom | 低于此阈值表示亚稳或稳定，是可合成性的初步判据 |
    - **质量门**：通过筛选的材料必须满足 ΔEₕᵤₗₗ ≤ 80 meV.atom⁻¹。

3.  **可见光吸收筛选 (s3)**
    - **描述**：选择带隙范围适合吸收可见光的材料。由于标准PBE泛函通常低估带隙（约40%），因此设定的筛选范围需考虑此系统误差，以确保最终材料的实际带隙位于理想的太阳光谱吸收区间（约1.7 eV - 3.0 eV）。
    - **上游依赖**：s2。
    - **输入参数**：
        | 参数名 | 类型 | 默认值/范围 | 说明 |
        | :--- | :--- | :--- | :--- |
        | `bandgap_PBE` | float | 1.0 eV - 2.5 eV | 此PBE带隙范围对应经误差校正后约1.7-3.0 eV的实际带隙 |
    - **质量门**：通过筛选的材料PBE计算带隙必须在1.0 eV至2.5 eV之间。

4.  **电化学稳定性筛选 (s4)**
    - **描述**：评估材料在水相环境中的电化学稳定性，防止其在催化反应条件下发生氧化或还原分解。此步骤通常基于计算Pourbaix图（E-pH图）的简化判据，如材料表面氧化或还原的吉布斯自由能变化（ΔGₚᵦₓ）。
    - **上游依赖**：s3。
    - **输入参数**：
        | 参数名 | 类型 | 默认值/范围 | 说明 |
        | :--- | :--- | :--- | :--- |
        | `delta_Gpbx` | float | ≤ 0.2 eV/atom | 低于此阈值表明在宽广的电位-pH窗口内稳定 |
    - **质量门**：通过筛选的材料必须满足 ΔGₚᵦₓ ≤ 0.2 eV.atom⁻¹。

5.  **计算成本筛选 (s5)**
    - **描述**：由于后续高精度计算（如HSE06）极其耗时，此步骤根据体系大小、原子数等估算计算成本，选择一个在可用资源内可处理的子集进行下一步。
    - **上游依赖**：s4。
    - **质量门**：筛选出的材料数量在计算资源可承受的范围内。

6.  **高精度电子结构计算 (s6)**
    - **描述**：对筛选出的材料子集，使用计算成本更高的杂化泛函（如HSE06）进行电子结构计算，以获得更准确的带隙值和带边位置。
    - **上游依赖**：s5。
    - **质量门**：获得收敛的、可靠的能带结构和态密度数据。

7.  **带边对齐评估 (s7)**
    - **描述**：根据高精度计算结果，检查材料的导带最小值（CBM）和价带最大值（VBM）是否满足CO₂还原的热力学与动力学要求。CBM需足够负（高能量）以驱动还原反应，VBM需足够正（低能量）以驱动水氧化等阳极反应。
    - **上游依赖**：s6。
    - **质量门**：CBM位置高于CO₂还原电位，VBM位置低于（或适合）水氧化电位。

8.  **文献对比验证 (s8)**
    - **描述**：将筛选流程应用于已知的光催化阴极材料，验证该方法能否成功“复现”它们，以此评估整个筛选策略的可靠性和预测能力。
    - **上游依赖**：s7。
    - **质量门**：预测结果与已知材料的实验或公认计算数据吻合良好。

## 边界与分流

- **适用边界**：本流程主要针对固态无机晶体材料的大规模初筛。它假设材料性质可通过周期性边界条件下的DFT计算合理描述。
- **不适用情况**：
    - **分子催化剂或液相体系**：本流程基于固体物理模型，不直接适用于离散分子催化剂或均相催化体系。
    - **表面重构与动态过程**：初始筛选基于体相性质，对于表面催化反应中可能发生的重构、吸附、反应路径等动态过程，需要额外的表面计算或动力学模拟。
    - **资源极度受限场景**：若完全无法进行高精度计算（步骤s6），则仅能提供基于PBE带隙的初步候选，其预测的准确性会显著降低。
- **上下游衔接**：
    - **上游**：需要接入标准化的材料数据库接口。
    - **下游**：最终候选材料需进入更精细的催化活性计算（如吸附能、反应能垒计算）或直接进入实验合成与测试阶段。

## 回退策略

根据潜在的失败模式，可采取以下应对措施：

- **问题**：电化学稳定性筛选过于严格，排除了潜在材料。
    - **策略**：可适当放宽ΔGₚᵦₓ阈值（如增至0.25 eV.atom⁻¹），或采用更精确、更耗时的全Pourbaix图计算方法对边缘材料进行复核。
- **问题**：计算资源不足，无法完成所有高精度计算。
    - **策略**：采用更激进的成本筛选（s5），减少待计算材料数量；或采用计算量较低的替代方法（如扫描电子结构数据库）进行初步验证。
- **问题**：高精度计算结果与PBE筛选结果不一致（如带隙反转）。
    - **策略**：将不一致的材料单独列出进行深入分析，可能揭示了PBE筛选的局限性，这些材料本身也可能具有研究价值。
- **问题**：最终筛选出的候选材料在实验中合成失败或性能不佳。
    - **策略**：回溯检查各层筛选判据的适用性，特别是电化学稳定性判据可能未考虑实际电解液中的离子吸附或表面钝化效应，需引入更复杂的计算模型进行复核。

## 资源召回建议

- **核心数据库**：Materials Project（提供初步结构与热力学数据）、ICSD（无机晶体结构库）。
- **计算软件**：第一性原理计算包（如VASP、Quantum ESPRESSO）、自动化工作流与数据库管理工具（如Fireworks、AiiDA、Atomate2）。
- **分析工具**：Pymatgen（用于凸包计算、Pourbaix图生成、能带结构分析）、ASE（原子模拟环境，用于结构操作）。
- **关键概念参考**：凸包能量（Energy Above Hull）、Pourbaix图（E-pH diagram）、杂化泛函（Hybrid Functionals）。
