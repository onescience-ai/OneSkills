# 材料候选组成生成方法

## 适用范围
本知识卡片适用于材料筛选任务中化学组成的生成和约束，确保候选材料具有合法的化学式、可合成的晶体结构、以及在目标材料体系范围内的组成空间。

## 输入
- 目标材料体系描述（元素组合、化学计量比范围）
- 晶体结构原型信息（空间群、 Wyckoff位置）
- 约束条件（电中性、价态平衡、化学计量比限制）

## 输出
- 合法的化学式列表
- 对应的晶体结构原型
- 组成空间覆盖分析

## 流程节点
1. **组成空间定义** → 2. **约束条件设置** → 3. **候选生成** → 4. **合法性检查** → 5. **结构原型匹配**

### 步骤1：组成空间定义
- **操作**：定义候选材料的元素组合和化学计量比范围
- **参数**：元素列表、化学计量比范围、电荷平衡要求
- **工具**：pymatgen、自定义脚本
- **质量门禁**：组成空间定义合理，覆盖目标体系

### 步骤2：约束条件设置
- **操作**：设置化学和物理约束
- **参数**：电中性、价态平衡、原子半径比、电负性差
- **工具**：化学知识库、规则引擎
- **质量门禁**：约束条件有科学依据

### 步骤3：候选生成
- **操作**：在约束条件下生成候选组成
- **参数**：生成算法、采样策略、多样性要求
- **工具**：组合优化、随机采样
- **质量门禁**：候选数量满足需求，多样性足够

### 步骤4：合法性检查
- **操作**：验证候选组成的化学合法性
- **参数**：价态检查、电荷平衡、化学计量比
- **工具**：化学规则验证
- **质量门禁**：所有候选通过合法性检查

### 步骤5：结构原型匹配
- **操作**：将候选组成匹配到已知晶体结构原型
- **参数**：空间群、Wyckoff位置、离子半径
- **工具**：pymatgen、晶体结构数据库
- **质量门禁**：匹配成功率>80%

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 电中性要求 | 总电荷=0 | [1] | 化学基本要求 |
| 价态平衡 | 氧化态代数和=0 | [1] | 化合物稳定性要求 |
| 化学计量比范围 | 1:1至1:4 | [2] | 常见材料体系范围 |

### 校准数值（来自具体体系）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 钙钛矿ABX3 | A:B:X = 1:1:3 | [2] | 典型晶体结构原型 |
| 尖晶石AB2X4 | A:B:X = 1:2:4 | [2] | 另一种常见原型 |

## 边界与分流
- **组成空间过大**：当候选数量>10000时，使用采样或机器学习筛选
- **约束条件冲突**：当无合法候选时，放宽约束或调整体系
- **结构匹配失败**：当匹配率<50%时，考虑新结构原型或无序结构

## 质量检查
- 化学式合法性验证
- 晶体结构原型匹配度评估
- 组成空间覆盖率分析
- 候选多样性评估

## 回退策略
- 候选生成失败时，检查约束条件或调整参数
- 结构匹配失败时，尝试替代结构原型
- 合法候选不足时，扩展元素范围或放宽约束
