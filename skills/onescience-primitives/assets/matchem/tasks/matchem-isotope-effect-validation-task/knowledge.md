# 同位素效应验证

## 适用范围
触发条件：在分子动力学模拟后，需要验证同位素效应，特别是涉及碳同位素（12C/13C）对比实验时。
适用场景：任何需要验证同位素效应的MD模拟任务。
不适用场景：已验证同位素效应且结论可靠的任务。

## 输入
- 12C和13C的模拟轨迹
- 扩散系数计算结果
- 统计检验数据
- 物理预期（质量效应预期）

## 输出
- 同位素效应验证报告（包含统计检验结果、物理合理性分析、限制条件说明）
- 验收判定（是否检测到同位素效应）
- 后续采样建议

## 流程节点
1. 扩散系数计算 → 2. 统计显著性检验 → 3. 物理合理性分析 → 4. 验收判定 → 5. 生成验证报告

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 质量效应预期 | 13C扩散系数应低于12C | 物理原理 | 同位素质量越大，扩散越慢 |
| 统计显著性检验 | t检验/ANOVA | 统计学标准 | p值<0.05认为显著 |
| 短时动力学与长时动力学关系 | 短时结果不能过度解释 | MD模拟标准 | 需要足够长时间验证 |
| 验收判定标准 | 基于真实模拟数据 | MD模拟标准 | 不能基于mock数据 |

## 边界与分流
- 扩散系数趋势与物理预期相反：标记为异常，检查模拟设置
- 统计检验不显著：标记为待确认，增加模拟时间
- 基于mock数据：标记为无效，需要真实模拟数据

## 质量检查
- 扩散系数计算必须正确
- 统计检验必须显著
- 物理合理性必须分析
- 验收判定必须基于真实数据

## 回退策略
- 验证失败：增加模拟时间或检查模拟设置
- 统计检验不显著：增加样本量或延长模拟时间
