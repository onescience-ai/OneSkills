# 多孔材料基础模型构建任务

## 适用范围
本卡片服务于构建多孔材料（金属有机框架MOF、沸石、多孔碳等）图神经网络基础模型的任务，用于原子级结构表示学习、性质预测（吸附容量、选择性、稳定性等）和跨体系迁移学习。

## 输入
- 多孔材料原子结构数据：晶体结构文件（CIF、POSCAR）、原子坐标、晶格参数
- 性质标签：吸附等温线、选择性系数、力学性质、热力学性质
- 数据来源：Materials Project、ICSD、QMOF、CSD等数据库

## 输出
- 预训练基础模型权重（支持微调下游任务）
- 模型评估报告：在标准测试集上的性能指标（MAE、RMSE、R²等）
- 迁移学习示范：在目标性质上的微调结果

## 流程节点

### 1. 数据准备
- **操作**：从公开数据库下载多孔材料结构数据，提取原子特征和图表示
- **参数**：截断半径4-6Å，原子特征维度64-256，图构建方法（半径图/KNN图）
- **工具**：pymatgen、ASE、DGL/PyG图构建工具
- **质量门禁**：数据去重、结构合理性检查、标签完整性验证

### 2. 模型架构选择
- **操作**：根据任务需求选择合适的图神经网络架构
- **参数**：见关键参数表
- **工具**：MACE、SchNet、DimeNet、NequIP、 PaiNN等
- **质量门禁**：架构与任务匹配性验证

### 3. 预训练
- **操作**：在大规模无标签或多任务标签数据上进行预训练
- **参数**：学习率1e-4~1e-3，batch size 32-128，预训练轮次100-500
- **工具**：PyTorch、PyTorch Lightning
- **质量门禁**：训练损失收敛、验证集性能稳定

### 4. 微调与评估
- **操作**：在目标下游任务上微调预训练模型
- **参数**：微调学习率1e-5~1e-4，冻结层数可选
- **工具**：scikit-learn、自定义评估脚本
- **质量门禁**：测试集性能达到baseline水平

## 关键参数

### 通用判据（方法层）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 图神经网络类型 | 等变GNN优先 | [1] | SchNet/DimeNet/MACE等能处理3D结构信息 |
| 原子特征维度 | 64-256 | [1] | 平衡表达能力与计算效率 |
| 截断半径 | 4-6 Å | [1] | 覆盖第一、二配位壳层 |
| 消息传递轮次 | 3-6轮 | [1] | 捕获长程相互作用 |
| 预训练目标 | 多任务学习 | [1] | 能量+力+应力联合预测 |

### 校准数值（多孔材料体系）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| MOF结构截断 | 最大500原子 | [1] | 平衡计算成本与结构完整性 |
| 吸附预测任务 | GCMC模拟数据 | [2] | 作为预训练或微调目标 |
| 标准测试集 | QMOF-20k | [1] | 用于模型性能基准比较 |

## 边界与分流
- **结构柔性MOF**：需考虑框架呼吸效应，建议使用可变形图或分子动力学轨迹增强训练数据
- **高温/高压条件**：需在训练数据中覆盖极端条件，或使用物理约束损失函数
- **小样本场景**：预训练+微调策略可缓解数据不足，但需确保预训练数据与目标任务分布相似

## 质量检查
- **结构合理性**：检查原子间最小距离>0.5Å，无重叠原子
- **模型可迁移性**：在不同MOF子类（IRMOF、ZIF、UiO等）上测试泛化能力
- **计算效率**：推理时间随体系大小线性增长

## 回退策略
- 若GNN架构性能不足，可尝试：(1) 增加训练数据量；(2) 引入物理先验（如周期性边界条件）；(3) 使用集成学习方法
