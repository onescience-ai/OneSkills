# 材料科学任务中数据可追溯性要求

## 适用范围
适用于材料科学研究中的数据管理和验证。当使用材料结构数据、性能数据或计算结果时，必须确保数据来源可追溯，避免使用假设数据或典型值作为正式结论依据。

## 输入
- 材料结构数据（CIF/POSCAR文件）
- 性能数据（离子电导率、电化学窗口等）
- 数据来源信息（Materials Project编号、ICSD编号、文献DOI）
- 验证标准（数据完整性、来源可靠性）

## 输出
- 数据来源验证报告
- 可追溯性声明
- 数据质量评估
- 正式结论（基于可追溯数据）

## 流程节点
1. 识别所需数据的类型和来源要求
2. 检查数据是否来自权威数据库（Materials Project、ICSD）
3. 验证数据来源的完整性和准确性
4. 标注数据来源和测量条件
5. 评估数据质量（精度、可靠性）
6. 生成数据可追溯性报告

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 结构数据来源优先级 | 用户上传 > Materials Project API > ICSD > 文献提取 | 最佳实践 | 优先使用最高优先级来源 |
| Materials Project编号格式 | MP-xxxx | Materials Project数据库 | 每个材料有唯一编号 |
| ICSD编号格式 | ICSD-xxxx | ICSD数据库 | 国际晶体结构数据库编号 |
| 文献DOI格式 | 10.xxxx/xxxxx | 学术文献 | 可追溯的文献标识符 |
| 假设数据使用限制 | 仅用于方法验证，不能作为正式结论 | 数据管理规范 | 必须明确标注数据性质 |

## 边界与分流
- 当数据来自用户上传时，需验证用户数据的可靠性
- 当数据来自Materials Project时，需验证MP编号的有效性
- 当数据来自ICSD时，需验证ICSD编号的有效性
- 当数据来自文献时，需验证文献的权威性和时效性
- 当数据为假设值或典型值时，必须明确标注且不作为正式结论依据

## 质量检查
- 验证所有材料结构数据包含权威来源标识
- 检查性能数据是否标注具体文献来源和测量条件
- 确认假设数据或典型值已明确标注
- 验证数据可追溯性报告完整性

## 回退策略
- 如果数据来源不可靠，应寻找替代数据源
- 如果数据不完整，应补充缺失信息
- 如果数据存在冲突，应进行交叉验证或寻求专家意见
- 如果无法获取可靠数据，应明确标注数据局限性

## 资源召回建议
- 当需要获取Materials Project数据时，召回Materials Project API相关知识
- 当需要获取ICSD数据时，召回ICSD数据库相关知识
- 当需要验证文献权威性时，召回学术文献评估相关知识
- 当需要管理数据来源时，召回数据管理最佳实践相关知识
