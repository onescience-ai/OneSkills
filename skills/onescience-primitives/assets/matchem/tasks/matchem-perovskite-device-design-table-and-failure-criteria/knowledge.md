# 钙钛矿太阳能电池器件设计表与失效判据标准

## 适用范围
本卡片适用于平面钙钛矿太阳能电池的器件设计阶段，提供标准化的器件设计表格式和失效判据制定方法。适用于研究规划、实验设计和性能评估。

## 输入
- 钙钛矿太阳能电池的层结构信息（如ETL/钙钛矿/HTL/电极）
- 材料组成（如钙钛矿组分、传输层材料）
- 面积和厚度参数
- 稳定性测试条件（如ISOS标准）

## 输出
- 标准化的器件设计表（包含层序、面积、材料组成、厚度等）
- 失效判据文档（包含效率衰减阈值、寿命指标、测试条件）

## 流程节点
1. 确定器件结构（n-i-p或p-i-n）
2. 定义各层材料及参数
3. 设计器件设计表格式
4. 选择ISOS稳定性测试标准
5. 制定失效判据（如PCE保持率>80%为通过）
6. 验证设计表完整性

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 器件结构 | p-i-n或n-i-p | [论文1] | 根据研究需求选择 |
| 钙钛矿层厚度 | 300-500 nm | [论文1] | 典型值 |
| 面积 | 0.1-1 cm² | [论文1] | 实验室规模 |
| 效率衰减阈值 | <20% after 1000h | [论文1] | ISOS-L-1标准 |
| 测试条件 | 85°C, 85% RH | [论文1] | 加速老化条件 |

## 边界与分流
- 若缺乏ISOS标准参考，可采用文献常用条件
- 若器件结构特殊，需调整设计表字段
- 若稳定性测试数据不足，可设置保守阈值

## 质量检查
- 设计表是否包含所有必要字段（层序、面积、材料、厚度）
- 失效判据是否明确（阈值、测试条件、判断标准）
- 是否引用相关标准（如ISOS）
