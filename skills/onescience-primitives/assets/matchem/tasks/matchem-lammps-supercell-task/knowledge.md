# LAMMPS超胞构建

## 适用范围
触发条件：在分子动力学模拟前，需要构建合适的超胞，特别是涉及表面模型（如Cu(111)）时。
适用场景：任何需要构建周期性边界条件超胞的MD模拟任务。
不适用场景：已构建超胞且验证通过的任务。

## 输入
- 晶体结构文件（POSCAR/data格式）
- 表面切割参数（Miller指数、层数）
- 超胞尺寸参数（扩胞矩阵）
- 固定原子组设置（底部原子固定）

## 输出
- 超胞结构文件（LAMMPS data格式）
- 原子类型映射文件
- 固定原子组定义文件
- 超胞构建报告

## 流程节点
1. 晶体结构解析 → 2. 表面切割 → 3. 超胞扩胞 → 4. 元素映射 → 5. 固定原子组设置 → 6. 生成超胞文件

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 三斜晶胞参数 | a, b, c, α, β, γ | 晶体结构 | 根据Miller指数计算 |
| 元素映射规则 | 原子类型与力场对应 | 力场文件 | 每个原子类型对应一个力场 |
| 固定原子组设置 | 底部两层原子固定 | 标准要求 | Cu(111)表面模型常用 |
| Cu(111) 3×3超胞 | 288个Cu原子 | 标准要求 | 4层×3×3×2=72个Cu原子（FCC基元每个晶胞2个原子） |

## 边界与分流
- 晶体结构缺失：标记为异常，要求提供结构文件
- 元素映射错误：标记为待确认，不作为正式输入
- 固定原子数不符：标记为异常，要求重新构建

## 质量检查
- 超胞尺寸必须符合标准要求
- 元素映射必须正确
- 固定原子组必须设置正确
- 晶胞参数必须准确

## 回退策略
- 超胞构建失败：暂停任务，请求用户提供正确结构
- 元素映射错误：标记并报告，不使用错误映射
