# 金属中扩散系数的物理合理范围和温度依赖关系

## 适用范围
金属中扩散系数的物理合理范围和温度依赖关系（Arrhenius关系），包括晶格扩散、晶界扩散和界面扩散的典型数量级，以及扩散系数随温度变化的单调性要求。

## 输入
- 金属材料类型（bcc、fcc等）
- 温度范围
- 扩散机制（晶格扩散、晶界扩散、界面扩散）

## 输出
- 扩散系数的物理合理范围
- 温度依赖性（Arrhenius关系）
- 扩散系数的单调性要求

## 流程节点
1. 确定金属材料类型和晶体结构
2. 识别扩散机制（晶格扩散、晶界扩散、界面扩散）
3. 查询或计算扩散系数的典型数量级
4. 验证Arrhenius关系的温度依赖性
5. 检查扩散系数随温度变化的单调性
6. 标记异常数据

## 关键参数
### 通用判据（方法层）

## 边界与分流
- 当扩散系数超出物理合理范围时：标记REJECT并说明异常
- 当温度-扩散系数关系不单调时：标记REJECT并说明违反Arrhenius关系
- 当扩散系数数量级异常时：标记PARTIAL并说明可能原因

## 质量检查
- 验证扩散系数在物理合理范围内
- 验证温度-扩散系数关系的单调性
- 验证Arrhenius关系的正确性

## 回退策略
- 如果扩散系数数据缺失，使用文献中的典型值
- 如果Arrhenius关系不成立，考虑非Arrhenius行为的可能性
