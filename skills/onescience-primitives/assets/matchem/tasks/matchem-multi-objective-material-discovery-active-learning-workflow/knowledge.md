# 多目标材料发现的主动学习工作流

## 适用范围
本卡片服务于多目标材料发现任务，旨在通过主动学习策略高效探索设计空间，识别Pareto最优材料集合，同时处理多目标之间的权衡、缺失数据和模型不确定性。适用于需要同时优化多个竞争性材料性能（如强度与韧性、吸附能力与选择性）的场景，尤其当实验或模拟资源有限时。

## 输入
- 设计空间定义：材料组成、结构或工艺参数的范围与约束。
- 目标函数：需要优化的多个性能指标（如吸附自由能、机械强度、电导率）。
- 初始数据集：少量初始样本（可通过设计实验或随机采样获得）。
- 不确定性量化需求：是否需要对预测不确定性进行量化以指导采样。

## 输出
- Pareto最优材料集合：在多目标空间中无法被其他材料同时优化的所有材料。
- 代理模型：训练好的高斯过程回归（GPR）或其他不确定性量化模型，用于预测新样本的性能及不确定性。
- 采样序列：主动学习迭代中推荐评估的材料列表。
- 结构-性能关系洞察：通过特征重要性分析（如SHAP）揭示的关键材料特征。

## 流程节点
1. **设计空间采样** → 使用设计实验（DoE）或随机采样生成初始材料集合。
2. **模型初始化** → 基于初始样本训练代理模型（如高斯过程回归），支持多输出核心化模型以处理缺失数据。
3. **主动学习循环**：
   a. **分类** → 基于模型预测均值和不确定性构建超矩形，利用ϵ-Pareto支配关系将材料分类为“可丢弃”、“Pareto最优”或“待定”。
   b. **采样选择** → 从待定材料中选择具有最大不确定性（如超矩形面积）的样本进行评估。
   c. **评估** → 通过实验或模拟获取所选材料的真实目标值。
   d. **模型更新** → 将新数据加入训练集，重新训练模型。
4. **终止条件** → 当所有材料被分类或达到预定精度（如超体积误差≤ϵ）时停止。
5. **后处理** → 提取最终Pareto最优集合，分析结构-性能关系，可选进行逆设计验证。

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| ϵ容差 | 0.01-0.1 | [1] | 控制Pareto front近似精度，ϵ越大分类越快但精度越低 |
| 初始样本大小 | 60 | [1] | 用于初始化GPR模型的样本数，需覆盖设计空间多样性 |
| 核心化GPR秩 | 1 | [1] | 多输出模型的复杂度，秩1通常足够且更稳定 |
| 不确定性度量 | 变异系数 | [1] | 使用预测均值归一化的不确定性，用于超矩形构建 |
| 采样策略 | 最大不确定性 | [1] | 选择超矩形面积最大的待定样本进行评估 |
| 特征化方法 | 单体序列统计 | [1] | 包括聚合度、序列熵、端基类型等 |

## 边界与分流
- 当目标函数噪声较大时：增大ϵ容差或增加初始样本量以稳定模型。
- 当缺失数据比例高时：使用核心化高斯过程模型利用目标间相关性进行预测。
- 当设计空间维度极高时：考虑降维或使用更高效的特征表示。
- 当计算资源极度受限时：可采用批量采样策略减少迭代次数。

## 质量检查
- 超体积误差：定期计算当前Pareto front近似与真实front的超体积比，确保收敛至目标精度。
- 分类准确性：监控可丢弃材料比例，确保算法有效减少设计空间。
- 模型性能：评估GPR模型在留出集上的预测误差，确保泛化能力。

## 回退策略
- 若主动学习收敛过慢：增加ϵ容差或采用多保真度建模。
- 若模型不确定性估计不准：切换至集成方法或贝叶斯神经网络。
- 若初始采样不足：补充基于多样性的采样（如最远点采样）。
