# 钝化方案优先级评估与独立复核

## 适用范围
本卡片适用于钙钛矿太阳能电池钝化方案的优先级评估和独立复核，包括多目标决策分析、敏感性分析和验证标准。适用于方案筛选、优化和验证。

## 输入
- 候选钝化方案列表（如不同分子、不同浓度）
- 性能指标（PCE、稳定性、成本）
- 敏感性分析参数（如温度、光照强度）

## 输出
- 优先级排序的方案列表
- 敏感性分析结果（参数变化对性能的影响）
- 独立复核计划（计算验证、实验验证）

## 流程节点
1. 收集候选方案性能数据
2. 应用多目标决策方法（如TOPSIS、AHP）
3. 进行敏感性分析（蒙特卡洛模拟）
4. 制定独立复核条件（计算验证、实验验证）
5. 生成优先级列表和复核计划
6. 验证方案可行性

## 边界与分流
- 若性能数据不足，可采用机器学习预测
- 若计算资源有限，可简化敏感性分析
- 若实验验证困难，可采用计算验证

## 质量检查
- 优先级排序是否合理
- 敏感性分析是否覆盖关键参数
- 复核计划是否可行
