# VASP输入文件生成配置

## 适用范围
VASP在OneScience环境中的配置要求、调用方式和输入文件生成规则，包括INCAR参数设置、POSCAR构建、KPOINTS网格选择和执行命令格式。

## 输入
- 材料结构信息（POSCAR格式）
- 计算参数要求（如泛函、截断能、k点网格等）
- OneScience环境配置（conda环境、VASP可执行文件路径）

## 输出
- INCAR文件（输入参数）
- POSCAR文件（原子坐标）
- KPOINTS文件（k点网格）
- POTCAR文件（赝势）
- VASP执行日志

## 流程节点
1. 构建POSCAR文件（原子坐标、晶格参数）
2. 设置INCAR文件（泛函、截断能、电子步、离子步等）
3. 生成KPOINTS文件（k点网格密度）
4. 准备POTCAR文件（赝势选择）
5. 验证输入文件完整性
6. 执行VASP计算
7. 解析输出文件（OUTCAR、OSZICAR、CONTCAR）

## 边界与分流
- 当VASP环境不可用时：标记BLOCKED并说明缺失条件
- 当输入文件不完整时：标记REJECT并说明缺失文件
- 当计算不收敛时：标记PARTIAL并说明可能原因

## 质量检查
- 验证输入文件格式正确性
- 验证VASP执行日志完整性
- 验证输出文件解析正确性

## 回退策略
- 如果VASP环境不可用，使用替代DFT软件（如Quantum ESPRESSO）
- 如果输入文件生成失败，使用模板文件
