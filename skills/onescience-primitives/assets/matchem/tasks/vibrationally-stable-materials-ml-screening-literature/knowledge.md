# 振动稳定材料机器学习筛选文献综述

## 适用范围
本知识卡片适用于需要了解振动稳定材料机器学习筛选领域研究进展的任务，包括振动稳定性的定义、计算方法、已发表的筛选工作流、以及相关数据库的使用。

## 输入
- 研究问题描述（目标材料体系、筛选目标）
- 文献检索需求（时间范围、数据库、关键词）
- 知识提取需求（方法、数据、结论）

## 输出
- 相关研究论文列表
- 关键方法和技术总结
- 数据来源和工作流梳理
- 研究空白和未来方向分析

## 流程节点
1. **文献检索** → 2. **相关性筛选** → 3. **知识提取** → 4. **工作流梳理** → 5. **研究空白分析**

### 步骤1：文献检索
- **操作**：在学术数据库中检索相关文献
- **参数**：关键词、时间范围、数据库选择
- **工具**：OpenAlex、Semantic Scholar、WebSearch
- **质量门禁**：检索策略覆盖主要相关文献

### 步骤2：相关性筛选
- **操作**：筛选与研究问题最相关的文献
- **参数**：相关性评分、引用次数、期刊影响力
- **工具**：文献管理工具、筛选标准
- **质量门禁**：筛选标准一致，无主观偏见

### 步骤3：知识提取
- **操作**：从筛选后的文献中提取关键知识
- **参数**：方法、数据、结论、局限性
- **工具**：文本分析、LLM辅助提取
- **质量门禁**：知识提取准确，有文献支撑

### 步骤4：工作流梳理
- **操作**：梳理已发表的筛选工作流
- **参数**：工作流步骤、工具链、数据流
- **工具**：流程图、工作流图
- **质量门禁**：工作流描述完整，可复现

### 步骤5：研究空白分析
- **操作**：识别研究空白和未来方向
- **参数**：未解决问题、技术挑战、应用需求
- **工具**：综合分析、专家讨论
- **质量门禁**：研究空白有依据，未来方向合理

## 边界与分流
- **文献数量过多**：使用自动化筛选工具和LLM辅助
- **文献质量参差不齐**：建立严格的筛选标准和质量评估
- **跨学科文献**：扩展检索范围，涵盖相关领域

## 质量检查
- 文献检索完整性评估
- 知识提取准确性验证
- 工作流可复现性检查
- 研究空白合理性分析

## 回退策略
- 文献检索不足时，扩展关键词或数据库
- 知识提取困难时，使用专家辅助或替代方法
- 工作流梳理不清晰时，参考标准操作流程
