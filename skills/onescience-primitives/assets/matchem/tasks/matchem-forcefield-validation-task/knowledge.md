# 分子动力学力场验证

## 适用范围
触发条件：在分子动力学模拟前，需要验证所选力场参数的适用性，特别是涉及多组分界面体系（如CO2/Cu(111)/水/K）时。
适用场景：任何需要确保力场参数物理正确性的MD模拟任务。
不适用场景：已有力场验证报告且参数已确认的任务。

## 输入
- 力场参数文件（LJ参数、电荷、键合参数）
- 参考数据（DFT计算结果、实验测量值）
- 体相性质数据（密度、蒸发热、扩散系数）
- 界面性质数据（接触角、吸附等温线）

## 输出
- 力场验证报告（包含参数来源、验证指标、验证结果和适用范围说明）
- 独立测试指标（体相性质、界面性质、能量验证）
- MD准入结论

## 流程节点
1. 参数来源追溯 → 2. 体相性质验证 → 3. 界面性质验证 → 4. 能量验证 → 5. 生成验证报告

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 水模型选择 | SPC/E vs TIP3P vs TIP4P | 通用标准 | 根据体系选择合适水模型 |
| CO2力场验证指标 | 密度、蒸发热、扩散系数 | 通用标准 | TraPPE CO2力场常用 |
| Cu表面力场验证 | 表面能、吸附能 | 通用标准 | 需要DFT或实验验证 |
| LJ参数来源 | DFT拟合/实验拟合 | 通用标准 | 优先使用经过验证的参数 |

## 边界与分流
- 参数来源不明：标记为异常，要求提供来源
- 验证指标不达标：标记为待确认，不作为正式输入
- 文献参数未经DFT验证：标记为参考级，不作为正式输入

## 质量检查
- 每个力场参数必须有明确的来源记录
- 验证指标必须与参考数据对比
- 异常参数必须标识
- 正式参数与参考参数必须明确区分

## 回退策略
- 参数验证失败：暂停任务，请求用户提供验证数据
- 参数来源不明：标记并报告，不使用未验证参数
