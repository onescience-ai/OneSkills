# LAMMPS安装与配置

## 适用范围
触发条件：在分子动力学模拟前，需要安装和配置LAMMPS软件，特别是在计算集群或超算平台上运行时。
适用场景：任何需要安装和配置LAMMPS软件的MD模拟任务。
不适用场景：已安装LAMMPS且验证通过的任务。

## 输入
- 操作系统信息（Linux/macOS/Windows）
- 计算资源信息（本地CPU/GPU、集群节点、超算平台）
- 依赖库信息（MPI、CUDA、Python绑定）
- 安装方法选择（源码编译、conda安装、模块加载）

## 输出
- LAMMPS可执行文件路径
- 依赖库验证结果
- 版本兼容性报告
- 安装验证测试结果

## 流程节点
1. 环境检测 → 2. 安装方法选择 → 3. 依赖库安装 → 4. LAMMPS安装 → 5. 验证测试 → 6. 生成安装报告

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 可执行文件路径 | /path/to/lmp | 安装目录 | 需要添加到PATH |
| 依赖库检查 | MPI、CUDA、Python | 系统环境 | 根据需求选择安装 |
| 版本兼容性 | LAMMPS版本与依赖库版本匹配 | 官方文档 | 避免版本冲突 |
| 验证测试 | 输入脚本测试运行 | 安装验证 | 确保安装正确 |

## 边界与分流
- 依赖库缺失：安装缺失依赖库
- 版本不兼容：降级或升级依赖库
- 权限不足：使用conda环境或联系管理员

## 质量检查
- LAMMPS可执行文件必须存在且可执行
- 依赖库必须正确安装
- 版本信息必须正确
- 验证测试必须通过

## 回退策略
- 安装失败：使用conda环境或联系管理员
- 依赖库冲突：使用虚拟环境隔离
