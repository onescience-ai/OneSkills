# 振动稳定材料数据集获取方法

## 适用范围
本知识卡片适用于需要获取振动稳定材料（vibrationally stable materials）真实数据集的任务，包括通过公开数据库API查询、文献数据提取等方式获取带有振动稳定性标签的材料数据。

## 输入
- 目标材料体系描述（如元素组合、晶体结构类型）
- 数据规模需求（样本数量）
- 数据格式要求（特征字段、标签定义）

## 输出
- 符合机器学习建模需求的振动稳定材料数据集
- 数据来源可追溯到公开数据库或已发表论文
- 包含晶体结构、声子谱、热力学稳定性等关键属性

## 流程节点
1. **数据源识别** → 2. **API接口调用** → 3. **数据提取与清洗** → 4. **标签定义与验证** → 5. **数据质量检查**

### 步骤1：数据源识别
- **操作**：确定适合的数据源
- **参数**：材料体系、数据规模、更新频率
- **工具**：文献调研、数据库访问
- **质量门禁**：数据源需为公开可访问的权威数据库

### 步骤2：API接口调用
- **操作**：通过编程接口获取数据
- **参数**：查询条件、字段选择、分页参数
- **工具**：Materials Project API、OMDB API
- **质量门禁**：API调用成功，返回有效数据

### 步骤3：数据提取与清洗
- **操作**：解析API返回数据，提取关键字段
- **参数**：字段映射、缺失值处理、异常值检测
- **工具**：Python pandas、numpy
- **质量门禁**：数据完整性检查，格式一致性验证

### 步骤4：标签定义与验证
- **操作**：定义振动稳定性标签
- **参数**：声子频率阈值、热力学稳定性判据
- **工具**：科学计算库
- **质量门禁**：标签定义有科学依据，可追溯到文献

### 步骤5：数据质量检查
- **操作**：验证数据集质量
- **参数**：数据分布、特征相关性、标签平衡性
- **工具**：统计分析工具
- **质量门禁**：数据满足机器学习建模基本要求

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 振动稳定性判据 | 声子谱无虚频 | [1] | 材料动力学稳定性的基本要求 |
| 热力学稳定性判据 | 形成能低于凸包 | [1] | 材料热力学稳定性的判据 |
| 数据规模建议 | >100个样本 | [2] | 机器学习建模的基本数据量要求 |

### 校准数值（来自具体体系）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| Materials Project数据字段 | material_id, structure, formation_energy, band_gap | [1] | 示例字段，其他体系需重新锚定 |
| 声子频率计算方法 | PHONOPY+VASP | [1] | 第一性原理计算工作流 |

## 边界与分流
- **数据不可用**：当目标数据在公开数据库中不存在时，转向文献数据提取或自行计算
- **数据规模不足**：当数据量小于100个样本时，考虑数据增强或迁移学习
- **数据质量差**：当数据缺失率>30%时，需要数据清洗或补充采集

## 质量检查
- 数据来源可追溯性验证
- 标签定义科学性检查
- 数据分布合理性分析
- 特征工程可行性评估

## 回退策略
- 数据源不可用时，尝试替代数据库或文献数据
- API调用失败时，使用缓存数据或离线数据集
- 数据质量不达标时，返回数据采集阶段重新执行
