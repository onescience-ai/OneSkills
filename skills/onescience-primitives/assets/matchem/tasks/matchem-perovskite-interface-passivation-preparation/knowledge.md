# 界面钝化方案制备方法与工艺日志标准

## 适用范围
本卡片适用于钙钛矿太阳能电池界面钝化方案的设计与制备，包括分子设计、结构建模和DFT计算流程。适用于钝化材料筛选、计算模拟和实验验证。

## 输入
- 钙钛矿表面缺陷信息（如铅空位、碘空位）
- 候选钝化分子结构（如Lewis碱分子）
- DFT计算参数（如泛函、截断能、k点网格）

## 输出
- 钝化方案候选列表（分子名称、SMILES结构、吸附位点）
- DFT计算输入文件（如VASP的INCAR、POSCAR）
- 工艺日志（计算参数、收敛性、计算时间）

## 流程节点
1. 确定钝化目标（表面缺陷类型）
2. 筛选候选钝化分子（如含磷、氮、氧的Lewis碱）
3. 构建分子-表面吸附模型
4. 设置DFT计算参数（如PBE泛函、500 eV截断能）
5. 执行结构优化和单点能计算
6. 分析吸附能和电子结构
7. 记录工艺日志

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 泛函 | PBE | [论文1] | 常用交换关联泛函 |
| 截断能 | 500 eV | [论文1] | 确保收敛 |
| k点网格 | 4×4×1 | [论文1] | 表面计算常用 |
| 吸附能阈值 | < -1.0 eV | [论文1] | 强吸附判据 |
| 收敛标准 | 力 < 0.01 eV/Å | [论文1] | 结构优化 |

## 边界与分流
- 若DFT计算资源不足，可采用简化模型（如团簇模型）
- 若候选分子过多，可先进行高通量筛选
- 若计算不收敛，调整截断能或k点网格

## 质量检查
- 吸附能是否合理（负值表示稳定吸附）
- 结构优化是否收敛
- 工艺日志是否完整
