# 钙钛矿稳定性基准数据集

## 适用范围
适用于钙钛矿太阳能电池等光电器件领域的环境稳定性研究，特别是针对材料水稳定性的高通量筛选与预测建模。当研究目标涉及以下方面时可使用本基准数据集：
1.  **开发或验证机器学习模型**：训练模型以根据分子修饰剂的特征（如分子描述符）预测钙钛矿薄膜在潮湿环境中的光电性能衰减。
2.  **评估特征工程方法**：比较不同分子表征方法（如指纹、量子化学描述符等）在关联宏观稳定性方面的有效性。
3.  **基准测试新算法**：作为标准化评估集，比较不同回归或分类算法在小样本材料性能预测任务上的表现。

## 数据集构成与格式
本基准数据集是一个结构化的实验测量结果集合，其核心构成如下：
-   **样本组成**：包含96种独特的分子组合修饰的甲胺铅碘（CH3NH3PbI3）钙钛矿薄膜样品。
-   **测量维度**：每个样品均在4个不同的水浸泡时间点（例如：0小时、12小时、24小时、48小时，具体时间需查阅数据文件）下，进行了水相光电流测试。
-   **总数据点**：96个样品 × 4个时间点 = **384个**独立的光电流测量数据点。
-   **典型数据结构**：数据通常以表格形式存储，每一行对应一个数据点，可能包含以下字段（具体列名需查看公开数据）：
    -   `sample_id`: 唯一的样品标识符。
    -   `modifier_composition`: 修饰剂分子的化学组成或标识。
    -   `immersion_time_h`: 水浸泡时间，单位为小时。
    -   `photocurrent_uA`: 测量得到的光电流值，单位为微安。
    -   可能包含其他元数据，如环境湿度、温度等。

数据集已按典型机器学习流程划分为训练集和测试集，输出为特征矩阵（X）和标签向量（y）。特征通常由分子修饰剂的化学结构通过信息学工具（如RDKit）计算生成。

## 数据集使用方式
在典型的材料信息学研究流程中使用本数据集：
1.  **数据加载与预处理**：从开源代码库加载原始数据表，处理缺失值，进行必要的数据清洗。
2.  **特征工程**：利用分子描述符工具包（如RDKit、Mordred）从分子SMILES字符串或名称生成数值特征向量。特征选择或降维可在此步进行。
3.  **模型训练与评估**：将特征矩阵和光电流标签输入机器学习模型（如随机森林、梯度提升机、神经网络）。使用划分好的训练集训练，测试集评估性能。
4.  **性能指标**：评估模型预测光电流或其衰减趋势的准确性，常用指标包括均方根误差（RMSE）、决定系数（R²）等。

## 边界与分流
-   **数据规模限制**：本数据集包含384个数据点，属于中小规模。对于参数量巨大的深度学习模型，可能存在过拟合风险。更适合用于评估基于传统机器学习或轻量级模型的预测方法。
-   **任务范围限定**：数据集专注于**水相光电流**这一特定稳定性指标。若需评估热稳定性、光照稳定性或长期运行稳定性，需要其他专门的数据集。
-   **体系特定性**：数据针对CH3NH3PbI3体系。将基于此数据训练的模型直接迁移至其他钙钛矿组分（如甲脒、铯基、混合卤素钙钛矿）时，预测可靠性需重新验证。
-   **上游依赖**：数据集是“多模态材料表征与优化工作流”的产出之一。使用前需理解其制备与测量背景。

## 质量检查与注意事项
使用本数据集时，建议进行以下质量检查：
-   **分布检查**：检查光电流标签在训练集和测试集中的分布是否一致，避免数据泄露或评估偏差。
-   **噪声考量**：实验数据不可避免地包含噪声。环境湿度等未被完全控制或记录的因素可能引入额外变异。在建模时，可考虑使用鲁棒性较强的算法或引入噪声鲁棒性损失函数。
-   **特征相关性**：分析生成的分子特征与光电流标签之间的相关性，排除无信息或冗余特征。
-   **可重复性**：确保从相同的原始数据、相同的特征工程流程出发，能够重现报告的模型性能。
