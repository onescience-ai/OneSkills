## content_principle

Zenodo v2（doi:10.5281/zenodo.5760191，CC BY 4.0）的 `train_test_data.tar.gz` 是用于 SCFNN 训练和测试的立方水盒外场 DFT 结果。作者 README 所引 doi:10.5281/zenodo.5521328 是同源早期记录。v2 的 `HirshfeldMullikenCharges.tar.gz` 用于 4G-HDNNP，不是本输入。论文 doi:10.1038/s41467-022-29243-2 的 Methods 描述标签来源；论文 Source Data 不等于逐构型标签。

## data_schema

每个构型保存 192 个核（64 O、128 H）和 256 个 Wannier 中心的三维坐标、立方盒长及 192×3 的核力。作者解析器以 `float64` 读坐标，从 Å 转 Bohr；`init.xyz` 第二行零基索引 10 是 Bohr 盒长。坐标按周期盒绕回，以原子顺序 O,H,H 对齐坐标和力。力文件取核力三分量，单位须查 DFT 输出或元数据，不能从源码没有转换就推断单位。每组字段带母轨迹/母 Config、外场和单位、数据和标签血缘；缺项不能零填。

## directory_layout

以三外场目录为相对根。`D0`、`D0p1V`、`D0p2V` 下按同名 Config 配对；各 Config 的必要成员是 `W64-bulk-HOMO_centers_s1-1_0.xyz`（核及中心）、`init.xyz`（盒长）、`W64-bulk-W64-forces-1_0.xyz`（核力）。上述成员定义的是核、中心、晶胞及参考力的读取契约，不能据此推定有能量或应力。使用能量或应力时须另核数据来源、标签定义、许可、参考设置及逐构型配对。

## storage_format

发布入口描述 tar.gz 包，内部成员由固定提交的 `train_test/assemble_data.py` 按文本列读取。D0 的 G2/G4 特征及导数是独立生成的前处理产物，不是 XYZ 或参考标签的替代品。

## scale_spec

每个母 Config 的目标形状是三种场各一个构型。实物未核验，实际完整组数、各标签数量、归档大小和哈希未知；源码枚举和排除表不是实体清单。

## coverage_spec

论文窄域为 64 个体相液态水分子的立方周期盒，沿 z 的 0、0.1、0.2 V/Å 成组；实际温压、采样和组覆盖从血缘核定。不是液汽界面、缺陷或高温的覆盖证明。

## label_spec

论文 Methods 记载 CP2K v7、revPBE0（25% 精确交换）、D3、GTH、TZV2P 和 400 Ry。用这些信息追溯实际产物，不代替逐构型设置。核力、能量、应力分别核验；能量需零点和每胞/每原子约定，应力需张量顺序、拉压符号、体积和单位，尚无匹配 E/应力文件的实物证据。

## split_strategy

同一母轨迹的 Config、三场响应及近重复不能跨训练、验证和独立测试。先核实组及近重复，再冻结分组、弃用理由和摘要；只在训练分区拟合归一化。实际分组须核对作者的排除清单及真实文件。

## constraints

许可确认不证明实体可访问。不能用组名、演示结果或论文汇总表填补缺失字段；无法确认目标覆盖、来源或必要标签时，完整的 s01 审计受阻。
