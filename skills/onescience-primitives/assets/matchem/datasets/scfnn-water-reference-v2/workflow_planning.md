## description

s01 的体相水参考审计，及 s03 的独立分组与标签交接。

## when_to_use

目标与论文周期水盒三场可匹配且有权读取真实组；不将界面、缺陷、高温或 4G 电荷另包当作本数据。

## inputs

v2 可读组级文件清单、标签来源/许可、原始设置、母轨迹与母 Config、外场和目标范围。

## outputs

核验过的成员及标签统计、组血缘与弃用清单、分组和摘要；持出组含原始参考约定。

## procedure

1. 按版本和三目录配对，读取核/中心、盒长及力，核对数量、顺序、有限性及单位。
2. 关联真实 E/应力和逐构型来源；对照目标覆盖，登记重复、异常、缺项和证据。
3. 按母轨迹及 Config 隔离训练、验证和独立测试；检查近重复和三场泄漏，冻结清单及摘要。

## constraints

无实际输入不生成空划分作结果；只用训练组拟合尺度；独立持出组不参与选择模型或调参。

## next_phase_recommendation

完整 s01 门禁通过后向 s02 提供训练文件及 `REFERENCE_PROVENANCE`、数据/分组摘要；向 s03 提供同版本持出组并核对 E/F/应力可配对性。

## fallback

缺可读官方/已授权组级成员或有界导出，或标签、血缘不全时，保留审计能确认的事实和缺项；取得可验证成员清单、标签语义和覆盖证据后复核，不能用无关归档或论文图表补齐。
