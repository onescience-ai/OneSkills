# CO2还原制甲酸性能基准指标

## 适用范围
本基准用于评估以CO2为原料，通过电化学还原途径高选择性制取甲酸（或甲酸盐）的电催化剂及电解槽系统的综合性能。适用于在实验室或中试规模下，对不同催化材料、结构设计或运行条件进行量化比较与筛选，是连接基础催化剂研究与应用开发的关键性能评价工具。

## 输入
- 必需数据：在受控电化学测试条件下采集的催化剂工作数据，包括：
  - 施加电位（通常需换算为相对于可逆氢电极的电位，V vs. RHE）
  - 响应电流（或电流密度，单位通常为mA cm⁻²）
  - 产物（甲酸/甲酸盐）的定量分析结果（如通过核磁共振、离子色谱或滴定法测得的浓度与产率）。
- 可选数据：电解槽的电压、阻抗谱数据、电解液成分与流速、温度等运行参数。

## 输出
核心性能评价指标，主要包括：
1.  **法拉第效率**：生成目标产物（甲酸）所消耗的电子占总通过电子的百分比，反映反应的选择性。
2.  **电池能量效率**：生成目标产物的吉布斯自由能占输入电能的百分比，综合反映反应的能量利用效率。
3.  **工作电位**：在指定电流密度下，相对于可逆氢电极的施加电位（V vs. RHE），反映驱动反应所需的能量高低。
4.  **稳定性时长**：催化剂在维持高活性与高选择性条件下连续工作的最长时间。
5.  **产物浓度**：在流动电解或膜电极组件系统中，产物在出口电解液中的浓度，关联产物收集与分离纯化成本。

## 基准指标体系
一套典型的、面向实际应用的CO2还原制甲酸性能基准参考如下：

| 指标                 | 参考性能门槛       | 意义与说明                                                                                     |
| :------------------- | :----------------- | :--------------------------------------------------------------------------------------------- |
| **稳定性时长**       | > 1000 小时        | 满足工业电解槽对催化剂寿命的基本要求，是实现技术经济可行性的关键前提。                         |
| **电流密度**         | > 100 mA cm⁻²      | 在工业级电流密度下运行，是实现高产率和低成本生产的核心要求。                                   |
| **法拉第效率 (FE)**  | > 95%              | 极高的选择性，意味着原料利用率高，副反应（如析氢）少，简化后续产物分离。                       |
| **电池能量效率 (CEE)** | > 70%              | 高能量效率意味着较低的生产能耗，直接关系到生产成本的经济性。                                   |

**注意**：以上数值为参考性门槛，旨在定义一个具有工业应用前景的性能区间。具体研究或应用中的“优秀”性能需结合具体系统设计、原料成本、能源价格和技术成熟度等综合判断。

## 边界与分流
- **测试条件标准化**：法拉第效率、能量效率等指标的绝对值**强烈依赖于测试条件**，包括电解液种类与pH值、电解槽类型（H型电解池、流动电解槽、MEA等）、阴极结构、温度等。因此，**不同研究工作之间，若测试条件差异显著，其性能指标不可直接横向比较**。进行有意义的对比时，应尽可能在相同或可换算的条件下进行。
- **系统层级差异**：在实验室H型电解池中测试的性能（尤其是电流密度和稳定性）与在膜电极组件系统或流动电解槽中测试的性能可能存在巨大差距。在评估性能时，需明确所报告的性能数据对应的电解槽系统类型。
- **与相关工作的衔接**：本基准主要针对甲酸产物路径。对于CO2还原的其他产物（如CO、乙烯、乙醇等），需使用相应的性能基准体系。同时，性能评估是技术经济性分析的输入，但完整的经济性分析还需考虑催化剂成本、系统复杂性、产物分离成本等因素。

## 质量检查
- **法拉第效率计算**：需确保产物定量分析方法准确、可靠，并正确换算电子转移数。应多次取样验证数据的可重复性。
- **稳定性测试**：应记录电流密度或电位的实时变化曲线，而不仅仅是最终时长。需关注催化剂活性衰减的速率和失效模式。
- **数据一致性**：检查电流密度、电位、产物生成速率之间的能量与物质守恒关系是否合理。异常的高法拉第效率（如接近100%）需格外仔细地核实数据。

## 回退策略
当测试数据无法达到或接近上述基准门槛，或数据质量存在问题时：
1.  **检查测试系统**：优先排查电解槽密封性、电路连接、参比电极校准等基础问题。
2.  **优化反应条件**：在不改变催化剂本体的前提下，系统性地优化电解液浓度、pH值、CO2流速、温度等参数，探索性能提升空间。
3.  **调整评估目标**：若稳定性或电流密度是主要瓶颈，则应将研究重点转向催化剂本身（如活性位点稳定性、导电性、微观结构）的优化，而非仅优化测试条件。
4.  **重新校准性能预期**：根据当前材料体系的公认挑战，合理调整对该体系性能的预期，并明确说明限制性能的主要因素（如析氢竞争、活性位点失活、传质限制等）。
