# 网络受限环境下的分子生成任务

## 适用范围
适用于在无法直接访问外部网络（如GitHub、PyPI、Google Drive）的环境中执行分子生成任务。需要提前规划资源获取和依赖管理策略。

## 输入
- 任务所需外部资源列表（代码仓库、模型权重、数据集、Python包）
- 网络限制详情（防火墙、代理要求、白名单）
- 本地存储空间

## 输出
- 可用的本地资源缓存
- 离线安装包
- 任务执行所需的全部依赖

## 流程节点
1. **资源清单** → 列出所有外部依赖
2. **优先级排序** → 按任务关键性排序
3. **获取策略** → 选择下载、镜像或代理方式
4. **本地缓存** → 存储下载的资源
5. **离线安装** → 使用本地资源安装依赖
6. **验证** → 确认所有资源可用

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 代理配置 | HTTP_PROXY/HTTPS_PROXY环境变量 | [D1] | 通过代理访问外部资源 |
| 镜像源 | 清华大学镜像、阿里云镜像 | [D1] | 国内镜像加速 |
| 离线包格式 | .whl (pip), .tar.bz2 (conda) | [D1] | 离线安装包格式 |
| 预下载工具 | pip download, conda pack | [D1] | 下载离线安装包 |

## 边界与分流
- **完全无网络**：需使用完全离线的预装环境
- **部分受限**：仅特定域名受限，可配置代理或镜像
- **带宽限制**：大文件下载需分块或使用断点续传

## 质量检查
- 测试网络连接：`ping github.com` 或 `curl https://github.com`
- 验证离线安装包完整性
- 确认所有依赖版本兼容

## 回退策略
- 使用容器化环境（Docker）预装所有依赖
- 使用虚拟环境隔离依赖
- 寻求管理员协助配置网络

## 资源召回建议
当遇到网络连接错误、SSL证书问题或外部资源下载失败时召回本卡片。
