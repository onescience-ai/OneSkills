# NiFe 基 OER 电极的 XPS 表面重构与价态演化分析协议

## 适用范围

本协议用于分析 NiFe 基（LDH/氧化物/羟基氧化物）OER 电极在碱性稳定性测试**前后**的 XPS 数据，回答"表面发生了什么"：表面重构（NiOOH 类相形成）、Fe 选择性溶出、还是电解液残盐覆盖。典型触发场景包括：稳定性测试后电极表面化学态表征、价态定量（Ni²⁺/Ni³⁺、Fe²⁺/Fe³⁺）、表面 Ni/Fe 原子比变化追踪、KOH 残盐干扰甄别，以及 XPS 表面结果与 ICP 体相溶出结果的联合解读。同样适用于其他碱性体系过渡金属（Co、Mn 等）电极的前后对比 XPS 分析，峰位参数需按元素替换。

## 输入与准备

- **谱文件**：before/after 各一组，含 survey 与 C 1s、Ni 2p、Fe 2p 高分辨谱（常见导出为两列文本：结合能 eV / 强度 cps）。
- **仪器信息**：相对灵敏度因子 RSF 表（以仪器库导出值为准，典型：C 1s 1.00、O 1s ~2.9、Ni 2p3/2 ~3.1、Fe 2p3/2 ~3.8、K 2p ~1.4）、是否已做荷电校正、是否 Ar⁺ 刻蚀、激发源（Al Kα 1486.6 eV）。
- **辅助证据（强烈建议配套）**：ICP-OES/ICP-MS 电解液金属溶出结果（含电解液体积与催化剂载量，便于折算损失比例）、稳定性测试电化学记录（活性衰减幅度）、样品清洗规程。
- **样品背景**：催化剂组成与载量、电解液浓度（如 1 M KOH）、基底类型（自支撑/滴涂）。

## 流程节点

1. **荷电校正**：以 adventitious carbon 的 C-C/C-H 组分 284.8 eV 为参考。对每个样品**分别**从 C 1s 实测主峰位置反推校正量（raw 峰位偏高时对全谱做减法平移），before/after 校正量不同是正常的，禁止共用一个值。适用前提：表面有足量吸附碳、非强荷电体系（校正量一般 0.5–3 eV）、碳参考峰未被污染峰主导。KOH 残盐覆盖时 C 1s 可能主要来自碳酸盐——应检查 289.0 eV（O-C=O）组分占比并与 survey 中 K 2p 交叉验证；参考不可靠时改用 Fermi 边或内标，并在报告中声明。

2. **本底扣除**：高分辨谱用 Shirley 或线性本底，survey 用线性本底；同一批样品前后处理方式保持一致。

3. **C 1s 拟合与残盐甄别**：组分按 C-C 284.8 / C-O 286.2±0.2 / C=O 287.5±0.3 / O-C=O 289.0±0.3 设置。**关键检查**：293.2–293.5 与 295.8–296.2 eV 若出现面积比约 2:1 的双峰，为 K 2p3/2/2p1/2（KOH 残盐，survey 中还应核对 K 2s ≈ 377.6 eV），必须独立立组分，**严禁拟合成"污染碳"**。残盐会抬高表观 O/C、稀释目标信号并干扰荷电校正，定量结论须声明此系统偏差。

4. **Ni 2p 拟合**：结构化约束模型——Ni²⁺ 2p3/2 855.3–856.0 eV（伴强 shake-up 卫星 ~861.0–861.5 eV）、Ni³⁺ 2p3/2 856.0–857.0 eV（NiOOH 类，卫星弱）；自旋轨道分裂 ΔBE(2p1/2−2p3/2) = 17.3–17.6 eV，A(2p1/2):A(2p3/2) ≈ 0.5 锁定；卫星峰独立组分（并入主峰会系统性高估 Ni²⁺）；FWHM 1.8–3.0 eV（卫星可放宽至 4 eV）。自支撑金属基底注意甄别 Ni⁰（852.7–853.0 eV）贡献。

5. **Fe 2p 拟合**：Fe²⁺ 2p3/2 709.5–710.3 eV（伴明显卫星 ~718.5–719.0 eV）、Fe³⁺ 2p3/2 710.7–711.5 eV（羟基氧化物中常见 711.0 附近，卫星弱）；ΔBE = 13.5–13.8 eV，面积比同样 ≈0.5。Fe²⁺/Fe³⁺ 峰差仅 ~1.1 eV，与 FWHM 同量级，两组分强相关——必须用不同初值重复拟合验证收敛到同解，并报告比例不确定度；出现 Fe⁰（706.7–707.0 eV）提示基底暴露或还原态。

6. **RSF 定量**：原子比 = (A_Ni/RSF_Ni)/(A_Fe/RSF_Fe)；价态占比按 2p3/2 主峰口径计算。定量口径（含卫星包络或仅主峰）在 before/after 间必须一致并写入报告。XPS 探测深度仅 ~5–10 nm，所有结论限定为"表面"组成，不外推体相。

7. **证据融合与机理判别**：将 XPS 表面比变化、价态变化与 ICP 溶出结果、电化学衰减行为组合判别：
   - Ni/Fe 表面比升高 + Ni³⁺↑ + Fe³⁺↑ + ICP 检出 Fe 而 Ni 低于检出限 → 表面重构为 Ni 富集的 (Ni)OOH 类相 + Fe 部分选择性溶出；
   - Ni/Fe 表面比降低 + Fe³⁺↑ → 表面 Fe 富集（Fe 掺入 NiOOH）；
   - 价态与 Ni/Fe 均无明显变化 + C/O 升高 + K 2p 出现 → 残盐覆盖为主，先建立清洗规程再复测，暂不下表面结论；
   - XPS 表面 Fe 损失比例远大于 ICP 体相损失比例属正常（表面敏感 vs 体相平均），按探测深度调和；差距极端时考虑溶解-再沉积动态平衡或 Fe 向体相迁移。

## 参数速查

| 项目 | 设定 |
|---|---|
| 荷电校正参考 | adventitious C 1s C-C = 284.8 eV，逐样品分别反推 |
| Ni 2p | Ni²⁺ 855.3–856.0 / Ni³⁺ 856.0–857.0 eV；卫星 ~861.2；ΔBE 17.3–17.6 |
| Fe 2p | Fe²⁺ 709.5–710.3 / Fe³⁺ 710.7–711.5 eV；卫星 ~718.8；ΔBE 13.5–13.8 |
| 自旋轨道约束 | A(2p1/2):A(2p3/2) ≈ 0.5（0.48–0.52） |
| K 残盐标志 | K 2p3/2 293.2–293.5 / K 2p1/2 295.8–296.2，面积比 2:1；K 2s ~377.6 |
| C 1s 组分 | 284.8 / 286.2±0.2 / 287.5±0.3 / 289.0±0.3 eV |
| FWHM | 主峰 1.8–3.0 eV，卫星 ≤4.0 eV |

## 输出与数据处理

正式结果应包含：

- 每个样品的荷电校正量（分别记录，含 C 1s 实测峰位依据）；
- 组分拟合表（峰位/FWHM/面积/约束说明）与前后拟合对比图（含残差子图，残差应无系统性结构）；
- 价态占比：Fe³⁺%、Ni³⁺%（before/after 对比，含不确定度）；
- 表面 Ni/Fe 原子比（before/after，声明定量口径）；
- 机理结论：对表面重构 / Fe 选择性溶出 / 残盐覆盖三个假设逐一给出证据支持或排除的推理链；
- 最薄弱环节声明与验证实验建议。

分析脚本应将组分峰参数（峰位、FWHM 界限、约束开关）做成可配置项，便于同批次样品复用。

## 边界与分流

- 本协议面向**碱性（KOH）体系 NiFe 电极的前后对比 XPS**。酸性体系无 K 残盐问题，但需另配 F 污染（来自 Nafion 等）的甄别；其他过渡金属体系峰位参数按元素替换。
- 只有 survey 无高分辨谱时，无法做价态定量，只能给元素组成半定量——应补测高分辨而非勉强拟合。
- 需要**体相**物相/氧化态结论时，XPS 不适用，应组合 XRD/XAFS；需要深度分布时用 Ar⁺ 刻蚀剖面（注意刻蚀诱导还原伪影，只做趋势判断）。
- 样品为强荷电绝缘体且无可靠内标时，荷电校正前提不成立，先解决校正（薄样、中和枪、内标）再谈定量。
- 表面结论与电化学衰减行为矛盾时，回到 OER 电催化评测协议的回退策略：稳定性测试后复测 LSV/EIS/C_dl，区分活性位损失（R_ct 增大）与接触/传质退化（Rₛ、气泡）。

## 质量检查

- 荷电校正量由实测 C 1s 反推并写入报告；校正方向不写反；before/after 未共用校正量。
- ΔBE 与 2p1/2:2p3/2 面积比约束全程锁定；卫星峰独立组分。
- K 2p 未被误拟合为碳组分；O-C=O(289.0) 与 K 2p 同时增强提示碳酸钾残盐，需在定量中声明偏差。
- Fe²⁺/Fe³⁺ 用不同初值重复拟合收敛到同解；价态比报告 ±区间。
- 残差图无系统性结构（有结构 = 缺组分或峰位/峰形错误）。
- 定量口径前后一致；结论只覆盖表面 5–10 nm，不外推体相。

## 回退策略

- **Fe²⁺/Fe³⁺ 拟合简并解不开**：退化为"Fe 以 +3 为主/混合价"定性结论，并建议 XAFS（XANES 边位定氧化态，不受荷电与拟合简并影响）。
- **C 1s 参考被残盐污染**：改用 Fermi 边或掺入内标（如 Au）复测；不可行时对校正量做 ±0.3 eV 敏感性分析并声明。
- **残盐疑虑**：同批样品做"清洗空白对照"（同规程清洗的未测试样品）比较 K/C 信号，建立去离子水/乙醇清洗规程后复测。
- **拟合不收敛或残差有结构**：先检查是否缺组分（卫星峰、K 2p、金属态），再收窄峰位浮动范围（±0.3 eV），不放开物理约束硬凑残差。
- **表面相化学指认存疑**：Raman 正交验证（NiOOH 特征 ~470 与 ~550 cm⁻¹；FeOOH 特征峰）；深度分布不明时补 Ar⁺ 刻蚀剖面或截面 HAADF-EDS。

## 资源召回建议

- 配套设备：XPS 仪器（含 Ar⁺ 刻蚀附件更佳）、ICP-OES/ICP-MS（电解液金属溶出）、Raman 光谱仪、超声清洗仪。
- 与 OER 电催化评测协议（oer-electrocatalytic-evaluation）联动：稳定性测试后的电极直接进 XPS 流程，电化学衰减数据作为机理判别的第三证据源。
- 机理深化可在后续管线接入准原位 XPS/XAFS（避免转移过程空气氧化伪影）、¹⁸O 标记、TEM/HAADF-EDS 面扫。
- 长期稳定性数据与 ICP（电解液金属溶出）搭配，判断催化剂疲劳模式（表面重构壳 vs 体相流失）而非单纯记录电流衰减。
