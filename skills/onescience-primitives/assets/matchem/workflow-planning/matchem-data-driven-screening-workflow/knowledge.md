# 数据驱动光催化剂筛选工作流

## 适用范围

**触发条件**：
- 需要从大规模材料库中筛选高效CO2光催化剂
- 需要执行完整的端到端材料筛选流程
- 需要整合数据获取、ML预测、DFT验证的多步骤工作流

**适用场景**：
- CO2光催化剂的高通量虚拟筛选项目
- 新型光催化材料的发现与优化
- 材料基因组计划的催化剂筛选任务
- 需要完整工作流文档和可重复执行的研究

**不适用场景**：
- 仅需单一步骤（如仅数据获取或仅ML预测）
- 需要实时实验验证的场景
- 数据量极小（<10个材料）的场景

## 输入

**必要输入**：
- 研究目标定义（目标性能指标、筛选标准）
- 计算资源（HPC集群、API访问权限）
- 工作流配置文件（参数设置、路径配置）

**可选输入**：
- 预训练模型
- 已有材料库
- 文献参考数据

**配置要求**：
- Materials Project API密钥
- VASP许可证（如需DFT验证）
- Python环境及依赖包

## 输出

**主要输出**：
- 候选材料列表（含排名、预测性能、置信度）
- 工作流执行日志
- 中间产物（数据集、训练模型、DFT结果）
- 最终筛选报告

**验证标准**：
- 工作流完整执行所有步骤
- 候选材料经过DFT验证
- 结果可重复执行

## 流程节点

### Step 1：数据获取（s01）
- **操作**：从Materials Project获取材料数据集
- **参数**：元素范围、带隙范围、数据量
- **工具**：MPRester API
- **质量门禁**：获取真实材料数据，非模拟数据
- **输入**：研究目标、筛选标准
- **输出**：结构化材料数据集（CSV/JSON）

### Step 2：特征工程
- **操作**：提取材料描述符，构建特征矩阵
- **参数**：特征选择方法、降维策略
- **工具**：pymatgen, matminer
- **质量门禁**：特征数量合理，无冗余
- **输入**：原始材料数据
- **输出**：特征矩阵（pandas DataFrame）

### Step 3：模型训练（s02）
- **操作**：训练预测模型，评估性能
- **参数**：模型类型、超参数、验证策略
- **工具**：scikit-learn, XGBoost
- **质量门禁**：使用领域标准模型，性能达标
- **输入**：特征矩阵、目标变量
- **输出**：训练好的模型、性能报告

### Step 4：候选筛选
- **操作**：使用模型预测新材料性能，排序候选
- **参数**：预测置信度、排序策略
- **工具**：模型predict方法
- **质量门禁**：预测结果合理，排序可解释
- **输入**：新材料数据集、训练好的模型
- **输出**：候选材料列表（含预测值）

### Step 5：DFT验证（s04）
- **操作**：对Top候选执行DFT计算验证
- **参数**：计算设置、收敛标准
- **工具**：VASP, atomate
- **质量门禁**：完成高精度计算验证，非统计分析
- **输入**：候选材料结构
- **输出**：DFT计算结果、验证报告

### Step 6：结果汇总
- **操作**：整合所有步骤结果，生成最终报告
- **参数**：报告格式、可视化选项
- **工具**：pandas, matplotlib
- **质量门禁**：报告完整，包含所有关键信息
- **输入**：所有中间产物
- **输出**：最终筛选报告、候选材料清单

## 边界与分流

**异常处理**：
- 数据获取失败 → 使用替代数据库或手动构建
- ML模型性能不足 → 调整特征工程或模型参数
- DFT计算失败 → 检查结构或调整计算设置
- 工作流中断 → 从断点恢复或重新执行

**降级策略**：
- DFT不可用 → 使用文献数据验证
- 计算资源不足 → 减少验证候选数量
- 时间紧迫 → 仅执行ML筛选，跳过DFT验证

## 质量检查

**验证点**：
1. 数据完整性：每个步骤产物符合预期格式
2. 模型性能：测试集R² > 0.8
3. DFT收敛：能量和力达到收敛标准
4. 结果一致性：ML预测与DFT验证趋势一致

**失败处理**：
- 步骤失败 → 记录错误，尝试恢复或跳过
- 性能不达标 → 调整参数重试
- 结果异常 → 人工检查并决策

## 回退策略

**替代方案**：
1. 仅执行数据获取和ML筛选（跳过DFT）
2. 使用文献已报道的催化剂作为候选
3. 采用简化工作流（减少步骤）
4. 降级为规则筛选（如带隙范围过滤）
