# 材料机器学习数据集规模与过拟合处理工作流

## 适用范围

**触发条件**：
- 需要评估数据集规模对模型性能的影响
- 需要诊断和处理模型过拟合
- 需要优化小数据集上的机器学习模型

**适用场景**：
- 材料机器学习建模中的数据集规模评估
- 过拟合诊断和缓解策略实施
- 小数据集材料性能预测优化
- 模型泛化能力提升

**不适用场景**：
- 数据集规模足够大（>1000样本）且过拟合风险低
- 研究对象为确定性模型而非机器学习模型
- 仅需模型训练而不需要性能评估

## 输入

**输入数据**：
- 训练数据集（可能规模较小）
- 模型配置信息
- 性能评估指标

**预处理要求**：
- 数据清洗和标准化
- 特征选择和工程
- 数据划分（训练集/验证集/测试集）

## 输出

**输出产物**：
- 学习曲线分析报告
- 过拟合诊断结果
- 模型优化建议

**验证标准**：
- 学习曲线收敛性良好
- 过拟合程度可接受
- 模型泛化能力达标

## 流程节点

### Step 1：数据集规模评估

- **操作**：评估当前数据集规模是否足够
- **参数**：
  - 最小样本数：特征数量的5-10倍
  - 数据集规模：样本数/特征数比
  - 数据质量：缺失值、异常值比例
- **工具**：pandas, numpy
- **质量门禁**：数据集规模评估完成，识别潜在风险

### Step 2：学习曲线分析

- **操作**：绘制学习曲线评估模型性能随数据量变化
- **参数**：
  - 数据子集比例：10%, 20%, ..., 100%
  - 评估指标：R², MAE, RMSE
  - 交叉验证折数：5折
- **工具**：scikit-learn, matplotlib
- **质量门禁**：学习曲线绘制完成，识别欠拟合/过拟合区域

### Step 3：过拟合诊断

- **操作**：诊断模型过拟合程度
- **参数**：
  - 训练集性能：R², MAE
  - 验证集性能：R², MAE
  - 性能差距：训练集-验证集性能差
  - 过拟合指标：方差分析、偏差-方差分解
- **工具**：scikit-learn, numpy
- **质量门禁**：过拟合诊断完成，量化过拟合程度

### Step 4：过拟合缓解策略

- **操作**：实施过拟合缓解措施
- **参数**：
  - 正则化方法：L1/L2正则化、dropout、早停
  - 模型简化：减少树数量、限制深度
  - 数据增强：特征选择、降维
- **工具**：scikit-learn, numpy
- **质量门禁**：缓解措施实施完成，过拟合程度降低

### Step 5：模型性能验证

- **操作**：验证优化后模型性能
- **参数**：
  - 评估指标：R², MAE, RMSE
  - 验证方法：5折交叉验证、独立测试集
  - 泛化能力：测试集性能
- **工具**：scikit-learn, matplotlib
- **质量门禁**：模型性能达标，过拟合问题解决

## 边界与分流

**异常处理**：
- 数据集过小：使用迁移学习或数据增强
- 过拟合严重：增加正则化或简化模型
- 欠拟合：增加模型复杂度或特征

**降级策略**：
- 优先使用简单模型（避免过拟合）
- 次选正则化技术
- 备选数据增强

**分支条件**：
- 数据量大（>500样本）→ 可使用复杂模型
- 数据量中等（100-500样本）→ 使用中等复杂度模型
- 数据量小（<100样本）→ 使用简单模型或迁移学习

## 质量检查

**验证点**：
1. 学习曲线分析：曲线收敛，无严重过拟合
2. 过拟合诊断：性能差距在可接受范围内
3. 缓解措施：过拟合程度显著降低
4. 模型验证：测试集性能达标

**阈值**：
- 训练-验证R²差 < 0.2
- 测试集R² > 0.6
- 学习曲线收敛标准差 < 0.1

**失败处理**：
- 标记过拟合诊断失败
- 记录失败原因
- 提供模型改进建议

## 回退策略

**失败时的替代方案**：
1. 过拟合无法缓解 → 使用更简单模型
2. 数据集过小 → 使用迁移学习
3. 模型性能不达标 → 重新设计特征工程
