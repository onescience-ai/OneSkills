# 电池电极电化学模拟计算工具选择

## 适用范围

面向电池电极电化学模拟任务，当需要根据研究尺度（原子/介观/宏观）和物理过程（电子结构/离子扩散/力学响应/传质传热）选择合适的计算工具时，本卡片提供VASP、LAMMPS、COMSOL等主流工具的适用条件、输入输出格式、资源需求和工作流集成方式。

## 输入

- 研究目标：电子结构、离子扩散、力学响应、相变、传质传热等
- 体系规模：原子数（几十到几百万）、时间尺度（飞秒到秒）
- 精度要求：第一性原理精度、经验势精度、连续介质精度
- 可用计算资源：CPU/GPU核心数、内存、存储

## 输出

计算工具选择建议、输入文件模板、资源需求估算、工作流集成方案。

## 流程节点

1. **问题定义** → 明确研究的物理过程和目标输出
2. **尺度分析** → 确定特征长度和时间尺度
3. **工具匹配** → 根据尺度和精度要求选择计算工具
4. **资源评估** → 估算计算成本和所需硬件配置
5. **工作流设计** → 设计多尺度模拟的工作流和数据传递方案

## 边界与分流

- **计算资源不足**：降低体系规模或使用机器学习势（MLP）加速
- **精度要求不确定**：先进行小规模DFT计算验证，再扩展到大体系MD
- **多物理场耦合**：使用COMSOL等商业软件的多物理场模块

## 质量检查

- 验证输入文件格式正确性
- 检查收敛性测试结果（能量截断、k点网格、时间步长）
- 确认计算结果与实验数据或高精度计算结果的一致性

## 回退策略

- DFT计算失败时，尝试使用半经验方法或紧束缚模型
- MD模拟发散时，减小时间步长或调整系综参数
- FEM收敛困难时，细化网格或调整求解器参数
