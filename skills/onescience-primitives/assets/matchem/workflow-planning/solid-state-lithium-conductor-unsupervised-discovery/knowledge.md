# 固态锂离子导体无监督发现范式

## 适用范围
当任务目标是发现新型固态锂离子导体时，采用无监督发现范式：在未偏置的材料空间中通过计算筛选识别新型导体，而非对已知材料进行模拟验证。适用于材料发现、高通量筛选、计算材料设计等场景。

## 输入
- 材料搜索空间定义：元素组成范围、结构原型、化学计量比约束
- 筛选指标：离子电导率阈值（如>1e-4 S/cm）、电化学窗口（>0V vs Li）
- 计算资源：HPC集群、计算软件（VASP、CP2K等）
- 机器学习势函数训练数据：已有DFT计算数据

## 输出
- 新型固态锂离子导体候选列表
- 离子电导率预测值
- 离子迁移能垒计算结果
- 材料稳定性评估

## 流程节点
1. 定义材料搜索空间 → 2. 生成候选材料 → 3. 高通量计算筛选 → 4. 离子电导率/迁移能垒计算 → 5. 筛选排序 → 6. 实验验证建议

每步含：操作、参数、工具、质量门禁

## 边界与分流
- 如果用户提供了特定材料（如LLZO），应明确区分是验证任务还是发现任务
- 如果任务目标是验证已知材料性能，不适用本发现范式
- 如果缺乏机器学习势函数训练数据，可先进行少量DFT计算生成训练数据

## 质量检查
- 验证搜索空间定义是否合理（元素组成、结构原型）
- 检查筛选指标是否明确（离子电导率、电化学窗口）
- 确认计算结果可追溯（计算参数、力场信息）

## 回退策略
- 如果主动学习效率低，可采用随机搜索或网格搜索
- 如果计算资源不足，可缩小搜索空间或降低筛选阈值
- 如果缺乏训练数据，可先进行少量DFT计算
