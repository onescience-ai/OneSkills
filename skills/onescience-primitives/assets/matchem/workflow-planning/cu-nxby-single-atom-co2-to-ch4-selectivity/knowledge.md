## 工作流

### 步骤 1：Cu-N4 基底与局域配位构型生成

**目的**：读取 Cu-N4 单原子催化剂结构，保持 Cu 原子孤立，按 Cu-NxBy 候选替换第一配位层中的 N/B 并生成统一表面模型。

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 基底结构 | `{CATALYST_STRUCTURE}` | doc | 是 | `{CATALYST_STRUCTURE}` | CIF/POSCAR 及活性位说明。 |
| 配位候选 | `{COORDINATION_SET}` | list[str] | 是 | `{COORDINATION_SET}` | Cu-NxBy 构型列表。 |

**输出**：配位候选 POSCAR、局域配位与电荷/自旋清单、构型检查日志

**质量门禁**：
- 每个候选只有定义内的第一配位层变化
- Cu 单原子孤立性和表面真空层满足设定
- 所有候选的超胞、表面取向和边界条件一致

**操作指令**：`读取 {CATALYST_STRUCTURE}，生成 {COORDINATION_SET}；核对 Cu 是否为孤立位点、周期边界是否引入非目标 Cu-Cu 相互作用以及每个候选的电荷/自旋设定。无法确认的构型写 BLOCKED。`

### 步骤 2：吸附构型搜索与 VASP 弛豫

**目的**：对 CO2、COOH*、CO*、CHO* 和 H* 在每个 Cu-NxBy 位点枚举合理吸附姿态，使用统一 VASP 设置弛豫并计算吸附能。

**依赖步骤**：s01

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 配位结构集合 | `{COORDINATION_STRUCTURES}` | doc | 是 | `{COORDINATION_STRUCTURES}` | s01 输出。 |
| 中间体集合 | `{INTERMEDIATE_SET}` | list[str] | 是 | `{INTERMEDIATE_SET}` | 反应路径和 HER 对照。 |
| DFT 设置 | `{DFT_CONFIG}` | object | 是 | `{DFT_CONFIG}` | 统一的 VASP 参数。 |

**输出**：弛豫后吸附结构、吸附能与关键键长表、电子结构/电荷分析输入

**质量门禁**：
- 每个候选和中间体至少有可解释的吸附构型搜索记录
- 吸附能参考态、真空层、覆盖度和自旋设置一致
- 近简并构型未被无记录地丢弃

**操作指令**：`使用 VASP 按 {DFT_CONFIG} 对 {COORDINATION_STRUCTURES} 上的 {INTERMEDIATE_SET} 枚举并弛豫吸附构型；保留最低能和近简并构型，记录吸附能、键长、配位变化和收敛信息。`

### 步骤 3：CO2→CH4 与 HER 竞争路径自由能分析

**目的**：以 *COOH、*CO、*CHO 等中间体建立 CO2→CH4 路径，计算电位相关自由能；同时分析 *H/HER 和 CO 脱附竞争，并对关键质子化步骤进行能垒计算或明确缺失。

**依赖步骤**：s02

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 吸附结果 | `{ADSORPTION_RESULTS}` | doc | 是 | `{ADSORPTION_RESULTS}` | s02 输出。 |
| 电位 | `{ELECTROCHEMICAL_POTENTIAL}` | float | 是 | `{ELECTROCHEMICAL_POTENTIAL}` | 相对于 RHE 的统一参考。 |
| 能垒方法 | `{BARRIER_METHOD}` | enum | 否 | `NEB` | 可选值：`NEB`、`not_available` |

**输出**：反应自由能图、限制步骤与选择性竞争分析、关键能垒或缺失项清单

**质量门禁**：
- 每个自由能修正项、参考电位和温度均有记录
- CH4 选择性结论同时考虑 CO 脱附和 HER 竞争
- 没有能垒结果时不得宣称动力学选择性已被证明

**操作指令**：`根据 {ADSORPTION_RESULTS} 和 {ELECTROCHEMICAL_POTENTIAL} 构建 CO2→COOH→CO→CHO→CH4 与 HER 路径；用 {BARRIER_METHOD} 处理关键步骤。区分吸附能、自由能和能垒，缺失项写 MISSING。`

### 步骤 4：位点稳定性与选择性排序

**目的**：结合局域配位保持、结构重构/脱附风险、关键中间体结合强度和反应路径，形成 Cu-NxBy 候选的 CH4 选择性—稳定性排序。

**依赖步骤**：s03

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 反应分析结果 | `{REACTION_ANALYSIS}` | doc | 是 | `{REACTION_ANALYSIS}` | s03 输出。 |
| 验证数据 | `{VALIDATION_DATA}` | doc | 否 | `{VALIDATION_DATA}` | 实验性能和局域配位表征。 |

**输出**：Cu-NxBy 候选排序、CH4 选择性设计规则、需实验验证的优先候选

**质量门禁**：
- 排序依据可回溯到原始吸附/自由能/能垒数据
- 推荐位点的结构与配位环境明确
- 计算预测和实验观察分开报告

**操作指令**：`依据 {REACTION_ANALYSIS} 对 Cu-NxBy 候选排序；将 CH4 路径、HER 竞争、位点稳定性及验证数据分列，输出推荐、淘汰和待验证候选，不把单一描述符当作充分证据。`
