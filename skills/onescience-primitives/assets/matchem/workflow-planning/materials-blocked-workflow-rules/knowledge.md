# Materials Workflow BLOCKED 触发规则

## 适用范围
当材料化学任务（如材料模拟、性能计算、高通量筛选）的必填输入缺失时，系统必须停止执行并标记BLOCKED状态。适用于所有需要用户提供材料结构、工况参数或电池配置的场景。

## 输入
- 材料结构数据：CIF、POSCAR或其他晶体结构格式
- 电池工况参数：温度、压力、循环次数等
- 电解液/对电极信息：电解液组成、对电极材料等
- 任务配置：计算方法、软件、精度要求等

## 输出
- BLOCKED状态标记
- 缺失项清单（列出所有缺失的必填输入）
- 建议的后续操作（如请求用户提供缺失数据）

## 流程节点
1. 检查用户输入完整性 → 2. 识别必填输入缺失项 → 3. 标记BLOCKED状态 → 4. 生成缺失清单 → 5. 暂停工作流执行

每步含：操作、参数、工具、质量门禁

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 必填输入类型 | 材料结构、工况参数、电解液信息 | [D1] | 材料模拟任务的核心输入 |
| 缺失判定标准 | 用户未明确提供且无法从公开数据库自动获取 | [归因报告] | 当无法从Materials Project/ICSD获取时视为缺失 |
| BLOCKED状态 | 必须写入task_state.json | [归因报告] | 阻止后续步骤执行 |

## 边界与分流
- 如果用户提供了部分输入，但缺少关键参数，仍应标记BLOCKED
- 如果输入数据来自非权威来源（如假设数据、典型值），应标记PARTIAL而非PASS
- 当无法获取真实数据时，应请求用户提供或从Materials Project API获取

## 质量检查
- 验证所有必填输入是否由用户明确提供
- 检查输入数据的可追溯性（是否有Materials Project编号、ICSD编号、文献DOI）
- 确认BLOCKED状态已写入task_state.json

## 回退策略
- 如果用户无法提供缺失数据，可尝试从Materials Project API获取默认结构
- 如果API也无法获取，应终止任务并说明原因

## 资源召回建议
- 当任务涉及材料模拟时召回本卡片
- 当用户未提供材料结构数据时召回本卡片
- 当需要验证输入数据完整性时召回本卡片
