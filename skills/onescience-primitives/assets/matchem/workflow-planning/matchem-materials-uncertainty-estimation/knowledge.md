# 材料筛选不确定性估计工作流

## 适用范围

**触发条件**：
- 需要评估机器学习模型预测的不确定性
- 需要在材料筛选中考虑预测可靠性
- 需要量化模型风险以支持决策

**适用场景**：
- 高通量材料筛选中的风险评估
- 无铅杂化钙钛矿稳定性预测的不确定性量化
- 材料性能预测的可靠性分析
- 模型选择和优化中的不确定性比较

**不适用场景**：
- 仅需点预测而不需要不确定性估计
- 研究对象为确定性模型（如物理方程求解）
- 计算资源极度受限的场景

## 输入

**输入数据**：
- 训练好的机器学习模型
- 训练数据集（用于不确定性估计）
- 测试数据（可选，用于验证不确定性校准）

**预处理要求**：
- 模型已训练完成
- 训练数据可用于重采样或贝叶斯推断
- 数据划分：训练集/验证集/测试集

## 输出

**输出产物**：
- 预测值和不确定性估计
- 不确定性校准曲线
- 风险决策支持信息

**验证标准**：
- 不确定性估计校准良好（预测区间覆盖率接近置信水平）
- 不确定性与误差相关性高
- 风险决策合理

## 流程节点

### Step 1：不确定性方法选择

- **操作**：根据模型类型选择不确定性估计方法
- **参数**：
  - 方法类型：集成方法 / 贝叶斯方法 / Dropout方法
  - 模型兼容性：随机森林、神经网络、高斯过程
- **工具**：scikit-learn, TensorFlow/PyTorch, GPyTorch
- **质量门禁**：方法与模型类型兼容

### Step 2：集成不确定性估计（适用于树模型）

- **操作**：使用随机森林的树间方差作为不确定性
- **参数**：
  - 集成大小：n_estimators（如100）
  - 不确定性度量：树预测的标准差或方差
  - 校准方法：分位数回归或高斯过程校准
- **工具**：scikit-learn, numpy
- **质量门禁**：不确定性估计合理，与预测误差相关

### Step 3：贝叶斯不确定性估计（适用于深度学习）

- **操作**：使用贝叶斯神经网络或变分推断
- **参数**：
  - 后验近似：变分推断或马尔可夫链蒙特卡洛
  - 采样数量：MCMC样本数或变分推断采样数
  - 不确定性分解：认知不确定性 + 随机不确定性
- **工具**：TensorFlow Probability, Pyro, GPyTorch
- **质量门禁**：后验收敛，不确定性分解合理

### Step 4：Dropout不确定性估计（适用于神经网络）

- **操作**：使用蒙特卡洛dropout估计预测不确定性
- **参数**：
  - Dropout率：0.1-0.5
  - 采样次数：50-100次
  - 不确定性度量：多次预测的标准差
- **工具**：TensorFlow, PyTorch
- **质量门禁**：多次预测稳定性好，不确定性合理

### Step 5：不确定性校准与验证

- **操作**：校准不确定性估计并验证
- **参数**：
  - 校准方法：Platt scaling, isotonic regression
  - 验证指标：预测区间覆盖率、校准曲线
  - 置信水平：90%, 95%, 99%
- **工具**：scikit-learn, matplotlib
- **质量门禁**：校准曲线接近对角线，覆盖率接近置信水平

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 集成方法 | RandomForest | [1] | 树间方差作为不确定性 |
| 贝叶斯方法 | 变分推断 | [2] | 后验近似方法 |
| Dropout率 | 0.1-0.5 | [1] | 蒙特卡洛dropout参数 |
| 采样次数 | 50-100 | [1] | 不确定性估计稳定性 |
| 置信水平 | 95% | [1] | 标准置信水平 |
| 校准方法 | Platt scaling | [1] | 不确定性校准方法 |

## 边界与分流

**异常处理**：
- 不确定性估计过高：检查模型复杂度和数据质量
- 校准失败：尝试其他校准方法或简化不确定性模型
- 计算资源不足：使用近似方法或减少采样次数

**降级策略**：
- 优先使用集成方法（简单有效）
- 次选dropout方法（适用于神经网络）
- 备选贝叶斯方法（计算成本高但更准确）

**分支条件**：
- 树模型 → 集成方法
- 神经网络 → Dropout或贝叶斯方法
- 高斯过程 → 内置不确定性

## 质量检查

**验证点**：
1. 不确定性估计合理性：不确定性与预测误差正相关
2. 校准良好：预测区间覆盖率接近置信水平
3. 计算效率：不确定性估计时间在可接受范围内
4. 稳定性：多次运行结果一致

**阈值**：
- 预测区间覆盖率：90%±5%（对于95%置信水平）
- 校准误差：< 0.1
- 不确定性与误差相关系数：> 0.5

**失败处理**：
- 标记不确定性估计失败
- 记录失败原因
- 提供简化不确定性估计

## 回退策略

**失败时的替代方案**：
1. 集成方法失败 → 使用简化集成（减少树数量）
2. 贝叶斯方法失败 → 使用dropout方法
3. 校准失败 → 使用未校准的不确定性估计
