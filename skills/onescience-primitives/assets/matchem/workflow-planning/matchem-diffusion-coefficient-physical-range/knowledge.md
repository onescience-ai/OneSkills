# 金属中扩散系数物理合理性检查

## 适用范围

面向金属中扩散系数的物理合理性检查需求，定义扩散系数的合理范围、温度依赖关系（Arrhenius关系）、晶格扩散与晶界扩散的数量级差异。适用于需要验证扩散系数计算结果物理合理性的场景，包括DFT/MD计算结果验证、实验数据合理性检查、扩散机制分析。当扩散系数数值异常时，提供检查规则和异常数据标记方法。

## 输入

**必要输入**：
- 扩散系数计算结果（数值和单位）
- 温度数据（开尔文温度）
- 扩散机制类型（晶格扩散、晶界扩散、界面扩散）

**可选输入**：
- 材料体系信息（金属类型、晶体结构）
- 扩散激活能（Arrhenius关系参数）
- 实验数据对比

**数据要求**：
- 扩散系数单位正确（m²/s或cm²/s）
- 温度数据完整，无缺失
- 扩散机制类型明确

## 输出

**主要输出**：
- 物理合理性检查结果
- 异常数据标记（PASS/PARTIAL/REJECT/BLOCKED）
- 温度单调性验证结果
- Arrhenius关系验证结果

**验证标准**：
- 扩散系数在合理范围内
- 温度单调性正确（扩散系数随温度升高而增大）
- Arrhenius关系成立（D=D0*exp(-Q/kT)）

## 流程节点

### Step 1：扩散系数范围检查
- **操作**：检查扩散系数数值是否在物理合理范围内
- **参数**：扩散系数值，扩散机制类型
- **工具**：范围检查脚本
- **质量门禁**：扩散系数在合理范围内

### Step 2：温度单调性验证
- **操作**：验证扩散系数随温度变化的单调性
- **参数**：扩散系数值，温度数据
- **工具**：单调性检查脚本
- **质量门禁**：扩散系数随温度升高而增大

### Step 3：Arrhenius关系验证
- **操作**：验证扩散系数是否符合Arrhenius关系
- **参数**：扩散系数值，温度数据，激活能
- **工具**：Arrhenius拟合脚本
- **质量门禁**：Arrhenius关系成立，线性拟合R²≥0.95

### Step 4：异常数据标记
- **操作**：对异常数据进行标记和分类
- **参数**：检查结果，异常类型
- **工具**：标记脚本
- **质量门禁**：标记正确，无遗漏

### Step 5：检查报告生成
- **操作**：生成物理合理性检查报告
- **参数**：检查结果，标记结果
- **工具**：报告生成脚本
- **质量门禁**：报告完整，状态明确

## 边界与分流

**异常处理**：
- 扩散系数超出范围 → 标记REJECT，检查计算方法
- 温度单调性错误 → 标记PARTIAL，检查数据质量
- Arrhenius关系不成立 → 标记PARTIAL，检查激活能参数
- 数据缺失 → 标记BLOCKED，补充数据

**降级策略**：
- 无法验证Arrhenius关系时 → 仅验证范围检查
- 缺少激活能参数时 → 使用经验公式估算
- 数据质量差时 → 标记PARTIAL，建议重新计算

**分支条件**：
- 扩散系数在范围内 → 继续温度单调性验证
- 扩散系数超出范围 → 标记REJECT
- 温度单调性正确 → 继续Arrhenius关系验证
- 温度单调性错误 → 标记PARTIAL

## 质量检查

**验证点**：
1. 扩散系数范围：数值在1e-30到1e-10 m²/s范围内
2. 温度单调性：扩散系数随温度升高而增大
3. Arrhenius关系：线性拟合R²≥0.95
4. 数据完整性：温度数据完整，无缺失
5. 标记正确性：异常数据标记正确，无遗漏

**阈值**：
- 扩散系数范围：100%在范围内
- 温度单调性：100%正确
- Arrhenius关系：R²≥0.95
- 数据完整性：温度数据100%完整
- 标记正确性：100%正确

**失败处理**：
- 范围检查失败 → 标记REJECT，检查计算方法
- 单调性验证失败 → 标记PARTIAL，检查数据质量
- Arrhenius关系验证失败 → 标记PARTIAL，检查激活能参数
- 数据不完整 → 标记BLOCKED，补充数据

## 回退策略

**替代方案**：
1. 使用文献数据替代计算数据
2. 采用简化验证（仅检查范围）
3. 降级为人工检查
4. 使用保守状态判定（标记为REJECT）

**回退触发条件**：
- 无法完成完整验证
- 数据质量太差
- 缺少必要参数
- 验证方法不可用
