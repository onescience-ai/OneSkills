# 模型适用域检测方法

## 适用范围

**触发条件**：
- 需要评估机器学习模型在新材料上的预测可靠性
- 需要识别模型预测的置信度范围
- 需要区分模型内插和外推的预测结果

**适用场景**：
- 材料发现中的模型筛选和排序
- 高通量计算中的预测可靠性评估
- 模型部署前的性能验证
- 多模型集成中的权重分配

**不适用场景**：
- 需要实时在线学习的场景
- 需要处理全新材料类别的场景（无训练数据）
- 需要解释模型内部机制的场景（可解释性问题）

## 输入

**必要输入**：
- 训练数据集（包含特征和标签）
- 待预测的候选材料数据
- 已训练的机器学习模型

**可选输入**：
- 验证数据集（用于校准阈值）
- 领域知识（用于特征选择）
- 实验数据（用于验证）

## 输出

**主要输出**：
- 适用域边界定义
- 每个候选材料的域内/域外标记
- 预测置信度分数
- 不确定性估计

**验证标准**：
- 域内预测误差 < 域外预测误差
- 置信度分数与预测误差相关
- 标记结果与领域知识一致

## 流程节点

### Step 1：特征空间分析

**操作**：分析训练数据的特征分布
- **特征选择**：选择代表性特征（组成、结构、性质）
- **降维可视化**：使用PCA/t-SNE可视化特征空间
- **分布统计**：计算特征的均值、方差、分位数

**参数**：
- 特征数量：10-100个
- 降维维度：2-3维
- 统计方法：均值、标准差、四分位数

**质量门禁**：
- 特征代表性检查
- 分布合理性验证
- 无多重共线性

### Step 2：距离度量计算

**操作**：计算候选材料与训练数据的距离
- **距离度量**：欧氏距离、马氏距离、余弦相似度
- **最近邻分析**：找到训练数据中的最近邻
- **距离分布**：计算距离的统计分布

**参数**：
- 距离度量：欧氏距离（标准化后）
- 最近邻数量：k=5-10
- 距离阈值：基于训练数据分布的95%分位数

**质量门禁**：
- 距离计算正确
- 阈值选择合理
- 计算效率可接受

### Step 3：概率密度估计

**操作**：估计训练数据在特征空间中的概率密度
- **核密度估计**：使用高斯核估计密度
- **高斯混合模型**：拟合多个高斯分布
- **密度阈值**：设置最低密度阈值

**参数**：
- 核函数：高斯核
- 带宽选择：Silverman规则或交叉验证
- 密度阈值：训练数据密度的5%分位数

**质量门禁**：
- 密度估计平滑
- 阈值选择合理
- 计算稳定性

### Step 4：置信度评估

**操作**：评估模型预测的置信度
- **集成方法**：使用多个模型的预测方差
- **贝叶斯方法**：估计预测的后验分布
- **蒙特卡洛Dropout**：使用Dropout估计不确定性

**参数**：
- 集成模型数量：5-10个
- Dropout率：0.1-0.3
- 置信度阈值：0.7-0.9

**质量门禁**：
- 不确定性估计合理
- 置信度与误差相关
- 计算成本可接受

### Step 5：域内/域外标记

**操作**：根据适用域标准标记候选材料
- **组合标准**：距离 + 密度 + 置信度
- **标记规则**：满足所有条件为域内，否则为域外
- **报告生成**：生成详细的适用域报告

**参数**：
- 距离阈值：训练数据95%分位数
- 密度阈值：训练数据5%分位数
- 置信度阈值：0.7

**质量门禁**：
- 标记一致性
- 报告完整性
- 结果可解释性

## 边界与分流

**异常处理**：
- 距离计算失败 → 使用替代距离度量或简化特征
- 密度估计不稳定 → 调整核带宽或使用参数化模型
- 置信度估计不准确 → 增加集成模型数量或使用更复杂的方法
- 标记结果不合理 → 调整阈值或使用组合标准

**降级策略**：
- 复杂方法不可用 → 使用简单的距离阈值方法
- 计算资源不足 → 使用采样或近似方法
- 领域知识缺乏 → 使用纯数据驱动方法

## 质量检查

**验证点**：
1. 特征代表性：特征能够区分不同材料类别
2. 距离阈值合理性：阈值能够区分内插和外推
3. 密度估计准确性：密度估计反映训练数据分布
4. 置信度校准：置信度分数与预测误差相关
5. 标记一致性：域内/域外标记与领域知识一致

**失败处理**：
- 特征不具代表性 → 重新选择特征或使用自动特征工程
- 阈值不合理 → 使用交叉验证调整阈值
- 标记不一致 → 结合领域知识调整标准

## 回退策略

**替代方案**：
1. 使用简单的距离阈值方法
2. 使用基于规则的适用域定义
3. 使用专家系统进行适用域判断
4. 使用多模型集成的一致性作为适用域指标
