# 固态锂离子导体无监督发现工作流范式

## 适用范围

本卡片服务于在未偏置的材料空间中探索性搜索新型固态离子导体的任务，适用于以下场景：

- 需要发现全新化学组成或结构原型的固态电解质材料
- 目标属性（离子电导率）的高质量标注数据稀缺
- 候选材料空间巨大（数千至数万种化合物），需要高效筛选策略
- 已知导体种类有限，需要突破现有化学体系的限制

不适用场景：
- 对单一已知材料进行验证性模拟
- 已有充足监督学习训练数据的属性预测任务
- 用户明确指定目标材料且仅需验证其性能

## 输入

| 输入项 | 格式 | 来源 | 预处理要求 |
|--------|------|------|------------|
| 材料结构数据库 | CIF/POSCAR | Materials Project/ICSD/用户指定 | 提取阴离子亚晶格，去除过渡金属化合物（可选） |
| 已知导体样本 | 结构+电导率 | 文献实验数据/计算数据 | 标注σ_RT值，用于聚类验证 |
| 搜索空间约束 | 元素范围/结构原型 | 用户定义 | 明确允许/禁止的元素组合 |

## 输出

| 输出项 | 格式 | 验证标准 |
|--------|------|----------|
| 候选材料列表 | JSON/CSV | 包含化学式、结构类型、来源数据库编号 |
| 聚类分组结果 | JSON | 包含每个材料的分组标签、聚类置信度 |
| 离子电导率预测 | JSON | σ_RT值、活化能Ea、AIMD模拟参数 |
| 筛选排序报告 | Markdown | 按σ_RT排序、标注发现新意性 |

## 流程节点

### 节点1：搜索空间定义
- **操作**：从数据库提取含目标离子（如Li）的化合物，定义化学组成范围和结构原型约束
- **参数**：数据库来源、元素过滤条件、结构类型过滤
- **工具**：Materials Project API / ICSD查询 / 用户指定
- **质量门禁**：搜索空间覆盖率评估，确保包含已知导体作为验证集

### 节点2：材料表示构建
- **操作**：为每个候选材料构建定量表示（如修改X射线衍射图mXRD）
- **参数**：衍射角范围、阴离子类型、原子体积归一化
- **工具**：晶体结构分析脚本
- **质量门禁**：表示唯一性验证，确保不同结构产生不同表示

### 节点3：无监督聚类
- **操作**：使用无监督学习算法对材料表示进行聚类
- **参数**：聚类算法（层次聚类/谱聚类）、分组数量
- **工具**：scikit-learn / 自定义聚类脚本
- **质量门禁**：已知高导体聚集在特定分组中，统计检验验证分组与电导率相关性

### 节点4：候选筛选
- **操作**：从聚类结果中选取与已知高导体同组的候选材料
- **参数**：交集阈值、最低候选数量
- **工具**：集合运算脚本
- **质量门禁**：候选数量从数千减少至数十至数百，降低后续计算成本

### 节点5：高通量计算验证
- **操作**：对候选材料进行第一性原理计算（AIMD）验证离子电导率
- **参数**：温度、模拟时间、势函数类型
- **工具**：VASP/CP2K等第一性原理软件
- **质量门禁**：计算收敛性验证、与已知实验值对比误差<1个数量级

### 节点6：结果排序与推荐
- **操作**：按预测电导率排序，评估新材料的新颖性
- **参数**：排序指标（σ_RT、Ea）、新颖性评估标准
- **工具**：数据分析脚本
- **质量门禁**：推荐材料与已知导体在结构/化学上有显著差异

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 无监督学习适用条件 | 标注数据<100条 | [1] | 当高质量属性数据稀缺时优先使用无监督方法 |
| 聚类质量验证 | t检验p<0.05 | [1] | 高导体组与低导体组电导率分布有统计学显著差异 |
| 候选筛选比例 | 100:1至30:1 | [1] | 从数千候选筛选至数十至数百 |
| AIMD验证精度 | σ_RT误差<1个数量级 | [1] | 与实验值对比可接受范围 |

### 校准数值（以下数值来自LLZO/LGPS体系，供量级校准；其他体系需以自身证据重新锚定）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 高导体σ_RT阈值 | >10⁻⁴ S/cm | [1] | 实用固态电解质最低要求 |
| 最优σ_RT水平 | 10⁻³–10⁻² S/cm | [1] | 与液态电解质可比 |
| 活化能Ea范围 | 0.17–0.45 eV | [1] | 新发现导体的典型范围 |
| 训练集规模 | 528个代表结构 | [1] | 从2986个ICSD条目去重后 |

## 边界与分流

### 前提不成立时的改道方案

| 前提 | 不成立条件 | 改道方案 |
|------|------------|----------|
| 搜索空间包含足够候选 | 数据库中含目标离子的化合物<100 | 扩展数据库来源或放宽元素约束 |
| 无监督聚类有效 | 已知高导体未聚集在特定分组 | 转向监督学习（需补充标注数据）或调整材料表示方法 |
| AIMD计算可行 | 候选数量>100且计算资源有限 | 分层筛选：先用快速描述符预筛，再对Top-N进行AIMD |

### 异常处理

- **聚类结果无明显高导体聚集**：检查材料表示是否充分捕捉结构特征，考虑增加表示维度
- **AIMD计算发散**：检查初始结构稳定性，必要时先进行结构弛豫
- **候选材料与已知导体高度重叠**：扩大搜索空间或调整聚类参数

## 质量检查

| 检查点 | 标准 | 失败处理 |
|--------|------|----------|
| 搜索空间覆盖 | 包含所有已知高导体类型 | 补充缺失的结构类型 |
| 聚类有效性 | 已知高导体聚集在≤3个分组 | 重新调整聚类参数或更换算法 |
| 计算收敛性 | AIMD轨迹能量波动<5% | 延长模拟时间或调整温度 |
| 新颖性评估 | 推荐材料与已知导体结构相似度<0.7 | 重新评估筛选标准 |

## 回退策略

1. **无监督聚类失败**：回退到基于规则的筛选（如bcc阴离子堆积规则）
2. **AIMD计算成本过高**：使用经验势函数或机器学习势函数替代
3. **候选材料均为已知导体**：扩大搜索空间至含过渡金属化合物
