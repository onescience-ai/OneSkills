# 分子动力学模拟输入审计规范

## 适用范围
触发条件：执行分子动力学模拟任务前的输入验证阶段，特别是涉及多组分界面体系（如CO2/Cu(111)/水/K）、同位素对比实验（12C/13C）时。
适用场景：任何需要确保输入数据完整性和正确性的MD模拟任务。
不适用场景：已确认输入完整的后续步骤。

## 输入
- 用户提供的结构文件（POSCAR/data/lmp/mol格式）
- DFT计算输出文件（OUTCAR/CONTCAR/XDATCAR）
- AIMD轨迹文件
- 力场参数文件
- 训练/验证/测试数据集
- 历史参考文献

## 输出
- 输入审计报告（包含每个输入项的来源、格式校验结果、异常标识和正式/参考分类）
- 待确认清单（列出需要用户确认的项目）
- 数据血缘追溯记录

## 流程节点
1. 结构文件解析 → 2. 格式校验 → 3. 来源追溯 → 4. 异常标识 → 5. 分类标记 → 6. 生成审计报告

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 结构文件格式 | POSCAR/data/lmp/mol | 通用 | LAMMPS支持的多种格式 |
| DFT能量收敛阈值 | < 1e-4 eV | 通用标准 | 电子步收敛标准 |
| DFT力收敛阈值 | < 0.01 eV/Å | 通用标准 | 离子步收敛标准 |
| AIMD能量漂移 | < 0.1 meV/atom | 通用标准 | 轨迹稳定性指标 |
| 训练:验证:测试比例 | 7:1.5:1.5 | 通用标准 | 数据划分规范 |

## 边界与分流
- 结构文件缺失：请求用户提供
- DFT未收敛：标记为异常，要求重新计算
- AIMD不稳定：标记为待确认，不作为正式输入
- 历史资料：仅作为参考，不作为正式输入

## 质量检查
- 每个输入项必须有明确的来源记录
- 格式校验必须通过
- 异常数据必须标识
- 正式输入与参考资料必须明确区分

## 回退策略
- 输入不完整：暂停任务，请求用户提供
- 输入异常：标记并报告，不使用异常数据
