# LAMMPS超胞构建规范

## 适用范围
触发条件：需要构建LAMMPS模拟超胞时，特别是涉及表面模型（如Cu(111)）的界面体系。
适用场景：任何需要周期性边界条件的MD模拟超胞构建。
不适用场景：非周期性体系或已确认超胞正确的后续步骤。

## 输入
- 原始晶胞参数（a, b, c, α, β, γ）
- 扩胞倍数（nx, ny, nz）
- 元素类型列表
- 固定原子组定义

## 输出
- LAMMPS data文件（包含原子坐标、原子类型、质量、键合信息）
- 超胞构建报告（包含原子数统计、固定原子组映射、晶胞参数和元素类型对应关系）
- 预检报告

## 流程节点
1. 晶胞参数解析 → 2. 三斜晶胞计算 → 3. 扩胞操作 → 4. 元素映射 → 5. 固定原子组设置 → 6. 输出文件生成 → 7. 预检验证

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| Cu(111) FCC基元 | 2原子/晶胞 | 晶体学 | 面心立方结构 |
| Cu晶格常数 | 3.615 Å | 实验值 | 25°C |
| 3×3超胞Cu原子数 | 4层×3×3×2=72原子 | 计算 | 标准3×3×4超胞 |
| 标准固定Cu数 | 288原子 | 任务要求 | 需要更大的超胞或更多层 |
| 固定层选择 | 底部两层 | 通用标准 | 表面模拟固定底层 |
| 三斜晶胞体积 | a·b·c·√(1-cos²α-cos²β-cos²γ+2cosαcosβcosγ) | 公式 | 通用计算 |

## 边界与分流
- 晶胞参数缺失：请求用户提供或从POSCAR解析
- 元素类型不匹配：标记错误，请求用户确认
- 固定原子数不符合要求：调整超胞尺寸或层数

## 质量检查
- 原子总数必须正确
- 固定原子组映射必须准确
- 晶胞参数必须与输入一致
- 元素类型对应关系必须正确

## 回退策略
- 超胞构建失败：检查输入参数，请求用户协助
- 固定原子数不满足：调整超胞尺寸或层数
