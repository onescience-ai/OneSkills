# 蛋白口袋PDB文件格式与获取方法

## 适用范围
本卡服务的问题类是如何在靶标特异性分子生成任务中获取、验证和准备符合科学要求的蛋白口袋PDB文件。适用于需要蛋白三维结构作为输入的各类分子生成、分子对接、虚拟筛选和基于结构的药物设计任务，尤其针对结合口袋的几何特征和化学环境要求。

## 输入
- 目标蛋白的PDB ID或序列信息
- 结合口袋的定义（残基列表、距离阈值、几何约束）
- 分子生成任务的输入要求（原子类型、坐标格式、文件大小限制）
- 数据来源偏好（实验结构、同源建模、预测结构）

## 输出
- 符合PDB格式规范的蛋白口袋文件
- 口袋几何特征验证报告
- 原子坐标和残基信息完整性检查
- 口袋体积、表面积、可及性等量化指标

## 流程节点
1. **结构获取** → 从PDB数据库下载实验结构或使用预测模型
2. **结构预处理** → 添加氢原子、修复缺失残基、优化质子化状态
3. **口袋定义** → 基于配体位置或几何特征确定结合口袋
4. **坐标提取** → 提取口袋周围一定半径内的原子坐标
5. **格式验证** → 检查PDB格式规范、原子命名、坐标精度
6. **质量评估** → 评估口袋几何合理性、化学环境完整性

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| PDB格式版本 | 3.0 | [D1] | 标准PDB格式规范 |
| 原子坐标精度 | 3位小数（Å） | [D1] | X,Y,Z正交坐标 |
| 原子命名规范 | IUPAC标准 | [D1] | 元素符号右对齐，残基名左对齐 |
| 口袋半径 | 5-15 Å | [D1] | 基于配体中心的距离 |
| 氢原子处理 | 可选添加 | [D1] | 影响分子对接精度 |

### 校准数值（以下数值来自常见蛋白口袋，供量级校准；其他体系需以自身证据重新锚定）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 典型口袋原子数 | 100-1000 | [D1] | 取决于口袋大小 |
| 口袋体积 | 100-1000 ų | [D1] | 结合位点体积范围 |
| 残基数量 | 10-50个残基 | [D1] | 口袋周围残基 |
| 文件大小 | 10-100 KB | [D1] | 单个口袋PDB文件 |

## 边界与分流
- **结构质量差**：使用同源建模或预测模型（AlphaFold、RoseTTAFold）
- **缺失原子/残基**：使用补全工具（MODELLER、SCWRL）
- **质子化状态不确定**：使用pKa预测工具（H++、PROPKA）
- **口袋定义模糊**：基于保守性分析或分子探针扫描
- **格式不兼容**：转换格式或使用格式转换工具（Open Babel）

## 质量检查
- PDB格式语法检查（记录类型、字段对齐、数据类型）
- 原子命名一致性检查（元素符号、残基名、链标识符）
- 坐标合理性检查（距离、角度、二面角）
- 口袋几何检查（体积、可及性、氢键网络）

## 回退策略
- 实验结构不可用时，使用同源模型或预测结构
- 结构质量不足时，进行能量最小化或分子动力学优化
- 口袋定义不明确时，使用多种定义方法交叉验证
- 格式转换失败时，手动编辑或使用其他工具
