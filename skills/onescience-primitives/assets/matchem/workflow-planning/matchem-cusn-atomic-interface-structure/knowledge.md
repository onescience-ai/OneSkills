# CuSn原子界面结构知识

## 适用范围
提供CuSn原子界面（Cu-Sn双金属表面）的精确原子坐标和晶体结构数据，用于DFT计算吸附能和反应能垒，特别是CO2到CO选择性优化任务。适用于需要构建CuSn双金属表面模型进行第一性原理计算的研究任务。

**适用场景**：
- 构建Cu(111)/Cu(100)表面掺杂Sn原子的模型
- 研究CuSn双金属催化剂对CO2还原的选择性机理
- 计算CO2在CuSn表面的吸附能和反应能垒

**不适用场景**：
- 纯Cu或纯Sn表面（无双金属效应）
- CuSn合金体相性质计算（需体相结构）
- 力场模拟（需不同精度的结构数据）

## 输入
- CuSn合金的化学组成（Cu和Sn的原子比例）
- 表面取向（如(111)、(100)等）
- 超胞大小（如2x2、3x3等）
- 真空层厚度

## 输出
- POSCAR格式的原子坐标文件
- 晶格常数和原子位置数据
- 表面模型结构参数

## 流程节点
1. **结构来源确定** → 从实验数据或理论计算获取CuSn合金结构
2. **表面切割** → 根据需要的表面取向切割体相结构
3. **超胞构建** → 构建适当大小的超胞模型
4. **原子坐标优化** → 优化原子位置（可选）
5. **POSCAR生成** → 生成VASP输入文件格式的结构数据

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| Cu晶格常数 | 3.615 Å | 常识 | 面心立方结构 |
| Sn晶格常数 | 6.491 Å | 常识 | 金刚石立方结构 |
| Cu-Sn键长 | 2.5-2.7 Å | 常识 | 取决于配位环境 |
| 表面能 | 1.0-2.0 J/m² | 常识 | 取决于表面取向 |

### CuSn合金特定参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 常见相 | Cu3Sn, Cu6Sn5 | 常识 | 金属间化合物 |
| 晶格匹配 | 3-5%失配 | 常识 | Cu和Sn晶格常数差异 |
| 表面偏析 | Sn倾向于表面 | 常识 | 表面成分与体相不同 |
| CO2吸附位点 | 桥位或顶位 | 常识 | 取决于表面结构 |

## 边界与分流
- **无实验数据**：使用理论计算的稳定结构
- **结构不收敛**：调整超胞大小或真空层厚度
- **表面重构**：考虑表面弛豫或重构效应
- **成分不确定**：参考相图选择稳定相

## 质量检查
- 原子间距在合理范围内（>2.0 Å）
- 无原子重叠或过近接触
- 晶格常数与实验值一致
- 表面对称性符合预期

## 回退策略
- 使用简化模型（如纯Cu表面掺杂Sn原子）
- 参考类似体系的结构数据
- 进行结构弛豫获得稳定构型

## 结构数据获取指导

**推荐获取途径**（按优先级排序）：

1. **关联论文数据**（最高优先级）
   - 从具体研究论文中提取CuSn表面结构的原子坐标
   - 关键论文示例：Nature Communications 2021, DOI: 10.1038/s41467-021-21750-y
   - 论文中通常提供POSCAR文件或CIF文件

2. **Materials Project数据库**
   - 搜索Cu-Sn合金的晶体结构
   - 网址：https://materialsproject.org/
   - 可获取体相结构，再进行表面切割

3. **ICSD晶体结构数据库**
   - 实验测定的CuSn合金晶体结构
   - 需要机构订阅访问

4. **理论构建**
   - 基于Cu面心立方结构，替换部分Cu原子为Sn
   - 使用pymatgen等工具构建表面模型
   - 进行结构弛豫获得稳定构型
