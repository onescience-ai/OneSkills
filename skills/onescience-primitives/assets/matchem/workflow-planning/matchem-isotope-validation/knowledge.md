# 同位素效应验证标准

## 适用范围
触发条件：需要验证同位素效应（如12C/13C）的动力学模拟任务，特别是涉及扩散、吸附、反应等动力学过程时。
适用场景：任何需要定量验证同位素效应的MD模拟任务。
不适用场景：不涉及同位素对比的模拟任务。

## 输入
- 12C和13C的MD轨迹文件
- 扩散系数计算结果
- 参考文献中的同位素效应数据

## 输出
- 同位素效应验证报告（包含统计检验结果、物理合理性分析、限制条件说明）
- 验收判定结论
- 后续采样建议

## 流程节点
1. 轨迹分析 → 2. 扩散系数计算 → 3. 统计显著性检验 → 4. 物理合理性检查 → 5. 验收判定 → 6. 生成报告

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 质量效应预期 | D(13C) < D(12C) | 物理学 | 重同位素扩散更慢 |
| 扩散系数比值 | D(13C)/D(12C) < 1 | 理论 | 质量效应导致比值<1 |
| 统计显著性阈值 | p < 0.05 | 统计学 | t检验或ANOVA |
| 样本量要求 | n ≥ 3 | 统计学 | 每个体系至少3次独立模拟 |
| 能量守恒检查 | 能量漂移 < 0.1 meV/atom | 通用标准 | 模拟稳定性 |
| 温度稳定性 | 温度波动 < 5% | 通用标准 | 系综稳定性 |

## 边界与分流
- 扩散系数比值>1（与质量效应预期相反）：标记异常，检查模拟设置
- 统计不显著：增加采样或延长模拟时间
- 能量不守恒：检查力场参数和积分步长

## 质量检查
- 扩散系数计算方法必须正确（MSD拟合）
- 统计检验必须通过
- 物理合理性必须满足
- 限制条件必须说明

## 回退策略
- 统计不显著：增加模拟次数或延长模拟时间
- 物理不合理：检查力场参数和模拟设置
