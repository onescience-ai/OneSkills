## 工作流

### 步骤 1：成分与结构搜索空间定义

**目的**：建立成分、压力和对称性约束。

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 成分与化学计量 | `{COMPOSITION}` | str | 是 | `目标化学式` | 给出元素、比例、价态假设和电荷约束。 |
| 结构约束 | `{STRUCTURE_CONSTRAINTS}` | object | 是 | {"pressure_GPa": 0, "max_atoms": 64} | 空间群、压力、原子数、层状或配位约束。 |

**输出**：搜索空间清单、初始构型

**质量门禁**：
- 化学计量和电荷约束一致
- 结构约束可复现

**操作指令**：`根据 {COMPOSITION} 和 {STRUCTURE_CONSTRAINTS} 生成合法搜索空间；不明确的价态或压力边界标记 BLOCKED。`

### 步骤 2：候选结构生成与去重

**目的**：生成多样候选构型并去除等价结构。

**依赖步骤**：s01

| 参数 | 变量名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|---|
| 结构约束 | `{STRUCTURE_CONSTRAINTS}` | object | 是 | {"pressure_GPa": 0, "max_atoms": 64} | 空间群、压力、原子数、层状或配位约束。 |

**输出**：候选结构库、去重日志

**质量门禁**：
- 无原子重叠
- 等价结构不重复计数

**操作指令**：`在 {STRUCTURE_CONSTRAINTS} 内生成并去重候选，保留生成器、种子和对称性信息。`

### 步骤 3：弛豫与稳定性排序

**目的**：对候选结构统一弛豫并计算稳定性指标。

**依赖步骤**：s02

|---|---|---|---|---|---|

**输出**：弛豫结构、稳定性排序

**质量门禁**：
- 收敛标准统一
- 参考态定义明确

**操作指令**：`按 {RELAX_CONFIG} 弛豫候选，比较能量、体积和稳定性；不同设置的结果不得直接排序。`

### 步骤 4：结构验证与输出

**目的**：对优先结构做独立检查和可合成性判断。

**依赖步骤**：s03

**输出**：优先结构、验证清单、PASS/REJECT/BLOCKED 结论

**质量门禁**：

- 输入和命令可复现
