# PtSA-NiO/Ni催化剂电化学合成协议

## 适用范围

本协议适用于制备用于碱性氢析出反应的负载型单原子催化剂，特别是当目标催化剂涉及金属氧化物/金属异质结构与单原子铂的协同设计，并需要将其集成到柔性、导电的基底上以用于可穿戴或柔性电化学器件时。该合成路线采用顺序电沉积策略，首先构筑异质结构纳米片阵列，再原位锚定贵金属单原子，是一种可扩展的“先构建基底，后负载活性位”的制备方法。

## 输入

- **必需输入**：
  1. **Ag纳米线悬浮液**：通过化学还原法（如乙二醇溶剂热法）制备并纯化。
  2. **柔性导电基底**：如导电布、碳布或柔性聚合物薄膜。
  3. **醋酸镍水溶液**：浓度通常为20 mM，作为Ni源。
  4. **氯铂酸（H2PtCl6）溶液**：作为Pt单原子前驱体，浓度需精确控制在低μM范围（如50 μM）。
  5. **KOH电解质**：1 M KOH溶液，作为电沉积和循环伏安过程的电解质。
  6. **三电极系统**：工作电极（制备中的样品）、参比电极（如饱和甘汞电极SCE）、对电极（如石墨片）。
- **可选输入**：
  1. 基底预处理试剂（如乙醇、丙酮）。
  2. 用于表征的TEM、XRD、XPS等样品制备耗材。

## 输出

- **最终产物**：负载有PtSA-NiO/Ni催化剂的Ag纳米线/柔性布复合电极。
- **产物特征**：该电极具备柔性、自支撑特性。催化剂结构包含三维多孔的NiO/Ni异质结构纳米片，其上均匀分散着锚定的Pt单原子，界面结构有利于电子传输与反应中间体的吸附。
- **后续用途**：可直接用作碱性电解水析氢反应的工作电极进行电化学性能测试，或作为集成到膜电极组件中的催化层。

## 流程节点

本协议的合成流程包含四个顺序步骤，形成有向无环图（DAG）。

### 1. 合成Ag纳米线（s1）
- **步骤描述**：通过油浴加热的溶剂热法还原银盐，合成一维Ag纳米线。
- **上游依赖**：无（起始步骤）。
- **关键参数**：

| 参数名 | 类型 | 默认值 | 取值范围 | 是否必需 |
| :--- | :--- | :--- | :--- | :--- |
| temperature | float | 110 | 100 - 120 | 是 |
| time | int | 12 | 6 - 24 | 是 |

- **输出**：Ag纳米线悬浮液。
- **质量门**：通过离心、洗涤，得到纯净、尺寸均一的Ag纳米线。

### 2. 制备Ag纳米线网络（s2）
- **步骤描述**：将Ag纳米线悬浮液均匀喷涂或涂覆到柔性布基底上，构建三维导电网络。
- **上游依赖**：s1。
- **关键参数**：无电化学参数，重点是控制Ag纳米线的负载量与分布均匀性。
- **输出**：负载有Ag纳米线的柔性导电布。
- **质量门**：布表面形成均匀的Ag纳米线层，质量负载量约为0.47 mg cm⁻²，确保良好的导电性。

### 3. 电沉积NiO/Ni异质结构（s3）
- **步骤描述**：在Ag纳米线网络上，通过恒电位电沉积镍，并控制其氧化状态，形成非晶NiO与晶态Ni的异质结构纳米片。
- **上游依赖**：s2。
- **关键参数**：

| 参数名 | 类型 | 默认值 | 取值范围 | 是否必需 |
| :--- | :--- | :--- | :--- | :--- |
| voltage | float | -3 | -4 ~ -2 | 是 |
| duration | int | 200 | 100 - 300 | 是 |

*注：voltage相对于饱和甘汞电极（SCE）；duration单位为秒。*
- **输出**：NiO/Ni异质结构纳米片阵列（负载于Ag网络上）。
- **质量门**：通过透射电子显微镜确认在Ag纳米线上均匀生长出纳米片，且结构为Ni嵌入非晶NiO基质中。

### 4. 电化学锚定Pt单原子（s4）
- **步骤描述**：将上述NiO/Ni/Ag电极置于含低浓度H2PtCl6的KOH电解质中，通过循环伏安法将Pt前驱体温和还原，并利用NiO/Ni界面锚定Pt单原子。
- **上游依赖**：s3。
- **关键参数**：

| 参数名 | 类型 | 默认值 | 取值范围 | 是否必需 |
| :--- | :--- | :--- | :--- | :--- |
| Pt_concentration | float | 50 | 10 - 100 | 是 |
| cycles | int | 200 | 100 - 300 | 是 |

*注：Pt_concentration单位为μM；扫描电位窗口为0 至 -0.5 V vs RHE。*
- **输出**：PtSA-NiO/Ni/Ag/布柔性电极（即最终产物）。
- **质量门**：通过高角度环形暗场扫描透射电子显微镜确认Pt以原子形式分散在NiO/Ni界面上，未发现Pt纳米簇或颗粒。

## 边界与分流

- **适用边界**：
  1. 本协议核心是“异质结构基底+单原子锚定”的顺序合成策略。若目标异质结构不同（如CoO/Co、FeOx/Fe），可替换金属盐种类，但电沉积电压（s3）需根据具体金属的沉积与氧化特性重新优化。
  2. 仅当需要单原子级贵金属位点时才执行步骤s4。若仅需NiO/Ni异质结构催化剂，完成s3即可。
  3. Ag纳米线网络是实现柔性导电的关键。若无需柔性，可使用平面基底（如碳纸、泡沫镍），此时s2步骤可改为直接将基底浸渍处理。
- **分流方向**：
  1. 若需合成其他金属单原子（如Ru、Ir），可修改s4步骤中的前驱体溶液，但循环伏安的具体参数（浓度、循环数）需实验优化以防止团聚。
  2. 若需更高负载量或三维结构更复杂的催化剂，可考虑结合水热法、化学气相沉积等技术先制备更复杂的NiO/Ni前驱体，再执行s4进行单原子锚定。

## 质量检查

- **中间步骤检查**：
  - s1后：通过动态光散射或电镜检查Ag纳米线长度与直径分布。
  - s2后：通过四探针法测量导电布的方块电阻，评估网络连通性。
  - s3后：采用X射线光电子能谱分析Ni的化学态，确认NiO与Ni共存；通过SEM/TEM观察纳米片形貌。
- **最终产物检查**：
  - s4后：**核心表征**——利用HAADF-STEM直接观察Pt原子是否为单分散状态。配合X射线吸收光谱（如XANES, EXAFS）可进一步确认Pt的配位环境和电子结构。
  - 电化学初步验证：在1 M KOH中进行线性扫描伏安法，测试其析氢起始过电位，以初步判断催化活性。

## 回退策略

- **电沉积NiO/Ni失败**（未形成异质结构纳米片）：
  - 可能原因：电压（s3）控制不当，导致沉积产物为纯Ni或致密NiO膜。
  - 措辞：首先检查并校准电化学工作站的电位。若问题依旧，可尝试微调电压（在-2.5 V至-3.5 V vs SCE范围内探索）或调整醋酸镍浓度，目标是控制Ni的沉积速率与后续氧化程度。
- **Pt单原子锚定失败**（发生团聚）：
  - 可能原因：H2PtCl6浓度过高、还原速度过快（扫描速率过快）或电位窗口不合适。
  - 措辞：立即降低H2PtCl6浓度（如从50 μM降至20 μM），并减少循环伏安的循环次数（如从200降至100）。也可尝试采用更温和的恒电位还原法替代循环伏安法，并严格控制电位。
- **整体电极失活**：
  - 可能原因：Ag纳米线网络在强碱性电沉积或循环过程中被氧化/腐蚀。
  - 措辞：可在s2后增加一步保护处理，如涂覆一层极薄的导电聚合物或碳层，或考虑使用更稳定的导电网络（如碳纳米管网络）。但需验证保护层不影响后续Ni沉积与Pt锚定。

## 资源召回建议

- **核心设备**：具备恒电位/恒电流功能的电化学工作站、喷涂仪（用于s2）、油浴锅、手套箱（如需惰性气氛保护）。
- **表征工具**：SEM、TEM、HAADF-STEM、XRD、XPS、电感耦合等离子体质谱（ICP-MS，用于精确定量Pt负载量）。
- **配套知识**：可参考“单原子电化学锚定技术”、“金属氧化物/金属异质结构电沉积制备”、“柔性电极制备”等相关知识卡，以获取更多制备细节或失败排查经验。
