# 物理信息图神经网络用于合金相预测

## 适用范围

**触发条件**：
- 需要预测多主元合金或高熵合金的相稳定性
- 需要从原子结构直接预测形成能、相图等热力学性质
- 需要结合物理约束提高机器学习模型的可解释性和准确性

**适用场景**：
- B2多主元金属间化合物单相发现
- 高熵合金的相稳定性筛选
- 合金成分优化与设计
- 材料基因组计划的高通量计算

**不适用场景**：
- 需要预测动态性质（如扩散系数）的场景
- 需要处理大尺度微观结构的场景
- 缺乏足够训练数据的全新合金体系

## 输入

**必要输入**：
- 合金成分信息（元素种类和比例）
- 晶体结构信息（晶格参数、原子位置）
- 训练数据集（包含已知合金的形成能、相稳定性等标签）

**可选输入**：
- 磁性配置信息（对于磁性合金）
- 电子结构信息（如态密度）
- 实验验证数据

## 输出

**主要输出**：
- 预测的形成能（eV/atom）
- 相稳定性评估（稳定/亚稳/不稳定）
- 预测置信度/不确定性估计

**验证标准**：
- 与DFT计算结果的对比误差（MAE < 0.1 eV/atom）
- 与实验数据的对比（定性一致性）
- 模型泛化能力评估（交叉验证、外部测试集）

## 流程节点

### Step 1：数据准备与图表示

**操作**：将合金结构转换为图表示
- **节点特征**：原子种类（one-hot编码）、初始磁矩、电负性等
- **边特征**：原子间距离、键角、配位数
- **图构建**：基于截止半径的k近邻图或Voronoi图

**参数**：
- 截止半径：5-8 Å（取决于合金类型）
- 节点特征维度：50-100
- 边特征维度：20-50

**质量门禁**：
- 图连通性检查
- 特征归一化
- 数据增强（对称性操作）

### Step 2：GNN模型架构设计

**操作**：构建物理信息图神经网络
- **消息传递层**：Transformer卷积或MPNN
- **多任务学习**：同时预测节点性质（如局域磁矩）和图性质（如总形成能）
- **物理约束损失函数**：
  - 形成能约束：E_form = E_compound - Σx_i*E_element
  - 相稳定性约束：energy above hull < 25 meV/atom
  - 对称性约束：晶体对称性保持

**参数**：
- 卷积层数：3-6层
- 隐藏维度：64-256
- 注意力机制：多头注意力（4-8头）
- 激活函数：LeakyReLU

**质量门禁**：
- 梯度流动检查
- 过拟合监控（早停法）
- 物理约束满足度验证

### Step 3：模型训练与验证

**操作**：训练模型并评估性能
- **训练策略**：Adam/AdamW优化器，学习率调度
- **验证方法**：k折交叉验证、外部测试集
- **性能指标**：MAE、RMSE、R²、方向误差

**参数**：
- 学习率：1e-4 to 1e-3
- 批量大小：32-128
- 训练轮数：100-500
- 早停耐心：10-20轮

**质量门禁**：
- 训练曲线收敛
- 验证集性能稳定
- 无数据泄漏

### Step 4：相预测与筛选

**操作**：使用训练好的模型预测新合金的相稳定性
- **输入**：候选合金成分和结构
- **输出**：形成能预测、相稳定性评估
- **筛选标准**：formation energy < 0, energy above hull < 25 meV/atom

**参数**：
- 预测置信度阈值：0.7-0.9
- 候选数量：100-1000
- 排序依据：预测形成能、置信度

**质量门禁**：
- 预测结果合理性检查
- 与已知合金的对比验证
- 候选多样性评估

## 边界与分流

**异常处理**：
- 训练数据不足 → 使用迁移学习或数据增强
- 模型过拟合 → 增加正则化、减少模型复杂度
- 物理约束冲突 → 调整约束权重或使用软约束
- 计算资源不足 → 使用更小的图表示或批量大小

**降级策略**：
- GNN不可用 → 使用传统ML模型（如随机森林）作为基准
- 物理约束难以实现 → 使用纯数据驱动方法，但在报告中明确标注
- 训练数据质量差 → 使用半监督学习或主动学习

## 质量检查

**验证点**：
1. 图表示正确性：原子环境描述符与DFT计算一致
2. 模型性能：测试集MAE < 0.1 eV/atom
3. 物理合理性：预测形成能符号与实验一致
4. 泛化能力：在未见过的合金体系上表现合理
5. 可解释性：注意力权重与化学直觉一致

**失败处理**：
- 性能不达标 → 调整模型架构或训练策略
- 物理约束不满足 → 重新设计损失函数
- 泛化能力差 → 增加训练数据多样性

## 回退策略

**替代方案**：
1. 使用传统机器学习模型（随机森林、梯度提升）
2. 使用经验模型（如Miedema模型、Engel-Brewer理论）
3. 使用CALPHAD热力学数据库
4. 使用简化物理模型（如原子尺寸匹配、电负性差）
