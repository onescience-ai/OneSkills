# 主动学习GAP势能模型训练工作流

## 适用范围

用于从第一性原理分子动力学（AIMD）模拟产生的原子轨迹中，自动筛选并采样最具信息量的训练与测试构型，以训练一个达到指定能量拟合精度（能量均方根误差 MAE）的高斯近似势（GAP）原子间势模型。该方法特别适用于需要高精度、可迁移势能模型的复杂材料模拟场景，例如非晶态、液态或经历相变过程的体系。其核心优势在于通过聚类确保采样构型的多样性，通过迭代优化最小化训练数据量。

## 输入

*   **必需输入**：
    *   **AIMD轨迹文件**：来自第一性原理分子动力学模拟的原子构型序列，通常为扩展XYZ（.extxyz）格式。该文件应包含模拟过程中产生的多个构型快照。
    *   **能量容差阈值 (Etol)**：用户指定的目标能量拟合精度，单位为 eV/atom。例如，5 meV/atom (0.005 eV/atom) 是一个常见起点。工作流将持续迭代直到验证集上的能量MAE达到或低于此阈值。
*   **可选输入**：
    *   初始聚类参数（如最小簇数 `min_clusters`），用于引导HDBSCAN算法。

## 输出

工作流收敛后，将产生以下主要输出文件：
*   `opt_train.extxyz`：经主动学习优化后，选出的最优训练构型集合。这是最终用于训练GAP模型的数据集。
*   `opt_test.extxyz`：与训练集配对的最优测试构型集合，用于评估模型性能。
*   `activelearned_quipconfigs.json`：工作流运行的详细报告，包含每轮数据迭代的信息、采样详情以及贝叶斯优化过程中找到的最优GAP模型超参数。
*   **训练完成的GAP模型**：基于优化后的训练构型集训练得到的最终GAP势能模型文件。

## 流程节点

本工作流是一个迭代式主动学习循环，核心步骤由 `activesample` Python类封装，并通过 `BayesOpt_SOAP.py` 脚本执行。其DAG（有向无环图）结构如下：

1.  **轨迹输入与预处理 (s1)**
    *   **依赖**：无（起始步骤）
    *   **输入**：`input_trajectory` (str) - AIMD轨迹文件路径。
    *   **输出**：原子构型集合。
    *   **质量门**：输入轨迹应包含足够的构型多样性，以支持后续有效的聚类。

2.  **构型距离矩阵计算 (s2)**
    *   **依赖**：`s1`
    *   **输入**：`input_trajectory` (str) - AIMD轨迹文件路径。
    *   **输出**：RMSD距离矩阵。
    *   **质量门**：计算得到的距离矩阵必须是对称矩阵，且对角线元素为0。此步骤通常调用MDTraj库的 `md.rmsd()` 函数实现。

3.  **无监督构型聚类 (s3)**
    *   **依赖**：`s2`
    *   **输入**：`distance_matrix` (float) - RMSD距离矩阵；`min_clusters` (int, 默认=10) - 最小期望簇数，用于防止算法将所有点合并为一个簇。
    *   **输出**：构型簇标签集合。
    *   **质量门**：聚类算法应能将数据点有效划分为多个（理想情况下不重叠的）簇，这些簇代表了构型空间中不同的局部结构。

4.  **从簇中采样训练与测试构型 (s4)**
    *   **依赖**：`s3`
    *   **输入**：`cluster_labels` (array) - 上一步得到的构型簇标签；`sampling_iteration` (int, 默认=1) - 当前采样迭代轮次。
    *   **输出**：训练构型子集；测试构型子集。
    *   **质量门**：从每个识别出的簇中，必须能采样到不重复的构型。采样策略通常按序从每个簇中各取一个或多个构型，初始迭代可能从每个簇采样1个构型。

5.  **贝叶斯优化GAP模型超参数 (s5)**
    *   **依赖**：`s4`
    *   **输入**：`train_configs` (array) - 当前轮次采样的训练构型子集。
    *   **输出**：最优超参数组合；对应的能量MAE。
    *   **质量门**：完成一轮完整的贝叶斯优化迭代，该优化过程在采样构型上训练GAP模型，并在超参数空间中寻找最优组合。

6.  **验证与收敛判断 (s6)**
    *   **依赖**：`s5`
    *   **输入**：`best_model` (model) - 当前轮次优化得到的最优GAP模型；`test_configs` (array) - 配对的测试构型子集；`Etol` (float, 默认=0.005) - 用户设定的能量容差阈值 (eV/atom)。
    *   **输出**：验证MAE；收敛判断结果（是/否）。
    *   **质量门**：验证MAE ≤ 用户设定的能量容差阈值 (`Etol`)。

7.  **迭代控制与输出 (s7)**
    *   **依赖**：`s6`
    *   **输入**：`convergence_status` (bool) - 收敛判断结果。
    *   **输出**：若收敛，输出 `opt_train.extxyz`、`opt_test.extxyz`、`activelearned_quipconfigs.json`；若未收敛，则更新采样迭代次数 `sampling_iteration`，并返回步骤 `s4` 继续采样。
    *   **质量门**：输出文件完整，包含最终选定的最优构型。

## 边界与分流

*   **适用边界**：
    *   本工作流适用于单组分或组分简单的材料体系，其AIMD轨迹能反映目标构型空间（如液态、非晶态、晶体缺陷等）。
    *   高度依赖AIMD轨迹的质量和多样性。若轨迹未充分采样目标构型空间，主动学习效果会受限。
    *   目标是训练GAP势能模型。对于其他类型的机器学习势（如神经网络势），采样策略可参考，但模型训练部分不同。
*   **上下游衔接**：
    *   **上游**：本工作流的输入来自使用VASP、Quantum ESPRESSO等第一性原理软件进行的AIMD模拟。
    *   **下游**：输出的训练好的GAP模型可直接用于LAMMPS、QUIP等分子动力学软件中进行更大尺度、更长时间的经典MD模拟。
    *   **可替换/相关组件**：聚类算法（如HDBSCAN）是可选的，但密度聚类是此类工作流的常见选择。贝叶斯优化框架（如GPyOpt）也是可替换的，但需提供类似的超参数优化功能。整个工作流的实现依赖于特定的Python脚本和类库。

## 质量检查

*   **聚类有效性**：检查聚类结果是否产生了足够数量的簇（接近或大于 `min_clusters`），并且簇内构型在结构上具有一定相似性，簇间具有差异性。可通过可视化（如t-SNE降维后着色显示簇标签）进行辅助判断。
*   **迭代收敛**：核心质量检查指标是步骤6中的验证能量MAE。应记录每轮迭代的验证MAE变化趋势，确保其单调下降并最终稳定在 `Etol` 以下。`activelearned_quipconfigs.json` 文件提供了详细的迭代历史。
*   **构型代表性**：最终选出的训练构型应能覆盖AIMD轨迹所描述的构型空间的主要特征区域，避免遗漏关键结构类型。

## 回退策略

*   **输入轨迹问题**：若输入轨迹构型过于均质（例如，仅来自单一晶体相的振动），HDBSCAN聚类可能失效（产生极少簇或单一簇）。**回退**：需要生成更多样化的AIMD轨迹，例如通过升高温度、施加扰动或模拟不同相态来扩大采样空间。
*   **收敛困难**：若能量容差 (`Etol`) 设定过严，导致迭代次数过多，计算成本过高。**回退**：根据实际需求适当放宽 `Etol`，或评估当前精度是否已足够满足后续模拟需求。
*   **依赖环境问题**：确保运行环境已安装所有必要的依赖库（如 `mdtraj`, `GPyOpt`， 以及用于GAP训练的QUIP/GAP工具链）。脚本执行失败时，应检查环境配置和库版本兼容性。
*   **输入格式错误**：若AIMD轨迹文件格式不符合预期（如非扩展XYZ），需使用标准工具（如ASE）进行格式转换。

## 资源召回建议

*   **核心工具**：
    *   **执行脚本**：`BayesOpt_SOAP.py`
    *   **核心类库**：`activesample` Python类（负责数据处理、聚类和采样）。
    *   **聚类算法**：HDBSCAN。
    *   **优化框架**：贝叶斯优化（如GPyOpt）。
    *   **距离计算**：MDTraj库 (`md.rmsd`)。
*   **势能框架**：
    *   **GAP**：高斯近似势，是训练原子间势能模型的具体方法。
    *   **QUIP/LAMMPS**：用于训练后进行分子动力学模拟的工具。
*   **数据格式**：
    *   **输入/输出**：扩展XYZ格式 (.extxyz)。
    *   **配置/日志**：JSON格式。
