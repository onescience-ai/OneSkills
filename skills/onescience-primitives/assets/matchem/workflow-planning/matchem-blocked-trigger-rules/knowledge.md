# matchem域BLOCKED触发规则

## 适用范围

**触发条件**：
- 任务必填输入缺失
- Materials Project API key缺失
- 晶体结构CIF/POSCAR文件缺失
- 工况参数不完整

**适用场景**：
- 晶体结构预测任务中的输入验证
- 数据获取步骤的输入检查
- 任务状态管理中的BLOCKED标记

**不适用场景**：
- 非必填输入缺失（可降级处理）
- 可用替代数据源的情况
- 用户明确允许使用模拟数据

## 输入

**输入数据格式**：
- 任务输入参数
- 必填输入清单
- 可用数据源列表

**数据来源**：
- 用户提供的任务参数
- 系统配置文件
- 数据库连接信息

**预处理要求**：
- 必填输入清单定义
- 数据源可用性检查
- 输入格式验证

## 输出

**输出产物**：
1. **BLOCKED状态标记**：任务状态标记为BLOCKED
2. **缺失项清单**：列出所有缺失的必填输入
3. **处置建议**：请求用户补充或提供替代方案

**格式要求**：
- JSON格式的状态文件
- 文本格式的缺失项清单
- 结构化的处置建议

**验证标准**：
- 缺失项清单完整性
- BLOCKED状态正确标记
- 无模拟数据替代执行

## 流程节点

### Step 1：必填输入检查
- **操作**：检查所有必填输入是否完整
- **参数**：必填输入清单
- **工具**：输入验证工具
- **质量门禁**：所有必填输入已提供

### Step 2：BLOCKED状态标记
- **操作**：当必填输入缺失时标记BLOCKED
- **参数**：缺失项清单
- **工具**：状态管理工具
- **质量门禁**：BLOCKED状态正确标记

### Step 3：缺失项清单生成
- **操作**：生成缺失项清单
- **参数**：缺失项详情
- **工具**：清单生成工具
- **质量门禁**：清单包含所有缺失项

### Step 4：处置建议生成
- **操作**：生成处置建议
- **参数**：缺失项类型、可用替代方案
- **工具**：建议生成工具
- **质量门禁**：建议可操作且合理

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| Materials Project API key | 必填 | 用户输入 | 数据下载必需 |
| 晶体结构文件 | 必填 | 用户输入 | 结构预测输入 |
| 工况参数 | 必填 | 用户输入 | 计算条件 |
| 模拟数据替代 | 禁止 | 框架规则 | 不得使用模拟数据 |

## 边界与分流

**异常处理**：
- 必填输入缺失：立即标记BLOCKED
- 部分输入缺失：标记BLOCKED并列出缺失项
- 输入格式错误：请求正确格式

**降级策略**：
- 无降级策略：必须标记BLOCKED
- 用户补充输入后：重新检查并继续

**分支条件**：
- 所有必填输入完整：继续执行
- 任何必填输入缺失：标记BLOCKED

## 质量检查

**验证点**：
1. 必填输入完整性检查
2. BLOCKED状态正确标记
3. 缺失项清单准确性
4. 无模拟数据替代

**阈值**：
- 所有必填输入必须提供
- BLOCKED状态必须正确标记

**失败处理**：
- 重试输入检查
- 请求用户补充输入
- 标记为BLOCKED并停止执行

## 回退策略

**失败时的替代方案**：
- 无降级策略：必须标记BLOCKED
- 用户补充输入后：重新检查并继续
- 替代数据源可用：检查是否满足要求
