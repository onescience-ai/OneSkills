# DFT和MD计算执行时间与资源需求

## 适用范围

面向DFT和MD计算的典型执行时间范围和资源需求，定义VASP单点计算、结构优化、AIMD模拟的时间估算方法，以及执行时间异常时的检查规则。适用于需要验证计算任务执行时间合理性的场景，包括计算时间估算、资源规划、异常执行时间检测。当执行时间异常时，提供检查规则和异常处理流程。

## 输入

**必要输入**：
- 计算任务类型（单点计算、结构优化、AIMD模拟）
- 体系大小（原子数、晶胞大小）
- 计算资源信息（节点数、CPU核数、GPU卡数）

**可选输入**：
- 计算参数（截断能、K点网格、电子步限制）
- 历史执行时间数据
- 资源使用情况

**数据要求**：
- 计算任务类型明确，无歧义
- 体系大小信息完整，原子数准确
- 计算资源信息准确，配置正确

## 输出

**主要输出**：
- 执行时间估算结果
- 资源需求计算结果
- 异常执行时间检测报告
- 资源使用建议

**验证标准**：
- 执行时间估算在合理范围内
- 资源需求计算正确
- 异常检测准确，无遗漏

## 流程节点

### Step 1：计算任务分类
- **操作**：根据计算任务类型确定时间估算方法
- **参数**：计算任务类型，体系大小
- **工具**：任务分类器
- **质量门禁**：任务分类正确，无歧义

### Step 2：执行时间估算
- **操作**：根据任务类型和体系大小估算执行时间
- **参数**：任务类型，体系大小，计算资源
- **工具**：时间估算器
- **质量门禁**：时间估算在合理范围内

### Step 3：资源需求计算
- **操作**：根据执行时间估算计算资源需求
- **参数**：执行时间，任务类型，体系大小
- **工具**：资源需求计算器
- **质量门禁**：资源需求计算正确

### Step 4：异常执行时间检测
- **操作**：检测实际执行时间是否异常
- **参数**：实际执行时间，估算时间，任务类型
- **工具**：异常检测器
- **质量门禁**：异常检测准确，无遗漏

### Step 5：检测报告生成
- **操作**：生成执行时间与资源需求检测报告
- **参数**：估算结果，检测结果，资源需求
- **工具**：报告生成器
- **质量门禁**：报告完整，建议合理

## 边界与分流

**异常处理**：
- 执行时间过短（<1小时） → 标记PARTIAL，检查是否实际执行
- 执行时间过长（>预期2倍） → 标记PARTIAL，检查资源使用
- 资源使用效率低（<50%） → 标记PARTIAL，优化资源配置
- 任务类型不明确 → 标记BLOCKED，明确任务类型

**降级策略**：
- 无法完成完整估算时 → 使用经验值进行估算
- 缺少历史数据时 → 使用通用时间范围
- 资源信息不完整时 → 使用默认资源配置

**分支条件**：
- 执行时间在合理范围内 → 继续资源需求计算
- 执行时间异常 → 标记PARTIAL，检查原因
- 资源需求合理 → 生成报告
- 资源需求不合理 → 重新计算

## 质量检查

**验证点**：
1. 任务分类：任务类型分类正确，无歧义
2. 时间估算：执行时间估算在合理范围内
3. 资源需求：资源需求计算正确
4. 异常检测：异常检测准确，无遗漏
5. 报告完整性：报告完整，建议合理

**阈值**：
- 任务分类准确率：100%
- 时间估算误差：±30%
- 资源需求计算准确率：≥95%
- 异常检测准确率：≥90%
- 报告完整率：100%

**失败处理**：
- 任务分类错误 → 重新分类
- 时间估算不准确 → 调整估算方法
- 资源需求计算错误 → 重新计算
- 异常检测遗漏 → 补充检测

## 回退策略

**替代方案**：
1. 使用通用时间范围（如1-24小时）
2. 采用简化估算（仅基于体系大小）
3. 降级为人工估算
4. 使用历史成功案例作为参考

**回退触发条件**：
- 估算方法不可用
- 缺少必要参数
- 资源信息不完整
- 检测工具不可用
