# CLI Non-Interactive Execution Fault Classification

## 适用范围
适用于任何需要通过命令行界面（CLI）自动化执行任务并处理异常情况的场景，包括科学计算、数据处理、系统管理等领域的脚本化工作流。不适用于交互式CLI使用或图形用户界面（GUI）应用。

## 输入
- CLI命令或脚本
- 执行环境（操作系统、shell类型）
- 预期退出码与错误处理策略

## 输出
- 故障分类报告（错误类型、严重程度、恢复建议）
- 退出码映射表
- 超时处理日志

## 流程节点
1. **命令执行** → 启动CLI进程，设置超时阈值。
2. **退出码捕获** → 监听进程退出，记录退出码。
3. **故障分类** → 根据退出码将故障分为：成功（0）、可恢复错误（1-125）、致命错误（126-255）、信号中断（>128）。
4. **超时处理** → 若进程超时，强制终止并记录超时事件。
5. **恢复策略** → 根据故障类别选择重试、跳过或终止工作流。

## 关键参数
### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 成功退出码 | 0 | [D1] | 表示命令执行成功 |
| 可恢复错误范围 | 1-125 | [D1] | 如参数错误、文件不存在等 |
| 致命错误范围 | 126-127 | [D1] | 如命令不可执行、无效shell |
| 信号中断退出码 | 128+信号编号 | [D1] | 如130表示Ctrl+C（SIGINT） |
| 超时默认值 | 30秒 | [1] | 可根据任务调整 |

### 校准数值
以下数值来自医疗集成引擎超时框架案例，供量级校准；其他体系需以自身证据重新锚定。
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 外部API调用超时 | 5秒 | [1] | 防止无限等待 |
| 重试次数 | 3次 | [1] | 指数退避策略 |

## 边界与分流
- 若退出码未在标准映射中，归类为“未知错误”并记录原始值。
- 若超时后进程仍运行，使用SIGKILL强制终止（可能导致资源未释放）。
- 若故障为间歇性（如网络波动），启用重试机制；若为永久性（如配置错误），终止工作流。

## 质量检查
- 验证退出码是否符合POSIX标准。
- 检查超时设置是否合理（避免误杀长时间任务）。
- 确保故障分类覆盖所有可能退出码。

## 回退策略
- 若自动恢复失败，记录详细日志并通知管理员。
- 提供手动干预接口（如跳过当前任务、调整参数后重试）。
