## 工作流

### 步骤 1：数据获取与目标定义

**目的**：从Materials Project等公开数据库获取真实材料数据集，定义筛选目标和约束。

**数据来源**：Materials Project数据库（https://next-gen.materialsproject.org/）

**API配置**：
- 安装：`pip install mp_api`
- API密钥：从Materials Project账户获取并设置环境变量`MP_API_KEY`
- 查询工具：MPRester客户端（`from mp_api.client import MPRester`）

**数据字段**：
| 字段名 | 类型 | 说明 | 来源 |
|--------|------|------|------|
| material_id | str | 材料唯一标识（如"mp-149"） | [1] |
| formula_pretty | str | 化学式 | [1] |
| band_gap | float | 带隙（eV） | [1] |
| structure | pymatgen.Structure | 晶体结构对象 | [1] |
| energy_above_hull | float | 凸包能量（eV/atom） | [1] |
| formation_energy | float | 形成能（eV/atom） | [1] |

**查询示例**：
```python
with MPRester(api_key) as mpr:
    docs = mpr.materials.summary.search(
        elements=["Ti", "O"],
        band_gap=(0.5, 3.0),
        fields=["material_id", "formula_pretty", "band_gap", "structure"]
    )
```

**输出**：结构化材料数据集（JSON/CSV）、数据审计报告

**质量门禁**：
- 数据来源标记为Materials Project
- 关键字段（material_id, band_gap, structure）完整性100%
- 与文献报道的材料属性一致性验证（带隙偏差<0.2eV）

### 步骤 2：分层漏斗筛选

**目的**：通过6层渐进式筛选，从数万候选中识别潜在光催化剂。

**Tier 1 - 热力学稳定性筛选** [1]：
- 判据：ΔEhull < 80 meV.atom⁻¹
- 依据：约80%已验证的硫化物和氧化物在此范围内
- 预期：从~69,000材料中筛选出~53,000

**Tier 2 - 可见光吸收筛选** [1]：
- 判据：1.0 eV < EPBEg < 2.5 eV
- 依据：可见光范围1.7-3.0 eV，PBE带隙低估约40%
- 预期：从~53,000中筛选出~11,500

**Tier 3 - 电化学稳定性筛选** [1]：
- 判据：ΔGpbx < 0.2 eV.atom⁻¹（保守标准）
- 依据：Pourbaix图计算电化学稳定性，考虑离子浓度10⁻⁵ M、温度298K、压力1atm
- 预期：从~11,500中筛选出~509（<5%）

**Tier 4 - 计算成本筛选** [1]：
- 判据：单胞原子数 ≤ 20
- 依据：限制后续高精度计算成本
- 预期：从509中筛选出~235

**Tier 5 - HSE06带隙验证** [1]：
- 判据：EHSE06g在可见光范围（允许0.5eV余量）
- 依据：HSE06杂化泛函提高带隙预测精度
- 预期：从235中筛选出~163

**Tier 6 - 能带边缘对齐** [1]：
- 判据：-4.3 eV < EHSE06g < -2.4 eV（CBM位置）
- 依据：CO₂还原电位约-4.2 eV vs vacuum
- 预期：最终筛选出~52个候选

**输出**：候选排序列表、各层级通过率、预测值与不确定性

**质量门禁**：
- 所有候选满足硬约束
- 适用域外候选单独标识
- 每层筛选结果可追溯

### 步骤 3：DFT高精度验证

**目的**：对优先候选执行VASP DFT计算验证电子结构。

**VASP计算配置** [1]：
| 参数 | 标准计算 | Slab计算 | 说明 |
|------|----------|----------|------|
| 交换关联泛函 | PBE/PBE+U | HSE06 | Tier 1-4用PBE，Tier 5-6用HSE06 |
| 截断能 | 520 eV | 400 eV | 平面波基组截断 |
| K点网格 | 1000/Natoms | 30/a×30/b×1 | Monkhorst-Pack网格 |
| 电子步收敛 | 1e-4 eV | 1e-4 eV | 能量差收敛标准 |
| 离子步收敛 | 0.0005×Natoms eV | - | 力收敛标准 |
| 自旋极化 | ON | ON | 磁性材料计算 |

**Hubbard U参数** [1]：
| 元素 | U值(eV) | 元素 | U值(eV) |
|------|---------|------|---------|
| Co | 3.32 | Mo | 4.38 |
| Cr | 3.7 | Ni | 6.2 |
| Fe | 5.3 | V | 3.25 |
| Mn | 3.9 | W | 6.2 |

**Slab模型要求** [1]：
- 最小厚度：15 Å
- 真空间距：12 Å
- 偶极修正：垂直于真空方向
- 考虑表面：(hkl) where h,k,l = 0,1,-1

**输出**：VASP输出文件、能量数据、电子结构、带隙和能带边缘位置

**质量门禁**：
- 能量收敛（电子步<1e-4 eV）
- 与Materials Project数据对比一致
- 带隙偏差<0.2eV

### 步骤 4：候选评估与结论

**目的**：综合评估筛选结果，形成最终候选列表和研究结论。

**评估维度** [1]：
- 热力学稳定性：ΔEhull和ΔGpbx
- 光吸收性能：HSE06带隙和吸收范围
- 能带边缘位置：CBM/VBM对齐
- 合成可行性：ICSD存在性和合成方法
- 电化学稳定性：Pourbaix稳定性区域

**输出**：最终候选列表、性能对比表、PASS/REJECT/BLOCKED结论

**质量门禁**：
- 预测与验证分开报告
- 失败候选保留记录
- 结论区分已证实结果和探索性观察
