# 晶体结构预测与优化标准工作流

## 适用范围

**触发条件**：
- 需要从化学成分预测晶体结构
- 需要评估候选结构的稳定性与可合成性
- 使用图神经网络（GNN）进行晶体性质预测

**适用场景**：
- 新材料发现与设计
- 高通量材料筛选
- 晶体结构优化与弛豫
- 可合成性评估

**不适用场景**：
- 非晶体材料（非晶态、液体等）
- 分子结构预测（无周期性）
- 纯实验研究（无计算模拟）

## 输入

**输入数据格式**：
- 化学成分（如 CsPbI3, LiFePO4）
- 工况参数（压力、温度）
- 结构约束（空间群、晶格参数范围）

**数据来源**：
- Materials Project API（需API key）
- ICSD（无机晶体结构数据库）
- 用户提供的CIF/POSCAR文件

**预处理要求**：
- 成分化学计量验证
- 对称性约束检查
- 原子重叠检测

## 输出

**输出产物**：
1. **搜索空间清单**（s01产物）：包含成分约束、压力范围、对称性约束的结构化描述
2. **候选结构库**（s02产物）：多个候选晶体结构的CIF/POSCAR文件集合
3. **弛豫结构**（s03产物）：经过能量最小化的稳定结构
4. **优先结构**（s04产物）：通过可合成性判断的候选结构

**格式要求**：
- CIF或POSCAR格式的晶体结构文件
- 元数据JSON文件（包含能量、形成能、带隙等）
- 去重日志和稳定性排序列表

**验证标准**：
- 结构合理性（无原子重叠、键长合理）
- 能量收敛性（弛豫后能量变化<阈值）
- 稳定性指标（凸包距离、形成能）

## 流程节点

### Step 1：成分约束建立（s01）
- **操作**：定义成分、压力、对称性约束
- **参数**：成分=CsPbI3, pressure_GPa=0, max_atoms=100
- **工具**：成分分析工具、对称性检查工具
- **质量门禁**：约束完整性检查、搜索空间大小评估

### Step 2：候选构型生成（s02）
- **操作**：在约束空间内生成多样候选构型
- **参数**：生成算法=随机结构搜索（RSS）、候选数量=50-100
- **工具**：ASE（原子模拟环境）、PyXtal
- **质量门禁**：原子重叠检测、等价结构去重

### Step 3：结构弛豫（s03）
- **操作**：对候选结构进行能量最小化
- **参数**：弛豫算法=共轭梯度法、收敛阈值=1e-5 eV/atom
- **工具**：VASP、Quantum ESPRESSO、GNN势函数（如CHGNet）
- **质量门禁**：能量收敛、力收敛、应力收敛

### Step 4：可合成性判断（s04）
- **操作**：评估结构的热力学稳定性
- **参数**：参考态=Materials Project热力学数据、凸包距离阈值=50 meV/atom
- **工具**：相图分析工具、凸包计算工具
- **质量门禁**：凸包距离<阈值、形成能为负值

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 成分约束 | CsPbI3 | 用户输入 | 目标材料成分 |
| 压力范围 | 0-10 GPa | 用户输入 | 工况压力 |
| 对称性约束 | 空间群1-230 | 用户输入 | 结构对称性 |
| 候选数量 | 50-100 | 经验值 | 生成候选结构数 |
| 弛豫收敛阈值 | 1e-5 eV/atom | 文献值 | 能量收敛标准 |
| 凸包距离阈值 | 50 meV/atom | 文献值 | 稳定性判断阈值 |

## 边界与分流

**异常处理**：
- 成分不合理：返回错误提示，要求修正成分
- 对称性冲突：降级为无对称性约束生成
- 弛豫不收敛：增加弛豫步数或调整收敛参数

**降级策略**：
- Materials Project API不可用时：使用本地数据库或用户提供的结构
- 计算资源不足时：减少候选结构数量或使用简化弛豫方法

**分支条件**：
- 单一成分：直接生成候选构型
- 组合成分：先进行成分空间搜索

## 质量检查

**验证点**：
1. 搜索空间清单完整性检查
2. 候选结构原子重叠检测
3. 弛豫结构能量收敛验证
4. 凸包距离计算验证

**阈值**：
- 原子间最小距离 > 1.0 Å
- 弛豫能量变化 < 1e-5 eV/atom
- 凸包距离 < 50 meV/atom

**失败处理**：
- 重试弛豫（调整收敛参数）
- 生成新候选结构（补充数量）
- 标记为BLOCKED（关键输入缺失）

## 回退策略

**失败时的替代方案**：
- 弛豫失败：使用预训练GNN势函数（如CHGNet）进行快速弛豫
- 凸包计算失败：使用形成能作为稳定性指标
- 可合成性判断不确定：标记为"待确认"并记录原因
