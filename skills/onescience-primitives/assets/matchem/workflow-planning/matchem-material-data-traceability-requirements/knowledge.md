# 材料科学数据可追溯性要求

## 适用范围

本卡片服务于材料科学计算任务中的数据质量管理，确保所有材料结构和性能数据具有可追溯的权威来源。适用于以下场景：

- 材料性质计算与预测任务
- 材料筛选与高通量计算
- 科研报告与论文撰写
- 材料数据库构建与维护

不适用场景：
- 方法验证与算法开发（可使用假设数据）
- 概念演示与教学示例
- 用户明确允许使用假设数据的场景

## 输入

| 输入项 | 格式 | 来源 | 预处理要求 |
|--------|------|------|------------|
| 材料结构数据 | CIF/POSCAR | 用户提供/数据库获取 | 确认数据来源和版本 |
| 性能数据 | JSON/CSV | 文献提取/计算结果 | 标注来源文献DOI和测量条件 |
| 数据来源声明 | 文本 | 用户/系统生成 | 明确数据来源类型 |

## 输出

| 输出项 | 格式 | 验证标准 |
|--------|------|----------|
| 数据来源报告 | JSON | 包含每条数据的来源类型、标识符、验证状态 |
| 可追溯性评估 | Markdown | 标注数据质量等级（完整/部分/缺失） |
| 缺失数据清单 | JSON | 列出需要补充来源的数据项 |

## 流程节点

### 节点1：数据来源识别
- **操作**：识别每条数据的来源类型和权威性
- **参数**：来源类型分类（用户上传/数据库/文献/假设）
- **工具**：来源识别规则引擎
- **质量门禁**：所有数据必须明确来源类型

### 节点2：权威来源验证
- **操作**：验证数据来源是否为权威数据库或文献
- **参数**：权威来源白名单、验证规则
- **工具**：数据库API查询/文献DOI验证
- **质量门禁**：核心数据必须来自权威来源

### 节点3：证据链构建
- **操作**：为每条数据建立完整的证据链
- **参数**：来源标识符、获取时间、验证状态
- **工具**：证据链记录器
- **质量门禁**：证据链完整且可验证

### 节点4：质量评估与报告
- **操作**：评估数据整体质量并生成报告
- **参数**：质量评估标准、报告模板
- **工具**：质量评估脚本
- **质量门禁**：报告准确反映数据质量状况

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 权威数据库来源 | Materials Project/ICSD/OQMD | 领域共识 | 结构数据首选来源 |
| 文献来源要求 | DOI可验证的同行评审论文 | 领域共识 | 性能数据首选来源 |
| 假设数据限制 | 仅用于方法验证 | 领域共识 | 不能作为正式结论依据 |
| 数据质量等级 | 完整/部分/缺失 | 领域共识 | 三级质量分类 |

### 校准数值（以下数值来自固态电解质研究，供量级校准；其他体系需以自身证据重新锚定）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| Materials Project ID格式 | MP-xxxxxx | Materials Project | 结构数据标准标识符 |
| ICSD编号格式 | ICSD_xxxxx | ICSD | 实验结构数据标识符 |
| 文献DOI格式 | 10.xxxx/xxxxx | DOI标准 | 文献来源标准标识符 |
| 数据验证时间窗口 | 获取后30天内验证 | 最佳实践 | 确保数据时效性 |

## 边界与分流

### 前提不成立时的改道方案

| 前提 | 不成立条件 | 改道方案 |
|------|------------|----------|
| 权威数据库可用 | 数据库API不可用或无网络 | 使用本地缓存数据并标注"本地缓存，未实时验证" |
| 文献来源可获取 | 文献付费墙或无法访问 | 使用摘要数据并标注"摘要级，未验证全文" |
| 数据完整 | 部分数据缺失来源 | 标记缺失项为PARTIAL，不标记为PASS |

### 异常处理

- **数据来源矛盾**：以权威来源优先，冲突记录待裁决
- **假设数据混入正式结论**：拒绝接受，要求提供真实数据来源
- **来源标识符格式错误**：尝试标准化格式或标记为无效

## 质量检查

| 检查点 | 标准 | 失败处理 |
|--------|------|----------|
| 来源完整性 | 所有数据有明确来源 | 补充来源信息或标记缺失 |
| 权威性验证 | 核心数据来自权威来源 | 降级为参考级或补充权威来源 |
| 证据链一致性 | 来源信息与数据内容匹配 | 重新验证或标记矛盾 |

## 回退策略

1. **权威来源不可用**：使用用户自有数据并标注来源层级
2. **文献无法获取全文**：使用摘要数据并标注"摘要级证据"
3. **数据来源矛盾**：保留所有来源，标注冲突待人工裁决
