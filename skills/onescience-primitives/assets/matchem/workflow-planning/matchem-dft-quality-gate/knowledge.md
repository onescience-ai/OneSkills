# DFT计算任务质量门禁定义标准

## 适用范围

**触发条件**：
- 需要定义DFT计算任务的质量门禁标准
- 需要检查计算任务是否完成
- 需要判定计算结果是否有效

**适用场景**：
- VASP计算任务的质量检查
- Quantum ESPRESSO计算任务的质量验证
- 多步骤DFT工作流的状态判定
- 计算任务完成标准的定义

**不适用场景**：
- 实验数据的质量检查（需要不同标准）
- 机器学习模型的质量评估（需要不同指标）
- 实时监控系统（需要实时更新）

## 输入

**必要输入**：
- DFT计算输出文件
- 任务执行日志
- 质量门禁标准

**可选输入**：
- 输入文件验证结果
- 收敛判断结果
- 资源使用情况

**数据要求**：
- 输出文件完整，可解析
- 执行日志记录完整
- 质量门禁标准明确

## 输出

**主要输出**：
- 质量门禁状态（PASS/PARTIAL/BLOCKED/FAILED）
- 验证结果详情
- 状态判定依据
- 改进建议

**验证标准**：
- 质量门禁状态正确，无遗漏
- 验证结果基于实际数据
- 状态判定有明确依据

## 流程节点

### Step 1：计算执行验证
- **操作**：验证DFT计算是否实际执行
- **参数**：输出文件存在性、执行日志
- **工具**：文件检查脚本、日志分析工具
- **质量门禁**：计算实际执行，非仅生成输入文件
- **验证点**：
  1. OUTCAR文件存在且非空
  2. OSZICAR文件存在且非空
  3. CONTCAR文件存在（如需结构优化）
  4. 执行日志显示计算开始和结束

### Step 2：输出文件完整性检查
- **操作**：检查所有必需输出文件是否存在
- **参数**：文件列表、文件大小、文件格式
- **工具**：文件完整性检查脚本
- **质量门禁**：所有必需输出文件存在且完整
- **必需文件**：
  1. OUTCAR：主要输出文件
  2. OSZICAR：SCF收敛信息
  3. CONTCAR：弛豫结构（如需）
  4. DOSCAR：态密度（如需）
  5. CHGCAR：电荷密度（如需）

### Step 3：SCF收敛检查
- **操作**：检查SCF计算是否收敛
- **参数**：收敛标准、收敛信息
- **工具**：收敛检查脚本
- **质量门禁**：SCF计算收敛，能量稳定
- **验证点**：
  1. OUTCAR中显示"reached required accuracy"
  2. 能量变化<1e-4 eV
  3. 电子步数在合理范围
  4. 无收敛警告或错误

### Step 4：能量读取验证
- **操作**：验证能量数据可正确读取
- **参数**：能量值、能量单位、能量范围
- **工具**：能量提取脚本
- **质量门禁**：能量数据可正确读取，值在合理范围
- **验证点**：
  1. 能量值可从OUTCAR中提取
  2. 能量单位正确（eV）
  3. 能量值在合理范围（-1000 eV 到 0 eV）
  4. 无能量异常或跳变

### Step 5：质量门禁状态判定
- **操作**：根据验证结果判定质量门禁状态
- **参数**：各验证点结果、状态定义
- **工具**：状态判定脚本
- **质量门禁**：状态判定正确，无遗漏
- **状态定义**：
  1. PASS：所有验证点通过，计算完成且有效
  2. PARTIAL：部分验证点通过，计算完成但数据不完整
  3. BLOCKED：关键验证点失败，计算未执行或无效
  4. FAILED：计算失败，数据无效

### Step 6：状态报告生成
- **操作**：生成质量门禁状态报告
- **参数**：状态详情、验证结果、改进建议
- **工具**：报告生成脚本
- **质量门禁**：报告完整，状态明确
- **报告要素**：
  1. 状态摘要
  2. 各验证点详情
  3. 状态判定依据
  4. 改进建议

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| SCF收敛标准 | 1e-4 eV | [1] | 能量收敛标准 |
| 能量范围 | -1000 eV 到 0 eV | [1] | 合理能量范围 |
| 电子步限制 | 100-300步 | [1] | 收敛步数限制 |
| 输出文件大小 | >1KB | [2] | 文件非空检查 |
| 执行时间 | >1秒 | [2] | 计算实际执行 |
| 状态定义 | PASS/PARTIAL/BLOCKED/FAILED | [3] | 标准状态定义 |

## 边界与分流

**异常处理**：
- 输出文件缺失 → 标记为BLOCKED，重新计算
- SCF不收敛 → 标记为PARTIAL，检查输入文件
- 能量读取失败 → 标记为PARTIAL，检查输出文件
- 状态判定异常 → 人工检查并决策

**降级策略**：
- 部分文件缺失 → 仅验证存在的文件
- 收敛检查失败 → 降级为文件存在性检查
- 能量读取失败 → 降级为文件完整性检查

## 质量检查

**验证点**：
1. 计算执行验证：计算实际执行，非仅生成输入文件
2. 输出文件完整性：所有必需输出文件存在且完整
3. SCF收敛检查：SCF计算收敛，能量稳定
4. 能量读取验证：能量数据可正确读取，值在合理范围
5. 状态判定：状态判定正确，无遗漏

**失败处理**：
- 验证点失败 → 标记为BLOCKED，不通过质量门禁
- 状态判定错误 → 重新判定，确保正确
- 报告不完整 → 补充缺失信息

## 回退策略

**替代方案**：
1. 使用文献数据替代计算数据
2. 采用简化验证（仅检查文件存在性）
3. 降级为人工检查
4. 使用保守状态判定（标记为BLOCKED）
