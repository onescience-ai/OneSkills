# 无铅杂化钙钛矿稳定性数据获取工作流

## 适用范围

**触发条件**：
- 需要获取无铅杂化钙钛矿的真实结构、稳定性和性能数据
- 需要从公开数据库下载数据训练机器学习模型
- 需要验证模拟数据或补充数据集规模

**适用场景**：
- 无铅杂化钙钛矿稳定性机器学习筛选
- 钙钛矿太阳能电池材料性能预测
- 高通量计算材料学数据获取
- 材料基因组计划数据整合

**不适用场景**：
- 仅需文献综述而不获取原始数据
- 研究对象为含铅钙钛矿或全无机钙钛矿
- 需要私有数据库或付费数据源

## 输入

**输入数据**：
- 查询参数：组分范围、稳定性条件、晶体结构类型
- 数据格式：JSON查询参数或CSV格式的查询列表
- 来源：用户指定或自动探测

**预处理要求**：
- 明确目标性质（形成能、分解能、带隙等）
- 定义数据质量阈值（能量收敛精度、结构弛豫标准）
- 确认数据许可和引用要求

## 输出

**输出产物**：
- 标准化数据集（CSV/JSON格式）
- 数据质量报告
- 数据来源追溯信息

**验证标准**：
- 数据条目完整性（无缺失关键字段）
- 数值合理性检查（能量范围、结构参数）
- 来源可追溯性（每个数据点关联数据库ID）

## 流程节点

### Step 1：数据库选择与API配置

- **操作**：选择目标数据库并配置API访问
- **参数**：
  - 数据库类型：Materials Project / OQMD / AFLOW / ICSD
  - 访问方式：REST API / 批量下载 / 网页查询
  - 认证方式：API密钥（Materials Project）或开放访问（OQMD）
- **工具**：mp-api, oqmd-api, python-requests
- **质量门禁**：API连接测试成功，返回有效响应

### Step 2：查询构建与执行

- **操作**：构建查询条件并执行数据检索
- **参数**：
  - 组分过滤：A位（MA/FA/Cs）、B位（Sn/Ge/Bi/Sb）、X位（I/Br/Cl）
  - 稳定性条件：分解能 > 阈值、形成能 < 阈值
  - 结构类型：钙钛矿结构（ABX3）
- **工具**：Materials Project API, OQMD REST API
- **质量门禁**：查询返回有效结果，数量符合预期

### Step 3：数据清洗与标准化

- **操作**：清洗原始数据并标准化格式
- **参数**：
  - 缺失值处理：删除或插值
  - 单位统一：能量单位为eV/atom，长度单位为Å
  - 重复数据去重：基于组分和结构
- **工具**：pandas, numpy
- **质量门禁**：无重复条目，单位统一，数值范围合理

### Step 4：数据质量评估

- **操作**：评估数据质量并生成报告
- **参数**：
  - 能量收敛精度：收敛阈值 < 1e-4 eV/atom
  - 结构弛豫标准：力收敛 < 0.01 eV/Å
  - 数据完整性：关键字段缺失率 < 5%
- **工具**：自定义质量检查脚本
- **质量门禁**：质量报告PASS，数据可用于训练

### Step 5：数据导出与追溯

- **操作**：导出标准化数据集并记录来源
- **参数**：
  - 输出格式：CSV（主数据）+ JSON（元数据）
  - 追溯信息：数据库ID、查询时间、版本号
- **工具**：pandas, json
- **质量门禁**：文件可读，追溯信息完整

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| Materials Project API | mp-api | [1] | 官方Python API |
| OQMD数据格式 | CSV/JSON | [2] | 开放量子材料数据库 |
| 能量收敛阈值 | 1e-4 eV/atom | [3] | DFT计算标准 |
| 力收敛阈值 | 0.01 eV/Å | [3] | 结构弛豫标准 |
| 钙钛矿组分 | ABX3 | [3] | 无铅杂化钙钛矿通式 |
| 稳定性指标 | 分解能、形成能 | [3] | 热力学稳定性判据 |

## 边界与分流

**异常处理**：
- API连接失败：切换到备用数据库或使用本地缓存
- 查询结果为空：放宽查询条件或检查参数
- 数据质量不合格：标记并排除不合格数据

**降级策略**：
- 优先使用Materials Project（数据质量最高）
- 次选OQMD（数据量最大）
- 备选AFLOW（计算数据丰富）

**分支条件**：
- 需要实验数据：转向ICSD或文献挖掘
- 需要计算数据：使用Materials Project或OQMD

## 质量检查

**验证点**：
1. API连接测试：返回HTTP 200状态码
2. 数据完整性：关键字段无缺失
3. 数值合理性：能量在合理范围内（-5~0 eV/atom）
4. 重复检查：基于组分和结构去重

**阈值**：
- 数据缺失率 < 5%
- 重复率 < 1%
- 数值异常率 < 2%

**失败处理**：
- 标记不合格数据点
- 记录失败原因
- 提供数据质量报告

## 回退策略

**失败时的替代方案**：
1. API不可用 → 使用批量下载或本地缓存
2. 数据质量差 → 增加过滤条件或人工审核
3. 数据量不足 → 扩大查询范围或补充文献数据
