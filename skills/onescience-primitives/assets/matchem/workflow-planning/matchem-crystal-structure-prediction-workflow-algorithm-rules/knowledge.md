# 晶体结构预测与优化工作流、算法及规则

## 适用范围

面向材料成分空间，执行晶体结构搜索、稳定性评估与可合成性判断的任务。本卡提供从成分约束建立到最终结构筛选的完整流程定义，涵盖候选构型生成算法、结构弛豫收敛标准、能量稳定性排序规则、可合成性判断指标，以及图神经网络模型在预测流程中的集成方式。适用于新材料发现、相稳定性研究、高通量结构筛选等场景；不适用于已确定结构的性质计算或分子动力学模拟。

## 输入

- 成分信息：化学式或组分比例（如 CsPbI3、LiNi0.8Co0.1Mn0.1O2）
- 结构约束：压力范围（GPa）、晶格对称性（空间群）、原子数上限
- 计算参数：交换关联泛函、截断能、k点网格、弛豫收敛阈值
- 数据来源：Materials Project API key（可选，用于获取参考结构与能量）
- 模型权重：预训练图神经网络权重路径（可选，用于性质预测加速）

## 输出

- 搜索空间清单：约束定义文件（JSON/YAML），包含成分、压力、对称性约束
- 初始构型库：初始结构文件（CIF/POSCAR）及元数据
- 候选结构库：去重后的候选结构文件及去重日志
- 弛豫结构：弛豫后结构文件及能量、力、应力收敛记录
- 稳定性排序：候选结构按形成能或能量凸包距离排序的列表
- 优先结构：通过可合成性判断的结构及验证清单
- 结论：PASS/REJECT/BLOCKED 状态及理由

## 流程节点

1. **成分约束建立**（s01） → 接收成分与化学计量、结构约束输入，输出搜索空间清单和初始构型。操作：定义成分空间、压力范围、对称性限制；参数：pressure_GPa、max_atoms、space_group；工具：pymatgen、ASE；质量门禁：约束完整性检查，缺失必填项则触发 BLOCKED。
2. **候选构型生成**（s02） → 在约束空间内生成多样候选，去除原子重叠和等价重复。操作：随机结构搜索（RSS）、对称性约束生成；参数：num_candidates、min_atomic_distance；工具：ASE、pymatgen；质量门禁：原子重叠检测、Space Group 对称操作比对，输出候选结构库和去重日志。
3. **结构弛豫与稳定性计算**（s03） → 对候选结构统一弛豫并计算稳定性指标。操作：几何优化、能量/力/应力收敛；参数：force_tol、energy_tol；工具：VASP、Quantum ESPRESSO、ASE；质量门禁：收敛标准检查，输出弛豫结构和稳定性排序（形成能、凸包距离）。
4. **可合成性判断**（s04） → 对优先结构做独立检查和可合成性判断。操作：热力学稳定性、动力学稳定性、实验可行性评估；参数：formation_energy_above_hull、band_gap；工具：Materials Project API、pymatgen；质量门禁：阈值判定，输出优先结构、验证清单和 PASS/REJECT/BLOCKED 结论。

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 原子最小距离 | > 1.0 Å | [D2] | 防止原子重叠的经验阈值 |
| 对称性比对 | Space Group 操作比对 | [D3] | 等价结构判定标准 |
| 弛豫力收敛阈值 | < 0.01 eV/Å | [D1] | 结构弛豫完成判据 |
| 形成能计算 |  elemental reference states | [D1] | 稳定性排序基础 |
| 凸包距离 | 0 eV/atom 为稳定 | [D1] | 热力学稳定性判据 |
| 可合成性阈值 | formation_energy_above_hull < 50 meV/atom | [D1] | 实验可合成性经验规则 |

### 校准数值（体系专属值）

以下数值来自典型钙钛矿体系（CsPbI3），供量级校准；其他体系需以自身证据重新锚定。

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 压力范围 | 0-10 GPa | [D1] | 常见高压合成条件 |
| 原子数上限 | 200 atoms | [D2] | 计算可行性限制 |
| k点密度 | > 40 atoms/kpoint | [D1] | 能量收敛经验 |

## 边界与分流

- **成分约束缺失**（如无对称性要求） → 转向无对称性约束的随机搜索方案族。
- **Materials Project API key 缺失** → 触发 BLOCKED 状态，列出缺失项，请求用户提供；不得使用模拟数据替代。
- **计算资源不足**（如无法运行 DFT） → 转向机器学习势函数或图神经网络代理模型方案族。
- **候选结构生成失败**（如无满足约束的构型） → 调整约束范围或转向已知稳定结构库。
- **弛豫不收敛** → 降低收敛阈值或转向更稳健的优化算法（如 FIRE、BFGS）。
- **可合成性判断存疑** → 标记为“待确认”，提供额外稳定性指标或实验文献参考。

## 质量检查

- 约束完整性：必填输入（成分、压力、对称性）是否齐全，缺失则 BLOCKED。
- 结构合理性：原子距离、键长、配位数是否在合理范围。
- 弛豫收敛：能量、力、应力是否达到阈值。
- 稳定性排序：形成能计算是否基于正确的参考态。
- 可合成性：凸包距离是否低于经验阈值。
- 文档记录：所有步骤的输入输出、参数、工具、质量门禁是否可追溯。

## 回退策略

- 约束过严导致无候选 → 放宽对称性或压力范围。
- DFT 计算失败 → 使用机器学习势函数（如 M3GNet）进行快速弛豫。
- 图神经网络预测不准 → 使用集成模型或增加训练数据。
- 可合成性判断不确定 → 提供多个候选并标注置信度。
