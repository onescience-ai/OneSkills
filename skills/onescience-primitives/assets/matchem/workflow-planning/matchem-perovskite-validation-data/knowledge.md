# 无铅杂化钙钛矿稳定性独立验证数据获取工作流

## 适用范围

**触发条件**：
- 需要获取独立验证数据验证机器学习模型预测
- 需要从实验文献或DFT计算中获取验证数据
- 需要评估预测准确性并量化误差

**适用场景**：
- 无铅杂化钙钛矿稳定性预测的实验验证
- 机器学习模型预测与DFT计算结果对比
- 材料性能预测的误差分析和校准
- 模型可靠性和适用性评估

**不适用场景**：
- 仅需内部验证（交叉验证）而不需要外部验证
- 研究对象为模拟数据而非真实材料
- 验证数据不可获取或成本过高

## 输入

**输入数据**：
- 机器学习模型预测结果
- 目标材料组分列表
- 验证标准（误差容忍度）

**预处理要求**：
- 预测结果标准化
- 验证数据来源明确
- 误差计算方法定义

## 输出

**输出产物**：
- 验证数据集（实验值或DFT计算值）
- 误差分析报告
- 模型性能评估

**验证标准**：
- 验证数据来源可追溯
- 误差计算准确
- 结论客观可靠

## 流程节点

### Step 1：验证数据来源识别

- **操作**：识别可用的验证数据来源
- **参数**：
  - 来源类型：实验文献 / DFT计算 / 高保真模拟
  - 数据格式：论文数据表 / 补充材料 / 数据库
  - 数据质量：实验条件、计算精度、数据完整性
- **工具**：文献检索、数据库查询
- **质量门禁**：来源可靠，数据可获取

### Step 2：实验文献数据挖掘

- **操作**：从实验文献中提取验证数据
- **参数**：
  - 文献类型：实验研究论文、综述、专利
  - 数据提取：稳定性数据、实验条件、误差范围
  - 数据验证：重复性检查、一致性分析
- **工具**：PDF解析、文本挖掘、人工审核
- **质量门禁**：数据准确，条件明确

### Step 3：DFT计算验证

- **操作**：使用DFT计算获取高保真验证数据
- **参数**：
  - 计算方法：密度泛函理论（DFT）
  - 软件：VASP、Quantum ESPRESSO、Gaussian
  - 计算参数：交换关联泛函、截断能、k点网格
- **工具**：VASP、pymatgen、ASE
- **质量门禁**：计算收敛，结果可靠

### Step 4：误差分析与对比

- **操作**：计算预测值与验证值的误差
- **参数**：
  - 误差指标：MAE、RMSE、R²、MAPE
  - 误差来源：模型误差、数据误差、计算误差
  - 误差范围：置信区间、预测区间
- **工具**：numpy、scipy、matplotlib
- **质量门禁**：误差计算准确，分析合理

### Step 5：验证报告生成

- **操作**：生成验证报告和结论
- **参数**：
  - 报告内容：误差分析、性能评估、可靠性结论
  - 结论标准：PASS/PARTIAL/REJECT
  - 建议：模型改进方向、数据补充建议
- **工具**：markdown、JSON
- **质量门禁**：报告完整，结论客观

## 边界与分流

**异常处理**：
- 实验数据缺失：转向DFT计算验证
- DFT计算不收敛：调整计算参数或使用其他方法
- 误差过大：分析误差来源并改进模型

**降级策略**：
- 优先使用实验数据（最可靠）
- 次选DFT计算数据（高精度）
- 备选高通量计算数据（数据量大）

**分支条件**：
- 需要快速验证 → 使用文献数据
- 需要高精度验证 → 使用DFT计算
- 需要大规模验证 → 使用高通量计算

## 质量检查

**验证点**：
1. 数据来源可靠性：来源可追溯，数据可重复
2. 误差计算准确性：误差指标计算正确
3. 结论客观性：基于证据的客观结论
4. 报告完整性：包含所有必要信息

**阈值**：
- MAE < 0.1 eV/atom（能量预测）
- R² > 0.8（相关性）
- 验证样本数 > 10

**失败处理**：
- 标记验证失败原因
- 记录误差来源
- 提供改进建议

## 回退策略

**失败时的替代方案**：
1. 实验数据不可用 → 使用DFT计算数据
2. DFT计算不收敛 → 使用简化计算方法
3. 误差过大 → 重新检查模型和数据
