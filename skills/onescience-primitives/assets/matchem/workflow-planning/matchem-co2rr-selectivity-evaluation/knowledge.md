# CO2RR选择性评价指标计算方法

## 适用范围

**触发条件**：
- 需要评估CO2还原反应（CO2RR）的选择性
- 需要分析HER竞争反应的影响
- 需要筛选高选择性CO2RR催化剂

**适用场景**：
- 单原子催化剂的CO2RR选择性评价
- 合金催化剂的CO2RR性能评估
- 表面修饰催化剂的选择性优化
- 电催化CO2还原的热力学分析

**不适用场景**：
- 动力学控制的选择性评价（需要过渡态计算）
- 实验验证的电化学测试（需要实验设备）
- 大规模高通量筛选（计算成本过高）

## 输入

**必要输入**：
- 吸附自由能数据（DFT计算结果）
- 反应路径信息（CO2RR和HER路径）
- 参考电位（可逆氢电极电位）

**可选输入**：
- 实验电位数据
- 文献报道的选择性数据
- 催化剂表面结构信息

**数据要求**：
- 吸附自由能数据基于实际DFT计算
- 反应路径包含所有关键中间体
- 参考电位选择适当（通常为标准氢电极）

## 输出

**主要输出**：
- 极限电位（Limiting Potential）
- 电位差（ΔU = U_L,CO2RR - U_L,HER）
- 选择性指标（CH4选择性、CO选择性等）
- 候选排序和推荐列表

**验证标准**：
- 极限电位计算正确，与文献对比合理
- 电位差正值表示CO2RR优于HER
- 选择性排序有区分度，不同候选有不同值

## 流程节点

### Step 1：吸附自由能数据准备
- **操作**：收集各中间体的吸附自由能数据
- **参数**：DFT计算结果、零点能校正、熵贡献
- **工具**：VASP输出文件解析、pymatgen分析
- **质量门禁**：吸附自由能数据基于实际计算，非估计值
- **关键数据**：
  1. CO2吸附自由能
  2. *COOH吸附自由能
  3. *CO吸附自由能
  4. *CHO吸附自由能
  5. *CH2O吸附自由能
  6. *CH3O吸附自由能
  7. *CH4吸附自由能
  8. *H吸附自由能（HER竞争）

### Step 2：极限电位计算（Schlögl模型）
- **操作**：计算CO2RR和HER的极限电位
- **参数**：吸附自由能变化、电子转移数
- **工具**：自定义计算脚本
- **质量门禁**：极限电位计算正确，物理意义明确
- **计算公式**：
  - CO2RR极限电位：U_L,CO2RR = -ΔG_max / (n*e)
  - HER极限电位：U_L,HER = -ΔG_H / (1*e)
  - 其中ΔG_max是CO2RR路径中最大自由能变化
  - n是电子转移数（CO2→CH4为8电子）

### Step 3：电位差计算
- **操作**：计算CO2RR和HER的电位差
- **参数**：极限电位值
- **工具**：简单减法计算
- **质量门禁**：电位差计算正确，符号有意义
- **计算公式**：
  - ΔU = U_L,CO2RR - U_L,HER
  - ΔU > 0：CO2RR热力学优于HER
  - ΔU < 0：HER热力学优于CO2RR

### Step 4：选择性指标计算
- **操作**：计算各候选的选择性指标
- **参数**：极限电位、电位差、反应路径信息
- **工具**：选择性计算脚本
- **质量门禁**：选择性指标计算正确，有区分度
- **关键指标**：
  1. CH4选择性：基于CO2→CH4路径的极限电位
  2. CO选择性：基于CO2→CO路径的极限电位
  3. H2选择性：基于HER路径的极限电位
  4. 综合选择性：考虑多个产物的选择性加权

### Step 5：候选排序和推荐
- **操作**：根据选择性指标排序候选
- **参数**：排序策略、筛选标准
- **工具**：排序算法、筛选脚本
- **质量门禁**：排序有区分度，推荐候选合理
- **排序策略**：
  1. 按电位差排序（ΔU越大，选择性越好）
  2. 按极限电位排序（U_L,CO2RR越正，活性越高）
  3. 综合排序（考虑活性和选择性）

### Step 6：结果验证和报告
- **操作**：验证计算结果，生成报告
- **参数**：验证标准、报告格式
- **工具**：验证脚本、报告生成模板
- **质量门禁**：结果与文献对比合理，报告完整
- **验证点**：
  1. 极限电位值在合理范围（-2.0 V 到 0 V vs RHE）
  2. 电位差符号与文献报道一致
  3. 选择性排序有区分度

## 边界与分流

**异常处理**：
- 吸附自由能数据缺失 → 使用文献估计值或重新计算
- 极限电位计算异常 → 检查反应路径和电子转移数
- 选择性排序无区分度 → 检查数据质量和计算方法
- 推荐候选不合理 → 调整筛选标准或排序策略

**降级策略**：
- DFT数据不足 → 使用文献报道值
- 计算成本过高 → 使用简化模型
- 选择性评价失败 → 仅进行活性评价

## 质量检查

**验证点**：
1. 吸附自由能数据：基于实际DFT计算，非估计值
2. 极限电位计算：与文献报道值对比，偏差<0.2V
3. 电位差计算：符号正确，物理意义明确
4. 选择性排序：有区分度，不同候选有不同值
5. 推荐候选：基于实际计算数据，非硬编码值

**失败处理**：
- 数据质量差 → 重新计算或使用文献值
- 计算异常 → 检查参数设置和计算方法
- 结果不合理 → 人工检查并决策

## 回退策略

**替代方案**：
1. 使用文献报道的选择性数据
2. 采用简化模型（如仅考虑CO2→CO路径）
3. 降级为活性评价（不考虑选择性）
4. 使用实验数据验证计算结果
