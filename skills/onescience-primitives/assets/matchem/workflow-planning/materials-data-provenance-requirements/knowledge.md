# 材料科学数据可追溯性要求

## 适用范围
当材料科学任务涉及材料结构数据、性能数据时，必须确保数据可追溯到权威来源。适用于材料模拟、性能计算、高通量筛选、数据分析等所有需要材料数据的场景。

## 输入
- 材料结构数据：晶体结构、分子结构、表面结构等
- 性能数据：离子电导率、电子电导率、力学性能、热力学性质等
- 来源信息：Materials Project编号、ICSD编号、文献DOI、实验测量条件

## 输出
- 带有来源标注的数据
- 可追溯性验证报告
- 数据质量评估

## 流程节点
1. 获取材料数据 → 2. 验证数据来源 → 3. 标注来源信息 → 4. 检查数据质量 → 5. 记录追溯信息

每步含：操作、参数、工具、质量门禁

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 结构数据来源优先级 | 用户上传 > Materials Project API > ICSD > 文献提取 | [D1] | 按优先级获取 |
| 性能数据标注要求 | 具体文献来源和测量条件 | [归因报告] | 不能仅标注"典型值" |
| 假设数据使用限制 | 仅用于方法验证，不能作为正式结论依据 | [归因报告] | 假设数据不能作为结论 |
| 数据质量标记 | PASS/PARTIAL/BLOCKED | [归因报告] | 根据数据可追溯性标记 |

## 边界与分流
- 如果数据来自Materials Project，应包含MP编号（如MP-8651）
- 如果数据来自ICSD，应包含ICSD编号
- 如果数据来自文献，应包含DOI和具体测量条件
- 如果数据为假设值或典型值，应标记PARTIAL而非PASS

## 质量检查
- 验证所有数据是否有权威来源标注
- 检查来源信息是否完整（编号、DOI、测量条件）
- 确认假设数据未被用作正式结论

## 回退策略
- 如果无法获取真实数据，应标记PARTIAL并说明原因
- 如果用户提供了假设数据，应明确标注其局限性
- 如果数据来源冲突，应以优先级更高的来源为准

## 资源召回建议
- 当任务涉及材料数据使用时召回本卡片
- 当需要验证数据可追溯性时召回本卡片
- 当数据来源不明确时召回本卡片
