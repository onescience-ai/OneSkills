# ADMET性质预测完整工作流契约

## 适用范围
本卡片适用于基于SMILES基础模型（如SMILES-Mamba）的ADMET性质预测任务，覆盖从输入数据验证到最终性质评估的完整工作流。适用于药物发现早期阶段的分子筛选，需要预测分子的吸收、分布、代谢、排泄和毒性性质。不适用于需要实验验证的高精度预测或需要三维结构信息的预测任务。

## 输入
- **s01输入**：标准化SMILES列表（CSV格式）和靶点条件（可选）
- **数据源**：公开数据集（如ChEMBL、PubChem）或用户提供的分子数据
- **模型权重**：预训练的SMILES基础模型权重文件（如smiles_mamba.pt）
- **预处理要求**：SMILES需经过标准化处理，确保化学合法性

## 输出
- **s01输出**：标准化SMILES列表和靶点条件向量
- **s02输出**：编码后的性质条件向量和模型预测结果
- **s03输出**：生成的候选分子SDF文件（约1000个分子）
- **s04输出**：排序分子集、每个端点的AUROC评估报告、QED≥0.6和SA≤6筛选后的分子子集、性质多样性报告

## 流程节点
1. **s01输入核验**：验证输入文件存在性，标准化SMILES，准备靶点条件
2. **s02权重加载与编码**：加载模型权重，编码性质条件向量，执行初步预测
3. **s03分子生成**：基于条件向量生成候选分子，输出SDF文件
4. **s04性质筛选与评估**：计算每个端点的AUROC，按QED和SA评分筛选，生成评估报告

每步质量门禁：s01需确保SMILES合法性100%；s02需验证模型加载成功；s03需确保生成分子数≥1000；s04需确保AUROC计算完成且QED/SA筛选有效。

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 生成分子数 | 1000 | [归因报告] | s03步骤需生成的候选分子数量 |
| QED阈值 | ≥0.6 | [归因报告] | 药物相似性评分阈值 |
| SA阈值 | ≤6 | [归因报告] | 合成可及性评分阈值 |
| AUROC计算 | 每个端点独立计算 | [归因报告] | 评估预测性能的指标 |
| SMILES标准化 | 必须执行 | [归因报告] | 确保输入分子化学合法性 |

## 边界与分流
- **输入文件缺失**：当默认输入文件不存在时，应尝试从公开数据源获取替代数据，而不是直接阻塞
- **模型权重缺失**：当预训练模型不可用时，可使用其他公开的ADMET预测模型作为替代
- **计算资源不足**：当无法生成完整1000个分子时，可生成子集并注明限制
- **网络连接问题**：当无法访问公开数据源时，应记录阻塞原因并等待网络恢复

## 质量检查
- **SMILES合法性校验**：使用RDKit等工具验证每个SMILES的化学合法性
- **AUROC计算验证**：确保每个端点的AUROC计算正确，值在0-1之间
- **QED/SA评分验证**：确保评分计算符合标准算法
- **多样性检查**：确保生成的分子在化学空间中具有多样性

## 回退策略
- **数据获取失败**：使用本地缓存的公开数据集或生成合成数据
- **模型加载失败**：使用轻量级ADMET预测模型（如ADMETlab）作为替代
- **计算超时**：减少生成分子数量或使用并行计算
- **评估指标异常**：检查数据质量，调整模型参数或使用其他评估指标

## 资源召回建议

- 需要构建ADMET性质预测工作流时

- 需要定义AUROC计算方法和QED/SA筛选规则时

配套资源建议：RDKit（化学信息学工具）、ADMETlab（ADMET预测数据库）、ChEMBL（生物活性数据库）
