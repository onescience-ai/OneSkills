# 实验数据与文献数据区分标准

## 适用范围
- **触发条件**：orchestrator 在 s03 步骤执行性能指标量化时
- **适用场景**：多孔硅锂离子电池负极结构设计任务，需要区分和报告不同来源的性能数据
- **不适用场景**：纯文献调研任务、已有完整实验数据的任务

## 输入
### 数据来源类型
1. **实验测量数据 (Experimental)**
   - 来源：本次任务的实际实验测量
   - 特点：可重复、有原始数据文件、有实验条件记录
   - 标记：EXP-[日期]-[序号]

2. **模拟计算数据 (Simulated)**
   - 来源：本次任务的计算模拟结果
   - 特点：有输入参数、有计算日志、有收敛性证明
   - 标记：SIM-[工具]-[日期]-[序号]

3. **文献引用数据 (Literature)**
   - 来源：已发表的论文、专利、技术报告
   - 特点：有DOI/引用信息、有作者和期刊来源
   - 标记：LIT-[作者]-[年份]-[序号]

## 输出
### 数据来源追溯表
```yaml
data_provenance:
  - metric: "初始比容量"
    value: "2500 mAh/g"
    source_type: "experimental"
    source_id: "EXP-20260915-001"
    description: "本次任务在0.1C倍率下的首次充放电测试结果"
    validation: "与文献报道值（2000-3000 mAh/g）一致"
  
  - metric: "首圈库仑效率"
    value: "85%"
    source_type: "literature"
    source_id: "LIT-Wang-2023-001"
    reference: "DOI: 10.1038/s41467-020-15217-9"
    description: "引用Nature Communications论文的典型值"
    validation: "作为参考基准，非本次任务直接测量"
```

### 证据层级定义
| 层级 | 数据类型 | 可信度 | 适用场景 |
|------|----------|--------|----------|
| 1 | 实验测量 | 最高 | 结论验证、性能确认 |
| 2 | 模拟计算 | 高 | 机理分析、参数优化 |
| 3 | 文献引用 | 中 | 背景参考、对比基准 |
| 4 | 理论预测 | 低 | 初步筛选、趋势判断 |

## 流程节点
1. **数据收集** → 汇总所有性能数据
2. **来源识别** → 判断每项数据的来源类型
3. **层级标注** → 按证据层级进行分类
4. **追溯验证** → 确认数据来源的可追溯性
5. **报告生成** → 按规范格式输出结果

## 关键参数
| 参数 | 要求 | 说明 |
|------|------|------|
| 数据来源标注 | 必填 | 每项数据必须标注来源类型和ID |
| 证据层级 | 必填 | 按1-4级进行分类 |
| 引用格式 | 推荐 | 文献数据需提供DOI或引用信息 |
| 验证状态 | 推荐 | 标注数据是否经过验证 |

## 边界与分流
### 数据混合处理规则
1. **实验+文献混合**：实验数据为主，文献数据为参考
2. **多来源冲突**：优先使用实验数据，标注差异
3. **数据缺失**：明确标注"未测量"或"待验证"

### 异常处理
1. **来源不明**：标记为"来源待确认"，降低可信度
2. **数据矛盾**：标注矛盾点，提供多种解释
3. **引用错误**：核实原始文献，修正引用信息

## 质量检查
- [ ] 每项数据都有明确的来源标注
- [ ] 实验数据有原始记录可追溯
- [ ] 文献数据有DOI或引用信息
- [ ] 证据层级分类正确
- [ ] 数据差异有合理解释

## 回退策略
1. 来源信息不完整 → 使用"来源待确认"标记
2. 无法获取原始数据 → 降低数据可信度等级
3. 数据矛盾无法解决 → 保留多种可能性，标注不确定性

## 资源召回建议
- **何时召回**：s03步骤开始时、数据来源不确定时
- **配套资源**：matchem-porous-si-anode-material-structure（材料结构参数）
