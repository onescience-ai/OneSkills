# CO2光催化机器学习预测模型工作流

## 适用范围

**触发条件**：
- 需要预测材料的光催化活性或CO2还原性能
- 需要快速筛选大量候选材料的光吸收性能
- 需要建立材料属性与光催化性能之间的定量关系

**适用场景**：
- CO2光催化剂的高通量虚拟筛选
- 新型光催化材料的性能预测
- 光催化机理的特征重要性分析
- 实验验证前的优先级排序

**不适用场景**：
- 需要第一性原理精度的DFT计算（应使用VASP）
- 需要实验验证的场景（ML仅提供预测）
- 数据量极少（<50个样本）的场景（易过拟合）

## 输入

**必要输入**：
- 材料属性数据集（含带隙、元素组成、晶体结构等特征）
- 目标变量（如光催化活性评分、CO2吸附能、产氢速率等）
- 训练/验证/测试集划分

**可选输入**：
- 预训练模型权重
- 特征工程配置
- 超参数搜索空间

**数据格式要求**：
- 特征矩阵：pandas DataFrame或numpy数组
- 目标变量：连续值（回归）或分类标签（分类）
- 缺失值处理：删除或插补

## 输出

**主要输出**：
- 训练好的预测模型（scikit-learn/XGBoost/LightGBM格式）
- 模型性能评估报告（R²、RMSE、MAE等）
- 特征重要性排序列表
- 候选材料预测结果及排序

**验证标准**：
- 测试集R² > 0.8（回归任务）
- 交叉验证稳定性（标准差<5%）
- 与文献报道性能对比合理

## 流程节点

### Step 1：数据准备
- **操作**：加载材料数据集，处理缺失值，划分训练/测试集
- **参数**：测试集比例=0.2，随机种子=42
- **工具**：pandas, scikit-learn
- **质量门禁**：数据完整性100%，类别平衡检查

### Step 2：特征工程
- **操作**：提取材料描述符（元素组成、电子结构、晶体学特征）
- **参数**：特征选择方法（方差阈值、相关性过滤）
- **工具**：pymatgen, matminer
- **质量门禁**：特征数量合理（10-100个），无高度相关特征（r<0.9）

### Step 3：模型选择与训练
- **操作**：选择并训练预测模型
- **参数**：模型类型（XGBoost/RF/NN），超参数优化
- **工具**：scikit-learn, XGBoost, LightGBM
- **质量门禁**：训练集拟合良好，无明显过拟合

### Step 4：模型评估
- **操作**：在测试集上评估模型性能
- **参数**：评估指标（R², RMSE, MAE, AUC等）
- **工具**：scikit-learn metrics
- **质量门禁**：测试集性能达到预设阈值

### Step 5：特征分析
- **操作**：分析特征重要性，解释模型决策
- **参数**：特征重要性方法（SHAP、 permutation importance）
- **工具**：SHAP, eli5
- **质量门禁**：关键特征与领域知识一致

### Step 6：候选筛选
- **操作**：使用训练好的模型预测新材料性能
- **参数**：预测置信度阈值、排序策略
- **工具**：模型predict方法
- **质量门禁**：预测结果合理性检查

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 模型类型 | XGBoost/RF/LightGBM | [1] | 集成学习方法，适合表格数据 |
| 测试集比例 | 0.2 | [2] | 标准划分比例 |
| 随机种子 | 42 | [2] | 保证可重复性 |
| 交叉验证折数 | 5 | [2] | 平衡计算成本与评估稳定性 |
| 特征选择阈值 | 方差>0.01 | [3] | 剔除低方差特征 |
| 相关性阈值 | r<0.9 | [3] | 剔除冗余特征 |
| 学习率 | 0.1 | [1] | XGBoost默认值 |
| 树数量 | 100-1000 | [1] | 根据验证集调整 |

## 边界与分流

**异常处理**：
- 过拟合 → 增加正则化、减少特征、增加数据
- 欠拟合 → 增加模型复杂度、添加特征
- 数据不平衡 → 使用过采样/欠采样、调整类别权重
- 预测偏差大 → 检查数据质量、调整特征工程

**降级策略**：
- 模型性能不足 → 使用简单基线模型（如线性回归）
- 数据量不足 → 使用迁移学习或预训练模型
- 计算资源有限 → 使用轻量级模型（如LightGBM）

## 质量检查

**验证点**：
1. 数据质量：无异常值、缺失值处理合理
2. 模型稳定性：交叉验证标准差<5%
3. 预测合理性：预测值在物理合理范围内
4. 特征一致性：重要特征与领域知识相符

**失败处理**：
- 性能不达标 → 调整特征工程或模型超参数
- 过拟合严重 → 简化模型或增加数据
- 预测异常 → 检查输入数据格式

## 回退策略

**替代方案**：
1. 使用文献报道的经验公式作为基线
2. 采用多模型集成提高鲁棒性
3. 使用迁移学习利用相关领域数据
4. 降级为规则筛选（如带隙范围过滤）
