# 同位素效应验证标准

## 适用范围
本卡片适用于同位素效应验证任务，确保质量效应预期合理、统计显著性检验充分、短时与长时动力学关系明确、验收判定标准清晰。适用于涉及同位素标记的分子动力学模拟验证。

## 输入
- 同位素标记数据：C12/C13扩散系数、能量数据
- 模拟轨迹：短时动力学轨迹
- 统计数据：多次模拟结果
- 物理预期：质量效应理论值

## 输出
- 验收判定报告：同位素效应检测结论、统计检验结果、物理合理性分析
- 风险与限制说明：结论边界、数据质量限制
- 后续采样建议：是否具备长时采样条件

## 流程节点
1. 质量效应预期建立 → 2. 扩散系数计算 → 3. 统计显著性检验 → 4. 物理合理性检查 → 5. 验收判定 → 6. 后续建议

## 关键参数
### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 质量效应预期 | 13C扩散系数 < 12C | 物理理论 | 较重同位素扩散较慢 |
| 统计显著性 | p < 0.05 | 统计标准 | t检验/ANOVA |
| 扩散系数比值 | D13/D12 ≈ sqrt(12/13) | 理论值 | 简单理论预测 |
| 能量守恒 | 能量漂移 < 0.1 meV/atom | MD标准 | 模拟质量指标 |

### 校准数值
以下数值来自CO2/Cu(111)/水/K界面体系，供量级校准；其他体系需以自身证据重新锚定。
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| C12扩散系数 | 待真实模拟数据 | 任务输出 | 需要真实模拟 |
| C13扩散系数 | 待真实模拟数据 | 任务输出 | 需要真实模拟 |

## 边界与分流
- 质量效应预期不合理：检查物理模型或模拟参数
- 统计不显著：增加模拟次数或检查数据质量
- 物理不合理：检查力场参数或模拟设置
- 数据质量不足：重新进行模拟或使用更长轨迹

## 质量检查
- 质量效应预期必须符合物理理论
- 统计检验必须通过
- 物理合理性必须检查
- 验收判定必须基于真实数据

## 回退策略
- 预期不合理：使用理论值作为参考
- 统计不显著：使用更敏感的检验方法
- 物理不合理：检查力场和模拟设置
- 数据不足：使用更长的模拟轨迹
