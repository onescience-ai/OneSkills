# 析氢反应电催化活性与稳定性评估

## 适用范围
本知识描述一套标准的电化学测试协议，用于在酸性电解液中系统评估电催化析氢反应（HER）催化剂的活性与长期稳定性。典型适用场景包括：对新合成的非贵金属或复合催化剂（如硫化物、硒化物、磷化物等）进行性能基准测试；比较不同催化剂或同一催化剂不同负载量、制备条件下的本征活性与耐久性；以及为后续的器件化（如膜电极组件测试）提供材料级的性能参考数据。该协议特别适用于需要精确控制传质（如旋转电极）和严格电位控制的研究与质控环节。

## 输入
- **必需输入**：
  1.  **催化剂工作电极（活性测试用）**：通常是催化剂被修饰或负载在玻碳电极（GCE）上的电极。
  2.  **催化剂工作电极（稳定性测试用）**：通常是催化剂被负载在碳纤维纸（CFP）等多孔导电基底上的电极。
  3.  **电解液**：0.5 M H₂SO₄溶液。
  4.  **脱气气体**：高纯氢气或氮气，用于电解液脱气。
- **可选输入**：
  1.  **批处理液**：含有如0.1 M KCl的电解液，用于校准参比电极。
  2.  **参比电极校准数据**：参比电极相对于可逆氢电极（RHE）的精确电位差。

## 输出
1.  **极化曲线（i-V曲线）**：电流密度随电位变化的原始数据图。
2.  **塔菲尔图（log j vs. η）**：由极化曲线转化得到，用于提取动力学参数。
3.  **活性性能指标**：包括起始过电位、特定电流密度（如10 mA/cm²）下的过电位、塔菲尔斜率（b）和交换电流密度（j₀）。
4.  **电流密度-时间（j-t）曲线**：反映催化剂在恒定过电位下长时间运行的电流稳定性。
5.  **测试后催化剂样品**：用于后续的物理化学表征（如XPS、XRD、SEM等），以分析结构与化学状态变化。

## 流程节点
该流程由两个核心模块组成，分别用于活性评估和稳定性评估。工作流程的节点（步骤）及参数如下：

1.  **节点 s1：电解液脱气**
    *   **步骤名**：电解液脱气
    *   **描述**：使用高纯氢气（或氮气）通入电解液，以去除溶解氧并建立H₂O/H₂平衡，这是获得准确HER电流的前提。
    *   **上游依赖**：无
    *   **输入参数**：
        | 参数名 | 类型 | 默认值 | 范围/约束 | 说明 |
        | :--- | :--- | :--- | :--- | :--- |
        | `electrolyte` | string | “0.5 M H₂SO₄” | - | 电解液种类与浓度 |
        | `degassing_time` | integer | 30 | 10 - 120 | 脱气持续时间，单位：分钟 |
    *   **质量门**：在后续测试中，检查开路电位是否接近0 V vs RHE，以确认H₂O/H₂热力学平衡已建立。
    *   **提示词模板**："请将 {electrolyte} 溶液置于电解池中，通入高纯 {degassing_gas} 气体，保持气泡稳定冒出，持续 {degassing_time} 分钟，确保溶解氧被充分去除。"

2.  **节点 s2：电化学活性评估 (LSV)**
    *   **步骤名**：电化学活性评估 (LSV)
    *   **描述**：在旋转圆盘电极上进行线性扫描伏安测试，获取催化剂的本征极化行为。
    *   **上游依赖**：s1
    *   **输入参数**：
        | 参数名 | 类型 | 默认值 | 范围/约束 | 说明 |
        | :--- | :--- | :--- | :--- | :--- |
        | `scan_range` | string | “-0.7 至 -0.2 V vs SCE” | - | 电位扫描范围（相对参比电极） |
        | `scan_rate` | float | 2 | 0.1 - 100 | 电位扫描速率，单位：mV/s |
        | `rotation_rate` | integer | 1600 | 0 - 5000 | 电极转速，单位：rpm |
        | `rhe_calibration` | string | “E(RHE) = E(SCE) + 0.28 V” | - | 参比电极电位校正公式（在0.5 M H₂SO₄中） |
    *   **质量门**：在Tafel图中，至少一个电流密度数量级范围内（如从0.1到1 mA/cm²），log j 与 η 呈现良好的线性关系。
    *   **提示词模板**："在 {rotation_rate} rpm 转速下，以 {scan_rate} mV/s 的速率，从 {scan_range_start} 扫描至 {scan_range_end}，记录i-V曲线。"

3.  **节点 s3：稳定性测试电极制备**
    *   **步骤名**：稳定性测试电极制备
    *   **描述**：制备负载量较高的催化剂电极，以适应长时间、大电流的稳定性测试。
    *   **上游依赖**：无
    *   **输入参数**：
        | 参数名 | 类型 | 默认值 | 范围/约束 | 说明 |
        | :--- | :--- | :--- | :--- | :--- |
        | `catalyst` | string | “待测试催化剂” | - | 待测试的催化剂材料 |
        | `substrate` | string | “碳纤维纸 (CFP)” | - | 导电基底材料 |
        | `loading` | float | 1.0 | 0.1 - 10 | 催化剂负载量，单位：mg/cm² |
    *   **质量门**：通过目视或显微镜检查，催化剂浆料应均匀覆盖在基底指定面积内，无明显团聚或脱落。
    *   **提示词模板**："制备催化剂墨水，将其均匀涂覆于 {substrate} 上，确保负载量为 {loading} mg/cm²，干燥后备用。"

4.  **节点 s4：恒电位长期运行 (CA)**
    *   **步骤名**：恒电位长期运行 (CA)
    *   **描述**：在固定过电位下进行长时间电解，通过监测电流随时间的衰减来评估催化剂的电化学耐久性。
    *   **上游依赖**：s1, s3
    *   **输入参数**：
        | 参数名 | 类型 | 默认值 | 范围/约束 | 说明 |
        | :--- | :--- | :--- | :--- | :--- |
        | `applied_potential` | float | -0.7 | - | 恒定施加电位，单位：V vs SCE |
        | `duration` | integer | 24 | 1 - 100 | 测试持续时间，单位：小时 |
    *   **质量门**：在初始阶段后，电流密度曲线应趋于稳定或出现回升（表明活性位点暴露或重构），而非持续性下降。
    *   **提示词模板**："在 {electrolyte} 中，对制备好的工作电极施加 {applied_potential} V vs SCE 的恒定电位，持续运行 {duration} 小时，实时记录电流密度。"

## 边界与分流
- **电解液类型**：本协议基于0.5 M H₂SO₄这一强酸性环境。若需评估在中性（如1 M PBS）或碱性（如1 M KOH）条件下的性能，需使用对应的电解液和参比电极电位校正值（例如，在碱性中SCE相对于RHE的校正系数不同）。
- **测试构型**：本协议主要针对旋转圆盘电极（RDE）或固定面积的电极。若催化剂用于实际的水电解槽，后续应进行气体扩散电极（GDE）制备及膜电极组件（MEA）单电池测试。
- **稳定性评判标准**：协议中24小时是典型测试时长。对于商业化目标，可能需要数百至数千小时的测试。电流密度的稳定性判断需结合初始电流值，通常要求在指定时间后保持一定的百分比（如 >90%）。
- **上下游衔接**：本协议的上游依赖催化剂材料的合成（如溶剂热法）和电极的制备（如催化剂墨水涂覆）。其输出数据，特别是经历稳定性测试后的催化剂样品，是进行事后机理研究（如XPS分析化学态）的关键输入。

## 质量检查
1.  **极化曲线质量**：曲线应平滑，无明显的振荡或噪声。iR补偿（如果进行）后，欧姆降导致的电位偏移应被修正。
2.  **Tafel区拟合**：拟合的Tafel斜率值应在预期范围内（对于Volmer-Heyrovsky机制，斜率约为40 mV/dec 或 120 mV/dec），且拟合的R²值应接近1。
3.  **稳定性曲线**：初始阶段的电流密度下降是常见现象，可能源于表面重构或杂质去除。关键看中后期的稳定性。测试结束后，应检查电极表面是否有可见的催化剂脱落或变色。
4.  **参比电极校准**：在测试前后，可用标准方法（如测量0.5 M H₂SO₄中铂电极在氢饱和下的开路电位）校准参比电极，确保其电位准确性。

## 回退策略
- **电解液脱气不充分**：表现为在开路电位或低过电位下出现异常的氧化还原电流峰（来自溶解氧的还原）。应回退至s1节点，延长脱气时间或检查气路密封性。
- **电极转速不稳或气泡积聚**：表现为极化曲线在高电流密度区域出现剧烈波动。应回退至s2节点，检查RDE装置连接，确保转速稳定，并可适当增加转速（在设备允许范围内）。
- **稳定性测试中电流持续衰减**：可能源于催化剂在强酸和还原电位下的结构降解或活性物质流失。此时，应中止测试，回溯至催化剂合成或电极制备环节进行优化。可将衰减后的催化剂样品（s4输出）用于失效分析（如与初始样品进行XPS对比）。

## 资源召回建议
- **核心设备**：电化学工作站（如Gamry, CHI, Solartron）、旋转圆盘电极（RDE）附件、三电极电解池、磁力搅拌器。
- **配套资产**：可参考“HER电催化剂墨水制备与电极涂覆”资产进行电极制备；可参考“MoS₂/CoSe₂混合催化剂的溶剂热合成”资产获取特定催化剂材料。
- **数据分析工具**：使用Origin、Python（Matplotlib, NumPy）或MATLAB进行数据绘图与Tafel斜率拟合。可使用电化学阻抗谱（EIS）辅助分析电荷转移电阻，作为活性评估的补充。
- **相关表征技术**：测试后催化剂样品可送交X射线光电子能谱（XPS）、X射线衍射（XRD）或扫描/透射电子显微镜（SEM/TEM）进行结构与成分分析。
