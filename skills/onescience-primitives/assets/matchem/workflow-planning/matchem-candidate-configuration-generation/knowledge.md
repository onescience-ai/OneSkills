# 候选构型生成算法与约束规则

## 适用范围

**触发条件**：
- 需要生成多样候选晶体构型
- 有成分约束和对称性约束
- 需要去除等价结构

**适用场景**：
- 晶体结构预测任务中的s02步骤
- 随机结构搜索（RSS）
- 对称性约束下的构型生成
- 候选结构库构建

**不适用场景**：
- 非周期性结构（分子、团簇）
- 无约束的结构生成
- 已知结构的优化（应使用弛豫）

## 输入

**输入数据格式**：
- s01产物：搜索空间清单（成分、压力、对称性约束）
- 结构约束参数：max_atoms, min_atom_distance, space_group
- 参考结构：已知的类似结构（可选）

**数据来源**：
- s01输出的搜索空间清单
- 用户提供的约束参数
- Materials Project数据库（参考结构）

**预处理要求**：
- 约束参数验证
- 空间群对称性检查
- 参考结构标准化

## 输出

**输出产物**：
1. **候选结构库**：多个候选晶体结构的CIF/POSCAR文件
2. **去重日志**：记录去重过程和等价结构判定
3. **结构元数据**：包含对称性、原子坐标、晶格参数

**格式要求**：
- CIF或POSCAR格式的晶体结构文件
- JSON格式的元数据文件
- 文本格式的去重日志

**验证标准**：
- 结构多样性（不同的对称性和原子排列）
- 无原子重叠（原子间距离 > 阈值）
- 等价结构已去除（Space Group对称操作比对）

## 流程节点

### Step 1：约束空间定义
- **操作**：解析s01输出的约束参数
- **参数**：成分约束、压力范围、对称性约束
- **工具**：约束解析器
- **质量门禁**：约束完整性检查

### Step 2：候选构型生成
- **操作**：在约束空间内生成初始候选构型
- **参数**：生成算法=随机结构搜索（RSS）、候选数量=50-100
- **工具**：ASE（原子模拟环境）、PyXtal
- **质量门禁**：生成数量满足要求

### Step 3：原子重叠检测
- **操作**：检测并去除原子重叠的构型
- **参数**：最小原子距离=1.0 Å
- **工具**：距离计算工具
- **质量门禁**：无原子重叠构型保留

### Step 4：等价结构判定
- **操作**：识别并去除等价重复结构
- **参数**：对称性容差=0.1 Å, 角度容差=1°
- **工具**：Space Group对称操作比对工具
- **质量门禁**：等价结构已去除

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 最小原子距离 | 1.0 Å | 经验值 | 原子重叠检测阈值 |
| 对称性容差 | 0.1 Å, 1° | 文献值 | 等价结构判定容差 |
| 候选数量 | 50-100 | 经验值 | 生成候选结构数 |
| 空间群 | 1-230 | 用户输入 | 对称性约束 |

## 边界与分流

**异常处理**：
- 约束冲突：降级为无对称性约束生成
- 生成数量不足：调整生成参数或算法
- 对称性判定失败：使用近似对称性匹配

**降级策略**：
- 对称性约束过严：放宽对称性要求
- 计算资源不足：减少候选数量

**分支条件**：
- 有对称性约束：使用对称性约束生成算法
- 无对称性约束：使用随机结构搜索

## 质量检查

**验证点**：
1. 候选结构数量检查
2. 原子重叠检测验证
3. 等价结构去重验证
4. 结构多样性评估

**阈值**：
- 最小原子距离 > 1.0 Å
- 等价结构判定容差 < 0.1 Å, 1°

**失败处理**：
- 重试生成（调整参数）
- 标记为BLOCKED（约束冲突）

## 回退策略

**失败时的替代方案**：
- 对称性约束生成失败：使用随机结构搜索
- 等价结构判定失败：使用能量排序去重
- 候选数量不足：使用已知结构作为候选
