# 层状材料可迁移机器学习原子势验证标准工作流

## 适用范围
本工作流适用于层状材料（如二维材料、层状化合物）的可迁移机器学习原子势（MLIP）验证任务。触发条件：需要验证机器学习原子势在层状材料上的准确性、可迁移性和泛化能力。不适用场景：非层状材料的原子势验证、经典分子力场验证、量子化学计算本身。

## 输入
- **参考数据**：量子化学或第一性原理计算数据（DFT、TDDFT等），包含结构、能量、力、应力张量。
- **数据格式**：extxyz 或 npz 格式，包含计算设置信息。
- **数据集要求**：至少包含训练集、验证集和测试集划分。

## 输出
- **数据审计报告**：数据质量、统计信息、异常值检测。
- **模型训练产物**：训练好的机器学习原子势模型。
- **验证评估报告**：模型在测试集上的精度指标（能量MAE、力MAE等）。
- **分子动力学验证报告**：模型在分子动力学模拟中的稳定性、能量守恒等。

## 流程节点
标准4步工作流：
1. **数据审计（s01）**：检查参考数据质量、格式一致性、统计分布。
   - 操作：加载数据，计算统计量，可视化分布，检测异常值。
   - 参数：数据路径、格式、阈值。
   - 工具：Python（ASE、NumPy、Matplotlib）。
   - 质量门禁：数据完整性检查通过，无缺失值，能量力分布合理。
2. **模型训练（s02）**：训练机器学习原子势模型。
   - 操作：划分训练集/验证集，配置模型架构，执行训练，保存checkpoint。
   - 参数：模型类型（如SchNet、NequIP、MACE）、超参数、训练轮数。
   - 工具：MLIP框架（如FLARE、DeePMD-kit、ASE）。
   - 质量门禁：训练损失收敛，验证集误差在可接受范围内。
3. **验证评估（s03）**：在独立测试集上评估模型精度。
   - 操作：加载模型，预测测试集能量和力，计算误差指标。
   - 参数：测试集路径、误差度量（MAE、RMSE）。
   - 工具：Python脚本。
   - 质量门禁：能量MAE < 1 meV/atom，力MAE < 0.1 eV/Å（典型阈值，需根据应用调整）。
4. **分子动力学验证（s04）**：验证模型在分子动力学模拟中的表现。
   - 操作：使用模型进行NVT/NPT模拟，分析能量守恒、结构稳定性。
   - 参数：模拟温度、压力、时间步长、模拟时长。
   - 工具：LAMMPS、ASE分子动力学模块。
   - 质量门禁：能量漂移<0.1 meV/atom/ps，结构无异常变形。

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据格式 | extxyz/npz | [领域通用] | 标准原子数据格式 |

| 验证集比例 | 10-15% | [领域通用] | 用于早停和超参数调整 |

## 边界与分流
- **数据缺失**：如果参考数据不可用，任务应阻塞并请求用户提供数据或搜索公开数据集（如Materials Project、AFLOW）。
- **数据质量差**：如果数据存在大量异常值，需进行数据清洗或请求更高质量数据。
- **模型不收敛**：调整超参数或尝试不同模型架构。
- **验证失败**：分析失败原因，可能是数据分布不匹配或模型泛化能力不足。

## 质量检查
- 数据审计：检查数据完整性、格式一致性、统计分布合理性。
- 模型训练：监控训练损失和验证损失，防止过拟合。
- 验证评估：使用独立测试集，计算多种误差指标。
- 分子动力学验证：检查能量守恒、结构稳定性、温度控制。

## 回退策略
- 数据缺失：尝试从公开数据库（Materials Project、AFLOW、NOMAD）下载相关数据。
- 模型训练失败：简化模型架构或增加训练数据。
- 验证失败：重新检查数据划分或调整模型超参数。
