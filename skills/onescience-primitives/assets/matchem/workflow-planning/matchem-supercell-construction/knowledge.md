# LAMMPS超胞构建规范

## 适用范围
本卡片适用于LAMMPS模拟中超胞构建的任务，确保超胞尺寸、原子映射、固定原子组设置符合模拟要求。涵盖三斜晶胞参数计算、元素映射规则、固定原子组设置、表面超胞尺寸计算。

## 输入
- 初始结构：晶胞参数、原子坐标、元素类型
- 模拟需求：超胞尺寸、固定原子层数、表面方向
- 力场要求：原子类型映射

## 输出
- 超胞构建脚本：LAMMPS输入脚本中的create_box、create_atoms等命令
- 原子组定义：固定原子组、移动原子组
- 超胞参数报告：原子数统计、固定原子组映射、晶胞参数和元素类型对应关系

## 流程节点
1. 晶胞参数计算 → 2. 超胞尺寸确定 → 3. 原子坐标生成 → 4. 元素映射 → 5. 固定原子组设置 → 6. 验证超胞构建

## 关键参数
### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 三斜晶胞参数 | a,b,c,α,β,γ | 通用标准 | 晶胞几何参数 |
| 元素映射规则 | 原子类型与力场对应 | 通用标准 | 每个原子类型对应力场参数 |
| 固定原子组 | 底部N层原子 | 通用标准 | 通常固定2-4层 |
| 超胞尺寸 | 3×3×1等 | 通用标准 | 根据体系大小确定 |

### 校准数值
以下数值来自CO2/Cu(111)/水/K界面体系，供量级校准；其他体系需以自身证据重新锚定。
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| Cu(111) 3×3超胞 | 4层×3×3×2=72原子 | FCC基元 | 每个晶胞2个原子 |
| 固定Cu数 | 288原子 | 标准要求 | 底部两层固定 |

## 边界与分流
- 晶胞参数不正确：重新计算或使用标准晶胞
- 超胞尺寸过大：分块构建或使用并行计算
- 元素映射错误：检查原子类型定义
- 固定原子数不符：调整固定层数或超胞尺寸

## 质量检查
- 晶胞参数必须正确
- 原子数必须符合预期
- 元素映射必须一致
- 固定原子组必须正确定义

## 回退策略
- 参数错误：使用标准晶胞参数
- 尺寸过大：使用更小的超胞或并行构建
- 映射错误：重新定义原子类型

## 资源召回建议
