# 数据驱动材料发现标准工作流

## 适用范围
数据驱动材料发现的完整工作流，涵盖从数据获取到实验验证的全流程。适用于CO2光催化剂、电池材料、太阳能电池材料等各类功能材料的高通量筛选和设计优化。

## 输入
- 研究目标定义（目标材料属性、应用场景）
- 初始数据集（实验或计算数据）
- 计算资源（HPC集群、DFT软件）
- 验证资源（实验设备、表征手段）

## 输出
- 筛选后的候选材料列表
- 材料性能预测报告
- DFT验证结果
- 实验验证结果（如适用）

## 流程节点
1. **任务定义** → 明确筛选目标、性能指标、约束条件
2. **数据获取** → 从数据库获取训练数据（Materials Project等）
3. **特征工程** → 提取材料描述符，构建特征矩阵
4. **模型训练** → 选择并训练预测模型
5. **高通量筛选** → 对候选空间进行快速预测筛选
6. **DFT验证** → 对筛选结果进行高精度计算验证
7. **实验验证** → 对最终候选进行实验合成和性能测试
8. **结果分析** → 综合分析，提出设计建议

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据质量门禁 | R² > 0.8, MAE < 0.1 eV | [1] | 模型性能要求 |
| 筛选阈值 | 根据目标属性确定 | [2] | 候选筛选标准 |
| DFT验证规模 | 前10-100个候选 | [1] | 计算资源分配 |
| 实验验证规模 | 前3-10个候选 | [2] | 实验资源分配 |
| 迭代轮数 | 2-6轮 | [3] | 主动学习迭代 |

## 边界与分流
- 数据不足：使用迁移学习、数据增强、主动学习
- 计算资源有限：分层筛选，先快速筛选再精细验证
- 实验验证困难：使用文献数据或代理实验
- 结果不理想：调整筛选策略，重新定义目标空间

## 质量检查
- 验证每个步骤的输入输出契约
- 检查数据质量和完整性
- 评估模型泛化能力和预测不确定性
- 与文献结果对比验证

## 回退策略
- 模型性能不足：尝试不同模型架构或特征组合
- DFT验证失败：检查计算设置，尝试替代方法
- 实验验证失败：分析失败原因，调整材料设计
