# 蛋白口袋文件准备（分子生成任务）

## 适用范围
适用于需要蛋白口袋PDB文件作为输入的靶标特异性三维分子生成任务。口袋文件必须包含完整的原子坐标、残基信息和合理的几何特征。

## 输入
- 目标蛋白的PDB ID或结构文件
- 结合位点残基列表（可选）
- 蛋白处理软件（如PDB2PQR、AutoDockTools）

## 输出
- 符合要求的蛋白口袋PDB文件
- 口袋几何特征描述
- 文件验证报告

## 流程节点
1. **获取蛋白结构** → 从PDB数据库下载或用户提供
2. **结构预处理** → 添加氢原子、修复缺失残基、分配电荷
3. **口袋定义** → 基于配体位置或已知结合位点定义口袋
4. **口袋提取** → 提取口袋周围的残基和原子
5. **文件格式化** → 保存为PDB格式，确保原子命名正确
6. **验证** → 检查文件格式、原子坐标、口袋几何

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| PDB文件格式 | .pdb | [D1] | 标准蛋白结构格式 |
| 原子坐标 | 三维笛卡尔坐标 | [D1] | Å为单位 |
| 残基信息 | 残基名称、链ID、序列号 | [D1] | 必须完整 |
| 口袋半径 | 通常5-10 Å | [D1] | 围绕结合位点 |

## 边界与分流
- **结构缺失**：蛋白结构不完整时，需使用同源建模或分子动力学模拟补全
- **口袋不明确**：结合位点未知时，需使用口袋预测工具
- **格式错误**：PDB文件格式不正确时，需使用格式转换工具

## 质量检查
- 检查PDB文件语法（使用PDB verifier）
- 验证原子坐标合理性（无负原子间距、无冲突）
- 确认口袋几何特征（体积、表面积、疏水性）

## 回退策略
- 使用简化蛋白模型（如Cα模型）
- 使用同源蛋白结构
- 使用分子对接软件自动准备口袋
