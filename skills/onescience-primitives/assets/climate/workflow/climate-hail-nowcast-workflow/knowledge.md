# 冰雹临近预报工作流

## 适用范围

**触发条件**：
- 需要构建完整的冰雹临近预报系统
- 需要从数据获取到验证评估的端到端工作流
- 需要概率化预报产品和业务可信度评估

**适用场景**：
- 气象台强对流天气预报系统开发
- 机场气象服务冰雹预警系统
- 科研机构临近预报算法研究

**不适用场景**：
- 仅需数据预处理或仅需模型推理的单一任务
- 非冰雹类天气现象预报

## 输入

- 雷达基数据或组合反射率产品
- 环境场再分析数据（ERA5）
- 地面冰雹观测报告（用于验证）

## 输出

- 冰雹概率预报产品（0-120分钟）
- 验证报告（指标计算、业务基准对比）
- 系统性能评估文档

## 流程节点

### Node 1：数据获取与预处理
- **操作**：获取雷达数据，质量控制，格式转换
- **关键参数**：数据源选择、质量控制阈值
- **判据**：数据完整率≥95%
- **任务绑定**：`climate-hail-radar-data-acquisition`

### Node 2：扩散概率模型实现
- **操作**：实现UNet+扩散模型，训练/推理
- **关键参数**：模型架构、扩散步数、噪声调度
- **判据**：配置与代码实现一致
- **任务绑定**：`climate-diffusion-nowcast-model`

### Node 3：独立验证资料生成
- **操作**：为每个预报时效生成独立验证标签
- **关键参数**：独立数据源、时效差异化
- **判据**：不同时效标签哈希不同
- **任务绑定**：`climate-hail-nowcast-verification`

### Node 4：检验指标与业务基准
- **操作**：计算CSI/FSS/CRPS，与业务基准对比
- **关键参数**：指标选择、基准范围
- **判据**：指标在业务可信范围内
- **任务绑定**：`climate-nowcast-metrics-baseline`

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 预报时效 | 0-120分钟 | [1] | 临近预报标准范围 |
| 验证时效间隔 | 10/20/30/45/60/90/120min | [1] | 多时效评估 |
| 集合成员数 | ≥20 | [1] | 概率预报要求 |
| 空间分辨率 | 1km | [1] | 雷达标准产品 |

## 边界与分流

**数据层分流**：
- 真实雷达可用 → 执行完整工作流
- 真实雷达不可用 → 仅执行算法流程验证（标注PARTIAL）

**模型层分流**：
- 扩散模型可实现 → 使用概率预报
- 扩散模型不可实现 → 降级使用确定性外推

## 质量检查

**工作流完整性**：
- s01-s06步骤全部执行
- 额外步骤标注为optional
- execution_steps与标准工作流对应

**输出质量**：
- 预报产品通过可视化检查
- 验证报告包含业务基准对比
- 结论标注PARTIAL/SUCCESS状态

## 回退策略

**工作流回退**：
- 某步骤失败 → 记录失败原因，跳过后续依赖步骤
- 全部步骤失败 → 输出最小可行产品（synthetic data demo）
