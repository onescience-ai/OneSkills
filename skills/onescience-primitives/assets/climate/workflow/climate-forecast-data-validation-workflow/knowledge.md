# 气象预报数据与验证工作流

## 适用范围
适用于earth域多站点温湿风时序预报任务的数据准备、预处理、验证全流程。涵盖输入数据契约、时空对齐、独立验证和数据时点规则四个核心环节。

## 输入
- 原始气象数据（站点观测、ERA5再分析、再分析产品）
- 任务定义（预报变量、时效、站点范围）
- 验证资料（独立于训练数据的参考资料）

## 输出
- 输入数据与版本清单
- 时空对齐后的标准输入
- 独立验证报告
- 资料截止时间验证记录

## 流程节点

### 1. 输入数据契约验证（s01）
- 操作：逐项核验数据来源、版本、时空覆盖、变量、单位、质量标志
- 参数：数据源URL/路径、版本号、时间覆盖范围、变量清单
- 质量门禁：任一必填项缺失 → BLOCKED，不得使用模拟数据降级

### 2. 时空对齐（s02）
- 操作：时间轴UTC对齐、空间坐标WGS84统一、单位标准化
- 参数：UTC为唯一时间基准、WGS84为唯一坐标系
- 质量门禁：输出时空对齐记录文件，含处理方法和影响范围

### 3. 数据时点验证（s01/s02）
- 操作：验证每条输入数据的观测时间是否早于资料截止时间
- 参数：资料截止时间（观测签发时点）
- 质量门禁：目标时刻之后的观测不得进入输入

### 4. 独立验证（s06）
- 操作：使用未参与训练的参考资料评估预报性能
- 参数：独立验证资料来源、时间范围、空间范围
- 质量门禁：验证资料必须来自与训练数据不同的来源或时间段

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 时间基准 | UTC | [1] | 气象领域唯一时间基准 |
| 坐标系 | WGS84 | [1] | 地理坐标标准 |
| 温度单位 | °C | [1] | 气象标准单位 |
| 湿度单位 | %RH | [1] | 相对湿度 |
| 风速单位 | m/s | [1] | 10m风速 |
| 数据分辨率 | 0.25°×0.25° | [1] | ERA5标准分辨率 |
| 训练/测试划分 | 1979-2017训练，2018测试 | [1] | Pangu-Weather协议 |

## 边界与分流
- 模拟数据 → 仅用于方法验证，不得用于业务验收
- 资料截止时间未设置 → BLOCKED
- 独立验证资料与训练数据同源 → 验证无效

## 质量检查
- 检查s01输出是否包含每项必填输入的来源、版本、覆盖范围
- 验证时间轴为UTC、坐标为WGS84
- 确认独立验证资料来源独立性

## 回退策略
- 数据来源不可用时：寻找替代数据源或请求数据权限
- 时空对齐失败时：检查坐标系、时区设置
- 独立验证不可行时：使用历史回放数据
