# 30米农田范围与面积制图数据预处理、产品生成与验证工作流

## 适用范围

**适用场景**：
- 遥感制图任务需要处理真实Landsat卫星影像数据
- 需要执行完整的遥感数据预处理流程（辐射定标、大气校正、几何配准、云掩膜）
- 需要生成符合标准格式的GeoTIFF/COG遥感产品
- 需要进行独立验证和基线比较
- 当必需输入缺失时需要标准处置流程

**不适用场景**：
- 使用合成数据而非真实传感器数据
- 不需要标准预处理流程的简单分析任务
- 不需要独立验证的探索性研究

## 核心科学问题

1. 真实传感器数据与合成数据在遥感制图任务中的本质区别是什么？对验收判定有何影响？
2. 遥感数据预处理工作流中辐射定标、几何配准和质量掩膜的具体作用与必要性是什么？
3. 方法配置与输入输出契约验证的具体执行要求是什么？
4. 遥感制图产品的标准输出格式规范（GeoTIFF/COG）和空间元数据完整性要求是什么？
5. 遥感分类独立验证的标准要求是什么？
6. Landsat数据预处理标准流程是什么？

## 工作流节点

### 节点 1：遥感数据预处理

**目的**：将原始Landsat数据转换为可用于分类的地表反射率产品

**关键参数**：
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 辐射定标 | DN→TOA辐亮度→TOA反射率 | [论文1] | 将传感器原始计数值转换为反射率 |
| 大气校正 | TOA反射率→地表反射率 | [论文1] | 消除大气散射和吸收影响 |
| 几何配准 | 多时相影像空间对齐 | [论文1] | 确保多时相影像空间一致性 |
| 云掩膜 | QA_PIXEL波段 | [论文1] | 排除云污染像元 |

**质量门禁**：
- 预处理后的时间轴、坐标、单位和形状可检查
- 每项插值、归一化、掩膜和缺测处理均有记录
- 辐射定标、几何配准和质量掩膜均有记录

### 节点 2：GeoTIFF/COG产品生成

**目的**：将分类结果转换为标准格式的遥感产品

**关键参数**：
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 输出格式 | GeoTIFF/COG | [论文1] | 遥感制图产品的标准交付格式 |
| 空间参考 | EPSG投影 | [论文1] | 包含完整的坐标系统信息 |
| 仿射变换 | 地理坐标变换矩阵 | [论文1] | 定义像素到地理坐标的映射 |
| 无效值标记 | nodata_value | [论文1] | 标识无效或缺失数据 |
| 置信度波段 | 可选 | [论文1] | 提供分类置信度信息 |

**质量门禁**：
- 输出文件能够重新打开且变量和元数据完整
- 结果单位、坐标、有效时间和物理范围已核验
- 输出坐标、分辨率、无效值和置信信息完整

### 节点 3：独立验证与基线比较

**目的**：使用独立参考数据验证分类精度并与基线比较

**关键参数**：
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 独立参考数据 | GlobeLand30、FROM-GLC、ESA WorldCover | [论文2] | 与训练数据生成过程无关的外部参考数据 |
| 验证指标 | 总体精度、Kappa系数、混淆矩阵 | [论文2] | 标准精度评估指标 |
| 基线比较 | 相同样本、网格、变量和指标协议 | [论文2] | 公平比较不同方法的性能 |
| 验收门限 | 预先登记的门限 | [论文2] | 判定性能PASS的标准 |

**质量门禁**：
- 验证资料未参与训练、参数选择或阈值调优
- 结果与基线采用相同样本、网格和指标协议
- 未达到预先登记门限时不得判定性能通过
- 验证采用独立地点、日期或传感器资料

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| Landsat数据预处理流程 | Level-1T→大气校正→地形校正→云掩膜 | [论文1] | 标准预处理流程 |

## 边界与分流

**真实数据与合成数据的本质区别**：
- 真实传感器数据：对真实地表的映射能力，可用于正式验收
- 合成数据：仅能验证管线逻辑正确性，不能替代真实观测用于正式验收
- 当必需输入缺失时：应标记相关产出为PARTIAL/BLOCKED而非自行降级

**预处理步骤完整性**：
- 即使使用合成数据，也应在日志中记录预处理配置或说明跳过原因
- 辐射定标将传感器原始计数值转换为反射率
- 几何配准确保多时相影像空间对齐
- 质量掩膜排除云污染像元

**产品格式规范**：
- 30米农田范围图应以GeoTIFF格式输出
- 包含EPSG投影、仿射变换、无效值标记和可选的置信度波段
- CSV仅作为辅助格式

## 质量检查

- 检查execution-manifest.json中real_satellite_data_used和overall_delivery字段的一致性
- 检查processing_log.txt中是否包含s02步骤的执行或跳过记录
- 检查是否产出method_identity_report.json、io_compatibility_matrix.json和dry_run_log.json
- 检查输出目录中是否存在.tif文件，quality_metadata.json中是否包含nodata_value和transform字段
- 检查validation_report.md中是否包含外部参考数据来源说明和基线比较结果表

## 回退策略

- 当真实传感器数据缺失时：标记任务为BLOCKED，不使用合成数据降级
- 当预处理步骤无法执行时：记录跳过原因，生成preprocessing_skip_record.json
- 当独立验证数据不可用时：只报告结果，不得声明性能PASS
- 当基线比较无法执行时：明确说明没有合规基线

## 资源召回建议

- 当需要执行Landsat数据预处理时召回本卡片
- 当需要生成GeoTIFF/COG格式产品时召回本卡片
- 当需要进行独立验证和基线比较时召回本卡片
- 当需要判定真实数据与合成数据区别时召回本卡片
