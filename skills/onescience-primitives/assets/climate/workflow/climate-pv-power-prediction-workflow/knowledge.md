# 光伏功率预测标准工作流

## 适用范围
本卡片适用于光伏功率预测任务的规划与执行，提供标准工作流步骤（s01-s06）的详细定义、每个步骤的输入输出契约、依赖关系以及验证要求。

## 输入
- 任务需求：预测时段、站点列表、预测精度要求
- 可用数据：气象数据、历史功率数据、电站属性数据
- 资源约束：计算资源、时间限制

## 输出
- 预测结果：各站点0-48小时功率预测值
- 验证报告：分层验证指标、基线比较、验收结论
- 执行报告：工作流执行记录、资源使用情况

## 流程节点
1. s01 数据预检 → 检查数据完整性、质量、时点规则
2. s02 时空对齐 → 对齐时间序列，处理时区差异，匹配站点与气象数据
3. s03 方法配置与契约验证 → 配置预测方法，验证输入输出契约
4. s04 核心计算 → 执行预测模型训练与推理
5. s05 结果恢复与产品生成 → 生成标准化预测产品，恢复原始量纲
6. s06 分层验证 → 按站点、按预测时效、按天气类型分层验证

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| s01数据质量门限 | 缺失率<20% | [行业标准] | 数据预检的验收标准 |
| s02时间对齐精度 | 分钟级 | [领域知识] | 气象数据与功率数据的时间匹配 |
| s03契约验证内容 | 输入输出格式、数据类型 | [归因报告] | 方法配置的验证要求 |
| s06验证分层维度 | 站点、时效、天气类型 | [归因报告] | 分层验证的具体维度 |

## 边界与分流
- 若s01数据预检失败，应返回数据获取阶段补充数据
- 若s03方法配置错误，应重新选择合适的方法
- 若s06验证不通过，应返回s04调整模型参数或重新训练

## 质量检查
- 验证每个步骤的输入输出契约是否满足
- 检查步骤间的依赖关系是否正确
- 确认验证要求是否按标准执行
