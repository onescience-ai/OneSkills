# 临近预报数据时点规则

## 适用范围
适用于所有气象临近预报任务中的数据时间管理，确保预报过程中不使用未来数据。

## 场景约束
预报、预警或决策只能使用签发时已经可获得的观测、分析和已签发预报产品。目标时刻之后形成的真实观测或事后分析不得进入输入。

## 输入
- 资料截止时间（Data Cutoff Time）
- 预报起报时间（Initialization Time）
- 预报时效范围（Forecast Lead Time）

## 输出
- 数据时间戳检查报告
- 时间违规告警（若检测到未来数据使用）

## 流程节点
1. **资料截止时间确定** → 明确所有输入数据的最新可用时间
2. **时间戳验证** → 检查每个数据源的时间戳不晚于起报时间
3. **预报时间范围计算** → 起报时间 + 预报时效 = 预报目标时段
4. **时间一致性检查** → 确保输入数据时间连续、无跳跃
5. **日志记录** → 记录所有时间相关信息，支持事后审计

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 资料截止时间 | 不得晚于起报时间 | [1] | 所有输入数据的最新可用时间 |
| 预报时效 | 0-60分钟 | [1] | 临近预报典型时效 |
| 时间分辨率 | 5-10分钟 | [1] | 雷达数据更新频率 |

## 边界与分流
- 若检测到未来数据使用 → 立即停止并报告违规
- 若时间戳缺失 → 标记该数据为不可用
- 若时间不连续 → 记录间隙并评估影响

## 质量检查
- 所有输入数据时间戳必须≤起报时间
- 预报输出时间必须>起报时间
- 时间范围必须完整覆盖预报时效

## 回退策略
- 时间违规时，使用可用的历史数据重新生成预报
