# NDVI融合产品独立验证方案设计

## 适用范围
执行AVHRR-MODIS连续NDVI历史序列融合重建后，需要设计独立验证方案评估融合产品质量。本卡指导如何选择验证数据源、构建验证指标体系、设定验收门限，确保验证结果的科学性和可信度。

## 输入
- 融合后的NDVI时间序列数据
- 任务验收要求
- 独立验证数据（高分辨率卫星、地面观测站、已发布产品）

## 输出
- 独立验证方案文档
- 验证指标计算结果
- 验收判定报告

## 流程节点
1. 选择验证数据源 → 2. 数据预处理与对齐 → 3. 构建验证指标体系 → 4. 计算验证指标 → 5. 设定验收门限 → 6. 执行验收判定

### 步骤1：选择验证数据源
- **操作**：选择与训练数据独立的验证数据源
- **数据源类型**：
  - 高分辨率卫星数据（如Landsat）
  - 地面观测站数据
  - 已发布产品（如GLASS、MOD13A2）
- **质量门禁**：验证数据与训练数据独立

### 步骤2：数据预处理与对齐
- **操作**：将验证数据与融合结果进行时空对齐
- **参数**：空间重采样、时间匹配
- **工具**：GIS软件
- **质量门禁**：数据对齐误差在可接受范围内

### 步骤3：构建验证指标体系
- **操作**：选择验证指标并定义计算方法
- **指标类型**：
  - 偏差（Bias）
  - 均方根误差（RMSE）
  - 相关系数（R²）
  - 趋势保持
  - 突变检测
- **质量门禁**：指标体系完整

### 步骤4：计算验证指标
- **操作**：计算各项验证指标
- **工具**：统计分析软件
- **质量门禁**：计算结果正确

### 步骤5：设定验收门限
- **操作**：根据行业标准和任务需求设定验收门限
- **门限类型**：
  - 偏差 < 0.05
  - RMSE < 0.1
  - 相关系数 > 0.9
- **质量门禁**：门限设定合理

### 步骤6：执行验收判定
- **操作**：根据验证指标和验收门限进行判定
- **判定规则**：所有指标达到门限要求
- **质量门禁**：判定结果明确

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 验证数据独立性 | 与训练数据独立 | [1] | 确保验证的公正性 |
| 空间匹配容差 | ≤1像素 | [1] | 空间对齐要求 |
| 时间匹配容差 | ≤8天 | [1] | 时间对齐要求 |

### 校准数值
以下数值来自卫星产品验证研究[1][2]，供量级校准；其他产品需以自身证据重新锚定：
| 指标 | 门限值 | 说明 |
|------|--------|------|
| 偏差（Bias） | < 0.05 | NDVI偏差在合理范围内 |
| 均方根误差（RMSE） | < 0.1 | 融合误差可接受 |
| 相关系数（R²） | > 0.9 | 趋势一致性良好 |
| 趋势保持 | 斜率差异 < 20% | 长期趋势保持 |

## 边界与分流
- 若无法获取独立验证数据，使用交叉验证方法
- 若验证数据质量不佳，降低门限要求并说明原因
- 若所有门限均未达到，判定任务失败

## 质量检查
- 检查验证数据是否真正独立
- 验证指标计算是否正确
- 验收门限是否合理

## 回退策略
- 若首选验证数据不可用，使用替代数据源
- 若门限设定不合理，重新协商门限值

## 资源召回建议
- 当任务涉及NDVI产品验证时召回本卡
- 配套召回NDVI融合算法卡和NDVI验收门限卡
