# 分位数回归森林方法

## 适用范围

面向需要从确定性预报或集合预报出发、生成完整条件概率预测分布的任务场景。典型需求包括：对数值天气预报集合输出进行统计后处理（校准），以获得概率预报、极端事件预警、风险评估所需的分位数信息或完整累积分布函数（CDF）。

QRF 方法族适用于以下条件：
- 目标变量的条件分布可能呈现多模态、偏态或不规则形状，不宜假设为高斯分布。
- 预测因子数量较多或因子间存在复杂非线性交互，需要数据驱动的变量选择能力。
- 需要同时利用多个预测因子（如集合预报统计量、地形参数、大尺度气象变量）对目标变量的条件分布进行灵活估计。

其中三个变体的针对性场景为：
- **基础 QRF**：一般性概率校准，直接对观测值的经验条件分布建模。
- **QRF EGP TAIL**：极端降水等重尾变量的尾部校准，通过在叶子节点上拟合参数化分布（扩展广义Pareto分布 EGPD3）来改善对极端分位数的估计。
- **异常值 QRF（anomaly-based QRF）**：冷热浪等温度异常预测场景，通过以观测与集合预报均值的差值（异常量）作为训练目标，使预测分布受制于历史异常的合理范围。

## 输入

### 必需输入

- **训练数据集**：包含预测因子与目标变量的观测配对数据。每条样本由一组预测因子特征和对应的目标观测值构成。训练集样本量需足够大，以支撑森林中每片叶子节点积累充分的观测样本。
  - 对于基础 QRF，目标变量为实际观测值。
  - 对于异常值 QRF，目标变量为观测值与集合预报均值之差（即异常量）。
  - 对于 QRF EGP TAIL，目标变量为降水量等连续值，叶子节点内需积累足够样本用于参数分布拟合。

- **预测因子**：用于驱动预测的特征向量，典型构成包括集合预报的统计量（均值、标准差、分位数等）、地形因子、大尺度环流指数等。QRF 算法在训练过程中会自动评估并选择对预测最有用的预测因子，因此初始因子集可以较为宽泛。

- **所需分位数列表**：根据业务需求指定的分位数值，例如 `[0.1, 0.5, 0.9]` 表示提取第10、50和90百分位。在高分辨率应用场景中，可能需要生成数百个分位数以完整刻画预测分布。

### 可选输入

- **集合预报均值**：异常值 QRF 的必需输入，用于计算训练目标中的异常量。基础 QRF 不需要此项。

- **叶子节点参数化分布选择**：QRF EGP TAIL 中，叶子节点上拟合的参数分布类型可配置。默认使用 EGPD3（扩展广义Pareto分布的三参数形式），该分布在极端值建模中具有理论基础。

## 输出

- **条件累积分布函数（CDF）**：对于每个新预测样本，输出其完整的条件预测分布。该分布以经验或参数化 CDF 的形式表示，是后续提取任意分位数的基础。

- **分位数预测值列表**：从条件 CDF 中提取的指定分位数值。每个预测样本对应一组分位数，构成概率预报的核心输出。

- **预测分布的统计特征**：基于完整 CDF，可进一步计算预测均值、方差、偏度、可靠区间等统计量。

输出质量特征：
- 基础 QRF 的预测分布范围受限于训练数据的观测范围，无法外推超出历史观测极值的预测。
- QRF EGP TAIL 通过参数化尾部分布扩展了极端值的覆盖能力，在重尾变量的高分位数区间提供更准确的估计。
- 异常值 QRF 的预测分布受历史异常范围约束，对冷热浪等极端温度事件的预测更为合理。

## 流程节点

### DAG 概览

```
s1（构建决策树森林）→ s2（叶子节点处理与预测分布构建）→ s3（分位数提取）
```

### s1：构建决策树森林

通过自助采样（bootstrap）和随机预测器子集选择，训练多棵回归树，形成随机森林。每棵树以最小化子节点方差为准则进行二叉分裂。

**参数：**

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `training_data` | dataset | — | 包含预测因子和目标变量的训练集。异常值 QRF 中目标变量为观测与预报均值之差 |
| `n_trees` | int | 200（温度）/ 1000（降水） | 森林中决策树的数量。降水校准需要更多树以稳定极端值估计 |
| `min_node_size` | int | 10 | 叶子节点中最少样本数，控制树的生长深度与过拟合程度 |
| `predictors_to_try` | int | 2（降水） | 每次分裂时随机候选预测因子数量 |

**质量门：** 模型在独立验证集上表现良好，且树间预测结果具有足够多样性（避免所有树收敛到相似结构）。

### s2：叶子节点处理与预测分布构建

对新的预测因子向量，遍历每棵决策树找到其落入的叶子节点，聚合所有树对应叶子内的训练观测值，构建条件累积分布函数。根据变体不同，CDF 的构建方式分为三种：

- **基础 QRF**：直接使用叶子内观测值的经验 CDF。
- **QRF EGP TAIL**：在每片叶子节点上拟合 EGPD3 参数化分布（三参数扩展广义Pareto分布），参数 $(\kappa, \sigma, \xi)$ 通过叶子内观测值估计。对于降水场景，还需考虑无降水概率 $P_0$，最终的预测分布为混合形式：$P_0$ 概率集中在零值，其余 $(1-P_0)$ 概率由 EGPD3 描述。
- **异常值 QRF**：叶子内的观测值为历史异常量（观测与预报均值之差），经验 CDF 描述的是异常量的条件分布。

**参数：**

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `new_predictors` | vector | — | 需要预测的新样本点预测因子 |
| `leaf_observations` | array | — | 来自 s1 的叶子节点内观测集合，用于经验或参数化 CDF 构建 |

**质量门：** 构建的 CDF 应当平滑且覆盖合理的预测范围；极端分位数（如第99百分位）在物理上合理。

**上游依赖：** s1

### s3：分位数提取

根据 s2 输出的条件 CDF，提取业务所需的指定分位数值作为概率预测结果。

**参数：**

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `cdf` | distribution | — | 来自 s2 的条件累积分布函数 |
| `quantiles` | list[float] | `[0.1, 0.5, 0.9]` | 所需分位数列表，根据业务需求确定 |

**质量门：** 分位数预测值在物理上合理且不超出极端范围；高分位数应大于低分位数（单调性）。

**上游依赖：** s2

## 边界与分流

### 适用边界

- **训练数据覆盖性**：基础 QRF 无法预测超出训练观测范围的极端值。若目标变量具有重尾特征且极端事件的量级超出历史记录，应转向 QRF EGP TAIL（参数化尾部扩展）或结合极值理论方法。

- **预测因子相关性**：当预测因子与目标变量之间相关性较弱时，模型性能显著下降。此时应优先检查预测因子选取的合理性，或考虑降维、特征工程等预处理手段。

- **异常量范围约束**：异常值 QRF 的预测能力受限于历史观测中异常量的变化范围。若预报系统发生系统性偏差漂移（如模式升级），历史异常量可能不再具有代表性，需要重新训练。

- **叶子节点样本不足**：当 `min_node_size` 过小或训练数据量不足时，叶子节点内积累的样本过少，EGP 参数拟合可能不稳定或失败。此时应增大 `min_node_size` 或增加训练数据量。

### 与上下游方法的衔接

- **上游（集合预报输出）**：QRF 作为统计后处理环节，接收集合预报的统计量（均值、离散度、分位数等）作为预测因子。若上游为确定性预报而非集合预报，预测因子集合将缺少离散度信息，模型对预测不确定性的估计能力受限。

- **下游（决策应用）**：输出的分位数预测可直接驱动决策阈值、风险评分、经济调度等应用。若下游需要概率密度函数（PDF）而非 CDF，需对分位数进行插值或参数化拟合。

- **可替换方案**：
  - **梯度提升机（GBM）**：在非参数回归框架下与 QRF 功能类似，但通常在拟合速度和某些指标上有所差异。
  - **EMOS（集合模型输出统计）**：参数化后处理方法，假设预测分布服从特定参数族（如正态、截断正态），在分布形态较为规则时效率更高，但灵活性不如 QRF。
  - **极值理论方法**：若仅关注极端尾部概率（如超越概率），专业的极值分析方法可能在尾部外推方面更为可靠。

## 质量检查

- **概率校准检验**：通过可靠性图（reliability diagram）或概率积分变换（PIT）直方图检验预测分布的校准质量。理想情况下，PIT 直方图应接近均匀分布。

- **分位数单调性**：检查输出的分位数是否满足单调性要求（高百分位值应不低于低百分位值）。不满足时表明 CDF 构建存在问题。

- **极端分位数合理性**：对高分位数（如第99百分位）进行物理合理性检查，确认其量级不超出已知的物理约束。

- **交叉验证性能**：在独立验证集上计算连续排序概率评分（CRPS）等概率评分指标，与基准方法（如集合均值、EMOS）进行比较。

- **叶子节点诊断**：检查叶子节点内样本量分布，确认不存在过小的叶子（可能导致过拟合或参数拟合失败）。

## 回退策略

- **训练数据不足**：若样本量无法支撑森林训练，应考虑减少树的数量和叶子节点大小，或转向参数化方法（如 EMOS）以降低数据需求。

- **EGP 参数拟合失败**：在 QRF EGP TAIL 中，若某些叶子节点的 EGPD3 参数拟合不收敛，可回退至基础 QRF 的经验 CDF 方式，或对失败叶子使用相邻叶子的参数值进行平滑替代。

- **预测因子相关性不足**：若验证集上 CRPS 显著劣于基准方法，应重新审视预测因子的选取，考虑引入更强的物理驱动因子或采用降维技术。

- **极端值预测偏差**：若高分位数预测存在系统性偏差，可结合极值理论对尾部进行后校准，或在 QRF EGP TAIL 中调整 EGPD 的形状参数约束。

- **计算资源受限**：若树的数量或训练数据量导致计算成本过高，可通过降低树的数量、使用近似最近邻方法加速叶子查找，或对训练数据进行空间/时间降采样来缓解。
