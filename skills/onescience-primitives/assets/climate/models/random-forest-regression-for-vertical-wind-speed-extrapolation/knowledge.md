# 随机森林回归用于风速垂直外推

## 适用范围
用于从低空和近地面气象站观测数据，预测目标高度（例如风力机轮毂高度）的垂直外推风速。该方法尤其适用于需要超越传统功率律或对数律剖面模型、并希望显式纳入大气稳定性影响的场景。典型触发条件包括：拥有多个高度的风速观测序列，且可获取或计算表征大气边界层稳定性的参数；任务目标是为风电场设计、发电量评估或电网调度提供准确的中长期风速预报。

## 输入
- **必需输入**：
  - 高空风速（例如65米处风速）。
  - 近地面风速（例如4米处风速）。
  - 时间信息：一天中的时间，通常编码为正弦和余弦函数以保留周期性。
  - 大气稳定度参数：至少应包括以下一至多项：
    - Obukhov长度（L）：直接表征大气稳定性。
    - 湍流动能（TKE）：反映边界层湍流混合强度。
- **可选输入**：
  - 风向、温度梯度等其他气象要素。
  - 地形参数（如地表粗糙度长度）。
  - 用于模型训练与验证的标记数据：即目标高度的历史实测风速。

## 输出
- **预测结果**：目标高度的30分钟（或对应数据时间分辨率）平均风速。
- **性能评估**：常用的指标包括平均绝对误差（MAE）、均方根误差（RMSE）和决定系数（R²）。
- **模型洞察**：通过`feature_importances_`属性可获取各输入特征对预测结果的重要性排序，有助于理解模型决策依据。

## 流程节点
1.  **数据准备与特征工程**：
    - 收集并对齐不同高度的风速、时间戳。
    - 从原始数据计算Obukhov长度、TKE等大气稳定度参数（可能需要温度和感热通量数据）。
    - 将时间转换为周期性特征（sin(hour), cos(hour)）。
    - 处理缺失值与异常值。
2.  **数据集划分**：
    - 将数据集按时间序列或随机方式划分为训练集、验证集和测试集。对于时间序列数据，需避免未来信息泄露。
    - 为进行可靠的性能评估，推荐采用循环交叉验证（round-robin validation），例如对多个不同地点或不同时段的数据进行轮流验证。
3.  **模型训练与超参数调优**：
    - 使用训练集数据，实例化`RandomForestRegressor`。
    - 通过网格搜索（GridSearchCV）或随机搜索（RandomizedSearchCV）结合交叉验证，在以下超参数范围内寻找最优组合：
      - `n_estimators`（树的数量）：10–800
      - `max_depth`（树的最大深度）：4–40
      - `max_features`（分裂时考虑的最大特征数）：1–6
      - `min_samples_split`（内部节点分裂所需最小样本数）：2–11
      - `min_samples_leaf`（叶子节点所需最小样本数）：1–15
    - 最终模型参数因站点而异，例如在特定站点C1，优化后的参数为：`n_estimators`=695, `max_depth`=13, `min_samples_split`=3, `min_samples_leaf`=6。
4.  **模型评估与解释**：
    - 在独立的测试集上评估最终模型的MAE、R²等指标。
    - 分析特征重要性，验证是否符合气象学直觉（例如，Obukhov长度或TKE应有较高重要性）。
    - 与仅使用风速的简化模型或传统经验剖面模型（功率律、对数律）进行性能对比。
5.  **模型部署与预测**：
    - 将训练好的模型用于预测新的、仅有输入特征的数据。
    - 输出预测风速序列。

## 边界与分流
- **与传统方法比较**：当输入特征仅限于高低空风速时，随机森林模型的性能（如MAE约0.86 m/s）与功率律或对数律剖面法相当。其优势体现在加入时间、大气稳定度（Obukhov长度、TKE）等特征后，预测性能可提升约20%。因此，若无法获取稳定度参数，或计算成本受限，传统剖面法仍是合理选择。
- **预测高度的影响**：随着预测高度与输入数据高度差的增加，模型性能会下降，但下降速度通常比传统经验方法慢。对于极高层（如数百米）的预测，需确保训练数据中包含足够的高空信息。
- **复杂地形处理**：在复杂地形区域，直接使用计算得到的Obukhov长度可能无法准确表征局地稳定性。此时应考虑引入更丰富的特征（如地形曲率、坡度）或使用其他稳定性指标。
- **数据规模要求**：该方法适用于中到大规模的监督学习数据集。对于非常小的数据集（如仅有几个月数据），模型预测性能可能不稳定，建议使用更简单的模型或增加数据收集时长。

## 质量检查
- **交叉验证一致性**：在多个站点或时段上进行循环交叉验证，确保模型性能指标（MAE, R²）稳定，而非偶然。
- **特征重要性合理性**：检查`feature_importances_`，风速特征和大气稳定度特征应具有主导重要性。
- **残差分析**：绘制预测值与实测值的散点图及残差分布图，检查是否存在系统性偏差（如在高风速或特定稳定性条件下预测偏低/偏高）。
- **与基线模型对比**：必须与不包含稳定性信息的随机森林模型（仅用风速）以及经典剖面法进行对比，以量化复杂度增加带来的真实收益。

## 回退策略
- **性能不佳**：若模型过拟合（训练误差远小于测试误差），应减少`max_depth`或增加`min_samples_leaf`。若欠拟合，可增加`n_estimators`或特征维度。
- **稳定性特征无效**：若Obukhov长度或TKE的特征重要性很低，可能因数据质量问题或特征计算不当。应检查原始数据并尝试其他稳定性参数（如Richardson数）。
- **数据不足**：当可用数据量极少时，可回退到仅使用风速输入的简化随机森林模型，或使用经典物理剖面模型，并明确说明不确定性。
- **计算资源限制**：对于大规模应用或实时预测，若`n_estimators`过大导致计算缓慢，可基于超参数搜索的结果，在精度与效率间取折中值，或考虑使用梯度提升树等其他集成方法。

## 资源召回建议
- **工具与库**：Python的`scikit-learn`库（`sklearn.ensemble.RandomForestRegressor`）是标准实现。可配合`pandas`进行数据处理，`matplotlib`/`seaborn`进行可视化。
- **方法对比**：在评估本方法时，建议同时运行`power-law profile extrapolation`和`logarithmic profile extrapolation`作为基准。可考虑引入`round-robin validation workflow`以获得稳健的站点间泛化性能估计。
- **特征工程参考**：大气稳定度参数的计算可参考边界层气象学教材。时间特征的周期性编码是处理日周期信号的通用技巧。
