# 基于神经网络的数值天气预报模型校准方法

## 适用范围

用于对全球数值天气预报（NWP）模型（如ECMWF）产出的未来1至3天近地面气温（2米气温）和24小时累积降水预报进行后处理校准。该方法属于数据驱动的混合预报校准范式：以全球模型预报值作为核心输入，辅以区域模型预报和小尺度特征参数（如空气质量指数AQI、城市绿色基础设施指数MEGI），通过反向传播神经网络学习预报误差的统计规律，从而输出系统性偏差校正后的预报值。

该方法的典型触发场景包括：
- 全球NWP模型在目标区域存在系统性偏差，且存在可用的区域模型预报或站点观测数据作为补充信息源。
- 降水预报存在严重的不平衡问题（如零降水样本占绝大多数），需要专门的数据处理策略。
- 研究者或预报员拥有MATLAB环境及神经网络工具箱，能够进行模型训练与部署。

## 输入

### 必需输入
- **全球NWP模型原始预报数据**：如ECMWF的2米气温和降水预报场，通常从公开气象数据服务网站获取。
- **区域模型预报数据**（如有）：用于提供不同模型视角的参考预报，可来自其他数值天气预报系统。
- **地面真值数据**：来自气象站的实测数据，作为训练目标变量。数据应覆盖足够长的时间段（建议一年以上）。
- **小尺度辅助参数**：如前一日空气质量指数（AQI）、城市水体表面面积、城市绿色基础设施指数（MEGI）等。这些参数被认为对NWP误差的估计和后续校正有用。

### 可选输入
- 批次效应或协变量信息（如站点类型、地形特征）。
- 其他机器学习算法（如高斯过程回归、逐步线性回归）的预报结果，用于交叉比较。

## 输出

- **校准后的2米气温预报值**：经神经网络后处理的逐小时或日均气温预报。
- **校准后的24小时累积降水预报值**：经神经网络后处理的日降水总量预报。
- **模型性能评估报告**：包括均方根误差（RMSE）、皮尔逊相关系数（R）等指标，以及与原始ECMWF预报、区域模型预报的对比结果。
- **训练好的神经网络模型**：可部署用于后续预报业务或进一步研究。

## 流程节点

### s1 数据收集与数据库构建

**步骤描述**：从多个公开气象服务网站（如windy.com, Yr.no）和国家气象局（如捷克、斯洛伐克水文气象研究所）收集全球NWP模型、区域模型预报数据以及气象站的实测地面真值，并整合AQI和MEGI等辅助参数，构建历史数据库。

**输入参数**：
| 参数名 | 类型 | 默认值 | 必需 | 说明 |
|---|---|---|---|---|
| ecmwf_data_source | str | windy.com | 是 | 提供原始ECMWF数据的公开网站 |
| regional_model_sources | str | Yr.no, CHMI, SHMU | 是 | 挪威气象研究所及捷克/斯洛伐克水文气象研究所的区域模型数据 |
| ground_truth_source | str | 捷克和斯洛伐克国家气象局气象站 | 是 | 作为训练目标的气象站实测数据 |

**质量门**：数据收集应涵盖超过一年的时间序列。为避免数据质量受外部事件（如COVID-19期间航空天气报告减少）影响，数据收集应在相关干扰发生前中断。

### s2 数据预处理与特征工程

**步骤描述**：将数据库随机划分为训练集（90%）和交叉验证集（10%）。针对降水数据的严重不平衡问题（例如零降水样本占比超过66%），采用从无降水子集和降水子集中随机抽取并保持1:1比例的策略，构建专门用于降水模型训练的平衡训练子集。

**输入参数**：
| 参数名 | 类型 | 默认值 | 必需 | 说明 |
|---|---|---|---|---|
| database | str | — | 是 | 输入上一步构建的原始数据库 |
| imbalance_strategy | enum | 1:1比例重采样 | 是 | 解决降水数据不平衡的策略，可选值为“1:1比例重采样”等 |

**质量门**：训练集和交叉验证集正确划分（90%/10%），且降水训练子集满足1:1的样本比例。

### s3 神经网络模型设计与训练

**步骤描述**：在MATLAB中使用神经网络工具箱，为气温预测和降水预测分别设计和训练反向传播神经网络。测试不同网络拓扑（从单隐藏层到3个隐藏层），并应用偏置-方差权衡、早停和贝叶斯正则化等技术来防止过拟合。典型的最优拓扑为气温预测7-5-2（3层隐藏层）和降水预测11-4（2层隐藏层）。激活函数使用双曲正切S型传递函数（tan-sig）。

**输入参数**：
| 参数名 | 类型 | 默认值 | 必需 | 说明 |
|---|---|---|---|---|
| training_set | str | — | 是 | 预处理后的训练数据 |
| activation_function | enum | tansig | 是 | 神经元激活函数 |
| early_stopping_patience | int | 当验证误差开始上升时停止 | 是 | 早停策略的触发条件 |

**质量门**：模型在训练、验证和测试子集上的性能指标（如RMSE）均达到要求且表现一致，无显著过拟合。

### s4 模型评估与比较

**步骤描述**：使用独立的交叉验证集评估训练好的模型性能，计算RMSE和皮尔逊相关系数（R），并与原始ECMWF预报、区域模型预报以及其他机器学习算法的结果进行比较。根据已有验证结果，该混合模型在交叉验证集上对气温预报的RMSE改善约13%，对降水预报的RMSE改善约45%。

**输入参数**：
| 参数名 | 类型 | 默认值 | 必需 | 说明 |
|---|---|---|---|---|
| trained_model | str | — | 是 | 训练好的神经网络模型 |
| cross_validation_set | str | — | 是 | 用于独立评估的交叉验证集 |

**质量门**：模型在交叉验证集上的RMSE显著优于原始ECMWF预报。

## 边界与分流

- **气温范围限制**：该方法在训练数据覆盖的温度范围内表现良好。若目标区域存在训练数据中未充分涵盖的极端低温（如低于-5°C），模型在极端低温情况下的预测准确性可能不足，需评估是否补充极端事件数据或改用其他方法。
- **降水数据不平衡**：降水预报的本质不平衡要求必须采用专门的数据处理策略。若不平衡问题极端严重或领域特殊，可考虑使用代价敏感学习、过采样/欠采样技术（如SMOTE）或调整损失函数。
- **时序对齐问题**：每日降水摘要的统计周期（如午夜至午夜）与实际降水发生时间可能存在时差，影响预测准确性。在业务应用中需注意统计窗口的对齐。
- **与其他方法的衔接**：该方法可作为全球NWP模型后处理的方案之一。对于需要更复杂时空特征的场景，可考虑结合基于物理的校正方法或更先进的深度学习架构（如卷积神经网络、循环神经网络）。在相关方案中，高斯过程回归（GPR）和逐步线性回归是常见的替代或补充方法。

## 回退策略

- **数据质量问题**：若数据收集期间受到外部事件（如疫情）干扰导致数据噪声，应中断数据收集以保证质量，仅使用受干扰前的数据构建数据库。
- **降水数据不平衡未解决**：若采用简单重采样后模型对降水事件的预测性能仍不理想，可尝试更复杂的不平衡处理技术，或调整模型的损失函数以赋予降水事件更高权重。
- **极端事件预测不足**：若模型在极端低温或强降水事件上表现不佳，应考虑收集更多极端事件样本进行针对性训练，或集成物理约束信息。
- **模型过拟合**：若模型在训练集上表现良好但在验证集上性能下降，应加强正则化技术（如增加早停严格性、调整贝叶斯正则化参数），或简化网络拓扑。

## 资源召回建议

- **数据源**：windy.com（提供ECMWF原始数据）、Yr.no（提供区域模型数据）、各国气象局官网（提供站点实测数据）。
- **开发环境**：MATLAB 2021a及Neural Network Toolbox，用于网络构建、训练和部署。
- **相关方法参考**：高斯过程回归（GPR）、逐步线性回归等统计后处理方法，可作为基线比较或替代方案。
