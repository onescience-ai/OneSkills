# 基于一维卷积神经网络的地下水水位预测

## 适用范围

适用于在气候变化情景下，对地下水补给过程主要受降水和温度影响的地区，进行中长期（数十年）的浅层地下水位变化预测。典型应用场景包括区域水资源评估、气候变化脆弱性分析以及制定适应性管理策略。该方法要求拥有足够长的（通常超过15年）站点地下水位观测记录，以及与之匹配的长时间序列网格化历史气象数据（降水、温度）。当预测目标是单点或小范围、或系统受到显著的人类活动（如开采）干扰时，则需考虑其他方法。

## 输入

- **必需**：
  - 站点级地下水位时间序列：周或更高频率的历史观测数据，时长需满足模型训练需求。
  - 网格化历史气象驱动数据：包括降水（P）和温度（T），需要与地下水位时间序列在时间上对齐。典型数据源为如HYRAS这类覆盖历史时段的高分辨率观测格点数据集。
  - 未来气候预测数据：用于情景预测的降水和温度时序投影数据，通常来自气候模式集合（如RCP情景），并需经过偏差校正和降尺度处理以适配目标区域。
- **可选**：
  - 用于数据插补的辅助信息，如同步观测的邻近站点数据或水文过程线。
  - 用于模型超参数搜索的独立验证数据集。

## 输出

- **核心预测结果**：在不同气候情景下（如RCP2.6, RCP4.5, RCP8.5），由训练好的模型生成的未来地下水位时间序列预测。
- **趋势分析结果**：对预测的地下水位时间序列（通常按年计算）进行统计趋势分析，包括均值、下极端（2.5%分位数）和上极端（97.5%分位数）的变化趋势。输出包括趋势的显著性检验结果（如p值）和变化率估计（如Theil-Sen斜率）。
- **模型可解释性报告**：基于SHAP值分析，揭示每个时间步的降水和温度输入特征对模型预测结果（地下水位）的贡献方向（正向或负向）与强度。
- **模型性能评估指标**：在独立测试集上计算的纳什效率系数（NSE）、决定系数（R²）、均方根误差（RMSE）、偏差（Bias）等。

## 流程节点

本方法的工作流是一个有向无环图（DAG），各步骤及其依赖、参数如下表所示：

| 步骤 ID | 步骤名称 | 上游依赖 | 关键输入参数 | 质量门 | 输出产物 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **s1** | 数据准备 | 无 | - `gw_data`: 地下水位数据<br>- `met_data`: 气象数据<br>- `gap_filling`: 缺失值处理方法 | 时间序列完整性高，缺失值插补比例低（通常<2%） | 站点专用的配对数据集（地下水位、降水、温度） |
| **s2** | 模型构建 | s1 | - `dropout_rate`: Dropout率<br>- `optimizer`: 优化器<br>- `max_epochs`: 最大训练轮数 | 模型结构包含指定的关键层（1D卷积层、最大池化层、Dropout层、全连接层） | 初始化的1D-CNN模型架构 |
| **s3** | 模型训练与评估 | s2 | - `split_ratio`: 数据集划分比例<br>- `target_func`: 超参数优化目标函数<br>- `ensemble_size`: 模型集成数量<br>- `perf_threshold`: 性能阈值 | 模型在测试集上达到规定的精度阈值（如NSE和R²均大于0.8） | 训练好的最优模型及其超参数；测试集评估指标 |
| **s4** | 模型外推与可解释性验证 | s3 | - `artificial_clim`: 人工气候测试情景<br>- `shap_explainer`: SHAP解释器 | 模型在人工极端情景下输出稳定；SHAP分析符合水文物理概念 | 模型稳定性评估报告；SHAP值特征重要性分析结果 |
| **s5** | 未来情景预测与趋势分析 | s4 | - `rcp_scenarios`: 气候情景<br>- `quantiles`: 分析分位数<br>- `trend_method`: 趋势分析方法 | 趋势分析基于长期时段（如≥30年）；结果经过归一化以便跨站点比较 | 未来地下水位模拟序列；年际趋势的显著性与变化率；空间分布模式分析 |

**详细步骤说明**：

1.  **数据准备 (s1)**：获取并预处理目标区域所有站点的地下水位周时间序列，以及覆盖相同时间段的网格化降水和温度数据（例如来自HYRAS的1951-2015年数据）。对地下水位数据中的缺失值，需根据数据特征选择合适的插补方法（如相关水文过程线插值或PCHIP插值），并记录插补比例。
2.  **模型构建 (s2)**：定义站点专属的1D-CNN模型架构。典型结构包括：一个一维卷积层（固定内核大小，如3；过滤器数量通过优化确定）、一个最大池化层、一个应用固定Dropout率（如0.5）的层以防止过拟合，以及一个全连接输出层。优化器通常选用Adam。
3.  **模型训练与评估 (s3)**：将数据集划分为训练集、验证集和测试集（测试集通常为时间序列末端的一个独立时段，如2012-2016年）。使用验证集，通过贝叶斯优化算法搜索最佳超参数组合（包括批大小、序列长度、过滤器数量、全连接层大小），优化目标为NSE和R²的综合值。为减少随机性，采用集成学习策略，训练多个（如10个）模型并取平均。只有测试集性能达到高标准（如NSE和R²均>0.8）的站点才会被纳入后续预测。
4.  **模型外推与可解释性验证 (s4)**：为了检验模型在训练数据分布之外（外推）的稳定性，可构造极端但合理的人工气候情景（如温度升高5°C，降水变为4倍）输入模型，观察其输出是否平稳。同时，应用SHAP（SHapley Additive exPlanations）框架计算每个输入特征对每个预测值的贡献，验证模型是否学到了合理的物理关系（例如，高温通常对应地下水位下降，即负贡献）。
5.  **未来情景预测与趋势分析 (s5)**：将训练好的模型应用于多组未来气候情景（如来自DWD核心集合、经过偏差校正的RCP数据）的降水和温度投影数据上，生成大量地下水位预测时间序列。计算每个情景下、每个站点地下水位年均值、2.5%和97.5%分位数的时间序列。最后，使用预白化处理消除自相关后，应用Mann-Kendall检验和Theil-Sen斜率估计来分析这些时间序列的长期趋势。

## 边界与分流

- **适用边界**：该方法基于数据驱动，假设预测期内系统（降水-温度-地下水位）的输入输出关系保持相对稳定。若预测区域存在显著的未来土地利用变化、大规模地下水开采计划等人为干预，则该假设可能不成立，模型预测可能失真。
- **性能要求**：仅采纳测试集性能优异（NSE/R² > 0.8，至少0.7）的站点模型进行预测。对于不满足性能阈值的站点，其预测结果不可信，应标记为“预测不可靠”或考虑其他方法。
- **数据依赖性**：方法高度依赖历史气象与水文数据的长度与质量。若历史序列过短，模型可能无法学习到完整的季节性或年际变化模式。未来预测的不确定性很大程度上源于气候模式本身的集合离散度。
- **替代方案**：
  - 若需要模拟物理过程（如非饱和带水流）或包含人类活动影响，应转向**物理概念模型或耦合数值模型**。
  - 若预测目标是地下水系统对单次降水事件的快速响应（小时至日尺度），可能**长短期记忆网络（LSTM）或非线性自回归外部输入模型（NARX）** 在捕捉序列依赖性上更具优势。
  - 若历史数据极其匮乏，需考虑**纯经验统计模型**或基于相似流域的类比方法。

## 质量检查

- **输入数据验证**：检查地下水位与气象时间序列的长度一致性、时间对齐情况以及缺失值插补的比例与合理性。插补比例应尽可能低（多数<2%）。
- **模型性能监控**：在训练、验证和测试集上分别监控NSE、R²、RMSE等指标，确保模型没有过拟合，且在独立测试集上表现稳健。
- **物理一致性检验**：通过SHAP值分析，确认关键特征的影响方向是否符合水文学基本认知（如：温度升高通常不利于地下水补给，表现为负SHAP值；降水增加通常利于补给，表现为正SHAP值）。
- **外推稳定性测试**：观察模型在人工构造的极端输入情景下的输出是否平滑、无异常“爆炸”或剧烈震荡。
- **趋势分析合理性**：对最终的趋势分析结果，结合区域气候背景知识进行常识性判断，例如，升温显著、降水减少的区域，地下水位呈下降趋势是否合理。

## 回退策略

- **若模型性能未达标**：首先检查数据质量（特别是缺失值处理）和数据对齐是否正确。若问题依旧，可尝试简化模型结构、调整超参数搜索空间，或使用更简单的基准模型（如多元线性回归）作为对比。
- **若SHAP分析结果不合理**：可能表明模型学习到了虚假相关性。需重新审视数据预处理过程，考虑增加特征工程（如滞后项、季节项），或检查是否存在数据泄露问题。
- **若气候模式数据不可用或质量差**：无法进行未来预测。回退方案是仅对现有历史观测数据进行趋势分析，或使用统计降尺度方法从全球气候模式结果生成区域驱动数据，但需明确说明其不确定性。
- **若计算资源不足**：可减少模型集成数量，或使用更简化的模型架构，但需权衡对预测不确定性估计的影响。

## 资源召回建议

- **核心工具库**：
  - 深度学习框架：TensorFlow或PyTorch，用于构建和训练1D-CNN模型。
  - 超参数优化：如Optuna、Hyperopt等，实现贝叶斯优化。
  - 可解释性分析：SHAP库，用于计算和可视化特征贡献。
  - 统计分析：SciPy、Statsmodels库，用于执行Mann-Kendall检验等趋势分析。
- **推荐数据集**：
  - 历史气象驱动：欧洲高分辨率降尺度气象数据集（HYRAS）。
  - 未来气候情景：德国气象服务（DWD）提供的核心集合（core-ensemble）数据，或CORDEX-EUR11等区域气候模式降尺度并经偏差校正后的输出。
- **相关方法/模型**：作为替代或基准，可参考LSTM、NARX网络，以及基于物理的地下水数值模型（如MODFLOW）。
- **模板参考**：工作流节点表（上文）可作为此类数据驱动水文预测项目的标准流程模板。
