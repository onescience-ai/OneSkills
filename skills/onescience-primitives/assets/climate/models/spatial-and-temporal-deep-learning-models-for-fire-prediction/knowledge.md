# 面向火灾预测的空间与时间深度学习模型

## 适用范围

适用于基于网格化时空数据（如月度火灾计数时间序列）的区域火灾发生预测任务。当输入数据同时包含空间维度（地理网格）和时间维度（历史序列）时，需要选择一种能有效捕捉对应维度依赖关系的深度学习架构。本知识覆盖四类主流模型——CNN、LSTM、CNN-LSTM 和 ConvLSTM，适用于火灾风险评估、季节性火灾趋势预报、以及需要在多个空间网格上同步输出预测值的场景。模型选择的关键判据是：目标区域火灾驱动因素以空间模式为主、时间模式为主、还是时空耦合为主。

## 输入

- **必需**：网格化火灾计数时间序列（时空数据），即以地理网格单元为行/列、以时间为步长的二维或三维张量。典型数据来源包括 VIIRS 375m active fire product 等卫星遥感火灾产品。
- **可选**：辅助气象变量（温度、降水、风速）、土地覆盖类型、地形数据等协变量通道，可作为多通道输入提升模型表现。

## 输出

- 每个网格单元在目标时间步的火灾发生预测值（连续计数或二分类概率，取决于任务定义）。
- 输出保留与输入相同的空间网格结构，便于与 GIS 系统对接或进行空间可视化。

## 流程节点

火灾预测的深度学习建模一般包含以下步骤，每类模型在核心特征提取机制上有所不同：

1. **数据预处理**：将原始火灾事件数据聚合为网格化时间序列；进行缺失值填充、归一化/标准化处理；按时间窗口切分为训练集、验证集和测试集。

2. **模型选择与构建**：根据目标区域的火灾驱动特征选择合适的架构：
   - **CNN（卷积神经网络）**：通过卷积层提取空间特征，池化层进行降维，全连接层输出预测值。CNN 擅长捕捉局部空间依赖关系（如相邻网格的火灾聚集模式），但缺乏内在的时间记忆能力。
   - **LSTM（长短期记忆网络）**：通过遗忘门、输入门和输出门控制信息流，更新细胞状态以捕捉长期时间依赖。LSTM 适合火灾具有强时间趋势或季节性规律的区域，但无法显式建模空间依赖。
   - **CNN-LSTM（混合架构）**：先用 CNN 提取每一步的空间特征，再将特征序列输入 LSTM 以建模时间关系。该架构平衡了空间与时间特征的提取，适用于时空特征均显著的区域。
   - **ConvLSTM（卷积 LSTM）**：在 LSTM 的输入-状态和状态-状态转换中引入卷积操作，替代标准矩阵乘法，从而同时捕捉空间和时间特征。这是四类模型中时空融合程度最高的架构。

3. **特征提取与预测**：对输入数据应用所选模型的特征提取机制，通过全连接层将提取的特征映射到最终的火灾发生预测值。

4. **模型训练与评估**：使用选定的损失函数（如均方误差 RMSE）进行训练，通过验证集监控过拟合，最终在测试集上评估预测性能。

5. **结果输出与后处理**：输出每个网格单元的预测值，必要时进行反归一化或阈值处理，生成可用于决策支持的火灾风险图。

## 边界与分流

模型选择应依据目标区域火灾驱动的主导维度进行分流：

- **空间依赖主导**：当火灾发生主要受局部地理因素（如地形、植被类型、人类活动分布）驱动，且时间变化相对平稳时，**CNN 是最优选择**。在空间主导型区域，CNN 在多个验证场景中均取得了最低的预测误差，而更复杂的混合模型（如 CNN-LSTM）反而可能因不必要的复杂度而性能下降或效率降低。

- **时间依赖主导**：当火灾表现出强烈的季节性、趋势性或受气候周期驱动时，**LSTM 更具优势**。LSTM 的门控机制使其能够记忆长期历史模式，对时间序列中的趋势和周期信号敏感。

- **时空耦合主导**：当空间格局随时间动态变化（如火灾蔓延路径、季节性空间转移）时，**ConvLSTM 或 CNN-LSTM 更为合适**。ConvLSTM 通过在 LSTM 内部引入卷积操作，实现了更紧密的时空特征融合，在时空复杂度高的区域表现最优。CNN-LSTM 则提供了模块化的时空建模能力，在需要分别调优空间和时间组件时更为灵活。

- **数据规模约束**：ConvLSTM 参数量较大，在数据量不足的区域有过拟合风险。此时应优先考虑参数量更小的 CNN 或 LSTM，或使用数据增强策略。

与上下游的衔接：模型输出可直接作为火灾风险预警系统的输入，或与气象预报模型的输出进行集成，构建更全面的灾害预警流水线。相关资产包括 VIIRS 375m active fire product（数据源）、Spatiotemporal Deep Learning for Regional Fire Prediction（完整工作流）和 Hyperparameter optimization for fire prediction models（超参数优化）。

## 质量检查

- **预测误差指标**：使用 RMSE（均方误差平方根）作为主要评估指标，值越低表示预测精度越高。不同模型在同一区域的 RMSE 差异是模型选择的关键依据。
- **空间一致性检查**：检查预测结果在相邻网格之间是否合理连续，突兀的空间跳跃可能暗示模型未能捕捉空间依赖。
- **时间稳定性检查**：检查预测结果在连续时间步之间是否符合物理合理性（如火灾不会在无驱动因素时突然爆发）。
- **过拟合检测**：对比训练集与验证集的性能差距，差距过大时需增加正则化、减少模型复杂度或增加训练数据。

## 回退策略

- **CNN 表现不佳**：若目标区域存在显著的时间趋势或季节性模式，CNN 因缺乏时间记忆而失效，应转向 LSTM 或混合架构。
- **LSTM 表现不佳**：若火灾驱动因素以空间分布为主（如地形、土地利用），LSTM 无法捕捉空间依赖，应转向 CNN。
- **CNN-LSTM 在空间主导区域表现不如 CNN**：混合模型的复杂度可能带来不必要的计算开销且未带来性能提升，应回退到更简单的 CNN 架构。
- **ConvLSTM 过拟合**：在训练数据不足时，ConvLSTM 的高参数量会导致过拟合，应减少模型层数、增加 dropout、使用数据增强，或回退到参数量更小的 CNN-LSTM 或 CNN。
- **所有模型均表现不佳**：可能需要重新审视数据质量、特征工程或问题定义，考虑引入更多辅助变量或调整时间分辨率。

## 资源召回建议

- **数据源**：VIIRS 375m active fire product 提供高分辨率全球火灾检测数据，是构建网格化火灾时间序列的常用数据源。MODIS Fire Detection 产品（MOD14/MYD14）也是可替代的数据来源。
- **框架与工具**：PyTorch 或 TensorFlow/Keras 均支持 CNN、LSTM、CNN-LSTM 和 ConvLSTM 的构建。ConvLSTM 的 PyTorch 实现可参考学术社区的开源代码。
- **超参数优化**：建议使用 Optuna、Ray Tune 等工具对学习率、批大小、网络层数、卷积核大小、LSTM 隐藏单元数等关键超参数进行系统搜索。
- **数据预处理**：xarray 适合处理网格化时空数据的切片与聚合；scikit-learn 提供标准化和数据切分工具。
- **可视化**：matplotlib、cartopy 或 geopandas 可用于将预测结果绘制在地理底图上进行空间可视化。
