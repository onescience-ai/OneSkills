# 无遗忘学习

## 适用范围

该方法适用于需要让一个在源域上预训练的分类模型在不接触源域数据的情况下学习一个新目标域任务，同时尽可能保留其在源域上性能的场景。核心触发条件是：1）已经有一个训练好的CNN分类模型（如VGG16, InceptionV3等）；2）需要让它识别新的类别集合；3）源域的原始训练数据在微调新任务时不可用或不便再次使用。典型应用包括在已有火灾图像识别模型基础上新增烟雾检测任务，或在通用图像分类模型上增量学习新物体类别。

## 输入

- **必需输入**
  - 原始预训练模型：包含特征提取层的共享参数（PS）和原始任务分类层的参数（PO）。
  - 新任务数据集：包含新类别标签的图像数据集（Xn），例如用于火灾烟雾检测的BoWFire数据集。
  - 新任务类别数（num_new_classes）：用于扩展输出层。
- **可选输入**
  - 原始任务的验证集：用于在训练过程中监控旧任务性能是否衰减。
  - 超参数配置：如学习率、迭代次数、新旧任务损失函数的权重等。

## 输出

- **模型**：一个经过更新的统一模型，其参数包含共享参数（PS）、原始任务参数（PO）和新任务参数（Pn）。该模型能同时对原始任务和新任务的输入进行分类。
- **性能指标**：在原始任务和新任务验证集上分别计算的准确率或其他相关指标，用于评估知识保留与新任务学习的平衡效果。

## 流程节点

1.  **准备数据与初始化**
    - **step_id**: `s1`
    - **依赖**: 无
    - **描述**: 准备新任务的训练数据（Xn），并确保已加载原始预训练模型的共享参数（PS）和原始任务特定参数（PO）。
    - **输入参数**:
      - `Xn` (str, 必需)：新任务图像数据集路径。
      - `PS` (str, 必需)：共享参数文件路径或对象。
      - `PO` (str, 必需)：原始任务参数文件路径或对象。
    - **质量门**: 验证Xn格式正确且PS/PO已成功从原始任务训练结果中加载。
    - **输出**: 新任务数据集就绪，原始模型参数已保留。

2.  **生成旧任务软目标**
    - **step_id**: `s2`
    - **依赖**: `s1`
    - **描述**: 使用保留的原始模型参数（PS, PO）对新任务数据集（Xn）进行前向传播，得到模型在原始任务类别上的预测概率分布（Yo）。这个分布被称为“软目标”。
    - **输入参数**:
      - `Xn` (str, 必需)
      - `PS` (str, 必需)
      - `PO` (str, 必需)
    - **质量门**: 软目标`Yo`的维度必须与原始任务的类别数量一致。
    - **输出**: `Yo`：旧任务类别上的预测概率分布。

3.  **扩展输出层**
    - **step_id**: `s3`
    - **依赖**: `s2`
    - **描述**: 在模型现有的输出层上，为新任务的每个类别添加一个新的神经元节点。
    - **输入参数**:
      - `num_new_classes` (int, 必需)：新任务的类别数量。
    - **质量门**: 新添加的节点数应严格等于新任务类别数。
    - **输出**: 扩展后的网络输出层架构。

4.  **初始化新任务参数**
    - **step_id**: `s4`
    - **依赖**: `s3`
    - **描述**: 为第3步中新增加的输出层节点随机初始化一组权重参数（Pn）。
    - **输入参数**:
      - `last_layer_size` (int, 必需)：模型倒数第二层（即新输出层的上一层）的神经元数量，用于确定新参数矩阵的输入维度。
    - **质量门**: 新参数Pn的维度应为 (`last_layer_size` x `num_new_classes`)。
    - **输出**: `Pn`：新任务特定的、随机初始化的参数。

5.  **迭代训练与优化**
    - **step_id**: `s5`
    - **依赖**: `s4`
    - **描述**: 进入训练循环。在每一次迭代中，使用当前模型（参数为PS, PO, Pn）对新任务数据（Xn）进行前向传播，得到模型在旧任务类别上的新预测（\widehat{Yo}）和在新任务类别上的预测（\widehat{Yn}）。然后计算组合损失并反向传播更新所有参数。
    - **输入参数**:
      - `Xn` (str, 必需)
      - `Yo` (str, 必需)：步骤2生成的软目标。
      - `Yn` (str, 必需)：新任务的真实标签。
    - **质量门**: 在验证集上，总损失应持续下降，且旧任务准确率和新任务准确率均不应出现显著下降。
    - **输出**: 更新后的参数（PS, PO, Pn）。
    - **提示词模板**:
      ```python
      # 伪代码示例
      for epoch in range(num_epochs):
          # 前向传播
          features = shared_backbone(Xn, PS)
          pred_old_task = old_task_head(features, PO) # 得到 \widehat{Yo}
          pred_new_task = new_task_head(features, Pn) # 得到 \widehat{Yn}
          
          # 计算损失 (具体损失函数见下文“质量检查”)
          loss = compute_combined_loss(pred_old_task, Yo, pred_new_task, Yn)
          
          # 反向传播与更新
          loss.backward()
          optimizer.step()
          optimizer.zero_grad()
      ```

## 边界与分流

- **适用边界**：本方法要求原始模型与新任务模型共享相同的特征提取器（主干网络），仅扩展最终的分类头。当新任务与原始任务差异极大，以至于它们所需的特征表示根本不同（例如从图像分类转到语音识别）时，共享特征提取器的假设失效，此时应考虑其他迁移学习方法，如特征提取器微调或从头训练。
- **与联合训练分流**：如果原始任务数据在学习新任务时仍然可用，则更优的策略是直接使用所有任务的数据进行联合训练，这通常能达到更好的性能且避免遗忘问题。LwF主要解决原始数据不可用的场景。
- **与其他持续学习方法分流**：若对模型架构修改有严格限制（不允许增加节点），或需要更精细的参数重要性评估，可考虑使用如渐进式神经网络、参数正则化等方法。

## 质量检查

在迭代训练过程中（流程节点s5），需要进行以下监控以确保训练质量：
1.  **损失收敛性**：监控组合损失是否随训练迭代逐步下降并趋于稳定。
2.  **旧任务性能保留**：在每个训练周期结束后，使用原始任务的验证集评估模型性能。准确率下降幅度应控制在可接受范围内（例如小于5%），这通过组合损失中的知识蒸馏项来约束。
3.  **新任务性能**：监控模型在新任务验证集上的准确率是否稳步提升。
4.  **组合损失计算**：总损失通常由两部分组成：
    - **知识蒸馏损失**：度量当前模型预测的旧任务概率分布（\widehat{Yo}）与原始模型软目标（Yo）之间的差异，常用KL散度。
    - **新任务交叉熵损失**：度量当前模型预测的新任务概率分布（\widehat{Yn}）与真实标签（Yn）之间的差异。
    - 总损失 = α * 知识蒸馏损失 + (1-α) * 新任务交叉熵损失。权重α需要调整以平衡新旧任务的学习。

## 回退策略

当训练失败或效果不佳时，可依据以下模式排查并调整：
- **模式：新旧任务差异过大导致旧任务软目标信息不足**
  - **回退方案**：这可能是方法的根本局限。可尝试增加蒸馏损失的权重（α），或转而采用更复杂的持续学习方法，如引入回放缓冲区（即使原始数据不可用，也可存储少量原始任务的代表性样本的特征或输出分布）。
- **模式：模型容量不足**
  - **回退方案**：如果模型在新旧任务上的性能同时很差，可能模型容量不足以同时表示两种任务的特征。应考虑换用一个更大容量的预训练模型（如从VGG16换成ResNet50）作为基础架构，重新开始整个流程。
- **模式：新任务数据量过少导致过拟合**
  - **回退方案**：对新任务数据进行强有力的数据增强。同时，可以尝试在训练时冻结共享特征提取层（PS），只更新原始分类头（PO）和新分类头（Pn），以减少需要优化的参数量，待新任务学习稳定后再解冻部分层进行微调。

## 资源召回建议

- **深度学习框架**：TensorFlow、Keras或PyTorch均可高效实现该流程。上述流程节点s5中的伪代码是通用的。
- **预训练模型库**：可从TensorFlow Hub、Keras Applications或TorchVision Models中获取在ImageNet等大规模数据集上预训练好的CNN模型作为起点。
- **相关工具**：可使用类似`tf.keras.callbacks.ModelCheckpoint`的回调函数，在训练过程中保存在新旧任务验证集上综合表现最佳的模型权重。
- **增强技术**：针对新任务数据不足的情况，除标准的数据增强（旋转、翻转、缩放）外，可研究使用Mixup、CutMix等高级增强策略来提升泛化能力。
