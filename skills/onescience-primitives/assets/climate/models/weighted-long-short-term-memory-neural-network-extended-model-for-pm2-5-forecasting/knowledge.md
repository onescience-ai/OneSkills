# 用于PM2.5预测的加权长短期记忆神经网络扩展模型

## 适用范围

适用于区域空气质量预报场景，尤其是监测站点空间分布不均匀、需要同时考虑站点密度与风场条件对空气污染浓度时空相关性影响的日均 PM2.5 浓度预测任务。典型触发条件包括：目标区域拥有多个监测站点的历史浓度与气象观测数据、需要融合站点间空间关联信息与气象预报来生成次日浓度预测值。该方案尤其适合站点稀疏区域的浓度预报改进需求。

## 输入

模型接受两部分输入：

**第一部分：历史观测数据**
- 目标站点及其附近站点的历史 PM2.5 浓度观测值
- 各站点的经纬度坐标（用于计算地理距离）
- 历史气象数据，包括温度、风速、风向、气压、露点温度、水汽柱总量等

**第二部分：天气预报数据**
- 目标站点的天气预报信息，包括天气状况、风向、风级、上下温度等

**关键参数**

| 参数 | 典型值 | 说明 |
|------|--------|------|
| r | 10 | 时间滞后天数（滑动窗口长度） |
| s | 10 | 考虑的邻居站点数量 |
| unit1 | 10 | 第一个 MLP 隐藏层神经元数 |
| unit2 | 10 | LSTM 隐藏层神经元数 |
| unit3 | 20 | 最终 MLP 隐藏层神经元数 |
| batchsize | 7 × 90 | 训练批次大小 |
| optimizer | RMSprop | 优化器 |

## 输出

- 目标站点次日的 PM2.5 浓度预测值
- 该预测值可直接用于空气质量预警、健康防护建议发布等下游决策场景

## 流程节点

### 1. 邻居站点选择与权重生成

从目标站点的邻近站点中选取 K 个最近站点作为邻居站点。将这些邻居站点的历史 PM2.5 浓度观测、地理距离以及历史风场条件作为输入，通过一个局部多层感知机（MLP）计算各邻居站点对目标站点的空间关联权重，生成加权的历史 PM2.5 时间序列数据。该步骤的核心目的是模拟风场与地理距离对空间相关性的动态影响。

### 2. 时空特征提取

将目标站点的历史 PM2.5 观测值与上一步生成的邻居站点加权 PM2.5 时间序列数据共同输入 LSTM 网络层。LSTM 同时模拟时间依赖关系与空间依赖关系，从中提取时空特征向量。

### 3. 预测输出

将上一步提取的时空特征向量与目标站点的气象预报数据输入另一个 MLP，通过特征融合与非线性映射，生成目标站点次日的 PM2.5 浓度预测值。

### 4. 模型训练

- 优化器采用 RMSprop
- 批次大小为 7 × 90（即 90 个站点的 7 天数据作为一个批次）
- 三段式架构的隐藏层神经元数分别为 10、10、20
- 训练过程中需确保时间滞后窗口 r 与邻居站点数 s 的设置与数据时间分辨率和站点密度匹配

## 边界与分流

- **站点密集区域**：该模型在站点稀疏区域的改进效果更为显著，对站点密集区域的性能优势相对较低。若目标区域站点分布密集且均匀，可考虑使用更简单的时空回归模型（如 STSVR 或 GWR）作为基准方案。
- **极端峰值预测**：在预测冬季极端浓度峰值时，模型精度可能出现下降。若应用场景对极端值预测精度要求极高，建议结合极端值统计方法或分位数回归进行补充校正。
- **数据缺失严重区域**：若监测站点密度极低或数据缺失严重，模型效果可能受限。此时应优先处理数据完整性问题，或转向对数据需求较低的替代方案（如基于卫星遥感的浓度反演方法）。
- **上游依赖**：模型的加权准确性依赖于输入数据的质量与代表性，包括邻居站点选择的合理性、气象数据的时空分辨率与完整性。
- **下游衔接**：输出的 PM2.5 预测值可接入空气质量预警系统、健康风险评估模型或环境决策支持平台。

## 质量检查

- 验证输入数据的完整性：目标站点及邻居站点的历史浓度与气象数据是否齐全，天气预报数据是否可用
- 检查时间滞后窗口 r 是否覆盖了足够的历史信息以捕获时间依赖模式
- 评估邻居站点数 s 是否与区域站点密度匹配：稀疏区域可适当增大 s 以覆盖更广的空间范围
- 对预测结果进行残差分析，关注极端值（高浓度时段）的预测偏差
- 对比模型在不同季节、不同天气条件下的表现，识别系统性偏差

## 回退策略

- 若邻居站点数量不足或分布不合理，可调整 s 参数或改用基于距离衰减权重的固定方案替代 MLP 动态权重生成
- 若 LSTM 时空特征提取效果不佳，可考虑增加 LSTM 层数或引入注意力机制增强时序建模能力
- 若模型在极端峰值预测上持续表现不佳，可结合统计后处理方法（如分位数校正）对预测值进行调整
- 若气象预报数据不可用或质量较差，可仅使用历史浓度数据进行自回归预测，但需注意预测精度会相应下降
- 若监测站点数据缺失严重，可先使用插值方法填补缺失值，或转向使用卫星遥感反演的网格化浓度产品作为替代数据源

## 资源召回建议

- **同类方法参考**：LSTME（长短期记忆网络扩展模型）、STSVR（时空支持向量回归）、GWR（地理加权回归）可作为对比基准或替代方案
- **配套工具**：深度学习框架（如 TensorFlow、PyTorch）用于模型实现；气象数据 API 用于获取天气预报输入
- **数据源**：中国环境监测总站的历史空气质量数据、中国气象局的气象观测与预报数据
- **扩展方向**：可引入注意力机制增强空间权重的动态建模能力，或结合图神经网络处理不规则站点拓扑结构
