# 异常数值观测校正法（ANO）

## 适用范围

用于数值天气预报（NWP）模式输出的系统性偏差校正，特别是针对中长期（如24-240小时）预报。该方法属于统计后处理中的气候学异常订正（Anomaly Correction）范畴，适用于网格化的预报场与观测场对比场景。其典型应用对象为2米气温、相对湿度等标量气象变量。该方法计算简单、原理透明，常被用作评估更复杂方法（如深度学习订正模型）的基准（baseline）。

## 输入

- 必需：
  - 待校正的预报场网格点坐标 (i, j)。
  - 该网格点对应的多年历史预报数据序列。
  - 同一地点、同时段的多年历史观测数据序列。
- 可选：
  - 用于计算气候平均值的具体历史数据年数（默认值可基于数据可得性设定，例如12年）。

## 输出

- 经校正的预报值网格场。

## 流程节点

1.  **定义网格点**：确定需要进行偏差校正的预报网格点坐标 (i, j)。
2.  **计算模型气候态**：收集该网格点 (i, j) 在历史 n 年内同一预报时效的所有预报值，计算其算术平均值，得到该点的“模型气候平均值”。
3.  **计算观测气候态**：收集同一网格点 (i, j) 在历史 n 年内同一观测时段的所有观测值，计算其算术平均值，得到该点的“观测气候平均值”。
4.  **计算预报异常**：对当前的单次预报值，减去步骤2得到的模型气候平均值，得到该预报场相对于气候态的“异常”（偏差）。
5.  **异常积分订正**：将步骤4得到的预报异常值，加上步骤3得到的观测气候平均值，得到最终的校正预报值。其核心思想是将预报的异常信号保留，并用更可靠的观测气候背景场进行叠加。

## 边界与分流

- **变量适用性**：该方法对温度、湿度等具有较强气候稳定性的标量变量订正效果较好。对于风速、风向等具有方向性、变化更剧烈的矢量变量，订正效果不佳，甚至可能引入新的偏差或使预报技巧下降。在这些变量上，应优先考虑其他统计方法或动力-统计结合的方法。
- **气候态稳定性假设**：方法成功的关键前提是气候平均值在长时间尺度上是稳定的。当面临快速变化的天气系统或气候趋势发生显著变化时，基于固定年份的气候平均可能失效，导致校正偏差。此时需要考虑使用滑动窗口计算气候态或引入趋势项。
- **与深度学习方法的关系**：ANO方法通常作为传统方法的代表，与CU-net等深度学习方法进行性能比较，以凸显后者的优势。

## 质量检查

- 检查输入的历史预报与观测数据在时间维度和网格点上是否严格对齐。
- 计算校正前后预报场的常用统计指标（如平均绝对误差、均方根误差、偏差），并与原始预报的指标进行对比，以量化校正效果。
- 分季节、分变量评估校正效果，警惕在特定变量或季节上出现性能下降（如风场）。

## 回退策略

- 若历史数据年数过少，导致气候平均值不可靠，应考虑使用更长的回溯期或采用其他不依赖长期气候态的偏差校正方法（如分位数映射、回归校正）。
- 若对风速、风向等变量的校正效果为负，应放弃使用ANO方法，转而使用专门针对矢量场校正的技术或直接对风速分量分别订正。
- 当预报异常与观测异常之间存在非线性关系或依赖关系时，ANO这种线性叠加的方法可能失效，可考虑采用更灵活的统计模型或机器学习模型进行订正。

## 资源召回建议

- 配套工具：可用于计算气候平均值、进行网格点数据操作的气象数据分析库，如 Python 的 xarray、netCDF4。
- 相关方法：作为基准，与之比较的更先进方法包括 CU-net 等深度学习偏差校正模型。
- 数据来源：历史预报数据通常来自数值天气预报中心（如ECMWF）的再分析或归档数据集（如ERA5），观测数据则来自地面气象站观测网络。
