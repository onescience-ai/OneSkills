# GLM降尺度方法

## 适用范围

广义线性模型（GLM）降尺度方法适用于大区域尺度上气候变量（降水发生、降雨量、气温）的统计降尺度任务。其核心思想是：对每个地面站点建立单点回归模型，以大尺度气象预测变量（通常来自再分析数据或全球气候模式输出）为输入，预测局地气候变量。该方法在基准评估研究中广泛用作独立统计降尺度方案，也常作为深度学习降尺度方法（如卷积神经网络）的对照基准，用于衡量新方法的改进幅度。典型应用场景包括：
- 区域气候模式输出的后处理降尺度
- 全球气候模式（GCM）预估在站点尺度的统计降尺度
- 降水和气温联合降尺度时需保持物理一致性

该方法的三个变体在预测变量的空间信息提取上有所不同：
- **GLM1**：使用距目标站点最近的单一网格点作为预测变量
- **GLM4**：使用距目标站点最近的四个网格点作为预测变量
- **GLMPC**：对预测变量空间做主成分分析（PCA），保留解释 95% 方差的主成分作为预测变量

## 输入

- **必需**：
  - 标准化后的气象大尺度预测变量。根据所选变体，可为：
    - GLM1/GLM4：目标站点邻近网格点的原始变量值
    - GLMPC：经 PCA 降维后保留的主成分得分（需从全区域预测变量场提取）
  - 参考观测数据：用于训练和验证的站点级降水（发生量、总量）和气温实测记录
- **可选**：
  - 预处理的季节划分信息（如冬季/夏季分别建模）
  - 降水阈值设置（如日降水阈值 1mm 用于区分降水发生）
  - 其他气象辅助变量（如大尺度水汽通量、位势高度等）

## 输出

- 每个目标站点的日尺度预测值：
  - 降水发生概率（二值预测）
  - 降雨量预测（连续值，仅在发生降水时有效）
  - 气温预测（连续值）
- 可选输出：模型诊断信息（拟合优度、残差分析、偏差统计量）

## 流程节点

1. **预测变量配置选择**：根据研究区域特征和数据可用性，选择 GLM1、GLM4 或 GLMPC 变体。若选择 GLMPC，需对全区域预测变量场进行主成分分析，提取解释 95% 方差的主成分。

2. **数据对齐与标准化**：将大尺度再分析数据（如 ERA-Interim、ERA5）与站点观测数据在时间维度上对齐。对预测变量进行标准化（通常使用 z-score 标准化，基于训练期统计量）。

3. **逐站点模型构建**：对每个目标站点分别建立三类子模型：
   - **逻辑回归模型**：用于估计降水发生概率，以日尺度大尺度变量为输入，二值化的降水发生状态（阈值通常为 1mm/日）为响应变量。
   - **Gamma 回归模型**（对数连接函数）：用于估计降雨量大小，响应变量为日降水量（仅在降水发生日），输入为对应的预测变量。
   - **高斯回归模型**：用于估计日均气温，响应变量为日气温观测值，输入为对应的预测变量。

4. **模型训练与交叉验证**：使用历史时期（如 1979–2010）的再分析数据和观测数据训练上述模型。推荐使用时间序列交叉验证（如多年保留法）避免时间泄露。

5. **模型应用与降尺度**：将训练好的模型应用于标准化后的 GCM 预测变量（历史时期或未来预估情景），生成逐站点的降尺度预测结果。

6. **结果汇总与评估**：汇总各站点的预测值，进行性能评估（如偏差、均方根误差、分类准确率等）。

## 边界与分流

- **GLM1/GLM4 对再分析与 GCM 预测变量之间的不一致性较为敏感**。当 GCM 输出与再分析数据在大尺度变量统计特征上存在显著差异时，基于局部网格点的模型可能产生更大偏差。此时 GLMPC 变体通常更具鲁棒性，因为主成分对模式间的系统性偏差有一定缓冲作用（综合推断，非单一素材直证）。

- **局部变异性低估问题**：所有基于回归的 GLM 方法都倾向于低估局地气候变异性，尤其是降水变量的极端值。若研究目标对极端事件敏感，应考虑分位数回归或非参数方法作为补充或替代。

- **特征选择与信息损失**：GLM 方法依赖于人工或半自动的预测变量选择，可能遗漏重要的大尺度信息。若需要端到端特征提取，可考虑基于深度学习的降尺度方法。

- **与 CNN 降尺度方法的对比**：在基准评估框架（如 VALUE 实验）中，GLM 变体常作为 CNN 等深度学习方法的基准对照。若 CNN 方法在性能上未显著优于 GLM 基准，则说明深度学习方法尚未充分发挥其优势，可能需要调整网络架构或训练策略。

## 回退策略

- **若再分析数据不可用**：可使用 GCM 历史模拟输出作为近似再分析数据进行训练，但需注意模型性能可能下降。此时应使用 GCM 历史期输出进行模型拟合，并在评估时明确说明数据源限制。

- **若站点观测数据稀疏或缺失**：考虑使用区域化方法（如空间回归）或使用邻近站点的观测数据进行空间插值后再建模。但需注意空间插值本身会引入额外不确定性。

- **若 GLM1/GLM4 偏差过大**：优先切换至 GLMPC 变体，因其对再分析-GCM 不一致性更具鲁棒性。若仍不满足要求，可考虑使用多变量 GLM 或引入额外的预测变量（如位势高度、水汽通量）。

- **若降水极端值模拟不足**：考虑使用分位数回归 GLM（Quantile GLM）替代标准 Gamma GLM，或在 Gamma 模型后添加极端值校正步骤。

## 资源召回建议

- **配套框架**：VALUE 降尺度实验框架（提供标准化评估协议和基准数据）
- **软件实现**：R 语言中的 `glm`、`mgcv`（广义加性模型，可扩展 GLM）包；Python 中的 `statsmodels`、`scikit-learn`（逻辑回归、线性回归）
- **数据源**：ERA-Interim/ERA5 再分析数据、E-OBS 站点观测数据、CMIP6 GCM 输出
- **相关方法**：可与分位数映射（QM）、偏差校正（BCSD）等统计后处理方法结合使用，以进一步提升降尺度性能
