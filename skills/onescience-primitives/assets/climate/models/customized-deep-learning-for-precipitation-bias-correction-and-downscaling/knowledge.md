# 定制化深度学习的降水偏差校正与降尺度方法

## 适用范围

本方法适用于气象学、水文学及气候影响评估等领域中，需要将粗分辨率（通常为0.25°或更粗）全球再分析数据（如MERRA2, ERA5）转换为高分辨率（如1km或更细）逐小时降水场的任务。典型应用场景包括：为水文模型提供高时空分辨率驱动数据、提高极端降水事件的模拟精度、以及为区域气候分析提供更精细的降水信息。该方法特别针对常规深度学习或统计降尺度方法在处理高度不平衡的降水数据时容易低估极端事件的问题进行了定制化设计。适用于研究者拥有长期、同步的粗分辨率再分析资料和高分辨率雷达或雨量计融合观测资料（作为训练目标）的场景。

## 输入

- 必需：
    - **粗分辨率再分析数据**：需要被校正和降尺度的源数据，例如MERRA2再分析小时降水数据。数据应包含足够长时间序列（建议不少于10年）以捕捉气候变率。
    - **高分辨率观测数据**：作为训练目标的参考真值，例如Stage IV雷达融合小时降水数据。其空间分辨率应显著高于输入数据（例如，输入0.25°，目标为1km）。
    - **数据时间划分方案**：明确的训练集、验证集和测试集划分（例如，基于年份划分），确保时间独立性以避免数据泄露。
- 可选：
    - **大气协变量**：可显著提升性能的物理相关输入变量，如可降水量、风场、湿度等，通常来自同一再分析数据集。
    - **损失函数权重参数**：定制加权损失函数中所需的权重阈值（MIN和MAX），需根据目标数据分布（如降水百分位数）进行校准。

## 输出

- **高分辨率降水数据集**：经过偏差校正和空间降尺度后的逐小时降水数据，分辨率与观测数据一致。
- **模型性能评估报告**：包括各实验场景（如不同损失函数、输入组合）在多个时间尺度（小时、日、月）和极端指数（如第99百分位降水量、年最大连续降水时长）上的定量评估结果（如KGE, RMSE, MAE, IOU）。
- **训练好的深度学习模型**：可用于对未来或新区域数据进行预测的推理模型。

## 流程节点

1.  **数据准备与划分**
    - **步骤描述**：获取并预处理MERRA2再分析数据和Stage IV观测数据。将两套数据在时空上对齐，然后按照预定时间方案（如训练:2002-2015, 验证:2016-2018, 测试:2019-2021）进行划分。
    - **上游依赖**：无。
    - **输入参数**：
        - `merra2_data` (str, 必需): 粗分辨率再分析数据，如“MERRA2 observation-corrected P”。
        - `stage4_data` (str, 必需): 高分辨率观测参考数据，如“Stage IV radar data”。
        - `time_split` (str, 必需): 时间划分方案。
    - **输出**：训练数据集，验证数据集，测试数据集。
    - **质量门**：数据时间范围正确，空间覆盖一致。

2.  **模型架构构建**
    - **步骤描述**：基于SRDRN（超分辨率深度残差网络）架构构建深度学习模型。该架构主要由用于特征提取的**残差块**和用于空间上采样的**上采样块**组成。残差块内通常包含卷积层、批归一化层和激活函数（如Parametric ReLU）。上采样块通过最近邻插值和卷积层实现分辨率提升。
    - **上游依赖**：`s1`。
    - **输入参数**：
        - `residual_blocks` (int, 必需): 残差块数量，默认16，用于确保网络足够深以提取精细特征。
        - `upsampling_blocks` (str, 必需): 上采样块配置，如“3个上采样块，因子为2,2,3”，对应总降尺度比12。
    - **输出**：SRDRN深度学习模型架构。
    - **质量门**：模型架构能实现从输入到输出的维度变换（降尺度）。

3.  **实验场景设计**
    - **步骤描述**：为系统性评估不同定制化组件的增量价值，设计多个对比实验场景。典型场景包括：仅使用常规损失函数的基线模型（Scenario 1）、引入加权损失函数的模型（Scenario 2）、加入大气协变量输入的模型（Scenario 3）、采用多任务学习框架的模型（Scenario 4-5），以及融合所有定制组件的完整模型（Scenario 6）。
    - **上游依赖**：`s2`。
    - **输入参数**：
        - `scenario_configs` (str, 必需): 各场景的具体配置表，明确每个场景所使用的损失函数、输入变量和任务设置。
    - **输出**：六个实验场景的模型配置。
    - **质量门**：场景设计能系统覆盖所有待评估的定制化组件。

4.  **模型训练**
    - **步骤描述**：使用训练数据集对每个场景的模型进行训练。使用Adam优化器，设置初始学习率（如0.0001）、批大小（如64）和训练轮数（如150）。在训练过程中，使用验证集监控模型性能，防止过拟合。
    - **上游依赖**：`s3`。
    - **输入参数**：
        - `optimizer` (str, 必需): 优化器，如“Adam”。
        - `learning_rate` (float, 必需): 学习率，如0.0001。
        - `batch_size` (int, 必需): 批大小，如64。
        - `epochs` (int, 必需): 训练轮数，如150。
    - **输出**：各场景训练好的模型。
    - **质量门**：在验证集上，模型性能（如KGE）达到最佳或稳定。

5.  **模型评估与比较**
    - **步骤描述**：在独立的测试集上，对所有训练好的场景模型以及传统统计方法（如QDM_BI）进行综合评估。评估需在多个时间尺度（小时、日、月）上进行，并特别关注对极端事件的模拟能力。
    - **上游依赖**：`s4`。
    - **输入参数**：
        - `eval_metrics` (str, 必需): 评估指标，如“KGE, RMSE, MAE, IOU”。
        - `eval_scales` (str, 必需): 评估时间尺度，如“小时、日、月”。
        - `extreme_indices` (str, 必需): 极端指数，如“99th百分位降水、年最大连续降水时长”。
    - **输出**：各模型性能评估报告和对比结论。
    - **质量门**：评估结论能清晰展示各定制化组件的增量价值。

## 边界与分流

- **适用边界**：
    - 本方法为监督学习，**必须**有同期的高分辨率观测数据（如雷达降水产品）作为训练目标。若无此类数据，应转向无监督或自监督方法，或采用统计降尺度。
    - 其架构（降尺度比12）针对特定空间尺度设计。对于全球范围应用或不同的降尺度比（如2倍、4倍），需要调整上采样块配置。
    - 该方法主要针对小时尺度的偏差校正与降尺度。对于日尺度及以上的偏差校正，可优先考虑统计方法或更简单的神经网络架构。
- **与上下游衔接**：
    - **上游**：输入数据需经过预处理（如重投影、重采样、质量控制、变量提取）。数据准备步骤（`s1`）是必不可少的上游环节。
    - **下游**：输出的高分辨率小时降水数据集可直接用于驱动分布式水文模型、进行极端洪水事件重现分析、或作为更高阶统计降尺度方法的输入。

## 回退策略

- **损失函数导致低估极端事件**：如果使用常规MAE/MSE损失函数训练后，发现模型严重低估降水（尤其是极端值），应立即回退至**加权损失函数**（如LMAE_weighted）。该函数通过动态权重使模型更加关注高值降水事件。
- **模型过拟合或训练不稳定**：
    - 减少模型复杂度，如减少**残差块数量**（从16个减少到12或8个）。
    - 检查**学习率**是否过高，可尝试降低。
    - 增加数据增强手段或引入更多正则化技术。
- **缺少大气协变量**：若无法获取可靠的大气协变量数据，可将其作为可选输入移除，构建仅基于粗分辨率降水输入的基线模型。但这可能限制模型性能的上限，特别是对物理一致性要求高的应用。
- **上采样插值方法影响细节生成**：如果生成结果的空间结构（如降水落区边界）不自然，可尝试更换上采样块中的插值方法（如双线性插值、转置卷积），并进行对比实验。

## 质量检查

- **训练收敛性检查**：监控训练和验证损失曲线，确保损失持续下降并趋于稳定，无剧烈震荡。
- **分布一致性验证**：比较模型输出的降水概率密度函数（PDF）与目标观测数据的PDF，确保模型未系统性地偏移整体分布。
- **空间连贯性检查**：目视检查输出的高分辨率降水场，确保其空间结构合理，无明显的网格伪影或破碎斑块。
- **极端事件重现能力评估**：计算模型输出的降水频率-强度曲线（如超过不同阈值的日降水量频率），并与观测对比，这是检验模型核心价值的关键。

## 资源召回建议

- **配套代码与数据**：可参考公开的实现代码库（如通过OSF等平台获取），其中通常包含SRDRN模型的实现、数据加载脚本和训练流程。相关研究中使用的MERRA2和Stage IV数据集也可从美国国家航空航天局（NASA）和国家环境预报中心（NCEP）获取。
- **深度学习框架**：实现可基于主流框架进行，如PyTorch或TensorFlow/Keras，它们提供了灵活的张量操作和自动微分功能，便于自定义网络层和损失函数。
- **相关方法/工具**：
    - **传统统计降尺度方法**：如量化映射（QM）、分位数映射（QDM）等，可作为性能对比的基线。
    - **其他深度学习架构**：如ESRGAN、U-Net等，可根据具体任务特性进行架构替换或融合实验。
    - **水文气象数据集**：全球降水测量任务（GPM）的IMERG产品等可作为其他区域的应用数据或参考。
