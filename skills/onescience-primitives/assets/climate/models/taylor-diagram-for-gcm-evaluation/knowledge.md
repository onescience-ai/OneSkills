# 泰勒图气候模型评估法

## 适用范围

用于从多个候选全球气候模型（GCMs）中，定量评估和综合排序其对特定地理区域（如流域、省份）内关键气候变量（如降水量、最高/最低气温）的模拟能力。典型应用场景包括为区域气候降尺度、水文气候情景预测、影响评估研究挑选最可靠的驱动数据集。当需要同时考虑模型模拟值与观测值的相关性、离散程度及整体误差时，该工具尤为适用。

## 输入

- **必需输入**：
  1.  **评估时段**：明确的基准期，用于计算统计量，例如1979-2009年。
  2.  **GCM 模拟数据**：候选GCM集合在该评估时段内对目标区域某气候变量的模拟结果（如降水、气温的时间序列或空间场）。
  3.  **观测数据**：同时段、同变量、同区域的可靠观测值，作为评估的真值基准。
- **可选输入**：
  - 变量的预处理方式说明（如是否经过偏差校正、空间降尺度）。
  - 评估所用的统计方法细节（如标准差是空间标准差还是时间序列标准差）。

## 输出

1.  **泰勒图（Taylor Diagram）**：一张图形化排序图。图中每个点代表一个GCM，其位置由相关系数（r）、中心均方根误差（CRMSE）和标准差比值三个统计量共同决定。观测点固定在 x 轴的（1, 0）位置。
2.  **GCM 排序列表**：根据各GCM点在泰勒图中与观测点的几何距离（即CRMSE）进行排序，距离越近表示综合模拟性能越好。最终输出筛选出的性能较优的GCM子集列表。

## 流程节点

1.  **数据准备与对齐**：收集所有候选GCMs与观测数据在指定评估时段、目标变量的数据，确保时间分辨率和空间范围一致。
2.  **统计量计算**：对每个GCM，计算其模拟序列（`Sim`）与观测序列（`Obs`）之间的三个核心统计量：
    - **相关系数（r）**：衡量模拟与观测时间序列变化的线性相关程度。
    - **中心均方根误差（CRMSE）**：衡量去除各自均值后，模拟与观测之间的差异大小。计算公式为：CRMSE = sqrt( std(Sim)^2 + std(Obs)^2 - 2 * std(Sim) * std(Obs) * r )，其中 `std` 表示标准差。
    - **标准差比值（SD Ratio）**：模拟序列标准差与观测序列标准差的比值（std(Sim)/std(Obs)），反映模拟的离散程度是否与观测一致。
3.  **绘图**：在极坐标系中绘制泰勒图。以相关系数（r）为角度，以标准差（或标准差比值）为半径，绘制每个GCM的坐标点。观测点固定在半径为 `std(Obs)`、角度为0°的位置。以观测点为圆心、不同CRMSE值为半径的同心弧线可用于辅助判断。
4.  **评估与筛选**：直观比较各GCM点相对于观测点的位置。理想模型应靠近观测点，即具有高相关性、标准差接近观测、CRMSE小。根据研究目标（如优先保证相关性或减小误差），确定筛选阈值，选择性能最稳健的GCMs用于后续分析。

## 边界与分流

- **泰勒图不适用的情形**：
  - 当需要评估模型对极端事件（如干旱、洪涝）的模拟能力时，泰勒图基于整体统计量，可能掩盖对分布尾部的表现。此时需辅以分位数-分位数图、极值统计量等。
  - 当模型与观测存在**系统性偏差**（如恒定偏暖或偏湿）时，泰勒图可能无法完全反映这种偏差的影响。建议先进行偏差检查或使用偏差校正后的数据计算统计量。
  - 当需要详细评估时间序列的**相位匹配**（如雨季开始时间）时，泰勒图提供的综合统计信息不足，需结合时间序列图或物候指标分析。
- **与其他方法的衔接**：
  - 泰勒图是模型评估的常用综合工具，但并非唯一标准。可与多性能指标评分（如模型置信指数）、概率评估等方法结合使用，进行更稳健的模型选择。
  - 评估结果（筛选出的GCM列表）可作为后续气候预测不确定性分析、多模型集合预测的输入。

## 质量检查

- **数据一致性检查**：确认所有GCMs与观测数据的时间步长、空间范围、单位一致。
- **计算验证**：可抽选个别模型，手动验算其r、标准差和CRMSE，确保绘图数据准确无误。检查所有模型点的分布是否合理，有无异常点。
- **图形解读验证**：除了目视距离判断，可记录每个GCM点对应的三个统计量具体数值，形成数据表格进行定量比较，确保排序结论可靠。

## 回退策略

- **计算结果存疑**：若发现某GCM的统计量计算结果明显异常（如相关系数为负），应检查原始数据质量、缺失值处理及计算过程。
- **筛选结果不确定**：若多个模型在泰勒图上位置接近，难以取舍，可考虑：1）扩大评估时段或增加评估变量进行综合评判；2）采用更严格的筛选标准（如仅保留相关系数>0.9的模型）；3）将这些模型全部保留，构建多模型集合进行预测以量化不确定性。
- **观测数据不可得**：若缺乏可靠的同步观测数据，无法进行泰勒图评估，应转向使用历史再分析数据集作为替代基准，或采用模型间互评估方法。

## 资源召回建议

- **绘图工具**：泰勒图可通过多种科学编程语言实现，例如：
  - R语言的 `plotTaylor` 或 `taylorDiagram` 函数（来自 `climdex.plu` 或 `openair` 等包）。
  - Python语言的 `skill_metrics` 或 `climpred` 库中的相关函数。
  - 也可通过MATLAB、Origin等通用绘图软件手工绘制。
- **数据源参考**：GCM数据可从地球系统网格联合会（ESGF）的CMIP6数据存储库获取。观测数据可来自全球降水气候学中心（GPCC）、东英吉利大学气候研究中心（CRU）等权威数据集。
