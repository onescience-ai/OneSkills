# 集合模型输出统计（EMOS）后处理方法

## 适用范围

用于对数值天气预报（NWP）集合预报产品进行统计后处理，以生成校正后的概率预报。典型场景是子季节尺度（2-6 周）的土壤湿度（RZSM）干旱预报，但该方法可推广到任何需要将集合预报统计校准到观测分布的变量（如温度、降水等）。EMOS 适用于以下情况：

- 动力模式集合预报存在系统性偏差和离散度不足问题，需要后处理提升概率校准质量；
- 需要生成连续概率密度函数（PDF），而非仅使用集合成员的离散分布；
- 训练数据量有限（数百个初始化日期），不足以支撑复杂非线性模型时，EMOS 的参数化结构是稳健选择。

## 输入

- **必需**：
  - 动力模式集合预报数据（如 GEFSv12 的根区土壤湿度异常集合预报，11 个成员），包含多个预报初始化日期、提前期（lead time）和网格单元；
  - 对应时段和空间范围的观测数据（如 GLEAM RZSM 异常产品），作为训练目标。
- **可选**：
  - 额外的预测因子（如集合均值、集合方差、大气驱动变量等），可用于扩展多元线性回归方程；
  - 预先计算好的集合统计量（集合均值、标准差）。

## 输出

- 校正后的 RZSM 异常概率密度函数（PDF），参数化为高斯分布（均值和方差）；
- 从该 PDF 可生成任意大小的集合预测（通过从分布中采样）；
- 每个预报周和网格单元独立的 EMOS 模型参数（回归系数）。

## 流程节点

1. **数据准备与配对**：将动力模式集合预报与观测数据在时空维度上对齐，确保每个（初始化日期，提前期，网格单元）三元组均有配对的预报和观测值。

2. **选择训练数据时间窗口**：确定用于拟合 EMOS 模型的训练样本。典型做法是以预报初始化日期为中心，选取一个固定的时间窗口（例如前后各 12 周，共约 192-432 个初始化日期），而非使用全部历史数据。训练窗口的选择需在样本量和数据时效性之间取得平衡。

3. **拟合 EMOS 模型**：对每个预报提前期和网格单元，独立建立 EMOS 模型。使用多元线性回归拟合以下方程：

   $$Y = a + b_1 X_1 + \dots + b_n X_n + \varepsilon$$

   其中 $Y$ 为观测值，$X_i$ 为集合预报的统计量（如集合均值、集合方差等），$\varepsilon$ 为误差项。误差项方差建模为集合方差的线性函数：

   $$\text{Var}(\varepsilon) = c + d \cdot S^2$$

   其中 $S^2$ 为集合方差，$c$ 和 $d$ 为待拟合参数。拟合目标是最小化连续排名概率评分（CRPS）。

4. **生成概率预报**：拟合完成后，给定新的集合预报输入，EMOS 输出一个高斯预测分布 $N(\mu, \sigma^2)$，其中均值 $\mu$ 由回归方程给出，方差 $\sigma^2$ 由集合方差和拟合参数计算得到。

5. **评估与验证**：使用独立验证集上的 CRPS、可靠性图（reliability diagram）、锐度（sharpness）等指标评估后处理效果。

## 边界与分流

- **线性假设的局限**：EMOS 假设集合预报统计量与观测之间存在线性关系。当预报偏差具有强非线性特征（如截断效应、极端事件的不对称误差）时，可能需要考虑非线性后处理方法或基于深度学习的端到端校正方案（如 RISE-UNet）。

- **训练数据量**：EMOS 通常只需数百个训练样本即可稳定拟合（如 192-432 个初始化日期），这使其在数据稀缺场景下优于需要大量数据的深度学习模型（如需要 835 个以上初始化日期的深度学习模型）。

- **变量假设**：标准 EMOS 输出高斯分布。对于有界变量（如降水，非负）或具有明显偏态分布的变量，需使用截断正态分布、Gamma 分布或对数正态分布等替代分布族。

- **与上游/下游资产的衔接**：EMOS 接收动力模式集合预报作为输入，其校正后的概率预报可直接用于干旱监测决策、农业风险评估或作为更复杂融合模型的输入。与深度学习模型（如 RISE-UNet）相比，EMOS 更易解释且计算成本更低，但可能在复杂偏差校正上表现不如端到端学习方法。

## 回退策略

- **训练窗口选择不当导致性能不佳**：若默认时间窗口（如 ±12 周）的 CRPS 表现不佳，可尝试缩小或扩大窗口，或采用滚动窗口交叉验证来确定最优窗口长度。

- **线性回归拟合失败或不稳定**：检查输入数据是否存在共线性、缺失值或异常值。可对集合统计量进行标准化处理，或使用岭回归（Ridge regression）等正则化方法提高稳定性。

- **观测数据不可用**：若缺乏观测数据进行训练，EMOS 无法应用。此时应退回动力模式原始集合预报，或考虑使用再分析产品作为替代观测源。

- **CRPS 未显著优于原始集合预报**：表明后处理未带来增益，可能原因包括集合预报本身已良好校准、训练样本代表性不足、或所选变量不适合高斯分布假设。需诊断偏差来源并调整模型结构。
