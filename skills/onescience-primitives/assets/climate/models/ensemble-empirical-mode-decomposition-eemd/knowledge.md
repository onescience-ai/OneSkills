# 集合经验模态分解（EEMD）

## 适用范围

用于非线性、非平稳的单变量时间序列分解任务，目标是将复合信号分离为多个具有物理意义的固有模态函数（IMF）子序列和一个趋势残差。典型触发条件包括：信号呈现多尺度波动、存在模式混叠风险、需要为后续预测模型提供平稳化的输入特征。该方法在环境监测（如污染物浓度序列）、生物医学信号、金融数据、机械故障诊断等领域均有应用价值。

## 输入

- 必需：原始时间序列数据（单变量，等间隔采样）。数据应为非线性、非平稳序列，例如PM2.5浓度时序、心电信号、股价序列等。
- 可选：数据预处理后的序列（如去趋势、标准化）。

## 输出

- 多个固有模态函数（IMF）子序列：每个IMF代表信号中一个特定频率尺度的振荡模式，从高频到低频依次排列。
- 一个残差序列：提取所有IMF后剩余的趋势成分，通常为单调或近似单调的低频信号。

## 流程节点

1. **参数初始化**：设定白噪声的幅值系数（通常取原始信号标准差的0.1~0.4倍）和集合试验次数（一般为100~500次）。这些参数的选择直接影响分解质量。
2. **添加白噪声**：向原始时间序列中添加一组独立的高斯白噪声序列，生成一个加噪信号副本。
3. **EMD分解**：对加噪后的信号执行完整的经验模态分解（EMD）流程，得到一组IMF和一个残差。
4. **集合迭代**：重复步骤2-3，每次使用不同的随机白噪声序列，生成多组IMF集合。
5. **集合平均**：对所有试验中对应阶次的IMF进行逐点平均，得到最终稳定的IMF集合。残差同样取平均。

## 边界与分流

- 当信号接近线性或平稳时，经典EMD可能已足够，无需使用EEMD。
- 若EEMD分解后仍存在明显的残余噪声或模式混叠，可考虑使用互补集合经验模态分解（CEEMD）或变分模态分解（VMD）作为替代方案。
- EEMD的输出IMF通常作为下游预测模型（如LSTM、GRU等深度学习网络）的输入特征；若下游模型要求输入维度固定或平稳性更强，可对IMF进行进一步筛选或重构。
- 该方法仅适用于单变量时间序列；多变量信号的分解需考虑其他多变量信号分解技术。

## 质量检查

- **模式混叠检查**：观察相邻IMF的频率范围是否存在明显重叠，理想情况下各IMF应占据相对独立的频带。
- **完备性检验**：所有IMF与残差之和应近似等于原始信号，可计算重构误差（如均方根误差）评估分解质量。
- **集合收敛性**：增加集合试验次数后，IMF结果应趋于稳定；若结果仍波动较大，需增加试验次数或调整噪声幅值。
- **物理意义验证**：各IMF应对应合理的物理尺度，例如在环境时间序列中，高频IMF可能对应日变化，低频IMF可能对应季节或年际变化。

## 回退策略

- **噪声参数不当**：若分解结果出现过度分解（IMF数量异常多）或分解不足（模式混叠严重），应调整白噪声幅值系数并重新试验。
- **残余噪声明显**：若最终IMF仍包含明显噪声成分，可尝试提高集合试验次数，或改用CEEMD等改进方法。
- **计算资源受限**：集合试验次数较多时计算开销大；在资源有限时可适当减少试验次数，但需权衡分解质量。
- **信号特性不匹配**：对于突变信号或含间歇性振荡的序列，EEMD可能效果有限，应考虑自适应信号分解方法。

## 资源召回建议

- **常用工具**：MATLAB的EEMD工具箱、Python的`PyEMD`库（支持EEMD变体）、R的`EMD`包。
- **配套方法**：EEMD常与LSTM、GRU等时序预测模型结合使用，构成“分解-预测-重构”的混合预测框架。
- **参数调优**：白噪声幅值和集合次数是关键参数，可通过网格搜索或经验法则（噪声幅值为信号标准差的0.1~0.4倍）进行初步设定，再根据分解效果微调。
