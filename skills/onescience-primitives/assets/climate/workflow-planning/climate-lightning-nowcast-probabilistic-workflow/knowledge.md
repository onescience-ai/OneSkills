# 雷达与环境场驱动的0-6小时闪电发生临近预报概率工作流

## 适用范围

**触发条件**：
- 需要生成0-6小时闪电发生概率场预报产品
- 已有雷达体扫数据、闪电历史观测和对流环境场数据
- 业务化临近预报系统需要标准化工作流指导

**适用场景**：
- 雷达反射率与闪电探测数据融合的临近预报
- 多源气象数据时空对齐与质量控制
- 概率预报产品的生成与验证

**不适用场景**：
- 确定性天气预报（如温度、风速）
- 0-2小时超短期外推预报
- 无雷达覆盖区域的闪电预报

## 输入

**必需输入**：
1. **雷达体扫数据**：反射率因子（dBZ）、径向速度、双偏振参数
   - 时间分辨率：5-6分钟
   - 空间分辨率：1km×1km
   - 质量要求：已完成地物杂波抑制、衰减校正

2. **闪电历史观测**：地闪/云闪位置和时间
   - 时间跨度：至少3年历史数据
   - 空间覆盖：目标预报区域
   - 格式：点位置数据，含经纬度和时间戳

3. **对流环境场**：数值模式输出的环境参数
   - 变量：CAPE、CIN、风切变、温度露点差、抬升凝结高度
   - 来源：ERA5再分析或高分辨率模式输出
   - 空间分辨率：与雷达数据匹配

4. **起报时间与预报时效**：
   - 起报时间：当前时刻或最近一次雷达体扫时间
   - 预报时效：T+1h至T+6h，共6个提前期

**输入契约**：
- 所有输入数据的时间戳必须不晚于起报时间
- 雷达数据必须完成质量控制并记录质量标志
- 环境场数据必须与雷达数据在时间和空间上对齐

## 输出

**核心输出**：
1. **分时段闪电概率场**（T+1h至T+6h）：
   - 格式：NetCDF4
   - 变量：lightning_probability（0-1连续值）
   - 元数据：时间、坐标系、单位、起报时间、预报时效

2. **超阈值告警区域**：
   - 格式：GeoJSON或Shapefile
   - 阈值级别：0.3（低风险）、0.5（中风险）、0.7（高风险）
   - 属性：区域面积、中心位置、最大概率值

3. **质量标志文件**：
   - 内容：数据完整性、预报范围、不确定性估计
   - 格式：JSON或XML

4. **验证报告**：
   - 指标：FSS（分数技能评分）、CSI（临界成功指数）、POD（探测概率）
   - 分层：按提前期、邻域半径、事件阈值分别统计

**输出契约**：
- 概率场文件必须可被标准气象工具（xarray、netCDF4）读取
- 告警区域必须包含空间参考信息
- 质量标志必须覆盖所有输出产品

## 流程节点

### Step 1：数据预检（s01）
- **操作**：检查所有输入数据的完整性、时间有效性和空间覆盖
- **参数**：execution-manifest.json必须包含所有必需字段
- **工具**：数据完整性校验脚本
- **质量门禁**：
  - 雷达数据时间连续性：无缺失帧
  - 闪电观测时间范围：覆盖最近3年
  - 环境场空间覆盖：与预报区域匹配
- **失败处理**：预检失败时标记任务为BLOCKED，输出结构化错误信息

### Step 2：时空对齐（s02）
- **操作**：将雷达、闪电、环境场数据统一到相同时空框架
- **参数**：
  - 目标网格：1km×1km（与雷达匹配）
  - 时间对齐：观测帧间隔5分钟，缺帧线性插补
  - 空间对齐：双线性插值（连续场）、最近邻（离散事件）
- **工具**：xarray、scipy.interpolate
- **质量门禁**：
  - 对齐后时间轴连续性检查
  - 坐标系一致性验证（WGS84或投影坐标系）
  - 单位统一（dBZ、km/h、K、Pa等）
- **输出**：对齐后的多源数据集、掩膜文件、样本索引

### Step 3：方法配置验证（s03）
- **操作**：冻结方法工件、参数和随机性配置，执行最小干运行
- **参数**：
  - 方法版本：记录模型架构和权重版本
  - 随机种子：固定以保证可复现性
  - 干运行样本：1%训练数据子集
- **工具**：配置管理脚本、模型推理接口
- **质量门禁**：
  - 输入输出形状匹配验证
  - 数据类型和缺失值处理检查
  - 最小干运行正常退出（无NaN/Inf）
- **输出**：方法工件身份报告、兼容性矩阵、干运行日志

### Step 4：概率场生成（s04）
- **操作**：按目标提前期逐时段生成闪电概率场
- **参数**：
  - 推理窗口：每个提前期独立推理
  - 输入格式：多通道张量（雷达+环境场）
  - 输出栅格：与目标区域一致的NetCDF文件
- **工具**：训练好的模型推理引擎
- **质量门禁**：
  - 每个提前期（T+1h至T+6h）均生成概率场
  - 概率值范围[0,1]，无异常值
  - 未使用未来观测（无信息泄漏）
- **输出**：6个概率场文件（T+1h至T+6h）

### Step 5：超阈值告警提取（s05）
- **操作**：从概率场提取超阈值区域并生成质量标志
- **参数**：
  - 概率阈值：0.3（低风险）、0.5（中风险）、0.7（高风险）
  - 提取算法：连通域分析（scipy.ndimage.label）
  - 面积筛选：最小告警区域面积≥1km²
- **工具**：scipy.ndimage、shapely
- **质量门禁**：
  - 告警区域空间连续性
  - 质量标志字段完整性（数据完整性、预报范围、不确定性）
  - 输出文件可重新打开且变量和元数据完整
- **输出**：分时段告警区域文件、质量标志文件

### Step 6：独立验证（s06）
- **操作**：使用独立验证资料检验概率场预报性能
- **参数**：
  - 验证资料：未参与训练和参数调优的独立数据集
  - 邻域指标：FSS（邻域半径1-10网格单元）
  - 事件指标：按提前期、邻域、事件阈值分层检验
- **工具**：xskillscore、自定义验证脚本
- **质量门禁**：
  - 验证数据集与训练集完全分离
  - 基线比较采用相同样本、网格、指标协议
  - 未达到预先登记门限时不得判定性能通过
- **输出**：分层检验指标报告、同协议基线比较报告、适用边界与交付判定

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 空间对齐方法 | 双线性插值（连续场）、最近邻（离散事件） | [1] | 连续气象场用双线性，闪电点位用最近邻 |
| 时间对齐策略 | 线性插补缺帧，保持时间连续性 | [1] | 观测帧间隔5分钟，缺帧不超过20% |
| 概率阈值 | 0.3/0.5/0.7 | [4] | 对应低/中/高风险等级 |
| 邻域验证半径 | 1-10网格单元 | [5] | FSS计算的邻域尺度范围 |
| 最小干运行样本 | 1%训练数据 | [2] | 验证输入输出契约的最小数据量 |
| 独立验证资料 | 未参与训练和调优 | [6] | 确保验证结果的独立性 |

### 校准数值（闪电临近预报体系）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 雷达反射率阈值 | ≥35 dBZ（对流回波） | [3] | 闪电发生相关的强回波阈值 |
| CAPE阈值 | ≥500 J/kg | [4] | 对流有效位能，闪电发生的必要条件 |
| 风切变阈值 | ≥20 m/s（0-6km） | [4] | 深层风切变，影响闪电活动组织性 |
| FSS参考技能 | 0.5-0.7（T+1h），0.3-0.5（T+6h） | [5] | 不同提前期的FSS参考范围 |
| CSI参考值 | 0.4-0.6（T+1h），0.2-0.4（T+6h） | [5] | 不同提前期的CSI参考范围 |

## 边界与分流

**前提条件与改道方案**：

1. **雷达数据缺失或质量差**：
   - 前提：雷达体扫数据完整且通过质量控制
   - 不成立时改道：使用卫星红外亮温数据作为替代输入，或降级为基于环境场的统计预报

2. **闪电历史观测不足**：
   - 前提：至少3年历史闪电数据用于训练
   - 不成立时改道：使用区域气候统计数据或邻近区域迁移学习

3. **环境场数据不可用**：
   - 前提：数值模式输出的对流环境场可获取
   - 不成立时改道：使用探空站观测插值或卫星反演产品

4. **独立验证资料不足**：
   - 前提：有足够的独立数据集用于验证
   - 不成立时改道：使用交叉验证或时间切分验证，但需在报告中注明验证独立性受限

## 质量检查

**验证点与阈值**：

1. **数据完整性检查**：
   - 雷达数据缺失率 < 5%
   - 闪电观测时间覆盖率 > 95%
   - 环境场空间覆盖率 > 90%

2. **概率场质量检查**：
   - 概率值范围[0,1]
   - 无NaN/Inf值
   - 空间平滑度合理（无椒盐噪声）

3. **告警区域质量检查**：
   - 区域面积合理（≥1km²）
   - 空间连续性（无孤立像素）
   - 与概率场一致性（告警区域内概率值≥阈值）

4. **验证结果质量检查**：
   - FSS值合理范围[0,1]
   - CSI值合理范围[0,1]
   - 基线比较统计显著性（p<0.05）

**失败处理**：
- 数据完整性检查失败：标记数据源问题，尝试替代数据源
- 概率场质量检查失败：检查模型推理过程，重新生成
- 验证结果异常：检查验证数据集独立性，调整验证方案

## 回退策略

1. **模型推理失败**：
   - 回退方案：使用光流外推或持续性预报作为备选
   - 降级策略：降低空间分辨率或延长推理间隔

2. **时空对齐失败**：
   - 回退方案：使用最近邻匹配代替双线性插值
   - 降级策略：接受一定程度的空间错位，在质量标志中记录

3. **独立验证不可行**：
   - 回退方案：使用时间切分验证（如周划分）
   - 降级策略：在验证报告中注明验证独立性受限
