# 基于气象因素的登革热发病率预测

## 适用范围

本知识描述的是利用气象变量预测登革热等虫媒传染病发病率时间模式的方法框架。该框架适用于以下典型任务：当目标区域积累了足够长时间（如5年以上）的周粒度或月粒度传染病病例记录，且同时拥有对齐的气象观测数据时，可通过比较多种统计与机器学习模型，建立发病率预测模型并识别关键气象驱动因子。

该方法的核心场景包括：
- 基于历史气象数据预测未来数周至数月的登革热发病率趋势；
- 评估不同气象变量（温度、降水、相对湿度、风速、南方涛动指数等）及其滞后效应对发病率的相对贡献；
- 对比统计模型与机器学习模型在传染病时间序列预测中的性能差异。

该方法假定病例数据与气象数据在时间轴上对齐，且病例报告系统相对可靠。若数据存在严重报告偏差或时间粒度不一致，需先进行数据对齐与质量评估。

## 输入

**必需输入：**

- 登革热发病率时间序列数据：按固定频率（如每周）记录的目标区域病例数或发病率，建议覆盖至少5年的历史数据以捕捉季节性与年际变化模式。
- 气象变量时间序列数据：与病例数据时间对齐的气象观测，典型变量包括：
  - 温度（日均、最高、最低）
  - 降水（日累计或周累计）
  - 相对湿度
  - 风速与风向
  - 南方涛动指数（SOI）等大尺度气候指数

**可选输入：**

- 人口数据（用于将病例数转换为发病率）
- 社会经济或环境协变量（如城市化率、绿化覆盖率）
- 蚊媒密度监测数据（如有）

**数据格式要求：**

时间序列数据应以规则频率采样，病例数据与气象数据的时间戳需对齐。缺失值比例应事先评估，若超过可接受阈值需在预处理阶段处理。

## 输出

- 各候选模型预测的登革热发病率时间序列：包括训练集拟合值与测试集预测值。
- 模型性能评估报告：以均方根误差（RMSE）和平均绝对误差（MAE）为核心指标，对比各模型在训练集与测试集上的表现。
- 气象变量重要性排序：各模型识别出的变量相对贡献或重要性评分，用于理解发病率的气象驱动机制。

## 流程节点

### 1. 数据获取与整合

获取目标区域的登革热病例时间序列数据与气象变量时间序列数据。将两类数据按时间轴对齐，合并为统一的分析数据集。确保病例数据的时间粒度（如每周）与气象数据的聚合方式一致。

### 2. 数据预处理

**缺失值处理：**
- 随机森林模型：使用插补方法填充缺失值，典型做法是基于非缺失观测的加权平均生成替代值（surrogate values）。
- 梯度提升模型：可直接处理缺失值，无需额外插补步骤。
- 其他模型：根据模型要求选择适当的插补策略（如线性插值、季节分解插补等）。

**滞后变量计算：**
根据传染病的生物学机制，气象因素对发病率的影响通常存在滞后（如蚊媒孳生需要累积降水与温度条件）。需为每个气象变量计算多个滞后阶数（如滞后1-12周），以捕捉其延迟效应。

**训练集/测试集划分：**
采用时间序列友好的划分方式（如前80%为训练集、后20%为测试集），避免未来数据泄露。

### 3. 模型构建

对训练集分别拟合以下候选模型：

**随机森林（Random Forest）：**
- 使用 randomForest R包（如版本4.6.12），设置 ntree = 1000 棵决策树。
- 通过袋外误差（OOB error）评估模型稳定性。
- 变量重要性通过预测误差增加量来衡量：当某个变量被随机置换时，模型预测误差的增加程度反映该变量的重要性。

**梯度提升（Gradient Boosting）：**
- 使用 gbm R包（如版本2.1.3）。
- 可直接处理缺失值，无需插补。
- 变量重要性以相对贡献百分比（relative contribution %）表示，百分比越高表示变量相对重要性越强。
- 关键参数包括学习率（shrinkage）、树的交互深度（interaction.depth）、迭代次数（n.trees）等，需通过交叉验证或信息准则调优。

**广义可加模型（GAM）：**
- 使用 mgcv R包，通过样条函数拟合非线性关系。
- 适合捕捉气象变量与发病率之间的平滑非线性效应。

**SARIMAX：**
- 使用 fpp R包（如版本0.5），通过 auto.arima 函数自动选择最优模型参数。
- 模型结构为 SARIMA(p,d,q)(P,D,Q)m，其中 m 为季节周期（如周数据取 m=52）。
- 参数选择基于赤池信息准则（AIC）取最小值。
- 模型设置为季节性模式（seasonal = TRUE），使用默认信息准则（ic = "AIC"）和 KPSS 平稳性检验（test = "kpss"）。
- 外生变量（即气象因子及其滞后项）作为预测变量纳入模型。

### 4. 模型性能评估

使用以下指标评估各模型在测试集上的预测性能：

- **均方根误差（RMSE）：** 衡量预测值与真实值之间的平均偏差，对大误差更敏感。
- **平均绝对误差（MAE）：** 衡量预测值与真实值之间的平均绝对偏差，对异常值更稳健。

综合比较各模型的 RMSE 与 MAE，选择表现最优的模型。根据已有比较研究，随机森林在该类任务中通常表现出较优的预测精度（综合推断，非单一素材直证）。

### 5. 变量重要性分析

分析最优模型识别出的气象变量重要性排序，理解哪些气象因子及其滞后阶数对登革热发病率预测贡献最大。这为公共卫生部门提供可操作的预警指标。

## 边界与分流

- **数据粒度不匹配：** 若病例数据为月粒度而气象数据为日粒度，需先将气象数据聚合至月粒度，或考虑使用更高频的气象指标（如月累计降水、月均温）。
- **传染病类型差异：** 本框架适用于登革热等由蚊媒传播、且与气象条件密切相关的传染病。对于水源性或呼吸道传染病，气象驱动因子与滞后结构可能显著不同，需调整变量选择与滞后阶数。
- **预测时域差异：** 若需要实时预测（nowcasting）而非提前数周预测，需考虑纳入实时可得的代理数据（如搜索引擎趋势、医院急诊量），并可能需要不同的模型架构。
- **区域差异：** 本框架的具体参数（如滞后阶数、季节周期）来自热带地区（如菲律宾马尼拉大都会区）的案例，其他气候区或地理区域的参数需根据本地数据重新校准。

## 质量检查

- **数据对齐验证：** 确认病例数据与气象数据的时间戳完全对齐，无时间偏移。
- **缺失值比例监控：** 在预处理前评估各变量的缺失比例，若某变量缺失超过30%，应考虑是否纳入该变量或使用更稳健的插补方法。
- **平稳性检验：** 对时间序列数据进行平稳性检验（如ADF检验、KPSS检验），非平稳序列需进行差分或变换处理。
- **模型诊断：** 检查模型残差是否为白噪声（如Ljung-Box检验），残差中若存在自相关结构，说明模型未能完全捕捉时间依赖性。
- **预测区间合理性：** 若模型输出预测区间，检查其覆盖率是否与名义置信水平一致。

## 回退策略

- **缺失值插补不当导致性能下降：** 若随机森林插补后模型性能明显低于预期，可尝试多种插补方法（如多重插补、季节分解插补）并比较结果，或改用能直接处理缺失值的梯度提升模型。
- **未考虑滞后效应导致预测精度不足：** 若模型遗漏了关键滞后变量，可通过互相关分析（cross-correlation）或格兰杰因果检验重新评估各气象变量的最优滞后阶数，并重新构建特征集。
- **SARIMAX参数选择不当导致过拟合/欠拟合：** 若 auto.arima 选出的模型在测试集上表现不佳，可尝试手动调整 p,d,q 与 P,D,Q 参数范围，或使用交叉验证评估不同参数组合的泛化能力。
- **梯度提升过拟合：** 若训练集性能远优于测试集，降低学习率（shrinkage）、增加树的迭代次数或减小交互深度。
- **所有模型表现均不理想：** 可能是气象因素对当前区域的登革热发病率解释力有限，需考虑纳入非气象协变量（如人口流动、蚊媒密度、公共卫生干预措施等）。

## 资源召回建议

- **R包：** randomForest（随机森林）、gbm（梯度提升）、mgcv（广义可加模型）、fpp（含 auto.arima 用于 SARIMAX 建模）。
- **Python替代：** scikit-learn 提供 RandomForestRegressor 与 GradientBoostingRegressor；statsmodels 提供 SARIMAX 实现；pygam 提供广义可加模型。
- **数据获取：** 登革热病例数据可从当地卫生部门或 WHO 获取；气象数据可从气象局或再分析数据集（如 ERA5、NCEP）获取；南方涛动指数可从 NOAA 获取。
- **交叉验证：** 对于时间序列数据，推荐使用时间序列交叉验证（rolling window 或 expanding window），避免随机划分导致的未来信息泄露。
