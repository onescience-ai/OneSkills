# 降水临近预报工作流

## 适用范围

该工作流适用于解决未来0至2小时内、空间分辨率优于雷达常规产品（如1km × 1km）的降水场短期预报问题。此类预报是众多天气依赖型行业进行实时决策的关键输入。工作流旨在生成概率性预报集合，而非单一确定性结果，以量化预报的不确定性。其典型应用场景包括：机场跑道积水预警、城市内涝风险预报、山洪灾害临近预警、户外活动安全规划以及短时能源负荷预测等。当预报提前量超过2小时或需要全球/区域尺度天气系统演变时，应转向数值天气预报（NWP）系统。

## 输入

- **必需输入**：过去20至60分钟的连续雷达观测序列。该序列通常包含多个时间步的雷达反射率因子或由其反演的降水率场。数据应覆盖目标预报区域，并具有足够高的时空分辨率（如每5分钟一帧，空间网格1km × 1km）。
- **可选/上下文输入**：
    - 地面雨量计观测数据：用于数据校准和最终验证。
    - 辅助气象数据：如风场、温湿廓线，可用于更复杂的模型架构或后处理。
    - 地理信息数据：用于地形校正或区域化分析。

## 输出

- **主要输出**：未来0-90分钟的高分辨率降水场概率预报集合。该集合通常包含多个（如20个）独立的、在统计特性上合理的未来降水场实现，反映了预报的不确定性。
- **次要输出**：
    - 集合平均或中位数预报场。
    - 基于集合计算的超越概率图（如未来1小时降水超过某阈值的概率）。
    - 预报验证报告，包含与观测对比的统计指标和评估结论。

## 流程节点

**1. 数据准备与预处理**
   - **步骤名**：数据准备与预处理
   - **步骤ID**：s1
   - **上游依赖**：无（流程起始点）
   - **描述**：对原始雷达数据进行收集、质量控制、时空重采样和归一化，并组织成监督学习格式。每个训练样本为一对“历史观测序列-未来真值序列”。按时间划分为训练集、验证集和测试集。
   - **输入参数**：
        - `raw_radar_data`（原始雷达数据，必需，类型：数组，通常来自气象雷达网络）
        - `temporal_resolution`（时间分辨率，必需，类型：整数，默认值：5，单位：分钟）
        - `spatial_resolution`（空间分辨率，必需，类型：字符串，默认值：1km x 1km）
   - **输出**：组织好的训练、验证、测试数据集（每个样本为一对历史-未来序列）。
   - **质量门控**：数据通过完整性检查（无缺失帧）、异常值剔除和分布分析（确保极端降水事件在训练集中有代表，但不一定达到平衡）。

**2. 模型选择与训练**
   - **步骤名**：模型选择与训练
   - **步骤ID**：s2
   - **上游依赖**：s1
   - **描述**：选择一个深度生成模型架构（如DGMR、扩散模型等），该架构应能学习时空数据的条件概率分布。将预处理后的数据集输入模型进行训练，优化目标通常包括生成逼真降水模式的对抗损失或变分下界等。
   - **输入参数**：
        - `prepared_dataset`（预处理后的数据集，必需，类型：数据集）
        - `model_config`（模型超参数配置，必需，类型：字典，包含架构细节、学习率、批次大小等）
   - **输出**：训练好的预报模型权重文件。
   - **质量门控**：模型在验证集上的核心指标（如CRPS、CSI）停止显著改善或达到预设阈值，表明训练收敛。

**3. 概率预报生成**
   - **步骤名**：概率预报生成
   - **步骤ID**：s3
   - **上游依赖**：s2
   - **描述**：在实时或批量模式下，将最新的雷达观测序列输入训练好的模型。通过从模型的潜变量空间进行多次采样，生成一组（集合）可能的未来降水场演变，构成概率预报。
   - **输入参数**：
        - `latest_radar_sequence`（最新观测雷达序列，必需，类型：数组）
        - `ensemble_size`（集合大小，必需，类型：整数，默认值：20）
   - **输出**：未来0-90分钟的降水场集合。
   - **质量门控**：生成的样本集合在空间结构、时间演变和统计分布上需通过初步的物理一致性检查（如无明显断裂、平滑度合理）。

**4. 预报后处理**
   - **步骤名**：预报后处理
   - **步骤ID**：s4
   - **上游依赖**：s3
   - **描述**：对生成的原始预报集合进行统计校准，以提升其可靠性和决策价值。常见操作包括可靠性校正（使集合概率与观测频率匹配）、去除系统性偏差等。此步骤可选，但对业务应用至关重要。
   - **输入参数**：
        - `raw_ensemble`（原始预报集合，必需，类型：数组）
   - **输出**：校准后的预报集合。
   - **质量门控**：校准后的概率预报的可靠图（Reliability Diagram）应更接近理想对角线。

**5. 预报验证与发布**
   - **步骤名**：预报验证与发布
   - **步骤ID**：s5
   - **上游依赖**：s4
   - **描述**：使用独立的测试集或实时观测，对校准后的预报进行多维度评估。评估包括定量统计指标（如连续评分概率（CRPS）、临界成功指数（CSI）、可靠图）和定性评估（如组织专家进行认知研究评估预报的实用性和一致性）。最终生成评估报告，并将格式化后的预报产品（如图像、概率网格数据）发布给下游用户或决策系统。
   - **输入参数**：
        - `calibrated_forecast`（校准后的预报，必需，类型：数组）
        - `ground_truth`（实际观测，必需，类型：数组）
   - **输出**：评估报告和/或可供决策者使用的预报产品。
   - **质量门控**：预报在标准验证指标上应优于简单的基线方法（如持久性预报、外推法），并在专家评估中被认为具有一致性和决策价值。

## 边界与分流

- **与数值天气预报（NWP）分流**：该工作流专注于0-2小时的“临近预报”。当需要预报提前量超过2小时，或需要考虑更大尺度天气系统动力学时，应使用NWP模式（如ECMWF、GFS）的输出，或将其与本工作流的输出进行融合。
- **与卫星降水估计互补**：在雷达覆盖不佳的区域（如海洋、偏远山区），卫星降水估计产品（如GPM、CMORPH）可作为重要的输入数据源或验证基准。
- **基线方法参考**：在开发复杂深度学习模型时，可将传统物理外推方法（如光流法，相关工具如PySTEPS）作为性能基线进行比较。
- **模型选择边界**：当数据量极其有限或计算资源严重不足时，可考虑使用更简单的统计外推模型。深度生成模型（如DGMR）在数据和算力充足时能提供更优的技巧和概率特性。

## 质量检查

1.  **数据质量**：检查输入雷达序列的连续性、反射率值域是否合理、是否存在明显的扫描间隙或噪声。
2.  **模型训练监控**：跟踪训练和验证损失曲线，防止过拟合；监控生成样本的多样性和逼真度。
3.  **预报输出检查**：人工或自动化检查生成的降水场是否符合基本的物理直觉（如降水范围、强度梯度）。
4.  **集合统计分析**：计算集合成员间的离散度，并与预报误差进行对比（如离散度-误差关系图），以评估不确定性量化的合理性。
5.  **验证指标对比**：定期将新模型的验证指标（CRPS、CSI等）与历史最佳模型或简单基线进行对比。

## 回退策略

- **训练数据不平衡**：若模型对罕见强降水事件预报不足，可采用数据增强（如对强降水样本进行过采样）或在损失函数中对强降水事件赋予更高权重进行重训。
- **快速演变对流系统预报失效**：当系统无法准确预报快速新生或消亡的对流单体时，可考虑在模型中引入更精细的雷达特征（如多普勒速度）作为额外输入，或结合卫星云图信息。在业务中，此时预报需附加更高的不确定性警示。
- **模型实时推理失败**：若实时推理延迟超出业务要求，需检查模型架构复杂度、计算硬件资源或尝试模型蒸馏、量化等优化手段。短期回退可使用基于物理的快速外推模型作为临时替代。
- **后处理效果不佳**：若校准后预报可靠性仍差，可能是因为训练数据不足以覆盖所有天气型，或后处理模型过于简单。应回溯检查训练数据的代表性，并考虑采用更强大的非参数校准方法。

## 资源召回建议

- **模型架构参考**：DGMR（Deep Generative Model for Radar）是该任务的代表性模型之一，其公开的描述和框架为构建类似系统提供了重要参考。
- **基线工具**：PySTEPS是一个开源、基于物理和统计的降水临近预报库，适用于构建和测试基线模型。
- **数据源**：各国气象局提供的公开雷达数据网络（如美国NEXRAD、欧洲OPERA网络）是获取训练数据的重要来源。
- **评估框架**：验证部分应参考世界气象组织（WMO）发布的临近预报验证指南，并确保使用标准的评分指标。
