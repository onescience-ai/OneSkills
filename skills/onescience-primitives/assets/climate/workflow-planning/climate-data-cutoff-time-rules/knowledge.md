# 气象临近预报数据时点规则

## 适用范围
面向气象临近预报数据时点规则任务，定义资料截止时间、观测资料时间限制和预报产品时间范围约束。适用于实时天气预报、临近预报、短临预警等时效性要求高的气象服务。不适用于气候预测、季节预测或历史资料分析。

## 输入
- 实时观测数据（地面站、雷达、卫星）
- 数值模式输出（分析场、预报场）
- 资料截止时间定义
- 预报起报时间要求

## 输出
- 资料截止时间确认报告
- 数据时间戳检查结果
- 预报时间范围约束说明
- 时点规则执行记录

## 流程节点
资料截止时间定义 → 数据获取 → 时间戳检查 → 起报时间确认 → 预报时间范围约束 → 时点规则验证

### 步骤1：资料截止时间定义
**操作**：定义当前任务的资料截止时间
**参数**：业务运行周期、数据可用性、用户需求
**工具**：时间管理器、业务日历
**质量门禁**：截止时间合理性验证、与业务流程一致性检查

### 步骤2：数据获取
**操作**：获取截止时间前的所有可用数据
**参数**：数据源列表、获取时间窗口、数据类型
**工具**：数据采集器、时间过滤器
**质量门禁**：数据完整性检查、时间戳有效性验证

### 步骤3：时间戳检查
**操作**：检查所有数据的时间戳是否符合截止时间要求
**参数**：时间戳格式、时区约定、精度要求
**工具**：时间戳解析器、时区转换器
**质量门禁**：时间戳格式正确性、时区一致性、精度匹配

### 步骤4：起报时间确认
**操作**：确认预报起报时间不晚于资料截止时间
**参数**：起报时间、截止时间、时间差阈值
**工具**：时间比较器、业务规则检查器
**质量门禁**：起报时间≤截止时间、时间差在允许范围内

### 步骤5：预报时间范围约束
**操作**：确保预报输出不包含截止时间后的数据
**参数**：预报时效、输出频率、时间范围
**工具**：时间范围验证器、输出过滤器
**质量门禁**：预报时间范围正确性、无未来数据泄漏

### 步骤6：时点规则验证
**操作**：验证整个时点规则执行过程
**参数**：验证清单、检查点、通过标准
**工具**：验证检查器、报告生成器
**质量门禁**：所有检查点通过、无违反规则情况

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |

| 观测资料时间限制 | 目标时刻之前形成的观测 | [1] | 禁止使用目标时刻之后的数据 |
| 预报时间范围约束 | 仅覆盖未来时效 | [1] | 预报输出不得包含过去数据 |

| 时区一致性 | 所有数据使用统一时区（通常UTC） | [1] | 避免时区转换错误 |

## 边界与分流
- 当数据延迟到达时：使用最新可用数据，记录延迟原因和时间差
- 当数据时间戳异常时：标记可疑数据，在预报中降低置信度
- 当起报时间超过截止时间时：推迟起报时间，通知相关人员
- 当预报时间范围溢出时：截断预报输出，标注时间范围限制
- 当时区不一致时：统一转换为UTC，记录转换过程

## 质量检查
- 资料截止时间定义正确：与业务需求一致
- 数据时间戳格式正确：符合ISO 8601标准
- 时区一致性：所有数据使用UTC或指定时区
- 起报时间≤截止时间：时间逻辑正确
- 预报时间范围正确：仅包含未来时效数据
- 无未来数据泄漏：验证所有输入数据时间戳

## 回退策略
- 数据延迟：使用最新可用数据，记录延迟原因，调整预报策略
- 时间戳异常：使用邻近时次数据，标记异常数据，记录异常原因
- 起报时间超限：推迟起报时间，通知业务人员，调整预报计划
- 时间范围溢出：截断预报输出，标注限制，提供部分预报结果
- 时区错误：统一转换为UTC，记录转换过程，重新计算时间
