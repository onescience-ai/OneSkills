# 雪崩危险等级预测任务

## 适用范围

一个完整的端到端预测任务，旨在为瑞士阿尔卑斯山区的干雪条件开发一个全自动数据驱动方法，以评估区域雪崩危险等级。该任务整合了数据获取、特征工程、模型训练与评估的全流程，并利用随机森林等机器学习方法，基于历史气象、雪盖数据和官方预报标签进行训练和验证。

当任务目标与该知识所述场景一致时，可复用本条目。

## 输入

- 来自“数据预处理与特征工程”步骤的特征数据
- 来自“数据基础设施”步骤的危险等级标签数据

## 输出

- 训练并优化后的雪崩危险等级预测模型
- 模型性能评估报告（准确率、宏 F1 分数、混淆矩阵等）

## 流程节点

1. 定义和准备目标变量（危险等级标签，来自 Dforecast 或 Dtidy 数据集）
2. 从气象时间序列和雪盖模拟中提取相关特征
3. 将特征数据与区域危险等级标签进行关联和过滤
4. 按时间分割数据集，确保训练集和测试集的独立性
5. 训练随机森林分类器（可能包含多个变体，如 RF1 和 RF2）
6. 通过超参数优化（如随机搜索、网格搜索）和特征选择（如递归特征消除）进行模型优化
7. 在测试集上评估模型性能，分析其与经验预报的一致性及空间、时间变化

## 前提条件

- IMIS 数据集
- SNOWPACK 模拟输出
- 预报危险等级标签（Dforecast）
- 机器学习环境（Python，scikit-learn）

## 边界与分流

- 相关资产/可替代方案：data preprocessing and feature engineering
- 相关资产/可替代方案：random forest classification and feature selection
- 相关资产/可替代方案：data infrastructure: observations and labels

## 回退策略

- 输入数据含大量缺失值，需依赖上游预处理步骤
- 模型可能过拟合训练数据，在未见季节或区域泛化能力下降
- 类别不平衡（如高危险等级样本少）可能影响模型对关键事件的预测
