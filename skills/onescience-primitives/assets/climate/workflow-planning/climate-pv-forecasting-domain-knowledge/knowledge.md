# 光伏功率预测领域专门知识

## 适用范围

光伏功率预测任务的领域知识支撑，包括光伏功率的物理原理、气象因素影响、常用预测方法体系、数据预处理规范以及多站联合预测的特殊考虑。适用于0-48小时功率联合预报场景。

## 输入

- **气象数据**：辐照度（GHI、DNI、DHI）、温度、云量、风速
- **电站数据**：装机容量、组件类型、安装角度、方位角
- **历史数据**：历史功率输出、历史气象数据

## 输出

- **特征工程方案**：基于领域知识的特征选择
- **预处理流程**：容量归一化、缺测处理、异常值检测
- **模型选择建议**：基于预测时效和数据条件的模型推荐

## 流程节点

### 1. 光伏功率物理原理

**辐照度-功率转换**：
- 基本公式：P = η × A × G × (1 - β × (T - T_ref))
  - η：组件效率（通常15-22%）
  - A：组件面积
  - G：辐照度（W/m²）
  - β：温度系数（通常-0.3%~-0.5%/°C）
  - T_ref：参考温度（25°C）

**关键气象因素**：
| 因素 | 影响 | 敏感度 |
|------|------|--------|
| 辐照度（GHI） | 直接决定功率输出 | 高（线性） |
| 温度 | 影响组件效率 | 中（负相关） |
| 云量 | 影响辐照度 | 高 |
| 风速 | 影响组件温度 | 低 |
| 湿度 | 影响辐照度和组件温度 | 低 |

**组件类型影响**：
- 单晶硅：效率高（20-22%），温度系数约-0.4%/°C
- 多晶硅：效率中（17-19%），温度系数约-0.4%/°C
- 薄膜：效率低（10-13%），温度系数约-0.2%/°C

### 2. 常用预测方法体系

**物理模型**：
- 基于辐照度-功率转换公式
- 需要精确的组件参数和气象数据
- 适用于：有准确气象预报的场景

**统计模型**：
- ARMA、ARIMA、指数平滑
- 基于历史数据的时序模式
- 适用于：短期预测、有足够历史数据[4]

**机器学习模型**：
- 随机森林、XGBoost、LightGBM
- 需要特征工程，可捕获非线性关系
- 适用于：中长期预测、多变量输入[1]

**深度学习模型**：
- LSTM、GRU、Transformer
- 端到端学习，自动特征提取
- 适用于：超短期预测、大数据量[2]

**混合模型**：
- 物理模型 + 机器学习
- 结合领域知识和数据驱动
- 适用于：需要高精度的业务场景

### 3. 数据预处理规范

**容量归一化**：
- 方法：P_normalized = P / P_installed
- 目的：消除电站规模差异，便于多站比较
- 适用于：多站联合预测、跨电站模型迁移

**缺测处理**：
- 短时缺测（<30分钟）：线性插值
- 中等缺测（30分钟-2小时）：气象均值填充
- 长时缺测（>2小时）：使用相似电站数据或标注缺失

**异常值检测**：
- 3σ原则：超出均值±3倍标准差
- IQR方法：超出Q1-1.5×IQR或Q3+1.5×IQR
- 物理约束：功率值应在[0, P_installed]范围内

**时间对齐**：
- 确保气象数据与功率数据时间戳对齐
- 处理时区差异（UTC vs 本地时间）
- 处理夏令时调整

### 4. 多站联合预测特殊考虑

**空间相关性**：
- 相邻电站的气象条件相似
- 可以利用空间相关性提高预测精度
- 方法：多任务学习、图神经网络

**电站异质性**：
- 不同电站的组件类型、安装角度不同
- 不同地区的气候条件不同
- 方法：分层建模、迁移学习

**数据聚合策略**：
- 逐站预测后聚合：各站独立预测，然后求和
- 直接预测总功率：直接预测多站总功率
- 混合策略：关键站点独立预测，其他站点回归预测

### 5. 预测时效与方法匹配

| 预测时效 | 推荐方法 | 关键特征 |
|----------|----------|----------|
| 0-1小时 | 持久性、LSTM、Transformer | 实时观测、云图 |
| 1-6小时 | LSTM、XGBoost、物理模型 | 辐照度预报、云量 |
| 6-24小时 | XGBoost、RF、NWP模型 | NWP预报、天气类型 |
| 24-48小时 | NWP模型、统计模型 | 气候平均、天气形势 |

## 边界与分流

**气象数据不足时**：
- 仅有历史功率数据 → 使用统计模型（ARMA）
- 有辐照度但无温度 → 使用简化的物理模型
- 无气象数据 → 使用持久性预报或气候平均

**电站信息不足时**：
- 无组件参数 → 使用PVLib默认值
- 无安装角度 → 使用水平面辐照度
- 无装机容量 → 无法进行容量归一化

**多站预测挑战**：
- 电站数量多 → 使用分层建模
- 空间分布广 → 考虑气候分区
- 数据质量差异大 → 逐站质量控制

## 质量检查

- **领域知识应用**：是否考虑了辐照度-功率转换关系
- **特征工程**：是否基于领域知识选择了关键特征
- **预处理规范**：是否执行了容量归一化、缺测处理
- **时效匹配**：模型选择是否与预测时效匹配
- **多站考虑**：是否考虑了空间相关性和电站异质性

## 回退策略

- 若领域知识不足，使用通用机器学习方法
- 若物理模型不可行，退化为数据驱动方法
- 若多站预测困难，退化为逐站独立预测
