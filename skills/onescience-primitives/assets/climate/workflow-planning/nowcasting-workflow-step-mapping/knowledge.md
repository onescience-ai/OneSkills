# 科研任务工作流步骤映射规范

## 适用范围

科研任务执行规划场景，将实际执行步骤与场景索引定义的标准工作流节点进行映射。场景索引定义的 s01-s06 为核心必选步骤，超出标准流程的额外步骤（如可视化、报告生成）应标注为可选扩展步骤，不纳入核心步骤计数。步骤映射不准确会影响执行进度追踪和步骤完整性验证。

## 输入

- 场景索引定义的标准工作流节点（s01-s06 或其他定义）
- 实际执行计划中的步骤列表
- 各步骤的功能描述

## 输出

- 步骤映射表（标准步骤 ↔ 实际步骤）
- 可选步骤标记
- 核心步骤计数

## 流程节点

1. 读取场景索引标准步骤 → 2. 对照实际执行计划 → 3. 标注可选步骤 → 4. 输出映射结果

### 步骤1：读取场景索引标准步骤

场景索引（scenario_workflow_capabilities_overview.jsonl）中每个任务定义了一组标准工作流步骤（如 s01-s06），这些步骤覆盖了从数据准备到验证的完整核心流程。

### 步骤2：对照实际执行计划

将实际执行计划中的每个步骤与标准步骤进行匹配：
- **精确匹配**：实际步骤功能与标准步骤一致 → 标记为对应标准步骤
- **部分匹配**：实际步骤包含标准步骤功能但有扩展 → 以标准步骤为主，扩展部分单独标记
- **无匹配**：实际步骤不属于任何标准步骤 → 标记为可选扩展步骤

### 步骤3：标注可选步骤

超出标准流程的步骤必须显式标注为可选：
- execution_steps 中对额外步骤添加 `optional: true` 标记
- 不将额外步骤计入核心步骤数量
- 额外步骤的执行时间不纳入核心步骤时间统计

### 步骤4：输出映射结果

映射表应包含：
- 标准步骤编号（s01-s06）
- 对应实际步骤编号
- 步骤状态（PASS/PARTIAL/FAIL）
- 是否为可选步骤

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 标准步骤范围 | s01-s06（或场景索引定义） | [系统内部] | 核心必选步骤 |
| 可选步骤标记 | optional: true | [本卡定义] | 超出标准流程的步骤 |
| 核心步骤计数 | 仅统计标准步骤 | [本卡定义] | 不含 optional 步骤 |
| 步骤状态判定 | 基于输入数据质量 | [各步骤定义] | 合成数据上的 PASS 应标注为 PARTIAL |

## 边界与分流

- **场景索引无标准步骤定义**：根据任务领域通用流程推断，但需在 observation 中说明
- **核心步骤失败**：任何核心步骤（s01-s06）失败都应影响最终判定（不能因额外步骤成功而掩盖核心步骤问题）
- **额外步骤价值**：可选步骤可能生成有价值产物（如可视化），但不应影响核心步骤的完整性判定

## 质量检查

- execution_steps 数组中核心步骤数是否与场景索引一致
- 额外步骤是否有 optional 标记
- 核心步骤的 PASS/PARTIAL 判定是否基于真实数据（合成数据应标 PARTIAL）

## 回退策略

- 映射不确定时：默认将实际步骤与最接近的标准步骤匹配
- 标准步骤缺失时：在 observation 中记录并建议补充场景索引定义
