# 气象驱动空气污染分析流程

## 适用范围

用于利用气象变量预测和解释PM1（空气动力学直径小于1微米的颗粒物）分物种及总浓度的日变化，并量化各气象因子对污染水平的驱动贡献。该方法特别适用于以下场景：

- 需要理解气象条件（如混合层高度、风速、降水、温湿度）如何独立影响不同化学组分颗粒物浓度
- 需要识别不同季节主导的气象驱动因素差异
- 需要分析高污染事件的气象成因
- 需要为大气污染防控政策提供基于统计证据的决策支持

该方法的核心优势在于结合了非线性机器学习模型的预测能力与SHAP框架的可解释性，能够为每个预测提供个性化的特征贡献归因。

## 输入

### 必需输入

1. **PM1分物种化学组成观测数据**
   - 来源：气溶胶化学组分监测仪（如ACSM、Aethalometer）
   - 包含的物种：有机物（Org）、铵（NH₄⁺）、硫酸盐（SO₄²⁻）、硝酸盐（NO₃⁻）、氯化物（Cl⁻）、化石燃料燃烧黑碳、木材燃烧黑碳
   - 时间分辨率：小时平均或更高
   - 数据质量要求：长时间序列（建议至少数年），连续观测，经过严格的质量控制

2. **同步气象观测数据**
   - 关键变量：混合层高度（MLH）、温度、风速风向、相对湿度、太阳辐射、气压、降水量
   - 时间分辨率：与空气质量数据匹配（如小时平均）
   - 混合层高度可从自动激光雷达和云高仪（ALC）数据反演获得

### 可选输入

- 人为排放清单数据（可增强对排放驱动变化的解释能力）
- 区域输送轨迹数据（如HYSPLIT后向轨迹）
- 卫星遥感气溶胶光学厚度数据（可补充空间信息）

## 输出

1. **训练好的预测模型**
   - 每个PM1物种一个独立的GBRT模型，另有一个总PM1模型
   - 模型性能指标：R²（决定系数）和NRMSE（归一化均方根误差）

2. **SHAP值分析结果**
   - 每个预测的特征贡献归因（正/负贡献）
   - 特征全局重要性排序（基于平均绝对SHAP值）
   - 特征非线性响应曲线（SHAP值 vs. 特征绝对值）

3. **季节性和污染水平分组统计**
   - 冬季/夏季的平均SHAP值对比
   - 典型浓度与高污染事件（>95th百分位）的驱动因素差异

4. **案例分析图表**
   - 高污染事件时间序列图（观测值、预测值、关键特征及SHAP值）
   - 特征交互效应图（如MLH与降水时间、风速的交互）

## 流程节点

### 1. 数据准备与质量控制

**目标**：获取并整理长时间序列的PM1分物种和气象变量数据，进行质量控制和时间聚合。

**步骤**：
- 获取PM1分物种浓度数据（如来自ACSM和Aethalometer的观测数据）
- 获取同步气象变量数据（如来自再分析观测数据集ReObs的数据）
- 执行数据质量控制：检查异常值、缺失值、仪器故障时段
- 将数据聚合为小时平均值
- 进行数据完整性检查，确保关键变量无大量缺失

**质量门**：数据完整性检查通过，关键变量（PM1分物种、混合层高度等）缺失率低于可接受阈值（通常<10%）。

**依赖**：无上游依赖。

### 2. 特征工程与数据预处理

**目标**：将原始小时数据转换为适合机器学习模型的输入特征和目标变量。

**步骤**：
- **时间聚合**：计算每日特定时段（如下午12:00-15:00 UTC）的PM1平均浓度，以减少昼夜边界层发展对浓度的混淆影响
- **风场特征构建**：
  - 从u、v风分量计算最大风速
  - 归一化风速信息，将风向转换为0-1范围的归一化特征
  - 计算3日滑动平均以减少短期波动
- **降水相关特征**：计算距上次降水事件的时间（以小时为单位）
- **目标变量定义**：选定分析时段的PM1分物种或总浓度平均值

**质量门**：特征维度与原始变量逻辑对应，风向归一化范围在0-1之间，无逻辑错误。

**依赖**：步骤1。

### 3. 模型构建与训练

**目标**：为每个PM1物种和总PM1建立GBRT模型，优化超参数。

**步骤**：
- **数据划分**：将数据集随机划分为训练集（75%）和测试集（25%）
- **模型选择**：采用梯度提升回归树（GBRT），推荐使用scikit-learn库的GradientBoostingRegressor
- **损失函数**：选择最小二乘损失（ls），以更好拟合高浓度值
- **超参数调优**：
  - 使用网格搜索系统测试预定义的超参数组合（如树的数量、最大深度、学习率、最小样本分裂数等）
  - 执行3折交叉验证确定最优超参数组合

**质量门**：模型在交叉验证中达到可接受的R²和NRMSE（具体阈值需根据实际数据特性确定）。

**依赖**：步骤2。

### 4. 模型评估与稳健性测试

**目标**：验证模型在独立数据上的预测能力和结果稳健性。

**步骤**：
- **独立测试**：在预留的测试集上评估每个模型的性能（R²和NRMSE）
- **稳健性测试**：重复数据划分和模型训练过程10次，每次使用不同的随机划分和超参数组合
- **性能统计**：汇总10次模型迭代的性能指标分布（均值和方差）

**质量门**：所有物种模型和总PM1模型的平均性能指标稳定，且不同迭代间方差较小。

**依赖**：步骤3。

### 5. SHAP值计算与特征贡献分析

**目标**：利用SHAP框架量化每个气象特征对模型预测的贡献。

**步骤**：
- **SHAP值计算**：使用SHAP库（如shap.TreeExplainer）为每个训练好的模型预测计算各输入特征的SHAP值
- **全局重要性分析**：计算每个特征的平均绝对SHAP值，排序特征重要性
- **非线性响应分析**：绘制SHAP值与特征绝对值的关系图，揭示特征对预测值的非线性影响模式

**质量门**：SHAP值计算准确，能分解模型预测（所有特征的SHAP值之和等于模型输出与基准值之差）。

**依赖**：步骤4。

### 6. 交互效应与季节性驱动分析

**目标**：识别特征间的交互作用和不同季节/污染水平下的主导驱动因素。

**步骤**：
- **交互效应分析**：分析成对特征的交互作用（如混合层高度与降水时间、混合层高度与风速的交互）
- **分组分析**：
  - 按季节分组：冬季（12-2月）、夏季（6-8月）
  - 按污染水平分组：典型浓度（四分位距IQR内）vs. 高污染事件（>95th百分位）
- **分组SHAP统计**：计算各组的平均SHAP值，对比不同情境下的驱动因素差异

**质量门**：交互效应和分组分析能揭示符合大气物理认知的模式（如冬季浅混合层对PM1的正贡献）。

**依赖**：步骤5。

### 7. 案例研究与物理过程验证

**目标**：选择典型高污染事件案例，验证模型解释的物理合理性。

**步骤**：
- **案例选择**：选取不同季节的典型高污染事件（如冬季、春季、夏季各一次）
- **时间序列可视化**：绘制案例期间的观测值、模型预测值、关键气象特征及其对应的SHAP值
- **物理过程解释**：结合大气化学和气象学知识，验证模型解释是否合理（如温度驱动、平流驱动、扩散条件不利等）

**质量门**：案例分析结果与已知的大气物理化学过程一致。

**依赖**：步骤6。

## 边界与分流

### 方法适用边界

- **仅适用于气象驱动分析**：该方法专注于气象变量对PM1浓度的影响，不直接模拟排放变化或化学反应机理。若需分析排放源贡献或未来情景预测，应转向化学传输模型（CTM）。

- **对排放敏感物种的局限**：对于高度依赖人为排放和化学过程的PM1物种（如Cl⁻、NO₃⁻），仅基于气象变量的模型性能可能不稳定。此类情况可结合正矩阵因子分解（PMF）进行来源解析，再与气象驱动分析联合解释。

- **极端事件的预测能力有限**：模型可能无法完全再现罕见或极端污染事件，特别是当事件由非常规因素（如区域性二次气溶胶爆发、罕见的大尺度干旱）驱动时。这些情况需要结合案例分析和机理研究深入理解。

### 与其他方法的衔接

- **上下游衔接**：该方法可作为PM来源解析（如PMF）的补充工具，PMF识别污染源，本方法解析气象条件如何调控这些源的贡献。

- **替代方案对比**：
  - 相比多元统计方法（如PCA），本方法能处理非线性关系并提供个性化的特征归因
  - 相比部分依赖图，SHAP能解释单次预测的特征贡献，而部分依赖图只能显示全局平均效应

## 质量检查

1. **模型性能验证**：检查R²和NRMSE是否达到可接受水平（具体阈值需根据数据特性确定）
2. **稳健性验证**：检查10次模型迭代的性能指标方差，确保结果不依赖于特定的数据划分
3. **SHAP值一致性**：验证SHAP值计算的正确性，确保所有特征的贡献之和等于模型预测与基准值之差
4. **物理合理性检查**：检查特征重要性排序和非线性响应曲线是否符合大气科学认知（如混合层高度降低通常导致污染物累积）
5. **季节模式检查**：验证冬季和夏季的主导驱动因素差异是否符合气候学特征

## 回退策略

1. **模型性能不佳时**：
   - 检查数据质量，处理缺失值和异常值
   - 考虑增加特征工程（如添加滞后变量、交互项）
   - 尝试其他树模型（如随机森林、XGBoost）作为对比

2. **对特定物种解释能力弱时**：
   - 记录该物种的气象解释能力有限，避免过度解读
   - 考虑结合排放源解析方法（如PMF）补充解释
   - 在结果中明确说明该物种的预测和解释不确定性

3. **数据缺失严重时**：
   - 评估数据缺失模式，判断是否系统性偏差
   - 考虑插补方法或减少分析时间范围
   - 在报告中明确说明数据覆盖范围和局限性

4. **极端事件分析失败时**：
   - 记录事件特征，说明模型在该类事件上的局限性
   - 转向案例研究方法，结合机理分析手动解释
   - 在政策建议中注明对极端事件的预测能力限制

## 资源召回建议

### 相关工具与库

- **机器学习框架**：scikit-learn（GradientBoostingRegressor）
- **可解释性框架**：shap（SHAP值计算）
- **数据处理**：pandas、numpy
- **可视化**：matplotlib、seaborn

### 数据获取途径

- **空气质量数据**：当地空气质量监测网络（如法国SIRTA观测站数据）
- **气象数据**：再分析数据集（如ReObs）、ERA5、气象站观测数据

### 相关方法

- **化学传输模型（CTM）**：用于排放和化学机理模拟，可预测未来情景
- **正矩阵因子分解（PMF）**：用于PM来源解析，可识别主要排放源
- **多元统计方法**：如PCA，用于分析多变量交互
- **部分依赖图**：另一种可解释性方法，但只能显示全局平均效应
