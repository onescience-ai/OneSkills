# 气象预报产品质量标志与独立验证规范

## 适用范围

面向气象预报任务的产品生成与验证阶段，提供标准化的质量标志编码与独立验证规范。适用于所有earth域预报任务，包括温度、湿度、风速等气象变量的24-72小时联合预报。规范涵盖气象预报产品质量标志编码体系、质量标志与不确定性关联关系、产品元数据标准、独立验证规范和验收门限规范。

## 输入

| 输入类型 | 来源 | 预处理要求 |
|---------|------|-----------|
| 预报结果 | 步骤4输出 | 需确保预测值已恢复物理量纲 |
| 独立验证资料 | 未参与训练的参考资料 | 需验证资料独立性（未参与训练、参数选择或阈值调优） |
| 基线结果 | 同协议基线 | 需确保与预报结果采用相同样本、网格和指标协议 |
| 验收门限 | 客户确认或预先登记 | 需在验证前确认门限标准 |

## 输出

| 输出类型 | 格式 | 验证标准 |
|---------|------|---------|
| 质量标志文件 | CSV/JSON | 包含每个预报点的质量标志编码，符合气象标准编码体系 |
| 产品元数据 | JSON | 包含坐标系统、时间基准、单位、质量标志说明等CF约定信息 |
| 分层检验指标报告 | Markdown/JSON | 按站点、变量、时效分层报告检验指标 |
| 同协议基线比较报告 | Markdown/JSON | 与基线采用相同样本、网格和指标协议的比较结果 |
| 适用边界与交付判定 | Markdown/JSON | 给出适用范围、限制条件和交付判定（PASS/PARTIAL/REJECT/BLOCKED） |

## 流程节点

### 步骤1：质量标志编码

**操作**：
1. 定义质量标志等级：
   - **观测质量标志**：数据源的质量标志（原始观测、插值、填补等）
   - **插值质量标志**：空间或时间插值的质量标志
   - **预报质量标志**：预报结果的质量标志（good/fair/poor等）
2. 实现气象标准编码体系：
   - WMO标准编码或业务系统标准编码
   - 每个预报点关联对应的质量标志
3. 质量标志与不确定性关联：
   - 质量标志等级对应不同的不确定性范围
   - 记录质量标志与不确定性的对应关系

**质量门禁**：
- 质量标志编码符合气象标准
- 每个预报点有对应的质量标志
- 质量标志与不确定性关联关系明确

**失败处理**：质量标志编码失败时使用默认编码，但必须标注

### 步骤2：产品元数据生成

**操作**：
1. 生成符合CF约定的产品元数据：
   - 坐标系统：WGS84
   - 时间基准：UTC
   - 单位：温度°C、湿度%RH、风速m/s
   - 变量说明和质量标志说明
2. 记录数据血缘信息：
   - 数据源版本、时空覆盖
   - 预处理方法和参数
   - 模型配置和训练信息
3. 生成文件清单和校验信息

**质量门禁**：
- 产品元数据包含坐标系统、时间基准和单位信息
- 数据血缘信息完整可追溯
- 文件清单和校验信息齐全

**失败处理**：元数据生成失败时标记BLOCKED

### 步骤3：独立验证执行

**操作**：
1. 验证资料独立性确认：
   - 验证资料未参与训练、参数选择或阈值调优
   - 验证资料来自与训练数据不同的来源或时间段
   - 验证前确认资料独立性
2. 计算分层检验指标：
   - 按站点分层
   - 按变量分层（温度、湿度、风速）
   - 按预报时效分层（24h、48h、72h）
3. 与基线比较：
   - 使用相同样本、网格和指标协议
   - 计算Skill Score（优于基线的技巧评分）

**质量门禁**：
- 验证资料独立性已确认
- 分层检验指标完整
- 基线比较使用相同协议

**失败处理**：验证资料不独立时标记BLOCKED

### 步骤4：验收门限检查

**操作**：
1. 检查验收门限是否已预先登记：
   - 门限是否经客户确认
   - 门限是否适用于可验证样本
2. 执行验收门限检查：
   - R²>0为基本要求
   - Skill Score>0表示优于基线
   - RMSE在合理范围内
3. 给出交付判定：
   - PASS：所有指标达到门限
   - PARTIAL：部分指标达到门限
   - REJECT：关键指标未达到门限
   - BLOCKED：门限未确认或验证失败

**质量门禁**：
- 验收门限已预先登记
- 交付判定有客观依据
- 门限未确认时不得声明性能PASS

**失败处理**：门限未确认时标记BLOCKED

## 关键参数

### 通用判据（方法层，同类体系可参考）

| 参数 | 推荐值 | 来源 | 说明 |
|------|--------|------|------|
| R²最低要求 | >0 | 统计学标准 | 低于此值表示模型不如简单均值预测 |
| Skill Score最低要求 | >0 | 气象预报标准 | 低于此值表示模型不如持续性预报基线 |
| 温度RMSE合理范围（短期预报） | <3°C | 业务规范 | 24小时预报的温度误差标准 |
| 温度RMSE合理范围（中期预报） | <5°C | 业务规范 | 72小时预报的温度误差标准 |
| 湿度RMSE合理范围 | <15% | 业务规范 | 相对湿度的误差标准 |
| 风速RMSE合理范围 | <2m/s | 业务规范 | 风速的误差标准 |

### 校准数值（供量级校准）

以下数值来自典型气象预报任务，供量级校准；其他体系需以自身证据重新锚定：

| 参数 | 典型值 | 来源 | 说明 |
|------|--------|------|------|
| 质量标志等级数 | 3-5 | 业务规范 | good/fair/poor或更多等级 |
| 不确定性置信水平 | 95% | 统计学标准 | 常用的置信水平 |
| 独立验证样本比例 | 20-30% | 业务规范 | 用于独立验证的数据比例 |

## 边界与分流

**前提否定即改道**：
1. 若验收门限未预先登记 → 只能报告结果，不得声明性能PASS
2. 若验证资料不独立 → 标记BLOCKED，重新获取独立验证资料
3. 若质量标志编码失败 → 使用默认编码，但必须标注
4. 若产品元数据不完整 → 标记BLOCKED，补充元数据

**降级策略**：
- 当验收门限未确认时，可提供探索性分析结果，但不得标记为正式业务验收
- 当验证资料不可用时，可使用交叉验证作为近似，但必须标注不确定性

## 质量检查

**验证点**：
1. 质量标志编码检查：编码是否符合气象标准
2. 产品元数据检查：是否包含坐标系统、时间基准和单位信息
3. 独立验证检查：验证资料是否独立
4. 验收门限检查：门限是否已预先登记
5. 交付判定检查：判定是否有客观依据

**阈值**：
- 质量标志编码符合气象标准 = 100%
- 产品元数据完整性 = 100%
- 验证资料独立性确认 = 100%
- 验收门限已登记 = 是（用于业务验收）

**失败处理**：
- 任何一项质量检查失败 → 标记BLOCKED或REJECT
- 门限未确认 → 不得声明性能PASS

## 回退策略

1. **验收门限未确认** → 只能报告结果，不得声明性能PASS
2. **验证资料不独立** → 标记BLOCKED，重新获取独立验证资料
3. **质量标志编码失败** → 使用默认编码，但必须标注
4. **产品元数据不完整** → 标记BLOCKED，补充元数据
5. **性能不达标** → 触发模型回退或参数调整
