# 对流初生检测：独立验证协议与质量保证

## 适用范围

面向CI检测结果的独立验证和产品质量保证。当CI检测算法完成开发并输出检测结果后，必须执行本规范定义的验证流程和质量标志生成。验证数据集必须独立于训练和调参数据，不得使用合成标签或同源数据替代。适用于卫星驱动的CI检测、雷达CI检测以及融合数据CI检测场景。

## 输入

**检测结果数据**：
- CI检测概率场（逐像素概率值）
- CI检测二值场（阈值化后的检测结果）
- CI对象列表（位置、面积、强度等属性）

**独立验证数据**（必须与训练数据来源不同）：
- 地基天气雷达组合反射率因子拼图（≥35 dBZ定义CI）
- 不同传感器观测（如红外卫星验证微波检测结果）
- 不同时段/区域的雷达数据
- 人工标注的CI事件记录

**质量控制参数**：
- 质量标志等级定义
- 不确定性估计参数

## 输出

**输出产物**：
- 验证报告：包含完整指标计算过程和结果解释
- 质量标志文件：逐像素/逐对象的质量等级标记
- 不确定性估计场：每个检测结果的不确定性范围
- 产品元数据：符合CF约定的完整元数据

## 流程节点

### Step 1：验证数据集准备
- **操作**：加载独立验证数据集，确认其独立性
- **参数**：数据源、时间范围、空间范围
- **工具**：xarray, numpy
- **质量门禁**：
  - 验证数据集与训练数据集无时间重叠
  - 验证数据集来自不同传感器或不同区域
  - 验证数据经过质量控制

**独立验证数据类型**（来源[1][3]）：

| 数据类型 | 独立性来源 | 适用场景 | 获取渠道 |
|----------|-----------|---------|---------|
| 地基雷达拼图 | 不同传感器 | 卫星CI检测验证 | CMA雷达业务系统 |
| 不同卫星数据 | 不同传感器 | 跨传感器验证 | 各卫星数据分发平台 |
| 不同时段雷达 | 不同时段 | 交叉验证 | 历史雷达存档 |
| 人工标注记录 | 人工判读 | 算法基准验证 | 气象台站记录 |
| 闪电定位数据 | 不同观测手段 | 间接验证 | 全国闪电定位网 |

### Step 2：时空匹配
- **操作**：将检测结果与验证数据进行时空匹配
- **参数**：时间容差（≤10分钟）、空间容差（≤4 km）
- **工具**：scipy.spatial, numpy
- **质量门禁**：
  - 匹配点数满足统计要求（≥30个CI事件）
  - 时间戳对齐准确
  - 空间匹配考虑投影差异

### Step 3：验证指标计算
- **操作**：计算标准验证指标
- **参数**：指标选择、阈值设置
- **工具**：自定义计算脚本

**核心指标计算公式**（来源[1][2]）：

构建2×2列联表：

|  | 预报CI | 预报无CI |
|--|--------|---------|
| **观测CI** | hits (H) | misses (M) |
| **观测无CI** | false_alarms (FA) | correct negatives (CN) |

**命中率 (POD)**:
```
POD = H / (H + M)
```
- 表示实际CI事件被正确检测的比例
- POD = 1.0表示无漏报

**虚报率 (FAR)**:
```
FAR = FA / (H + FA)
```
- 表示检测为CI的事件中实际未发生的比例
- FAR = 0.0表示无虚报

**临界成功指数 (CSI)**:
```
CSI = H / (H + M + FA)
```
- 综合考虑漏报和虚报的技巧评分
- CSI = 1.0表示完美检测

**HSS (Heidke Skill Score)**:
```
HSS = 2*(H*CN - FA*M) / ((H+M)*(M+CN) + (H+FA)*(FA+CN))
```
- 相对于随机预报的技巧评分
- HSS > 0表示优于随机预报

### Step 4：结果解释与报告
- **操作**：解释验证结果，分析性能瓶颈
- **参数**：业务标准阈值、基准线对比
- **工具**：报告生成模板
- **质量门禁**：
  - 指标值在合理范围内
  - 报告包含完整计算过程和数据来源

### Step 5：质量标志生成
- **操作**：为每个检测结果生成质量标志
- **参数**：质量标志等级定义
- **工具**：自定义编码脚本

**质量标志体系**（来源[1]）：

| 质量等级 | 标记值 | 含义 | 不确定性范围 |
|----------|-------|------|-------------|
| Good | 0 | 数据有效，检测结果可信 | 概率不确定性<0.15 |
| Fair | 1 | 数据基本有效，检测结果可参考 | 概率不确定性0.15–0.30 |
| Poor | 2 | 数据质量可疑，检测结果需谨慎使用 | 概率不确定性>0.30 |
| Missing | 255 | 缺测或无效数据 | N/A |

**质量标志生成规则**：
- 数据有效性：卫星数据完整且通过质量控制
- 缺测状态：通道数据缺失或异常值
- 可疑状态：检测概率处于边界区域（如0.4–0.6）
- 不确定性关联：质量等级对应不确定性范围

### Step 6：不确定性估计
- **操作**：估计每个检测结果的不确定性
- **参数**：不确定性来源分解
- **工具**：贝叶斯方法、ensemble方法

**不确定性来源**（来源[2]）：

| 不确定性来源 | 描述 | 估计方法 |
|-------------|------|---------|
| 观测误差 | 卫星辐射定标误差 | 定标不确定度传播 |
| 算法误差 | 模型预测不确定性 | MC-Dropout / Ensemble |
| 代表性误差 | 像元平均与点观测差异 | 空间尺度分析 |
| 标签误差 | 雷达CI定义的不确定性 | 多算法对比 |

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| POD目标值 | ≥0.70 | [1] | CI检测命中率下限 |
| FAR上限 | ≤0.30 | [1] | CI检测虚报率上限 |
| CSI目标值 | ≥0.50 | [1] | 综合技巧评分 |
| 最少验证CI事件数 | ≥30 | 统计要求 | 确保统计显著性 |
| 时间匹配容差 | ≤10分钟 | [1] | CI检测时间精度 |
| 空间匹配容差 | ≤4 km | [1] | CI检测空间精度（~1个卫星像元） |
| 验证数据独立性 | 强制 | [1] | 不参与训练/调参 |

### 校准数值（华南CI验证体系）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 验证数据来源 | 157部雷达拼图 | [1] | S波段122部+C波段35部 |
| 雷达数据分辨率 | 0.01°×0.01° | [1] | ~1 km |
| CI标签分辨率 | 0.01°×0.01° | [1] | 与雷达一致 |
| Developing CI占比 | 43% | [1] | 会进一步发展的CI |

以下数值来自华南CI验证体系，供量级校准；其他区域需以自身证据重新锚定。

## 边界与分流

- **独立验证数据不可用**：必须BLOCKED，记录阻塞原因，不得使用合成标签或同源数据验证
- **验证CI事件数<30**：扩大验证区域或时间范围，或标注"统计样本不足"
- **POD=0.0（零检测）**：阈值过高，返回Step 3重新校准阈值
- **质量标志生成失败**：标记为Missing，不得省略质量标志

## 质量检查

1. 验证数据独立性确认：与训练数据无时间和来源重叠
2. 指标计算正确性：通过已知结果验证计算逻辑
3. 质量标志完整性：每个检测结果都有质量标志
4. 不确定性估计合理性：不确定性范围与质量等级一致
5. 元数据完整性：包含坐标系统、时间基准、单位等CF约定字段

## 回退策略

- 独立验证数据完全不可用：报告限制，不声称性能达标
- 验证指标异常：检查数据匹配、阈值设置和计算逻辑
- 质量标志逻辑不完整：使用最简质量标志（有效/无效二值）

## 资源召回建议

当任务涉及以下情况时应召回本卡片：
- CI检测结果需要独立验证
- 需要生成CI检测产品的质量标志
- 需要估计CI检测结果的不确定性
- 验证协议设计需要参考规范
