# 数值预报模型配置验证规范

## 适用范围
面向数值天气预报模型配置验证任务，定义模型版本确认、参数冻结、随机种子设置和最小干运行测试等验证步骤。适用于WRF、COSMO、ICON、GFS、ECMWF IFS等各类数值预报模式。不适用于后处理算法验证或观测数据质量控制。

## 输入
- 模型配置文件（namelist、配置文件、参数文件）
- 模型权重文件（checkpoint、预训练权重）
- 输入数据（边界条件、初始场、强迫数据）
- 验证数据集（独立观测或再分析数据）

## 输出
- 模型配置验证报告（包含版本确认、参数冻结状态、干运行结果）
- 方法工件身份报告（method_artifact_identity_report）
- 干运行日志（dry_run_log）
- 配置变更记录

## 流程节点
配置文件审查 → 版本确认 → 参数冻结 → 随机种子设置 → 最小干运行测试 → 输入输出契约验证 → 配置锁定

### 步骤1：配置文件审查
**操作**：检查模型配置文件的完整性和一致性
**参数**：配置文件格式、必需参数、可选参数
**工具**：配置解析器、参数验证器
**质量门禁**：配置文件语法检查、参数范围验证

### 步骤2：版本确认
**操作**：确认模型版本、权重文件版本和依赖库版本
**参数**：模型版本号、权重文件哈希值、依赖库版本
**工具**：版本检测器、哈希计算器
**质量门禁**：版本一致性验证、兼容性检查

### 步骤3：参数冻结
**操作**：冻结模型参数，记录参数状态
**参数**：参数值、参数类型、冻结标志
**工具**：参数序列化器、配置快照工具
**质量门禁**：参数完整性检查、冻结状态验证

### 步骤4：随机种子设置
**操作**：设置随机种子，确保可复现性
**参数**：随机种子值、随机数生成器状态
**工具**：随机数管理器、状态保存工具
**质量门禁**：随机种子唯一性验证、可复现性测试

### 步骤5：最小干运行测试
**操作**：使用最小输入数据测试模型配置
**参数**：测试数据规模、测试时长、测试场景
**工具**：模型运行器、输出验证器
**质量门禁**：模型启动成功、输入输出格式正确、计算资源使用合理

### 步骤6：输入输出契约验证
**操作**：验证模型输入输出格式和单位
**参数**：输入变量列表、输出变量列表、单位约定、维度要求
**工具**：契约验证器、数据格式检查器
**质量门禁**：变量名匹配、单位一致性、维度正确性

### 步骤7：配置锁定
**操作**：锁定配置，生成配置哈希和版本标记
**参数**：配置哈希值、版本标记、锁定时间戳
**工具**：配置锁定器、版本标记工具
**质量门禁**：配置不可篡改性验证、版本可追溯性检查

## 边界与分流
- 当配置文件不完整时：提供默认配置，记录缺失参数
- 当版本不兼容时：升级依赖库或降级模型版本，记录兼容性问题
- 当参数冻结失败时：记录当前参数状态，标记为未冻结
- 当干运行失败时：分析错误原因，提供修复建议
- 当输入输出契约不匹配时：调整接口格式，记录变更

## 质量检查
- 配置文件语法正确：通过配置解析器验证
- 版本号格式正确：符合语义版本规范
- 参数值在合理范围内：与文档和物理约束一致
- 随机种子唯一性：不与其他实验冲突
- 干运行完成时间：在预期时间内完成
- 输入输出格式匹配：变量名、单位、维度一致

## 回退策略
- 配置文件损坏：使用默认配置模板，记录损坏原因
- 版本不兼容：使用兼容版本组合，记录兼容性矩阵
- 参数冻结失败：使用当前参数快照，标记为未验证
- 干运行失败：分析错误日志，提供逐步修复建议
- 输入输出不匹配：调整接口适配器，记录格式转换
