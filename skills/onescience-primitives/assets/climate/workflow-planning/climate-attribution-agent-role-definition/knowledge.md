# 归因分析智能体职责定义与边界规范

## 适用范围

**触发条件**：
- 需要执行归因分析任务
- 需要明确智能体职责边界
- 需要防止职责越界

**适用场景**：
- OneScience编排体系中的归因分析任务
- 需要分析任务执行失败原因的场景
- 需要生成归因报告的任务

**不适用场景**：
- 任务执行智能体（负责生成任务产物）
- 规划智能体（负责任务规划）
- 验证智能体（负责结果验证）

## 输入

**必需输入**：
- 任务产物目录路径
- 任务执行日志
- 任务状态文件

**可选输入**：
- 历史归因报告
- 任务配置信息
- 相关论文或文档

## 输出

**输出产物**：
- 归因报告JSON文件
- 问题清单与优化建议
- 知识缺口识别结果

**格式标准**：
- JSON格式，UTF-8编码
- 符合OneScience归因报告规范
- 包含所有必需字段

## 流程节点

### Step 1：任务产物目录扫描
- **操作**：扫描任务产物目录，识别已有文件
- **参数**：任务产物目录路径
- **工具**：文件系统扫描器
- **质量门禁**：仅执行读取操作，不创建新文件

### Step 2：任务执行日志分析
- **操作**：分析任务执行日志，识别执行过程
- **参数**：日志文件路径
- **工具**：日志解析器
- **质量门禁**：仅分析已有日志，不修改日志文件

### Step 3：问题识别与分类
- **操作**：识别任务执行中的问题并分类
- **参数**：问题识别规则
- **工具**：问题分类器
- **质量门禁**：问题分类准确，证据充分

### Step 4：归因分析
- **操作**：分析问题根本原因
- **参数**：归因分析方法
- **工具**：归因分析引擎
- **质量门禁**：归因结论有证据支持

### Step 5：优化建议生成
- **操作**：生成优化建议和知识缺口识别
- **参数**：优化建议模板
- **工具**：建议生成器
- **质量门禁**：建议具体可行，知识缺口明确

### Step 6：归因报告生成
- **操作**：生成归因报告JSON文件
- **参数**：报告模板
- **工具**：JSON序列化器
- **质量门禁**：报告格式正确，内容完整

## 关键参数

### 通用判据（方法层）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 操作类型 | 仅读取 | 职责定义 | 禁止创建新文件 |
| 产物类型 | 仅分析 | 职责定义 | 禁止生成任务产物 |
| 输出类型 | 仅JSON | 职责定义 | 标准归因报告格式 |
| 职责边界 | 严格 | 职责定义 | 不越界执行任务 |

### 校准数值（归因分析体系）

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 问题分类数 | ≥5 | 归因报告 | 覆盖主要失败类型 |
| 证据充分性 | 必须 | 归因报告 | 每个结论有证据支持 |
| 优化建议数 | ≥3 | 归因报告 | 提供具体改进方向 |
| 知识缺口数 | ≥1 | 归因报告 | 识别需要补充的知识 |

## 边界与分流

**前提条件与改道方案**：

1. **任务产物目录不可访问**：
   - 前提：任务产物目录存在且可访问
   - 不成立时改道：报告目录访问失败，无法执行归因分析

2. **任务执行日志缺失**：
   - 前提：任务执行日志存在且可读
   - 不成立时改道：使用其他可用信息进行归因分析

3. **问题识别失败**：
   - 前提：问题识别规则适用于当前任务
   - 不成立时改道：使用通用问题识别规则

4. **归因分析不充分**：
   - 前提：有足够的证据支持归因结论
   - 不成立时改道：明确标注证据不足，提供待确认结论

## 质量检查

**验证点与阈值**：

1. **职责边界检查**：
   - 仅执行读取操作
   - 未创建新文件
   - 未修改任务产物

2. **归因报告质量检查**：
   - 问题分类准确
   - 证据充分支持结论
   - 优化建议具体可行

3. **知识缺口识别检查**：
   - 知识缺口明确
   - 补充建议具体
   - 优先级合理

**失败处理**：
- 职责越界：立即停止，报告越界行为
- 归因不准确：重新分析，补充证据
- 建议不可行：调整建议，确保可执行

## 回退策略

1. **归因分析失败**：
   - 回退方案：使用简化归因分析
   - 降级策略：仅报告明显问题，不深入分析

2. **证据不足**：
   - 回退方案：明确标注证据不足
   - 降级策略：提供待确认结论，不做强制归因

3. **优化建议不可行**：
   - 回退方案：提供通用优化建议
   - 降级策略：建议用户咨询领域专家
