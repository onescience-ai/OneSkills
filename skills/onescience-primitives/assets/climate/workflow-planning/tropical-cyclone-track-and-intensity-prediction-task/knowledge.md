# 热带气旋路径与强度预测任务

## 适用范围

适用于基于历史多模态气象数据，利用深度学习模型预测未来一段时间内热带气旋（TC）的移动路径和强度变化。典型触发场景包括：构建全球或特定海域的TC预测系统，进行路径与强度的数值模拟，或对现有预报模型进行AI化改进。该任务是灾害预警的核心环节，要求模型能够同时处理一维时序数据、三维空间气象场和动态环境场。

## 输入

- 必需输入：
  - 原始数据源：需包含最佳路径数据集（如IBTrACS、CMA-BST）和再分析气象数据（如ERA5）。
  - 目标海域：需指定覆盖全球六大主要海域（NA, EP, WP, NI, SI, SP）或其中特定区域，以实现全球或区域预测。
  - 时间分辨率：数据需对齐到统一的时间步长，典型值为6小时。
- 可选输入：
  - 模型配置文件：定义网络架构（如TCNM）的参数。
  - 超参数：学习率、批量大小、训练轮数、生成器数量等。

## 输出

- 标准化的TCND格式多模态数据集：包含对齐后的Data1d（TC固有属性时序）、Data3d（三维气象网格）和Env-Data（环境场）。
- 训练好的深度学习模型权重文件。
- 模型评估报告：包含路径预测的绝对距离误差（km）和强度预测的绝对误差等指标，并与基线方法（如MMSTN, Pangu-Weather, CMO）的对比结果。

## 流程节点

1. **数据准备 (s1)**
   - **步骤描述**：收集、对齐并预处理来自不同来源的TC固有属性、气象网格和环境数据。
   - **输入参数**：
     - `raw_data_sources` (str, 必需): 原始数据来源，默认为“IBTrACS, CMA-BST, ERA5”。
     - `target_seas` (enum, 必需): 目标海域，可选值为“NA, EP, WP, NI, SI, SP”，默认为“全球六大主要海域”。
     - `time_resolution` (str, 必需): 时间分辨率，默认为“6小时”。
   - **输出**：标准化的TCND格式多模态数据集。
   - **质量门控**：数据需完整覆盖指定海域和时间范围，无缺失关键变量。
   - **依赖**：无。

2. **模型构建 (s2)**
   - **步骤描述**：设计并实现包含多数据编码器、环境时间网络和多生成器选择网络的深度学习模型架构。
   - **输入参数**：
     - `model_config` (str, 必需): 模型配置，默认为“TCNM架构”。
   - **输出**：可训练的深度学习模型（如TCNM）。
   - **质量门控**：模型架构能同时处理Data1d、Data3d和Env-Data三种模态数据。
   - **依赖**：s1。

3. **模型训练 (s3)**
   - **步骤描述**：在准备好的训练集上优化模型参数，使用组合损失函数进行训练。
   - **输入参数**：
     - `train_data` (str, 必需): 训练数据，默认为“TCND训练集”。
     - `val_data` (str, 必需): 验证数据，默认为“TCND验证集”。
     - `hyperparams` (str, 必需): 超参数，如学习率、批量大小、生成器数量等。
   - **输出**：训练好的模型权重。
   - **质量门控**：验证集上的损失收敛且性能达到预期。
   - **依赖**：s2。

4. **模型评估 (s4)**
   - **步骤描述**：在独立的测试集上评估模型的路径和强度预测性能，与基线方法进行比较。
   - **输入参数**：
     - `test_data` (str, 必需): 测试数据，默认为“TCND测试集”。
     - `baseline_methods` (str, 可选): 基线方法，如“MMSTN, Pangu-Weather, CMO”等，用于性能对比。
   - **输出**：评估指标报告（如绝对误差）和与其他方法的性能对比结果。
   - **质量门控**：模型在测试集上的性能优于或接近现有最佳方法。
   - **依赖**：s3。

## 边界与分流

- **数值天气预报（NWP）**：传统NWP模型（如ECMWF的IFS）基于物理方程，可解释性强但计算成本高。在计算资源有限或需要快速获取预报时，可考虑使用经过训练的深度学习模型作为补充或替代。
- **其他AI基线模型**：当任务侧重于全球尺度的中期天气预报（不仅限于TC）时，可考虑Pangu-Weather、Graphcast、Fengwu等通用天气预报模型。对于TC路径预测，MMSTN是常用基线。
- **数据不足**：若目标海域历史数据严重不足，应优先进行数据增强或迁移学习，而非直接训练新模型。

## 质量检查

- **数据质量**：确保输入数据在目标时间范围和海域内完整，关键变量（如中心位置、最大风速、气压）无缺失。数据需对齐到统一的时间网格（如6小时间隔）。
- **模型性能**：评估指标（如路径预测的绝对距离误差、强度预测的绝对误差）需在独立的测试集上计算，并与公认基线方法（如MMSTN）进行对比。评估协议应保持一致，例如采用相同的测试时间范围（如2017-2021年）和相同的误差度量方式。
- **泛化能力**：检查模型在未见过的海域或极端强度TC上的表现，避免因训练数据分布不均导致特定场景下的性能骤降。

## 回退策略

- **训练数据不足或分布不均**：导致模型在特定海域泛化能力差。回退策略包括：1) 使用数据增强技术（如时序扰动、空间平移）；2) 采用迁移学习，先在大规模全球数据上预训练，再在特定海域微调；3) 简化模型，减少过拟合风险。
- **忽略环境因素**：导致预测精度下降。应确保Env-Data（如大尺度环流场、海温）被有效编码并融入模型。
- **长时预测误差累积显著**：对于超出模型有效预测时效（如超过5天）的任务，应明确声明预测能力边界，或结合自回归策略进行迭代预测，但需注意误差累积。
- **评估协议不一致**：导致结果不可比。应严格遵循已建立的评估标准，使用公开数据集的固定划分和标准误差度量。
- **测试集不能代表真实世界分布**：测试集应包含不同年份、不同海域、不同强度的TC，以全面评估模型性能。若测试集过于单一，需补充更具代表性的数据。

## 资源召回建议

- **数据集**：TCND（热带气旋网络数据集）、IBTrACS（国际最佳路径档案）、CMA-BST（中国气象局最佳路径）、ERA5（欧洲中期天气预报中心再分析数据）。
- **模型架构参考**：TCNM（热带气旋网络模型）、MMSTN（多模态时空网络）。
- **基线方法**：Pangu-Weather、Graphcast、Fengwu、CMO（气候模型输出）。
- **计算框架**：主流深度学习框架如PyTorch或TensorFlow，需要GPU资源进行模型训练。
- **评估工具**：可使用标准气象数据处理库（如xarray, netCDF4）和科学计算库（如NumPy, SciPy）进行数据处理和指标计算。
