# 时间序列预测数据用途划分原则

## 适用范围

适用于时间序列预测任务的数据划分设计，特别是ENSO指数的6-24个月概率预测，确保训练、验证和测试数据的正确隔离。

## 输入

输入数据格式：
- 历史时间序列：`(n_timesteps, n_features)`
- 时间索引：`DatetimeIndex` 或 `PeriodIndex`
- 目标变量：需要预测的气候指数（如Niño3.4）

## 输出

输出产物：
- 数据划分方案文档
- 划分后的数据集
- 划分统计信息（时间范围、样本量）

## 流程节点

### 数据集定义

#### 1. 训练集（Training Set）
- **用途**: 模型训练和参数学习
- **时间范围**: 历史数据的早期部分
- **样本量**: 通常占总数据的60-80%
- **要求**: 
  - 必须包含完整的ENSO周期（2-7年）
  - 覆盖多种ENSO事件类型（El Niño、La Niña、中性）
  - 时间连续，无缺失段

#### 2. 验证集（Validation Set）
- **用途**: 超参数调优和模型选择
- **时间范围**: 训练集之后
- **样本量**: 通常占总数据的10-20%
- **要求**:
  - 不能与训练集时间重叠
  - 用于评估不同模型配置的性能
  - 不参与模型训练

#### 3. 测试集（Test Set）
- **用途**: 最终模型性能评估（独立验证）
- **时间范围**: 验证集之后（最新的数据）
- **样本量**: 通常占总数据的10-20%
- **要求**:
  - 必须完全独立于训练和验证过程
  - 时间上必须晚于验证集
  - 不参与任何模型选择或调参

### 时间序列划分方法

#### 1. 时序划分（Time Series Split）

```
时间线: 1980────────────────────────────────────────────────2024
        |←── 训练集 ──→|←── 验证集 ──→|←── 测试集 ──→|
        
第1轮: |1980-2010|2011-2013|2014-2016|  (早期训练，近期测试)
第2轮: |1980-2012|2013-2015|2016-2018|  (滚动更新)
第3轮: |1980-2014|2015-2017|2018-2020|  (继续滚动)
...
```

#### 2. 时序交叉验证（Time Series Cross-Validation）

```python
def time_series_cross_validation(data, n_splits=5, test_size=24):
    """
    时序交叉验证：每次用历史数据训练，预测未来test_size个时间步
    """
    splits = []
    n = len(data)
    
    for i in range(n_splits):
        # 训练集：从开始到当前分割点
        train_end = n - (n_splits - i) * test_size
        # 测试集：当前分割点之后test_size个时间步
        test_start = train_end
        test_end = test_start + test_size
        
        splits.append({
            'fold': i + 1,
            'train_period': (data.index[0], data.index[train_end - 1]),
            'test_period': (data.index[test_start], data.index[test_end - 1]),
            'train_samples': train_end,
            'test_samples': test_size
        })
    
    return splits
```

#### 3. 滚动预测划分（Rolling Forecast）

```
滚动预测数据使用:
├── 初始训练期: 1980-2010
├── 第1次预测: 用1980-2010训练, 预测2011-2012
├── 第2次预测: 用1980-2012训练, 预测2013-2014
├── 第3次预测: 用1980-2014训练, 预测2015-2016
└── 最终评估: 汇总所有预测结果与观测对比
```

### 数据隔离原则

#### 1. 时间隔离

| 原则 | 说明 | 违反后果 |
|------|------|----------|
| 训练数据必须早于测试 | 不能使用未来数据训练 | 数据泄露 |
| 测试数据不能用于训练 | 最新数据必须留作独立验证 | 高估模型性能 |
| 验证数据不能参与训练 | 用于模型选择的不能用于训练 | 过拟合评估 |

#### 2. 信息隔离

```
信息流控制:
原始数据 → [训练数据] → 模型训练 → 模型参数
                ↓
         [验证数据] → 模型评估 → 超参数选择
                ↓
         [测试数据] → 最终评估 → 性能报告

禁止:
× 测试数据信息回流到训练过程
× 验证数据信息影响训练损失
× 使用未来信息进行当前预测
```

#### 3. 标注隔离

| 数据类型 | 能否作为输入 | 能否作为标签 | 说明 |
|---------|-------------|-------------|------|
| 训练输入 | ✓ | × | 用于特征学习 |
| 训练标签 | × | ✓ | 用于监督学习 |
| 验证输入 | × | × | 仅用于评估 |
| 测试输入 | × | × | 仅用于最终评估 |

### ENSO预测任务的数据划分

#### 1. 推荐划分方案

```
ENSO预测数据划分:
├── 训练期: 1980-2015 (36年)
│   └── 用途: 模型训练和参数学习
├── 验证期: 2016-2019 (4年)
│   └── 用途: 超参数调优和模型选择
└── 测试期: 2020-2024 (5年)
    └── 用途: 独立验证（最终评估）
```

#### 2. 划分统计

| 数据集 | 时间范围 | 样本量 | 占比 | 用途 |
|--------|----------|--------|------|------|
| 训练集 | 1980-2015 | 432个月 | 80% | 模型训练 |
| 验证集 | 2016-2019 | 48个月 | 9% | 超参数调优 |
| 测试集 | 2020-2024 | 60个月 | 11% | 独立验证 |

#### 3. 滚动预测划分（可选）

```
滚动预测ENSO预测:
├── 第1次: 训练1980-2010, 预测2011-2012
├── 第2次: 训练1980-2012, 预测2013-2014
├── 第3次: 训练1980-2014, 预测2015-2016
├── 第4次: 训练1980-2016, 预测2017-2018
└── 第5次: 训练1980-2018, 预测2019-2020
```

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 训练期长度 | ≥30年 | [气候学惯例] | 足够样本覆盖ENSO周期 |
| 验证期长度 | 3-5年 | [气候预测实践] | 平衡评估准确性和数据利用 |
| 测试期长度 | ≥5年 | [IPCC指南] | 独立验证的最低要求 |
| 滚动窗口 | 1-3年 | [ENSO预测] | 平衡数据利用和计算成本 |
| 样本量最小要求 | ≥100 | [统计学] | 保证统计显著性 |

## 边界与分流

### 数据划分决策

```
IF (数据量 < 30年) → 使用时序交叉验证
IF (数据量 ≥ 30年) → 使用固定划分
IF (需要实时更新) → 使用滚动预测
IF (计算资源有限) → 使用简单时序划分
```

### 常见错误及避免

| 错误 | 正确做法 |
|------|----------|
| 使用随机划分 | 必须保持时间顺序 |
| 测试数据用于训练 | 测试数据必须独立 |
| 使用未来数据预测 | 只能使用历史数据 |
| 验证数据参与训练 | 验证数据仅用于评估 |

## 质量检查

| 检查项 | 标准 | 失败处理 |
|--------|------|----------|
| 时间连续性 | 训练、验证、测试时间连续 | 重新划分 |
| 无重叠 | 各数据集时间无重叠 | 重新划分 |
| 样本量充足 | 测试集≥50个样本 | 延长测试期或使用交叉验证 |
| ENSO覆盖 | 训练集覆盖多种ENSO事件 | 扩展训练期 |

## 回退策略

- **数据不足**: 使用交叉验证或留一法
- **数据缺失**: 使用插补或删除缺失段
- **划分失败**: 使用简单时序划分
