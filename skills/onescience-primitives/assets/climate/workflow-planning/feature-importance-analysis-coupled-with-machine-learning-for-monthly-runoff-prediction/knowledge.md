# 特征重要性分析与机器学习耦合的月径流预测方法

## 适用范围
用于从大量潜在预测因子（如数百个全球气候指数与局部水文气象变量）中，系统性地筛选关键变量，并构建高精度、可解释的月尺度径流预测模型。该方法适用于气候信息对径流影响显著、预测因子维度高且存在复杂非线性关系的流域预报场景。典型触发条件包括：需要融合大尺度气候信号提升预报技巧、需明确各驱动因子相对重要性以支持物理归因分析、或传统单一数据驱动方法陷入过拟合时。

## 输入
- **必需输入**：
  - 月径流时间序列（作为预测目标）。
  - 候选预测因子数据集，应包含：a) 与流域直接相关的局部水文气象因子（如降水、蒸发）；b) 大量潜在相关的大尺度气候指数（如大气环流指数、海温指数等，规模可达上百个）。
- **可选输入**：
  - 各气候指数的滞后时间信息（如1-12个月），用于构建时滞输入特征。
  - 预定义的模型性能基准或物理先验知识，用于辅助评估。

## 输出
- 关键预测因子集合及其重要性排序。
- 优化后的月径流预测模型及其超参数配置。
- 各因子对径流影响的量化评估结果。
- 不同输入情景下，各候选模型的性能对比报告（包含NSE, RMSE, R, KGE等指标）。

## 流程节点
本方法是一个包含反馈与选择的迭代优化流程，其核心步骤如下：

1.  **数据准备与初步筛选（s1）**
    - **步骤描述**：收集并准备包含目标月径流、局部气象因子及大量全球气候因子的数据集。使用基于k近邻的互信息（MI）方法，计算每个候选因子（可包含不同滞后阶数）与月径流之间的相关性强度。互信息是一种非参数统计方法，能够度量变量间线性及非线性的依赖关系。
    - **输入**：原始水文气象及气候因子数据（`raw_factors`），月径流时间序列（`target_runoff`）。
    - **输出**：互信息值矩阵，初步筛选后的Top-N因子列表（例如N=50）。
    - **质量门**：筛选出的因子与径流应具有统计显著的相关性（如p<0.01）。

2.  **特征重要性排序（s2）**
    - **步骤描述**：将上一步筛选出的因子（如Top-50）作为输入，训练一个随机森林（RF）模型。基于袋外（OOB）样本估计，通过打乱每个特征后计算模型均方误差（MSE）的变化量，来量化每个特征对预测精度的重要性。最终得到一个归一化至[0,1]的重要性评分排序列表。
    - **输入**：来自s1的Top-50因子数据集（`top50_factors`）。
    - **输出**：特征重要性排序列表（`factor_importance_rank`）。
    - **质量门**：重要性评分应正确反映因子对模型贡献的相对大小。

3.  **构建输入情景（s3）**
    - **步骤描述**：根据特征重要性排序，采用渐进式策略构建多个输入情景。例如，从最重要的1个因子开始，每次按固定步长（如增加5个）增加因子数量，直至包含所有筛选出的因子。这生成了一系列复杂度递增的输入情景（如Scenario 1至Scenario 10）。
    - **输入**：特征重要性排序结果（`factor_importance_rank`）。
    - **输出**：多个输入情景（`input_scenario`），每个情景包含不同数量的预测因子。
    - **质量门**：每个情景的输入因子数量需按设计步长递增，且因子组合严格遵循重要性排序。

4.  **模型训练与超参数优化（s4）**
    - **步骤描述**：针对每一个输入情景，分别使用多种候选机器学习模型进行训练与超参数优化。候选模型可包括混合核支持向量机（HKSVM）、极限学习机（ELM）、广义回归神经网络（GRNN）及多元线性回归（MLR）等。使用改进的粒子群优化（IPSO）算法，结合K折交叉验证，为每个模型在每个情景下搜索最优超参数组合。IPSO旨在克服传统PSO易早熟和局部收敛的问题。
    - **输入**：特定输入情景（`input_scenario`），机器学习模型类型（`ml_model`）。
    - **输出**：训练好的模型，优化后的超参数集。
    - **质量门**：模型在K折交叉验证中的性能需达到稳定。

5.  **模型评估与选择（s5）**
    - **步骤描述**：使用独立的测试集数据，对所有优化后的模型及其最优超参数进行最终评估。采用纳什效率系数（NSE）、均方根误差（RMSE）、相关系数（R）、Kling-Gupta效率（KGE）等多个指标进行综合评判。为每个机器学习模型，确定其在测试集上表现最优的输入情景。
    - **输入**：所有模型在所有情景下的预测结果（`all_models_results`）。
    - **输出**：每个ML模型的最优输入情景及其对应的性能指标。
    - **质量门**：根据测试集上的综合性能指标（如NSE）确定最佳情景与模型。

## 边界与分流
- **适用边界**：本方法尤其适用于预测因子维度高（数十至数百）、因子间可能存在非线性关联、且需要增强模型可解释性（通过特征重要性排序）的月径流预测任务。
- **分流情况**：
  - 若预测目标为日尺度或小时尺度等更精细时间分辨率的径流，或序列依赖性极强，可能需要考虑LSTM、Transformer等专门处理时序数据的深度学习模型。
  - 若主要目标为纯预测精度最大化且可解释性要求不高，可尝试端到端的深度学习模型（如LSTM）。
  - 若预测因子数量本身不多（少于20个），或具有明确的物理先导性，可简化或跳过初始的MI大规模筛选步骤，直接进行特征重要性分析或建模。
  - 本流程以机器学习为核心，与传统的基于物理机制的水文模型（如SWAT、VIC）为互补关系，而非替代。物理模型更适合无观测资料的流域或机理研究。

## 回退策略
- **输入因子过多导致模型泛化差**：回退至s3，减少输入情景中的因子数量（即使用更靠前的重要性排序子集），或加强正则化、调整IPSO优化范围。
- **输入因子过少导致信息不足**：检查s1的MI筛选过程，可适当放宽筛选阈值或增加Top-N的数量，并重新评估。
- **模型过拟合（如测试集性能远低于训练集）**：在s4中，加强K折交叉验证的严格性，或选择复杂度更低的模型（如从GRNN切换到ELM），或对HKSVM/ELM的超参数施加更强的正则化约束。
- **超参数优化效率低或陷入局部最优**：调整IPSO算法的参数（如惯性权重、学习因子），增加迭代次数，或尝试结合其他优化算法（如贝叶斯优化）作为补充。
- **物理机制解释与统计重要性矛盾**：若特征重要性排序结果与已知水文物理常识严重不符，应回溯检查数据质量（如异常值、缺失值处理），并审视力学过程是否被关键因子遗漏。

## 资源召回建议
- **工具库**：
  - 特征筛选：`sklearn.feature_selection` 中的 `mutual_info_regression`。
  - 随机森林与特征重要性：`sklearn.ensemble.RandomForestRegressor`，其 `feature_importances_` 属性。
  - 机器学习模型：`scikit-learn`（MLR），`libsvm` 或 `sklearn.svm.SVR`（HKSVM），`elm` 等专用库（ELM, GRNN）。
  - 超参数优化：`pyswarm`（PSO基础），需根据文献实现改进版本（IPSO），或使用 `scikit-optimize`、`optuna` 等通用库。
- **数据源**：全球气候指数通常来自国家气候中心（NCC）、NOAA Climate Prediction Center（CPC）等机构网站。径流与局部气象数据需从水文站网获取。
- **相关方法**：可参考主成分分析（PCA）、递归特征消除（RFE）等其他特征选择/降维方法作为对比或补充。对于时间序列分析，可结合SARIMA等经典方法作为基准模型。
