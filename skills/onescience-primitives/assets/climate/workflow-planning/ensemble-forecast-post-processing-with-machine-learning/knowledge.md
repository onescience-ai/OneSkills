# 基于机器学习的集合预报后处理

## 适用范围

用于对确定性或集合数值天气预报产品进行统计后处理，以校正预报系统的系统性偏差、改善预报的离散度，并生成经过校准的概率预报产品。典型触发场景包括：1）预报变量存在显著的系统偏差（如站点温度）；2）原始集合预报的离散度不足或过剩（如概率校准的PIT图不均匀）；3）需要输出逐点的概率分布而非单一数值预报；4）业务预报系统（如ARPEGE, AROME）需要提升其预报技巧。该方法适用于多种气象变量，但流程细节（如预测因子选择、模型变体）需根据变量特性（如连续型变量温度与离散型/阈值型变量降水）进行调整。

## 输入

- **必需输入**：
  - **原始集合预报场**：待校准的集合预报系统（EPS）输出的历史预报数据，包含多个集合成员。通常为格点或站点数据。
  - **对应的观测数据**：用于训练和验证的真实观测值。对于站点预报，为对应站点的观测时间序列；对于格点预报，可以是高质量的分析场或网格化观测产品。
- **可选/模型依赖输入**：
  - **预测因子集合**：用于提升模型技巧的协变量，可能包括地理信息（海拔、经纬度、离海距离）、预报场统计量（集合均值、方差）、或来自其他模型/数据的输出。
  - **模型超参数**：特定模型的配置参数，如量化回归森林中树的数量、每个节点最小样本数等。
  - **用于结构保持的原始集合成员信息**：在进行重排序步骤时，需要原始集合成员在每个点上的秩次或排序。

## 输出

- **校准后的概率预报场**：每个预报点（站点或网格点）输出一个校准后的概率分布（如分位数）或重新排序后的集合成员。
- **重新排序后的集合成员场**：在保留原始集合时空相关结构的前提下，将校准后的边际分布分配给各个成员。
- **性能评估报告**：包含如连续概率评分（CRPS）、概率积分变换（PIT）直方图、可靠图（Reliability Diagram）等统计指标，用于量化后处理相对于原始集合的改进。

## 流程节点

1.  **s1：模型训练**
    *   **步骤描述**：使用历史预报-观测配对数据，为每个预报点或一组相似点训练一个统计后处理模型，以学习预报误差与预测因子之间的关系，并输出校准后的边际分布。
    *   **上游依赖**：无（起始步骤）。
    *   **输入参数**：
        *   `eps_data`：历史集合预报数据（必需）。
        *   `obs_data`：历史观测数据（必需）。
        *   `predictors`：预测因子集合（可选但强烈推荐，用以提升技巧）。
        *   `hyperparams`：模型超参数（可选，使用默认或通过验证集调整）。
    *   **输出**：校准好的后处理模型；对训练期数据应用该模型得到的校准后边际分布。
    *   **质量门**：在独立的交叉验证集上，模型输出的CRPS相比原始集合预报应有统计显著的改善。
    *   **提示词模板**：（不适用，本步骤为传统数据处理与建模）。

2.  **s2：结构保持与重排序**
    *   **步骤描述**：将各点独立校准后的边际概率分布，通过集合Copula耦合（ECC）或其变体（如bc-ECC）重新组合成联合分布。此步骤使用原始集合成员在各点上的秩次信息，将校准后的分位数重新分配给各成员，从而保持原始集合预报在空间和时间上的相关性结构。
    *   **上游依赖**：s1。
    *   **输入参数**：
        *   `calibrated_margins`：来自步骤s1的、每个点独立校准后的边际分布或分位数（必需）。
        *   `raw_ensemble`：原始集合预报的成员值，用于提供秩次信息（必需）。
    *   **输出**：重新排序后的集合预报成员场。
    *   **质量门**：生成的集合预报在空间场和时间序列上，应与原始集合具有相似的波动特征和相关性，且不产生物理上不现实的离散或极端的组合。
    *   **提示词模板**：（不适用，本步骤为算法操作）。

3.  **s3：空间插值与降尺度（针对站点数据）**
    *   **步骤描述**：当后处理在观测站点上进行（如站点温度）时，需要通过空间插值将离散的站点预报结果转化为连续的格点预报场。常用方法包括结合多尺度B样条分析（MBA）的回归插值，以兼顾场的整体结构和站点处的精确性。
    *   **上游依赖**：s2。
    *   **输入参数**：
        *   `station_forecasts`：经过步骤s1和s2处理的、各站点校准后的集合成员预报值（必需）。
        *   `target_grid`：期望输出的网格定义，包括分辨率、范围和投影（必需）。
    *   **输出**：网格化的、高分辨率的后处理预报场（可以是每个成员的场或概率分布场）。
    *   **质量门**：插值过程引入的额外误差应尽可能小（例如，交叉验证的平均绝对误差在~0.3°C量级，具体取决于变量），且生成的格点场结构平滑、合理，站点处的值与输入一致。
    *   **提示词模板**：（不适用，本步骤为插值算法）。

4.  **s4：效果评估**
    *   **步骤描述**：使用独立的验证数据集和一组完善的概率预报评估指标，全面评估后处理链路的效果。
    *   **上游依赖**：s3（若流程包含插值）或直接s2（若输出为格点后处理）。
    *   **输入参数**：
        *   `processed_forecasts`：来自前序步骤的最终后处理预报结果（必需）。
        *   `verification_data`：与预报时段独立的观测数据（必需）。
    *   **输出**：评估指标报告，包括但不限于：
        - CRPS及其相对于原始集合的改善百分比。
        - PIT直方图的均匀性（用以判断概率校准度）。
        - 可靠图。
        - 对于分类预报（如降水），可使用ROC曲线、概率技巧评分（PSS）等。
    *   **质量门**：评估指标应表明：1）预报无偏（PIT直方图接近均匀）；2）离散度良好（可靠图接近对角线）；3）所有技巧评分（如CRPS）相比原始集合预报有明确提升。
    *   **提示词模板**：（不适用，本步骤为统计分析）。

## 边界与分流

- **适用边界**：该方法（QRF + ECC框架）因其鲁棒性和对变量类型的适应性（可直接处理分位数预测），特别适合业务化部署。它适用于多种连续型气象变量（如温度、风速）和可转换为分位数预测的阈值/累积型变量（如降水）。
- **分流场景**：
  - **变量特性不符**：若预报变量是严格分类变量（如雷暴发生与否），应考虑使用基于逻辑回归或概率校准的集合后处理方法，而非直接的分位数回归。
  - **数据稀缺**：当针对特定稀有事件（如极端高温）进行训练时，若训练样本严重不足，QRF等基于树的模型可能外推能力有限。此时可考虑引入物理约束、使用更简单的模型（如线性分位数回归）或采用基于再分析数据的增广样本策略。
  - **计算资源受限**：对于全球或超高分辨率系统的逐格点后处理，计算开销巨大。可考虑采用模型简化（如减少树的数量）、区域化处理或使用替代的更高效的统计方法（如后处理模型输出统计MOS）。
  - **需要多变量联合校准**：本流程主要关注单变量的边际校准和结构保持。若核心需求是保持或调整多个变量（如温度与湿度、风速与风向）之间的联合概率结构，则需要采用多变量后处理技术。

## 质量检查

1.  **校准度检验**：检查PIT直方图。均匀的直方图表明概率校准良好；U形表明离散度不足；倒U形表明离散度过剩。
2.  **技巧评分**：比较后处理前后的CRPS。CRPS的下降（改善）是衡量概率预报整体技巧提升的关键指标。
3.  **可靠图**：检查预测概率与观测频率是否一致。理想情况应接近对角线。
4.  **场光滑性与物理合理性**（针对格点输出）：目视检查或计算空间平滑度指标，确保插值后的场没有明显的人为条带或不连续。检查极端值是否在物理范围内。
5.  **集合成员统计特性**：检查重新排序后的集合，其均值、方差等统计量与校准后的边际分布及原始集合结构是否一致。

## 回退策略

- **训练数据不足或不匹配**：
  - **回退路径**：减少预测因子数量以避免过拟合；采用更简单的模型（如线性分位数回归）；使用迁移学习或从更大范围的同类数据中预训练模型再进行微调；明确声明模型技巧可能受限，并建议用户在实际应用中进行持续的性能监控。
- **预测因子选择不当导致离散度问题**：
  - **回退路径**：重新评估并精简预测因子集，优先保证关键动力因子的引入。可尝试使用特征重要性分析或逐步回归来筛选。若问题持续，可考虑在后处理中加入显式的离散度调整步骤（如使用异方差噪声模型）。
- **模型无法准确外推极端事件**：
  - **回退路径**：对于极端事件概率评估，该方法可能低估风险。建议结合基于物理的极端事件概率模型或使用极端值理论（EVT）对尾部进行单独校准，作为本方法的补充。
- **空间插值效果不佳**：
  - **回退路径**：调整插值方法参数（如MBA的层数或平滑参数）。若站点稀疏，可考虑先将集合成员进行简单的反距离加权插值，再对插值后的格点场进行后处理，以规避站点-格点转换的复杂性。

## 资源召回建议

- **核心算法库**：
  - **量化回归森林**：可参考 `quantregForest`（R包）或 `sklearn.ensemble.RandomForestRegressor`（Python，通过预测分位数实现）的实现与文档。
  - **集合Copula耦合**：该方法通常需根据预报系统定制实现，可参考相关气象统计文献中的算法描述进行编码。
  - **空间插值**：多尺度B样条分析（MBA）及相关插值方法可参考专业空间统计或地统计软件库。
- **评估工具**：使用 `propensity`、`scoringRules`（R）或 `properscoring`（Python）等库计算CRPS等概率评分。
- **相关技术**：本流程是集合后处理方法族的一种具体实现。与之相关的其他重要方法包括：模型输出统计（MOS）、贝叶斯模型平均（BMA）、非参数核密度估计等。在选择时，需权衡技巧、计算成本和模型复杂度。
