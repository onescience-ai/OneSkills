# 机器学习模型可解释性分析

## 适用范围

应用SHAP（SHapley Additive exPlanations）等可解释性方法，解释机器学习模型（如随机森林）的输出。通过计算Shapley值量化每个特征对预测的贡献，支持全局特征重要性排序、局部交互分析、特征与样本聚类，以理解模型行为、进行特征选择和模型调试。

当任务目标与该知识所述场景一致时，可复用本条目。

## 输入

- 已训练的机器学习模型对象
- 用于计算Shapley值的背景数据集

## 输出

- 每个特征对每个样本预测值的贡献（Shapley值）
- 全局特征重要性排名及方向
- 单个特征的依赖关系图与交互作用图
- 特征冗余性聚类结果
- 样本Shapley值热图

## 流程节点

1. 基于已训练模型和背景数据，计算每个样本的Shapley值。
2. 生成全局特征重要性摘要图（summary plot），展示特征贡献的方向和大小。
3. 生成特征依赖图（dependence plot）或交互图（force plot），分析特征对对特定预测的影响。
4. 使用层次聚类（hclust）识别冗余特征组。
5. 对样本进行聚类（heatmap），发现具有相似Shapley值模式的样本群。

## 前提条件

- 已有一个训练好的、可进行特征归因的机器学习模型（如随机森林）。
- 需要Python环境及SHAP库（shap）。
- 需要模型的训练或背景数据集用于计算Shapley值。

## 边界与分流

- 相关资产/可替代方案：是随机森林等机器学习模型的后处理解释工具。
- 相关资产/可替代方案：其分析结果可用于指导模型输入变量的筛选。
- 相关资产/可替代方案：可替代传统的特征重要性（如基尼不纯度）方法，提供更一致的解释。

## 回退策略

- 当特征之间存在高多重共线性时，Shapley值的方差可能增大，解释需谨慎。
- 对于高维数据，计算Shapley值及其交互值可能计算量巨大。
- SHAP解释的是模型的近似行为，并不保证与真实物理机制完全一致。
