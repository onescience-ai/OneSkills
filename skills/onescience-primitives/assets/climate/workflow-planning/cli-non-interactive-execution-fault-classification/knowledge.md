# CLI非交互执行与故障分类方法论

## 适用范围
适用于所有需要在非交互模式下执行的CLI工具，包括自动化脚本、批处理任务、CI/CD流水线中的工具执行。覆盖命令参数解析、环境检测、认证处理、沙箱执行、超时控制、退出码分类和标准错误判读。

## 输入
- CLI工具的命令行参数和配置选项
- 执行环境信息（操作系统、依赖版本、资源限制）
- 认证凭证（如需要）
- 输入数据文件或流

## 输出
- 执行结果（成功/失败状态）
- 退出码（标准或自定义）
- 标准输出和标准错误流
- 执行日志和诊断信息

## 流程节点
1. **环境预检** → 验证依赖项、权限、资源可用性
2. **参数解析** → 检查命令行参数的完整性和有效性
3. **认证处理** → 验证凭证、令牌、密钥等认证信息
4. **沙箱执行** → 在隔离环境中执行命令，捕获所有输出
5. **超时监控** → 监控执行时间，触发超时中断
6. **退出码分类** → 根据退出码判断执行结果类别
7. **错误诊断** → 分析标准错误流，识别故障类型
8. **恢复策略** → 根据故障类别执行相应的恢复或重试逻辑

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 超时阈值 | 可配置 | [通用实践] | 根据任务复杂度设置合理的超时时间 |
| 重试次数 | 3次 | [通用实践] | 对于瞬态故障，建议最多重试3次 |
| 退出码范围 | 0-255 | [POSIX标准] | 0表示成功，非0表示各类错误 |
| 缓冲区大小 | 4KB-64KB | [通用实践] | 标准输出/错误缓冲区大小 |

### 故障分类体系
| 故障类别 | 退出码范围 | 描述 | 恢复策略 |
|----------|------------|------|----------|
| 成功完成 | 0 | 命令正常执行完毕 | 无需恢复 |
| 参数错误 | 1-9 | 命令行参数无效或缺失 | 修正参数后重试 |
| 环境错误 | 10-19 | 依赖缺失、权限不足等 | 修复环境后重试 |
| 资源错误 | 20-29 | 内存不足、磁盘空间不足等 | 释放资源后重试 |
| 认证错误 | 30-39 | 认证失败、令牌过期等 | 刷新凭证后重试 |
| 超时错误 | 40-49 | 执行超时 | 调整超时阈值或优化任务 |
| 沙箱错误 | 50-59 | 沙箱环境异常 | 重启沙箱后重试 |
| 逻辑错误 | 60-69 | 业务逻辑执行失败 | 检查输入数据和业务逻辑 |
| 系统错误 | 70-100 | 不可恢复的系统级错误 | 记录日志并通知管理员 |

## 边界与分流
- **参数校验失败**：立即返回退出码1，不执行后续流程
- **认证失败**：返回退出码30-39，不重试或根据策略重试
- **沙箱执行超时**：返回退出码40-49，可配置是否重试
- **资源不足**：返回退出码20-29，等待资源释放后重试
- **不可恢复错误**：返回退出码70-100，记录详细日志

## 质量检查
- 所有CLI命令必须支持非交互模式（如--non-interactive标志）
- 退出码必须符合POSIX标准或自定义规范
- 标准错误流必须包含足够的诊断信息
- 超时必须可配置且默认值合理
- 沙箱执行必须隔离文件系统和网络访问

## 回退策略
1. **参数错误回退**：使用默认参数或提示用户修正
2. **环境错误回退**：尝试使用备用环境或容器化执行
3. **资源错误回退**：降级执行或分批处理
4. **认证错误回退**：使用备用凭证或匿名访问（如允许）
5. **超时错误回退**：增加超时阈值或拆分任务
