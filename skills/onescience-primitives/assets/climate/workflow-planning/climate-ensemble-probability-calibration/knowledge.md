# 集合预报概率校准知识

## 适用范围
适用于集合预报的概率校准任务，特别是EMOS（Ensemble Model Output Statistics）校准方法。包括EMOS校准原理、实现步骤、概率校准验证指标等知识缺口。不适用于确定性预报校准或非概率集合预报。

## 输入
- 集合预报输出：多个集合成员的预报值
- 观测数据：对应的观测值（用于校准参数估计）
- 校准参数：历史数据估计的EMOS参数

## 输出
- 校准后的概率预报
- 校准参数（均值、方差等）
- 校准验证指标（可靠性、分辨率等）

## 流程节点
1. **EMOS原理理解** → 学习EMOS校准的数学原理
2. **参数估计** → 使用历史数据估计校准参数
3. **概率校准执行** → 应用EMOS方法校准集合预报
4. **验证指标计算** → 计算概率校准验证指标

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| EMOS均值校准 | μ = a₀ + Σaᵢxᵢ | [U1] | 集合均值线性组合 |
| EMOS方差校准 | σ² = b₀ + Σbᵢ(xᵢ - μ)² | [U1] | 集合离散度校准 |
| 可靠性指标 | PIT直方图均匀性 | [U1] | 概率校准核心指标 |
| 分辨率指标 | ROC曲线下面积 | [U1] | 预报区分能力 |

## 边界与分流
- 当观测数据不足时：使用贝叶斯方法或正则化
- 当集合成员数过少时：考虑使用后处理方法
- 当分布假设不成立时：使用非参数化校准方法

## 质量检查
- 可靠性检查：PIT直方图是否均匀
- 锐度检查：概率预报是否过于分散
- 校准技巧评分：Brier技巧评分、对数技巧评分

## 回退策略
- 使用简单偏差校正作为替代
- 使用百分位校准方法
- 降低校准复杂度
