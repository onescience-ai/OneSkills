# OneScience标准工作流步骤映射规范

## 适用范围
适用于OneScience平台中所有需要执行标准工作流的任务，特别是需要区分核心步骤与可选步骤的场景。不适用于非标准工作流或自定义工作流。

## 输入
- 任务需求描述
- 场景索引中的工作流步骤定义
- 实际执行步骤列表

## 输出
- 标准工作流步骤映射表
- 核心步骤与可选步骤分类
- 步骤完整性检查报告

## 流程节点
1. **标准步骤识别** → 2. **实际步骤分析** → 3. **步骤分类** → 4. **映射关系建立** → 5. **完整性验证**

### 步骤1：标准步骤识别
- 操作：从场景索引中识别标准工作流步骤
- 参数：场景索引中的workflow_steps字段
- 工具：场景索引解析器
- 质量门禁：准确识别s01-s06标准步骤

### 步骤2：实际步骤分析
- 操作：分析实际执行的步骤列表
- 参数：execution_manifest中的execution_steps字段
- 工具：执行步骤解析器
- 质量门禁：准确识别所有执行步骤

### 步骤3：步骤分类
- 操作：将步骤分为核心步骤和可选步骤
- 参数：核心步骤定义（s01-s06）、可选步骤定义
- 工具：步骤分类规则
- 质量门禁：分类结果符合规范

### 步骤4：映射关系建立
- 操作：建立标准步骤与实际步骤的映射关系
- 参数：步骤名称、步骤顺序、步骤功能
- 工具：映射关系生成器
- 质量门禁：映射关系准确完整

### 步骤5：完整性验证
- 操作：验证工作流步骤完整性
- 参数：核心步骤必须全部包含、可选步骤可选择性包含
- 工具：完整性检查脚本
- 质量门禁：核心步骤100%覆盖

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 标准工作流步骤 | s01-s06 | [归因报告issue5] | 必须执行的核心步骤 |
| 核心步骤定义 | 数据检查、方法配置、概率生成、风险提取、验证、结论 | [归因报告issue5] | 任务必须包含 |
| 可选步骤定义 | 产品可视化、报告生成等 | [归因报告issue5] | 可选择性添加 |
| 步骤计数规则 | 仅核心步骤计入 | [归因报告issue5] | 可选步骤不计入 |
| 额外步骤标注 | optional标记 | [归因报告issue5] | 明确区分核心与可选 |

## 边界与分流
- **步骤缺失**：补充缺失的核心步骤
- **步骤冗余**：移除不必要的核心步骤或标记为可选
- **步骤顺序错误**：调整步骤顺序以符合逻辑依赖
- **新步骤类型**：评估是否为核心步骤，相应分类

## 质量检查
- 验证点：核心步骤完整性、步骤分类准确性
- 阈值：核心步骤100%包含、分类100%准确
- 失败处理：修正步骤分类或补充缺失步骤

## 回退策略

2. 咨询领域专家确定步骤分类
3. 扩展工作流步骤定义以适应新任务类型
