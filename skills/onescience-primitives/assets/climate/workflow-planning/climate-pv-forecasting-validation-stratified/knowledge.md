# 光伏功率预测分层验证方法

## 适用范围

光伏功率预测任务的验证与评估，包括超短期（0-6小时）、短期（6-48小时）和中长期预测。适用于单站和多站联合预测场景，覆盖确定性和概率性预报的验证需求。

## 输入

- **预测数据**：各站点各时效的功率预测值序列
- **实测数据**：各站点对应时段的实际功率输出（来自SCADA系统）
- **气象数据**：辐照度、温度、云量等辅助信息（用于天气类型分层）
- **电站元数据**：装机容量、组件类型、安装角度等（用于容量归一化）

## 输出

- **分层验证报告**：包含各层指标的详细评估结果
- **爬坡事件分析**：爬坡检测、预测准确性评估
- **基线比较表**：与持久性预报、气候平均等基线的技巧评分
- **验收判定**：基于门限的通过/不通过判定

## 流程节点

### 1. 数据预处理与容量归一化
- 将各站功率值归一化为容量比（p/P_installed），消除电站规模差异
- 检查数据完整性，标记缺测时段
- 质量门禁：缺测率 <5%方可进入验证

### 2. 分层指标计算
**按站点分层**：
- 逐站计算 RMSE、MAE、R²、MAPE
- 计算归一化 RMSE（nRMSE = RMSE/P_installed）
- 质量门禁：各站nRMSE < 15%（良好），<10%（优秀）

**按预测时效分层**：
- 按1h、3h、6h、12h、24h、48h等时效分组计算指标
- 评估指标随时效的衰减趋势
- 质量门禁：RMSE随时效单调递增（无异常跳变）

**按天气类型分层**：
- 晴天（clear）、多云（cloudy）、阴天（overcast）、雨天
- 依据云量或辐照度阈值分类
- 质量门禁：各天气类型样本量 ≥30

### 3. 爬坡事件检测与检验
**爬坡事件定义**：
- 功率变化率阈值：通常取额定容量的 10%/min 或 30%/10min [1]
- 持续时间：至少持续 5 分钟

**检测方法**：
- 滑动窗口法：计算相邻时段功率差值
- 阈值法：绝对变化率或相对变化率超过阈值
- 结合云图变化的物理方法

**检验指标**：
- 检测准确率：Precision = TP/(TP+FP)
- 召回率：Recall = TP/(TP+FN)
- F1分数：2 × Precision × Recall / (Precision + Recall)
- 质量门禁：F1 ≥ 0.60 [1]

### 4. 基线比较
**标准基线**：
- 持久性预报（Persistence）：预测值 = 当前时刻实测值
- 气候平均（Climate Average）：预测值 = 历史同时段平均值
- 线性趋势（Linear Trend）：基于最近N小时的线性外推

**技巧评分（Skill Score）**：
- SS = 1 - RMSE_model / RMSE_baseline
- 正技巧：模型优于基线
- 质量门禁：SS_persistence > 0，SS_climate_average > 0

### 5. 验收门限设置
**推荐门限（48小时预测）**：
| 指标 | 合格 | 良好 | 优秀 |
|------|------|------|------|
| nRMSE | <20% | <15% | <10% |
| R² | >0.5 | >0.7 | >0.9 |
| MAPE | <30% | <20% | <15% |
| SS_persistence | >0 | >0.1 | >0.25 |

**注意事项**：
- 门限应根据预测时效调整（超短期更严格）
- 多站联合预测需同时满足各站门限
- 爬坡事件预测的F1门限可适当放宽至0.5

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 容量归一化方法 | p/P_installed | [1] | 消除电站规模差异 |
| 爬坡检测阈值 | 10%/min 或 30%/10min | [1] | 功率变化率阈值 |
| 交叉验证方法 | 5-fold 或时间序列划分 | [2] | 避免数据泄露 |
| 技巧评分基线 | 持久性预报 | [1] | 最常用的基线方法 |
| 样本量要求 | ≥30 per stratum | [2] | 保证统计显著性 |

| 场景 | nRMSE | R² | 备注 |

## 边界与分流

**数据不足时**：
- 若某天气类型样本 <30，合并至相邻类别或标注"统计不确定性高"
- 若缺测率 >20%，降低验收门限一级或标记验证结果不可靠

**多站异质性**：
- 若各站性能差异大（标准差 >5%），需逐站分析原因
- 可能的分流：电站容量归一化不当、局部气象差异

**异常检测**：
- 若某站R² < 0或异常低，检查数据质量问题
- 若基线技巧评分为负，检查模型是否过拟合

## 质量检查

- **验证报告完整性**：是否包含按站点、时效、天气类型分层的指标
- **爬坡事件分析**：是否包含检测阈值定义和F1指标
- **基线比较**：是否与持久性预报和气候平均进行比较
- **门限判定**：是否设置了合理的验收门限
- **统计显著性**：样本量是否满足各层要求

## 回退策略

- 若分层验证失败，可退化为整体验证（但需注明）
- 若基线比较异常，检查基线计算方法和数据对齐
- 若爬坡检测不可靠，可使用功率波动率作为替代指标
