# 基于深度学习的天气锋面自动检测任务与算法

## 适用范围
用于从网格化的多源大气表层变量场（如再分析资料）中自动、客观地检测、分类并提取天气锋面（冷锋、暖锋、准静止锋、锢囚锋）的地理空间位置。该方法旨在替代或补充传统的人工分析，特别适用于构建长时间序列的锋面气候数据集，支持锋面频率统计、极端天气事件分析等气候学与天气预报研究。

## 输入
- **必需输入**：
  1. 一组二维网格化的气象变量场，典型变量包括：2米气温、2米比湿、海平面气压、10米东向风速、10米北向风速。这些变量构成每个时间步的多通道输入图像。
  2. 人工标注的锋面折线数据（例如来自气象分析公报）。此数据作为监督学习的训练标签，需覆盖训练时间范围，并提供锋面类型信息。
- **可选输入**：
  用于验证的独立标注数据集，其时间范围应与训练数据不重叠。

## 输出
- **中间产物**：
  1. 模型在每个时间步输出的五类概率场（冷锋、暖锋、准静止锋、锢囚锋、无锋）。
- **最终产物**：
  1. 经后处理提取的各类型锋面地理坐标折线（通常以JSON格式存储），可直接用于GIS分析或可视化。
  2. 基于锋面折线计算的月度或季度锋面穿越率气候态网格图。
  3. 与人工分析结果的统计对比报告（如相关系数、偏差分析）。

## 流程节点
1.  **准备训练数据 (s1)**
    - **依赖**: 无
    - **输入参数**:
        | 变量名 | 描述 | 类型 | 默认值 | 必需 |
        | :--- | :--- | :--- | :--- | :--- |
        | `merra2_data` | MERRA-2气象变量场 | str | "2003-2007" | 是 |
        | `csb_archive` | CSB公报存档 | str | "2003-2007" | 是 |
    - **输出**: 原始气象变量网格序列、CSB原始折线数据。
    - **质量门**: 气象场与CSB时间步对齐，空间范围覆盖目标区域。

2.  **构建标签数据 (s2)**
    - **依赖**: s1
    - **输入参数**:
        | 变量名 | 描述 | 类型 | 默认值 | 必需 |
        | :--- | :--- | :--- | :--- | :--- |
        | `csb_polylines` | CSB锋面折线 | str | - | 是 |
        | `grid_spec` | 目标网格规格 | str | "1度经纬度" | 是 |
    - **输出**: 按锋面类型分类的二维标签网格（每个时间步包含五个类别）。
    - **质量门**: 折线被栅格化为指定宽度（如3个网格单元），以模拟锋面的实际宽度并减少空间不连续性。

3.  **训练深度学习网络 (s3)**
    - **依赖**: s2
    - **输入参数**:
        | 变量名 | 描述 | 类型 | 默认值/范围 | 必需 |
        | :--- | :--- | :--- | :--- | :--- |
        | `learning_rate` | 初始学习率 | float | 0.0001 (0.00005-0.0005) | 是 |
        | `category_weights` | 类别权重 | str | "none:0.35, others:1.0" | 是 |
        | `epochs` | 最大训练轮数 | int | 1200 | 是 |
    - **输出**: 训练好的模型权重。
    - **质量门**: 验证集损失连续100个轮次（epochs）未改善时停止训练。
    - **提示词模板**:
      ```python
      # 使用Keras/TensorFlow构建DL-FRONT网络
      model = Sequential()
      model.add(ZeroPadding2D(padding=(2, 2), input_shape=(height, width, num_channels)))
      model.add(Conv2D(filters=32, kernel_size=(5, 5), activation='relu'))
      model.add(Dropout(0.5))
      # ... 可添加更多卷积层 ...
      model.add(Flatten())
      model.add(Dense(num_classes, activation='softmax'))
      
      # 编译模型
      optimizer = Adam(lr=learning_rate)
      model.compile(optimizer=optimizer,
                    loss='categorical_crossentropy',
                    metrics=['accuracy'])
      
      # 设置早停回调
      early_stopping = EarlyStopping(monitor='val_loss', patience=100, restore_best_weights=True)
      
      # 训练（需配合K-Fold交叉验证和网格搜索）
      model.fit(X_train, Y_train,
                class_weight=class_weight_dict,
                validation_data=(X_val, Y_val),
                epochs=epochs,
                callbacks=[early_stopping])
      ```

4.  **模型评估 (s4)**
    - **依赖**: s3
    - **输入参数**:
        | 变量名 | 描述 | 类型 | 默认值 | 必需 |
        | :--- | :--- | :--- | :--- | :--- |
        | `val_data` | 独立验证数据集 | str | "2008-2015" | 是 |
    - **输出**: 分类准确率、混淆矩阵、ROC曲线、精确率-召回率曲线。
    - **质量门**: ROC曲线下面积（AUC）接近0.90；精确率-召回率曲线在高召回区域保持较高精度。

5.  **锋面后处理与提取 (s5)**
    - **依赖**: s4
    - **输入参数**:
        | 变量名 | 描述 | 类型 | 默认值 | 必需 |
        | :--- | :--- | :--- | :--- | :--- |
        | `likelihood_grids` | 模型输出的五类概率场 | str | - | 是 |
    - **输出**: 各类型锋面的经纬度折线（JSON格式）。
    - **质量门**: 提取的折线应连续，且地理上对应于概率场的高值区域。
    - **关键子步骤**: 
      a. 生成“任何锋面”的总概率场，并进行二值化处理。
      b. 使用形态学骨架化算法（如`scikit-image`的`medial_axis`）提取概率场的脊线。
      c. 对骨架化后的线段进行分割。
      d. 对每个线段，寻找其端点，并使用最小代价路径算法（如`scikit-image`的`minimum_cost_path`）在发散度数据上追踪平滑折线。

6.  **计算锋面频率气候态 (s6)**
    - **依赖**: s5
    - **输入参数**:
        | 变量名 | 描述 | 类型 | 默认值 | 必需 |
        | :--- | :--- | :--- | :--- | :--- |
        | `front_polylines` | 待评估的锋面折线集 | str | - | 是 |
        | `reference_polylines` | 参考折线集（如CSB） | str | - | 是 |
        | `grid` | 计算网格 | str | "96km x 96km Lambert Conformal Conic" | 是 |
    - **输出**: 月/季锋面穿越率网格；与人工分析结果的统计对比。
    - **质量门**: 计算时应用24小时“空白期”以避免慢速移动的锋面被重复计数；与人工分析气候态的相关系数应大于0.94。

## 边界与分流
- **适用边界**: 该方法依赖于足够高质量和时空覆盖的人工标注数据进行监督学习。标注数据的匮乏或质量不佳将直接限制模型性能。
- **地形影响**: 在复杂地形区域（如大型山脉），由于气象变量场本身受地形扰动显著，模型自动检测的准确率可能下降。
- **系统偏差**: 模型输出可能存在空间上的系统性偏差，导致提取的锋面位置与真实位置不完全重合。
- **类别不平衡**: 训练数据中“无锋”类别占比极高（约88%），若不加以处理，模型将倾向于预测“无锋”。需通过类别权重调整或采样策略缓解。
- **替代方案**: 对于无法获得足够监督标注数据的场景，可考虑基于物理阈值的传统锋面检测算法（如基于温度梯度、风场切变的算法）或半监督/弱监督学习方法。

## 质量检查
- **训练过程监控**: 确保早停机制生效，且训练集与验证集的损失曲线在停止前有合理收敛。
- **模型评估指标**: 在独立验证集上检查总体分类准确率、各类别（尤其是少数类）的精确率、召回率和F1分数。混淆矩阵能揭示模型对哪些类型的锋面存在系统性误判。
- **概率场合理性**: 可视化模型输出的概率场，检查高概率区域是否与已知的锋面活动区（如锋面气候态高发区）在空间上大致吻合。
- **折线提取验证**: 抽查部分提取的锋面折线，目视检查其连续性、形态是否合理，避免出现明显的拓扑错误（如孤立的短线段）。
- **气候态对比**: 将计算的锋面穿越率与可靠的人工分析产品进行定量对比，计算空间相关系数和均方根误差。

## 回退策略
- **数据不足或质量差**: 若可用的人工标注数据不足以训练一个稳健的模型，可考虑：1) 采用迁移学习，使用在大规模图像数据集上预训练的CNN作为特征提取器，再在有限锋面数据上微调；2) 使用主动学习，优先标注模型不确定性高的样本；3) 退回到使用传统的基于规则的锋面检测方法。
- **模型过拟合**: 若训练集表现远优于验证集，应检查：1) 增加数据增强（如随机旋转、翻转）；2) 强化正则化（如增加Dropout率、使用L2正则化）；3) 简化网络结构；4) 检查并处理数据泄漏问题。
- **后处理失败**: 若从概率场提取的折线质量差（如严重断裂、伪影多），应：1) 调整概率场的二值化阈值；2) 优化骨架化后的断裂连接逻辑（如设置最大连接距离）；3) 在最小代价路径追踪中调整代价函数的权重。

## 资源召回建议
- **深度学习框架**: Python环境下的Keras（配合TensorFlow或Theano后端）、PyTorch。
- **科学计算库**: NumPy用于数组操作，SciPy用于科学算法。
- **图像处理库**: `scikit-image`用于形态学操作（骨架化）和图论算法（最小代价路径）。
- **机器学习辅助库**: `scikit-learn`用于数据预处理、交叉验证和评估。
- **数据处理工具**: 用于读取、处理气象网格数据和地理矢量数据的专用库（如xarray、GDAL/OGR、GeoPandas）。
- **数据来源**: MERRA-2再分析数据（美国国家航空航天局戈达德地球科学数据和信息服务中心）、美国国家气象局（NWS）编码地面公报（CSB）存档等。具体获取方式需查询相关数据机构官网。
