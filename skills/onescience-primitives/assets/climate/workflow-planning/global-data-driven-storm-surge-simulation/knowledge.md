# 全球海岸线数据驱动风暴潮模拟

## 适用范围

面向全球海岸线风暴潮的快速估算与预测任务，当传统水动力学模型（如GTSM）计算成本过高、运行条件不足、或需要快速生成大量情景模拟结果时，可采用数据驱动统计模型作为替代或补充方案。该方法利用气象海洋再分析或遥感数据作为预测变量，以验潮站观测数据训练统计回归模型，实现对每日最大风暴潮高度的逐站预测。典型触发条件包括：需要快速评估全球或区域风暴潮风险、缺乏高分辨率水动力模型的运行条件、需要对水动力模型输出进行偏差校正、或需要在观测稀疏区域生成风暴潮代理序列。

## 输入

**必需输入：**

- 验潮站逐小时海平面观测时间序列：用于训练和验证，可从全球海平面分析数据库（如GESLA-2）获取，涵盖全球数百个验潮站的历史记录。
- 多源气象海洋预测变量时间序列：包括但不限于风速、海平面气压、海表温度、降水等。可选遥感产品（如CCMP风场）或大气再分析产品（如ERA-Interim、20CRV2c）作为数据源，通过`predictor_source`参数指定。
- 验潮站元数据：各站点的经纬度坐标、时间覆盖范围和数据质量标记，用于空间定位和数据筛选。

**可选输入：**

- 全球潮汐和风暴潮再分析数据集（如GTSR，覆盖1979–2014年）：可作为对比基准，但需注意其对极端风暴潮峰值存在已知的低估倾向。
- 上游流域降水与径流数据：用于捕捉远程降雨驱动的风暴潮（如河流洪水与风暴潮叠加场景）。

## 输出

- 各验潮站位置的每日最大风暴潮预测时间序列（单位：cm）。
- 每个验潮站最终选定的最优模型配置，包括：模型类型（逐步线性回归LR或随机森林RF）、预测变量来源模式（相对源RS或绝对源AR）、是否包含时间滞后。
- 各模型配置的性能指标汇总表，包含相关系数、均方根误差（RMSE）和纳什-萨特克利夫效率系数（NSE），供质量审计和模型比较使用。

## 流程节点

本工作流为一个有向无环图（DAG），包含 5 个步骤。上游依赖关系构成步骤间的编排约束。

### s1 — 数据收集与准备

**上游依赖：** 无（入口节点）

**说明：** 获取多源气象海洋预测变量和风暴潮预测量数据，确保时间和空间覆盖满足研究需求。

| 参数 | 类型 | 默认值 | 取值范围 | 必需 | 说明 |
|------|------|--------|----------|------|------|
| predictor_source | enum | Remote Sensing | Remote Sensing, Atmospheric Reanalysis | 是 | 选择遥感产品（如CCMP）或再分析产品（如ERA-Interim）作为预测变量源 |

**质量门：** 数据时间覆盖研究时段（如1979–2014或1998–2014），空间覆盖目标全球海岸线验潮站。

**输出：** 每日最大风暴潮时间序列；预测变量时间序列。

---

### s2 — 风暴潮提取

**上游依赖：** s1

**说明：** 从验潮站海平面数据中通过谐波分析去除潮汐分量和年平均海平面，分离出非潮汐残差——即风暴潮信号。

| 参数 | 类型 | 默认值 | 取值范围 | 必需 | 说明 |
|------|------|--------|----------|------|------|
| hourly_sea_level | str | 从GESLA-2数据库获取 | — | 是 | 需要验潮站原始逐小时观测数据 |
| harmonic_package | enum | T_Tide | T_Tide, UTide | 是 | T_Tide与UTide结果差异可忽略不计 |

典型实现使用 T_Tide 包，以67个潮汐分潮为基准进行逐年的经典谐波分析。UTide（统一潮汐分析与预测函数包）可作为替代工具，两者结果差异极小。

**质量门：** 去除因相位偏移导致的错误尖峰，确保提取的残差信号不含潮汐能量混入。

**输出：** 风暴潮（非潮汐残差）时间序列。

---

### s3 — 特征工程与降维

**上游依赖：** s1, s2

**说明：** 对每个验潮站周围的预测变量空间网格进行主成分分析（PCA）降维，以减少维度和消除多重共线性。

| 参数 | 类型 | 默认值 | 取值范围 | 必需 | 说明 |
|------|------|--------|----------|------|------|
| spatial_grid_size | str | 10 × 10 度 | — | 是 | 围绕每个验潮站选取预测变量的空间范围 |
| variance_threshold | float | 0.9 | 0.85–1.0 | 是 | 保留能解释原始数据方差此比例的主成分 |

经PCA处理后，预测变量维度通常降至约300–500个主成分。将方差解释阈值从90%提高至95%并未带来明显的模型性能提升，反而增加了不必要的预测变量数量和模型复杂度，因此推荐使用90%作为默认阈值。

**质量门：** 保留的主成分能解释原始数据至少90%的方差，且有效减少多重共线性。

**输出：** 降维后的主成分集合（约300–500个）。

---

### s4 — 模型训练与配置

**上游依赖：** s3

**说明：** 使用逐步线性回归或随机森林算法训练风暴潮预测模型，可选择性地包含时间滞后预测变量以捕捉前期气象条件的持续影响。

| 参数 | 类型 | 默认值 | 取值范围 | 必需 | 说明 |
|------|------|--------|----------|------|------|
| model_type | enum | Random Forest | Linear Regression, Random Forest | 是 | 随机森林能捕捉非线性关系且不易过拟合 |
| time_lag_hours | int | 30 | 0–30 | 否 | 最长滞后30小时，用于捕捉前期气象条件的影响 |
| rf_num_trees | int | 50 | 1–200 | 否 | 基于袋外误差分析，50棵树在性能与计算成本间取得平衡 |

**逐步线性回归：** 迭代地添加或移除主成分，仅保留提供显著统计信息的变量（p < 0.05），构建精简的线性预测方程。

**随机森林：** 集成多棵决策树，利用袋外误差进行内部验证和优化。基于袋外误差曲线分析，50棵决策树为推荐最优值——超过此数量后误差下降幅度极小，而计算成本呈线性增长。

**质量门：** 线性回归中仅保留 p < 0.05 的显著预测变量；随机森林以袋外误差最小化为优化目标。

**输出：** 训练好的风暴潮预测模型。

---

### s5 — 模型验证与选择

**上游依赖：** s2, s4

**说明：** 使用k折交叉验证评估所有模型配置，并为每个验潮站选择性能最佳的配置。

| 参数 | 类型 | 默认值 | 取值范围 | 必需 | 说明 |
|------|------|--------|----------|------|------|
| num_folds | int | 10 | 2–20 | 是 | 10折交叉验证为常用选择 |

评估指标包括：
- **相关系数**（Correlation）：衡量预测值与观测值的线性相关程度。
- **均方根误差**（RMSE）：衡量绝对偏差量级，单位为 cm。
- **纳什-萨特克利夫效率系数**（NSE）：衡量模型相对于以均值预测为基线的改进程度。

**质量门：** 综合考量多个性能指标——至少两个指标应一致指向同一最佳配置——以确定最终模型，避免单一指标导致的片面选择。

**输出：** 各模型配置的性能指标汇总；每个验潮站的最佳模型配置（Model-RS 或 Model-AR）。

## 边界与分流

**区域适用性差异：** 数据驱动模型在温带和亚热带地区的模拟性能（平均相关系数约0.79，RMSE约7.5 cm）显著优于热带地区（平均相关系数约0.45，RMSE约5.3 cm）。热带地区性能下降的可能原因包括：局部预测变量方差较低、河流排放干扰、以及气象海洋预测变量的时空分辨率不足。当目标区域集中在热带海岸线且对精度要求较高时，建议优先考虑高分辨率水动力学模型（如GTSM），或在数据驱动框架中引入区域专用预测变量后重新训练。

**远程驱动的风暴潮：** 当风暴潮信号主要由远离本地的上游降雨（如河流洪水与风暴潮叠加）驱动时，仅依赖本地预测变量的模型无法有效捕捉此类信号。此类场景需结合流域水文模型输出作为补充预测变量，或转向全耦合的水动力-水文模型。

**预测变量分辨率限制：** 部分再分析数据集（如20CRV2c的海平面气压）的时空分辨率可能成为模型精度的瓶颈。若研究目标为极端事件的精细刻画，建议选用更高分辨率的再分析产品（如ERA5）。

**与水动力学模型的互补关系：** 全球潮汐和风暴潮再分析数据集（GTSR）作为水动力学模型的再分析输出，常用于提供基线参考，但其对极端风暴潮峰值的低估是已知局限。数据驱动模型在某些站点可能捕捉到水动力模型遗漏的局部信号，因此两种方法的集成使用可提升整体可靠性。

**上游资产衔接：** GTSR、GTSM 可作为本流程的上游参考数据源或下游对比基准；ERA-Interim 等再分析数据集则直接作为上游预测变量输入接入 s1 步骤。

## 质量检查

- **交叉验证一致性：** 对每个验潮站，检查10折交叉验证中各折的性能指标方差是否处于合理范围，避免因数据划分的随机性导致偶然性结论。
- **多指标综合判断：** 最终模型选择不应仅依赖单一指标。至少两个指标（如相关系数与RMSE）应一致指向同一最佳配置，方可确认选择的稳健性。若各指标指向不同配置，应进一步检查数据质量或考虑模型集成策略。
- **残差诊断：** 检查模型残差是否呈现系统性偏差——例如在特定季节、特定潮汐相位或极端事件中持续偏高或偏低——以识别模型的结构性缺陷。
- **潮汐提取质量验证：** 验证风暴潮提取过程中是否因相位偏移引入虚假尖峰。在潮汐非线性较强的河口或浅水区，67个分潮可能不足以精确模拟潮汐，导致残差中混入潮汐能量；此时应增加分潮数量或改用非线性潮汐模型。
- **数据完整性检查：** 检查GESLA-2等观测数据库中各站点的数据缺失率和质量不均匀时期，识别可能对训练产生不利影响的空洞或异常值。

## 回退策略

| 失败情形 | 替代路径 |
|----------|----------|
| 热带地区模型性能过低（相关系数 < 0.5） | 转向高分辨率水动力学模型（如GTSM），或在预测变量中引入区域专用变量后重新训练 |
| 线性回归性能显著低于随机森林 | 说明预测变量与风暴潮之间存在较强非线性关系，应以随机森林结果为主；若计算资源受限，可尝试梯度提升树等折中方案 |
| PCA后主成分仍存在残余多重共线性 | 将方差解释阈值提高至95%以保留更多主成分，或改用偏最小二乘回归（PLSR）替代 PCA + 逐步回归的组合 |
| 训练数据严重不足或噪声极大 | 增加交叉验证折数以最大化利用有限数据，或引入正则化手段（岭回归/LASSO）替代标准线性回归 |
| 随机森林计算成本过高 | 减少决策树数量至约30棵（基于袋外误差曲线判断边际收益），或改用轻量级集成方法如Extra-Trees |
| 潮汐提取在浅水/河口区失真 | 增加潮汐分潮数量（超过67个），或采用 T_Tide/UTide 的非线性扩展模块 |
| GESLA-2数据缺失严重 | 评估可用时段是否仍满足最低训练样本量要求；若不满足，考虑从其他潮汐数据库补充或排除该站点 |

## 资源召回建议

**工具与软件包：**
- T_Tide（Matlab）/ UTide（Matlab/Python）：经典谐波分析，用于从验潮站海平面数据中提取风暴潮信号。两者结果差异可忽略。
- scikit-learn（Python）：提供线性回归（含逐步回归实现）、随机森林、PCA 等模块的标准化接口。
- PyTides / TSTools：Python 生态下的潮汐分析备选工具。

**数据集：**
- GESLA-2（Global Extreme Sea Level Analysis）：全球验潮站逐小时海平面观测数据库，用于训练和验证。
- GTSR（Global Tide and Surge Reanalysis）：全球潮汐与风暴潮再分析数据集（覆盖1979–2014），可作为对比基准，但需注意其对极端峰值的低估倾向。
- ERA5 / ERA-Interim / 20CRV2c：大气再分析产品，提供海平面气压、风场等预测变量。
- CCMP（Cross-Calibrated Multi-Platform）：遥感风场产品，可作为遥感预测变量源。

**典型性能参考（以下数值来自全球验潮站验证实验，供量级校准；其他区域需以自身数据重新锚定）：**

| 指标 | 温带/亚热带 | 热带 |
|------|------------|------|
| 平均相关系数 | 0.79 | 0.45 |
| 平均 RMSE (cm) | 7.5 | 5.3 |
