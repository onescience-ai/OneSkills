# 气象雷达数据获取与管理知识

## 适用范围
适用于需要获取、预处理和质量控制气象雷达数据的科研和业务场景。特别针对中国气象局雷达数据共享政策、NetCDF数据格式规范、雷达数据预处理标准流程等知识缺口。不适用于非气象雷达数据（如军事雷达）或非中国区域的数据获取。

## 输入
- 数据来源：中国气象局雷达数据共享平台、区域气象中心数据服务
- 数据格式：通常为NetCDF格式，可能包含多普勒雷达反射率、径向速度等产品
- 预处理要求：需要进行数据清洗、格式转换、质量标记等步骤

## 输出
- 预处理后的雷达数据集（NetCDF格式）
- 数据质量报告
- 数据获取清单

## 流程节点
1. **数据获取渠道识别** → 确定可用的雷达数据共享平台和接口
2. **数据格式规范理解** → 学习NetCDF数据格式规范和元数据要求
3. **数据预处理** → 执行数据清洗、格式转换、质量控制
4. **质量控制标准应用** → 应用气象行业标准进行数据质量评估
5. **数据存储与管理** → 按照规范存储和管理处理后的数据

## 边界与分流
- 当数据获取渠道不可用时：考虑使用替代数据源或模拟数据
- 当数据格式不兼容时：使用格式转换工具进行处理
- 当质量控制标准不明确时：参考气象行业标准文档

## 质量检查
- 数据完整性检查：确保所有必需字段存在
- 数据一致性检查：确保数据值在合理范围内
- 数据质量标记：对可疑数据进行标记

## 回退策略
- 使用模拟数据进行方法验证
- 参考公开的雷达数据样本进行测试
- 联系数据提供方获取技术支持
