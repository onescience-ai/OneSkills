# NowcastNet模型验证知识卡片

## 适用范围

### 触发条件
- 任务需要验证NowcastNet或类似深度学习临近预报模型
- 需要了解模型检查点加载和干运行验证
- 需要验证模型输入输出尺寸和成员采样接口

### 适用场景
- 雷达驱动的0-3小时极端降水集合临近预报
- 深度学习模型的推理前验证
- 模型集成与部署前检查

### 不适用场景
- 模型训练过程（本卡片聚焦验证）
- 数值天气预报模式（NWP）

## 输入

### 模型架构信息
| 模型 | 输入维度 | 输出维度 | 说明 |
|------|---------|---------|------|
| NowcastNet | (B,T_in,C,H,W) | (B,T_out,C,H,W) | B:batch, T:time, C:channel, H/W:height/width |
| DGMR | (B,T_in,C,H,W) | (B,T_out,C,H,W) | DeepMind扩散模型 |
| ConvLSTM | (B,T_in,C,H,W) | (B,T_out,C,H,W) | 经典循环卷积模型 |

### 检查点文件格式
| 格式 | 说明 | 用途 |
|------|-----|------|
| .pth (PyTorch) | PyTorch模型权重 | 模型加载 |
| .ckpt (Lightning) | PyTorch Lightning检查点 | 完整训练状态 |
| .safetensors | 安全张量格式 | 模型发布 |

### 输入数据契约
| 维度 | 值 | 说明 |
|------|-----|------|
| T_in | 4-6 | 历史帧数（约30分钟） |
| T_out | 12 | 预报帧数（约1小时） |
| C | 1-4 | 通道数（反射率/降水率） |
| H, W | 256×256 或 512×512 | 空间分辨率 |

## 输出

### 验证产物
- 模型加载成功/失败状态
- 输入输出尺寸匹配验证结果
- 成员采样接口可用性验证结果
- 干运行（dummy run）通过状态

### 验证标准
- 模型权重加载无错误
- 输入输出维度匹配预期
- 集合成员采样接口正常
- 干运行在1个样本上完成

## 流程节点

### 模型验证标准流程
```
模型架构加载 → 检查点读取 → 权重加载 → 输入维度检查 → 输出维度检查 → 干运行验证 → 验证报告
```

### 每步操作
| 步骤 | 操作 | 工具 | 参数 | 质量门禁 |
|------|------|------|------|---------|
| 1. 架构加载 | 导入模型类 | torch/huggingface | - | 类可导入 |
| 2. 检查点读取 | 加载.pth/.ckpt文件 | torch.load | map_location='cpu' | 文件可读 |
| 3. 权重加载 | 加载模型权重 | model.load_state_dict | strict=False | 权重匹配 |
| 4. 输入维度检查 | 验证输入张量形状 | torch.Tensor.shape | - | 维度匹配 |
| 5. 输出维度检查 | 验证输出张量形状 | torch.Tensor.shape | - | 维度匹配 |
| 6. 干运行验证 | 使用随机输入推理 | model.eval() | torch.no_grad() | 无错误 |

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 输入帧数T_in | 4 | [论文21] | 约24分钟历史 |
| 输出帧数T_out | 12 | [论文21] | 约72分钟预报 |
| 空间分辨率 | 256×256 | [论文32] | 常见输入尺寸 |
| 集合成员数 | 16-50 | [论文21] | 集合预报生成 |
| 模型参数量 | ~100M | [论文21] | NowcastNet参考 |

## 边界与分流

### 异常处理
| 异常情况 | 处理策略 | 降级方案 |
|---------|---------|---------|
| 检查点文件损坏 | 重新下载或使用备份 | 跳过该模型 |
| 维度不匹配 | 检查预处理流程 | 调整输入预处理 |
| GPU内存不足 | 使用CPU推理 | 降低batch size |

### 分支条件
- 若使用GPU推理：检查CUDA可用性
- 若使用CPU推理：确认模型支持CPU
- 若使用混合精度：验证FP16支持

## 质量检查

### 验证点
1. 模型权重加载：无错误
2. 输入维度：(B,4,1,256,256) 或 (B,4,4,256,256)
3. 输出维度：(B,12,1,256,256) 或 (B,12,4,256,256)
4. 干运行：输出张量非空、非NaN
5. 集合采样：能生成多个集合成员

### 阈值
| 指标 | 阈值 | 失败处理 |
|------|------|---------|
| 权重加载成功率 | 100% | 检查文件完整性 |
| 维度匹配率 | 100% | 调整预处理 |
| 干运行成功率 | 100% | 检查模型依赖 |

## 回退策略

1. **模型不可用**: 使用简化模型或基线方法
2. **维度不匹配**: 重新设计数据预处理流程
3. **GPU不可用**: 使用CPU推理（性能降低）
