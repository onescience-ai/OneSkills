# 气象预报独立验证执行规范

## 适用范围

**触发条件**：
- 完成预报产品生成，需要验证性能
- 需要评估预报准确率和技巧评分
- 业务预报系统验收或发布

**适用场景**：
- 临近预报系统验证（0-6小时）
- 数值天气预报模型评估
- 预报算法性能比较
- 业务预报质量监控

**不适用场景**：
- 模型训练过程中的验证（应使用验证集）
- 实时业务运行监控

## 输入

**输入数据**：
- 预报产品（gust_forecast.nc等）
- 独立验证数据集（observed data）
- 验证区域定义

**前置条件**：
- 验证数据集已预先划分
- 验证数据集未参与训练、调参或阈值选择
- 验证区域具有代表性

**数据要求**：
- 验证数据时间覆盖预报时效
- 空间分辨率与预报产品匹配
- 质量控制完成

## 输出

**输出产物**：
- 验证报告（independent_validation_report.md）
- 验证指标结果（verification_metrics.json）
- 验证图表（可选）

**格式标准**：
- 指标结果为JSON格式
- 报告包含完整计算过程

## 流程节点

### Step 1: 验证数据集准备
- **操作**：加载独立验证数据集
- **参数**：数据路径、时间范围、空间范围
- **工具**：xarray, numpy
- **质量门禁**：
  - 验证数据集与训练数据集无重叠
  - 数据完整性和质量确认

### Step 2: 预报-观测匹配
- **操作**：将预报结果与观测数据进行时空匹配
- **参数**：时间容差、空间插值方法
- **工具**：scipy.interpolate, xarray
- **质量门禁**：
  - 匹配点数满足统计要求
  - 时间戳对齐准确

### Step 3: 验证指标计算
- **操作**：计算标准验证指标
- **参数**：指标选择、阈值设置
- **工具**：自定义计算脚本
- **计算公式**：

**命中率 (POD, Probability of Detection)**:
```
POD = hits / (hits + misses)
```
- hits: 预报命中次数
- misses: 漏报次数

**虚报率 (FAR, False Alarm Ratio)**:
```
FAR = false_alarms / (hits + false_alarms)
```
- false_alarms: 虚报次数

**临界成功指数 (CSI, Critical Success Index)**:
```
CSI = hits / (hits + misses + false_alarms)
```

**均方根误差 (RMSE)**:
```
RMSE = sqrt(mean((forecast - observation)^2))
```

### Step 4: 结果解释与报告生成
- **操作**：解释验证结果，生成报告
- **参数**：业务标准阈值、基准线对比
- **工具**：报告生成模板
- **质量门禁**：
  - 指标值在合理范围内
  - 报告包含完整计算过程

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| POD目标值 | ≥ 0.80 | 业务规范 | 命中率最低要求 |
| FAR目标值 | ≤ 0.20 | 业务规范 | 虚报率最高限制 |
| CSI目标值 | ≥ 0.70 | 业务规范 | 综合技巧评分 |
| 验证数据独立性 | 强制 | 归因报告 | 不参与训练/调参 |
| 最少匹配点数 | ≥ 30 | 统计要求 | 确保统计显著性 |
| 时间容差 | ≤ 5min | 业务规范 | 时间匹配精度 |

## 边界与分流

**异常处理**：
- 验证数据不足：扩大验证区域或时间范围
- 指标计算异常：检查数据匹配和阈值设置
- 结果不合理：回溯检查数据和计算过程

**降级策略**：
- 完整验证不可用：执行部分验证并说明限制
- ⚠️ 禁止使用模拟验证结果替代真实验证

**分支条件**：
- 分类预报：计算POD/FAR/CSI
- 连续预报：计算RMSE/MAE相关系数

## 质量检查

**验证点**：
1. 验证数据独立性确认
2. 指标计算结果合理性检查
3. 报告完整性验证

**阈值**：
- POD ≥ 0.80（命中率）
- FAR ≤ 0.20（虚报率）
- CSI ≥ 0.70（综合评分）
- RMSE在物理合理范围内

**失败处理**：
- 指标未达标：分析原因，提供改进建议
- 验证失败：报告详细错误信息

## 回退策略

**失败时的替代方案**：
- 独立验证数据不可用：记录并报告，等待数据
- 验证指标异常：检查预报和观测数据质量
