# 光伏功率预测数据来源与时点规则

## 适用范围

光伏功率预测任务的数据获取、时点合规性检查和缺失处理。适用于0-48小时功率联合预报场景，涵盖数据来源识别、签发时点验证、数据缺失降级等环节。

## 输入

- **任务需求**：预测目标（单站/多站）、预测时效（0-48h）
- **数据清单**：天气预报、历史功率、电站属性等
- **时间约束**：任务签发时间、预测目标时段

## 输出

- **数据可用性报告**：各数据源的获取状态和时点合规性
- **降级策略**：数据不可用时的处理方案
- **BLOCKED状态**：无法获取必需数据时的阻塞报告

## 流程节点

### 1. 数据源识别与分类

**必需数据源**：
| 数据类型 | 来源 | 时点要求 |
|----------|------|----------|
| 天气预报数据 | 气象局签发的预报产品 | 签发时已可获得 |
| 历史功率数据 | 电站SCADA系统 | 历史数据（无时点限制） |
| 电站属性数据 | 电站设计文档 | 静态数据（无时点限制） |
| 辐照度数据 | 气象观测或卫星反演 | 签发时已可获得（实况）或预报值 |

**辅助数据源**（可选）：
- 云图数据（卫星实时观测）
- 地形数据（DEM）
- 组件参数（PVLib数据库）

### 2. 数据时点规则（核心约束）

**签发时可获得的数据**：
- 定义：在任务签发时刻（T_issue）已经存在或已签发的数据
- 允许使用：T_issue 之前签发的天气预报、历史观测数据
- 禁止使用：T_issue 之后才签发的预报或观测

**示例**：
- 任务签发时间：2024-01-15 08:00
- 预测目标时段：2024-01-15 10:00 - 2024-01-17 08:00（48小时）
- 可用天气预报：2024-01-15 08:00之前签发的预报
- 禁止使用：2024-01-15 08:00之后签发的预报（即使是针对目标时段的）

**违反时点规则的后果**：
- 验证结果无效，不可用于业务判定
- 模型性能评估失真（使用了"未来信息"）

### 3. 数据缺失处理流程

**步骤1：评估缺失影响**
- 缺失数据类型（天气预报 vs 历史功率 vs 电站属性）
- 缺失时段（全部 vs 部分）
- 缺失原因（数据源不可用 vs 网络问题 vs 格式问题）

**步骤2：选择降级策略**
| 缺失类型 | 降级策略 | 适用条件 |
|----------|----------|----------|
| 天气预报缺失 | 使用持久性预报或气候平均 | 短时预测（<6h） |
| 历史功率缺失 | 使用相似电站数据迁移 | 有相似电站可用 |
| 辅助数据缺失 | 使用PVLib默认参数 | 参数敏感性低 |
| 全部数据缺失 | 标记BLOCKED | 无法执行任务 |

**步骤3：BLOCKED状态处理**
- 生成阻塞报告，说明缺失数据类型和原因
- 不使用模拟数据替代真实数据
- 记录阻塞原因，等待数据可用后重新执行

### 4. 数据质量预检

**完整性检查**：
- 缺测率 < 5%（可接受），> 20%（不可接受）
- 连续缺测 < 2小时（可接受），> 6小时（需标注）

**一致性检查**：
- 功率值范围：[0, P_installed]
- 温度值范围：[-30°C, 50°C]
- 辐照度值范围：[0, 1400 W/m²]

**时效性检查**：
- 历史数据时间戳与预报数据对齐
- 时区一致性（UTC vs 本地时间）

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 缺测率可接受阈值 | <5% | [1] | 超过需标注数据质量 |
| 连续缺测阈值 | <2小时 | [1] | 超过需降级处理 |
| 功率范围 | [0, P_installed] | [2] | 物理约束 |
| 温度范围 | [-30°C, 50°C] | [2] | 常规气象范围 |
| 辐照度范围 | [0, 1400 W/m²] | [2] | 地球表面最大值 |

### 校准数值（供参考）
以下数值来自瑞士和尼日利亚的光伏预测研究[1][2]，其他体系需以自身证据重新锚定：
| 数据源 | 典型延迟 | 可用性 | 备注 |
|--------|----------|--------|------|
| 卫星辐照度 | <15分钟 | 95-99% | 需要地面校准 |
| NWP预报 | 6-12小时 | 90-95% | 空间分辨率有限 |
| SCADA功率 | <5分钟 | 98-99% | 依赖通信系统 |
| PVLib参数 | 静态 | 100% | 默认值需验证 |

## 边界与分流

**数据源不可用时**：
- 天气预报缺失 → 降级为持久性预报，适用于超短期（<6h）
- 历史功率缺失 → 使用相似电站数据迁移学习[3]
- 电站属性缺失 → 使用PVLib默认参数，需标注不确定性

**数据质量问题**：
- 异常值检测：使用3σ原则或IQR方法
- 缺测插补：线性插值（<30分钟）或气象均值填充（>30分钟）

**数据时点违规**：
- 发现使用未来数据 → 立即停止，标记BLOCKED
- 验证结果中发现时点违规 → 验证结果无效

## 质量检查

- **数据源完整性**：是否列出了所有必需数据源
- **时点合规性**：是否检查了所有数据的签发时点
- **质量预检**：是否执行了完整性、一致性、时效性检查
- **降级策略**：是否为每种缺失场景准备了降级方案
- **BLOCKED处理**：是否正确处理了数据不可用的情况

## 回退策略

- 若主要数据源不可用，可使用降级策略（持久性预报）
- 若所有降级策略均不可行，标记BLOCKED等待数据
- 若数据质量问题严重，降低验收门限并标注
