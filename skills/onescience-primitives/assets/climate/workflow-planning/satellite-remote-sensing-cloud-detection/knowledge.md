# 卫星遥感云检测

## 适用范围
用于从卫星遥感影像中自动化识别并分割云覆盖区域，生成云掩膜或云概率图，是遥感影像预处理的通用关键步骤。该流程适用于多光谱、高光谱等各类星载传感器影像，服务于后续地表参数反演、土地利用变化检测、大气校正等定量遥感应用。典型场景包括应对不同地理位置、季节、地表类型（如沙漠、雪冰、海洋）及大气条件（如晴空、薄云、雾、霾）下的云检测挑战。

## 输入
- 必需输入：
  - `satellite_data`：待检测的卫星遥感影像（如 MODIS、Sentinel-2、Landsat-8、高分系列等），通常为包含多个波段的数字影像。
- 可选输入：
  - `training_data`：若采用监督学习方法（如 SVM、CNN），则需要准备带有云/非云像素标注的训练数据集。
  - 参考云图或地面观测数据：用于验证阶段，以评估检测精度。

## 输出
- 云掩膜：二值图（云/非云）或多类图（如薄云、厚云、云影、雪、晴空）。
- 云概率分布图：每个像素属于云的概率值（0-1）。
- 云定量参数（可选）：如云高、云光学厚度、云顶温度等，通常需要借助特定的反演算法从云掩膜和辐射数据中提取。

## 流程节点
1.  **影像获取与预处理** (`s1`)
    *   **描述**：获取多源卫星遥感影像数据。可能包含大气校正、几何校正等初步预处理，以将原始数据转换为可用于分析的反射率或亮温产品。
    *   **上游依赖**：无。
    *   **输入参数**：
        - `satellite_data` (str): 卫星数据源标识符，例如 'MODIS', 'Sentinel-2', 'Landsat-8', 'GaoFen' 等。必填。
    *   **输出**：待检测的遥感影像。
    *   **质量门**：暂无。

2.  **云特征提取与分析** (`s2`)
    *   **描述**：基于云的物理或光学属性，从影像中提取用于区分云与地表的特征。云的特征可来源于其物理参数（如形状、颜色、密度）或光学属性（如光谱反射率、亮度温度）。
    *   **上游依赖**：`s1`。
    *   **输入参数**：
        - `features` (enum): 待提取的特征类型。可选值包括 '光谱特征'、'纹理特征'、'形状特征'、'多尺度卷积特征'、'偏振特征'。必填，默认为 '多光谱特征'。选择需根据具体检测目标（如区分云与雪）。
    *   **输出**：特征图或特征向量，作为下一步分类器的输入。
    *   **质量门**：暂无。

3.  **云检测模型/算法应用** (`s3`)
    *   **描述**：应用选定的云检测算法。常见方法包括基于固定或自适应阈值的方法、传统机器学习分类器（如 SVM、决策树、随机森林）或深度学习模型（如 CNN、U-Net）。
    *   **上游依赖**：`s2`。
    *   **输入参数**：
        - `method_type` (enum): 检测方法类型。可选值包括 '阈值法'、'机器学习'、'深度学习'、'混合方法'。必填，默认为 '机器学习'。阈值法通用性较差；机器学习和深度学习方法依赖训练数据的质量和数量。
        - `training_data` (str): 监督学习方法所需的训练数据集路径或标识。当 `method_type` 为 '机器学习' 或 '深度学习' 时为必需。
    *   **输出**：初步的云掩膜或云概率图。
    *   **质量门**：暂无。

4.  **后处理与验证** (`s4`)
    *   **描述**：对初步检测结果进行精炼，并与外部参考数据进行精度验证。后处理步骤可能包括形态学滤波（消除椒盐噪声）、区域生长（填充云内部空洞）或云影补偿。
    *   **上游依赖**：`s3`。
    *   **输入参数**：无。
    *   **输出**：最终的云检测结果（云掩膜、云概率图等）。
    *   **质量门**：与参考数据（如人工解译云图、地面观测）对比，精度指标（如总体精度、Kappa系数、F1-score）需达到应用要求的阈值（例如总体精度 > 90%）。

## 边界与分流
- **方法选择**：
    - **阈值法**：适用于场景简单、大气条件均一且对通用性要求不高的快速处理。当影像覆盖不同地理位置、季节或地表类型复杂时，固定阈值易失效，应转向机器学习或混合方法。
    - **机器学习（如 SVM、随机森林）**：需要具有代表性的标注样本。适用于有可用训练数据，且计算资源有限的场景。
    - **深度学习（如 CNN）**：能自动学习复杂特征，在云边界精细化和薄云检测方面潜力大，但需要大量高质量标注数据和较强的算力支持。
    - **混合方法**：推荐将物理模型（大气参数检索）、机器学习与地面验证相结合，以克服单一方法的局限性，提高检测的鲁棒性和精度。
- **数据与场景分流**：
    - 当影像中存在大量高反射率地表（如沙漠、冰雪）时，云与地表的光谱混淆严重，需特别增强特征区分能力（例如引入热红外波段信息）或使用针对性训练的模型。
    - 当目标为区分云与云影时，特征提取需加入空间关系信息（如形状、相对位置）。
    - 缺乏训练数据时，可优先考虑阈值法或无监督学习方法作为起点。

## 质量检查
- **内部检查**：检查生成的云掩膜在视觉上是否合理，边缘是否平滑，是否明显存在大量碎云误判或漏判。
- **精度验证**：使用独立的验证数据集（如人工判读云图、更高分辨率影像的云产品）计算混淆矩阵，评估以下指标：
    - 总体精度（Overall Accuracy）
    - Kappa系数
    - 云检测的精确率（Precision）、召回率（Recall）和 F1-score
    - 针对特定类别（如薄云、云影）的精度
- **跨传感器/时相一致性检查**：对同一区域不同时相或不同传感器的影像，检查云检测结果是否具有一致性，以评估算法的稳定性。

## 回退策略
- **阈值法失效**：若因场景复杂导致固定阈值检测效果差，应回退至步骤2和3，更换为机器学习或深度学习方法；或构建自适应阈值模型（如结合局部统计特征）。
- **模型泛化能力差**：若机器学习/深度学习模型在新场景下误判率高，说明训练数据分布不足。应回退至步骤3，使用更多样化、更具代表性的数据重新训练模型，或采用迁移学习、域自适应技术。
- **大气条件干扰**：当雾、霾等大气状况严重影响影像质量导致检测误差大时，可考虑回退至步骤1，先进行大气校正预处理；或使用对大气影响相对不敏感的波段组合（如热红外与可见光比值）。
- **缺乏验证数据**：若无可靠的验证数据集，应明确标注结果未经验证，并建议用户在使用时结合目视解译或其他辅助数据进行质控。可尝试使用交叉验证、时间序列一致性检查等内部评估方法作为临时替代。

## 资源召回建议
- **经典算法**：Fmask（针对 Landsat 和 Sentinel-2）、ACCA（Automated Cloud Cover Assessment，针对 Landsat）、MOD35（针对 MODIS）。
- **机器学习工具**：支持向量机（SVM）库、随机森林实现、XGBoost 等。
- **深度学习框架**：TensorFlow、PyTorch，结合 U-Net、DeepLabV3+ 等语义分割网络架构用于云分割。
- **特征融合技术**：多尺度卷积特征融合（MSCFF）等，用于增强模型对不同尺度云的检测能力。
- **数据集**：可利用公开的遥感云检测基准数据集（如 Landsat-8 云检测数据集、Sentinel-2 云掩膜数据集）进行模型训练与评估。
