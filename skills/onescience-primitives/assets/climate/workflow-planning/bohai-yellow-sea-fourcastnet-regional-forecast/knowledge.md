# 渤黄海FourCastNet区域大气智能预报模型（E107）

## 适用范围

**适用场景**：
- 任务确为FourCastNet的渤黄海区域化预报，且能获得兼容的全球模型工件、区域再分析和大区域边界产品。
- 目标变量、网格、时效和独立验证协议已冻结，目标GPU环境能够运行所选实现。

**不适用场景**：
- 任务只需要WRF产品偏差订正而不需要FourCastNet区域化预报。
- 无法获得可用的FourCastNet模型工件、区域训练数据或边界产品，且任务范围不能调整。
- 目标是原始观测资料同化、集合概率预报或气候长期模拟。

## 研究对象与输入

## 核心科学问题

1. 全球FourCastNet的变量、网格和时间步能否与渤黄海再分析及边界产品一致对齐？
2. 区域化与边界约束后能否在不少于72小时的滚动预报中保持时空连续和物理合理？
3. 风速误差能否在冻结的独立样本和指标协议下达到不高于2.2 m/s？
4. 模型在目标曙光GPU集群的72小时预报计算是否在冻结的计时口径下不超过1分钟？

## 验收标准与质量门禁

### 硬约束（不可违反）

- 保留FourCastNet基于自适应傅里叶神经算子的基础架构和区域化移植目标；架构实质变更须写入任务配置。
- 必须引入s02冻结版本的大区域预报产品作为渤黄海区域边界约束，并记录边界生成、更新和使用方式。
- 训练与微调使用公开数据和已授权任务数据，30年资料的实际年份、版本和缺测须核验。
- 正式部署和性能计时须在目标曙光GPU集群完成。

### 最低证据要求

- 实际输入、任务范围和产品定义与冻结后的任务口径一致；所有偏离均有变更记录和配置版本。
- 为核验精度指标，独立验证样本须与模型开发或配置、参数选择和阈值选择隔离，业务回放不得使用当时尚未获得的资料。
- 源代码、与所选方法一致的可执行模型工件（训练后权重、数值模型配置或两者）、部署测试、预报产品和全套技术文档均可定位并重新读取。
- 模型能在目标GPU环境正常部署，支持移植和二次调优。
- 预报范围覆盖s02冻结的渤黄海区域，目标水平分辨率优于3 km、预报时效不少于72小时、输出间隔1小时。
- 按冻结的独立协议计算，风速误差不高于2.2 m/s。
- 在目标GPU集群上，72小时预报计算用时按冻结口径不超过1分钟。
- 模型能正常部署、移植和二次调优，并交付源代码与全套技术文档。
- 未冻结公式、验证集或基线的定性要求不能据此判定性能PASS。
- 部署、试运行、精度和计算性能分别提供证据，任一项通过不能替代其他项。

**验收判定**：agent必须对每项交付给出PASS、PARTIAL、REJECT或BLOCKED，并附可定位的数据、模型、日志、产品、图表、指标或哈希证据；只有满足冻结后的独立验证协议与阈值时才能判定性能PASS。

## 边界与限制

- 全球FourCastNet区域化、渤黄海再分析迁移学习、大区域边界约束和区域大气预报产品生成。

- 模型开发或配置、参数选择、独立验证和业务试运行资料是否按用途隔离，指标、基线、样本范围和统计方法是否已经冻结。
- 目标GPU环境的节点、加速卡、驱动、框架、存储、调度和计时边界是否足以复现实效要求。

**信息缺失策略**：若必需输入、变量定义、资料截止时间、基线、验证数据或指标公式缺失，agent必须列出缺口、影响和最小补充信息；可由执行方案决定的口径由agent在s02依据任务目标、实际输入和科学合理性选择单一可执行方案、记录理由并冻结。只有必要数据缺失或无法形成科学上可辩护的口径时才标记BLOCKED；未冻结前不得宣称性能PASS。

## 必要结果项

- **input_data_result**：输入数据与版本清单、时空和变量覆盖、单位与坐标、质量与缺测报告、资料截止时间、用途划分、样本索引及数据血缘。
- **core_result**：按s02冻结方案训练和微调得到的区域FourCastNet模型、配置、检查点、训练记录、边界约束实现记录和渤黄海预报结果。
- **product_result**：可重新读取的渤黄海逐小时多要素预报场，附变量、单位、坐标、网格、有效时间、边界质量标志、文件清单和校验信息。
- **validation_result**：在独立验证集上按区域、变量和提前期报告误差与基线比较，至少对风速误差≤2.2 m/s和运行时限给出可复核判定。
- **uncertainty_and_limit_result**：报告观测与再分析误差、抽样误差、方法随机性、边界或驱动不确定性、外推和适用域限制；无法量化的项目须说明原因和影响。
- **结论结果**：给出区分已验证结果、探索性观察、未通过项和因任务条件缺失而无法判定事项的结论，不得把结构完整或运行正常等同于业务性能通过。
