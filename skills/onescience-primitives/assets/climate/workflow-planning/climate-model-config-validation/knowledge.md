# 模型配置验证方法

## 适用范围

**触发条件**：
- 使用预训练模型进行推理
- 需要确保推理结果可复现
- 模型配置参数需要冻结和验证

**适用场景**：
- 气象模型推理前的配置验证
- 业务预报系统的模型部署
- 科研论文的可复现性要求

**不适用场景**：
- 模型训练过程（非推理阶段）
- 无需配置验证的简单后处理

## 输入

**输入数据**：
- 模型权重文件（checkpoint）
- 模型配置文件（config.yaml/json）
- 测试输入数据（最小样本）

**前置条件**：
- 模型权重文件存在且可访问
- 配置文件格式正确

## 输出

**输出产物**：
- method_artifact_identity_report（方法工件身份报告）
- dry_run_log（干运行日志）
- 配置验证结果

**格式标准**：
- JSON格式的身份报告
- 文本格式的干运行日志

## 流程节点

### Step 1: 模型权重版本确认
- **操作**：验证模型权重文件的完整性和版本
- **参数**：权重文件路径、预期版本/哈希
- **工具**：文件系统检查、哈希计算
- **质量门禁**：
  - 文件存在且大小合理
  - 版本/哈希匹配预期值
  - 文件可正常加载

### Step 2: 参数冻结
- **操作**：锁定所有配置参数
- **参数**：模型架构参数、训练超参数、随机种子
- **工具**：配置管理器
- **质量门禁**：
  - 所有参数已序列化
  - 参数值已记录

### Step 3: 随机种子设置
- **操作**：设置并记录随机种子
- **参数**：Python random、NumPy、PyTorch/TensorFlow种子
- **工具**：随机种子管理器
- **质量门禁**：
  - 种子值已记录到配置报告
  - 随机数生成可复现

### Step 4: 输入输出契约检查
- **操作**：验证模型输入输出维度和格式
- **参数**：预期输入形状、输出形状、数据类型
- **工具**：维度检查器
- **质量门禁**：
  - 输入维度匹配模型期望
  - 输出维度符合预期
  - 数据类型正确

### Step 5: 最小干运行测试
- **操作**：使用最小输入数据执行推理
- **参数**：最小输入尺寸（如1个时间步、小区域）
- **工具**：模型推理引擎
- **质量门禁**：
  - 推理完成无错误
  - 输出文件生成成功
  - 输出值在合理范围

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 干运行输入尺寸 | 最小可用 | 归因报告 | 验证可执行性 |
| 随机种子 | 固定值 | 归因报告 | 确保可复现 |
| 权重版本 | 必须确认 | 归因报告issue#4 | 避免版本混淆 |
| 参数冻结 | 强制 | 归因报告 | 防止意外修改 |
| 推理时间 | 记录 | 业务要求 | 性能基准 |
| 输出验证 | 数值范围 | 物理约束 | 合理性检查 |

## 边界与分流

**异常处理**：
- 权重文件损坏：重新下载或使用备份
- 参数不匹配：检查配置文件版本
- 干运行失败：检查依赖和环境

**降级策略**：
- 干运行失败：停止执行，报告错误
- ⚠️ 禁止跳过配置验证步骤

**分支条件**：
- GPU可用时：验证GPU兼容性
- CPU模式时：验证CPU推理路径

## 质量检查

**验证点**：
1. 权重文件完整性检查
2. 参数冻结确认
3. 随机种子可复现性验证
4. 干运行成功完成

**阈值**：
- 权重文件大小：> 0（非空）
- 干运行成功率：100%
- 输出值范围：符合物理意义

**失败处理**：
- 任一验证失败：停止执行
- 记录详细错误信息

## 回退策略

**失败时的替代方案**：
- 权重不可用：使用已知可用的备份版本
- 环境不兼容：检查依赖版本，必要时降级
- 干运行超时：简化输入或增加超时时间
