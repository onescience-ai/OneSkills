# 对流初生检测独立验证协议

## 适用范围

**触发条件**：
- 已完成对流初生检测算法开发或训练
- 需要评估算法在真实场景中的性能
- 需要使用独立于训练数据的验证资料

**适用场景**：
- 对流初生检测工作流中的验证阶段
- 算法性能评估与比较
- 业务化前的验证测试

**不适用场景**：
- 模型训练过程中的交叉验证（使用训练数据子集）
- 无独立验证资料时的性能估计
- 实时业务运行中的在线验证

## 输入

**输入数据格式**：
- 检测结果数组（二分类：检测到/未检测到）
- 真实标签数组（来自独立验证资料）
- 时间与空间坐标信息

**数据来源**：
- 雷达回波数据（反射率 > 40 dBZ）
- 闪电定位数据
- 其他卫星传感器数据（如MODIS）
- 人工标注数据

**预处理要求**：
- 验证资料与检测结果时空匹配
- 空间分辨率与时间分辨率对齐
- 标签定义一致（如CI事件定义）

## 输出

**输出产物**：
- 验证报告（JSON格式）
- 混淆矩阵（TP, FP, TN, FN）
- 性能指标（POD, FAR, CSI, Accuracy）

**验证标准**：
- 验证资料独立于训练数据
- 样本数量足够（≥100个事件）
- 时空匹配误差在可接受范围内

## 流程节点

### Step 1：独立验证资料获取
- **操作**：获取独立于训练数据的验证资料
- **参数**：资料类型=[雷达, 闪电, 其他卫星], 时间范围, 空间范围
- **工具**：数据下载脚本，API调用
- **质量门禁**：资料独立性确认，数据质量检查

### Step 2：时空匹配
- **操作**：将检测结果与验证资料对齐
- **参数**：时间容差=15分钟，空间容差=4km
- **工具**：pandas、xarray
- **质量门禁**：匹配成功率 ≥ 90%

### Step 3：混淆矩阵计算
- **操作**：计算TP, FP, TN, FN
- **参数**：匹配规则=[精确匹配, 邻域匹配]
- **工具**：numpy、sklearn.metrics
- **质量门禁**：矩阵元素合理（非负整数）

### Step 4：性能指标计算
- **操作**：计算POD, FAR, CSI等指标
- **参数**：指标列表=[POD, FAR, CSI, Accuracy, F1-score]
- **工具**：sklearn.metrics
- **质量门禁**：指标值在[0,1]范围内

### Step 5：不确定性估计
- **操作**：估计验证结果的不确定性
- **参数**：方法=[Bootstrap, 置信区间]
- **工具**：scipy.stats, numpy
- **质量门禁**：置信区间宽度合理

### Step 6：验证报告生成
- **操作**：生成结构化验证报告
- **参数**：报告格式=JSON
- **工具**：json模块
- **质量门禁**：报告包含所有必要字段

## 关键参数

**通用判据（方法层）**：

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| POD | TP/(TP+FN) | [1] | 检出率，越高越好 |
| FAR | FP/(TP+FP) | [1] | 误报率，越低越好 |
| CSI | TP/(TP+FP+FN) | [1] | 综合性能，越高越好 |
| Accuracy | (TP+TN)/(TP+FP+TN+FN) | [1] | 总体准确率 |
| F1-score | 2*Precision*Recall/(Precision+Recall) | [1] | 精确率与召回率调和平均 |

**校准数值（体系专属）**：

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 时间容差 | 15分钟 | 领域知识 | 静止卫星时间分辨率 |
| 空间容差 | 4km | 领域知识 | 静止卫星空间分辨率 |
| 最小样本量 | 100个事件 | 领域知识 | 统计显著性要求 |
| 雷达反射率阈值 | 40 dBZ | 领域知识 | 对流事件定义 |

## 边界与分流

**关键前提不成立时的改道**：
- 无独立验证资料 → 使用交叉验证但明确说明限制
- 验证资料质量差 → 降低置信度，增加不确定性估计
- 样本量不足 → 使用更保守的性能估计
- 时空匹配困难 → 放宽容差但记录影响

## 质量检查

**验证点**：
1. 验证资料独立性确认
2. 时空匹配成功率 ≥ 90%
3. 混淆矩阵元素合理
4. 性能指标计算正确
5. 不确定性估计合理

**阈值**：
- POD ≥ 0.7（可接受检出率）
- FAR ≤ 0.3（可接受误报率）
- CSI ≥ 0.5（可接受综合性能）

**失败处理**：
- 性能不达标 → 重新检查算法或数据
- 验证资料不足 → 降低评估置信度

## 回退策略

**失败时的替代方案**：
- 使用模拟数据进行初步验证（但明确说明限制）
- 使用专家评估替代定量验证
- 降级为定性性能描述
