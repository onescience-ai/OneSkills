# MetNet-2 训练数据集创建与划分协议

## 适用范围

适用于深度学习气象预报模型（尤其是基于雷达和卫星数据的短临降水预报模型）的训练数据集构建。当模型需要多源输入（如雷达回波、卫星图像、天气状态）和基于雷达估计的降水输出时，使用此协议创建无数据泄露的训练、验证和测试数据集。触发条件包括：从连续气象观测流中准备监督学习数据，要求数据在时间上独立划分，并在空间上随机采样以提升泛化性。

## 输入

- 必需输入：
  - 雷达数据（radar data）：提供降水反射率信息。
  - 卫星数据（satellite data）：提供云层、湿度等补充观测。
  - 天气状态数据（weather state data）：包括温度、风速、气压等气象变量。
- 可选输入：
  - 其他衍生气象场（如再分析数据、模式输出）。
  - 时间戳元数据，用于确保时间对齐。

输入格式通常为网格化时间序列，覆盖特定区域（如CONUS）。所有输入必须在相同时间分辨率和空间网格上对齐。

## 输出

- 训练数据集（training dataset）：用于模型参数学习的大规模数据集。
- 验证数据集（validation dataset）：用于超参数调优和早期停止。
- 测试数据集A和B（test datasets A and B）：用于最终模型评估的两个独立数据集，确保性能估计无偏。

每个数据集均以输入-输出对形式组织，输出为雷达降水估计（作为ground truth）。数据以标准化格式（如NetCDF、TFRecord）存储，便于直接加载到训练管道。

## 流程节点

该协议由三个顺序步骤组成，构成一个DAG（有向无环图），每步有明确依赖和输出。以下详细描述每个节点：

1. **s1: 收集数据对**
   - **步骤描述**：获取从起始日期到结束日期的连续输入-输出对数据。输入包括雷达、卫星和天气状态数据，输出为雷达降水估计。
   - **依赖**：无（起始节点）。
   - **输入参数**：起始日期（如`start_date`，格式YYYY-MM-DD）、结束日期（`end_date`）、数据源路径（`data_source`）。
   - **输出**：原始时间序列数据对。
   - **质量门**：数据完整性检查，确保时间连续无缺失。

2. **s2: 进行时间序列划分**
   - **步骤描述**：按照连续、无重叠的原则分配训练、验证和测试时间段。典型划分包括训练集（例如400小时）、验证集（12小时）、测试集A（40小时）和测试集B（40小时）。在不同集之间插入间断期（如12小时）以避免数据泄露。
   - **依赖**：s1（需要原始数据对）。
   - **输入参数**：划分比例（`split_ratios`）、间断期长度（`gap_hours`）、随机种子（`seed`）。
   - **输出**：时间序列划分方案，定义每个数据集的时间段。
   - **质量门**：无时间重叠——确保训练、验证和测试的时间段严格不重叠，且间断期插入正确。
   - **提示词模板**："根据给定的`split_ratios`和`gap_hours`，将连续时间段划分为训练、验证和测试集，确保各集间无时间重叠。"

3. **s3: 执行空间采样**
   - **步骤描述**：从覆盖区域（如CONUS网格）中随机采样空间补丁，为每个划分生成最终数据集。采样包括随机选择空间位置和固定补丁尺寸（如64×64像素）。
   - **依赖**：s2（需要时间划分方案）。
   - **输入参数**：采样区域（`region`）、补丁尺寸（`patch_size`）、采样数量（`num_samples`）、随机种子（`seed`）。
   - **输出**：训练数据集、验证数据集、测试数据集A和B。
   - **质量门**：空间采样随机性检查，确保补丁分布均匀，无系统性偏差。
   - **提示词模板**："对每个时间划分，从`region`网格中随机采样`num_samples`个尺寸为`patch_size`的空间补丁，生成独立数据集。"

流程执行顺序为s1 → s2 → s3，任何步骤失败需回退。

## 边界与分流

- 适用场景：此协议适用于基于雷达和卫星数据的降水短临预报（如1-12小时预报），数据具有连续时间序列和网格化空间结构。当模型需要无泄露的数据划分时使用。
- 不适用场景：
  - 对于单时次静态图像任务，无需时间序列划分，可改用随机空间采样协议。
  - 对于非气象领域（如医学图像），尽管类似数据划分思想可用，但输入数据类型和预处理不同，需适配领域特定管道。
- 上下游衔接：上游依赖数据采集和预处理（如质量控制、网格化），下游对接模型训练框架（如TensorFlow、PyTorch）的数据加载器。
- 替代方案：当时间数据不连续或空间覆盖有限时，可考虑基于k-fold交叉验证的划分方法，但需注意时间依赖性。

## 质量检查

- 时间划分验证：检查各数据集时间段是否重叠，间断期是否按要求插入。可通过时间戳排序和间隙检测算法实现。
- 空间采样验证：检查随机补丁是否均匀覆盖目标区域，避免热点偏差。使用统计检验（如均匀性检验）或可视化检查。
- 数据完整性：确保每个输入-输出对无缺失值，时间对齐正确（误差在允许范围内，如1分钟）。
- 泄露检测：运行时监控训练数据是否包含验证/测试时间的信息，可使用滑动窗口方法抽查。

## 回退策略

- 数据不足：如果收集的数据时间跨度短于所需最小训练长度（如400小时），可缩减训练集规模或延长数据采集周期，但需确保验证和测试集仍满足最小时间要求（如12小时）。
- 时间重叠错误：如果发现数据集间时间重叠，重新执行s2步骤，调整划分参数或增加间断期长度。
- 空间采样失败：如果目标区域网格数据不完整，可扩大采样区域或使用插值补全，但需记录插值方法以保证可复现性。
- 工具故障：使用Python库（如pandas、xarray）处理时间序列时，若内存不足，可分批次处理或升级硬件。

## 资源召回建议

- 数据源：
  - 气象数据库：如NOAA的NEXRAD雷达数据、NASA的卫星数据（如GOES）、ERA5再分析数据。
  - 公开数据集：如MetNet系列使用的CONUS降水估计数据集。
- 工具：
  - 数据处理：Python库pandas（时间序列操作）、xarray（多维网格数据）、numpy（数组计算）。
  - 格式转换：netCDF4（气象数据标准格式）、tensorflow.data（构建输入管道）。
  - 可视化：matplotlib、cartopy（空间绘图）。
- 模板：可参考开源代码库（如GitHub上的气象数据预处理脚本），但需根据具体数据源调整。
- 扩展：对于多模型训练，可复用此协议生成多个数据集变体（如不同空间补丁大小），通过参数化脚本实现。
