# 水文预报偏差校正协议

## 适用范围
用于校正全球或区域水文模型（如GloFAS）输出的径流预报中的系统性偏差。当原始物理模型预报存在稳定的统计偏差（如系统性偏高或偏低），且有充足的同期历史观测数据可用于校准参数时，该协议适用。它属于混合预报框架中统计后处理环节的一种具体实现，旨在提升预报在后续水文决策（如洪水预警、水资源调度）中的可用性。

## 输入
- 必需输入：
  1.  **原始模型预报数据**：来自目标水文模型（如GloFAS）的径流预报时间序列，通常为逐网格点输出。
  2.  **观测径流数据**：与预报网格点对应或可用的历史实测径流记录，用于计算校正参数。
  3.  **时间范围划分**：明确的训练期（用于建立映射函数和优化系数）和验证期/操作期（用于检验和应用校正）。

## 输出
- **偏差校正后的径流预报**：经过空间合并和操作微调的最终站点级径流预报时间序列。相较于原始模型输出，其统计指标（如偏差、相关性、技能评分）预期得到改善。

## 流程节点
该偏差校正协议包含三个顺序执行的步骤，构成一个有向无环图（DAG）：

1.  **步骤 s1: 分位数映射校正**
    *   **步骤ID**：`s1`
    *   **描述**：使用训练期数据，对每一个预报网格点独立建立分位数映射函数。该函数将模型预报值的累积分布函数（CDF）映射到对应观测值的CDF上，从而校正系统性的幅度偏差。
    *   **上游依赖**：无（起始步骤）。
    *   **输入参数**：
        *   `glofas_era5` (类型：数组): GloFAS-ERA5历史预报数据。用于建立模型预报的累积分布函数。
        *   `observations` (类型：数组): 对应时期的观测径流数据。用于建立观测值的累积分布函数。
    *   **输出**：分位数映射后的网格点径流值序列。
    *   **质量门**：映射函数基于训练期数据建立，并应适用于验证期数据以检验其外推能力。在操作预报中，当预报值超出训练期分布范围时，需谨慎处理。

2.  **步骤 s2: 空间优化合并**
    *   **步骤ID**：`s2`
    *   **描述**：将目标站点周围多个（例如36个）网格点的分位数映射后预报值，通过一个优化的线性组合合并为单个站点预报值。优化目标为最大化综合技能评分，例如最小化负的Kling-Gupta效率（KGE）与Nash-Sutcliffe效率（NSE）之和。
    *   **上游依赖**：`s1`。
    *   **输入参数**：
        *   `quantile_mapped_values` (类型：数组): 来自步骤`s1`的多个网格点校正后的径流值。
    *   **输出**：空间优化后的单站点径流预报。
    *   **质量门**：优化得到的线性组合系数 `a_i` 需满足 `0 ≤ a_i ≤ 1` 的约束，以确保物理意义的合理性。优化过程通常在训练期数据上进行，并通过验证期数据进行交叉验证。

3.  **步骤 s3: 操作阶段微调**
    *   **步骤ID**：`s3`
    *   **描述**：在实际操作预报阶段，对偏差校正后的预报进行最终调整。典型操作包括：
        1.  **松弛**：将校正后的预报值向原始预报值进行一定比例的拉回，以避免校正过度或维持预报技巧的稳定性。例如，采用线性松弛公式：`q_new = α * q_raw + (1-α) * q_old`，其中 `α` 为松弛因子（如0.25）。
        2.  **偏移校正**：基于近期预报误差的统计量（如平均误差）进行微小偏移调整。
    *   **上游依赖**：`s2`。
    *   **输入参数**：
        *   `bias_corrected_forecast` (类型：数组): 来自步骤`s2`的偏差校正后预报。
        *   `raw_forecast` (类型：数组): 对应时段的原始模型预报值，用于松弛计算。
    *   **输出**：最终用于发布或决策的操作径流预报。
    *   **质量门**：松弛因子和偏移量通常通过试错或优化测试选定，目标是使最终预报在操作期指标上达到最佳或最稳定表现。

## 边界与分流
- **适用边界**：该协议主要针对**系统性偏差**的校正。如果原始预报的主要问题不是偏差，而是随机误差大或相关性极低，则统计校正的效果有限，可能需要考虑更复杂的动力-统计混合方法或纯机器学习方法。
- **分流情况**：
  - 当目标河流为**低流量或间歇性流量**站点时，观测数据分布可能不完整或不稳定，标准分位数映射可能失效，需要考虑使用针对零流量或极低流量改进的映射方法。
  - 当预报值**频繁超出历史观测值的范围**时，分位数映射在尾部的外推可能产生非物理的极端值，此时应结合领域知识设置合理的上限或采用其他外推方法。
  - 当需要保持预报的**空间结构**（如整个流域的面平均流量或空间相关性）时，逐站点独立的偏差校正可能破坏这种结构，可考虑空间一致性更强的校正方法。
- **上下游衔接**：该协议的输出可作为决策支持系统的直接输入，或作为更高级别集成预报（如多模型集合平均）的成员预报。

## 回退策略
根据该协议可能遇到的失败模式，可考虑以下回退或调整路径：
- **校正效果不佳**：在低流量或数据稀疏站点，若优化过程无法得到有意义的系数，可尝试减小参与合并的网格点邻域范围，或采用更简单的平均方法（如距离反比加权平均）替代空间优化合并。
- **预报极端值异常**：当分位数映射产生非物理极端值时，应在映射函数或合并后设置上下界阈值（如基于历史观测最大/最小值的一定倍数），或转而使用基于参数分布（如Gamma分布）的映射方法以更好地处理尾部。
- **相关性被破坏**：如果校正后预报与观测的相关性显著下降，应检查空间合并步骤的优化目标，可考虑在目标函数中增加相关性项的权重，或放宽优化约束。在极端情况下，可能需要回退到仅使用分位数映射而不进行空间合并的简单校正方案。
