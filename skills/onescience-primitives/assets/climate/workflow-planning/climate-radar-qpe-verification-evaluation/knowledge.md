# 雷达定量降水估计（QPE）验证与评估方法

## 适用范围

**触发条件**：
- 需要验证雷达QPE方法的性能
- 需要评估强降水事件的估计能力
- 需要确保校准与验证样本的独立性
- 需要按业务门限进行验收判定

**适用场景**：
- 雷达QPE算法性能评估
- 强降水事件估计能力验证
- 业务验收门限判定
- 方法比较和基线评估

**不适用场景**：
- 算法开发阶段的单元测试
- 模拟数据验证（仅适用于算法开发）
- 非降水估计任务的验证

## 输入

**输入数据类型**：
1. **校准数据集**：
   - 用于参数选择和模型训练
   - 要求：独立于验证数据集

2. **验证数据集**：
   - 用于性能评估和验收判定
   - 要求：未参与参数选择和模型训练

3. **强降水事件样本**：
   - 降水强度≥10 mm/h或≥25 mm/h
   - 要求：样本量≥5-10个

**数据划分要求**：
- 时间划分：不同时段用于校准和验证
- 空间划分：不同站点用于校准和验证
- 传感器划分：不同设备用于校准和验证

## 输出

**输出产物**：
1. **验证指标报告**：
   - RMSE（均方根误差）
   - 相关系数
   - 偏差
   - 强降水指标（检测率、虚警率、临界成功指数）

2. **样本划分记录**：
   - 校准样本集和验证样本集
   - 划分规则和依据
   - 样本量统计

3. **验收判定报告**：
   - 预登记门限
   - 实际指标值
   - PASS/PARTIAL/REJECT判定

## 流程节点

### Step 1：样本划分设计
- **操作**：设计校准/验证样本划分方案
- **参数**：划分方法（时间/空间/传感器）、划分比例
- **工具**：样本划分算法
- **质量门禁**：划分独立性、样本量充足

### Step 2：强降水样本筛选
- **操作**：从数据中筛选强降水事件样本
- **参数**：强降水阈值（≥10 mm/h或≥25 mm/h）
- **工具**：阈值筛选算法
- **质量门禁**：样本量≥5-10个、时间分布合理

### Step 3：验证指标计算
- **操作**：计算RMSE、相关系数、偏差等指标
- **参数**：指标计算公式、样本集
- **工具**：统计分析库
- **质量门禁**：指标计算正确、样本集独立

### Step 4：强降水指标计算
- **操作**：计算检测率、虚警率、临界成功指数
- **参数**：强降水阈值、检测算法
- **工具**：分类评估算法
- **质量门禁**：指标计算正确、样本量充足

### Step 5：验收门限判定
- **操作**：按预登记门限进行PASS/PARTIAL/REJECT判定
- **参数**：预登记门限、实际指标值
- **工具**：判定逻辑
- **质量门禁**：门限预先登记、判定逻辑正确

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 强降水阈值 | ≥10 mm/h 或 ≥25 mm/h | 领域常识 | 根据业务需求和地区气候特征确定 |
| 最小强降水样本量 | ≥5-10个 | 归因报告 | 确保统计显著性 |
| RMSE门限 | <1.5 mm/h | 领域常识 | 典型业务门限 |
| 相关系数门限 | >0.8 | 领域常识 | 典型业务门限 |
| 校准/验证划分比例 | 70%/30% 或 80%/20% | 领域常识 | 常用划分比例 |
| 检测率要求 | >80% | 领域常识 | 强降水检测能力要求 |
| 虚警率要求 | <20% | 领域常识 | 虚警控制要求 |
| 临界成功指数要求 | >0.6 | 领域常识 | 综合性能要求 |

## 边界与分流

**异常处理**：
- 强降水样本不足：降低阈值或扩大时间范围
- 验证样本不足：使用交叉验证或bootstrap方法
- 门限未预先登记：只报告指标，不声明性能通过

**降级策略**：
- 样本量不足：报告置信区间，标注统计不确定性
- 门限缺失：提供参考门限，明确标注为建议值

**分支条件**：
- 有预登记门限：按门限进行PASS/REJECT判定
- 无预登记门限：只报告指标，不进行最终判定

## 质量检查

**验证点**：
1. 校准与验证样本独立性
2. 强降水样本量充足性
3. 验证指标计算正确性
4. 验收门限预先登记
5. 判定逻辑一致性

**阈值**：
- 校准/验证样本重叠率：0%
- 强降水样本量：≥5-10个
- 指标计算误差：<1%
- 门限登记状态：已登记或明确缺失

**失败处理**：
- 样本不独立：重新划分样本
- 样本量不足：补充数据或降低要求
- 门限未登记：报告指标，不进行最终判定

## 回退策略

**失败时的替代方案**：
1. 强降水样本不足：使用历史数据补充或降低阈值
2. 验证样本不足：使用交叉验证方法
3. 门限未登记：提供参考门限，标注为建议值

**降级使用条件**：
- 明确标注验证限制
- 报告置信区间和统计不确定性
- 不用于正式业务验收
