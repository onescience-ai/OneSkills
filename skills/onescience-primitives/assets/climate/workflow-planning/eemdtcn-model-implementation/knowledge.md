# EEMD-TCN混合模型实现

## 适用范围
EEMD-TCN（Ensemble Empirical Mode Decomposition - Temporal Convolutional Network）是一种用于时间序列预测的混合模型，特别适用于ENSO等非线性、非平稳气候时间序列的预测。本卡描述了EEMD-TCN模型的完整实现方法。

## 输入
- 原始时间序列数据（如Niño3.4指数、海表温度异常等）
- 历史时间步长（lookback window，通常12-24个月）
- 预测时间步长（forecast horizon，6-24个月）
- 模型超参数配置

## 输出
- 预测时间序列值
- 概率预测分布（集成多次运行结果）
- 模型训练日志和评估指标

## 流程节点

### 步骤1：数据预处理
- 操作：标准化时间序列数据，划分训练集和验证集
- 参数：标准化方法（z-score或min-max）、训练/验证比例
- 工具：sklearn.preprocessing, numpy
- 质量门禁：数据无缺失值，分布合理

### 步骤2：EEMD分解
- 操作：对原始时间序列进行集合经验模态分解
- 参数：噪声标准差（通常为原始信号标准差的0.2倍）、集成次数（通常100-200次）
- 工具：PyEMD库或自定义实现
- 质量门禁：分解得到有限个IMF（Intrinsic Mode Functions）分量，残差单调

### 步骤3：IMF分量分析
- 操作：分析各IMF分量的频率特征和能量分布
- 参数：IMF数量、各IMF的周期范围
- 工具：傅里叶变换、小波分析
- 质量门禁：IMF分量频率从高到低排列，无模态混叠

### 步骤4：TCN模型构建
- 操作：为每个IMF分量构建独立的TCN模型
- 参数：TCN层数、卷积核大小、膨胀率、通道数
- 工具：PyTorch、keras-tcn库
- 质量门禁：模型结构正确，参数量合理

### 步骤5：模型训练
- 操作：分别训练各IMF分量的TCN模型
- 参数：学习率、批大小、训练轮数、早停策略
- 工具：PyTorch训练循环
- 质量门禁：训练损失收敛，验证损失不发散

### 步骤6：预测与聚合
- 操作：对各IMF分量进行预测，然后聚合成最终预测结果
- 参数：聚合方法（简单求和或加权求和）
- 工具：numpy
- 质量门禁：预测结果在合理范围内，无异常值

### 步骤7：概率预测（可选）
- 操作：通过集成多次运行或MC Dropout生成概率预测
- 参数：集成次数、置信区间计算方法
- 工具：numpy, scipy.stats
- 质量门禁：置信区间覆盖合理的预测不确定性

## 边界与分流
- **数据长度不足时**：使用迁移学习或数据增强方法
- **计算资源有限时**：减少EEMD集成次数或TCN通道数
- **过拟合严重时**：增加正则化（dropout、权重衰减）或简化模型
- **实时预测需求时**：使用预训练模型进行推理，避免重新训练

## 质量检查
- EEMD分解后IMF分量数量合理（通常5-10个）
- 各IMF分量频率从高到低排列，无模态混叠
- TCN模型训练损失收敛
- 预测结果在历史数据范围内
- 概率预测的置信区间覆盖合理的不确定性

## 回退策略
- EEMD分解失败时，使用EMD或CEEMDAN作为替代
- TCN模型不收敛时，调整学习率或使用Adam优化器
- 预测精度不足时，尝试LSTM或Transformer模型
