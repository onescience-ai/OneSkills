# 对流初生概率阈值校准

## 适用范围

**触发条件**：
- 已获得对流初生（CI）概率预测输出
- 需要将连续概率转换为二分类检测结果
- 需要优化检测性能（POD、FAR、CSI等）

**适用场景**：
- 对流初生检测工作流中的后处理阶段
- 机器学习模型输出的概率校准
- 自适应阈值调整与性能优化

**不适用场景**：
- 多分类问题（需使用其他阈值策略）
- 回归问题（无需阈值）
- 概率校准本身（使用Platt scaling等）

## 输入

**输入数据格式**：
- 概率预测数组（0-1之间的连续值）
- 真实标签数组（0/1二值）
- 可选：概率分布统计信息

**数据来源**：
- 对流初生检测模型的输出概率
- 历史数据的概率分布
- 验证数据集的真实标签

**预处理要求**：
- 概率值已归一化到[0,1]
- 标签与概率对齐
- 数据划分（训练/验证/测试）明确

## 输出

**输出产物**：
- 校准后的阈值
- 阈值-性能曲线（ROC、PR曲线）
- 最优阈值对应的性能指标

**验证标准**：
- 阈值选择基于数据统计，非固定值
- 性能指标（POD、FAR、CSI）合理
- 阈值敏感性分析完成

## 流程节点

### Step 1：概率分布分析
- **操作**：统计概率分布，计算分位数
- **参数**：分位数=[0.1, 0.25, 0.5, 0.75, 0.9]
- **工具**：numpy、scipy.stats
- **质量门禁**：概率范围覆盖[0,1]，分布合理

### Step 2：ROC曲线分析
- **操作**：计算不同阈值下的TPR和FPR
- **参数**：阈值步长=0.01
- **工具**：sklearn.metrics.roc_curve
- **质量门禁**：AUC ≥ 0.7（合理性能）

### Step 3：阈值选择方法
- **操作**：应用多种阈值选择方法
- **参数**：方法=[Youden指数, F1-score最大化, CSI最大化]
- **工具**：numpy、sklearn.metrics
- **质量门禁**：每种方法得到唯一阈值

### Step 4：自适应阈值算法
- **操作**：实现滑动窗口或动态阈值
- **参数**：窗口大小=30天，更新频率=每周
- **工具**：pandas、numpy
- **质量门禁**：自适应阈值随时间变化平滑

### Step 5：概率校准
- **操作**：应用Platt scaling或isotonic regression
- **参数**：校准方法=Platt scaling
- **工具**：sklearn.calibration.CalibratedClassifierCV
- **质量门禁**：校准后概率更接近真实概率

### Step 6：性能评估
- **操作**：计算最优阈值下的性能指标
- **参数**：指标=[POD, FAR, CSI, Accuracy]
- **工具**：sklearn.metrics
- **质量门禁**：POD ≥ 0.7, FAR ≤ 0.3, CSI ≥ 0.5

## 关键参数

**通用判据（方法层）**：

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| ROC曲线步长 | 0.01 | 领域知识 | 平衡精度与计算量 |
| AUC阈值 | ≥ 0.7 | 领域知识 | 合理性能下限 |
| Youden指数 | J = TPR - FPR | [1] | 最大化敏感性+特异性 |
| F1-score | 2*Precision*Recall/(Precision+Recall) | [1] | 平衡精确率与召回率 |
| CSI | TP/(TP+FP+FN) | [1] | 综合检测性能 |

**校准数值（体系专属）**：

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| CI概率典型范围 | 0.1-0.8 | 领域知识 | 取决于区域和季节 |
| 固定阈值 | 0.5 | 领域知识 | 未经校准的默认值 |
| 自适应窗口 | 30天 | 领域知识 | 平衡稳定性与适应性 |
| 概率校准方法 | Platt scaling | [2] | 逻辑回归校准 |

## 边界与分流

**关键前提不成立时的改道**：
- 概率分布严重偏斜 → 使用分位数阈值或非参数方法
- 样本不平衡 → 使用代价敏感学习或重采样
- 概率校准失败 → 使用原始概率，记录不确定性
- 自适应阈值不稳定 → 降低更新频率或增大窗口

## 质量检查

**验证点**：
1. 阈值选择是否基于数据统计
2. 性能指标是否合理
3. 阈值敏感性分析是否完成
4. 概率校准是否改善性能

**阈值**：
- AUC ≥ 0.7
- POD ≥ 0.7
- FAR ≤ 0.3
- CSI ≥ 0.5

**失败处理**：
- 性能不达标 → 重新检查模型或数据
- 阈值选择不稳定 → 使用更保守的阈值

## 回退策略

**失败时的替代方案**：
- 使用固定阈值（0.5）但明确说明限制
- 使用简单规则（如概率 > 平均值 + 1标准差）
- 降级为概率排名而非绝对阈值
