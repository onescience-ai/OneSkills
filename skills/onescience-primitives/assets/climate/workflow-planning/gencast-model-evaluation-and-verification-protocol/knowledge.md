# GenCast模型评估与验证协议

## 适用范围

本协议用于评估一个完整的概率集合预报系统（例如先进的AI气象预报模型）相对于另一个基准系统（例如传统的业务集合预报系统）的综合预报技能。它适用于中尺度到全球尺度的预报变量验证，涵盖从地面到高空的多个垂直层和长达数天的提前期。该协议特别关注概率预报的核心质量维度：预报的锐度与可靠性（通过CRPS评估）、概率校准度、捕捉空间依赖结构的能力、对极端事件的预警能力，以及对高影响天气系统（如热带气旋）轨迹概率的预报能力。当研究目标是比较两个或多个集合预报系统的整体性能，并需要为结论提供统计显著性证据时，可采用此协议框架。

## 输入

- **必需输入**：
  1.  **待评估集合预报**：被评估系统（如GenCast）的多成员集合预报数据。
  2.  **基准集合预报**：作为比较基准的系统（如ECMWF ENS）的多成员集合预报数据。
  3.  **地面真值分析**：用于验证预报的高分辨率分析场数据。注意，不同预报系统可能需要使用不同的地面真值进行公平比较（例如，一个系统用ERA5，另一个用其自身的高分辨率分析场）。
  4.  **评估目标列表**：明确指定要评估的变量、垂直层、提前期等组合的清单。例如，一个标准的全面评估可能包含上千个组合目标。
- **可选/专项输入**：
  1.  **热带气旋最佳路径数据**：用于匹配和评估预报的热带气旋轨迹（如IBTrACS数据库）。
  2.  **成本-损失比曲线**：用于计算相对经济价值（REV）。

## 输出

- **CRPS评分卡**：一个汇总表格或可视化图表，展示两个系统在所有评估目标上的连续排名概率分数（CRPS）对比。
- **集合展开/技能比与排名直方图**：用于诊断预报概率分布的校准度。理想情况下，集合展开/技能比接近1，排名直方图平坦。
- **极端事件评估结果**：包括局部极端事件（如气温超过第99.99百分位）的Brier技能分数（BS Skill Score）以及相对经济价值（REV）曲线。
- **空间依赖评估结果**：通过空间池化（平均和最大池化）方法计算得到的技能指标，用于评估预报捕捉天气系统空间结构的能力。
- **热带气旋轨迹概率评估结果**：包括由集合成员计算的1°分辨率轨迹概率热图及其对应的REV曲线。
- **统计显著性检验结果**：针对上述所有关键指标差异的P值列表，基于固定块bootstrap方法计算。

## 流程节点

该协议由四个主要步骤（节点）构成，形成依赖链：

1.  **边际分布技能评估 (s1)**
    *   **步骤描述**：计算并比较两个预报系统在所有评估目标上的概率预报技能。核心指标是连续排名概率分数（CRPS），它综合评估了预报分布的锐度和可靠性。
    *   **上游依赖**：无（起始节点）。
    *   **输入参数**：
        *   `forecast_collections`（预报集合，数组，必需）：包含两个系统所有集合成员的预报数据。
        *   `ground_truths`（地面真值，数组，必需）：对应的真值分析数据。
        *   `evaluation_targets`（评估目标，列表，必需）：定义了要计算CRPS的所有变量、层、提前期组合。
    *   **输出**：CRPS评分卡。
    *   **质量门**：使用后续的配对差异检验评估结果的显著性。

2.  **校准度与极端事件评估 (s2)**
    *   **步骤描述**：在CRPS评估的基础上，进一步诊断预报概率分布的校准程度，并评估系统对罕见极端事件的预报能力。
    *   **上游依赖**：s1。
    *   **输入参数**：
        *   `ensemble_forecasts`（集合预报，数组，必需）：包含概率信息的预报数据。
        *   `ground_truths`（地面真值，数组，必需）：观测或分析数据。
    *   **输出**：排名直方图；极端事件Brier技能分数和REV曲线。
    *   **质量门**：需明确极端事件定义的分位数阈值（如第99.99百分位）。

3.  **空间依赖与热带气旋评估 (s3)**
    *   **步骤描述**：超越单点评估，检验预报场是否正确捕捉了天气系统的空间关联结构，并专项评估对热带气旋轨迹概率的预报能力。
    *   **上游依赖**：s2。
    *   **输入参数**：
        *   `spatial_forecasts`（空间预报场，数组，必需）：需要进行邻域验证的预报场数据。
        *   `cyclone_track_data`（气旋轨迹数据，数组，必需）：由热带气旋跟踪器提取的轨迹数据。
        *   `track_probability_fields`（轨迹概率场，数组，必需）：1°网格概率热图。
    *   **输出**：空间池化评估结果；热带气旋轨迹概率REV曲线。
    *   **质量门**：空间池化必须能缓解传统逐网格点评估中的“双重惩罚”问题。
    *   **提示词模板**：
        ```
        使用TempestExtremes从集合预报中提取热带气旋轨迹，并计算1°分辨率的轨迹概率热图进行REV评估。
        ```

4.  **显著性检验 (s4)**
    *   **步骤描述**：对前三个步骤产生的所有关键指标（CRPS差、REV差、BS Skill Score差等），进行统计显著性检验，判断两个系统间的差异是否随机。
    *   **上游依赖**：s3。
    *   **输入参数**：
        *   `metric_differences`（指标差异，数组，必需）：GenCast与ENS在各目标上的指标差值序列。
        *   `significance_level`（显著性水平，浮点数，默认0.05，必需）：判断显著性的P值阈值。
    *   **输出**：统计显著性检验结果（P值）。
    *   **质量门**：必须使用**固定块bootstrap**方法，以正确处理气象时间序列中普遍存在的强时间自相关性。

## 边界与分流

- **适用边界**：本协议核心用于**比较**两个已有的集合预报系统。如果目标是**开发或调试**一个新的预报模型，可能需要更侧重物理一致性和诊断性的评估，而非直接与业务系统做统计比较。
- **分流场景**：
  - 如果仅关注**特定应用**（如台风路径预报），可以简化协议，只执行第3步（空间与热带气旋评估）和相应的显著性检验。
  - 如果研究目标是**预报系统的概率属性**（如集合扰动的代表性），则需要增加针对概率分布本身（如PDF形状、集合离散度）的更深入诊断，而非仅依赖CRPS等综合评分。
- **与上下游衔接**：本协议的输入是下游应用（如预报后处理、决策服务）所依赖的原始预报集合。其输出（如经过验证的优势系统）为后续的系统选择或融合提供依据。

## 质量检查

- **统计显著性检验是质量控制的核心**：所有关于“系统A优于系统B”的结论，都必须伴随基于固定块bootstrap的P值，且P < 0.05（或预设的显著性水平）。缺乏显著性检验的比较结论不具备可靠性。
- **校准度诊断作为辅助检查**：CRPS高分但校准度差的系统（如排名直方图呈“U”型，表明集合离散度不足）可能在实际决策中被高估其可靠性。应结合CRPS和校准度图表综合判断。
- **使用一致的验证框架**：确保对两个系统的评估使用完全相同的评估目标、地面真值获取原则（虽然具体数据集可能不同）和统计方法，以保证比较的公平性。

## 回退策略

- **地面真值不匹配**：如果两个预报系统依赖不同的分析场作为真值（例如，一个用ERA5，一个用HRES-fc0），直接比较其评分可能不公平。**回退方案**：要么寻找一个独立的、更高分辨率的真值（如站点观测）进行统一评估；要么在比较时，特别强调这种差异，并在解释结论时保持谨慎，承认这可能引入系统性偏差。例如，不同真值分析场识别的热带气旋数量可能不同，需通过REV的归一化等方法进行公平比较。
- **数据不完整或时间分辨率不足**：如果某些评估目标（如特定层的风场）或长时间序列数据缺失，应缩小评估范围，仅对完整部分进行可靠评估，并在报告中明确说明评估的局限性。例如，12小时时间分辨率可能会影响热带气旋轨迹概率的平滑度，更精细的时间分辨率通常能得到更准确的轨迹描述。
- **CRPS评估不足**：认识到CRPS主要评估边际分布技能，不直接评估空间或时间上的依赖结构。当需要评估天气系统形态（如锋面、台风眼墙）预报时，必须依赖第3步的空间依赖评估方法，不能仅凭CRPS下结论。

## 资源召回建议

- **核心工具库**：
  - **CRPS计算**：可使用专门的气象验证库（如`xskillscore`、`properscoring`）。
  - **REV曲线生成**：需实现成本-损失模型，计算不同成本损失比下的预报价值。
  - **热带气旋跟踪器**：TempestExtremes是一个广泛使用的开源工具（GitHub: ClimateGlobalChange/tempestextremes），其`DetectNodes`和`StitchNodes`算法可用于从网格数据中提取气旋轨迹。
  - **统计检验**：可利用`scipy.stats`或`statsmodels`实现配对bootstrap检验，但**必须**采用固定块重采样以处理数据的时间依赖性。
- **标准数据集**：国际最佳路径档案（IBTrACS）可作为热带气旋轨迹验证的参考标准。ERA5、HRES分析场等是常用的地面真值数据集。
- **参数调优参考**：评估目标列表（变量、层、提前期）和极端事件阈值需要根据具体评估的预报系统和关注的应用场景进行定制。开始前应充分查阅该预报系统文档，确定其标准输出变量和典型验证范围。
