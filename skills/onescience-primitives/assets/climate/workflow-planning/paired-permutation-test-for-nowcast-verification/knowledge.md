# 配对置换检验用于临近预报验证

## 适用范围

用于评估在相同测试集上运行的两个降水临近预报模型（或算法）的性能差异是否具有统计显著性。核心场景是：你已通过回测获得两个模型在时间序列上（如逐日、逐周）的配对性能指标（如临界成功指数CSI、连续概率评分CRPS），需要判断一个模型是否确实优于另一个，而非随机波动所致。此方法通过构建独立观测单元来满足配对检验的基本假设，是预报技巧评估中确保统计严谨性的标准实践。

## 输入

- **必需**：
  1. 两个模型（模型A、模型B）在测试期的每个独立时间单元（如周）上的性能指标值配对序列。序列长度必须一致，且第i个单元的值来自模型A和模型B在相同时段的预报。
  2. 测试集长度（时间单元总数）。
- **可选**：
  1. 预先定义的显著性水平（α），通常为0.05。
  2. 置换次数（N），通常需足够大（如10^5至10^6次）以保证P值估计的稳定性。

## 输出

- **P值**：一个介于0和1之间的数值，表示在零假设（两模型性能无差异）成立的前提下，观察到当前或更极端性能差异的概率。
- **统计显著性结论**：若P值小于预设的α（如0.05），则拒绝零假设，认为两个模型在性能指标上存在统计显著差异。

## 流程节点

1.  **准备配对数据**：从评估结果中提取两个模型在测试集上按独立时间单元（如周）组织的性能指标序列。确保序列对齐，每个位置对应同一评估时段的配对观测。
2.  **定义独立单元**：为了满足检验的独立性假设，从原始时间单元中选取**交替的单元**（例如，仅使用所有奇数周）作为统计分析所依据的独立观测单元。这一步是关键，它确保了用于检验的数据点之间在时间上不相邻，从而最大程度降低因时间自相关导致的虚假显著性风险。最终获得长度为n的独立配对样本。
3.  **计算观察差异**：计算选定的独立单元上，两个模型性能指标的平均差异（例如，D_obs = mean(metric_A - metric_B)）。
4.  **执行置换检验**：
    a. 对于每次置换（共重复N次）：
        i.  随机生成一个置换标签向量，其中每个元素随机分配为“1”或“-1”（代表保持或交换该配对单元中模型A和B的标签）。
        ii. 根据置换标签，重新计算性能差异：D_perm = mean( label_i * (metric_A_i - metric_B_i) )。
    b. 收集所有N次置换得到的D_perm值，构建零假设下的性能差异分布。
5.  **计算P值**：P值等于零假设分布中，绝对值大于或等于观察差异绝对值的比例：P = (count(|D_perm| >= |D_obs|) + 1) / (N + 1)。加1是为了进行保守估计。
6.  **做出推断**：将P值与显著性水平α进行比较。若P < α，则结论为两模型性能差异显著；否则，差异不显著。

## 边界与分流

- **适用前提**：该方法的核心前提是用于检验的数据点（独立单元）应是独立的。如果原始数据存在强时间自相关（如相邻周的降水模式高度相似），**必须**通过选取交替单元（或更稀疏的采样）来构建独立样本。否则，直接使用所有连续单元进行检验会因样本非独立而夸大统计显著性。
- **替代方案**：
  - 如果数据无法通过间隔采样获得足够的独立单元（例如测试集太短），应考虑使用其他允许序列相关的检验方法，如基于时间序列重采样的Block Bootstrap。
  - 如果比较对象超过两个模型，应使用方差分析（ANOVA）或Kruskal-Wallis检验等多组比较方法，事后配对比较再考虑使用此类置换检验并进行多重检验校正。
- **与上下游的衔接**：此协议位于模型性能指标计算之后、最终技巧报告之前。上游输入是清晰、配对好的性能指标序列；输出（P值）是撰写评估报告、选择最优模型的关键统计依据。

## 质量检查

1.  **独立性检查**：在选取交替单元后，应检查相邻（如奇数周之间）数据是否存在明显的趋势或相关性。如果依然存在，可能需要更长的间隔或采用其他统计方法。
2.  **数据完备性检查**：确认两个模型在所有选定的独立单元上均有有效的性能指标值，无缺失。
3.  **P值合理性检查**：在零假设分布均匀的情况下，极小的P值（如< 10^-4）是可信的。但若P值恰好等于某个很小的值（如等于1/N），可能提示置换次数N不够大，应增加置换次数重新计算。
4.  **效应量考量**：P值仅表明差异是否随机产生，不表明差异大小。建议同时报告性能差异的点估计（如D_obs）和置信区间，以评估其实际意义。
