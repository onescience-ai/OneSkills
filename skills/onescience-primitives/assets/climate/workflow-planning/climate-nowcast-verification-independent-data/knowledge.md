# 临近预报验证独立资料生成规范

## 适用范围
适用于天气雷达驱动的冰雹概率临近预报任务的验证阶段，特别是需要评估不同预报时效技巧的场景。不适用于仅使用合成数据进行算法流程验证的场景。

## 输入
- 预报时效列表（如10, 20, 30, 45, 60, 90, 120分钟）
- 独立数据源（地面冰雹报告、双偏振雷达衍生产品）
- 预报区域和时间范围

## 输出
- 每个预报时效的独立验证标签文件
- 标签文件哈希值验证报告
- 验证资料元数据（数据源、生成方法、时间范围）

## 流程节点
1. **独立数据源识别** → 2. **时效标签生成** → 3. **时间差异性验证** → 4. **质量检查** → 5. **元数据记录**

### 步骤1：独立数据源识别
- 操作：识别与预报输入无关的独立验证数据源
- 参数：数据源类型（地面报告/双偏振产品）、时空覆盖范围
- 工具：数据源目录查询
- 质量门禁：确认数据源独立性，未参与模型训练/调参

### 步骤2：时效标签生成
- 操作：为每个预报时效生成对应的目标时刻标签
- 参数：预报时效、目标时刻、二值化阈值
- 工具：时间序列处理脚本
- 质量门禁：每个时效标签反映对应时刻的真实状态

### 步骤3：时间差异性验证
- 操作：验证不同时效标签之间具有时间差异性
- 参数：哈希值比较、相关性分析
- 工具：SHA-256哈希计算、相关性统计
- 质量门禁：不同时效标签哈希值不同

### 步骤4：质量检查
- 操作：检查标签质量和一致性
- 参数：缺失值比例、异常值检测、空间连续性
- 工具：质量检查脚本
- 质量门禁：缺失率<5%、无异常跳变

### 步骤5：元数据记录
- 操作：记录验证资料生成过程和元数据
- 参数：数据源、生成方法、时间范围、哈希值
- 工具：元数据生成脚本
- 质量门禁：元数据完整可追溯

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 预报时效列表 | 10,20,30,45,60,90,120 min | [归因报告issue3] | 标准临近预报时效 |
| 验证数据源 | 地面冰雹报告 | [归因报告issue3] | 独立于雷达输入 |
| 双偏振产品 | ZDR, KDP, CC | [归因报告issue3] | 提高冰雹识别精度 |
| 二值化阈值 | 基于ROC优化 | [归因报告issue3] | 平衡命中率和虚警率 |
| 时间差异性要求 | 哈希值100%不同 | [归因报告issue3] | 确保时效独立性 |

## 边界与分流
- **独立数据源不可用**：使用合成数据但必须标注"synthetic"
- **时间差异性不满足**：重新生成不同时效标签
- **数据质量不达标**：标记异常时段，跳过验证
- **多源数据冲突**：以地面报告为准，双偏振产品作为补充

## 质量检查
- 验证点：标签独立性、时间差异性、数据质量
- 阈值：哈希值不同率100%、缺失率<5%
- 失败处理：重新生成验证标签或降级处理

## 回退策略
1. 使用合成数据替代，但必须在execution-manifest中明确标注
2. 调整预报时效列表，使用可用时效进行验证
3. 采用统计方法替代逐像素验证

## 资源召回建议
- 何时召回：当任务需要验证不同预报时效技巧时
- 配套资源：climate-radar-data-source-specification、climate-nowcast-verification-standard
