# 基于机器学习的卫星降水估计

## 适用范围

一种利用机器学习算法（如随机森林），融合卫星遥感、再分析和地面观测数据，建立中尺度对流云系统降水量估计模型的方法。该流程包括数据融合匹配、模型训练与调优、独立验证评估，并可通过可解释性工具（如SHAP）分析模型行为。

当任务目标与该知识所述场景一致时，可复用本条目。

## 输入

- Himawari-8卫星观测数据（tbb， RH等）
- ERA5再分析数据
- 高密度自动气象站小时降水及地理信息数据

## 输出

- 小时降水量预测模型
- 模型特征重要性排序
- 模型预测精度评估指标（r, RMSE）

## 流程节点

1. 收集并融合Himawari-8卫星数据、ERA5再分析数据和高密度自动气象站观测数据。
2. 通过双线性插值法将ERA5和卫星数据与站点地理和时间信息进行匹配。
3. 使用匹配后的融合数据（如tbb， RH， 前一小时降水）作为输入变量，以小时降水率的对数作为输出变量。
4. 随机抽取MCS域内的站点数据作为独立的最终验证集，其余数据作为训练集。
5. 将训练集输入随机森林模型，通过10折交叉验证进行网格参数调整以构建最优预测模型。
6. 使用相关系数（r）和均方根误差（RMSE）评估模型在训练集和测试集上的预测精度。

## 前提条件

- 需要Himawari-8卫星AHI数据（16个波段，可见光至热红外）。
- 需要ERA5大气再分析数据（30km网格，137层）。
- 需要华北平原高密度自动气象站逐小时观测数据（包含降水、温度、湿度等）。
- 需要Python环境及RandomForestRegressor机器学习库（scikit-learn）。

## 边界与分流

- 相关资产/可替代方案：可与SHAP算法结合用于模型解释。
- 相关资产/可替代方案：输入变量筛选可参考SHAP分析结果。
- 相关资产/可替代方案：可使用其他机器学习模型（如XGBoost， 深度神经网络）替代随机森林。

## 回退策略

- 时空匹配数据存在误差会影响模型精度。
- 样本中非降水样本远多于降水样本，可能导致模型对小值预测偏向。
- 模型参数（如树深度、特征数）设置不当可能导致欠拟合或过拟合。
