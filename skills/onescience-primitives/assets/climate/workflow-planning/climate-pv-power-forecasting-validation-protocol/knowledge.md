# 光伏功率预测标准验证与工作流协议

## 适用范围
本卡片为光伏功率预测任务提供标准验证方法、数据来源规范、模型选择原则和工作流步骤。适用于多站光伏电站0-48小时功率联合预报等场景，涵盖按站点分层和爬坡事件分层的检验协议、数据时点规则、过拟合检测以及标准工作流步骤s01-s06的定义。不适用于其他能源预测任务（如风电、负荷预测）或非时间序列预测任务。

## 输入
- **天气预报数据**：来自气象局签发的数值天气预报产品，包括辐照度、温度、云量等。
- **历史功率数据**：来自电站SCADA系统的实测功率输出，时间分辨率通常为15分钟或1小时。
- **电站属性数据**：来自电站设计文档，包括容量、组件类型、安装角度、地理坐标等。
- **数据时点要求**：所有数据必须是签发时可获得的，不能使用目标时刻之后形成的观测。

## 输出
- **验证报告**：包含按站点、按预测时效、按天气类型分层的指标（RMSE、MAE、R²等），以及爬坡事件检测与检验结果。
- **基线比较**：与持久性预报、气候平均等基线模型的性能对比。
- **验收门限**：合理的性能验收标准（如RMSE<10%容量）。

## 流程节点
1. **数据预检（s01）** → 检查数据完整性、时点合规性、异常值检测。
2. **时空对齐（s02）** → 将天气预报数据与功率数据在时间和空间上对齐。
3. **方法配置与契约验证（s03）** → 选择预测方法，配置参数，验证输入输出契约。
4. **核心计算（s04）** → 执行模型训练、预测生成。
5. **结果恢复与产品生成（s05）** → 将预测结果转换为标准产品格式。
6. **分层验证（s06）** → 按站点、按预测时效、按天气类型、按爬坡事件进行分层验证。

每步含：操作、参数、工具、质量门禁。

## 关键参数
### 通用判据（方法层）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 验证指标 | RMSE, MAE, R², MAPE | [通用] | 标准回归评估指标 |
| 分层维度 | 站点、预测时效、天气类型、爬坡事件 | [通用] | 确保评估全面性 |
| 基线模型 | 持久性预报、气候平均、线性趋势 | [通用] | 性能比较基准 |
| 过拟合检测 | 训练R² - 验证R² > 0.1 | [通用] | 识别模型泛化能力差 |

### 校准数值（光伏功率预测）
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 容量归一化 | 功率/电站容量 | [领域实践] | 消除电站规模差异 |
| 爬坡事件阈值 | 功率变化>30%容量/15分钟 | [领域实践] | 定义显著功率变化 |
| 验收门限 | RMSE < 10% 容量 | [领域实践] | 合理性能标准 |
| 数据时点 | 签发时可获得 | [数据规范] | 避免未来信息泄露 |

## 边界与分流
- **数据不可用**：若缺少真实数据，应标记任务为BLOCKED，不得使用模拟数据。
- **模型过拟合**：若训练R²接近1.0但验证R²为负，应重新选择模型或增加正则化。
- **验证失败**：若验证指标远低于基线，应检查数据质量、特征工程或模型选择。
- **工作流不匹配**：若实际步骤与标准s01-s06不对应，应调整执行计划以符合标准。

## 质量检查
- 验证报告是否包含按站点和爬坡事件分层的指标。
- 是否设置了合理的验收门限（如RMSE<10%容量）。
- 模型选择是否基于验证集性能而非训练集性能。
- 数据是否满足时点规则（签发时可获得）。

## 回退策略
- 若验证失败，可尝试更简单的模型（如持久性预报）作为基准。
- 若数据不足，可收集更多历史数据或使用数据增强技术。
- 若工作流步骤缺失，可参考标准s01-s06步骤补充。
