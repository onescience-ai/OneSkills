# 光伏功率预测模型选择与评估方法

## 适用范围

光伏功率预测任务中机器学习模型的选择、训练、评估与比较。适用于确定性预测和概率性预测模型的评估，涵盖数据驱动方法（随机森林、XGBoost、LSTM、Transformer等）和混合模型。

## 输入

- **训练数据**：历史功率和气象数据（时间序列）
- **验证数据**：独立于训练集的验证数据
- **候选模型**：多个待比较的机器学习模型
- **评估指标**：RMSE、MAE、R²、MAPE等

## 输出

- **模型比较报告**：各模型在验证集上的性能对比
- **最佳模型选择**：基于验证集性能的最佳模型
- **过拟合诊断**：训练集与验证集性能差异分析

## 流程节点

### 1. 数据划分策略

**时间序列划分（推荐）**：
- 训练集：前70%数据
- 验证集：中间15%数据
- 测试集：最后15%数据
- 关键：按时间顺序划分，禁止随机打乱

**滑动窗口验证（推荐用于时间序列）**：
- 窗口大小：30-90天
- 滑动步长：7-30天
- 每个窗口独立训练和验证
- 适用于评估模型在不同时段的稳定性[1]

**K折交叉验证（适用于非时间序列）**：
- K=5或K=10
- 注意：时间序列数据不能随机划分，需使用时间序列交叉验证[2]

### 2. 过拟合检测

**核心指标**：
| 指标 | 计算方法 | 过拟合判断 |
|------|----------|------------|
| R²差异 | R²_train - R²_val | >0.1 为过拟合迹象 |
| RMSE差异 | RMSE_val / RMSE_train | >1.5 为严重过拟合 |
| 学习曲线 | 绘制训练/验证损失曲线 | 验证损失不收敛或上升 |

**关键原则**：
- 模型选择应基于验证集性能，而非训练集性能[1]
- 训练集R²=1.0（完美拟合）通常是过拟合信号
- 验证集R²为负值表示模型比随机预测还差

**示例诊断**：
```
模型A: R²_train=1.00, R²_val=-4.21 → 严重过拟合，不可选
模型B: R²_train=0.85, R²_val=0.82 → 泛化良好，可选
模型C: R²_train=0.78, R²_val=0.75 → 泛化良好，但性能略低
```

### 3. 模型比较框架

**比较维度**：
| 维度 | 指标 | 权重 |
|------|------|------|
| 准确性 | RMSE, MAE, R² | 高 |
| 泛化能力 | 验证集性能 | 高 |
| 稳定性 | 跨时段性能方差 | 中 |
| 计算效率 | 训练时间、推理速度 | 低-中 |
| 可解释性 | 特征重要性、SHAP值 | 低 |

**比较流程**：
1. 所有模型使用相同数据划分
2. 所有模型使用相同评估指标
3. 记录训练集和验证集性能
4. 计算过拟合指标
5. 基于验证集性能选择最佳模型

### 4. 常见模型在光伏预测中的表现

**树模型（RF、XGBoost、LightGBM）**：
- 优势：训练快、可解释、处理非线性
- 劣势：时序依赖捕获能力有限
- 适用：中长期预测、特征工程后[1]

**深度学习（LSTM、Transformer）**：
- 优势：捕获时序依赖、端到端学习
- 劣势：需要大量数据、训练慢、黑箱
- 适用：超短期预测、多变量输入[3]

**概率模型（Gaussian Process、分位数回归）**：
- 优势：提供不确定性估计
- 劣势：计算复杂度高
- 适用：需要概率预报的场景[2]

### 5. 模型选择决策树

```
训练集R² > 0.95?
├── 是 → 检查验证集R²
│   ├── R²_val > 0.7 → 可能过拟合，检查R²差异
│   │   ├── 差异 < 0.1 → 模型良好
│   │   └── 差异 > 0.1 → 过拟合风险，考虑正则化
│   └── R²_val < 0.7 → 严重过拟合，弃用
└── 否 → 检查验证集性能
    ├── R²_val > 0.5 → 模型可用
    └── R²_val < 0.5 → 模型不足，考虑特征工程或更换模型
```

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 过拟合R²差异阈值 | >0.1 | [1] | 训练集与验证集R²差异 |
| 验证集R²下限 | >0.5 | [1] | 模型可用的最低要求 |
| 时间序列划分比例 | 70/15/15 | [1] | 训练/验证/测试 |
| 滑动窗口大小 | 30-90天 | [1] | 保证统计稳定性 |
| K折交叉验证K值 | 5或10 | [2] | 平衡偏差和方差 |

### 校准数值（供参考）
以下数值来自美国和瑞士的光伏预测研究[1][2]，其他体系需以自身证据重新锚定：
| 模型 | 训练R² | 验证R² | 备注 |
|------|--------|--------|------|
| Random Forest | 0.92-0.95 | 0.85-0.90 | 泛化良好[1] |
| XGBoost | 0.93-0.96 | 0.86-0.91 | 泛化良好[1] |
| LSTM | 0.88-0.94 | 0.80-0.88 | 需要更多数据 |
| Gaussian Process | 0.85-0.90 | 0.82-0.88 | 概率预报[2] |

## 边界与分流

**过拟合严重时**：
- 增加正则化（L1/L2、Dropout）
- 减少模型复杂度
- 增加训练数据量

**验证集性能不足时**：
- 检查特征工程（添加滞后特征、天气特征）
- 尝试不同的数据划分方式
- 考虑集成学习方法

**计算资源受限时**：
- 优先选择树模型（RF、XGBoost）
- 减少超参数搜索空间
- 使用早停策略

## 质量检查

- **数据划分正确性**：是否按时间顺序划分，无数据泄露
- **过拟合检查**：是否计算了训练/验证集性能差异
- **模型比较完整性**：是否比较了所有候选模型
- **选择依据**：是否基于验证集性能选择最佳模型
- **结果可复现**：是否记录了随机种子和超参数

## 回退策略

- 若所有模型均过拟合，降低模型复杂度或增加数据
- 若验证集性能不足，检查数据质量和特征工程
- 若计算资源不足，使用简单基线模型（持久性预报）
