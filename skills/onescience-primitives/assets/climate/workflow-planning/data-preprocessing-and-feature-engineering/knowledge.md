# 数据预处理与特征工程

## 适用范围

为机器学习模型准备输入数据的一系列数据处理步骤。首先对原始自动气象站数据进行预处理（过滤错误、插值缺失），然后从预处理后的数据和 SNOWPACK 模拟的雪盖剖面中提取气象、雪盖和雪不稳定性相关特征。

当任务目标与该知识所述场景一致时，可复用本条目。

## 输入

- 原始自动气象站数据
- SNOWPACK 模拟的雪层剖面数据

## 输出

- 预处理后的干净气象数据
- 用于模型训练的特征矩阵

## 前提条件

- MeteoIO 库（用于数据预处理）
- SNOWPACK 模型输出
- 雪层剖面参数的定义与标准

## 边界与分流

- 相关资产/可替代方案：snow cover simulation workflow and toolchain
- 相关资产/可替代方案：random forest classification and feature selection
- 相关资产/可替代方案：avalanche danger level prediction task

## 回退策略

- 数据质量差可能导致预处理步骤失败或产生偏差
- 特征提取过程中对弱层的定位可能不准确
- 缺失值处理不当（如用最大值填充）可能引入噪声

## 备注

以上条目为通用可复用的领域知识，具体参数与实现细节需根据实际研究场景做适配与验证。
