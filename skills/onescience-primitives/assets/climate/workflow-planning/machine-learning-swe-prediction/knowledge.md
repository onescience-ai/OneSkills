# 机器学习预测雪水当量

## 适用范围

面向无密集地面站点的山区流域，在融雪季节（典型为 4–6 月）实时或近实时估算雪水当量（Snow Water Equivalent, SWE）时，可采用基于地形与遥感输入的机器学习回归框架。该方法适用于以下条件：
- 融雪主导的中高海拔流域，积雪期内云覆盖频繁导致光学遥感难以持续获取积雪深度信息；
- 可获取被动微波亮温、积雪面积分数（Fractional Snow-Covered Area, FSCA）、气象驱动场等多源数据；
- 需要通过物理模型预先产出历史 SWE 重建序列作为训练标签。

在森林覆盖率极低（如 < 5%）的干旱-半干旱山区，该方法可直接使用；若流域森林覆盖显著，则需额外引入树冠截留或冠层校正模块（此为边界条件，具体参数视树种与密度而定）。

## 输入

### 必需输入

| 数据类别 | 典型来源 / 变量 | 说明 |
|---|---|---|
| 静态地形变量 | 高程、坡度、坡向、纬度、经度（来自 ASTER GDEM v2 或同级 DEM） | 在整个训练与预测期保持不变，用于捕捉 SWE 空间格局的地形控制 |
| 动态遥感变量 | 积雪面积分数 FSCA（MODSCAG/MODDRFS）、被动微波亮温差（如 AMSR-E TB18V–TB36V）、气温、风速、辐射通量（GLDAS、CERES SYN 等） | 随日期变化，反映当日雪况与气象强迫 |
| 目标变量（训练标签） | 通过能量平衡模型（如 ParBal）倒推重建的历史 SWE 时间序列 | 需覆盖模型训练年份（例如 2003–2010）内的融雪期 |

### 可选输入
- 积雪反照率产品（用于改进能量收支估计）
- 流域边界与河网（用于后续集总式径流预报衔接）
- 历史气候态 SWE（如多年平均重建 SWE），可作为额外预测变量提升模型性能

所有变量须统一至相同空间分辨率（典型为 3.125 km）与时间步长。空间重采样可采用高斯金字塔降采样配合双线性插值（Gaussian pyramid reduction / bilinear interpolation）。

## 输出

| 产出物 | 格式 / 指标 | 后续用途 |
|---|---|---|
| 融雪期 SWE 空间分布图 | NetCDF 或 GeoTIFF，每个栅格为当日 / 时段累积 SWE（mm） | 接入分布式或集总式水文模型进行径流预报 |
| 模型性能评估指标 | RMSE、平均偏差（%）、纳什效率系数 NSE | 判断预测可信度；典型达标值见质量检查节 |
| 预测变量重要性排名 | 排序列表或柱状图 | 辅助数据收集优先级决策 |

## 流程节点

### s1  数据准备

**目标**：收集、处理并整合所有预测变量与目标变量至统一格式。

1. 下载并预处理静态地形变量（高程、坡度等），投影至目标坐标系。
2. 获取遥感动态产品（FSCA、亮温、气象场），裁剪至研究区与时间范围。
3. 获取通过能量平衡模型重建的历史 SWE 序列。
4. 将全部变量重采样至 3.125 km 分辨率：先使用高斯金字塔方法降/升采样，最后用双线性插值精化。
5. 按日期与栅格位置对齐，构建像素级特征矩阵与目标向量。

**质量门**：所有变量分辨率一致为 3.125 km；时间覆盖范围完整（例如 2003–2011 年 4–6 月）；无明显空值。

### s2  模型训练与选择

**目标**：在多种机器学习算法中选择泛化能力最佳的模型。

1. 从 s1 输出的完整数据中随机抽取子集（例如 80 000 个观测），用于控制训练时间。
2. 比较多种回归算法：袋装回归树（Bagged Regression Trees）、前馈神经网络（Feed-Forward Neural Network）、支持向析量机（SVM）、提升回归树（LS Boosted Regression Trees）、逐步多元线性回归等。
3. 采用 k 折交叉验证评估各算法在子集上的 RMSE。
4. 选择在交叉验证中 RMSE 最低且稳定性最好的算法（实践中袋装回归树与前馈神经网络表现相近且最优）。
5. 若计算资源允许，可用全部数据重新训练最终模型。

**质量门**：交叉验证 RMSE 达到最低且模型在不同随机子集上结果稳定。训练样本量（如 80 000）已被验证可获得接近使用全样本的精度。

### s3  模型评估与预测

**目标**：使用独立年份数据进行留一法评估，并对目标年份生成预测。

1. 对每一年（如 2003–2011），用其余所有年份的数据训练模型，对该年进行预测（Leave-One-Year-Out）。
2. 计算流域平均与逐像素的误差统计：RMSE、平均偏差（%）、纳什效率系数（NSE）。
3. 确认 NSE > 0（表示模型优于均值预测），偏差处于合理范围（例如 0–14%）。
4. 使用训练好的模型对目标年份（如 2011 年）生成每日 SWE 预测图。
5. 输出预测结果、误差统计和预测变量重要性排名。

**质量门**：独立年份 NSE > 0；流域平均偏差在可接受范围（例如 < 15%）。

## 边界与分流

- **数据缺失或传感器故障年份**：若某年遥感产品存在大范围缺失（如 AMSR-E 在 2011 年后停止运行），需用替代传感器（如 AMSR2）数据并重新标定亮温-积雪关系。
- **极端气候年份**：极湿年（如 2009 年）或极干年（如 2004 年）的预测偏差往往较大，这属于该方法的已知局限——模型在训练分布之外的年份泛化能力下降。对此，建议在最终预测中附加不确定性范围说明。
- **深雪流域**：积雪深度很大的流域（如 Upper Kabul）RMSE 可能显著升高，但偏差仍可维持在低水平。若 RMSE 超出应用需求，可考虑引入额外变量（如积雪密度产品）或改用物理-统计混合方法。
- **森林覆盖显著区域**：若流域森林覆盖率显著（如 > 10–15%），微波亮温信号会受树冠影响，需引入冠层校正模型或改用光学-微波融合方法。
- **替代方案**：当无法获取能量平衡模型重建的 SWE 作为训练标签时，可退而使用被动微波 SWE 反演产品（如 NASA GlobSnow）直接作为目标，但精度通常较低。若可获取密集地面观测（如 snow courses 或自动雪枕），可直接用于训练，通常优于重建数据。

## 质量检查

以下为该类方法在类似条件下报道的典型精度范围，供量级校准参考；其他流域需以自身独立评估重新锚定。

| 指标 | 典型达标范围 | 说明 |
|---|---|---|
| 流域平均偏差 | 0–14% | 正偏差表示模型高估 SWE |
| 平均 RMSE | 46–48 mm | 逐像素误差的均方根 |
| 纳什效率系数 NSE | ≈ 0.68（多年平均） | NSE > 0 表示优于均值预测；> 0.5 通常被认为“可接受” |
| 最重要预测变量 | FSCA、历史平均重建 SWE | 两者相关性 > 0.7，可能导致各自独立重要性难以区分 |

**额外检查建议**：
- 检验预测变量间是否存在强共线性（如 FSCA 与历史平均 SWE），若存在可通过主成分分析或变量筛选降低冗余。
- 检查被动微波亮温差变量（如 TB18V–TB36V）的单独预测能力：其预测价值通常较低，适合作为填隙变量而非核心预测因子。

## 回退策略

当主流程失败或精度不达标时，可按以下路径替代：

1. **无能量平衡重建数据**：使用被动微波 SWE 反演产品或积雪深度气候态作为目标变量，重新训练模型。精度预计降低，但可快速产出结果。
2. **遥感产品时间中断**：利用替代传感器（如从 AMSR-E 切换至 AMSR2）并执行亮温交叉标定；或仅使用气象驱动场中的气温积温法估算 SWE 变化。
3. **模型 NSE < 0**：说明模型预测不如均值，需检查数据质量（如重建 SWE 是否包含异常值、遥感产品是否有效覆盖）、是否引入了当年独有的异常变量，或考虑增加训练年份。
4. **目标流域积雪特性显著不同**（如高森林覆盖、极深积雪、冰川积雪混合）：需在通用框架上增加领域特定模块，或改用物理模型直接模拟。

## 资源召回建议

- **DEM 数据**：ASTER GDEM v2 或 SRTM 30 m；全球均可获取。
- **积雪产品**：MODSCAG / MODDRFS（MODIS 积雪面积分数与反照率）。
- **微波数据**：AMSR-E / AMSR2 L3 亮温产品（适用于 2002 年至今的连续记录，需处理传感器切换）。
- **气象驱动**：GLDAS-2 / CERES SYN / ERA5 再分析数据。
- **SWE 重建模型**：ParBal（Parameterizations for Balance）等基于能量平衡的反推模型。
- **机器学习工具**：Python scikit-learn（BaggedRegressor, MLPRegressor）、R caret 包；深度学习可选 PyTorch / TensorFlow。
