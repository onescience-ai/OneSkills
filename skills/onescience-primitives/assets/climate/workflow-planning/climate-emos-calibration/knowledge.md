# EMOS概率校准知识卡片

## 适用范围

### 触发条件
- 任务需要对集合预报进行概率校准
- 需要将集合成员统计量转换为概率分布
- 需要评估概率预报的可靠性和准确性

### 适用场景
- 气象集合预报后处理
- 降水概率预报校准
- 极端天气概率预警

### 不适用场景
- 确定性预报后处理（使用MOS而非EMOS）
- 实时业务预报（需离线训练）

## 输入

### 输入数据
| 数据类型 | 说明 | 格式 |
|---------|------|------|
| 集合预报 | N个集合成员的预报值 | (N,) 或 (N,T,H,W) |
| 观测数据 | 对应时刻的真实观测值 | (T,H,W) 或 站点值 |
| 历史数据 | 用于训练校准参数 | 多年历史样本 |

### EMOS模型
| 模型 | 分布假设 | 参数 | 适用变量 |
|------|---------|------|---------|
| EMOS-Gaussian | 正态分布 | 均值μ、方差σ² | 温度、风速 |
| EMOS-Gamma | Gamma分布 | 形状α、尺度β | 降水量 |
| EMOS-logistic | Logistic分布 | 位置μ、尺度σ | 极端事件概率 |
| EMOS-Bernoulli | Bernoulli分布 | 概率p | 二值事件（如降水发生） |

## 输出

### 校准产物
| 产物 | 格式 | 说明 |
|------|------|------|
| 概率分布参数 | μ, σ (Gaussian) / α, β (Gamma) | 校准后的分布参数 |
| 分位数预报 | 分位数列表 | 如5%, 10%, ..., 95%分位数 |
| 概率预报 | P(X>x) | 超越阈值概率 |

### 验证指标
| 指标 | 说明 | 目标值 |
|------|------|--------|
| CRPS | 连续排序概率分数 | 越小越好 |
| 可靠性图 | 预报概率 vs 观测频率 | 对角线附近 |
| 分辨率图 | 分辨率 vs 不确定性 | 右上角 |
| Brier Skill Score | 相对基线的改进 | >0 |

## 流程节点

### EMOS校准标准流程
```
历史样本准备 → 分布拟合 → 参数估计 → 残差分析 → 校准参数存储 → 实时校准 → 验证评估
```

### 每步操作
| 步骤 | 操作 | 工具 | 参数 | 质量门禁 |
|------|------|------|------|---------|
| 1. 样本准备 | 对齐预报-观测对 | numpy/pandas | - | 样本量>1000 |
| 2. 分布拟合 | 选择分布类型 | scipy.stats | - | 拟合收敛 |
| 3. 参数估计 | 最小化CRPS | scipy.optimize | - | 梯度收敛 |
| 4. 残差分析 | 检验校准效果 | crps库 | - | p>0.05 |
| 5. 参数存储 | 保存校准参数 | pickle/json | - | 文件可读 |
| 6. 实时校准 | 应用校准参数 | numpy | - | 无错误 |
| 7. 验证评估 | 计算CRPS等指标 | properscoring | - | CRPS改善 |

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 最小训练样本量 | 1000 | [论文16] | 确保参数估计稳定 |
| 交叉验证折数 | 5 | [论文11] | 防止过拟合 |
| 正则化系数 | 0.01 | [论文16] | 防止参数爆炸 |
| 预报因子 | 均值、方差、分位数 | [论文16] | 集合统计量 |
| 更新频率 | 每周/每月 | [论文20] | 漂移适应 |

## 边界与分流

### 异常处理
| 异常情况 | 处理策略 | 降级方案 |
|---------|---------|---------|
| 训练样本不足 | 使用正则化或贝叶斯方法 | 使用简单统计校准 |
| 参数估计发散 | 限制参数范围 | 固定部分参数 |
| 分布不匹配 | 尝试其他分布 | 使用非参数方法 |

### 分支条件
- 若预报变量为降水：使用Gamma分布
- 若预报变量为温度：使用Gaussian分布
- 若预报变量为极端事件：使用logistic分布

## 质量检查

### 验证点
1. 可靠性：预测概率与观测频率一致
2. 分辨率：区分不同结果的能力
3. 锐度：预报分布的集中程度
4. CRPS：综合评分优于基线

### 阈值
| 指标 | 阈值 | 失败处理 |
|------|------|---------|
| 可靠性偏差 | <0.05 | 重新训练 |
| Brier Skill Score | >0 | 检查数据质量 |
| CRPS改善率 | >10% | 调整模型 |

## 回退策略

1. **EMOS不可用**: 使用简单统计校准（均值/方差校正）
2. **样本不足**: 使用贝叶斯EMOS或正则化
3. **计算资源有限**: 使用简化模型或离线训练
