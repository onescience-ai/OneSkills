# 基于无人机的森林碳储量估算工作流

## 适用范围

适用于利用无人机（UAV）遥感技术对森林生态系统进行地上生物量（Above-Ground Biomass, AGB）与碳储量进行快速、中尺度（公顷至数平方公里）估算的完整作业流程。该流程旨在为传统地面调查（如样地每木调查）提供高效替代或补充方案，特别适用于需要重复监测、地形复杂或要求空间连续覆盖的场景。核心输入为无人机获取的森林影像，核心产出为定量的碳储量估值及其空间分布图。流程触发条件通常包括：森林碳汇项目核查、造林/再造林项目基线调查、森林健康与生产力动态评估，或大范围森林碳储量普查。

## 输入

- **必需输入**：
  1.  **无人机飞行计划**：包括飞行区域、航线、飞行高度、重叠率等参数。
  2.  **目标森林区域地理信息**：如矢量边界（Shapefile）或坐标点，用于规划飞行与结果定位。
- **可选输入**：
  1.  **先验知识**：目标区域优势树种信息，用于选择或标定异速生长方程。
  2.  **地面控制点（GCPs）**：用于提高影像拼接与三维重建的绝对精度。
  3.  **气候数据**：如历史降雨、温度、湿度数据，用于后续模型的空间外推优化。

## 输出

1.  **森林碳储量估算值**：以单位面积（如吨/公顷）或总量（如吨）表示的活生物量碳储量。
2.  **碳密度图**：空间分布图，展示碳储量在林分内的变化。
3.  **模型验证报告**：包含估算模型（异速生长方程或机器学习模型）的精度指标（如RMSE、R²、偏差）及验证方法说明。

## 流程节点

本工作流是一个由四个核心步骤构成的有向无环图（DAG），后一步骤依赖前一步骤的输出。

1.  **影像采集 (s1)**
    *   **描述**：使用无人机搭载指定传感器（RGB相机或LiDAR扫描仪）飞越目标林分，采集高重叠度的序列影像或激光点云数据。
    *   **上游依赖**：无（起始节点）。
    *   **输入参数**：
        *   `sensor_type` (枚举：`RGB`, `LiDAR`， 默认：`RGB`)：传感器类型。选择基于精度需求、成本及数据处理能力。RGB影像成本较低，通过运动恢复结构（SfM）算法可生成高精度正射影像和数字表面模型（DSM）；LiDAR直接获取高精度三维点云，对冠层下结构探测能力更强，但成本更高。
    *   **输出**：原始影像数据集或原始点云数据。
    *   **质量门控**：影像/点云需完整覆盖目标区域；飞行参数（如重叠度、分辨率）需满足后续结构参数提取的最低精度要求。

2.  **结构参数提取 (s2)**
    *   **描述**：处理原始影像数据，提取单木或林分尺度的森林结构参数。
    *   **上游依赖**：s1。
    *   **输入参数**：
        *   `imagery_data` (字符串)：来自s1步骤的无人机影像或点云数据路径/对象。
    *   **处理流程**：
        *   对于**RGB影像数据**：首先进行预处理（辐射校正、几何校正），然后通过SfM-MVS流程生成正射影像和DSM。接着，利用图像分割算法（如分水岭算法）从DSM中分离单木树冠，提取**冠幅面积**；通过DSM与数字地形模型（DTM）之差获得**树高**；基于冠幅与树高的经验关系，建立或应用模型来预测**胸径（DBH）**和**基径（D30）**。
        *   对于**LiDAR点云数据**：直接对点云进行地面点分类与滤波，生成DTM与DSM。利用点云高度信息进行单木分割，提取**树高**、**冠幅**等参数。LiDAR数据可直接或结合强度信息更可靠地估算**DBH**。
    *   **输出**：结构参数数据表，包含每个分割单元（单木或像元）的冠幅面积、树高、DBH、D30等估值。
    *   **质量门控**：提取的参数值需在生物学合理范围内；单木检测率与准确性需满足后续建模要求（如通过小样本目视解译验证）。

3.  **生物量与碳估算 (s3)**
    *   **描述**：利用提取的结构参数，通过经验或半经验模型估算单木或林分的地上生物量，并转换为碳储量。
    *   **上游依赖**：s2。
    *   **输入参数**：
        *   `structural_params` (字符串)：来自s2步骤的结构参数数据。
        *   `estimation_model` (枚举：`allometric_equation`, `machine_learning_model`， 默认：`allometric_equation`)：估算模型类型。
            *   `allometric_equation` (异速生长方程)：基于树木各器官生物量与易测参数（如DBH、树高）之间的幂函数关系。需要为目标树种选择或开发合适的方程。方程形式通常为 `Biomass = a * (DBH^b) * (Height^c)`。
            *   `machine_learning_model` (机器学习模型)：如随机森林、支持向量机、神经网络等。使用结构参数作为特征，训练预测生物量的模型。此方法更灵活，可融合多种参数，但需要足够数量的样本进行训练。
    *   **输出**：地上生物量估算值；通过乘以碳分数（通常为0.45-0.55，视树种和部位而异）转换为碳储量估算值。
    *   **质量门控**：模型预测结果需与已知的校准数据（如小样本破坏性采样数据）或文献值进行比对，误差需在项目或研究可接受范围内。

4.  **模型验证与优化 (s4)**
    *   **描述**：通过地面验证数据评估估算结果的精度，并可能结合辅助数据提升模型的区域适用性。
    *   **上游依赖**：s3。
    *   **输入参数**：
        *   `carbon_estimates` (字符串)：来自s3步骤的碳储量估算结果。
        *   `climatic_data` (字符串，可选)：气候变量栅格数据（如年均温、年降水）。
    *   **处理流程**：
        1.  **交叉验证**：选择代表性样地，进行小规模破坏性采样（伐倒称重）或利用已有的地面调查数据（如森林资源清查数据），获取“真值”生物量/碳储量，与无人机估算结果对比，计算精度指标（如均方根误差RMSE、决定系数R²、相对偏差）。
        2.  **模型优化（可选）**：若验证发现系统性偏差，或需将模型外推至更大区域，可将气候变量等环境协变量与生物量/碳储量进行空间回归或融入机器学习模型，以优化区域预测。
    *   **输出**：经过验证的最终碳储量估算结果；验证精度报告；优化后的碳密度分布图。
    *   **质量门控**：交叉验证的总体误差（如RMSE）应低于预设的精度目标（例如，生物量估算的RMSE < 20%）。

## 边界与分流

- **与卫星遥感方法的分流**：无人机流程适用于**中尺度、高精度、按需获取**的林分级调查。若需对极大区域（如国家、洲际尺度）进行周期性监测，卫星遥感（如Landsat, Sentinel）在时间频率和空间覆盖上更具优势，但空间分辨率（米级至十米级）通常无法支持单木参数提取，主要进行区域生物量密度制图。两者常构成“天-空-地”一体化监测体系。
- **与地面清查方法的分流**：传统样地每木调查（如FIA程序）是碳储量估算的“黄金标准”，能提供最准确的单木参数和生物量实测值，但耗时费力、成本高，空间覆盖有限。无人机流程可作为高效补充，用于在地面样地间进行空间插值和制图。
- **模型选择分流**：
  - **异速生长方程**：物理意义明确，适用于已知优势树种且有成熟方程可用的林分。缺点是对树种和地域的依赖性强，混合林或方程不适用的树种会导致较大误差。
  - **机器学习模型**：当林分结构复杂、树种多样、或缺乏可靠异速生长方程时更具潜力。但其性能严重依赖训练数据的数量和代表性，需要地面真值数据进行监督学习，模型可解释性也相对较低。

## 回退策略

根据已识别的常见失败模式，可采取以下回退或改进措施：

1.  **影像分辨率或质量不足**：若提取的结构参数（如冠幅、树高）精度不达标，应回退至s1步骤，调整飞行参数（如降低飞行高度、增加重叠率）或升级传感器（如使用更高分辨率的相机、增加LiDAR通道）重新采集数据。
2.  **结构参数提取失败**：在s2步骤，若自动分割算法效果不佳（如树木过密、地形起伏大），可引入半自动交互式编辑，或结合少量地面调绘数据进行修正。
3.  **估算模型不适用**：
    - 若所选异速生长方程与目标林分树种不匹配，应回退至s3步骤，寻找并验证更合适的本地化异速生长方程库，或改用机器学习模型。
    - 若机器学习模型因训练数据不足导致泛化能力差，应优先增加有代表性的地面样本进行补充采样和模型重训练，或转用参数需求更少的异速生长方程方法。
4.  **验证偏差过大**：若s4步骤交叉验证显示系统性高估或低估，需回溯检查：
    - 核查结构参数提取是否准确（s2）。
    - 核查异速生长方程系数或机器学习模型特征/标签是否正确（s3）。
    - 考虑是否因未考虑的林分因子（如林龄、立地质量）导致模型偏差，可尝试引入这些变量进行模型修正。

## 资源召回建议

- **图像处理与点云处理软件**：Pix4D, Agisoft Metashape (用于SfM-MVS处理)；LiDAR360, LAStools, PDAL (用于点云处理)；QGIS, ArcGIS (用于GIS分析与可视化)。
- **异速生长方程数据库**：各国/区域林业研究机构发布的本地化异速生长方程集（如中国林业科学研究院发布的《主要树种生物量模型手册》）。
- **机器学习建模环境**：Python (scikit-learn, TensorFlow, PyTorch, LightGBM)；R (randomForest, caret, xgboost 包)。
- **无人机平台与传感器**：根据载荷、续航、精度需求选择消费级或多旋翼工业级无人机，搭配相应RGB相机（如Sony α系列）或轻量级LiDAR传感器（如DJI Zenmuse L1, Livox Avia）。
- **地面验证数据**：项目区域历史森林资源清查数据；合作林场的固定样地数据；自行设计的验证样地调查方案。
