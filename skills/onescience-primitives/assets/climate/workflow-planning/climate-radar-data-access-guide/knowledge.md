# 天气雷达临近预报数据获取指南

## 适用范围
本卡片为天气雷达临近预报任务提供真实观测数据的获取方案。适用于需要雷达反射率、组合反射率等产品作为输入进行短时临近预报（0-2小时）的研究和业务场景。不适用于卫星遥感数据、数值模式输出或合成数据生成。

## 输入
输入为任务需求描述，包括：
- 所需雷达产品类型（如组合反射率、径向速度、双偏振参数）
- 空间覆盖范围（全国、区域、站点）
- 时间分辨率（如5分钟、1小时）
- 数据格式要求（如ODIM_H5、CF/Radial、二进制）

## 输出
输出为可直接使用的雷达数据文件，满足以下标准：
- 数据来源为真实观测（非合成）
- 时空覆盖满足任务需求
- 数据质量通过基本检查（无缺失、无异常值）
- 元数据完整（时间戳、位置、产品类型）

## 流程节点
1. **需求分析** → 确定数据产品类型、时空范围
2. **数据源选择** → 根据覆盖范围和格式选择合适数据源
3. **访问申请** → 向数据提供方申请访问权限（如需要）
4. **数据下载** → 使用官方工具或API下载数据
5. **格式转换** → 转换为任务所需格式（如需要）
6. **质量检查** → 验证数据完整性和一致性

## 边界与分流
- **无真实数据时**：仅当所有公开数据源均无法获取时，方可使用合成数据，但必须在结果中明确标注“合成数据，仅用于算法验证，不反映业务性能”。
- **格式不兼容时**：优先使用官方提供的格式转换工具；若不可用，使用标准库（如wradlib、pyart）进行转换。
- **访问受限时**：联系数据提供方获取访问权限；考虑使用替代数据源或降低数据需求。

## 质量检查
- 检查数据文件是否可正常读取
- 验证时间戳连续性
- 检查空间覆盖完整性
- 核对元数据与实际数据一致性

## 回退策略
- 若首选数据源不可用，按优先级尝试替代数据源
- 若实时数据无法获取，使用延迟可用的历史数据并标注时间差
- 若所有数据源均失败，记录失败原因并建议任务调整

## 资源召回建议
当任务涉及以下场景时，应召回本卡片：
- 天气雷达临近预报
- 强对流天气监测
- 降水定量估计
- 雷达数据预处理
- 多源数据融合
