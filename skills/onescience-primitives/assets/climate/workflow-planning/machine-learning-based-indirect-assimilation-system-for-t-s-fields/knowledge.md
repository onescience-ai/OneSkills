# 基于机器学习的温盐场间接同化系统

## 适用范围

用于海洋数值预报与再分析中，当直接观测数据（如温盐剖面）稀疏、而卫星遥感海表数据（SST, SLA, SSS）相对丰富时，通过机器学习重建三维温盐结构并同化以改善模式预报技巧的场景。该方法属于间接同化范畴，适用于ROMS等区域海洋模式，尤其适用于需要提升模式水下温盐结构精度、而传统直接同化卫星海表数据效果有限的业务或研究流程。

## 输入

- 必需：
  - 历史卫星海表数据（如SST、SLA、SSS），用于模型训练；时间序列需覆盖多年以表征海洋状态变率。
  - 历史原位温盐剖面数据（如EN4.2.1数据集，典型训练集为2004-2018年），作为监督学习的目标标签。
  - 实时卫星观测数据（SST、SLA、SSS），用于实时重建。
  - 位置信息（经纬度），用于匹配每个网格点。
  - 海洋数值模式（如ROMS）及其运行所需的初始/边界条件。
- 可选：
  - 模式背景场（来自前一时刻的预报或再分析）。
  - 同化系统配置文件（如ROMS的I4D-Var模块）。

## 输出

- 三维温盐伪剖面：机器学习模型根据实时卫星海表输入生成的、与模式垂直分层标准一致（如24层）的合成温盐剖面。
- 同化后的模型分析场：经I4D-Var同化后，模式温盐状态得到更新，水下结构模拟效果改善。典型改进表现为温盐均方根误差较直接同化方法有显著降低。

## 流程节点

1. **历史数据准备与模型训练**
   - 收集历史卫星数据（SST, SLA, SSS）与同期原位温盐剖面数据。
   - 使用FOAGRNN（果蝇优化自适应广义回归神经网络）算法训练重建模型。其中初始平滑参数在[0.001, 1]范围内，由果蝇优化算法动态调整。
   - 质量门：模型在独立测试集（如2019年数据）上的均方根误差（RMSE）和技巧评分（Skill score）需达到预设精度要求。

2. **实时三维温盐剖面重建**
   - 将每日实时卫星观测数据（SST, SLA, SSS）输入训练好的FOAGRNN模型。
   - 模型输出与模式垂直分层匹配的三维温盐伪剖面。
   - 质量门：重建剖面需满足模式的垂直分层标准（如与EN4.2.1一致的24层）。
   - 上游依赖：步骤s1。

3. **数据同化**
   - 采用I4D-Var（四维变分）同化方法，将生成的合成温盐剖面同化到ROMS海洋模式中。
   - 需要的输入包括合成剖面、模式背景场，以及设定的观测误差标准差。
   - 质量门：同化后模式的温盐RMSE较同化前或较直接同化方法应有显著降低。
   - 上游依赖：步骤s2。

## 边界与分流

- **与直接同化方法的分流**：若可同化的观测数据本身是高质量的原位温盐剖面，可考虑直接同化；当主要数据源为卫星海表面观测时，本方法（间接同化）通常更适用。
- **与统计方法的比较**：若仅需快速、静态的温盐结构估计而不涉及动力模式同化，可考虑使用MODAS、ISOP等统计方法。本方法强调与动力模式的结合。
- **与动态约束方法的比较**：若同化过程需严格满足模式动力约束，可考虑Nudging或动态守恒技术。本方法（I4D-Var）属于变分同化框架，侧重在时间窗口内优化整体拟合。
- **训练数据适用性**：训练数据的区域范围和时段需与实时应用区域匹配。若用于中尺度涡活动频繁或垂向分层结构复杂的海区，需确保训练集包含足够代表性的状态，否则重建误差可能增大。

## 质量检查

- **模型训练阶段**：使用独立测试集（如训练期外的一年数据）验证FOAGRNN模型的重建精度，评估指标通常为温度和盐度的深度平均RMSE及技巧评分。
- **实时重建阶段**：检查生成的三维温盐剖面是否满足模式的垂直分层格式要求，并可与稀缺的同期原位观测进行比对。
- **同化后分析**：比较同化前后模式背景场与分析场的温盐结构，评估同化对水下结构的改善程度。关键指标为温盐场的RMSE降低百分比。

## 回退策略

- **若训练数据不足或区域不匹配**：可尝试缩减重建模型的应用区域，或寻找更长时间序列的历史数据来扩充训练集。若仍无法满足精度要求，应回退到仅同化卫星海表面数据（如SST、SLA）或使用其他统计降尺度方法作为中间环节。
- **若实时卫星数据质量差（如SSS数据缺失或误差大）**：可暂时仅使用SST和SLA进行重建，或使用质量标志剔除异常观测。重建质量不足时，可降低同化中该类观测的权重或暂停使用合成剖面同化。
- **若同化系统出现不稳定**：检查观测误差协方差矩阵的设定（假设时空不相关可能过于简化），或调整同化窗口长度。可回退到较简单的同化方案（如松弛松弛法）或仅用机器学习重建结果作为模式初始场修正。

## 资源召回建议

- **相关算法与工具**：FOAGRNN（果蝇优化自适应广义回归神经网络）、ROMS模式及其I4D-Var同化模块。
- **相关数据集**：EN4.2.1海洋温盐剖面分析场、各类卫星高度计和散射计产品（SST, SLA, SSS）。
- **相关方法概念**：直接同化、间接同化、统计重建方法（如MODAS）、动态约束方法（如Nudging）。
