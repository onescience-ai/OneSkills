# CMIP6多模型集合降尺度与预测

## 适用范围

用于处理来自多个CMIP6地球系统模型（ESGCM）的粗分辨率输出，通过深度学习方法生成高分辨率气候预测，并构建集合以量化不确定性。该任务典型地服务于区域气候影响评估、脆弱性分析和适应性规划，需要从多个全球气候模型的预测中提取并综合区域尺度的气候变化信号。

## 输入

- 必需：
    - 多个CMIP6地球系统模型的原始预测输出（粗分辨率，如~1°网格）。
    - 用于降尺度的预训练深度学习模型（例如，经过ERA5或观测数据训练的卷积神经网络）。
    - 模型选择标准，用以确定纳入集合的模型范围。
- 可选：
    - 偏差校正数据或方法。
    - 用于插值的高分辨率网格模板。
    - 历史基准期气候态数据（用于计算未来变化异常）。

## 输出

- 高分辨率（如0.1°）的多模型气候预测集合。该集合由所有选定模型在不同深度学习架构下降尺度的结果组成。
- 未来气候异常值图。显示未来不同时段相对于历史基准期的变化信号，并标注每个网格点预测的稳健性（基于模型成员一致性）。

## 流程节点

1.  **模型选择与预处理（s1）**：根据与EURO-CORDEX区域气候模拟项目一致的标准，选择一组CMIP6模型。对选定模型的预测因子数据进行预处理，包括插值到公共网格、标准化以及偏差校正。上游依赖：无。质量门：完成数据插值到公共网格、标准化和偏差校正。
2.  **模型降尺度（s2）**：使用预训练好的多种卷积神经网络架构，对每个预处理后的CMIP6模型输出进行降尺度，生成高分辨率的气候变量场（ESGCM-DL）。上游依赖：s1。质量门：每个模型的降尺度输出通过基本性能评估（如与高分辨率再分析资料的统计比较）。
3.  **多模型集合构建（s3）**：将所有降尺度后的模型输出进行简单平均，构建多模型集合。该集合综合了来自不同气候模型和不同降尺度架构的结果。上游依赖：s2。质量门：集合预测在空间模式和幅度上与原始粗分辨率气候模型集合保持一致性。
4.  **未来变化计算（s4）**：将未来不同时段（例如近期2015-2040、中期2041-2070、远期2071-2100）的集合预测与历史基准期（例如1981-2010）进行比较，计算每个网格点的气候变化异常值。上游依赖：s3。质量门：在网格点上，如果少于三分之二的集合成员同意变化信号的符号或趋势，则该点被标记为预测不稳健。

## 边界与分流

- 该流程适用于**多个全球气候模型**输出的综合处理与集合构建。如果仅处理**单个**模型输出，或仅进行**动力降尺度**（运行区域气候模式），则流程不适用。
- 集合构建采用**简单平均**（非加权）方法。如果需要根据模型性能、独立性或观测匹配度进行**加权集合**，则需要修改集合构建步骤。
- 流程的降尺度步骤依赖于**预训练好的深度学习模型**。如果模型未训练或训练不足，则需先完成模型训练流程，或考虑使用其他统计降尺度方法（如异质最佳解、分位数映射等）。
- 该流程的最终产出是气候变化**信号**（异常值）。若需要原始的高分辨率气候变量场（而非变化量），则需调整输出步骤。

## 质量检查

- **预处理后数据检查**：验证插值、标准化和偏差校正后的数据范围、缺失值及与原始模型数据的一致性。
- **降尺度结果验证**：将单个模型的降尺度结果与独立的高分辨率观测或再分析数据进行比较，评估其统计性能指标（如偏差、均方根误差、空间相关系数等）。
- **集合一致性评估**：检查集合成员间的离散度，评估集合是否合理覆盖了预测不确定性。
- **变化信号稳健性判断**：根据预设规则（如至少三分之二的成员同意）标识预测不稳健的网格点，并在最终结果图中清晰标出。这是量化集合预测可信度的关键步骤。

## 回退策略

- **模型选择不一致**：如果无法获得与预设标准完全一致的模型集合，应记录实际使用的模型列表及其偏差，并在结果说明中注明集合组成可能带来的影响。
- **降尺度模型性能不佳**：如果某个模型或架构的降尺度结果明显偏离预期或观测，可考虑从集合中移除该成员，或降低其在加权集合中的权重（若采用加权方法）。
- **集合成员不足**：当可用的集合成员数量较少时，应谨慎解释集合统计量，并在报告中明确说明成员数量限制对不确定性量化的潜在影响。
