# 气象预报任务工作流依赖管理知识

## 适用范围
适用于气象预报任务的工作流规划、依赖关系管理和标准流程设计。特别针对OneScience工作流依赖关系定义、验证方法、任务拆解原则等知识缺口。不适用于非气象领域的通用工作流管理。

## 输入
- 任务目标：雷达驱动的0—3小时极端降水集合临近预报
- 约束条件：需要遵循标准工作流依赖关系
- 相关产物：execution-manifest.json、标准工作流步骤定义

## 输出
- 正确拆解的任务步骤
- 依赖关系验证报告
- 标准工作流对应关系文档

## 流程节点
1. **标准工作流理解** → 学习OneScience工作流步骤定义和依赖关系
2. **任务拆解** → 按照标准工作流拆解任务步骤
3. **依赖关系验证** → 检查步骤间依赖关系是否符合标准
4. **执行计划生成** → 生成符合依赖关系的执行计划

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 标准工作流步骤 | s01雷达数据预检→s02数据预处理→... | [U1] | 需要严格遵循 |
| 依赖关系验证方法 | 步骤间数据依赖检查 | [U1] | 需要验证 |
| 任务拆解原则 | 按照标准工作流拆解 | [U1] | 需要遵守 |

## 边界与分流
- 当标准工作流步骤不明确时：参考OneScience工作流文档
- 当依赖关系冲突时：重新评估任务拆解
- 当任务超出标准工作流范围时：考虑扩展工作流

## 质量检查
- 步骤完整性检查：确保所有必需步骤存在
- 依赖关系检查：确保依赖关系正确
- 标准符合性检查：确保符合标准工作流

## 回退策略
- 参考标准工作流模板
- 咨询领域专家
- 使用简化工作流进行验证
