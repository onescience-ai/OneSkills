# 时间序列预测独立验证设计原则

## 适用范围

适用于气候时间序列预测任务的验证设计，特别是ENSO指数的6-24个月概率预测，确保验证结果的独立性和可信度。

## 输入

输入数据格式：
- 历史时间序列：形状为 `(n_timesteps, n_features)` 的数组
- 时间索引：`pandas.DatetimeIndex` 或 `numpy.datetime64`
- 标签：与输入对应的观测值

## 输出

输出产物：
- 训练集、验证集、测试集的划分方案
- 验证报告：包含相关系数、RMSE、可靠度等指标
- 独立验证资料清单

## 流程节点

### 数据用途划分原则

#### 1. 时间序列划分方法

```
原始数据: 1980-2024
    ↓
├── 训练集: 1980-2015 (36年) - 用于模型训练和参数选择
├── 验证集: 2016-2019 (4年)  - 用于超参数调优和模型选择
└── 测试集: 2020-2024 (5年)  - 用于最终评估（独立验证）
```

#### 2. 滚动预测数据隔离

```
滚动预测数据划分:
- 训练数据: 1980-2010
- 第1次预测: 用1980-2010训练, 预测2011-2012
- 第2次预测: 用1980-2012训练, 预测2013-2014
- 第3次预测: 用1980-2014训练, 预测2015-2016
- 最终评估: 使用所有预测结果与观测对比
```

#### 3. 交叉验证设计（时间序列专用）

```python
def time_series_cv(data, n_splits=5, test_size=24):
    """
    时间序列交叉验证（避免数据泄露）
    """
    splits = []
    n = len(data)
    for i in range(n_splits):
        train_end = n - (n_splits - i) * test_size
        test_start = train_end
        test_end = test_start + test_size
        splits.append({
            'train': (0, train_end),
            'test': (test_start, test_end)
        })
    return splits
```

### 数据时点规则

| 规则 | 说明 | 违反后果 |
|------|------|----------|
| 时间顺序 | 训练数据必须早于测试数据 | 数据泄露，验证结果不可信 |
| 无重叠 | 训练集和测试集不能有时间重叠 | 过拟合评估 |
| 无未来信息 | 不能使用未来数据进行预测 | 预测偏差 |
| 标注独立 | 标注数据不得作为推理输入 | 验证失效 |

### 独立验证资料选取标准

| 标准 | 说明 | 示例 |
|------|------|------|
| 时间独立性 | 验证资料的时间段晚于训练数据 | 训练1980-2015, 验证2016-2024 |
| 空间独立性 | 验证区域不重叠（如适用） | 不同观测站点 |
| 方法独立性 | 验证资料不得参与模型选择 | 不能用于调参 |
| 数据独立性 | 验证数据来自不同来源或处理方式 | 卫星观测 vs 地面观测 |

### ENSO预测任务的科学背景

#### Niño3.4指数定义
- **区域**: 5°S-5°N, 170°W-120°W
- **计算**: 该区域平均SST异常的3个月滑动平均
- **阈值**: 
  - El Niño: Niño3.4 > 0.5°C 持续5个月以上
  - La Niña: Niño3.4 < -0.5°C 持续5个月以上

#### ENSO物理机制
- **Walker环流**: 大气中的纬向环流
- **Bjerknes反馈**: 海气耦合的正反馈机制
- **延迟振荡器**: 解释ENSO周期性的理论框架

#### 标准输入数据含义
| 变量 | 物理意义 | 对ENSO的影响 |
|------|----------|--------------|
| SST | 海表温度异常 | 直接反映ENSO状态 |
| OHC | 上层海洋热含量 | 储存和释放热量 |
| U-wind | 纬向风场异常 | 影响Walker环流 |
| U-stress | 纬向风应力 | 驱动海洋环流 |

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 训练期长度 | ≥30年 | [气候学惯例] | 足够样本覆盖ENSO周期 |
| 验证期长度 | 3-5年 | [气候预测实践] | 足够验证模型性能 |
| 测试期长度 | ≥5年 | [IPCC指南] | 独立验证的最低要求 |
| 滚动窗口大小 | 1-3年 | [ENSO预测] | 平衡数据利用和计算成本 |
| Nino3.4阈值 | ±0.5°C | [NOAA CPC] | El Niño/La Niña事件判定 |

## 边界与分流

### 验证设计决策

```
IF (数据量 < 30年) → 使用交叉验证而非固定划分
IF (有独立观测数据) → 使用真实观测进行最终验证
IF (数据有缺失) → 使用多重插补或删除缺失段
```

### 验证失败处理
- **相关系数低**: 检查模型是否过拟合，调整训练策略
- **RMSE高**: 检查数据预处理，考虑数据归一化
- **可靠度低**: 调整概率校准方法

## 质量检查

| 检查项 | 标准 | 失败处理 |
|--------|------|----------|
| 时间独立性 | 训练和测试数据无时间重叠 | 重新划分数据集 |
| 样本量 | 测试集样本量足够统计显著性 | 延长验证期或使用交叉验证 |
| 指标合理性 | 相关系数>0.5，RMSE<1°C | 检查模型和数据质量 |

## 回退策略

- **数据不足**: 使用合成数据进行方法验证，但必须标注"仅用于方法验证"
- **独立数据不可用**: 使用留一法交叉验证或时间序列交叉验证
- **验证指标异常**: 使用多种指标综合评估
