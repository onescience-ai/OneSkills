# 基于邻域的连续概率评分验证方法

## 适用范围

用于评估高分辨率（涡分辨率）海洋预报系统的预报技巧。当预报模型的输出分辨率高于观测密度时，传统的逐点比较会因空间位置的微小偏移而产生"双重惩罚"——预报在正确的位置模拟出正确的结构但略有偏移时，会被既扣"位置偏差"又扣"强度偏差"的分数。该验证策略通过在观测点周围构建邻域伪集合，将点对点比较转化为概率预报评估，从而公平地度量预报系统对海洋中尺度现象（如涡旋、锋面）的模拟能力。

该方法适用于以下场景：
- 涡分辨率（eddy-resolving）海洋预报系统的日常监控与季节评估
- 多模式预报技巧的横向比较
- 卫星高度计、漂流浮标、Argo 剖面浮标等多种观测平台的融合验证
- 海表温度（SST）、海面高度异常（SLA）、温盐剖面、15 米深度流速等海洋变量

## 输入

**必需输入：**

| 输入项 | 说明 |
|--------|------|
| 预报场数据 | 高分辨率海洋预报系统输出，包含所评估变量的逐时或逐日场 |
| 观测数据 | 卫星高度计（如 AVISO）、全球漂流浮标计划（GDP）数据、Argo 剖面浮标等 |
| 邻域范围 | 以观测点为中心的空间窗口，典型取值为 1° × 1°，需根据模型分辨率与观测密度调整 |

**可选输入：**

- 观测误差估计（用于观测模拟方法 OSE 的扩展分析）
- 持久性预报场（用于计算持久性技巧评分的基准）
- 多变量对应表（当同时评估 SST、SLA、流速等不同变量时）

## 输出

| 输出项 | 说明 |
|--------|------|
| CRPS | 连续概率评分，数值越小表示预报技巧越好。反映伪集合的概率分布与观测值的匹配程度 |
| PSS | 持久性技巧评分，通过比较预报 RMSE 与持久性预报 RMSE 来评估预报相对于气候学基准的提升 |
| 全球平均 CRPS | 对所有观测点的 CRPS 取平均，给出某初始时间和预报时效的总体技巧指标 |

## 流程节点

1. **邻域伪集合构建**：以每个观测点为中心，在指定邻域（如 1° × 1°）内收集所有预报网格点的数值，形成该点的伪集合。伪集合的成员数取决于模型分辨率和邻域大小。

2. **CRPS 计算**：将步骤 1 中得到的伪集合视为概率预报的经验累积分布函数，与该观测点的实测值进行比较，逐点计算 CRPS。CRPS 同时度量伪集合的可靠性（分布形态）与锐度（分布宽度）。

3. **空间平均**：对所有有观测覆盖的点的 CRPS 值求平均，得到特定初始时间和特定预报时效的全球（或区域）平均 CRPS。建议按预报时效（如第 1 天至第 10 天）分别计算，以刻画预报技巧随时效的衰减。

4. **持久性技巧评分计算**：先计算预报场与观测场之间的逐点 RMSE，再计算持久性预报（即将初始时刻场持续作为预报）的 RMSE。持久性技巧评分定义为两者之比，小于 1 表示预报优于持久性基准。

5. **结果汇总与可视化**：将 CRPS 和 PSS 按变量、区域、预报时效进行分组汇总，生成时间序列图、空间分布图和模式间对比图。

## 边界与分流

- **观测稀疏区域**：当邻域内观测点过少（如南大洋部分区域），伪集合成员数不足，CRPS 的概率估计不稳定。此时应缩小邻域范围或转为仅报告 RMSE 等确定性指标。
- **邻域大小敏感性**：邻域选得太大可能引入远距离无关信息，选得太小则伪集合成员不足。建议进行敏感性测试，选取使 CRPS 对邻域大小变化最不敏感的区间。
- **模式间比较**：若比较不同分辨率的模式，应统一邻域大小以保证公平性，或分别使用各自分辨率对应的最优邻域并注明。
- **与 GODAE OceanView IV-TT Class 4 框架的关系**：该方法可作为 Class 4 验证框架的补充，尤其适用于涡分辨率系统。对于粗分辨率系统，传统的逐点验证仍是标准做法。

## 回退策略

- **伪集合成员数不足**：若邻域内预报格点数低于最低阈值（如少于 5 个），该点不参与 CRPS 计算，改用逐点 RMSE 或 MAE。
- **观测数据完全缺失**：某区域无任何观测覆盖时，跳过该区域的验证，并在报告中注明覆盖盲区。
- **CRPS 计算异常**：若伪集合中所有成员值相同（退化为确定性预报），CRPS 退化为绝对误差，此时应同时报告 CRPS 和逐点误差以便对比。
- **无法获得持久性基准**：若缺少初始场数据无法构建持久性预报，仅报告 CRPS 而不计算 PSS，避免给出无基准的技巧评估。

## 质量检查

- 核实伪集合成员数：每个参与计算的观测点对应的伪集合应至少包含一定数量的成员（建议 ≥ 5），否则该点的 CRPS 估计不可靠。
- 邻域覆盖一致性：确认邻域选取在空间上是各向同性的，避免因网格变形引入系统偏差。
- CRPS 与逐点误差的对比：在观测密集区域（如北大西洋），同时报告 CRPS 和传统逐点 RMSE，检查两者给出的技巧排名是否一致。若不一致，需分析原因并决定采用哪种指标。
- 持久性基准的合理性：检查持久性预报的 RMSE 是否符合气候学预期，排除数据处理错误。

## 资源召回建议

- **观测数据**：AVISO 卫星高度计数据用于 SLA 验证；GDP 漂流浮标用于表层流速验证；Argo 剖面浮标用于温盐垂直结构验证。
- **验证框架**：GODAE OceanView IV-TT Class 4 验证框架提供了标准化的预报-观测比较协议，可作为本方法的补充参考。
- **工具**：常用 CRPS 计算函数可在 Python 的 `properscoring` 或 `xskillscore` 库中找到；ROMS、NEMO、HYCOM 等海洋模式的输出均可适配该验证流程。
