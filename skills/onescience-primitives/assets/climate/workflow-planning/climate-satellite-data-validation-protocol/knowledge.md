# 静止气象卫星数据验证协议

## 适用范围

**触发条件**：
- 使用静止气象卫星（如FY-4A/AGRI、Himawari-8/AHI）数据进行对流初生检测或其他气象应用
- 需要验证源观测资料的完整性、格式合规性与时序连续性

**适用场景**：
- 对流初生检测工作流中的数据预处理阶段
- 卫星数据质量控制与异常检测
- 数据截止时间与资料完整性判断

**不适用场景**：
- 极轨卫星数据验证（格式与时间分辨率不同）
- 非气象卫星数据（如地球观测卫星）

## 输入

**输入数据格式**：
- NetCDF4/HDF5格式的卫星数据文件
- 包含多通道亮温、反射率等变量
- 时间分辨率：15分钟（静止卫星典型值）
- 空间分辨率：4km（FY-4A/AGRI）、2km（Himawari-8/AHI）

**数据来源**：
- 国家卫星气象中心（NSMC）
- 风云卫星遥感数据网
- 日本气象厅（JMA）Himawari数据

**预处理要求**：
- 数据文件可读且未损坏
- 时间戳格式正确（UTC时间）
- 空间范围与目标区域匹配

## 输出

**输出产物**：
- 数据验证报告（JSON格式）
- 完整性指标（时间覆盖率、空间覆盖率、缺失率）
- 质量标志解析结果

**验证标准**：
- 时间连续性：相邻时次间隔 ≤ 15分钟
- 空间覆盖：目标区域像元覆盖率 ≥ 90%
- 数据有效性：非NaN值比例 ≥ 80%

## 流程节点

### Step 1：数据格式检查
- **操作**：验证文件格式、变量名、维度结构
- **参数**：格式=NetCDF4/HDF5，变量=亮温、反射率，维度=时间、经度、纬度
- **工具**：xarray、netCDF4、h5py
- **质量门禁**：文件可读，变量存在，维度正确

### Step 2：时间连续性验证
- **操作**：检查时间戳序列，计算间隔
- **参数**：最大间隔=15分钟，允许缺失≤2个时次
- **工具**：pandas、numpy
- **质量门禁**：时间序列连续，无异常跳跃

### Step 3：空间覆盖确认
- **操作**：计算目标区域像元覆盖率
- **参数**：目标区域边界，最小覆盖率=90%
- **工具**：numpy、xarray
- **质量门禁**：覆盖率 ≥ 90%，无大范围空洞

### Step 4：质量标志解析
- **操作**：解析数据中的质量标志位
- **参数**：质量标志变量名，有效值范围
- **工具**：numpy位运算
- **质量门禁**：有效像元比例 ≥ 80%

### Step 5：数据截止时间判断
- **操作**：确定数据最新可用时间
- **参数**：产品发布schedule，处理延迟
- **工具**：datetime计算
- **质量门禁**：数据时效性满足应用需求

| 参数 | 值 | 来源 | 说明 |

## 边界与分流

**异常处理**：
- 数据格式错误 → 请求重新获取或转换格式
- 时间不连续 → 标记缺失时次，评估影响
- 空间覆盖不足 → 考虑插值或裁剪区域
- 质量标志异常 → 降级使用或剔除可疑数据

**降级策略**：
- 部分数据缺失 → 使用可用数据子集，明确说明限制
- 质量不佳 → 降低置信度，增加不确定性估计

## 质量检查

**验证点**：
1. 文件完整性检查（checksum）
2. 变量范围合理性检查（亮温150-350K）
3. 时间戳单调递增检查
4. 空间坐标有效性检查

**阈值**：
- 文件大小 > 0
- 变量非全NaN
- 时间间隔 ≤ 15分钟

**失败处理**：
- 任一检查失败 → 标记数据不可用，记录错误原因

## 回退策略

**失败时的替代方案**：
- 使用替代数据源（如GFS分析场）
- 使用相邻时次数据插值
- 降低数据要求（如降低分辨率）
