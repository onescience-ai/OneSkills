# 给定边界强迫的全球气候大集合生成（E36）

## 适用范围

**适用场景**：
- 任务目标与“给定边界强迫的全球气候大集合生成”的对象、时空范围和输出定义一致。
- 能够在任务截止时间前获得并核实边界与外强迫、情景定义、模拟时段、异常基准期，且数据覆盖和质量足以支持状态模拟与集合生成。
- 能够获得用于历史期或留出样本检验的独立验证资料、检验指标，并为未来条件投影预先确认情景一致性、物理合理性和不确定性报告口径。
- 目标区域、时间、变量和数据分布位于可验证的适用范围内，资源与交付期限不存在未确认的冲突。

**不适用场景**：
- 超出上述研究对象、时空范围、目标变量或产品定义的任务不在默认范围内。
- 关键输入缺失、来源不可追溯、使用权限不明确，且场景不允许补充或调整任务范围。
- 客户要求作性能PASS或正式业务验收，但只能使用参与训练或调参的数据，且无法建立独立、同协议的验证或回放。
- 目标区域、时段、变量、传感器或事件类型明显超出可验证范围，且没有经确认的补充数据与验证方案。

## 研究对象与输入

## 核心科学问题

1. 在遵守数据时点、任务边界和输入输出契约的前提下，能否可靠完成“给定边界强迫的全球气候大集合生成”的核心分析与目标结果生成并形成长期气候集合、分布统计和极端重现期、质量标志与不确定性信息、产品元数据与文件清单？
2. 历史基准期或留出样本上的映射技巧如何，未来结果是否满足“检验稳定性、离散度与尾部分布”所要求的情景一致性和物理合理性？
3. 未来结果对情景路径、外部强迫、内部变率、历史训练期和方法选择有多敏感，能否明确分解这些来源，而不把集合离散度解释为真实未来概率？
4. 哪些结论由当前数据和独立检验直接支持，哪些只适用于特定区域、季节、事件或传感器条件，哪些因数据、资源或适用域限制不能得出？

- **core_result**：按冻结输入输出契约得到的给定边界强迫的全球气候大集合生成核心结果、中间状态、运行日志、配置身份和异常记录；具体算法不得被反写为客户需求。
- **product_result**：可重新读取的长期气候集合、分布统计和极端重现期、质量标志与不确定性信息、产品元数据与文件清单，并附单位、坐标、有效时间、质量标志、派生规则、文件清单和校验信息。
- **validation_result**：使用历史基准期、留出时段或留出区域完成“检验稳定性、离散度与尾部分布”及同协议比较，并对未来部分报告情景一致性、物理合理性和多来源不确定性；验收门限只适用于可验证历史期或预先定义的物理一致性检查。
- **uncertainty_and_limit_result**：说明数据误差、抽样误差、方法随机性、情景或外部强迫、外推和适用域限制；概率、区间或质量标志应给出可验证样本上的校准证据，无法量化时须明确原因。
- **结论结果**：给出区分已验证结果、探索性观察、未通过项和无法回答问题的结论报告，不得把文件生成成功等同于科学或业务性能通过。
