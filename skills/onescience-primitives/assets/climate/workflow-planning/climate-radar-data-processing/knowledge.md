# 气象雷达数据处理流程

## 适用范围
面向气象雷达数据获取与处理任务，定义从原始雷达数据到质量控制产品的完整处理流程。适用于S波段双偏振雷达、C波段雷达、X波段雷达等不同型号雷达的数据处理。不适用于卫星遥感数据处理或地面观测站数据处理。

## 输入
- 原始雷达体扫数据（反射率Zh、差分反射率Zdr、差分相位φdp、比差分相位Kdp、相关系数ρhv）
- 探空温度廓线
- 地面自动气象站数据（约500个站）
- 台风路径数据
- 数字高程模型（DEM）

## 输出
- 质量控制后的偏振参数场
- 水凝物分类图
- 降水粒子垂直廓线
- 警报指标（PI）

## 流程节点
数据采集 → 地物杂波抑制 → 生物回波滤除 → 衰减校正 → 波束阻挡校正 → 噪声滤除 → 一致性检查 → 粒子识别 → 特征提取 → 警报指标计算

### 步骤1：数据采集
**操作**：获取雷达体扫数据和辅助数据
**参数**：扫描周期6分钟、径向分辨率250米、可靠探测距离≤150km
**工具**：雷达数据接口、数据解析器
**质量门禁**：数据完整性检查、时间同步验证

### 步骤2：地物杂波抑制
**操作**：使用模糊逻辑方法去除地物杂波
**参数**：纹理阈值>10dBZ、相关系数阈值ρhv<0.80
**工具**：模糊逻辑分类器、纹理分析算法
**质量门禁**：杂波去除率验证、残余杂波检测

### 步骤3：生物回波滤除
**操作**：滤除昆虫、鸟群等生物回波
**参数**：Zh<35dBZ、Zdr>4dB、ρhv<0.95
**工具**：双偏振参数分类器
**质量门禁**：生物回波识别准确率验证

### 步骤4：衰减校正
**操作**：使用自洽方法校正信号衰减
**参数**：Zh衰减系数α=0.08dB/deg、Zdr衰减系数β=0.02dB/deg
**工具**：φdp约束自洽校正算法
**质量门禁**：校正自洽性验证、与探空数据对比

### 步骤5：波束阻挡校正
**操作**：基于DEM校正地形遮挡
**参数**：校正因子1.0-3.0dB
**工具**：DEM分析算法、阻挡校正模型
**质量门禁**：阻挡区域识别验证、校正效果评估

### 步骤6：噪声滤除
**操作**：去除低信噪比数据和平滑噪声
**参数**：SNR<5dB滤除、5×5中值滤波
**工具**：信噪比检测器、中值滤波器
**质量门禁**：噪声抑制效果验证、信号保真度检查

### 步骤7：一致性检查
**操作**：进行多维度一致性验证
**参数**：距离依赖阈值、时间连续性、空间相关性
**工具**：一致性检查算法
**质量门禁**：异常数据检测率、一致性通过率

### 步骤8：粒子识别
**操作**：使用模糊逻辑识别水凝物类型
**参数**：梯形隶属函数、温度约束、粒子特征库
**工具**：模糊逻辑分类器、温度廓线分析
**质量门禁**：识别准确率验证、与探空数据对比

### 步骤9：特征提取
**操作**：提取降水粒子垂直分布特征
**参数**：5km高度冰晶含量、亮带Zdr峰值、冰晶层厚度
**工具**：垂直廓线分析算法
**质量门禁**：特征物理合理性验证

### 步骤10：警报指标计算
**操作**：计算加权警报指标
**参数**：权重系数、阈值设置
**工具**：警报指标计算算法
**质量门禁**：警报效果验证、POD/FAR/CSI评估

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 扫描周期 | 6分钟 | [1] | 标准业务雷达扫描策略 |
| 径向分辨率 | 250米 | [1] | 距离库长度 |
| 可靠探测距离 | ≤150km | [1] | 超过此距离数据质量下降 |
| SNR滤除阈值 | <5dB | [1] | 低信噪比数据不可用 |
| 地物杂波阈值 | ρhv<0.80 | [1] | 相关系数低于此值判定为杂波 |

### 校准数值
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| Zh衰减系数 | α=0.08dB/deg | [1] | S波段雷达典型值 |
| Zdr衰减系数 | β=0.02dB/deg | [1] | S波段雷达典型值 |
| 波束阻挡校正因子 | 1.0-3.0dB | [1] | 取决于地形遮挡程度 |

## 边界与分流
- 当雷达数据不可用时：使用邻近雷达数据或卫星反演产品替代
- 当质量控制失败时：标记可疑数据，在产品中注明数据质量
- 当衰减校正异常时：使用保守校正系数，增加不确定性估计
- 当粒子识别不确定时：输出多类别概率，标记低置信度像元
- 当特征提取异常时：回退到统计特征，记录异常原因

## 质量检查
- 杂波去除验证：通过ρhv和纹理阈值验证
- 衰减校正自洽性：通过φdp验证
- 跨雷达验证：POD=82.7%、FAR=24.3%、CSI=65.2%
- 5折交叉验证：POD=83.9%±1.5%、FAR=23.1%±1.2%
- 空间验证：50-100km范围内CSI=72.5%、100-150km范围内>65%

## 回退策略
- 数据源故障：使用最近可用体扫数据，降低时间分辨率
- 质量控制算法失败：使用简化阈值方法，增加人工审核
- 衰减校正异常：使用气候平均衰减系数，输出原始和校正值
- 粒子识别错误：输出所有类别概率，标记不确定像元
- 特征提取异常：使用统计特征替代，记录异常原因
