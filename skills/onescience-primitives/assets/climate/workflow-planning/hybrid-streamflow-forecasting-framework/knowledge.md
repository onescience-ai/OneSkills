# 混合径流预报框架

## 适用范围

用于提升径流预报精度，特别是当物理水文模型因结构简化、参数不确定性或驱动数据误差而导致预报存在系统性偏差或技巧不足时。该框架适用于需要融合物理过程理解与数据驱动模式识别优势的场景，例如为洪水预警、水资源管理或气候影响评估提供更可靠的径流预报产品。它特别适用于处理物理模型在数据稀疏区域表现不佳，或统计方法在极端事件上泛化能力有限的问题。

## 输入

- 必需输入：
  - 气象数据：驱动物理模型的预报或再分析数据，如ERA5再分析数据或欧洲中期天气预报中心（ECMWF）的集成预报系统（IFS）输出。
  - 历史径流观测数据：用于训练和验证机器学习模型或统计校正算法，通常需要足够长的序列以捕捉水文过程的变异性。
  - 物理模型原始预报：由物理模型（如GloFas）生成的未经校正的径流预报时间序列。
- 可选输入：
  - 降水、温度等关键气象要素的预报集合，用于进行集合后处理。
  - 流域特征数据（如面积、土壤类型、地形），可用于辅助特征工程。

## 输出

- 改进后的径流预报时间序列：经过机器学习或统计方法后处理，通常在验证期表现出更高的技巧。
- 性能评估报告：包含原始预报、后处理预报与观测值之间的多种统计指标（如KGE、RMSE、相关系数）的定量比较结果，以及可视化图表（如散点图、时间序列对比图）。

## 流程节点

该框架包含三个核心步骤，构成一个依赖的有向无环图（DAG）。

1. **步骤ID: s1 - 物理模型预报**
   - 依赖：无（起始步骤）。
   - 描述：运行基于物理的分布式或集总式水文模型（以GloFas为例），使用气象输入数据驱动模型，生成未来一段时间的径流预报时间序列。
   - 输入参数：
     - `meteorological_input`：气象输入数据，类型为字符串，指定数据源（默认值："ERA5 reanalysis or IFS forecast"，必填）。提示：驱动水文模型的气象数据源，需与模型版本兼容。
   - 输出：原始径流预报时间序列。
   - 质量门：预报结果应具有物理意义（如非负、量级合理），且在模型校准/验证期间表现出可接受的基准性能。
   - 参考提示词模板：
     ```
     请生成用于物理模型预报的配置。气象输入数据源为：{meteorological_input}。确保配置与水文模型的版本和运行要求匹配。
     ```

2. **步骤ID: s2 - 机器学习/统计后处理**
   - 依赖：s1。
   - 描述：使用机器学习模型（如LSTM）或统计方法（如分位数映射、线性回归偏差校正）对步骤s1输出的原始预报进行改进。此步骤旨在学习并校正原始预报的系统误差。
   - 输入参数：
     - `raw_forecast`：来自步骤s1的原始预报数组（必填）。
     - `training_data`：用于训练模型的监督数据对，包含历史观测值与同期的物理模型预报值（必填）。
   - 输出：改进后的径流预报时间序列。
   - 质量门：在验证数据集上，改进后预报的关键指标（如Kling-Gupta效率，KGE）应优于原始预报的指标。
   - 参考提示词模板：
     ```
     请配置机器学习后处理模型。输入原始预报数据：{raw_forecast}。训练数据对：{training_data}。选择模型类型（如LSTM、线性回归）并设置超参数。
     ```

3. **步骤ID: s3 - 预报评估与比较**
   - 依赖：s2。
   - 描述：使用独立的验证数据集，全面评估改进后预报的性能，并与原始预报及（可选的）其他基准方法（如简单的偏差校正）进行定量比较。
   - 输入参数：
     - `improved_forecast`：来自步骤s2的改进后预报数组（必填）。
     - `observations`：用于最终评估的官方观测径流数据（必填）。
   - 输出：性能评估报告与模型比较结果。
   - 质量门：评估指标计算准确，比较结论基于充分的验证期数据，并考虑不同流量级的表现。
   - 参考提示词模板：
     ```
     请执行预报评估。改进后预报：{improved_forecast}。观测数据：{observations}。计算KGE、RMSE、相关系数等指标，并生成对比图表。
     ```

## 边界与分流

- **适用边界**：该框架的有效性高度依赖于步骤s2中训练数据的质量和代表性。如果历史观测数据稀缺或不能代表未来气候条件，机器学习模型的泛化能力会受限。
- **分流决策**：
  - 如果物理模型本身存在重大缺陷（如核心过程缺失），且没有足够的观测数据用于后处理训练，则应优先改进物理模型结构或进行参数重新校准，而非直接进行后处理。
  - 如果预报问题仅涉及数据的统计降尺度或时间分解，而无需利用物理模型提供的空间过程信息，可考虑纯统计或机器学习方法（如基于ARIMA的预报）。
  - 对于实时预报业务，需要评估后处理模型的计算效率是否满足时效性要求。

## 质量检查

1. **验证指标**：在独立的验证期（与训练期不重叠）计算关键技能指标，如Kling-Gupta效率（KGE）、归一化均方根误差（NRMSE）、相关系数。后处理预报的KGE应显著高于原始预报。
2. **多站点/多时段评估**：应在多个空间位置和不同水文季节（丰水期、枯水期）评估模型性能，确保改进的稳健性。
3. **物理一致性检查**：检查后处理后的预报是否保持了合理的物理约束，例如水量平衡、径流过程线的形状等，避免产生非物理的输出。

## 回退策略

- **当机器学习模型在验证期表现不佳**：检查训练数据是否充分、是否包含了极端事件；尝试调整模型架构（如LSTM的层数、神经元数）、训练策略或正则化方法；或考虑使用集成方法结合多个后处理模型。
- **当物理模型原始预报质量过差**：评估气象输入数据的质量；尝试更新物理模型的参数或结构；若条件允许，可转向使用更先进的物理模型或重新校准现有模型。
- **当缺乏长期观测数据**：采用迁移学习，使用相似气候和地理条件下的流域数据进行预训练；或采用无监督/自监督学习方法进行预处理；亦可简化为使用简单的统计偏差校正方法。

## 资源召回建议

- **物理模型**：GloFas (全球洪水预报系统)、HEC-HMS、VIC、Noah-MP等。
- **机器学习模型**：Long Short-Term Memory (LSTM)网络、Temporal Convolutional Networks (TCN)、Transformer-based models、Gradient Boosting machines (如XGBoost)。
- **统计后处理方法**：分位数映射 (Quantile Mapping)、线性回归偏差校正、贝叶斯模型平均 (BMA)。
- **评估指标库**：hydroeval (Python库)、hydroTSM包 (R语言)。
- **数据源**：ERA5再分析数据、Global Flood Awareness System (GloFas) 数据、各国水文局发布的河流观测数据。
