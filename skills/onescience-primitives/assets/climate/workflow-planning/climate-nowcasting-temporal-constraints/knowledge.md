# 气象临近预报数据时点规则

## 适用范围

**触发条件**：
- 执行气象预报任务（临近、短临、中短期）
- 需要定义数据时间约束
- 涉及实时或准实时数据处理

**适用场景**：
- 天气雷达驱动的临近预报
- 数值天气预报（NWP）
- 气象预警系统
- 航空气象服务

**不适用场景**：
- 气候模式模拟（无实时数据约束）
- 历史数据回算（不受时点限制）

## 输入

**输入数据**：
- 观测数据（雷达、卫星、地面站）
- 分析场数据（再分析资料）
- 已签发预报产品

**时间约束**：
- 资料截止时间（Data Cutoff Time）
- 起报时间（Initialization Time）
- 预报时效（Forecast Lead Time）

## 输出

**输出产物**：
- 预报产品（带时间戳）
- 数据时点检查报告
- 时间约束验证记录

**时间标准**：
- 所有输入数据时间 ≤ 起报时间
- 预报输出时间 > 起报时间
- 预报时效覆盖业务需求

## 流程节点

### Step 1: 资料截止时间确定
- **操作**：确定所有输入数据的最新可用时间
- **参数**：数据源延迟、处理时间、通信延迟
- **工具**：时间检查器
- **质量门禁**：
  - 资料截止时间已明确记录
  - 所有输入数据时间 ≤ 资料截止时间

### Step 2: 起报时间设置
- **操作**：设置预报起报时间
- **参数**：业务要求、数据可用性
- **工具**：时间管理器
- **质量门禁**：
  - 起报时间 ≤ 资料截止时间
  - 起报时间与数据时间对齐

### Step 3: 数据时间戳验证
- **操作**：检查所有输入数据的时间戳
- **参数**：时间容差、对齐方式
- **工具**：时间验证器
- **质量门禁**：
  - 无未来时间点数据（相对于起报时间）
  - 时间序列连续性检查

### Step 4: 预报时效验证
- **操作**：确认预报输出时间范围
- **参数**：预报时效、输出频率
- **工具**：时效检查器
- **质量门禁**：
  - 预报起始时间 ≥ 起报时间
  - 预报时效符合业务要求

### Step 5: 时间约束报告生成
- **操作**：记录时间约束检查结果
- **参数**：检查项、结果、异常
- **工具**：报告生成器
- **质量门禁**：
  - 报告包含完整检查项
  - 异常情况已记录

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 资料截止时间 | ≤ 起报时间 | 归因报告 | 所有输入数据的最新时间 |
| 起报时间 | ≥ 资料截止时间 | WMO标准 | 预报初始化时间 |
| 预报时效 | 0-6小时 | 业务规范 | 临近预报范围 |
| 时间容差 | ≤ 5min | 业务规范 | 时间对齐精度 |
| 未来数据检查 | 强制 | 归因报告issue#5 | 禁止使用未来数据 |
| 时间戳记录 | 必需 | 可追溯性 | 所有时间点可审计 |

## 边界与分流

**异常处理**：
- 数据时间超出范围：拒绝使用该数据
- 时间戳缺失：尝试从文件名/元数据推断
- 时间对齐失败：使用最近邻匹配或插值

**降级策略**：
- 数据延迟：使用延迟后的最新可用数据
- ⚠️ 禁止使用目标时刻之后的真实观测数据

**分支条件**：
- 实时预报：严格使用历史数据
- 回算任务：可使用全部历史数据

## 质量检查

**验证点**：
1. 资料截止时间确认
2. 输入数据时间戳验证
3. 预报输出时间范围验证
4. 时间约束报告完整性

**阈值**：
- 未来数据比例：0%（禁止）
- 时间戳完整率：100%
- 时间对齐误差：≤ 5min

**失败处理**：
- 发现未来数据：立即停止，报告违规
- 时间约束不满足：拒绝执行预报

## 回退策略

**失败时的替代方案**：
- 数据时间异常：回溯检查数据获取流程
- 时间约束不满足：重新获取正确时间范围的数据
- 无法满足时点要求：记录并等待数据更新
