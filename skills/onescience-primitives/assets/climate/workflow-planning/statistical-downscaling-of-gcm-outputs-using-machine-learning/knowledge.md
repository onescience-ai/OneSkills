# 基于机器学习的全球气候模式输出统计降尺度方法

## 适用范围

用于将全球气候模式（GCM）的低分辨率输出降尺度到站点或区域尺度，以获得更高时空分辨率的局地气候变量预测。该方法通过机器学习回归技术，在历史时期建立大尺度气候预测因子（如海平面气压、近地面气温、湿度、风速）与局地观测变量（如降水、气温）之间的统计关系，然后将此关系应用于GCM的未来情景输出，从而生成区域尺度的气候变化预测。该协议适用于利用CMIP6等模式数据进行区域气候影响评估、农业和水资源规划等场景。

## 输入

- **必需**：
  - 大尺度气候预测因子数据：如海平面气压、近地面气温、比湿、纬向和经向风速等。通常来源于全球再分析数据集（如NCEP/NCAR Reanalysis 1），时间跨度需与局地观测数据匹配（例如1980-2014年）。
  - 局地气象站观测数据：作为预测变量（predictands），例如月尺度降水量、最高气温和最低气温。数据应覆盖足够长的时间序列以支持模型训练和验证。
  - 全球气候模式（GCM）的输出数据：包括历史模拟和未来共享社会经济路径（SSP）情景（如SSP2-4.5, SSP5-8.5）的输出，用于应用训练好的降尺度模型。
- **可选**：
  - 更多候选预测因子数据（如其他再分析产品），用于变量筛选阶段比较。
  - 模型超参数优化所需的计算资源和配置。

## 输出

- 经过降尺度处理的局地气候变量预测数据，例如月尺度降水量、最高气温和最低气温的未来预测值。
- 模型性能评估报告，包含各模型在测试集上的统计指标，如决定系数（R²）、均方根误差（RMSE）、标准化均方根误差（NRMSE）、百分比偏差（PBIAS）和纳什-萨克利夫效率系数（NSE）。
- 基于最优模型和GCM情景生成的未来气候变量空间分布图和时间序列图表。

## 流程节点

1. **数据收集与整理** (`s1`)
   - 收集并整理研究区域的局地气象站观测数据（作为预测变量）和同时期、同区域的大尺度气候预测因子数据（来自再分析数据集）。
   - 上游依赖：无。
   - 关键参数：`obs_period`（观测数据时间范围，默认值“1980-2014”，字符串类型）；`variable_list`（需要的气候变量，默认值“降水量、最高气温、最低气温”，字符串类型）。
   - 质量门：数据时间连续、无重大缺失。
   - 产出：整理好的局地观测数据集和大尺度预测因子数据集。

2. **预测因子筛选** (`s2`)
   - 使用LASSO回归等正则化方法，为每个站点从众多候选预测因子中筛选出对预测变量解释力最强的子集。
   - 上游依赖：`s1`（数据收集与整理）。
   - 关键参数：`glmnet_package`（使用的R包，默认值“glmnet”，字符串类型）；`cv_folds`（交叉验证折数，默认值10，整数类型）。
   - 质量门：LASSO能将部分变量系数缩减至零，实现有效的变量选择。
   - 产出：每个站点选定的预测因子列表。

3. **数据划分与模型构建** (`s3`)
   - 将数据集按时间划分为训练集和测试集（例如，前2/3时间用于训练，后1/3用于测试），并分别构建随机森林（RF）、支持向量回归（SVR）和多元线性回归（MLR）等候选降尺度模型。
   - 上游依赖：`s2`（预测因子筛选）。
   - 关键参数：`train_ratio`（训练集比例，默认值0.67，浮点数类型）；`r_packages`（使用的R包，默认值“randomForest, e1071, caret”，字符串类型）。
   - 质量门：训练过程完成，无报错。
   - 产出：训练好的RF、SVR和MLR模型。

4. **模型验证与性能评估** (`s4`)
   - 在独立的测试集上对所有训练好的模型进行性能评估，使用多种统计指标进行综合比较。
   - 上游依赖：`s3`（数据划分与模型构建）。
   - 关键参数：`metrics`（评估指标，默认值“R², RMSE, NRMSE, PBIAS, NSE”，字符串类型）。
   - 质量门：模型R² > 0.5，NSE > 0.5，NRMSE < 0.7，PBIAS在可接受范围内。这些阈值可作为模型是否达到基本预测能力的参考标准。
   - 产出：模型性能评估报告和最优模型推荐。

5. **未来情景预测** (`s5`)
   - 根据性能评估结果，选择每个预测变量的最优降尺度模型（例如，RF用于降水，SVR用于气温），并将其应用于所选GCM的未来SSP情景输出数据，生成未来时期的局地气候预测。
   - 上游依赖：`s4`（模型验证与性能评估）。
   - 关键参数：`gcm_name`（全球气候模式名称，默认值“EC-EARTH3”，字符串类型）；`scenarios`（共享社会经济路径情景，默认值“SSP2-4.5, SSP5-8.5”，字符串类型）。
   - 质量门：预测数据在物理上合理，与历史观测趋势可比。
   - 产出：未来时期（如2020-2100）的局地降水量和气温预测数据。

6. **结果可视化与分析** (`s6`)
   - 使用GIS软件对预测结果进行空间插值（如反距离加权IDW），制作气候变化空间分布图和时间序列图，并进行分析总结。
   - 上游依赖：`s5`（未来情景预测）。
   - 关键参数：`gis_software`（GIS软件，默认值“ArcGIS 10.8”，字符串类型）；`interpolation_method`（空间插值方法，默认值“IDW”，字符串类型）。
   - 质量门：图表清晰，结论有数据支撑。
   - 产出：气候变量未来变化的空间分布图、时间序列分析图表和气候变化影响评估结论。

## 边界与分流

- **适用边界**：该统计降尺度方法的核心假设是历史时期建立的统计关系在未来气候条件下保持稳定。若气候变化导致大气环流模式发生根本性改变，模型的预测可靠性将下降。
- **替代方案**：
  - 当预测变量（如降水）具有高变异性、不连续性，或预测因子与之缺乏强相关性时，模型性能可能不理想。对于这类情况，可考虑动力降尺度方法或混合动力-统计降尺度方法。
  - 若缺乏足够长的局地观测数据来训练和验证模型，该方法可能不适用，需寻找其他数据源或方法。
- **上下游衔接**：上游需要获取格式规范、时间匹配的大尺度预测因子数据和局地观测数据。下游生成的局地预测数据可直接用于区域气候影响评估、水文模型输入、农业风险评估等应用。

## 质量检查

- 在预测因子筛选阶段，通过交叉验证确保LASSO方法能有效识别出最相关的预测因子。
- 在模型构建阶段，检查训练过程是否收敛，模型是否在训练集上拟合良好。
- 在模型验证阶段，使用独立的测试集数据，通过R²、RMSE、NRMSE、PBIAS、NSE等多个指标综合评估模型性能。通用参考阈值为：NSE ≥ 0.5（表示模型具有基本的预测能力），NRMSE < 0.7（表示误差在可接受范围）。具体阈值可能因变量（降水 vs. 气温）和应用领域要求而异。
- 在情景预测阶段，检查预测结果是否在物理上合理，例如降水不应为负值，气温变化趋势是否与区域气候变化的一般认知相符。

## 回退策略

- **预测因子相关性弱**：若LASSO筛选后剩余预测因子与预测变量的相关性仍然很弱，应重新审视预测因子列表，考虑引入其他物理意义明确的大尺度环流指数或海表温度等变量。
- **模型性能不达标**：若所有候选模型在测试集上的NSE均低于0.5或NRMSE高于0.7，表明当前统计关系不够强。应回退检查数据质量（如缺失值、异常值），或考虑使用更复杂的非线性模型、集成学习方法，甚至转向动力降尺度方案。
- **训练数据不足**：若可用的观测数据时间序列过短（如少于20年），模型可能无法捕捉足够的气候变异性。此时，应谨慎解释预测结果，并明确说明模型的不确定性范围，或尝试使用再分析数据延长训练期（需验证其与观测数据的一致性）。

## 资源召回建议

- **再分析数据获取**：NCEP/NCAR Reanalysis 1等全球再分析数据集可通过美国国家海洋和大气管理局（NOAA）物理科学实验室（PSL）网站获取。
- **气候模式数据**：CMIP6模式数据可通过气候变化建模计划（CMIP）的官方数据门户下载。
- **软件工具**：
  - R语言：使用`glmnet`包进行LASSO变量选择，`randomForest`包构建随机森林模型，`e1071`包构建支持向量回归模型，`caret`包进行模型训练与比较。
  - GIS软件：如ArcGIS、QGIS等，用于空间插值和地图可视化。
- **评估指标**：可参考水文和气候模型评估的通用文献，了解R²、RMSE、NSE等指标的计算公式和解释标准。
