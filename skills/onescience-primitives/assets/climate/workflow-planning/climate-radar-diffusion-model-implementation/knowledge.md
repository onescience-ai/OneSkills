# 雷达临近预报扩散概率模型实现规范

## 适用范围
适用于天气雷达驱动的冰雹概率临近预报任务，需要生成概率场而非确定性预报的场景。特别适用于需要量化预报不确定性的业务场景。

## 输入
- 多帧雷达反射率序列（时间维度）
- 环境场数据（如CAPE、风场、温度场）
- 模型配置参数（扩散步数、噪声调度等）

## 输出
- 概率场输出（每个网格点的冰雹发生概率）
- 集合扰动生成的多成员概率分布
- 模型置信度指标

## 流程节点
1. **条件输入编码** → 2. **前向扩散过程** → 3. **反向去噪过程** → 4. **概率场解码** → 5. **集合扰动生成**

### 步骤1：条件输入编码
- 操作：使用UNet编码器提取多帧雷达+环境场特征
- 参数：编码器层数、特征维度、跳跃连接
- 工具：PyTorch UNet实现
- 质量门禁：编码器输出维度匹配解码器输入要求

### 步骤2：前向扩散过程
- 操作：对编码特征添加噪声，生成噪声时间序列
- 参数：扩散步数T、噪声调度策略、噪声类型
- 工具：自定义扩散调度器
- 质量门禁：噪声添加符合预定调度策略

### 步骤3：反向去噪过程
- 操作：使用UNet解码器逐步去噪，生成预测特征
- 参数：去噪步数、学习率、损失函数
- 工具：PyTorch训练循环
- 质量门禁：去噪过程收敛，损失函数下降

### 步骤4：概率场解码
- 操作：将去噪后的特征解码为概率场
- 参数：解码器结构、激活函数（sigmoid）
- 工具：PyTorch解码器
- 质量门禁：输出概率值在[0,1]范围内

### 步骤5：集合扰动生成
- 操作：通过不同初始噪声生成多个扰动成员
- 参数：扰动数量、噪声方差、物理约束
- 工具：随机数生成器、物理一致性检查
- 质量门禁：扰动成员间差异合理，符合物理规律

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| UNet编码器 | 卷积层+跳跃连接 | [归因报告issue2] | 提取多尺度特征 |
| UNet解码器 | 转置卷积+注意力 | [归因报告issue2] | 生成概率场 |
| 扩散步数T | 100 | [归因报告issue2] | 控制噪声添加程度 |
| 噪声调度 | linear | [归因报告issue2] | 噪声方差随时间线性增加 |
| 条件输入融合 | 拼接/注意力 | [归因报告issue2] | 雷达+环境场融合方式 |
| 集合扰动数量 | 10-50 | [归因报告issue2] | 生成概率分布 |

## 边界与分流
- **计算资源不足**：减少扩散步数或集合扰动数量
- **模型不收敛**：调整学习率或网络结构
- **概率场不合理**：添加物理约束（如CAPE调制）
- **推理速度过慢**：使用蒸馏或加速采样方法

## 质量检查
- 验证点：概率场统计特征、集合离散度、物理一致性
- 阈值：概率均值[0.1, 0.5]、集合标准差[0.05, 0.2]
- 失败处理：调整模型参数或降级为简单外推

## 回退策略
1. 降级为简单反射率外推+sigmoid转换（如归因报告中描述）
2. 使用传统集合预报方法（如ECMWF EPS）
3. 采用多模式集成替代扩散模型
