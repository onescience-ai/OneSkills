# 光伏功率预测标准工作流步骤

## 适用范围

光伏功率预测任务的标准执行流程，涵盖从数据获取到验证报告的完整工作流。适用于0-48小时功率联合预报场景，确保关键步骤不被遗漏，输入输出契约得到满足。

## 输入

- **任务需求**：预测目标、预测时效、站点列表
- **数据源配置**：天气预报、历史功率、电站属性
- **资源配置**：计算资源、存储资源、网络资源

## 输出

- **执行清单**：各步骤的执行状态和产物
- **验证报告**：分层验证结果和验收判定
- **最终报告**：任务执行总结和建议

## 流程节点

### s01 数据预检与获取

**操作**：
- 识别并获取所有必需数据源
- 执行数据可用性检查
- 验证数据时点合规性
- 执行数据质量预检

**输入**：
- 数据源配置清单
- 任务签发时间

**输出**：
- 数据可用性报告
- 数据质量预检报告
- BLOCKED状态（若数据不可用）

**质量门禁**：
- 所有必需数据源可用
- 数据时点合规
- 缺测率 < 5%

**依赖关系**：无前置步骤

### s02 时空对齐与预处理

**操作**：
- 时间戳对齐（统一时区、处理夏令时）
- 空间对齐（统一坐标系、处理投影）
- 数据预处理（容量归一化、缺测处理、异常值检测）
- 特征工程（滞后特征、天气特征、时间特征）

**输入**：
- s01输出的原始数据
- 预处理配置

**输出**：
- 对齐后的标准化数据集
- 特征工程后的特征矩阵
- 预处理报告

**质量门禁**：
- 时间戳对齐误差 < 1分钟
- 缺测率 < 5%
- 异常值处理完成

**依赖关系**：s01

### s03 方法配置与输入输出契约验证

**操作**：
- 选择预测方法（基于领域知识）
- 配置模型参数
- 验证输入输出契约
- 准备训练/验证数据划分

**输入**：
- s02输出的特征矩阵
- 方法选择配置

**输出**：
- 方法配置文档
- 输入输出契约验证报告
- 数据划分方案

**质量门禁**：
- 方法选择与预测时效匹配
- 输入输出契约满足
- 数据划分按时间顺序

**依赖关系**：s02

### s04 核心计算与模型训练

**操作**：
- 模型训练（使用训练集）
- 超参数调优（使用验证集）
- 过拟合检测（比较训练/验证性能）
- 模型选择（基于验证集性能）

**输入**：
- s03输出的训练/验证数据
- 方法配置

**输出**：
- 训练好的模型
- 训练报告（包含性能指标）
- 模型选择决策

**质量门禁**：
- 过拟合R²差异 < 0.1
- 验证集R² > 0.5
- 模型选择基于验证集性能

**依赖关系**：s03

### s05 结果生成与产品输出

**操作**：
- 使用训练好的模型进行预测
- 生成功率预测结果
- 生成概率预报（若需要）
- 格式化输出产品

**输入**：
- s04输出的训练好的模型
- 预测输入数据

**输出**：
- 功率预测结果（逐站、逐时效）
- 概率预报结果（分位数、置信区间）
- 预测产品文件

**质量门禁**：
- 预测值在合理范围内 [0, P_installed]
- 输出格式符合规范
- 预测时效覆盖0-48小时

**依赖关系**：s04

### s06 分层验证与报告生成

**操作**：
- 执行分层验证（按站点、时效、天气类型）
- 执行爬坡事件检测与检验
- 执行基线比较
- 设置验收门限并判定
- 生成验证报告和最终报告

**输入**：
- s05输出的预测结果
- 实测数据
- 验证配置

**输出**：
- 分层验证报告
- 爬坡事件分析报告
- 基线比较表
- 验收判定结果
- 最终报告

**质量门禁**：
- 各层指标计算正确
- 爬坡事件F1 ≥ 0.60
- 基线技巧评分 > 0
- 验收门限设置合理

**依赖关系**：s05

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据划分比例 | 70/15/15 | [1] | 训练/验证/测试 |
| 过拟合阈值 | R²差异 < 0.1 | [1] | 训练/验证性能差异 |
| 验证集R²下限 | > 0.5 | [1] | 模型可用最低要求 |
| 爬坡事件F1 | ≥ 0.60 | [2] | 检测准确性要求 |
| 缺测率上限 | < 5% | [1] | 数据质量要求 |

### 校准数值（供参考）
以下数值来自瑞士和尼日利亚的光伏预测研究[1][2]，其他体系需以自身证据重新锚定：
| 步骤 | 典型耗时 | 备注 |
|------|----------|------|
| s01数据预检 | 5-10% | 依赖数据源数量 |
| s02时空对齐 | 10-15% | 依赖数据量 |
| s03方法配置 | 5-10% | 依赖方法复杂度 |
| s04核心计算 | 50-60% | 依赖模型和数据量 |
| s05结果生成 | 5-10% | 依赖预测规模 |
| s06分层验证 | 10-15% | 依赖验证复杂度 |

## 边界与分流

**步骤失败时**：
- s01数据不可用 → 标记BLOCKED，停止执行
- s02预处理失败 → 检查数据质量，降级处理
- s03方法不匹配 → 重新选择方法
- s04训练失败 → 检查数据和参数，降级为基线模型
- s05预测异常 → 检查模型和输入，使用持久性预报
- s06验证失败 → 分析原因，降低验收门限

**资源受限时**：
- 计算资源不足 → 使用简单模型（RF、XGBoost）
- 存储资源不足 → 降低数据粒度
- 时间受限 → 并行执行步骤，优先保证核心步骤

**数据质量问题**：
- 缺测率高 → 降级处理或使用相似电站数据
- 异常值多 → 加强质量控制
- 时点违规 → 标记BLOCKED，停止执行

## 质量检查

- **步骤完整性**：是否执行了所有s01-s06步骤
- **输入输出契约**：每个步骤的输入输出是否满足
- **依赖关系**：步骤顺序是否正确
- **质量门禁**：每个步骤的质量门禁是否通过
- **验证报告**：是否包含分层验证、爬坡事件、基线比较

## 回退策略

- 若s01-s06中有步骤失败，可退化为基线模型（持久性预报）
- 若验证失败，可降低验收门限并标注
- 若资源不足，可并行执行或简化流程
