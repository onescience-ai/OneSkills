# 临近预报检验指标业务基准值范围

## 适用范围
适用于天气雷达驱动的冰雹概率临近预报任务的验证阶段，特别是需要评估预报技巧和业务性能的场景。不适用于仅使用合成数据进行算法流程验证的场景。

## 输入
- 预报概率场
- 观测/验证标签
- 检验指标计算脚本

## 输出
- 检验指标计算结果（CSI、FSS、Brier Score等）
- 业务基准对比报告
- 合成数据局限性说明

## 流程节点
1. **指标计算** → 2. **业务基准对比** → 3. **局限性分析** → 4. **报告生成** → 5. **结果解释**

### 步骤1：指标计算
- 操作：计算标准检验指标
- 参数：CSI、FSS、Brier Score、ROC_AUC等
- 工具：指标计算脚本
- 质量门禁：指标计算正确，数值在合理范围内

### 步骤2：业务基准对比
- 操作：将计算结果与业务基准值对比
- 参数：业务基准值范围、对比方法
- 工具：基准对比脚本
- 质量门禁：对比结果准确，差异分析合理

### 步骤3：局限性分析
- 操作：分析合成数据对指标的影响
- 参数：合成数据特点、指标虚高原因
- 工具：局限性分析脚本
- 质量门禁：局限性分析全面，原因解释清楚

### 步骤4：报告生成
- 操作：生成检验报告
- 参数：指标结果、基准对比、局限性说明
- 工具：报告生成脚本
- 质量门禁：报告完整，包含必要信息

### 步骤5：结果解释
- 操作：解释检验结果的实际意义
- 参数：业务性能评估、方法改进建议
- 工具：结果解释框架
- 质量门禁：解释合理，建议可行

## 边界与分流
- **指标超出基准范围**：分析原因，可能是方法优秀或数据问题
- **合成数据指标异常高**：明确标注局限性，不作为业务性能依据
- **业务基准不适用**：参考相关领域基准或咨询专家
- **多指标矛盾**：综合分析，以主要指标为准

## 质量检查
- 验证点：指标计算正确性、基准对比准确性、局限性分析全面性
- 阈值：指标计算误差<1%、基准对比准确
- 失败处理：重新计算指标或修正分析方法

## 回退策略
1. 使用合成数据指标但明确标注局限性
2. 参考相关文献中的业务基准值
3. 采用相对比较而非绝对数值评估
