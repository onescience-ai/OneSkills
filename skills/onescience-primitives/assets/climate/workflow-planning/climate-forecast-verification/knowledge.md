# 预报验证知识卡片

## 适用范围

### 触发条件
- 任务需要进行独立验证和基线比较
- 需要计算降水预报验证指标
- 需要获取验证数据并评估预报性能

### 适用场景
- 气象预报系统性能评估
- 模型对比和基线比较
- 业务预报质量监控

### 不适用场景
- 模型训练过程中的验证（使用验证集）
- 实时业务预报（使用在线评估）

## 输入

### 验证数据来源
| 数据类型 | 来源 | 说明 | 获取方式 |
|---------|------|------|---------|
| 地面雨量站 | CMA站网 | 观测真值 | 数据共享平台 |
| 雷达反演降水 | 雷达定量估测 | 高分辨率真值 | 雷达数据产品 |
| 卫星反演降水 | GPM/IMERG | 全球覆盖真值 | NASA公开数据 |
| 再分析数据 | ERA5/ERA5-Land | 参考数据 | ECMWF公开数据 |

### 基线预报类型
| 基线类型 | 说明 | 适用场景 |
|---------|------|---------|
| 持续性预报 | 假设未来=当前 | 短期临近预报 |
| 气候态预报 | 使用历史气候统计 | 季节预报 |
| 模式输出统计(MOS) | 统计后处理结果 | 业务预报 |
| 简单外推 | 线性外推 | 雷达临近预报 |

## 输出

### 验证指标
| 指标类别 | 指标名称 | 说明 | 目标值 |
|---------|---------|------|--------|
| 连续变量 | RMSE | 均方根误差 | 越小越好 |
| 连续变量 | MAE | 平均绝对误差 | 越小越好 |
| 连续变量 | MAPE | 平均绝对百分比误差 | 越小越好 |
| 概率变量 | CRPS | 连续排序概率分数 | 越小越好 |
| 概率变量 | Brier Score | 二值事件概率评分 | 越小越好 |
| 分类变量 | POD | 命中率 | 越接近1越好 |
| 分类变量 | FAR | 虚警率 | 越接近0越好 |
| 分类变量 | CSI | 临界成功指数 | 越接近1越好 |

### 验证报告
- 指标计算结果表格
- 技能评分（相对基线的改进）
- 空间分布图
- 时间序列图

## 流程节点

### 验证标准流程
```
验证数据准备 → 预报-观测对齐 → 指标计算 → 基线比较 → 技能评分 → 报告生成
```

### 每步操作
| 步骤 | 操作 | 工具 | 参数 | 质量门禁 |
|------|------|------|------|---------|
| 1. 数据准备 | 加载验证数据 | xarray/pandas | - | 数据完整 |
| 2. 对齐 | 时间空间匹配 | xarray.sel | - | 匹配率>95% |
| 3. 指标计算 | 计算验证指标 | xskillscore | - | 无错误 |
| 4. 基线比较 | 计算基线指标 | xskillscore | - | 基线合理 |
| 5. 技能评分 | 计算改进比例 | 公式 | (基线-预报)/(基线-完美) | >0 |
| 6. 报告生成 | 生成验证报告 | matplotlib | - | 图表清晰 |

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 最小验证样本量 | 100 | [论文37] | 确保统计显著 |
| 空间匹配半径 | 10km | [论文34] | 雷达-雨量站匹配 |

## 边界与分流

### 异常处理
| 异常情况 | 处理策略 | 降级方案 |
|---------|---------|---------|
| 验证数据缺失 | 使用替代数据源 | 降低验证标准 |
| 样本量不足 | 使用自助法估计 | 标注不确定性 |
| 基线不可用 | 使用简单基线 | 仅报告绝对指标 |

### 分支条件
- 若验证降水：使用CRPS、POD、FAR等
- 若验证温度：使用RMSE、MAE、偏差
- 若验证风速：使用RMSE、MAE、方向误差

## 质量检查

### 验证点
1. 数据完整性：缺失值<5%
2. 对齐正确性：时空匹配正确
3. 指标合理性：在文献报道范围内
4. 技能评分：>0表示优于基线

### 阈值
| 指标 | 阈值 | 失败处理 |
|------|------|---------|
| 数据匹配率 | >95% | 重新对齐 |
| CRPS技能评分 | >0 | 检查模型 |
| POD | >0.7 | 调整阈值 |
| FAR | <0.3 | 调整阈值 |

## 回退策略

1. **验证数据不可用**: 使用再分析数据（ERA5）作为替代
2. **基线不可用**: 仅报告绝对指标
3. **样本量不足**: 使用非参数统计方法
