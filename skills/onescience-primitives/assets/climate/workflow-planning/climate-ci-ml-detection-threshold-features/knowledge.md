# 对流初生检测：ML方法、特征工程与阈值校准

## 适用范围

面向静止气象卫星数据的对流初生（CI）检测任务，覆盖方法选择、特征工程和概率阈值校准全流程。适用于使用卫星多光谱亮温数据进行CI二分类检测（发生/不发生）或多分类预测（Developing/Declining）的场景。不适用于不使用卫星数据的纯雷达CI检测，也不适用于CI后的对流系统追踪。

## 输入

**特征数据**（卫星多光谱通道）：
- 红外通道亮温：10.7–12.4 μm（云顶温度代理）
- 水汽通道亮温：6.2–7.3 μm（中高层水汽）
- 短波红外通道：1.6–3.75 μm（云相态、粒子大小）
- 可见光通道：0.65 μm（云纹理，仅白天可用）

**派生特征**（物理意义特征）：
- 通道亮温差：如BT(6.25)−BT(10.8)、BT(13.5)−BT(10.8)
- 亮温冷却率：连续时次间BT变化量
- 云顶温度趋势：多时次BT序列的斜率
- 亮温梯度：空间邻域内的BT变化

**标签数据**：
- 二分类标签：CI发生（1）/CI未发生（0）
- 多分类标签：Developing CI（1）、Declining CI（0）、无CI（-1）

## 输出

**输出产物**：
- 训练好的CI检测模型
- 校准后的检测阈值
- 阈值选择报告（ROC曲线、F1-score分析）
- 模型特征重要性排序

## 流程节点

### Step 1：特征工程
- **操作**：从卫星多光谱数据中提取CI检测特征
- **参数**：通道组合、时间窗口、空间邻域大小
- **工具**：numpy, xarray
- **质量门禁**：
  - 特征与CI形成有物理关联
  - 特征在推理时可实时获取
  - 缺失通道特征有降级方案

**核心特征体系**（来源[1][2][3]）：

| 特征类别 | 具体特征 | 物理依据 | 来源 |
|----------|---------|---------|------|
| 亮温绝对值 | BT(10.8μm), BT(12.4μm) | 云顶高度代理 | [1][3] |
| 亮温差 | BT(6.25)−BT(10.8), BT(13.5)−BT(10.8) | 水汽层结、云顶冲顶 | [1][2] |
| 冷却率 | ΔBT/Δt（连续时次差） | 云发展速率 | [1][2][3] |
| 空间梯度 | 邻域BT标准差 | 云边界锐度 | [3] |
| 纹理特征 | 亮温方差、对比度 | 云组织化程度 | [2] |

### Step 2：模型选择与训练
- **操作**：选择合适的ML模型并训练
- **参数**：模型类型、超参数、交叉验证策略
- **工具**：scikit-learn（RF/XGBoost）、PyTorch/TensorFlow（CNN/DL）
- **质量门禁**：
  - 模型在验证集上AUC≥0.80
  - 训练集/验证集无数据泄露
  - 类别不平衡已处理（过采样/欠采样/加权损失）

**模型选择决策**（来源[1][2]）：

| 模型 | 适用条件 | 优势 | 劣势 |
|------|---------|------|------|
| 随机森林（RF） | 样本量中等（10³–10⁵），特征维度<50 | 可解释性强，训练快 | 对高维时序特征捕捉有限 |
| XGBoost | 样本量中等，需高精度 | 精度高，支持缺失值 | 调参复杂度较高 |
| CNN/3D-CNN | 样本量大（>10⁵），时空特征丰富 | 自动特征提取，捕捉时空模式 | 需大量数据，可解释性差 |
| Transformer | 超大样本量（>10⁶），长序列依赖 | 捕捉长程时序依赖 | 训练成本极高 |

### Step 3：阈值选择与校准
- **操作**：基于验证集确定最优检测阈值
- **参数**：优化目标（F1/F2/POD）、业务约束（FAR上限）
- **工具**：sklearn.metrics（precision_recall_curve, roc_curve）
- **质量门禁**：
  - 阈值基于数据统计确定，非固定经验值
  - 进行敏感性分析（阈值±0.05范围内的指标变化）
  - 最大预测概率≥阈值（避免零检测）

**阈值选择方法**（来源[1][2]）：

| 方法 | 操作 | 适用场景 |
|------|------|---------|
| ROC曲线最优点 | 最大化TPR−FPR（Youden's J） | 平衡命中率和虚报率 |
| F1-score最大化 | 最大化2·P·R/(P+R) | 类别不平衡时 |
| F2-score最大化 | 偏重召回率（漏报代价高） | CI预警（宁可多报不可漏报） |
| 业务约束优化 | 在FAR≤α约束下最大化POD | 业务运行（虚报成本高） |
| 概率校准后阈值 | 先校准概率再选阈值 | 概率输出需可信 |

**CI概率典型范围**（来源[1][3]）：
- CI概率通常在0.1–0.8之间
- 阈值选择需考虑区域和季节差异
- 固定阈值（如0.5）可能导致零检测（当最大预测概率<阈值时）

### Step 4：概率校准
- **操作**：将模型原始输出校准为可信概率
- **参数**：校准方法（Platt scaling/Isotonic regression）
- **工具**：sklearn.calibration.CalibratedClassifierCV
- **质量门禁**：
  - 校准后Brier score改善
  - 校准曲线接近对角线

## 关键参数

### 通用判据

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| CI雷达定义阈值 | ≥35 dBZ | [1] | 对流单体首次观测标准 |
| 模型AUC目标 | ≥0.80 | [1][2] | 二分类区分能力 |
| POD目标 | ≥0.70 | [1] | 命中率下限 |
| FAR上限 | ≤0.30 | [1] | 虚报率上限 |
| 类别不平衡比 | 记录正负样本比 | [1] | 影响采样策略 |
| 时间提前量 | 0–60分钟 | [1][2] | CI预报的lead time |

### 校准数值（华南CI体系）

| 参数 | 值 | 来源 | 说明 |

## 边界与分流

- **样本量不足（<1000）**：使用简单阈值法作为baseline，记录限制，不得声称使用了ML方法
- **类别严重不平衡（>1:100）**：必须使用过采样/欠采样或加权损失函数
- **最大预测概率<阈值**：阈值过高导致零检测，必须降低阈值或使用自适应阈值
- **概率校准失败**：使用未校准概率输出，但在报告中说明不确定性
- **特征缺失关键通道**：使用可用通道子集，降级并记录

## 质量检查

1. 特征有效性：每个特征与CI有物理关联，非随机噪声
2. 模型性能：AUC≥0.80，POD≥0.70，FAR≤0.30
3. 阈值合理性：阈值基于数据统计，非固定经验值
4. 零检测检查：最大预测概率必须≥检测阈值
5. 概率校准：校准曲线接近对角线，Brier score合理

## 回退策略

- ML模型训练失败：回退到基于物理阈值的方法（如固定亮温差阈值）
- 特征工程不可行：使用原始通道亮温作为输入
- 阈值校准不稳定：使用多个阈值的集成或范围输出
