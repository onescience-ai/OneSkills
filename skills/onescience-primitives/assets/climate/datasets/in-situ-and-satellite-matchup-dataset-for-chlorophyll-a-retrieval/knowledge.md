# 叶绿素a反演原位与卫星匹配数据集

## 适用范围

叶绿素a（Chlorophyll-a, Chla）是水体富营养化评价和初级生产力估算的核心指标。遥感反演是实现大面积、高频次 Chla 监测的主要手段，而算法的开发与评估依赖于高质量的原位-卫星匹配数据集。此类数据集适用于以下任务：

- 训练机器学习或半分析反演模型（如神经网络、混合密度网络等），建立遥感反射率到 Chla 浓度的映射关系；
- 通过留出验证集或交叉验证评估算法的精度与泛化能力；
- 在近同步卫星影像条件下，评估算法应对真实大气校正误差、空间异质性和时间错配等噪声的鲁棒性；
- 为不同传感器（如 Landsat-8 OLI、Sentinel-2 MSI、MODIS 等）的 Chla 反演提供基准参考。

该数据集典型应用于内陆湖泊、水库、海湾、河口及近岸海域等光学复杂水体的 Chla 遥感监测场景。

## 输入

构建此类匹配数据集需要以下输入：

**必需输入：**
- 原位辐射测量数据：包括水面遥感反射率（Rrs）光谱，理想情况下为高光谱分辨率测量，覆盖目标传感器的波段范围；
- 原位生物地球化学参数：至少包含 Chla 浓度测量值（叶绿素a浓度，单位通常为 μg/L）；
- 卫星影像数据：与原位测量近同步的 Level-1T 或 Level-1TP 级别影像（如 Landsat-8 OLI），以及成功的大气校正产品或中间产品（如水面上行辐亮度或遥感反射率）。

**可选输入：**
- 辅助水质参数：悬浮物浓度、有色溶解有机物（CDOM）吸收系数等，用于多组分分析或质量筛查；
- 气象与环境数据：风速、太阳天顶角、观测几何等，用于误差源分析；
- 水体分类信息：营养状态类型、水体类别标签等，用于分层验证。

**数据来源渠道：**
原位数据通常从国际/国家水质数据库检索获取，例如美国 Water Quality Portal (WQP)、NOAA Chesapeake Bay Interpretive Buoy System、加拿大 Environment and Climate Change Canada (ECCC) 水质数据库、World Ocean Database (WOD) 等。此外，也包括研究团队自行组织的航次观测、浮标监测和站点巡检数据。

## 输出

该数据集的产出物包括：

1. **Type A 训练-验证数据集**：由共定位（co-located）的原位辐射光谱与 Chla 浓度配对构成，用于模型训练和内部交叉验证。典型规模为数千组配对（如 4,000–5,000 组），覆盖多种水体类型和营养状态。该数据集的核心特征是辐射数据与生物地球化学参数在时间和空间上高度同步，代表理想条件下的输入-输出关系。

2. **Type B 卫星匹配验证数据集**：由近同步的卫星影像像元值与原位 Chla 测量值配对构成，用于评估算法在真实业务化场景中的性能。该数据集包含了大气校正残差、空间异质性、时间错配等实际噪声，是算法泛化能力的最终检验标准。典型规模为数千组配对（如 3,000–4,000 组）。

3. **性能评估基准**：基于上述数据集的算法精度指标，包括均方根误差（RMSE）、平均绝对百分比误差（MAPE）、决定系数（R²）等。

## 数据构建流程节点

以下为从原始数据到可用匹配数据集的典型构建流程：

**1. 原位数据采集与汇编**
- 在全球或区域范围内，从湖泊、海湾、河口、海岸线、河流等多种水体类型中收集原位辐射测量和 Chla 浓度数据；
- 数据来源包括航次实测、浮标自动监测、站点巡检等；
- 汇编至统一数据库，确保每条记录包含时间戳、地理坐标、Rrs 光谱和 Chla 测量值。

**2. 光谱重采样**
- 将高光谱原位 Rrs 数据按照目标传感器的相对光谱响应函数（Relative Spectral Response Functions）进行重采样，使其与卫星波段配置匹配；
- 以 Landsat-8 OLI 为例，需将其 6 个陆地/水体波段（Band 1–5, Band 7）的响应函数应用于原位光谱。

**3. 数据预处理**
- **Rrs 预处理**：采用稳健的中位数中心化-四分位距（Robust Median-Centering IQR）标准化方法，以训练集为拟合基准进行特征缩放；
- **Chla 预处理**：对 Chla 浓度进行对数变换，并映射到特定区间（如 [-1, 1]），以改善模型训练时的数值分布；
- 以上预处理参数（中心化均值、IQR 缩放因子、对数变换参数等）均以训练集统计量为准，验证集和测试集使用训练集参数进行变换，不得重新拟合。

**4. 数据集划分**
- 将 Type A 数据划分为训练集、验证集和测试集（典型比例约 70:15:15 或 80:10:10）；
- 划分时需注意空间和时间的独立性，避免训练集与验证/测试集在空间上过度聚集或在时间上重叠。

**5. 卫星匹配构建**
- 根据原位测量的时间和位置，检索近同步的卫星影像（时间窗口通常为 ±1 天至 ±3 天，视传感器重访周期而定）；
- 从 Level-1TP 级别影像出发，执行大气校正流程（如 SeaDAS 处理链），获取水面遥感反射率；
- 在影像上提取原位坐标对应像元或邻域窗口的 Rrs 值，与原位 Chla 配对形成 Type B 数据集；
- 严格执行时空匹配标准，记录每次匹配的时间差、空间距离等元信息。

**6. 质量筛查与标注**
- 排除大气校正失败、云/阴影污染、岸线混合像元等低质量匹配；
- 标注数据来源、采集方法、传感器型号等元信息，便于后续溯源和分层分析。

## 边界与分流

**适用边界：**
- 本数据集主要针对单传感器（如 Landsat-8 OLI）的 Chla 反演，不同传感器的波段配置和辐射特性差异较大，跨传感器迁移需重新构建匹配数据集或进行波段等效重采样；
- 数据集对水体类型有隐含的采样偏差——若原位数据集中某类水体（如深水湖泊）占比过高，算法在另一类水体（如浅水浑浊河流）上的表现可能下降，需在数据构建时关注采样平衡。

**应分流的情形：**
- 若研究目标为**悬浮物或 CDOM 等多组分同步反演**，需构建包含多参数同步测量的匹配数据集，本数据集仅含 Chla 参数不足以支撑；
- 若研究对象为**海洋开阔水域**（Case-1 水体），其光学特性与内陆复杂水体（Case-2 水体）差异显著，应使用专门的海洋遥感匹配数据集（如 NASA Ocean Color 胶体数据集）；
- 若需要**高时空分辨率监测**（如逐日观测），应转向 MODIS、VIIRS 等高重访频率传感器的匹配数据集，Landsat 系列 16 天重访周期难以满足需求；
- 若算法为**半分析或解析模型**（非数据驱动），匹配数据集的用途限于参数校准和验证，而非模型训练。

**上下游衔接：**
- 上游：大气校正处理链（如 SeaDAS、6S、MODTRAN）的输出质量直接决定 Type B 数据集的可用性；
- 下游：匹配数据集的输出直接对接机器学习模型（如 MDNB、随机森林、XGBoost）或半分析算法的训练与验证流程。

## 质量检查

**原位数据质量：**
- 检查 Rrs 光谱是否满足物理约束（如 Rrs 在各波段应为正值且随波长变化平滑，不存在异常尖峰或负值）；
- 核实 Chla 测量方法的一致性（荧光法、分光光度法、HPLC 等方法间存在系统偏差，混用需谨慎）；
- 检查时间戳和坐标的完整性与合理性。

**匹配质量：**
- 监控时间差分布（原位与卫星影像的时间间隔），过大的时间差（如 >3 天）会引入显著的 Chla 时变误差；
- 检查空间匹配窗口内像元值的标准差，过高的空间异质性意味着单像元提取无法代表原位测量范围；
- 统计大气校正成功率，失败率过高（如 >30%）提示大气条件或校正算法存在问题。

**数据集整体质量：**
- 检查 Chla 浓度的分布范围和营养状态覆盖度，确保涵盖寡营养到富营养的完整梯度；
- 检查是否存在因数据筛选导致的系统性偏差（如仅保留大气校正成功的数据，可能偏向低浑浊度/低营养条件，导致高浓度端数据不足）；
- 评估训练集与验证集的独立性，避免空间自相关导致的精度高估。

## 回退策略

- **大气校正失败率过高**：若在高营养或浑浊水域大气校正持续失败，可考虑使用经验大气校正方法（如近红外波段归一化）替代物理校正，或直接使用 Level-2 级产品（若可用）；也可将这些水域的匹配数据从 Type B 中排除，但在算法评估报告中需明确说明此限制。

- **原位数据不足**：若特定水体类型（如小型水库、热带河流）的原位数据稀缺，可采用以下策略：（1）从 Type A 训练数据中筛选光学性质相似的水体作为代理；（2）使用半合成数据（基于辐射传输模型模拟）扩充训练集；（3）明确声明算法在该水体类型上的适用性未经充分验证。

- **匹配数据集规模过小**：若 Type B 卫星匹配数据不足（如 <500 组），统计显著性有限，此时应以 Type A 内部验证为主，Type B 结果仅作参考性展示，并在后续工作中持续积累匹配数据。

- **训练数据浓度偏差**：若数据集因质量筛选导致浓度分布偏向低值端，应在模型评估时使用未筛选的全量数据（即使含噪声）作为补充验证，或在报告中注明算法在高浓度端的泛化能力未经充分检验。

- **仪器与方法误差**：原位辐射仪器的校准状态和 Chla 分析方法的差异是固有误差源，应在数据集元信息中完整记录仪器型号、校准日期和分析方法，便于使用者评估误差传递。

## 资源召回建议

- **大气校正工具**：SeaDAS（NASA 水色数据处理标准工具链）、ACOLITE（针对高分辨率水体遥感的大气校正工具）、6S 辐射传输模型；
- **原位数据库**：Water Quality Portal (WQP)、World Ocean Database (WOD)、ECCC 水质数据库、NOAA 浮标系统数据；
- **卫星数据获取**：USGS EarthExplorer（Landsat 系列）、Copernicus Open Access Hub（Sentinel 系列）；
- **光谱响应函数**：各传感器的相对光谱响应函数文件通常随数据产品分发，或从传感器技术文档中获取；
- **相关算法资产**：叶绿素a反演算法（如 MDN 模型、经验波段比值算法、半分析算法）、水质多参数反演流程、水体光学分类方法。
