# 降水临近预报评估指标

## 适用范围

用于降水临近预报（precipitation nowcasting）模型的定量性能评估。典型的评估对象包括基于深度学习的雷达回波外推模型、光流法外推模型以及其他像素级降水预报方法。当需要在统一基准下比较不同模型的预报精度、检测能力和误差特征时，使用本指标集。

触发条件：已完成模型训练并生成了与真值时空对齐的预测序列，且目标输出为像素级雷达回波强度或降水率。

## 输入

- 必需：
  - **预测序列**：模型输出的逐像素雷达回波强度或降水率矩阵序列（时间步通常为 6–15 步，每步间隔 5–10 分钟）。
  - **真值序列（ground truth）**：与预测序列同分辨率、同时间窗口的观测数据，通常来自雷达观测或地面雨量站插值。
- 可选：
  - 不同降水阈值（如 1 mm/h、5 mm/h），用于多阈值评估。
  - 空间掩膜，用于排除雷达覆盖盲区或非感兴趣区域。

## 输出

计算结果为以下五项指标的数值（每个指标对应一个标量分数）：

| 指标 | 含义 | 取值范围 | 越大/越小越好 |
|------|------|----------|----------------|
| Rainfall-MSE | 预测与真值降水率之间的均方误差 | ≥ 0 | 越小越好 |
| CSI | 临界成功指数，综合衡量命中、漏报与误报 | [0, 1] | 越大越好 |
| FAR | 误报率 | [0, 1] | 越小越好 |
| POD | 检测概率（命中率） | [0, 1] | 越大越好 |
| Correlation | 预测与真值的空间相关系数 | [-1, 1] | 越大越好 |

## 流程节点

### 步骤 1：降水率转换

若模型输出为像素级雷达回波强度（dB），需先通过 Z-R 关系将其转换为降水率（mm/h）：

$$Z = 10 \log a + 10b \log R$$

其中 $Z$ 为雷达回波强度（dB），$R$ 为降水率（mm/h），$a$ 和 $b$ 为经验常数。一组常用的参数为 $a = 118.239$，$b = 1.5241$，对应 Marshall-Palmer 型 Z-R 关系。

转换后得到逐像素降水率矩阵 $R_{\text{pred}}$（预测）和 $R_{\text{truth}}$（真值）。

### 步骤 2：Rainfall-MSE 计算

在所有预测时间步和空间网格上，计算预测降水率与真值降水率的均方误差：

$$\text{Rainfall-MSE} = \frac{1}{N} \sum_{i=1}^{N} (R_{\text{pred},i} - R_{\text{truth},i})^2$$

其中 $N$ 为所有时间步中所有有效像素的总数。

### 步骤 3：二值化与事件统计

选取降水阈值（默认 0.5 mm/h），将预测和真值矩阵分别二值化为 0/1 矩阵（1 表示"有降水"，0 表示"无降水"）。统计以下三类事件：

- **命中（hits）**：预测 = 1，真值 = 1
- **漏报（misses）**：预测 = 0，真值 = 1
- **误报（false alarms）**：预测 = 1，真值 = 0

### 步骤 4：CSI、FAR、POD 计算

基于事件统计结果，计算三项技能评分：

$$\text{CSI} = \frac{\text{hits}}{\text{hits} + \text{misses} + \text{false alarms}}$$

$$\text{FAR} = \frac{\text{false alarms}}{\text{hits} + \text{false alarms}}$$

$$\text{POD} = \frac{\text{hits}}{\text{hits} + \text{misses}}$$

### 步骤 5：相关系数计算

在每个预测时间步上，计算预测降水率矩阵与真值降水率矩阵的空间 Pearson 相关系数，然后对所有时间步取平均。

### 步骤 6：多时间步汇总

将上述指标在所有预测时间步上分别取平均，得到最终报告的指标值。典型的评估覆盖 15 个预测时间步（对应约 75 分钟的预报时长，每步间隔 5 分钟）。

## 边界与分流

- **单一阈值的局限**：当前默认阈值 0.5 mm/h 仅区分"有降水/无降水"，无法区分小雨、中雨和暴雨场景下的模型表现差异。若研究需要评估模型对不同强度降水的预报能力，建议采用多阈值评估方案（如分别取 0.5、1.0、5.0、10.0 mm/h），为每个阈值独立报告 CSI/FAR/POD。
- **Z-R 关系的选择**：不同的 Z-R 关系对应不同的降水类型（对流性降水 vs 层状性降水），选用的参数会影响转换后的降水率数值，进而影响所有指标。在不同气候区域或降水类型下，应使用经过本地化校准的 Z-R 参数。
- **与分类指标体系的关系**：CSI、FAR、POD 本质上是机器学习中 precision、recall 在空间事件检测任务上的变体。若研究重点为二分类能力而非连续误差，也可直接使用 precision、recall、F1-score 等指标进行补充评估。
- **与连续误差指标的关系**：Rainfall-MSE 和相关系数反映的是像素级数值误差，适用于评估预报的整体精度；而 CSI 等二分类指标衡量的是"是否报对了降水事件的发生"。两者互补，不可互相替代。
- **适用于像素级外推任务**：本指标集面向像素级降水预报（如雷达回波外推）。对于基于概率的集合预报或格点化数值天气预报输出，可能需要补充使用 Brier Score、CRPS 等概率校准指标。

## 质量检查

- **降水率转换验证**：确认 Z-R 转换后的降水率范围合理（典型值在 0–100 mm/h 之间），异常高值可能指示回波强度单位不匹配。
- **二值化一致性**：确认预测和真值使用相同的降水阈值进行二值化，避免阈值不一致导致的统计偏差。
- **事件统计自洽性**：验证 hits + misses + false alarms 的总数关系。对于二值化矩阵，真值中"有降水"像素数 = hits + misses；预测中"有降水"像素数 = hits + false alarms。
- **时间步对齐**：确认预测序列与真值序列在时间维度上严格对齐，避免因时间偏移导致评估失真。
- **多阈值一致性检查**：若采用多阈值评估，随着阈值升高，"有降水"像素数应单调减少，CSI 和 POD 通常单调下降，这是合理的物理预期。

## 资源召回建议

- **配套工具**：OpenSTL、EarthBench 等时空预测基准框架中通常内置了上述降水评估指标的计算函数，可直接调用以保证计算一致性。
- **替代指标**：当评估重点为概率预报质量时，可参考 Brier Skill Score（BSS）、Continuous Ranked Probability Score（CRPS）等概率评分指标。
- **参考基线**：在降水临近预报领域，ConvLSTM 系列模型、ROVER 光流法外推、FC-LSTM 等方法的公开指标值可作为 baseline 参考（例如 ConvLSTM(3×3) 架构在 15 步预测上的典型指标为：Rainfall-MSE ≈ 1.42、CSI ≈ 0.58、FAR ≈ 0.20、POD ≈ 0.66、Correlation ≈ 0.91，ROVER 方法的典型指标为：Rainfall-MSE ≈ 1.71、CSI ≈ 0.52、FAR ≈ 0.31、POD ≈ 0.64、Correlation ≈ 0.84）。
- **Z-R 关系校准**：具体 Z-R 参数应根据实际观测数据和区域气候特征重新拟合，不宜直接沿用默认值。
