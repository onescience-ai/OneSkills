# 2020年全球冠层高度图

## 适用范围

该数据集适用于需要全球或大区域尺度上高空间分辨率植被冠层高度信息的各类科研与应用场景。典型应用包括但不限于：森林地上生物量估算的辅助参数、森林生态系统健康与结构变化监测、生物多样性栖息地建模中的结构异质性指标、全球碳循环模型中的植被垂直结构输入参数，以及野火风险与灾害影响评估。其核心解决的问题是提供近乎全球覆盖、空间细节精细（10米GSD）的冠层高度定量产品，弥补了传统中低分辨率卫星数据在刻画森林垂直结构细节上的不足，同时也通过提供不确定性估计来支持对数据可靠性的评估。

## 输入

- **必需输入**：
  - 2020年Sentinel-2 L2A（经过大气校正的地表反射率）图像存档。这是生成高度图的核心数据源。
  - 训练完成的全球冠层高度深度学习模型及其参数文件。该模型用于从光学影像中推理冠层高度。

- **可选/环境输入**：
  - 用于模型推理的计算资源，特别是具备并行处理能力的GPU，这对于处理全球尺度的海量数据至关重要。
  - 便捷访问和下载Sentinel-2数据的网络环境或本地数据镜像。
  - 辅助后处理数据，例如全球土地覆盖图（如ESA WorldCover），可用于对最终产品进行掩膜（例如，只保留林地区域）。

## 输出

- **核心数据产品**：
  - 全球陆地（南极洲除外）的冠层顶部高度栅格图。数据空间分辨率为10米，以地理坐标（经纬度）组织。
  - 每个像素对应的预测不确定性估计图层。这为评估高度值的可信度提供了量化依据，对于下游不确定性传播分析非常重要。

- **数据格式与组织**：
  - 数据通常以3°×3°的地理经纬度瓦片形式进行组织和发布，便于分区域下载和处理。
  - 常用的栅格格式包括GeoTIFF等，可在GIS软件（如QGIS、ArcGIS）或编程环境（如Python的rasterio、GDAL）中直接读取。

## 流程节点

1.  **数据获取与准备**：从数据发布平台下载所需的全球3°×3°瓦片。获取并配置好预训练的深度学习模型文件。
2.  **输入数据预处理**：确保2020年的Sentinel-2 L2A影像数据可用，并按照模型要求进行预处理（如波段选择、归一化等）。可能需要对影像进行镶嵌或分块以匹配瓦片。
3.  **模型推理**：将准备好的Sentinel-2影像输入深度学习模型。模型逐瓦片或分块运行，输出每个像素的冠层高度预测值及对应的不确定性估计。
4.  **后处理与镶嵌**：对各瓦片的推理结果进行必要的后处理（如去云掩膜、基于土地覆盖的掩膜），并将相邻瓦片拼接成连续的全球或区域覆盖产品。
5.  **数据打包与分发**：将最终的栅格图层（高度和不确定性）按照标准格式（如GeoTIFF）打包，并提供元数据说明，供用户下载和使用。

## 边界与分流

- **适用条件**：本数据集主要反映2020年的全球植被冠层高度状态。对于需要时间序列分析（如年度动态监测）的任务，需寻找其他具有重复观测能力的冠层高度产品（如ICESat-2系列）。其有效空间分辨率低于标称的10米，尤其在训练数据稀疏的区域，因此不适合需要米级甚至亚米级精细结构的局部研究。
- **局限性与已知问题**：
  - **高纬度地区**：可能存在因影像拼接或数据缺失导致的拼接伪影。
  - **持续多云地区**：如热带雨林区，由于缺乏足够的清晰光学影像，数据可能存在空洞。
  - **训练数据限制**：模型的性能受限于用于训练的样本数据（如稀疏的激光雷达数据）的地理分布和范围，可能导致在特定区域（如某些林型）精度下降。
- **替代方案**：
  - 对于小范围、超高精度需求，可考虑使用机载激光雷达（LiDAR）直接测量。
  - 对于需要特定年份或更高时间频率的全球数据，可关注其他全球冠层高度产品或合成孔径雷达（SAR）反演产品。
  - 在数据空洞区域，可结合该产品的不确定性估计进行保守分析，或使用多源数据融合方法进行填补。

## 质量检查

使用本数据集前，建议进行以下质量评估：
- **空间一致性检查**：对比已知的大型森林、沙漠、城市等区域的预期高度分布，检查是否存在明显异常或拼接缝隙。
- **不确定性评估**：关注不确定性图层的高值区域，这些区域的预测高度值可能不可靠，在进行定量分析时应赋予较低权重或进行不确定性分析。
- **交叉验证**：尽可能与独立的地面实测数据（如森林调查样地）、高精度机载LiDAR数据或已被广泛验证的其他卫星产品（如GEDI任务数据）进行对比，评估其在研究区域的局部精度和偏差。

## 回退策略

- **数据缺失或空洞**：如果在关键研究区域存在数据空洞，可以尝试：1）寻找其他时段或传感器的补丁数据；2）使用该数据集提供的不确定性估计作为掩膜，在后续分析中明确指出数据缺失区；3）采用空间插值方法（需谨慎评估其合理性）。
- **精度不足**：若评估发现该数据在研究区域的精度无法满足特定分析（如精确的单木生物量估算），应考虑降级使用：仅将其作为宏观背景信息，而非关键输入参数；或转向使用基于SAR或更高精度但覆盖有限的局部产品。
- **格式或处理问题**：若遇到瓦片拼接、坐标系统转换等问题，可借助标准地理空间处理工具（如GDAL、Rasterio、ARCGIS Pro）进行处理。具体参数需根据实际体系和软件版本进行调试。

## 资源召回建议

- **云处理平台**：处理全球尺度的栅格数据可利用Google Earth Engine、Microsoft Planetary Computer等云地理空间分析平台，它们通常直接集成了此类全球数据集，可避免大规模下载。
- **配套数据**：结合使用全球土地覆盖数据（如ESA WorldCover, GlobeLand30）进行掩膜和分类分析；结合全球森林变化数据集（如Global Forest Change）进行动态分析。
- **验证数据**：全球范围可参考GEDI（全球生态系统动力学调查）的激光雷达高度剖面数据作为校验参考。局部高精度验证可寻找公开的机载LiDAR点云数据或森林固定样地调查数据。
- **处理工具**：熟练掌握GDAL/OGR、Python的rasterio/geopandas/xarray库、R的terra/sf包等地理空间数据处理库，是高效使用和分析此类数据集的基础。
