# Kling-Gupta效率 (KGE) 指标

## 适用范围

用于评估水文模型或预报模型在模拟时间序列（如径流、降水）方面的整体性能。其核心场景是需要同时考察模型输出序列与观测序列在趋势一致性（相关性）、均值水平（偏差）和波动幅度（变异性）这三个维度上的匹配程度。当模型校准或验证需要比Nash-Sutcliffe效率（NSE）提供更均衡、可分解的误差诊断时，KGE是一个优选指标。它尤其适用于分析模型系统误差的来源，例如判断预测偏差主要源于系统性的均值偏移还是对过程变率的刻画不足。

## 输入

- **必需输入**：
  1.  **预测时间序列**：模型输出的径流或其他水文变量时间序列，需与观测序列在时间上一一对应。
  2.  **观测时间序列**：作为基准的真实观测数据时间序列。
- **格式要求**：两个序列应为等长的一维数组或列表，数据点数量相同。序列中的值应为实数，通常要求单位一致。

## 输出

- **主要输出**：
  - **KGE值**：一个介于负无穷到1之间的无量纲数值。
  - **分量分解值**：包括Pearson相关系数（r）、偏差比（β）和变异性比（γ），各自独立提供诊断信息。
- **后续用途**：
  - KGE值用于直接比较不同模型或同一模型不同参数集的性能。
  - 分量值用于诊断性能不佳的具体原因，指导模型改进方向（例如，低γ值表明需要调整过程的随机性或幅度）。

## 流程节点

KGE的计算遵循以下标准步骤：

1.  **计算Pearson相关系数（r）**：
    - 计算预测序列与观测序列的Pearson相关系数r。r衡量两个序列变化趋势的线性相关程度。
    - 完美预测时，r = 1。

2.  **计算偏差比（β）**：
    - β = μ_sim / μ_obs，其中μ_sim为预测序列的均值，μ_obs为观测序列的均值。
    - β反映了预测值在平均水平上是高估（β>1）还是低估（β<1）。完美预测时，β = 1。

3.  **计算变异性比（γ）**：
    - γ = σ_sim / σ_obs，其中σ_sim为预测序列的标准差，σ_obs为观测序列的标准差。
    - γ反映了预测序列的波动幅度相对于观测序列的大小。完美预测时，γ = 1。

4.  **计算KGE**：
    - 使用以下公式计算最终的KGE值：
      ```
      KGE = 1 - sqrt( (r - 1)² + (β - 1)² + (γ - 1)² )
      ```
    - 该公式计算了三个理想分量点(1,1,1)与实际分量点(r, β, γ)在三维空间中的欧几里得距离，距离越小，KGE值越高。

## 边界与分流

- **与Nash-Sutcliffe效率（NSE）的对比**：
  - NSE同样基于预测值与观测值的残差平方和，但未对误差结构进行分解。NSE = 1 - [Σ(pred-obs)² / Σ(obs-mean_obs)²]。
  - KGE的优势在于能诊断性能问题的来源（偏差 vs. 变异性）。一个高NSE值可能掩盖了严重的均值偏差或变异性失真，而KGE的分量分解可以揭示这一点。
  - **分流建议**：当仅需一个总体性能排名指标，且对误差结构诊断要求不高时，NSE或其改进版（如KGE的变体）可能是更简单直接的选择。当需要深入理解模型缺陷以进行针对性改进时，KGE是更优的诊断工具。
- **适用数据类型**：
  - KGE适用于连续的正态或近似正态分布的水文时间序列。对于具有强季节性或间歇性的流量序列（如旱季零流量），需谨慎使用，因为标准差和均值的计算可能被少数高流量事件主导。
  - 当序列中存在大量零值或极端值时，建议先进行数据变换（如对数变换）或使用专门处理这类分布的改进指标。

## 质量检查

- **基准解释**：
  - 对于完美的预测，r=1, β=1, γ=1，因此KGE = 1。
  - 一个常用的“技能”基准是将预测与持续性预报（如观测均值）进行比较。当KGE高于该基准（通常KGE > -0.414）时，认为预测具有一定的技巧。
- **分量交叉检查**：
  - 计算完成后，务必检查r, β, γ三个分量。如果KGE值很低，观察哪个分量偏离1最远，即可定位主要问题。
  - 例如，r接近1但β远离1，表明趋势模拟正确但存在系统性偏差；γ远离1但β和r尚可，则表明模型对水文过程的波动幅度模拟有误。
- **数值合理性**：
  - KGE的取值范围理论上是(-∞, 1]。在实践中，性能很差的模型其KGE可能为较大的负数。

## 回退策略

- **当KGE不适用或失效时**：
  1.  **数据质量问题**：如果输入时间序列包含大量缺失值或异常值，导致均值和标准差的计算不可靠，应回退到先进行严格的数据质量控制（插补或剔除异常值），或采用对异常值更稳健的替代指标（如基于秩的指标）。
  2.  **极端水文事件主导**：对于以间歇性或极端事件为主的序列（如干旱区溪流），传统KGE可能无法全面反映性能。此时可考虑使用针对特定时段（如洪水期）的KGE计算，或结合其他侧重极值评估的指标（如对洪峰的评估）。
  3.  **模型比较需求变化**：如果后续需求从“总体性能评估”转向“特定分位数预测性能评估”，则应分流至使用分位数评分（如CRPS）或概率预测评分（如Brier评分）等指标。

## 资源召回建议

- **计算工具**：KGE的计算在Python、R等科学计算环境中均可轻松实现，无需依赖特殊库，直接根据公式编写代码即可。一些水文模型框架（如Hype， SWAT的某些评估模块）也内置了KGE计算功能。
- **相关指标**：在需要评估模型概率预报性能时，可关联使用连续排名概率评分（CRPS）、可靠性图等。对于多站点或流域整体的评估，可能需要计算空间KGE或加权KGE。
