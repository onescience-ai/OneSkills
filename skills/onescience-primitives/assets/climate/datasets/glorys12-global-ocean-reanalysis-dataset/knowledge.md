# GLORYS12 全球海洋再分析数据集

## 适用范围

面向全球海洋状态分析与预报模型构建，GLORYS12 提供了一个基于物理海洋数值模式同化多源观测的高分辨率历史海洋状态基准。该数据集典型应用于：

- 作为数据驱动海洋预报模型（如深度神经网络）的训练目标场，提供连续的、物理一致的海面高度、温盐、流场及海冰变量。
- 作为海洋模式（如 NEMO）输出的参考验证场，用于评估预报或模拟技能。
- 用于全球或区域海洋气候态分析、中尺度涡旋活动研究及水团特性评估。

触发条件：需要长时间序列、高时空分辨率的全球三维海洋再分析场，且要求数据基于成熟海洋数值模式并同化了卫星与现场观测。

## 输入

GLORYS12 数据集的构建依赖于以下输入：

- **大气再分析驱动场**：ERA-Interim 大气再分析数据，提供风应力、热通量、淡水通量等大气强迫。
- **观测数据同化**：卫星高度计（海面高度异常）、卫星海表温度、卫星海面盐度（如 SMOS, Aquarius）以及现场剖面观测（如 Argo 浮标温盐剖面、XBT 等）。这些数据通过同化系统（如 OI 或更先进的方法）融入模式状态。

对于终端用户而言，使用该数据集时无需再处理上述原始输入，直接获取已生成的再分析场文件即可。

## 输出

GLORYS12 提供的再分析场产品包括：

- **海洋变量**：逐日的全球三维场，涵盖海面高度（SSH）、海面温度（SST）、海面盐度（SSS）、三维温度、盐度、海流（u, v 分量）、混合层深度等。
- **海冰变量**：海冰密集度、厚度、速度等。
- **时空规格**：水平网格为 1/12° 规则经纬度网格（约 8 km），垂直方向包含 50 个层（深度从近表层到约 5700 m），时间覆盖从 1993 年至今的逐日产品。

输出格式通常为 NetCDF，便于在海洋学和气候学工作流中直接使用。

## 流程节点

1.  **数据获取与预处理**：从数据分发平台（如 Copernicus Marine Service）下载所需时间段和变量的 GLORYS12 NetCDF 文件。
2.  **变量选择与提取**：根据具体任务（如神经网络训练）提取目标变量（如 SSH, SST, 海流分量）。可能需要进行变量重命名或单位统一。
3.  **时空切片**：根据研究区域（全球或特定海域）和时间范围，对数据进行子集化（subsetting）。
4.  **数据重排与格式化**：将数据整理成适合模型输入的格式。例如，对于时空预报模型，可能需要构造为 `[time, depth, lat, lon]` 的四维张量序列。可能涉及缺失值填充（尽管再分析场通常连续）、网格对齐等操作。
5.  **划分训练/验证/测试集**：在时间维度上进行划分，确保训练集、验证集和测试集在时间上不重叠（例如，1993-2012 用于训练，2013-2015 用于验证，2016-2018 用于测试），以评估模型的泛化能力。
6.  **归一化与标准化**：计算训练集统计量（均值、标准差）对数据进行标准化，以利于神经网络优化。验证集和测试集使用相同的统计量。

## 边界与分流

- **与大气再分析数据集的边界**：GLORYS12 的大气强迫来自 ERA-Interim。若任务需要更新或更高分辨率的大气驱动（如 ERA5），需注意 GLORYS12 本身的再分析场并未使用 ERA5 重建。ERA5 本身是独立的大气再分析产品，可作为替代或补充的大气强迫源用于其他模式模拟，但不能直接替换 GLORYS12 输出场。
- **与其他海洋再分析产品的分流**：
    - 若需要更长时间序列或更强调气候趋势，可考虑 SODA、ORAS5 等其他再分析产品。
    - 若需要更高分辨率（如全球 1/25° 或区域高分辨率嵌套），需寻找相应的高分辨率再分析或高分辨率模式结果（如 GLORYS12V2 的高分辨率版本）。
    - 若任务对实时性要求高（如业务预报初始化），可能需要使用实时分析场而非滞后再分析场。
- **作为“地面真值”的局限性**：GLORYS12 作为再分析产品，其本身是模式与观测同化的结果，在观测稀疏区域（如深海、极地）或中尺度涡旋的精细结构上，其保真度存在不确定性。因此，在用其作为“真值”评估另一个预报模型性能时，需认识到这种评估是模型相对于再分析的一致性，而非绝对的真值检验。在沿海等复杂地形和动力学区域，其代表性可能不足。

## 质量检查

使用 GLORYS12 数据前或在将其作为评估基准时，建议进行以下质量检查：

- **数据完整性检查**：确认所需时间步和变量无缺失。
- **物理合理性检查**：检查关键变量（如 SST, SSH）的时空分布是否合理，是否符合已知的海洋气候态（如主要洋流路径、季节循环）。
- **与独立观测对比**：将数据与未参与同化的独立观测（如特定航次断面、漂流浮标轨迹）进行对比，评估其在该区域的代表性。
- **与其它再分析产品交叉验证**：将 GLORYS12 的关键场（如海面高度、海表温度）与其他再分析产品（如 SODA）或卫星观测产品进行比较，了解其不确定性范围。
- **注意模式物理局限性**：认识到 GLORYS12 基于 NEMO 模式，其对次中尺度过程、特定海气相互作用过程的表征能力受模式物理参数化方案限制。

## 回退策略

- **数据不可用或缺失严重**：如果 GLORYS12 在特定关键区域或时间段数据质量不佳或缺失，可考虑使用其他全球海洋再分析数据集（如 SODA, ORAS5）作为替代训练数据或验证基准。需要重新进行数据预处理和标准化流程。
- **作为评估基准的偏差问题**：如果发现用 GLORYS12 训练的模型在某些区域系统性地偏离其他独立观测，可能表明 GLORYS12 在该区域本身存在偏差。此时，回退策略包括：1) 结合使用 GLORYS12 和其他数据集进行交叉验证；2) 在评估指标中考虑再分析产品的不确定性范围；3) 在模型开发中，尝试将部分独立观测直接纳入损失函数进行微调。
- **计算资源限制**：处理全球 1/12° 分辨率的全深度数据可能面临计算和存储挑战。回退策略是先从感兴趣的区域或关键变量入手，或采用降采样、数据压缩等预处理手段。

## 资源召回建议

- **数据分发**：主要通过 Copernicus Marine Service (CMEMS) 获取，需要注册并遵循其数据使用协议。
- **相关数据集**：
    - **ERA5**：可作为 GLORYS12 的大气驱动数据（ERA-Interim）的更新替代品，用于驱动新的海洋模式模拟，但不能直接替代 GLORYS12 再分析场本身。
    - **GLO12v4**：这是 GLORYS12 系列的后续业务预报系统，其再分析部分与 GLORYS12 有连续性，可能提供更新的数据。
- **配套工具**：使用 xarray (Python) 或 nctoolbox (MATLAB) 等库进行高效读取、处理和可视化 NetCDF 格式的 GLORYS12 数据。Dask 可用于处理大规模并行计算。
- **文档与社区**：查阅 Copernicus Marine Service 的产品说明书（Product User Manual, PUM）和质量信息文档（Quality Information Document, QUID），了解数据的详细生产过程、已知问题和不确定性。
