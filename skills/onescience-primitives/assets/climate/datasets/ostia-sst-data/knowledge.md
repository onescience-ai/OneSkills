# OSTIA海表温度数据

## 适用范围

本知识描述了用于海表温度（SST）相关研究与应用的基础数据集OSTIA SST。该数据集适用于需要全球范围、长时间序列、高分辨率基础SST数据的任务，例如开发和评估SST预测模型、进行SST异常分析、为海洋动力学模型提供初始或边界场等。当研究需要可靠的、经过验证的日分辨率全球SST场时，可优先考虑此数据集。

## 输入

- 必需参数：
  - 研究区域定义：通常以经纬度范围指定（例如，0–45°N， 105–135°E）。
  - 时间范围：定义所需的起止日期（例如，1985年至2019年）。
- 前提条件：
  - 需要拥有访问哥白尼海洋环境监测服务（Copernicus Marine Environment Monitoring Service, CMEMS）数据仓库的有效账户和权限。

## 输出

- 处理后的SST时间序列：一个按时间步（通常为每日）排列的、覆盖指定区域的网格化温度场数据。
- SST异常值（SSTA）序列：基于气候平均态计算出的SST距平数据，常用于突出信号变化。

## 流程节点

1.  **数据获取**：通过CMEMS门户网站或API，使用指定的区域与时间参数，下载OSTIA基础SST数据产品。数据为每日更新，提供全球覆盖。
2.  **数据裁剪**：将全球数据裁剪至研究所需的特定地理区域，以减少数据量并聚焦分析。
3.  **质量控制与预处理**：
    - 检查并处理数据中的缺失值或异常值。OSTIA数据集本身已包含质量标志，可根据需要进行过滤。
    - 若需要计算SSTA，则需计算长期气候平均态（如30年平均），并逐日减去该平均值得到异常场。
    - 可选：对数据进行重采样、插值或标准化，以满足特定模型的输入要求。
4.  **数据集构建**：将处理后的SST或SSTA数据组织成适合模型训练和测试的格式，例如构建样本-时间-空间维度的张量。

## 边界与分流

- **分辨率选择**：OSTIA SST的0.05°分辨率适用于大多数中尺度及以上的应用。若研究需要更高的分辨率（例如，分析近岸或内波等现象），可能需要考虑融合了更高分辨率卫星和现场观测的其他产品。
- **数据类型**：OSTIA提供的是“基础SST”，是多种观测源融合并经过分析的产品。若需要未融合的原始卫星亮温数据或特定传感器的SST，应查找对应的数据源。
- **相关资产**：在SST预测任务中，该数据集常与Argo现场观测数据（用于验证）或其他中期数值天气预报系统（如S2S预测数据）的SST输出进行比较或同化。

## 质量检查

- **交叉验证**：使用独立的现场观测数据（如来自Argo浮标、漂流浮标的数据）对OSTIA SST数据进行验证。这是评估其准确性的标准方法。
- **统计指标**：计算数据集与验证数据之间的偏差（Bias）和标准差（STD）。已知OSTIA SST数据与现场观测相比，可能存在约-0.1 K至-0.04 K的偏差和0.56 K至0.34 K的标准差。这些统计量是评估数据集可靠性的参考（具体数值因时间、区域而异）。
- **内部一致性检查**：检查时间序列的连续性、空间场的平滑性，识别是否存在明显的数据跳变或条带噪声。

## 回退策略

- **数据不可访问或缺失**：若无法从CMEMS获取OSTIA数据，可尝试寻找其镜像站点或联系数据管理员。对于历史缺失时段，可考虑使用其他全球SST分析产品（如GHRSST系列）作为替代，但需注意不同产品在算法和输入源上的差异。
- **质量不达标**：若发现特定区域或时段的数据质量（如偏差、方差）无法满足研究精度要求，应考虑使用其他经过更严格局部校准的数据集，或在分析中明确标注该局限性。

## 资源召回建议

- **主要数据源**：哥白尼海洋环境监测服务（CMEMS）是获取OSTIA SST数据的官方渠道。
- **相关工具与数据库**：处理此类大型NetCDF或HDF5格式的地球科学数据，常使用Python的xarray、NetCDF4库或专业GIS软件。
- **验证数据**：iQuam系统提供的Argo现场观测数据是常用的验证数据源。
