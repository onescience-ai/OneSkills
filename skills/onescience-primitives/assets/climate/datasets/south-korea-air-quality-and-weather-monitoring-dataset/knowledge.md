# 韩国空气质量与气象监测数据集

## 适用范围

本指南适用于需要构建或评估空气质量（特别是颗粒物 PM10 与 PM2.5）实时或短临预测模型的研究场景。典型任务包括：开发基于深度学习（如卷积神经网络）或时空统计方法的预测模型、研究污染物的时空传输规律、分析气象因素对空气质量的影响等。触发条件通常包括：研究区域为城市或区域尺度（如韩国），需要融合地面监测站网数据，且预测时间尺度为小时级。所描述的数据集为开发与验证此类模型提供了真实世界的、高时间分辨率的基准数据。

## 输入

- **必需**：
  1.  **数据获取权限**：需从韩国环境公社（Korea Environment Corporation）和韩国气象厅（Korea Meteorological Administration）获取数据。具体访问接口或下载页面需根据相关机构的当前政策查询。
  2.  **时空定义**：明确研究区域（本数据集覆盖韩国全境）、时间范围（2018年1月1日01:00至2019年12月31日24:00）。
- **可选**：
  1.  **处理计算环境**：用于处理大规模时序数据的计算资源（如 Python + Pandas/NumPy 环境）。
  2.  **空间坐标数据**：各监测站点的经纬度坐标，用于进行空间插值或构建空间图结构。

## 输出

- **核心数据**：
  1.  **空气质量数据**：来自全国243个空气质量监测站的连续2年小时级数据，包含二氧化硫 (SO2)、一氧化碳 (CO)、臭氧 (O3)、二氧化氮 (NO2)、颗粒物 (PM10) 和细颗粒物 (PM2.5) 的浓度测量值。
  2.  **气象数据**：来自94个自动天气观测站的同期数据，包含气温、降水、风向和风速。
- **数据格式**：通常为结构化的表格或时间序列文件（如 CSV），每条记录包含站点ID、时间戳、监测项目、观测值等字段。输出数据已满足模型训练的基本格式要求。

## 流程节点

1.  **数据获取与初步筛选**：
    *   从韩国环境公社获取2018年（约432个站）和2019年（约484个站）的空气质量原始数据。
    *   从韩国气象厅获取同期气象观测站数据。
    *   根据数据完整性，筛选出在两年内**持续运行**的站点。这是保证时间序列连续性的关键步骤，最终选定243个空气站和94个气象站。
2.  **数据整合与对齐**：
    *   将不同来源的数据按“站点ID”和“时间戳”进行匹配合并，构建统一的时空数据集。
    *   确保所有站点的时间戳频率统一为小时级，并对齐至标准时间（如韩国标准时间 KST）。
3.  **缺失值识别与初步处理**：
    *   检查各监测项（尤其是污染物浓度和气象参数）的缺失情况。
    *   针对部分站点因运营时间不同造成的短期缺失，需明确处理策略（如插值、丢弃该时间段）。
4.  **质量控制与标准化**：
    *   检查异常值（如超出物理可能范围的数值）。
    *   对于不同仪器或方法产生的系统性偏差，可能需要进行标准化或校准，具体需参考各机构提供的元数据说明。
5.  **特征工程（可选但推荐）**：
    *   根据建模需求，可将时间戳分解为小时、星期几、月份等周期性特征。
    *   对风向等方向性数据进行编码（如转换为正弦/余弦分量）。

## 边界与分流

- **适用边界**：本数据集专注于韩国区域的地面观测。若研究区域超出此范围（如中国、欧洲），需寻找对应国家或地区的类似公开数据集。
- **不适用场景**：
  - 需要卫星遥感反演的柱浓度或垂直分布数据时，本数据集（地面点测量）不能直接满足。
  - 需要室内空气质量或特定污染源（如工厂烟囱）直接监测数据时，本数据集（环境背景站网）不适用。
- **与其他方法的衔接**：本数据集是模型训练的基础。处理后的干净数据可直接输入各种时空预测模型（如题目中提及的ICNN，或LSTM、Transformer、图神经网络等）。空间信息（站点坐标）可用于构建空间相关性矩阵或作为图神经网络的输入。

## 质量检查

1.  **完整性检查**：确认所选站点在目标时间范围内（2018-2019年）的数据缺失比例是否在可接受范围内。特别注意降水数据的高缺失率（研究中发现高达约90.88%）。
2.  **一致性检查**：对比同一站点相邻时间点的数据，检查是否有不合理的突变。
3.  **合理性检查**：检查污染物浓度、温度、风速等数值是否在本地典型的量级范围内。例如，PM2.5浓度通常在0到数百微克每立方米之间。
4.  **关联性检查**：抽查部分站点，看气象条件（如风速、降水）与污染物浓度（如PM2.5）的变化趋势是否符合物理常识（如大风利于扩散，降水利于清除）。

## 回退策略

- **数据严重缺失**：若关键站点或关键时段缺失率过高，可考虑：
  1.  使用空间插值方法（如反距离加权 IDW）从邻近站点填补缺失值，但需注意这会引入不确定性。
  2.  放弃该站点或时段，但可能减少可用训练数据。
- **站点网络变更**：如果筛选后的持续运行站点数量过少，无法支撑空间建模，需考虑：
  1.  放宽筛选条件（如允许较短的间歇缺失），并采用更稳健的缺失值处理方法。
  2.  寻找替代数据源，如邻国的类似监测网络，或使用数值模型再分析数据（如ERA5）作为补充，但需注意数据融合的偏差。
- **降水数据问题**：面对极高的降水数据缺失率，一种处理方式是保守地假设缺失值为极小值（如0.05mm以下）并赋值为0，但这可能影响降水相关特征的准确性。更严谨的做法是尝试从其他临近气象站插值，或使用卫星降水产品（如GPM）进行补充验证。

## 资源召回建议

- **数据处理工具**：Python 的 `pandas` 库非常适合处理此类表格化时间序列数据。`xarray` 适用于处理带坐标标签的多维气候数据。
- **空间插值工具**：`scipy.interpolate` 或 `geopandas` 配合 `geopy` 可实现反距离加权（IDW）等基础空间插值。
- **替代数据集**：若无法获取韩国数据，可寻找其他拥有公开空气质量和气象监测数据的城市或区域，例如：
  - 中国国家环境监测总站公开数据。
  - 美国环保署 (EPA) 的 AirNow 数据。
  - 欧洲的 AirBase 或 Copernicus 大气监测服务 (CAMS) 数据。
- **数据元信息**：务必查阅韩国环境公社和韩国气象厅提供的官方数据字典，了解各监测项目的具体单位、检测限、质量标记（如哪些值表示仪器校准或故障），这是进行严格数据质量控制的基础。
