# 预测模型性能评估

## 适用范围

面向时间序列预测模型的性能评估，适用于任何产生点预测输出的回归类模型。典型应用场景包括空气质量指数预测、气象要素预报、电力负荷预测、金融市场短期预测等。评估的核心任务是将模型预测序列与真实观测序列进行逐点比较，通过一组互补的统计指标量化模型的准确性、稳定性和解释力。

该方法通常在模型训练与验证阶段完成后使用，也可用于不同模型或不同超参数配置之间的横向比较。当预测结果为多步超前预报时，指标通常按预报时长（lead time）分层计算，以评估模型在不同预报窗口上的表现衰减趋势。

## 输入

- **必需**：
  - 预测值序列（predicted values）：由模型生成的点预测结果，与观测值序列等长、时间对齐。
  - 观测值序列（observed/actual values）：真实测量值，作为评估的基准参照。
- **可选**：
  - 预报时长标签（lead time）：若需分层评估，需提供每个预测点对应的预报提前量。
  - 样本权重：在不等间隔采样或重要性不同的场景下，可指定权重向量。

两个输入序列必须等长、缺失值已处理、单位一致。建议在计算前对数据做基本的完整性校验：检查长度匹配、无NaN、无单位混用。

## 输出

四个标量指标，构成评估结果的核心报告：

| 指标 | 全称 | 单位/量纲 | 含义 |
|------|------|-----------|------|
| RMSE | Root Mean Square Error | 与原始数据同量纲 | 对大误差更敏感，反映预测值与观测值的整体偏差 |
| MAE | Mean Absolute Error | 与原始数据同量纲 | 所有预测点绝对偏差的平均值，对异常值相对稳健 |
| MAPE | Mean Absolute Percentage Error | 百分比（%） | 相对误差度量，便于不同量级序列间的横向比较 |
| R² | Coefficient of Determination | 无量纲（0–1） | 模型解释观测值变异的比例，越接近1表示拟合越好 |

输出可直接用于模型对比报告、超参数搜索排序、或作为后续模型融合的权重依据。

## 流程节点

1. **数据准备**：获取等长的预测值序列 \(\hat{y}_1, \hat{y}_2, \dots, \hat{y}_n\) 和观测值序列 \(y_1, y_2, \dots, y_n\)，执行完整性校验。
2. **计算 RMSE**：
   $$
   \text{RMSE} = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2}
   $$
   RMSE 对较大误差赋予更高权重（平方惩罚），对离群值敏感。单位与原始数据一致。
3. **计算 MAE**：
   $$
   \text{MAE} = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|
   $$
   MAE 对所有误差等权处理，对离群值的敏感度低于 RMSE。
4. **计算 MAPE**：
   $$
   \text{MAPE} = \frac{100\%}{n} \sum_{i=1}^{n} \left| \frac{y_i - \hat{y}_i}{y_i} \right|
   $$
   MAPE 提供百分比形式的相对误差，便于跨量级比较。注意：当观测值 \(y_i\) 接近零或为零时，MAPE 会发散或产生极大值。
5. **计算 R²**：
   $$
   R^2 = 1 - \frac{\sum_{i=1}^{n} (y_i - \hat{y}_i)^2}{\sum_{i=1}^{n} (y_i - \bar{y})^2}
   $$
   其中 \(\bar{y}\) 为观测值的均值。R² 衡量模型解释的变异比例；值域通常为 \((-\infty, 1]\)，实际使用中接近1为佳。
6. **结果汇总**：将四个指标整理为评估报告，标注数据集、时段、样本量等元信息。

## 边界与分流

- **零值或极小值问题**：当观测序列中存在零或接近零的值时，MAPE 的分母趋近零，导致指标失效。此时应改用对称平均绝对百分比误差（SMAPE）或平均绝对缩放误差（MASE）作为替代方案。
- **离群值敏感度差异**：RMSE 对大误差敏感，MAE 对大误差相对稳健。若数据中离群值较多且需稳健评估，应以 MAE 为主要参考；若需惩罚大偏差，以 RMSE 为主。
- **R² 的局限性**：R² 值高并不意味着模型在所有时间点上都预测准确，可能掩盖局部系统性偏差。建议将 R² 与 RMSE/MAE 联合使用，辅以残差分布图或时间序列对比图进行诊断。
- **多步预报评估**：对于多步超前预报，指标应按 lead time 分别计算，而非混合计算，以避免短期预报性能掩盖长期预报退化。
- **与上下游的衔接**：评估指标可作为模型选择、集成学习加权、超参数优化（贝叶斯搜索等）的输入判据。

## 质量检查

- 确认预测值与观测值序列等长、无缺失、单位一致。
- 检查观测序列中是否存在零值或极小值，若有则评估 MAPE 的可靠性或替换为 SMAPE/MASE。
- 交叉验证：将 R² 与散点图（predicted vs. observed）对照，确认无系统性偏移。
- 样本量确认：计算指标时应报告样本量 \(n\)，小样本下指标波动较大，需谨慎解读。

## 回退策略

- **MAPE 失效**：观测值含零或极小值时，替换为 SMAPE 或 MASE。SMAPE 使用对称分母，MASE 基于 naive 预测的误差归一化，两者均避免零分母问题。
- **R² 为负值**：表明模型表现不如简单的均值预测，需检查模型是否过拟合、数据预处理是否合理、或是否选择了不适当的模型类型。
- **指标之间矛盾**：若 RMSE 低但 MAE 亦低、而 R² 不高，可能是观测值方差本身较小导致 R² 偏低，此时不应单纯以 R² 否定模型；反之若 R² 高但 RMSE 亦高，需检查量纲是否恰当。
- **数据预处理异常**：若发现预测值或观测值存在异常极值，应回溯数据管线，检查是否在预处理阶段引入了错误。

## 资源召回建议

- 常见 Python 实现：`sklearn.metrics` 中的 `mean_squared_error`（设置 `squared=False` 得 RMSE）、`mean_absolute_error`、`r2_score`；MAPE 可通过 `numpy` 或 `sklearn.metrics.mean_absolute_percentage_error`（sklearn ≥ 1.2）计算。
- 替代指标库：`metrics` 模块中的 SMAPE、MASE 等，或使用 `tslearn`、`darts` 等时间序列库内置评估工具。
- 可视化辅助：`matplotlib` 或 `seaborn` 绘制预测值 vs. 观测值散点图、残差时间序列图、分 lead time 的指标柱状图。
- 报告模板：建议输出标准评估报告，包含指标值、样本量、数据时段、模型版本和超参数摘要，便于可复现对比。
