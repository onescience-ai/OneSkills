# TIGGE存档数据

## 适用范围
用于获取和共享来自多个全球数值天气预报中心的集合预报数据，是进行中长期天气预报技巧评估、模型对比及气象后处理研究的标准化数据基础设施。典型应用场景包括：与再分析资料（如ERA5）配合进行预报技巧基准测试；获取业务中心（如ECMWF）的预报输出，以与新开发的机器学习天气预报模型进行公平、可复现的对比评估；利用集合预报数据研究极端天气事件（如热带气旋）的预报不确定性。

## 输入
要访问TIGGE Archive中的数据，用户通常需要以下条件：
- 一个有效的CDS账户或ECMWF公共账户。
- 明确的数据需求，包括：预报中心（如ECMWF）、变量（如位势高度、风场、温度、湿度）、垂直层（如地面、500hPa、850hPa）、时间范围、空间范围（全球或特定区域）以及预报提前期（如0小时至240小时）。
- 了解数据下载方式，可通过CDS API脚本编程批量获取，或通过CDS网站手动检索下载。

## 输出
从TIGGE Archive下载的数据主要包括：
- **集合预报数据**：来自各中心（如ECMWF、NCEP等）的业务集合预报系统输出，包括控制预报和扰动成员预报。数据通常为GRIB1或GRIB2格式，包含多个气象变量在不同气压层或等位温面上的值。
- **相关产品**：部分中心还会提供基于集合预报生成的衍生产品，如热带气旋路径跟踪结果。
这些数据可直接用于后续的分析、可视化、模型训练或评估流程。

## 流程节点
获取TIGGE Archive数据的一般流程如下：
1.  **需求定义**：明确研究所需的预报中心、变量、层次、时间与空间范围。
2.  **账户准备**：访问CDS网站（https://cds.climate.copernicus.eu/）或ECMWF数据服务网站，注册并获取API密钥（如使用CDS API）。
3.  **数据检索与下载**：
    - **API方式（推荐用于批量处理）**：编写Python脚本，使用`cdsapi`库，根据需求填写检索参数，提交下载任务。示例代码结构可参考CDS官方文档。
    - **网页方式**：在CDS网站的“TIGGE”数据集页面，通过交互式表单选择参数，提交下载请求。
4.  **数据预处理**：下载的原始GRIB文件可能需要根据后续分析工具进行解码、格式转换（如转为NetCDF）、子集提取或重网格等操作。

## 边界与分流
- **与ERA5再分析数据的区别**：TIGGE提供的是**预报数据**，而ERA5是基于观测同化的**再分析资料**。评估预报技巧时，通常以ERA5作为“实况”参考。若需历史实况数据而非预报，应选择ERA5等再分析资料库。
- **与其他预报数据源的分流**：TIGGE是获取多中心历史及准实时预报归档的主要渠道。若仅需特定中心的最新实时业务预报（而非归档），可直接访问该中心的数据服务（如ECMWF的MARS）。若需要更密集的集合预报或特定高分辨率产品，可能需要直接联系数据提供方。
- **数据量与访问限制**：TIGGE数据量巨大，批量下载前需评估存储空间和网络条件。部分高分辨率或实时数据可能存在访问权限或延迟。

## 质量检查
获取TIGGE数据后，建议进行以下质量检查：
- **数据完整性**：检查下载的文件是否完整，变量、层次、时间步数是否齐全。
- **格式正确性**：使用标准气象数据处理库（如xarray、cfgrib、xesmf）尝试读取，确保文件格式正确且可解码。
- **初步可视化**：绘制关键变量（如500hPa位势高度场）的地图，检查空间分布是否合理，是否存在明显的空值或异常。
- **元数据核对**：确认数据的中心标识、预报起报时间、有效时间等元数据与需求一致。

## 回退策略
- **无法访问TIGGE**：如遇到长期访问问题，可联系CDS或ECMWF数据支持团队。评估期可使用其他公开集合预报数据集作为临时替代，但需注意数据覆盖和定义可能不同。
- **数据缺失或损坏**：对于部分缺失的变量或时间步，在评估时可能需要调整对比周期，或使用插值方法进行谨慎填补。对于损坏文件，重新下载是首选方案。
- **格式不兼容**：若标准工具无法读取，可尝试使用更底层的气象数据处理软件（如wgrib2）进行转码，或查找专门处理该数据格式的社区支持。

## 资源召回建议
- **官方门户**：
  - Copernicus Climate Data Store (CDS): https://cds.climate.copernicus.eu/ （TIGGE数据检索主入口）
  - ECMWF Data Services: https://www.ecmwf.int/en/forecasts/datasets （了解数据细节和文档）
- **关键工具**：
  - `cdsapi` (Python): 用于程序化下载数据。
  - `xarray` + `cfgrib`/`rasterio` (Python): 用于读取、处理和分析GRIB格式数据。
  - Panoply或ncview: 用于快速可视化NetCDF/GRIB文件。
- **相关数据集**：ERA5（再分析资料）、IBTrACS（热带气旋最佳路径数据，可用于评估TIGGE中的热带气旋预报）。
