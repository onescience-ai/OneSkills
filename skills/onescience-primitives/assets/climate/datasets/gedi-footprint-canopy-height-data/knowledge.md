# GEDI足迹冠层高度数据

## 适用范围
用于为全球或大区域尺度的冠层高度估算模型提供训练参考数据（标签）。典型应用场景是利用高时空分辨率的光学卫星影像（如Sentinel-2时间序列）估算连续的树高或森林结构参数，但模型需要可靠的地面真实数据进行监督学习。本数据集作为稀疏但全球分布的激光雷达参考值，是此类任务的首选基准数据之一。

## 输入
- **必需输入**：
  - GEDI L1B 版本波形数据（包含用于计算相对高度指标的原始波形）。
  - 定义数据空间范围的栅格网格系统（例如，与 Sentinel-2 瓦片对齐的网格），用于将离散的足迹点光栅化为与预测模型输出空间分辨率匹配的参考值。
- **可选输入**：
  - 轨道预测过滤元数据，用于筛选高质量的足迹。
  - 辅助地理定位误差信息，用于评估或调整足迹位置不确定性。

## 输出
- 经过处理的全球 GEDI 足迹高度参考数据集。典型输出格式为包含经纬度、RH98 值（或其他相对高度指标）及质量标志符的表格或点矢量数据。根据现有公开处理结果，该数据集包含约 6 亿个筛选后的样本点。
- 此输出数据通常作为光栅化后的参考图层，与配对的光学影像像素共同构成深度学习模型的训练样本对。

## 流程节点
1.  **获取原始数据**：下载指定年份（如2019年、2020年）的GEDI L2A 产品（包含从L1B波形推导出的参数）或直接处理L1B波形。
2.  **计算/提取参考高度**：从每个GEDI足迹的波形中计算相对高度指标，最常用的是相对高度98%分位数（RH98），它通常被用作有效冠层顶部高度的代理值。
3.  **质量筛选**：应用一系列过滤器以剔除低质量足迹。常见筛选标准包括：
    - 能量阈值（确保足迹内有足够能量返回）。
    - 质量标志（如`l2b_quality_flag` 或 `l2a_quality_flag`）。
    - 非重叠足迹筛选（避免同一位置多次测量带来的偏差）。
    - 排除明显异常值（如高度为负或极大值）。
4.  **空间配准与光栅化**：将筛选后的足迹点坐标与目标栅格网格（如10米、100米或1公里分辨率）进行空间匹配。每个栅格单元的参考高度可取该单元内所有GEDI足迹RH98值的均值、中位数或最大值。
5.  **最终数据集生成**：整合处理后的足迹点信息或光栅化后的参考图层，形成最终的训练参考数据集，并附加元数据（如处理日期、所用筛选参数版本）。

## 边界与分流
- **空间覆盖边界**：GEDI任务主要运行在国际空间站上，轨道倾角约51.6°，因此**数据不覆盖南北纬51.6°以外的区域**。对于高纬度地区（如北方针叶林、苔原）的冠层高度估算，必须寻找其他参考数据源（如机载LiDAR、ICESat-2数据）。
- **空间分辨率与稀疏性**：GEDI足迹直径约25米，但沿轨道间距约60米，交叉轨道间距达数百米至数公里，数据固有稀疏性。因此，它更适合作为训练数据，而非直接用于生成高分辨率（如<30米）的连续冠层高度图。若需要高分辨率参考数据，应考虑高分辨率机载LiDAR采集。
- **数据性质边界**：GEDI提供的是点尺度测量值，而非连续场。在将其作为训练标签时，需谨慎处理光栅化过程引入的尺度效应和混合像元问题。
- **替代方案分流**：
  - 若需密集、高分辨率的参考数据，应转向机载激光雷达数据集。
  - 若需监测冠层高度的年际变化，GEDI数据（受 revisit 周期限制）可能不足，需结合时间序列能力更强的光学或SAR数据反演。
  - 在GEDI覆盖区外，可考虑使用 ICESat-2 激光测高数据（提供沿轨道高精度高程剖面）。

## 质量检查
- **参考高度分布**：检查全球范围内RH98值的分布，应与已知的森林分布和高度生态学常识相符（如赤道附近热带雨林高度较高，城市与农田区域较低）。
- **空间覆盖度可视化**：绘制足迹点分布图，确认其覆盖了目标研究区域，并识别无数据的空隙区。
- **一致性检验**：将GEDI足迹RH98与小范围内的高分辨率机载LiDAR数据进行交叉验证，评估系统性偏差和随机误差。注意GEDI足迹存在15-20米的地理位置不确定性，这在交叉验证时需要考虑。
- **噪声与异常值筛查**：在苔原、灌丛或高度异质性区域，数据噪声可能较大，需检查这些区域的参考值是否合理。

## 回退策略
- **高纬度无数据**：若目标区域位于GEDI覆盖范围外，**必须采用替代数据源**。可使用ICESat-2 ATL08产品（提供植被高度产品）或规划局部机载LiDAR飞行。
- **数据稀疏或噪声过大**：在森林稀疏或结构复杂的区域，单一GEDI足迹的RH98可能无法代表足够大的区域。回退策略包括：（1）在光栅化时采用更大邻域的统计量（如平均值），但会牺牲空间分辨率；（2）增加额外的筛选条件以保留更高质量的足迹；（3）在模型训练时降低这些区域样本的权重，或使用半监督/弱监督学习方法融合更多数据。
- **位置不确定性影响模型精度**：若建模任务对空间位置极其敏感，需在训练数据准备时考虑使用足迹位置不确定性的概率模型，或在光栅化时采用位置加权方案。

## 资源召回建议
- **主要数据源**：GEDI L2A 数据可从美国国家雪冰数据中心（NSIDC）获取。作为训练参考的、已处理的全球足迹数据集可从 Zenodo 等开放数据平台下载（如 DOI: 10.5281/zenodo.7737946）。
- **配套影像数据**：训练时通常配对使用 Sentinel-2 L2A（大气校正后的地表反射率）时序数据。
- **处理工具**：可使用 Google Earth Engine（GEE）、Python 的 GDAL/rasterio/geopandas 库进行光栅化和空间分析，使用 TensorFlow/PyTorch 构建深度学习模型。
- **验证数据**：独立的高精度验证应使用 GEDI 数据未覆盖的区域或未用于训练的机载 LiDAR 数据。
