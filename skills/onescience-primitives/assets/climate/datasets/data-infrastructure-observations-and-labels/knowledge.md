# 数据基础设施：观测与标签

## 适用范围

雪崩危险等级预测系统所依赖的核心数据基础。包括来自瑞士州际测量和信息系统（IMIS）自动气象站网络超过20年的气象观测和雪盖模拟数据集（IMIS dataset），以及用于训练机器学习模型的地面真值标签数据集（Dforecast dataset），该标签数据集源自瑞士国家雪崩预警服务发布的公共雪崩预报。

当任务目标与该知识所述场景一致时，可复用本条目。

## 输入

- 自动气象站网络原始观测
- 瑞士国家雪崩预警服务发布的公共雪崩公报

## 输出

- IMIS 数据集（用于特征提取和模拟）
- Dforecast 数据集（用作模型训练的标签）

## 前提条件

- 自动气象站网络部署和运行
- 瑞士国家雪崩预警服务的持续运行

## 边界与分流

- 相关资产/可替代方案：snow cover simulation workflow and toolchain
- 相关资产/可替代方案：avalanche danger level prediction task

## 回退策略

- IMIS 数据网络可能出现站点故障或数据缺失
- 危险等级标签可能受预报员主观判断影响

## 备注

以上条目为通用可复用的领域知识，具体参数与实现细节需根据实际研究场景做适配与验证。
