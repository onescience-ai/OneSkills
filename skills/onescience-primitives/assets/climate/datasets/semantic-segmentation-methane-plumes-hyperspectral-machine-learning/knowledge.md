# STARCOP 数据集

## 适用范围
适用于开发、训练和评估针对航空或航天高光谱/多光谱影像的甲烷羽流自动检测与语义分割模型。典型场景包括使用机载高光谱传感器（如 AVIRIS-NG）或高空间分辨率多光谱卫星数据进行定点源排放监测的研究与应用。该数据集为模型提供了标准化的训练与测试基准。

## 数据集概述
该数据集为机器学习就绪格式，包含两类图像数据：源自机载高光谱传感器的原始数据切片，以及对同类高光谱数据进行谱段响应函数重采样后模拟出的多光谱卫星数据（如 WorldView-3）。所有图像切片均配有对应的二进制羽流掩模标签，表明每个像素属于甲烷羽流区域还是背景。标签经过人工审核与扩展以提高质量。数据集公开发布，可通过数字对象标识符获取。

## 输入
构建该数据集所需的原始输入包括：
1.  **AVIRIS-NG 高光谱原始影像**：来自特定区域的飞行活动（例如 Permian Basin）的 Level 1B 辐射亮度数据。
2.  **原始羽流掩模标签**：初始的、尺寸较小（例如 151×151 像素）的 RGB PNG 格式标签文件。

## 输出
最终产出的 STARCOP 数据集包含：
1.  **图像切片**：尺寸统一为 512×512 像素的图像芯片，包含原始高光谱数据。
2.  **精炼标签**：对应每个图像切片的、经过手动检查与扩展的羽流/非羽流二进制掩模。
3.  **增强产品**：与图像切片配对的甲烷增强计算结果，例如基于匹配滤波算法（如 mag1c）生成的甲烷浓度增强图。
4.  **模拟多光谱数据**：通过将高光谱数据重采样至特定卫星（如 WorldView-3）的谱段响应函数，生成的模拟多光谱波段数据，用于评估模型在不同传感器配置下的泛化能力。

## 流程节点
1.  **数据采样与切片**：从完整的 AVIRIS-NG 影像中，以固定步长采样并切割出 512×512 像素的图像芯片。
2.  **甲烷增强计算**：对每个高光谱图像芯片运行甲烷增强算法（例如 mag1c 匹配滤波器），生成对应的甲烷浓度增强产品。
3.  **标签审核与扩展**：使用专用标注工具（例如 IRIS - Intelligently Reinforced Image Segmentation）打开初始的小尺寸羽流标签，并将其叠加在对应的图像芯片上。标注人员手动检查并扩展标签边界，确保其准确覆盖 512×512 图像芯片中的整个羽流区域，形成精炼后的掩模。
4.  **多光谱数据模拟**：应用 WorldView-3 等卫星的谱段响应函数，将高光谱图像芯片重采样为模拟的多光谱图像。
5.  **数据集构建与划分**：将处理好的图像芯片、标签、增强产品和模拟数据按固定格式组织。按照特定日期（例如 10月18日、21日和25日获取的影像）划分独立的测试集，其余作为训练集，并确保正负样本比例均衡。

## 边界与分流
- **数据类型边界**：该数据集的核心是机载高光谱数据及其衍生品。虽然提供了模拟的多光谱数据，但其主要用于探索多光谱模型（如 MultiSTARCOP）的可行性。对于直接使用真实世界多光谱卫星数据（如 Sentinel-2、WorldView-3）的模型开发，此模拟数据仅作为参考，实际应用中模型性能可能因真实卫星影像的辐射特性、空间分辨率和大气条件差异而有所不同。
- **应用场景分流**：适用于羽流分割的监督学习任务。对于无监督的异常检测、基于物理模型的反演或需要时间序列分析的排放源定位等任务，可能需要结合其他数据集或方法。
- **下游任务衔接**：产出的图像-标签对可直接用于训练语义分割网络（如 HyperSTARCOP）。增强产品可作为辅助输入特征或用于生成伪标签。

## 质量检查
- **标签质量**：数据集质量高度依赖标签的准确性。所有标签均经过人工工具手动扩展与审核，以减少原始标签错误或不一致带来的影响。用户在使用前仍可对感兴趣的样本进行抽查。
- **数据平衡**：构建时已刻意平衡正负样本比例，避免模型训练时产生严重偏倚。用户应检查最终划分的训练/测试集是否维持了这一平衡。
- **模拟数据代表性**：需注意模拟的多光谱数据是基于特定传感器模型生成的，其与真实世界数据的差异应在模型评估中予以考虑。

## 回退策略
- **若标签质量存疑**：可借助标注工具（如 IRIS）对部分样本进行复核。若发现系统性错误，需重新进行标签审核流程。
- **若模拟多光谱数据不适用**：对于目标为真实多光谱卫星数据的应用，应考虑收集并标注对应卫星的真实历史数据，或采用更精细的大气校正和传感器模拟流程来生成训练数据。
- **若数据增强引入偏差**：在使用数据增强（如随机旋转、裁剪）时，应注意其可能使模型过于关注特定局部特征。可通过增加验证集多样性、采用更合理的增强策略（如仅限旋转、避免重叠切片）或使用显式的正则化方法来缓解。

## 资源召回建议
- **标注工具**：可参考 IRIS 等智能辅助标注工具，用于高效地创建和修正羽流分割标签。
- **增强算法**：数据集配套提供了 mag1c 等匹配滤波器生成的增强产品，可作为基准特征或输入通道。
- **相关数据集**：该数据集可与 EMIT（地球表面矿物尘源调查）任务的数据集在数据来源和覆盖范围上形成互补，用于构建更大规模的甲烷/二氧化碳等温室气体遥感监测训练库。
- **下游模型**：该数据集明确支持 HyperSTARCOP（用于高光谱数据）和 MultiSTARCOP（用于模拟多光谱数据）等特定分割模型的开发与对比。
