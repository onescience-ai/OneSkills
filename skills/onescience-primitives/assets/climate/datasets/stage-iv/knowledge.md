# Stage IV雷达降水数据集

## 适用范围

Stage IV 是美国本土（CONUS）范围内广泛采用的高分辨率降水参考数据集，适用于以下典型场景：

- **降水产品精度评估**：作为地面参考真值（ground truth），用于评估卫星反演、再分析产品、数值模式输出等各类降水估计产品的偏差与精度特征。在评估流程中，通常将待评估产品与 Stage IV 在相同时空窗口内进行逐格点或区域统计对比。
- **深度学习训练标签**：在降水偏差校正与降尺度任务中，Stage IV 常被用作高分辨率目标标签（label），驱动模型学习从粗分辨率再分析或卫星输入到细分辨率降水场的映射关系。典型的训练流程是将 Stage IV 聚合至与输入产品匹配的粗分辨率后作为分类或回归目标。
- **水文气象分析与驱动**：为流域尺度的降雨-径流模拟、洪水预报、极端降水事件分析等提供小时级高分辨率降水驱动场。

典型触发条件：需要 CONUS 范围内 4 km / 1 小时分辨率的地面降水参考场时，Stage IV 是首选数据集之一。

## 数据规格与来源

Stage IV 由美国国家环境预测中心（NCEP）下属的 12 个河流预报中心（River Forecast Centers）联合生成，通过融合约 140 部天气雷达和约 5500 个地面雨量计的观测数据，产出覆盖美国本土的逐小时格点化降水估计产品。

| 属性 | 规格 |
|------|------|
| 空间分辨率 | 4 km |
| 时间分辨率 | 1 小时 |
| 覆盖范围 | 美国本土（CONUS） |
| 时间跨度 | 2002 年至今 |
| 数据格式 | 网格化栅格，常见为 GRIB 或 netCDF 格式 |
| 数值含义 | 降水率（mm/h）或累积降水量（mm），具体取决于文件版本 |
| 生成机构 | NCEP / 12 River Forecast Centers |

**数据获取**：通过美国国家大气研究中心（NCAR）数据门户下载，需注册账号并同意数据使用协议。数据标识符 DOI 为 10.5065/D6PG1QDD。

## 边界与分流

- **覆盖范围限制**：Stage IV 仅覆盖美国本土。若研究区域位于美国以外（如欧洲、东亚、非洲等），需选用当地的雷达-雨量计融合产品或全球卫星降水产品作为替代。
- **空间代表性局限**：在山区和雷达稀疏区域（如美国西部山区），雷达波束遮挡与地形遮蔽导致降水估计的不确定性显著增大，数据可靠性降低。对于此类区域的精细分析，应考虑补充高密度雨量计网络数据或采用经过地形校正的专用产品。
- **与再分析产品的角色区分**：Stage IV 是基于雷达和雨量计的观测融合产品，而非再分析数据。在深度学习工作流中，它通常作为训练标签（target），而非输入特征。输入端一般使用 MERRA2、ERA5 等再分析产品或 GPM IMERG 等卫星产品。
- **分辨率匹配要求**：当输入产品（如 MERRA2，约 0.5°）与 Stage IV（4 km）分辨率差异较大时，需在训练前对 Stage IV 进行空间聚合以匹配输入分辨率，或在损失函数中设计多尺度策略。

## 质量检查

使用 Stage IV 数据时，建议关注以下已知质量问题并执行相应检查：

1. **雷达伪大值（spurious large values）**：受雷达传感器不确定性、波束旁瓣、地物杂波等因素影响，部分格点可能出现不合理的极端降水值。建议在使用前对极值进行统计检查，根据气候态分布设置合理的上限阈值进行截断或标记。
2. **山区降水偏差**：在地形复杂的山区，雷达波束无法有效覆盖低层大气，可能导致降水系统性低估。部分业务中心提供经过地形校正的版本，使用时应注意区分原始版本与校正版本。
3. **数据完整性检查**：个别时段或区域可能存在数据缺失（雷达故障、通信中断等）。建议检查时间序列的连续性，统计缺失比例，并对缺失时段做好插补或排除处理。
4. **版本一致性确认**：不同历史时期的 Stage IV 可能经历算法更新或数据源变化。进行跨时段分析时，应确认数据处理流程的一致性，必要时查阅对应的版本说明。

## 资源召回建议

- **数据下载**：NCAR 数据门户（https://doi.org/10.5065/D6PG1QDD）
- **配套读取工具**：Python 生态中可使用 `xarray` 配合 `cfgrib` 或 `netCDF4` 库读取 GRIB/netCDF 格式数据；用 `pyproj` 或 `cartopy` 进行投影转换与可视化。在大规模处理时，`dask` 可用于并行化读取与计算。
- **同类替代数据集**：
  - **MRMS（Multi-Radar Multi-Sensor）**：NCEP 生成的新一代融合产品，空间分辨率提升至 1 km，同样覆盖 CONUS，可视为 Stage IV 的升级替代。
  - **NEXRAD Level III**：单站雷达基数据产品，分辨率更高但需自行拼接覆盖。
  - **GPM IMERG**：全球覆盖的卫星降水产品，分辨率约 0.1° / 30 分钟，适用于全球性评估，但在 CONUS 范围内的精度通常低于 Stage IV。
- **在深度学习工作流中的典型角色**：Stage IV 通常作为训练集的高分辨率标签。使用时需将数据重采样或空间聚合至与输入产品（如 MERRA2）匹配的分辨率，然后按训练/验证/测试时段划分数据集。损失函数设计上，可采用以降水强度为权重的加权方案，以提升模型对极端降水事件的拟合能力。
