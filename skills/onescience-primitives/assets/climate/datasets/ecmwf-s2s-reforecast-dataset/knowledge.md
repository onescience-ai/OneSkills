# ECMWF S2S 亚季节性至季节性再预报数据集

## 适用范围

用于亚季节性（2至6周）至季节性时间尺度的预报任务，特别是需要大气与陆面变量耦合预报作为动态驱动输入的场景。典型触发条件包括：构建或评估亚季节性土壤湿度干旱预报模型；需要利用再预报数据进行模型训练、校准和技巧评估；需要全球范围的、具有一定预报时效（如45天）的集合预报驱动场。

## 输入

- **必需**：
  - ERA5 再分析数据作为初始场。
  - 访问 ECMWF 数据门户的权限。
  - 明确的预报目标变量列表（例如，大气平均温度 Tmean、可降水量 pwat、露点温度 Tdew；陆面变量如根区土壤湿度 RZSM）。
- **可选**：
  - 与其他再预报数据集（如 GEFSv12）的交叉验证需求。
  - 特定的初始化日期和预报起报时间要求。

## 输出

- 与实时预报同配置的集合再预报数据集，包含以下关键特性：
  - **集合成员数**：11个成员。
  - **预报时效**：标准为45天，部分应用可能使用其中的35天。
  - **空间分辨率**：1.5° 网格。
  - **输出变量**：大气变量（如 Tmean, pwat, Tdew）和陆面变量（如 RZSM）。
- 数据格式通常为 GRIB 或 NetCDF，可通过 ECMWF 数据存取工具（如 CDS API）下载。

## 流程节点

1.  **数据获取准备**：在 ECMWF 数据存取门户注册并获取数据访问权限。明确所需的变量、层级、时间范围和空间区域。
2.  **初始化日期与时间选择**：了解再预报数据的初始化时间表（通常为每周一和周四），并根据研究需求选择合适的初始化日期集合。
3.  **数据下载与预处理**：使用 ECMWF 提供的工具（如 CDS API 脚本）批量下载指定变量和时间范围的再预报数据。对原始数据进行解码、重网格或空间裁剪等预处理。
4.  **变量提取与对齐**：从下载的数据集中提取目标变量（如 RZSM, Tmean 等）。确保不同变量在时空维度上对齐，以备作为模型输入。
5.  **数据集构建与质量检查**：将处理后的数据组织成可供模型直接使用的格式（如时间序列、特征矩阵）。进行初步的质量检查，验证数据的完整性、值域合理性和时间连续性。

## 边界与分流

- **与 GEFSv12 数据集对比**：若研究需要比较不同预报系统（如 ECMWF 与 GEFS），需注意两者的初始化日期可能不完全对齐，需进行额外的日期匹配处理。
- **空间分辨率限制**：1.5° 的分辨率对于区域或局地尺度应用可能不足。若需要更高分辨率，应考虑使用降尺度方法或转向更高分辨率的数据集。
- **集合成员数量限制**：11个成员少于实时预报的51个成员，这可能限制对预报不确定性的完整量化。在需要更稳健的概率预报时，应意识到这一局限性。
- **数据可用性**：再预报数据的时间覆盖范围有限（例如，通常从1990年代中期开始），对于更早的历史时期研究可能无法提供数据。

## 回退策略

- **数据获取失败**：若无法访问 ECMWF 数据门户，可检查是否有替代的公开存档或合作渠道。在模型开发阶段，可考虑使用其他开源再预报数据集（如 GEFSv12）作为临时替代进行方法验证。
- **变量缺失**：若所需的特定变量（如某一层土壤湿度）未在标准输出中，需查阅 ECMWF 文档确认是否可通过派生计算获得，或调整模型设计以适应可用变量。
- **分辨率不匹配**：若下游应用需要更高分辨率，需开发或应用统计降尺度、动力降尺度或机器学习超分辨率方法，但这会引入额外的不确定性。

## 质量检查

- **完整性检查**：验证下载的数据是否覆盖了所有请求的初始化日期、预报时效和集合成员，无缺失文件或时间步。
- **值域合理性检查**：检查各变量的物理值域是否在合理范围内（例如，土壤湿度应在 0 到饱和值之间）。
- **时间一致性检查**：确保同一初始化日期的预报场在时间上是连续的，无异常跳变。
- **与观测对比（如适用）**：在可用时段内，可将再预报数据与对应的观测（如 ERA5 分析场或实测数据）进行初步对比，检查系统性偏差。

## 资源召回建议

- **官方门户**：ECMWF S2S 数据集存储库：`https://apps.ecmwf.int/datasets/data/s2s/levtype=sfc/type=cf/`
- **相关模式系统**：了解其背后的大气模式（Integrated Forecasting System, IFS）和陆面模式（HTESSEL）的基本原理，有助于理解预报场的特性和潜在偏差。
- **配套再分析数据**：ERA5 再分析数据是驱动再预报初始场的同源数据，常用于提供“真实”初始状态和评估预报技巧的参考真值。
- **社区工具**：xarray、cfgrib 等 Python 库常用于处理此类 NetCDF/GRIB 格式的气象数据。
