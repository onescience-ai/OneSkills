# 随机森林模型性能评估

## 适用范围

用于评估基于机器学习（如随机森林）的大气污染物浓度预测模型在独立测试数据集上的预测性能。本评估框架适用于任何将预测值与观测值进行对比的监督学习回归模型性能分析场景，典型任务包括模型开发过程中的性能验证、不同建模方案（如不同特征组合、不同算法）的横向比较、以及机器学习模型与传统统计模型或物理化学传输模型（如CMAQ）的预测能力对标。

## 输入

- **必需**：
  - 模型预测的污染物浓度值序列。
  - 对应时段、点位的实测污染物浓度值序列。
- **可选**：
  - 不同模型或不同配置下的预测结果序列（用于模型间比较）。
  - 按气象条件、季节、时段等维度划分的子集标签（用于分组评估）。

## 输出

- 一组综合性能指标，通常包括：
  - **误差类指标**：均方误差（MSE）、均方根误差（RMSE）、平均绝对误差（MAE）。
  - **相关性指标**：决定系数（r²）。
  - **偏差类指标**：平均偏差（MB）、归一化平均偏差（NMB）。
  - **综合误差与一致性指标**：平均绝对误差（MGE）、归一化平均绝对误差（NMGE）、效率系数（COE）、一致性指数（IOA）、预测值在观测值两倍范围内的比例（FAC2）。
- 模型性能的综合评估结论（如与基准模型的比较结果）。

## 流程节点

1.  **准备数据**：确保用于评估的测试集独立于模型训练数据。将模型对测试集的预测值与对应的观测值一一配对。
2.  **计算性能指标**：依次计算所选的一组统计指标。常用指标的计算公式如下：
    - **RMSE** = \(\sqrt{\frac{1}{n}\sum_{i=1}^{n}(P_i - O_i)^2}\)，其中P为预测值，O为观测值。
    - **r²**：预测值与观测值的皮尔逊相关系数的平方。
    - **MB** = \(\frac{1}{n}\sum_{i=1}^{n}(P_i - O_i)\)
    - **NMB** = \(\frac{\sum_{i=1}^{n}(P_i - O_i)}{\sum_{i=1}^{n}O_i}\)
    - **MGE** = \(\frac{1}{n}\sum_{i=1}^{n}|P_i - O_i|\)
    - **NMGE** = \(\frac{\sum_{i=1}^{n}|P_i - O_i|}{\sum_{i=1}^{n}O_i}\)
    - **COE** = \(1 - \frac{\sum_{i=1}^{n}(P_i - O_i)^2}{\sum_{i=1}^{n}(|P_i - \bar{O}| + |O_i - \bar{O}|)^2}\)，值越接近1越好。
    - **IOA** = \(1 - \frac{\sum_{i=1}^{n}(P_i - O_i)^2}{\sum_{i=1}^{n}(|P_i - \bar{O}| + |O_i - \bar{O}|)^2}\)（注：IOA与COE计算式在部分文献中等价，需注意定义）。
    - **FAC2**：满足 \(0.5 \leq \frac{P_i}{O_i} \leq 2.0\) 的数据点占总数据点的比例。
3.  **综合评估与比较**：
    - 分析各项指标，判断模型整体性能（如高r²、低RMSE、小偏差）。
    - 若存在基准模型（如传统统计模型、CMAQ模型）的评估结果，进行横向对比。
    - 可按子集（如不同季节、不同污染水平）分组计算指标，评估模型在不同条件下的稳定性。

## 边界与分流

- **与模型训练分离**：评估必须在模型未见过的独立测试集上进行。若数据存在时间或空间上的强相关性，需采用时间交叉验证或空间交叉验证等方式，防止评估结果因数据泄漏而过于乐观。
- **多指标综合判断**：不应仅依赖单一指标（如r²）。例如，模型可能存在高相关性但同时存在系统性偏差（MB显著不为零），此时需结合MB、NMB等偏差指标综合判断。FAC2等指标对极端值敏感度较低，可补充反映模型的稳健性。
- **性能比较基准**：在进行模型间比较时，需确保使用相同的测试集和相同的评估指标。与物理化学传输模型比较时，需注意两者输入数据和时空分辨率可能不同。
- **极端事件评估**：模型在重污染过程或特殊气象条件下的预测性能可能与整体性能存在差异，建议单独对这类子集进行评估。

## 回退策略

- **测试集不足或不可用**：若无法获取独立测试集，可考虑采用留出法、k折交叉验证或时间序列交叉验证进行内部性能评估，但需明确说明这属于模型内部验证，其性能估计可能比独立测试集评估乐观。
- **观测数据缺失或质量不佳**：对缺失观测值的数据点，在计算指标时应剔除。若观测数据本身存在较大测量误差，评估结果应注明观测数据的不确定性范围。
- **性能指标计算错误**：建议使用成熟的开源工具（如Python的scikit-learn、statsmodels或专用的气象模型评估工具包）进行计算，并与手动计算结果进行交叉验证。
