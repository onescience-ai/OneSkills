# 天气预报模型配置验证

## 适用范围
适用于天气预报模型（如深度学习模型、数值模式）在推理前的配置验证任务，确保模型可复现、配置正确。

## 输入
- 模型权重文件路径
- 模型配置参数（架构参数、超参数）
- 随机种子设置
- 最小测试输入数据

## 输出
- 方法工件身份报告（method_artifact_identity_report）
- 干运行日志（dry_run_log）
- 配置验证通过/失败状态

## 流程节点
1. **版本确认** → 记录模型版本号、权重文件校验和
2. **参数冻结** → 将所有配置参数写入配置文件，禁止运行时修改
3. **随机种子设置** → 设置Python、NumPy、PyTorch/TensorFlow随机种子
4. **最小干运行** → 使用小样本输入执行推理，验证输出格式和维度
5. **契约检查** → 验证输入输出契约（数据类型、维度、范围）

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 随机种子 | 固定值（如42） | [1] | 确保可复现性 |
| 干运行样本数 | 1-10 | [1] | 最小测试规模 |
| 权重校验 | SHA256校验和 | [1] | 权重文件完整性 |

## 边界与分流
- 权重文件不存在 → 回退至模型下载步骤
- 干运行失败 → 检查输入数据格式和模型配置
- 随机种子不一致 → 记录警告但继续执行

## 质量检查
- 必须生成method_artifact_identity_report
- 必须生成dry_run_log
- 配置文件必须包含所有关键参数

## 回退策略
- 干运行失败时，使用默认配置重试
- 配置验证失败时，记录详细错误信息
