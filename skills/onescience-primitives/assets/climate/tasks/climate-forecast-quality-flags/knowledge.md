# 气象预报产品质量标志编码

## 适用范围
适用于earth域预报产品的质量标志生成，涵盖观测质量标志、预报质量标志和产品元数据标准。

## 输入
- 预报结果（含不确定性估计）
- 验证指标（RMSE、R2等）
- 站点元数据（坐标、海拔、观测类型）

## 输出
- 质量标志文件（per-station, per-variable, per-time）
- 产品元数据文件（CF约定格式）
- 质量标志统计报告

## 流程节点

### 1. 质量标志等级定义
- 操作：定义good/fair/poor等级及对应阈值
- 参数：RMSE阈值、置信区间
- 质量门禁：阈值需与验收门限一致

### 2. 质量标志编码
- 操作：按WMO标准或业务系统标准编码
- 参数：编码体系选择
- 质量门禁：编码格式符合标准

### 3. 不确定性关联
- 操作：将质量标志与不确定性范围关联
- 参数：各等级对应的不确定性范围
- 质量门禁：每个质量等级有明确的不确定性区间

### 4. 产品元数据生成
- 操作：按CF约定生成元数据
- 参数：坐标系统、时间基准、单位
- 质量门禁：元数据完整且符合CF约定

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 质量等级 | good/fair/poor | [1] | 三级质量标志 |
| good阈值 | RMSE < 1σ | [1] | 低于标准差 |
| fair阈值 | RMSE < 2σ | [1] | 低于2倍标准差 |
| poor阈值 | RMSE ≥ 2σ | [1] | 高于2倍标准差 |
| 坐标系统 | WGS84 | [1] | CF约定 |
| 时间基准 | UTC | [1] | CF约定 |
| 温度单位 | K（CF标准）或°C | [1] | 需标注 |

## 边界与分流
- 不确定性估计不可用时 → 仅使用RMSE阈值
- 元数据不完整 → 标记为PARTIAL

## 质量检查
- 验证质量标志分布合理性
- 检查元数据是否符合CF约定
- 确认不确定性与质量标志关联

## 回退策略
- 质量标志逻辑异常时：检查阈值设置和验证指标
