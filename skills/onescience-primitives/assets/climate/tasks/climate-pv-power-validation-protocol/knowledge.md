# 光伏功率预测标准验证协议

## 适用范围
本卡片适用于光伏功率预测任务的验证阶段，特别是针对多站联合预测场景。提供按站点分层和爬坡事件分层的检验协议、指标计算方法和验收门限设置原则。

## 输入
- 预测结果数据集：包含时间戳、站点ID、预测功率值
- 真实观测数据集：包含时间戳、站点ID、实际功率值
- 站点元数据：包括站点容量、地理位置、组件类型等
- 爬坡事件定义：功率变化超过阈值的事件（如10%容量/15分钟）

## 输出
- 验证报告：包含分层指标、基线比较、验收结论
- 性能指标：RMSE、MAE、R²、MAPE等
- 爬坡事件检验结果：检测率、误报率、命中率

## 流程节点
1. 数据预处理 → 对齐时间序列，处理缺失值
2. 分层划分 → 按站点、按预测时效、按天气类型分层
3. 爬坡事件检测 → 基于功率变化率识别爬坡事件
4. 指标计算 → 计算各层性能指标
5. 基线比较 → 与持久性预报、气候平均等基线比较
6. 验收判定 → 根据预设门限判定是否通过

## 边界与分流
- 若数据质量不足（缺失率>20%），应先进行数据修复或降级处理
- 若站点数量过少（<3个），分层统计可能不显著，需合并分析
- 若爬坡事件样本过少（<10个），爬坡检验结果仅供参考

## 质量检查
- 检查预测与观测数据的时间对齐性
- 验证分层统计的样本量是否足够
- 确认基线比较的公平性（相同数据集、相同评估时段）
