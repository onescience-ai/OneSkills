# 闪电超阈值告警区域提取

## 适用范围

适用于0-6小时闪电发生临近预报任务的s05阶段，当需要从分时效闪电概率场中提取超阈值告警区域、生成质量标志和产品元数据时使用。不适用于概率场生成本身（那是s04的职责）、不适用于验证评估（那是s06的职责）。

## 输入

- 分时效闪电概率场：s04输出的T+1h至T+6h概率场栅格（NetCDF格式，值域[0,1]）
- 概率阈值配置：业务定义的告警阈值（如0.3、0.5、0.7）
- 质量标志规则：数据完整性、预报范围、不确定性信息的编码规则
- 最小告警区域面积：连通域面积筛选阈值（如5km²）

## 输出

- 分时效告警区域栅格：每个提前期的二值告警区域（0/1）
- 质量标志文件：每个网格点的质量编码（含数据完整性、预报范围、不确定性信息）
- 产品元数据：文件清单、变量说明、坐标系、时间信息
- 告警统计摘要：每个提前期的告警面积、最大概率值、告警区域质心

## 流程节点

### 1. 概率场阈值分割 → 2. 连通域分析 → 3. 面积筛选 → 4. 质量标志生成 → 5. 产品元数据编制

**步骤1：概率场阈值分割**
- 操作：对每个提前期的概率场，按阈值分割为二值告警区域
- 参数：
  - 告警阈值层级：
    - 0.3（黄色/注意）：表示有30%以上概率发生闪电
    - 0.5（橙色/警告）：表示有50%以上概率发生闪电
    - 0.7（红色/严重）：表示有70%以上概率发生闪电
  - 阈值设定依据：基于历史数据的POD（检测概率）和FAR（虚警率）平衡 [Stensrud et al., 2009]
- 质量门禁：阈值分割后二值矩阵形状与原始概率场一致

**步骤2：连通域分析**
- 操作：对二值告警区域进行连通域标记
- 参数：
  - 连通性定义：8连通（上下左右+对角线）
  - 标记方法：两次扫描算法（two-pass algorithm）
- 质量门禁：每个连通域有唯一标识；连通域数量记录

**步骤3：面积筛选**
- 操作：过滤面积过小的连通域
- 参数：
  - 最小面积阈值：5km²（约5个1km×1km网格）[通用实践]
  - 面积计算：连通域内网格数×网格面积
- 质量门禁：保留的连通域面积≥阈值；被过滤的连通域记录日志

**步骤4：质量标志生成**
- 操作：为每个网格点生成质量编码
- 参数：
  - 数据完整性标志（3位）：
    - 000：完整
    - 001：输入数据有缺测（≤10%）
    - 010：输入数据有缺测（10-30%）
    - 011：输入数据缺测>30%
    - 100：无输入数据
  - 预报范围标志（2位）：
    - 00：在训练数据空间范围内
    - 01：接近训练数据边界
    - 10：超出训练数据空间范围
  - 不确定性标志（2位）：
    - 00：低不确定性（模型置信度高）
    - 01：中不确定性
    - 10：高不确定性
- 质量门禁：每个网格点质量编码非空；编码值在有效范围内

**步骤5：产品元数据编制**
- 操作：生成产品元数据文件
- 参数：
  - 文件命名：`lightning_warning_T+{leadtime}h_{init_time}.nc`
  - 必需元数据：起报时间、坐标系、单位、数据来源、模型版本、阈值配置
  - 可选元数据：告警面积统计、最大概率值、质心坐标
- 质量门禁：元数据文件可正确解析；所有必需字段非空

| 橙色阈值 | 0.5 | [归因报告s05] | 警告级别告警 |

## 边界与分流

### 概率场数据缺失
- **前提**：s04输出的概率场完整
- **不成立时**：检查缺失的提前期；若缺失≤2个，使用相邻时段插值；否则标记该时段告警不可用
- **改道目标**：数据完整性检查、缺失时段处理

### 阈值设定不合理
- **前提**：阈值配置与业务需求匹配
- **不成立时**：若FAR>50%，提高阈值；若POD<50%，降低阈值；参考历史统计数据调整
- **改道目标**：阈值优化、业务需求重新评估

### 连通域面积过小
- **前提**：存在面积≥最小阈值的连通域
- **不成立时**：降低最小面积阈值（最低至1km²）；或标记该时段无有效告警
- **改道目标**：面积阈值调整

## 质量检查

- 阈值分割检查：二值矩阵中1的比例在合理范围（通常<30%）
- 连通域检查：连通域数量和面积分布合理
- 质量标志检查：每个网格点有完整质量编码
- 元数据检查：所有必需元数据字段完整且格式正确
- 文件检查：输出文件可正确打开和读取

## 回退策略

- 阈值不合理：使用验证集重新优化阈值
- 连通域分析失败：降级使用简单面积统计
- 质量标志生成失败：使用默认质量标志（0000000）
