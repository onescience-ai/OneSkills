# 机器学习模型选择与评估标准方法

## 适用范围
本卡片适用于光伏功率预测任务中的机器学习模型选择与评估，提供防止过拟合、正确选择模型的标准方法。

## 输入
- 训练数据集：包含特征和目标变量
- 验证数据集：用于模型选择和超参数调优
- 测试数据集：用于最终性能评估
- 候选模型列表：如线性回归、随机森林、梯度提升、神经网络等

## 输出
- 最佳模型：基于验证集性能选择的模型
- 性能报告：训练集、验证集、测试集上的性能指标
- 过拟合诊断：训练集与验证集性能差异分析

## 流程节点
1. 数据划分 → 将数据划分为训练集、验证集、测试集（如70%/15%/15%）
2. 交叉验证 → 使用k折交叉验证评估模型稳定性
3. 模型训练 → 在训练集上训练候选模型
4. 性能评估 → 在验证集上评估模型性能
5. 过拟合检测 → 比较训练集和验证集性能差异
6. 模型选择 → 选择验证集性能最好的模型

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 数据划分比例 | 70%/15%/15% | [通用实践] | 训练/验证/测试集划分 |
| 交叉验证折数 | 5折或10折 | [论文4] | 用于模型稳定性评估 |
| 过拟合检测阈值 | R²差异>0.1 | [归因报告] | 训练集与验证集R²差异超过0.1为过拟合迹象 |
| 模型选择标准 | 验证集性能最优 | [归因报告] | 基于验证集性能选择模型，而非训练集 |

## 边界与分流
- 若数据量过少，可使用留一交叉验证代替k折交叉验证
- 若模型复杂度过高，应考虑正则化或简化模型
- 若验证集性能普遍较差，应检查数据质量或特征工程

## 质量检查
- 验证数据划分的随机性，避免数据泄露
- 检查交叉验证结果的一致性
- 确认过拟合诊断的准确性
