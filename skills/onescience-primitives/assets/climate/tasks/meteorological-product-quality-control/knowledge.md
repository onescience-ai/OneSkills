# 气象产品质控规范

## 适用范围
适用于气象科研任务中需要对输出产品进行质量控制的场景，包括质量标志编码、物理范围核验、派生产品文档记录等。

## 输入
- 气象产品数据（NetCDF、GeoJSON等）
- 任务质量要求
- 相关标准规范

## 输出
- 质量控制报告，包含：
  - 质量标志编码记录
  - 物理范围核验结果
  - 派生产品文档
  - 元数据完整性检查

## 流程节点
1. **质量标志生成** → 为每个输出变量添加quality_flag属性
2. **物理范围核验** → 核验数据是否在合理物理范围内
3. **单位恢复** → 保留输入变量的units和standard_name属性
4. **公式记录** → 记录派生产品的计算公式和源变量
5. **元数据验证** → 验证元数据完整性

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 温度合理范围 | 250-320K | [1] | 气象学合理范围 |
| 湿度合理范围 | 0-0.05 kg/kg | [1] | 比湿合理范围 |
| 气压合理范围 | 90000-110000 Pa | [1] | 气压合理范围 |
| 风速合理范围 | 0-100 m/s | [1] | 风速合理范围 |
| 质量标志类型 | bit-field质量标志 | [2] | 多级质量分类 |
| 置信度分级 | 0-100% | [2] | 算法置信度 |

## 边界与分流
- 当数据超出物理范围时，记录异常值并标记为可疑数据
- 当质量标志缺失时，在元数据中说明并标记为未质控
- 当公式记录不完整时，在交付物中补充说明

## 质量检查
- 验证质量标志变量是否存在
- 检查物理范围是否合理
- 确认元数据是否完整

## 回退策略
- 当质控失败时，记录失败原因并标记相关交付项为PARTIAL
- 当质量标志缺失时，在元数据中说明并标记为未质控
