# NDVI数据异常值检测与处理

## 适用范围
执行AVHRR-MODIS连续NDVI历史序列融合重建前，需要对输入数据进行质量检查和异常值处理。本卡指导如何理解NDVI物理意义、确认标准范围、识别异常值并采取适当处理策略，确保输入数据质量。

## 输入
- 原始AVHRR和MODIS NDVI数据
- 数据质量标志文件
- 任务质量要求

## 输出
- 处理后的NDVI数据（异常值已处理）
- 数据质量报告
- 异常值处理记录

## 流程节点
1. 理解NDVI物理意义 → 2. 确认标准范围 → 3. 识别异常值 → 4. 分析异常原因 → 5. 选择处理方法 → 6. 执行处理并验证

### 步骤1：理解NDVI物理意义
- **操作**：理解NDVI的物理意义和计算公式
- **NDVI计算**：(NIR - Red) / (NIR + Red)
- **物理意义**：反映植被生长状况，值越高表示植被越茂盛
- **质量门禁**：正确理解NDVI含义

### 步骤2：确认标准范围
- **操作**：确认NDVI的标准范围
- **理论范围**：-1 到 1
- **有效范围**：0 到 1（植被区域）
- **典型值**：
  - 裸土：0.1-0.2
  - 稀疏植被：0.2-0.3
  - 茂密植被：0.6-0.9
- **质量门禁**：标准范围明确

### 步骤3：识别异常值
- **操作**：使用统计方法识别异常值
- **识别方法**：
  - 阈值法：超出[0, 1]范围的值
  - 统计法：超出均值±3倍标准差的值
  - 质量标志法：根据质量标志识别不可靠值
- **质量门禁**：异常值识别准确

### 步骤4：分析异常原因
- **操作**：分析异常值产生的原因
- **常见原因**：
  - 云污染
  - 大气影响
  - 传感器误差
  - 数据处理错误
- **质量门禁**：原因分析合理

### 步骤5：选择处理方法
- **操作**：根据异常原因选择处理方法
- **处理方法**：
  - 裁剪：直接移除异常值
  - 掩膜：标记异常值为无效
  - 替换：用邻近值或插值替换
  - 质量标志加权：根据质量标志降低权重
- **质量门禁**：处理方法适当

### 步骤6：执行处理并验证
- **操作**：执行异常值处理并验证结果
- **验证内容**：
  - 处理后数据范围是否合理
  - 异常值是否被正确处理
  - 数据连续性是否保持
- **质量门禁**：处理结果合格

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| NDVI理论范围 | [-1, 1] | [1] | 物理计算范围 |

| 异常值检测阈值 | 均值±3σ | [2] | 统计异常值检测 |

### 校准数值
以下数值来自遥感数据质量研究[1][2]，供量级校准；其他区域需以自身证据重新锚定：
| 地物类型 | NDVI典型范围 | 说明 |
|----------|--------------|------|
| 水体 | -0.1 - 0.1 | 水体NDVI通常为负值 |
| 裸土 | 0.1 - 0.2 | 无植被覆盖 |
| 稀疏植被 | 0.2 - 0.4 | 植被覆盖度低 |
| 中等植被 | 0.4 - 0.6 | 植被覆盖度中等 |
| 茂密植被 | 0.6 - 0.9 | 植被覆盖度高 |

## 边界与分流
- 若异常值比例过高（>10%），检查数据源质量
- 若无法确定异常原因，保守处理（标记为无效）
- 若处理后数据缺失过多，考虑使用替代数据源

## 质量检查
- 检查处理后数据是否在合理范围内
- 验证异常值处理是否正确
- 确认数据连续性是否保持

## 回退策略
- 若处理方法效果不佳，尝试替代方法
- 若数据质量问题严重，报告并等待指示
