# 光伏功率预测领域专门知识

## 适用范围
本卡片适用于光伏功率预测任务的规划与执行阶段，提供领域专门知识，包括物理原理、预测方法、数据预处理和多站联合预测考虑。

## 输入
- 任务需求：预测时段、站点列表、预测精度要求
- 可用数据：气象数据、历史功率数据、电站属性数据

## 输出
- 方法选择建议：基于领域知识推荐合适的预测方法
- 数据预处理方案：容量归一化、缺测处理、异常值检测
- 多站联合预测策略：空间相关性、电站异质性考虑

## 流程节点
1. 物理原理理解 → 光伏功率的辐照度-功率转换、温度系数、组件效率
2. 方法选择 → 物理模型、统计模型、机器学习模型、混合模型
3. 数据预处理 → 容量归一化、缺测处理、异常值检测
4. 特征工程 → 气象因素、时间特征、电站属性
5. 多站联合预测 → 空间相关性、电站异质性、联邦学习
6. 模型验证 → 分层验证、基线比较、验收判定

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 辐照度-功率转换效率 | 15%-20% | [领域知识] | 典型光伏组件效率范围 |
| 温度系数 | -0.3%/-0.5% per °C | [领域知识] | 温度对光伏输出的影响 |
| 容量归一化方法 | 功率/装机容量 | [领域知识] | 不同容量电站的可比性处理 |
| 空间相关性范围 | 10-50公里 | [领域知识] | 多站联合预测的空间尺度 |

## 边界与分流
- 若物理模型数据不足，应转向数据驱动方法
- 若电站异质性过大，应考虑分组建模或联邦学习
- 若气象数据精度不足，应降低预测时效或使用集合预报

## 质量检查
- 验证物理原理应用的正确性
- 检查数据预处理的一致性
- 确认多站联合预测的合理性
