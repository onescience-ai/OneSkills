# NDVI融合产品验收门限设定

## 适用范围
执行AVHRR-MODIS连续NDVI历史序列融合重建后，需要设定验收门限判定产品是否达到预期性能标准。本卡指导如何选择验收指标、确定门限值、参考行业标准和制定验收流程。

## 输入
- 融合产品验证指标计算结果
- 任务性能要求
- 行业标准参考文档

## 输出
- 验收门限文档
- 验收判定报告
- 性能改进建议（若未达标）

## 流程节点
1. 确定验收指标 → 2. 收集行业标准 → 3. 设定门限值 → 4. 制定验收流程 → 5. 执行验收判定 → 6. 输出验收报告

### 步骤1：确定验收指标
- **操作**：根据任务需求选择验收指标
- **指标类型**：
  - 绝对精度指标：偏差、RMSE
  - 相对精度指标：相关系数、Nash-Sutcliffe效率
  - 趋势指标：趋势保持、突变检测
- **质量门禁**：指标选择合理

### 步骤2：收集行业标准
- **操作**：收集相关产品的验收标准
- **标准来源**：
  - USGS产品验证标准
  - ESA产品验证指南
  - GLASS产品验证报告
- **质量门禁**：标准来源权威

### 步骤3：设定门限值
- **操作**：根据行业标准和任务需求设定门限值
- **门限设定原则**：
  - 参考行业最佳实践
  - 考虑任务特殊需求
  - 确保门限可达到
- **质量门禁**：门限值合理

### 步骤4：制定验收流程
- **操作**：制定验收流程和判定规则
- **流程步骤**：
  1. 验证指标计算
  2. 门限比较
  3. 综合判定
  4. 报告输出
- **质量门禁**：流程完整

### 步骤5：执行验收判定
- **操作**：根据验证指标和门限进行判定
- **判定规则**：
  - 所有指标达标：通过
  - 部分指标未达标：有条件通过
  - 关键指标未达标：不通过
- **质量门禁**：判定结果明确

### 步骤6：输出验收报告
- **操作**：生成验收报告文档
- **报告内容**：
  - 验证指标结果
  - 门限比较
  - 判定结论
  - 改进建议
- **质量门禁**：报告完整

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 验收指标完整性 | 覆盖精度、趋势、稳定性 | [1] | 确保全面评估 |
| 门限设定依据 | 行业标准+任务需求 | [1] | 确保合理性 |
| 判定规则明确性 | 三级判定（通过/有条件/不通过） | [1] | 确保可操作性 |

### 校准数值
以下数值来自卫星产品验证标准[1]，供量级校准；其他产品需以自身证据重新锚定：
| 指标 | 优秀门限 | 合格门限 | 说明 |
|------|----------|----------|------|
| 偏差（Bias） | < 0.02 | < 0.05 | 越小越好 |
| 均方根误差（RMSE） | < 0.05 | < 0.1 | 越小越好 |
| 相关系数（R²） | > 0.95 | > 0.9 | 越大越好 |
| 趋势斜率差异 | < 10% | < 20% | 趋势保持能力 |

## 边界与分流
- 若行业标准不明确，参考类似产品标准
- 若任务需求特殊，与客户协商门限值
- 若门限无法达到，提出改进建议

## 质量检查
- 检查门限设定是否合理
- 验证判定规则是否可操作
- 确认验收报告是否完整

## 回退策略
- 若门限设定过高，适当放宽并说明原因
- 若验收流程复杂，简化流程但保留核心判定
