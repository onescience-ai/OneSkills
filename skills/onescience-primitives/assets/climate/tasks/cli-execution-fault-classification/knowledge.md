# CLI 非交互执行与故障分类

## 适用范围
适用于科研计算中命令行工具（CLI）的非交互执行场景，包括气象模式编译、数值模拟运行、数据处理脚本等。触发场景：CLI命令执行失败、超时、返回非零退出码或标准错误输出异常。

## 输入
- CLI命令及参数
- 执行环境信息（操作系统、shell、权限）
- 认证凭证（如API密钥、令牌）
- 超时设置
- 工作目录和环境变量

## 输出
- 退出码（exit code）
- 标准输出（stdout）
- 标准错误（stderr）
- 故障分类结果
- 修复建议

## 流程节点

1. **命令解析** → 解析CLI命令、参数、环境变量
2. **执行环境检查** → 验证执行权限、依赖项、资源限制
3. **命令执行** → 启动进程并监控执行状态
4. **退出码分析** → 根据退出码分类故障类型
5. **标准错误解析** → 提取关键错误信息
6. **超时检测** → 检测命令是否超时
7. **故障分类** → 将故障归类为认证、权限、依赖、资源、超时等类型
8. **修复建议生成** → 根据故障类型提供修复策略

## 关键参数

### 通用判据
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 退出码0 | 成功 | 通用 | 命令执行成功，无错误 |
| 退出码1 | 通用错误 | 通用 | 命令执行失败，具体错误需查看stderr |
| 退出码2 | 用法错误 | 通用 | 命令参数或选项错误 |
| 退出码126 | 权限问题 | 通用 | 命令不可执行或无执行权限 |
| 退出码127 | 命令未找到 | 通用 | 命令不存在或PATH未正确设置 |
| 退出码130 | SIGINT中断 | 通用 | 命令被Ctrl+C中断 |
| 退出码137 | SIGKILL终止 | 通用 | 命令被系统杀死（通常因内存不足） |
| 退出码143 | SIGTERM终止 | 通用 | 命令被正常终止 |

### 故障分类表
| 故障类型 | 典型退出码 | 典型错误信息 | 修复策略 |
|----------|------------|--------------|----------|
| 认证失败 | 1, 401, 403 | unauthorized, forbidden, token expired | 更新凭证、检查认证配置 |
| 权限不足 | 1, 126 | permission denied, access denied | 检查文件权限、用户组、sudo配置 |
| 命令不存在 | 127 | command not found, No such file | 检查PATH、安装依赖、验证命令路径 |
| 参数错误 | 2 | invalid option, missing argument | 检查命令语法、参数顺序、帮助文档 |
| 资源不足 | 137 | out of memory, killed | 增加内存限制、优化算法、分批处理 |
| 超时 | 124, 137 | timeout, time limit exceeded | 增加超时设置、优化算法、异步执行 |
| 依赖缺失 | 1 | module not found, library missing | 安装缺失依赖、检查虚拟环境 |

## 边界与分流
- 退出码不在上述常见范围 → 查阅具体工具的退出码文档
- stderr输出为空但退出码非0 → 检查日志文件、环境变量、权限
- 超时设置不合理导致误判 → 根据任务复杂度调整超时参数
- 认证凭证格式错误 → 验证凭证格式、编码、有效期

## 质量检查
- 退出码解析准确率 > 95%
- 故误分类匹配率 > 90%
- 修复建议有效性验证：执行修复建议后命令成功率提升

## 回退策略
- 退出码分析失败 → 回退到基础错误信息提取
- 故误分类不确定 → 返回"未知故障"并建议人工排查
- 修复建议无效 → 记录失败原因，建议升级或更换工具
