# 光伏功率预测数据来源规范

## 适用范围
本卡片适用于光伏功率预测任务的数据获取阶段，明确必需数据的来源、时点规则以及数据缺失时的处理流程。

## 输入
- 任务需求：预测时段（如0-48小时）、站点列表、预测精度要求
- 数据可用性检查清单

## 输出
- 数据获取方案：明确数据来源、获取方式、时间要求
- 数据缺失处理协议：当数据不可用时的正确处理流程
- 数据时点验证报告：确认数据符合时点规则

## 流程节点
1. 数据需求分析 → 确定所需数据类型和时间范围
2. 数据源识别 → 确定气象数据、历史功率数据、电站属性数据的来源
3. 数据时点验证 → 确认数据是签发时可获得的，而非事后数据
4. 数据获取尝试 → 从指定来源获取数据
5. 数据缺失处理 → 若数据不可用，标记任务为BLOCKED并说明缺失信息
6. 数据质量检查 → 验证数据完整性、一致性、时效性

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 气象数据来源 | 气象局签发预报产品 | [归因报告] | 必须是签发时可获得的预报数据 |
| 历史功率数据来源 | 电站SCADA系统 | [归因报告] | 历史运行数据，用于模型训练 |
| 电站属性数据来源 | 电站设计文档 | [归因报告] | 容量、组件类型、安装角度等 |
| 数据时点规则 | 签发时可获得的数据 | [归因报告] | 不能使用目标时刻之后形成的观测 |

## 边界与分流
- 若气象预报数据不可用，应标记任务为BLOCKED，而非使用模拟数据
- 若历史功率数据缺失，可考虑使用相似电站数据迁移，但需标注
- 若电站属性数据不完整，应基于可用信息进行合理假设，并记录假设

## 质量检查
- 验证数据时间戳是否符合预测任务的时间要求
- 检查数据是否在签发时可获得（非事后数据）
- 确认数据缺失率是否在可接受范围内（<20%）

## 资源召回建议
当任务涉及光伏功率预测数据获取、数据预处理或数据质量评估时召回本卡片。配套资源包括光伏功率预测验证卡片、数据预处理卡片等。
