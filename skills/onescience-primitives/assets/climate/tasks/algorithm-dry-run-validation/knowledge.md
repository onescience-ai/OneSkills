# 最小干运行验证规范

## 适用范围
适用于气象科研任务中需要验证算法输入输出契约的场景，在正式执行核心计算前，使用小样本数据验证算法的正确性和可复现性。

## 输入
- 算法代码
- 小样本数据（1-2个时间步）
- 配置参数文件

## 输出
- 最小干运行验证报告，包含：
  - 输入输出契约验证结果
  - 输出值域检查结果
  - 随机种子设置记录
  - 方法工件身份报告

## 流程节点
1. **小样本数据准备** → 准备1-2个时间步的子集数据
2. **算法执行** → 使用小样本数据执行完整算法流程
3. **输出检查** → 检查输出shape、值域、NaN/Inf情况
4. **随机种子设置** → 设置随机种子保证可复现性
5. **方法工件记录** → 记录方法版本、参数来源和兼容性说明

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 随机种子默认值 | 0 | [1] | 保证可复现性 |
| 小样本时间步数 | 1-2 | [2] | 最小验证数据集 |
| 输出值域检查 | 无NaN/Inf | [3] | 基本正确性验证 |
| 形状检查 | 与输入一致 | [3] | 输入输出契约验证 |

## 边界与分流
- 当随机种子未设置时，使用默认值0并记录
- 当输出包含NaN/Inf时，记录异常位置并标记验证失败
- 当形状不匹配时，记录不匹配详情并标记验证失败

## 质量检查
- 验证输出不含NaN/Inf值
- 验证输出shape与预期一致
- 验证随机种子设置正确

## 回退策略
- 当最小干运行失败时，记录失败原因并暂停核心计算
- 当随机种子设置失败时，使用确定性算法模式

## 资源召回建议
- 当任务需要验证算法输入输出契约时召回本卡片
- 配套使用算法选择论证卡片
