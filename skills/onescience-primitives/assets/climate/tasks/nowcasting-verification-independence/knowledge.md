# 临近预报验证中的独立验证数据规范

## 适用范围

临近预报（0-2小时）模型性能验证场景。每个预报时效（如 10min、20min、30min、45min、60min、90min、120min）的验证标签必须反映各自目标时刻的真实天气状态，而非使用同一份标签数据。验证标签的独立性直接影响检验指标（CSI、FSS、Brier Score）的可信度和时效依赖性分析的有效性。

## 输入

- 预报产品：各时效的冰雹概率场（如 P_10min, P_20min, ..., P_120min）
- 观测数据：与各预报时效目标时刻对应的独立观测（地面冰雹报告、双偏振雷达衍生产品、卫星观测等）
- 预报-观测时空匹配规则（邻域半径、时间容差）

## 输出

- 各时效独立的验证标签（二值化冰雹发生/不发生）
- 验证数据的哈希校验值（确保不同时效标签不同）
- 基于独立验证的检验指标及时效依赖曲线

## 流程节点

1. 确定各时效的目标观测时刻 → 2. 获取对应时刻的真实观测 → 3. 生成验证标签 → 4. 独立性校验

### 步骤1：确定各时效的目标观测时刻

对每个预报时效 lead_time_i，目标观测时刻 = 预报初始化时间 + lead_time_i。

| 预报时效 | 目标时刻偏移 | 示例（初始化 12:00 UTC） |
|----------|-------------|------------------------|
| 10 min | +10 min | 12:10 UTC |
| 20 min | +20 min | 12:20 UTC |
| 30 min | +30 min | 12:30 UTC |
| 45 min | +45 min | 12:45 UTC |
| 60 min | +60 min | 13:00 UTC |
| 90 min | +90 min | 13:30 UTC |
| 120 min | +120 min | 14:00 UTC |

### 步骤2：获取对应时刻的真实观测

**独立数据源**（优先级从高到低）：
1. **地面冰雹报告**：Storm Event Database（美国）、中国气象局灾情直报系统
2. **双偏振雷达衍生产品**：MESH（Maximum Expected Size of Hail）、ZDR 柱、KDP 柱等
3. **卫星观测**：GOES-16/17 GLM 闪电数据、IR 亮温极低值区
4. **MRMS 融合产品**：MESH 产品提供逐 2 分钟的冰雹尺寸估计 [2]

**关键原则**：验证观测必须来自预报模型未使用的数据源，避免信息泄漏。[1]

### 步骤3：生成验证标签

- 对每个时效的观测数据，使用独立的二值化阈值（如 MESH ≥ 1 inch 对应冰雹事件）
- 每个时效的验证标签文件应基于**各自时刻的独立观测**生成
- 文件命名应包含时效标识：verification_hail_label_{lead_time}min.npy
- 每个文件的 SHA-256 哈希值必须不同

### 步骤4：独立性校验

- 计算所有验证标签文件的 SHA-256 哈希值
- **强制要求**：不同时效标签文件的哈希值必须不同
- 交叉验证：不同时效标签之间的相关系数应随时效增大而减小（短时效相关性高、长时效相关性低属正常）
- 标签数量一致性：每个时效的有效验证像元数应相近（差异 < 20%）

## 关键参数

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| 验证观测来源 | 独立于预报模型 | [1] | 不得使用预报模型的输入数据作为验证 |
| MESH 冰雹阈值 | ≥ 1 inch (2.54 cm) | [2] | SPC 定义的显著冰雹标准 |
| 邻域匹配半径 | 3-5 km | [1] | 考虑雷达定位误差 |
| 时间容差 | ±2-5 min | [2] | 考虑雷达体扫时间差 |
| 哈希独立性 | 7个时效 SHA-256 各不同 | - | 基本数据完整性检查 |
| 标签数量一致性 | 时效间差异 < 20% | - | 防止因掩膜导致验证偏差 |

## 边界与分流

- **无独立观测可用**：当所有独立数据源均不可达时，验证部分应标注为"基于合成验证"或"待补充"，不得使用预报模型输入数据的派生标签
- **稀有事件验证**：冰雹为稀有事件（base rate ~0.1-1%），需使用分层抽样或稀有事件检验指标（如威胁分数而非准确率）
- **多雷达覆盖差异**：不同时刻的雷达覆盖率可能不同，需对验证区域做统一掩膜

## 质量检查

- 验证 7 个 verification_hail_label_*.npy 文件的 SHA-256 哈希值各不相同
- 检查各时效标签的有效像元数是否相近
- 确认验证标签的时间戳与对应预报时效的目标时刻匹配

## 回退策略

- 独立观测不可用时：标注验证数据局限性，不删减或合并已有独立标签
- 时效标签哈希相同：回退为重新生成（基于不同时刻的观测）
