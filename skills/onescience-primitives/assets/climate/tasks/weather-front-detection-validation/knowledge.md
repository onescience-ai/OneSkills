# 气象锋面检测独立验证规范

## 适用范围
适用于气象科研任务中需要对锋面检测结果进行独立验证的场景，包括独立验证资料定义、位置距离指标、类别命中率、概率技巧和降级判定规则。

## 输入
- 检测结果数据
- 独立验证资料（未参与训练或参数选择）
- 验证指标要求

## 输出
- 独立验证报告，包含：
  - 位置距离指标计算结果
  - 类别命中率计算结果
  - 概率技巧计算结果
  - 降级判定结果

## 流程节点
1. **独立验证资料准备** → 准备未参与训练或参数选择的验证资料
2. **位置距离指标计算** → 计算Hausdorff距离、Fréchet距离等
3. **类别命中率计算** → 计算precision、recall、F1等指标
4. **概率技巧计算** → 计算Brier Skill Score、ROC AUC等
5. **降级判定** → 根据验证结果进行降级判定

## 关键参数
| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| Hausdorff距离 | 越小越好 | [1] | 位置距离指标 |
| Fréchet距离 | 越小越好 | [1] | 形状相似性指标 |
| Precision | 越高越好 | [2] | 查准率 |
| Recall | 越高越好 | [2] | 查全率 |
| F1 Score | 越高越好 | [2] | 综合指标 |
| Brier Skill Score | >0表示优于气候态 | [1] | 概率技巧指标 |
| ROC AUC | 越高越好 | [1] | 分类性能指标 |

## 边界与分流
- 当独立验证资料缺失时，标记相关交付项为PARTIAL
- 当验证指标低于阈值时，记录并说明原因
- 当缺少验收门限时，只能报告指标，不得声明PASS

## 质量检查
- 验证独立验证资料确实未参与训练或参数选择
- 检查验证指标计算是否正确
- 确认降级判定是否合理

## 回退策略
- 当独立验证资料缺失时，标记相关交付项为PARTIAL并说明原因
- 当验证指标异常时，记录异常情况并评估对任务结果的影响

## 资源召回建议
- 当任务需要对锋面检测结果进行独立验证时召回本卡片
- 配套使用天气锋面检测方法学对比知识卡片
- 配套使用气象产品质控规范卡片
