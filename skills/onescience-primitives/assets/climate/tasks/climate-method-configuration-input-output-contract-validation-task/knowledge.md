## 质量门禁 quality_gate
- 伪缺口与独立验证块未参与重建参数选择
- 同期资料在坐标、单位和质量标志上严格对齐
- 回报或验证年份未参与参数选择
- 容量、时区、采样间隔和缺测规则一致
- 强迫与状态资料的有效时间满足任务边界
- 方法工件、配置和运行环境属于兼容版本
- 时次、变量、单位和坐标满足任务契约
- 最小干运行正常退出且结果不存在NaN或Inf
- 校准、验证和测试时段互斥且无未来信息泄漏
- 正负样本构造保留真实发生率并记录抽样策略
- 目标变量和输出结构与任务定义一致
- 站点、网格、单位和质量标志已统一
- 缺帧、异常回波和多源延迟已显式记录
- 背景场与观测在时空位置和物理量上匹配
- 训练、检测和显著性评估样本相互独立
- 训练与验证时空块互斥并防止目标泄漏
- 训练验证划分阻断同一地点或事件的信息泄漏
- 训练验证按时间或流域隔离并防止未来泄漏
- 辐射定标、几何配准和质量掩膜均有记录
- 风浪流已插值到航行时空网格且保留质量标志
