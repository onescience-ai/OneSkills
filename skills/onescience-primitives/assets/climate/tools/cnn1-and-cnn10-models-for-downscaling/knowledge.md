# 用于降尺度的CNN1和CNN10模型

## 适用范围

面向大尺度气象场到站点/网格点尺度的统计降尺度任务，选择基于卷积神经网络的 CNN1（降水）和 CNN10（温度）架构作为替代方案。该方法以 19×22 经纬度窗口内的多个标准化预测变量为输入通道，经三层卷积提取空间特征后输出降水发生概率与降雨量参数或温度预测值。适用于区域性气候降尺度、极端天气事件分析以及高分辨率气象数据同化等场景，能够同时处理多个空间预测变量并输出与 E-OBS 网格匹配的降尺度结果。

## 输入

- 必需：20 个标准化的大尺度气象预测变量（如温度、气压、湿度、风场分量等），以堆叠通道形式输入，空间维度为 19×22（纬度×经度）。
- 可选：批量校正因子、协变量调整参数（用于处理模型间系统偏差）。
- 格式要求：输入数据需预先标准化至均值为 0、标准差为 1 的分布，以确保不同物理量纲的变量在神经网络训练中具有可比性。

## 输出

- 降水降尺度（CNN1）：每个网格点的降水发生概率 p（Bernoulli 分布参数）和降雨量参数（Gamma 分布的 α 和 β）。
- 温度降尺度（CNN10）：每个网格点的温度预测值。
- 输出空间分辨率：与 E-OBS 陆地网格点匹配，覆盖 3259 个预测点。
- 后续用途：输出结果可直接用于高分辨率气候情景分析、极端事件统计、水文模型驱动或农业影响评估。

## 流程节点

1. **数据准备**：收集 20 个大尺度气象预测变量，进行标准化处理，确保空间窗口为 19×22 经纬度网格。
2. **模型构建**：
   - CNN1（降水）：输入层 → 50 个 3×3 卷积核 → 25 个 3×3 卷积核 → 1 个 3×3 卷积核 → 输出层（3259 个网格点）。
   - CNN10（温度）：输入层 → 50 个 3×3 卷积核 → 25 个 3×3 卷积核 → 10 个 3×3 卷积核 → 输出层（3259 个网格点）。
3. **损失函数设计**：
   - 降水：最大化 Bernoulli-Gamma 分布的对数似然（loglikelihood）。
   - 温度：最小化均方误差（MSE）。
4. **训练与验证**：使用历史观测数据（如 E-OBS）进行训练，采用交叉验证防止过拟合。
5. **预测与后处理**：将训练好的模型应用于未来气候情景数据，生成降尺度后的降水概率/降雨量参数或温度预测值。
6. **质量评估**：计算技能评分（如 CRPS、Brier Skill Score）并与基准模型（如 GLM1、GLM4）比较。

## 边界与分流

- 该方法适用于区域尺度降尺度，但可能无法很好地外推到训练数据中未出现过的极端气候变化条件。
- 作为“黑箱”模型，其结果缺乏物理可解释性，可能导致不受控的外推伪影，此时应考虑物理约束更强的降尺度方法（如动力降尺度）。
- 若需处理更复杂的时空依赖关系，可考虑引入时空卷积或循环神经网络架构。
- 该模型与 GLM1、GLM4、GLMPC 等传统统计降尺度模型属于同族工具，可根据具体任务需求选择。

## 质量检查

- 技能评分：计算连续分级概率评分（CRPS）评估概率预测质量，Brier Skill Score 评估分类准确性。
- 与观测对比：绘制降尺度结果与 E-OBS 观测的散点图、QQ 图，检查系统偏差。
- 空间一致性：检查输出场的空间平滑度，识别可能的伪影或异常值。
- 交叉验证：使用独立验证期数据检验模型泛化能力。

## 回退策略

- 若模型无法外推极端条件，可回退到基于物理约束的降尺度方法（如统计降尺度中的分位数映射或动力降尺度）。
- 若黑箱特性导致结果不可信，可尝试使用可解释性工具（如 SHAP、Grad-CAM）分析特征重要性，或转向可解释性更强的模型（如广义线性模型）。
- 训练数据不足时，可采用迁移学习或数据增强技术。

## 资源召回建议

- 软件环境：downscaleR.keras 包（基于 R 语言），需安装 Keras 和 TensorFlow 后端。
- 数据集：E-OBS 欧洲高分辨率观测数据集（用于训练和验证），CMIP6 气候模式输出（用于未来情景预测）。
- 相关工具：GLM1、GLM4、GLMPC 等传统统计降尺度模型，可用于基准比较。
- 参考框架：VALUE 实验框架，提供标准化的降尺度评估指标和方法比较平台。
