# TropiCycloneNet 热带气旋预测系统与基准数据集

## 适用范围

该方案服务于热带气旋（TC）的短期预报任务，核心目标是同时预测TC的未来路径和强度。典型的应用场景包括：基于历史观测序列的热带气旋轨迹预测、强度预报（如最大持续风速）、以及需要融合多种观测和再分析数据源进行综合预测的气象预报与研究任务。该方案特别适用于需要处理多模态（1D固有属性、3D气象场、环境数据）、多时间步数据输入，并希望输出多个潜在预测趋势以供决策参考的场景。

## 输入

系统需要以下多模态时间序列数据作为输入：

- **Data1d（1D固有属性数据）**：TC的内在属性时间序列，典型包括经度、纬度、最大持续风速、中心气压等。输入序列长度为8个时间步（对应过去42小时历史数据，时间间隔约6小时）。
- **Data3d（3D气象网格数据）**：TC所在区域的气象场数据，如温度、湿度、风场等三维气象场信息。
- **Env-Data（环境数据）**：TC所处的环境场数据，用于表征大尺度环境条件。

输入数据需遵循TCND数据集的格式规范。数据通常需要经过预处理，包括归一化、缺失值处理和序列对齐。

## 输出

系统输出以下内容：

- **路径预测结果**：未来24小时（4个时间步）的TC中心位置（经纬度）预测。
- **强度预测结果**：未来24小时的TC强度（如最大持续风速）预测。
- **多趋势预测**：由于采用多生成器架构，系统能同时输出多个潜在的预测趋势（默认6个），为预报决策提供概率性参考。

## 流程节点

基于模型架构，数据处理与预测遵循以下步骤：

1.  **数据输入与准备**：加载符合TCND格式的多模态历史数据序列（Data1d、Data3d、Env-Data）。
2.  **多模态特征提取**：
    *   使用 **3D-Data Encoder** 对气象网格数据（Data3d）进行特征提取。
    *   使用 **1D-Data Encoder** 对固有属性数据（Data1d）进行特征提取。
    *   使用 **Environment-Time Network** 对环境数据（Env-Data）进行时空特征提取。
3.  **趋势生成与选择**：
    *   通过 **Generator Chooser Network** 基于提取的特征，从K=6个生成器中为当前样本选择最合适的生成器组合。
    *   被选中的生成器生成l=6个采样，代表多个潜在的未来演变趋势。
4.  **真实性评估**：使用 **判别器** 评估生成预测序列与真实序列的差异，以对抗训练的方式优化模型。
5.  **输出预测**：最终输出选定的生成器所产生的未来24小时路径和强度预测结果。

## 边界与分流

- **预测时效**：该方案主要设计用于24小时内的短期预报。当预测时长超过12小时时，路径预测的误差可能会累积，性能可能下降。对于更长期（如48小时以上）的预报，建议结合数值天气预报模式或其他专门针对中长期预报的方案。
- **数据稀缺区域**：在历史TC样本相对较少的海域（如南太平洋），模型的泛化能力可能受限。在这些区域应用时，需谨慎评估预测结果，并考虑使用数据增强或迁移学习等策略。
- **特殊TC事件**：对于发生快速增强或突然转向的TC，其强度预测可能存在更大挑战。此类事件的预报应结合更多物理约束或专家知识进行修正。
- **上游数据依赖**：该方案依赖高质量的多模态输入数据。如果输入数据格式不符或质量不足，需先进行数据清洗、格式转换和质量控制。
- **替代方案**：若需要更长的预报时效，可考虑与全球数值天气预报模式（如ECMWF、GFS）结合；若任务仅需路径或强度单一预报，可使用更简单的模型架构。

## 质量检查

验证预测结果的质量可关注以下方面：

- **路径误差**：计算预测位置与真实位置之间的平均绝对误差（MAE）或平均距离误差（通常以公里或海里为单位）。
- **强度误差**：计算预测强度与真实强度（如最大风速）之间的平均绝对误差或均方根误差。
- **概率校准**：由于模型输出多个预测趋势，可以评估这些预测的集合离散度，以及真实结果是否落在预测趋势的合理范围内。
- **与基准对比**：将预测结果与业务预报中心（如JTWC、JMA）的官方预报，或与其他深度学习基线模型（如LSTM、GRU、SGAN）的预报进行对比，以评估相对性能。

## 回退策略

当模型运行失败或预测质量不达标时，可考虑以下策略：

- **数据问题**：检查输入数据是否完整、格式正确、且时间序列连续。若数据缺失严重，需先进行插补或筛选数据完整的个例。
- **模型性能不足**：在数据稀缺区域或特定TC类型上性能不佳时，可尝试调整训练策略，如使用更长的预训练轮次（调整超参数q）、调整学习率、或在目标海域的数据上进行微调。
- **计算资源不足**：模型训练需要NVIDIA GPU支持。若资源受限，可尝试减小批量大小或模型复杂度。
- **备选方案**：若TCNM模型因故无法使用，可考虑使用其他基于深度学习的TC预报模型（如Pangu-Weather, Fengwu, MMSTN）作为替代进行预测任务。

## 资源召回建议

- **代码与模型**：TCNM预测模型的实现代码可在GitHub和Zenodo上获取。
- **数据集**：TCND基准数据集在GitHub和Zenodo上公开发布，包含近70年、六大主要海域的3630个TC数据。
- **相关工具与数据**：
    *   **数据来源**：可参考IBTrACS（国际最佳轨迹档案）获取TC最佳路径数据，CMA-BST（中国气象局热带气旋最佳路径数据集）等。
    *   **环境再分析数据**：如ERA5再分析数据集，可用于获取大尺度环境场信息。
    *   **其他AI模型**：可参考Pangu-Weather、Fengwu、MMSTN等用于气象预测的深度学习模型作为对比或补充。
    *   **社区资源**：Digital Typhoon等数据库可用于获取更多TC观测资料。
