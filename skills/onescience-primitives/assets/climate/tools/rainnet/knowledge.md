# RainNet 降水临近预报模型系统

## 适用范围

用于基于多普勒雷达反射率或降水产品的短时（通常为 0-2 小时）降水预报模型（nowcast）的构建、训练与评估。典型触发任务包括：需要将连续的雷达观测序列转化为对未来几分钟至一小时内降水场分布与强度的预测；关注模型在不同降雨强度和空间尺度下的预报性能；以及研究卷积神经网络在处理此类时空序列预测问题时的特性（如平滑效应）。

## 输入

- **必需**：
  - 连续时刻的雷达降水合成网格时间序列。典型为 4 个连续时刻（例如，t-15, t-10, t-5, t 分钟），每个网格为空间二维数组（例如，900x900 单元）。
  - 与输入序列对应的未来时刻（例如，t+5 分钟）的观测降水网格（标签）。
- **可选**：
  - 用于空间填充的镜像填充尺寸参数。
  - 用于数据变换的对数转换参数。

## 输出

- **模型预测**：未来指定时刻（例如 t+5 分钟）的降水场预测网格。
- **模型参数**：经过一轮或多次迭代更新后的神经网络权重。

## 流程节点

以下为 RainNet 模型一次迭代训练的核心步骤，构成了一个有向无环图（DAG）。

1.  **数据准备与预处理 (s1)**
    *   **步骤描述**：读取训练样本，对输入雷达网格序列和未来观测网格进行空间填充与值变换。
    *   **上游依赖**：无。
    *   **输入参数**：
        - `input_grid` (必需)：输入网格时间序列，类型为 `numpy.array`，形状 `(4, 900, 900)`。
        - `obs_grid` (必需)：未来时刻的观测网格，类型为 `numpy.array`，形状 `(1, 900, 900)`。
    *   **输出**：填充至 928x928 并经过对数变换的输入张量和观测张量。
    *   **质量门控**：数据格式正确，填充后空间尺寸（928x928）符合 2 的幂次要求，以适配网络中的池化与上采样层。

2.  **模型预测 (s2)**
    *   **步骤描述**：将预处理后的输入张量送入已定义的 RainNet 架构进行前向计算。
    *   **上游依赖**：`s1`。
    *   **输出**：预测的 t+5 分钟降水网格。
    *   **质量门控**：预测张量的空间形状与观测网格一致。

3.  **损失计算 (s3)**
    *   **步骤描述**：计算模型预测结果与实际观测之间的损失值。
    *   **上游依赖**：`s2`。
    *   **输入参数**：
        - `prediction` (必需)：模型预测结果，类型为 `numpy.array`。
        - `observation` (必需)：实际观测，类型为 `numpy.array`。
    *   **输出**：标量损失值。
    *   **质量门控**：损失值为有效浮点数。

4.  **参数更新 (s4)**
    *   **步骤描述**：基于计算出的损失值，使用 Adam 优化器进行反向传播，更新模型权重以最小化损失。
    *   **上游依赖**：`s3`。
    *   **输入参数**：
        - `loss` (必需)：损失值，类型为 `float`。
    *   **输出**：更新后的模型参数。
    *   **质量门控**：优化器成功执行一步参数更新。

## 边界与分流

- **多步预报**：RainNet v1.0 设计为单步预测（如 t+5 分钟）。若需生成更长时效的预报（如 30、60 分钟），需将上一步的预测结果作为输入进行递归应用。需注意，此过程会导致预测平滑效应累积，预报质量随提前时间增加而显著下降。
- **数据类型**：该流程适用于以网格形式呈现的雷达降水数据（如复合反射率或降水深度产品）。若输入为原始雷达极坐标数据或卫星反演降水数据，需额外的数据预处理与坐标转换步骤。
- **计算资源**：模型训练（如参数规模约 3140 万）依赖于 GPU 加速。在缺乏 GPU 的环境下，仅能进行小规模数据测试或模型推理。
- **架构变体**：RainNet 架构灵感源于 U-Net 和 SegNet。在类似任务中，也可考虑使用其他编码器-解码器架构（如 SegNet 变体）或引入时序模块（如 ConvLSTM、ConvGRU）的复合模型。

## 质量检查

对训练好的模型进行预报技能评估时，应综合使用多类指标，避免单一指标误导：

1.  **连续指标**：使用平均绝对误差（MAE）评估预测与观测在连续降水强度上的整体差异。
2.  **类别指标**：使用关键成功指数（CSI）在多个降水强度阈值（例如 0.125, 1, 5, 10, 15 mm/h）上评估模型对“有无降水”及“降水等级”的分类能力。
3.  **空间尺度指标**：使用分数技能评分（FSS）在不同空间邻域尺度（例如 1, 5, 10, 20 km）和强度阈值上，评估模型预报性能对空间尺度的依赖性，这对于理解模型的“可预报尺度”至关重要。
4.  **频谱分析**：使用韦尔奇（Welch）方法计算预测和观测场的功率谱密度（PSD），分析模型在不同空间尺度上保持细节（高频信息）的能力，这是量化模型平滑效应的客观方法。

评估应选择涵盖不同降雨类型（对流性、层云）、强度和持续时间的代表性事件进行，以避免结论的偶然性。

## 回退策略

当训练或评估过程出现异常时，可考虑以下方向：

- **训练不收敛（损失不下降）**：检查学习率设置（默认 1e-4 可能不适），尝试降低学习率；检查损失函数（LogCosh）是否适用，可尝试切换为 MSE 或 MAE；检查输入数据是否已进行对数变换。
- **过拟合（训练损失低，验证损失高）**：增加 Dropout 比例或添加其他正则化项；使用数据增强（如随机旋转、翻转）扩充训练集；提前停止训练（Early Stopping）。
- **预报结果过度平滑**：这是基于 CNN 的降水预报模型的常见特性。可尝试调整网络结构以减少下采样层数，或引入生成对抗网络（GAN）等以提升细节生成能力。需认识到，一定程度的平滑可能是模型在给定信息量下的最优预测。
- **数据问题**：确保输入数据格式、空间范围和时间戳对齐；检查数据是否包含无效值（如无回波区）并进行适当填充。

## 资源召回建议

- **官方实现**：RainNet 的模型架构与训练代码可在 GitHub 上找到（`https://github.com/hydrogo/rainnet`），基于 Python 和 Keras 实现。
- **数据集**：RainNet 的训练与验证使用了德国气象局（DWD）的 RY 产品，这是一个覆盖德国全境、空间分辨率 1km x 1km、时间分辨率 5 分钟的质控雷达复合降水深度数据集。其他地区需使用本地化的雷达复合数据或公开数据集（如 MRMS）。
- **相关模型与方法**：在雷达降水外推领域，可与光流法（如 ROVER、Rainymotion）、持久性预报（Persistence）以及其他深度学习模型（如 ConvLSTM, TrajGRU）的性能进行对比。评估时参考标准化的气象预报验证框架。
