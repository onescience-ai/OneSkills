# ANNI-NH3-v2.1卫星氨反演算法及再分析数据集

## 适用范围

本知识描述一套用于从IASI（Infrared Atmospheric Sounding Interferometer）卫星观测数据中反演大气氨（NH₃）柱浓度的神经网络算法及其衍生再分析数据集。该方法适用于需要快速、大范围获取近地面或整层大气氨浓度数据的各类大气化学、环境监测及气候研究任务。典型应用包括但不限于：区域乃至全球尺度的农业氨排放估算与评估、氨与酸性气体的化学传输过程研究、长期趋势分析，以及为大气化学模式提供关键的初始场或验证数据。

该算法的核心优势在于处理速度快、可提供近乎实时的数据产品，并且通过特定处理流程（使用再分析气象数据）可生成时间序列连贯的数据集，非常适合趋势研究，弥补了卫星过境时间不一致及业务气象输入数据可能存在的间断性问题。

## 输入

进行反演需要以下输入参数，它们构成了神经网络的特征向量：

1.  **核心观测数据**：IASI卫星L1B级辐射数据或L2级预处理数据。
2.  **关键地表与几何参数**：
    *   地表温度（Tₛ）。
    *   地表压力。
    *   卫星天顶角。
    *   地表粗糙度（z₀）。
    *   地表发射率（ε）。
    *   地表反照率（σ）。
3.  **大气状态参数**：温度垂直廓线、水汽垂直廓线。
4.  **质量控制与辅助参数**：
    *   云覆盖率（通常使用IASI L2云产品）。
    *   高效反演指数（HRI），用于表征观测光谱对氨吸收的敏感性。
5.  **再分析数据输入（专用于生成连贯数据集版本）**：当使用再分析版本时，上述部分参数（如温度、水汽廓线、地表气压）可由ECMWF ERA-Interim等再分析数据集提供，并由专用神经网络补充反演地表温度。

**预处理要点**：输入数据通常需要进行预滤波（例如，根据云覆盖率进行初步筛选）和归一化处理，以匹配神经网络的训练格式。总输入参数数量已优化至20个。

## 输出

该算法的直接输出为：

*   **大气氨柱浓度（NH₃ VCD）**：单位为 molecules cm⁻²，代表从地表到大气顶单位面积垂直气柱内氨分子的总数。

基于不同处理流程，可获得以下衍生数据集：

*   **近实时数据产品**：直接使用业务气象输入，适用于监测实时污染事件。
*   **网格化再分析数据集（如v2.1R-I）**：输出为规则网格（如0.25°×0.25°）上的时间序列数据，时间分辨率通常为3小时。该数据集使用一致的再分析气象场（如ERA-Interim）和统一的反演算法，消除了因业务气象输入变化导致的数据间断，时间序列连贯，是研究长期趋势的优选数据。

## 处理流程

该算法的典型应用流程如下，涵盖了数据准备、反演计算与后处理：

1.  **数据获取与准备**：获取IASI Level 1B或Level 2数据，以及对应的ECMWF ERA-Interim再分析数据。准备工具流程以将ERA数据（如总水汽柱、地表气压、2米温度和露点温度）转换为神经网络可接受的输入格式。
2.  **预滤波与数据匹配**：
    *   应用云覆盖率阈值进行初步筛选（例如，剔除云覆盖率大于特定阈值，如10%或25%的观测，具体取决于算法版本设置），以减少云污染。
    *   将卫星观测数据与相应的气象输入数据在时间和空间上进行匹配。
3.  **神经网络反演计算**：
    *   将匹配好的、预处理后的20个输入参数向量输入到预先训练好的神经网络模型中。
    *   算法为陆地和海洋观测分别部署了独立的神经网络模型，以提高各自场景下的反演性能。
    *   神经网络模型基于大规模模拟数据集（例如约45万次模拟）训练，用于建立卫星辐射观测与氨柱浓度之间的复杂非线性映射关系。
4.  **后处理与质量控制**：
    *   对网络输出的原始反演结果进行后处理。
    *   应用质量控制标志，例如剔除反演值为负（[NH₃] < 0）且高效反演指数（HRI）绝对值过大（如|HRI| > 1.5）的不可靠数据点。
5.  **结果输出与存档**：输出单次观测的氨柱浓度值。对于再分析数据集，将结果在目标网格上进行时空插值或统计，生成格式化的网格化数据产品。

## 边界与分流

*   **适用数据源**：本算法专用为IASI红外高光谱数据设计。对于其他卫星传感器（如CrIS、AIRS），需使用针对其光谱特性和通道设计重新训练的模型。
*   **训练数据代表性**：反演性能高度依赖于训练数据集的覆盖范围。算法在训练集所覆盖的热力对比（地表与大气温差）范围、地理区域和季节条件下表现最佳。若实际观测超出训练集典型范围（例如极端热力对比条件），反演不确定性会增大。
*   **与传统方法的分流**：对于无法获取IASI数据或需要更高垂直分辨率的场景，应考虑基于地基FTIR、激光雷达或大气化学传输模型反演等其他方法。对于时间序列趋势分析，优先使用基于一致再分析气象场的网格化数据集（如v2.1R-I），而非混合了不同来源气象输入的近实时业务产品。
*   **上下游衔接**：该算法的输出（氨柱浓度）可直接作为输入，用于排放清单优化、大气化学模式同化或与其他地面/卫星观测进行融合分析。

## 质量检查

为确保反演结果的可靠性，可采取以下质量检查措施：

*   **输出物理合理性检查**：氨柱浓度应为非负值。显著的负值输出通常表明反演失败或数据质量问题。
*   **反演指数监控**：关注高效反演指数（HRI）等质量标志。HRI绝对值过小表明光谱信号弱，反演不确定性高；HRI绝对值过大可能表明算法在非训练区间外推，结果需谨慎对待。
*   **与辅助数据一致性比对**：将反演结果与同区域、同时段的其他可靠氨观测（如地面监测站网络数据）或高精度卫星反演产品进行比较，评估其量级和时空分布的一致性。
*   **内部一致性检验**：在网格化数据集中，检查相邻网格点或连续时间步结果的平滑性，突兀的异常值可能是数据质量问题。

## 回退策略

当算法反演失败或结果不理想时，可考虑以下替代或补救路径：

*   **输入数据问题**：若因ECMWF ERA-Interim数据缺失或质量不佳导致无法运行再分析版本，应回退到使用业务提供的IASI L2气象数据运行近实时版本算法，并在结果说明中注明数据源的不一致性。
*   **算法性能局限**：在训练数据未充分覆盖的极端条件下（如极高或极低热力对比），若反演结果与其它独立观测差异巨大，应降低对该结果的确信度。在分析中可考虑对此类数据设置权重或进行标记。
*   **模型选择替代**：在需要更高精度但可接受更慢处理速度的个别案例研究中，可考虑使用基于最优估计（Optimal Estimation）或更复杂物理模型的氨反演算法作为补充或验证手段。
*   **神经网络性能退化**：对于负责反演地表温度等辅助参数的专用神经网络，在极端条件下性能下降时，可尝试使用替代的地表温度产品（如MODIS LST）进行敏感性测试。

## 资源召回建议

*   **相关算法与数据集**：ANNI-NH3-v1（早期版本）、其他卫星氨反演产品（如CrIS NH3）。
*   **气象再分析数据源**：ECMWF ERA-Interim（历史数据）、ECMWF ERA5（新一代再分析数据，适用于更新的数据集构建）。
*   **核心遥感数据源**：IASI L1B/L2数据产品（由EUMETSAT提供）。
*   **配套工具**：用于处理NetCDF/HDF格式数据、执行空间重网格化及时间序列分析的软件（如Python的xarray, pandas, scikit-learn库；或NCL, CDO等气候数据分析工具）。
*   **相关应用领域参考**：全球氨排放清单（如CEDS）、大气化学传输模型（如GEOS-Chem, WRF-Chem）的氨模拟与验证。
