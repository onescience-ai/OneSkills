# CABAM算法

## 适用范围

适用于从自动激光雷达/测云仪（如Vaisala CL31）获取的原始后向散射信号数据中，自动反演大气边界层混合层高度（Mixing Layer Height, MLH）并同时进行云层分类。该算法尤其适合需要长时间序列、高时间分辨率（如逐小时）边界层高度观测的场景，例如城市空气质量评估、大气污染扩散研究、边界层参数化方案验证以及气象预报模式的评估与同化。典型触发条件包括：拥有连续运行的ALC观测数据流，且需要将原始信号转化为可用于分析的MLH和云信息产品。

## 输入

- **必需输入**：
  - 自动激光雷达/测云仪（如Vaisala CL31）的原始后向散射信号数据。数据通常以固定时间分辨率（如15秒）和垂直高度分辨率（如10米）存储。
  - 数据采集的时间和高度坐标信息。
- **可选输入**：
  - 同步的气象要素观测（如总入射太阳辐射、相对湿度、温度），用于辅助数据质量控制或结果解释，但不是算法运行的必需输入。

## 输出

- **主要输出**：
  - 小时平均的混合层高度（MLH）时间序列数据。该数据可直接用于后续的气象分析、污染过程研究或作为其他模型的输入。
  - 与MLH对应的云层分类信息（例如：晴空、低云、中云、高云等），有助于解释MLH反演的可靠性。
- **数据格式**：通常输出为结构化表格，包含时间戳、MLH值（米）、云类型标识等字段。

## 流程节点

1.  **数据预处理与质量检查**：对原始ALC信号进行初步检查，识别并标记仪器故障、信号饱和或明显异常的数据段。对于因仪器故障导致的缺失数据时段，需要记录缺失标记。
2.  **后向散射信号处理**：对预处理后的信号进行必要的校正，如重叠校正（overlap correction）、背景噪声去除等，以获得清晰的后向散射信号廓线。
3.  **边界层特征识别**：利用CABAM算法的核心逻辑，分析信号廓线中的梯度特征。算法通过识别信号强度随高度变化的拐点或最大梯度位置，来定位潜在的混合层顶。同时，分析信号在低层的连续性特征以区分混合层顶与云底。
4.  **云层检测与分类**：基于信号强度和垂直结构特征，对廓线中检测到的云层进行分类（例如，通过信号强度阈值、信号连续性等判据）。云层的存在及其类型会直接影响MLH反演结果的判定。
5.  **混合层高度（MLH）确定与质量标记**：综合梯度分析和云层信息，确定每个时间点的MLH值。同时，为每个MLH值赋予一个质量标记，反映反演的置信度（例如：高置信度晴空MLH、受云影响的MLH、反演失败等）。
6.  **时间聚合与产品生成**：将逐时间点的反演结果（MLH值、云类型、质量标记）按用户指定的时间窗口（如1小时）进行聚合，生成最终的小时平均MLH数据和云分类产品。

## 边界与分流

- **适用边界**：CABAM算法主要针对单波长、近地面ALC（如Vaisala CL31）设计。对于多波长、具有更高垂直分辨率和信噪比的高级激光雷达系统，可能需要采用更复杂或专用的反演算法。
- **与其它工具的衔接**：
  - 若需要更精细的边界层结构（如湍流特征）或探测更高层的大气，可考虑使用更复杂的激光雷达系统进行补充观测。
  - 无线电探空仪可提供直接的、基于温湿廓线定义的边界层高度，可作为MLH反演结果的校准或验证基准，但其时间分辨率低（通常每日2-4次）。
- **数据缺失处理**：当仪器出现故障导致数据缺失时，算法本身无法填补。此时需要采用其他数据源进行填补，例如：
  - 邻近站点的ALC数据（如果空间代表性允许）。
  - 数值天气预报模式的再分析数据（如边界层高度诊断场）。
  - 其他间接观测指标（如基于太阳辐射和湍流参数的经验公式估算）。

## 质量检查

- **与探空数据对比**：在有探空观测的时段，将CABAM反演的MLH与探空仪定义的边界层高度（如基于位温廓线）进行对比，评估算法的系统偏差和随机误差。
- **时间连续性检查**：检查MLH时间序列是否平滑连续，是否出现不符合物理常识的跳变。
- **晴空与有云条件分类统计**：分别统计晴空和有云条件下的MLH反演成功率（非缺失、非异常值的比例）和典型值范围，评估算法在不同天气条件下的性能。
- **与其它算法对比**：如有条件，可与其他ALC数据处理算法（如梯度法、小波协方差变换法等）的输出结果进行对比，评估一致性。

## 回退策略

- **算法反演失败**：当CABAM算法无法可靠反演MLH时（例如在降水、厚云层覆盖或强逆温等复杂天气下），输出结果应带有明确的质量标记。使用者在进行后续分析时，应根据质量标记对这些低置信度数据进行过滤或赋予较低权重。
- **数据完全缺失**：对于仪器故障等导致的数据缺失时段，必须使用外部数据源进行填补。填补方法的选择取决于缺失时段的长度和后续分析对数据连续性的要求。
- **算法不适用**：如果ALC仪器型号或数据格式与CABAM算法的设计输入不匹配，应首先寻求对算法进行适当调整或选择其他适用于该仪器数据的处理工具。

## 资源召回建议

- **配套工具**：
  - 数据读取与预处理：通常使用Python（如`numpy`, `pandas`, `xarray`）或MATLAB编写脚本读取ALC原始数据。
  - 可视化：使用`matplotlib`, `seaborn`等绘制MLH时间序列、信号廓线图，用于结果检查。
- **参考实现**：算法的具体实现细节可参考其开发者发布的技术文档或开源代码库。
- **替代方案**：
  - 若需要更复杂的边界层诊断，可考虑使用基于后向散射系数梯度的其它算法。
  - 对于非常规气溶胶（如沙尘、烟雾），可能需要对标准ALC信号处理流程进行调整。
