# CiPS 卷云特性反演算法

## 适用范围

适用于从静止气象卫星搭载的成像辐射计热红外观测数据中，对卷云进行自动化检测、不透明性分类以及冰云物理特性的定量反演。典型应用场景包括：基于 MSG-SEVIRI 多通道亮温数据的逐像素卷云识别，以及云顶高度（CTH）、冰光学厚度（IOT）和冰水路径（IWP）的同步反演。该方法适用于地球同步轨道平台的业务化和研究性云遥感产品生成。

触发条件：当任务涉及从被动红外成像仪数据中提取冰云信息，且需要同时获得卷云的检测结果与光学/物理属性时，可采用此类基于人工神经网络的反演策略。

## 输入

- 必需：
  - SEVIRI 热红外通道亮温数据，中心波长分别为 6.2、7.3、8.7、10.8、12.0 和 13.4 µm（共 6 个通道）
  - ECMWF 再分析资料提供的地表温度数据
  - 辅助参数：像素纬度、观测天顶角（viewing zenith angle）、地表类型标志、年内日期（day of year）
- 可选：
  - CALIOP L2 云和气溶胶层产品，用于训练数据构建与独立验证
  - 地表覆盖类型数据（如 MODIS MCD12C1），用于地表类型标志生成

所有输入按逐像素方式组织，亮温数据构成核心输入特征。

## 输出

| 产物名称 | 类型 | 说明 |
|---|---|---|
| 卷云检测标志 (CCF) | 分类标志 | 指示像素是否存在卷云 |
| 不透明性标志 (OPF) | 分类标志 | 区分薄卷云与不透明卷云 |
| 云顶高度 (CTH) | 连续物理量 | 卷云云顶高度（km） |
| 冰光学厚度 (IOT) | 连续物理量 | 冰云光学厚度 |
| 冰水路径 (IWP) | 连续物理量 | 冰水路径（g/m²） |

上述产物为逐像素输出，可直接用于云气候学分析、辐射收支计算或作为其他遥感产品的输入。

## 流程节点

该算法由一组人工神经网络（ANN）级联构成，各网络分别承担不同任务。整体处理流程如下：

1. **数据预处理**：获取 SEVIRI 六通道亮温、ECMWF 地表温度及辅助参数，按逐像素方式组织输入向量。
2. **卷云检测**：使用专门训练的 ANN，输入 18 个变量，输出卷云检测标志（CCF），判断像素是否包含卷云。
3. **不透明性分类**：对检测到卷云的像素，使用另一组 ANN 识别其不透明性类别（OPF），区分薄卷云与光学厚卷云。
4. **物理属性反演**：对已分类的卷云像素，使用反演 ANN（输入 16 个变量），同时或分别输出云顶高度（CTH）、冰光学厚度（IOT）和冰水路径（IWP）。
5. **结果汇总**：将各 ANN 输出整合为统一的逐像素产品。

各 ANN 的输入变量数量不同：卷云检测和不透明性分类网络使用 18 个输入变量；CTH/IOT/IWP 反演网络使用 16 个输入变量。具体变量组合基于物理考虑进行选择。

### 输入变量重要性评估

可通过计算连接输入神经元与第一隐藏层神经元的所有权重的欧氏长度来估计各输入变量的相对重要性。具体计算方式为：

$$W_i^* = \frac{W_i}{W_1 + W_2 + \cdots + W_n} \times 100\%$$

其中 $W_i$ 为第 $i$ 个输入变量对应权重向量的欧氏长度，$n$ 为输入变量总数（检测/分类网络为 18，反演网络为 16）。该指标使各网络所有输入变量的相对重要性之和为 100%。

## 边界与分流

- **适用平台限制**：该算法针对 MSG-SEVIRI 的通道配置设计。应用于其他成像仪（如 VIIRS、ABI）时，需根据实际通道波长和响应函数重新构建输入向量，并以同步主动观测数据重新训练网络。
- **云类型限制**：算法专门针对卷云（冰云）设计。当任务涉及混合相态云、低层水云或气溶胶反演时，应采用其他专用算法。
- **与物理反演方法的关系**：对于需要辐射传输模型显式正向模拟的场景（如基于 Nakajima-King 方法的云反演），本类数据驱动方法可作为快速替代方案或交叉验证工具，但不能完全替代物理反演在辐射传输一致性方面的优势。
- **上下游衔接**：本算法的输出（CTH、IOT、IWP）可直接作为辐射传输模型（如 RRTMG）的输入参数，也可用于云气候学统计或与气候模式输出进行比较。

## 质量检查

- 使用独立的 CALIOP L2 云和气溶胶层产品对反演结果进行验证，比较 CTH、IOT、IWP 的反演值与激光雷达参考值。
- 检查各 ANN 输入变量重要性分布是否合理，异常的变量权重可能指示数据质量问题或网络训练不充分。
- 对生成的逐像素产品进行空间一致性检查，卷云检测标志和物理属性的空间分布应与气象背景场协调。

## 回退策略

- **在永久冰雪或沙漠地表上**：薄卷云的检测能力和 IOT/IWP 反演精度可能降低。若对此类区域的精度要求较高，应考虑结合多源数据（如同时利用主动激光雷达观测）进行联合反演，或使用针对特定地表类型优化的替代算法。
- **当不透明液态水云与卷云在垂直方向上接近或相邻时**：薄卷云的 IOT/IWP 反演误差可能显著增大。此时应降低对反演结果的信任度，或在数据分析中将此类像素标记为高不确定性。
- **在低云顶高度和低光学厚度的组合条件下**：反演误差最大。对于此类极端薄且低的卷云场景，建议仅依赖检测标志（CCF），对定量物理属性反演结果保持谨慎。
- **网络训练失败或输入数据缺失**：若因缺少必要的辅助数据（如地表温度）而无法运行完整流程，应记录受影响的像素范围，并在产品元数据中明确标注数据缺失区域。

## 资源召回建议

- **训练数据构建**：CALIOP L2 气溶胶和云层产品是构建训练集的核心参考数据源，需与 SEVIRI 观测在时间和空间上精确匹配。
- **地表类型数据**：MODIS L3 MCD12C1 地表覆盖类型数据可用于生成地表类型标志输入。
- **替代/对比方案**：基于物理的云反演方法（如 Nakajima-King 方法）可作为独立验证基准；对于云属性的综合分析，可参考 CloudSat 等主动遥感平台的产品。
- **神经网络框架**：具体实现时可选用主流深度学习框架（如 TensorFlow、PyTorch）或传统 ANN 库构建网络架构，关键在于保持输入变量定义和归一化方式与训练时一致。
