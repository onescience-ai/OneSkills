# CiPS 卷云属性反演算法与工作流

## 适用范围

用于从静止气象卫星 SEVIRI 热红外通道观测数据中反演卷云（cirrus cloud）的完整属性集，包括卷云检测、不透明度分类、云顶高度（CTH）、冰光学厚度（IOT）和冰水路径（IWP）。该方法面向需要高时间分辨率卷云参数的场景，典型应用包括辐射传输校正、卷云辐射效应估算、气候模型验证、航空气象中的高空云检测与预警。核心思路是利用多个人工神经网络分别处理不同子任务，每个网络可根据任务特性独立定制输入变量、训练数据与网络结构。该方法继承自 COCS（Cirrus Observations using Cloud properties from SEVIRI）算法，通过任务分离提升了各属性反演的灵活性与精度。

## 输入

### 必需输入

- **SEVIRI 热通道亮度温度**：MSG-2/SEVIRI 传感器的热红外通道数据。需排除 9.7 µm 臭氧吸收通道及有显著太阳短波贡献的通道，避免大气吸收和太阳辐射干扰亮温信号。
- **区域特征**：以每个像素为中心的 19×19 像素窗口内计算的区域平均亮度温度和最大亮度温度。这类空间统计特征用于捕捉卷云在邻域内的纹理与温度异质性信息。
- **ECMWF 地表皮肤温度**：来自 ECMWF ERA-Interim 再分析数据集的地表温度产品，作为云-地表温度差计算的基准。
- **纬度**：像元地理纬度，用于编码季节性和纬度依赖的大气廓线特征。
- **卫星天顶角**：SEVIRI 观测几何参数，影响亮温的大气路径长度校正。
- **地表类型标志**：水体、冰雪覆盖等二值标志，用于区分地表发射率差异对热红外信号的影响。
- **年积日时间变量**：将一年中的日序号通过正弦/余弦变换编码为周期性变量，捕获年周期信号。

### 可选/辅助输入

- ANN 权重文件（预训练模型参数）。
- CALIOP V3 L2 5km 云和气溶胶层产品（训练阶段作为参考真值，运行阶段可选用于在线验证）。

## 输出

| 输出变量 | 符号 | 描述 | 值域 |
|---------|------|------|------|
| 卷云检测标志 | CCF | 卷云概率（0 = 无云，1 = 卷云） | [0, 1] |
| 不透明度分类标志 | OPF | 不透明度概率（0 = 透明，1 = 不透明） | [0, 1] |
| 云顶高度 | CTH | 卷云云顶海拔高度 | km |
| 冰光学厚度 | IOT | 卷云的冰晶光学厚度 | 无量纲 |
| 冰水路径 | IWP | 卷云柱内冰水总量 | g/m² |

所有输出保持与输入 SEVIRI 视场一致的空间覆盖。CCF 与 OPF 为概率值，需根据下游应用需求设定阈值转换为二值决策。

## 流程节点

### s1 — 数据预处理与特征提取

- **依赖**：无上游步骤。
- **输入**：SEVIRI 亮温数据、ECMWF 地表温度数据、辅助数据集（纬度、地表类型、年积日等）。
- **操作**：
  1. 读取并校验所有输入数据的空间/时间对齐。
  2. 排除 9.7 µm 臭氧通道和太阳贡献显著的通道。
  3. 对每个像元计算 19×19 像素窗口内的区域平均亮温和最大亮温。
  4. 对年积日执行正弦/余弦周期编码。
  5. 将所有特征拼接为标准化后的多变量输入张量。
- **输出**：标准化后的多变量输入张量。
- **质量门**：输入数据完整；区域特征（19×19 像素窗）计算正确；无缺失/异常值。

### s2 — 卷云检测（CCF ANN）

- **依赖**：s1。
- **输入**：输入张量（来自 s1）；卷云检测阈值 `ccf_threshold`（默认 0.62，范围 [0, 1]）。
- **操作**：对所有 SEVIRI 像素运行 CCF 分类网络。网络为 3 层隐藏层、每层 16 个神经元的结构，使用 sigmoid 激活函数，输出卷云概率。
- **输出**：卷云掩膜和概率图（CCF）。
- **质量门**：检测概率（POD）和虚警率（FAR）在可接受范围内。典型性能：IOT ≥ 0.1 时检出率约 71%，IOT ≥ 1.0 时检出率约 95%；无云像元正确分类率约 96%。

### s3 — 不透明度分类（OPF ANN）

- **依赖**：s2。
- **输入**：卷云掩膜（来自 s2）；不透明度分类阈值 `opf_threshold`（默认 0.86，范围 [0, 1]）。
- **操作**：仅对 s2 检测为卷云的像素运行 OPF 分类网络。网络为 1 层隐藏层、16 个神经元的结构，使用 sigmoid 激活函数。该步骤专门识别 CALIOP 激光在厚卷云中完全衰减的情况——此时 CALIOP 无法提供可靠的 IOT/IWP 反演，CiPS 对这些像素的 IOT/IWP 结果不应被信任。
- **输出**：不透明度标志（OPF）。
- **质量门**：透明/不透明分类的 POD 和 FAR 在可接受范围内。

### s4 — 云顶高度反演（CTH ANN）

- **依赖**：s2。
- **输入**：卷云掩膜（来自 s2）。
- **操作**：仅对卷云像素运行 CTH 回归网络。网络为 2 层隐藏层、每层 16 个神经元的结构，使用 tanh 激活函数，输出连续的云顶高度值。
- **输出**：云顶高度（CTH，单位 km）。
- **质量门**：反演 CTH 与 CALIOP 参考数据的 MAPE 满足精度要求（例如云顶高度 > 8 km 时 MAPE ≤ 10%）。

### s5 — 光学厚度与冰水路径反演（IOT/IWP ANN）

- **依赖**：s2。
- **输入**：卷云掩膜（来自 s2）。
- **操作**：仅对卷云像素运行 IOT/IWP 回归网络。网络为 2 层隐藏层、每层 16 个神经元的结构，使用 tanh 激活函数，同时输出 IOT 和 IWP 两个回归量。
- **输出**：冰光学厚度（IOT）和冰水路径（IWP）。
- **质量门**：IOT 在 0.35–1.8 范围内时 MAPE ≤ 50%（校准数值来自 CALIOP 训练验证体系，其他体系需以自身证据重新锚定）。

### s6 — 产品整合

- **依赖**：s2, s3, s4, s5。
- **输入**：CCF 结果、OPF 结果、CTH 结果、IOT/IWP 结果。
- **操作**：将所有 ANN 输出按空间网格对齐并整合为单一数据集。对未检测为卷云的像素，CTH/IOT/IWP 填充为缺失值。
- **输出**：包含 CCF、OPF、CTH、IOT、IWP 的完整卷云属性产品。
- **质量门**：所有输出变量完整；空间覆盖匹配输入 SEVIRI 视场。

## 边界与分流

### 适用边界

- **传感器限制**：该方法针对 MSG-2/SEVIRI 传感器设计，其热通道配置、空间分辨率（3 km 圆盘视场）和时间采样率决定了算法的输入特征空间。应用于其他传感器（如 VIIRS、MODIS、AGRI）时，需重新设计输入特征并重新训练 ANN。
- **卷云厚度范围**：
  - 对极薄卷云（IOT < 0.03）检测率较低，可能漏检。
  - 对极厚卷云（IOT > 2.0）会低估光学厚度和冰水路径，因为训练参考（CALIOP）在此范围存在饱和截断。
  - 对低云顶高度（< 6 km）的云反演误差可能增大。
- **训练参考限制**：算法训练依赖 CALIOP V3 L2 产品，反演结果继承 CALIOP 数据的任何系统偏差或质量缺陷。当 CALIOP 产品版本升级或发现新偏差时，需重新评估算法性能。

### 与其他方法的分流

- **前代算法 COCS**：COCS 使用单一 ANN 同时反演 IOT 和 CTH，结构更简单但定制性有限。当需要独立优化各属性的反演精度时，应选择 CiPS 的多任务分离方案。
- **主动遥感验证**：当需要高精度卷云光学参数的绝对真值时，应直接使用 CALIOP/CALIPSO 主动激光雷达数据，而非 CiPS 被动反演产品。
- **不透明卷云处理**：OPF 标记为不透明的像素，其 IOT/IWP 反演结果可信度低，下游应用应仅使用 CTH 或将 IOT/IWP 视为缺失值。

## 质量检查

- **逐像元检查**：CCF 和 OPF 概率值应在 [0, 1] 区间；CTH 应在合理高度范围（如 5–18 km）；IOT 和 IWP 应为非负值。
- **空间一致性**：卷云掩膜应与 SEVIRI 可见光/红外图像目视一致，无明显空间伪影或破碎。
- **与参考数据比对**：将反演产品与 CALIOP V3 L2 产品在时空匹配像元上比较，评估 CTH 的 MAPE（> 8 km 时目标 ≤ 10%）和 IOT 的 MAPE（0.35–1.8 范围时目标 ≤ 50%）。
- **统计汇总**：按不透明度分类分别统计 POD、FAR、偏差和 RMSE，确认各子产品的性能满足应用需求。
- **阈值敏感性分析**：调整 `ccf_threshold` 和 `opf_threshold`，绘制 POD-FAR 工作特性曲线，根据具体应用的容许误报率选择最优工作点。

## 回退策略

- **输入数据不完整或格式错误**：检查数据文件完整性与格式规范，修复后重新运行预处理步骤 s1。若 ECMWF 数据缺失，可尝试使用其他再分析数据源（如 ERA5），但需验证地表温度的一致性。
- **ANN 权重文件缺失或损坏**：重新下载或训练权重文件。若需重新训练，准备 CALIOP V3 L2 参考数据与 SEVIRI 历史数据，使用 FANN 库执行训练流程。
- **运行环境缺少 FANN 库**：安装 FANN（Fast Artificial Neural Network）库。该库是 CiPS 算法执行 ANN 推理的必要依赖。
- **阈值选择不当导致性能下降**：若 POD 过低（漏检严重），降低 `ccf_threshold`；若 FAR 过高（误报严重），提高 `ccf_threshold`。OPF 阈值同理调整。具体阈值需根据目标应用对检测率与误报率的权衡需求确定。
- **极薄卷云检测失败**：这是算法已知局限（IOT < 0.03 时检测率低）。若应用场景对薄卷云敏感，应考虑补充主动激光雷达观测或其他高灵敏度被动探测方法。
- **厚卷云 IOT/IWP 低估**：当 OPF 标记像素为不透明时，应将 IOT/IWP 视为不可靠，或使用专门针对厚云的微波/红外联合反演方案。

## 资源召回建议

- **ANN 训练与推理库**：FANN（Fast Artificial Neural Network Library）——CiPS 算法的底层 ANN 执行引擎。
- **训练参考数据**：CALIPSO/CALIOP V3 L2 5km 云和气溶胶层产品——提供卷云垂直结构与光学参数的主动激光雷达参考。
- **输入数据源**：EUMETSAT MSG 数据中心（SEVIRI L1.5/L2 产品）；ECMWF 数据存档（ERA-Interim 或 ERA5 地表温度）。
- **前代算法参考**：COCS（Cirrus Observations using Cloud properties from SEVIRI）——了解 CiPS 设计演进与改进点。
- **同类方法比较**：其他卫星卷云反演算法（如 MODIS cirrus flag、CALIOP 直接反演产品），用于交叉验证与互补分析。
