# SeaDAS OLI数据处理链

## 适用范围
本知识适用于利用 Landsat-8 陆地成像仪（OLI）数据进行水体（海洋、湖泊等）遥感反射率反演的场景。典型触发条件包括：需要将 Landsat-8 Level-1T 级数据产品转换为可用于水色参数（如叶绿素-a 浓度、悬浮物浓度）定量反演的遥感反射率（Rrs）产品，或用于特定算法（如基于机器学习的方法）训练/验证所需的瑞利校正反射率（ρs）中间产品。该处理链的核心是实施大气校正以去除大气影响，是水色遥感数据处理链中的关键环节。

## 输入
- **必需输入**：Landsat-8 Level-1T（L1T）级别的场景数据包。这是经过几何精校正和辐射定标的基础数据产品。
- **软件环境**：需要安装并配置好 NASA 的 SeaDAS（SeaWiFS Data Analysis System）软件及其处理模块。
- **关键参数**：处理时需要指定水体掩膜、大气校正模型参数等。其中，数据匹配与处理遵循 Bailey and Werdell (2006) 提出的严格时空过滤标准，以确保大气校正结果与验证数据的一致性。

## 输出
1.  **大气校正后产品**：水体遥感反射率（Rrs）。这是最终产品，可直接用于水色参数的生物光学反演。
2.  **中间产品**：瑞利校正反射率（ρs）。这是去除了瑞利散射（分子散射）影响但尚未去除气溶胶散射影响的反射率数据，可用于特定反演算法或作为质量检查参考。

## 流程节点
使用 SeaDAS 处理链对 Landsat-8 OLI 数据进行处理，其逻辑流程如下：

1.  **数据准备与导入**：将 Landsat-8 Level-1T 场景数据导入 SeaDAS 软件。确保数据头文件信息完整，能被软件正确识别。
2.  **大气校正参数设置**：在 SeaDAS 处理面板中，选择适用于 Landsat-8 OLI 的大气校正算法（如基于查找表的方法）。根据研究区域特点（如气溶胶类型）和数据情况，设置相关参数，例如气溶胶模型选择、波段匹配关系等。
3.  **执行处理链**：启动处理流程。SeaDAS 将自动执行一系列步骤，包括辐射定标、几何校正（L1T 数据已包含）、大气校正（计算并去除气溶胶和分子散射影响）。其核心是继承自海洋水色传感器（如 SeaWiFS）的遗产算法。
4.  **产品生成与导出**：处理完成后，导出生成的遥感反射率（Rrs）或瑞利校正反射率（ρs）产品。通常以 GeoTIFF 或 NetCDF 等格式输出，包含各波段的反射率值及元数据。

## 边界与分流
- **适用边界**：该处理链是为海洋等相对清洁的开阔水体设计的遗产算法。在高营养盐、高浑浊度的沿岸或内陆水体中，由于其固有的大气校正假设可能不成立，处理可能失败，无法返回有效的 Rrs，或引入显著的光谱形状与幅度误差。
- **替代方案分流**：对于复杂水体（二类水体），应考虑使用其他专为近岸或内陆水体设计的大气校正算法或工具，例如 ACOLITE、POLYMER 或 C2X 等。USGS 也提供官方的水体反射率产品，可作为另一种选择。
- **上下游衔接**：输出的 Rrs 产品是后续水色参数反演（如叶绿素-a 浓度反演）的标准输入。ρs 产品则常用于训练某些反演模型。

## 质量检查
- **可视化检查**：对生成的 Rrs 影像进行可视化，检查是否存在明显的条带、坏线、异常高值或低值区域，以及水陆边界是否清晰。
- **光谱形状检查**：提取清洁水体区域（如深海区）的典型像元光谱，检查 Rrs 的光谱曲线形状是否合理（例如在蓝绿波段有峰值，随波长增加而衰减）。
- **与已知数据对比**：若存在同期现场实测数据或更高精度的大气校正产品（如 MODIS-Aqua 标准产品），可进行定量对比，评估 Rrs 的绝对值和光谱形状的一致性。注意，对比需考虑传感器间时空匹配差异。
- **辅助信息验证**：结合气溶胶光学厚度（AOD）反演结果、云掩膜等辅助产品，检查大气校正过程中使用的气溶胶模型是否合理。当前版本的 SeaDAS 处理链可能提供的自动化质量标志有限，需要使用者结合其他方法进行判断。

## 回退策略
- **处理失败（无有效Rrs输出）**：若在复杂水体区域处理失败，首先检查输入数据质量（如云覆盖、太阳耀斑）。若数据可用，应立即转用上述“边界与分流”中提到的其他大气校正工具（如 ACOLITE、POLYMER）进行处理。
- **结果异常（光谱/幅度错误）**：若生成的 Rrs 光谱形状或幅度明显异常，可能是由于大气校正参数设置不当（如错误的气溶胶模型）或算法不适用于当前水体。应尝试调整大气校正参数重新处理，或改用更适应复杂水体的算法。例如，对于高浑浊度水体，可考虑使用基于短波红外波段（SWIR）的气溶胶估计方法（如果所选替代工具支持）。
- **软件环境问题**：确保 SeaDAS 版本与 Landsat-8 数据兼容。如遇兼容性问题，可查阅 SeaDAS 官方文档或社区获取支持。

## 资源召回建议
- **软件工具**：SeaDAS（NASA 官方网站下载）、ACOLITE（开源工具，擅长近岸水体处理）、POLYMER（适用于高太阳耀斑和复杂水体）。
- **数据与文档**：USGS Landsat 数据官网（获取Level-1T数据）、NASA OceanColor Web（获取算法文档与验证数据）、SeaDAS 用户手册与教程。
- **相关算法与产品**：可作为对比或替代的大气校正产品包括 USGS 的官方水体反射率产品，以及其他经过验证的 AC 算法（如 C2X）。在建立反演模型时，可参考 Bailey and Werdell (2006) 中描述的严格匹配标准来筛选高质量的训练与验证数据。
