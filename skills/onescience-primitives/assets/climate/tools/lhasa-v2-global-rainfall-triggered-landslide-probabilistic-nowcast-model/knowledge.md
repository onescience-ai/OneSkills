# LHASA v2 全球降雨触发型滑坡概率预报模型

## 适用范围

用于全球尺度降雨触发型滑坡的近实时概率预报。当需要在数小时至数天内获取全球陆地表面的滑坡灾害风险空间分布（高/中/低等级及概率值）时，该系统可提供覆盖全球的逐日风险视图。典型应用场景包括灾害应急规划、人道主义响应协调、全球滑坡风险监测以及为下游决策系统提供概率化预警输入。该方法假设滑坡主要由降雨触发，依赖卫星降水、土壤湿度等解释变量的实时可用性。

## 输入

运行该预报系统需要以下多源数据图层，以全球网格格式提供：

| 数据层 | 来源产品 | 说明 |
|--------|----------|------|
| 每日降雨 | IMERG Early Product | 当日降水强度，为模型最重要变量 |
| 前期降雨 | IMERG | 此前累积降雨，反映土壤水分累积效应 |
| 土壤湿度 | SMAP L4 | 地表及根区土壤含水量 |
| 雪质量 | SMAP L4 | 地表积雪质量 |
| 地形坡度 | Viewfinder Panoramas DEM | 地表坡度角 |
| 断层距离 | GEM Global Active Faults | 距最近活动断层的距离 |
| 岩性强度 | GLiM | 岩石/地表物质强度等级 |

所有图层需重采样至统一空间网格。训练阶段还需要全球滑坡目录（GLC）和 Landslide Reporter Catalog（LRC）作为标注标签。SMAP L4 产品自 2015 年春季起可用，IMERG 产品自 2000 年 6 月起可用，模型的卫星数据驱动预报可追溯至 2015 年。

## 输出

系统每日产出两张全球栅格图：

1. **滑坡概率图**：逐像元输出 0–1 的滑坡发生概率值，为连续型概率预报。
2. **离散化风险等级图**：将概率值映射为三个灾害等级——高、中、低，便于快速判读和决策。

最近一次预报可通过 REST API 获取，也可在 NASA 滑坡查看器中浏览。概率阈值用于将连续概率转换为离散等级，具体阈值选择可依据所需假阳性率调整。

## 模型配置

该系统基于 XGBoost 梯度提升框架构建，核心配置如下：

- **目标函数**：binary:logistic（二分类逻辑回归）
- **树构建方法**：exact
- **集成规模**：训练 1000 棵树，但因验证集性能在 300 轮后下降，最终保留前 300 轮
- **树最大深度**：2（浅树结构，用于支撑特定的交互约束排列）
- **学习率 η**：0.05
- **最大 delta step**：1
- **子采样率**：0.5

**交互约束**：所有解释变量必须与降雨变量交互，其他变量间的交互被禁用。这一设计确保降雨作为主要触发因素在模型决策中居于核心地位。

**单调约束**：降雨、土壤湿度、雪质量、坡度等变量对滑坡概率的边际效应被约束为单调正相关；断层距离和岩性强度被约束为负相关（即距离断层越近、岩石越弱，风险越高）。这些约束保证模型输出与已知的地学物理一致性吻合。

数据预处理和模型训练在配备 10 个 CPU、120 GB 内存的 Linux 虚拟机上完成，生成一天的全球预报耗时约 8 分钟。

## 流程节点

1. **数据获取与预处理**：获取当日及前期 IMERG、SMAP L4、DEM 坡度、断层距离和岩性强度数据，统一空间网格与时间戳。
2. **特征构建**：计算前期降雨累积量，将所有解释变量组装为逐像元的特征向量。
3. **模型推理**：将特征向量输入训练好的 XGBoost 模型（300 轮、深度 2），获得逐像元滑坡概率。
4. **等级划分**：根据概率阈值将连续概率离散化为高/中/低三个灾害等级。
5. **产品发布**：将概率图和等级图通过 REST API 发布，并更新在线可视化查看器。

## 边界与分流

- **卫星降水低估问题**：该系统依赖 IMERG 降水产品，对强对流系统触发的短时强降雨事件可能存在低估，导致漏报。当需要捕捉此类极端对流事件时，应考虑融合地面雷达或高分辨率区域降水产品作为补充。
- **人为改造地形局限**：道路开挖、矿区等人为改造地形可能在较少降雨下即触发滑坡，当前模型主要基于自然地学变量，对此类区域预测能力有限。在工程边坡或矿区场景中，应结合场地特定的稳定性分析方法。
- **数据延迟约束**：SMAP L4 数据存在约 2.5–3 天的延迟，因此模型只能将其作为前期条件变量而非当日触发因子。在数据中断期间，系统预报可能延迟或无法发布。
- **训练数据偏差**：滑坡清单存在语言/经济偏差和空间精度不足，模型对训练数据覆盖薄弱区域的预测置信度较低。
- **非降雨触发滑坡**：该系统专门针对降雨触发型滑坡，对地震、火山或人为活动触发的滑坡不适用。此类场景需使用地震滑坡模型或工程分析方法。

## 回退策略

- **SMAP L4 数据中断**：当 SMAP L4 产品不可用时，可使用历史同期土壤湿度和雪质量均值替代，或暂时仅依赖降雨和静态地学变量运行模型（预测精度可能降低）。
- **IMERG 数据异常**：若 IMERG Early Product 质量不合格，应切换至 IMERG Final 产品（延迟约 3.5 个月但精度更高），或使用其他全球降水产品（如 GPM 近实时产品）。
- **模型推理失败**：若输入图层不完整或分辨率不匹配导致模型无法运行，应检查数据完整性并确保所有图层投影和分辨率一致后重新执行。
- **极端事件漏报**：对于模型可能遗漏的极端滑坡事件，可在事后通过灾害报告目录进行验证，并持续监控模型在极端事件上的表现以指导后续迭代。

## 质量检查

- 模型在独立验证期（2019–2020 年）的表现显著优于前代版本，对所有评估的滑坡目录均表现优异。
- 变量重要性分析确认降雨为最核心预测变量（按增益、覆盖度和频率三项指标综合判断）。
- 概率校准可通过在验证集上绘制可靠性曲线和计算 ROC-AUC、PR-AUC 等指标进行评估。
- 建议定期将预报结果与实时滑坡报告目录比对，监控模型在不同区域和季节的表现稳定性。

## 资源召回建议

- **XGBoost 官方文档**：用于理解模型参数含义和调优策略（https://xgboost.readthedocs.io）。
- **IMERG 数据获取**：NASA GPM 数据门户（https://gpm.nasa.gov）。
- **SMAP L4 产品**：NASA NSIDC 或 JPL DAAC（https://nsidc.org/data/spl4sma）。
- **全球滑坡清单编制方法**：可参考全球网格化滑坡目录的编制流程与偏差分析文献，用于理解训练数据的局限性。
- **在线查看器与 API**：https://landslides.nasa.gov/viewer/ 提供交互式浏览，REST API 支持编程访问最新预报数据。
- **开源代码**：https://github.com/nasa/LHASA 提供系统实现代码，可在此基础上进行本地化部署或二次开发。
