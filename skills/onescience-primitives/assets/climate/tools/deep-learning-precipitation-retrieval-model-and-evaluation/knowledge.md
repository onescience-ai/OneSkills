# 基于深度学习的降水检索模型与评估方法

## 适用范围
用于从地基微雨雷达（MRR）和大气再分析（如ERA5）数据中反演地面短时降水累积（如20分钟平均值）。典型场景包括：利用垂直廓线信息提升雷达定量估测降水（QPE）精度、研究传统雷达反演算法的改进、评估机器学习方法在气象反演中的表现、处理需要融合主动遥感与再分析场输入的反演任务。当任务需要超越简单功率律（Ze-R关系）或浅层机器学习模型（如随机森林、多元线性回归）的表达能力，并且可用训练数据充足时，可考虑采用此类深度学习方案。

## 输入
模型接收一个拼接后的115维大气协变量向量，典型构成包括：

- **雷达数据（约29维）**：MRR垂直廓线信息，例如不同高度层的反射率因子、多普勒速度、谱宽。
- **再分析数据（约12维+）**：ERA5等再分析资料提供的温度、垂直风速等垂直廓线。
- **地表观测数据（数维）**：如地表温度、10米风速等边界层信息。

**关键要求**：所有输入数据必须在时空上与目标反演事件对齐，并按模型预处理管道归一化或标准化。具体输入通道的数量与物理含义需与训练模型时的设定严格一致。

## 输出
- **核心输出**：单个数值，表示在给定时间窗口内（例如20分钟）的地面平均降水累积量（单位通常为mm或mm/h）。
- **后续用途**：可直接用于降水过程分析、水文模型驱动、气候统计或作为其他算法的校准输入。

## 流程节点
1.  **数据加载与预处理**：加载包含115维特征的输入协变量向量。确保数据形状和量纲符合模型输入要求。
2.  **垂直特征提取**：输入向量首先通过两个一维（1D）卷积层。这些层沿垂直维度（或向量维度）滑动，自动提取大气廓线中的关键特征，有效减少后续全连接层的参数数量。
3.  **正则化与降维**：应用最大池化层进一步压缩特征，随后通过丢弃层（随机失活，如`dropout rate = 0.1`）防止过拟合。
4.  **回归预测**：将提取的特征扁平化，输入由多个全连接层组成的多层感知器（MLP）。最终输出层为单个神经元，使用线性激活函数回归出降水累积估计值。
5.  **模型训练与评估**：在留一站点交叉验证框架下，使用均方误差（MSE）作为损失函数，通过Adam优化器（如`learning rate = 1e-07`，`batch size = 128`）对模型进行最多`512`个周期的训练。评估采用非打乱的90/10数据划分。
6.  **基准比较**：将深度学习模型的预测性能（如MSE）与传统Ze-S/R功率律关系和随机森林等基准模型进行系统比较。

## 边界与分流
- **适用条件**：当拥有足够数量的、与目标区域气候特征相似的“雷达-雨量计”共位观测数据集用于训练，且计算资源（如GPU）可支持深度学习模型的训练与推理时，本工具是提升反演精度的有力选项。
- **分流至传统方法**：若训练数据稀缺、任务区域气候特征与训练集差异极大、或对模型可解释性要求极高，建议优先使用传统的Ze-R关系或经充分验证的参数化方案。这些方法虽精度可能较低，但物理意义明确，泛化性更易评估。
- **分流至浅层机器学习**：若数据量中等，或计算资源有限，可考虑使用随机森林（RF）、梯度提升树或多元线性回归（MLR）等模型。它们在数据量较少时可能表现更稳定，且训练成本远低于深度神经网络。

## 质量检查
- **性能指标**：使用均方误差（MSE）、均方根误差（RMSE）、相关系数（R²）等指标评估模型在独立测试集上的表现。应与基准方法（Ze-S/R, RF）进行量化对比。
- **交叉验证**：必须采用严格的站点外推验证（如留一站点交叉验证），而非简单的随机划分，以真实评估模型的区域泛化能力。
- **误差分析**：检查预测误差在不同降水强度（小雨、暴雨）、不同相态（雨、雪、混合相）以及不同气象条件（如高风速）下的分布，识别系统性偏差。
- **特征重要性分析**：可使用SHAP（SHapley Additive exPlanations）等方法解释模型决策，理解哪些大气协变量对预测贡献最大，增强结果可信度。

## 回退策略
- **泛化性能不足**：若模型在全新站点或气候区表现显著下降（例如MSE大幅增加），应收集目标区域的样本数据进行微调（fine-tuning），或重新训练一个包含该区域数据的更通用的模型。若数据不可得，则需退回到物理或统计反演方案。
- **极端事件处理失真**：对于高风速导致雨量计截留误差、或混合相降水等复杂情况，若模型误差明显增大，建议：1）在预处理或后处理阶段加入对这些条件的标记；2）考虑为这些子样本建立专门的校正模型或采用集成方法。
- **计算资源限制**：若无GPU/TPU支持，训练过程可能极其缓慢。回退方案是使用参数量更小的轻量级神经网络架构，或直接采用随机森林等传统机器学习模型。
- **模型不可解释**：若应用领域要求强解释性，深度学习模型的“黑箱”特性可能构成障碍。此时应结合SHAP等可解释AI工具进行事后分析，或转向可解释性更强的模型（如线性模型、决策树）。

## 资源召回建议
- **官方代码库**：该工具的实现代码可于GitHub（https://github.com/frasertheking/DeepPrecip）获取，提供了模型构建、训练和评估的完整流程。
- **配套数据**：模型训练依赖于MRR与高精度雨量计（如Pluvio2）的长期共位观测数据集，以及对应的ERA5再分析数据。获取和准备此类配对数据是复现和应用该方法的前提。
- **相关工具**：TensorFlow/Keras（构建深度学习模型）、scikit-learn（数据处理、传统模型基准）、SHAP（模型解释）。
- **替代模型**：可参考同一代码库或相关文献中实现的随机森林（RF）、多元线性回归（MLR）基准模型，作为对比或轻量级替代方案。
