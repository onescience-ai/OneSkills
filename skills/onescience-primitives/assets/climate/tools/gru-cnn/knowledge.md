# GRU_CNN热带气旋路径预测模型

## 适用范围

一种结合了门控循环单元（GRU）和卷积神经网络（CNN）的深度学习模型，用于融合处理历史轨迹序列数据和三维气象环境场数据，以预测未来6-72小时的热带气旋路径。

当任务目标与该知识所述场景一致时，可复用本条目。

## 输入

- 经过随机森林筛选的11维历史轨迹特征序列（过去24小时）
- 网格化的三维气象环境场数据（风场， 海温， 位势高度）

## 输出

- 未来6-72小时每个预测时刻的经度和纬度变化值

## 前提条件

- Keras深度学习框架
- 处理好的轨迹特征数据和网格化环境场数据

## 边界与分流

- 相关资产/可替代方案：随机森林特征选择方法（用于输入轨迹特征的选择）
- 相关资产/可替代方案：气象环境数据网格化处理流程（用于生成环境场输入）
- 相关资产/可替代方案：ERA5数据集
- 相关资产/可替代方案：IBTrACS数据集

## 回退策略

- 对于异常轨迹（如急转弯、迂回）预测误差较大。
- 当预报时效超过24小时，模型精度会下降。
- 训练数据若未充分覆盖特定类型TC（如高纬度转向型），模型泛化能力可能受限。
