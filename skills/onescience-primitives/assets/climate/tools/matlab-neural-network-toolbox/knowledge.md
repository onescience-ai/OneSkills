# MATLAB神经网络工具箱

## 适用范围

本知识适用于在MATLAB环境中利用Neural Network Toolbox构建、训练和部署神经网络模型，以解决回归预测、时间序列预测等任务。典型场景包括但不限于气象预报、环境数据建模、工程系统性能预测等。该工具箱支持创建反向传播网络（feedforward network）、长短时记忆网络（LSTM）、卷积神经网络（CNN）等多种网络结构，并提供自动化脚本生成与模型导出功能，便于将训练好的模型集成到外部应用或部署系统中。

## 输入

构建模型所需的基本输入包括：
- **特征向量**：作为网络输入层的数据，通常为预处理后的特征矩阵，每列对应一个样本，每行对应一个输入变量。
- **目标值**：与特征向量对应的实测数据或标签，用于监督训练。

数据通常需要在训练前进行归一化或标准化处理，以提升训练稳定性和收敛速度。输入数据的质量和代表性直接影响最终模型的泛化能力。

## 输出

训练完成后，工具箱主要产出：
- **训练好的神经网络模型**：以MATLAB函数（`.m`文件）或对象形式存在，可直接用于对新数据进行预测。
- **性能评估指标**：包括但不限于均方根误差（RMSE）、皮尔逊相关系数（Pearson R）等，用于量化模型在验证集和测试集上的表现。
- **训练脚本与自动代码**：工具箱可生成用于重现训练过程的MATLAB脚本，以及将网络封装为独立函数的代码，便于后续部署。

## 流程节点

1.  **数据准备与划分**：将可用数据集随机划分为训练集、验证集和测试集。一个常用的比例是80%-10%-10%（训练-验证-测试），该比例平衡了模型学习与泛化评估的需求。具体划分可通过MATLAB的`dividerand`等函数实现。
2.  **网络设计与配置**：根据任务类型选择网络架构（如前馈网络、LSTM等），并配置关键参数：
    - **激活函数**：对于隐藏层，常用双曲正切S型传递函数（`tansig`），它能输出范围在[-1, 1]之间的值，适用于大多数非线性映射问题。
    - **网络拓扑**：确定隐藏层数和每层神经元数量。网络复杂度需与数据规模和问题复杂度匹配，避免过拟合。
3.  **模型训练**：使用`train`函数启动训练过程。工具箱默认采用Levenberg-Marquardt反向传播算法，并支持早停（Early Stopping）等正则化技术以防止过拟合。训练过程中，验证集性能用于监控泛化误差。
4.  **性能评估与验证**：使用测试集对训练好的模型进行最终评估，计算RMSE、Pearson R等指标。可通过绘制预测值与实测值的散点图、残差图等方式进行可视化分析。
5.  **模型导出与部署**：通过工具箱功能将训练好的网络生成为独立的MATLAB函数（例如使用`genFunction`），该函数可直接在其他脚本或环境中调用，实现模型的迁移与部署。

## 边界与分流

- **与传统机器学习方法的边界**：对于线性关系明显或数据量较小的问题，可优先考虑使用Statistics and Machine Learning Toolbox中的逐步线性回归（Stepwise Linear Regression）或高斯过程回归（GPR），它们通常更简单、更可解释。神经网络更适用于捕捉复杂的非线性关系。
- **与其他深度学习框架的边界**：Neural Network Toolbox是MATLAB生态的一部分，与MATLAB的数据处理、可视化工具无缝集成。若项目技术栈以Python为主，或需要大规模分布式训练，则应考虑TensorFlow或PyTorch等框架。
- **与上游流程的衔接**：输入特征向量通常来自上游的数据预处理流程（如特征工程、缺失值处理）。确保输入格式与网络输入层维度一致。

## 质量检查

- **训练过程监控**：观察训练、验证和测试集的误差曲线。理想情况下，三条曲线应同步下降并在训练后期趋于平稳。若验证集误差在训练后期开始上升，则表明可能发生过拟合。
- **过拟合诊断**：比较训练集和测试集的性能指标（如RMSE）。若训练集误差远低于测试集误差，说明模型泛化能力不足，需简化网络结构、增加正则化或获取更多数据。
- **残差分析**：检查预测残差是否随机分布。若残差呈现系统性模式（如趋势或周期），则表明模型可能未能捕捉某些重要特征或关系。

## 回退策略

- **网络拓扑过复杂导致过拟合**：若出现过拟合，应简化网络结构（减少层数或神经元数量）。同时，可启用并调整正则化参数（如`L2WeightDecay`），或增加训练集的噪声数据。
- **激活函数选择不当**：若`tansig`函数导致训练不稳定或性能不佳，可尝试更换为线性传递函数（`purelin`）或ReLU函数（需自定义或使用特定网络类型），以适应不同数据特性。
- **训练不收敛**：检查数据是否已归一化；尝试调整学习率、动量参数；或更换优化算法（如将训练函数从`trainlm`改为`trainscg`）。
