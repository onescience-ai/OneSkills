# 气溶胶化学组分监测仪

## 适用范围

用于对环境大气中亚微米气溶胶（PM1）的主要非折射性化学组分进行在线、连续、近实时的质量浓度监测。该仪器适用于长期大气观测站、区域空气质量监测网络以及短期外场观测实验中对气溶胶化学组分的高频采样分析。典型应用场景包括：城市与郊区背景站的气溶胶化学组分长期趋势观测；重污染事件期间化学组分的快速响应追踪；为正矩阵因子分解（PMF）等源解析方法提供高质量输入数据；以及为大气化学传输模型（CTM）提供化学组分的观测约束与模型评估基准。

适用条件：被测气溶胶主要为非折射性组分（有机物、铵盐、硫酸盐、硝酸盐、氯化物）；仪器需要稳定的供电、数据传输和环境控制条件；操作人员需具备基本的气溶胶质谱或气溶胶在线分析技术背景。

## 输入

- **必需输入**：经过采样入口（通常配备粒径切割器，如 PM1 或 PM2.5 切割头）引入的环境空气气溶胶样品。
- **采样条件**：环境温度、湿度应在仪器正常工作范围内（通常为 0–40°C，相对湿度 <90%）；采样流量由仪器内置流量控制器精确维持（典型值约 0.1 L/min）。
