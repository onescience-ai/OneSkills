# GenCast全球概率天气预报模型

## 适用范围

一种基于条件扩散模型和图神经网络的全球概率天气预报模型，通过迭代去噪过程生成15天、0.25°分辨率的全球集合预报。其技巧和速度优于欧洲中期天气预报中心（ECMWF）的业务集合预报系统ENS。模型训练使用ERA5再分析数据，采用两阶段训练策略（先1°分辨率预训练，后0.25°分辨率微调），并利用条件扩散采样协议从噪声中恢复天气状态。

当任务目标与该知识所述场景一致时，可复用本条目。

## 输入

- 初始天气状态 (X0, X-1) - 来自ERA5分析数据
- 初始噪声样本 (Z0) - 用于扩散采样

## 输出

- 未来天气状态 (X1:T) - 15天、30步的全球天气轨迹集合
- 集合预报轨迹 - 每个时间步的天气状态，分辨率为0.25°纬度-经度网格

## 流程节点

1. 初始化：使用两个连续的ERA5分析状态 (X0, X-1) 作为模型输入条件。
2. 噪声采样：从尊重全球几何的球面高斯白噪声分布Pnoise中，为每个预测时间步采样初始噪声样本 Z0。
3. 迭代去噪：使用ODE求解器（DPMSolver++2S）对噪声样本进行N=20步迭代精炼。在每一步，调用去噪神经网络 Dθ，以噪声状态Zσ、前两步状态(Xt-1, Xt-2)和噪声级别σ为输入，预测期望的无噪声残差。
4. 状态更新：将去噪得到的残差（经归一化矩阵S调整后）加到前一状态上，计算当前时间步的天气状态 Xt。
5. 自回归生成：将 Xt 和 Xt-1 作为条件，重复上述过程，自回归生成完整的15天预报轨迹。
6. 集合生成：对多个初始噪声样本重复上述过程，生成集合预报轨迹。

## 前提条件

- 需要至少两个连续的ERA5分析状态作为初始化数据
- 需要Cloud TPUv5或类似硬件进行训练和推理
- 需要ERA5再分析数据集进行训练

## 边界与分流

- 相关资产/可替代方案：ERA5 (训练和初始化数据源)
- 相关资产/可替代方案：ENS (比较基准，ECMWF业务集合预报)
- 相关资产/可替代方案：GraphCast (架构基础，GenCast的去噪器架构相关)
- 相关资产/可替代方案：GenCast-Perturbed (使用GenCast架构的确定性基线模型)
- 相关资产/可替代方案：球面扩散模型 (噪声分布的理论基础)

## 回退策略

- 在更长的提前期，预报的不确定性可能增加，集合成员的分散度可能变大
- 需要较高的计算资源（TPUv5）进行训练和推理
- 若训练数据时间步长选择不当（如使用1小时步长），可能引入双峰分布问题
- 分辨率过渡时未调整编码器GNN的信号尺度，可能导致微调初期训练不稳定
- 如果噪声分布选择不当（如i.i.d.高斯），可能导致生成的预报缺乏真实的物理功率谱
- 求解器步数N不足可能导致去噪不完全，影响样本质量
