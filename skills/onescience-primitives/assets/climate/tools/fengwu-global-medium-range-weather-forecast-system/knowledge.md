# FengWu全球中期天气预报系统

## 适用范围

本知识描述一个基于深度学习的全球中期天气预报工具系统，适用于需要处理多模态、高分辨率气象数据（如不同压力层的大气变量与地面变量）并生成未来一周至两周逐6小时全球预报的任务。典型应用场景包括：开发和评估数据驱动的数值天气预报模型、研究气象变量间的跨模态特征交互、探索如何通过训练策略抑制长提前期（如10天以上）预报的误差累积问题。该系统提供从数据准备、模型训练到自回归推理与评估的完整工作流，其核心方法（多模态特征融合、不确定性加权、重放缓冲）具有较强的通用性，可迁移至其他需要处理高维时空序列预报的地球科学或复杂系统预测场景。

## 输入

- **必需输入**：当前全球大气与地面状态的快照数据。
  - **数据源**：通常为ERA5再分析数据集或其他同等级别的全球再分析产品。
  - **格式与维度**：数据需整理为张量格式，维度为 `(C, W, H)`。其中，`C` 为通道数，对应所有预测变量；`W` 和 `H` 分别为纬度和经度的网格数。
  - **变量覆盖**：典型配置为189个变量，包括5个大气变量（如温度、风、位势高度、比湿等）在37个垂直压力层（从1000 hPa至1 hPa）上的值，以及4个地面变量（如海平面气压、2米温度等）。
  - **空间分辨率**：0.25° 纬度-经度网格（对应 `W=721, H=1440`）。
  - **时间戳**：输入状态对应特定时刻（例如，UTC时间00:00, 06:00, 12:00, 18:00）。
- **可选输入**：在训练阶段，需要预先划分好的历史时间段数据集，用于训练、验证和测试。系统采用固定划分策略：训练集为1979-2015年，验证集为2016-2017年，测试集为2018年。数据采样频率通常为6小时一次（T00, T06, T12, T18）。

## 输出

- **预报数据**：以初始状态为起点，自回归生成的未来1至14天（即1至56个时间步，步长为6小时）的全球气象状态预测序列。
- **数据格式与维度**：输出序列包含与输入相同数量的变量（189个），空间分辨率与输入保持一致（0.25°）。每个时间步的输出为一个 `(C, W, H)` 张量。
- **下游用途**：输出数据可直接用于预报技巧评估（计算RMSE、ACC等指标）、与业务模式或再分析数据进行对比，或作为下游气候/天气应用研究的输入。

## 流程节点

以下流程描述了一个可复现的端到端工作流，其核心步骤构成一个有向无环图（DAG）。

1.  **数据准备与预处理** (`s1`)
    - **上游依赖**：无。
    - **步骤描述**：获取原始ERA5再分析数据集，按照预设的时间范围（训练：1979-2015；验证：2016-2017；测试：2018）和采样频率（6小时）进行切分、标准化等预处理，并转换为模型所需的张量格式。
    - **关键参数**：
        - `era5_path` (类型：`str`，必需)：指向ERA5数据集的存储路径。
    - **质量门**：处理后的数据集必须完整覆盖所有189个预测变量（5个大气变量×37层 + 4个地面变量），且时间序列连续。
    - **产出**：训练数据集、验证数据集、测试数据集。

2.  **模型训练** (`s2`)
    - **上游依赖**：`s1`。
    - **步骤描述**：加载预处理好的训练数据，初始化模型架构（包含多模态编码器-解码器、跨模态融合Transformer），并启用不确定性损失和重放缓冲机制进行训练。训练过程中，使用验证集数据定期评估模型表现以调整超参数。
    - **关键参数**：
        - `epochs` (类型：`int`，必需)：训练的总周期数，需根据计算资源（典型配置为32块NVIDIA A100 GPU）和收敛情况确定。
    - **质量门**：在验证集上，关键预报指标（例如500 hPa位势高度场的异常相关系数，ACC）需达到预设的性能阈值。
    - **产出**：训练完成的模型检查点文件。

3.  **模型推理** (`s3`)
    - **上游依赖**：`s2`。
    - **步骤描述**：加载训练好的模型检查点，给定一个初始天气状态张量，模型以自回归方式逐步生成未来多个时间步的预测。
    - **关键参数**：
        - `init_state` (类型：`tensor`，必需)：初始天气状态，形状为 `(C, W, H)` 的张量。
    - **质量门**：在单张NVIDIA A100 GPU上，生成完整10天预报（40个时间步）的推理耗时应显著低于传统数值模式（典型值小于30秒）。
    - **产出**：未来14天的完整预报序列。

4.  **结果评估与可视化** (`s4`)
    - **上游依赖**：`s3`。
    - **步骤描述**：将模型预测序列与同期的ERA5测试集真值进行对比，计算各变量在不同提前期（1天至14天）的均方根误差（RMSE）和异常相关系数（ACC），并与基准模型（如GraphCast）的结果进行对比。
    - **关键参数**：
        - `pred_data` (类型：`tensor`，必需)：模型输出的预测数据。
        - `gt_data` (类型：`tensor`，必需)：用于对比的ERA5真值数据。
    - **质量门**：在核心变量（如500 hPa位势高度场）上，10天提前期的ACC值应大于0.6，标志着达到了“有技巧”的预报水平。在整体评估中，应有超过80%的预测变量的ACC指标优于基准模型。
    - **产出**：各变量的RMSE和ACC随提前期变化的曲线图、预测场与真值场的对比可视化图。

## 边界与分流

- **适用边界**：本系统专注于基于AI的、以固定时间步自回归驱动的全球确定性中期预报。其优势在于处理多模态数据融合与抑制长提前期误差。训练和推理高度依赖于特定格式（如ERA5）和分辨率的再分析数据。
- **分流建议**：
    - **若任务需要概率性预报或集合预报**：单纯的自回归确定性预报无法提供不确定性估计。此时应考虑在模型中引入概率输出层（如预测分布参数），或使用其他生成式模型方法。
    - **若预报目标为极端天气事件或快速演变的强对流系统**：该系统基于6小时固定时间步的再分析数据训练，对生命周期短于6小时的系统捕捉能力有限。需转向更高时间分辨率数据或专门针对短临预报的模型。
    - **若计算资源严重受限（无法使用多块高端GPU训练）**：该系统的训练对硬件（如32块A100 GPU）有较高要求。可考虑使用更简化的模型架构，或采用迁移学习、预训练微调等策略降低资源门槛。
    - **若输入数据为非ERA5格式或分辨率差异大**：需重新进行数据预处理以匹配模型输入要求，或对模型进行微调以适应新的数据分布。

## 质量检查

为确保预报结果可靠，应在评估阶段实施以下检查：
1.  **指标基准验证**：在独立的测试集（如2018年）上，必须验证关键指标。对于北半球中纬度区域（如40°N-60°N）的500 hPa位势高度场（Z500），10天提前期的异常相关系数（ACC）是公认的技巧预报阈值，需确保其值大于0.6。
2.  **多变量覆盖验证**：系统预报变量众多，需检查绝大多数（如80%以上）变量在主要预报技巧指标（ACC）上是否达到或超过现有基准模型（如GraphCast）的性能，以确认系统的整体优势并非仅限于少数变量。
3.  **物理一致性检查**：对预报结果进行定性可视化分析，检查是否存在明显的物理不一致（如虚假的数值振荡、不合理的能量耗散），尽管这是定性检查，但对模型可信度至关重要。
4.  **计算效率验证**：检查推理时间是否符合承诺（例如，单次迭代推理时间约为600毫秒），确保其实时业务应用潜力。

## 回退策略

当遇到已知的失败模式或执行中断时，可采取以下策略：
1.  **应对误差累积问题**：如果发现长提前期预报技巧下降过快，应确保训练流程中**严格启用了重放缓冲机制**。该机制通过存储历史预测结果作为训练输入来模拟推理误差，是抑制误差累积的关键。若未启用，必须返回模型训练步骤重新配置。
2.  **应对优化困难问题**：如果直接端到端训练14天预测任务导致损失不下降或震荡，可考虑调整训练策略。首先，检查是否因数据量过大（每步预测数据量巨大）导致。可尝试先从较短提前期（如3天）开始训练，逐步增加预测长度。其次，确保不确定性损失已正确应用，它能自动平衡不同变量、不同位置和不同压力层之间的训练权重。
3.  **应对硬件资源不足**：
    - **训练阶段**：若GPU集群规模不足（少于32块A100），可显著延长训练周期，或采用梯度累积等策略模拟大batch训练。
    - **推理阶段**：若单卡显存不足处理完整数据，需将模型部署到多卡环境，或将数据沿空间维度进行分块（tilling）处理后拼接结果。
    - **重放缓冲内存**：重放缓冲区数据存储在CPU内存中，若CPU内存不足，需减小缓冲区大小或优化数据类型。

## 资源召回建议

- **核心框架与工具**：
    - **深度学习框架**：PyTorch。
    - **硬件平台**：NVIDIA A100 GPU（训练与推理）。
    - **参考实现**：开源代码库（如FengWu）提供了从数据处理到评估的完整脚本。
- **关键数据源**：
    - **ERA5 再分析数据集**：这是训练、验证和测试的核心数据源，由欧洲中期天气预报中心（ECMWF）发布。
- **相关模型与方法**：
    - **对比模型**：可参考GraphCast等同类数据驱动预报模型的评估方法和结果，进行横向对比。
    - **核心方法组件**：需进一步了解的术语包括多模态Transformer、不确定性加权损失（基于同方差不确定性）、重放缓冲机制（源自强化学习）。
- **评估指标库**：
    - **均方根误差（RMSE）**：衡量预报值与真值之间的绝对误差。
    - **异常相关系数（ACC）**：衡量预报场与真值场在异常空间上的相似性，是判断预报技巧（skillful forecast）的核心指标。
